# 高地双手剑第三人称检查（2026-11-06）

结论：尚不合格。本轮只增加检查工具、构建并保存检查证据，没有修改正式动作资源或战斗逻辑。

## 实际检查范围

- 后台 UnrealEditor-Cmd 运行当前 `UFPSPlayerBodyAnimInstance`，使用当前 Jason / Kaitlin 身体网格，保留各自的 Post Process AnimInstance。
- 普通 / 长握柄各采样横扫、重击强化突刺、普通第三击、冲刺突刺、取消蓄力、移动中突刺，共 24 个组合。
- 动画图以 60 Hz 更新，最终骨骼以 30 Hz 保存；从当前 UE LOD0 渲染缓冲读取顶点、三角形和权重，在 Blender 中渲染最终骨骼驱动的皮肤及当前武器部件。
- 身体为无服装基础网格，便于检查腕臂；头部等模块未加入预览。渲染不代表游戏最终材质效果。
- 使用人工提供的等价表现状态，没有运行真实玩家输入、角色移动执行器或双端网络传输。不能据此宣称联机整体验收通过。

## 确认的问题

1. **强化突刺的第三人称动作来源不符合设计。** `FPSBodySwordMotion.h` 把强化突刺蓄力和所有突刺释放均路由到 `Melee.FullBody.Thrust`。当前配置仍是 Kevin 的 `Attack2H01`（Kaitlin 使用其对应重定向版本），渲染表现为上举蓄势、大幅前俯下劈，不是与第一人称一致的水平收剑、前刺。
2. **强化突刺出手时腕部转动突兀。** `FPSPlayerBodyAnimInstance.cpp` 将旧动作从 `0.7 × Contact` 快速推进至 Contact / Release。四个体型握柄组合在释放开始后约 0.033 秒，右腕相对前臂变化约 102.5°–115.9°，左腕约 115.8°–130.2°。结合正反面蒙皮近景，不可判为自然流畅。第三击和冲刺复用同一来源，也受影响。
3. **横扫虽已接入专用全身动作，握持仍不合格。** 当前渲染在横扫中段可见不自然折腕，在收势可见左手离开握柄。男女体型均可复现。不能以 NativeSwordGrip 标记、有限数值或动作已加载代替视觉通过。
4. **横扫表现与判定时序存在偏差。** 当前第一人称横扫及 FromReady 均为 1.333333 秒，全身横扫为 1.2 秒；动画图对该变体直接使用归一化进度。以 2 倍播放速度计算，第三人称 Contact / Release 标记相对执行器约延后 16.7 / 26.1 毫秒。应按接触标记映射时间，或重新统一经过确认的动画时序。

后续修复应先为强化突刺制作合适的独立全身动作，再修横扫完整肩—肘—腕链、双手握柄与收势，最后复核时间映射及联机观察者表现。
