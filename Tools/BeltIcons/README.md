# 腰带物品图标统一规则

用户于 2026-10-25 确认：战术弹匣、破阵近战、星律导能腰带统一横 3 × 竖 2 格，以星律扣具正面略俯视的机位展示。皮革箭袋腰带保持原有横 2 × 竖 3 格与斜前视角。

`policy.json` 为三款腰带制作与发布的共同设置。每格 160 像素，正式图标为 480 × 320 透明 PNG，保持模型比例，正交机位偏移为 `(0.12, -3.0, 1.05)`，轮廓主轴约填满画布 91%。

`render.py` 从各自保存的图标 Blend 生成正式图片，星律使用 KeeperFixR2；不重新制作穿戴或掉落模型。通过现有互斥桥执行 `save_icons.py` 保存三张 UE UI 贴图，再执行 `publish.py` 按字段更新目录及两个 PNG 路径。现有战术与战斗腰带制作入口也读取同一规则。

本轮记录在 `SourceAssets/BeltIcons20261025/ArcaneFrontR1/published.json`，它是该修订图标的当前记录；各腰带较早的 saved_assets / published 回执保留为历史。

旧实例沿 `MigrateAuthoredItemFootprint` 迁移，保留旋转状态。主背包、夹层、仓库及联机共享容器沿既有重排流程处理扩大后的物品，空间不足不丢弃物品。共享掉落与拾取入口同步尺寸。未主动运行游戏、联机测试或视觉验收。
