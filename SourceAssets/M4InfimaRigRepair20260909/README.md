# M4 手臂骨架与换弹修复 — 2026-09-09

## 修改

- 新资源目录：`/Game/Weapons/M4InfimaRigV4`。原 `M4InfimaV3` 和原始源文件保留。
- 重建 98 根骨骼的有效父子层级，保留手臂、手指链；扳机、弹匣、枪机和瞄具以机匣为父级。弹匣仍按原换弹路径运动。
- 将扳机铰接点移到当前 M4 扳机几何的上端，保留原开火旋转，避免围绕模板枪械的错误轴心摆出护圈。
- 根据现有 Infima 动作烘焙 60 Hz 局部轨道，四元数保持同半球连续，关闭 FBX 关键帧简化。
- 为新动画设置专用 ACL 压缩精度和目标骨骼网格，关闭关键帧剥离。
- 角色使用新网格与新动画；瞄准校准累积完整父级变换，取消重复的 100 倍单位换算。
- 普通换弹仍为 2.7 秒，空仓换弹仍为 3.466667 秒；二者沿用源 Reload 0–94 帧。没有新增独立空仓拉机柄动作。

## 源文件与复现

- `SK_M4_Infima_RigRepair.blend`：可编辑修复源文件。
- `build_rig.py`：从原 `SourceAssets/M4Infima/M4_Infima_Candidate.blend` 重建；Blender 5.1 后台运行。
- `SK_M4_Infima.fbx`、`A_AKM_*.fbx`：网格和 8 段动画。
- `import_rig.py`：UE Python 命令行导入，复用 V3 材质。
- `validate_ue.py` / `analyze_ue.py`：UE 原始与压缩姿态读取、子帧误差比较。
- `render_candidate.py`：实际修复模型的扳机特写、换弹接触姿态预览。
- `create_validation_map.py`：独立空旷测试场，避免主场景设施影响动作回归。
- `run_validation.ps1`：在独立游戏进程内通过 PlayerController 输入运行现有枪械验收。
