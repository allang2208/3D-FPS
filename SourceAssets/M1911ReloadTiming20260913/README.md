# M1911 reload ready timing

用户反馈上一版换弹时间仍过长。本轮缩短两个实际动画资产的回握收尾，同时沿用导入动画长度驱动枪匠属性、动作状态、接触音效和补弹完成。

| 动作 | 旧文件长度 | 主动作保持原样至 | 新归位结束 |
| --- | ---: | ---: | ---: |
| 普通换弹 | 2.233333 s | 1.600 s | 1.750 s |
| 空仓换弹 | 2.733333 s | 2.100 s | 2.250 s |

读取当前 Contact 源关键帧发现：普通换弹 1.6 秒时，左手相对待机握持的腕部偏差约 0.58 mm / 0.75°；空仓 2.1 秒时约 0.22 mm / 0.32°。此后仍有枪体的衰减归位与静止尾帧。上一版按完整文件长度等待，未缩短这一段。

保留普通前 1.6 秒、空仓前 2.1 秒所有骨骼轨道；之后用 0.15 秒平滑完成整套枪／手姿态归位，最终精确衔接已接受的待机姿态。不是全段倍速：退匣 38/120、插匣 126/120、压实 128/120 和空仓释放 192/120 秒不变。两个片段各缩短约 0.483 秒。

- `read_source_timing.py` / `source_timing.json`：为定位本次等待问题读取原有骨骼关键帧，未渲染或运行游戏。
- `author_reload_ready.py`：在当前 Contact 可编辑源基础上制作两个独立动作，保留其余枪械、配件和手型。
- `M1911_ReloadReady_Editable.blend`：可编辑动作源；FBX 位于 `Animations/`，120 Hz 烘焙。
- `import_animations.py` / `import.json`：导入 `/Game/Weapons/M1911/ReloadReady20260913/Animations/`，沿用当前 M1911 骨架和压缩设置。
- `M1911WeaponAssets.h`：仅将 `reload` / `reload_empty` 路由到新目录，其余动作继续使用 Contact 版本；角色和枪匠共用这一入口。
- `gunsmith.json`：默认普通／空仓时间同步到 1.75 / 2.25 秒，运行时仍以当前动画真实长度和配件倍率为准。

本轮只做了必要的问题定位、动作制作、资源导入和原生构建。未启动游戏或执行自测、验收渲染；需重启 UE 编辑器后由用户体验新的换弹时长。

导入记录中的实际资产长度为 1.75 / 2.25 秒，两个新片段仍引用原来的 `P9Retarget20260913/SK_M1911_Manny_Skeleton`。动画单独 FBX 的绑定姿势提示未改变该骨架引用。必要构建结果 `Succeeded`，输出 `UnrealEditor-FPSGAME-913192626.dll`。导入脚本完成，但命令行进程因工程既有 GameFeatureData 与 8000 端口报错返回 1；未将这一结果记为游戏验收通过。
