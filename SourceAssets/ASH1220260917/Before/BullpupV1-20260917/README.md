# 斗牛犬换弹第一版（2026-09-18 备份）

本目录留两件东西，是"滚转时机放错半段"那一版的现场：

- `build.py`：**斗牛犬编排的第一版脚本**。它把 60° 侧滚的峰值放在**换弹匣那半段**（帧 42）、之后回落；弹匣被甩出画面再回来。
- `A_ASH12_reload_empty.pre-bullpup.fbx`：重做**之前**的空仓换弹片段（仍是 M4 基底分工：左手走弹匣路径、右手钉在握把）。FBX 按忽略规则不进仓库，只留本地。

**注意**：M4 基底的*脚本*不在这里，在 `Before/M4ReloadBaseline20260917/build.py`（上一轮留的）。

保留原因：用户实机反馈"看不见换匣"后，第二版把滚转改成换匣段稳定 44–50°、拉栓帧 120 峰值，并把弹匣改成紧凑换位。两版对照能看清"滚转时机放错半段"的具体差别。

恢复方式：把 `build.py` 覆盖回 `Scripts/build.py`（覆盖前先备份当前脚本），再按项目 README 第 1 节末尾的顺序重建 → 导入 → 复测。
