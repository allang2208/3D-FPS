## 修正内容

- 两枪的前臂主骨与 twist 辅助骨原先分别累加旋转，接触段存在较大的相对扭转。在线性蒙皮下，这会把腕臂表面压成尖锥或折叠；PKM 图中的连接缺口属于这种蒙皮塌缩，源手臂并没有删除该处顶点。本轮修正骨骼变换，没有添加替代连接网格或遮挡件。
- 使用掌宽方向在前臂垂面上的投影定义前臂轴向旋转，避免把手腕屈伸当成前臂扭转。大小臂辅助骨随对应整段运动，并保留相对于主骨的参考变换，移除互相抵消的额外分段扭转。
- SVD 以当前模块化枪身的 `SM_SVD_RetainedGrip` 为基准重新拟合右手。旧移植右手偏移使主要手指接触区距握把约三厘米；本轮调整手掌整体位置和角度，并小幅调整中指、无名指、小指及拇指的屈曲。握把和扳机本身不移动。
- SVD 校准在近战起势中进入，收势时回到现有 idle；此轮只修改快速近战，不将校准扩散到 idle、换弹或其他动作。右肘使用固定骨长解算跟随新握点。
- 保留上一版枪根及机械部件轨迹、0.9 秒时长、1/6 秒命中时点、五类握把分支与原运行路径。保持骨架参考姿态、骨长、蒙皮权重、模型和材质，无 C++ 改动。
