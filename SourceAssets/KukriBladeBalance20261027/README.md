## 消耗归属

- 普通攻击与重击出手保留既有单手基础消耗和消耗下限；刀身倍率覆盖重击蓄力每秒消耗。
- 快速打击读取实际出招武器：主手弯刀取主手，手枪配副手弯刀取副手。客户端、服务端及技能显示调用同一入口。
- 挑击已有主手／手枪配副手选择入口，大旋风使用实际发动旋风的主手刀；各自按所选武器计算体力。
- 双刀普通连击和双刀冲刺攻击保留已有的动作基础总消耗，将其分为两份，分别应用两把刀的倍率后合计。不会相乘两把刀的倍率，也不会把主手倍率重复使用两次。
- 双刀扫砍的左右段分别使用自身攻速、伤害、削韧和武器实例；同时突刺共用动作时钟，取两把刀各自耗时的平均值，命中仍分别结算。
- 双刀冲刺攻击沿用两把刀物理伤害相加的设计；各自先计算自身伤害和削韧贡献，再合并本次判定。重击、挑击、柄尾快速打击及现有大旋风仍沿用其单刀动作归属。
- 防御、闪避、奔跑不读取本次刀身攻击体力倍率。未修改动作、基础技能消耗、技能冷却与游戏存档。
