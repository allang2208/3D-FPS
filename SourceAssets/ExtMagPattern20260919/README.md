# 三枪扩容弹匣：原厂表面延续修订

本轮针对用户否决上一版的弯曲弧度、纹路和材质延展而制作。未将旧版“弧管定稿”或已导入资产视为接受标准。

## 制作变化

- 来源是三枪自己的原厂弹匣。`author.py` 从上一轮源文件中保留的 `Factory_M4 / Factory_AKM / Factory_QBZ` 副本取原件，不读取上一轮延长网格。原始 FBX 来源见上一轮 `build_magazines.py`。
- 排除喉部和斜底板后，分别使用前后轮廓拟合共同圆心与两个半径。圆弧参数只用于本轮这些源件；不是所有弹匣都应采用圆弧。
- 在圆柱曲线坐标内剪出真实表面单元，保留每个面的 UV。M4 以约 12.5 mm 的纹路单元延长 5 段；QBZ 以约 31 mm 的分区单元延长 2 段；AKM 以 30 mm 纵筋段延长 2 段。参数见 `parameters.json`。
- 切环具有不同截面时，差异分布到整个单元；两边使用共有的角向分割点，避免刚性配准后硬钉一圈。M4 内外两层壳分别处理。底板沿相同圆弧移动，插接段和上段保留原件。
- 复用原厂完整面片与 UV，撤掉通用横肋和最近三角面 UV 外推。极小拼接边按 0.01 mm 合并，退化细面在导出时消解。
- 游戏材质继续使用各枪宿主的弹匣槽。图标从新源网格和源贴图生成，1024 RGBA；Blender 材质转换不等于 UE 实机材质验收。

## 文件和接入

- `author.py`：源模型处理及 FBX/Blender 导出。
- `export_tangents.py`：少数切分角点的 Mikk 切线为零时，从相邻面的方向构造正交切线基并写入 FBX；保持 UV 不变，不改 Blender 安装文件。UE 导入原始法线和切线。此处理不等于实机着色验收。
- `FBX/SM_ExtMag_*.fbx`、`*_ExtMag_Editable.blend`：模型交付。
- `make_icons.py`、`*_IconStudio.blend`、`Icons/`：配件图标制作源。
- `install_assets.py`、`install_receipt.json`：导入及材质绑定。
- UE 目录 `/Game/Weapons/ExtMagPattern20260919/Surface`，由 `M4DrumVisual.cpp` 的三枪扩容分支使用。
- 延续现有 M4 扩容换弹专用动作，本轮不再次移动手臂。容量、物品 ID 和存档字段不改。

## 技能修订

个人和工程镜像中的 `ue5-weapon-workflow/references/extmag-lengthening.md` 已同步替换矛盾规则：不再同时要求“复制优先”和“禁止复制”；说明失败的是忽略截面/曲线差异的刚性复制。撤销光滑弧管的“定稿”称呼，明确材质绑定不等于 UV 延展完成，失败版本不作为下一轮默认母版。
