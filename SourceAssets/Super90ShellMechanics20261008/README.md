# Super90 侧挂备弹与检视枪机修复

2026-10-08。用户反馈枪械右侧的红色霰弹消失、检视时拉机柄自行移动。

## 原因

- `Super90_body` 中的侧挂备弹绑定 `WPN_root`，有 830 个面；独立装填弹药 `12g_12gauge_0` 则绑定 `WPN_Shell`。两者此前都叫 `12gauge`，导入后共用材质区块。为了去掉脚边的独立弹药而隐藏该槽时，侧挂备弹被一并隐藏。
- `author_super90.py` 从最后一发射击后查看空膛的源片段生成检视。它全程保持开膛，枪机相对枪身比闭膛待机后退约 10.77 cm；进入和退出检视时的混合就造成拉机柄自行移动。普通逐发补弹原本是闭膛，快速装填的普通分支也只使用闭膛位置。

## 修改范围

- 侧挂备弹独立使用 `12gauge_mounted` 槽，继续绑定枪身并使用原 `12gauge` 的红色材质、几何与 UV。独立装填弹药继续使用原 `12gauge` 槽，沿用当前隐藏规则。因此持枪、检视、展示副本和随身模型都能保留侧挂备弹，脚边弹药不会随之恢复。
- 检视只替换 `WPN_bolt` 的局部轨道为当前待机闭膛值，不重做手部和枪身动作、不改变时长。导入时同时处理握把配置中存在的独立 retained 检视片段。
- 开火的枪机往复、空仓换弹的释放/上膛、装填事件及 R6 的 0.85 倍播放配置保持现有路径。
- 同步原始作者、WS1 重建入口和主导入材质别名，防止之后重导入再合并两种弹药的显示身份。
- 网格重导入后按材质槽名重写手部装备隐藏索引，保留新槽之外的原材质。

半自动机构的参考为 [Benelli 官方 M4 手册](https://www.benelliusa.com/sites/default/files/content/media/manuals/2019-10/M4%20Tactical%20Shotgun%20Product%20Manual.pdf) 的 Operation 章节；本轮只调整游戏动画，不把开火时正常往复误删为故障。

## 制作与保存

- `author_repair.py`：保留当前几何、UV、蒙皮和骨架，导出分槽网格与修订后的检视制作源。
- `import_repair.py`：保存分槽网格，并直接修改当前 UE 检视的枪机轨道，保留其他已编辑轨道。
- `publish_source.py`：在实际资产保存完成后同步正式 Blend/FBX。
- 变更前的文件和目标资产保存在 `Before/`；实际保存结果见 `import_receipt.json`。
