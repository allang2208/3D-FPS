# Twinblast 双持换弹与左轮专项检查

用户于 2026-10-22 明确要求检查手枪换弹，特别是左轮，排除穿模或错误。范围为本对话正在开发的第三人称双持；使用隔离 commandlet，不启动 GUI／PIE，不写玩家存档。

## 先修正检查入口

旧 `DualPistolStandardsReview.inl` 把左轮 `reload` 固定替换成 `speed_0`、`reload_empty` 替换成空仓补满，没有覆盖逐发只补一发／非空仓补弹。它还清空 `ActionPoseProfile`，没有按生产入口选择动作姿态层；首次大步长 Tick 跳过了 0.12 秒动作交接。

新增显式入口 `-DualReloadReview`，仅用户指定该参数时启用：

- 用真实 `StartAction` 选择每手片段与姿态层；用生产 `SampleActionTime` 取甩枪重定时后的源时间。
- 根据逐发数量、退壳与入弹时间更新隔离样本中的弹药可见状态；不执行玩家库存提交。
- 每组先以 60 Hz 稳定持枪，再以真实帧步长进入换弹；分别记录完整与中断回握。
- 检查实际蒙皮前臂／手、可见枪体和配件对 Jason 躯干的穿入；逐个比对源与世界武器的 `WPN_` 机械骨，记录位置与旋转差。
- 检查原生骨长、有限变换、腕部角度、另一手的独立性及 60 Hz 腕点连续性。旧的“肩腕伸展比例必须小于 0.97”是旧合成姿态指标，Twinblast 自身的自然源动作会略超过它；本轮直接测骨长，不修改原动作迁就旧阈值。

`-QuickReload` 选代表分支：逐发空仓仅装一发、空仓补满、剩一发待补的非空仓补弹，以及空／非空状态的快速装弹器。每个分支分别覆盖右、左、同时两手。完整／中断回握另覆盖三种手掩码。`-ReloadStress` 补充蹲姿、横向移动、上下瞄向、另一枪射击；不传 `-QuickReload` 才会逐一枚举所有起始装弹数和装填数。

## 已定位的问题与修改

`rsh-before.json`：18 组代表状态、5,241 个姿态，273 项检查中 30 项失败。其中 18 项是上述旧伸展比例误报，12 项是右手／双手换弹的真实连续性问题。该轮躯干穿入测量均为零，但不能据此称换弹正确。

右手单发换弹在显示时间 0.2667→0.2833 s（重定时源时间 0.2134→0.2539 s）跳约 9.31 cm，快速装弹器约 9.79 cm。`rsh-transition.json` 进一步保存源动作差量和最终手腕：源手平移变化不足 3 cm，掌向变化经旧腕点、肩肘重建及枪体前侧约束后被放大到最终腕位。

`FPSBodyDualPistolSource.inl` 现将双持换弹也归入完整源手臂的所有权：沿当前 Twinblast 手臂整体运输源动作差量，不先转腕再追着枪体边界重建肘面。第一人称画外的甩动以较小幅度适配全身；保持肘腕相对旋转、原生骨长和 twist 站。握枪手指、装填时钟和库存规则保持原路径。装备和砸击仍沿此前各自路径。

首次扩展矩阵 `reload-matrix-01.json`：108 组状态、25,584 个姿态、1,585 项检查，左轮分支无失败，普通手枪有四项枪械网格穿入。`part-diagnosis.json` 定位到 M1911／G18／Pit Viper 的真实 `WPN_SOCKET_Magazine` 网格（骨缩放仍为 100，不是隐藏点误报）。第一人称取匣路径的横向后伸在第三人称横移时跨过腹部。`FPSPlayerBodyMotion.cpp` 将该三枪双持换弹的弹匣整体后伸缩至 20%，保留武器基准竖向抽插行程、所有旋转／尺寸／时序及精确就位点；弹匣子树整体平移，避免拉长或拆散模型。左轮弹巢和装弹器不经过此处理。

对有意适配的离枪弹匣，复查真实身体净空、完整子树刚性、原抽插行程和实际就位接触；枪体与弹巢等未适配机械骨仍逐骨精确比较源动作。不把新轨迹与旧轨迹逐点相同当作正确条件，也不取消弹匣的接触和几何检查。

`rsh-fix-01.json` 同一失败片段定向复查：24 项检查无失败；右腕最大单帧位移约 2.26 cm，躯干穿入深度仍为零。此结果只证明该受控片段，最终扩展矩阵与构建结果在交付回执中记录。
