# 战术伸缩枪托表面修整 R1 — 2026-10-14

对象：枪匠配件 `tactical_telescopic`（战术伸缩枪托）。本轮基于原有 Meshy 造型修整，未重新生成模型。

后续用户截图反馈后的 R2 修复位于 `../M16AttachmentSurface20261014/README.md`：M16 的空 UV 通道/切线错配已进入精确恢复流程，共享后托法线改为修整高模重新烘焙的结构细节。本文件和回执保留 R1 历史，不代表 R2 后的最新资产散列。

## 制作内容

- 对现用 LOD0 几何进行双边面法线滤波和受限平面拟合，减轻生成模型的细碎凹凸。保留顶点/三角形拓扑、各 UV 层、材质分区与各枪装配坐标。
- 主体单点修整上限 0.65 mm，尾垫上限 0.2 mm；前端约 3.4 cm 不参与平滑，之后 1.3 cm 渐变过渡。各枪专用连接件、封板与支杆不参与修整，功能孔洞不填充。
- 仅对实际移动面重算法线，保留原有法线分裂边；用 GeometryScript 重建切线并保留作者切线，不在资产构建时再次覆盖。启用全精度 UV 和高精度切线；M16 沿用其 UV2 中的原枪托图集计算切线，所有 UV 数据本身保持原样。
- 用 Blender 材质烘焙将专用的旧生成法线起伏强度降至 0.18。保留原始贴图，以及 UE 的法线压缩、绿色通道、纹理组和流送设置；各枪的颜色、金属/聚合物/橡胶与淋湿材质绑定继续沿用。
- 处理 M4、AKM、QBZ191、M16、HK416、A762、PKM、SVD、LMG201、Super90 共 10 个现用配件网格。没有修改武器数据、动画、枪匠属性或其他后托类型。

## 文件与复现

- `inputs.json`：实际运行引用、材料绑定和制作前资产散列。
- `Before/`：本轮修改前的原始 UE 包备份，包含专用法线纹理。
- `Inputs/`：原始 FBX 和保留 UE 顶点编号的几何输入。
- `Refined/`：受限位置修订数据、制作中 Blender 源及减弱起伏的法线烘焙源。
- `Final/`：从保存后的 UE 网格导出的 FBX，以及由最终 FBX 保存的可编辑 Blender 几何源。正式材质仍以 UE 原资产为准。
- `authoring.json`：实际制作参数与逐枪位移记录。
- `install_receipt.json`：逐件保存结果及完成状态；不是游戏或视觉验收报告。
- `collect_inputs.py`、`refine_surface.py`、`install_surface.py`、`save_editable.py`：后台制作入口。基线采集拒绝覆盖已有备份；不要对已经修整的网格重复执行平滑。

原始高模及旧法线源仍位于 `SourceAssets/StockRefresh20260914/TacticalTelescopic/`。今后若从旧制作源重建配件，需要重新应用本轮表面修订；不要直接重导旧 FBX 覆盖本轮结果。
