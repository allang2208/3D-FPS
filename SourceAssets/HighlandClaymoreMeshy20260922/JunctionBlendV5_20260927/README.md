# 高地剑连接区 V5

2026-09-27，用户在 V4 重启加载后反馈剑身与护手、宝石附近仍有割裂感，要求继续优化。本轮只制作连接区与其模块拆分，保留五种剑身、五种护手的可替换关系。

## 几何与表面处理

1. 从原装可编辑模块及原阔锋、裂角作者源开始，将所选剑身和护手临时合为连续制作母版。移除旧 V 切口的封口面并焊合原交界边。旧封口扇心使用边界平均高度，未必落在 V 切平面上；本轮按作者封口 UV 标记识别整组封口，避免只按顶点平面条件漏掉斜穿连接区的面。
2. 接近护手时逐渐收起剑刃两侧的磨刃面，形成完整支承肩。去掉 V4 在横向 32 mm 处先收薄再增厚的厚度凹槽，与护翼根部平滑过渡。剑身主体仍为 12 mm，保留远端磨刃面和剑尖。
3. 连续母版先生成表面法线，再按三角形插值位置、UV、面角法线与顶点色拆分。新切口改为 `z=0.058+0.95*abs(x)` 米，位于宝石及镶边之上；整颗宝石与周围连接区完整归入护手。
4. 新封口扇心放在 V 的实际最低点，封口法线只用于隐藏端面。所有剑身/护手共享新接口；握把、配重、安装原点和攻击端点不变。

保留原材质与纹样、宝石切面及突出高度，没有增加遮缝饰圈、额外覆盖片或整体粗糙度遮掩。

## 文件与接入

- `Highland_ContinuousJunctionV5_Editable.blend`：所有改造件和连续连接区母版。
- `author_junction_v5.py`、`Export/`、`author_receipt.json`：后台制作和 11 个 FBX。
- `import_junction_v5.py`、`import_receipt.json`：UE 重导入与保存记录。
- `Before/<时间>/`：重导入前当前在用的 UE 包备份。
