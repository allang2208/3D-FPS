# 共振握把着色诊断

对象：seed91871，原始网格、纹理母版、修整母版及已接入版本的 M4 Blender 源。用户明确授权排查与对照渲染。

## 已完成实验

- 同一 M4 源网格、相机和灯光，分别渲染当前材质、关闭法线、关闭颜色/法线、低反光材质、白模；无顶点修改。
- raw、textured、repaired 用统一常量金属材质比较，同样去除所有图像贴图。
- 纹理母版单独清除自定义法线、以 1e-7 源单位合并接缝顶点、重新计算面法线并按35度硬边着色；未做形状平滑。它未显著消除现有表面起伏，不应作为修复版使用。
- 64采样、不降噪；图中少量颗粒为路径追踪噪声。未做 UE 游戏测试。

## 发现

1. M4 源金属区域没有法线贴图。关闭聚合物法线贴图后内框扭曲仍然存在；去掉颜色图也未消除它。
2. 高反光放大了已有表面起伏。低反光试验降低了闪亮扭曲观感，但不修复孔洞、折面或形状。
3. raw 11622012 三角面，textured 487083，几何数量差约95.8%。纹理导出包含几何处理，不能称为只加贴图；仅凭数量差不能证明全部缺陷来自减面。
4. 原始几何已有局部折面/瑕疵，修整版部分螺丝座周围更不规整。此批不是单一材质故障。
5. M4 Blender 金属近似参数为 metallic=.8、roughness=.38，UE 使用原枪 Phong 转换函数，因此本次 Blender 结果不能冒充 UE 渲染结果。
6. 聚合物 NormalMap 节点未明确指定 UV1，而贴图坐标来自 UV1，值得修正切线基准；本次关图对照不支持它是内框主要问题。491x205 的金属颜色图不能称4K细节，但去图实验也不支持它导致主要几何观感扭曲。

## 下一步建议

暂停重抽。对生成原始网格到纹理导出阶段分离处理，保留原始几何并单独烘焙材质，以同一反光材质比较几何变化。正式材质应和枪体一起定标，不直接将诊断用粗糙度.62/非金属设置作为所有枪统一修复。
