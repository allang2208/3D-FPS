# AKM M4 配件接入 — 2026-09-11

后续换弹食指与弹鼓拔出/脱手修正见 [AKM Reload Polish](../AKMReloadPolish20260911/README.md)；换弹资产当前运行引用已切换到该记录的新路径。

当前 Soviet Fab AKM 已接入 M4 的全息镜、消音器、制退器、钛合金制退器、50 发弹鼓、棱镜短握把和斜握把。配件在枪匠按原有槽位选择，保存到武器实例。没有改动 M4 配件的数值效果。

## 安装与几何

- 正式路径 `/Game/Weapons/AKMIntegration/SovietFab/Attachments`。模型仍使用已接受的低细分 AKM，默认手模仍是当前 M4 的 Manny 双手。
- 配件源与原材质绑定记录在 `sources.json`。复用已有合法本地资产，没有引入新的下载或再分发授权。
- 全息镜使用 AKM 机匣桥座、贴合防尘盖的中央鞍座及左侧支撑，右侧留给拉机柄。准星位置独立标定，保持镜体尺寸。
- 棱镜握把使用 85 mm 下导轨；斜握把复用已接受的 Compact75 尺寸，使用 130 mm 下导轨。原 M4 固定架上部在 AKM 护木表面处截断并封口，防止穿出木护盖。
- 三种枪口件按 AKM 实际枪口中心安装，保留原零件尺寸。弹鼓重新定位到 AKM 弹匣接口，并拆分原弹匣材质槽，使原弹匣完整隐藏。
- 静态件几何已烘焙到 AKM 根骨空间，挂根骨时相对缩放 0.01 抵消骨架 100 倍导入尺度；这是单位换算，不是缩小配件。
- 切换枪型时重建配件组件，防止 AKM 和 M4 互用错误的模型或安装变换。

## 动作

`prism/`、`angled/` 各保留 9 条可编辑 Blender 动作与 FBX：待机、瞄准、射击、瞄准射击、装备、普通/空仓换弹、弹鼓普通/空仓换弹。

先复用 AKM 已接受的源动作，再沿用 M4 接受过的握把手掌姿态进行左臂适配。120 Hz 烘焙；关节长度、手模权重和机械骨骼保持原值。换弹源帧 42 至结束前 48 帧保持原接触动作；只处理握把松手及回握。弹鼓沿用 AKM 的弹匣颈部抓握轨迹，装弹时长继续由原有配件倍率控制。

装备仍为 1.7 秒拉栓，弹匣保持连接；普通换弹基础 3.333333 秒，空仓 4.291667 秒。`source_validation.json` 对全部 18 条动作逐帧比较，非左臂矩阵及换弹中段最大数值差约 1.14e-6，未改变非锁骨关节平移与缩放。
