# 棱镜握姿的动作参考

先查看现有三角握把源渲染 `review_idle_0`、`review_reload_5`、`review_reload_116`、`review_reload_empty_150` 和 `review_equip_30`，读取其动作构建与运行选择。复用同一 M4 手套/手臂以及两骨臂链、twist 分摊与连续四元数烘焙方法；不改变手指骨长、平移、权重。

源动作使用 60 FPS 时间坐标：idle 0–180 循环，aim 0–2，fire/aim_fire 0–46，equip 0–38；普通换弹 0–126，空仓 0–162；弹鼓普通 0–126，空仓 0–148。动作时长保持当前运行资产对应值，弹鼓按既有运行时映射播放。

左手从阻手器松指、侧退后沿现有路径取弹并包握弹匣。普通与空仓换弹分别在 16–102、16–138 帧完整保留现有接触；弹鼓对应 28–102、28–124。末段从侧面靠近阻手器再闭合。右手、枪根、机械骨骼和弹匣轨迹保持原动作。装备拉栓维持右手职责，左手支撑阻手器。

棱镜阻手器采用已接入的混元修整网格与安装基准，尺寸不为握姿而放大。短小阻手部不能照搬大型三角握把的全指开口；小指自然收于下端。先安排掌位，再在局部弯曲轴内调整手指和有限拇指外展；用实际表面碰撞、近距离画面共同检查。

作者脚本复用 ReferenceWorkflow 中冻结的三角握把工作流 solver，当前候选和产物全部位于本目录，避免改写已有三角握把资产。
