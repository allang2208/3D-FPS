# RSH 共振握把腕部与支撑臂调整

后续检视返修见 `../RSH12InspectArmRepair20261005/README.md`。用户反馈检视中的锁子甲变形、整臂闪动；本作者已接入新的检视持握链处理，原始修订的检视结果不作为已解决依据。

2026-10-05，针对用户反馈的短枪身共振握把腕部过折。

原作者将步枪的穿孔握姿移到 RSH 的前握把，却保留原手枪左肘弯曲平面，并把手臂推到接近满展。读取作者姿态时，待机、ADS 的腕轴折角分别约 60.56°、64.01°；即便只转肘极，两者最低仍约 50.30°、56.80°。这些是同一骨架上的制作诊断，不是医学角度或实机验收。

`arm_support.py` 以原手掌、手指接触为约束，给 RSH 共振握把增加专用支撑：

- 按 18° 的作者腕轴摆角目标寻找支撑肘点；原肩点不可达时，以最小所需位移前送整个肩带，保留上臂、前臂和锁骨连接长度。
- 在精确两骨交圆上连续调整屈肘平面，同时运输上臂与前臂朝向。
- 前臂两个 twist 辅助骨分担掌面滚转，避免全部堆在腕口。
- 手腕组件空间矩阵、手指局部姿态、枪根和机械轨道继续使用输入。只重写锁骨、左上臂、左前臂、辅助骨和手腕局部轨道。
- 同步现有握把接触权重：换弹前 0.18 s 松握、末尾 0.30 s 回握；快速近战前 0.09 s 松握、末尾 0.16 s 回握；中间接触权重为零时保持原轨道。装备末尾 0.30 s 恢复支撑。

`author.py` 从 `Before/angled.json` 制作这次修订，输出 `profile.json`、可编辑 Blend，并发布到原制作目录的 `Profiles/angled.json`。旧总作者 `RSH12Foregrips20261004/author.py` 已接入同一求解器，且仅在 `family == angled` 时调用，避免今后重制覆盖此修订。

`import_profile.py` 只更新并保存 `/Game/Weapons/RSH12/Foregrips20261004/Profiles/DA_RSH12_angled`。实际保存结果以 `import_receipt.json` 为准。原 JSON、Blend 和 UE 包分别保存在 `Before` 与 `BeforeAssets`。

没有改配件模型、数值、右手、其他握把家族或双持姿态。不涉及 C++，无需编译 DLL。未运行游戏、测试或验收渲染；最终观感由用户在游戏中确认。
