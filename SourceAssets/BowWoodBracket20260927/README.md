# 弧臂圆环木制瞄具 V19

2026-09-27。按用户确认的方案，在 Blender 5.1 中重新制作 V17 木制瞄具。

## 造型与衔接

- 支臂主体截面为约 6.5 × 5.8 mm 的椭圆，根部约 11.2 × 11.0 mm，沿弧线收细后接入圆环右下方。
- 木座沿原木弓实际表面取样贴合，Z 范围 13.65–18.75 cm；水滴形肩部、羽化薄边和局部圆角代替突出的矩形块。
- 上下两道浅槽内各有三圈蜡麻线，另有两枚低凸木销；木座下表面轻微嵌入弓体，避免悬浮间隙。
- 圆环外径 36.0 mm、内径约 29.6 mm，径向壁厚 3.2 mm。接头额外裁出圆孔，控制支臂加粗后的开口遮挡；竖向准星尖宽 1.2 mm。
- 木纹沿支臂与圆环方向排布，木座沿用弓体表面 UV。复用现有木弓 PBR，法线强度降至 0.28；顶点色只给接触边缘和绑线凹槽少量压暗。
