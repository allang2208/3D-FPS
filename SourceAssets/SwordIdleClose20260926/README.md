本次直接读取当前安装的普通柄／长柄原生动画制作，不用旧版 FBX 覆盖现有动作。

## 姿态

- 剑与双手沿视线向玩家收回 6 cm，放低 1.2 cm。原生组件的偏移为 `(0, +6, -1.2)` cm；该组件以 +90° yaw 挂在相机下，+Y 对应玩家后方。
- 保留剑刃朝向、双手相对握柄的位置和方向、各手指局部轨道。
- 两肩位置保持，用原上臂／前臂长度重解肘位；肘部提示点稍向下、向内，使手收回时手臂自然弯曲。辅助骨沿用原父骨下的支撑关系。
- Idle、Walk 全段采用新持握位置，保留原呼吸／行走起伏和播放时长。
- 装备、检视、攻击及冲刺只在本来就接近待机的开始／结束段渐进衔接（入段 0.20 s、出段 0.28 s），工作段不施加待机偏移。与待机不接近的片段不改写。
- 普通柄、长柄各用自身当前轨道，保持各自握距。

## 源与接入

- `author_idle_close.py`：UE Python 原生姿态制作、导出和保存。以 `SwordIdle.Revision` 元数据避免重复累加偏移。
- `run_author.ps1`：后台 commandlet，使用现有资产批次互斥。
- `Standard`／`LongGrip`：原始局部轨道、编辑后逐帧轨道和完整 FBX；保存原始待机锚点，以便中断后继续同一批次。
- `Before`：被修改资产的导入前包备份。
- `receipt.json`：实际保存的目标、编辑帧数、原时长和作者源；跳过的片段单独记录。

目标为当前 `/Game/Weapons/AzureRunesword20260913` 与 `/Game/Weapons/FrostCrystalSword20260915/Grips20260919/LongGripAnimations` 动作目录，运行引用不变。本次未修改原生 C++、网格、蒙皮、骨段长度、伤害、攻击节拍或检视转刀的工作段。
