# M870 通用后托、前握把、后握把

**当前范围（2026-10-17）**：独立后握把改造已按用户要求取消。后托装配所需原厂颈部仍保留；下文后握把制作仅作历史记录，当前目录注册与运行定义以取消后的配置为准。

沿用 SUPER90 的五款后托、五款前握把、三款后握把 ID、属性、配件图标与实例存档。M870 使用独立安装模型与姿态层。

## 安装结构

- 原厂后托与传统握持颈部原本连成一体。按连通岛提取 1016 个原厂三角面，在生产骨骼网格中归入 `M870_FactoryFurniture`；仅改变材质分组。当前已保存的左肘表面修订、骨架、蒙皮、UV、机械部件及 13 条基础动画保留。
- 两个后部槽独立选择。任一个替换时，原厂整件隐藏，由两个独立刚体组合；未替换的一半使用原厂切分件。全部卸下恢复原骨骼网格整件，不残留接杆。替换资源未就绪时恢复原厂整件。
- 后托保留通用本体尺寸，以实测原厂颈部截面接封闭过渡肩、23.2 mm 连接杆及各款真实插口；长托向后延伸。作者坐标为原生组件 bind 米，UE 导入为厘米，运行时使用完整根骨参考变换的逆。
- 三款后握把适配为 M870 传统握持颈部的接触外壳，复用通用源的纹理、表面细节和材质；保留原厂虎口承托、扳机护圈及基础右手握姿。不是把传统枪托改成垂直手枪式握把。
- 前握把保留 SUPER90 使用的通用本体，单独重做 M870 护木下安装座；座顶采样当前护木三角面，接触处压入 0.15 mm。安装在 **WPN_bolt**，随护木完成泵动，不能绑定 WPN_root。

## 姿态与运行接入

- 四个 `WeaponGripProfile`，两款垂直握把共享垂直抓握。基于当前 `M870LeftArm20261016` 13 条动作，沿用认可通用抓握，保留原生关节长度并复用最新 M870 肘／腕辅助骨分配。
- 握持阶段手与握把使用同一个泵动骨参考；原动作左手脱离护木时，按原接触位移退出抓握层，保留装备、检视、冲刺与快速近战的离手轨迹。
- 稀疏层仅涉及左臂／左手。右手取弹、子弹轨迹、扳机接触、音效与机械时钟不变。ADS 使用同一基础动画及握姿层。
- `M870FurnitureAssets.*` 负责装配；现有 stock/reargrip/underbarrel setter 分流，覆盖枪匠草稿、库存图标、独立预览及拾取装配。第三人称装备捕获同步原厂隐藏分区，静态附件沿用现有子组件复制。
- 所有模型与姿态层提供完整资产路径供既有异步预加载注册表生成；图标预加载同时请求两个后部组合件与当前握姿层。`/Game/Weapons/M870` 已在打包目录内。

## 制作入口与交付边界

1. `run.ps1 -Script read_inputs.py`：读取当时已保存的 M870 与通用源，保留 `Inputs/`、SHA 和材质引用。原厂分组后不要覆盖这份输入。
2. Blender 后台运行 `author_models.py`、`author_profiles.py`，生成可编辑 `.blend`、FBX 与稀疏姿态 JSON。
3. `run.ps1 -Script install.py`：通过现有互斥在已有编辑器桥或后台 commandlet 中导入与保存。`install_receipt.json` 才是实际保存记录。
4. `integrate.py` 接入 M870 三槽；生成预加载注册表，执行必要 Editor 构建。

本次不启动游戏、不做截图、渲染或运行验收。外观、握姿、组合拆装与游戏表现由用户测试。最终制作状态见 `delivery.json`；不能把制作完成视作视觉接受。

最终后台构建成功，15 个静态模型、4 个姿态层和生产网格分区共 20 个资产已保存。后握把塌缩小面及退化 UV 已修整；三款后握把仍有近零切线／副法线导入警告，未把资产保存成功当作着色与视觉验收通过。
