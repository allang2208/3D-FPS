# M870 后握把切线与材质修订（2026-10-17）

范围仅为三款后握把静态配件与其专用材质。运行资产路径、配件 ID、安装骨与变换不变；不导入基础动画、骨架、手模或握姿层。

## 修订

- 旧贴合把纵向截面取整、把径向起伏硬截断，并把供体端部压到同一环，造成塌缩或细长三角面。改为连续截面插值与平滑径向映射，保留供体中段 UV、细节和顶点区域遮罩；先裁掉其他枪型的端部，再贴合 M870 颈部。
- 原碎边逐边封口仍会制造极窄的过渡面。新封口使用原生截面生成规则闭合环，底部贴入原生表面，外缘平滑衔接。原厂虎口承托及与后托衔接的基准面保留。
- 变形和拓扑完成后，重新建立供体的角点法线空间，再生成 UV0 的 MikkTSpace 切线。保留原生接触面的 UV0 与法线；新过渡面独立展开。按真正的 UV0 对齐材质，避免 Join 后错用另一对象的 UV 通道。
- 参考 SUPER90 的静态后握把 WS1 材质，创建三份 M870 私有实例和过渡材质。聚合物参数来自原装颈部 110 个 UV 样本，涂层区域参考已有 M870 机匣导轨配方；保留区域遮罩、供体粗糙贴图、物理颗粒尺度及湿润层。
- 原生纹理接触面另建静态专用副本，关闭不适用的骨骼／衣物／Morph 用途；不修改原枪或 SUPER90 的共享材质。
- UE 重导入会保留旧显示槽名。按 `imported_material_slot_name` 绑定，并同步显示槽名，避免本体、原生接触面和新封口材质串槽。作者源显式导出切线，导入入口同步资产自身的旧 FBX 选项与构建设置。

## 生产入口

1. Blender 后台运行 `author.py`，只写三款后握把的 FBX／可编辑源及 `models.json` 中对应三行；完整 `author_models.py` 也使用此入口。
2. 普通 Python 运行 `finish.py`，从保留的原生 UV 生成材质配方。
3. 父目录 `run.ps1 -Script install_rear_finish.py` 创建私有材质并保存三款静态网格，再按本次切线修复范围读回渲染数据。
