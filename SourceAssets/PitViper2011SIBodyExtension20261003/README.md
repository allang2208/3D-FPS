# SI 枪口补偿器：原厂斜线枪口延展修订

用户本次要求是侧视图中原厂枪口的斜切面与完整宽度。此前修订使用套筒后安装面和上肩截面作为接口，属于错误基准；这次改为原厂前端实际外表面。

从 `2011pv barrel compensator_2 / h-190` 提取前端外露三角面、下缘侧视斜切面和复合侧角。SI 后接合面由这些原始面反向构成，沿枪管轴向延展 29 mm，整段沿用约 23.861 mm 的原厂外轮廓宽度，取消 26.2 mm 加宽和后端扩口。侧视下缘斜线约为相对竖直 33.024°；不再把截面的上肩倒角当作侧视接合线。

保留完整原厂黑色枪口段和后方准星桥，加入同一个 SI 静态资产。装配仍只隐藏已分区的原厂骨骼网格材质段，因此没有丢失原厂前段，也不会显示重复的外壳。SI 后面向内贴合 0.04 mm，避免露出细缝。前端采用同类斜切轮廓，开孔和标识按新宽度及延展段位置重新布置。

保留现有安装原点和配件 ID；`Muzzle` 改为 X=0.046218629 m，`AimGuide` 改为 X=0.071218629 m，现有装配代码从资产插槽读取火光与出射方向。只需重新导入现有 SI 静态网格和专属图标，不改动画、枪体骨骼资产或原生代码。

材料槽从已保存资产取得并恢复，沿用上一轮 2011 细腻金属实例，不重建共享母版。作者脚本为 `../PitViper2011SICompensator20261002/author_si_compensator.py`，几何接口帮助文件为 `../../Tools/Weapons/pit_viper_si_extension.py`。Blender 源文件和 FBX 位于既有 SI 制作目录，本目录保存此次参数、导入和交付记录，`Before/` 保存本次修改前的源文件和资产。
