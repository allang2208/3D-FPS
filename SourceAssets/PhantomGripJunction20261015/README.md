# 幻影后握把接颈修整 · 2026-10-15

任务：继续排查幻影后握把与枪械衔接，消除明显空隙、叠层台阶和接颈突变。

从当前 9 款在用握把及宿主骨骼网格读取安装数据。M4、M16、AKM、QBZ191、A762、PKM、LMG201 按运行时代码的 WPN_root 与 0.01 缩放补偿还原；HK416、SUPER90 使用其实际绑定空间。工件、握点、骨架和组件挂接设置均未整体移动或缩放。

## 修改范围

- M4、M16、AKM、QBZ191：从当前原厂握把提取真实上端安装面，连接到保留的幻影握持主体。移除原有垫块、叠层套领、不贴合的翘尾与旧连接头小凹槽，改成连续过渡。下方镂空和握持表面保留。
- PKM：保留现用封闭安装座的上端接触面，重做其下方到握持主体的连续连接；避免重新引入原厂分材质上端的开放碎片。
- HK416、A762：保留当前已贴合的上端接触面及 A762 扳机避让区，只局部重建接颈下沿，与主体切口共享边界顶点。
- SUPER90：上端原生接触面不变，按当前镂空主体的支撑轮廓局部收整下沿和法线；保留第一处镂空的桥顶结构。
- LMG201：装配排查未见同类明显空隙或叠层台阶，保持原资产。
