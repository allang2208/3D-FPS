# 医疗／生态调配材料

六种材料的模型、图标、物品目录及容器掉落已接入。复合稳定剂默认 1×2；六件均为稀有或史诗材料。药水调配系统仍未开发。

当前为混合制作链：基液、赤脉根萃取物和银叶花精华使用根目录作者源；稳定剂、活性催化晶和蓝髓菌结晶使用 `VisualRefineV4`。UE 网格保留 V3 稳定路径，后三件引用 V4 材质；最终模型和图标来源以本机 `model_manifest.json`、`presentation.json` 为准。

保留 `Scripts` 和 V4 作者/导入脚本。先恢复根目录资产，再运行 V4 精修与 `install_icons_and_receipts.py`；候选图标在资产保存完成后发布。`setup.py` 是初始模板，不应在最终脚本之后盲目重跑。媒体、UE 包、导入宿主及回执留本机。

旧模型与快照已可恢复地移入 trash。完整恢复顺序、共享库存修复、历史检查与待测范围见 [本轮整理发布](../../Docs/Publication/RegionalLoot20261015/README.md)。
