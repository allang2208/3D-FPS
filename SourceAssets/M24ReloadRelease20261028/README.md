# M24 拔插节奏与离手手势，2026-10-28

用户要求弹匣拔插更慢，并参考其他枪械增加拔出后松手。本次保留上一轮侧握及纯拉栓装备动作。

## 参考和制作

参考 `../M4TacticalToss20260910/M4_Hand_MAT_Editable.blend` 的 `M4_MAT_reload`（60 Hz、0–126 帧）以及 HK416 的旧匣／新匣独立接触窗口。读取现有骨骼动作与时间表，采用“旧匣释放—空手取匣—重新包握”顺序，不把其他枪的腕部坐标直接复制到 M24。

制作源 `M24_ReloadRelease_Editable.blend` 沿用最新 V9/115 个矫正形状，以及此前纯拉栓装备、拉栓拇指和肩肘工作。仅四种换弹源帧 22–35 的左侧完整骨链、手指和弹匣轨迹产生新差量：

- 抽出至原源帧 23 的姿态后，让肩、肘、腕整链暂留在画面下方的已有姿态。不能只延迟腕点，否则原肩部继续退后会超出臂展。
- 24–26.8 帧五指错峰舒展；26.25 帧弹匣离手，沿下落轨迹退出画面。
- 27.5–31 帧空手下探，31–34 帧重新包握新弹匣。旧匣／新匣切换在画外完成，复用原有弹匣骨及扩容挂点，不新建世界掉落物。
- 34 帧以后重新接回此前的侧握、插入、压实及回握；空仓后段拉栓、右手、枪根、装备、ADS 和冲刺保留。
- 原生骨长、指骨局部平移及缩放保留。四分之一源帧采样（120 Hz）写入 Profile，源动画仍用原 30 Hz 时钟。

## 节奏

`M24ReloadTiming.h` 将源帧 `0,8,18,21,24,27,30,34,38,40,44,50,54` 映射到播放帧 `0,8,24,34,43,54,64,77,90,96,104,116,120`。拔出、松手和推入分别分配时间，空仓拉栓保持原速度。

基础普通换弹由 2.8 秒改为 4.2 秒，空仓由 4.4667 秒改为 5.8667 秒。现有敏捷、快手和配件速度仍作用于整个动作时钟。声音、装匣提交和姿态继续共享 `ReloadSourceTime`。

## 接入

`register_timing.py` 仅修改 `Content/ColdSteelData/gunsmith.json` 中 M24 的两个基础时长数值，保留其余文本。`install.py` 将局部差量合并到正式 `DA_M24_SupportGrip` 和 `DA_M24_Mag10`，保留其他动作与窗口外现有轨道。替换前目标保存在 `Backups/`。

作者入口为 `author_release.py`；构建、落盘状态以 `build-receipt.json`、`install_receipt.json` 为准。本轮未启动游戏、未渲染或进行验收，由用户试玩确认。
