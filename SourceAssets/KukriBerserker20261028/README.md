# 狂战士符文

弯刀专属传说改造，槽位 `blade_2`，选项 ID `berserker_rune`。

## 数值与结算

- 常驻：本刀物理伤害+10%，沿用 `physical_damage_mult: 1.10` 的既有改造公式。
- 蓄能：12次成功攻击动作命中敌人后激活。同次出手命中多个目标、双刀命中，合计只计1次；空挥不计。
- 狂战士持续20s：对应符文刀攻击和武技不消耗体力，攻击速度+25%、攻击伤害+25%，直接攻击按实际伤害的10%恢复生命；角色移动速度+15%。
- 双持两枚符文时共用同一个蓄能槽、持续时间及状态，效果不叠加。只安装一枚时只强化对应刀；双持费用仍分别计算。
- 吸血按实际扣除生命结算，不包含过量伤害或流血持续伤害。双刀冲刺斩合并伤害时按符文刀伤害占比分配吸血。
- 激活期间不延时、不为下一轮蓄能；结束后从0重新累计。切换武器立即退出并清空蓄能，切回后重新累计；包括切换武器栏、主副手互换、更换配对武器、切换生产工具与卸下符文。死亡时同样清空状态。
- 临时攻速加成独立乘到既有改造攻速结果上，保留常驻改造原有计算与限制。

## 外观与图标

狼首、獠牙和向下延伸的血痕组成红色符文，按原装、轻型迅刃、厚背重刃、百炼均衡刃、猎手刀身、犬牙刀身分别贴合烘焙。沿用各刀身既有PBR材质和法线细节，只增加符文遮罩、染色与微弱呼吸发光。

能量条以符文战锤 `HudSymmetricCapsV3` 为来源：保留玻璃、螺旋能流、32枚漂浮光粒与随视角轻微漂浮；改为血红色、狼首与下缘血滴，显示12段蓄能，激活后显示20s剩余时间。

狂战士激活时另显示镜头边缘红色火焰光晕；对应持刀手与前臂持续升起红色浮光，每手128枚。对应整把弯刀及其改造件同时转为红色发光外观，结束时恢复原材质；按状态同步启停。制作源、预算和交付回执位于 `ActiveFX/`。

刀身采用 `VolumeRefine/` 的本地厘米等比例投射。能量条按用户要求切掉上方尖顶和旧狼纹，沿用苍龙 `HudV10` 的设计图分层法，将具有明显体积明暗的血红水晶狼头接到原玻璃柱上；下段柱体、底部尖锥保留。后续将螺旋符文带替换成同半径、圈数与间距的红色粒子流，复用32枚环境粒子中的22枚呈现从螺旋飘散、上浮和淡出。活动制作源见 `WolfHeadComposite/README.md`。整体重制狼首能量柱与原线稿浮雕两版均已停用，重导入不再恢复。

改造图标使用灰阶钢框、四角铆钉、内银环和狼纹主图。原始生成图留存在 `Art/` 与 `Icons/`；UE图标导入采用UI压缩、无mip、最大1024。

## 制作与交付文件

- `bake_runes.py`、`Kukri_Berserker_Runes_Editable.blend`、`Textures/`：六款刀身2048遮罩和可编辑源。
- `BerserkerEnergyHud.hlsl`：原设计基线；当前材质源为 `WolfHeadComposite/BerserkerWolfHeadHud.hlsl`，截顶拼接新狼头，并接入同轨迹螺旋粒子。
- `import_assets.py`、`import-background.ps1`：后台导入和保存资产。
- `import-receipt.json`：实际保存资产清单，只有 `complete: true` 表示导入完成。
- `publish.py`：合并当前改造表和材质映射，保留其他改造；修改前文件保存在 `Before/`。
- `build-editor.log`：本次后台编译结果。

源码组件 `Source/FPSGAME/Weapons/Kukri/KukriBerserkerComponent` 由服务器统一结算，并向拥有者同步蓄能与持续时间。瞬时状态不写入存档；符文选择继续沿用既有改造装备存档。

按用户规则未运行游戏或进行验收，视觉、手感和联机实机效果由用户测试。
