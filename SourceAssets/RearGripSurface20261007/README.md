# 通用后握把表面整理 01

用户要求按现有 skill 经验提升几款后握把的表面，除去毛刺和粗糙部分。本轮范围为幻影、均衡、稳固防滑三款，涵盖 M4、AKM、QBZ191、HK416、M16、A762、PKM、LMG201 的 24 个当前适配资产。HK416 原装后握把、手枪握把防滑皮肤不在本轮范围。

## 制作方式

- 输入从当前 UE 静态网格读取，保留已经修订的安装接颈，不从早期生成母版覆盖当前适配。
- 参考 `ue5-weapon-workflow/references/weapon-finish.md` 的表面与结构分离，以及 A762 双边法线去噪方法，按本次握把尺寸重新限制处理范围。
- 保留拓扑、材质槽、UV、顶点色和挂点。相同位置的 UV 分裂顶点仅在计算图中合并，原资产不焊接、不重拓扑、不减面。
- 邻域半径 1.8 mm、最多 32 个相邻面；安装面、材质边界、真实开放孔边及超过 42 度的棱边冻结，距边界 1.2 mm 内渐隐。高曲率特征减弱处理，防滑沟槽、镂空框架和已重建接头保持身份。
- 顶点修正最大限制为幻影 0.08 mm，均衡／稳固防滑 0.12 mm；另对受影响区域整理角点法线。原结构法线贴图保留，不整图减弱或换成平法线。
- 只为握把主体复制专用表面材质，降低细粒、粗糙度斑驳、旧生成粗糙度权重和微划痕；保持原枪型金属反射、颜色及非金属分区。旧直接材质只调整聚合物粗糙度分支。主体细纹和防滑几何各自承担原有用途。
- 现有湿润配对同步建立新材质键；WS1 自带湿润实例沿用原生识别，不叠加第二层水膜。不修改共享枪身母材质。

## 文件与执行

1. `collect.py`：当前资产、材质与 LOD0 作者数据，位于 `Input/`。只读取制作输入，不运行游戏。
2. `produce.py`：使用本机 Python 3.11 / NumPy / SciPy 写入 `Plans/`；`production.json` 是制作参数及修改计数，不是验收报告。
3. `install.py`：应用局部修正、编译材质、更新槽和天气映射、导出修订 FBX、更新网格重导入源并保存。
4. UE 脚本通过 `../WeaponSurface20260930/run_ue.ps1 -Script <绝对脚本路径>` 的现有批次互斥执行；编辑器未运行时用后台 commandlet。

`Before/` 保存被修改的原资产；`Exports/` 为本轮已安装版本的可编辑 FBX。后续表面或接缝制作从当前 UE 网格及此处导出的 FBX 继续，不直接重跑早期整批 FBX 覆盖本次修订。材质配方由 `install.py` 保留；原贴图和许可沿用既有来源。

## 交付边界

实际完成数量及保存状态以 `install_receipt.json` 为准。脚本具有按已完成步骤续接的记录，不将脚本文件本身当作资产接入完成。未启动 UE 交互编辑器、PIE、游戏、截图或验收渲染，也未执行额外测试。资产保存与视觉效果认可分别记录，由用户测试实际观感。
