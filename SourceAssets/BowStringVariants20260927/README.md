# 两款弓弦改造 · 2026-09-27

规格来源：用户确定的紧捻稳弦、柔芯长持弦数值，见 `Docs/Weapons/bow-string-design-20260927.md`。

- `series.json`：名称、描述、数值、材质参数；柔芯长持弦不提供保持时间加成。
- `Fiber.hlsl`：非金属纤维底色和粗糙度；按动态圆柱实际轴长计算厘米制编纹，细纹随屏幕导数淡出。
- `import_assets.py`：保存共享材质、两份材质实例与两张图标纹理；只保存本批资产。游玩期间拒绝操作。
- `render_icons.py` / 两份 `.blend`：宿主实际弦挂点、0.09 cm 半径的可编辑源。输出 1024 RGBA 灰阶图标；仅图标把线宽提高至 64 像素显示时至少 1.2 像素，不改游戏弦粗细。
- `install_config.py`：资产保存完成后，向当前弓改造目录加入选项、复制目录图标、追加打包目录，保留其他槽位及装备。
- `live_compile.py`：仅通过已运行编辑器编译共享速度行名，不启动或关闭编辑器。
- `resume_own_material.py`：本轮首次导入中断留下的未保存主材质恢复入口；仅限恢复本批，不作为日常导入入口。

无外部素材下载。材质表达与图标为本轮程序化制作；游戏几何复用引擎圆柱，挂点来自现用猎手长弓数据。

运行时通过现有 string 槽、装配签名、属性计算与 gunsmith_parts 存档接入；不添加 Tick、不叠加第二套数值、不修改玩家当前装备。三种弓弦改造与原装在同槽互斥，适用于当前猎手长弓四款弓体。

制作状态以 `render-receipt.json`、`import-receipt.json`、`install-receipt.json` 的实际产物为准。图标、5 个 UE 资产与两款正式改造选项已保存接入。首次被游玩状态阻止的资产保存已在箭台接入批次中完成；未进行游戏测试或视觉验收。
