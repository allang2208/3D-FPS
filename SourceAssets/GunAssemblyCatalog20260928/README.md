## 制作与玩法

- 复用游戏现用枪械资产，按原有材质分区、机械骨骼及完整面分组，保留 UV、材质引用与分裂法线。没有重新建模枪体、任意裁切或减面。
- 手臂、弹药、弹壳、快速装填器，以及换弹时出现的备用弹箱/弹链不进入组装。PKM 装空弹箱，201 沿用原厂弹匣配置并包含原厂脚架；成品继续沿用现有空弹匣交付规则。
- QBZ-191、A762、201 的独立原厂机瞄及 201 的脚架沿运行时代码中的挂点装配。只读取参考骨架，不写回任何武器、骨架或原材质。
- 同一把枪的所有部件使用共同的刚性坐标变换；较长枪械必要时整体等比适配现有工作垫，部件不分别缩放，游戏成品尺寸不变。
- 每枪有独立目标位置、散件停放位置与初始角度。沿现有异步资源准备、拖拽、旋转、吸附、评分、持稳校准、工件保存及领取机制运行，无需按枪复制 C++ 游戏逻辑。
- 入口为现有工作台的“枪械制造”卡片与配方下拉框。原 M4 配方、弹药制造页保持现有规则。

## 文件与接入

- `sources.json`：现用枪械资产、原始导入文件、原始材质槽。
- `Sources/`：从当前 UE 资产导出的 FBX 与可编辑源副本。
- `extras.json`：独立原厂小件与运行时挂点、参考骨架坐标。
- `Authored/<枪械>/`：每枪可编辑 Blender、部件 FBX、配方和制作清单。
- `manifest.json`、`recipes.json`：本批生成的资产与配方清单。
- `import.json`、`import-catalog-01.txt`：58 个网格保存成功、10 个新配方发布成功的导入回执。
- 游戏目录：`Content/ColdSteelData/gun-assembly.json`，保留原配方并添加新配方，合计 11 个。
- UE 资产目录：`/Game/Building/GunAssemblyCatalog20260928`，已加入 `Config/DefaultGame.ini` 的 AlwaysCook。
- 原制作目录备份：`Before/gun-assembly.json`。

制作入口依次为 `Tools/GunWorkbench/export_catalog_sources.py`、`prepare_catalog_sources.py`、`export_catalog_extras.py`、`author_catalog_assembly.py`、`import_catalog_assembly.py`。重新制作必须在独立修订目录导入，避免覆盖当前工件配方的部件数量或顺序；本批没有改动既有 M4 工件合同。
