# Super90 脚边游离弹药

用户要求排查并去除随玩家移动、出现在脚边的独立弹药。

## 来源

主枪 `SK_Super90_V7` 包含原始 `12g_12gauge_0` 几何，使用 `12gauge` 材质区块，绑定 `WPN_Shell`。该骨骼直接挂在 `VM_Root`，不属于枪体机械骨骼。原生 idle 样本把它停在视模下方约 82.9 cm；它仍是完整尺寸，并未通过缩放隐藏。源数据见 `SourceAssets/Super90Foregrips20261007/native.json` 的 idle / reload_full 样本。

原先只在装填器首帧隐藏该区块，动作结束又恢复显示。普通初始化、非装填动作、展示用角色和第三人称武器副本没有一致的排除规则，因此这发换弹道具会成为随模型移动的杂物。

## 修复

- 所有 Super90 初始化在恢复区块后隐藏该发弹药，包含提前返回的图标和拾取物展示路径。
- 原生逐发换弹沿现有更新时钟开启该区块：有实际补弹数量、进入动画混合完成、尚未跳到收尾。装填器及仅操作枪机时保持隐藏。
- 动作完成或中断统一隐藏，取消装填器收尾的重新显示。
- 身体系统的随身枪械副本永久排除这个第一人称换弹道具区块。
- 可见性仅在变化时提交；复用换弹更新，不新增 Tick、反射字段、组件或网络状态。弹药数量、提交时机和存档保持原路径。

该修复通过运行时区块可见性移除常态杂物，保留手动装填需要的原生弹药几何与独立抛壳资源，不重新导入枪体、材质或动作。

源码修改前副本位于本目录 `Before/`。必要构建通过 `build_background.ps1` 使用现有 UE 批次互斥；本轮不启动编辑器或游戏，不做自动测试、截图或验收。构建结果另见 `delivery.json`。
