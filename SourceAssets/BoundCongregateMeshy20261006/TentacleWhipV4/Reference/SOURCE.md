The locally retained research excerpt includes `main_whip.py`, `modules/controllers.py`,
`modules/utils.py`, `models/3D_model_w_whip.xml` and the upstream README. This excerpt
is not a complete runnable distribution; obtain the named commit from upstream for
the full reference project. These raw reference files remain local and unmodified.

`Tools/BoundCongregate/simulate_whip_v4.py` independently authors the monster's
chain and controller using minimum-jerk root motion and passive damped joints in
MuJoCo. `bake_whip_table_v4.py` produces the original native sampling table.
No Elden Ring animation or game data was extracted or redistributed.
