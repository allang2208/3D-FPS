# 地牢战斗空间扩容与流体升级

目标地图：`/Game/GameMaps/L_Dungeon_AuthoredExpansion`。原样板通道及其入口关系保留。

## 本轮调整

- 桥面问题定位：场景内只有一份桥板；旧生成器把桥板上表面和坑道侧墙上表面都放在地面高度 0，左右两端各重叠 8 cm。当前桥板独立成 `SM_RS_Drainage_Bridge`，板面高 2.5 cm、支座顶下沉 5.5 cm，两端用 22 cm 长斜面连接地面。坑道端墙也下沉，去除同类共面重叠。
- 粘液采用与喷泉 V3 相同的水面处理原则：同一套解析波形同时计算高度与坡度，细分网格承载 WPO，两层连续流动法线，按水深／视角变化的透明度、接触消隐和表面逐像素照明。使用场景反射，不加入喷泉的室外环境立方体。保留高光而降低均匀绿色遮盖。
- 法线纹理依据现有资源的 BC5、原始线性或 Masks 压缩设置选择采样类型；不更改喷泉共用资源。材质父图写入独立资产，避免覆盖已使用的旧图。
- 管体已有内外双层几何，本轮明确分离内壁湿金属、切口钢材及外部漆面，增加管口厚度至约 1 cm，圆周细分提高到 48。外部采用原创 2K 漆层、局部掉漆／锈蚀 PBR，80 cm 实际纹理尺度，法线凹凸限制在细小漆损范围。
- 管口增加一段连续液舌及三组错相的实体液滴。液滴按重力轨迹落下，1.55 s 循环，落点涟漪使用相同周期、相位及坠落时间。地面薄积液独立于坑道水面。
- 坑道与管下积液复用已有 `DungeonPusChannel`，每 0.5 s 施加 8 点基础腐蚀伤害，交由既有受伤系统结算。桥上／跳过坑道时继续以脚部高度区分，不将液体变成阻挡碰撞。

## 面积与布局

面积口径是地面矩形并集减去墙体和柱子实际占地，并排除未架桥的坑道；这是生成参数的设计面积，不是运行时导航网格面积，也不含角色胶囊的边界退让。

| 房间 | 原可走地面 | 新可走地面 | 增量 |
|---|---:|---:|---:|
| 管线分配间 | 71.44 m² | 107.15 m² | 50% |
| 排水检修室 | 122.03 m² | 183.05 m² | 50% |
| 破损支护室 | 138.56 m² | 207.83 m² | 50% |

墙体平面位置、楼板、梁柱、管道路线、灯具、战斗锚点和连接段随各房间参数重排。管径、柱径、门洞净宽、层高、砖块纹理尺度、坑道和桥的宽度保留实物尺寸。发现侧室保留原大小并向外迁移；神像随侧室平移，保留已有朝向与缩放。

新房间继续由 `DungeonRoomShells20260922/Scripts/author_rooms.py` 生成，墙砖剥落直接复用 `DungeonTileFracture_Source.blend` 的认可版本。损坏墙洞、支护和碎石位置改为由侧室配置推导，避免扩容后留在旧坐标。

## 后续生成入口

1. `Scripts/layout.py` 以 `Config/rooms-before.json` 为输入，按面积目标求房间扩张参数，输出当前房间配置；重复运行不会再次扩大 50%。
2. 使用 Blender 执行 `DungeonRoomShells20260922/Scripts/author_rooms.py`；使用 Python 执行同目录 `author_interfaces.py` 更新接口。
3. 使用 Blender 执行本目录 `Scripts/author_fluids.py`，重建液体与管口位置，同时写入 `pipe_slime` 生成配置。
4. `author_pipe_textures.py` 制作原创贴图；UE 桥依次运行 `import_materials.py`、`import_meshes.py`、`install_scene.py`。模型导入回执按 FBX SHA-256 判断已导入版本，标准房间安装器也消费当前资产路径和积液配置。

新资产根：`/Game/Dungeons/CombatExpansion20260922`。旧资产保留用于恢复。`Receipts/scene-before.json` 记录变更前场景数据，`Config/rooms-before.json` 保留原布局。
