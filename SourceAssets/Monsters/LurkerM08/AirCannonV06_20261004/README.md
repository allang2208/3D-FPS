# 伏窥者 M-08 / 背环空气炮 V06

用户指定：原地下伏后，使用背部圆环发射空气炮，计算提前量，命中造成物理伤害并眩晕 3 秒，冷却 20 秒。

## 行为与数值

| 项目 | 本轮配置 |
| --- | --- |
| 动作 | `AttackAirCannon`，1.85 秒，120 fps，无根运动 |
| 前摇 | 0–0.34 秒下伏，随后四足支撑蓄压 |
| 预判 | 发射前 0.10 秒锁定目标位置与速度，用恒速截击方程计算提前量，计入剩余前摇 |
| 发射 | 动作源时间 0.92 秒，由背环开口中心发出；源时钟跨帧仍只生成一次弹体 |
| 收势 | 背环回缩、肩肘承受后坐、躯干恢复，1.85 秒交回行为树 |
| 基础伤害 | 48 物理伤害，沿用现有飞扑基础值作为本轮可调初值，结算玩家物理防御 |
| 眩晕 | 有效扣血且存活后施加 3 秒，沿用现有眩晕、免疫与玩家输入锁接口 |
| 冷却 | 从进入动作起计 20 秒；中途被控制打断不退还冷却 |
| 触发距离 | 2.8–18 米；保留现有 14 米初始警戒距离 |
| 弹速／半径 | 16 米/秒，球体扫掠半径 34 厘米；最大飞行 18 米 |

攻击选择仍由现有 `MonsterAIController` / Behavior Tree 发起。满足冷却、支撑、视线、前方角度及距离时优先空气炮；近身继续原咬击，其他情况继续飞扑与追击。角色 Tick 只推进已开始的动作，不另建索敌或技能选择循环。

下伏期间停步，保留地面／墙面／天花板支撑，四足沿用有界接地节点；空中不开始蓄力。目标在发射前失效、身体失去支撑、受控或死亡会取消未发射攻击。普通枪击是否打断继续服从现有控制合同。

弹体飞出后保持直线，不追踪，侧移和掩体可躲避。服务器连续扫掠，最近的有效碰撞体阻挡；单发只结算一次。墙面碰撞只显示气浪消散，冰墙使用既有伤害接口；视觉消散环没有额外范围伤害。来源死亡会取消仍在飞行的弹体。
