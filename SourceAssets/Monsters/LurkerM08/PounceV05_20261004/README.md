# 伏窥者 M-08 / 飞扑 V05

用户反馈 V04 飞扑像整体平移的固体。本轮只重做 `AttackPounce` 和 `TraverseJump`，保留 V04 行走、近身咬击、受击、死亡，以及现有模型、蒙皮、材质、F6 入口。

## 动作制作

编辑源 `M08_Pounce_Animated_V05.blend` 保留 V04 全套动作，并新增两段 1.50 秒、120 fps 的 V05 动作。独立导出位于 `Animations`，制作入口 `Tools/LurkerM08/author_pounce_v05.py`。

- 0.00–0.24 秒：骨盆后坐和下沉，前掌先离地，后腿继续蹬送至起跳。
- 0.24–0.74 秒：胸部先伸展，腰盆稍后跟随，后腿由蹬直转为收拢，前臂由前伸转为落地探掌。骨盆俯仰与脊柱局部弯曲分开制作。
- 0.74 秒前掌、约 0.84 秒后足落地，右侧迟约 0.028 秒；肘肩屈曲承重、躯干下沉、后腿跟进。
- 1.09 秒后抬掌／补步归位，1.50 秒结束。使用保形三次 Hermite 曲线，过渡关键点不再全部强制零速度。
- 背拱沿用连续胸盆变形场，中央跨度追加 65 ms 滞后，位移上限 3.5 cm，两端保持跟随身体。

## 位移与接触合同

`AWolfMonster` 新增可覆盖的飞行时长接口；默认返回原动画飞行长度，其他使用者沿用原速率。M08 起跳时按实际锁定路径计算真实飞行秒数：`clamp(距离厘米 / 760 + 0.16, 0.44, 0.95)`；越障跳跃最大 1.05 秒。只映射飞行区间，蓄力和恢复保持源速率。

扑击源时间起跳为 0.24、到达为 0.74、咬合接触为 0.70–0.88 秒。移动扫掠、动画取样、单次伤害消费使用同一映射后的源时钟。攻击前等待 0.06 秒，动作后恢复 0.16 秒。近身咬击不变。

M08 既有接触节点在起跳前保留支撑，在真实表面接触且进入落地段时恢复分足 IK；空中只增加由实际路径切线得到的有界俯仰，不锁脚。前后足分时接地，1.04–1.14 秒逐渐退出接地修正，交回烘焙补步。世界查询沿用原 4 足、30 Hz 有界采样；无新增 Tick 或资源加载。

飞扑／越障仍使用既有胶囊扫掠路径和表面路由，不能把本次描述为完整刚体弹道或全新物理运动系统。
