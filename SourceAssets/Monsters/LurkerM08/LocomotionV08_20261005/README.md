# M08 移动全身细调 V08（2026-10-05）

用户要求移动时头部有一定摆动，并继续精调全身。沿用 V04 的接触驱动步态、V03 骨架蒙皮及现有动作资产，本轮制作在原生 `FLurkerM08ContactNode` 中完成。

## 动作设计

- 每只脚的真实摆动进度、对角承重与落脚压缩共同驱动身体，不建立与脚步分离的循环时钟。
- 骨盆、两段脊柱和胸部小幅反向转动，身体加入低幅侧移、前后送力和上下承重变化。
- 颈部、头部逐级阻尼跟随，增加左右摆动和点头；少量反向侧倾用于保持头部稳定。响应速度随移动档位变化，匹配 V07 提速后的换步频率。
- 前掌抬起时肩胛轻提，落地时局部压肩；腕指提前收拢并在摆动结束前展开，五指卷曲幅度略有区别。全身和肩部修正后再做四肢接地求解，继续使用原有世界空间脚底支撑目标。
- 背环两侧使用同一连续变形场，在中段加入约厘米量级以内的阻尼跟随差值；胸部／骨盆连接端的额外偏移及转动衰减到零。沿用实际蒙皮内缘计算空气炮出口的 V07 路径。
- 摆动强度随移动或转向平滑启停；攻击支撑、飞扑腾空、受击、死亡及物理模拟不叠加本轮移动摆动。以当前接触面为基准，因此同一逻辑适用于地面、墙面和天花板。

本轮没有更改移动速度、飞扑时长、空气炮伤害／眩晕／冷却、原模型权重、材质、碰撞或 F6 入口。
