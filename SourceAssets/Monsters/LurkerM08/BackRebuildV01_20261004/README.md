## 本轮修改
在原有纵向背拱上制作前后方向的贯通开口，留下左右支撑与顶部拱冠，并局部圆滑孔缘。新增孔壁是实体网格；用原始表面的颜色、粗糙度重投影制作独立 UV 图集。新增孔壁为非金属组织，使用平滑几何法线，不把原表面的切线法线直接套到方向不同的孔壁上。

原头部、四肢、束带和远离背部开口的表面沿用原网格与原 UV/PBR 图像；开孔邻近区域因局部重建而改变拓扑。原有法线在修订区域以外从源模型传递保留。源 GLB 的 UV 接缝位置点在导入时合并，UV 仍按面角保留；不能将此过程表述为整个模型顶点编号完全不变。

这是一版基于现有高模的局部几何修订，不是整只重新生成。保持 Meshy 原始单位和整体比例，本轮未调整至最终游戏尺寸，未减为游戏低模，未新增骨架、蒙皮、动作或 UE 引用。
