# 写实地下设施 · 首轮美术场景段

依据：用户认可的 [概念图与情绪图](../DungeonConcept20260920/V1/README.md)。制作日期为 2026-09-20 至 09-21。

本轮制作可复用结构、材料和三个连接的场景段，接入现有 `/Game/GameMaps/L_Dungeon_Prototype`。这是一张美术开发样板，不代表完整随机地牢、战斗循环或事件系统完成。

装配输出：277 个实例、44 个按房间分组的 HISM 组件、25 个独立来源道具/结构 Actor、12 盏灯。主图入口仍显示 `DUNGEON / Prototype`。

## 交付结构

- `layout.json`：400 cm 网格、房间格子尺寸、连接边、出生点与事件位置。
- `Scripts/build_kit.py`：通过 Vibe3D 创建 21 个 StaticMesh 和 10 种材质。
- `Scripts/import_event_prop.py`：导入既有女神像母版的独立候选副本，保留 UV，建立可保存的 PBR 材质，启用 Nanite。
- `Scripts/assemble_slice.py`：去重边界、门洞替换、按房间和网格分组 HISM、有限种子的装饰、灯光、平台与地图保存。
- `Receipts/kit-build.json`、`scene-build.json`、`event-prop.json`：制作/保存返回记录，**不是测试报告**。
- `Receipts/placement-manifest.json`：本轮模块摆放清单；供后续运行时装配器迁移，不是当前运行时消费者。
- `Archive/L_Dungeon_Prototype.umap`：改造前原始地图文件，只归档不覆盖。

正式资产目录：`/Game/Dungeons/IndustrialV1/`。原图的编辑器副本：`/Game/Dungeons/IndustrialV1/Archive/L_Dungeon_PreIndustrial20260920`。

## 模块约定

单位厘米；Z 向上。墙长 400、厚 20、高 400，基点在墙长中心/厚度中心/地面。墙与楼板相交，单层地面到天花底为 380，二层挑高大厅为 780。地板 400×400×20，原点是上表面中心；天花原点为下表面中心。

门洞净宽 200、净高 280，装饰压边位于净空以外。楼梯每跑 10 步，步高 20、踏深 35、宽 200、升高 200；两跑加 140 长平台到 400 高检修层。上楼连接处补了落脚板。静态碰撞采用真实三角形，保留门洞和楼梯间隙，不用包围盒封闭开口。

矩形房间先展开为格子集合；外边去重，同一连接边只生成一个门洞。现阶段没有运行时随机房间图，也没有把这份 Python 编辑器脚本当作打包后的生成器。

## 材质与灯光

新建混凝土、旧瓷砖、橄榄绿漆钢、深色钢、古石、地坪、局部湿地坪，以及冷白/琥珀/微量青绿自发光材质。材料使用世界坐标控制纹理尺度，结合现有噪声与细节法线，区分砂眼、瓷砖灰缝、漆层磨损和粗糙度；这轮不是整套扫描混凝土贴图采购。

每个场景段有独立冷暖灯位，通道 3 灯、大厅 6 灯、遗迹室 3 灯；投影灯分别 1/2/1。无日光或天空光照亮地下室。曝光和灯强属于首轮作者参数，尚未经实机调校。湿面只布在排水、泵机与事件室局部，异常发光集中于末端遗迹。

## 重制方式

在当前项目的现有编辑器上，经 `Tools/AssetPipeline/mcp_call_codex.ps1 -PythonScript <绝对路径> -OutputFile <唯一文件> -MaxOutputChars 3000` 顺序执行三个制作脚本。发现多编辑器时使用 `-PythonNodeId` 固定到当前接入编辑器；不要另开命令行编辑器覆盖资源。脚本不保存其他关卡，不停止 PIE，不关闭或重启编辑器。

套件脚本复用已保存的版本资产；若要改变几何，先制作新修订路径。装配脚本仅清理 `DungeonPrototype` 与 `DungeonIndustrialV1` 文件夹的本轮替换对象；有其他关卡未保存或目标地图已有非本轮未保存工作时保留现场。

这轮交付美术套件、样板地图和编辑器装配源。完整地牢后续仍需房间图生成、房态与流送、随机多层连接、导航、波次、事件卡与奖励、地图 UI、出征和结算。遵照用户要求，未执行 PIE、碰撞/导航/性能测试、截图或验收渲染，由用户自行测试。
