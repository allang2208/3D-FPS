# M870 装填右手：腕臂支撑与旋转修订

**状态：用户再次否定本版右手处理。** 后续重新采用原始 Blend 的版本为 `../M870ReloadSource20261016/`，已通过后台导入并保存两条动画，游戏资产已由新源版本替换。完整重制链最后改为新源版本。下列指标只描述本版，不代表用户验收。

历史范围：普通、空仓两条装填序列。可编辑源 `M870_ReloadWrist_Editable.blend` 包含此前 AKM 左手、弹药接触和 SUPER90 冲刺输入。

## 定位

从当前安装的两条动画分别读取 RAW 与 COMPRESSED 关键姿态，并提取当前原生 V7 裸手网格和权重。压缩前后位置一致，问题已存在于作者轨道。旧手部接触层把掌心校准到弹药，却保留另一套前臂支撑方向；腕部在完整装填区间最大折转约 136°。前臂辅助骨没有按新的掌向分担旋转。松手时还恢复了旧拇指根部约 13.014 mm 的位移，并在每轮回收中出现约 126.283 mm 的单帧手部跳动。

## 修改

- 保留 UC `reloadinsert.smd` 的手部抓握与动作节奏；将同一源动作的完整上臂／前臂方向，通过解剖掌面映射到当前手掌，使用本枪原生骨长。
- 复用 SUPER90 `RightArmR9` 的解剖弯曲平面和原生 0、1/3、2/3 前臂辅助骨站位，只分配轴向旋转。手腕独立保留持弹世界变换，重新编码父子局部轨道。
- 保留手指弯曲和指节位置，以各指的弯曲平面消除来源骨轴带来的额外轴向滚转；松手阶段恢复原生手指根部位置，避免拉长拇指根部和掌面。
- 入弹事件后，用完整 16 帧的短弧线收手到下次取弹位置，去掉原轨迹最后几帧的瞬跳。七次持弹／入弹区间、弹药和枪体轨迹、入弹事件时间保持。
- 松手沿当前持弹手型向原生放松姿态作小幅过渡，去掉旧回收段的异常卷指。源帧 360–372 与既有手部接触层同步交接到枪托，之后保留原持枪支撑和空仓泵动尾段。
- 两条动作时长保持 6.65 秒与 424/60 秒。左臂、其他动作、库存和事件时钟继续沿用原实现；只导入两条动画，不重新导入共享网格或骨架。
