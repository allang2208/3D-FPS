# Dan-Wesson 715 缎面金属升级

本轮是材质贴图制作与游戏接入。依据当前用户规则，不启动游戏，不制作验收渲染，不追加测试。

## 材料设计

当前 Upgrade 材质将旧底色亮度以 0.86 权重乘回金属，旧贴图的宽暗斑随之进入反射底色；微纹还叠加了较密的凹凸。本次复用 191 的分件 PBR、物理尺度烘焙和独立修订路径方法，保留 715 的不锈钢身份。

| 分区 | 线性金属反射底色 RGB | 粗糙度中心 | 加工细纹 |
| --- | --- | --- | --- |
| 枪身 Frame | 0.490 / 0.515 / 0.540 | 0.285 | 沿枪体纵向的克制拉丝 |
| 弹仓 Cylinder | 0.530 / 0.545 / 0.560 | 0.225 | 周向车削纹、略亮的抛光面 |
| 钢件 Steel | 0.450 / 0.470 / 0.490 | 0.245 | 扳机、击锤、吊架、抽壳杆与速装器旋钮的细加工表面 |
| 弹药 Ammo | 0.560 / 0.345 / 0.115 | 0.255 | 黄铜色和周向加工细纹 |

- 粗糙度细纹变化幅度 0.018，缓慢底层变化 0.012；凸边仅轻微降低粗糙度 0.035，不画白边或重划痕。
- 烘焙微纹频率按模型米制坐标控制，主要跨纹频率 1600–2200/m；凹凸高度 0.8–1.0 微米、强度 0.12。将难以稳定表达的更高频细节归入粗糙度，不靠高强度凹凸制造颗粒。
- 源刻字底色混合权重降到 0.22；源雕刻法线强度从 0.72 调到 0.46，在高模上先分离调整，再烘焙回现有 UV0。新的几何倒角投射不统一削弱。
- AO 使用 1.8 mm 范围的局部凹腔遮蔽，单独写入 ORM.R，底色只保留克制的旧标记对比。
- 枪身/弹仓 4096²，钢件 2048²，弹药 1024²。BaseColor 与 ORM 使用 BC7；Normal 使用专用 Normalmap 压缩并翻转绿通道；普通平均 mip 保留浅表面变化。
- 橡胶握把、消光照门准星、内腔、速装器聚合物与手臂沿用各自材质。内腔在金属图集中保留原消光材质。

## 作者入口

1. `bake_finish.py` 打开最新 `DanWesson715LeftRecovery20260914/DanWesson715_LeftRecovery_Editable.blend`，使用现有高低模与 HeroUV，制作 4 套 BaseColor/ORM/NormalGL。
2. `DanWesson715_MetalFinish_Editable.blend` 保存作者材质、打包贴图、原网格和最新回握动作。烘焙只用临时网格副本；不重排低模 UV、材质槽或改动动作曲线。
3. `import_finish.py` 在 `/Game/Weapons/DanWesson715/MetalFinish20260914` 导入贴图及干/湿材质，并复制已接入的 Upgrade 骨骼网格后替换对应材质槽。保持 Skeleton、蒙皮、导入切线和动作资产引用。
4. 当前运行入口为 `Source/FPSGAME/Weapons/DanWesson715WeaponAssets.h` 的 `MeshPath`；角色、枪匠预览、图标和掉落共享同一武器初始化入口。已有 `/Game/Weapons/DanWesson715` cook 目录覆盖新修订。

湿润变体沿用项目 WeatherBeads 图，向 RainVisibility 和 NaturalV2 材质库合并新映射；保留其他武器以及本枪非金属材质映射。
