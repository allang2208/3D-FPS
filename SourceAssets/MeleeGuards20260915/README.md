# 寒晶·双手剑：三款护手

## 设计与来源

用户于2026-09-15要求先查看原护手，再使用5080模型管线生成并接入三种可替换护手，正确贴合原剑，统一护手材质。

原剑作者源：`SourceAssets/MeshyMelee20260915/FrostCrystalSword_Manny_Editable.blend`。现有护手为约21.8cm宽的古铜双翼结构，中央V形安装座贴合蓝色晶体刃根，下方连接黑色双手握柄。

- 壁垒护手：加厚盾翼，强化防守。
- 反击护手：上挑钩形护翼，突出招架反击。
- 轻量护手：镂空细翼，保留三角孔洞。

`original_guard_*.png` 和 `OriginalGuardReference.blend` 是按用户“先看原护手”的要求制作的原模型参考。`designs.json` 保留内置 image_gen 的三款三视图提示词。每款目录的 `three_views.png` 为设计参考，`workflow.json`、`receipt.json`、`history.json` 为真实5080任务记录。

5080生成使用 `microsoft/TRELLIS.2-4B`、三个独立视图、1024_cascade、结构分辨率64、结构/形状/纹理16/32/24步、4K贴图、50万面母版导出目标。实际母版面数见各款 `authoring.json`。三视图按本轮图片位置分别裁切，再各自去背景，接入front/left/back多视图输入。保留raw与textured_master原始GLB，不将概念图或本地拼接部分称为5080独立生成结果。

## 安装接口

只适配 `ue_frost_crystal_sword`。原剑本体、手柄、配重锤、手臂、骨架与动作保持原样。

安装基准沿用真实WPN_root坐标：单位米，+Z指向刃尖，X沿护手左右，Y为厚度。保留原剑中央安装座和刃根/握柄接触面，切分两侧约±6cm处的原护翼。连接套依据两侧所有原切口顶点的实际包络制作，向原安装座内部嵌入约3mm；护翼根部截面据此适配，并在连接套内搭接。完整武器导出保留原中央几何、UV和法线；安装不依赖整件模型包围盒上下平移。三款完整护手宽度约27–30cm。

原始生成曲面的起伏不适合直接作为规整的护翼。游戏模型从真实5080几何的正投影轮廓提取外边与镂空，再进行本地重拓扑、平整表面、实体厚度和倒角制作。不是再次生成其他造型，也不把本地重建部分称为直接的5080网格输出。高模采用更细的倒角，向游戏模型烘焙法线和AO。

三款新护翼共用 `M_FrostGuard_Bronze`，UV1映射到原铜色护翼的连续纹理区域，直接使用原件的底色、金属度和粗糙度纹理；具体区域记录在 `finish_patch.json`。UV0用于结构法线、AO及对应导出切线。每款实例仅绑定各自结构法线和AO，原安装座保留原材质与UV。独立部件和图标沿原纹理中的铜色边界分离安装座；完整武器使用未切分的原中央表面。两翼采用同一生成翼体轮廓镜像，保留原安装座自身的左右接口差异。

## 文件与运行入口

每款目录包括：

- 生成参考、原始GLB、工作流和任务记录。
- `FrostCrystalSword_<id>_Editable.blend`：带原手臂/骨架、生成母版、已适配模型的可编辑源。
- `SM_Guard_<id>.fbx`：护手部件。
- `SM_FrostCrystalSword_<id>.fbx`：世界与预览模型。
- `SK_FrostCrystalSword_<id>.fbx`：第一人称完整武器和原手臂。
- `normal.png`、`ao.png`：结构法线与AO。
- `guard_icon.png`：用于改造面板的实际模型透明图标。

作者脚本：`prepare_mount.py`、`prepare_finish.py`、`retopology_profiles.py`、`retopology_guard.py`、`author_guard.py`。`retopology_profile.json`保存每款生成几何提取的轮廓和来源。导入：`import_guards.py`。完整UE资源目录：

`/Game/Weapons/FrostCrystalSword20260915/Guards20260915/<id>/`

其中三个id为 `bastion_guard`、`riposte_guard`、`light_guard`。

运行路径由 `ColdSteelMeleeGuard` 统一选择，覆盖第一人称、改造草稿与撤销、物品预览/缩略图、世界掉落。原装选择恢复旧网格；剑身Ⅱ符文覆盖继续跟随同一物品的保存选择。现有FrostCrystalSword打包目录覆盖新增子目录。

## 属性

| 项目 | 效果 |
| --- | --- |
| 壁垒 | 格挡减伤×1.30；弹反判定时间×1.25；耐力消耗×1.10；攻击速度×0.95 |
| 反击 | 成功弹反获得反击激励：近战攻速×1.20、耐力消耗×0.80，持续6秒，重复成功弹反刷新时间 |
| 轻量 | 攻击速度×1.05；耐力消耗×0.85 |

格挡减伤沿用现有乘法规范，单独安装壁垒时基础50%减伤变为65%，基础1秒弹反窗变为1.25秒。耐力消耗包括攻击、重击和防御受击，弹反原有零消耗不变，冲刺和闪避不受影响。反击激励是角色的6秒近战增益，不保存为永久属性；新一刀开始时读取并固定本次攻击速度。

原装和改造项仍通过武器实例 `gunsmith_parts.guard` 保存，兼容已有无护手改造的存档。护手模型只为寒晶剑制作，因此三个选项只向寒晶剑开放；其他剑保留原装栏目。
