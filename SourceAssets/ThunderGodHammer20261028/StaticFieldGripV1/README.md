# 静电场 · 雷神之锤专属特殊握柄

本次制作按用户确认仅作用于敌对目标，排除玩家自身、队友与友好单位。

## 玩法与显示

- ID：`static_field_grip`，槽位 `grip`，品质 `special`，仅限 `ue_thunder_god_hammer`。
- 重击蓄力速度增加 15%，通过现有蓄力速度加成累加；物理攻击力直接增加 5。属性面板、改造对比及伤害使用相同来源。
- 普通蓄满重击释放时，以玩家为中心，在半径 3000 cm 范围叠加 2 层感电。未蓄满普通攻击、冲刺攻击不触发。
- 贯雷投出时以锤子为中心立即触发一次，此后每 3 秒在锤子当前位置叠加 2 层。飞行与落地阶段均持续；切换当前武器保留，开始召回、销毁或脱离装备栏后停止。
- 疾雷每次实际落雷，在落点半径 1000 cm 内叠加 5 层。震霆后续三道落雷分别继承已提交的改造与符文数据，保持原有 0.25 秒间隔。
- 静电叠层调用共用感电过载逻辑，继承回响的延长眩晕与保留 2 层。场脉冲本身不额外结算重击伤害、不重复抽取雷鸣随机叠层，也不增加武器熟练度。过载放电仍遵循原有规则。
- 服务端执行范围叠层，同一目标的多个碰撞组件只计一次；投掷计时器属于该场上锤子实例。

## 设计与制作

`Design/StaticField_ThreeViews.png` 是 Blender 三视设计及材质构造图，不是游戏截图。图像生成服务连续两次未产出可用图，改为直接按真实接口制作三维设计；之后使用同一设计源完成模型。图标同样由实际模型在独立灰阶场景渲染，不改变游戏材质。

- 原装握柄长度 49 cm，主握持直径约 31 mm。上下接口保留原模型表面、UV 与角法线；模块枢轴位于原装上端，运行偏移仍为 40.5 cm。
- 缝合皮革主体、沉入式交叉银纹、北欧连续编结、环印及锻造收口均有几何结构。上下端在内部交叠封闭，不使用单面薄片替代外壳。
- 皮革、锻钢、嵌银分别提供 4096 × 4096 BaseColor、ORM 与切线法线，共 9 张纹理。物理平铺尺度 65 mm；源法线为 OpenGL，UE 导入翻转绿色通道。
- 宏观缝隙、倒角、导体与编结由几何承担；皮孔、锻造肌理和细划痕由法线与粗糙度承担。原装端面复用宿主材质。
- 近景静态握柄启用 Nanite、显式切线与完整回退网格；不添加阻挡碰撞，不改变现有手部动作。

## 可重建源与接入凭据

- `make_textures.py` → `Textures/`。
- `author.py` → `StaticField_Design.blend` 与三视图。
- `finalize.py` → `StaticField_Editable.blend`、FBX、GLB、独立图标场景与 PNG。
- `runtime_manifest.json` 记录实际导出三角数、材质槽、枢轴与 FBX 哈希。
- `import_assets.py` / `install.ps1` 通过现有互斥批次导入保存；`import_receipt.json` 的 `complete` 表示资产落盘状态。
- `publish.py` 仅加入本武器握柄选项与模型映射；发布前副本在 `Backups/`，结果见 `publication_receipt.json`。
- `build-*-receipt.json` 记录后台原生构建。2026-10-31 的完整构建成功，之后用于包含最终品质头文件的增量构建报告目标已更新。
