# 疾雷单手举锤 V4：外侧屈肘与整臂支撑

2026-10-29，用户提供游戏截图并明确要求重新检查、优化扭曲的右肘。本次范围是疾雷蓄力、举锤保持、释放与回位，以及截图所穿衣袖的对应形变。

## 定位与修订

从现有游戏实例读取到实际视模为 `SK_Warhammer_BareArmsSprintV1`，衣袖为 FieldRangerTop 的 `ue_field_sweater/Pickaxe` 派生，手套为 BlackLeatherStitchWearV4/Pickaxe。衣袖与视模骨骼位置一致。随后读取已保存的两条序列与这些网格的原生参考绑定和蒙皮，离线复现了截图中的内折上臂。

V3 满蓄力右肘在相机右侧约 16.0 cm、下方 13.0 cm，右肩在右侧 23.5 cm、下方 18.0 cm，肘部向中间内收并抬过肩位。旧求解优先让手与锤柄达到指定目标，再搜索肘向，允许了不自然的支撑姿势。握点不漂移、原生骨长正确，并不能排除这类人体姿态错误。

V4 改为先确定整臂支撑：肩根下沉，肘部落在手的外侧下方，原生肘铰链带动前臂，再从手部推导锤子的变换。固定右手相对锤柄的完整抓握关系；左手快速松开与自然下落沿用 V3。武器整体稍向前留出锤头空间，未修改锤子比例或全局 FOV。

最终作者相机坐标为右、前、上，单位厘米：肩 `(26,10.5,-30)`，肘 `(38.65,34.38,-23.61)`，腕 `(32,59,-14)`。肘在腕下方约 9.6 cm、外侧约 6.6 cm。新姿态的原生参考系前臂 roll 参数不是医学关节角，不将它独立作为人体工学通过标准。

释放沿同一支撑链连续回收，首尾与蓄力、原待机一致。作者采样 240 Hz，蓄力 2 秒，释放约 0.72 秒；实际玩法时钟未改变。

## 保存与定向检查

- `author_motion.py`、`JiLeiMotionV4_Editable.blend`、`Export/` 为可编辑制作源。
- `import_receipt.json` 是两条正式动画压缩与保存回执，旧包保留在 `Backups/`。
- `runtime-context.json` 只读记录已存在的游戏实例，没有启动或驱动游戏。
- `native-poses-before.json` 保留修改前 UE 数据模型；`readback.py` 按序列自己的 240 Hz 读取保存后轨道，回执为 `readback-receipt.json`。
- `review-receipt.json` 比较保存前后的骨长、逐帧局部旋转和握点漂移；`before-frames/`、`after-frames/` 为同相机、实际装备网格的离线结构回放。

离线预览使用简化材质，不含游戏内闪电、镜头反馈和实时矫正形状；侧视图可看到原有视模肩端开口，不是游戏内视角。此次未启动游戏或做实机验收。蓝白闪电、伤害、资源消耗及贯雷分支未改；只有动画资产发生接入，不需要 C++ 重编译。

最终后台读回完成：蓄力 481 键、释放 174 键，均为 240 Hz，Skeleton 与现用视模一致。右手相对锤柄的位置漂移上界约 0.00028 cm；右腕最大折角由旧版约 49.8°降为约 30°。蓄力右臂单采样最大局部旋转约 1.00°，释放约 4.94°，骨段长度保持不变。这些是轨道和离线形态证据，不等于游戏内人体动作已获用户认可。
