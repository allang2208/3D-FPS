# 雷神之锤投掷双臂 V4

用户要求排查并优化向前投掷时的手臂扭曲。本轮只覆盖运行中的蓄力、出手两条动画，后台导入保存已完成；无 C++ 改动，不需要新增原生构建。

## 定位

逐帧读取上一版真实作者动作（240 fps），发现出手附近右腕骨骼轴向折角达到 80.13°，两侧前臂的轴向扭转接近 180°。旧握姿的拇指朝向沿柄方向与过顶前挥不匹配，肘部逐帧搜索又会换到另一分支。前臂辅助骨分配比例本身不足以修正这个握姿约束。

## 制作

- 蓄力时分手换成适合前挥的握姿：右手 0.18–0.62 秒、左手 0.60–1.04 秒；松开、离柄、回握按同一时间窗制作，张掌期间手腕随前臂放松。右手沿柄下移 9 cm，避免在出手处过伸并折腕。
- 肘部使用连续分支和有限角速度，搜索同时考虑腕部折角、前臂扭转和镜头附近空间。张掌换握时，肘部提前适配目标握姿，避免回握的最后几帧才拧过去。
- 前挥时左手先退出支撑（0.16 秒起），右手继续导向至 0.24 秒脱手；之后掌向独立于握柄自然展开，左右手分别随挥、下收。
- 保留原生骨长、V9 前臂 twist_01 100% / twist_02 50% 分配；不修改公共手模、权重和骨架。WPN_root 轨迹、投掷事件以及动作末端的原有衔接仍沿用输入。

## 本轮定向排查结果

详见 `before-metrics.json`、`after-metrics.json`。投掷整段右腕最大骨骼轴向折角由 80.13° 降为 42.14°，实际出手附近约 20°；左前臂最大绝对扭转约 179° 降为 29.51°，右侧约 179° 降为 61°（后者峰值位于收势段）。这些是骨架轴线指标，不是视觉验收结论。

`native-diagnosis.json` 对导入后的蓄力、前挥、出手、随挥关键帧比较 SOURCE 与 COMPRESSED：同一原生 Skeleton，最大位置误差 0.00156 cm、最大旋转误差 0.0375°，骨段长度变化小于 0.00002 cm。运行时仍加载 `ThunderThrowV1/A_ThunderHammer_ThrowCharge` 与 `A_ThunderHammer_ThrowRelease`，`import_receipt.json` 已记录两者保存成功。
