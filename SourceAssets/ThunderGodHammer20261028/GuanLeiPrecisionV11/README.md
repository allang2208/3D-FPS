## 制作内容

重建封闭主体、左右承力腹板、四条前后曲面锻肩、低顶盖、背部盾形实体和连续编结、薄圆徽边框及颈部过渡。肩部凹槽为实际表面凹刻，嵌银纹与主要编结有实体起伏；细微金属表面另有 BaseColor、ORM、Normal。原厂中央符印浮雕保留原 UV 与面角法线，局部适配进新圆徽；未用三个简单线框三角形替代最终符印。

实际安装面沿原厂 `ModulesV1/interfaces.json`：左右 X=-0.0654452141 / +0.0645547859 m，柄颈 Z=0.842 m。接口附近原网格条带保留，新增承力实体在条带内侧过渡。侧视中的大平面是贴合原锤头的隐藏安装面，不是可见正面的装饰替代件。

模型保持原作者坐标和单位，可编辑制作源保留各组成实体。精细检查稿面数由 `model_manifest.json` 记录；尚未作为最终运行 LOD 接入。本轮没有更改玩法、伤害、动画、改造稀有度或上一轮两款通用锤座的剔除结果。
