# 静电场握柄 V2：几何与表面精修

用户于 2026-10-31 要求继续提高面数、结构细节和法线材质效果。本轮仅更新静电场握柄模型、材质和对应实际模型图标；武器功能、数值、改造 ID、握点、原装接口及动画保持原合同。

## 本轮制作

- 皮革从浅刻纹圆柱重做为削薄搭接的缠皮表面：实体搭边、压低接缝、卷边及轻微手工厚薄变化。网格采样向螺旋接缝集中，细分承担真实轮廓与高光。
- 440 针双股缝线，各自有绞合与入皮端。皮革法线中的 880 个针孔对应相同的两端坐标，不以随机凹坑代替缝合结构。
- 双向银纹使用有宽度、圆润截面的嵌条，沿皮革沟槽贴合，端部接入套箍。上端编结改成带交错层次、中央錾线的宽嵌银带，细绞边收进金属边槽。
- 正背矩形贴片改为有厚度的贴合曲面圆印，包含双环、三叶北欧结、细錾刻度与少量蓝色珐琅导桥。
- 锻造收口分出小倒角、银色卷边、深色退刀槽与承托面；原装上下连接面保留原 UV 和角法线。总长度仍为 49 cm，主握持直径约 31 mm。

## PBR 与法线

- 皮革独立 4096 × 8192 圆柱展开：不规则细胞皮纹、压紧区、针孔压痕、接缝磨亮和粗糙度变化。
- 锻钢、嵌银各 4096 × 4096，提供不同强度的锻纹、微划痕和粗糙度；三种主要材质共 9 张 BaseColor、ORM、Normal。
- 所有法线均由物理尺度的高度源生成；保留 16-bit 高度源和作者配方。宏观搭接交给几何，法线补充微表面，避免宏观凹凸重复计算。
- 源法线为 OpenGL，UE 使用 Normalmap 压缩、关闭 sRGB 并翻转绿色通道。金属 ORM 使用 Masks，纹理保留流送。皮革允许最长边 8192，实际驻留 mip 仍由引擎流送决定。
- 保留既有 Nanite 路线、显式切线、完整回退几何和无阻挡碰撞。针线与窄嵌纹采用 10 档位置精度（步长约 9.77 微米）、15-bit 法线、12-bit 切线；回退明确选择百分比模式并保留 100%，避免 Auto 使用项目启发式。仅设置本握柄，不修改全局画质、纹理池、光照或运行时加载策略。

## 文件和落盘

`surface.py` 是米制几何配方；`make_textures.py` 制作 PBR；`author.py` 建模并保存；`finalize.py` 导出 FBX/GLB、保存可编辑源并渲染独立灰阶图标。接口保留代码复用未删除的 V1 作者源，宿主仍为 `ModulesV1/ThunderGodHammer_Modular_Editable.blend`。

`runtime_manifest.json` 记录实际导出三角数、枢轴和文件哈希。V1 为 534,792 三角形；V2 的最终数值以本轮清单为准，不将面数增长描述为实测画质或性能结果。

新 UE 资产使用独立目录 `/Game/Weapons/ThunderGodHammer20261028/StaticFieldGripV2`，保存后仅切换 `slots.grip.static_field_grip` 的模型引用和版本。旧引用与图标备份位于 `Backups/`；资产保存与发布状态分别见 `import_receipt.json`、`publication_receipt.json`。

本轮为美术资产制作与接入，没有 C++ 变更，无需重新编译原生模块。没有打开 UE 窗口、启动游戏或执行测试、验收；未额外生成验收渲染。实际近景表现与手部接触由用户测试。
