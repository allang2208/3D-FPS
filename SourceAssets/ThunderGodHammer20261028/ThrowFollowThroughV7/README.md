# 雷神之锤出手后的随挥与下收 V7，2026-10-29

## 定位

当前保存动画的数据模型显示，旧下收在 0.315 秒附近双手速度仅约 0.4 cm/s，分段平滑曲线把随挥和收手分成了两次起停。0.58 秒以后又混入旧移动姿态，造成左手前后折返；旧版离线关键帧在 0.64 秒已退出画面，0.78 秒手又短暂冒出。

## 修改

- 用带连续中间切线的弧线连接离手、随挥、屈肘和下收，取消中途停住再启动。
- 左手先向外下方撤离；右手保留向前下方的随挥，再屈肘收回，两侧节奏错开。
- 上臂先回收，手腕稍晚放松，并加入一次小幅屈腕随动；手指逐渐回到原有的松弛终点。
- 后段沿既定空间轨迹接原终点，关节朝向绕当前骨段轴平滑调整，去掉混回旧运动轨迹造成的反向伸手和再次入镜。制作中发现直接混合整链局部旋转仍会拉偏左手，已改为保持肩、肘、腕的位置轨迹。
- 保留整个武器驱动轨迹、0.24 秒离手事件、原始骨长、现用骨架、240 fps 和末端的召回入口。没有修改 C++、飞行、雷击、伤害、召回及接锤资产。
