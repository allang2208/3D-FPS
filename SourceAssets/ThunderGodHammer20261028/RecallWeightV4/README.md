# 雷神之锤接锤受力 V4

用户反馈 V3 接锤过于保守，本轮重做右臂接锤的主节奏。

- 保留左臂等待时自然下垂、右手等待微晃和 V9 原生肘铰链／前臂扭转分配。
- 落掌后 0.025 秒开始主压缩，0.105–0.155 秒进入承重低点。右掌关键帧后移 16.5–17.4 cm、下沉 9–9.8 cm，武器随握点倾转 12–14°。收肘承受重量，肩部略随受力后退下沉。
- 手指于 0.016–0.082 秒错峰握紧；拇指随后压住握柄。主压缩后保留短暂承重停顿，再加入小幅衰减余震并主动收稳，不再用短正弦波替代整个接锤动作。
- 锤柄与右掌使用同一变换，左手在 0.25–0.48 秒重新扶柄。保留 0.10 秒投射物／手持模型交接及 0.60 秒结束合同，末段复用原有待机衔接。
- 召回路径的时间曲线从五阶两端缓动改为 `T*T*(2-T)`，入掌时保留速度，由手臂压缩承担停止。路径控制点、沿途扫掠伤害、整圈旋转对掌和追踪手掌逻辑继续沿用。
- 镜头以同一 0.025 秒落掌时钟驱动：受力下压、短承重、回弹及快速衰减余震。主俯仰参数 4°，再由现有 `CameraMotionScale`（源码默认 0.45）与 `fps.Camera.Shake` 缩放，不改变控制瞄准方向。
