# 雷神之锤投掷动作 V3

范围：贯雷锤座的蓄力与投掷两条第一人称动画。

- 抬举时左肩根向后外侧移，右肩支撑高位握柄；在真实骨长内解双臂，避免通过缩放手臂隐藏根部。
- 肩肘腕按同一屈伸平面求解，肘基部不承担掌部轴向旋转。前臂扭转骨遵循 V9 的 distal 100%、middle 50% 分配。
- 挥锤期间右手相对握柄只增加 15° 转握，左手回转 10°，替代原来右手在短促出手段大幅拧转。
- 左手先松开支撑，右手维持最后导向；拇指、小指、无名指、中指、食指按先后松开，各指节保留少量自然弯曲，掌骨不另行展开。脱手后左右手分别随挥和回收。
- WPN_root 的既有逐帧轨迹、0.24 秒投掷时点、原总长与召回入口姿态保留。未改投射物轨迹、伤害、模型、召回/接锤动画或公共手模。

作者源：`ThunderHammer_ThrowRefineV3_Editable.blend`；导出位于 `Export`。导入仍覆盖已被运行代码引用的 `ThunderThrowV1/A_ThunderHammer_ThrowCharge` 与 `A_ThunderHammer_ThrowRelease`。后续投掷调整以此作者脚本为入口，旧 ThunderThrowV1 作者脚本保留为原始制作记录。

本轮仅制作、导入并保存。未启动游戏、未追加动作测试或验收渲染；视觉效果由用户实机确认。
