# 贯雷锤座蓄力指示线调整 — 2026-10-28

用户反馈：重击蓄力时看不到抛物线指示线。本次仅排查和调整该指示线。

## 诊断证据

- `before.json`：已安装贯雷、满蓄力、体力 100 / 释放消耗 15 时，正常生成 28 个轨迹点和 27 段线条；组件注册与可见标志正常。
- `render-before.json`：隔离后台游戏视图中能绘制，960×540、水平瞄准时红色像素 121。因此没有把正常水平场景的故障归因于触发入口或组件被隐藏。
- `after.json`：近台阶的真实碰撞轨迹只有两个点。使用保持原样的魔法默认绘制参数重放该轨迹，可见线段为 0；原因是唯一线段从进度 0 取样，整个线段 alpha 为 0。
- 投掷释放点横向偏移约 0.158 cm，接近视线轴；水平/俯视时正确轨迹的屏幕投影本身很窄。

## 修改

- `FPSMagicPreview::DrawPath` 增加线宽和最低透明度可选参数；火球、冰锥默认参数及旧渐隐样式保留。
- 贯雷专用参数：线宽 3.2 cm，起段最低 alpha 0.6。
- 在实际预计接触点增加半径 18 cm 的红色小圆标记，沿接触面法线抬高 2 cm。标记表示落点中心，不表示雷击 AOE 半径。
- 预览仍使用真实投掷的 Launch / Advance、固定步长、重力和碰撞逻辑；满足满蓄力及释放体力要求后显示。
- 失去本地角色控制时清除旧线段。现有取消、未蓄满、体力不足、未安装贯雷的隐藏规则保留。
