## 原因与修改

旧版直接复用贯雷的过顶武器终点，仅向右移动。满蓄力时锤头中心相对镜头为前方约 12.3 cm、上方 90.2 cm，超出视野；固定原右手握点后继续套用投掷的逐帧肘极搜索，右腕折角约 67°，中段发生翻肘。收势最后一帧又直接恢复旧待机，形成约 113° 的前臂局部旋转跳变。

V2 改为右前方举锤：满蓄力锤头中心前方约 70.4 cm、上方 35.1 cm。先确定单一最终肘部弯曲方向，再从原待机连续运输弯曲平面；锤柄抬升与轴向转动分别编排，保持右手相对武器的握点与手指姿态。右腕沿平缓前送弧线，左手先松开再下垂。释放有短促缓冲，随后沿连续路径回收，左手最后重新扶柄。
