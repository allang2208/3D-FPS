# 贯雷召回音效 V1

当前版本提示：后续 V3 已修改空气循环并将接锤改为掌击式闷拍，空气声／接锤声恢复入口为 `../RecallAudioV3/`；本目录只保留金属嗡鸣作为现用素材，其余为历史。

2026-10-29 用户认可前段飞回声，否定旧接锤声。当前接锤制作与导入入口已转到 `../RecallAudioV2/`，两段独立试听也在 V2；本目录的完整试听与旧接锤配方保留为历史，勿用旧导入恢复覆盖 V2。两条飞行循环仍沿用本目录素材。

用户要求：金属嗡鸣 + 旋转划破空气 + 回到手中的厚重声音，并提供试听。本批只为贯雷召回增加声音，不修改动作、飞行、伤害或疾雷。

## 素材与试听

- `Audio/S_GuanLei_RecallMetalLoop.wav`：2 秒单声道循环，低频非整数倍金属共鸣与轻微颗粒。
- `Audio/S_GuanLei_RecallAirLoop.wav`：2 秒单声道循环，以项目内用户提供的钝器挥舞录音制作连续旋转破风。
- `Audio/S_GuanLei_RecallCatch.wav`：1.02 秒单声道接锤，短低频重音、握持冲击、受阻尼的金属余响。
- `Audition/GuanLei_Recall_Full.wav`：2.65 秒立体声完整试听，模拟 1.3 秒召回，声音从右前方逐渐接近。
- `Audition/GuanLei_Catch_Only.wav`：接锤单独试听，保持完整试听中的接锤电平。

试听是分层合成示例，不是游戏录音；游戏中实际方位与响度由锤子距离、方向和用户音量设置决定。实际召回会因距离在 0.55～3 秒间变化，不能把整段试听作为固定时长音效直接套进动画。

作者源为 `author_audio.py`，音源、逐文件 SHA-256、采样率和制作参数见 `audio_manifest.json`。挥舞与砸地供体来自用户此前提供的本项目录音，金属供体及新共鸣为项目合成音，不推定对外分发许可。

## 运行时接入

入口为 `AThunderHammerThrown`，音频准备与武器外观共用异步请求。三个 SoundWave 跟随现有雷神之锤烹饪目录，无每帧同步加载。

- Phase 2：两条空间循环随返回中的锤子移动。80 ms 淡入，靠近时渐强；破风播放速度参考实际五次旋转时钟的导数。
- Phase 3：实际接触手掌时淡出循环，独立播放一次接锤重音。使用真实到达事件，不使用估计飞行结束时间。
- 手持交接后锤子 Actor 在 0.1 秒退场，接锤单次声音仍保留约 1 秒尾音；中止召回则停止循环。专用服务器不创建音频组件。
- 资产目录：`/Game/Weapons/ThunderGodHammer20261028/RecallAudioV1`。

`import_audio.py` 导入并保存三个 SoundWave 与飞行／接手两个衰减配置。`publish.ps1` 完成后台 Editor 构建及无界面导入，沿用资产批次互斥；结果分别看 `build-*-receipt.json` 与 `import_receipt.json`。写好脚本不代表已导入，以回执为准。本批不启动游戏；主观听感与游戏内音量由用户试听确认。
