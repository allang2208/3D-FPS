# 贯雷锤头嵌地落点（2026-11-01）

用户要求贯雷落地后具有嵌入地下的姿态，不悬空、不与接触面留缝。

此前 Land 固定使用 ImpactPoint + 世界 Z 36 cm，停留与召回均重建世界 135° / FlightYaw 姿态。该位置未使用锤头实际表面，姿态也未跟随坡面。

本轮将水平地面的 135° 锤头向下、锤柄向上倾斜姿态转换到实际地面法线坐标系，朝向优先取入射速度的切向分量，垂直下落时取投掷朝向的坡面投影。落地时将实际锤头支撑点对准命中点，并沿接触面法线压入 4 cm。偏移包含接触点到飞行枢轴的完整向量，不再用整个武器包围盒或固定上抬量。

原装、重锻、棱锤、轻鼓、尖锤五种接触点均从现有 Blender 作者网格导出，按实际模块变换及 CenterZ=70 cm 换算。author_contacts.py 为制作入口，contacts.json 为作者数据，ThunderHammerGroundContacts.h 为运行时小型常量表。更换锤头网格或改变 GroundPitch 后需重导接触点；只升级中央锤座且保留原厂锤头接口时，无须随锤座外形修改该表。

飞行球扫命中地面后，只对已命中的组件沿法线追加一次复杂表面线段查询，尽量消除简化碰撞高于可见面的间隙。预览与真实投掷共用 Advance，因此使用同一接触点。组件无可用复杂表面命中时沿用原命中。

落地姿态由服务器确定并复制 GroundRotation，客户端无需等待模型加载参与定位；专用服务器不加载高精度网格。召回旋转从复制的落地姿态开始，保持现有召回时长、路径、伤害及接锤动作。落雷与冲击波仍从地面命中点发出，位置不跟随埋入偏移。

制作期间未改动现有模型、材质、属性或存档。未启动 UE 编辑器，未运行游戏、截图、测试或验收。后台 Editor/Game 构建结果以本目录各 target 的 receipt 为准；编译结果不代表视觉或联机实测。
