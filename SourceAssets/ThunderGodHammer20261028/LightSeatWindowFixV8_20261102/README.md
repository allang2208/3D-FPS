# 镂肋轻型座横杠穿模修复 V8 — 2026-11-02

用户截图显示轻型座顶部有一条无纹理横杠向两侧穿出。本轮只修复 `head_mount / ribbed_light`。

## 原因

V7 轻型座布尔开窗错误保留了切割体的外侧面。源模型前后范围约为 -59.78 至 +58.35 mm，而 V7 轻型座延伸到了切割体的 -90 至 +90 mm；12 个外侧顶点与 14 个切割材质面形成截图中的横杠。

开窗前的 C6 源网格含退化三角形和部分四面共边结构。原布尔流程未处理这些结构，错误的内外分类将切割体壳面带入输出。本轮从 C6 开窗前源重建，保留 V7 的窗口位置与造型、原厂圆徽、安装端、UV 和材质。

## 修复制作

- 在局部变形后处理小于约 0.15 微米的退化边，将原自定义法线作为面角属性保留。
- 使用支持自相交与非封闭输入的精确布尔分类，重新制作两个贯穿窗口；切割体对象在运算后移除。
- 新窗口内壁单独分配现有金属材质与 UV。
- 导出流程拒绝任何穿出源模型前后边界的切割面，直接针对本次横杠故障；正式 V8 导出恢复原厂前后范围。
- 该处理不宣称整个高密度原网格已全部拓扑清理，也不修改其他部件。

`LightSeat_WindowFixV8_Editable.blend`、`Export/`、`author.py` 为本轮制作源。`reported_geometry.json` 记录针对用户报告故障的定位数据；没有运行游戏测试或额外模型渲染。

## 接入

已有编辑器运行时先通过 UE MCP 批次互斥排队；前两次等待超时且未发出请求，第三次获得通道时编辑器已关闭，远程节点发现失败，仍未执行导入。随后通过同一互斥在后台 commandlet 完成导入、保存与引用切换，退出码 0。

新资产保存在独立目录 `/Game/Weapons/ThunderGodHammer20261028/LightSeatWindowFixV8/Meshes`。`import_receipt.json` 记录一份网格已保存；`publish.py` 仅更新轻型座引用，`publication_receipt.json` 保存新旧路径及旧配方备份。两个回执的 `complete` 均为 true。

厚壁重铸座、叠片缓冲座、疾雷、贯雷、数值及存档 ID 保持原值。本轮无 C++ 修改，无需重新编译。没有主动关闭或启动编辑器界面，也没有启动/停止试玩；下一次游戏实例将加载 V8 新引用。未进行实机测试，由用户查看效果。
