## 玩法

按住普通攻击键开始蓄力，使用原有重击蓄满时间及其加速规则。右手单手举锤，左手自然下垂，锤身缠绕电弧。蓄满且指向有效地面时显示魔法式范围圈。松键后，服务端重新核对蓄力、装备、资源和落点，在落点释放雷神重击同款落雷，武器留在手中。

| 项目 | 初始数值 |
| --- | --- |
| 最远指定距离 | 20 米，视线被地形阻挡则不可越墙选点 |
| 落雷范围 | 半径 3 米 |
| 主击伤害 | 与雷神之锤一次完整重击的防御前总伤害相等，整体转换为魔法伤害；物理部分计入总量后转换，不丢弃；原生落雷仅计入一次。详见 `../../GroundAreaTargeting20261029/README.md` 的用户口径纠正 |
| 蓄力消耗 | 8 体力/秒，受装备动作消耗倍率影响；6 魔法/秒 |
| 资源不足 | 中止蓄力，反向放下；已消耗资源不退还 |
| 蓄满前松开 | 延续普通攻击输入语义 |
| 命中状态 | 1 层感电，原生重击眩晕 1.5 秒；精英控制沿用破韧规则 |
| 表现 | 雷束宽度 1.65 倍，增强落地爆闪，保留分叉电弧、地面冲击与声音 |

范围圈复用现有魔法的地面投影语义，20Hz 更新。重击释放、消耗结算与命中由服务器处理；身体与远端沿用原生动作流，独立求解右手举锤与左手下垂。现有贯雷投掷、召回及其他锤座分支保留。

## 感电规则

当前 `skills.json` 的雷电规则为每层增加 3% 受到的电系伤害，5 层触发过载并清空感电，过载眩晕 1.2 秒，对附近敌人放电。疾雷命中只增加 1 层；过载溅射不继续叠层。

`UCombatStatusFormula::AddElectrified` 接收阈值并完成叠层/清空，`AddStun` 取剩余眩晕时间和新眩晕时间的较大值。因此疾雷自身 1.5 秒与过载 1.2 秒不会直接相加成 2.7 秒。
