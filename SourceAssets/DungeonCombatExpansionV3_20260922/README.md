# 地牢第二次扩容与自然滴液

目标地图：`/Game/GameMaps/L_Dungeon_AuthoredExpansion`。

## 面积和战术通路

以当前上一版的可走地面为基准再增加 50%。面积按地板并集扣除墙、柱和未架桥坑道计算；不是角色胶囊退让后的导航面积。

| 房间 | 上一版 | 本版 |
|---|---:|---:|
| 管线分配间 | 107.15 m² | 160.73 m² |
| 排水检修室 | 183.05 m² | 274.58 m² |
| 破损支护室 | 207.83 m² | 311.75 m² |

累计为初始版可走地面的约 2.25 倍。保留房间轮廓语义、层高、管径、墙砖物理尺度、侧室大小和原通道入口。

排水室四根柱子向两侧重新排布，柱内侧到坑道栏杆净距 3.214 m；外侧到墙面约 2.81 m，提供内侧侧移、外侧绕柱与过桥的选择。入口与前连接段净宽 2.8 m，出口与后连接段净宽 3 m。新增东西侧翼战斗锚点。

## 液体

- 积液改为 112 段、38 径向环的近圆形网格，半径约 72 × 67 cm。边缘采用两组低幅波动，透明边缘沿径向衰减，取消原超椭圆方形轮廓。
- 取消常驻长液条。管口保留 1.2～4.3 cm 动态聚滴液颈，增长后收颈，释放后回缩；三处滴点错开相位。液滴独立下落并逐渐拉长，约 2.35 s 一个聚滴周期。
- 同一函数计算液滴位移与法线，避免形变后高光仍像静态圆管。模型面朝向同步调整。
- 落地涟漪使用相同释放时刻、周期、相位与坠落时间；不产生独立乱序的落点动画。
- `PusRadialFootprint` Actor tag 启用圆形积液伤害轮廓。`DungeonPusChannel.cpp` 沿用原计时和伤害流程，仅将带该 tag 的积液改为径向边界，坑道继续矩形边界。每 0.5 s 8 点基础腐蚀伤害，由现有受伤系统结算。

## 生成与接入

1. `Scripts/layout.py` 固定从上一版快照 `Config/rooms-before.json` 取面积目标，从最初几何配方推导新布局。重复运行不继续累乘。
2. Blender 执行 `DungeonRoomShells20260922/Scripts/author_rooms.py`；Python 执行该目录 `author_interfaces.py`。
3. Blender 执行 `Scripts/author_fluids.py`，写回积液几何、位置和伤害形状配置。
4. 通过既有桥依次执行 `import_fluids.py`、`import_meshes.py`、`install_scene.py`。新资产位于 `/Game/Dungeons/CombatExpansionV3_20260922`，坑道液面复用上一版资产。
5. 标准房间安装器仍支持当前配方；圆形积液 tag 与伤害尺寸一同生成。

当前原生 Editor DLL 时间晚于本次 `DungeonPusChannel.cpp` 修改；必要 Live Coding 同步构建返回成功、无待编译变更。没有启动 PIE、额外测试、截图或渲染，观感和战斗走位由用户体验。
