# M24 标准 V9 待机手臂排查与修订

用户明确要求重新按标准手模检查待机左腕、手臂的拉伸。所有检查在后台完成，没有启动游戏或主动打开可见编辑器。两份正式握持配置已保存并在新后台进程读回；各 13 个片段全部找到，浮点序列最大读回误差约 1.12e-7。保存状态见 `install_receipt.json`、`readback.json`。

## 定位

当前生产视模是 `MotionMagazine20261027/SK_M24_MotionV9`，待机/瞄准由 Hold 动画加 `MotionPolish20261027/DA_M24_SupportGrip` 或 `DA_M24_Mag10` 姿态差量求值。

对 `M4_V9_Template.fbx` 的逐顶点和逐骨对比：20,485 个标准裸臂顶点的参考表面、原生参考关节及蒙皮权重最大差值均为 0（`template_comparison.json`）。上臂 27.771 cm、前臂 27.251 cm 与参考骨长一致，没有使用骨段缩放。问题是旧待机差量的肩部外移、较直的肘部、腕部偏折，以及虎口/手指压进护木，而非标准手模被换掉。

## 修订

在武器坐标内重排肩肘，托点沿护木后移约 5.6 cm，掌根向侧下方避开实际护木表面。保持原生骨长、手掌朝向、枪根和右手轨道；肩、上臂、原生肘铰链以及前臂 100%/50% 扭转站一起适配。手指使用实际蒙皮和护木网格做有界屈伸/MCP 侧摆拟合，不改变轴向旋转。

本次只写两份现有握持 DataAsset 的左锁骨子树/左手 IK 差量，保留其他差量。每份配置涵盖 13 个接近原持枪姿态的片段；动作操作阶段按握点距离与掌向释放修正，回握时连续恢复。脚架片段只在 0–0.12 秒伸手和 0.30–0.44 秒回握衔接，0.12–0.30 秒勾拉及总时长 0.48 秒保留。标准皮肤网格、材质、参考绑定、基础动画与机械事件没有重导入；无 C++ 修改。

## 针对性离线结果

- 待机/瞄准：肘弯约 34.51° → 43.85°；腕轴偏折约 25.59° → 20.51°。这些是本骨架的方向诊断量，不是临床活动角。
- 所有受影响片段全源帧采样，骨段长度误差小于 0.001 mm，未通过拉伸骨头达成握点。
- 原待机的护木穿入最大约 11.83 mm；新握姿未检出超过 1 mm 的手部穿入，不等于零几何交叠。见 `contact.json`。
- 待机腕、肘区未检出折回面；指根原有微小折回面由 6 面降至 5 面，主要在中指/无名指根部，仍有精修空间。见 `review.json`。
- 两种弹匣的脚架衔接各 49 个完整蒙皮采样，肘部翻折为 0；腕点最大 10 ms 步长约 2.69 cm，见 `handoff.json`。
- `Comparison/` 是相同相机、实际 V9 蒙皮的修改前后图，包含侧面、腕部、掌侧和第一人称离线视角；不是游戏截图，也未覆盖全部衣物/枪身改造组合。
