## 制作依据与修正

- 按 `ue5-fps-arms-animation/references/pose-contact.md` 的顺序，先处理掌面、拇指对握和四指包覆，再处理各指节；参考 M4 已沉淀的方法，不复制另一把枪的角度常量。
- 当前骨架指段沿局部 X 延伸。旧版本的 `Rx(spread)` 实际产生轴向扭转；本轮改为局部 Y 张合、Z 屈曲。保持骨长、rest、蒙皮和手指局部平移/缩放。
- 旧指腹区域沿用 AKM 最近点，拇指选到了侧缘。重新用各指骨局部坐标选取中央掌侧皮肤，避免侧缘靠近而中央指腹仍然悬空。
- 同时约束掌面、四指和拇指。宽弹匣使用较平缓的关节增量；关节增量不等于骨段累计弯曲角。末轮拇指修订锁定手掌与四指骨骼，并约束受拇指蒙皮影响的掌面距离。
- 保持 `hand_l = magazine * grasp` 的持匣关系；同步取匣闭合、持匣、插入压实、逐指松开和向外退手。整条左臂随手腕目标重建，保留源机械事件、右手动作及换弹时钟。
