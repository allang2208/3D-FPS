# 空闲左手自然摆动 V16

用户反馈 V15 左手僵硬，要求加入手指摆动、减轻机械感。本次仅调整单手持杖的空闲左臂。

## 改动

- V15 的五指屈曲在整个步态内固定，手腕相对前臂也固定。V16 将肩、肘、腕、手指分别安排相位：肩先运动，肘与腕跟随，五指再作轻微松紧变化。
- 腕部位置采用周期三次曲线；前送、抬升、回落的极值错开，前后摆不再共用一条正弦轨迹。肩保持相机后方，肘仍朝左下支撑。
- 保留原生骨长和位置，手腕仅增加小幅屈伸和侧偏；辅助骨完整跟随其骨段，不作分数扭转补偿。
- 食指至小指逐渐延后，MCP/PIP/DIP 再逐节延后 0.09 rad。四指屈曲变化幅度约 3–7 度，拇指约 1–2 度。各指基础弯曲度不同，避免整手同步张合。
- 奔跑的基础手型更收拢，手指摆幅为行走的 80%，手臂前送/抬升使用独立轨迹。
- 仍用脚步距离时钟驱动 32 个完整局部姿态；起停、走跑、蹲行与动作占用沿用现有混合。附加缓慢幅度变化仅在 94.4%–100% 范围，不改脚步相位、不引入随机逐帧抖动。
- 姿态缓存增加版本失效条件，防止 Live Coding 后同一手模继续使用旧姿态表。

右手握持、法杖右移和施法动作沿用当前版本。
