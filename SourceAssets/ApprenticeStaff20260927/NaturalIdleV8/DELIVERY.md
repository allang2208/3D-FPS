# 长杖完整待机支撑 V8 · 2026-09-27

用户要求结合已有抓握与整臂经验优化待机持杖。本轮遵循 `grip-arm-refinement.md` 的“先固定已接受部分”，不再通过自由旋转整手或重新卷指来修正整臂观感。

## 实际修改

- 保留 V6 的正手方向、整手位置及全部手指接触修正；上段握点 Z=32 cm、杖身构图和 V7 裸手原生骨架保持。原有接触平面偏移约 4.34 cm 也保留：它对应当前粗杖柄的容纳空间，不能只因数值较大就直接减去。
- 用原生骨长、当前手腕位置和方向制作肩—肘—腕完整支撑。相机空间肩点为 `(0.524, 19.503, -23.910)` cm，肘点为 `(19.572, 39.385, -27.527)` cm。原代码的 `(16, 35, -39)` 是 IK pole，不是实际求解后的肘位置，二者不能直接作为位移前后比较。
- 制作时同时考虑腕轴折弯、肩位偏移和肘部支撑；不强求腕轴完全笔直而将肘无限抬高／外展。输出腕轴指标约 25.56°，这是作者目标的结果，不是医学角度、视觉通过或游戏测量。
- `StaffWeaponComponent.cpp` 的携杖姿态使用这套明确的肩肘坐标，替代通用施法默认支撑点；走跑、惯性与呼吸偏移仍在该基底上叠加。
- `StaffArmsMeshComponent.cpp` 将制作好的完整右臂基准随握杖运动搬运，再适配当前弯曲平面。上臂轴向旋转来自这套基准，避免每帧从参考姿态重新猜测支撑。保留原生骨长、辅助骨完整变换和左手逻辑。
- 蓄力／挥杖的时间、接触点轨迹和阶段目标没有修改；其回收目标会自然使用新的携杖支撑。没有新增反射字段，也无需重导网格或动画资产。

- `author_idle.py`：读取 V4 的已纠正 VRE 镜像数据、V6 接触及 V7 原生骨架，冻结接触后制作整臂。原生 M4 rest 本身已有指节弯曲，不能把 donor 的开合系数直接解释成人体关节角度。
