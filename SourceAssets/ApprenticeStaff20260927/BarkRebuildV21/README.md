# 长杖自然木杆 V21

按用户指定的 `../BranchCrystalV18/Design/staff_three_views.png`，在 Blender 重建木杆的实际凹凸轮廓。三视图是造型依据，既有握持区和改造接口是装配依据。

- 非圆截面、沿高度变化的粗细、轻微弯曲的中心线。
- 纵向沟槽、断续浅裂纹和不对称的隆起边；错落分布的愈合枝节，与杆身共用连续网格。
- 裂纹表现为凹槽，不切穿木杆；保持上一版封闭分件的制作方式。
- 接触手掌的原始握柄四个版本继续保留，局部 Z=22～42 cm；前后过渡自然淡出，避免粗糙凸起改变握持直径。
- 上方麻绳下的安装段保持原尺寸，仅顶部保留绳结；默认白水晶使用原几何与 QuartzAimV22 材质路径，透明度为 V29 恢复的 0.24–0.42，保留 V32 照明。V34 外壳与内含物升级已被用户否决，源文件与重导入口退回升级前方案。
- 符文、导魔线和尾部箍从新杆身表面重新取样生成，沿用六槽改造结构和原资产路径。

作者源：`Staff_NaturalBark_V21.blend`、`author_model.py`、`natural_bark.py`。作者源中保留原 Meshy 底稿，新的裸露木杆表面由本地 Blender 重建；本次没有新发起 Meshy 生成。

输出：`Export/` 下的 24 个 FBX、网格清单、接口清单及库存图标。制作入口是 `author_model.py`；接入入口是 `import_model.py`，实际保存结果由 `import-receipt.json` 记录。当前运行资产仍位于 `/Game/Weapons/ApprenticeStaff20260927/Meshes/`，修订资产及旧版备份位于 `/Game/Weapons/ApprenticeStaff20260927/BarkRebuildV21/`。
