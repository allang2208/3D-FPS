# 长杖封闭网格与连续木纹修复 V19

## 已定位问题

- V18 生成网格在 UV 缝处分裂，直接切割再补盖无法得到完整封闭边界；旧母版焊接后，杖身仍有 274 条开放边，原握把有 220 条开放边。
- 握持段／圆形连接段的最近三角形 UV 转移跨过 Meshy 图集切片，出现长条拉伸与锯齿木纹。
- 封口处的平滑法线参与侧面插值，产生黑色接缝和尖状阴影。
- 不活动的空 UV 通道排在正确通道之前，Blender 与 UE 使用了不同通道；统一为正确的第 0 通道，并补齐绳头、晶体等端面的 UV 面积，导出显式平滑组。UE 网格开启完整 UV 精度，防止微小切口的 UV 被半精度量化压缩。
- 水晶内部开放白色薄层与外部透明材质叠加，造成发白外观。

## 修复内容

`author_model.py` 沿已适配的 Meshy 木枝外轮廓重建连续闭合截面，保留原弯曲和接口位置；握把沿用四种原有模型的侧面顶点，仅补齐端盖。原握把不规则切口的端盖改用中心扇形三角面，防止 UE 剔除共线细长三角面造成二次开口。端盖使用硬法线，侧面维持平滑法线；独立实体在装配时不再跨部件强行焊接。元素杖头从干净的单独颈部网格取形，不再从包含绳圈和相接端盖的整个装配体切片。

木质部件采用同一轴向 UV 场，重用项目已有 `/Game/UnrealNormandy/Textures/T_WoodSurface_00A_*` PBR，未更改这些共享贴图。RHAOM 的 R/B 通道分别用于粗糙度／AO，法线强度 0.6，金属度 0；默认木色调为棕色。纹理出处沿用本地 UnrealNormandy 资产，不新增外部素材或 Meshy 计费任务。

去掉开放白色内层，保留封闭切面水晶；UE 材质改为 Thin Translucent，反射与透射分开处理。只有上部麻绳和短绳结，下部无缠绕。

保持 160 cm 长度、握点 `(0,0,32)`、握持段 `z=22..42`、杖头接口 `z=62`、默认尖端 `z=80`。沿用 24 个资产路径和六个改造槽。没有修改手臂、握姿、移动、奔跑、施法动画及游戏数值。
