# 学徒长杖分件、替换与贴合检查

日期：2026-09-27。用户明确要求“检查一遍”。

**结论：真实分件和底层换件通过专项检查；改造件的几何贴合未通过，不能作为完整贴合成品交付。** 本轮保留问题现场，没有重做模型或修改正式组装逻辑。

## 发现的问题

| 优先级 | 问题及实际证据 | 原因 / 建议修正 |
|---|---|---|
| P1 | **两种导魔线完全埋入杖身。** 链式、直流各 3,456 个 UE LOD0 顶点均在木杖内部，离外表面约 1.1–8.0 mm；完整组合中不可见。 | `author_staff.py:131–135` 固定半径 2.65 cm，而对应段杖身半径约 2.86–3.34 cm。按真实截面生成贴表路径并留出可见厚度。 |
| P1 | **三种符文大面积被遮挡。** 鹰眼、暴击各约 60.7% 顶点在木杖内，风暴约 85.2%；画面只剩尖角和零碎短线。这里是顶点比例，不是投影面积比例。 | `author_staff.py:108–116` 把图案放在固定切平面，未适配曲面。应投射到实际杖身表面或采用受控浮雕。 |
| P1 | **四种挂坠都未接上连接杆。** 雷铃间隙约 14.69 mm；冰魄、净厄、烈焰约 2.94 mm。均可在近景直接看见断开。 | `author_staff.py:123–128` 连杆终点和吊坠顶端分别独立设定。以实际连接孔、环扣和吊点制作连续结构。 |
| P2 | **三种替换握柄与木杖接缝有明显台阶。** 替换握柄主体半径 2.5 cm；下、上切口木杖半径分别约 2.74–2.81 / 2.84–2.90 cm，主体径向相差约 2.4–4.0 mm。端环未补齐接口。 | `author_staff.py:117–121` 使用统一圆柱，没有沿原切口边界做过渡。不是轴向悬空，而是外轮廓突然收窄。 |
| P2 | **冠饰与改造杖头的接口没有统一贴合。** 例如冰晶组合，冠环内缘与金属座约有 3.5 mm 径向间隙。原装头、四种新头各与四种冠饰的近景已保存。冠齿可与头部相交，不宜把整个冠饰一概判为完全悬空。 | `author_staff.py:92–107` 金属座、冠环、冠齿各用独立固定尺寸，应明确冠环承托面及头部包络。 |
| P2 | **鹰眼符文与暴击符文无法从模型区分。** 实际 UE 顶点位置哈希相同，材质也相同。 | 两者走同一图案生成分支，只有风暴分支不同。需要各自独立可读的图案。 |

模型来源也需明确：Meshy 生成的是基础木杖；20 个改造选项由 `author_staff.py` 的程序化几何生成，不是 20 个分别由 Meshy 生成的精制配件。

## 已通过的部分

- 24 个已保存 UE StaticMesh 均成功加载，材质槽没有空引用：完整母版 1、杖身 1、原装杖头/握柄 2、改造选项 20。
- 杖身已实际切开握柄区间与杖头区间；替换的是独立模型，不是在完整母版外简单叠加配件。六个逻辑槽位中，原装杖头和原装握柄有网格，其余四槽原装为空。
- UE 原生 `ColdSteelStaff::Resolve` 与 `ColdSteelStaffAssembly::Apply` 在独立预览世界遍历 **6,000 种组合 + 最终恢复原装，共 6,001 次应用**。零失败：选项路径、组件数量、无重复/残留旧件、父子挂接、零相对变换、可见性继承、保留无关子组件均符合预期。
- 原装组装总长 160 cm；排除新切面的边界后，三个分件的外表面顶点到原始完整模型的距离为零。原装外形得以保留。
- 改造台关闭时会重置共用预览键；没有确认此前怀疑的关闭重开缓存跳过问题。

上述验证证明组装器可以换件，**不等于改造台点击、扣券、存档回读、第一人称及掉落场景的全流程均已验证**。

## 方法与可复现证据

1. 后台编译专用 `StaffAssemblyAuditCommandlet`，不改游戏组装逻辑。
2. 执行 `UnrealEditor-Cmd.exe`，绝对项目路径，`-run=StaffAssemblyAudit -nullrhi -unattended -nop4 -nosplash`。
3. 创建临时 `GamePreview` 世界；不加载关卡、不启动游戏、不读取或写入玩家存档。实际调用生产组装器，载入正式 UE 资产。
4. 从 UE LOD0 导出顶点、三角形、UV 和材质引用到 `ue_meshes.json`。随后 Blender 后台根据这些实际几何制作检查图；复用源材质呈现木纹和配件颜色。**图片是 UE 已导入几何的 Blender 检查渲染，不是 UE 游戏截图，也不是新生成的概念图。**
5. BVH 最近面距离量化接缝；射线奇偶判定顶点是否在杖身内，避免依赖左右手坐标转换后的法线符号。接缝距离为顶点到三角形的双向采样估计。

- `ue_assembly_report.json`：6,000 组合、6,001 次应用、24 个模型、零断言失败。
- `ue_meshes.json`：来自已保存 UE 资产的实际 LOD0 几何。
- `geometry_report.json`：截面半径、接缝距离、内部顶点计数、原装外轮廓复原、符文重复几何。
- `inspect_geometry.py`：几何量测和渲染脚本。
- `../audit-build.log`、`../audit-commandlet.log`：成功构建与原生组装检查日志。
- `blender-audit.log`：检查图渲染记录。

## 未完成的验证与修正顺序

第一人称手部动态贴合仍未验证。源码使用固定手腕偏移和同一组握指角度，没有按不同握柄直径调整。尝试增加独立姿态检查时，构建脚本发现当前项目编辑器正在运行并拒绝原生构建；没有关闭或重启该编辑器，也没有联系其他任务。新增但未编译的手部检查插桩已撤回，仅保留已构建并执行成功的组装检查 commandlet。

建议先按真实杖身截面重做符文、导魔线和握柄接口，再接通挂坠、统一头冠接口、区分符文图案。重新导入后复用本报告的同一组组合、距离测量和近景，再补第一人称持握/挥击以及改造台应用、恢复原装、存档回读检查。
