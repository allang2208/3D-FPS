# 法杖装备图标尺寸修正 V25

用户反馈 V24 装备栏图标太小，要求对照 SKILL 调整。

## 根因与规则适用

`ue5-ui-umg-slate/references/runtime-icon-pipeline.md` 要求作者占格决定画幅、主轴填充 91%、轮廓居中、离线与实时图一致。V24 机械套用了最小宽度 256 和固定高度 320，导致作者 1×4 的长杖变成 4×5 画幅。PNG 实测 256×320，主体 alpha 范围为 `(119,15)..(137,306)`，只有 18 像素宽；装备栏横放后，238 像素透明短边占用了卡片高度，等比 fit 被提前限制。

本次保留占格宽高比这一构图约束，将最低分辨率应用为等比放大：256×1024（1×4），沿用 91% 主轴填充、中心对齐和装备栏 −90° 横放。这里有意修正固定高度示例在细长物品上的适用方式；单独扩短边会破坏规则要求的占格比例。没有硬拉伸、修改共享画刷或增大背包占格。

动态图标和目录导出共用 `ColdSteelMeleeIcon.cpp` 的尺寸计算。重新生成 `Icons/ue_apprentice_staff.png`，同步 `apprentice_staff.png` 兼容别名。原图与修改前源码在 `Before/`。

本轮只改图标构图，保留 V23 水晶材质和 V24 手套／衣袖登记。编译和实际目录图落盘状态见本目录回执；游戏内效果由用户确认。
