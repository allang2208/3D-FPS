# Staff inventory orientation correction — V26

用户反馈：背包中按 F 横放后，法杖图标比竖放明显缩小。

原因：旧绘制按整张 256×1024 画布缩放，而实际有内容的范围只有 56×932。物品名称又固定扣除屏幕高度 20 像素，横放后的短轴因此成为缩放瓶颈。上一轮提高画布分辨率没有修正这条 UI 计算。

本次修改：

- 法杖目录图导入和动态图发布时，各计算一次 alpha 非零包围盒，保留 2 像素过滤边距，将 UV 与画刷尺寸同步到可见内容。PNG、模型和占格数据不变。
- 背包及仓库按未旋转的格子尺寸计算统一倍率，并为两个方向保留相同的名称余量。F 旋转只改变方向，两个轴始终等比缩放。
- 拖动预览共用同一尺寸函数及中心偏移，避免拖起、转向、放下时尺寸发生跳变。
- 保留现有装备槽布局、标题、角标、旋转锚点和其他武器的绘制规则；法杖画刷的透明留白处理也适用于装备槽。

实现：`ColdSteelStaffIcon.h/.cpp`、`ColdSteelInventoryPresentation.cpp`、`ColdSteelInventoryWidget.h/.cpp`、`ColdSteelWeaponIconReadback.cpp`。修改前文件保存在本目录 `Before/`。

定向排查记录见 `layout-diagnosis.json`。以 40 像素格子为例：旧逻辑竖放可见长度 116.50 像素，横放 72.81；新计算两个方向均为 139.40，宽度均为 8.38。此记录是原始 PNG 像素与布局公式计算，不是游戏截图或实机验收。

基础 Editor DLL 已后台编译成功，日志：`Saved/BuildEditor/build-20260928-001542.log`。未启动编辑器、PIE 或游戏；显示效果由用户下次打开项目确认。
