# 两把剑的剑身Ⅰ外形首版

2026-09-22，按用户确认的“延锋修长、重脊厚重、轻羽轻巧”方案，从两把剑当前原装剑刃制作六个独立变体。保持原装版本与其他模块。

## 造型

- 延锋：从受保护剑根以上渐进延伸，剑刃包围盒轴向长度增加 15%，尖部两侧略收束。没有整体缩放安装端。
- 重脊：寒晶外侧刃面最多拓宽 14%，符文剑最多拓宽 12%；中央脊部增厚，向尖部渐弱。
- 轻羽：两侧刃面最多收窄 14.5%，外围厚度最多减少 24%；中央符文带与承力脊保留。
- 寒晶 Z≤8.5 cm、符文剑 Z≤16.5 cm 的根部固定，包括现行护手连接边界。原始几何的晶体棱面、轮廓不规则性、UV0、附加 UV、材质索引和顶点色沿用。
- 变形法线按局部 Jacobian 逆转置变换，保留原表面自定义法线与硬边；不执行重拓扑、减面或全局平滑。

## 接入

`author_blades.py` 输出两份可编辑 Blend、六个 FBX、六张模型实拍菜单图与 `variants.json`。图标为 1024 RGBA，中性棚拍、相机水平正交、剑尖向左，同一武器三款共用取景尺度；Blender 材质来自原作者源，UE 模型沿用当前原装资产的实际材质绑定。

`install_blades.py` 经项目 MCP 互斥桥导入：

- `/Game/Weapons/FrostCrystalSword20260915/BladeVariants20260922`
- `/Game/Weapons/AzureRunesword20260913/BladeVariants20260922`

随后只合并 `frost-sword-modules.json`、`rune-sword-modules.json` 的 `blade_1` 三个已有选项：`extended_edge`、`heavy_spine`、`feather_edge`。对应名称、战斗数值和存档 ID 不变。共用装配入口负责持剑、改造台、物品预览和掉落。

原攻击端点与 `trace_from_animation` 保持；延锋范围仍由现有 1.15 倍改造倍率计算，不把新模型的剑尖再次用于放大判定。投射符文长度/宽度随变体调整；原生金色符文继续依赖保留的 UV0，护手底部符文归属不变。

## 生效与交付边界

模块目录在 C++ 中按进程缓存；若当前编辑器已读取过旧目录，需要重新打开编辑器以载入新增模型映射。UI 图像也存在画刷缓存。此次不修改 C++，无需原生编译。

菜单图属于正式 UI 资产制作；没有运行 PIE、游戏测试、验收截图或额外预览渲染。最终外观由用户测试。原模型及材质来源许可继续沿用，未新增可公开分发素材的授权。安装回执记录导入/保存完成情况，不代表实机验收。
