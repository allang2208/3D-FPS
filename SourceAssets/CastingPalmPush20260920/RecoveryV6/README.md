# 推掌 V6：小臂转向与柔和收手

历史版本：后续用户要求推掌速度加倍、停顿补足省下的时间，总时长不变。V7 保留本版姿态与 recover，当前时序及源文件见 `../PushTimingV7/README.md`。

用户要求“小臂有些扭曲，适当调整一下，recover 动画也有点僵硬，排查以后修复”。本次以 V5 完整施法动作及原推掌照片为参考，限定处理共用左手动作；尚待用户实机确认。

## 排查与修正

- V5 前臂依照掌宽轴转向，上臂却固定于肘部弯曲平面，转向集中在肘部连接处。V6 让上臂沿自身轴小幅分担掌向转动，最多 12°，按推掌进度渐入；推掌位置、掌向及肘腕位置保持 V5。主骨长度、缩放和辅助骨的完整局部变换保持不变。
- 原 recover 使用固定的低位外侧控制点 `(23,-35,-37)` cm，回握不同武器时容易绕远。现以当前真实握点加 `recovery_approach=(-4,-5,-3)` cm 确定接近方向，离开推掌点的偏移收敛为 `(-8,-2,-3)` cm。
- 原手指始终保持张开，直到最后的整臂淡出才回握。现收手前段开始翻腕、依次合指，前臂和上臂的轴向转动也逐渐回到当前武器动画；最终局部姿态混合从收手 20% 开始，避免集中到后半段。手指回握目标随当前武器姿态更新，保留真实退出姿态的衔接。
- recover 从 0.44 s 微调至 0.50 s。独立动作 0.26 s 预备 + 0.34 s 推掌 + 固定 0.30 s 停顿 + 0.50 s recover，共 1.40 s；接触仍在整段 0.46 s。停顿仍不受施法速度缩短。
