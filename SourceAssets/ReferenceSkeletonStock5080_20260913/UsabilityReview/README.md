# 骨架枪托候选可用性检查

结论：可保留为局部修整的造型母版；目前不宜作为正式游戏配件直接替换现有枪托。主体轮廓和主要镂空已经形成，优先局部修整、制作低模并烘焙，无需仅因这些缺陷整件重生成。

本轮依据用户“帮我检查是否可用”的明确请求，检查本候选的网格、UV、贴图及 Blender 实际渲染。没有修改源 GLB、源 Blend 或游戏引用，也没有启动 UE。以下结论是离线资产检查结果，不是引擎导入、装配或运行测试通过。

## 视觉结果

![实际模型原材质斜视图](angle_textured.png)

- 横向上壳、弯曲托板、两处主体镂空、斜支撑的身份保住了，具备继续制作价值。
- 托板下端与斜支撑相接处出现明显黑色缺口，参考图中这一段应连续；上壳前端侧面也出现非参考中的不规则穿孔。
- 薄支撑沟槽、圆形细节、壳体接缝及外沿局部软塌、起伏和裂缝，近距离不够规整。
- 同相机、同灯光的常量灰材质中仍能看到上述缺口和变形，说明这些问题在几何本身。加深颜色只能弱化它们，不能修复。
- 主镂空、前端开口和圆形设计孔不应一并封死；需要区分原设计开口与生成缺陷。

其余实际视图：[正侧](side_textured.png)、[另一侧](opposite_textured.png)、[前端](front_socket_textured.png)、[同视角灰模](angle_clay.png)。这些图来自实际候选网格，不是三视图概念图。

## 数据结果与含义

| 项目 | 结果 | 意义 |
| --- | --- | --- |
| 纹理母版 | 476,673 三角面 / 390,525 导出顶点 | 相当于现有枪托低模报告 50,000 三角面的约 9.53 倍；尚未制作游戏低模，不能据此推断实际 FPS |
| 原始几何 | 9,470,880 三角面 | 留作生成来源；本次未将 raw 与纹理母版对齐做逐点比较，不判断缺陷具体出自哪一步 |
| 相同坐标精确合并后 | 6,798 条多于两面共用的边；17 条边界边 | 排除大部分 UV 接缝假阳性后仍存在拓扑异常；边界边数不等于视觉破洞数量 |
| 重复面 | 1,918 个，忽略绕序按相同顶点集计 | 修整和烘焙前应清理 |
| 顶点连通部分 | 42 个；最大部分 475,376 面 | 小部分可能包含细节或碎片，不能直接全部删除 |
| 近零面积 | 5 个几何三角形；129 个 UV 三角形 | 需针对性处理，避免减面、切线与烘焙问题 |
| UV | 坐标有限，无超出 0–1 的顶点 | 有有效 UV 基础；未做全量 UV 重叠检测 |
| 贴图 | 4K Base Color + 4K Metallic/Roughness，两张均可读取 | 金属度和粗糙度通道存在；当前没有 Normal 贴图，游戏低模结构法线尚未烘焙 |
| 物体尺度 | 生成空间范围约 1.002 × 0.672 × 0.265 | 未建立目标枪型的实际尺寸、枢轴和连接面适配 |

拓扑补充：初步面邻接算法得到的 2,775 个区域会在非流形边处断开，不能称为 2,775 个悬浮碎片。最终采用精确坐标合并和顶点连通的 42 个部分作为连通性说明。所有合并只发生在检查脚本的内存副本中。

## 材质排查

Blend 中 Base Color、Roughness 和 Metallic 均已正确连到对应节点，两张 4096 × 4096 图像保留在打包数据中。将同一图像的外部 PNG 在内存中重新连接后，渲染外观一致，未发现贴图丢失问题。

首轮灯光较强使模型显得发白；最终预览使用较低灯光功率并将曝光设为 0，保留原材质。`diagnostic_original_material.png`、`diagnostic_external_same_textures.png`、`diagnostic_constant_clay.png` 采用同一网格、相机和灯光，分别记录原材质、同贴图外部加载及常量材质对照。

## 建议制作顺序

1. 保留主体，局部重建托板下端连接、前端异常孔及变形接缝；清理重复面和异常拓扑，保护设计镂空与有效 UV。
2. 制作游戏低模。可以现有约 5 万三角面的枪托作为初始预算参照，依据剪影和细杆细节调整；从修整母版烘焙结构法线。
3. 依据目标枪体实际连接面适配尺寸、枢轴与挂点，再完成 UE 材质和配件引用。当前游戏使用的是现有枪托资源，本候选尚未替换进去。

原始数值见 `mesh_report.json`、`topology_clarification.json`、`material_report.json`；渲染设置与输出见 `render_review.py`、`render_receipt.json`。本轮只交付检查结论和预览，未自动修整或接入游戏。
