## 旧版问题来源

只针对用户指出的缺陷读取 V08 制作数据和 UE 当前网格：

- 当前实际入口是 `SK_FacelessSecurity_V08`。UE 导出与作者源的顶点位置、骨架参考姿态一致，位置误差低于 0.001 mm；没有定位到肩袖在导入时整体丢失。读取回执：`Inputs/active_mesh.json`、`export_geometry_source.json`。
- V08 袖山先在 Meshy 姿态缝合，再按逐点混合的体型适配矩阵反算。反算后的腋下纵向截面发生折返，共享接缝顶点没有消除这种形状问题。旧上衣有 232 个面角的自定义法线与实际面朝向相反。读取记录：`bind_defect_source.json`、`cap_normals_source.json`。
- 旧领片、领座、肩章被逐点贴向双层衣物表面，内外层和原厚度受到压缩；领座存在 801 个反向面角法线。不能继续将已经压坏的结构作为投射输入。
- 旧作者源及 UE 网格均保留手部顶点。本轮仍延长袖内身体覆盖，避免只留手掌与袖端局部搭接。

这些是针对旧缺陷的制作定位资料，不是 V09 游戏或视觉验收结果。

## 本轮制作

- 保留原 161 骨的名称、层级、参考变换和 0.01 单位转换。新上衣直接在原生参考姿态中制作，不再将新袖山通过逐点混合矩阵反算回去。
- 衣身与两条袖子生成连续外表面，领口、衣摆、左右袖口按实际位置开口。最终游戏外表面约 36000 三角面，再制作 2.6 mm 内壁；保留生成用的高密度源 datablock。
- 先在完整身体上处理同侧肩臂过渡权重，再传递给衣物。外表面沿实际网格连接平滑过渡，内外层继承同一组权重；在最终参考几何上重算法线。
- 重新制作领座、翻领、肩章、胸袋、门襟、领带和标识。厚度在外表面成形之后生成，不把已有内外层一起压向最近表面。肩章只落在实际肩面上。
- 从完整身体重新生成显示副本，保留前臂、腕、掌和全部手指；完整身体几何仍为 111909 顶点／199401 三角面。身体与衣物仍可分别导出。
- 保留 V07 已清理的裤装、腰带及靴子。继续使用 V06 待机、Walk_B 移动、攻击／恢复动作及当前接地与战斗参数。
