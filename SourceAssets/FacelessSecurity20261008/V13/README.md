# 安保员 M-03 V13：长袖露肤修订

2026-10-09 整理补注：本文记录对应版本历史；当前组合、保留依赖及已移入 trash 的旧导出/备份路径见 [无面职员发布与恢复](../../../Docs/Publication/FacelessStaff20261009/README.md)。不要批量运行旧导入脚本覆盖当前入口。

## 问题与修改

用户明确指出袖子下方穿出白色皮肤，并要求排查修复。基线为 V11 模型、V06 待机/移动、V10 攻击、V12 受击/倒地/起身/眩晕。

- 穿衣显示模型仍保留了长袖内的肘部/前臂皮肤，弯臂时与衣物的权重场错开而露出。按实际前臂轴重做覆盖裁片，保留袖口内约 46 mm 的手腕搭接；完整身体母版不裁切。
- 原袖口跨前臂与手骨混合，攻击和撑地时会向袖内折回。袖口及其内部手腕改为跟随同侧前臂；手掌过渡移至袖口外，远端手掌和手指保留原权重。
- 主衣物内外壁的配对顶点采用相同权重。衣物轮廓、领口、肩部拓扑、腰部、鞋子、材质和帽子不变；不更换任何动作或战斗参数。

## 制作与排查

- 制作源：`Authoring/FacelessSecurity_V13.blend`，独立衣物和穿衣模型 FBX/GLB 位于 `Delivery/`。
- `Diagnosis/sleeve_overlap.json`：8 类当前动作，每类 9 个姿态，共 72 个姿态；按同侧衣袖/袖口表面排查覆盖区皮肤。旧版存在穿出，新版采样中的穿出顶点为零（阈值 0.8 mm）。这是离线采样结果，不代表完整游戏或全部过渡验收。
- 查询时根据实际臂轴统一三角形法线方向，避免将旧内壁法线误判为穿出；袖口仅用于其真实覆盖的轴向区间。
- `Diagnosis/preservation.json` 记录完整身体、骨架参考、衣物几何、远端手掌/手指及其他衣物部件的保留结果。
