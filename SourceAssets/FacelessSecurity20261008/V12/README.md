## 制作内容

- 从本地现有 Nurse 共用库取得受击、倒地、仰卧起身、俯卧起身和眩晕五段源动作。俯卧起身沿用项目已有翻身加仰卧起身组合，不标作新的独立动捕。
- 受击以实际 V06 抬臂准备姿势为基础，保留源动作的冲击与回弹变化，躯干反应略加强；腿脚保留该准备姿势，结束回到同一姿势，消除原护士站姿到男僵尸准备姿态的断点。
- 眩晕围绕当前准备姿势使用源上身摇晃，保留脚部支撑，并在循环尾段平缓回到起点。
- 倒地保留源整身动作；两种起身保留原地面翻转与手部支撑阶段，最后站立部分连续收回当前准备姿态，并以原靴底支撑高度处理站立衔接。
- 五段动画烘焙到原安保骨架，显式绑定 `Combat.HitClip/DizzyClip` 与 `Knockdown.FallClip/GetUpClip/ProneGetUpClip`。共用骨架检查继续保留。
- 播放代码复用现有原生姿态播放器，加入攻击／待机／移动／受击过渡。重复受击捕获当前姿态，不回放旧快照；攻击权威时钟和命中判定不变。
