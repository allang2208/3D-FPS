# 近战改造：五栏原装配置

用户于 2026-09-15 确认本轮先接入栏目和原装部件。支持 `ue_rune_sword`、`ue_frost_crystal_sword`。

## 玩家入口

重新启动工程后，装备剑按 **J**；也可以在背包选中剑按 J，或从物品菜单选择“改造武器”。仓库物品通过“取出并改造”进入，背包空间不足时沿用原有转移提示。

五个栏目依次是 **剑身Ⅰ、剑身Ⅱ、护手、配重锤、握把**。每栏有一个原装选项，显示“当前原厂配置”和对应部件说明。剑身Ⅰ对应刃口/刃形，剑身Ⅱ对应剑脊/剑面；这次不拆分既有模型。

面板中央显示当前剑的实际世界模型，支持旋转、缩放与水平复位，背包内未装备的剑也可预览。右侧展示现有近战伤害、间隔、距离、体力消耗和格挡参数。当前原装项没有额外数值修正，无待应用修改时确认按钮禁用。

## 实现入口

- `Content/ColdSteelData/melee-gunsmith.json`：五栏顺序、名称、原装说明及支持的武器。
- `Source/FPSGAME/Weapons/MeleeGunsmith.cpp`：读取近战目录，复用改造实例、草稿、撤销及提交接口。
- `UGunsmithSystem::ModifiableWeapon` 返回所有可改造武器；既有 `Weapon` 维持枪械语义，枪械公共选项不扩展到近战。
- `M4MeleeGunsmith.cpp`：近战工作台识别、预览可见条件、当前角色实际数值汇总。
- `SMeleePartIcon.h`：银灰线形栏目示意图，复用同一套主题；中央完整模型才是武器实际外观。
- 原有 `M4MeleePreview.cpp` 与捕获生命周期继续承载模型预览。本次仅修改代码，没有为交付启动模型捕获或离线渲染。
- `build_native.ps1`：必要的 FPSGAMEEditor 构建入口。

## 保存与范围

原装使用已有“改造映射中没有该键”的默认语义。旧存档自然显示五个原装项，打开或查看面板不会制造修改或额外写档；没有新增存档字段或修改玩家存档。尚未加入可选配件、属性增减、拆卸模型或额外消耗。

实际规划与交付状态见 [近战改造规划](../../Docs/UI/melee-gunsmith-plan-20260915.md)。按用户规则不运行测试、PIE、截图或验收；完成必要构建后交由用户测试。
