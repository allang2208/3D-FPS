`install_balance.py` 只更新执行时目录中的 `riser/strong_draw`，保留其他改造与武器，并保存本轮目录副本和带时间戳的接入回执。稳定改造 ID 保持 `strong_draw`，旧装备按当前目录生效，不直接修改存档。
