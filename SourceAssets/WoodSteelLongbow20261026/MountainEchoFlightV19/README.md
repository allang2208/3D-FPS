# 弦影箭金色飞行轨迹 V19

用户要求射出的弦影箭也有明显的金光轨迹。替换现用 `MountainEchoFXV14/NS_MountainEcho_GoldenFlight` 的表现层，使用原生飞行、异步加载及命中入口。

- 箭体加强金色发光；箭头亮点、箭身柔光跟随箭体。
- 金色内芯与柔光外层使用世界空间粒子。引擎按组件位移计算 Owner.Velocity，出生点分布在该帧真实移动段，后续不会跟着箭体转向或位移。
- 内芯按 22 cm 间距生成，单条长度 86 cm，寿命 0.21 秒；外层寿命 0.26 秒。长条中心位于出生点之后，避免超过箭头。
- 内芯宽 6.5 cm，距离超过 16 m 时有宽度补偿，上限 3 倍；外光宽 18 cm、低透明度。保留场景深度遮挡和曝光补偿。
- 世界层最多每秒 420 条内芯、220 条外光及 60 颗火星，最长寿命 0.26 秒；箭身两层各每秒 60 颗、寿命 0.065 秒。沿用每箭一个 Niagara 组件，不增灯光、额外碰撞或 Actor Tick。
- 使用 CPU 自动粒子边界，避免高速箭矢的世界尾迹被旧的 2.8 m 固定包围盒裁掉。
- 命中时停止箭身光与新粒子，已有轨迹保留最后一次世界位置并完成短暂淡出，然后自动销毁组件。

本轮只修改飞行表现和停止方式，不改 V18 金色爆裂、伤害、弹速、弓弦印记或训练靶判定。V14 统一作者入口已同步调用本版，旧飞行参数不会在重建时覆盖本版。

制作入口 `author_flight.py`；保存回执 `asset-receipt.json`；必要原生构建记录 `build-FPSGAMEEditor.json` 和 `build-FPSGAME.json`。
