# 山鸣弓弦金色命中爆裂：V18 可见性修正

用户反馈 V17 几乎看不到炸开的粒子。仅排查该命中特效的资产、发射栈、材质和运行引用；不运行游戏或启动预览。

## 已定位的设置问题

现用系统为 `MountainEchoFXV14/NS_MountainEcho_GoldenImpact`。读取到 V17 六层发射器及其实际材质，发射数量、尺寸／颜色绑定均存在，ParticleState 后接表现参数更新。

效果类型的距离裁剪档位从 150 m 起，不会解释近中距离的细弱火花；本次保留其原有裁剪预算。

V17 主火花贴片宽度仅 0.5～1.15 cm，针形材质又把半峰亮芯收窄到贴片宽度约 12.9%，实际仅约 0.065～0.148 cm。按 1920 像素横向分辨率、90° 水平视角、20 m 距离估算，仅约 0.031～0.071 像素；这是投影估算，不是游戏采样。主火花寿命 0.16～0.4 秒且出生即淡出，颜色同时变暗；多层收缩叠加削弱了可见轨迹。

## 本版调整

- 主火花贴片宽度 3.4～5.8 cm，材质亮芯加宽，距离超过 16 m 时宽度逐渐补偿，上限 3 倍。长度与爆裂半径不随距离放大。
- 主火花 36 颗，寿命 0.42～0.7 秒；前半段保留亮度，后半段再衰减、冷却。
- 起始喷射 12 条，寿命 0.16～0.26 秒；碎屑 16 颗，寿命 0.52～0.84 秒，保留重力和阻力。
- 发射方向提高沿命中面的横向展开比例，让迎面观察时也能读到炸开的范围。接触短闪 2 层，淡尘 3 片，单次共 69 颗粒子。
- 保留无整齐光圈的表现，保持场景深度遮挡与曝光补偿。使用原接入位置、对象池及命中面重力转换，不修改伤害、飞行箭、弓弦层数或训练靶判定。

制作入口 `mountain_echo_impact_v18.py`；统一 V14 入口已调用本版。新材质保存到 `MountainEchoImpactV18`，命中系统仍沿用现用路径，无需修改 C++ 或重建 Editor DLL。
