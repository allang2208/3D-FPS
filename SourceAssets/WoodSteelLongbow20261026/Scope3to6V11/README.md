# 观峰变倍镜：高地长弓专属特殊改造

当前光学分划已于 2026-10-28 升级为 V3，计划与实现说明见 `Docs/Weapons/peakwatch-reticle-v3-20261028.md`；保留此目录的原始模型、材质与制作记录。

用户于 2026-10-27 要求在已选设计基础上精细化建模并接入游戏。

## 造型与资产

- 圆形短镜身、银钢薄压圈、旧黄铜倍率环与调节轮、胡桃木饰片。
- 新增压圈台阶、凹槽、滚花、螺钉槽、倍率数字及固定指示标。
- 镜架按原弓上部金属安装面的实际接触形状制作；内面贴合，外面为平整安装面。
- 固定镜架和倍率环分别导出。倍率环使用镜片中心作为旋转轴；从 3 倍至 6 倍，UE Roll 为 0° 至 −111°。
- 运行镜片沿用已修复弓镜的真实 UV 和实体玻璃准星材质作者模块，包含细十字、中心点和下方参考刻线。
- 材质分为钢、深钢、旧黄铜、刻字、胡桃木及透明镜片；木纹烘焙为 1024 纹理，金属复用已有细纹法线和 ORM。
- 固定件 52,256 三角面，倍率环 18,848 三角面。微型滚花使用简洁截面，主要圆环保留细分和倒角。

可编辑源：`Highland_Peakwatch3to6_Production.blend`。导出文件位于 `Export/`。

## 接入与操作

- 武器：`bow_woodsteel`（高地长弓）。槽位：`sight`。改造 ID：`highland_peakwatch_3_6x`。
- 分级：特殊改造，仅高地长弓可用。
- 默认 3 倍；按住瞄准时滚轮每格调节 0.5 倍，上限 6 倍。到达上限或下限时继续消耗该滚轮操作，避免同时切换装备。
- 2026-10-28 光学 V2：显示倍率、瞄准灵敏度和实体倍率环共用平滑过渡。同次装备中退出再进入瞄准保留所选倍率；重新装备恢复 3 倍。
- 开镜时间 ×1.25；伤害、暴击伤害、最大飞行距离不另加数值。
- 倍率环通过可选的 `sight_zoom` 部件接入第一人称、装配预览和第三人称部件集合。第三人称及掉落展示使用默认刻度；倍率属于本地瞄准偏好，不增加网络消息。
- 2026-10-28 光学 V2 已改为本人开镜期间的独立 SceneCapture，镜外保持普通弓 ADS 视野，镜框与手臂保持最低倍率的构图；性能模式保留单相机成像。无每帧资源加载。当前实现与本轮交付范围见 `Docs/Weapons/peakwatch-optics-v2-20261028.md`，下列模型制作和首次构建结果仍为历史记录。
