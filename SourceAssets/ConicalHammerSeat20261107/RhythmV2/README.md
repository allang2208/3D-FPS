各段使用端点速度一致的三次 Hermite 曲线，起止源速度为零。接触仍采样原 V7 的 0.150 秒姿态，当前前方范围、伤害公式、击退和被动数值不变。空间扰动沿原源时间 0.090–0.175 秒，出手音效跟随 0.205 秒释放边界。

有效命中增加 0.038 秒局部动作停顿；基础总长挥空 0.740 秒、命中 0.778 秒。停顿冻结动作姿态，不冻结世界或摄像机输入；命中抖动使用独立冲量年龄继续衰减。低帧跨接触先结算一次，再用剩余时间消耗停顿和收势。动作占用条同步计入停顿；迅捷仍使用本次动作开始时记录的速率。

## 镜头

蓄力轻微后拉、抬头和侧倾；前顶同步前压并短暂放宽视野；回收时小幅反向卸力，末尾平滑归零。使用五次平滑包络，镜头输出仍受 `CameraMotionScale` 和 `fps.Camera.Shake` 控制。

有效接触额外叠加短促衰减冲量及小幅振动；挥空只有前顶惯性镜头。锥形锤座专用镜头位移与旋转、FOV 同帧采样，避免仅位移被额外平滑而滞后。镜头不修改控制朝向或伤害射线朝向。

联机本机碰到有效目标即可表现阻力，伤害与击退继续沿既有权威流程；远端身体使用动作保存的速率与停顿状态，并可靠发送停顿/恢复边界。没有增加每帧可靠 RPC。
