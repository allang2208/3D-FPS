## 动作

`A_RuneSword_Equip` 改为 1.20 秒、非循环，480 Hz，0–576 帧。旧 V5 装备动作是双手已经握剑、从待机下方抬起，长 0.55 秒；新动作重新制作取剑及双手接续过程。

| 时段 | 制作意图 |
| --- | --- |
| 0–0.29 s | 右手越过右肩伸向背后剑柄，左手在下方放松 |
| 0.21–0.31 s | 右手收拢手指，握住剑柄 |
| 0.32–0.54 s | 向上抽出剑 |
| 0.54–1.08 s | 从肩部右侧带剑到身前 |
| 0.68–1.06 s | 左手靠近下握点并合握 |
| 至 1.20 s | 收稳至现有待机端点 |

右手握住后以固定剑柄坐标驱动；左手在剑来到前方时加入。手臂采用分段长度约束和前臂旋转传递，并携带锁骨及上下臂辅助骨，延续 V21/V22 的关节处理思路。结束姿态直接使用 V22 蓄力首帧的待机端点。以上为作者设计与实现记录，尚未进行本版视觉或运行验收。

本版范围是第一人称右肩后取剑动画，没有新增第三人称背部剑鞘或剑鞘碰撞，也未制作完整转花剑动作。

## 可编辑源与接入

- `read_authoring_inputs.py`：读取 V5 原装备轨迹和 V22 待机端点，生成 `authoring_inputs.json`。
- `author_equip.py`：在 V22 完整骨架源上新增装备动作，生成 `AzureRunesword_Manny_Editable.blend`、`Export/A_RuneSword_Equip.fbx` 和 `authoring.json`。
- `run_live_import.ps1`：通过当前编辑器导入；临时打开 Python 连接，并在结束时恢复先前设置。
- `import_equip.py`：只替换 `/Game/Weapons/AzureRunesword20260913/A_RuneSword_Equip`，原资源保存在 `Before/`。
- `import_receipt.json`、`live_import_result.json`：此次导入与保存成功回执；UE 记录时长约 1.20 秒。

当前 `RuneSwordComponent` 按动画实际时长结束装备阶段，无需修改 C++ 或重建原生模块。其他攻击、格挡、模型和蒙皮资产没有在此次导入中替换。此入口当前接入物品为 `ue_rune_sword`，不代表所有剑类物品均已独立适配。
