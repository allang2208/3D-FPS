# 双手符文剑 CompactNaturalV4

用户本轮要求：剑模型缩小 20%，待机适当露出剑面且不退回首版角度，并检查挥砍时的手臂扭曲。

## 制作

- 仅剑体顶点在护手原点周围统一乘以 0.8。手臂尺寸、Manny 骨架参考姿态、网格和蒙皮权重沿用现有资产。
- 待机绕剑长轴的角度由 V3 的 85° 调为 65°，比首版 -5° 仍偏转 70°；护手位置继续为 `(13,48,-8) cm`。原五路材质、UV 和贴图继续使用。
- 缩放后上下握位分别位于护手下 7.2 cm / 17.2 cm，掌部径向贴合收近 2.5 mm。剑根、剑尖的动画位置及两张剑气轨迹网格同步新尺寸。
- 双斩保留 0.230–0.345 s 快速阶段、2× 快速阶段时间映射、160° 剑尖方向跨度和 0.8333 s 总时长。起势先转到侧方，再压剑横扫；收势先侧向抬剑，再回中间。双手在横扫中适当内收，给肘部留下弯曲空间。
- 握柄角度按整条动作求连续路径，同时考虑肩肘运动代价。角度路径允许完整周转，以等价姿态闭合；肩肘支撑使用连续极角平滑，再按原骨长恢复两段式手臂。手掌和手指始终以剑柄变换为目标。
- 前臂辅助骨随完整骨段变换，去掉 V3 跨越 ±180° 后分数扭角造成的蒙皮折叠与收尾残余旋转。重新制作六条动作并以 240 Hz 导出。
