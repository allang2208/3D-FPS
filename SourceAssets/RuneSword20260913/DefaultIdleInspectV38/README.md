# V38 · 默认待机位置转剑试版

2026-09-15。用户反馈 V37 的手臂和手腕仍扭曲，要求改到默认待机位置旋转。本版以项目现有身前握持姿态为基础，供用户观察效果。

**后续用户反馈：V38“更僵硬了”，明确要求退回 V36。现已恢复 [V36](../ReferenceReplicaV36/README.md)，本版停用；以下保留制作时的记录。**

## 本版动作

- 右肩、上臂、肘、前臂、手腕及臂段辅助骨，全程直接采用原待机姿态；没有右臂 IK、肩侧搬运或手腕跟剑翻转。
- 剑在默认右手握点转动。沿用 V36 核心的剑身朝向顺序与逐指变化，将起止朝向接回同一个默认持剑姿态。
- 转柄的支撑点随原松握阶段变化；剑的位置从当前手内支撑点和剑柄点推导，不让剑体单独绕网格原点漂移。支撑点是作者构造，实际手指、皮肤与剑的接触效果待用户观察。
- 左臂只从肩部整体向外、向下让开。上臂以下共用同一个变换，肘和手腕保持待机时的相对姿态；返回沿原路，随后手指依次收拢。
- 去掉 V37 的肩后蓄势和收势。全段 1.80 秒，中间 0.50–0.80 秒转剑，随后在原位接稳、左手回握。

这是按用户要求简化腕臂运动的待机位置试版。V36 的手指轨道继续使用，但不再保留原参考的翻腕轨道。
