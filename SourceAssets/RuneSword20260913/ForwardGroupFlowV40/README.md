# V40 · 整体前移与手臂衔接

2026-09-15。用户反馈 V39 主体太靠后、几乎出屏，要求前移并自然衔接手臂。

**历史状态：已被 [V41](../AnchoredArmFlowV41/README.md) 替换。用户反馈前移后能看到手臂空心内部；V41 专项检查确认右上臂开放裁切口进入镜头，并修正其连接方向。本版源文件保留。**

## 调整

- 保留 V39 的 65° 整体转向、V36 内部骨骼动作和 2.90 秒时序。
- 转剑段将手臂、手指与剑共同沿作者坐标全局 +Y 前移 **0.24 m**。位移在共同转向之后施加，方向是镜头朝向的前方。
- 从默认待机平滑加入前移量，收势时平滑退回；将位移同时纳入原有的位置和转动速度衔接曲线。
- 所有骨骼每帧继续使用同一个共同变换，腕臂和手与剑的相对关系沿用 V36。首尾仍为原双手待机。

本版是根据用户画面反馈选择的前移幅度，实际构图与连续感由用户观察。
