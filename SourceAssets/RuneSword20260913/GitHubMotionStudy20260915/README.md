## 两个值得学习的片段

### Bayonet / draw：F8–24（0.267–0.800 s）

见 `sheets/bayonet_draw_front_detail.png` 与 `bayonet_draw_side_detail.png`。

- F8–10：手的姿态改变，手指已在逐渐松开；刀和手之间开始改变相对方向。
- F12–13：四指与拇指之间留出空间，刃尖下行。
- F14–18：刀经过转向，手仍在调整角度，指节状态随之改变；侧面可以看到刀与掌的相对位置变化，不能解读成固定在掌心的一次整圈旋转。
- F20–24：手指逐步回握，手和刀一起衔接持握方向。
- 在这一窗口相对 F8 的取样中，前臂世界方向差最大约 12.2°，手相对前臂的方向差约 93.4°。这些只是同一骨架方向差，不能当作人体生理角度，也不能推断必须锁死前臂。

适合学习：松握先行、腕部持续配合、四指与拇指不同步处理、回握接上余势。它包含更明显的脱离/换握表现，不能直接替代要求持续虎口控制的长剑动作。

### Stiletto / lookat01：F58–74（1.933–2.467 s）

见 `sheets/stiletto_lookat01_front_detail.png` 与 `stiletto_lookat01_side_detail.png`。

- F58–60：手指打开，刀柄相对手掌开始翻转。
- F62–66：在侧面示意中，刀靠近抬起的拇指指端区域转过，其他四指让出空间；这是对骨架示意的观察，不是对皮肤接触点的测量。
- F68–72：中指等指节先发生弯曲，开始控制刀柄，其他手指仍有伸展；它们不是同一个开合系数。
- F74 起再次进入打开/翻转，后面还有重复循环，不应把全部重复动作搬到一次剑花里。
- F58–74 所选帧中，前臂相对 F58 的方向差在约 3.7°以内，腕部相对方向差可达约 25.7°；武器还有相对手部的独立旋转。它支持“前臂稳定、手腕与手指配合”的制作思路，但动作支撑位置并非已经确认的虎口夹持。

适合学习：小幅腕部动作如何配合大幅武器翻转、不同手指如何轮流让位和接回。不要照搬其指端支撑位置、短刀尺寸或循环次数。

## 对本项目的制作结论

这次实际观察得到的主要差别，是握持关系在动作中变化：四指先让位，拇指承担不同职责，刀柄在可控区域内经过，手指分时接回；骨架里手与刀也没有被当成同一个刚体。原视频的长剑仍应以用户确认的虎口外侧路径为准。

重新查看了已保存的原视频 76.000–76.367 s 连续帧与教学 147.6–148.1 s 帧：它们仍是长剑接触区域的首要参考。Source 刀具资料提供的是协作方法，不能取代长剑的接触位置。

下一次制作应围绕三阶段建立可变握持约束：闭握下带 → 四指张开、拇指/虎口控制柄、腕部配合 → 手指分时回握后收势。明确哪些时段接触点固定，哪些时段允许柄在手中滚动；不能整程用一个固定掌心旋转点，也不能整程把手锁死在刀上。前臂只负责小幅支撑，不随武器转满一圈。

时序方面，以上两段核心窗口各约 0.533 s，动作顺序持续推进。应借鉴相邻阶段重叠和速度连续的方式；不能把整个 3.9–6.2 s 检视总时长当作一次转剑时长。具体游戏速度仍按长剑重量、用户希望更流畅的要求重新设计。

研究阶段只完成资料转换、关节读取和参考观察；后续尝试 V35 并未解决用户的问题。V34/V35 都不是已认可动作，制作现已暂停。参考帧移至 `../VideoReferenceStudy20260915/`，教学原研究仍在 `../PivotStudy20260915/`。
