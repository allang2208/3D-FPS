## 从画面可以观察到的关系

1. **握持区域在护手下方、靠近虎口和拇食指根部。** 24–41 秒近景中，另一只手指向这里并辅助转动；145–150.8 秒单手连续动作中，同一段握柄始终处在这片手部区域。被遮挡的准确接触面和受力不能仅凭这一机位确定，不能声称已经测出精确三维支点。
2. **掌握状态发生变化。** 从完整抓握转为松指、展开让位，手掌随手腕翻转，最后重新包住柄。张指是一段过渡，不是让五指和手掌全程离开武器。拇指在近景中仍贴近近护手的握柄段；它承担的具体压力和逐帧接触转移需要三维重建。
3. **剑与手共同运动。** 剑尖走大弧线，近护手的握柄部分由手部控制；手腕和前臂随动，手掌朝向改变。不能把世界空间的剑轨迹固定后，再将整只手挪走来避开剑。
4. **回握提前衔接。** 剑柄返回时，手掌已经顺着它跟随，手指逐渐合拢；回握和转动在时间上重叠。并非先让剑独自转完，再把手搬回原位抓住。
5. **分清教学停顿和连续动作。** 79.8–80.5 秒附近的张掌停住是分解演示；147–148.4 秒附近的连续示范通过这一阶段时没有同样的长停顿。可据连续片段制作连贯角速度曲线，不能在每个四分之一圈节点反复减速到零。

## 对 V30 的修正结论

V30 为避穿模，把开放手势整体推离剑的既定轨迹。这即使消除了几何交叉，也破坏了持械的支撑与控制关系。零相交不等于成立的转剑动作；五指展开幅度也不能代替接触关系。

下轮应按以下依赖顺序重建，而不是继续扩大避让位移：

1. 在项目剑的近护手握柄段确定可用接触位置，再与右手虎口/拇食指根部区域配对。需要按项目剑较宽的护手、握柄和配重头形状适配，不能直接套用教程刀的尺寸。
2. 以随右手运动的接触坐标系组织旋转。剑相对手的转动、手腕翻转和前臂旋转分别承担各自部分；不可让腕骨单独做整圈扭转。
3. 先安排闭握、松握保持支撑、翻掌通过、随动回握四个阶段，再逐根调整手指的展开、弯曲和拇指位置。
4. 接触区域切换时保持剑的连续位置和方向；回握开始于转动结束之前，用合握与腕部收势完成制动。
5. 保留用户认可的右手侧旋转方向、F 键检视职责，以及原本从背后拔出的装备动作。此前具体的世界空间剑柄轨迹不应继续被当作不可更改的前提。

这份记录建立的是参考动作与重建方案，不代表游戏中的现有检视动作已修好。
