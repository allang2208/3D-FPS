# 左拳抵剑格挡：左肘修正 V21

2026-09-14 用户反馈 V20 左臂关节仍然扭曲，明确要求重新检查并调整。本轮完成左臂专项检查、动作修改和三个同名 UE 动画的重新导入。

## 原因与修改

源网格近景复现了肘部折叠。V20 的上臂按肘部弯曲平面建立旋转，前臂则按拳头方向建立旋转，两套基准在持守处产生约 111.83° 的轴向差；骨段长度及腕部方向单独正确，并不能排除这个关节扭转。

V21 从前臂的整体变形沿最短摆动建立上臂方向，使上下臂旋转连续配合，同时携带上臂两条蒙皮辅助骨。锁骨对袖口的支撑一同转动，避免把肘部的集中扭转转移成肩口塌陷。上臂起点、肘、腕位置、左拳、抵剑接触、右手和剑的轨迹保持 V20；未改网格、权重、手指姿态、材质或玩法。抬手和回握用渐进权重衔接原待机。

持守处同一定义的轴向差由约 111.83° 降为 41.64°。这个骨架指标只辅助定位，形变结论同时来自本轮源模型及 UE 压缩姿态的实际网格近景，不是人体医学角度或通用阈值。

## 本轮检查范围与结果

- 源模型：V20/V21 同机位持守、左关节近景和抬手中段渲染，见 `Review_FistBraceGuardV20/`、`Review_FistBraceGuardV21/`。修正后的肘部折叠和肩口塌陷已改善；近景能看到本身没有躯干的手臂网格肩口，未隐藏或裁切网格。
- 骨架：三个动作按 960 Hz（含半帧）共取 791 个样本，对比除左锁骨、上臂及其两条辅助骨外的保留骨骼。位置差最大约 0.1414 mm、旋转差最大约 0.0069°；两段左臂长度差最大约 0.0023 mm。这些是重建局部轨道及帧间插值差异，不宣称逐位完全相同。见 `source_preservation.json`。
- UE 读回：使用实际运行目录中的三个动画，在独立 UE 进程按 120 Hz 取 101 个时刻，比较相关骨骼 RAW/COMPRESSED。位置差最大约 0.00245 mm、旋转差最大约 0.0381°；三个时长仍为 0.20、106/480、0.40 秒。见 `ue_animation_readback.json`。
- UE 网格：实际导入网格与压缩动画检查了抬手、持守、左关节近景、受击、破防及回握六个姿态，见 `UEReview/` 和 `ue_review_receipt.json`。离屏图中的局部材质黑斑不作为关节几何判断依据；同机位灰模用于分离材质与真实表面形变。

本轮是用户明确要求的左臂专项检查，没有进行完整玩法、伤害、体力、音效或输入回归。2026-09-14 用户反馈“成功”，接受本次关节修法，并要求继续修正蓄力攻击左臂；后续入口为 `../ChargedArmV22/`。
