2026-09-14 用户要求推倒旧的扭曲防御姿态重做：右手持剑，左臂弯曲、握拳抵住剑身。左拳依据本次用户照片制作。照片显示四指收向掌心、拇指压在外侧、掌侧朝向观察者；未展示的完整肩肘和剑身接触是本轮三维设计。

## 重新制作的姿态

- 右手保留原有握柄关系，剑柄在右下，剑身向左上斜横。左手离开柄尾，掌侧面向玩家、手背抵住剑身近侧平面，左肘保持弯曲并落在左下方。
- 四指以原关节位置和骨长重新闭合，拇指合在拳外。绕屈指轴连续转动整套方向基，避免累计屈曲超过 90 度时用固定掌面法线重算造成翻转。
- 新持守姿态按 rest 骨段重建两条手臂，结合左右肩位、肘位和手掌方向求解。上臂、前臂辅助骨使用各自完整骨段的 rest-local 变换；没有沿用 V19 持守的骨骼变形，也没有绕剑柄搜索多圈。
- 左手接触点根据现有手套手背和剑身的几何位置建立。受击动作保持该相对关系，由肩肘重新提供支撑；破防先卸开拳背接触，再退手、回到原双手待机。
