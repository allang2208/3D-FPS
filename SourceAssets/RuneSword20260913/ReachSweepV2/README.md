# 符文剑 ReachSweepV2

用户要求：排查贴图/材质显示，待机双手前伸，攻击扩大横扫范围和力度。

## 当前制作入口

- `build_sword.py`：从首版原始剑、CC0 动作参考和项目既有 Manny 包握手型制作六条动作。
- `AzureRunesword_Manny_Editable.blend`：包含两只手臂、剑、打包源贴图和六条已烘焙动作的当前可编辑源。
- `Export/`：当前动作 FBX 及随源保存的静态/骨骼网格 FBX。本轮只导入动画，剑体几何和骨架仍使用既有资源。
- `import_revision.py`：启用材质骨骼网格用途，并将六条动作导入 `/Game/Weapons/AzureRunesword20260913` 原有名称。
- `Before/`：导入前材质、动画和剑骨架的 uasset 备份，首版 blend/FBX 仍保留在父目录。
- `authoring.json`：姿态位置、挥砍关键点、动作时长及握位制作参数。
- `material_before.json`：用户要求的材质排查结果。
- `import_receipt.json`：实际导入入口完成后写出的六条动画路径和材质设置回执。

## 动作制作

待机双手随剑柄向前 12 cm、向上 5 cm、向中心 2 cm；右手握护手下方 9 cm，左手握 21.5 cm，双手同随剑柄运动。使用固定骨长的双臂解算和既有手指包握，步行、装备和作者冲刺动作一并衔接新待机。

保留 CC0 参考的右侧起势→跨身向左收剑，以及左侧起势→向右回斩的动作差异，以双手剑重新制作水平大扫。两斩方向相反，分别略向下/略向上，在 0.23–0.46 s 的有效接触窗内横跨 160°；前后关键点继续至约 ±100° 形成侧方起势和惯性收势。采用非均匀三次曲线，接触中段连续经过，不逐关键点停顿。

仍使用 0.833 s 攻击时长和原有接触/声音时序，无需变更存档字段或运行代码。运行时原有 Blade_Base/Blade_Tip 骨骼球扫掠会使用导入的新轨迹，距离上限仍是 1.8 m。
