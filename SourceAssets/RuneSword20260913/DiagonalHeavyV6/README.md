# 双手符文剑 DiagonalHeavyV6

用户要求：修复待机剑面角度影响挥砍刃向；第一斩向右后上方大幅举剑，保留剑柄、允许大部分剑身离开屏幕，定住 0.5 s 后快速从右上斩向左下并顺势超出画面；第二斩镜像剑路，注意双臂交叉与扭曲。

## 制作依据与范围

沿用上一版 V5 双手剑与 V4 连续肩肘、前臂辅助骨经验。制作前读取 V5 时序、运行状态和解算源，并查看已有 `CompactNaturalV4/UEReview/slash1_windup.png` 作为原起势构图参考。本轮不制作验收渲染或运行测试。

实际游戏只更新两条攻击动画和两张剑气弧面。剑体大小、网格、骨架参考姿态、蒙皮、手指形状、材质、待机、步行、装备和冲刺资产保持当前版本。可编辑 blend 收录 V5 的四条非攻击动作，保留完整作者源。

## 剑路与时间

基础攻速时间：

| 阶段 | 时间 | 动作 |
| --- | --- | --- |
| 大幅起势 | 0–0.40 s | 先将剑柄送到右侧，再举高并后带；大部分剑身允许伸出上方／侧后画面 |
| 固定蓄力 | 0.40–0.90 s | 剑柄、双手、肩肘定住 0.50 s |
| 快速斜劈 | 0.90–1.015 s | 右上到左下，约 0.115 s 内完成作者空间 220° 剑轴扫角 |
| 顺势下斩 | 1.015–1.115 s | 延续到左下侧后方，允许剑超出相机视野 |
| 回握 | 1.115–1.65 s | 从外侧抬回，再回到原左剑面待机 |

继续使用现有整次攻击攻速快照；角色攻速会缩放整条动作的实际播放时间。第二斩只镜像武器轨迹的水平坐标，保持右手在护手下、左手在剑首上的角色职责，不互换骨名、不负缩放手臂。

作者相机空间以米为单位、+Y 向前。第一斩蓄力护手位于 `(27,30,10) cm`，剑轴向右上及后方伸出；最终顺势护手到 `(-37,26,-31) cm`。第二斩水平镜像对应位置，回握均接回原待机。实际屏幕构图仍需用户在游戏视角中判断。

## 刃向修复

V5 的 `face_flip` 原先参与每一条攻击姿态，导致待机额外 50° 剑面翻转跟随进入快速段。

V6 的 `diagonal_motion.py` 单独输出 `grip_pose` 和 `blade_pose`：双手按前者解算，剑根与剑根／剑尖骨按后者烘焙。两者始终共享护手原点及剑柄长轴，仅绕该轴的剑面角不同。起势、收势通过局部长轴旋转过渡，避免两组世界四元数各自插值时将剑柄轴与双手轴分开。

快速段的剑宽轴沿斜劈弧切线，剑面位于该切割平面内。刃向由攻击轨迹生成，不引用待机额外 50° 翻面；回握末端才恢复当前 115° 左侧剑面待机。

## 双臂与反馈

- 保留完整手型、握柄深度和连续握角路径。相邻四元数保持同号，前臂辅助骨继续随完整骨段变换，避免旧版分数扭角越过 ±180° 后发生翻折。
- 肩肘先沿 V4/V5 的原骨长支撑解算，再联合选择左右肘部弯曲平面。制作目标同时考虑两条手臂骨段间距、视角内前臂交叉、腕轴折角及逐帧肘位变化。
- 联合解算只调整肘平面，不拉长骨段、不移动手指、不改变握柄位置。蓄力段保持固定解，首尾以零修正接回已保留的待机姿态。
- 两条攻击按 240 Hz 烘焙，每条 397 帧。上述约束是制作方法，并非已经证明所有角度均无穿插；本轮按用户规则不执行视觉或运行检查。
- 原镜头反馈改为随斜劈抬起、向斩击侧下压、轻震并回弹；停顿期间保持蓄力镜头目标。受现有 `CameraMotionScale` 控制，首次命中短促冲击继续保留。
- 剑气弧面重新取样实际斜劈轨迹，接触窗、挥剑声音启动时间、组件攻击时长和物品定义同步为 V6 时间。
