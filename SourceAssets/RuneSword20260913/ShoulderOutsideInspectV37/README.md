## 如何兼容“身前转”和“前臂外侧转”

这两个要求的参照物不同：动作可处于身体右前方，同时位于右前臂外侧。

- 将 V36 核心片段的手掌与剑作为共同空间组绕竖轴转向 65°，并移到右侧。保留 `hand^-1 × weapon` 接触变化和每根手指的局部轨道，不单独拧剑或重做一条匀速圆周。
- 核心起始右腕位置为 `(0.39, 0.38, -0.10)` m；作者坐标为右 +X、前 +Y、上 +Z。
- 右肘的引导方向向内、向下，使前臂与转剑平面分开；剑的后向阶段朝右肩侧，向下阶段朝前方。实际皮肤与剑刃间距仍待用户观察。
- 肩侧剑身方向为 `(0.28, -0.94, 0.18)`，显式表达向后、略向外和略向上，替换 V36 后半段基于单视角估计的身前侧持。
- 进出转剑的剑与右手保持原闭合握柄关系。收势先回右侧立剑姿态再回身前，左手最后接稳。

V36 的手指核心来自逐帧制作。本版的转动平面、肩部姿态和衔接是按项目需求重新编排的三维适配，不代表原视频全段保持不变。
