# V41 · 上臂衔接修正与动作微调

2026-09-15。用户反馈 V40 的手臂内部空心截面进入视野，要求优化手臂衔接、微调动作，并明确要求自行检查审计。

**历史状态：本版已完成源蒙皮与 UE 资源画面审阅。随后用户要求检视中途左手不要入镜，当前由 [V42](../OffscreenLeftInspectV42/README.md) 替换；本版源文件与审计保留。**

## 原因与修改

- V39/V40 将肩部根节点也纳入整套动作的共同转向和前移。V40 前移 24 cm 后，右上臂原本藏在镜头外的开放裁切口进入视野。UE 修改前画面可以复现，源动画本身也存在；不是动画导入压缩造成的缺口。
- 继续使用 V40 的前移位置、65° 共同转向和 V36 的内部手部动作。上臂围绕既有肘部位置重新连接到镜头下方；锁骨、上臂及两根上臂 twist 辅助骨作为完整骨段一起处理。
- 起势局部将整套动作最多下移 **2.775 cm**，平滑加入、平滑收回。大于 0.001 cm 的修正分布在约 0.188–0.808 秒；手、剑、前臂接受相同位移。
- 手腕、手指、剑及前臂的配合继续沿用 V40/V36；完整 120 Hz 关键帧保留它们的目标姿态。父骨修改后的帧间插值有微小差异，详见审计。
- 网格、蒙皮权重、静止骨架及上臂长度不变。首尾仍为原双手待机，动作时长 **2.90 秒**，没有添加停顿段。

### 审计中保留的已有现象

- 约 1.837–1.842 秒，母版左臂存在很大的角度步进。V41 与 V40 一致；额外 UE 姿态图中左臂已退出画面，未将此现象误判为新肩部修正导致的问题。右上臂最大半帧角度步进从约 9.899° 降至 8.568°。本轮没有重写母版左手动作。
- UE 独立预览进程在运行本脚本之前记录了 13 条 `LogAutomationTest: Error: Condition failed`，进程退出码为 1。动画采样、全部画面及完成回执均已生成，随后正常执行 `QUIT_EDITOR`；无本脚本异常回执。不能据此声称 UE 启动检查全部通过。这些启动期错误未在本次动画修改中处理。
- UE 审阅使用加载正式资源的独立预览场景，按项目 viewmodel 朝向和 FOV 采样压缩骨骼动画；没有执行完整 PIE 中的 F 键输入及移动/战斗流程回归。
