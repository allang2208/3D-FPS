# 鸣雷疾驱座：顶部闭合与悬空饰线修复

用户于 2026-10-25 明确要求检查顶部线条是否未封闭、独立悬空，并优化。

## 原因与修复

实际 V1 源模型近景及局部网格检查发现：每款模型四根银色饰线本身有端帽，但作为四段独立几何没有汇合，路径也偏离承载外框。Steel 上端离实体 4.397–5.846 mm，Runebound 为 4.339–5.803 mm；所以看到的是悬空断头，不是漏面。顶部每面七颗小铆钉采用了前面板的偏移，未正确落在收窄的顶盖斜面上。

- 移除每款四段旧饰线，替换为前后各一圈连续尖拱包边。闭环共用首尾顶点，没有独立端头；背面嵌入原外框约 0.55 mm。
- 每款顶部十四颗铆钉按顶盖真实斜面重新定位和转向，基部埋入约 0.20 mm。
- Steel 保留 61,573 个未变顶点，Runebound 保留 64,608 个未变顶点；保留主体 UV、材质索引、面角法线、原装安装端面及武器根坐标。移动的铆钉法线同步旋转，UV 不变。
- 原六张 4K 贴图继续使用；新闭环包边单独制作共享 2K BaseColor、ORM 与切线法线，避免重排主体 UV。
