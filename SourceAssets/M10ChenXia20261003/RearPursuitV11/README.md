# M-10 后方远目标追击 V11

用户要求目标在身后且超出毒雾攻击范围时，调转方向接近并攻击。

- `IsInRearGasRange` 统一判断毒雾起手和背向驻守距离：沿用臀部出口到目标的水平距离 `RearGasTriggerRange`（当前 600 cm）及原高度限制 220 cm。
- `PrefersRearAttack` 同时要求目标在后半面且位于该范围内，判断独立于毒雾冷却。
- 范围内：行为树保持驻守，转向组件用较短方向对齐臀部，继续原背向毒雾行为。
- 超出范围：释放驻守，恢复既有导航追击与路径转向；接近后按当时方位选择撕咬、嚎叫或毒雾。
- 沿用 V10 转身速度、同步步频和有碰撞突进；未改变攻击伤害、动画、冷却、云团扩散或已开始攻击的锁定时序。

本轮只修改原生逻辑，不需要导入资产。后台 Editor/Game 构建结果见 `delivery.json`。未运行游戏、测试或预览，交由用户体验。
