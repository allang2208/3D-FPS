# M-10 坡地接地与八足修订 V12

用户要求参考手脑处理宽体悬空，并排查移动时腿脚穿模和扭曲。

## 排查依据

手脑使用 `UMonsterCharacterMovementComponent` 的平底支撑、跨阶高度判断和网格跨阶平滑，M-10 的专用移动组件已继承这些功能。它们只处理角色整体碰撞/跨阶，不负责长跨度身体倾斜和八只脚的不同落点。旧 `FM10FootPlantNode` 只锁动画给出的世界位置，没有地面采样；固定 0.28 秒补步也没有随 V10 转身提速缩短。

本次用户授权的离线源动作诊断采样 Walk、两侧弧行及两侧原地转身，每段 36 帧、八条腿，使用 V5 实际蒙皮数据中的脚掌/脚趾样本。弧行最低脚底样本约 -1.64 cm，支撑段最高最低脚底样本约 6.66 cm。该诊断只覆盖原作者动作，不能代替 UE 动态 IK 或实机验收。原始结果见 `source_locomotion_diagnosis.json`。

## 制作内容

- 沿用手脑的共用跨阶处理。在 M-10 动画节点增加最多 11 条、20 Hz 的地面支撑射线：八只脚及三个腹部支撑点，不增加 Actor Tick，也不读取全量渲染网格。
- 多脚支撑拟合身体坡面，姿态与高度平滑过渡，倾斜上限 22°、高度补偿 -80～60 cm。腹部单独防止拟合面把宽躯干压入台阶/凸起。
- 逐脚沿地面法线对齐，用现有专用 Physics Asset 的脚掌凸包接触样本确定落点高度；无凸包才退回绑定脚底高度。保持原模型、材质、62 骨绑定和权重。
- 支撑段锁脚，摆动段至少保留 12 cm 抬脚弧线；攻击期间保留源动作抬脚量，咬击突进不被世界锁脚拽回。
- 最大伸展从 98% 收至 96.5%，94% 时允许提前补步；补步时长随实际步频调整为 0.09～0.22 秒。跨过完整摆动段的帧也会释放旧脚锁。
- 限制脚掌反拧至 35°、落脚纵向行程及向身体内侧穿越；膝盖沿身体局部稳定弯曲方向求解，腿根组织仍在最终 IK 后跟随。
- 接地数据和碰撞读取留在动画 PreUpdate 的游戏线程；工作线程只使用复制的地面数据和骨骼姿态。状态快照先移除旧根骨接地补偿，再叠加当前补偿，避免切换动作时重复下沉。
- 死亡前导保留最后身体支撑，物理接管后不再覆盖身体；攻击数值、前后方决策和接触时钟不变。

本轮为原生动画接入，无需重导模型或动作。实际 Editor/Game 构建见 `delivery.json`。未启动游戏、PIE 或预览渲染；未做实机地形/形变测试，最终观感由用户体验。
