# M-10 转向与脚步 V2

用户确认直行移动基本可用，要求改善转向与脚步配合。本次保留 RigV1 的模型、54 骨、权重、原直行动作及攻击接触时刻，不重导骨骼网格。

## 作者产物

`Delivery/M10_TurningV2_Editable.blend` 保留旧动作并新增四段 1.2 秒循环：`CurveLeft`、`CurveRight`、`PivotLeft`、`PivotRight`。对应 FBX 只导出动画骨架。制作参数与来源保存在 `turn_contract.json`；`author_turns.py` 复用已接受的直行姿态函数，不重新计算蒙皮。

弧线爬行动作按 46.15 cm/s、10°/s 的刚体平面运动反算每条脚的支撑轨迹，内外侧各自形成不同步长；原地转身使用同角速度与零前进速度。转向动作支撑段为 75%，八腿四组错相；原直行仍为 65%。前躯和头部朝转向侧引导，后躯以小角度反向缓冲，肉甲沿其父链运动。UE/FBX 手性差异在左右动作的作者符号中处理。

## UE 实现

- `UM10MovementComponent` 继承已有怪物移动组件，保留寻路、扫掠碰撞与台阶补偿。30°开始减速，70°转为原地调整，降到25°后恢复前进；最大转速初值为行进24°/s、原地20°/s，角加速度65°/s²。这些是可调初值，尚未由用户体验确认。
- `UM10AnimInstance` 继承现有反应与战斗时钟，仅替换 M10 的动画图。直行、左右弧线和左右原地循环共用一个归一化相位，根据实际线速度和角速度计算步频与混合权重；原地旋转也会迈步。
- `FM10FootPlantNode` 只进行八条肢链的有界 IK。支撑期间脚掌位置和朝向锁在世界坐标，起落边缘渐变；在接近腿长极限且其他支撑允许时增加一次短换步，不拉长骨段。传送、骨架重建、攻击、受控和死亡释放锁。没有加入新的逐脚地形射线，本轮处理的是转向支撑与脚底滑移，沿用原有地面/台阶移动。
- 近战须处于正面15°内且转速降至5°/s以下才进入攻击。起咬不再瞬间对准目标；保持起手时身体朝向与原0.85秒伤害接触时钟。行为树仍决定追击、返回和攻击，移动组件只执行当前路径/近距离朝向调整。
- 服务器负责角色转向；动画从各端可见的实际位移、朝向变化计算。没有新增逐帧资源加载、网格顶点遍历或伤害时钟。

## 导入与制作状态

先执行 `author_turns.py`，再执行带 BOM 的 `finish_production.ps1 -Stage All`。它进行常规 Editor/Game 构建与 `import_turns.py` 的后台资产保存，不重建地图导航，不启动游戏。新动画位于 `/Game/Monsters/M10Mawcrawler/Animations/TurningV2`，绑定原 `BP_M10Mawcrawler`；F6 入口不变。

`delivery.json` 记录本轮构建/制作结果，`asset_receipt.json` 逐资产记录保存结果。未进行形变、游戏或性能测试，最终由用户测试；源文件存在或构建成功不等于资产导入完成。

本轮实际结果：Editor/Game Development 均构建成功；四段新动画和 `BP_M10Mawcrawler` 已由后台导入脚本保存，蓝图绑定的动画类为 `M10AnimInstance`、移动组件为 `M10MovementComponent`。为必要原生构建正常退出了没有未保存内容、没有运行 PIE 的编辑器；制作结束后未重新打开。
