# M-10 眼口层次与腿根修订 V5

本次范围：用户明确要求排查眼口平面感、张嘴组织僵硬及转向腿根扭曲。只对这些问题做源模型分析与姿态对照；没有启动 UE、PIE 或游戏测试。

## 制作内容

- `prepare_surface.py` 用原色贴图、原 UV 与眼口解剖分区制作 16 位有符号高度图 `M10_FaceHeight16.png`（中灰为零，完整编码范围 ±6 cm）。眼球凸起、眼窝凹槽与眼睑边缘分开控制；牙齿/牙龈和暗口腔使用不同高度响应，金属口箍不参与位移。高度图实际采样至原网格并焊接 UV 接缝位移；运行时用烘焙后的几何，不额外进行全身 WPO。
- 以原 1,299,090 个三角形及 UV 为基础，替换口腔内部粘连面，制作独立的 19 颗上牙、17 颗下牙、牙龈和凹入口腔内壁；具体移除数与内壁顶点数记录在 `export_contract.json`。原网格内部存在上下组织粘连，仅沿高度、表面距离或颜色重新分配权重仍会拉长连接面，因此此处采用局部重建。外部眼睑、嘴唇、脸和身体保留原外观与 UV。原细节法线贴图保留；改变位置的局部重算法线，其余区域保留原自定义法线。
- 嘴角、上唇和下唇各有渐进权重与两段组织修形；独立牙齿整颗刚性跟随头或下颌，牙龈及口腔内壁在嘴角连续过渡。`M10_MouthOpenTissue` / `M10_MouthWideTissue` 由动画最终下颌开合量驱动，步行/闭嘴时不常驻变形。
- 原第二至第四对腿在绑定姿态下，髋到脚踝距离约为两段腿骨总长的 99.3%–99.97%。新膝盖留出屈曲余量，八条腿的新比例约 91.3%–95.6%。脚掌及髋根绑定位置不变。
- 新增八个腿根过渡骨，整体 54→62 骨；按髋根/大腿/膝/小腿/脚掌沿链分配权重，保留每顶点最多 4 权重。过渡骨在最终锁脚求解后跟随 45% 的腿部旋转，缓和躯干与肢体连接区的折叠。
- 锁脚节点使用躯干局部参考弯曲方向稳定膝盖，最大伸展限制在总长 98%，换步触发提前到 96.5%。仍使用原八足相位和有界换步数量。
- 原十段在用动作全部按新绑定重新烘焙，保持原身体表演、脚步节奏、咬击 0.70 秒接触及嚎叫六跳时刻。新骨架采用独立资产路径，避免旧动作误用新参考姿态。

## 文件与接入

1. 运行 `prepare_surface.py` 生成高度图、权重和绑定定义。
2. 后台 Blender 运行 `build_surface_rig.py`，输出 `Delivery/M10_SurfaceRigV5_Editable.blend`、新骨骼网格和十段动画 FBX。
3. 用户本次“排查”范围内的离线姿态对照由 `diagnose_source_poses.py` 输出至 `Diagnosis/`；这些是 Blender 源模型图，不是 UE 实机图。
4. `finish_production.ps1 -Stage All` 先构建 Editor/Game，再通过后台互斥 commandlet 执行 `import_surface_rig.py`。导入会创建 `/Game/Monsters/M10Mawcrawler/SurfaceRigV5` 下的网格、独立骨架、物理资产和全套动作，并绑定现有 `BP_M10Mawcrawler`。F6 入口、弱点和战斗数值保留。
5. 原生 `M10TissueNode` 驱动腿根与嘴周修形；`ConfigureSurfaceRig` 统一 FBX morph 名字并写入 UE morph 曲线元数据；引擎物理资产按新绑定制作。

当前实际构建、资产保存状态以 `delivery.json` / `asset_receipt.json` 为准。仅源文件和导入脚本就绪不代表已接入。若编辑器正运行 PIE 或存在未保存内容，保留现场；结束/关闭须遵守当前用户授权。

本轮实际交付：Editor/Game 构建成功；后台 commandlet 已保存 18 个资产，包括新网格、骨架、物理资产、高度纹理、三种口腔材质、十段动画及原怪物蓝图。用户已授权结束 PIE；最终导入在编辑器退出后通过后台完成，完成后未启动编辑器或游戏。导入时出现 Blender 多网格 FBX 的 BindPose deformer 警告；源文件各部分使用同一参考骨架，UE 导入与保存完成，但这不等同于实机形变验收。

## 本次针对性诊断

`root_deformation_diagnosis.json` 比较左右弧行、左右原地转身各 4 帧，共 16 个相同采样点的腿根表面边长畸变（拉伸和压缩均计入）。99 百分位畸变的均值由 1.447 降为 1.223；超过 2 倍的边样本由 6616 降为 1704。此数据来自绑定权重和源动作矩阵计算，未覆盖 UE 运行时锁脚求解，不等同于游戏通过。归一化权重均为有限值，最大归一化误差约 1.8e-7。
