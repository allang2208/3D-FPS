# M-10 方位攻击与六秒喷气 V7

根据用户 2026-10-03 的方位规则调整，保留 SurfaceRigV5 蒙皮和所有其他攻击动作。

- 前方目标：能撕咬时优先撕咬，否则可在现有正面扇形内吼叫；不再为了吼叫强制先将玩家摆到扇形中央。
- 后方目标：选择毒气并保持背部朝向玩家。冷却期间由现有行为树停下等待，不进入迎面追击来切换攻击方式。距离与遮挡仍使用已有毒气起手条件。
- 侧方目标：比较身体前、后两端对准目标的角度，选更近的一端；正侧面 90° 等距时选择正面。选择仅取决于玩家位置，不取决于哪一招冷却完成。近距离继续使用原有渐进转向、转向步态和腿根过渡。
- 毒气冷却从起手开始计 12 秒；实际喷气 6 秒。动作总长 8 秒：1.2 秒摆身抬臀，1.2–7.2 秒喷射，7.2–8 秒恢复；没有把起手和收势一起慢放。
- 毒雾不再覆盖父类持久时间，直接沿用百目黑烟：每团保持 8 秒、最后 1.5 秒消散。绿色浓雾和绿色目盲材质继续使用 V6 资产。
- 中毒、额外魔法伤害、目盲进出规则以及受击打断沿用 V6。

`author_rear_gas.py` 后台生成 241 帧动画及可编辑 Blender 文件；`import_rear_gas.py` 导入新动作、保存原骨架导入元数据并更新现有 M10 蓝图的动作与冷却。`finish_production.ps1` 执行常规 Editor/Game 构建和后台资产保存。实际结果见 `delivery.json`、`asset_receipt.json`。
