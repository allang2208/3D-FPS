# M-10 眼球弱点与爆发咬击 V3

2026-10-03：用户要求前端眼球可暴击，其余部位对枪、弓、魔法等远程攻击减伤30%，并将近战改为瞬间发力上前张嘴咬。

## 命中与伤害

- 从原 Meshy 模型的顶点/贴图坐标定位九个可见虹膜，排除下方拘束带铆钉。作者数据为 `eye_regions.json`；作者辅助坐标图仅用于定位输入表面，不是游戏或形变验收。
- 九个狭窄椭圆区域通过实际 UE 参考骨坐标变换保存为 `EyeWeakpointFrames`，随头骨姿态移动。只有真正命中该怪物头部骨骼网格的正面接触，才进一步判断眼球；针对现有头部凸包浅层外包络做有界投影补偿，后方/甲壳命中不通过此入口。
- `ColdSteelSkills::IsCriticalHit` 增加 M10 专用分支，不再让整块 `head` 触发要害。直击眼球走现有要害必暴、暴击倍率、武器提示和技能经验链，不额外乘第二次暴击倍率。其余部位仍保留角色原有随机暴击规则。
- 远程身体命中在既有防御、附加伤害和暴击计算后乘0.70。按攻击来源/结算上下文识别枪、弓、投射物、独立魔法、点伤害及范围伤害，贴脸射击仍属于远程。普通近战、枪械近战和近战武器的混合元素面板不乘这一系数。既有直接扣血类状态伤害与状态毒气保留其原规则。
- 火球直接撞中眼球可要害暴击并免除此层身体减伤；溅射/区域伤害没有真实眼球接触，按身体减伤处理。火焰伤害仍按魔法入口承伤。武器的基础/追加伤害回执同步缩放，避免显示伤害与扣血不一致。

## 新咬击

`A_M10_BiteSnap_V3` 为1.6秒非循环动作：0–0.30秒后压蓄力，0.25–0.55秒张嘴，0.52–0.70秒快速前冲，0.70秒合咬结算一次，0.84–1.45秒恢复。下颌最大打开32°，头部姿态前探39cm，肢体分组抬掌/蹬地并用既有双段IK保持骨段长度。

角色同时执行最多35cm的短距离扫掠前冲，遇墙/角色停止，不瞬移、不收招倒退。前方缺乏可走支撑时不继续冲出地面。攻击打断、目标失效或死亡取消后续前冲与未发生的接触；头部前探超过胶囊时，身体到嘴之间的遮挡仍阻止隔墙伤害。原来0.85秒接触改为0.70秒，与新动画第21帧（零基、30fps）一致。

模型、权重、九段既有移动/转向/反应动作均保留；新咬击另存并替换蓝图引用，旧咬击仍在作者文件和原资产路径中。
