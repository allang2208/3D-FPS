# 办公室顶板与第一间工具柜位置修正 V4

制作范围仅为第一间货运中转房工具柜/抽屉的随机点位，以及车站办公室顶板。沿用原办公室墙体、灯具、材质、门窗和容器交互。

V3 顶板重建直接使用了 Blender 正 Y 中心，未按房间作者的 UE→Blender Y 轴约定翻转，导致平板伸出办公室。新 `SM_SW_Roof_FittedV4` 使用 Blender 中心 `[5,-3.5,3.28]` m，长宽厚 `[10.14,7.14,0.16]` m。UE 局部边界 X `-7..1007`、Y `-7..707` cm，与 14 cm 厚墙的外边界一致；底面 320 cm，厚度向上至 336 cm。继续使用 V3 哑光混凝土材质。

两个维护柜候选位：西侧 `[55,-1300,0]` cm、朝向 90°；东侧 `[1745,-1030,0]` cm、朝向 -90°。柜体与抽屉一起移动；西侧柜避开推车轮组、液压机构及手柄，门向房间内打开。固定样板保持原有选择，只移动已放置的西侧柜及抽屉。

交付目标为生产地图 `/Game/GameMaps/L_Dungeon_Randomized` 和车站测试图 `/Game/GameMaps/Design/L_FreightTransit_Theme_Subject`。实际资源保存状态见 `Receipts/assets.json`，实际地图保存状态见 `Receipts/install.json`。原地图与生成器目录备份保留在 `Backup`。

`Scripts/author_roof.py` 导出本批独立 Blender 源、FBX 和清单；`fit_rules.py` 保持其他配方，仅修正顶板引用与工具柜点位。V3 顶板作者坐标、工作间配方重建入口、容器增补点位作者和目录入口同步保留修正。

没有原生代码改动，无需编译。未启动编辑器、游戏/PIE、测试、截图或验收渲染，由用户继续试玩。
