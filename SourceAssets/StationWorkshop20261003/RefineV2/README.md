# 工作间与车站精修 V2

用户要求的文字镜像排查覆盖车站线路使用的印刷面家族，按源 FBX 法线、UV 的 U 方向和 UE 相机左右关系定位。修正工作间告示、门牌、流线牌、安全牌、电脑屏幕、设备铭牌、货架备件盒、推车标签、抽屉标签，并统一桌面文件的阅读方向。沿用印刷图集原比例；另修复五个共用仓库容器标签，独立网格副本保留碰撞与材质。

货架三套布置随地牢种子选择：轴承堆叠数量与间距、立式套筒高度、备件盒位置和角度、铜棒数量与角度、底层箱体位置均有变化，模型保持贴在各层承托面上。

调度桌设备重新制作：薄边框显示器、后壳散热与接口、独立键帽及字符、导航区和数字键、鼠标双键与滚轮、主机散热口和插头、电话听筒与卷线、对讲机旋钮及天线接口。电源、视频、USB 和电话线有连接端点；桌面范围内抬高到桌面之上，电话线绕出桌沿后下降接墙上端口。

观察窗使用医院的 `UWardBreakableGlass`、碎片材质、玻璃撞击特效和声音，三块玻璃独立破碎。按窗口尺寸重新制作完整玻璃及 Voronoi 碎片，继承医院 UV/WPO 合同。人员门与两扇维修门改为默认关闭的 `AColdSteelDoor`，按 E 开关、沿用冲刺撞门动作，打开后不自动关闭。

桥面上新增一只现有地牢骨骼宝箱，位于站内坐标 `[2650,0,480.8]` cm，留出西侧通路。正式地牢使用原领取键、开启动画及战利品面板；线路样板的宝箱用已有 `DungeonTreasure.HubTest` 标签支持场外开箱和战利品面板。

继续使用现有样板：

```text
open /Game/GameMaps/Design/L_FreightTransit_Theme_Subject
```

制作入口为 `Scripts/author_refine.py`、`repair_warehouse_labels.py`、`prepare_refine.py`。`audit_scene_text.py` 只执行用户本次要求的文字方向排查。实际构建、导入与地图保存分别记录在 `Receipts/native-build.json`、`assets.json`、`install.json`，文字结果在 `text-direction-audit.json`。21 个网格和三个新办公设备材质、一张键盘字符图集；原纸面、外壳、木、金属、医院玻璃表面继续共用。

后台制作、必要编译、导入与落盘，不主动打开 UE；未运行游戏、PIE、交互测试、截图或渲染。运行与视觉效果由用户继续测试。
