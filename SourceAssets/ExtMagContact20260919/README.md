# 扩容弹匣：三枪换弹与 AKM 缺口修复

本轮按用户要求排查 M4 左手未握住弹匣、QBZ-191 左手扭曲、AKM 局部穿模及下段缺口。AKM 整体造型已获用户认可，本轮保留。

## 原因与修复

- **QBZ-191**：`bUsingM4Infima` 是包括 QBZ、部分手枪在内的共用动作时钟标记，不是 M4 身份。此前扩容分支因此把 M4 专用动作给了 QBZ。`ReloadPressed` 现在同时限制实际 M4 枪型，并确认动画骨架匹配；QBZ 恢复既有的专用普通/空仓动作和拉栓尾段。本轮没有重做 QBZ 骨架。
- **M4**：原手型的指节仍在弹匣一侧，整手平移未形成包握。`author_contacts.py` 从用户认可的 AKM 接触姿态取完整手型，按 M4 自己的截面中心、切线和握持高度适配。接触段用弹匣坐标固定手腕关系；手指以局部旋转过渡，保持骨段长度；锁骨、上臂和前臂联动处理可达性，避免伸长前臂。普通/空仓仍保留原时长、甩匣与拍击时序。
- **AKM 接触**：保留自身动作，接触段给手掌增加 2 mm 外侧余量，四指中间关节舒展 4°。原厂、斜握把、垂直握把、棱镜阻手器和倾斜握把分别从其现用作者源烘焙，保留各自起势/回握。
- **AKM 网格**：下段存在 650 条开放边，导致局部露空。正式制作入口 `seal_akm.py` 在 35 个局部边界组补面，保留原顶点、外轮廓、纹路和上端插接开口；制作回执中下段开放边为 0。`repair_akm.py` 是早期自动填洞尝试，不是交付重建入口。

## 交付

- UE `/Game/Weapons/ExtMagContact20260919`：M4 普通/空仓两段动作，AKM 五种握持配置的普通/空仓共十段动作，以及 `SM_ExtMag_AKM40_Closed`。
- `animation_authoring.json`：每段动作的真实源、时长、采样率与接触窗口。M4 480 Hz、AKM 基础 240 Hz，AKM 握把变体保留原 120 Hz。
- `FBX/` 与同名 `.blend`：可编辑动作与引擎导出。网格源为 `AKM_ExtMag_Closed_Editable.blend`。
- `install.py` / `install_receipt.json`：各枪使用自身宿主骨架导入，AKM 使用自身原厂弹匣材质。
- `diagnose.py` / `show_contact.py`：本轮明确授权的源姿态排查图；`after_*.png` 是源模型局部图，不是实机验收图。
- `make_icon.py`：AKM 更新后的实际网格图标；M4/QBZ 模型与图标本轮不改。

容量、附加属性、物品 ID 和存档字段保持原有行为。未启动 PIE 或游戏回归；源姿态排查与必要编译不等于实机通过，用户重启编辑器后测试三枪普通与空仓换弹。
