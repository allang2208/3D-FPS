# SVD 手掌与五指抓握重制（2026-09-23）

## 2026-09-23 整理后的当前入口

旧换弹导出已由 `SVDThumbUp20260923` 替代；当前模型与材质入口为 `SVDRefinedFinish20260923`。本目录的旧制作记录保留其历史日期与验收边界。已经移走的旧导出、自动备份及恢复快照位于 `trash/svd-superseded-20260923/SourceAssets/` 下的同名目录，原路径、散列及保留替代物见 [归档清单](../../Docs/AssetArchives/svd-superseded-20260923.json)。当前所需 Blend、脚本、参数与原素材仍保留；不要直接重跑旧导入覆盖用户已认可的抓握。新 checkout 的恢复方式见 [SVD 发布说明](../../Docs/Weapons/svd-publication-20260923.md)。

用户再次明确：问题在抓住弹匣的手部关节扭曲和包握不贴合，并询问是否因为弹匣太宽。前两轮 `SVDReloadArm20260923` 与 `SVDMagazineSeat20260923` 主要处理腕肘和松手衔接，不能算解决了这个手型问题。本轮直接更换掌位与五指关节姿态。

## 本轮制作依据

从最新 `SVDMagazineSeat20260923/SVD_base_Editable.blend` 读取实际手套、骨架 rest、原手型和完成细化的弹匣外壳，记录于 `inputs.json`。手套顶点映射与既有抓握输入一致，手指局部 rest 无显著差异。

当前 SVD 外壳左右厚度约 26.75 mm，AKM 参考外壳约 26.08 mm。SVD 抓握区前后截面跨度约 86 mm，AKM 对应中部约 75 mm；这种形状差异需要独立掌位与手型，不能直接照搬。这里是项目模型尺寸比较，不是对现实枪械尺寸的认证。

旧 SVD 食指 `index_02_l` 的局部 Z 屈曲约 -2.1°，`index_03_l` 却约 45.3°；小指中节约 19.9°、末节约 51.9°。旧拟合优先追表面间隙，缺少中节与末节的自然联动约束，留下中节过直、末節过折及食指轴向扭转。上一轮调整整臂仍保留了这些手指姿态。

## 实际修改

- 按当前 SVD 外壳重新拟合整个掌位和拇指后侧对握。
- 四指 MCP 保留有界外展和屈曲，取消为追贴合而产生的轴向扭转；PIP、DIP 仅沿已辨认的屈曲轴旋转。
- 中节屈曲下限 32°，末节屈曲为中节的 0.5–0.8 倍、上限 48°；这些是本轮制作边界，不是跨骨架通用人体限值。
- 本轮食指 MCP/PIP/DIP 约 41.7°/32.9°/26.3°；中指约 47.2°/36.0°/27.1°；无名指约 49.7°/41.2°/20.6°；小指约 50.0°/37.2°/29.8°。
- 对实际手套完整表面使用外壳截面包络约束，同时考虑掌面与固定指腹区域；求解数据保存在 `grasp_fit.json`。数值间隙不等于视觉验收通过。
- 新手型应用于接近、取匣、持匣、插入、压实和松开，肩肘按新的手腕目标同步支撑；普通／空仓及四种握把共 10 段。保持弹匣模型尺寸、骨长、rest、蒙皮、手指局部位置和缩放、右手与机械时钟。
