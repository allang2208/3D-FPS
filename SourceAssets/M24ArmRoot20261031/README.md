# M24 独立后握把的左臂根部净空 — 2026-10-31

用户报告待机和战术冲刺时左臂末端进入镜头，要求保留现有动作并自行检查。

## 原因与修改

实际显示的 Kaitlin 装备手臂通过 Leader Pose 跟随 M24。独立后握把修改右手握点后，FRifleHipFraming 会根据新 profile 重新计算整枪相机锚点；此前针对原厂右手锚点的肩端净空检查不足以覆盖此分支。

保持当前枪位、左肘、小臂、手掌、手指及其世界朝向，将左肩/上臂围绕肘点、沿不含上臂轴向扭转的方向下收 10 度。锁骨和上臂同组移动，保留其相对关系与原生骨段长度、缩放。只有骨架枪托两份 profile 的 clavicle_l、upperarm_l、lowerarm_l 局部轨道负责补偿；上臂 twist 随父骨运动。普通 5 发、10 发 profile 不改动。

待机、ADS、冲刺进入/循环/退出及持枪拉栓段保留持续修正；释放扶木手的动作只在起止 0.22 秒内平滑交接，其主体动作保留。之前装备/空仓换弹复用开火拉栓的枪械位移不变。

## 保存与检查范围

`install_receipt.json` 为两份实际 profile 的保存记录，`saved_profiles.json.gz` 是另一次后台 commandlet 从磁盘加载后的读回数据。作者差量位于 `arm_root_patch.json.gz`。没有 C++ 修改。

`review.json` 使用实际 Kaitlin 网格与权重、独立后握把的相机锚点，检查待机、冲刺进入/循环/退出与局部姿态混合；包括四份配置、骨长、握点/枪位差、真实臂根开口净空和肘部新增折面。开口来自几何焊接后的边界边，避免将 UV 接缝或正常可见的上臂误判为截口。

`before_idle.png` / `after_idle.png`、`before_sprint_loop.png` / `after_sprint_loop.png` 是不含枪体遮挡的离线手臂观察图。未启动编辑器、PIE 或游戏，不将离线复现称为实机验收。
