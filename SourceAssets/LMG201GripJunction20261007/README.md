# 201 后握把衔接修整，2026-10-07

本批对应用户“跟 201 的后握把衔接组件还是没处理好，排查并优化，参考原厂后握把的优化”。仅修改现用三款改造后握把的接颈，实际保存状态以 `install_receipt.json` 为准。

## 依据与问题

- 当前枪体：`/Game/Weapons/LMG201/Cover10/SK_LMG201_Cover10`；当前配件：`/Game/Weapons/LMG201/Accessories22/Meshes/SM_LMG201_{phantom_reargrip,balanced_reargrip,stable_antislip_reargrip}`。
- 原厂参考为 `SourceAssets/LMG20120260927/SurfaceFinish50/model.py` 的局部曲面整理，以及当前枪体 `FactoryRearGrip` 分区的真实顶面轮廓。原厂下方与安装边界的保护思路继续保留。
- 上轮通用材质/网格细修仅允许 0.08–0.12 mm 位移，并保护硬折边。它不能修复旧接颈放样继承下边界凹陷产生的纵向折痕。
- 现用网格取自 UE SOURCE_MODEL，UV4 标识重建接颈。均衡款顶圈沿实际安装轮廓来回折返，轮廓参数没有完整绕行一周；其顶圈凸包面积为当前原厂安装面的 79.04%。该比例是二维凸包面积比，不是实际接触率或游戏中的缝隙测量。
- 三款材质已有 UV4 驱动的结构法线淡出，AO 输入为空（默认 1）。原厂有独立 AO 淡出，但此处无需再添加。保留上一轮 RG01 材质和天气映射。

## 正式制作

使用 `author_neck.py`。`author.py` 是未采用的 0.55 mm 有界拉普拉斯候选，不能用于重新安装。

1. 锁定原始接颈下边界：幻影约 z=-2.2 cm，均衡/稳固约 z=-2.0 cm；完整保留其下的原始握把位置、法线、UV、颜色和细节。
2. 使用原厂实际顶面凸包轮廓，包括倒角转折点；顶面仍为 z=0.6 cm，三款顶圈最终均覆盖该轮廓。
3. 对完整绕行的顶圈消除局部回折；均衡款重新建立沿周长单向绕行的对应关系。只调整既有 11 圈接颈，保留网格连接关系和面数。
4. 按边界弧长平滑过渡形状，整理下边界至顶面的放样；沿曲面参数方向生成连续法线，避免狭长三角形面积差造成的高光条纹。
5. 修正均衡款一个接颈三角面的朝向，顶盖法线朝外。顶面以内部分仍作为原配件安装区域。
