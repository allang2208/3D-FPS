# 主手避让节奏与支撑调整 — 2026-11-08

用户反馈主手法杖、手枪配副手单手近战武器时，快速近战避让僵硬，要求排查节奏及主手位置。后台修改和必要构建，不启动编辑器或游戏，不执行运行测试。

## 源码定位

- 手枪＋斧头：旧曲线在 0.10 秒内达到相机右移 30 cm、上移 10 cm、后移 6 cm，随后减少横移但保持静态避让，到 1.08 秒后才集中回位。右手肩肘目标仍固定在交叉待机位置。
- 手枪＋刀：直接套用原参考的枪框轨迹，作者键含约 63 cm 横移及约 50 cm 下沉，关键点位置线性插值；左手腕点又相对这只枪手采样，因此不能直接缩小枪的偏移而不处理刀路。
- 法杖：旧曲线平移握点、肩肘，实际最终手臂层却仅消费握点，刚性搬运整条作者右臂；修改 `FStaffCastPose.Shoulder/Elbow` 本身不足以改变最终支撑。斧头分支从 0 秒开始，却使用从 -0.14 秒开始的入场混合，第一帧已经混向待机。

## 本次实现

新增 `OffhandQuickClearance.h`，分别为斧头下劈和单手刀突刺提供主手避让曲线。相邻键使用共享、保形的 Hermite 切线，起止速度归零；避免每个键停一次。先向右让出通道，发力阶段小幅跟随，回收阶段先收横向距离再降低握点。

- 手枪：斧头曲线最大右移 22 cm、抬高 9.5 cm、后移 3.8 cm；刀曲线最大右移 21 cm、抬高 8.5 cm、后移 4.8 cm。轻微外转围绕原作者掌心合成。肩跟随握点平移的 12%，肘极点跟随 45%，并略向外下方调整；实际骨长、握枪手和手指沿原生求解保留。
- 副手：将最终枪手位置逆变换回原生枪坐标，再投到副手原作者参考框；斧头归位仍以原待机枪手为锚点。副手动作和主手避让独立，突刺接触直接采样当前接触时刻的参考框。
- 法杖：按同一分段意图派生独立幅度，最大右移约 18.7 cm。沿原生作者手型锁住杖柄，最终姿态层将已经求值的原生右臂作为参考，重新安排肩、肘支撑。肩只承担小部分位移，保留原握点、手指及辅助骨关系；不再用整条右臂的刚性平移承担全部避让。
- 法杖＋斧头的主手入场改为 0–0.16 秒从实际保存姿态进入；中断回位保留当时的主手避让及支撑偏移，再共同淡出。

沿用现有斧头下劈、刀突刺、时长、音效、命中窗、伤害、击退及顿帧。主手避让读同一动作时钟，因此命中停顿时共同停住，正常收势末尾回到原待机。上挑和旋风主体沿原路线；进入旋风时仅清理本次新增的快速近战支撑返回状态。

当前装备接入仍是已支持的手枪／法杖＋副手单手近战组合，本轮没有扩展新双手武器握持或新副手模型。刀剑沿现有 `offhand_melee_mesh` 适配范围工作。
