# A762 UE5 游戏接入

后续模型与材质精修见 [Refinement01](../Refinement01/README.md)。其导入沿用本页的运行网格路径，新的可编辑源为 `../Refinement01/A762_Refined_Editable.blend`；本目录保留初始接入源与 11 段动作。

用户于 2026-09-20 要求按枪械标准工作流接入，并复用 AKM 当前音效。本目录承接上一级 Meshy Candidate01，原始生成文件保留在上一级目录。

## 游戏入口

- 独立物品：`ue_a762`，显示名 **A762**。
- 通过现有仓库初始武器发放流程加入；载入存档或打开仓库时，尚未领取此物品的档案会获得一把。沿用既有领取标记，仓库需要有可放入空间。
- 支持装备、切换、背包及仓库转移、丢弃拾取、实际模型动态图标、独立枪匠预览，以及现有装备/弹量/改造存档流程。
- 基础数值沿用 AKM：`ammo_762`、30 发、伤害 35、开火间隔 0.1 秒；普通换弹 3.333333 秒，空仓换弹 4.291667 秒。游戏中的改造系数仍使用现有系统。
- 改造几何开放现有全息、全景红点、2 倍棱镜、1–6 倍 LPVO，以及现有消音器/战术消音器/制退器/钛制制退器。使用 A762 独立安装位置；装镜时折叠原厂机械瞄具。弹匣、枪托、握把为原厂形态，目录未开放这些部位的外观改造。通用数值选项仍由既有枪匠系统提供。

## 模型、骨架和动作

- UE 根目录：`/Game/Weapons/A762/Integrated20260920`。
- 骨骼网格：`SK_A762_Manny`；共用项目已有的 Manny/M4 武器骨架与手臂材质。
- 高细节原始模型按机匣、弹匣、扳机、枪机、枪口件、枪托、握把、护木和前后机械瞄具分件，保留 UV 与 PBR 图集。只封闭分件新增切口。
- 弹匣、扳机、枪机分别绑定现有机械骨；机械瞄具为独立静态网格；枪口件按材质分段支持替换隐藏。
- 模型依据现有 AKM 手部基准进行比例与位置适配，工作长度约 0.912 米，为游戏适配尺度。保留 Meshy 原始细节，尚无运行性能或手指接触验收。
- 11 段独立 A762 动作：idle、aim、fire、aim_fire、inspect、equip、reload、reload_empty、sprint_enter、sprint_loop、sprint_exit。源动作来自现有 AKM/Manny 动作库，重新烘焙 A762 准星、枪口及抛壳标记位置。
- 动作来源、帧率、帧数、时长和循环记录在 `authoring.json`；导入保存记录在 `geometry_import.json`、`motion_import.json`。

## 音效

直接引用 AKM 当前资产，不复制或另建音效库：

- 开火、拔匣、插匣、就位、拉栓、释放：`/Game/Weapons/AKM/VideoAudio20260921/S_AKM_*`。
- 其余机械音保留 AKM 原有 `/Game/Weapons/AKM/Audio` 路线。
- 消音开火沿用 AKM 当前使用的 `/Game/Weapons/M4MuzzlesV1/S_M4_Suppressed`。
- 普通/空仓换弹使用 AKM 原动作时钟和插匣声偏移；装备拉栓使用 0.55/0.80 秒声音节点。

## 可编辑交付

- `A762_Rigged_Editable.blend`：完整枪体、手臂、重装配机械瞄具及 11 段 A762 动作。
- `A_A762_*.blend`：分离的动作编辑库。
- `Exports/`：骨骼网格、前后机械瞄具和 11 段动作 FBX。
- `author_a762.py`、`assemble_editable.py`：分件、绑定、动作烘焙与编辑工程装配入口。
- `import_geometry.py`、`import_motion.py`：经项目 UE 桥导入并保存资产。
- `integrate_catalog.py`：本次已执行的源代码与数据目录修改记录；不可在已修改的工程上直接重复执行。
