# A762 外观精修 01

针对用户反馈的生成模型粗糙、准星与照门堵塞进行本地精修。参考枪械 SKILL 中 QBZ191 的 SurfacePolish、Machined 与 Hero 制作记录：孔洞靠真实几何，硬边法线和结构法线分别处理，材质按部位区分。本轮保留 Meshy 母版与现有动画，不重新请求生成模型。

## 本次修改

- 重建后照门的环形通孔、内壁、支撑和护翼；重建前瞄具护圈及独立准星柱。新增孔口与细杆使用真实几何，内壁单独消光。前后瞄线中心和原折叠轴沿用已接入的坐标。
- 重建顶部连续导轨与规则齿槽，顶部安装平面保持在现有配件基准位置；替换外露枪管/导气管中段、连接环、双杆枪托中段以及枪口外观。枪口保留真正的开口和内壁。
- 机匣、护木、弹匣、握把等保留原形、原 UV0、机械分件和蒙皮。只在限定范围内规整小尺度起伏，固定开边与高夹角特征；对机匣侧面的局部大平面作有边界过渡的整理。
- 未改表面保留分裂法线差异，随局部顶点变化调整方向。新硬表面使用小倒角、38 度硬边及加权平面法线；FBX 导出平滑组与自定义法线，UE 导入法线并使用 MikkTSpace 生成切线。
- 材质分为涂层金属、钢件、聚合物、橡胶和消光内壁。保留旧结构法线完整强度与原 UV0；源颜色只作为纹样贡献，粗糙度围绕各部位独立基准变化。新增规则几何不采样无关的旧结构法线。
- 底色使用 BC7、正确 sRGB；结构法线使用专用压缩，OpenGL 到 UE 只转换一次绿色通道。枪口内壁的 SurfaceRegions.R 明确写入，外壁为 0、内壁为 1。
