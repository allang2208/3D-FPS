# A762 参考图重建 02

依据用户原始彩色侧图、灰模三分之四视图、先前整理的三个参考视角，以及本次换弹截图，重建上一版外观偏差明显的机械瞄具、残缺弹匣和枪口连接段。遵循枪械 SKILL 中 QBZ191 的处理经验：孔洞使用真实几何；新形体使用自己的 UV 和硬表面法线；保留表面不丢失原结构法线；不把旧生成贴图投到无关的新零件上。

参考图目录在上一级 `References/`；本轮问题截图保留在 `References/user_reload_defects.png`。参考图仅作为外观依据，没有按实物内部结构或制造规格重建。

## 重建内容

- **前瞄具**：移除上一版细环和楔形支柱，改为侧面有长窗的立柱、加厚通孔头罩、两侧圆形凸台、底部支座和窄准星柱。后照门改为紧凑盒形罩与内凹通孔。沿用原瞄线标记及折叠轴。
- **弹匣**：整体替换原扫描分件。完整弯曲外壳包括两侧面、前后壁、倾斜底板，以及有底的口部凹槽、口沿和托板。添加参考图中的纵向压筋和短横筋；压筋下面仍然有完整外壁。全部零件绑定原弹匣骨骼，随现有换弹动作一起移动。另补固定在机匣上的弹匣井边框。
- **前段衔接**：移除旧机匣中残留的生成前段和碎边。从护木出口到枪口安装处重建连续枪管、导气管、带浅凹槽的套管、前座连接体、箍环和肩部接头。消焰器保留开口、内壁和独立材质槽，沿用现有枪口配件显隐逻辑。
- **材质和法线**：新弹匣和前段使用独立的涂层金属、边缘金属及消光内壁材质。新增低幅度粗糙度纹理，不给这些新 UV 套用旧图集法线。硬表面使用小倒角、分裂硬边和加权法线；保留枪身的 UV0 和自定义分裂法线。UE 使用导入法线与 MikkTSpace 切线。
