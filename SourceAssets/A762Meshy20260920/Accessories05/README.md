# A762 通用配件接入

以用户认可的 Refinement04 枪身为基础，保留原有外形、骨架和 AKM 音效。未启动 PIE、自测、截图或验收渲染。

## 配件与装配

- 瞄具：全息、全景红点、2×棱镜、1–6× LPVO，保留镜片、分划、倍率环及各自光学中心。沿 A762 实际导轨冠面 Z=0.0995 m 安装，前后位置分别为 0.060、0.065、0.078、0.105 m。
- 枪口：普通消音器、战术消音器、制退器、钛金制退器。使用明确的出口轴和枪管连接面，替换原厂枪口段。
- 前握把：垂直、战术垂直、45°侧倾、棱镜阻手器、共振二代；增加护木底部的闭合连接座，沿用同骨架 AKM 已制作的整臂抓握、换弹回握和装备动作。
- 弹匣：60 发弹鼓、40 发扩容弹匣。弹鼓保持已制作的自由下落与新弹鼓抓取动作；扩容弹匣由 A762 原厂曲面连续延伸，保留完整供弹口、加强筋、侧板和底板。均以真正的 magazine bone 局部坐标绑定。
- 枪托：骨架、镂空轻型、高性能、战术伸缩；独立 A762 接口，隐藏完整原厂可替换枪托分区。
- 后握把：幻影、稳固防滑、均衡；复用相同右手接触区，补齐上部连接件。
- 战术设备：镭射、手电，附带 A762 侧座和发射器／方向挂点，继续走现有照明、遮挡、ADS 汇聚逻辑。
- 通用长短枪管数值选项由现有 common_options 自动接入，保持其既有“数值改造、不改变枪管外观”的规则。

配件采用独立 A762 材质副本，金属涂层参考当前枪身；保留原 UV、结构法线、镜片、发光、橡胶及聚合物分区。来源资产路径与材料绑定见 sources.json、authoring.json；沿用对应源资产许可证，不新增公开分发授权。

## 机械瞄具

固定底座归入枪体，可翻折部分使用独立静态网格；原旧头部不参与枪体导出。前准星向枪身后方折叠，后照门向前折叠。分别调整转轴至管件与导轨上方，避免长底座旋转后重新竖起。安装任何光学瞄具时同时收起前后机瞄，卸下时恢复。
