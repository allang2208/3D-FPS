# A762 后照门、前端缺面与 ADS 表面修订 03

本轮依据用户三张新图制作：后照门实物/游戏参考特写、圈出的前端两侧漏空，以及 ADS 时后机匣粗糙轮廓。三张输入原样保存在 `References/`。沿用现有 A762、Meshy 母版、原挂点与机械分件；参考枪械技能和 QBZ191 Hero 的局部重建、结构法线与表面涂层分离方法。

## 对应修改

1. **贴眼侧后照门**：撤去上一版大方框和顶部小柱。根据新特写改为开放的两侧护翼、独立窄照门片、圆形侧调节件、轴盖、斜坡安装鞋及低位横筋。照门保持真实通孔，孔心和折叠轴仍使用原标记。
2. **导轨前端两侧漏空**：原来的护木与机匣按区域分件，交界留下了不完整的顶缘和肋片。本轮整体替换这一段的共享扫描边界：闭合的聚合物护木包含两侧浅凹槽、底部和端面；其上覆盖连续钢制上盖及侧裙。外部肋片下面有完整表面。前颈箍按收窄后的轮廓重做，替换上一版偏宽的端板。
3. **ADS 粗糙边缘**：从导轨两侧到后机匣肩部重建连续顶盖，整理后部斜肩、两侧固定件以及枪托杆接口。新平面采用可控倒角、分裂硬边、加权法线和自己的 UV；不把旧图集法线套到新表面。保留的机匣侧面只在两块平面内作小幅规整，保留铭文、源 UV0 和结构法线。

新涂层以原 A762 金属和聚合物颜色为基础，分别设置粗糙度；没有用全枪平均法线或削弱整张结构法线来掩盖轮廓缺口。新旧表面的工艺分界落在机匣盖、护木和安装座的实际分件处。
