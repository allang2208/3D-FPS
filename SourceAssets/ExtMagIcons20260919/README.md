# 扩容弹匣图标朝向修正

本轮检查范围：M4、AKM、QBZ-191 的改造选项 `magazine/ext_mag`，以及共享回退图。现用 UI 优先读取 `武器定义ID_magazine_ext_mag.png`，按实际键缓存。

发现：三张原图从与标准图标相反的一侧拍摄，弯曲方向与各自普通弹匣相反；且仍是较早模型图。`before.jpg` 保留图标对照。

处理：

- 由各枪源骨架的前后照门及上向测量安装坐标，三维旋转当前 `ExtMagContinuity20260919` 模型，重新渲染；没有二维镜像。
- 沿用已认可配件图标的棚拍配置：前方朝左、枪械上向朝上、水平正交侧视、1024 RGBA 透明、主体约占 85%。弹匣保留实际安装时的竖向弧度。
- 保留当前源贴图，图标场景补接缝采样及切线基准换算。M4 的嵌套壳体在 Cycles 规定观察侧出现严重自遮挡，因此仅为图标副本关闭投影；不修改游戏模型、几何、法线或材质。Blender 的表面响应仍是 UE 材质的近似，不声称像素一致。
- 替换三张专属 PNG；共享 `magazine_ext_mag.png` 使用本轮 M4 图作为回退，三枪实际均走专属图。同步对应 UE Texture2D 副本。

`prepare.py` 记录真实源与安装矩阵并复用旧图标棚拍脚本；`render.py` / `materials.py` 为本轮制作入口；`Icons/*.blend` 是打包贴图的可编辑图标场景。`install.py` 保留原 PNG/UE 贴图副本，实际写入见 `install_receipt.json`。

已查看本轮三张最终图及 64 px 缩略图，见 `after.jpg`。本轮检查的是图标来源、朝向、构图与显示，不表示游戏模型获得新一轮验收。没有启动 PIE 或游戏测试，没有修改 C++，无需编译。已打开的改造界面可能需要重新进入以重建图片缓存。
