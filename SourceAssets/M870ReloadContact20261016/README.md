**已通过后台 commandlet 导入并保存普通、空仓两条动画，退出码 0。** `install_receipt.json` 记录 `completed=true`；源动画检查和实际保存分列于 `delivery.json`。

用户反馈：装填时右手与弹药分离、悬空。本历史右手装填修订入口为本目录；其余动作与左手基线仍为 `M870AKMArmSupport20261016`。

## 定位结果

旧 UC 重定向使用待机握枪姿态校准右手旋转，弹药则单独跟随 `870_shell2` 轨迹。手骨初始弯曲方向不同，迁移后的手指没有保持供体的持弹形状；两条轨迹之间也没有适配后的抓握约束。这个问题已存在于继承的装填层，上一批只修改左臂，因而保留了它。

在原生 V7 几何上检查送弹帧，旧版拇指、食指、中指与弹药表面的最近距离分别约 31.5、22.8、38.8 mm。源码入口为 `M870UrbanAnimations20261015/author_animations.py` 的 `hand_corrections`、`fingers` 与 `shell`，诊断记录为本目录 `before_contact.json`。

## 本次修改

- 继续使用已有 UC `reloadinsert.smd` 的右手持弹动作。以实际掌面、指段方向和原生骨轴迁移完整手型，保留目标骨长；没有新增自由卷指拟合。
- 对整个手掌与手指施加一份小幅刚体接触调整，记录在 `rigid_contact.json`。接触微调不改变手指关节关系。
- 持弹阶段用固定的“弹药到手腕”变换驱动右手，肩肘跟随原有动作做支撑；弹药进入装填口后，手按自身退让轨迹松开，不再追随被隐藏的弹药。
- 只输出普通、空仓两条装填序列。当前 AKM 左手、枪体、弹药轨迹、入弹帧、弹量结算及泵动尾段时钟保留。C++ 没有变更，不需要另行编译。
