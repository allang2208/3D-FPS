## 原因与采用的参考

最初的 M870 制作以 SUPER90 右手为输入，围绕食指根关节整体旋转约 -50° 适配传统枪托，但未按 M870 的真实扳机表面重新配准。原生 V7 源表面中，旧食指末节与扳机最近距离约 46.6 mm，其他三指也未包住枪托颈部。上轮重新制作的是取弹／推弹阶段，起止的旧持枪姿态仍被保留。

本批复用原始 `M870UrbanAnimations20261015/Original/870/Renmington 870 unfucked.blend` 的 `gmod_arms` / `Idle` 持枪姿态。逐骨固定绑定映射沿用 `M870ReloadSource20261016` 的原始 Blend 路线；原模型和来源记录保持不变。

## 制作

- 整手先按枪轴和参考接触配准，再根据当前 V7 指腹、枪托颈部及扳机前侧表面作有界调整。
- 关节调整只沿来源手型的屈曲轴，不追加轴向滚转；保留原生骨长、手指根部位置、蒙皮和网格。拇指对握、中／无名／小指包握枪托，食指指腹位于扳机前侧。
- 前臂与上臂沿同一原始参考支撑新的手腕位置，原生辅助站沿前臂轴线分担旋转。没有只移动指尖或单独扭腕来追接触。
- 食指按实际 `WPN_Trigger` 轨道做有限的屈曲跟随；本次作者轨道最大附加屈曲约 5.46°，其余手指维持枪托握持。
- 13 条动作同步新握姿，使用现有加载路径。普通／空仓装填只修改离枪与回握的持枪贡献，每条的 343 个活动装填采样保留原轨道；枪、弹药、入弹和闭锁时钟保留。
- 冲刺继续使用 SUPER90 枪体／左臂轨迹和 120 Hz 采样，其余动作仍为 60 Hz。快速近战的 `Super90MeleeArmAuthored` 所有权曲线继续保留。

`grip_input.json` 保存源姿态与制作几何；`grip_fit.json` 保存最终固定参数。接触数值只是制作依据，不是实机无穿模或自然度验收。没有新增渲染、截图、游戏、声音或联机测试；沿用并查看了上一轮已有的持枪近景。最终游戏观感由用户确认。
