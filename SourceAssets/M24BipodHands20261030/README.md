# M24 脚架手部与肘部修订 — 2026-10-30

针对用户反馈的部署手势、手腕及手肘问题制作。沿用 V9 原生手模，保留 0.48 秒部署、0.12–0.30 秒拉开、0.44 秒回握的机械时钟。

左手改抓近侧支腿靠近铰链的位置。减少原约 10 cm 的臂根突进，肘位在受限弯曲面内连续移动；上臂及辅助骨按原生参考铰链重建，前臂使用 V9 100%/50% 绝对扭转分站，避免在旧待机扭转上重复叠加。手腕方向与肘位联合求解。

手指以自然勾握为先，拇指只做小幅对握；逐接触关键点适配转动的支腿，食指、中指先闭合，其他手指跟随。释放阶段先松指再退手，回握恢复当前生产支撑姿势。没有改变右臂、枪根、枪械机械轨道、脚架网格或部署判定。

## 再次检查后的整链修订

用户指出上臂、前臂与腕部仍不符合人体运动。上一轮仅减少了表面翻折，不能据此认定骨骼运动合格。本轮重新比较原生参考绑定、上一轮正式压缩动画与当前实际蒙皮。

定位结果：M24 原生绑定的上臂辅助骨局部 Z 本来就与几何肘轴反向，不能直接套用 PKM 的局部 Z 判据。以本枪参考绑定校准后，肘部并没有显著轴向扭转；主要问题是掌向跟随脚架支腿转轴，造成前臂从待机先转开约 66°、再反向转回约 81°，以及锁骨和上臂辅助骨的变形框架不一致。

当前修订：
- 掌向保持接近本枪原生支撑姿势，由手指勾拉转动的支腿；求解器约束相对待机的旋前变化，不再追求绝对扭转值归零。
- 肘部绕肩腕轴的摆动限制在 ±20° 内，上臂和肘侧前臂沿本枪原生铰链联动。锁骨同步承载肩部变形，保留骨段长度。
- 接触点移到距支腿转轴约 2.5 cm 处；肩部前送减至 4.8 cm，取代此前 7.8 cm。伸手先从安装座侧面绕行，拇指提前收拢再接近支腿，避免末段闭指扫过安装座。
- 手指仅作有界屈伸及 MCP 侧摆修订，不追加指骨轴向翻转。回握恢复当前生产待机。
- 17 个动作专用局部肘部修形消除剩余细小蒙皮尖折；这是骨骼运动修正后的表面处理。没有修改原生参考表面、蒙皮权重、材质槽、枪根或右臂轨道。
