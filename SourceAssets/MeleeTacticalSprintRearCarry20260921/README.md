## 动作修改

- 保留双手与武器的固定握持矩阵、手指、骨长和原蒙皮。普通柄与长柄分别制作。
- 持握组中心从 `(0.235, 0.315, 0.075)` 调整为 `(0.235, 0.055, 0.075)` 米，即相对 V1 后移 26 cm。轴向为右、前、上；剑身继续水平前指。按项目冲刺 FOV 112° 布置护手位于右侧画缘，手和握柄收在画外；该构图尚未经过游戏画面测试。
- 肘位不再只跟随固定 pole：用当前手掌朝向对应的中性腕轴选择肘部弯曲平面，同时保留向下支撑的偏好及有限的摆肘范围。双手位置不因解算肘部而脱离握柄。
- 减少肩部抬升与上臂轴向旋转，将剩余前臂转动沿原辅助骨分配；不以手腕单独扭转实现水平剑身。
- 跑动侧摆、上下起伏和滚转缩小，配套重做进入、退出及直接下劈交接。

## 资产与时序

两套各四条动画：SprintEnter 0.20 秒、SprintLoop 76/120 秒、SprintExit 0.20 秒、SprintOverhead 源长 2.60 秒。仍为 120 Hz。攻击运行从 1.22 秒直接开始，1.31 秒接回原 V5 下劈；瞬发业务时钟、60° 判定和伤害数值不变。

`author_sprint.py`、`motion.json`、两套 `*_inputs.json` 是制作入口；两套 Blend 和完整骨轨道保存在本目录。V1 作者文件保留在 `../MeleeTacticalSprint20260921/`。`layout_inputs.py` 仅用于读取原姿态地标来确定后移构图，不是回归或验收工具。
