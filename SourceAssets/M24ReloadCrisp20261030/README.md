# M24 换弹局部节奏与空仓持枪修订 — 2026-10-30

本次针对用户要求：去除空仓换弹靠近身体的多余枪械动作，参照普通换弹，并使拔出弹匣更干脆。覆盖 5 发与 10 发弹匣的普通／空仓四个配置片段。

## 正式修改

- `DA_M24_SupportGrip`、`DA_M24_Mag10` 的 `A_M24_reload`、`A_M24_reload_empty` 增量轨道。原始 AnimSequence、M24 V9 网格、原生骨长、蒙皮、变形修正、衣物配置及其他动作保留。
- 原先空仓修订只抵消平移，源帧 55–105 仍包含最高约 76.25 度的转枪。现在空仓枪根完整变换沿用普通换弹，同步搬运右手和枪栓，保持其局部机械接触。
- 旧转枪还包含左肩／左肘的反向补偿；取消转枪后会显露上臂根部。空仓源帧 54 以后直接继承普通换弹结束的完整左臂支撑链，包括当前拇指握持修订。
- 只重排源帧 18–25.25 的拔匣动作。整条左臂、手腕、手指和弹匣按枪身坐标成组配准，不独立平移指骨。抓稳后加快直线抽出，再连续衔接松指／甩匣；直线拔出部分基础播放时长约 0.3384 → 0.2087 秒。
- 源帧 21 的拔匣接触、25.25 的释放，以及 29–30 的额外约 0.5 秒取新匣间隔保留。插匣、压实、右手拉栓、业务事件和音效时钟保留；普通总长 4.7 秒、空仓约 6.3667 秒（属性倍率前）。
