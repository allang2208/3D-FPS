# 裂空 · 双尖轮廓蓝白剑气 V4 与刃部扰动

用户当前指定：史诗后缀、剑类专用，蓄满重击释放一道中间宽厚、两端收尖的蓝白剑气。只借用裂隙的轮廓，保留剑气的能量填充、流动和柔边，不能做成真正的空间裂口。射程 12 m、该次重击 100% 伤害、穿透敌人、遇墙消散。月牙轮廓以及 V3 暗心裂边的质感均已被用户否决。

早期原型曾参考 [Sword Slash VFX 的公开产品介绍](https://www.fab.com/listings/da79a45e-0716-429c-bc46-4704fc125d31) 的挥砍特效类别；当前按用户指定的双尖轮廓和剑气质感制作。没有下载、复制或使用该商品的网格、贴图、材质、Niagara 图或音效。

本目录的 OBJ 与 HLSL 由 FPSGAME 独立制作。剑气面沿 YZ 平面展开，+X 飞行；128 × 8 网格片，共 2,048 三角形。长 176 cm，中间约 38 cm 厚，两头逐渐收尖，轮廓平顺。蓝白能量填充主体，细流纹沿长轴运动，外侧呈饱和蓝色并宽范围羽化淡出；没有暗色空洞、空间撕裂边或闭合亮描边。两个材质实例分别表现主体和淡蓝能量尾雾。程序材质无需第三方纹理。

`rift_blade.hlsl` 与 `SM_RiftBladeRibbon.obj` 为刃部空间扰动：沿 X 轴 9–92 cm 的开放螺旋带，共 1,152 三角形；运行期按真实刃长缩放，用两份错位旋转与移动的双流纹表现折射。V3 中央宽度 6.8 cm、基准半径 6.2 cm，径向波动、两端收窄；折射参数 0.075，并避免主体法线被低透明遮罩重复压弱。边界依然柔和归零，强化的蓝紫流纹帮助识别运动，不增设动态灯。实际挂接真实剑组件或 WPN_root 骨骼，随动作、检视和镜头移动。

`Tools/Skills/build_rift_slash.py` 从引擎自带 SimpleSpriteBurst 模板建立 Niagara 生命周期，重新指定全部粒子外观、生成位置、数量、运动和材质。模板属于 Unreal Engine 随附内容，遵循项目现有 Unreal Engine 许可；非第三方商品素材。
