# M4 普通弯弹匣：动画与音效审计（2026-09-10）

本次保留 M4 模型，检查普通换弹、空仓换弹和装备拉栓。实际运行资源为 `/Game/Weapons/M4AnimationAuditFinal/` 的三段动作和两段重排音效；待机、瞄准、开火仍使用此前的匹配手位。弹鼓分支没有改动。

## 发现并修正

1. **插匣机械关系错误**：旧普通换弹在插入音触发时，弹匣仍离最终位置约 249 mm；空仓锁定音触发时还差约 30 mm，而且之后仍继续移动。现在先对正插槽、开始插入，再压到底锁定；锁定后弹匣保持完全固定。模型测量显示，开始插入时弹匣顶部距机匣接触面约 0.12 mm。
2. **不自然的手臂和弹匣路径**：去掉空仓换弹前段左手异常上甩；旧弹匣改为向下退出，新弹匣从画面下方接入。抓取过渡跟随当帧弹匣，不再朝后面的关键帧位置硬插值。
3. **帧间握持抖动**：枪、弹匣和手腕改在同一个枪械坐标系内约束，480 Hz 烘焙，并在 960 Hz 检查 UE 压缩后的实际姿态。持枪手最大偏移约 0.37 mm，插匣握持约 0.30 mm，拉机柄接触段约 0.02 mm。前臂、腕部骨段长度变化小于 0.016 mm。
4. **拉栓穿模**：原右手会穿过机匣和枪托。现在先从外侧离开握把，绕开枪托接触拉机柄、随柄后拉，然后向外撤回；拇指增加少量收拢。全过程 120 Hz 检查，活动右手与机匣、枪托未检出三角面交叉。
5. **空仓最后拍击**：保留已有快速拍击与枪体受力反应。止动件不再提前回位，枪机在接触后约 33 ms 内复进。拍击接近峰值约 1.93 m/s；保留轻微手套接触压入，不宣称整个模型完全零交叉。
6. **普通换弹枪托挡镜头**：实机回放发现中段还有多余的翻枪。去掉这个关键姿态，让枪保持在拔匣与插匣之间的角度，已用实际画面前后比较。
7. **音效与动作错位**：装备音的拉动声原来早于手指接触，释放声偏晚；空仓释放音的主冲击也偏迟。重新剪接原 HK416 片段，保留原音高，按后拉与复进时刻安排。开火、取匣、插入及锁定音保留原素材。
