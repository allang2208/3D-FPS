## 动作合同

| 时间 | 动作 |
| --- | --- |
| 0.00～0.25 秒 | 长指先张开，重心开始下沉，手指动作领先于肩臂 |
| 0.12～0.86 秒 | 双脚承重，躯干反向预旋，右臂抬到侧前方蓄力 |
| 0.86～0.98 秒 | 短暂蓄势，给玩家辨认攻击方向的时间 |
| 0.98～1.30 秒 | 躯干先发力，巨臂从右侧快速扫过正面，手指向内钩拢 |
| 1.30～1.48 秒 | 巨臂随挥，背囊和排热管延迟摆动 |
| 1.48～2.60 秒 | 缓慢拖臂收回、抬起重心，恢复待机/移动 |

总长 2.6 秒，60 FPS；使用非线性阶段曲线。双脚使用原腿链的支撑解算，右臂按肩/肘/腕实际骨长求解，不伸长骨骼来放大范围。起手后保持角色朝向，攻击中不追着玩家转身；近身未攻击时，原转身系统可朝向目标。
