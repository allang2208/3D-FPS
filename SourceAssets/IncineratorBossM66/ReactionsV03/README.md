## 动作

| 片段 | 长度 | 用途 |
| --- | --- | --- |
| HitFront / HitRight / HitBack / HitLeft | 各 0.85 秒 | 四方向受击，双脚支撑，躯干先受力、巨臂与背部组织迟滞跟随；运行时按实际硬直期限重采样 |
| Stun | 2.8 秒循环 | 明确眩晕时站立摇晃，重复眩晕延长期限，保持循环相位 |
| Airborne | 1.1 秒 | 前 0.3 秒收腿受冲击，后 0.8 秒用于空中循环；实际抛物线由角色移动组件计算 |
| Landing | 0.9 秒 | 实际落地事件触发，受力压缩后倒向侧后方 |
| GetUp | 3.2 秒 | 等控制期限结束后，巨臂支撑、抬髋，再恢复站立与导航 |
| Death | 2.3 秒 | 膝部失力、躯体倾倒；站立死亡在 0.9 秒交给尸体物理，物理预算不足时播完整段并冻结 |

制作文件：`author_reactions.py`、`Authoring/M66_reactions_v03.blend`、`Export/A_M66_*_V03.fbx`。60 FPS，原地动画，容器根骨保留导入单位，倒地与起身使用子根骨完成身体位移。倒地制作时根据蒙皮后表面确定地面接触高度。

## 接入规则

- 现有 F6 稳定 ID `IncineratorBossM66Rig`、蓝图 `/Game/Monsters/IncineratorBossM66/BP_M66RigPreview` 保留；显示名为“焚骸 M-66（受击·死亡）”。
- `M66IncineratorMonster` 开启伤害结算，沿用公共防御、韧性与首领分类；基础生命 6000、等级 12，再受现有全局生命倍率影响。攻击招式与正式遭遇未在本阶段制作，经验配置为 0。
- 普通命中沿用公共韧性规则；破韧进入硬直，技能眩晕单独计时。击飞/击倒沿用公共可受控条件，不绕过首领韧性。
- 服务器拥有生命值和反应状态，复制阶段、序号、方向及服务器开始/结束时间。客户端从同一时间轴采样，避免重复计算伤害与落地状态。
- 原生动画图负责移动与受击过渡，公共受击逻辑不会调用单动画播放器覆盖 M66 动画实例；击飞/倒地/起身/死亡期间停用脚底地形修正。
- 空中或倒地死亡直接从当前姿势交给物理，不先采样站立死亡第一帧。各端尸体物理属于本地表现，最终骨骼姿势不做逐骨网络复制。
- 新建 `ReactionsV03/PA_M66_Reactions_V03`，按蒙皮区域制作躯干、巨臂、小臂、双腿、背部和排热管碰撞体及受限关节，单独用于当前角色。原导入 PhysicsAsset 保留。
- 尸体复用共享物理预算、稳定后冻结与 25 秒 Actor 回收，不增加永久活动尸体。
