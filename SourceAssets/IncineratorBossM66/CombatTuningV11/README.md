90 与两只现有大型领主的单次近战同档，是防御/格挡减免前的伤害，不另叠加阶级乘数。M66 当前 Rank=Boss、等级、生命、奖励不随本次“参考领主攻击数值”而改动。

正式接触采样在 1.00–1.35 s，完整动作 2.6 s，因此一轮结束后至少 1.0 s 才能再次起手。3.5 m 是起手上限，仍需通过既有真实轨迹可达判定；攻击中继续沿手掌/手指采样扫掠，并非整个半径内自动伤害。基于已有动作采样，正前方接触处手部约在 2.5–3.1 m，停步设为 2.7 m，判定半径补足掌面厚度。
