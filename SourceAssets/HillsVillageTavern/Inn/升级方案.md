# 丘陵村庄三层酒馆

[场地与楼层平面生成源](draw_plan.py)

酒馆沿用 StoneCourtR2 的外壳、石墙贴图和屋顶。三层依次承担营业、住宿和店主生活。酒馆正门朝主街，前庭西面保留三个马位，原菜圃改作碎石草坡，沿斜向的夯土小径通往院巷与马位。

| 区域 | NativeDiningWallsR5 布局 |
|---|---|
| 主街与前庭 | 拆除来路上的 18 段旧残墙。从主街至门前铺设压实泥路，路面随前庭展开至约 5.6 米，再向门槛收窄。浅车辙间留有低路拱，碎石集中在路肩。 |
| 一层大厅 | 四组餐桌及十一张凳子设在大厅。柜台连同老板娘向后移 2.76 米，身后留出取酒和去厨房的通道。 |
| 一层厨房 | 沿用原灶口和烟道。后场设备餐台、洗涤台、干燥架和储藏架。后厨西面设员工门，餐点经面向大厅的传菜窗递出。主上菜台宽 1.64 米、深 0.77 米，保留 1.01 米台高。厨房灰泥按灶边、墙脚和传菜口分别处理烟垢、擦痕与溅污。 |
| 二层 | 西侧楼梯和回廊接入东西向中央过道。过道两侧各有两间客房，每间配床、桌凳和带盖箱。前后排错开隔墙和房门，客房占用扩建后的整个进深。房内窗墙、双面隔墙和中廊直接沿用一楼餐厅的 Normandy 石墙、门洞及窗洞原件和材质。 |
| 三层 | 楼梯平台直接通起居厅。临街窗旁为账桌，厅东用靠背长椅、餐桌和活动凳围出用餐区。后东角为独立卧室，卧室门从厅内开启。梳洗桌和拱顶壁镜沿卧室西墙布置，衣柜、床尾箱和床分置两侧。 |
| 结构 | 两段 1.60 米宽的木梯分别升至 3.40 米和 6.42 米。楼上外墙沿用一楼灰石与灰缝。二、三层起居空间和客房隔墙共用一楼餐厅石面与灰缝。传菜隔墙采用木作与旧灰泥。 |

### 三楼空间与饰面

卧室内净尺寸约 5.2 × 5.1 米，低坡屋顶下增加木板内顶。楼梯外保留连续过道。柜门、镜框和靠背长椅用橡木制作，镜框内圈和柜门拉手用黄铜。参考 Warhorse 环境美术师公开的木作与座椅作品，收小装饰尺度以符合村庄酒馆。

本次修复后的酒馆含 37 处外窗及两处传菜口。破损状态额外保留两扇底层后窗，沿用同一套改良窗棂。主窗梃贯通，横棂左右分段，原窗洞与窗框之间留安装余量。厨房两块台面各自独立承托。

### 楼上原生石墙

整段实墙采用餐厅原件 `SM_H_OldWall_00A`。窄墙垛及门窗边从同一套一楼墙件裁接，按放置组件的实际材质槽保留石面、灰缝和洞口边石。二楼客房及中廊、三楼起居厅及卧室和外立面均使用这套墙面。木梁、木门、窗框和卧室内顶继续使用原木作。
