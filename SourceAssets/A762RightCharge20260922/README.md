# A762 空仓换弹：右手拉栓优化

接续 A762EmptySupport20260922 的左手托枪版本。用户指出右手扭曲，要求参考其他枪械拉栓动作后优化。本次只修改基础、斜握把、垂直握把、棱镜阻手器、45°握把五套空仓动作的右臂和右手旋转；普通／扩容弹匣共用这些动作。

## 参考与问题

实际查看 ASH12RightEdgeCharge20260919 的侧面拉栓，以及 M4WrapGrip20260910 中 M4_MAT_equip_charge 的作者姿态。前者在 2.34–2.60 秒侧面接触拉柄；后者为 0–38 帧、60 Hz 的后方横柄动作，也是 M16 当前拉柄动作的参考来源。仅借鉴原生骨段配合和成组手型，按照 A762 的枪身翻转与实际侧柄位置适配。

原 A762 接触阶段的腕部折弯诊断约为 51–67°，松手早段第 350 帧约为 103°；其右手食指仍使用之前统一保持的握枪弯曲，未跟随其余手指进入拉柄姿态。上述角度是原生前臂方向与手骨朝向之间的制作指标，不是人体关节角度测量。

## 修改

- 使用 ASH-12 的完整右手指组，按 A762 实际侧柄调整整手方向和接触点；食指勾柄，其余手指自然收拢，不把五指挤到小柄上。
- 联动上臂、肘部与前臂，保持原生骨长、局部平移、缩放、rest 和蒙皮权重。完整前臂与辅助扭转骨共同转向，减轻袖口拧缩。
- 第 270–310 帧进入拉柄姿态，第 310–344 帧跟随原有枪机行程，第 344–354 帧向外松手，第 354–402 帧平滑回握。枪机仍在 314–320 帧后拉、344–350 帧复进，行程约 74.6 mm。
- 左手托枪、此前抓匣及食指避让、枪根、枪机、弹匣、音效与补弹时钟不变。总时长仍为 515/120 秒。AKM、非空仓换弹、独立弹鼓动作未修改。

## 文件与接入

- sources.json：通过现有编辑器读取的五条实际加载资产和此前作者源。
- reference_poses.json、Diagnosis/：本次问题排查所用的源姿态和局部模型图，非游戏画面。
- fit_contact.py、fitted_contact.json：成组手型适配枪身与移动枪机的局部包络。接触帧食指至实际枪机网格最近距离约 1.0 mm；此为源模型采样，不作为全动作或实机无穿模保证。
- author_charge.py、authoring.json：五套可编辑 Blend／FBX 及编辑窗口；仅替换指定右臂、手指旋转曲线。
- authored_pose_diagnosis.json：源动作采样及修改范围记录。接触段采样的腕部折弯约 14–26°。
- import_receipt.json：最终导入保存回执。通过项目 MCP 桥批次互斥更新原运行路径；Before/ 保留本轮最初的五个动画包，包含此前左手托枪修改。
