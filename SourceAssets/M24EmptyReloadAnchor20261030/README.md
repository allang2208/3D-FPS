# M24 空仓换弹取消收枪位移

2026-10-30 用户要求去掉空仓换弹时把枪靠近身体的位移动作。

当前运行时已经排除 M4 动作展示偏移。读取现用两套 M24 Profile 和原生动画后，定位到源帧 55–75 的整枪收回：枪根相机前向位置从 31.69 cm 到约 17.00 cm，随后再次前送。它位于插匣完成后的拉栓段，不是换弹镜头反馈。

本次在现用 `DA_M24_SupportGrip` 与 `DA_M24_Mag10` 的空仓换弹条目中添加/修订 `VM_Root` 平移差量。源帧 55–105 的枪根位置保持在第 55 帧位置，枪械、双手和手臂通过共同根节点同步移除收枪/前送位移。旋转、手指局部抓握、关节长度、枪栓相对行程及其他局部轨道保留，边界回到零补偿。

- 只覆盖 5 发和 10 发弹匣的空仓换弹。
- 普通换弹、开火、装备、战术冲刺和近战条目保持。
- 换匣后的 0.5 秒间隔、拉栓时钟、弹药提交、音效和镜头反馈保持。
- 使用现有 Profile 消费入口，无 C++ 修改或 DLL 构建需求，无骨骼模型重导。

`before.json` 是从当前编辑器读取的制作输入；`source_motion.json` 记录用于定位的源曲线；`author.py` 生成 `translation_patch.json`，`install.py` 只合并目标条目的一条平移轨道并实际保存。`Backups/` 保留修改前的 Profile。交付状态以 `install_receipt.json` 为准。

使用现有 UE MCP 批次互斥完成保存，未启动编辑器、游戏、预览或回归测试。实机效果由用户体验。
