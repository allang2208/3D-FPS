# M4 写实裸手与连续裸臂候选

制作日期：2026-09-24。状态为单枪候选，未运行游戏或视觉验收，不代表全武器兼容完成。

## 使用

需要通过装备切回旧手模时，在 F6「服装与手套」领取并穿戴「原版战术手套」（`ue_original_gloves`）。它恢复原版整套手臂和衣袖；卸下后回到当前默认外观。新增物品目录在下一次进入游玩时加载。

1. 正常打开项目并持有 M4，卸下本套新增的上衣和手套。
2. M4 裸手候选已设为默认启用，无需输入命令；`Config/DefaultEngine.ini` 的 `[ConsoleVariables]` 持久化 `fps.Outfit.BareArmsCandidate=1`。
3. 输入 `fps.Outfit.BareArmsCandidate 0`，恢复原 M4 手臂和手套。

初次交付时开关为 0；用户反馈测试仍显示手套后，项目默认已改为 1，并应用到当前运行的编辑器。该开关不写入玩家存档。只影响本地玩家 M4 第一人称视模；第三人称身体、其他枪械和近战武器不会启用本候选。穿戴已有模块化上衣/手套时仍使用原装备配方，本候选尚未制作配套装备覆盖区。

`native_bare_hands_default` 继续关闭；未穿戴本套装备时，M4 使用本候选，其他武器保留原手模。旧 NativeSkin 与 SmoothWristV3 是此前迭代记录，不是本候选；不要重新开启全局替换。

## 本轮制作

- 使用 MakeHuman core 的连续手指、手掌、腕、前臂及上臂表面；不拼接原有袖口或衣服褶皱。上臂近端作封口。
- 沿用 M4 原生骨骼、参考姿态和逆绑定矩阵，在其独立网格副本中写入新表面。原武器与动画资产保持原状。
- 指节按骨段长度拟合，横向厚度单独处理；四根掌骨保留独立映射。手臂部分继承原生扭转骨权重，避免把全部旋转压在腕部一处。
- 一次细分补充关节表面，LOD0 约 3.37 万三角面；LOD1/2 制作比例为 50% / 20%，不代表性能测试结果。
- 官方 CC0 2K 肤色贴图、独立次表面散射材质、可调肤色与粗糙度、经导数过滤的程序化微法线。微法线是本地制作的细节，不是扫描法线；贴图源为整个人体图集，第一人称极近距离精度仍需用户判断。

## 文件

- `M4_RealisticBareArms_Candidate.blend`：包含贴图、表面权重和用于编辑的原生参考骨架。
- `M4_skin.json`：UE 厘米坐标下的表面、UV、法线和权重。
- `Donor/provenance.json`：官方来源、许可链接和下载记录。
- `saved.json`：仅在 UE 资产保存完成后生成的回执。
- UE 资产目录：`/Game/Characters/ModularOutfit20260924/RealisticM4Candidate`。

制作脚本为 `Tools/ModularOutfit/author_realistic_m4.py`，导入脚本为 `import_realistic_m4.py`。Blender 参考骨架用于编辑，不作为 UE FBX 重导入骨架；导入仍以原 M4 参考骨架为准。
