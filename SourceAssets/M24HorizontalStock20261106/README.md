# M24 碳纤维后托水平衔接

本轮按用户认可的 `M24NaturalStockRail20261106` 衔接形态制作水平版。原始后托仍是 `Meshy_AI_Carbon_Stock_1105135808_texture.glb`。

- 后托整体俯仰由下倾 4° 改为 0°，纵轴与枪身源坐标的 Y 轴平行。
- 枪身尾部切面由 Y=-18 mm 前移到 Y=0；额外截短 18 mm，后托圆接头同步前移 18 mm。
- 继续使用上一版 25 mm 连续承接面，由新枪身截面连接原模型圆形接头，保持两端相切的设计。
- 后托主体保持刚体定位、原比例和原 UV/角点法线。碳纤维仍绑定原 Meshy 材质，金属接头绑定相应机匣材质。
- 原厂与先进机匣版本覆盖原有两项 `CarbonSpine20261104/Meshes/SM_M24_CarbonSpine_*` 资产。仅涉及这两项资产；不需修改 C++。

可编辑源为 `M24_HorizontalStock.blend`，FBX 在 `Exports/`，发布回执为 `saved.json`。本轮之前已保存的资产备份在 `Before/`；用户认可的上一版可编辑源保留在 `../M24NaturalStockRail20261106/`。

制作阶段未运行游戏、未追加验收渲染。
