# M16 护拳腕掌权重分区

本轮读取现有 M4 V7 canonical、M16 共用腕部重新绑定生产、已保存包回执及当前撞门完整姿态。当前护拳中 `hand_l` 和两根前臂 helper 的局部旋转均与参考一致；腕部不需要再补偿一次旋转。源表面存在另一处问题：`thumb_01_l` 权重包络伸到腕点后约 4.08 cm，护拳拇指根部原局部转动 128.35 度会牵拉这一段掌根和腕部。此前只改绑定没有修正这个权重分区。

这次仅重分腕点近端的拇指权重。以 canonical 手掌纵轴和真实拇指根部位置分区：腕点后 0.5 cm 及更近端的皮肤不受拇指独立运动；到拇指根部 1.992 cm 平滑恢复原权重。移除的份额交回 `hand_l`，其余前臂 helper、掌骨、四指权重和所有非受影响顶点保持原值。拇指根部及远端顶点不改。没有移动、缩放、平滑几何，没有更改 UV、材质、原生参考骨架或已有动画。

作者数据已落盘：9 个现有 M16 网格的稀疏权重补丁（每个裸手 449 个顶点；不同细化装备按其原顶点数独立制作），以及可编辑裸手 JSON。野外毛衣不含拇指权重，本轮不改。锁子甲袖口含来自裸手的拇指溢出权重，一并只改对应权重分区，表面和厚度不动。

统一接入入口是 `install_wrist_weight_partition.py`；通过现有序列化 UE 桥或者后台 commandlet 执行。它复用原有源 LOD 顶点索引，以包哈希、当前顶点/权重作编辑前置条件，每个实际保存包立即记录 `installed.json`。编辑前保存包备份，保留既有 LOD 策略并从修改后的源权重重新生成已有伴随 LOD。未执行 UE 导入、运行测试、渲染或截图。

`save_editable.py` 已由现有后台 Blender 可执行文件执行，独立腕掌权重 Blend 源已保存。根任务也已通过后台 commandlet 实际保存上述 9 个 UE 包；逐包结果位于 `installed.json`，完整动作与构建状态见上级 `integration-completion.json`。拇指姿态本身由独立的动作作者处理，本目录不改 C++ 或公共动作表。未运行游戏测试或渲染。
