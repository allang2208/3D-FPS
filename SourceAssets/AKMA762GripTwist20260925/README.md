# AKM / A762 换弹左手拇指扭曲修复（2026-09-25）

用户反馈 A762 与 AKM 换弹时抓握弹匣的手有扭曲。按 SVD 换弹的同类经验排查，定位为**拇指根部的轴向滚转**（`thumb_01_l` 绕自身长轴 67°），只重做拇指三条旋转轨道；未启动游戏、未跑 PIE，观感由用户实机判读。

结论、量测表与根因见 [AKM / A762 换弹拇指扭曲](../../Docs/Weapons/akm-a762-reload-thumb-twist-20260925.md)。

## 根因

抓握手型来自 `SourceAssets/RifleMagazineGrip20260922` 的成组拟合。为了把指腹凑到弹匣，拟合把拇指根部的轴向滚转也当自由量，`thumb_01_l` 因此绕自身长轴扭了 67°，拇指翻成平贴在前面的板状。四指与腕臂本身正常（四指角度在 V4 后已逐指不同，手腕弯曲与认可的 M4 同级）。

## 做法

1. **量每根指骨绕自身轴的扭转**（局部旋转做 swing/twist 分解），不只看指尖到壳面的距离——"位置对了但翻了"只有这一步能看出来。
2. **只改拇指三条轨道**：根部限定纯 swing（按掌面语义轴两自由度摆动后，投影掉绕拇指轴的扭转），后两节轻屈；AKM 与 A762 各拟合一组参数。掌面、四指、腕、前臂、弹匣轨道、右手、枪根、机械与音效时钟不动。
3. 进出窗口沿用原动作（20→44 闭指、保持到 237、237→250 回到 clip 自身轨道），时序不变。
4. 30 条运行动画重导（AKM 5 握把 × 普通/扩容 × 普通/空仓 = 20；A762 5 握把 × 普通/空仓 = 10），导入前逐条备份。

**核对当前实际加载**要用 `RifleMagazineGrip20260922/IndexClearanceV4/sources.json` 的 asset→blend 映射：该目录根下的 `selected_grasp.json` 与 `AKM/`、`A762/` 子目录是早期版本，不是运行来源。
