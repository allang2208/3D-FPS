## 结算

当前持握唐刀且安装祥云符文时生效。沿用 `ColdSteelMelee::EquippedModifiers` 读取实际激活装备的改造，不读取背包中的唐刀，也不以固定15点替代最大体力占比。

目标真实死亡时通过 `ColdSteelSkills::NotifyKillByOwner` 定位击杀者，进入其档案的 `ApplyKillStaminaRecovery`；通常击杀奖励入口 `AwardKill` 也接同一函数。六种怪物基础死亡入口及角色健康组件均已接入，包括这些基础怪物的派生类。经验/金币结算保留原规则；无经验的召唤小手等目标同样通知体力恢复。按玩家归属结算，近战、魔法、技能、持续伤害均可触发，不附加目标种类或经验奖励条件。

每个目标用原生弱引用去重，过期引用在下一次击杀通知时释放；同一死亡的直接通知、经验回执和火球延后结算共享去重结果。恢复上限为当前最大体力；普通自然恢复等待不变。体力达到既有奔跑重启阈值时清除耗尽状态，通过 `OnStaminaChanged` 更新 HUD。瞬时恢复留在实时档案，沿用正常自动存档，不增加逐杀写盘、额外 Tick 或定时器，不修改用户存档文件。

最大体力100时回复15点；最大体力120时回复18点。满体力时仍保持满值。
