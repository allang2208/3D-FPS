# 唐刀专属：祥云符文

改造界面路径：唐刀 → 剑身Ⅱ → 祥云符文。内部 ID：`auspicious_cloud_rune`，仅兼容 `ue_tang_dao`，卡片沿用已批准的限定金色样式。

靠近护手的卷云主印向刀尖收成错落流云。淡金云纹保留轮廓，玉青流光由护手向刀尖缓慢游走，亮度与覆盖率平滑呼吸。纹样直接在现有不透明刀身材质中发光，不增加贴面透明层。

| 效果 | 倍率 |
| --- | --- |
| 攻击速度 +10% | `attack_speed_mult = 1.10` |
| 攻击耐力消耗 -15% | `stamina_mult = 0.85` |
| 击杀任何目标后，恢复最大体力值的15% | `kill_stamina_max_ratio = 0.15` |
| 攻击韧性伤害 -10% | `toughness_damage_mult = 0.90` |

效果在装备期间生效，按现有改造乘法规则与刀刃、护手、握柄及配重锤效果叠加；替换或卸下符文后恢复。界面效果说明与结算使用同一组数值。
