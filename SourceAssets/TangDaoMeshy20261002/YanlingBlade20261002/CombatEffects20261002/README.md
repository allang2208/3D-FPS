# 破锋燕翎刀身：连段竖劈改造

用户于 2026-10-02 确定以下效果，适用于唐刀 `ue_tang_dao` 的 `blade_1/yanling_edge`。

| 效果 | 配置 |
| --- | --- |
| 第三段攻击伤害 | `combo_third_damage_mult = 1.40` |
| 第三段动作 | 复用当前握柄对应的冲刺下劈 `Overhead` |
| 第三段命中区域 | 玩家前方矩形，宽 90 cm；长度沿用原第三段攻击距离 |
| 第三段前踏 | 与突刺一致，1 m；原始动作时钟内 0.24 秒，随攻速缩放 |
| 攻击耐力消耗 | `stamina_mult = 1.10` |
| 格挡减伤倍率 | `block_reduction_mult = 0.90` |

按用户“调整为”的要求，第三段竖劈取代原参考方案的第二段横斩伤害 +15%；本刀身不再提供第二段加成。没有增加此前参考方案中的第三段削韧加成。格挡是原减伤比例乘 0.90，不是减去 10 个百分点。伤害倍率与其他已安装改造件按原有规则相乘。

`catalog_extension.py` 同时维护正式改造效果与模块行的 `combo_third_attack = sprint_overhead_rectangle`；父级目录重装继续复用这个扩展。安装选项不会变更物品 ID、实例或存档结构，卸下本刀身后恢复原装第三段突刺。

`ColdSteelModularSword::UsesOverheadFinisher` 使用当前模块目录缓存识别正式装备或改造草案。在 `StartSwing` 输入 `Thrust` 时先固定第三段连击身份，再替换为 `Overhead`。使用冲刺释放的 0.25 秒前摇：从动画原始 0.97 秒进入，保留 1.22–1.40 秒接触窗及 2.60 秒原动画结束点；当前基础攻速下该段动作耗时为 1.63 秒，随现有攻速一起缩放。握柄自己的动画目录、持柄过渡、音效、竖直裂隙和镜头反馈继续复用。

第三段作为普通连击触发，沿用一次普通攻击体力扣除与连段排队。用户随后要求与突刺一致的前进效果，因此追加复用 `RuneSwordThrustRhythm::LungeDistance` 的 1 m 真实前踏及同一 SmoothStep 曲线，跨步时长仍为 0.24 秒。将突刺的前踏时钟按接触点平移到竖劈原始时钟 1.14–1.38 秒，前踏、动作和接触窗统一随攻速缩放。地面支持、障碍扫掠、方向锁定及中断规则共用 `AdvanceThrustLunge` / `ApplyMeleeLungeStep`，矩形查询与竖直裂隙跟随实际角色位移。没有触发冲刺技能的就绪、技能倍率、冲刺技能消耗或修炼。客户端攻击语义仍为第 3 段，现有服务器同参复算继续读第三段伤害倍率。

接触窗内每帧一次定向盒体查询：以玩家位置为矩形后边中点，按稳定瞄准朝向的水平投影定向，高度沿用角色胶囊高度。该段替换原剑刃扫掠和低位扇区补判，保留墙体遮挡、尸体过滤与同挥击 `HitActors` 去重。矩形内允许多个目标受到这次竖劈打击；没有扩大其他连段或冲刺技能的区域。宽度常量位于 `RuneSwordOverheadRhythm::FinisherRectangleHalfWidthCM`。

第三人称动作同步复用 `DashOverhead` 视觉变体，第一人称仍使用当前认可的 Overhead 动画。面板比较、选中改造详情及物品提示显示第三段竖劈名称和对应耗时，伤害、耐力与格挡读同一份改造数据。没有新增反射字段、改变组件或现有统计结构的布局，没有改武器模型或符文材质。
