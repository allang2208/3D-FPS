# 破锋燕翎配重锤：八面锥修订 V3

按用户两张参考重建：宽端在连接环一侧，八个平直三角折面直接收向单一尖端；头部基准半径 35.6 mm，锥体从本地 Z −55 mm 延伸至 −163 mm。

连续折线鎏金框采用闭合、带倒角的 2.9 mm 宽甲框。后部小型龙云浮雕高度 0.14–0.27 mm，细鳞纹／刀刻由同源法线补充，前段为裸露水波锻钢。连接环与握柄座的云纹按周长 UV 展开，避免此前世界坐标图案拉伸和波纹干扰。

材质槽为 Steel、Gilt、Lacquer。钢使用中等强度金属反射色与 0.335 左右粗糙度；鎏金为暖色反射、细微旧化和约 0.265 的粗糙度；漆面金属度为 0。钢／金 4096 PBR，漆面 512 PBR。
