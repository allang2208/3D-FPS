# 唐刀专属改造：凤仪华羽护手

`ue_tang_dao / guard / phoenix_feather`。沿用璇云龙璧护手的双面实体浮雕、厚壁贯通镂空和真实安装端制作方式，按本次用户参考重做凤羽外形、凤首、卷云及红石嵌饰。

护手板面约 13.4 × 17.8 cm，承力板厚 8 mm，正面浮雕最高 3.1 mm，背面同源纹饰稍降低高度。羽脊、凤首与卷云形成真实高低层次；细小羽毛刀刻和磨损进入法线与粗糙度。镂空有封闭内壁，不以透明贴图代替孔洞。

两处红石在正反面各有独立封闭曲面和实体鎏金托座，采用非金属材质；雕纹、凸面和暗铜凹底使用独立 4K 鎏金 PBR。纹饰沿 X 偏移 2 cm，将主嵌饰置于刀身安装圈外侧，中央承力芯仍保持实际挂点。前端 Z=14 mm、后端 Z=−50 mm 的 123 / 215 顶点安装环沿用原件，不修改握持、刀身或手臂。

## 制作入口

`prepare_author.py` 复用上一款护手的封闭几何与端面作者方法；`surface_recipe.py` 生成高度、PBR 和石件位置；`author_guard.py` 导出 Blender、FBX 三档 LOD 与 GLB；`render_menu_icon.py` 以当前实际模型生成灰阶图标素材，再用 imagegen 沿用认可金属框。

`prepare_integration.py` 将本扩展加入基础唐刀和 SurfaceV2 的后续重导入流程；祥云符文仍最后处理。`catalog_extension.py` 只合并本护手 ID、材质与选项，保留原厂、璇云龙璧护手、刀身、符文及配重锤。`import_background.ps1` 实际导入并保存网格、材质、纹理、旋风响应副本和 UE 图标，再发布选项。编辑器存在时使用现有桥的批次互斥，否则使用后台 commandlet。

限定金色卡片身份已加入 `M4GunsmithLayout.cpp` 的唐刀专属护手列表；`build_background.ps1` 等待正在执行的原生构建结束后，串行编译 Editor / Game，不自动打开 UE 或运行游戏。制作源、构建产物、资产保存状态分别记录在回执中。

本次只制作外观，未将参考图标注自动换成战斗数值。隐藏背面的纹饰和石件布局依据可见参考推断。未主动运行游戏、测试或验收渲染；独立灰阶渲染仅用于图标制作。完成状态以 `delivery.json` 为准，由用户测试持握与改造预览。
