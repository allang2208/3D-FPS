# 腾云游龙刀身：平整刀面与统一厚度

用户反馈 SolidV3 的刀根扭曲、不平整，要求关注整把刀的线条并保持相同厚度。该版本把原装不规则厚刀根按周长匹配到薄刀身，再沿 z=1.401–4.5 cm 插值收肩；虽为封闭网格，这段截面与角点对应仍使刀面鼓起、扭转。

SolidV4 完全删除原装刀根几何，以固定 X/Y 截面直接制作整个刀身。两侧主体刀面为平行平面，厚度统一 7 mm，根部轮廓用保持单调的曲线连接到原有弧形刀身，避免旧插值产生的腰部与鼓包。刀根 z=1.34 cm，嵌入现有护手 z=1.4 cm 安装面 0.6 mm，底面封闭；没有可见的过渡套段。刃口与刀背保留倒角、长导槽保留 0.70 mm 实体深度，刀尖仅最后 2 mm 收锋，取消长段减薄。龙纹浮雕、锻钢与流云继续由现有 4K 颜色／法线／ORM 表现，不让微浮雕改变主刀面厚度。

父目录作者入口改为 `author_planar_blade.py`，制作可编辑 Blend、三档 LOD FBX 和 LOD0 GLB。平滑面先设置，再写各刀面／倒角独立的自定义角点法线；两侧主刀面法线保持一致，倒角保留自己的明暗边界。源网格几何记录在 `authored-geometry.json`，属于用户本次平整度排查范围，未进行游戏渲染或测试。
