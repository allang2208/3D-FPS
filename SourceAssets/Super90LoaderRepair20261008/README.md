# Super90 装填可见性与腕肘修复 R4

后续反馈：用户认为本版枪身抬高过多、枪托遮挡装填细节。取景返工见 `../Super90LoaderFramingR5_20261008/README.md`；下文保留 R4 制作记录，不代表用户已接受本版取景。

2026-10-08。用户否定 R3：手臂扭曲且离开画面，装填器也不可见。本轮针对该反馈修正动画取景、肘部支撑和道具裁剪。制作、FBX 导出和原生构建已完成；00:42（北京时间）后台保存完成，`import_receipt.json` 为 `completed=true`，19 项资产落盘。未启动游戏或做验收渲染。

## 已定位的问题

1. **源轨迹就落在画面外。** 按 `RifleHipFraming` 的 M4 标尺和 Super90 枪轴还原腰射取景，旧版对口第 87 帧左腕位于镜头前 5.09 cm、右 9.44 cm、下 17.88 cm；管体后端位于前 5.56 cm、下 23.42 cm。仅纠正单位/绑定不能解决这条离屏路径。
2. **旧肘极不适合推杆操作。** R3 只运输待机肘极，对口时肘比腕更靠前；推进中掌向与前臂方向严重相反。原生骨长不变，并不等于腕肘自然。
3. **裁剪没有跟随主视模。** 无物理资产的随动装填器仍可能采用导入参考姿态的停放包围盒，显示时间已到也会被裁掉。显示时钟本身仍用同一个 `Super90ReloadSourceTime`。

故障读取文件：`author_geometry_r3.json`、`saved_motion_r3.json`、`saved_coordinate_trace_r3.json`。旧保存资产的 SOURCE/COMPRESSED 与旧作者位置差异小于 0.00006 cm，问题已存在于作者轨迹，不是本次读到的 FBX 位置丢失。这一结论只用于定位用户报告的问题，不代表画面验收。

## 修改

- 工作段整枪和握持关系一起向前、左、上调整，收尾回到各自待机。位置基于本枪实际相机坐标求解，不改变常态腰射、ADS 或战术冲刺锚点。
- 推杆横柄与整手一起转向，沿用 R3 米制绑定及原生指节长度。`solve_contact_layout.py` 根据实际接触段可达性、腕向和取景生成 `contact_layout.json`，生产作者直接读取该文件。
- 左肘在准确两骨圆上选取接近原生中性腕轴延长线的位置，进出操作段只混合肘极角度；保留本骨架解剖铰链及实际前臂蒙皮站点。没有通过缩短手臂或隐藏手臂掩盖反折。
- `Super90SpeedloaderVisual.cpp` 令装填器沿用主视模的裁剪边界，与项目模块化手臂的处理一致；保留原有 owner、第一人称、装填状态和显隐时间限制。
- 15 段数量/空仓动作与四类握把差量同步重新烘焙。保留现有 1.3 倍默认速度、弹药接触事件、中断退件、空仓释放、枪体材质与松散弹药隐藏规则。

接触布局的制作数据：完整七发推进段关键帧左腕由前 22.66 cm 推进到前 45.26 cm；所求腕轴摆角约 4–21°。这些是作者几何约束结果，视觉和游戏表现仍由用户确认。
