## 制作和接入

1. `textures.py` 制作微纹法线和粗糙度。
2. Blender 后台执行 `author.py`、`bake_masks.py`、`author_icons.py`，保存几何、材质遮罩和一张实际部件的灰阶图标。
3. `run_assets.ps1` 使用现有 UE 批次互斥，调用 `install.py` 保存同一路径的运行附件与材质，并同步四个既有图标键。原装件图标保持原样。
4. 父目录 `register.py` 登记说明。无需游戏 C++ 改动或 DLL 重编。

本次先在内存中建立与新 FBX 一致的三类材质目录，再重导入，使用 `reset_to_fbx_on_material_conflict=True` 和 `replace_existing_settings=True`；仅打开冲突重置选项仍会保留旧 Rubber/ContactPolymer 槽。新几何导入后才保存网格，回执记录实际材质路径。

原始身体版本的源文件和 `.blend` 保留在父目录；本轮修改前资产在 `Before/Assets/`，目录快照在 `Before/gunsmith.json`。当前制作源为本目录的 `M24_AdvancedAction_DetailV2.blend`。运行入口保持 `/Game/Weapons/M24/AdvancedAction20261029/Meshes/SM_M24_m24_advanced_action`。

回执仅记录制作、导入和保存结果；未启动游戏，未进行视觉、动作或性能测试，由用户测试。
