# M24 先进枪机系统：完整前部枪身

当前制作版本为 [FullBodyV3](FullBodyV3/README.md)，取代只覆盖上方的 DetailV2。用户已明确保留原装枪托，只重构前方枪身。先前否决的骨架枪托不再使用。

本版重构机匣套筒、下底盘、弹匣口和完整上下护木，细化真实孔槽、倒角、沉孔紧固件、连续顶轨与侧轨。原装枪托接口保持，枪管、枪栓活动路径、弹匣和独立通用改造件继续使用。

当前原生 SK_M24_MotionV9 的 1864 个前部面划入 M24_FactoryFront，安装本改造时隐藏、拆除时恢复。M24_FactoryChassis 保持原装枪托可见。只修改材质分区，不从历史 FBX 重导骨架、权重、手臂或动作。第一人称、改造台以及世界外观记录接入同一隐藏状态。

脚架重建贴合底盘的安装座，原双腿网格、铰链和 0.48 秒部署时序保留。用户要求的连接面排查记录在 FullBodyV3/bipod-fit.json，不代表游戏动作验收。

沿用独立静态武器母材质，枪身与脚架座分别有 UV1 表面遮罩，UV0 使用 4 cm 微法线与粗糙度。M24 对应改造图标按当前模型更新。body 槽和 m24_advanced_action ID 不变，数值仍为后坐力-15%、稳定性+20%、开镜耗时+10%。

制作源、导出、贴图、图标、接口与执行顺序均位于 FullBodyV3/；根目录旧模型和 DetailV2/ 作为历史源保留。根 install.py 随发布指向活动版本，catalog.py 与 register.py 仅更新 M24 条目。最终保存及构建状态以 delivery-status.json、install_receipt.json 与 build-receipt.json 为准。

默认后台制作、必要构建与 commandlet 导入，不打开编辑器或运行游戏。实机外观和动作由用户测试。
