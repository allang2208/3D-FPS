# M870 快速近战：右肘修订 R3

用户后续反馈：本版动作基本合格。后续接入及联机链路检查位于 `../M870QuickMeleeAudit20261017/`；这一反馈不等于全部改造组合或联机测试通过。

用户反馈 R2 的快速近战右肘仍然扭曲。本次从当前安装的动画数据模型、原生蒙皮和四份握姿 Profile 制作，保留双手与手指接触、枪路、左臂、动作时序及起止姿态。

## 修改依据

R2 对上臂、前臂和辅助骨分别搬运 SUPER90 相对待机的旋转，再分别叠加掌部轴向分量。这没有保证大小臂沿同一条皮肤解剖铰链弯曲。源姿态中，0.1 秒的上臂皮肤铰链与实际弯曲轴约差 35 度；0.6 秒右肘弯折约 153 度。前者造成肘部方向错位，后者容易把近肘表面挤压到一起。这些是制作输入的骨骼计算，不是游戏画面验收。

M870 与当前 SUPER90 的右臂原生参考绑定一致。R3 复用 SUPER90 的 V7 皮肤映射依据，分别取得上臂和前臂的真实铰链基准，再把两段对准同一个当前肘弯轴。参考绑定中的骨段夹角不能直接代替皮肤铰链。

## 制作方式

- 右手世界接触固定，肩肘作为支撑重新解算；主段目标弯折上限 135 度，起止平滑接回当前姿态。
- 肘端不再叠加掌部旋前；肘部辅助骨只承担大小臂之间的弯折过渡。
- 沿原生前臂的实际站位逐步分配掌部旋前：肘端为零，1/3 站位约一半，2/3 站位为完整掌部轴向分量。手腕剩余摆动由手骨承接，手掌世界矩阵保持原值。
- 继续使用实际蒙皮的肩口边界和近眼距离约束，保留 R2 对用户截图视野的避让。只作有限肩部和肘极调整，不移动整枪或隐藏手臂。
- 同步制作原厂、vertical、canted、prism、angled 五种握姿。

游戏写入限定为右锁骨、上臂、前臂、近肘辅助骨、两根前臂 twist 和手骨共七条轨道，以及四个 Profile 的 quick_melee 条目。手骨局部补偿用于保持接触，不是改变握姿。其他动作、网格、伤害、冷却和联机代码不变。时长仍为 0.9 秒，命中时点仍为 1/6 秒。
