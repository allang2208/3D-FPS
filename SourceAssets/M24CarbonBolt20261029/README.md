# M24 碳纤维轻型栓机

- 改造 ID：`m24_carbon_light_bolt`，M24 独立 `bolt`（栓机）槽，特殊改造件。
- 原装项：`false`。拆下后从原骨骼网格材质槽恢复原装表面。
- 拉栓速度乘数：`1.30`；射击间隔乘数：`1 / 1.30 = 0.7692307692`。
- 原装基础间隔 `55 / 30 = 1.833333` 秒，安装后 `55 / 30 / 1.30 = 1.410256` 秒。
- 使用原有 M24 射击周期时钟，同步原拉栓动作、机械音效与抛壳。换弹及装备不另加速。

## 外观与接入

沿用现有 V9 武器骨骼、拓扑、UV、持枪位置与原拉栓动作。碳纤维遮罩覆盖原栓体和尾帽的选定表面，保留金属端面、接合环和原精修法线。由 M24 区域母材质派生专用材质，继续使用原有湿润层。

装卸时只替换 `M24_Body` 材质槽；遮罩外保持原枪体材质。弹匣和手臂材质不变。持枪、枪匠预览及背包枪械图标应用相同部件选择；第三人称装备沿用现有材质快照通路。

图标使用原栓机几何制作，提供原装、碳纤维及槽位图标，沿用统一金属边框。

## 制作文件

- `author_surface.py`、`M24_CarbonBolt_Surface_Editable.blend`：原 UV 碳纤维区域遮罩制作。
- `Textures/T_M24_CarbonWeaveMask.png`：R 碳纤维区域，G 纤维明暗，B 编织方向。
- `author_icons.py`、`Icons/`：模型图标及可编辑 Blender 场景。
- `install.py`、`run_assets.ps1`：导入并保存材质、纹理和 UI 图标。
- `catalog.py`、`register.py`：接入现有枪匠目录，只追加 M24 栓机选项。
- `build.ps1`：当前模块对象上的增量编译链接；默认发布正式 DLL，可用 `-StageOnly` 暂存。
- `install_receipt.json`、`catalog_receipt.json`、`Build/build-receipt.json`：实际保存、注册、构建状态。
