# 消音器开火音效

2026-09-08 用户试听后指定，将 AKM 单发候选用于游戏消音器开火声。

当前资源：akm_recorded_shot.wav。与用户试听的 AKM_single_candidate.wav 完全相同，48 kHz / mono / PCM16，未追加变调、均衡、增益或混音。所有使用现有消音器音频入口的武器共用此声，卸下消音器恢复各自 WeaponData.shoot_sound；播放器仍为 -5 dB、pitch 1。

原录音来自 Pole Position Production / AKM 7.62x39mm，Sonniss GDC 2016 免费包的 AKM_7.62x39mm_1m_left_on_ground_DPA4062_clean_Triple_shots_x_1.wav。取第三枪 0.563–1.850 秒，仅重采样及边界淡入淡出。原录音没有标注安装消音器，本次是用户选择的游戏声音用途，不宣称真实消音 AKM 实录。
