# M4 枪口配件升级与 Godot 迁移

## 来源与可编辑文件

旧项目输入：`E:/3d/3-dfps/assets/models/attachments/akm/suppressor_01.glb`、`muzzle_brake/brake_01.glb`、`titanium_brake_candidate/titanium_brake.glb`。两种制退器保留原网格及开孔，加入倒角与连接细环；消音器根据原有轮廓、长度和五道抓握环重建96边连续壳体，增加可见开口与端盖细节。没有增加外部枪械模型。

上述地址是导入时来源，现已退役。重新读取原模型时设置 `GODOT_SOURCE_ROOT` 为恢复后的 Godot 归档根目录。脚本默认遵循宿主记录的归档地址，但本次收尾时该地址不存在；已有 Blend、FBX、已导入 UE 资产和本地声音完整保留，游戏运行不依赖 E 盘源目录。原始输入散列保留在 `source-manifest.json`。

本目录的 `*-editable.blend` 是可编辑源；`SM_M4_*.fbx` 是 UE 导入入口；`build_models.py` 可重建候选。`source-inspection.json` 和 `build.json` 记录源面数、升级面数与安装测量。升级模型以游戏外观为目的，不是现实武器的加工设计。

材质直接复用当前运行 M4 的 `/Game/Weapons/M4InfimaV3/Flash_Hider_001`。凹面和钛金嵌边复制同一父材质并保留原实例贴图/参数，只加入小幅颜色调节；没有覆盖原枪材质。原枪及其贴图仍依赖宿主工程已有授权资产，不将此目录解释为可单独公开分发的完整资源包。

消音声复制 Godot 当前使用的 `akm_recorded_shot.wav`，保留 `SUPPRESSOR_AUDIO_SOURCE.md`：用户原先选定的游戏用声音，非真实消音枪录音声明。本次没有二次调音。混音记录属于同一实际 UE 验收进程。

## 数值合同

| 配件 | 后坐力倍率 | 射击晃动倍率 | 开镜耗时加成 | 弹速 |
|---|---:|---:|---:|---:|
| 原厂 | 1 | 1 | 0 | 90 m/s |
| 消音器（兼容ID true） | .75 | .75 | 0 | 72 m/s |
| 制退器 brake | .85 | .85 | +10% | 90 m/s |
| 钛金制退器 titanium_brake | .70 | .80 | +17.6470588% | 90 m/s |

依据实际 `scripts/weapon_feedback.gd`、`scripts/muzzle_variants.gd`、`scripts/gun.gd` 和 `scripts/weapon_data.gd`，不沿用旧文案里“降低稳定性”的方向错误。稳定性面板沿用 UE 新评分，晃动降低不等同于评分直接增加同样百分比。

用户确认将 M4 从即时命中切到 Godot 基础弹速。弹丸使用零重力、逐段射线扫掠，匹配 Godot 实际 `Projectile.fire(..., 0.0)`。不提前给命中目标扣血，也不通过延迟执行旧命中结果模拟飞行；目标可以在到达前移开。新增部件与已发射弹丸分别拥有状态，换配件不改变已发射弹丸速度。

原厂装置单独材质节隐藏/恢复，配件挂在 `WPN_root`，安装基准来自当前导出网格的原厂枪口后缘，距原枪口挂点后方4.83633cm。发射、火光和烟雾使用配件真实端点，抛壳口保持独立。消音火光不透明度为原版的12%，制退器不会误用消音声。

## 验证入口

1. `inspect_sources.py`：只读取原模型和 M4 可编辑源，生成实际源渲染与检查记录。
2. `build_models.py`：生成升级候选。
3. UE Python commandlet 执行 `import_assets.py`：只导入 `/Game/Weapons/M4MuzzlesV1`，复用现有枪械材质。
4. 编译当前 FPSGAMEEditor 模块，运行 `run_validation.ps1 -RunId <唯一名称>`。独立 `MuzzleMigrationAudit` 存档，生成各配件改造面板、ADS、腰射截图、实际混音和断言。

验收覆盖原厂替换、精确材质引用、挂点/轴向/端点、实际输入开火、声源选择、配件倍率、保存重载、卸下恢复、弹鼓/全息共存，以及90m靶标的飞行时差与移动目标。
