# M24 折叠脚架

2026-10-30 手部/肘部续修：当前动作作者源见 `../M24BipodHands20261030/README.md`。正式路径保持不变，仅更新两套动作的左臂轨道。本目录 `author_hands.py` 是 10-29 历史版本；后续重制使用新入口，避免覆盖手肘修订。本轮未做游戏测试或验收渲染。

改造 ID：`m24_foldable_bipod`，独立 `bipod` 槽，默认不安装。复用 PKM Bipod26 的夹环、铰链、支腿、UV 和现用表面材质；支腿缩为原长的 80%，夹环适配 M24 枪管。折叠时两腿沿枪管下侧向前收拢。

靠近有效支撑面、站稳后进入瞄准，沿用架枪系统的双脚支撑与服务端判定。按用户要求改为一次直接拉开，展开总长 0.48 秒：

- 0.00–0.12：左手松开护木，经外下侧抓住近侧支腿。
- 0.12–0.30：一次拉开双腿并锁止，取消跨枪换腿抓握。
- 0.30–0.44：松开手指，经枪体外下侧连续回握。
- 0.44–0.48：平滑抬入瞄准、枪身落位。

取消瞄准反向收起；途中取消沿当前进度返回。开火拉栓未结束时，收起等待拉栓完成。换弹先收起脚架，再进入原有换弹动作。展开和收起期间不可开火。架设后的收益使用原系统：后坐力 -66%、稳定性 +66%、散布 -45%，并保留移动锁定和视域限制；未架设时不加永久属性。

手部以当前 V9 裸手及保存的 M24 支撑握姿制作，分别保存 5 发与 10 发弹匣动作。枪根与右手沿用原握枪基准；左臂用固定骨长两段 IK，带肩部支撑和 V9 前臂扭转分配。手指按脚架上段做有限角度包握，松开、到达、闭合、退手与铰链共享同一时钟。已有第三人称动作/附件采样继续消费这套组件。
