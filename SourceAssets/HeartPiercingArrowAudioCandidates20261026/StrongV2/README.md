# 穿心箭强冲击试听 V2

用户认为第一组冲击不足后制作的三款叠层设计音，编号延续为 E、F、G。每段仅含出箭声音，连放两次，间隔 0.85 秒。尚未选择、导入或绑定游戏，不包含命中音、蓄力循环或就绪提示。

- E 重弦崩响：降调弦响叠短促低频、压力瞬态与快速掠风，收尾较短。
- F 裂空穿刺：更锐利的起音与高频破空，低频较短，用于比较穿透／速度方向。
- G 蓄力震爆：更重的弓体、低频下冲与压力瞬态，带较长空气尾声，偏夸张技能音。

三款保留相同的 −3 dBFS 峰值上限，以叠层、包络、频段与尾部改变力度；没有宣称主观等响或实机听感已经通过。Singles 为 48 kHz / 24 bit 双声道单发候选，Auditions 为 16 bit 双声道试听版。运行 author_strong_candidates.py 可从上一层 Sources 重建；manifest.json 记录源文件散列、处理方向与交付状态。源裁切、各层增益、延迟、滤波、随机种子及饱和处理保留在作者脚本中。
