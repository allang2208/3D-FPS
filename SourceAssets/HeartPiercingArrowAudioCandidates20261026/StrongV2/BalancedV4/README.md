# 穿心箭三合一平衡版 V4

按用户“第三种声音最后一下太大，要平衡并加入前两个声音细节”的反馈调整正式 H 音色。

- E：取消上一版的 4.2 kHz 低通限制，高通从 150 Hz 降为 80 Hz，保留弦响的主体与上端细节。
- F：高通从 1350 Hz 降为 180 Hz，权重从 0.68 改为 0.82；起音软化从 10 ms 缩为 2 ms，让中频撕裂和破空更完整。
- G：低频权重从 1.30 降为 0.38（混音前约 −10.7 dB），收窄到 45–500 Hz；65 ms 后平滑衰减、240 ms 收尽，取消额外的 G 高频尾声。G 只作前段轻量支撑。
- 总线取消额外饱和；峰值上限仍为 −3 dBFS，结尾在 620–840 ms 淡出，单发长 0.86 秒。没有宣称主观等响或用户认可。

原始 E/F/G 与 CombinedV3 保留。rebalance_efg.py 从上一层 Singles 重建；源与作者许可沿用 StrongV2/README.md，均为 CC0。正式接入仍使用 SelectedH 的相同资产路径和播放参数，仅重导入 WAV；无需 C++ 构建。
