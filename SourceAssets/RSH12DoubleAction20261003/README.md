# RSH-12 双动重制

用户于 2026-10-03 重新授权制作，参考 BV1vh4HejEUF 的 0–22 秒，先握持，再开火、ADS、镜头、声音、换弹与视觉效果。

`author_double_action.py -- single grip` 首先从未叠加单动拨锤的原始 profile 与最新注册模型求握持，保存 `single/grip.json`；`-- single motion` 消费该握持制作新网格与动作。`r`、`l` 为原生双持左右分支。`pose_math.py` 仅提取原有固定骨长解算，不执行旧拨锤制作程序。全程保持 POSE 求值导出动画。

新 UE 根为 `/Game/Weapons/RSH12/DoubleAction20261003`，旧单动目录保留用于恢复。动作与网格不覆盖已有候选；共享 715 的其他动作沿用私有 profile。制作源、FBX、Blend、参考与音频衍生保留本机。

单持使用新握持、腰射／ADS 开火、五发速装换弹；双持和法杖副手使用新握持与双动开火，继续使用单手逐发装填。参考视频只有单持双手操作，不能把双持的逐发装填描述成视频速装复刻。

参考第一段空仓换弹的关键帧约为开巢 5.87、抬枪 6.2、按退壳杆 6.47、取速装器 7.5、装入 7.8–8.1、抽离 8.5、甩回闭巢 9.08、回握 9.6 秒。第二段约从 15.2 秒开始，退壳的左手手法略有不同。制作归一到 4.333 秒源时钟，普通换弹 4.167 秒；两者均整组退壳/装填。不可见的三维深度、手掌背面与原视频不同模型的尺寸属于本地适配，不是原动画文件。

`framing.json` 是参考前／后瞄点和弹巢的透视拟合，额外保留腕部正深度。它是制作参数，不是游戏像素对比通过。`author_audio.py` 从用户指定视频混音生成八段本地衍生 WAV，记录裁切、滤波、增益与散列；这些不是游戏独立音轨，公开分发许可未建立。

`import_assets.py` 实际保存新模型、动作、profile、声音和速装器材质，并为新网格延续裸手／装备外观映射。`import_receipt.json` 的当前 revision 和 complete 才表示这次导入完成。之后 `publish_catalog.py` 只修改 RSH 的物品与枪匠对象。
