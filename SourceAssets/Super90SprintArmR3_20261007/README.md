## 制作修改

生产作者入口为 `../Super90TacticalSprint20261007/author_sprint.py`，版本 `ShoulderReturnR3-20261007`。

1. 在松握阶段按 `smooth(.16,.78,progress)` 将整条左臂（包含锁骨、肩、肘、腕、辅助骨、手指）整体向后 19 cm、向左 8 cm、向下 1.5 cm 收向身侧。该位移在两骨求解之后作用于整链，上臂、前臂骨段长度及手腕关系保持；不会只拉走手掌、留下肩端。
2. 松握时把上臂和前臂的滚转从各握把 idle 连续放松到本枪原生解剖铰链，前臂辅助骨仍按真实 0 / 1/3 / 2/3 站位分配。两次腕部求解使用相同的放松量。
3. 进入第零帧保留原握姿；退出沿同一进度反向恢复。进入/退出 0.30 s，循环 0.60 s，120 Hz，右手和枪的原有抬枪轨迹保留。
4. 重制基础三段动画和 vertical/canted/prism/angled 四份配置中的冲刺条目。导入合并保留各配置中普通动作和装填器动作，不改通用运行时、网格、材质、装备或换弹节奏。

方法依据：手臂 SKILL 的 `grip-arm-refinement.md` 臂根平移案例、`thrust-elbow-clearance.md` 的原生解剖弯轴，以及 `Docs/Weapons/akm-sprint-left-wrist-relax-20260917.md` 的整臂松握/下垂。采用本枪相机和网格定位，不照抄其他枪的位置参数。
