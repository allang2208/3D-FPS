# ASH战术制退器

用户参考图：`Reference/user_brake.png`。按可见短粗多棱壳体、大开窗、后端环形接座进行游戏外观设计；遮挡面采用对称重建，并非已确认的背面复刻。

## 制作与安装

- `author_vibe.py`：当前 UE 编辑器 Vibe3D 作者入口。八棱外壳、四个贯通窗口、倒角前缘、前端开口、环形后接座和车削环槽均为几何。只释放本任务的临时 handle。
- `SM_ASH12_TacticalBrake.fbx`：从 UE 生成的实际 StaticMesh 导出。
- `ASH12_TacticalBrake_Editable.blend`：从实际导出资产生成的可编辑源，带打包材质贴图及 UI 图标场景。
- 坐标：厘米，+X 向枪口，+Z 向上；X=0 为后安装接触面，前端 X=8.4。运行时沿用 ASH 当前原厂枪口后端距 socket 6.79 cm 的安装面。
- 外壳与安装环直接引用 ASH 当前 `M_ASH12_GripMetal_Coat`、`M_ASH12_OpticShoe_Coat`，保留金属度、粗糙度、细法线及现有水膜/水珠映射。不使用参考图的橙色。
- UV0 用于切线法线和水珠；UV3 用于现有涂层的 4 cm 平铺。模型保留硬边，按 MikkTSpace 构建切线。

## 游戏数据

`ue_ash12 / muzzle / ash12_tactical_brake`，名称 **ASH战术制退器**，不加入其他枪械的配件目录。

| 属性 | 数值 |
| --- | --- |
| 后坐力 | ×0.75（−25%） |
| 枪械稳定性 | ×1.15（+15%） |
| 开镜速度 | ×0.90（−10%） |

用户明确确认开镜变慢。现有系统使用开镜耗时增量，本选项写 `ads_percent = 0.1111111111111111`，单独安装时耗时 ×1.1111，等价速度 ×0.90；与其他配件继续遵循现有耗时增量相加规则。属性描述与数据一致；未增加弹速、消音等其他效果。

运行时沿用枪匠预览、应用、实例保存和拆卸恢复入口，新配件火光端点使用其实际前端。制退器不进入消音判定。

## 图标与来源

`make_icon.py` 使用实际 FBX、现有黑色金属参数与纹理生成 1024×1024 透明 UI 图标；水平正交侧视，枪口向画面左。图标制作属于 UI 资产产出，不是验收渲染。`import_icon.py` 同步 PNG 与 UE Texture。

几何由本任务作者脚本制作；参考图由用户提供，其来源权利不作扩展声明。金属及天气材质继承现有项目来源。没有下载或公开分发外部模型。

模型已在当前编辑器内制作并保存，输出 6,488 三角面；FBX、可编辑 Blender 源、透明 PNG 与 UE 图标 Texture 已生成。原生接入已包含在恢复后的常规模块构建中。

未执行模型验收、游戏测试、PIE 或额外预览，由用户测试。
