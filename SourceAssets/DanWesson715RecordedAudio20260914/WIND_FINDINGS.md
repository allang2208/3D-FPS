# DW715 速装器换弹音效：风声识别与处理

2026-09-25。针对测试反馈"左轮手枪快速装填换弹音效里录入两声背景风声"，用户要求先识别。

## 识别结果：两声是 **Eject（抛壳）** 和 **Close（关转轮）**

三种独立方法指向同一结论：

| 片段 | 250–1000 Hz 风声 RMS | 相对录音底噪 | 风声占总能量 |
| --- | --- | --- | --- |
| **Eject** | **−34.7 dBFS** | **+7.8 dB** | **29.3 %** |
| **Close** | **−34.9 dBFS** | **+6.5 dB** | **22.0 %** |
| Open | −43.6 | +2.1 | 4.1 % |
| Insert | −45.9 | +2.0 | 3.4 % |
| Retrieve | −52.0 | −1.5 | 7.0 % |
| Release | −54.2 | −1.7 | 0.6 % |
| Withdraw | −58.2 | −0.8 | 1.4 % |

1. 全部录音里最响的风声窗口是 1.5–2.5 s 与 1.0–2.0 s（都在 Eject 内），第三是 5.0–6.0 s（Close 内）；其余片段所在窗口低约 15 dB。
2. 原降噪对这两声最无效：其余片段降了 8–12 dB，**Eject 只降 6.5 dB、Close 只降 5.0 dB**。
3. 逐 20 ms 切片比较：**Eject 81 % 的切片、Close 74 % 的切片，风声频段高于机械频段。**

## 关键发现：这两声大部分是风，不是机械

对每个"风声占优"的片段做频谱形状比对（与纯风参考、机械参考分别算距离）：

| 片段 | 与纯风参考 | 与机械参考 | 判定 |
| --- | --- | --- | --- |
| Eject 1.800–1.945（预卷） | **1.8 dB** | 16.7 dB | 风 |
| Eject 1.920–1.940（最强阵风） | 9.5 dB | 23.8 dB | 风 |
| Eject 2.040–2.080（撞击） | 13.7 dB | **5.1 dB** | 机械 |
| Close 5.020–5.200 | **6.1 dB** | 20.6 dB | 风 |
| Close 5.060–5.120（最响） | 11.2 dB | 25.5 dB | 风 |
| Close 5.340–5.400（尾段） | **4.2 dB** | 17.6 dB | 风 |

**真正的机械内容只有几个 20–40 ms 的爆发**：Eject 的 2.040–2.080；Close 的 5.000–5.020、5.200–5.220、5.280–5.320。其余 70–80 % 的时长都是风。

这也解释了为什么用户会觉得"两声"特别明显：Eject 的整个预卷就是一阵 −13.8 dBFS 的阵风，Close 则有一段 180 ms 连续风声压过机械。

## 走过弯路（如实记录）

1. **原地剔除**——强化软谱掩蔽（strength 1.35→4.0、floor 0.075→0.02）只降 **0.4–1.0 dB**；零深检验显示安静窗之间的归一化互相关只有 **0.13–0.36**，风声不平稳，无法用模板减法。
2. **剪短暴露段**（用户先选的方案）——实测**对 Eject 有效、对 Close 无效**：Close 越剪风声占比越高（23.9 % → 28.4 % → 36.8 %）。原因就是上面那条：Close 大部分是风，剪掉哪一段都只是让剩下的风占比更大。
3. **尾音重建**（PKM 那套方法）——做了三版，都不成立：频谱形状距离显示 Close 的"尾段"其实是风（4.2 dB vs 17.6 dB），不是机械衰减；按机械频谱做环境床又会把 250–1000 Hz 抬高（Eject 反而恶化 6.3 dB）；按爆发峰值包络定增益在频谱零点上不稳（Close 一度 +32 dB）。
4. **最后才发现正解一直摆在管线里**：原管线本来就用高通降风，只是定在 200 Hz，而风声正好落在通带内。

## 采用方案：把高通从 200 Hz 提到 800 Hz

机械在 1.5–8 kHz，风在 250–1000 Hz，两者几乎不重叠，所以提高高通能直接切掉风而不动机械：

| 高通 | Eject 风电平 | Eject 机械峰值 | Eject 风占比 | Close 风电平 | Close 机械峰值 | Close 风占比 |
| --- | --- | --- | --- | --- | --- | --- |
| 200 Hz（原） | −27.9 | −29.3 | 32.0 % | −29.3 | −29.3 | 25.1 % |
| 400 Hz | −34.9 | −29.3 | 15.0 % | −36.4 | −29.3 | 9.1 % |
| **800 Hz（采用）** | **−46.3** | **−29.3** | **1.3 %** | **−48.0** | **−29.3** | **0.7 %** |

**保留原录音、原窗口、原长度，只改一个滤波器。**

### 实测验收（交付资产口径）

| 指标 | Eject | Close |
| --- | --- | --- |
| 时长 | 0.4300 s（不变） | 0.4800 s（不变） |
| 峰值 | 0.46 == 0.46 | 0.58 == 0.58 |
| 风声频段 | −34.7 → **−52.5 dBFS**（**−17.8 dB**） | −34.9 → **−52.5 dBFS**（**−17.6 dB**） |
| 机械峰值 | −8.2 → −8.6 dBFS | −6.3 → −6.2 dBFS |
| 风声占比 | 29.3 % → **1.29 %** | 22.0 % → **0.70 %** |
| 整体 RMS | −29.4 → −33.6 dBFS | −28.3 → −30.9 dBFS |

整体 RMS 下降是因为被切掉的那部分本来就是风——这正是目的。峰值不变，所以游戏内触发响度一致。
