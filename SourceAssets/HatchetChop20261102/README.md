## 二、双持旋风副手避让

- 原因：旋风用弯刀的单刀 clip，左臂是抬在画面左上的护手拳；双持时副手斧挂在 `hand_l` 上，跟着抬到准星斜上方（实测斧头 NDC 约 −0.2, 0.65，压住视野）。
- 做法：`UKukriArmsMeshComponent::SetLeftArmPitch()`——绕左锁骨把整条左臂刚性下压（各骨局部旋转不变，只整体转过去）。旋风期间对**双持斧头**施加 45°（`KukriWhirlOffhandPitch`），两端各 0.18 s 缓入缓出，起手和收势回到 clip 自己的左臂。
  - 只影响视模左臂与副手斧；右手刀、剑气、判定、第三人称都不动。
  - 只在 `IsDual() && bDualHatchet` 生效；弯刀、单持斧、法杖副手不变。
- 预览对比：`Work/pitch_0.jpg`（原样，副手斧压在准星上方）、`pitch_30.jpg`、`pitch_45.jpg`（下压后落到画面下方）。
