# 设施内部中转大厅与六套主题入口

2026-10-07；按用户要求后台制作，独立样板阶段。正式随机地牢与接待大厅原图不在本批保存范围。

## 空间设计

- 主厅 48 × 36 米，屋顶净高 8.4 米；接待厅后接 8 米长、3 米宽、3 米高的介绍走廊。新厅中心相对接待厅向东 59 米，两侧地坪同高。
- 地面为主要分流层。正前方、左侧、右侧各一个出口，7.6 米宽入口立面，内部标准净开口 3 × 2.8 米，后接 4 米过渡段。
- 西侧 4.2 米高观察平台，两侧各一套 3 米宽双段楼梯，中间休息平台；楼梯口留开口，栏杆配置连续简单碰撞及 Traversal.GuardrailDrop。
- 二层玻璃调度室有两个完整复用工作位、椅子、资料抽屉、可破坏玻璃与原生交互门。其他平台布置复用沙发、茶几、饮水机。
- 一层西侧座椅，北侧防护用品柜与更衣凳，南侧检修台和工具箱。柜体、桌椅和抽屉行程保留独立位置，主通路不摆家具。
- 主厅没有地面中柱；梁、外墙柱和西平台支撑按房体尺寸单独制作。管线在高处沿墙走，地面无横跨主路的障碍管道。

## 已制作内容与来源

- `prepare.py`：尺寸配置、原创中文导视图集、复用家具及容器布局。
- `author.py`：精确 Blender 建模、UV、倒角、独立简单碰撞、FBX 和可编辑 `.blend`。
- `install.py` / `install_background.ps1`：使用现有批次互斥后台导入、构建 Nanite、保存资产及两个接待厅衔接样板。正在运行的编辑器沿现有桥处理；PIE 或未保存地图时停止写入。
- `compose_portals.py`：按已选 Route1 / Route2 / Route3 的主题 ID 返回相应入口零件，**不重新抽签**。
- `Config/module-draft.json`：房体 cells、四个端口、六套门口、原生交互与未来接入约定。当前为作者草案，没有修改正式生成器。

原创门框、管件、通道、导视、碰撞均为本批制作。复用材质来自已保存的墙面、SeamMetal 和接待大厅；办公设备、沙发、桌椅来自接待厅精修及既有车站/生活区资产；容器来自 IncineratorContainers；破窗使用既有隔离病房原生玻璃方案。未下载新的 Fab 资源。

## 用户体验入口

主样板展示货运、医疗、焚化三套入口，从接待大厅出生，可以连续走到新厅：

```text
open /Game/GameMaps/Design/L_FacilityTransit_Subject
```

第二套展示生活、生态、发电三套入口，出生在新厅入口，也保留与接待大厅的连通：

```text
open /Game/GameMaps/Design/L_FacilityTransit_Alternate_Subject
```

返回主场景：

```text
open /Game/GameMaps/DayNight_Lighting
```

## 当前接入边界

两个样板采用固定入口组合，供用户看到全部六套模型；未启动随机地牢，也未把未确认的新厅注册为正式 Junction。入口后端当前是独立样板封口，主题三连房不在这两张样板图中重复摆放。正式接入时读取生成器已有 `RouteThemes`，同时套用入口、过渡段与示牌，并由求解器连接实际主题路线。六个主题是六套可替换设计，不是六条同时开放的新增分支。

保存状态以 `Receipts/install.json` 为准。入口近景精修及用品柜转向记录在 [RefineV2](RefineV2/README.md)，该修订以其 `Receipts/install.json` 为保存依据。未自动运行游戏、地图检查、截图、渲染或验收，由用户体验。
