# 楼梯、六套门口接缝与防护用品精修

本轮只更新设施衔接厅的既有两张 subject 地图。中央植物展柜、家具布局、灯光和其余主题设备保持当前保存状态。

楼梯以 14 × 15 cm 的两段高度连接 2.1 米休息平台与 4.2 米二层。每段水平长 4.7 米，休息平台长 1.6 米，上端精确终止于 x=-16 的二层边界。踏步、支承和休息平台同宽 3.16 米，二层封边在两处梯口裁开；扶手连续经过坡段和平台，立柱底端按实际踏步面落地。保留独立简单碰撞和统一栏杆翻越标签。

六套主题入口结构内侧退到 1.55 米，内衬完成面维持 1.50 米，形成实体退层。前门框 y=.07 结束，天花从该边界开始；内衬从 y=.10 起，与框后收口相接。旧前侧结构墙与内衬、门框与天花的共面区间已从建模源移除。内衬背板、金属返边和接缝独立分层，不用材质偏移掩盖重复面。

防护柜继续复用原柜壳、层板、铰链坐标和活动门。柜内固定物品改为带鼻梁与面部密封轮廓的面罩、双侧滤罐及栅格、柔性绑带、织物保护包、包边、拉链、扣带、折叠褶皱和多折滤芯。织物使用原创同源微法线、粗糙度和色调纹理；印刷标签保持 4:1 字形比例。更换柜体固定网格，容器 ID、仓储页数和开门交互保持原值。

执行顺序：Python prepare.py → Blender 后台 author.py → install_background.ps1。两套 Blender 文件、FBX 和材质源保留在 Authored。完整重建及 RefineV2 安装末端会重新应用本轮已保存修订，防止旧接缝复活。
