# 六套主题入口近景精修 V2

本批仅调整两张既有中转厅样板中的主题入口及六个防护用品柜朝向，不重建接待大厅、二层办公室、家具布局或灯光。

## 修订

- 防护用品柜转为 UE Yaw -180°，门面朝室内。沿用原生容器 ID、柜体、活动门与铰链；作者布局同步为 Blender Yaw 180°。
- 六套入口替换为独立 V2 资产：实体多层门框、内缩缝、密封条、柱脚、折边墙板、压边条、紧固件和完整灯具外壳。门框与通道内衬按三米净宽制作。
- 货运：D 型橡胶缓冲、防撞固定板、卷帘驱动箱、驱动电缆与限载牌。
- 医疗：带门盖和过滤格栅的过滤箱、釉面墙砖、清洁液分配器、喷嘴和接水格栅。
- 焚化：开放百叶隔热罩、曲面排风管、双法兰、垫圈、支架、圆顶防撞柱与高温标识。
- 生活：木饰面收边、实体壁灯支架及灯罩、钥匙挂钩和钥匙圈、员工信箱与锁具。
- 生态：阀体、填料函、五辐阀轮、固定管夹、压力引管、表盘刻度与独立指针、流量表和回流软管。
- 发电：完整隔离开关柜、门框密封、铰链、锁扣、模制旋钮、ON/OFF 刻度、柜顶支承绝缘子、接线端子、电缆压盖和桥架支架。绝缘子使用连续曲线旋转轮廓。

## 材质与资产

新材质在 `/Game/Dungeons/FacilityTransit20261007/RefineV2` 内，未修改共享材质。喷涂金属、拉丝钢、橡胶和釉面陶瓷分别使用原创、配准的 Tone / Roughness / NormalDX 微表面贴图；金属主色降低饱和度与亮度，主指示牌沿用原始图集及比例。设备铭牌另用 2048 图集，表盘保持圆形 UV。

几何用于轮廓、开口、边缘倒角、厚度、支承和机械连接；亚毫米颗粒、拉丝与粗糙度使用纹理。静态刚体沿用 Nanite 构建及简单碰撞；文字面独立保持非 Nanite。材质显式支持 Nanite 和实例化静态网格。未增加运行时 Tick、灯光或全局纹理池预算。

`Authored/SixPortal_DetailV2.blend` 是可编辑建模源，`manifest.json` 是实际 FBX 导出清单。后台导入与两张地图的保存状态见 `Receipts/install.json`。实际保存完成后才更新父级场景 manifest；父级制作入口会自动路由到本修订，避免重建恢复旧柜向与粗模。

未自动启动 UE、运行 PIE、截图、渲染或验收。由用户进入原样板体验，直达命令保持不变。
