# 中央植物玻璃展柜

设施衔接大厅的独立可复用组合件，安装到两张 FacilityTransit subject 地图。局部中心 (0,0,0)，连接大厅世界偏移沿用 59 米。

- 底座直径 7 米、玻璃外接圆直径 6.6 米、总高 6.526 米；十二块薄框立面玻璃、透明顶盖、石材种植圈、金属收口及维护口。
- 原有 RuralAustralia Tree_M_03 均匀缩放至 4.8 米高，依据完整树冠包围范围居中、根部埋入土壤。搭配 24 株现有林下植物，采用原模型与材质，不复制制作树木。
- 土壤复用 Ecology RefineV5 土壤材质并以连续起伏表面承接树根；环形滴灌管、固定扣、分支滴头、比例保持的铭牌及两盏局部无阴影照明。
- 十二块立面玻璃使用项目既有 WardGlassWindow 系统及相同的碎裂、玻璃声音/粒子资源。顶盖是固定透明网格。
- 以完整曲线带替换原来穿过中央的地面引导线；周围留出环行空间，保留三个主题出口。

制作：Python 执行 prepare.py，Blender 后台执行 author.py；保存：install_background.ps1。导入脚本只替换本组合件标签和原中央引导线，其他大厅资产、交互和主题门口保持现有存档。

后续门口修订不删除本组合件；大厅完整重建时会在主装配完成后重新安装已发布的展柜。模块草稿记录 central_display 引用以便将来正式接入地牢。

本次不启动编辑器、PIE、截图渲染或验收测试；由用户自行体验。
