`FFPSQuiverMotion` 接在现有换装生命周期中，以渲染后的骨盆动作驱动阻尼弹簧。固定端顶点遮罩为 0，袋身为 1，挂带平滑过渡。默认频率 1.7 Hz、阻尼比 1.0、角度上限 2°，袋体总位移预算 2 cm，并对朝向髋部的位移作向外修正。当前位置和上一帧变形分别写入材质；瞬移、长帧间隔、隐藏及布娃娃状态会清除残留惯性。这是有重量感的外观悬挂模拟，不是带环境碰撞的 Chaos 布料。
