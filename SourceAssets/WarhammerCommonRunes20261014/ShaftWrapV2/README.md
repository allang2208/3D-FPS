# 战锤符文移至裸露金属柄

依据用户红圈截图 `placement-reference.png`，把符文承载模块从中央锤座移至固定金属长柄 `shaft`。握持包覆、套箍、锤头、柄尾及各改造数值保持原样。

## 真实坐标与纹样比例

- `read_shaft.py` 从当前原装模块源读取几何；安装点为武器 Z=82 cm，模块长度约 41.5 cm，截面半径由约 1.6 cm 过渡到约 2.05 cm。
- 符文轴向范围为柄模块局部 Z=-39.5 至 -2.0 cm，即武器 Z=42.5 至 80 cm，共 37.5 cm；两端各留约 2 cm，边界柔和淡出。
- 横向坐标使用 `angle * radius` 的表面弧长，纵向使用实际厘米距离。按源纹样纹理的宽高比计算物理宽度，两轴保持相同的每像素物理尺寸，不把窄柄直径当作整张纹样宽度，也不将整图独立拉伸填满长柄。
- 共鸣原纹样较宽，以完整一周容纳环印；导魔、侵蚀和急速的窄纹样在相对两面各放一条完整纹样，保留其轴向内容，不沿柄长重复铺满小图案。
- 保留源遮罩、语义颜色、亮度参数、呼吸及流光，只替换投射坐标。未改原装网格 UV 或几何。
