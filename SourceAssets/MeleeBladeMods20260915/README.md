## 数值口径

- 基础伤害倍率作用于强化与角色属性组成的武器攻击公式，之后再计算打造、精通和附魔；暴击与目标护甲仍在命中阶段处理。伤害公式说明、总览、背包摘要及实际攻击共用该倍率。
- 攻速倍率为 0.90 / 0.85 / 1.15，攻击间隔按倒数计算。继续使用现有角色攻速、附魔和剑术加成以及 0.2–4 倍动作速率限制；动作、命中窗口和声音共用原时钟。蓄力门槛和突刺位移不变。
- 攻击范围同时作用于挥砍/突刺的最大距离、扩展剑刃扫掠及命中半径；每次攻击开始时快照，视觉模型不缩放。
- 耐力消耗词条：影响范围包括攻击（包括重击）和防御受击的耐力消耗。倍率同时用于普通挥砍、突刺、重击及重击起手体力门槛，以及每次格挡受击消耗和破防体力门槛；HUD 可攻击次数使用相同攻击消耗。奔跑、闪避和弹反规则不变。按当前基础攻击消耗15、格挡消耗20，延锋刃分别为15.75/21，轻羽刃分别为13.5/18。
- 重脊刃对这次命中原本触发的普通硬直或韧性破防眩晕时间乘以 1.15；目标原有免疫/触发条件保留，不延长弹反或中毒。效果只在该目标的同步伤害处理作用域内生效，结束后恢复；多次命中不额外相乘剩余硬直。
- 轻羽刃按相对比例降低格挡减伤：50% × 0.8 = 40%，故受到原伤害的 60%。弹反规则不变。
