# V24 — 在认可的 V23 翻转后接上开书

V23 整体翻转已在当前对话获用户认可。本目录保留该段 0–0.90 秒的手臂与书本采样，仅追加松指与展开，未写入运行时源码或游戏资产。

- 0–0.90 秒：逐帧复用 V23，原抓握、腕部关系与 180 度前臂转幅不变。
- 0.95–1.25 秒：五指松开，复用已有自然开掌的局部指骨姿态。
- 1.14–1.62 秒：手臂小幅下移，为悬浮的书留出间隙，腕部局部变换不变。
- 1.28–1.94 秒：后半部与前封面分别绕书脊展开 +90 / -75 度，合计展开 165 度。
- 1.94–2.70 秒：展示打开后的阅读状态。

书本在释放时固定于 V23 的实际握点，位置为此前认可的 `(44,-19,-14)` cm。沿用原阅读书页平面与 25 度倾角，同时保留 V23 的书脊首尾方向；展开时只有约 20.3 度书脊倾角调整，不追加整本书的 180 度回转。原始模型、贴图与页面图案未修改。

`author_preview.py` 生成 `candidate.json`；`render_preview.py` 保存可编辑 `Spellbook_PalmUp_Preview.blend` 并输出 Blender 预览帧；`package_preview.py` 生成 `spellbook-turn-release-open-preview.gif`。前半段由原握点约束驱动书本，释放时退出约束，之后书本对象根变换保持不动，由书本局部骨骼完成展开。
