# 终律·镇魂钟：符文战锤第二款传说锤头

仅替换 `hammer_heads`，ID `final_toll_soul_bell`；原中央锤座、颈部、长柄、握把、配重及通用改造继续沿用。与星誓占同一槽位，两款专属被动不会同时生效。

## 模型与材料

`../FinalTollHammerHeadV1` 保存可编辑实体构建源、装配 PBR 源、FBX、GLB，以及三张 4096×4096 的 BaseColor／ORM／Normal。模型为成对镂空钟室，三道竖向拱窗、内部前后两排且每排三根音柱、厚实外侧平砧、独立铆钉和细金属嵌纹。锤头共111240个三角形、三个材质槽，保留原70mm安装面与Z=91.6cm模块偏移。

只有实体钟室孔洞，没有透明贴片。新网格可用Nanite，金属与发光材质由同一制作脚本保存。符文音柱通过 `RuneAwake`、`RuneImpact`、`EnergyTint` 在苍金与破坏红之间切换。

`author_icon.py` 以实际成品模型生成统一灰阶输入，内置 image_gen 按项目方形钢框、四角铆钉和银色圆环标准制作图标。`icon_manifest.json` 保存完整提示词与来源；正式改造台直接读取PNG。

## 双重重击与镇魂刻印

- 重击伤害＋15%，双段每段都使用完整重击伤害。
- 蓄满后先下砸，再从落点向右上回击，最后回到原待机。释放时长1.25秒，两个接触点为0.10与0.42秒。参考赤霄的动作意图，使用战锤自身蓄力、上挑、双手接触与完整骨段制作，不替换全局动作。
- 释放时钟独立于普通攻击速度；行动加速沿用既有公共倍率。出手时一次支付双倍重击体力，蓄力消耗不变。
- 苏醒期间，重击每个有效接触给该目标叠一层镇魂刻印，持续6秒。两层消耗，附加350%当前魔法攻击力的单体魔法伤害；触发重击本身的削韧×2。双段均命中同一目标，可当次完成叠印与终律。
- 破坏魔力符文保持智力、精神＋10%和原生苏醒附伤翻倍，将本被动附加伤害提升至700%魔攻，并使魔法表现转红。迅捷保持5次命中苏醒与既有＋10%普通攻击速度，不再次加速双重击时钟。
- 叠印按目标和武器实例分别维护，每段对同一目标最多一次。服务端只在实际有效伤害后计数，挥空或无效接触不计数。苏醒结束、换武器、换锤头或目标死亡时清除。
- 附加魔法伤害冻结当次魔攻、魔穿和公共魔法增伤，延至下一Tick独立结算，避免递归触发原始攻击事务。它不产生范围爆震，也不再附带一次削韧；×2削韧作用于触发重击本身。

## 表现与动作范围

原有一个有界动态粒子网格继续共用；增加64个固定四边形供最多16个目标的竖向刻印，终律出现集中声纹与上浮光尘。音柱响应苏醒和命中闪光；苍金为基线，破坏符文为红色。

第一人称源为 `FinalToll_DoubleHeavy_Editable.blend` 和 `Motion/A_Runebound_FinalToll_DoubleHeavy.fbx`，240Hz。第三人称分别从当前Jason和Kaitlin已装配的战锤全身动作派生双段，写入各自骨架；新角色键为 `Warhammer.FullBody.FinalTollHeavy`。其他普通攻击、冲刺重击、旋风、上挑、格挡、检视和走跑仍用原路由。
