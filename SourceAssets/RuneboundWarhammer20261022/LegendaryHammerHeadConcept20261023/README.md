# 星誓·封界之砧

符文战锤专属传说锤头的首轮外观设计，当前仅交付设计图，不创建或注册模型、改造目录、属性或技能。

替换范围为左右两个外锤头。保留原中央哥特锤座、锤颈、长柄、握持包覆与配重，因此后续模型仍需沿用现有装配与动画接口。

造型采用厚实的层叠暗铁主体、旧银倒角、少量旧黄铜嵌线与圆形蓝色封印核心，侧面古符沿拱形肋骨延伸。符文苏醒时刻纹与核心亮起，伴随蓝色漂浮光尘。后续如制作模型，应继续兼容当前破坏魔力符文的红色外观切换。
