# 星誓·封界之砧 · 模型与被动接入

符文战锤专属传说锤头，装备槽为 `hammer_heads`，ID 为 `star_oath_sealing_anvil`。沿用现有改造草稿、应用、取消、恢复原装、实例存档和模块装配入口。

## 本次数值

- 当前手持符文战锤且装配本锤头时，角色物理攻击力、魔法攻击力各乘以 1.10，持续生效。
- 原有符文苏醒维持 10 次有效攻击激活、持续 20 秒；迅捷魔力符文仍为 5 次激活，并保留 +10% 攻击速度。
- 苏醒期间，每 3 次有效攻击命中触发一次封界震荡；从激活后的攻击开始计数。同一次攻击序号的多目标接触只计一次。
- 爆震以命中点为中心，作用于命中目标及 250cm 球形范围内的敌人。伤害基础为当前魔法攻击力 ×2，随后走共享魔防、魔穿、魔法增伤和目标易伤结算。
- 破坏魔力符文保留原有智力、精神 +10% 与苏醒附伤翻倍，并使本爆震的基础系数翻倍为当前魔攻 ×4。新锤头的两项攻击力加成先进入派生属性，未在爆震侧重复乘以 1.10。
- 挥空或未造成有效伤害的接触不计数。苏醒到期、死亡、切换武器实例或卸下锤头清空爆震计数。已命中提交的爆震按当次快照结算。

## 权威结算与表现

现有 `ColdSteelSkills::ApplyHit` 确认敌方接触后，将实际命中信息交给 `RecordRuneboundHit`。服务端以原有攻击序号去重。第三次命中冻结魔攻、破坏符文倍率、魔穿与共享魔法增伤，延至下一 Tick 独立结算，避免嵌套原近战的修炼、暴击、蓄能和附魔事务。

敌人以共用敌我判断筛选，多个碰撞体只结算一次；范围传播使用 `MagicOcclusion`，保留实体墙和楼板遮挡，并兼容已标记的栏杆和镂空结构。

爆震表现复用原有一个动态粒子网格与四个固定爆发槽；单次爆震 384 枚粒子，其中 48 枚构成快速扩散的光屑环，其余为高速光丝、碎屑和减速上浮微粒。普通命中优先复用过期或普通槽，保留爆震尾粒的漂浮时间。蓝色为基线，破坏符文切换为红色。核心和导能槽通过 `RuneAwake`、`RuneImpact`、`EnergyTint` 联动闪亮。

## 已制作资产与生产入口

模型沿用 `../StarOathHammerHeadV1` 的 245625 三角形近景母版、原装 70mm 接口和 91.6cm 作者原点。新资源目录为 `/Game/Weapons/RuneboundWarhammer20261022/StarOathV1`：一个静态网格、四个材质与三张 4K PBR 贴图。切面核心保留透光材质，因此本模块使用完整的传统静态几何；未对原模型全局减面。

`author_isolated.py` 在独立的引擎原生后台工程完成导入、材质编译和保存，随后只安装本次新资源路径。它不操作共享编辑器世界或覆盖原资产。

正式灰阶金属框图标由实际模块渲染作为输入，再通过内置 image_gen 生成；源图、可编辑图标场景、最终提示词与母图分别在本目录保存。改造台直接读取部署 PNG。

`publish.py` 读取最新文件，只增加本锤头的目录和模型配置，同步 ModulesV1 的作者基表，保留其他原装件、共用配件及符文数据。选择仍写入既有 `gunsmith_parts.hammer_heads`，无需存档结构迁移。

`import_receipt.json` 是实际保存与安装回执；`build_receipt.json` 是必要 Game/Editor 构建结果；`delivery_receipt.json` 是正式发布结果。默认后台制作，没有打开 UE 界面、启动游戏或执行测试。
