# 终律·镇魂钟：第二款传说锤头设计

本目录保留用户已认可的概念设计稿与最初建议玩法。后续已获授权制作模型、双重重击及玩法接入，当前交付状态见 `../FinalTollIntegrationV1/README.md` 与实际制作回执。

## 外观

成对纵向钟室，镂空拱窗与内部符文音柱，黑铁、风化暗青铜和少量象牙银包边。苏醒时苍金色竖向声纹亮起，细光尘缓慢上浮。破坏符文只将魔法发光与声纹转为红色。

与「星誓·封界之砧」区分：由横向层叠、圆形宝石核心改为高挑钟室与音柱；由蓝色范围爆震改为苍金单体重击镇魂。

## 建议效果：镇魂刻印

- 常驻重击伤害＋15%。
- 苏醒期间，每次重击有效命中为该目标叠加1层镇魂刻印，持续6秒，命中刷新时间。
- 同一目标达到2层时消耗刻印，造成350%当前魔法攻击力的单体附加魔法伤害，触发重击的削韧效果×2。
- 每次重击对同一目标最多叠1层；按武器实例、目标分别计数。苏醒结束、换装或目标死亡时清除。
- 搭配破坏魔力符文时，附加魔法伤害为700%魔法攻击力，魔法表现转红，并保留既有属性效果。
- 迅捷魔力符文保留5次有效攻击苏醒与既有＋10%普通攻击速度；刻印仍由重击施加。
- 与星誓占用同一锤头槽位，效果不叠加。

上述数值均为建议，尚未写入游戏数据。
