# 破势古印座

依据用户批准的 `../AncientSealConceptV1/ancient_seal_hammer_seat_design_01.png` 制作。配件身份为 `head_mount / ancient_breaking_seal_seat`，钢制双手锤与符文战锤共用的特殊品质改造。

## 模型与接口

制作古铜包覆锻铁的八棱主体、双面凹刻古印、嵌银回纹、沉入式销钉、分层包边和连续铜制柄套。主要轮廓、印槽、框饰及套座均为实体几何。两种宿主分别保留原装左右接面和下端连接面，并插值保存切口面角属性；不对整件模型做统一缩放来适配。

| 版本 | 原装侧接面 X（m） | 下端 Z（m） | 安装偏移（cm） |
| --- | --- | --- | --- |
| Steel | -0.040 / +0.040 | 0.865 | 0, 0, 0 |
| Runebound | -0.0354452141 / +0.0345547859 | 0.842 | 0, 0, 0 |

`AncientSealSeats_Editable.blend` 保存两个最终网格，默认显示 Steel，Runebound 可单独切换显示。各宿主的 Construction 文件保留分件制作源。`Export/` 为实际 FBX，`Textures/` 为每个宿主独立烘焙的 4K BaseColor、ORM、切线法线。ORM 使用 AO/Roughness/Metallic；OpenGL 法线在 UE 翻转绿色通道。

Steel 资产路径为 `/Game/Weapons/CommonHammerSeats20261024/AncientSealV1`；Runebound 网格保留在 `/Game/Weapons/RuneboundWarhammer20261022/AncientSealV1`，以维持现有符文战锤锤座锚点识别。两者共用古印嵌件、目标印纹、音效与图标。

## 已实现机制

装备后被动属性：体力消耗 +10%、攻击速度 -5%、韧性伤害 +5%、物理伤害 +5%。四项通过共享锤座目录的标准属性倍率接入，钢制双手锤与符文战锤共用；与目标上的破势印减益分别结算。2026-10-25 已同步正式配置与制作入口，本次仅修改数据和说明，无需构建或资产重导，未运行游戏测试。

快速近战对仍存活的敌人造成有效伤害后施加 8 秒破势印。目标后续受到的物理伤害提高 15%，受到的韧性伤害提高 25%；重复命中刷新同一个目标状态，不叠加数值，不由后续命中消耗。

| 接入点 | 行为 |
| --- | --- |
| `ColdSteelSkillRules::Snapshot` | 按实际武器与已安装锤座捕获破势资格 |
| `ColdSteelSkillModel` | 快速近战命中结算之后，由服务器给存活敌人上印；首次施印不追溯强化本次伤害 |
| `CombatStatusFormula` | 独立读取破势印的 15% 物理承伤乘区，保留其他易伤状态 |
| `MonsterCombatComponent::ToughnessDamageFor` | 固定基础削韧与通常削韧路径均应用 25% 加成 |
| `AncientBreakingSealComponent` | 目标拥有一个可刷新的到期时刻，复制位置、来源与刷新序号，显示 3D 印纹、刷新提示与到期淡出 |
| 状态目录及图标绘制 | 新增“破势印”减益说明及图形标识；支持净化与原有状态免疫 |

原有群体快速近战按每个实际命中的目标施加；目标上的状态也作用于队友的相应伤害。普通攻击和其他武器行为本身不会触发该锤座。

## 表现与制作文件

古印嵌件常态为暗朱色，命中时短暂发出暖铜光。命中位置印纹与头顶古印都复用同一份有厚度的 `SM_AncientSeal_TargetMark` 立体线条，正常深度遮挡，不使用带不透明底板的图像卡片。

2026-10-25 新增头顶金色悬浮古印：按目标体型将印纹高度设为 26–44 cm，底缘离身体顶部约 15 cm，上下轻浮 3 cm；朝向当前观察者，常态保持可见并轻微呼吸发光，刷新时短暂变亮。角色使用胶囊与主体网格顶部，其他目标使用首次创建时的碰撞包围盒顶点，排除印纹自身造成的高度反馈。使用同一材质的 `MarkColor` 参数区分暖铜命中印与明亮金色头顶印；不重复加载网格或新增粒子系统。

两处标记随同一个 8 秒破势印状态显示，最后 0.7 秒淡出；重复命中刷新该状态，不叠出多枚头顶印。目标死亡、状态清除或销毁时两处表现均移除；专用服务器不创建图形组件。修改、必要构建和材质保存入口及回执保存在 `OverheadV1/`，本轮未进行游戏或联机测试。

`S_AncientSeal_Impact.wav` 为原创合成的短促金石尾音，随目标位置播放，配置距离衰减及有限并发。未试听。`head_mount_ancient_breaking_seal_seat.png` 来自实际模型灰阶输入与内置 imagegen，提示词保存在 `icon_prompt.txt`；灰阶只用于统一改造图标，游戏模型使用古铜、铁、银和暗朱配色。

`author_model.py`、`author_audio.py`、`author_icon_input.py` 为制作入口；`build.ps1` 进行必要构建；`import_assets.py` 在启用 D3D12/SM6 的后台作者进程中完成材质 GPU 编译和资产保存；`publish.py` 只合并本配件、状态定义及两种宿主配方，保存原文件备份。

以 `build_receipt.json`、`import_receipt.json`、`published.json` 分别记录构建、已保存资产和实际目录接入。未运行游戏、联机测试、截图或视觉验收；由用户确认实机表现。
