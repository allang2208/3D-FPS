# M24 冲刺肩端与上臂衔接 — 2026-10-31

用户反馈上一版小臂已有改善，本轮只继续优化上臂及靠近身体的尾部。沿用 `M24SprintArm20261031` 的已保存动作，保留其小臂、左腕、手指、枪位与右手；待机、换弹、检视等片段不修改。

## 修改内容

- 当前肩端仍沿用上一版调整前的方向，与上臂的原生关系在稳定冲刺中相差约 45 度。重新建立锁骨／肩端与上臂的原生连接，避免尾部蒙皮保留旧方向。
- 以肘点为中心、沿当前肘关节弯曲平面将上臂尾部下收 12 度；上臂长度保持，肘点及整段小臂／手掌的世界目标不动。这样改善上臂尾部的轮廓，且无需重新调整已经改善的小臂抓握。
- 修正随冲刺进度在前 65% 内平滑进入；循环保持，退出按现有 canonical enter 反向恢复。肩端、上臂、前臂三根骨骼的局部轨道负责联动补偿；前臂的世界姿态保持原有目标。
- 只有肩端的位移与上述三根骨骼的旋转通道改变，保留原有缩放。原生骨长、V9 网格／矫正形状、前臂 twist_01 100% / twist_02 50%、所有手指轨道保留。
- 更新 5 发、10 发弹匣两份配置中的进入、循环、退出，共六个片段。其他动作与衣物配置逐项保留，不修改 C++，无需 DLL 重编译。

- `read_inputs.py` 本轮通过已有编辑器桥读取实时配置、原始动作及网格；修改前资产保存在 `Before/`，输入散列见 `input_manifest.json`。
- `probe_saved.py` 是首次准备期间使用的上一轮保存快照，其资产散列与当前磁盘匹配；正式 `solve.py`、`author.py` 使用本轮新读取数据。
