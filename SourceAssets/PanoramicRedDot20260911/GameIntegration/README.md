# 全景薄框红点 · 游戏接入

来源为 `../Reroll03/reroll03_textured_master_00001_.glb`，RTX 5080 / TRELLIS.2 第三版生成母版，99,829 三角面。保留并平滑生成镜框，切除有错误按钮和孔洞的下部，重建底座、支撑、紧固件与按键。不是纯生成直出，也没有把整个模型换成程序造型。

用户要求底座匹配枪械导轨后，底座主体从 52.5 mm 收窄至 25 mm；夹脚外宽 23.6 mm。上方镜框保持约 55.3 mm 原尺寸，只有镜框下方的支撑向两侧展开。底座长约 59 mm，整件高约 47.5 mm。世界和作者坐标都是 X 朝枪口、Z 向上、底部安装面 Z=0；作者数值为厘米，FBX 导出转米，UE 导入一次转厘米。

## 网格和材质

- 最终 15,894 三角面，较 99,829 面母版减少 84.08%；主体 15,388，镜片 126，红点 380。
- 主体零开放边、零非流形边、零退化面。镜片为有意保留的单面光学面，双面材质；其边缘沿实际镜框内侧射线采样，有嵌入余量。
- 四张 2048² 烘焙图：BaseColor、Roughness、Metallic、Normal。石墨色阳极氧化金属、机加工紧固件和橡胶按键合并为一个 UV 图集；UE 导入法线翻转绿通道。
- 三个运行材质槽：主体、低透明度镀膜镜片、独立自发光红点。镜片和红点是专用材质，不宣称有完整光学仿真。
- `PanoramicRedDot_Editable.blend` 为可编辑源，`SM_PanoramicRedDot.fbx` 为引擎入口。`beauty.png`、`side.png`、`ads.png` 均为最终模型直接渲染。

## 游戏入口

资产 `/Game/Weapons/PanoramicRedDot/SM_PanoramicRedDot`；M4 枪匠“瞄具”下新增 **全景薄框红点瞄具**，ID `panoramic_red_dot`。原全息瞄具保持独立选项，不自动修改玩家已保存配置。

`SetGunsmithOpticVariant` 统一角色、枪匠草稿、独立物品展览、库存图标和地面武器入口。沿用 WPN_root 挂点及导轨基准；新光学中心为局部 `(2.125,0,3.25)` cm（红点面），镜片中心 `(2.15,0,3.25)` cm。ADS 及射击方向共用该点，机械照门和准星随光学配件折下。属性、弹药和动作选择不因新瞄具改变。烹饪目录已登记。

## 复现

1. Blender 后台执行 `build_model.py`：修整、减面、烘焙、导出和渲染。
2. UE Python commandlet 执行 `import_assets.py`：导入、建立材质并读回尺寸与三角面。
3. 编译当前 FPSGAMEEditor 原生模块，使用独立 suffix，启动新游戏进程。
4. `run_validation.ps1 -RunId <唯一标签>`：隔离 profile 下写入和新进程重载两轮，结果保存在该标签目录。

运行审计覆盖草稿、取消、保存失败回滚、安装/拆除、旧全息互换、实例隔离、ADS 光学中心、水平和导轨角度、真实开火/换弹、未装备实例、独立展览、库存图标与地面模型。当前 DayNight_Lighting 地图为无限备用弹，审计按此现行规则检查库存不扣弹；有限备用弹地图仍使用实际扣弹预期。素材导入 commandlet 的既有 GameFeatureData 配置和 HTTP 8000 端口错误导致退出码 1；`PANORAMIC_IMPORT_PASS` 与新游戏运行证据另行记录，不能将退出码写成 0。

初次小红点在抗锯齿后不清晰，最终直径调整为 0.9 mm，自发光 40；以实际 1600×900 游戏截图中心红色像素验证可见性。旧审计对无改动重复 Apply 的失败预期及同帧输入时序也已修正。原失败记录保留，不作为最终验收。

最终结果与文件散列见 `acceptance.json`。上游参考图仅用于外形设计，不作为最终贴图，也不套用其他枪械资产的许可。所有生成回执与原始模型仍保留在父目录；本次没有公开发布二进制资产。
