# 近战下砍与突刺：上臂开口避让 V1

2026-09-23。用户反馈冲刺攻击和三连击第三段突刺露出中空手臂，授权先调整肩／上臂位置，必要时再补隐藏模型。

后续状态：本目录仍是下砍和冲刺下砍的有效来源；当前两套突刺在本 V1 上叠加 `../ThrustElbowRepair20260923` 的肘部支持。相机顺序修正、当前资产恢复及废案归档见 [发布记录](../../Docs/Weapons/melee-arm-publication-20260923.md)。下文的构建失败为早期历史，后续相机修正已完成正式 Editor 构建，不代表当前仍处于同一阻塞。

## 来源与原因

从实际安装的标准柄、长柄动画读取源骨轨道；当前模块化符文剑、冰霜剑的真实手模分别导出到各目录 `SourceArms.fbx`。在原网格上按位置焊接拓扑仅用于识别边界，不修改源网格：两侧上臂各有 61 个点构成的开口，主要由 `upperarm_twist_01`、锁骨和少量 `upperarm_twist_02` 驱动。

第三段突刺伸尽时，标准柄右侧开口最前方约为相机前 29.65 cm；此前肩随动也把这部分截断边带进了视野。下砍的问题主要发生在举顶转入下砍的阶段，不能只处理最终落点。输入记录为 `source.json`、`geometry.json`、`opening_source.json`，均来自本次实际安装版本。

## 制作

- 标准握柄和长握柄分别更新 `Thrust`、`Overhead`、`SprintOverhead`，共六条；普通下砍与冲刺持剑转下砍均覆盖。
- 突刺：肩部最多后收 4 cm、下移 2 cm，手剑成组最多回收约 3.45 cm。
- 普通下砍：肩部最多后收 2 cm，手剑成组最多回收约 2.25 cm。
- 冲刺持剑转下砍：肩部最多后收 2 cm，手剑成组最多回收约 1.95 cm。
- 先按当前变形开口识别相关时间区间，再在前后加入平滑包络。保留原肘弯曲平面，以固定上臂／前臂长度重新求解；整段搬运辅助骨，保留掌指相对剑的握点、手腕朝向、骨骼比例、蒙皮和材质。
- 手剑只在保持肩部位置后超出自然可达距离时共同少量回收，不将两手分别移动。各段时长、攻击速度、伤害时钟、一米突进业务、攻击数值均未调整；实际剑尖随这几厘米的视觉轨迹回收。
- 只写 17 条必要的局部补偿轨道，其余骨轨道、曲线、通知和动画设置保留。起止姿态沿用原动作。

制作约束采用相机空间 82° 垂直视野、16:9 和 1.5 cm 边界余量；这覆盖当前 75° 基础垂直 FOV 及 112° 水平冲刺 FOV 的参考范围。按整个开口而非单个肩骨点约束，并用现有蒙皮计算边界位置。六条的作者求解均无需追加隐藏几何，因此本版没有改动手模拓扑、双面材质、全局 FOV 或近裁剪距离。

以上是源数据上的制作约束，不能替代游戏画面验收，也不承诺任意自定义 FOV／宽高比均不暴露。

## 文件与执行

- `capture_source.py`：读取当前六条动作、两套待机参考与骨架参考姿态，导出实际手模。
- `mesh_source.py`：将 FBX 参考坐标标定到 UE 组件厘米，读取蒙皮与开口。
- `author_clearance.py`：求解肩部修正、持握整体回收和时序包络，生成 `*_patch.json` 与 `authoring.json`。
- `build_editable.py`：从本次真实手模与原始轨道重建两套 `Melee_ArmOpening_Editable.blend`，每套包含三条修正动作。
- `install_clearance.py`：核对目标未被其他修改替换、备份原包后，仅更新六条动画的指定轨道，完成压缩、完整 FBX 导出和 UE 保存。保存结果见 `install_receipt.json`。
- `Before/`：本轮被替换的六条原始 UE 动画包。

Blender 5.1 后台依次运行 `mesh_source.py`、`author_clearance.py`、`build_editable.py`。UE 读源与安装使用 `UnrealEditor-Cmd.exe <项目绝对路径> -run=pythonscript -script=<脚本绝对路径> -unattended -RenderOffscreen -AllowCommandletRendering -nosound -NoLiveCoding -multiprocess`。本引擎的骨骼网格 FBX 导出依赖 RHI，`-NullRHI` 在导出阶段触发 MeshObject 断言，因此改用后台图形上下文；没有截图、渲染成片或启动游戏。

若交互编辑器已经加载项目，改走既有 MCP 批次桥，并保留目标资产的未保存修改。默认不打开编辑器、不自行运行测试。
