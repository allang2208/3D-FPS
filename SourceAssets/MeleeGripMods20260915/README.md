## 选项

## 计算范围

- 耐力消耗的定义沿用用户最新要求：影响攻击（包括重击）和防御受击。攻击体力门槛、HUD 可攻击次数、格挡扣除和破防门槛使用相同倍率。原装基础攻击15、格挡20时，吸震缠柄为12.75/17，长柄双手为15.75/21。
- 不同栏目同类倍率相乘。例如轻羽刃与吸震缠柄耐力消耗为0.9×0.85=0.765；攻速为1.15×1.05=1.2075。攻击时长、命中窗口与声音沿用原动作时钟及速率上限。
- 速握轻柄按现有三段动作识别：Slash1 / Slash2 / Thrust 的伤害倍率为1 / 1.10 / 1.15；在起手时快照，不按击中目标数量或命中次数增长。第三段独立乘1.15，不在第二段的1.10上再次乘1.15。重击继续使用原重击倍率，连段重置、超时、换装与蓄力回退沿用既有状态规则。
- 面板总览与背包详细说明增加第二、第三段实际伤害；候选对比使用相同计算。基础伤害字段仍代表没有连段加成的一击，避免把第二/第三段额外伤害反复应用到其他攻击。
- 格挡减伤 -10% 按相对比例计算，单独使用速握轻柄时50%×0.9=45%；配合轻羽刃为50%×0.8×0.9=36%。弹反规则不变。
- 长柄双手伤害沿用现有近战改造伤害倍率口径，与剑身改造相乘后进入原强化/属性、精通及附魔流程。范围同时影响最大距离、扩展剑刃扫掠及命中半径，保留突刺位移和模型尺寸。
