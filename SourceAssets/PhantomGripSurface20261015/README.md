# 幻影后握把表面优化 · 2026-10-15

范围：M4、AKM、QBZ191、M16、HK416、A762、PKM、LMG201、Super90。所有运行时资产沿用原路径及材质绑定。

## 定位

- 中性材质、关闭贴图后，旧约 5 万三角面主体仍有明显碎面反光；重新计算法线不能消除。原始 seed 91627 高精度模型表面明显更连续。
- 旧减面模型存在大量断开边，沿用了分裂的纹理壳。粗糙表现不只来自法线贴图。
- M16 的旧主体 UV0/UV1 大面积塌缩；LMG201 的接颈 UV4 遮罩全零。
- 5 款旧接颈还保留了塌缩 UV0，已另行修复这些小面片的物理投影坐标。

## 制作与交付

- 从同一个已认可的原始模型焊接重复顶点、清理退化边并重新减面，保留原来的镂空、握持轮廓与前侧纹路。8 款主体采用约 12 万三角面的制作基线，各枪裁切后实际面数不同。
- 从原高模传递表面法线，并通过安装变换的逆转置矩阵保留其方向。UE 使用导入法线、全精度 UV 与高精度切线基底，按实际 UV 重新计算切线。
- LMG201 保留全部 461081 个三角面，恢复原接颈遮罩，修复 6 个无效角点法线。
- 保留各枪现有安装接口几何；A762 的扳机避让、HK416/Super90 的原生接颈、PKM 的安装调整均保留。接口几何逐面比较结果见 `interface_preservation.json`。
- 已保存运行时资产见 `install_receipt.json`；最终读回检查见 `saved_asset_review.json`。源文件在 `Exports`，修改前包在 `Before`。

## 证据与边界

`Preview/*_authored.png` 是同光照下的 Blender 中性金属表面对照，不是游戏最终材质截图。LMG201 最终预览以重新冻结正确米制坐标后的文件为准。

最终独立进程读回 9 款资产：无无效法线，主体及接口的非退化面均无塌缩 UV0，原材质绑定保留，LMG201 遮罩恢复 18375 个角点；检查进程退出码为 0。

后台没有启动编辑器、游戏或 PIE。引擎仍报告近零切线/副法线提示；安装颈塌缩 UV 已针对性修复，不能把这些提示描述成全部消除。高模原有局部曲率起伏仍属于原始造型，未进行整体磨平或改变镂空结构。

初次保存完成后 commandlet 在退出阶段发生过异常，之后通过独立进程重新读取已保存资产确认数据；不能把退出异常误报为正常的全流程退出。最终游戏反光、持枪与动画表现仍由用户验收。
