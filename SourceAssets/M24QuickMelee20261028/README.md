# M24 快速近战：原生握持枪托撞击

用户要求依据长枪体和实际握点开发快速近战。本轮参考 M4 N 的发力／回收分段与 QBZ191 O 的原生握点约束，单独制作 M24 的整枪路径与肩肘支撑。

## 动作安排

- 0–0.05 s：短促收拢准备。
- 0.05–0.15 s：左手保持护木托握，收肘，长枪管转向左下侧。
- 0.15–0.25 s：右手带动整枪前送，枪托后垫领先；0.25 s 为接触时刻。
- 0.25–0.325 s：保留接触的持枪滚转方向，短促跟随、回弹。
- 0.325–0.90 s：分段收枪，准确回到当前 M24 idle；不在动作结束后另加一次整体回正。

双手掌矩阵相对 `WPN_root` 沿用实时读取的本枪 idle，手指局部姿态随掌保持。长枪的路径通过整枪／双掌共同位移适配实际臂长，未借用 M4 的后握把枢轴或肩坐标。肩根维持本枪 idle；肘部沿可达圆求解，下沉与身体侧约束参与制作，极向控制在作者关键帧间平滑插值。前臂辅助骨沿 V9 的 100%／50% 分配，未拉长骨段、修改网格或移动腰射／ADS 标定。

`WPN_StockContact` 的动作轨道使用原模型枪托后表面的作者坐标，运行时命中沿现有枪托骨探针读取，不使用瞄准镜或枪口位置替代枪托。

## 接入

- 仍共用原 0.9 秒基础序列 `/Game/Weapons/M24/MotionMagazine20261027/Animations/A_M24_quick_melee`。
- 实际新姿态写入 `/Game/Weapons/M24/MotionPolish20261027/DA_M24_SupportGrip` 和 `DA_M24_Mag10` 的 **quick_melee** 差量条目。作者源 120 Hz；恒等轨道省略，常量轨道缩为一帧。
- 安装只合并近战条目；其余动作从当前资产读取并保留，若有人同时修改近战条目则中止该批次。
- M24 采用独立 .05/.15/.25/.325/.90 秒阶段时钟，姿态、接触和占用由同一执行器推进；角色端提前发布正确片段和握姿层，跨帧命中采样不读取之前的射击片段。
- 第三人称沿既有步枪源姿态接触通道接入 M24。未另建伤害、体力、修炼、冷却或联机结算公式。
- 镜头用短促前送、回弹和衰减，命中反馈强于空挥；它只改变镜头表现。

## 作者输入与入口

- `ue_before.json`：本轮从 UE 读取的实际基础片段与两套完整配置，作为制作与冲突检测输入。
- `layout.json`：本枪肩肘、握点和枪托制作坐标。
- `author.py`、`library.py`、`authoring.json`：动作制作入口和参数。
- `M24_StockBash_Editable.blend`、`A_M24_StockBash.fbx`：可编辑动作源及导出。FBX 是作者交付；运行时通过已保存的共享序列＋新差量播放，不另外增加整套变体序列。
- `install.py`、`install_receipt.json`：两套实际配置的定向保存。
- `build.ps1`、`build-receipt.json`：后台 Editor 目标构建；不启动编辑器界面。

本轮没有运行游戏、预览渲染、截图或动作验收。人体观感、遮挡和打击手感由用户进游戏测试，制作约束与编译成功不等同于视觉通过。

原模型与骨架派生许可继续沿用 `../M24CustomScope20261026/ATTRIBUTION.md`；本轮未下载新的第三方动作。
