# QR 高性能后托细节精修

用户于 2026-09-12 查看改造栏截图后指出 5080 生成几何精度不足、细节粘连，授权精修并更新游戏。当前精修仍保留 `qr_performance` 身份、约 18 cm 的原模型尺度和 M4 / AKM 各自挂点。

## 具体修改

- 以原三视图和 5080 生成源的尺寸为依据，重建连续后架及三个镂空窗口，整理规则孔边和倒角。
- 前斜撑增加明确的浅凹槽；调整拨片、凹六角螺钉及圆形背带接口独立建模，避免原生成母版的熔融起伏。
- 上部贴腮壳具有真实贯通安装孔；两侧垫片嵌入独立凹面，保留窄接缝，防滑颗粒使用细小独立几何。
- 后部金属承架、橡胶肩垫分离；肩垫接触面使用规则横纹。
- M4 金属槽继续使用实际枪身 `Body_001`；AKM 使用 `M_AKM_Soviet_PBR` 并保留专用机匣盖板。聚合物、橡胶使用独立粗糙度参数，新表面不再使用旧生成模型烘焙出的宏观凹凸法线。

此轮属于按已有轮廓进行的硬表面重拓扑与细节重建，不是重新请求 5080，也不是只增加面数或平滑旧模型。原三视图、5080 原模、初版游戏网格和上轮截图继续保留在上级目录。

- `refine.py`：精修作者入口，Blender 后台运行，仅制作和导出。

- `M4/QRStock_Refined_Editable.blend`、`AKM/QRStock_Refined_Editable.blend`：合并后的游戏网格源。
