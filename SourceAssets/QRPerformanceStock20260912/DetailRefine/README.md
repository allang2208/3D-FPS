# QR 高性能后托细节精修

用户于 2026-09-12 查看改造栏截图后指出 5080 生成几何精度不足、细节粘连，授权精修并更新游戏。当前精修仍保留 `qr_performance` 身份、约 18 cm 的原模型尺度和 M4 / AKM 各自挂点。

## 具体修改

- 以原三视图和 5080 生成源的尺寸为依据，重建连续后架及三个镂空窗口，整理规则孔边和倒角。
- 前斜撑增加明确的浅凹槽；调整拨片、凹六角螺钉及圆形背带接口独立建模，避免原生成母版的熔融起伏。
- 上部贴腮壳具有真实贯通安装孔；两侧垫片嵌入独立凹面，保留窄接缝，防滑颗粒使用细小独立几何。
- 后部金属承架、橡胶肩垫分离；肩垫接触面使用规则横纹。
- M4 金属槽继续使用实际枪身 `Body_001`；AKM 使用 `M_AKM_Soviet_PBR` 并保留专用机匣盖板。聚合物、橡胶使用独立粗糙度参数，新表面不再使用旧生成模型烘焙出的宏观凹凸法线。

此轮属于按已有轮廓进行的硬表面重拓扑与细节重建，不是重新请求 5080，也不是只增加面数或平滑旧模型。原三视图、5080 原模、初版游戏网格和上轮截图继续保留在上级目录。

## 可编辑源和导出

- `refine.py`：精修作者入口，Blender 后台运行，仅制作和导出。
- `M4/QRStock_Refined_Parts.blend`、`AKM/QRStock_Refined_Parts.blend`：保留独立零件，并附隐藏的原生成参考集合。
- `M4/QRStock_Refined_Editable.blend`、`AKM/QRStock_Refined_Editable.blend`：合并后的游戏网格源。
- 每个枪型目录的 `SM_QRPerformanceStock.fbx`：游戏导出。
- `import_refined.py`：导入到既有 `/Game/Weapons/QRPerformanceStock/M4/SM_QRPerformanceStock` 及 `/Game/Weapons/QRPerformanceStock/AKM/SM_QRPerformanceStock`，绑定三个材质区域。
- `authoring.json`：作者导出信息。当前接口修正版 M4 为 92,578 三角面，AKM 为 97,196 三角面；增加部分主要用于规则倒角、独立硬件、防滑颗粒及 AKM 金属图集分块。

本轮是资源替换，复用现有装配入口、目录、保存和属性；没有原生源码改动，不追加原生编译。

制作进程已导出两款 FBX；UE 脚本记录两款精修网格均已导入保存。整个 commandlet 退出码为 1，日志仍有工程 `GameFeatureData` 规则缺失，并出现 `127.0.0.1:8000` 监听绑定失败；这与已完成的资产导入分别记录，不声称导入进程零错误，也不为本次资源精修改动相关配置或占用端口的其他进程。

最初精修轮次按用户规则仅制作、导入，未主动测试。随后用户明确要求预览，并指出改造面板穿模与上方材质不统一；以下仅针对这两项进行排查，不追加玩法回归。

## 2026-09-13 接口与上盖修复

- 上盖此前误分配 `StockPolymer_Refined`。现将硬壳归入枪身金属槽，并重建对应枪型的金属图集 UV；两侧防滑嵌片及橡胶肩垫保留独立非金属材质。
- 挖贴腮凹槽、AKM 图集切面后，旧自定义法线没有更新。现将最终法线处理放到所有几何编辑之后，保持大平面法线，消除上盖三角明暗折痕。
- M4 保留安装原点，上盖及前框局部避让原机匣尾板，接环随接口调整。
- AKM 保留安装原点，单独增加尾舌内腔并调整接环；转接盖板前面由 X=-0.09 cm 改为 X=0.31 cm，避开机匣保留边缘 X=0.282 cm。
- AKM 金属图集交替镜像采样，使分块边缘连续，避免硬壳上出现突兀的纹理接缝。

`diagnose_assembly.py` 是本次明确要求的接口排查入口，加载冻结的实际枪身变形参考，以运行时相同枪根变换比较上盖、前框、接环及 AKM 转接盖板；并输出装配近景。它不会启动射击、换弹或存档测试。证据留在 `Diagnosis20260913/Before`、`After` 和 `Final`；最初独立预览在 `Preview20260913`。运行结果及材质绑定见同目录日志。最终游戏效果仍由用户测试。
