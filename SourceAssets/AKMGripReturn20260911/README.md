# AKM 换弹直接回到已安装握把 — 2026-09-11

后续腕肘支撑已在 [AKMArmSupport20260911](../AKMArmSupport20260911/README.md) 完成；当前运行引用 ArmSupportFinalV2，并保留本轮直接回握和压缩后手指姿态。本目录继续作为回握时序的作者基础。

当前 AKM 可选前握把为棱镜短握把和共振二代斜握把。本次覆盖二者各四种换弹（普通、空仓、弹鼓普通、弹鼓空仓），共八条。

问题发生在动画源的回握时段：普通动作约第 320 帧已回到默认护木，但旧握把修正从第 352 帧才开始；空仓动作第 440 帧已回到默认位置，旧修正从第 467 帧才开始。仅检查最后一帧或结束后的待机，无法发现中间多出的默认握姿。

新动作从最后操作后的离手阶段直接回到已安装握把：普通源帧 270–330，空仓 380–440，均为 120 Hz。先沿握把外侧接近，再收指包握；到位后保持相同枪根局部握姿直至切回待机。没有修改运行时混合时长来掩盖动作路径。

- 保留已接受的握姿、手模、骨长和权重。
- 前段取弹、插入、空仓拉栓及业务时长不变。
- 保留上一轮右手食指自然弯曲、弹鼓先拔出再脱手，以及原厂弹匣在弹鼓预览中隐藏的修正。
- 当前专用换弹引用 `/Game/Weapons/AKMIntegration/SovietFab/GripReturn/{prism,angled}`；无前握把的基础换弹仍使用 ReloadPolish，待机等已接受姿态仍使用 Attachments。
