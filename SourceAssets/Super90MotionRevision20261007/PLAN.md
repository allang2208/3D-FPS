# Super90 装填器手部动作重制计划

用户目标：按 BV11wTe6sEsS 的 40–44 秒复刻可见动作，旧版装填器动作不合格。用户要求继续后，已按此计划制作 Reference R2 动作；实际导入和构建状态见本目录 README.md。最终视觉仍由用户确认，不宣称达到 100%。战术冲刺另见 `../Super90TacticalSprint20261007/README.md`。

## 参考与差异

参考地址：https://www.bilibili.com/video/BV11wTe6sEsS/

本地公开参考视频为 30 FPS，854×384；`Reference/40-44_sheet.png` 和 `Reference/40.5-42.5_sheet.png` 是源视频动作分解，不是游戏验收截图。实际动作约从 40.63 秒开始，42.50 秒恢复持枪；40–44 秒包含前后待机。以下时间为画面定位窗，制作时在原始 30 FPS 上定关键帧。

旧版 `author_speedloader.py` 从第 6–25 帧直接将左手插值到推杆握点，第 12 帧即显示装填管，第 24–56 帧对接，不能表达参考中的下探取管、短暂留空与最后张手回握。旧版拇指释放枪机是为游戏空仓分支另行设计，不能说该动作来自这段非完整空仓参考。

## 分段制作合同

| 参考时间 | 画面动作 | 重制内容 |
| --- | --- | --- |
| 40.63–40.80 s | 左手松开护木并向下出画，右手继续握持 | 分开手指松握、腕部退让、整臂下探三个时钟；先脱离接触再移动，不能穿过护木。 |
| 40.80–41.60 s | 枪身侧倾后维持，左手和装填器主要在画面外 | 右手和枪体共用刚体变换，以握柄为约束；保留这段留空，禁止提前把装填管横摆在镜头前。 |
| 41.60–41.75 s | 装填管从左下方进入并就位 | 从相机画面外建立弧线轨迹，先拟合可见管轴、枪体倾角，再解算左肩肘腕；接触后锁定管口。 |
| 41.75–42.10 s | 管身保持斜向，完成推送 | 管口相对枪体不滑动；手指包住推杆握部，掌心跟随推杆；推杆与入仓事件使用同一时钟。 |
| 42.10–42.30 s | 撤管，左手重新进入画面并张开 | 先退出接口再收管；分指展开、腕部转向及整臂回程分别设关键帧，不能从握管拳形直接插值到护木握姿。 |
| 42.30–42.50 s | 左掌接回护木，枪身回正 | 手掌先接近、接触，再闭指；接回当前原厂或已安装前握把的实际握点，末帧与待机完全衔接。 |

## 制作顺序

1. 先制作满容量普通装填的独立候选，以原视频中的枪轴、右腕、左腕、掌心、管轴作为可见关键点。用参考画面时序约束曲线，不再从旧版 54° 单轴侧倾和直线插值推导整段动作。
2. 固定右手握柄接触和装填管口接触，分别设计左手取管、握推杆、松手、回握的手型。每个阶段给出腕部相对前臂的旋转，分配到原生 `lowerarm_aux`、`lowerarm_twist_02`、`lowerarm_twist_01`；肘部弯曲方向连续，保留骨长和 V7 手臂体积。
3. 将参考中的可见动作与本模型的实际尺寸配合。视频没有展示的掌心背面、完整取管位置和推送手指细节作为三维适配记录，不能伪称从单视角恢复了不可见动作。
4. 满容量普通动作确定后，派生 1–7 发版本。各版本保留取管/对口/撤管/回握，仅按缺弹数量截短推送。保留已经入仓才扣弹、软中断先完成当前一发、硬中断沿用现有仲裁的合同。
5. 空仓分支共用装填段，但枪机释放另外列为需要参考的阶段；40–44 秒没有足够证据支持旧版“左拇指按释放钮”的 100% 复刻说法。不得把缺少依据的空仓动作混入普通装填。
6. 四种前握把只保存入场/回握的左臂差量，不改变操作装填器的主体段。导入时替换对应条目，同时保留本轮战术冲刺及其他原动作。
7. 参考时序约 1.87 秒，旧版完整普通动作 2.4 源秒按 1.3 倍播放约 1.85 秒。先保持既有基础 1.3 倍设置，通过源帧时钟分配匹配参考的各阶段；角色/配件倍率继续按游戏合同作用，不能把总时长接近当作动作已经复刻。
