# M870 通用瞄具

当前制作批次：2026-10-16。物品 `ue_m870`，资产目录 `/Game/Weapons/M870/Optics20261016`。

## 制作与接入

| 通用 ID | 瞄具 | 独立夹座 |
| --- | --- | --- |
| holographic | 全息 | 原底座夹槽对应截面 |
| eoth_holographic | EOTH 全息 | 较深夹槽、横向止退件避让 |
| panoramic_red_dot | 全景红点 | 短座、较高的内部承压面 |
| prism_scope_2x | 2× 棱镜 | 短座、低内部承压面 |
| lpvo_1_6x | 1–6× LPVO | 前后双环底座、原倍率环 |
| thermal_scope | 热成像 | 底部横向止退槽、原倍率旋钮 |

五个普通瞄具及 LPVO 倍率环复用 SUPER90 当前独立瞄具网格，热成像复用 Common 网格和旋钮。制作的是 M870 私有副本；保留各自原 UV、光学网格、镜片、分划与瞄准插槽。夹座另建独立静态网格，沿 M870 的原生 `WPN_root` 跟随机匣。

轨面中心为组件空间 `(0, 1.88748126, -70.752369)` cm，朝向 `(0,-1,0)`；可用长度 90.7226 mm，顶部半宽 7.2548 mm、下斜翼半宽 9.6404 mm。夹座底面承压于原导轨，内侧夹爪沿其斜面，下层后端避开原后机瞄座。上层按实际供体底座的下表面制作，给止退件形成凹槽。瞄具整体偏移与夹座出自同一 `authoring.json` 参数。

新增夹座的独立 UV、倒角与法线在 Blender 制作；涂层基色、金属度和粗糙度从原枪导轨的 16 个 UV 样点提取，带 `WeaponWetness` 粗糙度参数。没有把原枪图集套到新 UV 上。

`M870OpticVisual.cpp` 管理六种组合、拆卸恢复及两个倍率机构。`M4GunsmithVisual.cpp` 分派到 M870 并使用瞄具的 `SightRear`；原有管式霰弹枪 ADS 标定读取 `SightRear/SightFront/SightUp`。热成像直接进入本枪组装路径。资源预加载包含镜体、夹座和倍率机构，枪匠、图标及拾取物沿既有角色组装入口，第三人称装备沿既有附件复制入口。普通五项加入本枪目录，热成像继续使用 `common_options.optic`；存档沿用现有 optic 配件 ID。

## 重制

运行本目录 `rebuild.ps1` 可后台制作、必要构建、导入及保存。`read_inputs.ps1` 单独更新供体导出输入；默认重制使用本批已有输入。每个 `Exports/M870_*_Editable.blend` 包含瞄具与夹座的可编辑装配，FBX 仅导出夹座。`install_receipt.json` 记录实际保存资产，`build_editor_final.log` 记录最终原生构建。原始 M870 目录登记脚本也保留已经加入的瞄具选项。

本批不修改 M870 枪体骨骼、蒙皮、原机瞄及动作。未启动游戏或进行测试、截图、渲染和实机验收；接触外观与瞄准效果由用户测试。
