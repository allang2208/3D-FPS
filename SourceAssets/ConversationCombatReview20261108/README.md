## 已修复

1. **锥形锤座伤害类型**：公式输入已使用物理面板，但本地与远端服务器生成的命中快照仍混入宿主战锤魔法通道。现在两端共用 `ConicalHammerSeat::PrepareQuickDamage`，保留基础/附加物理比例，清除这次前顶伤害的基础/附加魔法分量。其他法术触发不变。
2. **快速近战与持握身份**：服务器接受动作时记录主副手槽位、实例及武器定义，命中时核对。换主手、换副手或换另一件同型号武器后，旧动作编号不能继续授权新装备命中。结束动作清除绑定。
3. **副手快速近战节奏**：起手保存迅捷动作倍率，执行、恢复和第三人称进度共用本次倍率。迅捷中途到期不会使同一次劈砍突然减速。
4. **蓝焰与电环附着时序**：Niagara 改在 `TG_LastDemotable` 按组件 TickGroup 模拟，本地第一人称使用 Solo；星髓参数更新等待角色、剑与身体姿态。修正批量模拟只读取父节点前置依赖、可能早于晚帧参数生产者的情况。火焰颜色、密集核心、篝火图集及当前已保存 V10/V11 资产均保留。
