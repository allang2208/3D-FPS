# 保留原腕部的肩肘修正 V4

后续状态：仅两支冲刺 `Overhead` 已由 [下砍中段伸展 V5](../RuneSwordDowncutReach20260920/README.md) 替换。V5 保留本版手腕朝向与握姿，展开此前仍接近直角的下砍中段；待机、走动及其他攻击继续使用 V4。以下保留本版制作记录。

用户反馈肘部 V3 的手部观感比前版差，要求保留手腕，仅优化手臂与肘关节。

V3 虽然保留了手骨世界变换，却移动了肘位，改变了前臂到手腕的接入方向；同时重做腕侧 twist，不能据此称为保留原来的腕部观感。**V3 不再作为当前姿态方案。**

## 本版制作约束

- 以 V3 之前保存的实际安装轨道为源，冲刺攻击继续采用 ImpactV2。恢复原来的肩、肘、腕位置、前臂方向及弯曲平面，不再压低待机肘位。
- 锁定原手腕与手掌世界变换、全部手指，以及腕侧 `lowerarm_twist_01` 的位置和朝向。这样同时保留握点、手型、手腕折角与腕侧支撑，而非只保留一根手骨。
- 只在原本存在较大肘部轴向差的姿态里，给上臂有限滚转支撑，并调整肘帽和近肘辅助骨。上臂额外滚转上限 45°，肘帽补偿上限 60°，补偿沿前臂渐退，并在腕侧归零。这里是制作参数，不是人体医学限位。
- 已有肘部支撑的下劈中段直接沿用原姿态。普通柄与长柄分别读取各自原轨道，保留长柄握距。
- 撤销上一轮对待机、走动、下劈及相邻动作待机衔接的肘位下压。相邻动作只在待机邻域加入新的近肘支撑，原工作段继续保持。
- 全程保留骨长、比例、蒙皮、手指、武器轨迹与时序；2.60 秒冲刺动作、命中窗、竖直扰动、音效与镜头冲击不改。

## 文件与接入

- `wrist_locked_solver.py`：近肘支撑求解。
- `author_wrist_locked.py`：从原始安装快照制作完整局部补偿轨道，确保父骨变化后手腕/腕侧骨仍留在原来的位置与朝向。
- `Standard/`、`LongGrip/`：可编辑轨道 JSON，以及待机、走动、下劈 Blend；接入脚本导出完整 FBX。
- `target_inputs.json`：制作开始时目标包的 SHA256；修改前核对，遇到后续写入或未保存编辑时保留现场。
- `apply_wrist_locked.py`：只写原先 V3 改动过的 28 条动画的同一组骨轨道，其他骨轨道与资产设置保留；`Before/` 存放被替代的 V3 包。
- `import_receipt.json`：完成接入后记录已保存资产、可编辑 FBX 与恢复路径。
