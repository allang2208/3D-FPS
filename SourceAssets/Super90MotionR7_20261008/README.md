# Super90 快速装填：接口、支撑臂与节奏 R7

2026-10-08。对应用户反馈：装填器下方衔接口悬空、不负责装填的手穿模、动作匀速僵硬。沿当前 V7 原生骨架制作，继续使用已保存的 BV1Re411e77Q 40～52 秒参考画面。

## 定位与修改

- 原导向口上沿写死在原生 Z=-0.795 m，机匣下表面约在 -0.780 m 一带，留下明显间隙。新的上沿逐点投射到真实机匣下表面，收窄至实际承接宽度，留 0.35 mm 的表面嵌合；下方开口和装填管的原对口点保持一致。导向口中间仍为空腔。
- 侧倾后右臂仍搬用待机肘向，支撑前臂进入枪体。固定右掌与握把的关系、保持骨长，按实际 V7 表面选择支撑弯面和臂根位置；本枪选出的中段参数为肘极旋转 45°、臂根下移 7 cm，并在起收段平滑交接。
- 左手松开后改为沿机匣外侧回到前护木/所装前握把，先在外侧转向，再接近握点。保持管体、推杆独立脱手下落。
- 起止使用五次平滑曲线；对口分为快速接近与短距离减速入座；推送使用连续 Hermite 速度曲线，保留每发到位时刻；枪身加入接触受力与回弹。保留现有 0.85 播放倍率，不靠整段再减速替代动作编排。
- 普通/空仓、1～7 发以及仅枪机释放分支共 15 段动画，四类前握把差量同时重制。接口、道具与动画沿用现有资产路径，其他武器、普通逐发换弹和非装填动画不在本次导入范围。

## 接触与时钟

源 60 Hz、首发 90 帧、间隔 4 帧、道具显示 74 帧、末发后 13 帧隐藏、空仓释放末发后 44 帧均保留。所有数量变体保持可中断续接所需的共同推进前缀；运行时代码、音效表和补弹业务不需要重编译。

`read_contact.py` 保存修改前与修改后关键姿态的网格交叠候选和骨骼信息；`fit_support.py` 用枪体/手臂表面、骨长与腕折共同约束制作参数。所选右臂在 42、87、114、122 帧的枪体交叠候选为零。该结果限于源模型的这些采样，不代表所有帧、衣物或 UE 实机画面均验收通过；待机原有握姿接触保留。
