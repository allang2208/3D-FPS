## 本次按用户要求完成的检查

1. **镜头与实际蒙皮**：按 C++ 静止动作锚点建立源模型相机，垂直 FOV 75°、近裁剪 5 mm。248–452 帧每帧计算右臂蒙皮表面距相机的位置：上一版最近 4.326 mm，本版最近 240.323 mm；本版该区间无右臂顶点进入相机 60 mm 范围。肩口另外以 82° 视锥和额外边距约束。记录见 `source_inspection.json`、`shoulder_profiles.json`。
2. **接触与骨长**：310–344 帧手掌相对枪机的位置偏差小于 0.0001 mm；大小臂长度差小于 0.0001 mm。全片左侧与 WPN 骨矩阵差为 0。这里是源姿态数值比较，接触手型另有近景图可查看。
3. **五分支几何与连续画面**：每分支检查 220–515 帧共 75 个采样，间隔 4 帧并包含末帧，使用实际变形后的右臂三角面和枪身、瞄具、镜座、弹匣求交。240–492 帧的采样中没有交叠。连续预览覆盖接近、拉栓、退手及首尾过渡。
4. **首尾限制如实保留**：220–236 与 496–515 的部分采样仍存在原姿态衔接中的模型交叠，不能称为整副模型处处零穿模。逐点复核这些交点均在本次源预览视锥外，输入动作在对应阶段也有此类交叠；本轮未扩大修改到原来的持枪待机。详见 `arm_weapon_intersections*.json` 与 `transition_contacts.json`。
5. **实际保存与压缩读回**：五个正式 uasset 已保存并重新加载，导入源和包哈希吻合，长度均为 4.2916665077 秒。每条对 150 个时刻、30 根相关骨比较 SOURCE 与 COMPRESSED：最大角度差 0.000360°，最大骨组件空间位置差约 0.001254 UE cm（0.01254 mm）。根节点缩放 100；上臂到肘部的组件空间长度约 27.77 cm，已记录坐标探针，避免把局部原始 API 数值当作厘米。原有骨架、压缩和 root-motion 设置保留。

这些是源模型预览、离线几何与已保存动画数据检查；不等于游戏运行验收。连续预览使用固定静止动作锚点，尾部游戏锚点混合、移动时相机效果、其它 FOV 和其它配件组合尚未在游戏中确认。
