# 弓：快速近战

2026-09-27：右手抓点与画面位置已进入 [V2 修正](../BowQuickCombat20260927/README.md)。本目录保留首版制作源，当前动作包的最新修改及保存结果见该记录。

用户要求：左手待机持弓，右手迅速抓弓，双手向左下方用力挥扫，时长接近已有快速近战，并加入屏幕抖动。

当前制作采用 V7 裸臂、ContactV9 原生骨架及 SightContactV11 待机。保留完整左手闭合握持，将其按原生左右手参考空间镜像成右手抓握，右手接触位于左手下方 11 cm。手掌、掌骨、拇指、四指作为完整抓握转换；手指闭合与腕部接近分别定时。闭合后两手与弓保持固定接触，肩肘保持原生骨长求解，收势后右手松开并退出画面。

总长 0.90 秒，与现有步枪快速近战的总长接近：0–0.14 秒抓握，0.14–0.22 秒向右上加载，0.22–0.32 秒向左下加速，0.32 秒接触判定，0.32–0.44 秒惯性跟随，0.44–0.62 秒带弓回收，0.62–0.90 秒松开右手并恢复左手待机。接触点处使用连续位置与角度曲线，不在命中帧停住。

`BowQuickCombatMotion.h` 是作者脚本与运行时共用的时序来源。`author_action.py` 在后台生成 240 Hz FBX 和可编辑 Blender 源。`import_action.py` 仅导入并保存新动作，使用既有骨架、网格及压缩设置。`run_background.ps1` 等待既有 UE/构建进程，借助现有批次互斥完成 commandlet 导入，再构建 Editor 目标。

资产：`/Game/Weapons/DarkBow20260925/QuickCombat20260926/A_Bow_QuickCombat`。弓默认使用此动作，也可通过物品字段 `bow_quick_combat_animation` 指定同骨架动作。

运行时接入原有快速近战技能入口，沿用体力、修炼、单次命中、击退和命中音效。动作本身、判定、动作镜头使用同一个动作时钟；判定时采样精确接触帧，并从弓身下段发出探针。出力镜头沿左下方向跟随，判定当帧叠加现有快速近战震动，空挥亦有动作震动。

进入动作时取消拉弓，不发射或扣除箭；已有搭箭预约保留，挥扫期间隐藏箭，结束后恢复。切武器、死亡、菜单等中断释放技能占用并停止震动。完整恢复后才允许下次攻击。
