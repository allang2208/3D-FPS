# Recipe manual derived from the existing spellbook

Source: https://sketchfab.com/3d-models/magic-book-set-ee1747b4d426446ba5f14bcf2aec8400

This revision reuses the project's blue-purple Elemental Alchemy cover, original exterior UVs and material assets, page blocks and existing double-sided leaf geometry. Changes: tabletop opening pose, spine pivot, printable recipe-page UVs, and a separate turning leaf. Recipe text is generated from current game recipe data. Hidden inner illustrations retain the existing project artwork and materials from PagesV1.

The original spellbook assets and authoring files remain unchanged. Preserve this credit, the original source attribution and modification notice with distribution. This is an adaptation of the existing model, not a newly generated replacement design.
