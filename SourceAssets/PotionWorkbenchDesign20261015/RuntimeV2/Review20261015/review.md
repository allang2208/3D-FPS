# 药水工作台代码与联机检查

日期：2026-10-15。范围：已实现的坩埚分支、其管理/操作界面、存档与现有监听服网络通道。用户本轮授权检查并修复；沿用后台处理约束，未启动游戏、未进行实际主客机测试。

## 发现并修复

| 问题 | 原影响 | 修正 |
| --- | --- | --- |
| 共享事务只回滚档案，没有回滚炼药运行缓存 | 客机备料事务最终保存失败后，可能留下未支付的活动炉、错误占用或卡死的重试状态 | 在外层交易结束后通知炼药系统；失败时还原原批次、收火并释放占用。炼药个人交易不再快照/恢复整座建筑世界 |
| 客机进度检查点只更新宿主内存 | 五秒检查点并未按约定直接落盘，仍依赖其他宿主保存时机 | 检查点绑定该客机的宿主存档槽，在发布进度前保存；不明写入结果沿现有事务冻结规则处理 |
| 客机在收火确认前清除活动状态 | 保存拒绝/回执延迟时，面板可能离开而服务器仍在操作 | 有效工作台等待服务器确认；死亡、换 Pawn、拆台等失效情况允许关闭本地界面，服务器独立暂停绑定会话 |
| 旧回执/慢档案镜像可能覆盖较新进度 | 温度、熬煮、已投料或完成状态可能退回；不相关库存版本还可能挡住最后一条完成通知 | 按同一 JobId、Revision、Elapsed 保留较新进度；轻量已确认进度写入本地档案镜像；成功旧回执不覆盖已收到的较新活动状态；补齐焦化累计、结果及保存状态 |
| 可达检查未校验当前 Pawn、当前构件实例和 World | 旧 Pawn、同格替换后的旧台或换图遗留对象可能继续保留操作上下文 | 校验 Controller 当前 Pawn、World、PrefabActorAt 实例和活动占用；距离采用建筑本体包围盒 |
| 鼠标拖动按事件频率发 Reliable RPC | 高频鼠标/高帧率下搅拌会发送过多可靠包 | 累积鼠标转角，每 0.1 秒最多提交一次，按真实转角速度计算搅拌强度，停止移动时停止输入 |
| 保存失败后领取没有阻止重试状态残留 | 成品领取成功后，残留保存重试标志可能阻止下一炉 | 保存待恢复时禁用结算入口，领取成功清理重试标志 |
| 资源准备期间可以废弃待续炼批次 | 资源加载完成后可能把已经废弃的续炼意图变成新一炉，造成意外备料 | 准备期间锁定配方和废弃入口，关闭仍可取消准备 |

## 已逐项阅读的链路

- E 入口、配方下拉、手册、备料、准备资源、进入/退出镜头及输入归还。
- 八个配方的投料、研磨、火候、沙漏、搅拌、冷却、灌装与分数/产量。
- 原料范围：背包、夹层和个人主仓库；无队友库存和世界箱子扣料。
- 原子整批领取、背包放不下保留批次、按实际未开封数量退款、已付款配方快照。
- 客机请求由拥有者 PlayerState 发出，交易绑定 Pawn/库存版本/JobId，过程输入绑定 Pawn/JobId/递增序号。
- 服务端小步骤推进、工作台排他占用、松键输入超时、失去可达性后暂停。
- 宿主客机各自模型、宿主客机存档槽、清理与换图调用、重连档案合并。
- 客机过程状态、库存回执与整档镜像的先后顺序；旁观者台面状态只负责表现。

## 静态数据结果

`data-review.json`：8 个配方引用的原料和成品 ID 均存在，备料数量与投料步骤一致，熬煮温区可达，最终冷却符合灌装要求；22 个已安装资源包均存在。此项不代表资源视觉或声音已验收。

## 证据边界

检查方式为源码阅读、流程推演、配方/资源静态核对和必要编译。没有运行 PIE、游戏、双端网络进程、存档故障注入或自动测试。实际延迟/丢包、同时抢台、强退重连、死亡/换图及背包满的玩家操作，仍需运行层确认。不能把代码路径完备或编译成功写成“联机已全面验证”。

最终后台构建：Game 与 Editor 均返回 `Succeeded`，退出码均为 0。Game 回执为 `build-game-complete.log`，Editor 回执为 `build-editor-linked.log`；主交付记录已更新。过程中的旧生成代码、并行新增接口及 DLL 占用导致的失败日志保留，未修改这些并行功能，也未终止其运行进程。
