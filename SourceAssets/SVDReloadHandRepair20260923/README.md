## 本轮手型

依据 `ue5-fps-arms-animation/references/pose-contact.md`、`github-grasp-donor.md`，以及本地 `RifleMagazineGrip20260922/ThumbOppositionV2` 的前方四指、后方拇指对握方法。

- VRE 已迁移到 Manny 的成组手型提供四指屈曲方向，固定掌骨，取消四指轴向旋转。各指保留中节／末节联动，按实际 SVD 外壳与手套适配掌位。
- 拇指以统一的掌根方向、弯曲平面和累计 MCP／IP 角重建，再换回实际骨架局部旋转。保持后侧对握，松手继续从后侧展开，避免开放姿态重新扫向四指前方。
- 相对上一版，掌位移动约 8.82 mm、整手转向约 7.44°；拇指根局部轴向扭转约 −34.68° → −12.36°。这是当前骨架上的姿态量，不是通用人体关节限值。
- 同步取匣闭合、持匣、插入、压实、松指及退手。肩肘随新掌位支撑，并使上臂及辅助骨连续承接前臂方向。保留右手、机械部件、时钟、骨长、rest、手指局部平移／缩放及蒙皮。
- 弹匣尺寸、当前枪体、后托和 PSO 材质不在本轮修改范围。

制作中尝试的侧向抓握、独立局部拇指角度方案被局部图否定，未导入。最终手型保存在 `grasp_fit.json`，实际动画作者入口是 `author_hand.py`；`author_arm.py` 只作为该入口调用的整臂辅助方法，不能单独重跑并发布为手指修复。
