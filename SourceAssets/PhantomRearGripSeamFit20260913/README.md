# 幻影后握把连接修订

上一版以原厂握把整体包围盒拟合生成模型。生成模型的翘尾高于实际连接头，导致整体最高点对齐后，连接头与机匣、扳机护圈后侧仍存在明显空隙。

本轮按 M4A1、AKM、QBZ-191 分别制作上端过渡：

- 连接头沿枪根坐标前移/上移：M4 11/12 mm，AKM 5/12 mm，QBZ-191 10/11 mm。
- 变形在枪根 Z -45 mm 至 -15 mm 区间平滑过渡，握持下半部与底座位置保留。
- M4 翘尾局部抬高最多 4.5 mm。
- 从各枪原厂握把提取上端接口轮廓，制作封闭的收窄过渡部分；AKM 限制后缘伸出。所有尺寸仅为游戏模型局部空间的作者调整量。
- 继续使用同一配件 ID 及原数值。三份静态握把导入各枪原路径的 `ReceiverFit` 子目录，运行引用切换到修订版；新增过渡材质，不重导枪械骨架/动画。旧路径因加载占用无法覆盖，故保留旧资产。
- 导入时保留每把枪现有握把的主体材质，避免覆盖并行的材质工作。

制作入口：`author_fit.py` 读取现有枪体、原厂握把和旧候选，`fit_mount.py` 制作并导出，`import_mounts.py` 更新 UE 资产。各枪目录含可编辑装配源与 FBX。`*_before.png` / `*_mount.png` 是定位连接问题使用的 Blender 源模型示意，非游戏截图、非最终材质验收。

按用户规则，未进行游戏运行测试或动画回归；实际持枪及动态效果由用户测试。导入回执见 `import_results.json`，进程日志见 `import_revision.log`；`import.log` 保留首次覆盖保存失败的记录。项目既有 GameFeatureData 配置错误可能使导入进程非零退出，应区分脚本完成回执与项目整体状态。
