# M4 重建与 QBZ-191 下沿曲线修整

2026-09-19，用户否决上一轮 M4 扩容模型，并提供 191 下沿折线图片。

## 本轮修改

- M4 从 Factory_M4 原厂网格重新制作（原源 M4HK416Replica20260910），不继续修改上一轮扩容网格。采用 119.5–132 mm 的原厂纹路区间，新增五个 12.5 mm 单元。上下壳边界以原拓扑顺序求交，按带体内连通分量维持内外壳身份，替换此前按角度排序和逐点最近壳体选择。保留插接段、抓握区、原厂底板和 UV。
- M4 新增区域使用几何分裂法线；原上部法线保留。PBR 接缝继续用原先干湿连续材质及切线变换数据。图标不再使用旧 M4 的禁用自身阴影处理。
- QBZ 保留现有主体和底板，修整弧长 142.24–220.24 mm 区间的前后边缘，以两端位置/切线的 Hermite 曲线连接，向侧面 8 mm 内渐变，替换固定半径造成的端部折线。此次最大顶点位移约 0.775 mm。
- 新 UE 路径 /Game/Weapons/ExtMagRemodel20260919，材质继续绑定各自当前正式材质。M4 与 QBZ 专属图标和 M4 共用回退图重新制作并接入；AKM、ASH、容量和动作引用不变。

## 制作入口

measure.py 为原件尺寸/部件提取；rebuild_m4.py 从原件重建；finish.py 完成接缝数据与 QBZ 曲线；install.py 导入网格；render.py 与 install_icon.py 制作并接入产品图标。
可编辑模型为 M4_ExtMag_Remodel_Editable.blend 与 QBZ_ExtMag_Remodel_Editable.blend，FBX 在 FBX 子目录。
重做全流程先运行 rebuild_m4.py 再运行 finish.py；不要单独对已完成 M4 模型重复添加接缝 UV 通道。
