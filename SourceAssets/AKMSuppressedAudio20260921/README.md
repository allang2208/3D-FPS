# AKM suppressed fire

Derived from the accepted AKM video fire one-shot. Low-pass at 2450 Hz, enhanced 70-350 Hz body, short filtered chamber returns. Original duration and pitch retained. RMS and K-weighted energy compensation are part of authoring; runtime volume and SoundWave volume remain the same as normal fire. Not auditioned or gameplay tested.

Source attribution and processing measurements: provenance.json. Local project use; source rights retained.
