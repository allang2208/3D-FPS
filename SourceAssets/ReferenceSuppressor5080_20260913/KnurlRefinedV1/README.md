# 原模型尾部斜纹局部优化 V1

用户要求：“斜纹偏粗糙：能在原模型上优化吗”。本版本直接编辑 `../seed_91353/Suppressor_5080_Candidate_Editable.blend`，没有重新提交 5080 生成，没有替换筒身造型。

尾部原有破碎、起伏不规则的外表面被局部替换为连续浅斜纹。外轮廓依据原斜纹带的截面数据拟合；两端保留原边缘，并为浅槽设置收尾过渡。非尾部的原顶点位置、面、UV、材质层和导入的逐角法线随局部编辑保留。新斜纹带为独立可编辑对象，有自己的圆柱 UV。

新带材质从原模型光滑筒身的纹理采样颜色、粗糙度和金属度，使用独立常量 PBR 材质；斜纹高低起伏由真实网格表达。主体原有图像材质继续保留。这里没有生成新的完整 PBR 贴图组。`SourceTextures/` 保存原材质的内嵌图像字节。

交付文件：

- `Suppressor_KnurlRefinedV1.blend`：可编辑局部优化源。
- `Suppressor_KnurlRefinedV1.glb`：导出模型。
- `author_knurl.py`：局部修整作者脚本。
- `author_receipt.json`：实际制作参数和导出记录。所有形状参数使用生成器原始坐标，不是制造尺寸。
- `Preview/angle.png` 与 `side.png`：延续用户上一轮图片参考请求，以原拍摄角度、灯光渲染当前实模。

GLB 导出提示一个纹理使用多个 image 节点时按首个节点的 sampler 输出；主体保留自原 GLB 导入的材质连接。本次没有追加导出读回、游戏检查或测试。尚未导入 UE，也未改变任何游戏运行引用，由用户测试。

原 5080 母版、原 Blender 和上一版图片继续保留。参考图权利记录继承上级 README，不新增公开再分发许可。
