# 战术单手斧：通用挂坠接入

在 `ue_tactical_hatchet` 改造面板新增“挂坠”列，默认“无挂坠”。槽键沿用 `lanyard`，直接引用 `shared-knife-component-options.json` 的同名公共列，不复制数值定义，也不加入尼泊尔弯刀专属挂饰。

| 通用选项 | 沿用词条 |
| --- | --- |
| 编织短绳 | 攻击体力消耗 -10%；装备期间击杀恢复最大体力的 10% |
| 铜环短穗 | 武技冷却 -10%；物理伤害 +5% |
| 方牌挂饰 | 暴击率 +10% |

## 模型与挂点

用户要求检查穿孔后，确认直接复用的宽绳根部与战斧柄尾相交，已用 `FitV2` 修正。三款挂坠保留原 `PhysicsV1` 下部外形、材质、UV2、绑定导线、质量和阻尼，仅替换上部固定连接段：直径 1.5 mm 的细绳实际穿过孔洞，沿柄尾两侧绕到下方接合。新根部使用独立深色绳材质，不参与摆动；原挂饰主体继续使用 `SwordTasselMeshComponent`。

战斧挂坠相对柄尾的最终位置为 `[0.1341219509, 0, -1.8265980792]` 厘米，父槽为 `pommel`。主体下移 5 mm，让固定连接点完全位于柄尾下方，绳孔中的连接段按实际孔心单独制作；选用其他柄尾时随对应父槽变换。原始测量保存在 `mount.json`，修正几何记录在 `FitV2/fit.json`。柄尾碰撞包络同步适配，第三人称 `HangingDynamics` 增加战斧目录识别。

默认 `factory` 配置为隐藏，恢复默认即可卸下挂坠。主副手与第三人称沿用现有模块装配逻辑和通用挂绳动态组件；改造存档继续使用现有 `gunsmith_parts`。

## 图标与落盘

三款选项直接引用既有 `lanyard_knife_lanyard_*` 共享图标。沿用批准的弯刀挂饰分类图与卸除挂绳图，一次提升为共享 `category_lanyard`、`lanyard_false`；不重新生成或为战斧复制三套选项图。

`prepare_icons.py` 准备两个共享键，`import_icons.py` 导入并保存 UI 纹理。现有 UE 远程节点不可连接时，`run_staged_import.ps1` 在同一 UE 批次互斥下使用隔离无界面工程保存新包，再由 `publish_staged_icons.py` 以禁止覆盖方式发布。目录发布入口为 `register_pendants.py`，只更新本武器的挂坠槽与改造列，保留已有斧刃、握柄和柄尾。

`ModulesV1/register_modules.py` 同步保留后来添加的槽，避免重新导出原装三段时丢失挂坠配置。最终保存与发布状态见 `icon_import_receipt.json`、`registration_receipt.json`。

## 用户指定的穿孔检查

检查了编织短绳、铜环短穗、方牌挂饰与原装、钢制、棱面、环纹四款柄尾的 12 组静态组合。原始直接复用方案均有相交；修正后作者网格与已保存 UE StaticMesh 导出的实际几何均为 0 个相交面、0 个深度超过 0.025 mm 的内部顶点。每个孔洞中面都有 12 条绳体边穿过，确认连接段确实穿孔，而不是整体移到柄尾外侧。

保存资产的复核数据与正反面、斜视图位于 `FitV2/SavedMeshCheck/`。检查图使用灰色柄尾和橙色绳体以显示几何关系，不代表游戏材质；游戏为原挂饰 PBR 与深色细绳。复现入口：`check_mount.py -- --fit --ue`。

本轮未启动游戏，也未进行动作摆动验收。
