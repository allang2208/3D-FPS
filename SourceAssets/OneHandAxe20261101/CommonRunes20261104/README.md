## 贴合规则

- 从当前真实源网格读取两侧斧面，避开柄颈、孔洞、轮廓和亮色磨刃。
- 采用斧头局部 XZ 正交坐标，横纵厘米／像素相同，保持原图比例，不将纹样拉满整件 UV 或包围盒。
- 两侧分别使用朝外可读方向；钩月使用 44 mm 方形投射区域，其余为 50 mm。纹样本身保留原留白，窗口与可用主体边界留出 3 mm。
- 位置拟合采用作者表面法线与实际 PBR 区域；只选接近正面的主体。结果烘焙进各模型自己的 UV0，运行时不重新投射或每帧扫描几何。
- 保留实际基础材质节点、法线与钢材纹理，只在符文遮罩内叠加既有通用符文金属色及轻微流光。发光继续复用 AllWeaponRuneFlow20261102/knife_material.py；纹样坐标固定，仅光强变化。

## 制作与维护

1. py -3.11 prepare_sources.py：读取活动斧刃配方及共享符文，记录 sources.json。
2. Blender 后台执行 bake_runes.py：完成实际几何拟合与 UV 遮罩烘焙；各 Kind.json 记录物理尺寸与来源，Editable 保存制作场景。
3. run_import.ps1：既有 UE 批次互斥下进行后台保存；已有编辑器时使用同一互斥下的现有桥执行 import_assets.py。
4. py -3.11 register.py：读取实际保存回执，合并战斧两份目录，保留其他配件与数值。
