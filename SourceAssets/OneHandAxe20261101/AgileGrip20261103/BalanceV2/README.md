# 破阵握柄：数值定位与功能修订

用户明确要求检查数值与功能区分。此次只调整原轻捷握柄，长柄与通用改造数值不动。当前真源为上级 `design.json`；旧 ID `hatchet_grip_agile` 及模型、图标路径保留。

## 定位

| 握柄 | 用途 | 属性 |
| --- | --- | --- |
| 缠革握柄 | 普攻连击与续航 | 攻速+10%、攻击耗体-10% |
| 棱纹胶柄 | 武技伤害 | 武技伤害+20%、攻击耗体+10% |
| 层压木柄 | 蓄力、重击削韧 | 重击蓄力速度+20%、重击削韧+20% |
| 长柄握把 | 范围与物理攻击 | 距离+25%、物理攻击+10%、攻击耗体+10%、攻速-5% |
| 破阵握柄 | 对抗护甲、破韧 | 物理防御穿透+25%、韧性伤害+20%、攻击耗体+15% |

轻型钩月斧刃、缠革握柄及棱面柄尾已经提供攻速路线。旧轻捷相较缠革只有额外约4.55%的速度、5.56%的单次耗体优势，却损失10%物伤。在相同物理攻击循环、未触及攻速上限、不考虑暴击和额外机制时，输出代理为 `0.9*1.15=1.035`，低于缠革的 `1.1`；伤害/体力代理为 `0.9/0.85`，也低于 `1/0.9`。对应落后约5.91%与4.71%，不构成清楚的特殊定位。

新方案取消旧攻速、减耗和物伤惩罚。穿透是忽略目标25%的物理防御，不是固定伤害+25%，不作用于魔法伤害，也不向目标施加持续减防。零物防目标没有生命伤害收益，但依然承受20%的额外韧性伤害；耗体代价持续存在。削韧不改变击退距离、硬直时长或免疫规则。与厚背斧刃组合时削韧为 `1.3*1.2=1.56`，不是加算50%；耗体为 `1.2*1.15=1.38`。

`balance_review.py` 读取实际目录计算比较，并检查长柄未改、名称/数值真源一致、旧加减项移除与已有模型配方仍有效。计算结果见 `balance_review.json`，不视为实测 DPS。

## 功能路径

- 目录由 `WarhammerGunsmith.cpp::LoadWarhammerCatalog` 加载，包含战斧和共享选项；`GunsmithSystem::Calculate` 汇总穿透、削韧和耗体。
- 普攻/连段、重击、上挑、旋风和快速近战从本武器的 `ColdSteelSkills::Snapshot` 获得穿透。削韧经快照或技能属性进入实际 `ApplySkillWeaponHit`；快速近战用自己的削韧倍率，但包含通用削韧乘区。
- 普攻、重击释放、重击蓄力耗体、快速近战、上挑、旋风及冲刺沿现有各自费用入口读取 `Stamina`。新方案不修改攻击动作、冷却或蓄力时间。
- 修复法杖配副手斧的快速近战：`QuickCombatModifiers` 原来没有把法杖的副手刀刃作为属性来源，现在与手枪副手共用实际副手解析。主手枪弹、法术不会借用副手破甲。
- 修复双持组合冲刺：以前合并伤害只带主手穿透。现在起手保存两把武器的物理贡献与各自穿透，按各自防御结算后汇成一次伤害；服务端从影子档案重建，客户端不上传穿透数值。组合冲刺仍沿既有物理伤害合同，不混入附加魔法伤害。
- 双持普通攻击分别结算；双持重击既有独立贡献路径保持。普通单刀攻击不读取新组合冲刺字段。

## 定向检查与边界

`UHatchetGripAuditCommandlet` 使用独立 `SkillNetworkAudit_` 档案，无地图 BeginPlay。检查目录、特殊分类、斧头专属范围、长柄原数值、各类体力费用、手枪/法杖配副手的两个武器组、主手不借用副手穿透，以及双持均无/仅主手/仅副手/双方安装时的真实伤害事务。仅副手案例还在捕获后更换夹具装备，检查结算继续使用捕获值。

构建、原生检查分别运行 `run_build.ps1` 和 `run_native_audit.ps1`。最终执行结果以各自回执及 `native-check.json` 为准；未覆盖实际输入、动画画面、UDP 传输、改造台交互或用户存档重新进入游戏。
