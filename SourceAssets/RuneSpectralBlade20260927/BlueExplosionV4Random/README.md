# 幽蓝灵体剑随机蓝色爆炸 V4

用户反馈 V3 爆炸形状过于固定，要求每次命中有随机变化。本版保留蓝色爆心、冲击弧与光晕主体，保持原命中伤害、碰撞范围、射程与冷却。

- 每次命中创建独立随机流，保存该次参数；Tick 不重新抽取随机数。爆炸只连续演化，不逐帧重置形状。
- 爆炸整体尺度为 V3 的 85%～115%，三个主体分别随机拉伸、初始角度、偏移、旋转速度、扩张速度与向外漂移。
- 完整圆环改成随机起伏的断续冲击弧；光晕的瓣数、密度和翻动相位随机，爆心宽度、消散时间与发光强度也随实例变化。
- 粒子数量 32～48；光丝比例每次从 18%～38% 抽取，各粒子再独立选择。随机三束主喷散方向与散点混合，粒子的尺寸、速度、初始位置、滚转、亮度和消散时间各自变化。
- 整体寿命 0.85～1.15 秒；拖曳系数 2.6～3.8，使用解析阻尼位移。沿命中表面外半球喷散，避免主要粒子束直接进入目标内部。
- 复用已有无阴影点光源；峰值 3600～5000、闪光 0.19～0.29 秒，照明范围随整体尺寸变化。技能视觉保持蓝色。
- 上限为 3 个主体加 48 个粒子，共 51 个 ISM 实例、306 个源三角面。继续复用原六三角面网格、一个 ISM 和一个已有灯光组件。

材质实例自定义数据：第 0 项为 Kind（光点／爆心／弧／光晕），第 1 项为 Seed；均经 VertexInterpolator 进入像素阶段。SpectralPhase 为命中种子，SpectralFade 为当前随机寿命的归一化剩余量。运行时不加载新资源。

作者为上级 import_spectral_blade.py，本目录 import_random_explosion.py 只保存 M_SpectralImpact。修改前 cpp、h、作者脚本和材质包保留在 Before/。

必要常规构建记录为 native-build.log：UBT 返回 Target is up to date、Result: Succeeded，本轮未重复执行编译链接。材质落盘结果见 import_receipt.json 与 import_commandlet.log。未启动 GUI、游戏、截图或测试，视觉效果交由用户测试。
