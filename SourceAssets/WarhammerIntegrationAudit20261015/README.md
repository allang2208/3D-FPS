# 战锤改造与通用符文回查（2026-10-15）

范围：金属／锻钢战锤的锤头、中央锤座、符文、握持包覆、柄尾配重；双棱尖头锤、陨星熔核、无配重；双手剑和锤共用的力量符文。用户明确要求检查遗漏及联机问题，允许本轮范围内的回归。

## 查出的实际遗漏与修复

1. **战锤的装备被动被工具分支排除。** `ColdSteelMelee::EquippedModifiers` 原先在 `ActiveProductionTool()` 非空时直接返回空改造，因此锤类共鸣符文在通用魔法冷却等调用点漏算。现在先选实际手持入口，再保留双手剑／双手钝器判定；铁铲、斧和镐不会继承背后武器的被动。
2. **远端武器没有符文动态状态。** `CaptureWeapon` 只存持久基础材质，剥离 MID，且没有复制叠加符文。现在 `FFPSBodyAttachment` 带符文定义、选项、承载槽和实际尺寸；服务器记录实际持有者的符文，观察端按公共入口恢复遮罩、颜色、柄部环绕及原生符文材质。纯符文切换也进入装备缓存键。
3. **服务器扣费缺少即时客机回执。** 普通、蓄满重击和冲刺攻击现在返回实际体力消耗；旋风和升龙返回实际消耗及带版本和服务器时间的武技冷却。按攻击编号消费回执，重复／旧回执不重复扣费，动作结束或切换装备后仍处理已发生的扣费。监听主机不会因自己接收回执再扣一次。旋风在起手提交，升龙在实际释放提交。

## 保留并核对的链路

- 选配以 `gunsmith_parts` 的稳定 ID 写入现有物品与存档；删除的金属长柄没有重新加入可选栏。
- 客机行为从 Pawn 的影子档案取属性，服务器提交普通攻击、蓄满重击、冲刺及武技；伤害／穿透从该武器改造快照读取。
- 无配重普通消耗乘 0.95，蓄满重击额外乘 1.10；冲刺、旋风和升龙不吃该重击专用倍率。
- 陨星熔核的重击／冲刺冲击波半径为 450 cm，服务端 `AWarhammerShockwave` 执行伤害，`MaxRadius` 与 `StartedAt` 复制给观察端。
- 共鸣的全技能冷却倍率 0.85；双盘配重武技倍率 0.8；组合武技倍率 0.68。
- 力量符文只乘基础物理及附加物理，不增加火焰或魔法通道。
- 本轮没有改动共用档案上传／库存事务协议。改造后的整档上行、确认时序与重连恢复仍沿现有 PlayerState 管线；下面的隔离测试不等于实际跨进程网络测试。
