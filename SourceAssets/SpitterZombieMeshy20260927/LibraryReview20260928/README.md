# 毒液僵尸：已导入僵尸动作库筛选（2026-09-28）

用户反馈当前移动和 AttackV6 不达标，要求查看库中的僵尸动画包能否参考；随后告知已经下载导入。本轮交付为源动作读取、片段筛选和对比预览，没有重定向或替换毒液僵尸的正式动作。

## 实际资产

- 本地包：`/Game/ZombieAnimationPack`。
- 读取到 64 个 AnimSequence：32 种动作，各有 UE4、UE5 两套。以当前实际资产为准。
- 本次导出并查看 UE5 源动作 20 个：Attack A–D、Walk A–C、Run A、Idle A/B、Burst A–I/K。
- 源骨架为包内 `SKEL_Mannequin`，预览模型为包内 `SK_Manny_Simple`。灰色人偶预览不代表 Meshy 毒液僵尸的重定向效果。
- 完整清单见 `inventory.json`，导出路径与源资产信息见 `export_receipt.json`。源资产和正式毒液僵尸资产没有在本轮修改。

## 建议的下一版制作方向

1. 以 Walk_A 的完整躯干、骨盆、腿和手臂运动关系作为移动重定向基础，保留其拖步与肩部起伏；按 Meshy 的实际肢体比例处理足底和摆臂。
2. 攻击以 Attack_A 前半段的后仰/前扑作为身体动作参考，参考 Attack_D 的落步承重和站立收势，重新编排连续的站立吐毒片段。不是直接拼接两段 FBX。
3. 手臂保持下垂，随胸肩加速产生拖后和余摆，去掉源动作的主动张臂、挥掌意图。颈头单独适配目标方向，不能直接保留源动作低头或后抬头。
4. 继续遵守原战斗时序：当前 `animation_contract.json` 的攻击为 1 秒，释放点为 8/24 秒；源片段的关键相位需重新对齐，不能只对整段统一倍速。

本次选看的动作中，没有可直接替换的站立吐毒成品。移动已有合适基础，攻击有可借鉴的全身运动，但仍需适配。
