## 制作内容

- 头部：把整段动作的平均朝向偏向前方目标，保留 80% 的源头部旋转变化，并让颈部承担少量朝向补偿。取消逐帧将头锁向同一点的处理；这是离线朝向制作，不是新加实时眼球追踪。
- 身体：按步态加入小幅骨盆转动和向支撑侧的重心转移，胸部作反向补偿。肩、肘、腕使用不同的局部延迟和轻微肘部弯曲，保留四种源动作姿态，不改成向前推手。
- 双脚：用足部和脚趾蒙皮识别接触区间，拟合支撑脚后移轨迹，采用双骨腿部求解保持接触。骨盆只使用整段固定高度偏移，保留源动作的上下起伏；不再跟着每帧全身最低顶点跳动。
- 循环：在边界两侧处理源动作接缝，末键使用首帧姿势；延迟取样按循环相位回绕。
- 播放：每只生成时选一次姿态；该动作的参考步速同时成为角色本次生命期的 WalkSpeed。实际速度与参考速度的比值继续驱动动画，加减速和减速效果仍可以影响播放。
