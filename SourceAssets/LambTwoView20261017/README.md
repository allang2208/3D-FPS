第三人称原路径把大羊排映射到 `Consume.EatBread`，只混合左臂，再从混合前双手关系补算右臂。`BlendConsume` 没有一组为大羊排制作的双臂、肘、腕和辅助骨动作。新路径为独立的 `Consume.EatLargeLamb`，使用同一原生 Jason 身体骨架；保留现有饮用供体的轻微躯干节奏，重新拟合双臂与实际羊排握点。
