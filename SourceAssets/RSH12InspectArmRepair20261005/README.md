# RSH 共振握把检视：手臂跳变与锁子甲变形

2026-10-05，用户提供检视截图并要求排查锁子甲破形、整臂闪动。

## 定位

当前 RSH 共振握把使用 `DA_RSH12_angled`，检视基片段为 `A_DW715_inspect`。左手固定握把后，旧作者仍从 715 的松手检视逐帧继承肩部朝向和前臂滚转。上一轮腕部支撑修订保留了这些变化，又逐帧重选肘部平面和扭转分支，未解决连续性。

读取 299 个作者帧与当前实际 DW715 锁子甲 LOD0（磁盘包散列和保存快照一致），检视左前臂主骨单帧旋转最高 101.74°、辅助骨 116.29°；衣袖顶点单帧位移最高 10.84 cm。尖刺和闪动在动作蒙皮层已经存在，不需要以材质闪烁或袖口轻量 WPO 解释。

## 修改

- 只重写 RSH 共振握把的单持 `inspect` 左臂轨道。
- 以本枪已调整的待机支撑姿态为基准，由检视中的手掌矩阵连续运输锁骨、上臂、前臂及其辅助骨。固定握把的左手不再继承供体松手时的肩部急转，也不逐帧切换肘极或分摊有分支跳变的扭转角。
- 保留手掌和手指接触、枪体、右手、动作时长及全部非检视片段。其他前握把、双持、数值、模型与锁子甲公共配置不变。
- 上臂和前臂共同保持待机的屈肘与腕角，因此整段衣袖保持同一蒙皮形状，避免检视中额外拉长、卷折。没有扩大相机透明范围或隐藏衣袖。
- `inspect_support.py::rewrite_inspect` 同时接入原前握把总作者和上一轮腕部作者，后续重制不会恢复旧检视。
