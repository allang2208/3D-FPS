# 赤霄第二刀右肩开口修正 V3

用户反馈：二连重击第二刀的右臂根部进入镜头，能看到模型开口；整体动作已认可，只调整局部衔接。

定位：V2 的肩位保护只约束骨骼中心，没有把实际蒙皮的肩口边界纳入。当前 V7 网格右肩边界有 61 个顶点，主要受右上臂 twist 和锁骨控制；75° 垂直视角下，约 0.25–0.65 秒有开口顶点进入画框。

修正方法：以 V2 作为输入，锁住双手、全部手指、左臂、刀根及原有时间采样。右前臂围绕不动的腕点小幅随动，右上臂和锁骨围绕肘点调整，使真实肩口边界移到画框下方。保持上臂、前臂长度，沿原蒙皮骨组传递旋转；使用连续包络和平滑进出，不通过隐藏手臂、补黑面或改变相机来遮挡开口。

- 覆盖普通柄、长柄两套动画，正式路径仍为 `ChixiaoDoubleHeavyV1/A_Chixiao_DoubleHeavy_Standard` 和 `...LongGrip`。
- 第一刀至 0.12 秒的原始轨道保留；第二刀刀路、1 秒时长、命中窗口和现有握持保留。
- 继续使用 240 Hz 平台采样及 `BC_M4Viewmodel` 压缩设置。
- 未修改赤霄的传说分级、攻速被动、双斩伤害、双倍出手体力、红色剑气或背嵬加成。
- `author_root.py` 为作者入口；`review_root.py` 仅检查本次肩口与保留姿态；`install_assets.py` 保存两条已有动画并导出 FBX。运行编辑器内接入使用现有桥的批次互斥，保存前结束正在使用这些动画的 PIE。
- 本次做了用户要求的局部离线姿态与蒙皮画面检查；默认 75° 垂直视角、16:9 下，采样的第二刀及回收段没有肩口边界点进入画框。原动作中的快速回位节奏保持，修正量平滑进出。没有运行游戏验收；用户实际体验仍是最终依据。

作者源、离线检查与 UE 保存分别记录在 `authoring.json`、`shoulder-review.json`、`install-receipt.json`。是否完成游戏资产接入以 `delivery.json` 为准。
