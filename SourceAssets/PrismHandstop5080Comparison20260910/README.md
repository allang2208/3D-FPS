# 同款棱镜阻手器：5080 与混元对比

2026-09-10。5080 实机使用 microsoft/TRELLIS.2-4B、512 管线、seed 91037、shape_steps 16，未生成纹理。未替换游戏资产。

输入来自 `../PrismHandstop20260910/three_views_v01.png`，取侧视区域，经现有 ComfyUI 管线抠除背景。首轮任务 `103969ec-9efa-4f52-b79f-3b66f43bc815` 的阈值 0.61 会抠除部分金属亮部；修正为 0.76 后任务 `69aee180-de18-4b3f-a87d-47ebc890410a` 成功。两次输入、工作流和服务历史均保留；比较使用 `trellis_fixed.glb`。原始首轮模型为 `trellis_raw.glb`。

混元来源为既有任务 `1489624951358898176` 的左侧独立重建体。混元曾输入整张三视图，因此这是同一设计的实际管线比较，并非完全相同输入、相同采样预算的严格模型基准。没有重新提交混元付费任务。

混元原始文件合计 500,003 三角面，包括三个分离的重建体；表格只统计最终选用的单个阻手器。数量来自实际网格，不采用任务目标面数代替实际导出。

`compare.py` 将两者高度统一为 1，使用相同正交相机、灯光、灰材质，清除原纹理与自定义法线影响。原始网格与减面网格均渲染侧、正、背、斜视。5080 原始网格直接焊接停滞，普通体素重建加减面产生破碎结果；改用 SHARP 八叉树重建（深度 8）后减到 16000 面。混元采用重复顶点焊接与直接减面。两者后处理不同，减面图衡量当前整理结果而非纯生成能力。

此次视觉判断：混元的安装座平面、倒角过渡、背面和防滑纹更干净。5080 的棱面更硬，但原始表面存在层状条纹与凹坑；重建后改善，仍有安装座长缝、边缘缺口和不规整表面。同为 16000 面，混元的表面完成度更高；不以此次单一样本推广到所有模型。
