## 负一层触发

四个地下槽位从区域初始化开始存在，但不生成 Actor、不启用 AI、不进入预生成与生成队列，枪声、同伴警报或上层交战均无法提前吸引它们。

服务器每 0.2 秒随现有遭遇更新检查存活玩家脚部位置。使用房间旋转/平移后的本地坐标，负一层地面为 -360 cm；到达楼梯最后几阶或地下空间（脚部 Z 为 -400 至 -300 cm，且在该厅内部）后一次性释放四个槽位。此后按原世界生成调度逐只生成，正常感知与追击恢复；玩家离开、死亡或再次进入不会再次释放/复制这些槽位。来自客机的真实玩家 Pawn 同样触发，全队共享这一遭遇。

地下候选点固定在 -355 cm 探测高度，楼上候选点为 +5 cm，不允许失败后退到其他楼层。所有落点继续使用实际地面、体型导航、胶囊净空、足印支撑和玩家/怪物间距条件；失败保留待生成槽位。地下槽位尚未触发或尚未击杀时，不登记第二间房完整清除。
