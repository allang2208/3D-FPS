# Boss 泵房模型与材质细化

最新追加：顶部电缆与管道旧化，当前 23 组网格、11 份本房材质。下方第一轮记录保留当时结果，新增内容见文末。

用户明确要求检查模型细节并优化材质和表现；继续遵守此前“不重开 UE”的要求。本次检查、修改与图片都来自实际 Blender 模型。

## 检查发现与修改

| 发现 | 本次修改 |
| --- | --- |
| 电机脚座与长向钢底座之间缺少承接横梁 | 补四道床架横梁，脚座与横梁实际相接；增加安装螺栓 |
| 尾部细条覆盖在封闭圆盘上，无法形成真实通风孔 | 改成环形风罩、凹进的风机内腔与双向开孔格栅 |
| 泵体圆柱化、接口层次弱 | 重建带圆弧肩部的铸造泵壳、双法兰与密封缝、轴向吸水弯管、连接出水颈及联轴器护罩 |
| 压力罐平封头 | 改成上下曲面封头、环焊缝、顶口、支脚底板、压力表和铭牌 |
| 二层大跨格栅没有分块；踏步为实心平板 | 改成有真实缝隙的可拆格栅块、边框与中间承托，踏步采用开孔格栅与黄色防滑前缘 |
| 设备、混凝土基础和主钢架缺少边缘高光 | 添加毫米级制造倒角及加权法线；不对每根格栅扁钢叠加高成本倒角 |
| 新设备源材质主要是占位，地面读感均匀 | 绑定实际 PBR；增加褪绿机漆、暗钢架、裸钢格栅、混凝土基础、地坪、湿润地坪、仪表与铭牌 8 份本房配方 |
| 底座周围缺少环境联系 | 增加墙脚／设备基础接触污渍、分缝、检修警示线和有渐变边缘的局部湿痕；不将整间地面改成镜面 |

保留 30×26 m 主体、3.6 m 二层标高、两条楼梯、错位机械掩体、唯一入口及现有终末汇聚方案。墙面仍复用既有最终碎砖几何、UV 和原材质，不重制或替换其他房间。

## 追加：电线走天花板、管道锈蚀与旧化

用户指出电线僵硬、要求改走天花板，并继续优化管道锈迹。本次移除旧的直角设备绕线和 5.7 m 侧墙直线束，新增 8.235 m 顶棚主桥架、柜体与设备分支、吊点、绑带、接头和应力释放套。主线采用连续曲线和轻微弯曲，设备垂线从天花板到接线盒，短引线从侧面接头进入电机，保留自然下垂余量、不横跨散热片或基础前方地面。

新增 `BossCableJacket`：非金属橡胶护套、细微模压纹理与较高粗糙度，避免裸钢似的反光。桥架和吊杆仍保留钢材身份。控制点、桥架位置与线径保存为 `Authored/cable-layout.json`。

新增 `BossPipeCoat`、`BossPipeHardware`：旧漆与裸钢底层分开，叠加暗褐色氧化层、边缘较浅锈斑及锈层凹凸。腐蚀权重由实际管段和法兰位置产生，在接缝、法兰外沿、管道下侧及重力流挂处增强；锈层粗糙度升高、金属度降至零。配方与顶点通道同时写入 Blender 和待执行的 UE 导入脚本，未改公用管材。

实际模型预览：`Previews/cable-pipe-pipe.png`、`cable-pipe-cable.png`、`cable-pipe-ceiling.png`、`cable-pipe-atmosphere.png`。顶棚近景使用局部检查补光，不能视作 UE 游戏灯光。旧版快照保存在 `Sources/BeforeCablePipePolish/`。
