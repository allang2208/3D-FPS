# M870 左肘与腕部：原生辅助骨和局部表面修订

用户提供 ADS 截图，指出待机左肘拧缩、腕关节突起。本批接续 `M870TriggerGrip20261016` 的右手握姿，输入包含此前的右手修订及此前已保存的原始参考装填。新可编辑源为 `M870_LeftArm_Editable.blend`；已通过后台 commandlet 保存并完成接入。`install_receipt.json` 为 `completed=true`；`saved_assets.json` 读回确认 13 条动画的源散列与本批一致、两份 M870 网格均有本次表面修订标记。前次等待记录保留在 `install_attempt.json`。

## 排查结论

读取了当前 UE M870 网格、待机 RAW／COMPRESSED 姿态和实际显示配置。两种动画求值与作者源一致，最大矩阵差约 0.0000015；问题并非动画压缩引入。裸手状态使用 M870 内嵌表面，模块化装备路径使用 `modular_outfits.json` 中的裸臂；两条路径分别核对。

旧 AKM 支撑迁移按骨名带入辅助骨旋转。M870 原生前臂主骨不直接影响皮肤，实际变形由肘端辅助骨、1/3、2/3 站位及腕手共同承担。待机腕骨轴线折角约 11.16°，但最远端前臂站与手掌仍差约 42.91°，局部皮肤拧缩，不能只调整手腕角度。肘部现存的局部表面凹折在仅调整骨骼后仍明显，需要独立局部修整。

## 修订范围

- 保留肩、肘、腕位置以及全部手掌／手指世界轨道。上臂朝向对齐原生 V7 转换后的弯曲平面；扭转沿实际原生前臂站位分布，腕端接回手掌方向。
- 采用 SUPER90 原生分站方法，经过本次左肘实际表面对照，肘端不提前叠加掌面旋前；没有直接照搬右臂的 35% 预旋转和半混合参数。最远端站与手掌旋转差降到约 11.16°。
- 对真实 M870 左肘的局部皮肤做接缝一致的平滑，并通过现有蒙皮矩阵逆变换回绑定表面。1319 个渲染顶点、最大约 5.052 mm，整体包围盒不变；保持骨架、权重、UV、材质、手型和腕部几何。
- 表面修订写入本枪 `SK_M870_V7`，并从共享原生裸臂复制 `/Game/Weapons/M870/Arms20261016/SK_M870_BareArmsV7` 后修订同一局部。只更新 M870 配置的三项裸臂路径，共享 SUPER90 网格不修改。
- 13 条动画统一衔接相同左臂支撑，同时包含上一轮右手持枪修订。右手装填轨道、左手握点、枪和弹药轨道及机械事件保持；冲刺继续为 120 Hz，其余为 60 Hz。快速近战所有权曲线继续保留。
