# 机房设备收集物模型源资产

八件写实硬件收集物的可编辑模型、PBR 图集、FBX、GLB 和透明背包图标。正式 UE 资产已安装到 `/Game/Items/SearchServerEquipment20261013`，物品目录已绑定占格和图标，详见 [模型交付索引](../../Docs/Art/search-server-equipment-models-20261013.md)。

- `Authored`：带分件和倒角修改器的 Blender 文件。
- `Export`：FBX 与带材质 GLB；FBX 含 UCX 简单碰撞。
- `Textures`：BaseColor、ORM、Normal 源 PNG。
- `inventory_icons.json`：八张透明背包图标；PNG 位于 `Content/ColdSteelData/Icons/SearchServerEquipment20261013`。
- `Scripts`：纹理制作、硬件组件、八件模型、导入与安装脚本。
- `UEImportHost`：同版本 UE 5.8 后台导入工程。
- `Receipts`：制作、导入和安装记录。
- `Before`：修改前的设计清单副本。

`model_manifest.json` 记录身份、分件、尺寸和文件路径；`delivery.json` 记录实际交付与构建状态。模型、背包图标和正式物品定义均已落盘；搜索池尚未投放。原始模型和贴图均由本项目制作，现实产品资料仅用于结构参考。
