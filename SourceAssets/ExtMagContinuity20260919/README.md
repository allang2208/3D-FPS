# 扩容弹匣延长段连续性修订

用户反馈：AKM/M4 下方延长段明显截断，QBZ-191 下段边缘线条扭曲。本轮沿用前次运行资源与同枪材质，局部处理延长段；未修改换弹动作、安装座位、容量及存档。

## 处理

- **AKM**：旧延长段重复了纵向冲压筋的收尾，导致长筋被切成分段。现在从原厂长筋尚未收尾的截面插入连续曲线扫掠，保持截面细节；原底板和筋条收尾整体移至下端。保留最新口缘、内壁及托弹板。扫掠起点在曲线坐标 140 mm，延长量仍为 60 mm；上段原厂法线从源表面取回。
- **M4**：保留现有延长几何与原厂纹路，在下段按实际面重建分离法线，修正旧形变雅可比生成的异常角点法线。原上段法线保留。
- **M4/AKM 材质**：UV0 保留原厂纹理。接缝两侧各 4 mm 范围使用对侧表面 UV 渐变混合，作用于本枪原有颜色、粗糙度、金属度、AO 和法线采样；保留材质实例覆盖及 M4 原有 Phong 转换。法线先把对侧切线坐标转换到当前 UV0 切线坐标再混合，不将不匹配的 UV1 法线直接套在 UV0 切线上。源网格 UV1 储存对侧 UV，UV2–6 储存权重与转换矩阵，并预补偿 UE FBX 导入的 V 翻转。
- **QBZ-191**：只对新增长度范围的前后缘轮廓做径向修整，保留凹槽内部、侧面厚度及原厂底板。边缘最大位移约 1.66 mm，按新表面重建下段法线，材质仍是现用 QBZ 聚合物材质。
- **雨天**：M4/AKM 的现用 NaturalV2 湿润材料也复制相同接缝处理，保留原雨滴采样；在天气绑定处加入新干湿材料对，避免换成旧湿润图后接缝重新出现。QBZ 原干湿映射不变。
