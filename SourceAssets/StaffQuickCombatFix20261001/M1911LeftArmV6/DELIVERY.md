# M1911 副手左侧快速近战腕臂修复源

仅制作六条左侧主攻动画：compact / fitted / long，每档普通与空仓。
旧 SpinRecoveryV5 作者源、UE 资产和两侧其他动作均未修改。

## 修正方法

原 V5 的掌向与肩肘联动只在 0.32 秒之后的 recover 窗口生效，打击前伸段没有限制掌向与前臂方向的夹角。此版从出招起建立完整腕臂支撑，在 0.055 秒之前平滑进入，持续经过 0.18 秒接触，0.70–0.80 秒交还原 idle。

- 手掌与未转枪的整枪基准一起改变方向；保持原生枪根相对抓握矩阵。
- 以已认可 idle 的腕臂关系校准支撑轴，夹角目标为 22 度。按真实上臂、前臂长度解肩肘和腕点，在原肘侧的两骨圆上限制肘面调整至 48 度；不把手腕单独掰向枪柄。
- 前臂轴向差由上臂有限分担，比例 0.32、上限 38 度；两根上臂辅助骨跟随整段，前臂辅助骨按 V7 原生蒙皮主导区域的实际分站传递，肘端保持铰链支撑。
- 手枪回收的整圈独立转枪保留，时间 0.435–0.675 秒；转轴继续以弯曲食指为中心，三档倾角与普通/空仓机械状态保留。
- 可编辑 Blend 内采用认可 V7 裸手、裸臂，逐骨原生逆绑定配准；FBX 仅导出原生骨架动画，不覆盖网格、材质或绑定。

## 产物与接入

`author_actions.py` 后台生成 `authoring.json`、`M1911/l/M1911_l_QuickCombat_LeftArmV6_Editable.blend` 和 `M1911/l/Animations/` 下六个 FBX。

`import_assets.py` 可通过工程现有 UE Python 桥直接运行；目标为 `/Game/Weapons/StaffQuickCombatFix20261001/M1911/l/Animations/` 下同名六条 AnimSequence。脚本只创建、压缩并保存新动画，不修改旧动画、共享姿态层、运行时引用或网格，也不启动 UE 或停止正在运行的 PIE。

动画总长保留 0.80 秒，单次接触保留 0.18 秒，采样 120 Hz。源码修复与资产接入由主任务继续；未进行渲染或运行测试，交由用户测试。
