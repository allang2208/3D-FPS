# 201 后握把衔接定向检查

2026-09-29。用户请求检查后握把是否被单独处理，以及材质粗糙问题。本轮只读取当前资产、材质图及保存后的 FBX，没有修改运行资产、灯光或动作，没有打开编辑器或运行游戏。

## 当前证据

- 四个现用网格的 SHA256 均与 GripFinish43 保存回执一致，检查的 After FBX 对应该批保存结果。
- G43 在原厂握把外新增独立肩座；三种改装握把先删除旧公共安装座，再追加同一个 540 三角面的连接座。对象合并没有把接合位置焊接成连续表面。
- 同一肩座没有按不同握把的真实颈部截面逐件过渡。例如 Z=-12 mm，肩座 X 范围约 [-14.22,15.82] mm，稳定握把为 [-10.72,10.25] mm，左右分别突出约 3.49/5.57 mm。平衡握把、幽灵握把的颈部截面也不同。肩座与枪身存在重叠不能证明肩座与握把的外轮廓连续。
- 原厂和三个改装件的肩座 UV0 面积全部为零。材质中的微法线使用 UV0 × 18，因此该通道不能在肩座上形成正常细节；粗糙度使用另一套局部坐标三平面采样，仍会正常变化。不是所有贴图都缺失。
- 当前握把及肩座粗糙度中心均为 0.53，新增枪身涂层为 0.385。非金属与金属有差异是合理的，但尚未控制好交界处的质感连续性。微法线强度在握把上为 0.45，主体为 0.30；这些是制作值，不是视觉验收依据。
- UV 密度中位数：原厂握把约 1.18 UV/m，稳定握把约 3.19，平衡约 2.96，幽灵约 2.45。同样的 18 倍 UV 平铺产生不同物理纹理尺度。新增肩座没有有效 UV0，情况更不同。
- 原厂握把继承其原来的结构法线；稳定/平衡握把的新微法线节点以平法线为底。不能把全部可见凹凸简单归因于微法线强度，也不能通过统一减弱所有结构法线解决。

## 修正方向

逐个按实际颈部边界制作连接肩，连续过渡至枪身接触面，移除接合处被覆盖的旧表面；保持原安装枢轴和手部动作。新增面写入真正被材质读取的 UV0，并以一致物理尺度制作细纹。交界区使用细腻聚合物表面，原防滑纹和必要结构法线单独保留；减少额外颗粒与粗糙度波动，不以全枪变亮或磨平细节掩盖接缝。

原始证据：`geometry.json`、`materials.json`。此前 `GripFinish43/saved_contacts.json` 仅针对肩座到枪身的垂直接合采样，未覆盖肩座到握把的轮廓与 UV，不能作为本处完整修复的证明。
