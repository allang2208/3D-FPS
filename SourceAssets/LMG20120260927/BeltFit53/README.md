# 201 弹链衔接修正 B53

2026-09-30。针对袋口孤立子弹、换弹时弹链截断、机匣入口衔接和旧链松手后的堆叠，局部替换 B52 弹链，并在当前 ClothReload44.3 上叠加弹链轨道修正。

## 原因与制作范围

- B52 重排了中间弹节，但 R44 动作仍使用旧弹链的驱动中心；袋口附近相邻弹节在抽链时可拉开至约 28–30 mm。袋口的末节因此显得孤立。
- 原来从袋口向下外推弹链，会逐渐偏向布袋前壁；只增加子弹数量仍会穿出布面。B53 按现用 C45 袋口和袋腔安排下行段，在袋内遮挡范围收纳多余链长。
- 弹壳、弹头和钢制卡环继续采用 B52 独立金属模型及材质。新增独立刚性连接片，使用现有 Link 骨骼随相邻子弹摆动，子弹本体不拉伸。
- 上端两节在铺链时独立转入机匣，取消随首节整段翻转的旧覆盖方式；袋口折返采用圆弧和固定节距取样，避免松手时挤成一团。

本轮只有旧／新弹链几何、连接片、56 条弹链／连接片骨骼曲线以及对应进弹阻尼代码。手臂、弹药袋、枪体其他几何、换弹时序、音效和容量规则保持现有内容。没有改动并行会话的手部动作源。

## 交付文件

- `LMG201_BeltFit53.blend`：可编辑弹链母模；`mesh_buffers.json.gz`：直接导入 UE 骨架原生空间的刚性网格。
- `layout.json` / `write_layout.py`：14 单元循环路径及独立连接片数据。旧链 14 颗（含隐藏循环颗），新链 13 颗，合计 73,416 三角形。
- `Tracks/`：base、vertical、canted、prism、angled 五类弹链补丁；每类用于普通／空仓两条现用动画，共十条。
- `install.py` / `install_motion.py`：候选制作、正式枪体局部替换与现用动作的逐骨骼补丁；不删除或重写手部等其他曲线。
- `Before/`：修改前的原生源码、现用枪体和十条动画备份。保存状态以 `delivery.json`、`animation_delivery.json` 和构建日志为准。

正式枪体仍为 `/Game/Weapons/LMG201/Cover10/SK_LMG201_Cover10`；动画仍在 `/Game/Weapons/LMG201/ClothReload44/Animations/`。三个金属材质沿用 `/Game/Weapons/LMG201/BeltRebuild52/`，不使用布料材质绘制子弹。

## 本次指定的离线排查

读取了现用十条动画及其源数据；检查了抽旧链、旧链松手、新链抓取、提链中段和铺入机匣的离线关键姿态。`Inspection/contact_489.png`、`contact_526.png` 使用未修改的左手手套网格，供接触位置查看；`after_222.png`、`after_574.png` 分别显示松手后和铺链后的结构。图中是离线诊断材质，不代表游戏最终灯光或材质效果。

`motion.json` 记录五类轨道中其他曲线逐值不变、外露主链相邻节距以及袋口外移量。为了把原本落在袋壁内的抓取段移到布袋外，弹链首节在相关阶段最多外移约 19.2 mm；手指曲线没有改动。`max_legacy_cell5_displacement_mm` 是旧第 5 节与原固定袋口位置的差异：新路径允许弹节经过袋口，不再把第 5 节强锁为袋口接触点，不能将该值当作断链间隙。

后台构建完成；未启动 UE GUI、PIE 或游戏。运行时开火进弹、阻尼和完整换弹由用户实机测试，离线关键姿态不等于实机验收。

## 后续继续制作

正式结果是 R44.3 的现用动作加 B53 弹链补丁。不要直接重跑 R44 的旧整段导入器，否则会覆盖本轮弹链轨道；后续应先读取现用保存资产，或在新动作上重新适配本目录的弹链补丁。B53 的原始采样和作者脚本用于追溯，不应整枪覆盖后续其他局部修改。
