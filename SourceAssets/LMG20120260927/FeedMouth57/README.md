# 201 弹链入口局部让位 F57

2026-09-30。按用户认可的方案修整固定机匣入口，保持 B53 弹链的位置、模型、袋口接触及换弹轨道。

现用枪体：`/Game/Weapons/LMG201/Cover10/SK_LMG201_Cover10`。

## 修改原因

A40 制作的供弹侧收口条和托盘侧壁仍按当时的开口布置。现用 B53 弹链上端跨入机匣后，与这些固定表面及后端局部封口相交。仅删除最外侧薄片会留下内层挡壁。

## 已制作的局部形状

- 在现有固定结构上做带圆角的开口，包含收口条、内壁、后端面、后缘立边及它们后方的原机匣表面。
- 切口按实体差集补齐厚度，底角半径 2 mm，新切边局部倒角 0.22 mm。下方托面、对侧壁和前部连接保留。
- 制作范围在 WPN_root 本地米坐标中为 X `[-0.0128, 0.050]`、Y `[0.098, 0.171]`、Z `[0.052, 0.115]`。这是局部游戏模型的切割工具范围，Z 上界伸出表面以形成开放入口。
- B53 上端三节的轴向范围约为 Y `[0.10598, 0.16310]`；开口留出了当前 4 mm 阻尼通道及开火细摆所需的建模余量。此处记录制作依据，不表示已做运行验收。

## 原始数据保留

原生源网格读取包含 UV、分裂法线、材质槽与权重。制作时仅导出局部变化：707 个原面被替换，新增 1,593 个面；被提取组件中另外 40,059 个原面在现用 DynamicMesh 中直接保留。新切面沿用现有对应材质；旧表面分割出来的新顶点按源三角面插值法线及顶点颜色。

本轮没有修改弹链骨骼、换弹动画、手部动作、阻尼代码、弹药袋、大弹鼓或材质资产。H56 的提把撤除继续生效。
