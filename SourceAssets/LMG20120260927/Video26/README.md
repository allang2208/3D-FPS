## 制作内容

- 机匣盖改为较低的连续折边壳体，调整顶面、肩部、边缘厚度与侧面浅槽；增加后端横纹压扣、顶沿、侧销及盖轴外观。
- 按开盖画面补出连续内沿、阶梯加强板、导向条、横销和圆柱压件等可见表面。它们是游戏美术造型；被遮挡部分没有当作精确机械设计。
- 前准星改为细边椭圆护圈、真实通孔、中央细柱和带窗口的台阶基座。
- 后照门按视频改为护翼包围的缺口式结构，包含中央窄缺口、折叠底座、横轴、侧帽与防滑小齿。保留原前后机瞄安装轴和现有瞄线接口。
- 固定后导轨与后防尘盖一并细化过渡及倒角，仍归 WPN_root；活动盖仍归原 LMG201_Cover 骨。原生手臂、Magazine24 换弹和已取消的弹箱状态不重导。
- 上述局部高模共 **259,068** 三角面；游戏局部共 **50,984** 三角面。它们是新制零件统计，不是整枪面数。主机匣 Surface25 去毛躁结果保留。

## 材质

新件独立 UV，使用高模向游戏网格烘焙的法线和 PBR：主体图集 2048²，前后机瞄分别 1024²，各有 BaseColor、Normal、ORM 三张图。ORM 分别为 AO／粗糙度／金属度。Blender 法线为 OpenGL 约定，UE 导入时仅翻转一次绿色通道。

涂层参考视频采用中性炭灰，凹槽和内表面更暗、更粗糙；边缘有克制的间断磨亮，销轴是较亮的缎面钢。其余原厂钢件采用 201 私有材质副本调整色调、粗糙度与旧图集混合权重，保留原 UV 和结构法线。聚合物及手臂身份不改为金属。

新材质有 `WeaponWetness` 参数，并追加到 201 现有湿润映射表；保留通用改造件的原映射。材质绑定继续同步到已有 Material21 恢复入口，避免后续导入恢复旧绑定。

## 作者源与接入

- `LMG201_Video26_HighLow.blend`：根骨局部空间的高低模与独立 UV 烘焙源。
- `LMG201_Video26_Editable.blend`：装配后的可编辑枪体源，高模隐藏保存，游戏件与已有枪体可继续编辑。
- `model.py` → `bake_export.py`（调用 `finalize_source.py`）：模型、烘焙和 FBX 导出制作链。
- `Textures/`：9 张实际烘焙 PNG；`Exports/`：局部骨骼枪体、前后机瞄三个 FBX。
- `replace_regions.json`：按旧源对象记录表面身份。接入只替换这些已知对象，不按空间包围盒裁断生成枪体。
- `integrate.py` 按顺序执行 `materials.py` → `install.py`：在同一 UE 制作批次内创建并保存私有材质，再写回现用主网格和原机瞄资产。保留当前原生手臂、主机匣和所有动画。
- `materials_receipt.json`、`delivery.json`：各阶段的实际保存回执；只有完成状态才表示对应资产已保存。脚本存在不代表已经接入。
- `Before/`：接入前资产和材质绑定文件备份。
