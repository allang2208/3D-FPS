# 201 视频参考拆解

用户来源：`Reference/source.json`，8.65 秒、2560×1440、约 60 fps 的自录游戏视频。本轮只用画面作为造型、材质参考；没有提取或替换声音，没有提取游戏原始资产。

- 1.65 / 7.65 秒：低矮折边盖壳，平缓顶面，外周圆角折肩；靠玩家一端有明显的横纹压扣。前后不是两块高楔形积木。
- 3.15–6.65 秒：上盖内侧具有连续厚壁、内沿、阶梯状加强板、长条压件、横销和局部磨亮的圆柱面。按可见外形建模，遮挡部分不当成精确机械设计。
- 1.65 / 4.65 / 7.65 秒：后照门是护翼包围的缺口式照门，有中央窄缺口、厚侧壁、侧向调节帽和横轴；当前孔式小叶片应替换。
- 前准星是细边圆顶护圈、中央细柱，下方有窄台阶及镂空基座；保留真实通孔，避免宽实心牌状轮廓。
- 材质：中性深炭灰金属，平面反射较均匀；棱边、横销、按钮有局部轻磨亮；凹槽和内腔更暗且粗糙。保留细腻表面，不铺满高强度噪点或大面积银白磨损。

参考视频不是尺寸图。沿用现用 201 的接口、盖轴、前后瞄线与骨架空间，根据画面调整外观比例。上一轮 Surface25 主机匣修整和 Magazine24 供弹／换弹状态继续保留。

制作：精确壳体与孔槽、分级倒角和圆弧高模；保留高模源，独立游戏网格 UV，烘焙法线及 PBR。视频中可见的装链行为只用于辨认盖内表面，本轮不恢复已取消的弹箱供弹或重新制作手臂动画。
