# 201 布料弹箱上部优化方案

## 现状与范围

用户要求查看布制建模上方的粗糙问题并调整模型。旧源上方可见不规则穿孔、撕裂状薄片、粘连的布料翻边与机械连接块；这些在无贴图灰模中仍存在，不能仅靠材质或打光消除。当前 ClothFeed33 直接使用 R30 的 AmmoBag 网格，新旧箱只作复制与绑定。

本次局部替换袋身上部和供弹连接口。保留袋身下部外形、原 UV／法线、挂点、换弹骨架、弹链及 125 发选项；不重新生成整枪或改动作。

## 制作方案

1. 读取现用主枪体、ClothFeed33 分件及材质槽，保留文件散列和原包备份。
2. 在既有袋身的上沿截面上重建连续过渡，整理为圆润的布料包边、浅层受拉褶皱和有厚度的顶部翻边，移除原生成破片。
3. 按当前弹链入口和原安装高度建立独立、规则的供弹口框，圆角及内侧面使用真实几何。保留弹链通过区域；其余旧随机孔洞封闭。
4. 新布面使用有效 UV 和与原织物接近的细纹尺度；结构包边用几何、细针脚用法线／粗糙度。硬接口与织物明确分区，不将旧图集中的异常凹凸拉到新面。
5. 同步新旧箱两份骨骼网格、现用枪体、分件源及选项图标；通过后台导入保存。游戏网格与高密度制作源分离，不把细纤维做成百万面。

## 交付边界

现状图仅用于本次用户要求的局部模型排查；必要图标属于制作资产。默认不启动 UE GUI、不运行游戏或追加验收渲染。实际外观与换弹由用户测试；不宣称参考图 1:1 或运行验证通过。
