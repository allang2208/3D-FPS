# 201 枪械材质检查与优化

2026-09-28。按用户要求检查当前 201 材质，参考 `ue5-weapon-workflow/references/weapon-finish.md`、`generated-rifle-refinement.md`、QBZ191 Hero 与 A762 的结构/表面分离方法。只改表面材质；不改几何、UV、法线/切线、蒙皮、动画、镜头和音效。

## 检查发现

- 实际运行主体仍是 `/Game/Weapons/LMG201/Cover10/SK_LMG201_Cover10`，共 28 个槽。检查范围还包括 Production 下实际接入的 14 个静态部件/改造件。完整槽位、材质图、参数和纹理设置在 `before.json`。
- 原上盖、导轨、五金、机瞄使用常量涂层，没有细微粗糙度变化；生成主体保留的原粗糙度图带有较密集斑驳。源图已直接查看，不将它误当结构法线处理。
- 新旧弹箱的 Paint 实例继承上盖的 Metallic=0.72；弹壳、弹头和弹链也共用五金母材质的反射参数，材质身份区分不足。
- 战术消音器仍通过旧 `MF_PhongToMetalRoughness` 输出 Specular；其中名为 M4 Roughness 的 sRGB 纹理实际连到 Shininess。它不是当前 Roughness 的直接输入，不能只按文件名改色彩空间。当前粗糙度是独立参数。
- 201 主体的 UV0 结构法线已经使用专用法线压缩、线性采样及单次绿通道转换；主体基色为 BC7/sRGB，粗糙度为线性灰度。保留这些设置。瞄具金属区域、标记保护、AO 和光学输出沿用已有分支。

## 已制作并接入

- 新建 `/Game/Weapons/LMG201/Material21` 私有材质变体：29 个母材质、17 个实例，以及 1 张私有细纹纹理。源材质和共享贴图保留。
- 上盖粗糙度中心 0.35、导轨 0.37、五金 0.33、机瞄外表面 0.40；枪体和附件沿用本枪深色涂层，附件中心 0.35。以上为此次制作值，不是所有枪的通用标准。
- 原粗糙度图变化权重从 0.065 收窄到 0.024，同时调整中点偏移；原始结构法线强度与连接保持不变。
- 无独立细纹的材质使用静止局部坐标、5 cm 三向投射，在粗糙度上增加最大约 ±0.012 的变化；不添加颗粒法线。位置/法线经顶点插值传入像素阶段。已有 A762 独立 UV 细纹的瞄具保留原采样与遮罩，只复制纹理为 201 私有资源，避免叠加第二层涂层。
- 新旧弹箱均为 Metallic=0 的完整漆面，粗糙度 0.44；保留其原深色，不新增无依据的全箱露钢磨损。弹壳和弹头分别使用独立铜合金色、Metallic=1、粗糙度 0.32/0.30；弹链为独立钢件参数。
- 聚合物保留非金属身份，粗糙度约 0.49–0.50。机瞄内壁和枪体内面消光材质、皮肤、镜片与既有钛制制退器材质保留。
- 不透明 PBR 附件中遗留的 Phong Specular 输出改为独立的 0.5 参数，去除不相干的旧 M4 反射转换依赖；保留附件自己的结构法线。未改共享 M4 贴图。
- 15 个当前网格保持资产路径和槽位名称/顺序，逐槽绑定后保存。主体 28 槽包含手臂、原厂弹匣、新旧弹箱与弹链分区，均未合并。

## 保存与可重复制作

- `finish_recipe.py` / `FineRoughness.hlsl`：材质配方与细纹实现。
- `install.py`：制作私有材质、编译、备份并保存运行绑定。
- `bindings.json` / `bind_current.py`：保存的按槽名绑定；Refinement01、Refinement02、Cover10、Refine12 和原附件材质制作入口在完成后恢复此绑定，避免模型重导恢复旧涂层。
- `Before/Content`：修改前网格包；`Before/Scripts`：五个制作入口的修改前版本。旧材质包未覆盖。
- `delivery.json` / `install.log`：29 个母材质编译结果、46 份材质/实例及 15 个网格的实际保存回执。
- `read_saved_materials.py` / `after.json` / `read_saved.log`：本轮按用户检查要求独立读回的落盘状态。

只运行后台命令行材质制作、编译及资产读取，没有打开 UE GUI、启动游戏或生成验收截图。材质绑定与编译检查不代表实机视觉验收；实际观感交由用户测试。
