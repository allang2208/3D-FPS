# 201 Surface32：在原模型上修整细节与降低反光

用户要求：新模型反光过强，按所给左右侧原图优化细节；不增加组件覆盖缺陷。

本版直接编辑 `Install30/LMG201_R30_NativeFit.blend` 的既有顶点与角点法线。没有添加外壳、贴面或运行时组件；没有重新生成枪械，也没有重做手臂、动作、挂点或恢复弹箱换弹。

## 制作内容

- 原机匣、上盖和枪托的连通近似平面做有位移上限的平整，保留凹槽、凸筋、倒角和材质分界。机匣顶点最大修正 0.55 mm，上盖 0.45 mm（均为项目模型作者单位）。
- 护木、导轨、提把、前瞄具底座和前后机械瞄具按相邻面的法线差异限制局部平整。断面、安装接缝及显著硬边固定；不以整枪平均法线抹去结构。
- 所有现有面片、UV、分件身份、绑定和尺度保留。结构法线图继续使用 R29 的 UV0 贴图，不增加颗粒噪声，也不整体减弱法线来掩盖几何问题。
- 参考用户左右侧图片中的深色低反光涂层，将新枪体涂层粗糙度从约 .35–.42 提至约 .60–.66，聚合物约 .68–.74；保留原有区域遮罩并降低涂层金属响应。仅轻微增强原底色的局部纹路对比，不虚构刻字和结构。
- 固定内壁材质粗糙度 .76，小型钢件 .56；Specular .28。湿润系数不再将粗糙度降至干燥的一半，保留受约束的湿润变化。
- 旧模型、旧材质、旧参考和 Refine29 原件均保留。UE 接入另存 Surface32/Previous 后，只替换原资产中的 R30 枪体区域；原生手臂、弹匣、扳机、拉栓活动件和脚架继续从当前 UE 资产保留。

本轮是表面和局部线条修整，不声称恢复图片中未清楚展示的内部结构或全部精密细节。尚未唯一定位的 ADS 右侧遮挡也不能算作本轮已修复项。

## 制作入口及产物

1. `extract.py`：从现用适配源读取部件、UV、角点法线和顶点。
2. `refine.py`：编辑现有顶点及颜色/ORM 图集。
3. `export.py`：保存 `LMG201_S32_Editable.blend` 和 `Exports/` 下枪体、前后瞄具 FBX。
4. `integrate.py`：编译新材质，备份旧资产，导入并保存现用入口，保存完整装配 FBX，更新 Material21 材质绑定清单及湿润资源表。

编辑器已关闭时使用 `run_headless.ps1`；编辑器已运行时使用工程 `mcp_call_codex.ps1 -PythonScript .../integrate.py`。两者沿用同一批次互斥。不在 PIE 中导入或保存，不主动打开编辑器/游戏。

实际导入状态以 `delivery.json` 为准。只有其 `status` 为 `current_201_refined_and_saved` 才表示现用资产已保存；Blend/FBX/脚本存在不等于 UE 已应用。
