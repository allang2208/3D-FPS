# 201 大弹鼓接头修复 — DrumJoint47

2026-09-30，针对用户截图中的弹鼓上方漏空和疑似原装弹匣残留，局部替换 Drum46 接头。现用资产已后台导入并保存；没有启动编辑器、游戏或 PIE。

## 定位

- Drum46 将当前原厂弹匣上方约 34 mm 连同筋条和不完整的生成表面复制进了静态弹鼓，作为 `D46_FactoryNeck` / `D46_FactoryInside`。它们属于弹鼓自身，原厂弹匣材质分区的隐藏操作不能隐藏这段复制几何。
- 原生代码 `LMG201WeaponAssets::SetMagazineSections` 已在大弹鼓启用时隐藏 `M_LMG201_Magazine*`，改造预览也复制现用分区显隐。本次读取到 PIE，但没有找到正在使用 201 的实例，因此未把运行时显隐宣称为已实测。
- 当前 201 idle 与 bind 的弹匣相对枪根位置相差约 61.39 mm（纵向）、25.51 mm（竖向）。修复按当前原生 idle 下的弹匣槽位置制作，逆变换回原有弹匣挂点空间。

## 已保存的修改

- 完整移除弹鼓中的旧原厂上段、旧封面和独立过渡块；改为一体的圆角过渡肩、平整插入颈、上口厚度、内壁及有底凹槽。接头上端进入现有槽口下沿约 7.5 mm。
- 保留已用鼓壳、锁扣、紧固件、原 UV、安装挂点与单位比例；没有移动鼓壳、手部接触点或修改十条换弹动画。
- 新金属接头使用私有材质，取当前 201 弹匣涂层的颜色、金属度与粗糙度，不继承旧生成弹匣的破损法线。过渡肩、内部与鼓壳继续使用相应现用材质；湿润映射仅追加新材质。
- 更新实际模型制作的灰阶透明改造图标，同时保存 PNG 与纹理资产。
- 现用网格路径保持 `/Game/Weapons/LMG201/Drum46/SM_LMG201_LargeDrum`，新模型为 16,884 三角形。枪体、原厂弹匣和布箱资产未修改，不需要 C++ 构建。
