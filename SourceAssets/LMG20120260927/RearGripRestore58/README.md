# 201 改造后握把原件恢复 R58

用户要求恢复全部三款改造后握把的原件，并重新与当前 201 拼接。范围为稳固防滑、均衡、幻影后握把；原厂握把、枪身、弹链和动画不在本次替换范围。

## 来源与问题依据

- 稳固防滑：`SourceAssets/StableAntiSlipRearGrip20260913/seed_91727/textured_master_00001_.glb`。
- 均衡：`SourceAssets/BalancedRearGrip20260913/seed_91703/textured_master_00001_.glb`。
- 幻影：`SourceAssets/PhantomRearGripMultiview_20260913/seed_91627/textured_master_00001_.glb`。
- 早期制作脚本在纹理网格合并同位置 UV 分裂点之前直接减面；中间版本出现分离面片。G43 又对握持区进行了最高 1.22 倍加宽及分高度重映射，J44 对整个握把做了 0.22 mm 体素重建，随后减到约 4.5 万三角形。本次不沿用这些被用户否决的中间几何。

## 制作范围

从完整纹理母版恢复几何，合并同位置的 UV 分裂顶点，保留面角 UV 与法线。使用原有物理尺寸适配矩阵，再通过刚体旋转和平移，将原件握持区定位到当前原厂握把的接触区域；不再对握持区整体加宽或分段扭曲。

上端切接使用原件自己的边界环，连续连接到当前原厂安装顶面轮廓并封闭顶面。新接颈独立生成 UV，沿用当前材质的 UV4 接颈遮罩；下部保留源纹理 UV0。三款均保留完整源拓扑，不再次减面或体素化。

首次后台导入提示少量近零法线/切线，随后使用 `finish_geometry.py` 清理零面积面、修复零法线及局部塌缩 UV 三角面。正常源 UV 岛和有效表面保留；具体处理数量记录在 `model.json`。这一步是导入错误处理，不是游戏验收。

安装参考来自 F50 正式输出中的原厂握把。F57 当前枪体的文件散列与已保存记录一致，后续修订未改变该部位。`capture.json` 记录本次替换前目标散列；导入前再次比较，避免覆盖期间发生的改动。
