# 201 SurfaceFinish50

后续当前表面已接到 [201 表面标准 R01](../../../Docs/Weapons/lmg201-surface-standard-20261001.md)（2026-10-01）。F50 继续作为既有几何和材质来源，不要重跑本目录旧绑定脚本覆盖新实例；下一轮几何制作仍从当前实际 UE 资产取源。

本轮按 2026-09-30 的整枪收尾排查处理表面缺项。制作输入是当日现用 UE 主体导出的 `Inputs/Body.fbx`，原始主体散列记录在 `model.json`。不使用历史完整枪体覆盖并行修改。

当前已完成后台制作与落盘：现用主体的目标分区已替换，89 个私有材质已编译保存，相关现用配件完成材质绑定，湿润映射及 `Content/ColdSteelData/Icons/ue_lmg201.png` 已同步。导入与图标 commandlet 均正常结束；这不包含游戏测试或外观验收。

## 修改范围

- 机匣：取掉原左右后侧板的叠面几何；按原轮廓、凹槽、厚度做带约束的三角化，凹槽有真实底面及侧壁。前肩、供弹接口、护圈与紧固件保留。
- 护木：保留前端、上部散热孔与上缘；下部侧面及两侧斜肋改为规则硬表面，保留原安装范围。
- 原厂弹匣：保留顶部原有装配段和原生弹匣骨骼；下段改为连续曲面壳体与表面压筋。新槽名仍以 `M_LMG201_Magazine` 开头，沿用弹鼓／布箱改造隐藏规则。
- 枪托：保留前部安装杆，重建有实体内壁的镂空主体、双侧浅凹槽、端垫和紧固件。全部新槽保留 `FactoryStock` 身份。
- 后握把：仅整理原厂接头附近的顶点与平滑法线，最大位移限制 0.55 mm；安装顶面与下部已制作的手部接触区域保留。原 UV、颈部法线过渡遮罩保留。
- 材质：201 私有烤漆、钢件和聚合物家族；烤漆线性色值沿用此前参考 191 的基准，粗糙度分别约 0.357／0.30／0.455。新表面采用独立 UV 和物理密度一致的粗糙度细节，不使用旧模型结构法线；旧区保留结构贴图并减弱额外起伏。保留湿润参数、光学材质和内部材料。

## 制作与落盘

- `model.py` → `LMG201_SurfaceFinish50.blend`、`Exports/SK_LMG201_F50_Parts.fbx`、`model.json`。
- `materials.py` 只创建 SurfaceFinish50 下的私有材质，不修改 191 或共享母版。
- `install.py` 使用现用骨架导入局部网格，再按材质槽精确替换现用主体的目标分区；其他分区、骨架及动画保留。备份在 `Before/`。
- `run_background.ps1` 通过现有桥互斥运行无界面 commandlet；已有 UE 进程保留。
- `delivery.json` 记录实际保存状态及散列；`materials.json` 记录材质，`bindings.json` 记录本轮实际绑定。
- 目录图标生产脚本只重生成 `ue_lmg201.png`，沿用现有 5×2、800×320、91% 取景规则。实例改造图标继续使用现有动态装配。

布料弹箱换弹动作由并行会话负责，本轮不修改其资产、接触时序、手臂曲线或源码。BeltMotion49 弹链分段及运行逻辑保留。

本轮不启动编辑器或游戏，不追加运行测试或外观验收。制作／材质编译／资产保存的状态以回执为准，不代表用户已认可 1:1 外观或达到 191 的最终材质效果。
