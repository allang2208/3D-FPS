# 201 弹链模型重建 B52（2026-09-30）

用户指出弹链沿用弹药袋生成表面，布料与子弹材质混合，子弹形状不规则，链条在侧面供弹口终止。本次重建完整的新、旧弹链；B51 只修正过单位和权重，没有解决这些造型问题。

## 制作内容

- 弹壳、弹头、底火、厚壁 C 形钢夹及连接片分别建模。所有弹药单元复用相同的规则旋转体轮廓；不再从生成弹药袋的网格切片。
- 分为 Case、Copper、Link 三个材质角色，引用独立的低强度金属细纹/微法线。底火用 Case 的局部顶点色区分。弹药不再使用布料图集、布料法线或旧 Surface 图集。
- 新、旧链均保留原有六段换弹骨骼的语义，首尾接触点保持原坐标。中间四节沿规则曲线排布，旧链另保留一个隐藏回收单元。
- 在侧面入口与机匣盖下方之间新增两颗弹药和对应钢夹，使用现有 07/08 骨骼，不增改参考骨架。新增段在换弹时跟随 00 的作者接触姿态；开火时进入同一个循环池。
- 循环池从 7 个单元扩为 9 个，退场点移到新增机匣内段之后，避免在裸露的供弹口缩小退场。
- 正式主网格仅替换 `M_LMG201_Cloth33__OldBelt*` 与 `M_LMG201_Cloth33__NewBelt*` 的几何。枪体、弹药袋、手臂、既有涂层、ClothReload44 动作轨道及其时序不修改。
