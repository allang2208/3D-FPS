# GripJunction44 — 后握把连接颈与细腻聚合物

本轮落实 `GripJunctionAudit44` 中的修复方向。实际资产保存情况以 `delivery.json` 为准；制作文件存在不等于完成接入。

2026-09-30 已后台保存现用枪体、三个改装后握把及湿润映射，共五个目标资产；四份 J44 私有材质已编译保存。最终导入记录为 `install_runtime.log`，保存回执状态为 `current_j44_saved`。未运行游戏或渲染验收。

## 制作内容

- 移除 G43 的独立通用连接座。原厂握把从 Z=-18 mm 的实际边界向机匣接触面重建连续颈部，保持原厂隐藏分区和 `WPN_root` 绑定。
- 三种改装握把的旧表面有大量断开的薄片，无法直接得到完整的接缝边界。以 0.22 mm 分辨率重新连接现有外形，并从保留的源握把转移 UV 与角点法线，然后分别从稳定／平衡握把 -18 mm、幽灵握把 -20 mm 的截面生成过渡。并非原网格逐顶点不变；安装位置、枢轴及下部外形仍以原握把为源。
- 高密度体素结果仅作为作者中间表面。完成连接颈和 UV 后，`runtime_surface.py` 为三种新建改装握把分别整理至约 45,000 三角形，并从连接完成的源表面转移 UV 和法线；只导入 `RuntimeSource/model.json` 指定的游戏网格。近景握把曲面、纹路和连接颈共用这部分预算，不对原枪体其他部分减面。
- 新颈部从各自边界逐渐过渡至现有枪身安装面。内侧小切环局部封闭，旧连接座不再叠加；接合处使用共享边界顶点。
- 新面显式写入 UV0。`finish_seam_uv.py` 在共享边界延续源 UV，再过渡到新展开，另用独立 UV 通道标记新颈部。原厂为 UV1，改装握把为 UV4；材质读取相同通道。
- 每个握把的本体和新连接颈使用同一份聚合物材质。粗糙度中心从 0.53 改为 0.46，细纹波动系数从 0.045/0.075 改为 0.012/0.018；取消额外微法线颗粒。源结构法线和 AO 在连接颈开始处平滑退出，不把旧握把图集投射到新安装面。
- G43 的手部动作、枪身其他部位及预览灯光代码不在本次修改范围。

## 可重复制作用法

1. `capture.py` 读取五个目标资产的当前身份和材料槽；正式制作前保留该快照。
2. Blender 后台依次运行 `model.py`、`finish_seam_uv.py`、`runtime_surface.py`。
3. 在现有编辑器桥或无编辑器占用的后台 commandlet 中依次执行 `materials.py`、`install.py`。
4. `install.py` 保存原厂握把所在枪体、三个改装握把及湿润材质映射，输出实际整枪／握把 FBX 和保存回执。只按本次目标修改材质绑定清单。

旧资产字节保存在 `Before`；高密度编辑源为 `LMG201_GripJunction44.blend`，当前游戏编辑源为 `RuntimeSource/LMG201_GripJunction44_Runtime.blend`。首次后台导入因中间网格过密发生内存不足；本轮保存的稳定握把中间版本已经按保存回执恢复到原备份，随后使用游戏网格继续导入。本轮没有修改 C++，无需新增原生构建。未运行游戏或渲染验收，外观及实际抓握表现由用户测试。
