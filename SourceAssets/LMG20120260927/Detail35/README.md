## 制作范围

- 机械瞄具：在现有前、后瞄具对象内重整精细拓扑，包括护圈、准星、开窗支杆、U 形缺口、护翼和横向调节部位。沿用原折叠轴点、安装接口和瞄准线高度；使用独立暗色涂层，不再把整枪旧图集的斑驳法线套到精修表面。
- 右侧拉机柄：沿用现有滑块、折叠杆、握持纹和转轴表面以及对应骨骼权重，修整边缘半径和分裂/加权法线，分配独立涂层与克制的金属高光。原机匣右侧表面与左侧一起做局部平整处理。
- 左侧及机匣主体：直接修改原顶点，按原有平面区域消除局部波浪；保护切口、槽线、锐边与 UV。仅对这些平面区域的原图集法线和粗糙度降噪，保留刻线、铆钉、文字和非平面结构。
- 机匣盖：保留当前外壳基础并修整表面，删除旧的大块平板切口封面，形成内向厚度和连续翻边；按视频可见外观加入阶梯内板、导条、压件、滚轮、轴销、侧拨件和铰接回边。全部合入现有机匣盖网格，由原 `LMG201_Cover` 骨骼驱动。

这些是游戏模型外观调整；视频中不可见的内部不作精确还原声明。没有新增运行时覆盖组件。未改动画、镜头、ADS34 衣袖修正、弹匣/布料弹箱供弹逻辑、音频或枪匠接口；枪管、护木、枪托和后握把保留当前 Surface32 几何。
