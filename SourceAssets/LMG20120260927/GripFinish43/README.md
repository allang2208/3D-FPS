# GripFinish43 — 后握把、回握与表面材质

2026-09-29。输入是现用 SurfaceReform42，保留原生骨架、S42 左右侧板、R38 盖壳以及 S41 瞄具定位。实际保存清单见 `delivery.json`，材质清单见 `materials.json`。

## 本轮制作

- 原厂和三种改装后握把增加贯通连接肩。接头进入枪身底部，与护圈后端连接；三种改装握把保留原枢轴与安装变换，按原厂握把分段中心线调整接触区。
- 原厂握把与其连接座的材质槽均含 `FactoryRearGrip`，沿用改装时隐藏原厂部件的现有逻辑。
- 86 段现用动作仅重写右上臂、前臂、手腕旋转轨道。在握枪区应用两段手臂 IK，放手动作平滑退出修正；不改变骨长、动作时长或枪械机械轨道。
- 新侧板、护圈及盖体增加独立的涂层细节与小范围倒角磨损。保留其他零件已有 UV、纹理细节和材质分区；聚合物、涂层钢、裸露钢分别定义金属度和粗糙度。
- 为 201 改造栏设置独立的主光、补光及环境反射强度，切换其他枪械后恢复原值。原生代码需要正常 Editor 构建后生效。

## 文件

- `LMG201_GripFinish43.blend`：可编辑模型。
- `Exports/SK_LMG201_G43_Parts.fbx`：本轮骨骼部件；三个 `SM_LMG201_G43_*.fbx`：改装握把。
- `Exports/After_Body.fbx`：完成接入后导出的整枪，不是仅部件的制作输入。
- `capture.json`、`geometry_inputs.json`、`pose_inputs.json`：修改前的局部资料。
- `AnimationInputs`：源姿态；`AnimationKeys`：三条旋转轨道的烘焙输入。
- `Before`：被改动现用资产的原字节备份。
- `materials.py`、`install.py`：私有材质制作、受限接入与保存入口。

不批量重跑旧版导入器。本轮未启动游戏、未做渲染或运行验收；外观与动作表现由用户实际查看。
