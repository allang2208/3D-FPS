# 201 弹链换弹消失修复（2026-09-30）

用户报告：弹链在换弹过程中或换弹之后消失。本次只处理弹链资产，保留并行制作的 ClothReload44 动作。

## 已定位原因

- 正式枪体 `SK_LMG201_Cover10` 的 `M_LMG201_Cloth33__OldBelt_Belt49` 顶点带有 100 倍组件空间尺寸错误。UE 原生 GeometryScript 读取确认，排除了 FBX 导出/Blender 显示单位造成的假象。
- 例如第一段中心修正前为 `(198.7706, -2788.4550, -360.4144)` cm，修正后为 `(1.987706, -27.884550, -3.604144)` cm。修正后七段骨骼局部中心与 BeltMotion49 原始 layout 一致。
- 换弹中的 NewBelt 尺寸正常；流程结束恢复 OldBelt 时，旧网格落在正常枪体之外。动画骨骼尺度本身正常，不能用改动画或显示开关来补偿网格尺度错误。
- 循环补位段有 6,645 个顶点混合绑定到 `LMG201_Belt_05/06`。运行时在换弹中隐藏 06 时，混绑网格仍受 05 牵引；现已全部改为只受 06 控制。

- 只将正式枪体中上述旧弹链槽的 34,249 个顶点位置乘以 0.01，校正补位段权重。
- 未修改新弹链、枪体其他几何、材质槽、材质资产、参考骨架、换弹动作、接触点、动作时序、弹药数或 C++。

- 正式资产：`/Game/Weapons/LMG201/Cover10/SK_LMG201_Cover10`，现有运行时引用直接使用该资产。

## 制作与排查证据

`repair.py` 是本次源制作脚本，`prepare.py` 保存候选，`publish.py` 在新进程读回候选后保存正式资产，`read_saved.py` 读回正式落盘结果。运行时需沿用项目桥批次互斥，不对已打开编辑器中的资产直接覆盖。脚本针对已记录的源 SHA 执行，不应盲目重复用于后续枪体。

后台日志与原始诊断数据位于 `Saved/LMG201BeltRepair51/`。原生数据同时读取了普通/空仓换弹的交接关键帧。保存核对包括七段刚性绑定、相对原始接触中心的误差、各材质槽三角面数及材质绑定。没有启动游戏或 PIE，也未做渲染验收；实际换弹表现由用户测试。
