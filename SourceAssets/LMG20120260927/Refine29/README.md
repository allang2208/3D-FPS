## 毛躁与几何处理

1. 从 Meshy 原文件读取源三角面、面角 UV 和自定义法线，保留原始候选。
2. 在机匣、上盖和护木的大面上做有位移上限的双边法线投影平整。硬边、孔槽边和分区交界受到固定与衰减保护；不做全枪缩形平滑，不为了面数目标减面。
3. 对规则枪管、导气管中段拟合圆柱表面，保留接口和凸环，局部小幅纠偏。
4. 用户截图中导气管前端的破碎突起局部重建为规整外形、倒角和真正的环孔，不继续在坏面上叠旧法线。
5. 仅在已平整的大面上减弱低幅法线噪声；原来的强结构法线、螺钉和沟槽保持。枪体涂层压低整片发白的生成描边，金属与聚合物分别烘焙。

表面字段和数值是此候选的作者空间参数，不是现实枪械尺寸或跨模型通用标准。

## 弹药袋布料

“布料”范围是参考中的迷彩弹药袋及其缝制区域。弹链和弹头继续为金属，不把金属弹药整体改成布。

参考近期手套制作中的方法：裁片路径按弧长布置针脚，中段略起、两端针孔下陷；织纹、针脚、针孔、粗糙度和绒面使用同源表面字段。保留迷彩图案，取消袋身金属反射，采用较高粗糙度和局部短纤维光泽。

弹药袋单独制作 UV 图集，高模实际位移后向导出网格烘焙。细节高模保留在 `HIGH - pouch baking source`，不进入 GLB / FBX 游戏候选。细织纹主要由法线承担，不在导出网格上逐根加纤维。

## 拆分与封口

Meshy 源是一个整体连通网格，连通岛不是零件身份。本轮按参考可见接缝定义部件区域，对穿过接缝的三角形插值位置、UV 和角点法线；不是删掉半边三角形后留锯齿。

每个切面独立做约束三角化，按边界内外关系保留孔洞，断面使用独立内壁材质。枪管在前瞄具底座内部补连续表面，让前瞄具拆下后枪管仍连续。导气管前端环孔保留。

零件包含机匣、上盖、护木、枪管、枪口件、前后瞄具、导轨、导气管及前端件、枪托、握把、扳机护圈组件、提把、弹药袋、弹链。扳机与护圈目前作为一个组件；内部不可见机构没有参考，不声称已重建完整机械内部。

接缝与活动原点依据外观参考推断，当前交付为分件候选。它们并未与旧 201 的骨骼、换弹轨道或枪匠配件一一重定向。
