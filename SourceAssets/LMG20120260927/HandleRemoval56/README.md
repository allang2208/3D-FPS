# 201 提把撤除与悬挂块残面清理（H56）

2026-09-30，按用户测试后的要求，撤除 H54 恢复、M55 加入晃动的提把，并清理此前删除悬挂块时遗漏的前端封口面。

现用枪体：`/Game/Weapons/LMG201/Cover10/SK_LMG201_Cover10`。

## 局部几何修改

- 删除 H54 提把握持段 2,783 个三角面、支杆 764 个三角面、固定销 764 个三角面，共 4,311 个三角面。
- H54 当时仅删除 `M_LMG201_H39_Receiver` 中的悬挂块外表面。它的前端封口仍在共享的 `M_LMG201_F37_Interior` 材质槽中，留下 49 个三角面的独立薄片；本次删除这片封口。
- 残片范围为 WPN_root 本地坐标（米）：X `[-0.032937, -0.015084]`，Y `0.222510`，Z `[-0.035126, -0.000500]`。这是原悬挂块的切断平面，不属于护木主体。
- `install.py` 在当前文件散列、未保存状态和播放状态允许时，仅删除目标面。共享材质槽其余几何保持现状，不重新导入整个枪械。

## 动态接入

`Source/FPSGAME/Weapons/PKMCarryHandleDynamics.cpp` 撤除 `LMG201_CarryHandle` 的识别分支，以及 201 的专用旋转轴与力臂。PKM 使用原来的轴和力臂。

201 骨架中的空闲提把叶骨保留，以维持已保存动画的骨骼索引；现用网格已删除它所驱动的全部提把表面，运行时代码也不再识别这根骨骼。原材质槽保留稳定索引。

M55 的弹链参数继续有效。B53 弹链模型、换弹轨道、大弹鼓、弹药袋和现有枪面材质不在本次修改范围。
