# 焚化炉线路容器模型 · 2026-10-03

本批按五类方案完成原创精确建模：检修工具箱、防护用品柜、耐热器材柜、停尸间档案柜、滤芯运输箱。
复用现有仓库/医院容器的规则建模和分件导出方法、共用钢与橡胶材质；现有模型保持原样，新模型保存在独立路径。

| 类型 | 主体尺寸（宽×深×高 cm） | 活动结构 |
| --- | --- | --- |
| 检修工具箱 | 70×36×32 | 独立翻盖、后侧铰链、搭扣、内部托盘与工具 |
| 防护用品柜 | 64×43×170 | 独立门板、真正通风缝、门锁与固定隔板，内部防护包与呼吸面罩 |
| 耐热器材柜 | 80×49×108 | 下层独立柜门，上层独立抽屉；陶瓷内衬/把手与滑轨 |
| 停尸间档案柜 | 74×46×116 | 独立柜壳及三层独立抽屉，复用同一滑轨/抽屉网格，随抽屉移动的文件夹 |
| 滤芯运输箱 | 64×42×36 | 独立翻盖、密封圈、搭扣、滤芯托架，真实褶皱/空心套筒与端盖 |

活动分件的 UE 原点按真实铰链或抽屉基准导出，共 13 个网格。
固定主体/抽屉框带 UCX 简单碰撞，柜门及箱盖用于动态活动分件。所有不透明网格使用 Nanite，显式切线和完整回退几何保留近景轮廓。
模型涂层包含基色、粗糙度、金属度及微表面法线，掉漆/积灰使用本批顶点通道，避免全表面均匀锈斑。
五种标签使用原生字体等比绘制，800×400 像素区域对应 2:1 实体牌面，使用已经修正的正向 UV；不拉伸字形。

## 制作源与资产

- `Authored/IncineratorContainers_Source.blend`：可编辑闭合装配，保留五类源模型和活动分件。
- `Authored/SM_Treatment_*.fbx`：13 个实际导出分件，带 UV、顶点色及固定件简单碰撞。
- `Authored/T_Treatment_Labels.png`：本项目原创标签图集。
- `Authored/Drawings/*.svg`、`Config/design.json`：制作尺寸草图及参数；并非游戏验收截图。
- UE 路径：`/Game/Dungeons/IncineratorContainers20261003`。
- `Config/assemblies.json`：导入后生成的组装配置，含真实分件资产引用、轴心、开门角度、抽屉位移和档案柜三层组合。

`Scripts/author_labels.py` 使用本地 Python/Pillow，`Scripts/author_containers.py` 使用后台 Blender。
UE 实际导入/材质编译/Nanite 构建/保存入口为 `Scripts/import_assets.py`；后台方式为 `Scripts/install_background.ps1`，已有编辑器使用 `import_existing_editor.py` 经工程 MCP 批次互斥处理。
实际落盘状态以 `Receipts/assets.json` 为准，脚本本身不表示资产已导入。

## 三间房接入

`Config/layout.json` 保存贴墙候选位，正式随机地牢使用现有固定种子容器选择流程抽取；焚化炉测试图使用固定预览种子 20261003。

| 房间 | 实体箱柜数量 | 独立搜寻入口数量 |
| --- | --- | --- |
| 破损支护室 | 4–5 | 4–5 |
| 焚化处理厅，含 B1 停尸间 | 6–7 | 10–11 |
| 烟气净化站 | 7–8 | 8–9 |
| 三房合计 | 17–20 | 22–25 |

搜寻入口数接近医院/货运三房主题。耐热柜的柜门与上层抽屉分别搜寻；档案柜三层抽屉分别搜寻，因此入口数超过实体数。
本次已保存测试图为 17 件实体箱柜、22 个搜寻入口，三房分别为 4、10、8 个搜寻入口。
停尸档案柜固定在 B1 登记区域的安全墙边，其余箱柜从各自候选位随机抽取；滤芯运输箱也包含净化站检修平台候选位。

作者脚本 `Scripts/prepare_layout.py` 在后台 Blender 中读取房间与箱柜实际 FBX 几何，按地面支撑面、门口/通道保留区域、箱柜完整开启动作包围区和前方 90 cm 操作空间构建点位；全部候选区域彼此分离，任意选点组合沿用同一空间约束。
`Config/geometry-files.txt` 为作者输入路径索引，引用本地上游 FBX；索引不包含提取几何。规则建模和描边 helper 已留在本目录，不依赖整套仓库/医院作者目录。
柜子落地高度来自所在楼层实际地面，B1 和平台不会套用首层高度。该步骤是布置制作，没有运行游戏或物理模拟。

`Scripts/install_scenes.py` 合并最新已保存正式生成器目录，保存 `/Game/GameMaps/L_Dungeon_Randomized` 和保留的 `/Game/GameMaps/Design/L_Incinerator_Theme_Subject`；只更新本批容器，保留其他模块/场景调整，原地图备份在 `Backup`。
后台入口为 `Scripts/install_background.ps1 -Phase scenes`；已有编辑器使用 `install_scenes_existing_editor.py` 经工程 MCP 批次互斥处理。
正式线路重建和两个设备房单独重建入口会重新应用本批规则。实际地图落盘状态以 `Receipts/install.json` 的 `stage: maps_saved` 为准。

接入既有容器开启、独立储物页与描边交互；奖励/掉落填充沿用其他主题的后续配置阶段。
保留医院、车站和焚化炉测试地图。没有运行游戏、测试、截图或验收渲染，由用户测试。
