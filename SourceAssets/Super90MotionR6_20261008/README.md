## 实现

- 保留 R5 较低的装填构图。持枪准备、推进受力和回位使用连续曲线；所有数量变体在最后入仓前保持相同前缀。
- 左手松开后直接沿弧线回到各自护木/前握把。手指分时松开与闭合，掌向随前臂过渡。
- 推杆从 `hand_l` 改绑到本枪未使用、未加权的原生辅助骨 `WPN_SOCKET_Magazine`；动画单独驱动其轨道。管体仍由 `WPN_Shell` 驱动。共享骨架和参考姿态不修改，推杆落下时不会拉走左手。
