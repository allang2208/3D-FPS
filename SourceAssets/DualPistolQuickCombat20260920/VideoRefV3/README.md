# 双持手枪：视频参考 V3

用户指定参考：[以防你不知道手枪的近战动画有多帅](https://www.bilibili.com/video/BV19hUoBMEdX/)，作者「云映蓝海」。参考视频约 13.47 秒，先展示枪械，随后多次近战；本次制作依据其中的单手横击、另一手避让，以及收招翻枪回握。没有导入视频中的枪械、皮肤、音频或原游戏动画数据。

## 参考观察与三维适配

在本机 Saved 目录按 30 Hz 解码参考帧作动作研究；原视频不进入 Content 或作者源。主要片段为 6.13–7.00 秒的右手动作和 8.53–9.33 秒的左手动作：

- 待机后两枪短促压低，主手横向挥过前方，副手向下收出动作路线。
- 击打后主手继续带出，短暂移出画面，再由下侧重新抬回。
- 收招可见手指展开、枪体相对手掌翻转，然后重新包握。手臂本身没有整圈旋转。
- 副手先恢复持枪，主手最后完成回握；左右手有独立动作变体。

这些是屏幕可见的姿态与顺序；深度、遮挡段、手指轴和枪体尺寸由本项目重新制作。不是对原始动画曲线的精确提取。DeepSeek 脚本返回的文字推测没有作为定量姿态依据。

## 本版制作

- 总长 **0.80 秒**，接触 **0.18 秒**，单次只结算一击。
- 0–0.12 秒压低与起势；0.12–0.18 秒加速横击；0.18–0.37 秒带出；0.395–0.705 秒张指、翻枪及回握；0.70–0.80 秒交回实时待机。
- 右手／左手交替主攻，另一手播放对应避让。已有快速进战动作序号选择左右，拒绝的输入不切换出手顺序。
- 主手击打时保持该枪已有的固定握姿；收招时以食指第二骨段为枪体翻转轴，拇指和其他三指从本手待机向放松姿态张开，再恢复原握姿。完整肩、上臂、前臂和扭转辅助骨随动，枪与腕的旋转分开。
- 沿用当前 NaturalAimV3 的 M1911、DW715 和 Manny 手模；两种枪均有两侧版本。M1911 每只手保留独立正常／空仓机械姿态，DW715 弹巢与弹壳仍由运行时维护。
- 四份可编辑 Blend，十二条 120 Hz 动画 FBX。连续 Hermite 曲线烘焙，首尾回到各手当前待机。

作者入口 `author_actions.py -- M1911|DW715`，参数 `motion.json`。导入入口 `import_assets.py`，通过工程 MCP 桥执行。

运行路径为 `/Game/Weapons/DualPistolQuickCombat20260920/VideoRefV3/<Weapon>/<side>/Animations`。`quickcombat` 是右手主攻，`quickcombat_left` 是左手主攻，M1911 各自有 `_empty` 版本。V1／FlowV2 的作者源和旧运行资产保留。
