- V5 作者脚本只导出 ARMATURE 动画；导入设置 `import_mesh=False`、`import_materials=False`、`import_textures=False`，使用原双持网格的 skeleton。
- 当前加载的双持 DW715 网格路径仍为 `PistolDualWield20260914/DW715/r/SK_Dual_DW715_r` 与左侧对应路径。磁盘文件修改时间分别为 2026-09-14 23:35:39、23:39:01，未被 V5 改写。
- 作者模型中，枪身和枪管使用 WPN_root，弹巢使用 WPN_Cylinder，弹巢架与退壳机构使用各自 WPN 骨。V5 将这些部件作为固定枪体关系一起旋转。
- 四份 V5 Blend 的武器骨缩放/剪切变化均处于浮点误差量级。针对 DW715 又读取当前 12 支 V5 动作及 2 支旧 V3 对照，每支 97 个时刻；分别读取 Source、Source 未重定向、Compressed。
- 读取的枪体骨骼缩放在整段内恒定，枪身与机械部件相对关系保持稳定。例如右侧 compact 的最大部件位置误差约 0.0000154 cm，压缩后约 0.0000119 cm，未发现足以解释可见枪身/弹巢形变的骨骼拉伸。
- 运行代码中的双持瞄准层旋转整套姿态根；子弹可见性层仅缩放 WPN_Case / WPN_Round。角色相机代码明确关闭常规 MotionBlurAmount，不能未经画面证据就断言是运动模糊。
