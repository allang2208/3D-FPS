# PKM 待机上盖与弹箱修复

用户截图显示待机上盖直立、弹箱和箱盖翻折。定位结果：问题已存在于 Blender 作者源，不是仅发生在游戏状态机。

`build_reload.py` 在创建零长度 EditBone 后先赋 `matrix`、再赋 `length`。这使新骨骼的实际静止坐标轴偏离作者使用的装配矩阵。动画目标姿态虽然正确，蒙皮的逆绑定矩阵却来自另一组轴，因此待机也会翻起部件，箱盖会相对箱体偏移。

修复：先设置明确的 head/tail，再赋完整矩阵；所有新增机械骨骼共用此顺序。制作入口添加针对实际静止矩阵的拒绝条件，避免同类错误再次导出。重新生成 Animation03 和 Integration04 可编辑源、骨骼 FBX 及全部动作。

## 本轮针对性检查

- `bind_before.json` 保留修复前坐标轴误差；修复后上盖、弹箱、箱盖、弹链静止矩阵与装配矩阵最大分量误差小于 0.000001。
- `source_pose_check.json` 记录待机与普通/空仓换弹关键帧：待机上盖角度 0°，换弹展开为 108°，两种换弹末帧恢复 0°；箱盖始终保持与弹箱的装配关系。
- `idle_closed.png`、`reload_open.png` 是本轮实际模型源渲染，已查看待机闭合与弹箱装配、换弹开盖状态。
- UE 使用原有 PKM 独立 Skeleton，并在重导入网格时显式更新该 Skeleton 的 reference pose；不改共享 M4 骨架。
- `mesh_reimport.json` 和 `imported_pose_check.json` 分别记录实际保存与 UE 原始/压缩动作的针对性采样；以后者实际生成结果为准。

没有修改枪械数值、存档定义或 C++。此次检查限定上盖、弹箱与相关待机/换弹状态，不代表整套玩法及所有手部接触已经验收。
