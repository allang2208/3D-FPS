# PKM 左手握持、射击与换弹复查

执行依据为用户本轮明确提出的状态检查请求。本目录保存只读采样、分析和离线姿态渲染，不是新的动画修订版本。

结果与限制见 [项目检查记录](../../../Docs/Weapons/pkm-left-hand-state-review-20260926.md)。本轮 30 条动作、8,730 原生帧、165 混合姿态和 55 张关键画面的检查，未发现新的腕肘开缝、射击滑握或动作首尾跳变。未启动 PIE；没有修改游戏资产。

- `collect.py`：通过项目互斥桥读取当前 UE 网格、四种实际配件、30 个动作的原始及压缩骨骼姿态。
- `collect_normals.py`：读取实际分裂法线供诊断渲染使用。
- `analyze.py`：腕肘角度、骨段、辅助骨一致性、压缩误差、握点及动作首尾比较。
- `seams_and_blends.py`：两种手套的腕口、射击手指接触、瞄准及换弹入场混合。
- `body_seams.py`：直接比较裸臂上段/下段与腕/手的共位顶点及权重。
- `render_poses.py -- all`：用当前网格和压缩姿态生成诊断图。使用中性材质和无投射阴影的 Workbench；不是游戏截图。
- `make_report.py`：生成对照图、汇总结果，并记录被读取的资产在检查期间没有变化。

参考骨架、网格及 30 条动作快照位于 `Input/`；具体结果分别在 `pose_audit.json`、`seam_blend_audit.json`、`body_seam_audit.json`、`summary.json`。真实游戏的相机层、材质、后坐力与输入切换没有在此次离线渲染中完整复现，不据此声明所有实机场景都无问题。
