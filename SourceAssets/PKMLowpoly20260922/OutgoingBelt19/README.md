# PKM 左侧空弹链与端部引导片

2026-09-23。用户圈出的部件为原模型 `PKM_Part_113`；前序接入将其留在独立的 `PKM_EmptyLink` 骨骼上，没有随弹链运动或隐藏。本次修改该视觉部件及其出链表现。

## 模型与材质

- 基于 `../CarryHandle18/PKM_CarryHandle_Editable.blend`，保留木制提把铰轴、枪身、手模、改造分区、材质与原动画。
- 保留原小片的卷边形状、UV 和钢材贴图。沿外伸方向缩短为 86%，增加 18 度下垂，连接点保持在原弹链端部位置。这是游戏视觉调整，不是实物尺寸还原。
- 原小片改为 `PKM_OutgoingTab` 的刚性权重，材质归入 `__OldBelt`；新弹链有自己的 `New_PKM_OutgoingTab` 和 `__NewBelt`。防尘盖不属于本次变动。
- 左侧新增 25 个空链节与连接片，复用 Belt08 已有 C 形链节、连接片、UV 和钢材 PBR，间距沿用现有右侧弹链约 1.833 cm 的视觉参数。不复制弹头或弹壳。
- 所有新增运动骨骼都是枪根下的叶骨骼；未使用的空链节停在上盖内并在运行时局部隐藏，不缩放枪身或父骨骼。
- 当前作者源为 `PKM_OutgoingBelt_Editable.blend`，后续导出枪体以此为基底。

## 运行表现

`Source/FPSGAME/Weapons/PKMOutgoingBeltDynamics.h/.cpp` 经 `UFPSCastingMeshComponent` 的姿态完成阶段应用，角色动作更新提供弹量、换弹状态和开火源时间。

- 开火时与 Feed13 同步：0.012–0.080 秒送出一节，停止开火后保留已经送出的长度，不倒放回枪内。
- 空链通过出口后向下弯曲，按枪身加速度和重力方向分量产生有限幅度的弹簧阻尼摆动。积分子步不大于 1/240 秒。此处是程序化表现，并非 Chaos 链条碰撞模拟。
- 按 25 节显示段处理空链移除；引导片仅在本次弹链开头出现，不在每个显示段上重复生成。
- 普通换弹时，旧引导片和空链跟随原 `PKM_Belt_00` 的取链轨道；新引导片跟随 `New_PKM_Belt_00`。两者复用现有旧／新弹链的显隐时刻。
- 空仓旧链隐藏；末发沿用现有送弹结束后隐藏的时序。枪匠检视使用未射击的初始状态。
- 该层只读取弹药和动作状态，不改变弹药结算、射速、换弹时长或手臂动作。
