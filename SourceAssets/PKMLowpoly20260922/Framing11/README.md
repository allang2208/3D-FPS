# PKM 待机视野调整

用户反馈左侧提把挡视野，本轮读取当前 UE 的 M4、QBZ191、ASH12、A762、PKM 待机动作及角色默认镜头参数，并读取 PKM 当前源模型的提把位置。数据见 `idle_comparison.json`、`handle_geometry.json`。

## 当前对比

相机局部坐标为 X 向前、Y 向右、Z 向上，单位厘米。运行角色的 M4 基准为 `(0, 7, -7)`，默认垂直视野 75 度。

| 枪械 | 调整前待机锚点 |
| --- | --- |
| M4 / QBZ191 | (0, 7, -7) |
| ASH12 | (8, 7, -7) |
| A762 / PKM | (6, 7, -7) |

PKM 仍沿用 AKM / A762 的前移参数，提把木制部分（源部件 136）位于相机前约 27–37 cm、右侧约 4–8 cm、下方约 4–7 cm，接近中央观察区。待机枪根轴向已基本水平，无须靠再次侧倾整枪补偿。

## 本轮修改

在 `Source/FPSGAME/FPSGAMECharacter.cpp` 的 PKM 专属分支将相对 M4 的偏移从 `(6, 0, 0)` 改为 `(9, 2, -4)`。默认最终待机锚点为 `(9, 9, -11)`：相对原版前移 3 cm、右移 2 cm、下移 4 cm。

位移作用于完整枪体、双手和附件组件，保持握点关系。继续使用已有动作展示位置混合和 ADS 校准，不修改换弹动画、材质、提把网格或视野角。现有 PKM 实例在重新装备时取得新参数。

本轮执行的是用户要求的待机位置对比。没有启动游戏或执行改后视觉验收，由用户试用后确认遮挡程度。

必要构建时遇到 `AuthoredDungeonGenerator.cpp` 的 C4458 错误，局部变量 `Role` 隐藏 `AActor::Role`。仅将该局部变量及其三处引用改名为 `LightRole`，灯光逻辑不变。
