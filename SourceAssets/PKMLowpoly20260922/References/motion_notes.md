# 用户视频动作观察与制作口径

来源：https://www.bilibili.com/video/BV1jHeA6sEmj/ ，标题《三角洲彩六联动pkm盾峰白板检视换弹等演示》。读取公共播放版本用于本机逐帧动作参考，不再分发。解码帧率约 30 Hz，共 1547 帧。动作不循环，动画作者时间基准为 60 Hz。

已实际查看完整视频的分段关键帧，以及约 10–17.6 秒和 19.5–27.1 秒的密集关键帧。开始/结束点取作者观察范围，并非游戏内部事件日志。普通换弹约 10.1–16.6 秒；空仓动作前段需从约 18 秒开始，约 25.7 秒回稳。两段动作均有侧倾、双手交接和上盖动作。

| 阶段 | 可观察动作 | 制作关系 |
|---|---|---|
| 起势/开盖 | 左手离开前支撑，抬起上盖；右手保留后握把支撑 | 左手到盖尾后才跟随上盖 |
| 处理余链 | 普通版本左手在供弹区域触及余链 | 不让整条弹链刚性整块翻转 |
| 支撑交接 | 左手回前部支撑，右手离开握把 | 先建立左手支撑再松右手 |
| 弹箱交替 | 右手在枪侧/下部工作，部分路径受枪体和画面边缘遮挡 | 被遮挡的路径属于本次三维作者适配 |
| 放链/压合 | 右手回到供弹区，手掌跨向枪体上方 | 手与链段/上盖分阶段接触，不贯穿插值 |
| 合盖/归位 | 右手合盖后退出，普通版本回握 | 保留短促接触制动和回稳 |
| 空仓末段 | 空仓版本合盖后另有拉柄/回握 | 独立末段，不套 M4 拍击事件 |

新模型的原厂 PKM 外形、弹箱、上盖和参考游戏皮肤存在差异，因此只沿用动作意图、左右手职责和相对节奏。内部补模依据同一实物的开盖照片，不能用游戏视频遮挡部分推断真实完整机构。此次不复制参考游戏的网格、贴图或动画轨道。

计划输出：`PKM_Idle`、`PKM_Reload_Normal`、`PKM_Reload_Empty`。暂不制作音效与游戏补弹事件，不进行验收渲染或游戏测试。
