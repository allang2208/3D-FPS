## 第一部分：为什么不原地剔除（诊断结论）

**BGM 能识别，但不能原地剔除。** 判据不是"听不出来"，而是实测的电平关系：

| 项 | 实测 |
| --- | --- |
| BGM 性质 | 连续、平稳、谐波性的背景床（整段视频都在，不止那两声） |
| 频段 | 能量主要在 110–600 Hz；稳定谐波列 46.9 / 117.2 / 210.9 / 328.1 / 515.6 / 609.4 / 679.7 / 820.3 Hz |
| BGM 电平 | RMS −41.5 ~ −46.3 dBFS（安静段的"纯 BGM"实测） |
| 机械撞击电平 | CoverOpen 峰值 −4.3 dBFS、CoverClose 峰值 −4.0 dBFS |
| BGM 占整段能量 | **1.5 % ~ 2 %**（打开/合上盖两个窗口实测） |
| 撞击相对 BGM | 高出 **≈ 22 dB**，且撞击在时间上极短 |

后果是双向锁死：撞击期间 BGM 被掩蔽、听不见；撞击衰减后 BGM 才露出来，而那时两者电平已经接近。
因此**任何能真正削掉 BGM 的处理，都必须同时削掉机械撞击本身**。

## 三种剔除方案都实测过，都不能用

| 方案 | 做法 | 实测结果 | 判定 |
| --- | --- | --- | --- |
| 谱减（Wiener 软掩蔽） | 用时间分位数估计背景床，逐 bin 抑制 | 对瞬态透明（峰值 −0.3 dB，整体 −0.6 dB），但只压掉 **3.5 dB**；且残留床仍与相邻安静段电平相当 | 收益在感知阈值附近 |
| 瞬态门（downward expander） | 按 1 ms 包络在低电平处衰减 | **打坏起音**：CoverClose 峰值 **−14.8 dB**，整体 −8.9 dB | 不可接受 |
| 谐波窄带陷波 | 只处理 BGM 谐波 bin | 加大深度到 γ=50 也只降 2.5 dB（已收敛） | 同样不可用 |

**为什么谱减压不下去：** 参考视频 10–16 s 的安静段背景床本身在 26 dB 范围内浮动（60–260 Hz 频带从 −56 到 −82 dB 波动），
不是平稳噪声。用邻近安静段估计出的床，套到两声片段上时电平并不匹配，
独立同分布检验（用一个安静段估计、去减另一个安静段）只能得到 0.2 ~ 8 dB 的抑制，拿不到"静音级"的零深。

**为什么没有可用参考：** 背景床有 2.5 s 的节律，但相位级互相关最高只有 0.74（0.6 s 探针），
远低于相消所需的 0.95+，说明它不是严格循环，无法用"重复段相减"真正抵消。

## 第二部分：尾音重建（最终采用）

### 为什么只重建尾音

实测把污染范围定得很窄。逐帧算"撞击相对背景床的余量"，只有余量落到 6 dB 以下的地方
BGM 才可能被听见，而这些位置全在撞击衰减之后：

| 片段 | 撞击峰值 | 撞击仍压制床到 | 需要重建的尾音 | 保留的撞击本体 |
| --- | --- | --- | --- | --- |
| CoverOpen | 320.0 ms 处 +29.1 dB | **437.3 ms** | 437.3 → 515.0 ms（**77.7 ms**） | 0 → 437.3 ms |
| CoverClose | 10.7 ms 处 +27.5 dB | **192.0 ms** | 192.0 → 235.0 ms（**43.0 ms**） | 0 → 192.0 ms |

也就是说：**占能量 98 % 以上的撞击一个字都没动，只换了最后 0.08 / 0.04 秒。**

### 方法

1. **素材**：用 `ChargeRelease`（25.010–25.215 s）作供体——它是全部 8 个接触音里唯一
   100 % 帧都 ≥6 dB 压制背景床的干净素材。**不用被污染片段自己的尾巴**做素材。
2. **音色**：用该片段自己的**安静周边**（CoverOpen 取 9.05–10.00 s，CoverClose 取 15.10–15.75 s）
   作音色参考——同一房间、同一批机械，但不含接触声，因此不含音乐。
   按 11 个频带做零相位色彩传递，限制 ±20 dB。
3. **包络**：跟随原尾音的强平滑衰减轮廓（25 ms 平滑，抹掉音乐调制）。
4. **拼接**：交界处 15 ms 交叉淡化；首尾各 6 ms / 25 ms 淡化防咔哒。
5. **长度与电平**：输出严格对齐在用资产的采样数与峰值，并套用 `author_audio.py` 的
   `common_gain_db = −1.9473`，保持整组相对响度不变。

### 实测验收

| 指标 | CoverOpen | CoverClose | 判据 |

| 采样数 | 33228 == 33228 | 11280 == 11280 | 与在用资产完全一致 |
