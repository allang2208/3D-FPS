每个片段均按峰值对齐，方便背靠背比较。

| 文件 | 内容 |

| `A_<片段>_RAW_withBGM.wav` | 未处理的视频原始裁切（带背景床），用来对照"床本身是什么样" |

**一处与记录不符，如实记下**：`BGM_FINDINGS.md` 写 09-25 那版"保留段逐样本一致、
撞击前缀相关度 1.00000"。相关度 1.0 不等于逐样本一致，实测该交付 WAV 的**撞击本体里
有 1166 / 28464 个采样与原始裁切不同**（CoverClose 728 / 9211），最大偏差 3.9e-2 /
1.5e-2（约 −28 / −36 dBFS，远低于峰值，听感上应不可闻）。**v2 的保留段才是真正逐样本一致**
（差异恰好从交叉淡化起点开始）。两者峰值与采样数都未变。

## 两版的实质区别（不是电平，是尾音性格）

| | 09-25 / 第一版 | v2 |
| --- | --- | --- |
| 替换材料音色 | 色彩传递到**背景床**的频谱 | 保留供体自身机械音色 |
| 替换材料电平 | 包络跟随**背景床电平**（约与床齐平） | **合成衰减**，落到比床低 30 dB |
| 床频带（250–1000 Hz）抑制度 | 12.5 dB（= 供体掩蔽余量上限） | **+36.4 dB（开盖）/ +39.2 dB（合盖）** |

所以 `B` 的尾音是一段"和床差不多响、且音色像床"的平稳声；`C` 的尾音是从拼接点衰减下去的。
如果你当初认可的正是 `B` 那种，`C` 会让你觉得尾巴"变短、变干"；如果你要的是彻底没有床，
`C` 才是目标。
