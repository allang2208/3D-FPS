# PKM：逐节收短、柔性弹链与参考换弹音效

2026-09-23。沿用 Motion21 网格、Finish20 材质与 Reload16 普通/空仓动作。此次修改运行时弹链表现及换弹声音，不重新导入枪体或手臂动画。

## 左侧出链

- 移除每 25 发归零的整段显示逻辑。25 个已有叶骨作为循环池，每节依据绝对生成序号沿出链方向移动；旧节先退场，新节从出口依次进入。
- 出口累计路程 14.7 cm 为退场边界，位于原出链路线的弹箱上缘附近。最后 0.65 cm 做单节收小，连接片与对应链节一起退场；通常仅保留约 8 节可见链节。
- 原始引导舌片只出现一次，也在相同边界退场，不随骨池循环重生。新弹链的引导片仍由换弹显隐窗口控制。
- 保留末发供弹展示宽限及旧链/新链 Section 时序；换弹隐藏旧道具属于原动作交接，不是 25 发整体消失。

## 柔性表现

- 新增 `FPKMSoftChain` 世界空间粒子层，240 Hz 子步、链节距离约束、重力与惯性，替代左侧出链原来的整段旋转摆动。
- 左侧出链固定出口前 3 点，悬空部分最多有 3.2 cm 渐增活动范围；抓起旧链时改以手持链头为锚点，重力仍来自世界方向。
- 换弹供弹链仅处理裸露的 0–8 号节点及连接片。0 号手指接触点、8 号弹箱入口和箱内部分保留当前动作；中间悬空段活动范围最大 2.4 cm，靠两端收紧。阻尼 3.6、引导弹簧 42，降低对旧烘焙曲线的依附。
- 新链在铺入供弹位前逐渐收回作者轨迹，正常与空仓均使用 `ReloadEventTime` 的动作时钟。盖板接触在弹链解算后计算。
- 这是有长度约束的外观动态层，不是全枪 Chaos 碰撞模拟。活动边界沿当前作者路径限制，主观柔软程度和遮挡表现尚待用户游戏测试。
