# PKM 独立脚架与下垂支腿惯性

2026-09-23。按用户要求检查脚架拆分、独立改造分类及移动时的摆动，并按后续明确指示将选装后的两条支腿设为向下姿态。

## 分件与装配

当前 Motion21 源的 65、72、127、128、129 五个零件均标记为 `attachment_id=pkm_bipod`，没有枪体导出使用的 `mechanical_bone` 属性；原游戏使用独立 `Bipod07/SM_PKM_Bipod`，已确认此前拆分存在。

本轮继续拆成 3 个静态资产：

- `SM_PKM_Bipod_Base`：72 夹座和 129 横销，固定随枪体运动。
- `SM_PKM_Bipod_LegA`：127 支腿及其 65 收拢卡扣。
- `SM_PKM_Bipod_LegB`：128 支腿。

源姿态的支腿原本沿枪管收拢，本轮围绕实测横销放下约 82°，两腿各外张 12°。腿部网格的原点移到各自销轴接点，材质、UV 及原始细节保留。`authoring.json` 记录实际枢轴、尺寸和导出分组。

当前运行资产目录为 `/Game/Weapons/PKMLowpoly20260922/Bipod26`。固定件使用 WPN_root 坐标，运行时只抵消一次根骨的 100 倍单位缩放；支腿使用各自局部枢轴，不在枪根处旋转整套脚架。

## 枪匠与存档

- 新分类 `bipod` / “脚架”，仅 PKM 开放；选项为“无脚架”和“PKM 脚架”。新配置、无该字段的配置均默认不装备。
- 前握把槽不再包含脚架。脚架与前握把可以同时装备，不再互相清除。
- 旧实例明确保存的 `underbarrel=pkm_bipod` 在读取时迁移为独立脚架槽；不会给空配置自动添加脚架，也不会覆盖新槽中的明确选择。应用时由原有枪匠保存流程写入。
- 已同步持枪外观、枪匠应用/取消、独立展览、物品图标准备、掉落模型组件复制和预加载路径。
- 卸下脚架会销毁夹座及两腿组件，防止递归显示枪体时把未装备脚架重新显示出来。
- 分类/选项使用本模型制作的透明图标，文件位于 `Content/ColdSteelData/AttachmentIcons20260913`；“无脚架”沿用现有中性移除图标。图标的 Blender 材质来自原脚架作者材质，游戏内材质以导入时读取的当前 Finish20 绑定为准。

## 摆动实现

`UPKMBipodComponent` 只负责本地外观，不改变弹药、伤害或武器数值。读取实际挂点线加速度和角加速度，叠加重力，以 240 Hz 子步的弹簧/阻尼模型驱动两腿。两腿频率为 3.2/3.4 Hz，阻尼比为 0.40/0.42，围绕下垂姿态各限制在 ±6°，末端有软限位和低回弹。

固定夹座不摆动；腿部从各自销轴运动。停止后回稳，装卸、切枪、长时间中断或位置跳变重置惯性。未装备不创建组件；隐藏时清除摆动，展览和图标使用静态默认姿态。此轮没有新增触地支撑、展开操作或架枪增益。

三个网格复用导入前实际脚架的材质对象及已有湿润映射，继续由现有天气组件发现。

## 记录与交付边界

- `source_inspection.json`：源零件的分离状态、材质及包围盒。
- `grip_clearance.json`：最初收拢姿态的相交记录，仅说明旧姿态的问题，已被用户要求的下垂姿态替代。
- `grip_clearance_down.json`：下垂姿态及前后各 6° 三个角度下，与当前五款前握把的源几何表面检查；采样中均未发现交叉面。不代表整枪/手臂连续动作验收。
- `PKM_Bipod_Editable.blend`、`Exports/`、`PKM_Bipod_Icon.blend`：本轮可编辑模型、FBX 和图标制作源。
- `import_receipt.json`：已保存的 UE 资产、实际尺寸、干湿材质路径、散列及图标记录。
- `build_legs_down_console.log`：包含本轮 C++ 的常规 Editor 构建结果。构建过程中遇到天气模块导出类的多变量静态声明 C2487，最小修复仅将该声明拆行，保留其逻辑。

没有启动交互式 UE 编辑器或游戏，运动观感由用户在游戏中测试。制作入口：`inspect_source.py` → `author.py` → 常规 Editor 构建 → 后台 `import_assets.py`。
