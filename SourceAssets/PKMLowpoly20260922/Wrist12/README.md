# PKM 左腕与前端支撑接触修正

用户要求排查待机左腕并重新校准握持接触。本轮以当前 `HandReload10/PKM_ReloadHands_Editable.blend` 为源，修改左侧支撑链及相邻动作回握。

## 定位与调整

- 当前 UE 待机资产仍来自 Belt08；RAW / COMPRESSED 腕轴折角分别为 41.6808° / 41.6807°，与源动作一致。源数据见 `source_diagnosis.json`，引擎读取见 `engine_before.json`。
- 仅固定肩部、改肘位，最小腕轴折角仍约 38.6°。本轮沿枪械局部坐标将肩带向前移 6.5 cm、向内移 1 cm，重解双骨链；上臂与前臂长度不变。
- 整手围绕原前端窄支撑轴轻转 -5°，手腕因此随握面移动约数毫米；保留五指局部抓握形状，不移动指关节、不缩放骨段。
- 保持原肘关节的弯曲平面，独立计算 rest 相对的前臂轴向扭转，并分配到现有两个辅助骨。避免把手腕完整弯折套给辅助骨，也避免把变形集中到肘部。
- 调整后的源姿态腕轴折角约 17.83°，肘部折弯约 61.10°。这些是同一骨架的比较指标，不是人体医学角度或游戏验收阈值。
- 按实际变形后的手套测量前端机匣与窄支撑面。掌垫及五指均保留邻近接触；`contact_geometry.json` 区分掌垫与只受手骨控制的腕部区域。最近距离只是局部贴合指标，不单独证明所有表面或动态过程无穿插。

## 动作与文件

- `PKM_WristContact_Editable.blend`：完整可编辑源，新增 `_Wrist12` 动作，保留前一轮动作。
- `Exports/A_PKM_*.fbx`：待机、瞄准、射击、瞄准射击、装备、检视、奔跑进/循环/出、快速近战、普通/空仓换弹，共 12 个动画。
- `author.py`、`fit_support.py`：本轮制作与参数入口；`support_fit.json`：明确的握点和整臂参数。
- 普通/空仓换弹仅改左手支撑、脱离和回握窗口（0–0.62 s、2.13 s 后），开盖/取链的操作段保留 HandReload10；右手、枪根、机械件、弹链时序不变。
- `before_side.jpg` / `before_underside.jpg` 与 `after_side.jpg` / `after_underside.jpg`：针对本次排查生成的源模型近景。浅蓝为手臂诊断色，不是游戏材质修改。
- `PKM_WristCandidate.blend` 是姿态诊断快照，交付以完整 `PKM_WristContact_Editable.blend` 为准。

12 条动画已全部导入并保存，桥结果为 `Saved/pkm12-import-03.txt`。接入后读取当前待机来源为 `Wrist12/Exports/A_PKM_idle.fbx`；RAW / COMPRESSED 腕轴折角分别为 17.8256° / 17.8255°，见 `engine_after.json`。这是针对本次排查的姿态读取，不是游戏运行验收。
