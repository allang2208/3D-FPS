## 排查过程与结论

### 1. 不是网格问题，也不是权重问题

`v7_mesh.npz` 里整条手臂网格是 **完全镜像对称** 的两块：

- 2 个 loose part，左右各 9321 顶点，包围盒互为镜像，拓扑一致。
- 开放边界环只有 4 组：左右肩各一条 61 边的开口（护臂截断处，正常），
  加左右手各一条 4 边小环。**小臂上没有任何接缝。**

把左臂每个顶点与右臂镜像点配对（KD-tree，9320/9321 对在 1 mm 内），
把右臂权重按 `_l`/`_r` 互换后比较：

```
per-vertex |dW|:  mean 0.0000  median 0.0000  p99 0.0001  max 0.0006
```

**权重逐位镜像一致。** 所以折痕既不是建模接缝，也不是左右权重不对称。

### 2. 是姿态：左小臂承担的旋前量是右臂的三倍

同一帧、同一片段、同一光照下渲染左右臂，右臂光顺、左臂有折痕。
用同一套表面滚转度量量两条手臂：

| | 左 | 右 |
|---|---|---|
| 肘弯曲 | 61.1° | 117.2° |
| 旋前量（`hand_l` − `upperarm_twist_02_l`） | **−196.5°** | +53.4° |

### 3. 用"边拉伸"定位失败（记录以免重走）

逐边比较形变后长度 / 静置长度，左臂最大值 12.9×（右臂 4.2×），
看着像撕裂。但把最严重的边打出来后发现：

```
ratio   rest_mm  posed_mm
12.91     0.16     2.01
 9.62     0.10     0.99
```

**全是 0.1–0.4 mm 的退化短边**，比值再大也没有视觉意义。
这个指标被数值噪声主导，不能用来判定表面缺陷。已放弃。

### 4. 真正的成因：表面读的是"权重质心处"的滚转，不是 t 处的滚转

表面在 t 处的滚转 = 各骨骼滚转按权重加权平均。所以

```
surface(t) = Σ w_b(t)·roll_b / Σ w_b(t) = R(t̄(t))
```

其中 `t̄(t)` 是该处的**局部权重质心**。若骨骼滚转只是 t 的线性函数，
表面仍然会在 `t̄(t) ≠ t` 的地方鼓包，鼓包大小 ≈ |slope|·|t̄(t) − t|。

实测左右翻转点就在 `lowerarm_l` 与 `lowerarm_twist_02_l` 的权重交叉处
（t ≈ +0.25..0.35），那里权重质心比 t 落后约 0.10，于是出现 ~14° 的回折。

**所以 Elbow39 把三根小臂骨强行拉成直线并不能压平鼓包——只是把它挪个位置。**
Elbow39 把最差背面台阶从 32.8° 降到 9.0°，剩下的正是这个 14° 回折。

### 5. 本轮做法：直接对着表面轮廓做优化，不再假设直线

对每一帧：

1. 用同一套度量量出当前表面滚转轮廓 `cur(t)`。
2. 从网格权重算出每根被修骨骼在每个 t 分箱里的**权重占比** `Wn[t,b]`（前向模型）。
3. 在该模型上枚举三根骨骼的修正量（−45°..+45°，步长 5°，共 6859 组合），
   取让「最差背面台阶 + 0.02×总变差」最小的一组。
4. 施加世界空间绕**实时小臂轴**、过该骨骼自身头部的旋转；随后按
   `ORDER` 从近到远用各自**保持不变的世界矩阵**重算局部通道，
   所以 `hand_l` 及其所有手指、握持、接触点按构造不可能移动。

修正量（整个片段恒定，待机是静止的）：

| 骨骼 | 修正 |
|---|---|
| `lowerarm_l` | −35.0° |
| `lowerarm_twist_02_l` | −20.0° |
| `lowerarm_twist_01_l` | +45.0° |

## 教训（已并入技能）

1. **逐边拉伸比值不能用来判定表面缺陷**：三角网格里存在大量 0.1–0.4 mm 退化边，
   比值会被它们主导。要看表面就用表面度量。
2. **骨骼滚转线性 ≠ 表面滚转线性**。表面读的是权重质心处的滚转，
   所以修复目标必须按权重质心定义，或者干脆直接对表面轮廓做优化。
3. 先做**左右对照**：同一帧、同一光照、同一网格，右臂光顺而左臂不光顺，
   就立刻排除了建模与权重，把范围缩到姿态上。
