# PKM ArmJoint49：腕口衔接与肘腕配合

用户截图显示棕色手套与裸前臂之间有可见断面和漏空，并要求再次检查肘关节、改善人体工学。范围为当前 PKM 的两款手套、衣袖，以及基础/四种配件的换弹动作。

## 排查与实施计划

1. 读取当前实际装备网格、参考骨架与动作，比较腕口两侧的几何位置和骨骼权重。
2. 让手套的对应顶点沿用当前裸臂权重；衣袖在同侧裸臂表面转移权重，并平滑衔接至上臂。
3. 复查肩、肘、腕关系。在固定肩与手掌接触、保持两段骨长的条件下，调整肘部参与开盖动作，减轻腕部过折。
4. 平滑换弹中原有的肘部转向急跳，保存实际资产、JSON 制作源及可编辑 Blend。
5. 按本次明确提出的关节检查要求，读取保存后的腕口及关节数据。没有启动游戏或追加截图、渲染验收。

## 确认的原因

- 上轮 LeftArm48 修改了裸臂绑定，却没有同步 PKM 手套与衣袖。这是制作接入遗漏。
- 两种手套左腕口各有 87 个边界顶点；全部仍使用旧裸臂权重。参考姿态位置相同，但动画中被不同骨骼拉动，最大分离 3.113 cm。
- 棕色手套为当前运行时装备的 `HuntFieldGlovesV1/PKM`，不是错误材质或未使用的候选网格。
- 原换弹最大腕轴折角约 77.84°。基础待机约 17.83°；待机骨架轨迹无需修改，断口通过同步装备蒙皮解决。
- 肘部屈曲约 6.91°–113.39°，没有反折；普通换弹第 262 帧的上臂方向单帧变化约 24.54°，原动作已经存在。

## 制作内容

- 两款手套依据 `bare_vertex_ids` 逐顶点复制当前 PKM BarePalmV7 权重，包含两侧腕口，保持原几何、法线、UV 和接触面。
- 衣袖在同侧裸臂三角面做重心插值；肘后过渡带逐渐混合到新权重。原袖口覆盖厚度与几何保留。
- 三份服装各保留原有 3 个 LOD，源模型和 UE 实际网格都已更新。没有修改其他武器的服装或共享母版。
- 10 条普通/空仓换弹修改左上臂、两根上臂辅助骨、三根前臂骨和手骨补偿。肩/手掌位置、手掌朝向与原有骨长保留，手指和枪械轨道保持原数据。
- 肘部在固定肩腕的两骨圆弧上参与开盖，避免把动作全部压到腕关节。腕轴最大角降至约 66.4°；该数值是骨架几何指标，不等同于实机视觉验收。
- 对肘部弯曲方向使用随肩腕轴最小旋转传递的坐标系，再平滑连续角度。没有直接平均肘部世界坐标，避免缩短骨长。动作首尾保持原姿势。

## 文件与落盘边界

- `Inputs/`：修改前实际网格、全动作采样和运行时装备记录。
- `Authored/`：三份服装 JSON；已同步回 `ModularOutfit20260925/<family>/Authored/PKM.json`。
- `Editable/`：按当前原生骨架和最终源面重新生成的三份 Blend；已同步回各服装 `Editable/`。
- `Tracks/`：10 条最终换弹轨道，直接通过 AnimDataController 保存；旧 FBX 重导入会覆盖这些修改。
- `Before/Packages`、`Before/Sources`、`Before/Editables`：本轮修改前的原始资产与源文件。
- `install_receipt.json`：逐资产落盘回执，`complete` 和 `pending_animation_updates` 表示最终轨道是否全部写入。
- `SavedReadback/`、`saved_joint_inspection.json`：最终平滑版本保存后的网格和 15 条待机/换弹动作读取结果。
