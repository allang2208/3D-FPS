# PKM 握把腕部与后握把接口修订

用户反馈：安装前握把后左腕不自然、扭曲；替换后握把与原装安装位置错位。

## 左腕修订

制作基底为 Accessories14 当前四组握持动作。原始手型、枪根、右手、机械件、动作时长和换弹操作阶段继续沿用。

- 保留当前手掌和手指的接触坐标，调整肩肘支撑。作者参数见 `fit_frames.json`；肩部修正为 0–约 25 mm，斜握把族较小。
- 分开处理腕部折弯和轴向旋转；前臂 roll 由掌宽方向在前臂横截面上的投影确定，不把腕部完整折弯带入 roll。
- 上臂、前臂辅助骨恢复所属骨段的完整 rest-local 关系，去除旧版叠加的分数扭角。保持骨架、骨长和蒙皮权重。
- 换弹脱手／回握窗口使用原 0.26–0.62 秒、2.13–2.30 秒的过渡；中间操作段保留原动作。各采样帧按原骨长重新解肘部，手掌保持原轨迹。
- 四组动作各 12 段；开火动作沿用 240 Hz，其余 60 Hz。战术垂直握把继续复用垂直握把族。

`source_frames.json` 是本轮制作所需的源骨架／几何读取，不是运行测试或验收报告。`fit_frames.json` 中的角度是作者骨架指标，不能代替手腕蒙皮的视觉验收。

## 后握把接口

原 Accessories14 使用供体右手坐标变换，供体握把接口与 PKM 实际机匣接口不一致。本轮取消这项定位依据，以原装 `PKM_Part_045/046` 的上端安装面和下端握柄轴线重新定位幻影、均衡、防滑稳定三款后握把。

- 按 PKM 安装面调整中心、倾角及小范围等比尺寸，重做安装垫片并贴合接口。
- 保留供体握柄的形状、UV0、法线、材质区域、聚合物和金属涂层；UV2 随新几何位置更新为原有 5 cm 物理涂层尺度。
- 原装握把的隐藏／恢复逻辑及右手动作不变。

## 文件与接入

- `author_arms.py`、`PKM_<family>_Editable.blend`、`Animations/`：修订动作及可编辑源。
- `author_reargrips.py`、`SM_PKM_<key>.blend`、`Exports/`：三款后握把及可编辑源。
- `reargrips.json`：安装面、轴线和作者变换。
- `import_reargrips.py`、`import_<family>.py`：通过工程互斥桥导入；复用 Accessories14 的实际游戏路径和材质绑定。
- `reargrips_import.json`、`animations_import.json`：实际导入保存记录。
