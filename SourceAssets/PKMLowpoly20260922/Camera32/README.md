## 接入与时序

- `FPSGAMECharacter.cpp` 将 PKM 接入动作镜头入口，分别选择 `PKMEquip`、`PKMReload`、`PKMReloadEmpty`。
- 换弹镜头使用 `ReloadSourceTime` 和当前 `MechanicalCueTimes`，与姿态、声音共用源动画时钟。换弹速度变化不另计时。
- 普通接触顺序：开盖 0.65、旧链抬起 1.65、弹箱移出 2.60、弹箱装入 4.35、新链铺入 5.10、关盖 5.72 秒。
- 空仓接触顺序：开盖 0.65、弹箱移出 1.70、弹箱装入 3.45、新链铺入 4.20、关盖 4.82、后拉 5.13、释放 5.55 秒。省略旧链动作与镜头冲击。
- 空仓后拉及释放复用 ASH-12 的完整随动幅度与冲击节奏，使用 PKM 的 5.13 / 5.55 秒接触时点；拉栓段不复用 M4 拍击事件。
- 装备按当前 0.90 秒片段采样：0.39 秒接握、0.64 秒落回支撑、0.86 秒回稳。以源片段时长同比缩放，无额外装备拉栓。

## 强度与范围

用户实测反馈第 32 版过轻，2026-09-23 本轮改为第 33 版，直接采用其它步枪的现有幅度：

- `ReloadPKM` 直接调用 M4 普通换弹的 `Reload` 曲线及冲量函数，将退匣、插入、压实三个事件映射到 PKM 退箱、装箱、关盖；沿用 M4 的俯仰、横滚、位移与回弹时长。
- 空仓后拉和释放照搬 ASH-12 的镜头参数：后拉俯仰峰值由 0.56° 改为 2.10°，释放冲量由 -0.52° 改为 -1.25°，释放反馈时长改为 0.34 秒；不应用 M16 的 0.45 倍拉栓衰减。
- `EquipPKM` 用 M4 装备的随动向量与两个冲击向量，对应 PKM 接握 0.39 秒和落枪 0.64 秒；冲击俯仰分别为 1.20°、-2.25°，时长分别为 0.22、0.26 秒（按装备片段时长同比缩放）。
- 开盖、旧链抬起及新链铺入补充中等反馈，空仓仍省略旧链。以上角度均为共享强度缩放前的作者参数，并非实测屏幕峰值。

继续使用现有 `Strength`、`FollowStrength`、`ImpactStrength`、角色 `CameraMotionScale` 和 `fps.Camera.ActionShake`。现有通用参数会共同缩放上述作者值。镜头每帧按源时间重建，状态结束或取消时由现有入口清除该层，不累积位移。

反馈写入相机 additive view offset，保留瞄准控制、射击射线、伤害与弹药结算。已烘焙的枪/手受力动作继续使用；不开启旧的通用机械事件冲量，避免重复。开火、移动、战术冲刺和快速近战反馈沿用现有实现。
