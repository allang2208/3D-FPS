# PKM 换弹手部精修：本轮参考观察

本轮重新解码并查看用户指定的 `References/PKM_UserReloadReference.mp4`：640×360、30 Hz、1547 帧。实际查看 10.5–16.1 秒普通换弹及 18.3–25.3 秒空仓片段的关键帧，另查看原空仓连续动作表。详细取样时刻在 `reference_decode.json`；这些图只用于本地作者参考。

- 10.7–11.3：左手张指接近盖尾，抬盖后松握离开；右手留在后握把。
- 11.5–12.1：左手在供弹区用拇指/食指捏取余链，抬起并扫向侧边，随后开指释放。
- 12.3–12.7：左手已回前方支撑，右手才开始操作弹箱。
- 12.7–14.5：右手取放弹箱，画面下缘和枪体遮住主要路径。该段采用当前 PKM 的三维接触适配，不声称精确恢复遮挡内容。
- 14.7–15.3：右手从侧面转腕，捏住链头、铺链，指腹压入后先松指。
- 15.5–15.9：右手另行抬起，以掌部推合盖，再离开盖面；不是握拳随盖到底。
- 空仓末尾 24.5–25.3：关盖后右手另接拉柄并回握；与普通版本的回握收尾分开。

本轮保留当前 6.5 / 7.5 秒时长及机械音效时点（0.65、1.65、2.60、4.35、5.10、5.72；空仓另有 6.03、6.45）。按这些接触点对参考相对节奏进行适配。

使用当前 Belt08 几何、21 节可视弹链和 SectionFix09 材质映射。旧 PKM 程序手部求解不是成功模板：本轮新建分阶段手型、物体局部接触及整臂方向。枪体/手臂网格、蒙皮权重、静止骨架不变，只导入普通和空仓换弹两个动作。为配合可达的持箱接触，局部调整箱子退入路径和余链离座路径；不改容量、结算、状态切换或声音事件。

用户未要求新的预览渲染或游戏测试；本轮交付作者源、FBX 和游戏动作资产，由用户测试。
