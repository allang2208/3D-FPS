# PKM 游戏接入候选

本轮使用用户下载的 EXcaliburK117 / EXcalibur117 PKM 模型及本目录上级的机械、换弹作者源。来源和使用边界沿用 `../SOURCE.md`，未使用旧 Meshy PKM 枪体。

## 入口

- 武器实例定义：`ue_pkm_lowpoly`，游戏显示名 **PKM**。
- 弹药袋定义：`ammo_pkm_762x54r`，7.62×54R LPS，100 发弹箱。
- 首次仓库配发：PKM 一把，箱内 100 发，弹药袋追加 300 发；按 ArmoryReceived 保持一次性配发。
- 新定义独立于退役的 `ue_pkm`、`ue_pkm_a`、`ammo_762x54r`，保留旧存档清理规则。
- 物品图标、掉落模型、枪匠展示沿用游戏现有实际视模截取流程，隐藏手臂及备用弹箱/弹链。
- 当前是原厂构型；未制作额外瞄具、弹鼓、枪托等可见改装。枪匠的全枪通用数值枪管选项沿用现有目录规则。

## 动作与材质

`PKM_Gameplay_Editable.blend` 包含共享 Manny 手臂、原枪体、内部可见补模、独立机械骨骼和两套换弹道具。`Exports` 保留 FBX。游戏目录为 `/Game/Weapons/PKMLowpoly20260922`，独立 Skeleton，不修改 M4 骨架。

12 个 clip：待机、瞄准、开火、瞄准开火、装备、检视、冲刺进入/循环/退出、快速近战、普通换弹、空仓换弹。普通/空仓换弹源长 6.5/7.5 秒，按现有游戏换弹倍率整体缩放。补弹结算沿用原游戏动作完成事务。新增持枪辅助动作是适配后的作者候选，不代表已经获得视觉认可。

备用道具由材质区段控制显示。换弹结束时直接交接到同一握持姿态，不让两套弹箱在淡出混合中穿过枪身。空仓隐藏旧弹链，重新装填后恢复。当前弹链显示按空仓/有弹状态切换，尚未按每发剩余弹量逐节缩短。

六组基础 PBR 加内部钢材，导入原生分裂/加权法线；法线贴图翻转绿色通道并保留 0.3 强度。手臂材质绑定到当前 M4 正式视模的同名材质槽。射击及机械声音暂复用现有 AKM 通用音效，事件时间对应此 PKM 动作，不宣称录制自真实 PKM。
