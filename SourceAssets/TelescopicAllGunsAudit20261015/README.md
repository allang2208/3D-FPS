## 证据与范围

- `capture.json`：读取实际网格、文件散列、槽/section、构建设置；从当前材质 Normal 输出向上遍历有效输入，包含实例覆盖值。共享纹理的实际导入源仍为 `M16AttachmentSurface20261014/Detail/T_TelescopicStructuralDetail_R2.png`；M16 指向私有匹配法线。
- `Exports/`：10 个实际当前 UE 网格的 FBX 导出。9 个未替换网格的完整包与 R1 回执一致，因此本次 M16 修复没有挪动这些枪型的现有接口。该一致性不代表它们已有接口经过本轮实机装配验收。
- `surface_audit.json`：UV 通道、材质面数、角点法线和结构法线隔离渲染结果。
- `degenerate_normal_check.json`：进一步区分异常角点法线与近零面积面。
- `Preview/all_stocks.png`：10 枪对照。使用实际导出的网格、有效主体结构法线和统一诊断金属材质；8 个 R2 使用者均可复现菱形异常，M16 没有该异常，A762 中性法线显示其剩余低模起伏。
- 以上图片是 **Blender 诊断渲染**，不是完整 UE 材质/配色效果或枪体安装画面。没有运行游戏、操作枪匠界面、多人、天气或动画测试。

枪匠的 10 个 ID：`ue_m4a1`、`ue_akm`、`ue_qbz191`、`ue_m16a2`、`ue_a762`、`ue_svd`、`ue_pkm_lowpoly`、`ue_lmg201`、`ue_hk416`、`ue_super90`。静态运行路由在 `SkeletonStockVisual.cpp`、`HK416WeaponAssets.h`、`M16Attachments.h`、`QBZ191Attachments.h`、`A762Attachments.h`、`PKMAttachments.h`、`SVDAttachments.h`、`LMG201Attachments.h` 和 `Super90StockAssets.h`，均对应本轮读取的网格路径。
