# A762 空仓换弹：左手托枪微调

后续右手拉栓优化已接续此版本，五条空仓动画的最新作者源与导入记录见 [A762 右手拉栓](../A762RightCharge20260922/README.md)。不要单独重跑本目录导入覆盖后续右手修改。

用户要求检查并微调插入弹匣后、左手托住枪体而右手拉栓的阶段。以当前 IndexClearanceV4 动作作为输入，仅修改 A762 五套空仓换弹的左臂和左手旋转。

## 定位与修改

原 A762 动作沿用 AKM 支撑位置，左掌偏后、偏低，以指尖靠近护木后缘，掌面没有充分承托主体。参考当前原厂前端托持姿态，将支撑点放在护木后段、弹匣井前方；按 A762 的实际枪身宽度调整掌面倾角及成组手指包覆。原生骨长、rest、局部平移、缩放和蒙皮权重不变。

源时钟 120 Hz：254–272 帧从插匣结束姿态平滑进入支撑；272–385 帧在枪根坐标中维持托枪关系，覆盖右手接近拉柄、后拉、释放与回收；385–440 帧衔接各自原有前握把回握。前段取匣／插匣及此前食指修正保留。右手、枪根、弹匣、枪机轨道以及补弹和音效时序未改动。

共 5 条空仓动作：原厂、斜握把、垂直握把、棱镜阻手器、45°握把。A762 普通和扩容弹匣共用这些动作。未修改 AKM、非空仓换弹或独立弹鼓动作。

## 源与局部检查

- sources.json：UE 当前加载的五条动画、导入来源、骨架和压缩设置。
- Support_Working.blend、support_input.json：实际 A762 枪身与当前空仓动作，制作时排除被隐藏的旧 Before 网格。
- fit_support.py、fitted_support.json：实际护木／机匣外壳适配；保留成组手型，旋转关节而不拉伸或平移指骨。
- author_support.py、authoring.json：五套完整可编辑 Blend 与 FBX、支撑窗口和目标资产。
- Diagnosis/：本轮明确要求检查所使用的源模型局部图，非游戏截图。
- contact_diagnosis.json：朝向枪身的近掌面采样，最近 50 点的平均距离由约 22.50 mm 缩至约 2.10 mm；这是源模型局部估算，不是实机精度声明。
- support_phase_diagnosis.json：272–385 帧支撑窗口中，实际源姿态与枪根支撑目标的最大位置差小于 0.001 mm，手部表面采样点在枪身保守外包络之外。窗口外记录用于观察交接，不将原有握把／待机手型或非支撑区域概括为全部无穿模。
- 动画曲线比对未发现左臂／左手旋转轨道之外的修改；动作仍为 515/120 秒。
