# 独立铸造台与连续冶炼 · 2026-09-26

按用户选定的方案 2 制作：高炉逐轮出料到成品架，玩家领取后自行存入已有储物箱。铸造台是单独的可建造设施，后续再开发打铁和自动化。

当前铁砧改用 [实物参考修订 V3](AnvilReferenceV3/README.md)：砧角、切削台阶与砧身合成连续实体，取消独立工作面薄板；使用项目已有 Normandy 氧化金属与新制锤击钢面，通过网格磨损权重混合。下文 V1 模型源和三角形数量属于初版装配记录；当前完整源和清单位于 `AnvilReferenceV3/Authored/`，父目录安装入口已转向该修订。外观和运行效果尚待用户测试。

厘米尺寸修正后，用户已认可模型。当前材质继续改为 `AgedIron4` 深色做旧铁：降低整片亮钢覆盖和泛白反光，保留氧化、凹坑与局部旧磨痕；此次仅更新材质，模型、尺寸和 FBX 不变，材质外观待用户测试。

## 使用

1. 建造列表「其他」内放置「铸造台」，位于高炉旁、同一层，中心水平距离不超过 3.5 米。
2. 在高炉添加燃料、选择矿石并「加入队列」。每座高炉连接最近的空闲铸造台，一台供一炉使用。
3. 当前任务外可排 8 项，单项投料上限沿用高炉的批量升级（初始 5 份、最高 25 份）。投料时扣除材料。
4. 每完成一份配方即把成品存到架上，随后继续冶炼。铁、铜、银、金合计容量 60 块。
5. 成品架满时暂停进度，已排队的原料保留。燃料沿用已有规则：有燃料便持续燃烧，满架和空闲也消耗燃料。
6. 对高炉或已关联的铸造台按 E，领取背包能容纳的成品；其他成品保留。腾出空间并有燃料时自动续炼。之后由玩家存入现有储物箱。

成品架四条金属分类槽各显示最多 3 个代表锭，界面和存档记录实际数量，不生成 60 个独立物理 Actor。没有铸造台的高炉沿用原有单项冶炼/整批领取方式。
