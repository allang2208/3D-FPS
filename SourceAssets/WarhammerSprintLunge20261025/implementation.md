# 双手锤冲刺攻击释放前移

适用于所有通过 ProductionToolComponent 执行冲刺攻击的双手锤，包括原版钢锤、符文战锤及其改造组合。

- 地面释放时，在现有抬锤阶段内完成一次平滑前踏。基础时长为 0.25 秒，随现有迅捷动作倍率缩放；距离取角色的 DashAttackStats().DistanceCM，与双手剑冲刺攻击共用数值来源。
- 锁定释放时的水平方向，通过现有 ApplyMeleeLungeStep 执行胶囊碰撞和地面支撑处理。
- 空中或已排队的滑铲跳跃释放时，沿用 BeginMeleeDashMomentum 承接真实水平速度；成功承接时不叠加固定前踏。
- 镜头锚点与抬锤落点随角色真实位移更新；命中后固定砸地落点。
- 联机通过 CMC 累计位移通道传输专属 HammerDash / HammerAirMomentum 请求，并绑定具体攻击编号。服务端在冲刺攻击被接受后提供阶段距离上限；移动包先到时等待可靠攻击 RPC，旧攻击、取消、过期请求不能借用下一次攻击。空中沿用服务器已有速度，不叠加固定前踏。

伤害、体力消耗、命中时点和锤头改造属性沿用现有数值。没有新增或重新导入资产。

本目录根级构建回执属于最初的前移实现；后续修复和验证以 CompletionReview/ 为准，不能用旧回执证明新修改已生效。
