## 基础逻辑

- 射后动作在源时间 0.62 秒闭锁前被切枪或优先近战打断，给原枪实例写入既有 `reload_pending_cycle`。已闭锁则无需重复泵动。
- 切枪事务可能已经选中新枪，所以保存旧枪时明确使用实例 ID，不再同步旧枪弹量到新枪。
- 回到可操作状态后，既有恢复入口播放独立 `cycle`；闭锁接触清除标志，不额外扣弹或增加弹药。再次打断仍保留标志。
- 客户端用可靠消息请求中断，服务端核对已接受的射击序号、原枪、角色和时刻；旧射击回执不能提前覆盖更新的本地中断预测。服务端不会为处理旧枪事件重新选择旧装备栏。
- 尚未执行的本机退壳计时器随中断暂停，恢复泵动到退壳点时补发一次；已抛出的壳不重复生成。飞壳属于本次角色生命周期内的临时特效，机械闭锁标志才随物品存档。
