# 食指穿模修正 V4

用户反馈 V3 收紧后食指穿模，要求重新排查并调整。本轮只修改 `index_01_l`、`index_02_l`、`index_03_l` 的旋转，保留 V3 其余三指、V2 后侧拇指、掌根、腕臂及枪械机械轨道。

## 原因与修正

V3 用稀疏顶点和指腹平均距离辅助收紧，允许少量局部压入，也没有将食指的完整表面作为不可穿透约束。重新读取原生手套变形后，在食指内侧复现了穿入弹匣外壳的问题；普通与扩容的外壳均参与本次排查。

V4 展开食指过度向内扣的中节、适度放松末节，并小幅配合根节方向，让指腹沿弹匣前缘包覆。限制指节高度，保持食指处于原有四指排列，避免为避开外壳而抬成独立钩形。全食指受影响顶点、三角形边中点和面心参与约束，共 5294 个表面采样点。使用实际弹匣截面的保守外包络，禁止用中空部分或表面凹槽容纳手指。源手型目标预留 0.45 mm 余量；这不是 UE 实机精度或整段动作无穿模的保证。

骨长、局部位移、缩放、rest、蒙皮权重均不变。只重制原取匣、持匣、松手阶段的食指旋转，不改变补弹时钟或其他手指姿态。原来的中间姿态在进入和松开时也存在向壳内扫掠：源时钟 120 Hz 第 20–32 帧先准备张开的食指，38–46 帧贴合闭指，237–245 帧沿外侧松开，244–254 帧恢复各动作原有食指轨道。

## 本轮资料

- `sources.json`：从现有 UE 编辑器读取的 30 条运行动画与导入来源。
- `author_index.py`、`selected_grasp.json`：食指姿态制作、约束和结果；`contact_diagnosis.json` 为局部源手型诊断。
- `Diagnosis/`：本轮明确要求排查所使用的源手套与弹匣局部图，属于源模型渲染，不是游戏画面。
- `build_index_animations.py`：仅修改三节食指轨道，保留 Blend 和 FBX；`authoring.json` 逐条记录目标资产。
- `source_pose_samples.json`、`source_contact_diagnosis.json`：原取匣、持匣、松手阶段的相关源帧诊断；不替代完整游戏回归。
- `transitions.json`、`author_transitions.py`：独立张指姿态、贴合闭指和外侧松开路径；`transition_input_poses.json` 保留本轮调整前的过渡诊断输入。
- `import_index_animations.py`：沿用现有互斥桥，按短批次导入原运行路径；`Before/` 保存导入前的 V3 包。

本轮排查仅针对食指与弹匣接触，不启动 PIE，也不运行游戏操作回归；实机观感由用户测试。

源动画局部排查：每条动作采样 83 个姿态，包含 28–50 帧与 236–254 帧的半帧采样，以及第 148 帧持匣姿态。30 条动作的食指表面采样点均在对应弹匣保守外包络之外；最小余量约 0.449 mm。A762 同一动作分别对普通和扩容外壳计算。仅针对本轮已列出的接触区域与采样时刻，不作为整套游戏验收。

接入完成：6 个桥批次已导入并保存全部 30 条动画，见 `import_receipt.json`；V3 包保存在本修订 `Before/`。普通／扩容、普通／空仓、原厂和各握把配置沿用原引用路径，无 C++ 改动。

导入后局部读回：`read_compressed_index.py` 对 30 条资产的 12 个相关时刻读取三节食指 SOURCE／COMPRESSED 旋转，最大差约 0.000063°，见 `compressed_index_diagnosis.json`。该读回针对食指压缩轨道，没有启动 PIE 或做实机游戏验收。
