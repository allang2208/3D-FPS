# 弹匣前后对握：拇指 V2

用户指出上一版拇指位置仍不正确，要求“四指在前方抓握，大拇指在后方抓握”。上一版拇指横扣向食指的方式不再作为本轮目标。

本轮保留上一版的手掌、四指、手臂和持匣轨迹，只重新制作 `thumb_01_l`、`thumb_02_l`、`thumb_03_l` 的旋转。四指继续绕弹匣前缘包握；拇指从掌根张向后缘，指腹从后方压住弹匣，与四指相对施力。按 AKM、A762 各自弹匣的后缘位置独立适配，不以靠近任意表面的最短距离决定拇指朝向。

拇指进入和退出也独立处理：120 Hz 源时钟第 14–32 帧先张向后方，30–48 帧收拢；持匣期间维持后侧对握；237–250 帧向后侧松开，随后按各原动作回握或进入空仓拉栓。松手姿态保留后侧方向，避免重新横扫四指前方。

骨长、rest、手指局部位置、缩放、蒙皮权重以及右手、机械件、弹匣、四指和整臂轨道保持上一版。普通／扩容、普通／空仓和五种前握把配置沿用原 30 条运行资产路径；弹鼓不在本轮范围。

- `selected_grasp.json`：本轮后侧对握及独立松指姿态。
- `author_thumb.py`：固定掌面与四指，只适配三节拇指。
- `build_thumb_animations.py`：只改三条拇指旋转轨道，保留每条源动作的其他轨道。
- `AKM/`、`A762/`：逐条可编辑 Blend 和动画 FBX；`authoring.json` 记录制作来源与目标资产。
- `import_thumb_animations.py`：复用现有批次互斥桥的导入流程；`Before/` 独立保留上一版 UE 包，`import_receipt.json` 仅记录实际完成的保存。
- `Diagnosis/`：源手型局部图，不代表 UE 实机截图。隔离显示的腕部截口不是完整游戏手臂的几何缺口。
