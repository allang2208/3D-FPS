# 弹匣前方四指贴合精调 V3

用户已认可 V2 的前后对握方向，本轮要求收紧前方四指与弹匣之间的间隙。以 `ThumbOppositionV2` 的可编辑动作作为直接输入，固定手掌、手腕及后侧三节拇指，只调整食指、中指、无名指、小指的 12 节旋转轨道。

按 AKM、A762 各自普通与扩容弹匣的实际外壳制作。主要让食指、中指和无名指的近节带动中节靠近外壳，再配合中节、末节的角度保持指腹贴合；小指只做轻微调整。制作使用原生手套网格与蒙皮计算接触，没有移动指关节、拉长骨骼、缩放手指或重刷权重。

新增收紧随原来的错峰闭指渐入，持匣阶段保持，在 120 Hz 源时钟第 237–250 帧随松指渐出，到第 250 帧恢复 V2 的原有四指姿态。V2 的拇指后侧张合、手臂轨迹、右手、弹匣机械轨道、换弹时长及拉栓部分不增加改动。

- `author_finger_contact.py`、`selected_grasp.json`：四指关节制作参数与实际手套表面的贴合目标；其中距离是制作求解数据，不是游戏验收结果。
- `read_extended_geometry.py`、`extra_magazines.json`：将 AKM 扩容外壳转换到原有弹匣骨骼坐标，连同已有 A762 扩容几何参与手型制作。
- `build_finger_animations.py`、`authoring.json`：30 条动作的源文件、导出 FBX 与目标资产记录。AKM 普通／扩容各 10 条；A762 普通与扩容共用 10 条。每组覆盖普通／空仓换弹以及原厂和四种握把配置。
- `import_finger_animations.py`：使用现有桥互斥批次导入相同运行路径；`Before/` 保留导入前的 V2 包，`import_receipt.json` 仅记录实际完成的资产保存。

本轮不新增预览渲染，不启动 PIE，不做游戏测试或回归；实际换弹效果由用户测试。

接入完成：6 个桥批次已导入并保存全部 30 条动画，见 `import_receipt.json` 与各批次输出。沿用原运行路径，无 C++ 修改或编译；上一版 V2 包保存在本修订 `Before/`。
