# AKM / A762 换弹弹匣包握调整（2026-09-22）

后续用户否定了本页首版的拇指横扣方向，并认可 [ThumbOppositionV2](ThumbOppositionV2/README.md) 的“四指抓前方、拇指从后方对握”方向。[FingerContactV3](FingerContactV3/README.md) 收紧四指后，用户反馈食指穿模。最新修订为 [IndexClearanceV4](IndexClearanceV4/README.md)：单独修正食指持匣、收拢和松开的接触，保留其余三指、拇指及腕臂。V4 已导入原 30 条运行路径，并完成相关源帧与食指压缩轨道的局部排查，实机效果待用户测试。

A762 空仓换弹的后续托枪阶段已在 [A762EmptySupport20260922](../A762EmptySupport20260922/README.md) 微调：以 V4 为输入，保留前段弹匣抓握，修正左手支撑枪体、右手拉栓时的接触。五条 A762 空仓动作的最新源位于该目录；其他动作仍使用 V4。

用户要求排查普通与扩容弹匣换弹中的左手，并明确要求借鉴 SKILL 已接受的握把抓握方法。本轮使用 VRE GrabAnimation 经 Manny 解剖坐标迁移后的成组手型，沿用项目已有来源与许可；未引入新手模。

## 排查发现

- 运行分支共 30 条动作：AKM 原厂、斜握把、垂直握把、棱镜阻手器、45°握把，各含普通/空仓换弹和普通/扩容弹匣；A762 五种握持配置的普通/空仓换弹，普通与扩容弹匣原本共用这 10 条动作。弹鼓独立，不在本轮范围。
- AKM 扩容动作的旧作者脚本额外将手掌外移 2 mm、四指中间关节舒展 4°；它保留了旧张散手型，没有形成新的成组包握。
- 原空仓动作的手腕在弹匣坐标中明显漂移：120 Hz 源帧 48 约为 `(0.034, 0.051, -0.015)` m，帧 180 约为 `(-0.010, 0.055, -0.119)` m。仅增加手指闭合不能解决手掌与弹匣脱离。
- 原生 Manny 四指中节、末节的主要蒙皮区域没有发现跨指牵动。相邻掌骨和指根的混合影响不能直接当作错误权重全部清除。保留原网格、材质、rest、骨长、手指局部平移、缩放与蒙皮权重；本轮修改动作中的左臂和手指旋转。

## 修改

- 四指采用已接受 VRE 手型的成组弯曲，保留各指相对关系；近节、中节和末节使用受限的分组开合幅度，拇指按掌面语义轴对握。
- AKM 和 A762 独立适配整手方向与握持截面。A762 用自己的实际扩容弹匣接触面约束，在本轮源姿态排查中同时查看原厂与扩容外壳，避免沿用 AKM 的握点。
- 持匣时固定 `hand = magazine * grasp`，从取匣到插入、压实保持同一握持关系；肩肘配合，前臂与辅助骨一起跟随，不拉长指骨或缩放手臂。
- 120 Hz 源时钟：18 帧开始进入握持，约 49–237 帧保持闭合；237–250 帧松指，240 帧起沿外侧退让；普通换弹到 284 帧恢复源动作，空仓到 272 帧恢复源动作并接原拉栓尾段。各前握把继续使用自身原始起势和回握。
- 仅改左侧目标旋转轨道；右手、枪根、机械件、弹匣轨迹、动作总长度、补弹业务和音效时钟保留。普通 400/120 秒、空仓 515/120 秒。

- `sources.json`：经项目桥读取的实际 UE 资产、导入来源、骨架、时长和压缩设置。

- `prepare_grasp.py` / `fit_grasp.py`：原生权重排查及 VRE 成组手型适配。拟合代价不是视觉验收分数。
