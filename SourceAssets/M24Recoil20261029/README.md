# M24 强后坐与枪口上跳

用户要求提高 M24 的枪口上跳和后坐力。本批只调整该枪的基础后坐数据与开火表现，不编辑骨骼、动作资源、静止握姿或瞄准标定。

- 基础后坐力指数 145 → 260；现有射击方向公式、面板和配件倍率共用该值。狙击枪消音器仍为 ×0.7，装配后指数为 182。
- 基础抖动指数 115 → 150；有效反馈与恢复时间仍由现有稳定性公式计算，保留消音器稳定性加成。
- 新增 `M24Recoil.h` 独立表现参数，击发、视模更新和弹簧积分读取同一个配置。
- 定向增强枪口上跳与向后冲量，减少随机侧滚；镜头俯仰冲量另乘 1.65，横向不追加此倍率。
- 额外动作补偿在腰射峰值为 4° 上跳、1.6 cm 后移，ADS 为 0.7°、1.8 cm；实际位姿还包含弹簧、原动画、配件与姿态系数。这些是参数，不是实测总位移。
- 补偿层按实际击发时钟开始，0.38 秒内归零，不拉长到后续枪栓操作。M24 的额外补偿同时服从后坐力、消音器及既有姿态增益。
- 腰射上跳使用相机空间旋转，保留零反馈时的原朝向；程序后坐位移上限 5.5 cm，ADS 沿用现有上限与高倍收敛。

正式数值写入 `Content/ColdSteelData/gunsmith.json` 并同步原 `register_data.py`。编译入口 `build.ps1`。未启动编辑器或游戏，未运行测试、截图或验收，交由用户试玩。
