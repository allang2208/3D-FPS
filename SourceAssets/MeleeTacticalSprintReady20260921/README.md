## 条件与过渡

- `RuneSwordSprint.cpp` 使用现有 `DashReadyFraction()` 满格作为进入条件。准备计时继续复用技能等级、有效奔跑、装备与动作占用等原条件，不重新引入每帧完整武器公式求值。
- 准备条未满时播放原普通移动握姿；满格后播放 `SprintEnter`，长度从0.20秒改为0.50秒，120Hz共61个采样。保持V3先向右后收再抬剑的左臂避让路径。
- 半途停跑时，将当前进入进度映射到 `SprintExit` 对应位置；退出期间重新满足条件时反向映射回进入进度。正常退出仍为0.20秒。既有持握约束快照继续处理当前走动步相与片段交接。
- 0.5秒属于姿态表现。准备满格后，即使举剑尚未完成，也可点击发动原瞬发冲刺攻击；不增加技能等待、体力消耗或伤害判定延迟。

## 剑身与镜头节奏

参考当前运行代码 `M4TacticalSprintComponent.cpp`、`WeaponActionCameraComponent.cpp` 和 `FPSGAMECharacterLocomotion.cpp`，以及既有枪械作者源 `SourceAssets/RifleTacticalSprint20260915/`。

- 剑身循环由角色本帧缓存的 `M4SprintPhase` 采样。它来自脚步距离计时，与枪械及镜头使用同一左右步周期；不再按剑自身Elapsed匀速循环。
- 使用枪械的左右摆动、双倍频上下步动及去均值落脚脉冲。剑身带0.10弧度的轻微滞后，左右位移幅值4.5mm、上下基础幅值6mm，另有俯仰0.85°、左右转动0.75°、滚转1.2°。武器和双手成组运动，再解肩肘；不只扭动剑刃网格。
- 角色镜头复用现有 `WeaponActionCameraComponent` 冲刺层。近战使用枪械冲刺强度的65%，乘以举剑进度、有效地面移动与速度权重，逐渐进入和退出。原步行bob按已有机制交叉淡出，避免叠加两套完整冲刺抖动。
- 保留V3的持剑最终位置、左臂避让、两种固定握距和手指。SprintLoop仍为77采样的循环；SprintOverhead源长2.6秒，运行从1.22秒直接进入，1.31秒接回原下劈。
