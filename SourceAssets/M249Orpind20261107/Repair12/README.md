# M249 金属表面与通用瞄具（2026-11-08）

## 制作内容

- 枪身及原厂分件采用 WS1.1 / Clean 深色缎面基线，从现有 `M_WeaponSurface` 复制私有分区母图，保留其单层动态淋湿；不修改共享母图或其他枪械。
- 原始 UV0、结构法线、法线绿通道约定、透明裁切与图集标识保留。ORM 的 B 区分金属与非金属，R 作为唯一源 AO；聚合物粗糙度独立。UV、拓扑、蒙皮、手模和动作不在本轮写入范围。
- 枪身金属基色（线性）`.034/.035/.037`，普通钢件粗糙度 `.42`，枪管、枪口和机械件 `.40`，原厂镜壳 `.44`；亚毫米细纹采用 WS1.1 小幅粗糙变化，压低旧图的大块斑驳。
- 新增七款可单选通用瞄具：全息、EOTH、全景红点、二倍棱镜、LPVO、KV、热成像。保留原厂后置倍镜作为默认选项，选装时隐藏其壳体、镜片及分划；其他五类改造栏仍仅提供原厂件。
- 通用瞄具使用现有模型的 M249 私有副本，保留镜片、分划、消光内壁、倍率环/选择器及原生瞄准挂点。高倍镜接入现有镜内成像。
- 瞄具及适用底座挂到 `PKM_Cover`，随开盖动作运动。五款直接对齐现有导轨；EOTH、KV 使用低矮前伸导轨座，底脚和镜身保持原尺寸。
- 持枪、改造预览、库存图标及掉落复用同一装配入口；资源通过已有异步准备路径加载。

## 文件与接入

- `read_assets.py` / `current_assets.json`：当前实际资源与输入。
- `author_optics.py` / `optic_recipe.json`：按盖体原生坐标及真实导轨、底脚生成挂接参数。
- `author_rail.py` / `M249_CommonRail.blend`：导轨座可编辑源。
- `install.py` / `install_receipt.json`：材质、私有瞄具及网格槽的导入保存。
- `register_catalog.py` / `catalog_receipt.json`：只更新 M249 瞄具条目，复用通用图标和属性。
- `material_bindings.json`：供原始 M249 导入器沿用的新材质绑定；脚架导入器同步继承。
- `build.ps1` / `build_receipt.json`：后台 Editor/Game 必要构建。
- `before.zip`：本轮写入前资产和源码备份；不包含其他枪械的修改。

材质编译与资源保存不代表视觉或玩法验收。本轮不主动启动 UE 窗口，不运行游戏、PIE、截图或回归；实际效果由用户确认。
