## 修正

- 原厂、垂直、斜握、侧倾、棱形五类握姿共用同一套经过修正的持握参考；换弹中的持枪阶段和结束回握按枪根变换衔接，解决手掌位置相近但肘部、前臂关系不同造成的再次扭腕。
- 用锁骨、上臂、前臂整条链分配调整，保持骨长与握持朝向。普通及空仓弹箱换弹只在离开接触后的自由移手段缓和翻腕，保留开盖、移开旧弹链的接触。
- 垂直、战术垂直和棱形握把沿现有导轨前移 3 cm，手部握点同步移动，为前臂避让弹箱留出空间。
- 平滑冲刺入口和回握过渡，保留快速近战有效挥击段。脚架配置的持握入口、出口同步衔接。
- 原始 13 段动画、手臂骨骼模型、右手换箱/送弹/合盖动作、机械轨道与动作时长保持原样；仅合并本次负责的左臂修正轨道。
