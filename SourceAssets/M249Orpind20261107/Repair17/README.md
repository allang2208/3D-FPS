## 作者文件与生产顺序

1. `read_inputs.py`：读取当前原生动作、握把配置和已接受的弹匣抓握。
2. `author_models.py`：完整格纹周期延长、侧插接口适配、Blender/FBX 导出。
3. `author_motion.py`：生成两条原生序列与五组稀疏回握差量。
4. `install.py`：实际导入、必要网格/动画/材质构建、追加握把动作并保存。原有配置备份在 `BeforeProfiles.zip`。
5. `register_catalog.py`：只替换 `gunsmith.json` 中 M249 的条目，保留其他武器和并行修改。
6. `render_icons.py` / `install_icons.py`：图标制作与实际导入落盘。
7. `build_editor.ps1` / `build_game.ps1`：复用 UE 批次互斥，后台构建，保持编辑器关闭。

执行步骤不包含主动测试、审计或验收。构建回执不代表游戏内效果已通过。

左侧供弹参考：美军 FM 3-22.68 对 M249 备用 M16 弹匣口的说明：https://www.moore.army.mil/infantry/DoctrineSupplement/ATP3-21.8/PDFs/fm3_22x68.pdf 。本次为游戏模型、动作和数值改造。
