# M249 侧弹匣压实后短距离回握

2026-11-09。针对 30/45 发侧弹匣插入后左手上抬、外绕、抬肘幅度过大的反馈。

从当前已压缩动画和当前五类握把 profile 取样制作，仅重写两条侧弹匣换弹的左臂、左手指、左手 IK 轨道以及五类 profile 中对应的两行。输入文件哈希见 inputs.json；发布前原件保存在 Before.zip；实际保存结果以 install_receipt.json 为准。

- 压实后保留源时间 2.76 s 前的原接触动作。松指后手掌向弹匣外侧短距离退开，沿机匣外侧向下回握，取消上抬绕行。
- 普通换弹源时间 3.50 s 完成回握；空仓换弹 3.14 s 完成回握，在右手 3.18 s 开始拉栓前恢复前方支撑。
- 左手落点使用各自当前 idle 的真实枪根相对位置。回握后随枪根同步，手腕使用最短旋转弧，手指在接近握把时合拢。
- 肩、肘、前臂、twist 辅助骨共同重算。回握起点和终点渐接原接触与当前 idle，避免末端二次归位。
- 30 发普通/空仓 3.6/4.8 s，45 发 4.1/5.3 s，沿用 Rhythm22。枪根、弹匣机械轨道、右手拉栓、镜头反馈、音效、弹药提交时钟保持原有实现。

authoring.json 为制作过程中记录的轨迹参数，不是实机验收报告。本轮不启动 PIE、不渲染，不追加实机测试，由用户自行测试。
