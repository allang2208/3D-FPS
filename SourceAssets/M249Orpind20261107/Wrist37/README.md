## 本轮原因与制作

- 旧检查主要看腕部摆角，遗漏了前臂轴向旋转。棱形 W36 持握旋前约 100.84°，虽然其腕摆只有 3.04°，仍会压缩前臂轮廓。`held.py` 保持手掌接触矩阵，改肩肘朝向、使用原生肘弯平面与 V9 扭转站位。新候选旋前约 35.3°，并保留腕部适当弯曲。
- 右手必须在圆柱弹壳上夹持，而不是跟着弹节骨的全部轴向滚转。第一次固定完整弹节矩阵的试验把手背转进机匣，实际近景已拒绝。`cartridge_frame()` 保持弹壳长轴与接触点，朝向参考机匣上方，避免铺链时手掌滚入枪内。
- `smooth_release.py` 平滑松链后的肘部弯曲平面，手掌接触矩阵保持；关节局部位移、缩放不改变。
- 作者网格 154113 顶点、UE 运行网格 170357 顶点，不能混用顶点编号。运行时接触须按该次导出的 dominant bone / indices / materials 确定真实指尖与弹节；旧 tipids 仅属于作者网格，不能拿来检查 UE 导出的蒙皮。
