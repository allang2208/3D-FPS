# M249 30/45 发侧弹匣左手换弹修正

2026-11-08。两条换弹动画与五套握把配置已保存。通过现有编辑器互斥桥导入，未启动新编辑器、未运行游戏，没有 C++ 修改。

## 发现与修正

- 原动作拔匣阶段存在肘部方向翻转：120 Hz 源采样中，肘部单帧位移最大 20.51 cm，手腕相对前臂偏折最大 107.56°。改为连续肘部方向、原生肘关节铰链求解和分配前臂旋转，更新关联扭转辅助骨。
- 依据实际原生手部蒙皮及两款弹匣重新拟合掌心与指节。拔出、对位、插入和压实共享同一弹匣相对抓握变换；手指先松开末端指节，再离开弹匣。
- 30/45 发使用相同上部接口与抓握位置。手部进出路线按 45 发长弹匣避让，并用按弧长分配速度的连续曲线消除中间停顿与突变。
- 原始动作起止本身已对齐待机；问题主要发生在中途求解。新动作保持起止对齐，并为原厂、vertical、canted、prism、angled 五类握把分别匹配回握。
- 同步将 canted 姿态的左食指掌骨沿枪体向下调整 3 mm，去除原有待机/回握目标与机匣的重叠。其现有动作配置同步采用同一修正。
