# M249 原厂图标、快速近战与架枪接入

本批范围是 M249 当前六个原厂改造栏位、快速近战右臂，以及复用现有机枪架枪系统。保持全息移除、后置倍镜、六栏改造、向枪口折叠脚架的已定合同。

## 图标

- `render_icons.py` 从当前 `M249_Editable.blend` 的真实部件生成 1024 方形灰阶素材，保留安装方向及纹理。
- `generated_icons.json` 记录六次独立 imagegen 的金属框成图。采用认可的方框、四角铆钉、圆环与深灰底板，不加禁止标识。
- 已替换 `FramedFirearms/ue_m249_<slot>_false.png` 和六个对应分类副本，实际导入 12 份 UI Texture2D。分类仍沿用现有共享分类图优先顺序；原厂选项使用本枪专属图。未改变共享图与加载缓存逻辑。

## 快速近战

- 基于当前序列的数据模型按时间读取完整原生骨链；`DATA_MODEL_*` 是本次修改前的权威输入。早期 `RAW_*` / `COMPRESSED_*` 仅为初步诊断，制作入口不依赖 AnimPose 求值。
- 保留原 0.9 秒时长、1/6 秒接触时钟、枪路及握点。将原入场/收势混合烘入动作，并仅为 M249 快速近战取消第二次运行混合。
- `author_melee.py` 重解右肩、肘、前臂及辅助骨；腕端与原厂握把保持当前 idle 关系，五指沿用当前握姿。twist_01 / twist_02 分别承担完整/一半轴向扭转。
- 肩部保留在相机后方，限制腕轴折弯和肘轴旋转；支撑交接保持原上、下臂长度。
- 作者解算为 240 Hz；针对已定位的高速帧间脱把，将最终姿态按 960 Hz 重编码，保存后用 1440 Hz 的独立中间时刻检查。读回结果为 `melee_check.json`，不等于用户视觉验收。
- `fit_motion.py` 的 quick_melee 分支和 `import_motion.py` 已接上本次数据与帧率，后续重导不会覆盖回供体腕臂。
- 已进行定向蒙皮画面检查和 UE 原生 V9 修形采样；没有启动 PIE 或执行实战输入/伤害测试。

## 原厂脚架

- `author_bipod.py` 从当前原始脚架分件保留 UV 和材质，分别导出基座、左腿、右腿。支点不前移；收纳时仍朝枪口折叠。
- `M249Bipod.h` 的实际根空间支点、脚端和折叠方向由同一源自动生成。
- 复用 `UPKMBipodComponent` 与 `UWeaponBipodDeploymentComponent`：支撑面搜索、自动架枪、稳定性加成、视角约束、解除条件及服务端支撑判定均走现有系统。展开/收回随原机枪 0.32/0.16 秒过渡；架枪时固定已展开姿态。
- 脚架是固定原厂件，不新增改造栏。旧存档的脚架拆除值不影响本枪；启用分件时隐藏枪体内的重复脚架。
- 没有额外进行架枪实战或联机测试，由用户体验。

`before.zip` 保存主要修改前文件；`import_receipt.json` 记录实际保存资产。Editor/Game 构建日志为 `Saved/Logs/M249Repair08Build.log.console`。
