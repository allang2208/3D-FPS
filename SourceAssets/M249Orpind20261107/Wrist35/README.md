## 实际发现与修复

对六种配置（原厂、垂直、战术垂直、斜握、侧倾、棱形）进行了实际玩家视口连续采集，并检查待机、ADS、普通/空仓换弹及回握的分阶段关键帧和问题段连续帧。旧版棱形在两类换弹托枪时，屏幕左下角露出明显的上臂尖片。Wrist34 的旧相机投影检查没有覆盖换弹阶段，因此其数值 PASS 没有发现这个问题。

本次仅改正式 `DA_M249_prism` 中普通及空仓换弹的左锁骨、上臂、前臂、辅助旋转骨和腕部补偿旋转。保持掌心接触，调整肩肘弯曲方向，并补入取箱期间的短肘部避让。没有修改源手网格、权重、骨长、局部位置、缩放、手指、其他基础动作或机械时钟。仅该握姿资产哈希改变，其余 22 项受跟踪资产（包括认可的源手模）保持一致。

修后玩家视口中，普通/空仓托枪段的左下角尖片均已消失；所查看的腕部双侧近景、回握连续帧及正式远端身体动作未再出现旧图那种明显的腕部拧折、收窄、弹箱穿过前臂或回握突跳。换弹过程中保留正常屈腕，不把所有动作锁成直腕。此结论是本次实际画面复核结果，不等同于每一种环境和每个三角形接触的穷尽证明。
