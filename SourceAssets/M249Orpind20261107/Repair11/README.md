# M249 脚架抓握位置微调（2026-11-08）

按用户反馈将左手向支腿收近。正式制作入口为 `author.py`；该脚本承接 Repair10 的部署、收回动作。

- 接触锚点从中指末节内侧移到中节内侧，使脚架进入更深的抓握位置。
- 微调四指和拇指的收拢，按实际支腿表面重新拟合手位；肩、肘、腕随新目标重新求解，保留骨长和扭转分配。
- 接近、抓握、松手、回握使用同一组目标；保留 0.90 秒部署/收回时长，以及原有支腿转动、松指与回握时序。
- 正式接入只写 `A_M249_Bipod` 和 `DA_M249_Bipod`。`DA_M249_SupportGrip` 和原有普通动作资产不在本轮写入范围。

两项正式资产已通过无界面 commandlet 导入并保存。导入入口为 `run.ps1`，保存回执及资产散列见 `import_receipt.json`。修改前两项资产及作者输入已备份至 `before.zip`。

本轮未新增游戏测试、原生采样、截图或验收渲染；实际效果由用户确认。作者接触拟合用于制作，不作为实机验收结论。

`author_proximal_study.py`、`fit_contact.py`、`contact_fit.json` 与 `contact_seed.pkl` 是指根接触的制作研究文件，不参与正式导入；正式动画只读取 `author.py` 导出的 `bipod.json.gz`。
