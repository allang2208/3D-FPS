# M249 通用枪口、枪托、后握把与前握把（2026-11-08）

## 制作范围

- 枪口五款：消音器、战术消音器、制退器、钛金制退器、多口径消音器。
- 枪托五款：镂空枪托、核心枪托、高性能后托、战术伸缩枪托、可调式战术后托。
- 后握把三款：幻影、稳固防滑、均衡。
- 前握把五款：垂直、战术垂直、45° 侧倾、棱镜阻手器、斜握把。

实际名称、属性、描述及图标沿用现有目录，M249 仍保留六个栏位和各栏原厂选项，弹箱仍仅为原厂。保留 Repair12 的通用瞄具。

## 制作与接入

当前共享资源通过 `read_inputs.py` 导出；`author_parts.py` 以 M249 当前原生枪根、枪托前端接面、下导轨、枪口入口及右手接触制作专用版本。保持部件物理尺寸、UV、结构法线，移除旧宿主的独立安装块并制作 M249 接口。

`author_grips.py` 将已采用的 PKM / VRE 握把手型匹配至 M249，以当前 M249 动作为基础，输出四组稀疏姿态差量。只在握把接触阶段改左手，保持机械操作阶段；包含换弹、装备、近战、冲刺出入和脚架部署的回握。两款垂直握把共用垂直手型，目录 ID、模型与属性独立。后握把按当前右手接触帧适配模型。

配件金属区域沿用本枪 Repair12 深色缎面基线，保留源结构法线、聚合物、橡胶、标识与凹腔分区；材质使用静态用途和单层动态淋湿。源枪型及共享材质不改写。新消音音色由用户 M249 单发加工，保留时长、音高和声道；属于设计音效，不是新的真实消音录音。

统一装配入口覆盖持枪、改造展示、背包图标及掉落，通用图标直接复用。选装后隐藏对应原厂分件，拆下时恢复；枪口出口和轴向用保存的 `Muzzle` / `AimGuide` 挂点，消音播放使用 M249 独立音源。新增资源接入已有异步准备流程。
