# M249 配件材质统一与上部后托接口

## 已制作并接入

- 18 款通用配件、7 款通用瞄具、倍率环、热成像选择器和导轨座，共 28 个网格完成材质绑定。47 个 M249 私有材质变体对齐当前枪身 WS1.1 / Clean 响应：金属线性底色 `.034/.035/.037`，普通钢件粗糙度 `.42`，枪口 `.40`，镜壳 `.44`，聚合物 `.55`，橡胶 `.70`。
- 复用金属母材质的物理尺度细纹及 `WS_Wet` / `WS_WetNormal`，结构法线、原 UV、AO、刻字和材质身份沿用原图。橡胶、聚合物、光学窗口、分划、内腔和有意保留的彩色饰件分别处理。旧图的宽幅颜色与粗糙变化收敛到同一枪身表面；补齐没有实际连接淋湿层的后托材料。
- 共享源资产与公共母材质未写入；原厂配件已经使用本枪 WS1.1 材质，本轮沿用这一基准。
- 五款改造后托使用原厂上部连接管前端的 24 点环形截面作为入口。上一版使用下方锁扣的最前端；本次修正接口高度与纵向位置，新增 2.2 cm 短连接柄，前端保留原厂斜接面，后端收成圆角颈部并嵌入后托。后托主体保持原尺寸、结构法线和 UV。
- 持枪、改造展示、背包与掉落仍使用原有网格路径，无需修改 C++ 或装备存档。

## 制作记录

- `current_assets.json`：本轮实际资源与材质输入。
- `stock_plan.json`：原厂上部接口、延长尺寸和坐标变换。
- `plan_stock.py` / `author_stocks.py` / `Exports/`：五款后托的配方、可编辑 Blender 源与 FBX。
- `install.py` / `finalize_surfaces.py`：材质、静态网格构建与资产保存入口；经 `run.ps1` 在后台执行。
- `install_receipt.json`：28 个网格、47 个材质变体、5 款后托，共 122 个保存资产的路径与散列；表面修订为 2。
- `before.zip` / `before_hashes.json`：精确覆盖本轮 28 个目标网格的写入前备份。导入中断时仅从该备份恢复了本轮尚未保存的核心枪托，随后继续完成导入。

资源已导入、构建并保存，不依赖待执行脚本。本轮未开启编辑器窗口、PIE、游戏测试、截图或验收渲染；视觉与实际使用效果由用户测试。
