# M249 手动脚架部署与收回

复用当前 M24 脚架动作、原厂握姿差量和架枪状态机。M249 保留自己的脚架模型、原始铰链和向枪口折叠方向，使用原生 PKM/Manny 骨架制作一条可逆动作。

- 作者时钟 0.48 秒，运行时部署和收回各 0.72 秒。
- 0.18 秒接触近侧脚架，0.45 秒展开完成，0.66 秒回握，随后完成落稳与 ADS 过渡；收回反向采样。
- 左手绕枪身外下侧伸出，指腹按当前 V9 皮肤与脚架实际截面匹配。右手保留 M249 原厂后握把抓握。
- 肩、肘、腕与辅助骨整体求解，前臂 twist_01 / twist_02 按 100% / 50% 分配。
- 枪体及机匣盖、弹箱、弹链等武器根骨子树随持枪动作整体后收与复位。
- 复用现有架枪支撑、移动限制、服务端确认、稳定性和 ADS 入口。动作期间限制开火；架枪时换弹先完成收回，重复瞄准排队处理。
- 六个原厂改造栏保持原有设置，脚架仍为固定原厂部件。

运行资产：

- `/Game/Weapons/M249/Bipod/A_M249_Bipod`
- `/Game/Weapons/M249/Bipod/DA_M249_Bipod`

M24 与 M249 的原生根变换和绑定尺度不同，因此保留一条 M249 原生序列；部署和收回不复制两份动作。`author.py` 从 `read_inputs.py` 读取的 M24 当前基础动画和握姿差量重新制作，`import.py` 同时保存序列与运行配置。`authoring.json` 记录源依赖、接触时序和制作参数。

源文件备份：`before.zip`。资产保存结果见 `import_receipt.json`，后台构建结果见 `../../../Saved/Logs/M249Repair09Build.log.console`。
