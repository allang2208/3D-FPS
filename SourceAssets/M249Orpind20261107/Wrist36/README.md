## 正式修改

- 五份既有 GripProfile：原厂、垂直（含战术垂直）、斜角、倾斜、棱形。最终只修改每份的 idle、reload、reload_empty，共 15 个片段。

正式网格仍是 `/Game/Weapons/M249/SK_M249_V7`（资产名保留 V7，内容为已认可的 V9 派生），SHA-256：`ee0872997aff83a071f3e0764f371dbca6bd38dbe04532e65ae03ad9128aa78d`。23 个跟踪资产中仅五份姿态资产变化，见 `assets-after.json`。本轮为资产修订，无新增 C++ 修改或 DLL 编译需求。
