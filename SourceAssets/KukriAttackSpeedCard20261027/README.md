# 攻速受限时的改造详情显示修复

2026-10-27：仅修改 `Source/FPSGAME/UI/M4GunsmithSelectedDetails.cpp`。

- 配件有直接攻速倍率改造时，即使最终攻速相对该栏原厂的实际差值为零，也保留攻速属性行。
- 继续显示配件配置百分比与当前组合的真实攻速倍率；零差值显示为中性色的 `0.00×`。
- 零差值条目补充“攻速受限，当前实际变化为 0。”，同时适用于上下限，避免误称全部都是达到上限。
- 普通近战与双手钝器的详情卡共用该处理；没有攻速改造且没有实际变化的配件仍不增加攻速行。
- 不改攻速上限、双持独立结算、左手后摇规则或任何配件数值。

修改前文件保存在 `Before/`。后台构建状态另见 `delivery.json` 和 `build-editor.log`。
