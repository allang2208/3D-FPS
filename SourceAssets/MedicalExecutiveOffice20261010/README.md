# 医生办公组合

本包替换 MedicalDoctorOffice 的 9 个医生工位及 6 把访客椅。正式随机地牢、医生办公室独立场景和医院主题场景使用同一组资产。原有门、可搜索容器、会议桌和茶水区保留。

- 主桌 240 × 110 cm，打印机侧柜向右延伸 60 cm；木纹连续台面、石墨灰收边、两组抽屉、锁孔、拉手、金属支撑、遮挡板、脚垫及桌下配电组件。
- 人体工学椅包含织网靠背、腰托、头枕、软包坐垫与缝线、扶手、调节杆、气压杆、五爪支架和双脚轮。访客椅使用配套软包与金属框架。
- 复用 StationWorkshop20261003/RefineV2 的细化电脑、键盘键帽与字符、鼠标、机箱和电话几何；新增打印扫描一体机、纸盘、线缆、台灯、笔筒、书籍、病历夹、文件托盘、台历及桌牌。
- 复用 ReceptionHall20261006/Refine20261007 的木纹、金属、皮革、塑料、纸张与织物纹理。新增材质限定于本资产包。书封、表单、桌牌和屏幕内容为本包原创虚构图文。
- 六个可复用静态网格、四个新材质、两张 2048 像素印刷/屏幕贴图。桌、医生椅和访客椅使用简化凸碰撞；桌面小物件无碰撞。启用 Nanite 与完整回退几何。

`prepare_art.py` 生成原创图文，`author.py` 在后台 Blender 中制作并导出 FBX，同时保存可编辑的 `Authored/MedicalExecutiveOffice.blend`。`recipe.py` 仅修改办公工位；原房间生成源已调用此配方，重新生成不会退回旧桌椅。

`run_background.ps1 -RenderShaders` 导入、编译材质并保存资产和三张地图。沿用 UE 桥的批次互斥；保留运行中的试玩与未保存内容。生产记录在 `Receipts/assets.json` 和 `Receipts/install.json`。

本次不运行游戏、不渲染预览、不进行测试或视觉验收，交由用户试玩确认。

## 复用来源与编辑入口

几何复用入口为 `SourceAssets/StationWorkshop20261003/RefineV2/Scripts/author_refine.py` 的显示器至电话段落，保留已有键盘文字贴图。此次没有下载第三方模型，也没有替换共享家具资产。

`Authored/MedicalExecutiveOffice.blend` 内含六个最终网格；比例为米制，导入 UE 后使用厘米。`author.py` 保留台面轮廓、坐垫曲面、椅背织网、纸书尺寸和设备布局的参数，可独立重新制作。主桌/设备/桌面杂物共用地面原点，椅子拥有各自地面原点；9 个工位共享资产，两种书籍摆放交替使用。

精细桌面设备属于场景装饰，本次不新增电脑使用、打印机操作或办公桌抽屉交互。
