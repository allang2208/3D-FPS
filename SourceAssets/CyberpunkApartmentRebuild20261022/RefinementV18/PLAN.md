# V18 滨水街区收口计划

## 制作范围

现有 V17 已区分五座地标和六种立面；V16 已有行驶车辆、道路和树列。此次补齐它们之间仍较空的地面层，不重建公寓、天空、天际线或车辆系统。

1. 十一处前排楼入口：有支撑的金属雨棚、深色门厅、台基、种植座椅和连接路边人行道的铺装。读取原楼体尺寸确定位置，避开既有路面与树池。
2. 滨水休憩层：六处观景凉棚、分段栏杆、长椅和低矮绿化；用疏密变化组织岸线，而非连续发光围边。凉棚跨中留出步行空间。
3. 三处码头细化：护栏留登船口、护舷、系泊设施、门架和到站指示；两艘系泊电动渡轮具有真实船体、驾驶舱、窗框和登船跳板。此轮船只作为静态布景。
4. 补齐铺装 BC／法线／ORM，复用现有金属法线及昼夜参数。暖色用于人行空间，青色用于码头识别，灯带附着在实体灯槽上。
5. 为新增静态布景重烘城市倒影贴图，保留现有水波、广告和探照灯的动态倒影分支；新增布景分区合批、Nanite、无远景碰撞，无新增 Tick、动态光源或实时捕获。
