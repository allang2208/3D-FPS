收尾包含：坡面以脚掌为轴对齐，避免转脚踝后把落点带偏；地形高度与法线平滑；必要时小幅降低骨盆避免锁脚导致膝盖伸直拉扯；退出攻击逐渐释放脚锁。毒瓶投射物从实际旋转后的握持点生成，连续施法时恢复手持瓶可见性。
