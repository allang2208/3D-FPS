## 造型与材质方向

保留原巫婆的弯尖帽、鹰钩鼻、年老妇性面容、灰白乱发、佝偻肩颈、枯瘦手脚、破长袍、骷髅木杖和毒液瓶。主体与手持道具分开建模，法杖、瓶子分别挂接与脱手；煮锅是独立伴生单位。

参考当前 `Docs/Monsters/FatZombieStyleV1.md`、`MonsterStyleV1.md` 和 `SourceAssets/FatZombieStyleV1/style_parameters.json` 的制作规则：低饱和灰绿/灰褐干皮肤、细浅皱纹和毛孔、少量干痂、局部湿润；粗织旧布以炭灰/灰褐为主，泥污集中在下摆和缝隙。保留巫婆身份，不套全身绿色或满身粗硬结节。现有材质样板也不视为本角色已经获得用户认可。

后续材质参数起点：皮肤 Roughness 0.57–0.70，布料 0.78–0.89，局部湿组织 0.29–0.40，干痂 0.73–0.84；非金属表面 Metallic 0。这些是现有样板的制作参考，三视图本身不包含数值贴图。瓶子采用独立玻璃/液体材质。

后续沿用 BaseColor(sRGB)、DirectX Normal、ORM(R=AO/G=Roughness/B=Metallic)、TissueMasks(R=皮肤/G=湿组织/B=干痂) 分区合同，创建巫婆自己的贴图与实例，不重置共用母材质。

| 动作 | 原帧数/时间 | 原图动作意图与后续保留内容 |
|---|---|---|
| 待机 | 1 帧，循环 | 佝偻站姿，杖侧手抓杖，另一手持瓶；A 姿势仅用于模型绑定 |
| 行走 | 11 帧，10 fps，循环 1.1 s | 短步交替，身体轻微起伏，脚从袍底露出，保持持杖/持瓶的左右差异 |
| 施毒法 | 14 帧，1.5 s，单次 | 杖侧肩肘抬升，杖头上举；另一手持瓶相对稳定，随后收回 |
| 掷毒瓶 | 18 帧，1.5 s，单次 | 持瓶手由身前向目标伸出并脱手，另一手维持法杖，前倾后收势；不能换成通用双手施法 |
| 死亡 | 17 帧，1.5 s，单次 | 仰头后倾，屈膝失去支撑，向后坐倒再平躺；不是正面扑倒 |

事件按源代码 `elapsed >= frame / frameCount * duration` 计算，保留该公式，不把说明文字的“第几帧”自行减一：施法音效/发射为 5/14×1.5 = 0.535714 s；掷瓶音效为 8/18×1.5 = 0.666667 s，脱手为 9/18×1.5 = 0.75 s。两次攻击期间停止移动。死亡后原项目定格 1.0 s、淡出 0.3 s；UE 死亡物理接续在接入阶段按当前怪物工作流设计。

源二维表会按朝向镜像，无法证明角色在三维中的惯用手。后续制作约定左手持杖、右手持瓶，并保持全套动作一致；这是三维制作约定。二维像素移动和体型数值不直接当作 UE 厘米。提示词中的杖 165 cm/瓶 18 cm 仅是比例设计起点，尚未冻结游戏尺寸。
