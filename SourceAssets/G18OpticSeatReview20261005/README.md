# G18 全息镜衔接检查

本次按用户要求只检查衔接位置，未修改正式网格、材质、安装变换或玩法数据。

从当前 UE 资产直接读取枪体、全息镜三角面和参考骨骼，按 `M1911AttachmentVisual.cpp::SetM1911Optic` 的安装计算还原装配。近景为 Blender 几何检查图，橙色仅用于标明安装座，不代表游戏材质；没有执行开火或换弹测试。

## 结论

- **套筒与底座已贴合。** 在底座内部 17 × 19.6 mm 区域采样 1,435 点，全部命中接触面，未发现正间隙。嵌入约 0.18～0.31 mm，中位数 0.18 mm，与避免透缝的微嵌入设计一致。
- **底座顶部与镜体尚未完全收口。** 同区采样有 71 点垂直间隙超过 0.1 mm，最大 0.799 mm，集中于靠前的高低转折，光学局部 X 约 11.5 mm。主承托区中位数为 0.20 mm 微嵌入；局部过渡也有较深嵌入，说明顶面插值未完全跟随镜体底脚的台阶。
- 正侧面、前斜角和后斜角近景中，底座没有整体悬空。建议后续仅修底座顶面转折轮廓，保持瞄具主体、光心和现有安装位置。

## 证据与边界

- `seat_measurements.json`：采样区域、装配矩阵和逐点间隙，负值表示嵌入。
- `host_geometry.json`、`holographic_geometry.json`：当前 UE 资产只读提取数据。
- `seat_side.png`、`seat_rear.png`、`seat_front.png`、`seat_front_detail.png`：实际网格按运行代码装配关系生成的几何近景。
- `current_assets.json`：导入来源指向修正版 FBX；当前资产没有旧 SHA 元数据，因此不能以 `source_sha256_matches_repaired_fbx=false` 判断其为旧几何。本次结论使用直接提取的当前网格。
- 首次读取时存在 PIE，但没有可读取的已装备 G18 全息镜实例。后续编辑器已退出，骨骼与网格数据通过无界面只读 commandlet 取得，退出码 0；未主动打开编辑器。

检查范围是静态接触面，不等同于实机第一人称、开火、套筒往复或换弹动态验收。
