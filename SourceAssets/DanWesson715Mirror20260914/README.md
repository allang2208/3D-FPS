# 715 镜面抛光金属

用户要求把仍显粗糙/模糊的缎面枪身改为非常光滑的镜面反射金属，并改善细节表现。本轮为材质制作、导入与必要构建；不启动游戏、渲染或追加验收。

## 镜面与细节

| 部位 | 旧粗糙度中心 | 新粗糙度中心 | 线性金属底色 RGB |
| --- | --- | --- | --- |
| 枪身 Frame | 0.285 | 0.045 | 0.62 / 0.64 / 0.66 |
| 弹仓 Cylinder | 0.225 | 0.035 | 0.65 / 0.665 / 0.68 |
| 钢制小件 Steel | 0.245 | 0.060 | 0.58 / 0.60 / 0.62 |
| 配件金属与安装座 | 缎面图块 | 0.060 | 与 Steel 相同 |

- 去掉拉丝/车削微凹凸、粗糙度噪声、底色云斑和旧颜色图阴影乘色。使用金属度 1 的干净反射底色和低粗糙度；不以自发光或额外清漆层制造亮白外观。
- 用源法线的中心采样减去 3×3 高斯近邻均值，分离细刻字与大范围切线法线渐变。邻域半径为 12 个源纹素，权重为中心 4、轴向 2、对角 1，总权重 16。仅将分离出的 XY 细节按 0.45 强度重建单位法线，再从高模烘焙回现有 UV0。
- 这一过滤不作用于新高模的真实倒角。高模到低模的几何法线投射仍完整保留，刻字/凹槽附近适量提高粗糙度并降低底色，形成镜面大平面与细加工区域的反差。
- 凸边抛光量为 0.008，几何凹部粗糙度增加量最高 0.08；刻字细节粗糙度增加量最高 0.08。内腔继续使用原消光材质，握把、照门准星、聚合物及黄铜弹药保持各自身份。
- 枪身/弹仓 4K；钢制小件从 2K 提到 4K。三组各有 BaseColor/ORM/Normal，共 9 张 4K 图；另有 2 张 1K 配件物理涂层图。BaseColor/ORM 为 BC7，Normal 保留专用压缩与正确绿通道，UV0 和导入切线不变。

## 配件与雨滴

四种已接入配件的网格和干/湿材质在新目录复制，按本枪镜面钢件更新金属图块。保留安装尺寸、曲面底座、光心、分划尺寸、玻璃、发射口遮罩与灯光/激光逻辑；不重新导入几何。

本轮新增枪体 3 个、配件 7 个干/湿材质映射，并合并到现有 RainVisibility/NaturalV2 表。既有非金属与弹药映射继续使用。镜面湿润粗糙度调整为 `lerp(lerp(Base,max(.018,Base*.72),Wet),.035,Bead*.8)`，避免原缎面水膜的 0.085 下限把镜面面板变粗。水滴曲面法线及配件光学排除遮罩继续保留。

本轮没有重跑前一轮雨滴检查，也没有将前一轮的 14 材质检查作为镜面版本验收。工程已有反射配置沿用，本轮不改全场景的光照、曝光或渲染质量。
