# V5 左手拇指局部修复

用户指定排查 V4 书本朝下预览中的拇指扭曲。本轮冻结书本、掌部、其他四指、肩肘腕和右臂，仅改变左手三节拇指的局部旋转。

排查发现旧书本握姿本身已有约 44.13° 的拇指根节轴向扭转，后两节相对原生参考姿态分别约为局部 Z -37.63° 与 +43.25°，形成相反方向折弯。并非本轮转腕时单独改变了拇指；转腕后原缺陷更加可见。另外，V4 Blender 预览曾把腰射计算的 custom normals 用在瞄准 Shape Key 上，额外产生明暗假折痕。

`author_thumb.py` 只拟合三节拇指：减小根节滚转，后两节改成同向轻屈，指腹靠近书脊旁封面。手指骨长、局部平移、缩放、原生绑定、蒙皮和书本挂点不变。`thumb_pose.json` 保存最终四元数、原始／最终根节滚转、指腹位置与限定范围检查。没有任何拇指骨权重的顶点位移为 0 cm；参与拇指蒙皮的虎口表面会自然随关节变化。

- `before-palm.png`／`after-palm.png`、`before-side.png`／`after-side.png`：同机位、同材质的针对性局部对照，已按当前姿势生成法线。
- `aim.png`：保持 V4 相机、枪、书和手臂布局的完整修订预览。
- `PistolBook_ThumbV5.blend`：单帧作者模型，包含原生 V9 手部与对应关节修正表面；不是游戏画面。
- `SpellbookPistolThumbPose.h`：由作者脚本产生的三个原生局部旋转。`CachePistolSupport` 缓存索引；`ApplyPistolSupport` 在完整左臂解算后写入这三节，再使用现有入场权重。

只作用于第一人称手枪＋魔法书姿态分支。普通持书、专注动作、施法、食物和其他武器的原有手型继续由自身层处理；本次不重导入共享手模或共享动作资产。
