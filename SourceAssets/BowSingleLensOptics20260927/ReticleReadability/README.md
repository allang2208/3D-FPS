# 弓镜分划清晰度修订

用户反馈实体瞄具 ADS 中的中心十字看不清。原作者几何为半径 0.0035 cm 的六边形细线，即线宽 0.07 mm，深色 Default Lit 材质；远离镜片时容易成为亚像素线，暗处也缺少对比。

本次只调整两款镜片和原刻线的 3 个材质，沿用当前静态网格、玻璃 UV、光轴、挂点、倍率、ADS 和开镜模式。

- 使用镜片 UV0 绘制实际玻璃表面的分划，中心为 UV `(0.5,0.5)`。跟随实体镜片移动，非 HUD 十字或全屏覆盖。
- 当前十字亮芯最小 1.15 渲染像素宽，暗边扩展约 0.25 像素，使用 `fwidth` 与平滑距离边缘抗锯齿。较近距离保留归一化物理线宽下限。
- 当前作者源码的中心实心点直径约 3.6 渲染像素，四周留白。用户认为上一轮荧光绿太卡通后，基础发光 RGB 改为 `(0.035,0.36,0.055)`，压低绿色峰值并略降低饱和度；最新中心点独立发光增益为 2.4。从镜片半径 22% 到 78% 平滑减弱照明，外围降至基础亮度的 16%，保留细刻线的视觉层次。
- EyeAdaptationInverse 稳定发光亮度，减少环境照明／自动曝光对亮芯的影响；原透明玻璃与 Fresnel 镀膜保留。分划区域抑制镜面反射，避免高光盖过刻线。
- 4× 保留两条下方无距离标注参考线。2×／4× 均保留实体弓、手臂、周围视野和 HUD。
- 原亚像素几何仍保存在源网格中，由原刻线材质的零 Opacity Mask 隐藏，避免重影和深度干扰；未重导或覆盖网格。Blender 原始刻线几何是旧作者参考，最终运行分划以这里的 HLSL 与材质作者脚本为准。

`Reticle.hlsl` 是分划源；`materials.py` 是 UE 材质构造；`apply_materials.py` 已执行并保存三份现有材质，见 `apply-receipt.json` 和 `apply.bridge.txt`。修改前资产副本已随本轮旧版本归档到 `trash/weapon-bow-inspect-publication-20260927/` 下的原相对路径。上级 `import_assets.py` 的新建材质路径同步调用本版作者函数，后续从源重建不会恢复旧刻线。

本次未修改 C++，无需额外原生构建。初次保存材质时结束了已有 PIE，保留编辑器打开；没有重新启动游戏、截图或测试，效果由用户测试。3.6／1.15 像素是当前着色器设计值，最终显示还受渲染分辨率与上采样影响，并非实机测量结果。

当前完整重建入口为 `materials.py` 与 `Reticle.hlsl`，最后局部更新入口为 `TemporalStability/apply_temporal.py`。均匀荧光绿、NaturalGreen 与两次中心点过渡目录已归档到 `trash/weapon-bow-inspect-publication-20260927/` 的原相对路径；它们不是当前重建依赖。中心点最终参数已合入当前 HLSL。

用户反馈十字与中心点拖影后，两份镜片材质已增加分划区域的深度／运动向量和局部 Temporal Responsiveness；透明玻璃低于写入阈值。保留 After DOF、深度遮挡、大小／亮度和解析抗锯齿。实际材质已后台保存，见 `TemporalStability/README.md` 与本机回执，未做实机验收。
