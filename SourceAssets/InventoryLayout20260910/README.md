# 装备背包布局优化 · 2026-09-10

## 实际调整

- 对照 Godot `ui/backpack_hud.gd` 和 `docs/apple-glass-ui-standard.md`，保留右侧 45% 抽屉、15 槽 3×5 装备区、18×4 空间背包和公共冷钢字体/配色。
- 装备卡高度由 38px 改为随板宽计算的 52–72px，横纵间隙由 2px 改为 6px，空槽文字为 16px。图标按卡片空间等比适配。
- 删除背包下方八个常驻操作按钮、选中物品介绍/数量详情、通用操作说明和键盘说明。整理入口移到背包标题右侧。
- 保留快捷物品绑定区、操作结果与拖放失败反馈。详情由现有浮窗展示；Shift+右键物品菜单仍提供拆分、整理、保存、丢下及改造等操作，双击/右键和键盘原有操作继续可用。
- 使用同一份布局坐标驱动绘制、命中、拖动预览、抓取偏移和弹窗锚点；装备间隙不触发槽位。内容高度按实际布局更新，小窗口通过原有滚动容器浏览。

## 实现边界

UMG UUserWidget 承载 Slate 自绘装备/背包板，仍以 ColdSteelStatusModel 为唯一物品数据源，OnChanged 更新图标。尺寸变化只更新 SizeBox 最小高度，不新增游戏状态轮询。焦点、输入模式和关闭清理由原 HUD/板/弹窗管理；浮窗沿用原有视口限制与关闭路径。未改容量、实例、存档规则、Godot 项目或其他 HUD 页面。
