# DW715 单持退壳：掌面避让与中立腕（2026-09-15）

用户反馈 DonorPress 仍穿模，要求调整手臂和手腕方向并保持自然人体姿态。本轮重新制作空仓退壳及快速装填共七段动画，保留前轮参考动作的指节形状，改变整手朝向、接近/离开路径和腕肘支撑。

## 制作依据

前版 `DanWesson715DonorPress20260915/author_actions.py` 将掌面法线与退壳杆轴线严格对齐，在单个按压峰值帧中，以稀疏掌心顶点和指节点拟合接触。这不足以约束整个手套表面和持续运动。前臂目标沿用参考片段中的腕肘关系，也不能等同于当前接触方向下的中立腕。

当前作者源通过本目录 `reference_basis.py` 读取原 GitHub 参考手型及 LeftRecovery 机械/装填轨道；参考来源见 `Reference/README.md`。有效库函数与独立导入器已从旧版提取，当前制作不依赖废案或 trash。

## 调整

- 掌面允许有限侧倾和前后倾斜，接触点从变形后的掌面顶点选择。手指、拇指根、虎口、掌背均参与几何约束，包含顶点、边中点和三角面中心。
- 制作拟合同时使用普通空仓及快速装填的接近、按压和轴向撤手阶段；枪架、枪管、弹仓、转轴架、扳机、击锤分别按自身机械骨变换。
- 腕部以 Manny 的中立骨架关系为方向依据。肩—肘—腕用原骨长求解，前臂整体携带掌面方向，左肘在外侧下方支撑，扭转辅助骨跟随所属完整骨段。骨架轴角是制作参数，不作为医学角度或外观合格证明。
- 掌面接触间距 3 mm；对枪体实体的制作间隙目标 6 mm。退壳杆按原机械轨道移动。
- 轴向撤手距离由 30 mm 调整为 50 mm；进入和退出使用更靠外侧的曲线，在空间腾出后接入原有取弹动作。
- 时序和业务合同保留：单持逐发空仓 1–6 发为 3.3/4.4/5.5/6.6/7.7/8.8 秒；快速装填 3.85 秒。动作以 120 Hz 导出/导入。
