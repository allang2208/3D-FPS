## 图片与材质

使用内置 image_gen 生成三张独立纹样；完整提示词在 `prompts.json`。

- `Generated/resonance_rune.png`：共鸣环纹。
- `Generated/erosion_rune.png`：侵蚀裂纹。
- `Generated/conduction_rune.png`：导魔回路。

生成原图保留于上述目录，复制为 `Content/ColdSteelData/AttachmentIcons20260913/blade_2_*.png` 供改造卡片使用。运行时表面贴图和材质位于 `/Game/Weapons/MeleeRunes20260915`，可由 `import_assets.py` 重新导入、制作。未使用 API/CLI 生图路径。

`silver_runes.hlsl` 从图片中提取银白笔画，输出纯银白自发光；背景不覆盖剑面。共鸣采用呼吸亮度，侵蚀采用交错闪烁，导魔采用纵向流动亮点。三个材质变体共用 `M_SilverRuneSurface` 和独立动态材质参数。

通过 UE 每材质槽的 overlay 仅绘制剑体槽。模型、UV、骨骼、动作和原有材质资产均保留。使用当前组件空间位置和法线，运行时随 Blade_Base/Blade_Tip 更新投影轴，不依赖预蒙皮位置节点或关闭 GPU skin cache。剑体从护手以上约10cm开始，至73cm结束，纹样宽度由12cm投影画布中的透明/暗色留白决定。

## 数值约定

1. 共鸣符文：当前手持此剑时，魔法技能最终冷却乘0.75。接入当前火球和冰锥的施法快照；已有冷却不会因中途换武器重新缩短。
2. 侵蚀符文：每次近战攻击追加智力×0.10+精神×0.10魔法基础伤害，包含装备属性的小数部分。普通三连击、突刺和重击均生效。附加值不随重击蓄力倍率或连击物理倍率再次放大；和本次攻击共用一次暴击结果，分别经过魔法防御、魔法增伤和魔法易伤，再与物理部分合并。一次命中仍只有一次受击反应、奖励和训练结算。面板展示防御前附加基础值。
3. 导魔符文：当前手持此剑时魔法伤害乘1.20，和套装魔法增伤相乘。火球、冰锥施法时快照；其他已有非快照魔法伤害在命中结算时读取。近战有效命中存活目标后附加10%魔法易伤，持续10秒。重复命中刷新时间，符文本身不叠层；与既有法杖易伤分别计时并相乘。尊重目标状态免疫。

耐力词条保持之前约定：攻击（包括重击）和防御受击共用耐力消耗倍率。
