# 2011 细腻表面修订（2026-10-03）

本轮范围为 Pit Viper 2011、通用改造件、SI 补偿器与 VIP 蝮蛇防滑纹。保留已有共享金属母材质，在 2011 私有实例与材质副本中制作新版细纹和表面响应。实际资产保存记录见 `import_receipt.json`；未运行游戏、截图、渲染或验收。

## 制作依据

`Input/current.json` 是修改前的实际生产资产输入。2011 的 WS 材质继承 `GrainRoughness=.03`、`MottleRoughness=.02`；聚合物与 SI 灰色标识还继承 `Stipple=.06`。三种共享握把的底色、粗糙度与法线包含随机点状噪声。读取输入用于本次制作，不代表视觉测试结果。

## 新版材质和贴图

- 机匣、套筒、准星支撑、SI 外壳及相同材质的配件使用 2011 专用 1024 细纹图。保留很弱的连续加工纹，取消低频斑驳与额外点状粗糙度。阳极金属粗糙度中心为 .38，钢件为 .34，铜色枪管为 .24，黄铜为 .26；金属度与底色继承当前枪型。
- 原厂聚合物粗糙度中心为 .50，取消叠加的点状粗糙度。原几何防滑结构、刻字、UV 与法线不变。
- 三款通用防滑纹各自制作 2011 私有 BaseColor / Normal / ORM（1024）。保留颗粒、菱形、圆点的主要形状与物理尺度；降低随机色点、粗糙度变化与叠加的微小凹凸，避免把防滑纹做成满屏细砂。
- 蝮蛇纹使用 2048 私有贴图。鳞片主体与边缘深度不变，减少微细加工纹和白噪声法线的强度；保留斜向刻纹、金边和徽记。
- 战术灯和激光器复制现有材质图，在金属涂层分支替换旧 M4 表面图，原有结构、标记与材质区域继续使用。玻璃、分划和发光区域保持既有材质。
- 线性数据和色彩图分别使用正确的采样类型；ORM / 细纹采用 BC7，法线采用专用压缩、单次绿通道翻转。纹理保留流送和平均 mip，不添加锐化或强制常驻。

新版资产根目录：`/Game/Weapons/PitViper2011/SurfaceRefine20261003`。共有 15 张新贴图、6 个私有材质图；10 个既有 2011 WS 实例更新参数，4 个附件网格更新材质绑定，现有湿润材质表合并新条目。新增握把材质通过枪匠的按零件 ID 配方接入，保留单持、双持及法杖副手的既有使用通路。

## 持续制作入口

`produce_textures.py` 按数字配方制作表面图；`import_surfaces.py` 保存 UE 材质与绑定；`surface_contract.py` 保存实例参数及握把配方；`restore_saved_finish.py` 在 2011、常规配件、VIP 握把和 SI 重新导入后恢复此版本，避免退回旧颗粒层。原始 `finish_recipe.json` 和蝮蛇纹制作参数也同步更新。

本轮无 C++ 改动，无原生构建需求。材质图编译与资产保存属于制作；游戏表现由用户测试。未修改其他枪械的材质或共享母材质。
