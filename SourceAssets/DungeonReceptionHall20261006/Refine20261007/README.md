## 制作与保存入口

1. `prepare.py` 生成原创印刷与织物、木材 PBR 贴图，保存本次初始布局快照。
2. Blender 后台执行 `author.py` 与 `author_electronics.py`，输出 FBX 和可编辑 `.blend`。
3. `install_background.ps1` 使用项目批次互斥。已有编辑器时沿用桥；PIE 或脏地图时停止，保留当前会话。关闭编辑器时使用 PythonScript commandlet 后台导入并保存。
4. 以 `Receipts/install.json` 的 `stage=map_saved` 为实际地图保存回执。脚本存在和模型导出不等于 UE 已导入。
5. 保存成功后，主布局和主网格清单切换为新引用，再用主目录 `draft.py` 刷新未来首房草案。没有启用正式随机地牢池。

本轮不主动启动游戏、测试、截图或渲染，使用用户给定截图作为修改依据。材质与布局在实际游戏中的效果由用户测试。
