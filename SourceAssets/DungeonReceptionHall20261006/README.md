## 尺度与空间

参照 `DungeonTransitStation20260928/Config/room.json` 的 48 × 33 米车站主厅，接待大厅采用同等占地，室内净高 10 米，二层标高 4.5 米。中央挑空约 34 × 21 米。

| 区域 | 设计 |
| --- | --- |
| 访客入口 | 西端 4 米宽、3.4 米高，3 米长入口缓冲段；正常 FPS 出生点 |
| 一层接待 | 北侧 9 米柜台；两处坐姿登记工位、站立台面、低位登记台、踢脚和线孔 |
| 等候与休息 | 西侧四组三人沙发和茶几，饮水机、盆栽、垃圾桶、流程与须知牌 |
| 队列 | 独立 1.8 米宽折返队列，位于楼梯接近范围以西 |
| 安检 | 东侧两条净宽约 1.8 米的检测通道、行李传送带、托盘、读卡面板与值班工位 |
| 通行 | 中央主通路贯通；检测区外侧保留绕行空间；家具避让柱脚及楼梯落脚处 |
| 楼梯 | 南北两部 3 米宽楼梯，各 28 级、级高约 16.1 厘米，34 厘米踏面，中间休息平台 |
| 二层 | 四边连通回廊、休息长椅、饮水机、两间玻璃接待办公室；办公室前廊净宽约 3 米 |
| 后续连接 | 东端 3 米宽、3 米高设施通道；端口和完整三维占位已写成草案 |

室内采用暖灰水磨石、深绿金属、木质饰面和少量黄铜收边。地面分块留缝；文字牌保持字形比例，背板只有一个印刷表面。墙、楼板、楼梯和顶棚按实际厚度封闭制作。

## 复用与交互

- 复用生活区沙发、茶几、座椅、长凳、V5 饮水机；复用车站精修办公桌、显示器、键鼠和桌面文件，不重复制作显示器。
- 复用现有植物及生态区土壤材质，按植物根部锚点摆入花盆。
- 六个访客寄存柜、三个档案柜的九个独立抽屉使用 `ColdSteelSceneContainer`，共 15 个独立搜索容器，沿用现有库存界面与描边。
- 二层两扇门使用 `ColdSteelDoor`，沿用交互开关和冲撞开门。
- 二层十二块独立玻璃使用 `WardGlassWindow`，沿用现有碎片、声音和玻璃冲击效果。
- 栏杆保留连续简单碰撞和 `Traversal.GuardrailDrop` 标记。斜扶手、楼梯承托面与平台单独制作。
- 23 盏有限距离局部灯，其中 4 盏投影主灯；光源避开灯壳背面。静态重复资产在可用时通过现有原生工具保存为实例组件；交互资产保持独立。

## 制作入口与产物

- `prepare.py`：原始中文字牌、水磨石颜色／DX 法线／粗糙度贴图、布局与复用记录。
- `author.py`：精确尺寸模型、UV、简单碰撞、玻璃碎片；生成 `Authored/FacilityReceptionHall.blend`、FBX 与 `manifest.json`。
- `install.py`、`install_background.ps1`：通过已有批次互斥导入、构建 Nanite、创建材质、接入原生交互并保存独立地图。
- `draft.py`：生成 `Config/module-draft.json`，只包含正式房间需要的资产／端口／交互，不包含样板封口和出生点。
- `Receipts/install.json` 是实际导入保存状态。仅 `stage: map_saved` 表示地图已落盘；脚本或草案存在不代表导入完成。
