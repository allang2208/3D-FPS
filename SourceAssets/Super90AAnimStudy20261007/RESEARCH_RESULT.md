# Super90 快速装填研究定稿

日期：2026-10-07。范围是用户要求的研究续作：读取 AAnim、对照用户视频、分析现有作者数据，并形成可执行重制方案。本轮没有修改正式动作或生产脚本，没有导入资产、编译、启动 UE、运行游戏或进行验收渲染。

## 结论

当前最先要修的是本项目装填器的坐标、手部接触和推杆绑定。AAnim 可提供分指运动、手臂 Roll 层次和脱手/回握的研究参考；尚无证据确认该 RTM 就是用户视频中的管式装填器动作，也没有可直接接入的管体/推杆模型与独立机械轨道。采用“用户视频定动作、V7 与实际道具定接触、AAnim 辅助手指和腕臂节奏”的制作路线。

## 1. 本项目问题已追到具体接触数据

读取当前 `SourceAssets/Super90Speedloader20261007/author_speedloader.py`，只在研究脚本的内存副本中加入根空间校准，对比同一原厂普通七发动作第 87 源帧（对口结束）。没有执行该生产脚本的烘焙、导出或保存段。

| 数据 | 当前生产作者计算 | 研究副本仅校正根空间 |
| --- | ---: | ---: |
| 左手世界缩放 | 约 0.01 | 约 1 |
| 左前臂世界缩放 | 约 1 | 约 1 |
| 手腕到推杆握柄原点 | 52.99 cm | 8.82 cm |
| 推杆参考绑定缩放 | 约 100 | 约 1 |

原因链：UE SOURCE 的根节点继承 0.01 缩放 → 四种握把 idle 被当成米制作者姿态 → 共用 `grasp=idles['vertical']` → `hand_in_handle` 含有 0.01 缩放和错误偏移 → 原厂与前握把装填都使用错误抓握。推杆绑定 `rest['hand_l'] @ hand_in_handle.inverted()` 又引入反向 100 倍缩放；画面里道具可能看起来仍有尺寸，但手和前臂不在同一尺度。

因此下一轮不能仅重导动画：**推杆所在的 `SK_Super90_LoaderProps` 也必须用新接触关系重新绑定、导出、保存**。否则旧的反向补偿还在。枪体本身、材质、通用导向件不因这个问题需要换资源。

8.82 cm 只说明恢复了合理数量级。`hand_l` 是腕关节，不能把它压到握柄中心；掌心与指腹仍要依据实际 V7 网格拟合。当前游戏道具握柄为 32×30 mm 截面、94 mm 长的圆角条，原供体是竖直圆柱握把，校正单位以后也不能直接宣称五指已经贴合。

复现输入与输出：`study_loader_contact.py`、`loader_contact_study.json`。该计算是故障研究，尚未成为正式动作修复。

## 2. AAnim 可提取的内容与实际边界

动作锁定于 [AAnim 提交 50d7311 的 m1014_Reload.rtm](https://github.com/HopeJohnson/AAnim/blob/50d731135a81977d0ed758872a35b2185dcae296/Anim/reloadactions/m1014_Reload.rtm)。已读 89 个相位采样、67 条轨道，参考 [配置](https://github.com/HopeJohnson/AAnim/blob/50d731135a81977d0ed758872a35b2185dcae296/cfganimation.hpp) 的 speed=0.28，完整相位周期推算约 3.57 秒；不是 89/60 秒。

此次进一步读取 [Arma3ObjectBuilder 的 OFP2_ManSkeleton 层次](https://github.com/MrClock8163/Arma3ObjectBuilder/blob/9f2b8bc2320688a4c817be3650278c5f9122ce0d/Arma3ObjectBuilder/utilities/data.py) 与 [RTM 导入算法](https://github.com/MrClock8163/Arma3ObjectBuilder/blob/9f2b8bc2320688a4c817be3650278c5f9122ce0d/Arma3ObjectBuilder/io/import_rtm.py)，没有安装插件或执行下载代码。

关键层次为 Shoulder → Arm → ArmRoll → ForeArm → ForeArmRoll → Hand；小指的父级经过 HandRing。不能略掉 Roll 后把世界矩阵的变化误认为腕关节屈伸，也不能把这些骨头与 UE 同名骨直接一一复制。

按真实父子层次计算相对初帧的局部旋转变化，得到：

| 通道 | 最大相对变化 | 峰值相位 | 对制作有用的含义 |
| --- | ---: | ---: | --- |
| 左食指近节 | 53.36° | 0.607 | 食指有独立于其他四指的阶段 |
| 左中指近节 | 39.15° | 0.944 | 末段仍有显著指节调整 |
| 左无名指近节 | 43.08° | 0.944 | 与回握阶段相关的独立指节数据可研究 |
| 左小指近节 | 42.46° | 0.944 | 不能用掌骨刚体移动代替小指调整 |
| 左拇指近节 | 24.73° | 0.944 | 拇指变化幅度和其他指节不同 |
| 左拇指中节 | 17.74° | 0.348 | 拇指各节也不是统一时钟 |

这些是与初始姿态相比的变化量，**不是人体关节的绝对弯曲角，也不能仅凭峰值判断张开或闭合方向**。可提取的是错峰和曲线结构，不能直接把上述角度写到 V7 指骨。

配置的左手 IK 在 phase 0.012–0.041 释放，在 0.941–0.982 回接。它表达握点约束何时交给动作，但不证明装填器已对口或弹药已入仓。项目的弹药接触事件仍由道具与枪体接触确定。

数据交付：`parent_relative_motion.csv` 保存每个采样的局部变化曲线；`motion_study.json` 保存层次、峰值和拟合结果；`analyze_motion.py` 可复现分析。

## 3. 对完整重定向途径的进一步研究

RTM 是变形矩阵，需要参考绑定才能完整还原。此次还尝试由父子骨共用转动支点约束 `D_parent(t) p = D_child(t) p` 反推关节中心，并记录可观测性与残差：

- 左肩关节中心能稳定拟合，条件数约 3.53。
- 左肘的拟合条件数约 306，沿铰链方向约束不足，未作为可靠关节点采用。
- 左腕的纯固定支点拟合最大残差约 5.51 mm，不满足本次 2 mm 的研究精度门槛，未用于接触轨迹。

这条方法能帮助识别哪些数据可还原，却不能凭空补出完整源绑定。`inferred_joint_paths.json` 仅包含通过上述研究门槛的点，不是完整人体骨架或可投产动画。本次没有把猜测的肘、腕路径导入 UE，也没有用 Reforger 的另一套骨架替代 Arma 3 源骨架。

因此 AAnim 的完整空间动作迁移仍需要与它匹配的原始参考骨架。现阶段已有分指/父子旋转研究数据足以辅助重新制作，不必把整段重制阻塞在寻找旧源模型上。

## 4. 用户视频决定的动作母版

重新查看既有本地参考分解 `../Super90MotionRevision20261007/Reference/40-44_sheet.png` 与 `40.5-42.5_sheet.png`。视频窗口中的实际装填约为 40.63–42.50 秒，约 1.87 秒；40–44 秒包含前后待机。按原参考时间保留以下制作合同：

| 视频时间 | 动作重点 | 应控制的关系 |
| --- | --- | --- |
| 40.63–40.80 | 松开护木，左手下探 | 先解除指腹接触，再带动腕与肩肘；不要抓着护木横移 |
| 40.80–41.60 | 左手在画外取管，右手维持侧倾 | 保留画外留空；右手、枪身、导向件保持刚体关系 |
| 41.60–41.75 | 管体由左下入画并对口 | 先定管轴、端点和枪体接口，再求整臂；不要手先到、道具随后追上 |
| 41.75–42.10 | 推送 | 管口锁在枪体接口，推杆沿管轴，掌心与握柄固定；四指、拇指分别包握 |
| 42.10–42.30 | 退出接口、撤管、张掌 | 先解除管口约束；道具退出可见区后手指再松开 |
| 42.30–42.50 | 掌心接回护木，闭指并回正 | 先接近与接触，再闭指；回到当前装配对应的握点 |

视频只有 854×384、30 FPS 单视角，部分推送和取管被遮挡。可要求严格匹配可见管轴、手腕路径、枪姿与时序；背面的指腹接触、画外取管和空仓枪机操作需要三维适配，不能声称已从视频完整提取。

## 5. 下一轮制作的具体范围

1. **只先制作普通七发母版。** 修根空间输入；重新建立无缩放的手腕—掌心—握柄坐标；在 V7 上重新拟合五指；按新抓握重绑推杆。手指不能通过骨缩放来贴合。
2. **整臂跟随接触求解。** 同一肘弯面解上臂/前臂，肘极连续搬运；辅助骨使用本枪真实 0、1/3、2/3 站位。根据装填接触和相机位置处理肩根，不照抄本次冲刺的 19 cm 收肩参数。
3. **分离手指通道。** 拇指、食指、中指、无名指、小指有独立的脱离、闭合和松开阶段；AAnim 仅作曲线结构参考。掌心对推杆的约束优先于装饰性指节动作。
4. **先保留 Reference R2 的事件时钟。** 源 60 FPS，首发 90 帧、后续间隔 4 帧、七发末次 114 帧、普通完成 146 帧；基础 1.3 倍后约 1.872 秒。当前总时长已接近参考，首轮先解决接触和姿态；只有可见动作确需改时，才同步改 C++ 常量、道具显隐和弹药接触时钟。
5. **母版再派生数量和中断。** 1–7 发共享对口前缀；数量只决定推送终点和撤管起点。每发仍在接触后结算，保留已入仓/未入仓区分、软中断和硬中断规则。
6. **空仓单独制作。** 共用装填母版，枪机释放另设动作；当前视频和该 RTM 分析不足以证明某个拇指动作属于原参考，不把它伪称为复刻部分。
7. **最后合并四类握把。** 操作管体的主体段共用，前握把差异仅影响脱手和回握。合并现有四份 Profile 的 15 个装填条目，保留已保存的 3 段冲刺和 12 段其他动作。

预计正式制作落盘范围：生产作者脚本、可编辑 Blend、装填器 Props 网格及其 FBX、15 段基础动画、4 份握把 Profile；若事件时钟不变，无需为此改 C++ 或编译。枪械 WS1 表面、通用瞄具、前握把模型及 R3 冲刺不在本轮重制范围内。
