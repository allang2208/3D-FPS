# RSH-12 单持握位与检视穿模修订

当前单持握姿入口为 `author_profiles.py` → `import_profile.py`。网格、材质、五发装填器和左右双持资产继续使用 `RSH12Speedloader20261003`；本次只保存单持 `DA_RSH12_base`。

## 本次问题与修正

- 上一版按 715 与 RSH 的枪体表面对齐，保留了原始手型。检视时右手相对枪体基本不动，但中指、无名指等进一步收紧，穿进更厚的 RSH 握把。
- 使用当前 V7 手模完整混合权重计算实际皮肤接触，重新安排右手握位、共同三指包握，以及日常扣扳机和检视伸食指两个端点。进入和退出检视沿原动作姿态连续过渡。
- 保留骨段长度与缩放，使用局部关节旋转和手臂带动；不缩小枪体、不裁掉手指、不用相机偏移遮掩穿模。
- 保留 715 主体轨迹、24 个共享基础动作引用、已有机构/子弹/装填器差量及左手操作。接触修订在右手握住枪时生效，离枪时按原姿态淡出。
- 没有采用制作过程中试算的左手整体外移，它会拉开双手接触。最终左手仍保留上一版原动作与换弹接触。

## 可继续编辑的制作源

`production_single_r_inspect.json` 是右手落位和检视端点；`ready_index_thumb.json` 是扳机指与拇指端点；`pinky_finish.json` 是小指最终绝对局部目标。`held_grip.py` 处理共同握持和动作衔接，`Single/profile.json` 是已生成的导入数据。

其余 `fit_*`、`natural_*`、`wrap_*`、`support_*` 为排查/候选制作资料，不能当成已采用姿态直接导入。早期候选图可能不是最终版本。

`BeforeAssets` 保留本次修改前的活动单持 Profile。不要直接重跑旧 Speedloader 的单持 Profile 导入覆盖本版。

用户本次明确要求排查，因此仅进行了离线握把接触计算和局部制作观察。`diagnosis_single_after.json` 记录抽样结果；没有启动编辑器 UI、PIE 或游戏，没有进行整体动作/换弹运行验收。实际保存以 `import_receipt.json` 为准。
