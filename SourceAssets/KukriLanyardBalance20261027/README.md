| 挂饰 | 属性 |
| --- | --- |
| 编织短绳 | 攻击体力消耗 −10%；装备本刀期间，本人每次击杀恢复最大体力的 10% |
| 方牌挂饰 | 改造暴击率 +10%（增加 10 个百分点） |
| 铜环短穗 | 武技冷却 −10%；物理伤害 +5% |

## 结算范围

- 短绳是当前持用武器的装备被动，不要求由该刀打出最后一击；沿用本人击杀通知。双持两把短绳各计 10%，合计恢复最大体力的 20%，最多补至体力上限。沿用服务端同一目标去重；没有额外修改自然恢复等待时间。
- 只统计当前持用的主手刀与有效配对副手刀；手枪配副手刀时，副手短绳可生效。备用武器组、背包中的刀，以及切换使用采集工具时收起的刀均不计入。
- 暴击加成在实际攻击武器的快照中读取，单独增加该刀的 10 个百分点；不合并到角色全局暴击率，不转给另一把刀或手枪。双刀两把都装方牌时，各刀均增加 10 个百分点。
- 消耗、物理伤害与武技冷却继续使用已接入的每刀独立倍率与现有乘法叠加路径。
