# 焚化炉主题正式接入

采用已认可的破损支护室 → 焚化处理厅 → 烟气净化站固定核心，保留所有原有门位、完整房体、楼层、碰撞、灯光和遭遇描述。五类可搜索箱柜按现有种子流选择贴墙候选位，最后一房二层平台下保留一个共用探险宝箱。

`Config/release.json` 为采用版本；`Scripts/extend_catalog.py` 只合并本主题的容器、宝箱和核心顺序，不覆盖其他线路。`Scripts/install_theme.py` 读取正式生成器最新目录、补齐资产硬引用并保存地图；不生成地牢或运行游戏。保存结果见本地 `Receipts/install.json`。只有真实保存回执可以启用上游自动重建扩展，不手写安装回执。

正式地图：`/Game/GameMaps/L_Dungeon_Randomized`。用户要求继续保留的焚化炉、医院、车站线路测试地图继续保留。

公开源码含原创建模、PBR、组装和接入配方；UE 包、FBX、Blender 源、许可素材、完整运行快照和恢复备份留在本机。完整工程需按 `Docs/AssetSetup.md` 恢复本地资产，不能把 Git 源码发布称为可直接运行的游戏包。共享宝箱仍使用原正式资产路径和动画；本轮没有运行测试。
