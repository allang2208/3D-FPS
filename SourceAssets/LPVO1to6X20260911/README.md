## 来源和制作

无品牌原创游戏变体，沿用现代 LPVO 长镜筒、双环悬臂座和倍率拨杆的结构。三视图 three_views.png 和浅灰建模输入 reference_white.png 均为本会话内置 imagegen 生成；没有复用厂商模型或贴图。

三视图用于设计；5080 输入为同设计的单张三分之四参考图，不是多视图融合。RTX 5080/TRELLIS.2-4B，1024_cascade，16/32/24 steps，seed 911166，2K 纹理，目标 100K 面。任务 b585ba11-7661-424c-aaad-fe44aa857f9e 成功，执行约 116.209 秒。完整请求/回执/历史、设备与队列快照、源文件 SHA256 均在本目录。

生成母版 lpvo_textured_master_00001_.glb 为 98,219 三角面。已查看其实际渲染，轮廓和部件布局明确，但圆口、纹路和支架表面仍有起伏。沿用此前二倍镜的经验，按照参考布局在 Blender 重建可见机械几何：同轴壳体、双环支架、窄夹座、40 道规则浅纹旋钮和独立倍率环。生成模型保留为源参考，不宣称最终网格直接来自减面。原生成镜片占位面不用作游戏玻璃。

最终主体 20,608 面 + 活动倍率环/拨杆 2,204 面 = 22,812 三角面。主体 3 材质槽，活动件共享主体材质；4 张 2048² 烘焙 PBR 贴图。主体与活动件开放边、非流形、退化面均为零，两个玻璃面是双面薄片。

作者单位 cm：总长 25，导轨夹座宽 2.5，光轴高 4，目镜瞄准点 (-12.15,0,4)，活动环枢轴 (-7.1,0,4)。源文件 LPVO_SeparateParts.blend 保留分件，LPVO_Editable.blend 为烘焙导出文件；build_model.py 可复现建模/UV/烘焙/导出/渲染。SM_LPVO1to6X.fbx 与 SM_LPVORing.fbx 分别导入。

## 运行实现与边界

后续 HUD 修订：用户要求高倍镜隐藏所有游戏面板。当前 PlayerController 在 LPVO 光学显示生效后隐藏本玩家的顶层游戏 Widget，仅保留 ScopeOverlay；退出 ADS 或进入菜单交互时恢复各 Widget 原始可见性。因此下方早期交付中“血量/弹药仍可见”和“倍率提示显示”已被本次需求取代。滚轮变倍和倍率记忆不变。验收目录 scope-clean-hud-20260911；截图检查使用 verify_scope_aperture.py <目录> --hidden-hud，并检查退出后 HUD 恢复。引擎屏幕调试信息不属于这些游戏 Widget。

2026-09-11 ADS 视野修订：当前开镜使用 LPVOScopeWidget 的大圆形光学显示，清晰口径为屏幕短边的 85%，薄边框尺寸独立于 1–6× 倍率。镜框置于普通 HUD 下层，血量/弹药仍可见。完整开镜时仅对持枪者隐藏视模与挂接件，退出后恢复；外观网格、改造展览和换弹资产未重做。主相机继续控制放大，分划固定在屏幕中心；光学显示生效时射击方向使用包含后坐力的相机前向，不再使用隐藏镜筒的几何分划。倍率提示移到快捷栏上方。新增实际截图口径检查脚本 verify_scope_aperture.py，检查范围包括正常开镜与再次开镜。

资产目录 /Game/Weapons/LPVO1to6X，配件 ID lpvo_1_6x。镜身与活动环独立挂接；武器重建时先清理活动环，避免脱离父瞄具后残留。安装、取消、保存失败回退、重载、未装备实例、库存图标和地面武器沿用通用入口。原有二倍镜保留。

倍率沿用现有整画面 ADS FOV 系统：2*atan(tan(55°/2)/倍率)，同步灵敏度；不是镜内独立画中画。1–6× 期间保持目镜位置校准的眼距 28 cm，不在跨越 1× 时跳动。当前分划是固定几何十字红点，不提供真实光学折射或弹道刻度标定。
