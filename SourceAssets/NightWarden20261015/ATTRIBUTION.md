# 来源与公开边界

- 原始守寝者：用户提供的 `Meshy_AI_Character_output (5).glb`，智能绑骨；本机副本 `Input/NightWarden_Meshy_Original.glb`。模型/材质许可未在本轮重新核准，不公开模型、蒙皮、UV 或原始贴图。
- 当前移动供体：Epic Paragon Rampage，项目内 `Jog_Biped_Fwd`；百目挥击供体为 `Attack_Biped_Melee_A`。仅公开独立编写的重定向、适配和导入代码，不公开供体、UE 包或可重构动作的密集关键帧。使用者必须自行取得对应资源授权。
- 历史待机来源：项目已有 UE Manny `MM_Idle`；旧 ZombieAnimationPack 候选均已退役。第三方原始动作不随本批发布。
- 已退役候选：[100STYLE](https://www.ianxmason.com/100style/) 的 DragRightLeg、BentForward 等，作者 Ian Mason、Sebastian Starke、Taku Komura，CC BY 4.0；候选发现入口 [orangeduck/100style-retarget](https://github.com/orangeduck/100style-retarget)。本项目曾裁剪、重定向和适配其中动作，现已否定并归档；源清单和完整许可随候选目录一起保存在本机 trash。其 GitHub 免费可访问不意味着所有其它动作均可再分发。
- 本批 Git 内容为原创 C++、Python/PowerShell 制作配方、文档和经验；不包含 Blender/FBX/BVH/GLB、第三方模型动作数据、引擎、插件、缓存或日志。
