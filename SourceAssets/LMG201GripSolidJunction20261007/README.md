# 201 一体化平滑衔接件

2026-10-07 用户修订：“衔接件不要有凹入设计，就一体化平滑设计”。本修订替代同日 `LMG201GripJunction20261007` 仍保留内凹造型的接颈版本。

## 制作

- 幻影、均衡、稳固防滑三款均采用实心、连续的外轮廓，去掉旧接颈的收腰、凹槽与凹入过渡。
- 在握把肩部重新取闭合边界：幻影和稳固 z=-30 mm，均衡 z=-28 mm。此处至 z=+6 mm 原厂安装面的区域重新制作；不再保留此前 z=-20/-22 mm 上方的凹入设计。
- 中间截面用握把肩部凸包与原厂真实安装轮廓的凸组合，保持饱满的外表面；最下方短过渡与原始边界共享顶点，连接下方握持区。安装端包含原厂轮廓的倒角转折点。
- 原始源有微小分离边界，按闭合区域构造肩部；均衡采用 -28 mm 连续截面，未沿 -30 mm 断开的源边界强接。
- 保留切口下方主体的 UV、法线、材质与尺寸；没有进行整把体素重建、整把缩放或减面。新连接区替代了原有细碎网格，面数因此有所变化。
- 新区域继续使用现有连续材质及 UV4 接颈法线淡出；不增设装饰套圈或独立凹面。

## 文件与接入

`input.json` 与 `Input/` 为上一版现用资产的完整 FBX。`author.py` 输出三份可编辑 `.blend` 与 `Exports/*.fbx`，`model.json` 记录制作结果。`install.py` 通过项目 UE 批次互斥导入，保存正式配件原路径和独立制作资产，并更新重导入来源；旧版资产备份在 `Before/`。

实际完成状态见 `install_receipt.json`，只有其中 `complete: true` 才表示三款正式资产均已保存。
