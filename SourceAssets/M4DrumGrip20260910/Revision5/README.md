# 大弹鼓换弹节奏与握枪姿势 Revision5

本版依据用户对 Revision4 的最新反馈制作：掉鼓前后保持握枪姿势，适当抬枪，随后左手自然下甩取鼓、装鼓，右手与枪械轻微配合晃动。

## 动作改动

已实际查看 Revision4 游戏截图并采样骨骼动作。上一版左手从源帧 5 就开始离开护木，早于弹鼓释放；枪械在抬起后长时间保持相同变换，形成机械般的停顿。

- 保持支撑握法到普通源帧 22 / 空仓源帧 18，均在物理旧鼓释放后 4 帧。期间左手相对枪械的位置、朝向及指形保持一致。
- 起手先约 8° 抬枪、2.2 cm 抬高，不立即大幅翻枪。左手离开之后才渐渐转入装鼓姿态；主要翻枪幅度约为上一版一半。
- 左手下甩采用连续位置曲线，经过下方过渡点再取鼓，避免每个中间点都停一下。张手发生在下甩开始后，随后重新包握新鼓。
- 取鼓、抬鼓及插入时加入不等间隔、约 1° 的小幅起伏与侧摆，带数毫米位移。右手与枪把保持稳定接触，枪械不再在中段完全静止。
- 保留旧鼓独立物理掉落、装鼓接触轨迹和动作起止姿态；沿用双臂肘部屈伸约束和前臂辅助骨扭转分配。

源片段仍为 2.1 / 2.7 秒；游戏总换弹时间、时间映射、机械声音时点、释放和新鼓显示时点、50 发容量及弹药结算均保持原有合同。
