# 大弹鼓掉落换弹 Revision4

依据用户对 Revision3 肩、肘、腕扭转及镜头穿模的反馈重做。Revision2/3 是历史版本，不代表本次验收结果。

## 当前接入

默认动画为 `/Game/Weapons/M4DrumDrop/Final/A_M4_DrumDrop_reload` 和 `A_M4_DrumDrop_reload_empty`。根目录下同名资源属于本轮中间试验，因编辑器占用而保留，默认代码不再引用它们。普通弹匣动画、五个弹鼓支撑动画、枪械及手臂网格保持原有资源选择。

动作顺序：释放旧弹鼓 → 旧鼓独立向左下方掉落 → 左手离开镜头取新鼓 → 张手包握新鼓 → 沿已调好的轨迹对准、插入 → 回到持枪姿态。空仓保留后续机械操作。源片段仍为 2.1 / 2.7 秒，沿用现有游戏换弹时间映射，不修改弹药结算时点。

旧鼓在普通源帧 18、空仓源帧 14 释放。C++ 创建独立物理 Actor，继承角色速度并给予轻微左下方初速度和转动，8 秒后清理；它不再随手或枪械运动。挂接模型在取新鼓期间隐藏，普通帧 50、空仓帧 35 再显示。仅为换弹视觉，不生成额外库存物品。

## 手臂和镜头

从既有动作核对肘部屈伸轴，上臂和前臂共同使用同一个弯曲平面，消除之前不同旋转基准造成的侧向肘部扭转。左肩后移、降低，肘部配合手掌目标求解；前臂扭转由辅助骨分担，保留实际骨长。右臂保留原来的肩、肘、手位置轨迹，统一屈伸基准，不把右肩额外拉低。

对左肘弯曲平面的连续角度进行平滑，避免取鼓及收势时突然翻转；起止姿态恢复到原有持枪姿态。手掌及安装阶段各指姿态沿用已调好的包握轨迹。自由手段使用已有张手姿态，不任意旋转指骨轴。

弹鼓动作的额外前移量由 12 cm 调为 4 cm，配合左肩调整，检查实际第一人称画面中的肩部露出和近镜头穿模。

- `endpoints.log`：双臂上臂、前臂、手掌的起止世界旋转与修改前姿态一致。
- `import_report.json`：最终 UE 路径、253 / 325 个采样键、源文件和压缩位置误差。导入、保存及检查通过；命令行仍因项目既有 GameFeatureData 配置错误返回非零。
- `after_*.png` / `before_*.png`：同一模型、相同动作帧的局部渲染；用于检查肘部护甲与腕口，早期帧中的 Blender 弹鼓并非运行时物理掉落模拟。
- `runtime-drop_release_r4.log` 及 `drop_release_r4_*.gif`：最终资源的独立游戏验证和真实游戏截图动图；以日志中的 ACTIVE 完整路径为准。无音频，不作为实时帧率基准。

最终游戏验证于 2026-09-10 完成，`COMPLETE failures=0`：普通及空仓均补满 50 发，备弹账目正确，每次仅产生一个独立下落旧鼓，动画期间及结束后的挂接检查通过。此次后台截图速度较慢，外层原 120 秒等待先超时，游戏随后自行完成全部检查并退出；等待上限现已调整为 300 秒，没有将超时当作通过，也没有中断测试进程。

顶点接触检查覆盖左手与鼓体包络，普通最大侵入 0 mm，空仓约 0.35 mm；不等同于对整把枪所有表面的自动碰撞证明。视觉验收结合第一人称全程截图和局部模型渲染。

## 编辑源及复现

`M4_DrumDrop_Editable.blend` 中 `A_M4_DrumDrop_*` 为本次动作，`BeforeDrop_*` 保留修改前动作。`build_drop_reload.py` 从 Revision3 源文件重建，导出同名 FBX；`validate_drop.py` 校验骨骼及接触；`import_wrist.py` 导入最终路径。`run_review.ps1 -Run <唯一名称> -DefaultAssets` 用独立测试存档运行真实换弹，`make_review.py <名称>` 生成动图。测试不改用户正式库存。

此次 native 修改集中于默认动画引用、动作构图、物理掉落和换弹审计。构建期间另对并行枪械 UI 代码做了三项编译修复：局部 Children/Slot 变量避开基类同名成员，以及补齐分类按钮的 Slate 右括号；没有重写其工作台逻辑。

当前打开的编辑器可能缓存了中间动画或旧 native 模块。保存工作后重启 UE，可加载最终默认引用；无需再次导入源文件。
