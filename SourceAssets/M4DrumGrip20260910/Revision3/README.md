# 左腕与前臂衔接细修

基于用户认可整体方向的 Revision2，只调整左臂骨骼衔接。当前默认路径仍是 `/Game/Weapons/M4DrumGripRebuilt/A_M4_DrumGrip_reload` 和 `A_M4_DrumGrip_reload_empty`；本次只重新导入这两套动画，没有改 C++ 或支撑动画。

## 修正内容

靠近袖口的扭转骨由分担约 2/3 的转动调整为更接近手掌方向，同时分配少量转动给近端前臂。肩部最多配合 6 cm，肘部向自然前臂方向调整，以减少腕部弯折。起止段平滑回到已有姿态。

手掌、各指骨、右手和弹鼓在 120 Hz 对照中的位置差小于 0.00004 cm；抓握及插入轨迹保持原样。提高导出/导入采样至 120 Hz，避免局部骨骼插值在采样帧之间带来额外接触漂移，时长仍是 2.1 / 2.7 秒。

## 证据

- `wrist_validation.json`：抓握阶段袖口与手掌的残余旋转差，正常从 47.89° 降至 17.04°，空仓从 46.37° 降至 15.99°。这是骨骼衔接量度，不是人体关节医学指标或零形变保证。
- `before_*` / `after_*.png`：相同动作帧的实际模型近距离渲染，检查腕口、前臂和肘部。Manny 分段护甲原有的内侧开口仍保留，本次没有改网格或蒙皮。
- `wrist_r3_normal.gif` / `wrist_r3_empty.gif`：本次真实游戏截图动图，包含正常和空仓整段动作。无音频；游戏按固定时间步运行，截图约 22–30 张/秒。
- `runtime-wrist_r3.log`：正式默认路径的独立游戏测试，换弹、弹药和挂接检查完成且零失败。
- `full_motion_contact.json`：全整数帧皮肤顶点与鼓体包络检查，残余侵入最大约 0.29 mm，没有超过 1 mm 的顶点。范围不覆盖整把枪的全部表面。
- `import_report.json`：253 / 325 个采样帧，最大压缩位置误差约 0.012 cm。导入保存及检查成功，另一个新游戏进程完成验证；项目现有 GameFeatureData 配置错误仍使导入命令行返回非零。

可编辑源为 `M4_DrumGrip_Rebuilt.blend`，其中 `BeforeWrist_*` 保留本次修改前的动作，`A_M4_DrumGrip_*` 为当前动作。`polish_wrist.py` 从 Revision2 源文件重建本次修正；`BeforeAssets/` 保留修改前的两个正式 UE 动画资产。

当前编辑器缓存是否刷新应以读回为准；独立游戏测试已读取本次新资源。若编辑器中仍播放旧动作，可保存工作后重启编辑器。
