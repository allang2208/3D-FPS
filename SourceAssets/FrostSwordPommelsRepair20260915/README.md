## 原因与修改

- **512 贴图导出参数错配**：符文／魔力球的形状流程为 512，但纹理导出节点的 voxel grid 仍为 1024。`reexport_textures.py` 复用原 seed 与视图，仅以 512 网格重新导出 4K 母版；旧母版与回执留存。原 `generate.py` 的新任务入口也已修正分辨率对应关系。
- **减面前未焊接重复顶点**：glTF 在 UV 接缝拆分顶点，直接大幅减面产生裂口，也使颈部切口只剩碎片。新作者流程先焊接同位置顶点、保留面角 UV，再减面、重新展开并烘焙颜色／ORM／法线，使用完整切口制作过渡。硬化配重的主体仍来自原 1024 母版。
- **符文轮廓和图案**：恢复生成模型的统一缩放比例，不再分别压缩宽深高。生成结果丢失银白符号，因此按原参考正面描出上叉、分支、中央菱形、下叉，投射到前后曲面并制作实体镶嵌。符号使用独立银白材质及轻微周期发光，主体保持生成的分瓣造型。
- **魔力球材质分区**：旧结果仅有 16 个三角面分到水晶槽。修正贴图后，球体表面分到独立水晶槽，支架保持金属。水晶使用剑刃蓝色、Metallic=0、Opacity=0.62、Roughness=0.16，移除球体上造成碎片高光的切线法线贴图。
- **连接颈材质**：安装边沿保留原 UV／法线；新增过渡面通过顶点色在安装口下方 2–4 mm 区间渐变至原剑古铜色贴图区域，避免将原剑的蓝色纹理拉长到整段连接颈。UE 复用既有 `M_FrostCrystalSword_SeamlessBronze` 的双 UV 混合逻辑。另为新增过渡面和隐藏安装封口展开有效 UV；保留作者表面法线，切线改由 UE 根据最终 UV 生成，避免导入 Blender 多 UV 层的切线记录。

## 作者入口

1. `reexport_textures.py`：只负责两个 512 母版；已有回执不重复提交。
2. `author_pommel.py -- <id>`：焊接／减面、4K 颜色与 ORM 烘焙、2K 法线、安装口及过渡面。
3. `refine_details.py -- <id>`：符文配重制作银白镶嵌；魔力球去掉水晶表面的结构法线。
4. `finish_collar.py -- <id>`：原安装边与古铜过渡面的 UV／顶点色材质；为少数生成细长面修整局部 UV 和切线坐标系，保持顶点位置不变。
5. `make_icon.py -- <id>`：制作实际模型的 UI 图标。
6. `import_pommels.py`：独立目录导入，明确绑定水晶／金属／银白镶嵌／轮廓／连接颈材质，最后更新三个配重锤选项的模型引用。重导入时同步资产保存的法线导入设置，避免 UE 继续使用旧切线策略。

`finish_models.py` 按上述顺序制作三款本地模型。每款保留 `FrostPommel_Editable.blend`、FBX、贴图、`Pommel_Icon_Editable.blend`、PNG 及 `authoring.json`。重新执行从基础作者入口开始，避免对已经制作好的符文重复添加镶嵌。
