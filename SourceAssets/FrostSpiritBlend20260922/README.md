# 精神迸发：冰蓝融合与淡入淡出

用户认可聚能与双波迸发的思路，但反馈紫色不契合蓝色剑体、线段感过强。本轮只修改精神迸发的材质表现和对应选项描述。

主色改为冰蓝，聚能中心为青白，蓝紫仅在退光边缘参与不超过 8% 的混色。独立参数见 `palette.json`。配色目的在于呈现从寒晶内部透出的晶光，不代表改成真实次表面散射模型。

三处节点改为分别计算的圆润菱形，去除原 `floor/frac` 空间分段带来的边界。轮廓使用柔和距离衰减，常亮硬线改成低权重的渐隐轮廓。双重回响按先后次序扩散，随半径增长加宽、降低透明度，再渐隐；循环两端归零以避免突然重置。周期约 2.94 秒，节点错峰出现。

整体覆盖上限 0.56，实际随局部能量进一步降低，让剑体透出。原裂纹以柔化遮罩为主，只留低强度余光；剑宽和根尖方向都有渐隐收边，发光保持色相并限制峰值。

运行资产仍为 `/Game/Weapons/FrostSpiritBurst20260922/M_SilverRuneSurface_FrostSpirit`，保留既有图节点、纹样贴图、坐标投射和曝光连接。没有改动 C++、伤害倍率、改造兼容性或存档规则。
