# M1911 消音器预览与圆滑红点底座（2026-09-13）

## 预览模型消失

`M4GunsmithPreview::SyncStudioPreview` 已使用变形后的可见枪身顶点计算取景范围，但预览中的 Leader Pose 骨骼副本仍通过 UE 默认逻辑计算裁剪边界。没有可用物理包围盒时，该逻辑退回导入的手臂/初始姿态边界。长消音器改变居中取景后，两者不一致会使枪身被裁剪而静态配件保留。

本次复用库存图标已有的处理方式：把当前可见姿态的包围盒转换到预览副本的位置，为副本计算足以包住该姿态的 BoundsScale，同时覆盖盒体和球体范围。范围按当前姿态及坐标计算，不使用固定超大倍数；后续整件居中平移仍同步移动这些边界。侧视和瞄准预览都使用此逻辑，原枪身、手臂隐藏规则及正式游戏模型不变。
