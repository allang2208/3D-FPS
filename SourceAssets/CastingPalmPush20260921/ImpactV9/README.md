# 推掌 V9：总长 1 秒与增强回震

用户要求将总时长调整为 1 秒，并反馈测试未见回震。上一轮 V8 代码与源动画已制作，但曾被其他模块的 UHT 错误阻断编译，未接入运行；不能将该次未见回震直接判为幅度过小。

本轮在保留快速起手、推出和 V6 自然回握的基础上，缩短终点停留：默认预备 0.16 s、推掌 0.113333 s、终点停留 0.226667 s、recover 0.50 s，完整独立释放为 1.00 s。发射接触仍在整段 0.226667 s。若从凝聚直接进入推掌，则跳过独立预备；凝聚本身不属于这一秒的发射动作。

终点停留从 `ReleaseTotalSeconds=1` 减去三个运动阶段计算；施法速度 S 下，运动阶段继续加速，停留保持真实时长，总长为 `0.773333/S+0.226667` 秒。

回震仍由发射接触触发，肩、肘 pole 与腕部共同平移，保持腕部姿态、骨长和缩放。纵向位移系数由 1.2 cm 提至 3.0 cm，侧向 0.18→0.45 cm，抬升 0.35→0.90 cm；频率 14→12 Hz，衰减时长 0.16→0.18 s，平滑起振仍为 0.012 s。这些系数约放大 2.5 倍，不等于实际采样峰值。回震先后撤再回弹，跨推掌/停留连续衰减，不改变相机或瞄准。

作者入口 `SourceAssets/FireballCast20260914/author_cast.py` 同步读取 C++ 参数及姿态配置，300 Hz 输出本目录的可编辑 Blend、九段 FBX 和作者记录。游戏使用共用程序化施法层，FBX 是可编辑交付；V8 文件保留。未运行测试、PIE、截图或渲染。
