## 材质

每枪外壳和底座使用各自机匣涂层，保留镜片、反光杯外观和橡胶尾键。UV0 保留原纹理；独立 UV1 用于涂层，角点色区分涂层与光学/橡胶区域。M4 沿用现有 sRGB Shininess 与 Phong 转换；AKM 使用机匣金属区域；QBZ 使用当前程序化涂层和磨损，在自身 UV1 烘焙。未修改枪身共享材质。

## 游戏接入

- M4、AKM、QBZ-191 的 `tactical` 槽互斥选择 `laser` / `flashlight` / `false`，保留 Godot 对非导轨手枪的排除范围。
- 激光沿用后来确认的旧版平衡：腰射散布 ×0.5、ADS 耗时 -0.2 秒。早期 attachment-fit.md 中的零散布/+200ms 已被后来的用户修正取代。枪管的百分比 ADS 修正规则独立保留。
- 手电不额外赋予数值加成。新 UE 照明调校：1000 lm，40 m 衰减范围，12°/24° 内外锥角，支持动态阴影。
- 激光范围 80 m，腰射沿实体发射器轴线；ADS 使用当前可见准星方向求目标，再从发射口向目标汇聚。相机至发射器及发射器至目标都执行遮挡射线，光束遇物体截断，命中点保留深度检测。
- `TacticalDeviceComponent` 在姿态更新后处理效果，收起、卸下、攀爬或隐藏时关闭。无控制器的展示/掉落模型和枪匠菜单只展示几何，不把灯光与激光射入游戏场景。
- 同一装配入口供装备角色、枪匠草稿/撤销、独立实例预览、武器图标和掉落模型使用。配件保存复用原有枪械实例数据，无存档版本变更。
- 运行资产目录 `/Game/Weapons/TacticalDevices20260913/<M4|AKM|QBZ191>/<laser|flashlight>/SM_TacticalDevice`，已纳入打包目录。
