# 状态页与顶部状态栏：冷钢玻璃同步升级

2026-09-12。用户要求将已确定的仓库／背包装备风格更新为正式冷钢 UI 规则，并同步到状态面板。

## 实现

- [正式设计规则](ui-cold-steel-design-system.md) 成为当前 UE UI 入口，列明新配色、字体、玻璃、按钮、仓库动作及被替换条款。项目 AGENTS 与 UI 索引已指向该文。
- `ColdSteelUIStyle` 统一中性灰色板及 Noto Sans SC／JetBrains Mono，移除对 Windows 宋体、Consolas 和 Saved 临时字体的首选依赖；`GunsmithUIStyle` 改为共享主题兼容入口。旧调用保留 Slate 点数合同，避免重复换算导致字号改变。
- 状态抽屉沿用背包装备的低透明度玻璃外壳。身份区改为姓名／职业与等级／属性点分列；分区采用深灰细边卡片和银白标题，正文与属性数值统一 14px，角色名／分区／辅助信息分别为 20／16／12px。
- 属性行扩大留白、数值右对齐，武器名称及普通文字使用 UI 字体并允许换行；加点按钮为 24×24px，保留原模型回调。状态页字体与属性行在抽屉布局变化时更新 DPI 尺寸。
- 生命／魔法／体力／经验条保留语义色与实际数据，轨道改为深灰细条。状态详情浮窗、顶部生命／魔法／等级栏同步真实 BackgroundBlur 和银灰边框。
- 仓库与背包改用公共玻璃和标准按钮值；仓库上一轮的“存入同类”、等宽四按钮及排序菜单继续保留。

## 数据与输入

仍由 `UColdSteelStatusModel` 提供身份、六维、经验、魔法与加点，角色组件提供生命、移动、弹药与武器实值；刷新事件、定时读取节奏、保存和战斗公式没有变更。鼠标悬停／键盘焦点复用原详情入口，关闭、页签切换及销毁继续解绑和清理。没有新增存档字段。
