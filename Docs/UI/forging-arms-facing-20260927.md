# 锻造鼠标方向与手臂动作修订

用户反馈：鼠标左右反向，实景锻造中未见有效的持锤、持钳手臂。

## 修改

- 鼠标移动使用锻造相机的屏幕右、上方向，投影到铁砧平面，再转换为落点坐标。原镜头朝工作台 +Y，屏幕右方实际为 -X；不再把 +X 当作屏幕右方。
- 手臂继续使用项目认可的 V7 裸臂/M4 原生绑定及其现有皮肤材质。新增专用姿态组件，把身体朝向与位置放在组件变换中，按实际肩、肘、腕及手指位置更新可见包围盒。原先在骨骼姿态内抬高手臂，裸臂又没有 PhysicsAsset，PoseableMesh 默认回退到原始模型范围，不能覆盖铁砧前的姿态。
- 身体绕 Z 转向工作台，保留真实左右手。剑坯调转朝向，让夹持端位于屏幕左侧，右手锤位于右侧；同步调整淬火提起路径。
- 右手围绕锤柄调整持握方向，使落锤时腕部位于握柄上方、前臂自然向前下方发力。左手按钳子双柄闭合。保留掌骨自然展开，指节局部收拢，骨长与缩放不变。
- 肩带为前伸提供支撑，肘部优先向身体外侧、下方弯曲，并连续参考掌向。前臂朝向由手掌宽度轴决定，辅助骨跟随完整骨段，撤去原先的分数扭转，减少拧细与腕部折弯。
- 仍沿用 0.82 秒锤击、0.34 秒接触帧，以及原有计分、库存、品质和抽屉行为。
