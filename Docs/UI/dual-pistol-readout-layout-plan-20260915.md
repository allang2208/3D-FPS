# 双持手枪右下状态栏统一

用户要求统一主手、副手的字体大小与布局。当前主手采用完整武器栏（16px 名称／24px 数字），副手为附加文字（12px 名称／16px 合并弹药）。本次直接改造展示，不修改双持战斗与弹药逻辑，不主动启动游戏或测试。

- 同一 360px 自适应玻璃外壳中上下排列主手、副手，两组共用一套构建及布局代码。
- 每组依次为“主手／副手 · 完整武器名”（Noto Sans SC 16px Medium）、“左键／右键 · 对应口径 · 换弹中（按实际状态）”（12px）、细分隔、左右弹匣／备弹标签（12px）及数字（JetBrains Mono 24px）。弹匣两手均显示当前／容量，备弹均独立右对齐；相同角色使用相同字重。
- 两组之间使用额外细线和等距留白；长武器名、口径说明按当前可用宽度换行，面板高度自然增加，继续使用 HUD 的底部避让与侧栏位置计算。
- 两组分别读取 `DualPistols.Hand(0/1)` 的物品、当前弹量、容量、换弹状态；口径使用各自 `AmmoDefinitionFor(Item)`；备弹使用 `Reserve(0/1)`。保留无限备弹、空弹、低弹和换弹颜色，两手统一颜色算法。
- 单持枪械与近战沿用原显示内容，副手整组及组间分隔在退出双持时一起折叠。控件只读，不新增输入、计时器、存档或资源操作。
- 修改范围：`ColdSteelAmmoReadout.h/.cpp`、正式 UI 规则与索引。本次使用现有 UE UI 技能；必要构建走 `Tools/Build/Build-Editor.ps1`，实机由用户测试。
