## 响应布局与视觉

独立 owner-only Slate leaf，单一 UI 材质，非交互、无鼠标命中、不获取焦点。Z=16，位于苍龙 HUD(15)之上、冷钢面板(20)之下。面板打开时覆盖经文；关闭 HUD、切视角或死亡隐藏。

采用以局部视口高度 H 为基准的两列竖排行书：左边 x=.32H，顶边 y=.20H，宽=.155H，高=.31H。水平浮动最大 .0015H，垂直最大 .003H。苍龙 V10 整张四边形连同其最大横向偏移的右界约 .287H；经文左界最小 .3185H，预留至少 .0315H 间隔。1080 高视口留约34像素，720 高留约23像素。不同宽高比共用局部视口坐标，不采用固定1920画布。

金色为经文专属表现：高血量偏香槟金，中血量琥珀金，低血量明亮暖金。0.45秒交叉淡入淡出；每帧只更新材质标量和一张绘制四边形，轻微呼吸、扫光及浮动。吸血期间微加强扫光，不覆盖经文本体或苍龙能量。

2026-10-06 按用户要求追加金色燃烧：稳定字芯上保留原金色渐变，笔画边缘接暖金热边，八级向下取样形成向上卷动的细火舌；火焰从琥珀金过渡到浅金亮芯，随经文状态共同淡入淡出。火焰在原四边形内衰减，不扩大与苍龙能量条的相邻区域。复用现有图集、Age及单张材质，无新增贴图、粒子组件或原生修改。作者及后台单材质保存入口为 `SourceAssets/JingangRune20261006/FlamesV2/`。本轮未预览或游戏测试。

行书使用白色笔迹黑底三栏图集，shader以R通道为透明度，不依赖系统字库。每栏准确包含一个八字节选，无生成的伪符号。菜单数字和普通文字仍用现有冷钢字体。
