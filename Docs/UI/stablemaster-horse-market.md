# 东门马市

步行靠近东门马厩管理员，瞄准她按 E 打开马市。面板复用冷钢商店抽屉，与背包并排。交易使用灵魂。已有出战马时，买马后可到「马匹」栏目更换出战对象；角色取得的第一匹马会自动出战。

## 浏览与购买

东门马市和按 I 打开的个人马匹栏共用缩略卡片。悬停或用键盘聚焦时，马图拉近变清晰，并展开六维、每级成长和鬃尾信息。名册可用滚轮浏览。个人名册标出当前出战马，同名马用短编号区分。

点击金色加号后，左侧显示该马详情，右侧打开玩家背包。在售马匹可查看生命、体力、等级、经验、六维成长和装备位，点击详情中的「确认购买」才支付灵魂。已拥有的马匹还可在详情中设为出战、召唤、遣散或使用生命药水。

详情抽屉顶部显示当前马匹的毛色图鉴、等级、经验和状态。生命与坐骑体力分别使用红色和蓝色进度条。马匹装备优先显示，其后是六维数值和每级成长、骑乘能力。返回名册与底部操作固定，中间内容可滚动。

### 马匹装备

每匹马独立保存马蹄、马鞍、护甲和行囊四个装备位。槽位沿用玩家装备栏的左文右图形式。空槽显示部位和「未装备」，已拥有马的空槽有加号。穿戴后显示物品名、对应图标和品质色。装备区右上显示已穿戴数量。可以从随身背包拖到对应部位，也可点击部位，从列表选择装备或卸下。替换时原马具放回背包，空间不足则保持原有穿戴状态。基础铁制马蹄铁、皮革马鞍、钢制马面甲、双联马鞍行囊均可在制作台制作。

## 六维与数值

各属性独立取 6 至 14 点，10 点对应原有基础值。下表为每增加 1 点相对基准的变化，百分比按基准线性相加。

| 属性 | 对马匹的实际影响 |
| --- | --- |
| 力量 | 起跳高度增加 5 厘米，基准为 220 厘米 |
| 敏捷 | 移速增加 2.5%，骑乘疾驰基准为 11.6 米/秒 |
| 智力 | 骑乘与跟随转向速度增加 3.5% |
| 体质 | 生命上限增加 12，体力上限增加 8，基准均为 300 |
| 精神 | 体力上限增加 4，按玩家体力恢复基准每秒增加 5% |
| 幸运 | 站定后的静养回血速度增加 6%，基准每秒恢复该马生命上限的 2.5% |

## 日更与存档

村庄天气时钟跨过午夜后更换整批名册。每个角色独立选货，开关面板或读取同一天的存档保留报价。新马的名字、外形、基础六维和每级成长按永久身份独立抽取，可以同名。新马售价采用已有的出生属性和成长权重，历史马匹沿用其出生版本。

单机和联机共用交易处理。服务器按当前角色、商人距离和当日名册重新定价，一次写入灵魂扣款和马匹归属。重复购买、旧日期、距离不足和余额不足均给出结果。归属沿用马匹栏及 X 键召唤流程。旧马的状态按原生命和体力比例换算，逃离和召回冷却继续生效。
