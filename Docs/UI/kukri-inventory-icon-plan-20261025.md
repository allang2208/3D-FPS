## 范围与布局

按装备栏已有侧视图、等比拟合和可见轮廓规则放大弯刀。沿用 UMG 宿主内的 Slate 自绘、冷钢主题、槽位命中区域和文字列。装备槽横放，刀尖朝左；保留左侧槽名、名称和状态，刀图在右侧图区按可见轮廓居中撑满，刀柄与刀尖完整保留，不改变模型比例。

单手近战沿用现有 `IsOneHandedMelee` 分类，当前为尼泊尔弯刀。其动态图独立采用作者占格比例，弯刀为 1×3、256×768；双手剑仍用原有画幅。目录 PNG 与动态图都在首次载入／生成时计算 alpha 轮廓，保留两像素过滤余量，不在绘制或 Tick 中读取像素。复用 `ColdSteelStaffIcon` 的现有轮廓和转向尺寸函数。

背包、仓库与拖影使用相同的尺寸函数和中心偏移；F 转向只交换方向，维持缩放倍率。装备槽按自己的图区等比拟合，不把背包 1×3 的长宽当作装备槽尺寸。紧凑、矮窗沿用现有槽高和字体，不增加新行或新面板。
