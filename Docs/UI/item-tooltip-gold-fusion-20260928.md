# 物品浮窗文字暗金融合 · 2026-09-28

用户要求：结合冶炼台字体颜色方案的分层思路，对物品浮窗（白色鉴定详情卡）的文字颜色做暗金融合升级；
先研读 skill 与设计系统的既有暗金落地（HUD 淡金、改造台专属金卡），保持同一套克制口径。

## 依据

- 设计系统 §1（v2.19）：金只作克制装饰，不批量染金，游戏语义色不变；全局色以 `ColdSteelUIStyle` 为单一来源。
- HUD 淡金（2026-09-27）：`HUDGold #C7AA70 / HUDGoldLight #E8D39A / HUDGoldDim #756447`，用于身份与交互强调。
- 改造台专属金卡（2026-09-27）：暗金底金边、标题淡金——"标题金、正文中性"是该轮确立的文本分层。
- 冶炼台字体方案（本日核查）：三层灰阶正文 + 语义色只管状态，文字零硬编码、全走共享常量。

## 对比度实测（WCAG 相对亮度，sRGB）

浅底文字金不能直接用 HUDGold：对卡面 `#EEF0F2` 仅 **1.95:1**（头带 `#E2E6E9` 1.78:1）。
取色定为 **`HUDGoldDim #756447`**：对卡面 **5.01:1**、对头带 **4.56:1**，12px 元信息行也达标，
且是 HUD 暗金三件套的既有加深档——不发明新色相，符合"优先消费现有主题值"。

## 改动（全部集中在 `ColdSteelUIStyle.h` + `ColdSteelItemTooltipLayout.cpp`）

新增两个常量，退役一个：

| 常量 | 色值 | 用途 |
| --- | --- | --- |
| `ItemTooltipGold` | = `HUDGoldDim #756447` | 身份层文字：区块标题（核心属性/装备对比/进阶详情/完整装备对比）、卡片标题（锻造工艺/枪械装配工艺/附魔效果/改造项目）、折叠区标题（改造与附魔/详细参数/物品说明/特殊性质）、主卡分区标题（战斗参数/物品信息/采集参数，14px Medium）、头部元信息行（类型 · 稀有度 · Lv · 强化，12px） |
| `ItemTooltipGoldRule` | `#C7AA7059`（HUDGold 35% alpha） | 全部分隔线：实线规则、虚线规则（SItemTooltipDashedRule） |
| ~~`ItemTooltipRule`~~ | ~~#CDD2D5~~ | 灰色分隔线退役；关闭按钮悬停底改用中性 `Gray(204)`（同按下色） |

保持不动（明确边界）：

- 物品名标题（20px 深灰 `ItemTooltipText`）——可读性优先，金不上正文。
- 正文、摘要网格标签与数值（`ItemTooltipText/Secondary`）。
- 正/负语义色 `ItemTooltipPositive/Negative`（游戏语义，设计条款"语义色不变"）。
- 特殊性质五色（ItemTrait*）、展开指示箭头三色、位置行/口径说明/页脚提示（次级灰）。
- 卡面/头带底色不变——本轮只动文字与线，白卡专语义条款继续有效。

## 分层口径（与冶炼台一致的表述）

金 = 身份与结构（标题、元信息、分隔线）；灰 = 内容（正文、数值、辅助）；绿/红 = 语义（增益/代价）；
青/紫/深青 = 特殊性质类别。四层互不越界，后续新增行按层取色，不再新增字面量。
