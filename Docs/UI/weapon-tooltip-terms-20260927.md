## 本轮发现

浮窗的数据正文、核心摘要、改造汇总、改造总览与强化预览各自硬编码属性名。同一伤害结构分别显示为武器总伤害、自卫总伤害、普通攻击总伤害、满拉武器伤害；攻击间隔与开镜耗时存在秒／毫秒混用。弓只有四项摘要，没有对应的攻击公式，改造汇总还会落到枪械分支。弓的分类正文曾显示内部标识 weapon_bow。

## 修改

- `bows.json` 将 `bow_dark` 显示名改为“猎手长弓”。已有 `ReloadProfile` 会将目录名称同步到物品实例，下次用户加载时应用；不改 ID、存档或物品状态。
- 新增 `ColdSteelWeaponText.h` 作为共同字段词表。浮窗、改造及强化相关显示引用它，布局层不再二次改写“当前伤害”为其他标签。
- 浮窗枪械／弓／近战／工具／长杖使用相同伤害行生成函数，依次列总伤害、基础物理及实际存在的附加分项。基础与附加继续使用原有伤害评估函数。
- 弓使用六项摘要：武器总伤害、拉弓耗时、搭箭耗时、最大飞行距离、体力消耗、开镜耗时。加入攻击与强化公式、弹药修正后伤害、满弓数值条件；图标使用现有长武器图片区。
- 弓改造汇总读取真实 Bow 倍率，显示伤害、拉弓、搭箭、弹速、体力、保持、晃动、散布和开镜的实际变化。
- 总伤害保留满弓数值，阈值与倍率说明读取实际蓄力函数；未更改战斗数值。工具改造中的原“自卫伤害”效果名改为“基础伤害”，与倍率作用对象一致。
- 普通攻击间隔及开镜耗时统一毫秒，弹速统一 m/s；弓的拉弓耗时不是攻击间隔，保持独立字段。有效射程与最大飞行距离使用不同比较键，避免比较不同含义的距离。
- 伐木伤害仍在采集参数单独显示，修正其比较收益方向为越高越好。工具目录的采集说明改为当前实际树木生命值／矿物命中次数机制。
- 删除把命中改造基准误写成“标准树所需挥砍”的行：实际砍倒次数还取决于树种、尺寸和剩余生命，不能在物品浮窗虚构一个固定次数。
- 在正式 UI 设计规则、项目和个人 UI skill 中保存固定结构、词表、单位与计算条件规则，供后续武器沿用。
