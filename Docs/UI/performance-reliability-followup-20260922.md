# 性能面板：15:08 导出问题的实现规划

用户已授权优化，继续先修面板可靠性。依据 `Docs/Performance/performance-export-analysis-20260922-1508.md`，本轮不改变武器材质、图标生成调度或画质。

- 保留现有 F6 UMG 抽屉、主题、自动换行、主体滚动区及输入逻辑，不增加新的弹窗或焦点入口。
- 原长帧栏目始终展示最慢 3 帧；同一快照提供超过目标预算、超过 33.34 ms、达到 50/100 ms 的累计计数，分级之间不相加。
- 后台保存最近 16 次达到 50 ms 的长帧，每次最多前 2/后 2 帧及 32 条相交事件。标注上下文未收齐、事件截断与尚未完成的 scope。显示最新 3 次，JSON 保留全部。与 10 秒窗口分开；清空/重新开始采集会清空历史，停止保留已有上下文。
- 线程数值旁说明发布边界不同，来源帧号/发布时间未知；保留原值，禁止自动固定平移。JSON 提供机器可读的来源与对齐状态。
- 图标子系统保留最近 32 条失败详情，包含完整配方、失败阶段、资源、原因、时间和帧号；原因上限 2048 字符并标注截断。历史容量不足明确标记，目录图回退状态继续沿用现有 Failed 集合。清空性能采样不清除真实业务失败状态。
- 失败详情放在原图标栏目，显示最近 3 条并提供全文提示；快照/冻结/异步导出均复制同一份值。不存在来源时显示未采集，不将其当成零。
- 新增项目可控阶段的计时：当前 World Tick、玩家装备信息采集、可见性更新和性能页刷新，补充周期性长帧的观测范围；这些是包含等待的主线程区间，不是完整 CPU/渲染归因。
- 文件范围：FPSPerformanceMetrics、FPSPerformanceEvents/Export、DevelopmentPerformancePanel/Diagnostics、ColdSteelWeaponIcons，以及已埋点的玩家身体入口。构建按当前编辑器状态安排；不自动运行测试或启动 UE。

实现和必要构建结果另记于 `Docs/Performance/performance-reliability-followup-20260922.md`。
