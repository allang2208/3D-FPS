# 交互开发面板 · 2026-09-14

交付范围：在游戏中使用 F6 打开开发面板，将现有天气控制合并为天气页，添加玩家前方的怪物生成页。沿用 `WeatherControlWidget` 的天气业务入口、`FPSGAMEPlayerController` 的菜单互斥、`ColdSteelUIStyle` 的主题。用户已授权实现；未要求预览或测试，由用户自行测试。

## 结构与布局

| 区域 | 内容 | 布局及滚动 |
| --- | --- | --- |
| 固定标题 | 交互开发面板、关闭 | 右侧停靠，保留左侧世界画面 |
| 固定页签 | 天气环境 / 怪物生成 | 两个等宽按钮 |
| 天气环境 | 当前场景、时钟、实际雨量、天气预设、自动天气 | 正文独立滚动；保留降雨前聚云与渐变 |
| 怪物生成 | 类型、数量 1–10、距离 3–15 米、结果 | 正文独立滚动；默认胖子僵尸、1 只、5 米 |
| 固定操作 | 生成、清除本面板生成的怪物、返回游戏 | 始终可达；清除操作仅作用于当前控制器记录的生成实例 |

宽窗面板宽 520px；小于 720px 的窗口使用可用宽度，四周 12px，面板高度服从视口。主体滚动，不整体缩放固定画布。冷钢共享玻璃、圆角与按钮样式，Noto Sans SC / JetBrains Mono，20/16/14/12px 字号；DPI 变化更新布局和字体。

## 数据与动作

- 天气仍只有 `AFPSWeatherManager` 一个权威来源；调用 `SetWeatherState` / `ResumeAutomaticSchedule`，不另建天气模拟或改变昼夜合同。打开时以 0.2 秒刷新实际雨量、时钟和聚云剩余时间，关闭时停止刷新。
- `UDevelopmentSpawnComponent` 管理可配置怪物目录与生成记录。目录包括现有三个怪物 Blueprint 和新胖子僵尸 C++ 类；类型的显示与生成都使用同一目录。
- 以玩家视角的水平朝向确定“前方”，按所选米数换算厘米。候选点保留在前方扇区；按怪物胶囊、脚下支撑、坡度、墙体遮挡和占用情况寻找地面位置，不在被阻挡时改成背后或强制挤入。
- 数量超过当前空间时允许部分生成并报告成功数。无玩家、无权限、缺失角色资源、无可用落点时返回原因，不报告生成成功。
- 只清除本组件本轮创建的实例；不操作场景已有怪物及自动刷怪器。清除不触发伤害、奖励或新的刷新。
- 胖子僵尸复用既有近战僵尸和 Behavior Tree 执行链，使用上一轮导入的四个动作与原蒙皮。新类补充死亡动画表现与行走播放比例，不改护士的默认表现。首版生命、伤害和命中窗口为可配置开发值。

## 输入与生命周期

UMG 宿主管理面板与页签，天气控件负责天气展示，生成组件负责世界操作。F6、Esc 和关闭按钮返回游戏；打开时关闭背包、改造及强化面板，停止持续开火和瞄准，获得鼠标与移动/视角锁。关闭释放本面板的锁并恢复游戏焦点；场景继续运行。

保留旧 `ToggleWeatherPanel` 与天气控件接口作为兼容入口，统一打开新面板。只在编辑器/Development 等非 Shipping 构建显示入口。销毁时清除定时器、UI 引用和弱对象记录，不销毁关卡原有怪物。

## 实际使用与实现

本轮增加了原生角色类、控制器组件和 UI 类；编译完成后，请保存当前工作并重启编辑器，再进入游戏使用面板。

1. 在非 Shipping 游戏中按 F6，或在鼠标可用时点击左下角“F6 开发面板”。F6 / Esc / 返回游戏均关闭面板。
2. “天气环境”保留晴天、多云、小雨、中雨、暴风雨与恢复自动天气。聚云等待和雨量渐变继续由现有天气系统处理，面板显示实际状态。
3. “怪物生成”默认胖子僵尸、1 只、前方 5 米；数量可选 1–10，距离可选 3–15 米。多只怪物在目标附近分排生成，朝向玩家。可切换护士僵尸、手脑和毒蛆。
4. “清除本面板生成的怪物”只销毁本控制器本轮记录的实例，不发放击杀奖励，不影响地图原有刷怪器。

生成器不另建 NavMesh；怪物追击沿用当前地图已有导航。后续移动故障修复已为 `DayNight_Lighting` 的 200 × 200 米开发区域补建导航，并要求生成落点具备适合怪物胶囊体型的导航覆盖，缺失时在面板显示原因，详见 [导航修复记录](../fat-zombie-navigation-fix-20260914.md)。胖子僵尸使用 `AFatZombie`，复用护士的近战/受击/Behavior Tree 通路，独立覆盖死亡表现。当前开发数值为 600 生命、25 伤害、65 cm/s 移速、1.00–1.18 秒命中窗口，后续可在派生 Blueprint 调整。其死亡播放专用动画并保留末姿态，15 秒回收；护士维持原布娃娃处理。

面板源码在 `Source/FPSGAME/UI/DevelopmentPanelWidget.h/.cpp`，生成目录及放置逻辑在 `Source/FPSGAME/Development/DevelopmentSpawnComponent.h/.cpp`，胖子僵尸在 `Source/FPSGAME/Monsters/FatZombie.h/.cpp`。天气控件原接口作为兼容入口保留，正常游戏只创建新开发面板宿主。

本轮只进行开发、接入及必要构建，未运行游戏、截图、视觉验收或回归测试。UI 表现、落点、动画和实战效果由用户测试。
