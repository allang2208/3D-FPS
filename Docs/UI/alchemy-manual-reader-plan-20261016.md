# 配方手册实体阅读改造

用户要求直接展示无底板书本，将文字与图片像装备魔法书一样印到纸张上；按住鼠标拖动翻页，上角书签直达首页／末页。本次授权为制作与接入，未要求预览或测试。

- UMG 宿主保留现有工作台控制器。透明阅读层遮挡下层点击；打开时隐藏管理面板／操作栏与背包，关闭恢复原状态。没有玻璃底、遮罩或底部按钮；B／Esc 放下，方向键仍可翻页。
- 私有三维预览沿用颜色＋覆盖率合成，书本等比适配可用视口。皮革封面和纸堆沿用已接入魔法书；新增两条带凹口的书签、柔弯纸页和纸张细节，独立 ManualV4 资产路径。
- 文字、成品／材料插图和工序示意在换配方／换页时合成到 2048×1536 纸张纹理，按左右页 UV 映射到真实网格。数据仍读取实际配方、物品与效果，不把生产数值烘死进图片。插图提前异步载入，拖动只改变纸页姿态，不重绘文字或读取磁盘。
- 右页按住向左拖翻下一页，左页向右拖返回；按住 0.16 秒并产生拖移后抓起纸页。松手越过 35% 完成，否则缓动回弹。失焦、关闭和捕获丢失取消拖页。左右书签分别跳首页／末页，边界不越页。
- 书签命中与纸页拖动共用捕获相机的投影，随窗口缩放。提示为横排轻文字，书签自身为真实模型，无额外按钮面板。
- 私有阅读只改变当前页；工作中的公共台面仍通过原有 Book 输入同步已确认页码。库存、炼制和存档事务不变。
- 关闭阅读取消拖动，销毁会话时释放委托、预览场景及纹理资源。沿用静止停止捕获、翻页 30 Hz 的有界刷新。
