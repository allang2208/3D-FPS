# 星髓长锋充能条

用户已选定横向圆角蓝色能量条与蓝焰设计，现授权接入。复用 `ColdSteelCrosshair` 中 `ColdSteelStarMarrow::Paint`，仍为只读 Slate HUD，不建立新输入层或抢占焦点；G 继续由现有充能组件处理。

画面为屏幕中央下方一条最长 360 px 的圆角能量条。透明素材来自认可设计图的独立主体；金属边框固定，内部能量和外缘蓝焰独立流动，少量蓝色火星向上浮。名称 `充能 [G]` 在左上，秒数在右上，采用共享中文与数字字体，均为单行。紧凑窗口按可用横向宽度收紧条长，矮窗保留准星与下方经验提示的间距；无滚动或点击区域。

数据只读服务端充能截止时间。30 秒按剩余时间从满条递减至空条；结束后 0.4 秒整体淡出，随后边框、文字和火焰全部隐藏。切武器、卸下改造或死亡立即隐藏，不把外观尾帧延长为战斗效果。释放失败与等待回执保留短暂文字反馈，平时不显示空条。

后续按用户要求加入四等分刻度：内部在 25%、50%、75% 位置绘制深色细分隔和冰蓝高光；下方按实际能量槽两端对齐标注 0%、25%、50%、75%、100%。已消耗区刻度转暗，右上同时显示剩余百分比与秒数。所有刻度和文字共用整体淡出透明度，不改变蓝焰材质和充能机制；制作与构建回执放在 `SourceAssets/StarMarrowChargeHUD20261103/QuarterTicksV2/`。

本地装备时异步预载 UI 母材质，每个持有者只创建一个动态材质。Paint 只更新进度值和实时秒数，不读取文件或重建控件；非本地玩家与专用服务器不加载此 HUD。EndPlay 取消请求并释放引用。原三维剑身蓝焰、扣魔、伤害和联机规则沿用现有实现。

来源与制作脚本保存在 `SourceAssets/StarMarrowChargeHUD20261103/`，素材使用内置 image_gen 从认可图提取，提示词为该目录 `sprite-prompt.txt`。资源保存与必要 Editor 构建分别记录；按用户规则不运行游戏、截图、回归或视觉验收。

2026-11-03 用户反馈“只有刻度、没有背景图”：当前运行日志明确记录该 UI 材质的 SM6 编译失败，原因是火星位置变量使用 HLSL 保留字 `point`。制作源将其改为 `sparkPosition`，`ShaderFixV3/repair_hud.py` 只更新现有材质的 Custom 节点，不重导图片或改变能量条布局。材质编译请求之后调用引擎的 `Editor.AsyncAssetCompilationFinishAll`，等着色器编译完成后保存，避免把异步任务刚提交误当作编译完成。原 `install_hud.py` 同步采用此步骤。修复资产落盘记录为 `SourceAssets/StarMarrowChargeHUD20261103/ShaderFixV3/delivery.json`；运行时视觉效果仍由用户体验。
