# 改造品阶与镇魔符文

用户已授权制作及接入；未要求测试，由用户体验。

枪匠中央改造区沿用横向滚动、左部件栏、右侧数值汇总和固定应用按钮。选项按「通用改造 → 特殊改造 → 传说级改造」分组，组内保留目录顺序，原厂选项位于通用组首位。空组不显示；有传说选项时新增红色传说分栏。各分组标题随横向内容滚动，紧凑布局沿用现有重排，增加标题所需高度。

原有金色卡片统一显示「特殊改造」，祥云与山岳在唐刀、镇岳上同为特殊。传说卡片使用共享主题中的暗红底、朱红边框和浅红文字。选中/已安装仍使用现有绿色状态条；品阶不替代安装状态。灰阶图标和共享图复用规则不变。

镇岳剑身Ⅱ新增专属「镇魔符文」，与同槽其他符文互斥；使用原有草稿、应用及物品存档事务。暴击率增加25个百分点；实际攻击暴击触发15秒随身八卦阵，重复触发刷新。半径15米，阵内敌方怪物承伤乘1.25、移动速度乘0.5，同类阵法不叠加。离开范围、结束、切换装备或死亡解除。剑身使用金色太极八卦主印、沿刃方向的符线；阵法使用同源八卦结构。
