# 食物腐败卡片接入

2026-10-15。范围为现有空间背包、装备背包夹层、仓库及容器复用的库存卡片和物品浮窗；不新增面板或交互入口。

- 数据由权威食物生命周期提供。目录 `spoilDays`：四种生肉 3 个游戏日、四种熟肉 4 个游戏日、普通面包和法棍 8 个游戏日；面包优先于熟食通用规则。饮料和药剂不变。
- 共用 UMG 宿主的 Slate 画卡函数，在卡片底部内侧留出 7 px 腐败条。填充为已消耗寿命，随腐败程度由共享 Success、Warning、Danger 语义色过渡。
  - **2026-10-17 用户变更：** 条改为显示剩余鲜度，满条绿色随时间缩短，颜色仍按同一阶段转黄、红；数据字段仍为已消耗寿命，卡片与浮窗绘制时取 `ColdSteelFoodUI::Remaining()`。本项取代上文“填充为已消耗寿命”的方向，见 [食物腐败条改为剩余鲜度](food-spoilage-bar-remaining-20261017.md)。
- 1×1 卡片显示细条；悬停／固定详情只显示同一进度条，不再显示倒计时或百分比文字。名称保持顶部单行，堆叠数向上避开腐败条，图标在剩余空间等比绘制。
- 模型变更重建现有展示缓存；可见腐败物品只按秒更新缓存并使画面失效。浮窗按秒只更新同一进度条，不重建控件、不加载图标、不重复解析物品介绍。关闭后停止这些更新，沿用现有 OnChanged 解绑。
- 卡片与浮窗只读，不改实例寿命、库存提交、焦点、拖拽、命中、关闭或视口约束。已到期但尚待权威结算时保留红色最低填充，不误报剩余寿命。
- 新增腐败食物为不可食用材料，1×1、最多 10 份／堆；本批采用中文文字兜底，不新建图片或模型。转换数量与原子事务由玩法层负责。

本分支仅落盘目录及 UI 源码。构建和用户授权的隔离回归由主任务统一执行；未进行 UI 实测、截图或渲染。
