# 木工台切割与方向调整 · 2026-10-13

## 目标与接入范围

加工途中能随时切回自由调整，保留工件和切口，再从当前木板位置继续切割。复用木工系统、现有 V6 台锯和冷钢面板，不重建资产或改配方、损伤与完成阈值。

## 布局与主题

- 保留顶部项目、角度、时间和底部清除率、损伤、提示、操作区；沿用当前宽窄屏断点和整枚按钮换行。
- 准备阶段主按钮为“进入切割”；加工阶段保留“完成加工”，旁边为“调整方向 · 空格”或“进入切割 · 空格”。短文案单行横排。
- 沿用 ColdSteelUI 玻璃、字体与 36 px 按钮。调整时灰白虚线显示落刀位置，切割时继续显示红色锯口高亮。

## 状态与动作合同

| 状态 | 木板与锯片 | 时间 | 输入 |
| --- | --- | --- | --- |
| 初次准备 | 锯片下降，木板自由移动、旋转；未切削 | 未计时 | 拖动；Q/E 1°；Shift+Q/E 0.25°；空格或主按钮进入切割 |
| 切割中 | 锯片升起、运转；移动或旋转均按扫掠范围切削 | 只累计切割时间 | 保留原操控；空格或按钮切回调整 |
| 加工中调整 | 锯片下降，不阻挡、不切削；保留掩码、损伤与撤销记录 | 暂停 | 可反复移动、转向；空格或按钮继续切割 |
| 结束/退出 | 沿用原结算与生命周期，恢复台锯静止展示 | 冻结 | 沿用领取、重做、返回 |

进入切割会立即切除锯口覆盖的木料，不会重置工件或刷新时限；提示明确提醒观察虚线再进入。切割中仍可细调方向，并正常计算损伤。松开鼠标或切换状态结束当前一刀，既有废料脱落和关键连接判定保持。

## 数据与生命周期

- UWoodworkingSystem 继续作为唯一状态来源，复用电机开关表示切割/调整。累计已用切割时间，运行时只增加当前切割段。
- UI 使用既有 10 Hz 文本更新与事件驱动布局；无新增资源同步加载。锯片调整仅改现有子组件相对高度，异步装载完成后继承当前状态。
- 三种模式沿用现有材料来源、领取时一次扣料与发放、结果和撤销规则；不增加存档字段。
