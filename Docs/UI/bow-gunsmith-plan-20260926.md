# 弓的五槽改造接入

用户已授权制作并接入，完成后汇报；不启动游戏或额外验收。使用当前木质长弓、V7 裸臂、V11 动作和 V12 木质瞄具。

完成记录见 [木弓五槽改造 V13](../Weapons/dark-bow-modular-v13-20260926.md)：模型/贴图资产已保存，C++ 后台构建成功；未进行游戏测试。

## 栏目与结构

沿用 M4GunsmithWidget 的冷钢三栏布局、宽窄窗断点、字体、固定操作区及滚动容器。左侧按弓身、握把缠带、弓弦、箭台、瞄具排列；中央显示独立装配模型并支持旋转和缩放；底部选择件；右侧显示当前/草稿实值及所选件说明。弓不显示枪械弹匣、换弹和后坐力行。

## 部件与初版选项

弓胎保留连续木体；中心握把绳拆成独立网格，弓梢与弓臂绑绳归弓身。原装弦仍由两段实时端点驱动。新增贴合弓侧的实体木箭台；箭矢独立使用 arrow 槽，不作为改造栏目，箭种沿用箭袋。

首版每槽保留原装：弓身增加强拉调校（保留原装几何）；握把增加棕色蜡麻缠带；弦增加细弦；箭台增加包皮承托；瞄具增加拆除选项。目录同时记录外观、数值与图标。仅调校而没有新几何的选项明确说明沿用原装外形。

## 数据与状态

新增 bow-gunsmith.json，复用 gunsmith_parts 作为唯一持久化选择。UGunsmithSystem 负责槽位、选项、倍率及草稿；Bow 视觉解析生成临时表现数据，不将草稿写进真实装备。选择/撤销更新独立预览；应用经现有 CanApply 和 CommitState，一次保存选择，再由角色装备刷新生效。关闭未应用草稿恢复当前配置。旧箭台键迁移为 arrow，新增 arrow_rest 才是真正的承托件。

伤害与拉满耗时纳入现有共享武器公式；箭速、搭箭耗时、满拉体力、保持时间、摆动及腰射散布使用同一份弓改造倍率。ADS 继续由实际针尖位置解算，拆除瞄具时使用原有无实体瞄具分支。满 ADS 随机散布为零的行为不变。

## 预览、图标与生命周期

所有静态展示共用弓装配入口和实际材质，隔离于玩家持弓对象。资源异步加载，过期回调通过配方键失效，面板关闭取消请求并释放组件。动态装备图标接入已有有界队列、材质/mip 准备、回读和缓存；配方键包含部件选择和外观字段。目录 PNG 保留为回退。配件图标由实际模型离线制作。
