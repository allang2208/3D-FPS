# 木工台缺陷修复

范围：统一背包/附袋/主仓库扣料；禁止普通制作接口直接产出木工装备；断线解除遗留请求锁；同步铁匠抽屉动画与输入门禁；准确显示 97.5% 阈值；实景切口超预算时保留加工并切换平面台面；保存、恢复未完成工件。

恢复约定：投入材料与初始工件同时保存。加工中定期保存切口、角度、撤销和耗时；主动离开保存并暂停。完成、失败、领取和半数退款仍走既有结算。未完成工件可继续或主动废弃，不重复扣料。

制作边界：保留其他会话修改；只做必要源码修改、后台 Editor/Game 构建与落盘。不启动 UE、游戏或测试，不宣称实景或联机验收通过。

## 本轮实现

- 材料计数和扣除统一使用背包、附袋（Place 5）及主仓库。木工专用配方在普通制作的客户端入口和权威准备入口均被拒绝。
- 未完成工件使用原有存档字段中的版本化进度载荷，兼容旧版原始切口数据。保存木板位置、角度、撤销状态、切口与耗时，不改变成品和实付材料快照。
- 加工期间每 5 秒尝试保存变化，暂停/关闭时立即保存。保存进度不重新装备角色；保存失败保留工件并显示原因。突然退出恢复最近一次成功保存的进度。
- “暂停并返回”及 Esc 保留未完成状态；“结束并返回”按现有指标结算。暂停工件在管理面板可继续加工，也可主动废弃返还逐项向下取整的一半材料。
- 联机恢复使用 wood.resume 事务，沿用服务器回执；断线清除本地遗留请求锁。关闭后迟到的开始回执将服务器工件暂停。
- 选择面板沿用铁匠 4/s 与 EaseSmooth 动画，背包到位后展开；关闭与背包一起移动，过渡期间禁止按钮操作。配方继续使用横向下拉选择。
- 清除和损伤要求统一保留一位小数，法杖显示 97.5%。切口网格超预算会暂停锯子，切换到同一切割数据驱动的平面操作界面，不据此判定失败。
