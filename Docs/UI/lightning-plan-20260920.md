# 闪电迁移与技能页接入

- 入口：现有技能抽屉的全部／主动／魔法分类，位于冰锥之后；可点击详情、拖入混合快捷栏，旧绑定不变。F6 技能调级纳入闪电。
- 复用 ColdSteelSkillPage 的 Slate 卡片、共享冷钢主题、固定页签／返回与滚动区；窄窗沿用现有数据行重排，不增加弹窗或输入模式。
- 图标：蓝紫电弧主体、拉丝银六边框、石墨底，由 skills.json 同时供列表、详情、拖影、快捷槽与升级通知读取；来源与恢复脚本同本轮作者目录。
- LightningStats 为施放快照与当前／下级效果唯一数值入口；展示主目标伤害、魔攻／智力系数、目标数、逐跳衰减、射程、锁定容差、传导距离、眩晕、消耗、起手冷却、感电和过载。
- 输入：单次按键锁定准星附近可见敌人；左手临时冲突排队一次、不扣费；双持长期占手立即拒绝。目标不存在、超距、被遮挡、缺蓝或缺资产不扣资源。有效起手扣蓝并开始冷却，接触帧复查原目标，失效不改锁其他目标。
- 冷却、进度通过状态模型事务保存；旧存档只补闪电等级1及冷却字段，升级不重置其他技能。不保存进行中的动作、电弧或怪物感电。
- 快捷槽复用缺蓝变暗、冷却和左手提示；显示锁定失败／等待左手／施法。图像由 UPROPERTY 持有，关闭时沿用既有 Slate 释放与焦点机制。
- 仅制作、资产导入和必要构建；未授权运行测试、PIE 或验收截图。
