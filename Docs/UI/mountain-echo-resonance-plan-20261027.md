# 山鸣弓弦共鸣印记

- 入口：装备山鸣弓弦的高地长弓，沿用主 HUD 的菜单、鼠标和翻越隐藏规则；实物瞄具与 ADS 不隐藏印记。
- 布局：准星中心下方，拉弓进度条再下移 24 px；三枚山峰菱形横排，中心间距 26 px，使用 HUD 像素换算。没有文字、交互、输入焦点或独立面板。
- 数据：直接读取同一武器实例的服务器复制弦鸣层数。零层显示暗金轮廓；获得一层时该印记短促增亮；首次到三层时扩散金环和碎光，之后柔和呼吸。消耗、到期、死亡及换装仍由原有游戏逻辑清空。
- 状态所有者：BowMountainEchoComponent 保存仅本机表现时间，不另建技能层数或存档字段。Paint 只读取状态与绘制，不加载资源、不写数据、不启动计时器。
- 生命周期：组件结束时取消异步资源请求，切换装备时释放缓存；HUD 无委托、额外 Tick 或动态控件。
- 世界特效：弦影箭使用独立金色材质、箭头光核和流动金丝；撞击使用短闪、扩散环与金色火星。命中复制位置与法线，短暂保留箭 actor，远端客户端也能播放。仅视觉效果，不增加范围伤害。
- 交付：后台制作、导入保存、必要 C++ 构建；用户自行进行游戏内效果与联机测试。
