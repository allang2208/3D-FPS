# 体素建造工具栏规划

- **目的**：在世界内选择木材／石头并放置或移除 20 cm 方块。`V` 进入／退出；保留 B／Tab 原有背包键，不占用鼠标视角。
- **结构**：自由建造标题 → 当前材料／刷子 → 可放置／拒绝原因／保存结果 → 操作提示。仅建造模式可见，无页签、虚假库存数量或商品按钮。
- **布局**：右侧下部窄工具栏，与准星保持距离；宽度不超过视口可用范围，窄窗缩短提示并允许换行，矮窗减少边距。信息按容器垂直排列，不缩放整张固定画布。
- **视觉**：`ColdSteelUIStyle` 黑灰背景、银白正文；成功、拒绝分别用主题 Success／Warning。Noto Sans SC，16 px 标题、14 px 正文、12 px 提示，遵守点数换算；无新图标捕获任务。
- **数据**：材料来自 Palette；刷子与提示来自 VoxelBuildComponent；格距和放置／删除数量来自 VoxelBuildWorld。控件只显示，编辑与保存由模型完成。
- **输入**：鼠标左键放置、右键删除；1／2 选材料；滚轮切刷子；R 旋转墙面；中键取样；Ctrl+Z 撤销。V／Esc 退出并吞掉退出事件。菜单打开时退出建造；释放原射击／瞄准状态，建造鼠标事件不穿透成枪械操作，Ctrl 在建造中不触发滑铲。
- **状态**：准备世界、无命中、超距离、已占格、无支撑、角色阻挡、资源未生成、保存失败、成功。自由建造不扣背包材料，后续 Crafting 接入须单独定义扣料与跨存档提交规则。
- **生命周期**：控制器拥有建造组件；组件拥有显示控件，结束时移除；HUD 内容仅在状态改变时更新，布局随窗口改变更新。
- **范围**：新增 `Source/FPSGAME/Building/`，控制器只增加组件与输入转发。按用户规则不执行 UI 自测或预览。

## 预览、自由位置与支撑提示升级

- 建筑预览由独立可见 Actor 持有，建造期间持续显示；有效为绿色，无命中、重叠或缺支撑为红色。预览显示实际刷子体积，判定与提交使用同一位置；本条指游戏内预览功能，不启动应用做截图验收。
- 每次 V 开启建造都默认吸附；F 在体素吸附／完全自由位置之间切换。自由模式保留 20 cm 方块尺寸，允许连续世界坐标，尺寸与旋转规则不变。控件显示当前模式与 F 的操作含义。
- 原工具栏 Selection 增加模式行并将材料与数量合并成一行，Status 显示支撑拒绝原因或横向支撑路径长度（米，最大 2 米）；Controls 增加 F。继续复用 ColdSteel 字体、字号与背景，矮窗压缩快捷键文案并按可用高度约束工具栏。
- 显示模型由 VoxelBuildComponent 提供，支撑来源为 VoxelBuildWorld 的统一支撑图；UI 不修改存档。保存 v2 增加带原点和稳定 ID 的自由体素体积，v1 格坐标建筑仍读入零原点。
- 单机自由建造，不显示材料扣费或虚构公斤承重值。沿用旧 Godot 的地基锚点、向上传递、横向 2 米跨度与拆除保护规则；未接入建筑耐久或受击自动坍塌。
