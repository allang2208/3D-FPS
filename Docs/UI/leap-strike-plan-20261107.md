# 跃击面板接入

- 入口：技能面板的全部/主动页，在连斩旁添加跃击卡；点击进入详情，拖动沿用快捷栏 Q/E/X/1–0。F/G 专属槽保持原有规则。
- 结构：银框暗底的跃锤人物图标、技能名、双手锤限定标签、三阶段简述。详情只说明蓄力 0.5 s、固定腾空 0.75 s、可达落点与落地范围打击。
- 本轮不展示等级对照、修炼条、训练卡、伤害数值、冷却或资源费用。
- 布局：沿用现有列表滚动、详情返回及冷钢公共字体/玻璃样式。短标签横排，长说明按可用宽度自然换行；图标已含银框，不追加美术边框。
- 数据：skills.json 定义、MasteryDefinition 只读缓存、技能存档迁移；运动参数由 LeapStrikeMotion.h 统一定义。快捷栏只查询状态，不逐帧求解路径或重建面板。
- 状态：未持双手锤、动作占用、非地面、动作资源未就绪、蓄力/腾空/收势；无可达目标在按键时反馈。
- 资产：SourceAssets/LeapStrike20261107/Icon 与正式 Content/ColdSteelData/Skills；恢复入口 Tools/UI/prepare_cold_steel_skill_icons.py。
- 默认后台完成，不启动 UE、不截图或运行测试，交由用户体验。
