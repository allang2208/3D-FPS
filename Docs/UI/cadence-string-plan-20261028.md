# 疾律弓弦接入

> 历史方案；当前实现以 [cadence-rhythm-v4-tuning-20261028.md](cadence-rhythm-v4-tuning-20261028.md) 与发布清单为准。退役实物文件的恢复位置见 `Docs/Publication/HighlandBow20261028/archive-manifest.json`。

用户已确认概念图和数值，并要求叠层特效放在山峰印记同一位置。本轮为实际游戏接入，不运行游戏、测试或验收。

## 布局和状态

- 复用 `ColdSteelBowResonance`，中心下方 `TrackY+4`，160×53.3px；与山鸣按弓弦槽互斥显示。窄窗沿现有缩放规则，经验信息沿用136px避让。
- 疾律使用独立五段银金细纹透明贴图，逐次节拍点亮五分之一；无层暗显、满层白金呼吸，每次成功节拍有短促辉光。贴图和MID由装备变化时异步创建，不在绘制时加载。
- 左上既有状态栏显示单个「律动」图标、1–5层和4秒计时环；满层名称「律动·合拍」，五道刻纹全亮。状态栏布局、字体、悬停和滚动归属保持共用规范。
- 改造台使用实际模型制作的中性灰阶金属框图标；常驻卡片仅拉弓速度+20%，条件效果写入绿色特效段。

## 数据和玩法

服务器拥有实例、层数、到期时刻和状态修订号，整个状态一起复制。普通节拍放箭成功提交后叠层，不依赖敌人命中，不从贯穿或附加弹体重复叠层。

每层拉弓速度+6%，最多5层，4秒刷新；加到既有装备拉弓速度加算区。原有节拍下一次拉弓速度+25%的独立计时因子保留。每次开始拉弓固定动作时长，避免途中Buff到期导致进度跳变。

满层腰射扩散−50%（含移动、腾空和连射扩散），物理伤害+20%（基础与附加物理一起，魔法不变）。箭矢快照及扩散先结算旧层数，再叠层或清层；第5箭完成叠层，后续箭矢受益。

失拍箭成功放出后清空；取消收弓不刷新，超时、换武器、拆弦、死亡、离场清空。临时状态不存档。两款传说弦为同槽选项，现有装备存档保存选项ID，不增设装备顶层稀有度。
