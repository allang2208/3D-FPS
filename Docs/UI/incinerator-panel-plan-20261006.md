# 焚化炉：物品销毁面板 · 2026-10-06

用户授权独立焚化炉、冷钢 UI 及隔离场景验证。复用 `ColdSteelWorkbenchHUD` 生命周期，不修改其他工作台资源，不新增产出、返还、燃料或配方。

## 结构、样式与输入

E 交互进入「销毁 · 焚化炉」。面板与背包等宽、零缝并排，沿既有 4/s 抽屉动画、UIOnly、移动/视角锁与关闭恢复。来源为随身物品（含夹层）、装备、主仓库、弹药袋；搜索及虚拟化列表使用实例身份。标题、数量和操作固定，内容滚动，名称省略时有全文提示，选中名称及确认正文完整换行。关闭/Tab 丢弃草稿；Esc 在确认页先取消，再关闭。

复用 `ColdSteelUIStyle`：黑灰玻璃、银白选中强调；Noto Sans SC 20/16/14/12px，JetBrains Mono 14px 数字；36px 控件，10/8/6px 圆角及 1px 细边，工作台模糊 5/13。DPI 变化才重排，库存 OnChanged 才重建条目，普通 Tick 不解析目录。危险提醒用共享 Danger，普通卡片不染红。

## 数据与结算

- 显示、数量、报价和提交均使用同一来源范围。普通物品以 InstanceId 选择，不合并同定义独立实例；弹药以 AmmoPouch 的弹种键与 int64 数量选择。
- 明确「查看销毁清单」后再「确认销毁」；清单列出数量、来源、装填弹药、已装配改造、强化与附魔，明确不可恢复、无产出和无返还。确认初始焦点放在取消。
- 任务目录和已查库存规则没有任务锁/绑定/不可销毁字段，不建立绕过规则。箱内物品先取出，未领取工件先领取。
- 已装备背包槽 14 若夹层或扩展格仍有物品，列明阻挡内容，要求先清空；不自动级联删除。遵守现有容量与校验契约。
- 只在明确确认时重读状态，复核 Generation、数量及完整实例内容，再通过现有 `CommitState` 保存。每份确认在保存前即消费，失败也需重新确认。关闭、来源改变或库存变化使确认失效。
- 完全销毁后清除对应快捷实例引用和活动生产工具引用；其余物品及独立弹药袋保持原样。改造数据内嵌在本体 Data，无独立返还记录。角色持久化沿当前本地档案契约，不新增共享世界库存或 RPC。
