# 武器与装备取消稀有度 · 2026-10-09

## 用户规则

武器、装备以后不分稀有度；稀有度只用于非装备物品。武器包括枪械、近战、弓、法杖和手持生产工具；装备包括防具、衣物、饰品、背包、盾牌、副手法术书及所有有装备槽的物品。判定取物品种类，不取当前存放位置。

## 数据与旧档

- 活动目录 `items.json`、`bows.json`、`staffs.json`、`production_tools.json` 移除上述物品顶层 `rarity`、`grade`。非装备目录保持原值。
- 共享 `ColdSteelItemRarity` 在目录加载、物品创建、档案恢复／提交与联机镜像接收时统一去掉装备顶层稀有度字段；不再赋值为“普通”。
- 旧档所有位置的装备均通过现有 A/B 存档事务迁移，包含背包、穿戴、夹层、仓库、储物容器和已登记地面掉落；本次不直接改写玩家存档文件。新目录若误带旧字段，运行时同样移除。
- 只移除顶层字段；保留实例、数量、位置、属性、价格、强化、改造配件、锻造／装配工艺和附魔。卷轴自身与嵌套附魔等级仍属于独立系统。

## 显示与交互

- 物品浮窗、武器图鉴、出征奖励卡不再为装备显示稀有度或遗留分隔符；奖励卡副行改为物品类型。
- 后续同日用户调整：装备掉落改为按数值强化等级区分颜色／高度／亮度，不按旧稀有度染色；未强化仍为银白。档位见 [强化掉落光束](../Art/equipment-enhancement-loot-glow-20261009.md)。非装备保留原有稀有度颜色与高度。
- 仓库按稀有度整理时，仅非装备按稀有度排序，装备归在无稀有度组内，再按类别／名称排序；按价值和类别入口仍可用。
- 冷钢主题及强化／改造／附魔的状态标记保持原语义。数据更新沿现有事件与保存路径，无新增 Tick。
