# 配方手册装帧与排版升级计划

用户反馈 V4 的书签、字体与书页粗糙、廉价；本次要求制定计划并直接实施。升级方向为精装炼金典籍：温润象牙纸、深棕墨、克制的旧黄铜、窄织带与清楚的中文书籍排版。保持无背景板和直接操作书本。

## 实施范围

| 部分 | 现状 | 本次制作 |
| --- | --- | --- |
| 书签 | 两片宽扁色块，粗边与大字 | 缩窄为有厚度、轻褶与弯折的织带；细密织纹、双缝线、小型黄铜扣；横排首页／末页，模型与点击区域共用尺寸 |
| 纸张 | 泛黄底色与外围矩形框，只有固定粗糙度 | 象牙纸、弱纤维／纸浆起伏、独立法线与粗糙度；低对比页边与书脊暗部；去掉整页矩形框 |
| 装帧 | 纸面近似平板，书口层次弱 | 重建本次可打印纸面和翻页叶的细分、弧度与薄边；补书脊压槽、页叠起伏、细封面包边；保留原封面纹样 |
| 字体 | 与游戏面板同一无衬线字体，大段同级文字 | 书内改 Noto Serif SC 派生的常规／半粗两档；标题、眉题、正文、参数、批注、页码分级，避免伪粗体 |
| 内容 | 产品与材料图像孤立，材料说明和规则混成一段 | 首页左页分成成品、材料明细、药效、产出；工序页固定编号、操作说明和参数层级；提示收至批注区，保留真实玩法数据 |
| 图文 | 低分辨率大幅简笔工序图 | 工序改为排版明确的编号条目；实际物品插图小幅配图并附数量；装饰只留细线与小型章记 |
| 展示 | 单一硬光，纸页起伏难读 | 沿用透明双捕获，调整方向光／环境光比例以呈现边缘和凹槽；不增加场景背景板 |

## 布局与交互合同

UMG 继续只渲染两页的实时内容，2048×1536 页纹理沿用现有开销；文字按像素到 Slate 点数统一换算。每页内侧留白大于外侧，正文正常横排，短标题、数量和页码不折行。每页最多三个工序；正文与批注分区，不以大量空行定位。窄窗仍等比显示书本，书签命中跟随相机投影，保留长按拖页、回弹、方向键及 B／Esc 关闭。

真实数据继续来自当前 `FAlchemyRecipe`、`items.json` 和共享物品效果。保留本轮开始前已加入的 `AutoBase`、`FreeBrewing`、`BottleHeat`、双向搅拌说明，避免用旧 V4 快照覆盖并行玩法改动。不修改炼制判定、材料扣除、联机或存档事务。

纸张／织物 PBR 和装帧写入独立 `ManualV5`；旧版本保留恢复。字体来自 Google Fonts 官方 Noto Serif SC，原始文件、OFL 与实例化脚本一起保存，运行用字体进入打包目录。重用的 evildeer 原书资产保持 CC BY 4.0 署名。

## 制作顺序与交付边界

1. 保存当前源码快照，制作字体、纸张／织带纹理与新版书本几何。
2. 重排实时页内容，保持既有交互并将书签命中尺寸与模型合并为同一契约。
3. 后台导入并保存独立资产，接入真实运行路径与打包设置，完成必要 Editor／Game 构建。
4. 交付制作源、计划、保存与构建回执。用户未要求截图、运行、测试或验收，故不自动执行；观感与操作由用户确认。
