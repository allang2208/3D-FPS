# 开发工具 · 基本调参

## 目标与布局

在现有 F6「交互开发面板」新增「基本调参」页签，完成游戏接入。沿用天气环境、怪物生成页和打开／关闭输入入口，新页默认显示在首位。结构为固定标题和三页签、滚动调参区、固定「全部关闭」及返回游戏按钮。

调参区依次为无敌、秒杀、无限备弹、无限魔法值、魔法／技能无 CD。每行包含名称、说明和已开启／已关闭按钮。宽屏复用现有 520px 面板上限，窗口四周保留 12px；窄窗服从实际视口。内容宽度不足 360px 时开关移至说明下方，矮窗只滚动正文，不整体缩小画布。

外壳、分区卡片、字体与按钮均使用 `ColdSteelUIStyle`；中文为 Noto Sans SC，20／16／14／12px 四档按共享点数合同换算。每行卡片共用外壳的背景模糊，无新增图像或字体资源。

## 数据与业务

`UDevelopmentTuningSubsystem` 是单机当前 GameInstance 的唯一开关来源。开关不加入角色存档，关闭面板及重生保留，结束游戏实例后重置；未手动覆盖时保留 DayNight_Lighting 原有无限备弹默认规则，手动关闭可覆盖该规则。

| 开关 | 实际入口与语义 |
| --- | --- |
| 无敌 | 玩家 TakeDamage 在伤害事件之前拒绝伤害；血量组件免疫查询同源，保留独立闪避逻辑 |
| 秒杀 | 护士／胖子、手脑、毒蛆受伤入口对玩家有效命中使用目标剩余生命值，保留死亡、布娃娃、奖励与掉落 |
| 无限备弹 | HasInfiniteReserveAmmo 读取调参状态；现有换弹事务补入弹匣且不扣背包弹药，保留弹匣容量、射击消耗与换弹时间 |
| 无限魔法值 | 模型显示有效满魔法，施法资源判断放行且不扣实际存储的魔法值；关闭后显示原有魔法值 |
| 魔法／技能无 CD | 开启时立即清除已有主动技能冷却，新施法不产生冷却；当前主动魔法为火球，保留凝聚、发射、飞行与收手流程；闪避目前无独立冷却，不取消其动作与体力消耗，也不影响药品或武器射速 |

按钮直接调用子系统动作，OnChanged 更新当前页，不重建控件、不改变焦点及滚动位置；模型同步通知 HUD。无本地玩家或非单机时禁用动作并显示原因。全部关闭一次发布五项关闭状态，包括覆盖场景无限备弹默认。

## 生命周期与范围

UMG 宿主复用现有控制器输入模式、光标、移动／视角锁定与关闭防穿透。Construct 绑定调参通知，Destruct 解绑；控件保留原有天气刷新计时器，新增开关不增加轮询计时器，Tick 仅适配布局。无新弹窗或悬浮提示。

新增文件为 Development 目录下调参子系统、状态模型调参桥接、UI 基本调参布局文件及本文。局部接入现有开发面板、角色无限备弹及伤害入口、血量组件、三类怪物伤害入口、火球模型及施法条件。不改变物品占格、存档结构、技能成长配置或素材。

必要构建使用项目 `Tools/Build/Build-Editor.ps1`，若编辑器仍打开则保留用户进程并说明构建限制。未要求预览、检查或测试，由用户自行测试。
