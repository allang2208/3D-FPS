# 技能快捷栏拖拽迁移 · 2026-09-14

来源：原 game-dev `src/ui/quick-bar.js:109-363` 和 `src/ui/skill-manager.js:585-619`。用户选择保留 UE 的 Q/E/X/1–4 七槽；E 优先交互，无交互目标再使用绑定；C 滑铲和左 Shift 短按闪避继续保留。

- 主动技能卡支持图标拖影；技能开始拖动时收起抽屉，让出快捷栏，拖放结束才释放 UI 输入。被动技能只可查看详情。
- 七槽均可放已接入主动技能（火球、闪避）或背包消耗品。快捷栏内空槽移动、占用槽交换；同一技能／物品实例唯一绑定。来自技能页／背包的已绑定内容再次投放时交换原位置与目标；未绑定内容覆盖目标快捷引用。
- 快捷栏内容拖出槽位松手只解绑；技能页拖出不删除技能；背包实体只有原背包丢弃规则能落地。Esc、关闭、窗口失焦取消拖动，不解绑。
- `ColdSteelStatusModel` 负责混合绑定、唯一性、交换、使用和 A/B 存档；新增版本 1 的七槽绑定表，旧四个物品槽映射到数字键，保留 Q 火球默认绑定。旧数组作为背包数字槽兼容视图。空绑定和零数量物品引用可保存。
- UMG 槽位与拖影复用冷钢主题、新图标和实际屏幕几何；技能页沿用现有 Slate 卡片及独立修炼卡片。维持七槽尺寸／位置与当前 DPI 行为，不引入新面板。
- 真实绑定变化和 OnChanged 更新图标；既有 HUD 时间刷新更新数量、施法状态和冷却。拖放以绑定快照和源物品实例判定失效，不因自然冷却／自动保存计数变化而中断。
- 拖动后释放鼠标与视觉层；取消时保留存档。必要原生构建后交付，不启动游戏或执行自测。
