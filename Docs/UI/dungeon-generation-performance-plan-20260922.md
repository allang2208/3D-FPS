# 地牢生成与常驻开销

用户授权继续实施；沿用性能页及加载页的现有布局、字体、滚动、焦点与取消入口，不新建页签。

- 性能页已有卡顿事件栏目增加生成、资源、网格与碰撞注册、灯光、宝箱、积液伤害的中文阶段名。事件随既有快照暂停和清空；单次生成累计信息不冒充当前帧窗口计时。
- 在现有环境信息正文追加当前地牢种子、生成状态、任务进度、模块数、实例化/独立构件数和最慢创建批次；无地牢时不追加。沿用正文换行与外层滚动，随快照冻结；明确与当前帧窗口无关，不新增操作或扫描。
- JSON schema 8 增加 `dungeon_generation` 数组，沿用原场景扫描获取当前生成器，不添加独立全场景扫描。保存实际种子、状态、模块/宝藏房数、唯一资源解析数、已实例化/保留独立的刚性构件数、任务进度、工作线程规划耗时、主线程阶段耗时与最慢创建批次。
- 尚在工作线程规划时不读取其正在修改的布局；未完成的数据用 null。网格与碰撞注册暂为一个含子步骤的阶段，不声称单独采集了物理 cooking。单个不可拆分任务可能超过帧预算；不以预算设置推算 FPS。
- 加载页在随机地牢准备期间持续显示，房间与碰撞完成后才结束。异步规划失败或资源缺失显示原因，保留取消返回入口。构建期间暂停角色移动组件，完成/取消销毁时归还原本开启的移动组件。
- 游戏世界默认每帧约 3 ms 创建任务；编辑器 GeneratePreview 保持同步，兼容已有地图安装脚本。线程只计算普通布局数据；Actor、组件和资源操作继续在游戏主线程。
- 重复刚性网格按材质、碰撞、投影设置与 40 m 空间组聚合。仅有有效 Nanite 数据的非流体构件进入 ISM；宝箱、危害、定位点独立。非 Nanite 构件保留原组件以保护 Lumen。
- 积液按玩家控制器枚举接触目标，保留每区独立伤害时钟、椭圆/矩形湿区、脚底高度、桥面和跳跃规则。关闭宝箱先求值闭合姿态再停骨骼 Tick；未来开箱需要先恢复 Tick。

本轮不主动进行运行测试或验收；源码构建与实际运行收益分别报告。
