## 后续：展开大理石使上方木材／石头卡片换行

用户要求排查打开大理石「其他构造」后，上方原本单行的木材／石头构造也换行。

- 源码原因：各分类共用一个 `UScrollBox`。原实现让滚动条随内容高度折叠／出现，UE的纵向滚动条作为水平兄弟槽占宽，且默认有2 Slate单位的四边外边距。轨道画刷默认也有8 Slate单位的期望宽度，单独设置6px滑块厚度不能约束它；DPI较大时会继续吃掉行宽。
- 另一处布局不稳定：展开任意材质都会重建所有网格。原 `UWrapBox` 未显式指定行宽，重建初始使用默认500 Slate单位，随后再等分配尺寸更新，已有分类也参与重排。
- 修复：固定预留6px滚动条，清除默认外边距及滚动内容内边距，轨道画刷宽度一起按DPI换算。网格创建及视口变化共用 `ConfigureBuildGrid`，显式按抽屉宽扣边框／边距／滚动条／子级缩进设置行宽。1040px抽屉预算为988px，八张卡含间距需984px；图片104²、卡宽116px、文字14px保持现有规格。
