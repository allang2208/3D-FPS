## 界面与交互

采用 `ColdSteelUIStyle` 的灰黑玻璃、银色边缘、字体与 36px 按钮。顶部为部件名称和剩余时间；左侧为粗/细加工、半径、撤销和重置视图；中部为真实掩模画布；右侧为目标缩略图、清除率、完整度、边缘贴合度和质量；底部为提示、开始、完成、领取与放弃。

左键连续削除，1/2 切换粗/细半径，滚轮改变可见圆形半径，中键平移，Ctrl+滚轮围绕指针缩放，Ctrl+Z 撤销上一笔。DPI 改变按共享物理像素规则重建布局；侧栏内部滚动，主画布按剩余空间适配；缩放/平移和半径使用同一几何逆变换，不依赖窗口分辨率。极小窗口的可读性尚未实机验证。

松键、离开画布/木料、失焦、Alt-Tab 和关闭均结束当前笔划并释放本画布捕获。打开时停止角色武器动作，平衡增加/释放移动与视角锁；关闭恢复之前的纯光标模式或游戏输入。工作台失效、掉落、离开记录或玩家离开 2.4m 的模型包围盒时退出加工。实际输入和距离体验尚未运行验证。

## 判定与计时

`WoodworkingMask` 的木料、目标、损伤三张有界二维掩模同时驱动显示和评分。笔划是线段胶囊形覆盖，避免低帧率/快速移动留下离散圆洞。目标轮廓仅作显示，照样能被削伤；红色表示实际受损目标像素。

每笔结束后可自动剥离纯废料连通块；任何含有剩余目标像素的块都不自动删除。撤销只恢复上一笔及该笔剥离的废料，消耗次数而不返还时间。超过主体损伤阈值立即失败；笔划结束或结算时关键锚点断连则失败。轻微损伤可保留并影响评分。

预览不计时，明确开始后使用单调实时时钟。切工具、缩放、确认关闭及暂停/切出窗口不返还时间；恢复调度时按真实截止时间结算。到时冻结当前状态，达标才成功。提前完成必须满足外围清除率；完整度、边缘贴合和清除率是主要质量指标，时间占小权重。

## 配置

`Content/ColdSteelData/woodworking.json` 在子系统初始化时读取一次。参数为首版占位设计值，可调整，不能视为平衡验收结果：

| 字段 | 当前值 / 合法范围 |
| --- | --- |
| maskWidth / maskHeight | 512×256；宽 64–768，高 64–512 |
| timeSeconds | 90；5–600 秒 |
| undoCount | 3；0–10，仅上一笔 |
| requiredClearance / maximumDamage | 0.98 / 0.12；清除率 0.5–1，损伤 0–0.5 |
| coarseRadius / fineRadius | 18 / 4 掩模像素 |
| minimumRadius / maximumRadius | 1 / 32；配置上限 64 |
| edgeBandPixels | 4；1–16 |
| integrityWeight / edgeWeight / clearanceWeight / speedWeight | 0.50 / 0.25 / 0.20 / 0.05；速度权重最多 0.1 |
| autoPeel / checkConnections | true / true |

`patterns` 最多 16 个，ID 唯一。每个图样含 `id`、`name`、`craftRecipe`、`outline`、`connections`：轮廓为 3–128 个归一化顶点，关键连接锚点为 2–16 个且必须位于连通目标内部。默认提供弓臂与法杖木芯。加载错误会阻止开始，不静默退回其他配方。

显示纹理为有界瞬态纹理，掩模改变时最多每秒提交 30 次；木纹缓存一次。组件/连接扫描只在笔划结束、初始化或结算执行，不扫描库存/JSON，不重新加载资产。
