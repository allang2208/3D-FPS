# 双手剑通用配重锤

用户授权先完成配重锤通用开发。沿用改造台「配重锤」栏目、冷钢主题、现有宽窄布局、选项网格、三维预览、右侧选中详情与总览，以及应用/撤销/保存行为；不新增面板和输入方式。

三款统一为陨星锤首、凝碧星核、疾星配重，属性取用户已指定的符文剑三款配置。共用同一份改造定义和同一组三维主体网格。每把剑仅维护安装位置、比例、材质主题和可选接口连接件。当前接入符文剑、寒晶剑；原装和所有握把继续沿用原配置。

旧 `ballast_hardened` / `ballast_rune` / `ballast_magic_orb` 分别对应上述三款，保持 ID 与现有 `gunsmith_parts` 存档结构。寒晶剑原有这三个选项的旧效果随统一改造更新，不追加兼具新旧属性的分支。选中详情、合计数值、技能施放和 Tooltip 继续由 `GunsmithSystem` / `MeleeWeaponStats` 计算。

符文剑复用现有银色材质和图标；寒晶剑使用实际共用主体加古铜材质实例及同一个接口件制作透明图标。配重与接口一起跟随握把的 `pommel_offset_cm`，恢复原装时移除接口并还原原材质。视觉缩放不改变技能判定距离或属性倍率。

共享外观目录为 `Content/ColdSteelData/shared-sword-pommels.json`，武器目录引用该文件并指定 `pommel_profile`。新增剑在近战目录注册后，只需增加自身适配配置，无需复制三套改造项目。

制作交付包含接口 FBX/GLB、可编辑场景、三张寒晶材质实物图标、材质实例、共享目录与装配源码。没有布局或反射结构变动。Live Coding 因动作数量限制取消后，经用户授权完成普通 Editor 构建并重开项目；构建日志为 `Saved/BuildEditor/build-20260920-100109.log`。未执行测试、截图或验收，由用户测试。
