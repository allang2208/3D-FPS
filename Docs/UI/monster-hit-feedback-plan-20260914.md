# 怪物命中反馈

阶段：修复并接入现有 HUD；不启动游戏或自行验收。

- 入口：715、其他枪械、符文剑和火球现有的实际伤害确认回调。保留原伤害公式和胖子僵尸 600 生命、25 攻击力。
- 数据：由怪物战斗组件只读提供名称、当前生命、生命上限；实际扣血成功后保存本次伤害和死亡状态。UI 不扣血、不推算击杀、不写存档。
- 布局：现有 UMG HUD 的 Slate 自绘层，在准星下方显示目标名称、生命条、当前/上限及本次扣血。280 屏幕像素宽；窄窗服从可用宽度，矮窗位置限在视口内。无按钮、无滚动、不获取焦点。
- 状态：无命中时隐藏；命中后显示 4 秒，最后 0.5 秒淡出；每次命中更新，切换目标替换；死亡明确显示“击杀”；背包/仓库/菜单开启时隐藏。命中反馈独立于是否持枪、是否正在瞄准，枪械准星继续沿用原条件。
- 主题：复用 ColdSteelUIStyle 的黑灰底、危险/成功色，中文 Noto Sans SC，数值 JetBrains Mono，14/12 像素字号。无需外部素材。
- 生命周期：玩家实例持有瞬时弱引用与伤害快照，HUD 只绘制；使用既有 Tick 对自绘层请求重绘，确保短时提示不会被 Slate 缓存吞掉；角色销毁后数据自然释放。
- 修改范围：MonsterCombatComponent 只读生命接口、FPSGAMECharacter 命中回调及数据、ColdSteelCrosshair 绘制、HUD 自绘刷新、NurseZombie 扣血诊断日志。
