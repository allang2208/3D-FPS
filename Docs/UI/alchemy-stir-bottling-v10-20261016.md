# 炼药拖动与装瓶 V10

针对用户反馈：搅拌拖动希望越过锅沿仍能继续，装瓶时缺少清晰的药液入瓶过程。

## 搅拌输入

- 初次按下仍需命中搅拌棒或可用药液，避免背景物触发操作。
- 按下后捕获鼠标，用锅面投影的两条轴计算鼠标绕锅心的角度。捕获期间取消锅沿半径限制；两侧 UI 区域也不会截断正在进行的拖动。
- 保留锅心死区与大跨度跳变过滤，穿过中心重新建立角度基准，避免突然翻向或凭空累计半圈。
- 静止发送零角速度，松键、丢失捕获、失焦或离开工作台仍停止。捕获中忽略额外按键点击，防止另一只鼠标键切换器具。
- 继续使用原 10 Hz 输入、服务端转速上限和输入租期；没有新增客户端工序结算。

## 装瓶

- 一次点击执行完整动作，共 4.6 秒：拿起量瓶和汤勺、浸入舀取、抬离锅沿、移到瓶口上方、倾倒、滴尽、回正、放回。末段留出短暂停稳后才由服务端结束本炉。
- 汤勺倒口固定对准量瓶实际瓶口，倾角从 35° 改为 65°。瓶子移至坩埚前方，倒口高于瓶口 13 cm，液流终点伸入瓶颈 1.5 cm。
- 液流半径从约 1.6 mm 增至约 3.5 mm，独立材质增强可见性。流柱按飞行时间逐段到达/排空，保留最后几滴，避免整段同时淡出。
- 勺中余液与瓶内液面由同一个流量积分驱动；瓶内液面比出液晚 0.16 秒开始上升，填充固定从瓶底开始。
- 勺中液面保持水平，倾倒时向倒口收缩。瓶内液体使用写入深度的材质，避免与外层透明玻璃互相排序时消失。
- 灌装声音改在实际出液时触发，迟到的状态不会重新播放整段开头声音。提示文字与当前有模型的动作一致，不再描述未制作的封口动作。
