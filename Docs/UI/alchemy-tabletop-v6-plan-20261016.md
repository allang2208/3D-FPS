# 炼药台面直接交互 V6

本次将已授权的炼药玩法转为直接点选台面物件，保留 V5 配方、手册与权威结算。后台制作和必要编译，不追加游戏测试、截图或验收。

## 台面交互

| 物件 | 操作 |
| --- | --- |
| 本炉材料模型 | 左键投入一份；需要研磨的材料右键选入研钵 |
| 研钵 | 选好材料后按住左键研磨，松开停止 |
| 锅内液面/搅拌棒 | 按住左键，在锅面绕圈拖动；方向和转量来自实际鼠标轨迹 |
| 符文加热环 | 左键加一档，滚轮增减火力，右键收火 |
| 沙漏 | 左键翻转 |
| 空瓶/长柄舀勺 | 左键收火装瓶；仍由玩家判断炼制程度 |
| 配方书 | 左键翻阅，保留书签、拖动翻页和 B/Esc 返回 |

使用当前物品定义里的 `world_mesh` 展示本炉材料，按模型包围盒缩放并落在实际台面。最多三件，异步预载，随配方切换；不把装饰瓶猜测成物品，也不另造一套材料模型。

命中从鼠标射线与当前模型局部包围盒计算，合并在建筑内的研钵/加热环采用作者坐标的局部区域，锅面按平面圆盘命中；选最近目标，支持旋转/缩放的建筑。屏幕大圆热区退出使用。俯视桌面镜头固定覆盖材料、手册和坩埚，避免镜头自动跟随导致拖圈方向偏移。

## UI 与输入

UMG 管理界面仍负责选配方、开炉、领取、作废退半。进入实景后不创建投料/研磨/调火/装瓶按钮；左侧仅材料余量与研钵选料，右侧仅温度、火力、药液观察。底部为只读悬停提示和 Esc 暂存提示，无操作按钮。

提示只说明被指物件及可执行操作/拒绝原因，不公布下一工序、配方目标或评分。悬停目标与点击共用一次命中方法；鼠标按下时重新取目标。状态小窗不拦截台面点击，阅读层仍独占输入。保留原快捷键作为可选辅助入口，统一使用同一可操作性判断。

左键持续研磨和搅拌在松键、失焦、捕获丢失、开书、返回、关闭时停止；不因材质轮廓或 UI 提示自己下发库存修改。所有操作继续经过现有服务器输入/批次事务。客户端只新增本地研钵选料与悬停状态，成本、评分、计时、保存与退料格式不变。

资产引用、源码落盘和 Game/Editor 编译分别记录；不把编译当成鼠标命中、画面或联机的实机验收。
