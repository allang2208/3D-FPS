# 区域地图

> 2026-11-17 归档说明：本记录中的测试/构建日期和结果为历史证据；本次整理未重新运行。地图任务的 Saved 临时目录及截图已移入 `trash/map-system-20261117/` 下的原相对路径，详见 [发布与归档清单](../Publication/MapSystem20261117/README.md)。 标记的最终共享语义与真实 UDP 结果以 [后续共享记录](map-marker-sharing-20261115.md) 为准，覆盖旧版本的“仅个人”说明。


M 从玩法打开当地地图。地图打开时键盘继续控制角色移动，鼠标用于地图交互，世界继续运行。玩家箭头逐帧更新位置和朝向，手动拖动或缩放后的视野保持在所选位置。M、Esc 或「关闭」返回原来的玩法或 Alt 光标模式。

固定顶栏放区域名和关闭按钮，中间为随窗口伸缩的地图。底栏的操作提示、定位与楼层选择按整项重排。使用一层共享冷钢玻璃、银灰线条、Noto Sans SC 文字和 JetBrains Mono 数字。正北与 HUD 的世界 +X 一致。

- 废弃设施按本机玩家在本局走过的位置揭雾，关图期间也记录。同一层里的医疗区、货运区等在首次走到时标名。可行走遮罩按 2 米格裁剪，脚下格和相邻格均检查整块范围的视线与角色阻挡，门边的脚下格细分至最多八分之一格宽，站在原地开门后也会更新；未配置遮罩的房间、起始区和跨层通道只揭开脚下格。未探索的几何、地标和楼层不显示，个人标点只能放在选中楼层的已探索区域。探索保存在本地会话，新一局重新开始。
- 设施楼层相对入口标注，按实际装配高度和可行走平台区分。地图自动跟随玩家位置及楼层，手动切层可浏览已探索的楼层，拖动或缩放可固定视野，「定位自己」恢复跟随。折返坡道按脚下在三维通行路线上的位置区分上下段，走过两段后显示对应目的层。联机按玩家的逻辑区域区分基地与同世界的地牢。
- 联机迷雾只接受菜单所属本地控制器的位置，不跟随队伍任务进度同步。本人先返回主神空间、队友仍在原地牢时保留本人的探索，重进同一局立即继续采样；最后一人离开导致实例退役、新局开始或当前实例重新生成时清空旧探索。传送未完成、流送实例与已生成布局不一致时显示等待状态，地标只取当前实例。记录限本地菜单会话，不跨断线重连或重启保存。
- 主神空间使用从已保存的 `DayNight_Lighting` 关卡正交拍摄的 2048 × 2048 底图。贴图内保存拍摄中心与覆盖宽度，图上方为世界 +X，右方为 +Y。底图、玩家、地标与右键选点共用这一投影。平台布局改动后在项目目录后台运行 `UnrealEditor-Cmd.exe FPSGAME.uproject -run=ColdSteelHubMapBake -AllowCommandletRendering -RenderOffscreen -unattended` 重新生成 `/Game/ColdSteelUI/WorldMap/T_GodSpaceOrtho`。
- 主神空间只把绑定主仓库的箱子标为「仓库」。开着地图时，新生成的地标和联机传送门的目的地会更新，销毁或卸载的地标会移除。
- 温带丘陵从本局高度场生成覆盖整个可玩区的地表网格，使用和场景相同的地面材质、纹理投影及林地、河岸混合数据，正交拍摄 1024 × 1024 彩色地表。水域和等高线独立叠加，细线每 5 米一条，主线每 25 米一条。等高线沿地表三角面插值，水面处收线。采样在后台进行，关图可取消；挖填后等待新水域数据就绪再更新。
- 其他区域根据本地导航范围、出生点、地标与静态场景表面生成俯视底图。每个本地菜单缓存最近一次完成的底图与叠加层，同一世界、相同有效范围内重开可复用。
- 滚轮围绕鼠标缩放，左键拖动平移，定位回到本人。右键放置个人标点，Delete 清除。标点在同一区域重开时保留，按运行实例区分。交互不写存档。
- 在操作说明登记 M。地图窗口按需创建，关闭时释放窗口和地标监听；已完成的采样图随菜单缓存释放。
