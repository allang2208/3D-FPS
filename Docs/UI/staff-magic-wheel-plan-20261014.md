# 法杖快捷魔法圆盘

## 范围

直接制作并接入：法杖长按 R 打开十等分圆盘，松开 R 选择；左键操作当前选择的魔法，默认未选择。按后续用户调整，未选择魔法时左键恢复原法杖挥击；已选魔法保留原有的凝聚、再次释放和瞄准流程，施法失败不回退挥击。

P 技能栏增加「配置快捷魔法」按钮。点击后在技能栏左侧零间距展开同宽同高的配置栏，沿用冷钢主题、字号及抽屉 0.25 秒线性进度＋EaseSmooth 动画。配置栏和战斗圆盘共用同一十格控件及顺时针顺序。

## 布局和交互

- 技能栏顶部固定配置按钮，列表维持现有独立滚动。左栏显示标题、十等分圆盘和拖拽说明；长名称在中心详情完整显示，扇区只保留短名与图标。
- 两栏总宽受视口约束，技能栏和配置栏同时等宽缩至可用宽度；上下边界、高度及 DPI 跟随现有技能抽屉。圆盘按剩余宽高缩放，文字横排。
- 技能卡拖入指定扇区登记；相同魔法已登记时移位／交换，不重复登记。右键扇区清除登记；点击配置盘中心清除当前选择。只有已学会的魔法可以登记，武技、被动和物品不能登记。
- 战斗圆盘复用弹药圆盘的相对鼠标位移和 0.30 秒长按门槛。松开 R 确认悬停的有效槽位；中心、空槽切换为“未选择魔法”，Esc 取消本次切换并保留原选择。配置圆盘点击中心或空槽采用同样的取消选择规则。
- 圆盘打开时拦截左右键及视角转动，关闭不穿透攻击。菜单、失焦、死亡、切换武器取消未确认选择，保留已经保存的配置。
- 法杖短按 R 保留已有冰墙形态切换／副手装填操作；长按用于魔法圆盘。
- R 魔法圆盘的打开、选择、选择中心／空槽以及 Esc 关闭均保留魔法书专注，不重置专注动画进度或加成。只清理施法预览与鼠标输入；菜单、换武器、受击等原有专注打断条件不变。
- 法杖右下角在现有魔法值、每秒恢复、冷却缩减和回满时间下方增加当前魔法行：左侧 36px 图标与 16px 名称，右侧 12px“剩余冷却”标签与 20px 数值（秒，一位小数）；无选择显示“未选择魔法”，隐藏图标，冷却显示“—”。图标异步加载已有技能资产，名称与计时复用现有 HUD 刷新，不建立新 Tick 或修改技能状态。整栏保持现有宽度，向上自动增高，文字横排。

## 数据与生命周期

- `FColdSteelProfile` 新增独立的十格魔法配置、版本与当前选中槽。旧存档迁移为十个空槽、未选择，不更改原有十三格快捷栏。登记、清除、选择都由状态模型一次提交并保存。
- 法术定义、等级、图标与施法继续读取现有技能模型；冷却／魔法值不足不移除登记，只由原施法入口拒绝并反馈。
- 快捷栏施法入口提取为按技能 ID 调用，法杖与原快捷键共用，不临时改写快捷栏绑定。实际扣蓝、冷却、施法手势和联机结算继续由各法术负责。
- 配置拖拽沿用现有拖拽视觉和快照校验，但保持两个栏目展开。图标异步加载，仅刷新相关画刷；控件销毁解除委托，取消拖拽不保存。

## 已落盘实现

- `ColdSteelMagicQuickCast` 管理十格配置迁移、合法法术登记、移动／交换、清除、选中和原施法入口转发；当前选择按法术身份随槽位交换移动。
- `ColdSteelMagicWheel` 共用于战斗与配置：顶部第 1 格，顺时针十等分，复用弹药圆盘鼠标灵敏度；图标异步加载已有技能纹理，空槽始终保留。
- `ColdSteelMagicConfigurationHUD` 管理左侧同尺寸玻璃抽屉，完整命中区域覆盖整栏；整体关闭时随技能栏同曲线向右收回。配置栏中的拖放不会触发原先的技能拖拽自动关栏。
- `ColdSteelQuickBarModel` 提取按技能 ID 的施法与预览入口。法杖用独立输入标记，第一次按下凝聚、第二次操作按原预览／释放规则结算；真正松开左键与动作打断分别处理。
- 角色输入接入长按 R / 左键，控制器在圆盘内拦截攻击与技能快捷键；副手专注／手枪原行为保留。联机档案镜像保留本地魔法圆盘配置，实际施法继续使用既有各法术的服务端结算。
