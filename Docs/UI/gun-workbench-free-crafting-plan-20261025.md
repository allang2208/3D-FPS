# 枪械工作台接入 F6 免材料制作 · 2026-10-25

## 范围与规则

- 复用 F6「制作不消耗材料」开关，覆盖枪械工作台的枪械制造及弹药制造。沿用本地权威玩家的开发开关范围，不扩展到联机客人的档案。
- 枪械允许材料不足时开始，不扣背包、随身隔层或主仓库材料。组装、校准、品质结算、领取和背包容量约束沿用原流程。
- 枪械工件新增 `bMaterialsWaived=false` 标记，开始时锁定，随现有反射存档及工件同步保存。免费工件实付材料为空，废弃不使用旧档配方返料；正常收费工件继续按原实付记录返还一半。已有旧档默认仍为收费工件。
- 弹药通过现有即时制作事务接入；只有弹药配方目录参与此次免材料扩展，不更改普通工具配方和其他工作台。原弹药袋上限、目录可用性及保存失败处理保留。

- 保留冷钢布局与控件，材料栏显示「免材料制作」、实际消耗 0 和「免消耗」，材料不足不再置灰制作按钮。

- F6 按钮说明同步列出枪械与弹药制造。
