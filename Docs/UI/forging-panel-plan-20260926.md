# 铸造台锻造小游戏与冷钢抽屉

用户已要求设计并制作。本轮为游戏接入；后台必要构建，不启动编辑器、游戏或验收。现有铸造台模型不变。

## 玩法

- 铸造台 E 打开锻造栏与装备栏；锻造栏内「冶炼队列 / 领锭」继续进入原冶炼栏，高炉入口不变。无需连接高炉也可使用已持有材料锻造。
- 首版配方为现有高地·双手剑，每把铁锭 8、木材 2（初版平衡值，独立 JSON 可调），一次一把。材料范围与工作台相同：背包优先，其次主仓库，不读取储物箱。
- 点击开始，成功扣料保存后预备 3 秒，再锻打 20 秒。每秒一个热打击点，窗口 0.85 秒，每点只接受一次鼠标左键按下，双击的第二次按下按同规则处理，按住不连打。位置由模具内的作者点位产生，不会落到柄、背景或栏外；顺序每局打乱，相邻点保持距离。
- 每点一分，20 分满分。品质倍率 = 0.75 + 0.5 × 命中 / 20；0 / 5 / 10 / 15 / 20 次对应 -25 / -12.5 / 0 / +12.5 / +25%。空点不扣已得分、不新增目标；不额外掷随机数。两次点击至少间隔 0.12 秒，防止连点刷分。
- 工艺品质先影响武器物理伤害，沿用实际伤害与详情公式。武器稀有度、强化、附魔、攻速、距离和魔法特殊性质不改。质量档：粗制(0–4)、普通(5–9)、合格(10–13)、精良(14–17)、精工(18–19)、完美(20)。工艺档不改掉落稀有度色。
- 结束自动结算到角色的单格「待领取」记录，玩家点击领取放入背包。背包空间不足保留结果，不重复扣料，也不丢到地面。待领未清不允许开始下一把。
- Esc、Tab、×、切换工位或离开当前铸造台提前结束：剩余点计未命中；扣除材料不退，结果可稍后领取。说明在开始按钮上方常驻。退出后重新进入，对中断记录按已保存命中数结算。命中只更新内存及正常自动存档，不做每击磁盘写入；启动、结束、领取走已有持久化事务。异常退出可能失去尚未自动保存的本轮命中，投入和待领坯料仍保留。

## 布局与主题

以 ColdSteelInventoryTheme.cpp、ColdSteelSmeltingHUD.cpp 为当前源码对照。锻造与装备等宽、等高，上下 12 px，接缝为 0。共用装备栏 48% / 720–1040 px 基准，两栏同时出现时各自上限为 (视口宽度-12)/2；窄窗仍等宽，正文换行，内容区可滚动。

| 分区 | 内容 | 布局与溢出 |
| --- | --- | --- |
| 固定页头 | 锻造 · 铸造台、关闭 | 与装备栏页头同档，标题 20 px |
| 配方 | 成品名称、材料需求/持有、切换配方 | 单配方先完整上线，不显示虚假未实现配方 |
| 状态 | 倒计时、命中、工艺百分比、剩余时间条 | 16 px 数字；窄窗换行 |
| 模具 | 已有武器 PNG、凹槽衬影、刻度底板、热打击环 | 保持贴图比例；绘制和命中共用同一坐标变换；高度按视口夹取 |
| 规则与结果 | 预备/进行/成品/失败原因 | 正文 14 px，次要说明 12 px，可滚动 |
| 固定页脚 | 开始 / 领取；冶炼队列 / 领锭 | 36 px 同级按钮，未就绪禁用并说明 |

复用 ColdSteelUIStyle：黑灰玻璃、银白文字/选中、绿收益/红代价；热打击点使用 Warning 暖色，有明确锻打语义。主壳一层玻璃模糊；卡片不再叠模糊。字体沿现有 GunsmithUI 像素入口取得 Noto Sans SC 与 JetBrains Mono。

动画沿冶炼：背包到位后侧栏展开，4.0/s + EaseSmooth；关闭作为整体向右收回；与冶炼、工作台、仓库互斥，背包单独打开不带锻造。滑动期间不接受锻打。键鼠由背包现有输入模式阻断射击，画布鼠标事件均消费。

## 数据、生命周期与文件

UColdSteelForgingSystem（GameInstance 单玩家子系统）负责配置、时序、一次性命中、扣料、品质和领取。FColdSteelForgeJob 附加于角色 Profile；旧档缺省空记录；不改原物品格子、建筑存档和冶炼队列。成品 Item.Data 的 _forgeQuality 记录命中、总数、倍率与档位，随现有物品移动、储存与存档保留。

UColdSteelForgingWidget 只负责显示/转发。模具 Slate 画布共用绘制/点击几何，只有可见面板更新绘制，计时由子系统维持，低频标签刷新，静态 PNG 仅首次加载。OnChanged 绑定在 Construct，Destruct 解除；子系统退出完成未结算工件。

新增 ForgingSystem、ColdSteelForgingWidget/Board、ColdSteelForgingHUD、forging-recipes.json；局部修改 HUD/布局/世界交互、Profile、伤害处理及物品提示。复用 Content/ColdSteelData/Icons/ue_highland_claymore.png，无新增外来资产。
