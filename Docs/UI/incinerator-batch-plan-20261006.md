# 焚化炉批量销毁清单（2026-10-06）

用户已授权实现和隔离测试。基于本轮重新读取的源码，保留外部已修复的 InputKey 调用；不修改钥匙环，不操作现有编辑器，不改模型资产。

## 布局与样式

沿用工作台 UMG 宿主和 Slate 面板，与背包等宽、零缝并排；共享 ColdSteelUIStyle、Noto Sans SC / JetBrains Mono、20/16/14/12px 字号、36px 操作高度。标题、来源页签、搜索、全选栏与底部操作固定，列表和确认详情独立滚动。

每行最左侧提供 36px 点击区的复选框，名称与来源居中弹性排列，右侧显示逐项数量输入、增减和全部。禁用行仍展示原因，不能勾选。顶部同列的全选框支持未选／部分／全选；显示已选条目数及合计数量。

默认“全部来源”允许跨随身、装备、主仓库、弹药袋选择。全选覆盖当前来源和搜索结果的全部可用条目（包括滚动条目），排除禁用行；没有分页。固定说明明确此范围。更改来源或搜索会清空勾选并提示，确认不携带隐藏选择。

## 数据、事务与状态

勾选和数量编辑只改变面板临时状态。底部未选时禁用，确认页逐项列出名称、选定数量、来源、随实例消失的装填/改造/强化/附魔等内容。取消确认保留清单勾选，取消面板/关闭丢弃全部选择并恢复原输入流程。

批量报价与确认使用同一份库存快照；逐项复核身份、计数、完整实例、Generation 和背包承载限制，拒绝重复键。所有条目先对原始状态校验，再在一个候选状态扣除，最终一次 Validate 与一次 CommitState。任一失效则整批拒绝，不跳过、不逐条保存；确认在保存前消耗，重复点击不能重放。保存失败保留原库存并要求重新勾选确认。

装有夹层/扩展格内容的装备背包始终禁用，即使同时勾选了其中物品也不会绕过限制。没有任何产出或返还。

库存 OnChanged 使整批确认失效并刷新列表，明确提示后清空勾选。不在 Tick 解析 JSON；Tick 只保留既有 DPI 和工作台生命周期检查。虚拟化列表只创建可见行；状态统计按交互/刷新事件更新。
