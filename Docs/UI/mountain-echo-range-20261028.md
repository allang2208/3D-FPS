# 山鸣：连续山脉与比例点亮（V21）

> 历史方案；当前实现以 [mountain-echo-alpine-20261028.md](mountain-echo-alpine-20261028.md) 与发布清单为准。退役实物文件的恢复位置见 `Docs/Publication/HighlandBow20261028/archive-manifest.json`。

用户对 V20 独立纹章的粗糙感提出调整，要求连绵群山、命中按比例点亮，并为亮区添加发光。本轮替换 `ColdSteelBowResonance.cpp` 的绘制，不再显示独立菱形纹章或环绕椭圆。

山脉由远山、连续主峰、山体脊线与山麓组成，共 14 条静态矢量路径，约 116 × 24 px。山峰高低不对称，山谷自然衔接；折点仅做 10% 邻段长度的二次曲线过渡，保留峰顶。主体线宽 0.85 px，远山与细脊线约 0.40–0.55 px。沿用暗金／金色／浅金 HUD 色板，主体无底板。

数据继续只读 `ChargesFor`、`GainAge`、`ReadyAge`，沿用原满弓有效命中和训练靶判定。每层对应全宽的 1/3，新一层用 0.38 秒从上次边界推进；所有山脊共享同一横向裁剪边界。已点亮的山脉持续泛金，前沿有短促亮带；满三层增加一次沿主山脊上浮消散的辉光，并保留轻微呼吸。

保留原装备、死亡、菜单、翻越隐藏条件，以及现有层数时限、弦影箭消耗、存档与联机规则。使用已有 NativePaint 入口，无新增控件、委托、定时器或输入焦点。静态折线仅初始化一次，每帧复用小缓冲裁剪；5 层低透明度窄光晕围绕细金线，不引入同步资源读取或纹理加载。

设计图与点亮动图由 `SourceAssets/WoodSteelLongbow20261026/MountainEchoMarksV21/render_design.py` 从当前 C++ 山脊控制点生成，仅为用户要求的设计展示，不是 UE 实机截图。构建日志保存在同目录；不自动启动 UE 或进行游戏测试。
