## 布局与资源

- 右侧纵排人物状态、背包、技能，按钮 44×44px，间距 8px，距右 20px，整组中心默认在屏幕高度 37.5%。标题和内容仍在原共享抽屉中。
- 图片使用现用步枪精通的银色六边框、石墨底、金属浮雕与左上柔光，只替换中心符号为人物半身像、背包、技能书。图片等比居中，按键叠加在右下角，不烘焙文字。
- 内置 image_gen 每图单独生成；完整源、提示词和来源放 `SourceAssets/PanelNavigation20260915`，运行 PNG 放 `Content/ColdSteelUI/Icons/Navigation`，通过 HUD 的现有纹理加载缓存读取。
- 共享抽屉右侧预留入口宽度与间隔；仓库与背包仍等宽，窄窗按剩余宽度收缩。入口按实际视口和 DPI 定位，避让顶部 HUD 与右下武器栏。省去原抽屉内重复的横排导航（含原已禁用图鉴占位）。

## 数据、状态与输入

- 入口顺序为人物状态 Caps、背包 Tab、技能 P，点击直接选择原 page 0/1/2；已打开同页时收起。键盘原有 Tab 关闭任意抽屉合同不变。
- 实际打开、关闭、仓库收起、拖放取消、焦点与输入模式继续使用 HUD 现有方法，不增加存档或业务状态。
- 普通 FPS 操作显示图标与按键；使用现有 LeftAlt 释放鼠标后可点击，抽屉打开时亦可切换。侧栏纳入外部点击保护，避免切页先被认作点到抽屉外而关闭。
- 无选中时中性边，当前页深青蓝边；快捷键统一使用已有 `ColdSteelQuickSlotFX::KeyOpacity`，1.2 秒、1→0.4→1、CSS ease-in-out，图标本身不闪。悬停／焦点在左侧显示名称。
- 素材缺失时保留可用入口并显示中文简称。图标仅初始化加载；每帧只更新按键透明度及必要的布局／选中状态，不重建栏目。
- 控件与事件由 HUD 的 WidgetTree 持有，没有新全局监听或独立计时器。
