# 拉弓完美节拍（2026-10-13）

用户要求拉弓时在准星下方显示节拍条，ADS 同样可见，并在合适的松手时机提高箭伤。

## 规则与数据

- 满拉后 0.20 秒内手动松手，该箭直接伤害乘 1.25；错过窗口仍保持原本满拉伤害。
- 既有 50% 最低拉距、半拉至满拉伤害曲线、暴击、弹种、扣箭、体力和回收继续沿用。力竭自动放箭不获得节拍奖励；取消收弓不放箭。
- 节拍跟随本次拉弓采用的实际满拉时长，包括精通、改造及状态的拉弓速度。阶段转换保留跨帧余量。
- 单机与服务器生成箭矢时固定伤害；客户端只发送本次拉弓开始与释放时间信息，服务端核对本次角色、弓实例和计时后计算奖励。

## 画面与状态

- 准星中心下方 50px：208px 宽紧凑条，深灰底、银灰进度、金色最佳释放区间，采用当前 Cold Steel 字体和调色板。
- 时间轨道显示拉弓阶段、0.20 秒金色窗口及窗口后的短尾段；移动亮标直接读取战斗时钟，无平滑延迟。
- 横排状态依次为“拉弓 · 金色区间松手”“松手 · 伤害 +25%”“节拍已过 · 满拉”；成功后短暂显示“完美释放 · 伤害 +25%”。
- ADS 实体瞄具隐藏原准星时仍保留节拍条；菜单、翻越、收弓、换武器时收起。新增绘制不读取磁盘、不加载资产、不每帧解析装备数据。

## 参考与交付边界

参考 [EA 的 Legacy 官方更新说明](https://www.ea.com/inside-ea/news/legacy-update-patch-notes) 中 Bocek 满拉释放节奏。原 Deadeye’s Tempo 奖励为射速，本项目按用户要求采用伤害奖励，数值为本项目设计。

后台完成源码和必要 Editor 构建；不启动编辑器、游戏或额外测试，实际节奏、画面及联机体验交由用户测试。

## 实现落点

- `Weapons/Bow/BowStats.h`：统一窗口与倍率常量。
- `Weapons/Bow/BowWeaponComponent.*`：本次拉弓时长固定、满拉跨帧余量、手动奖励、HUD 只读状态、自动释放排除。
- `Multiplayer/ColdSteelBowAuthority.cpp`、`ColdSteelPlayerState.h`、`ColdSteelInventoryRequestTypes.h`：每次拉弓发送一次开始/结束；服务端按弓实例、角色和计时核算本箭奖励。声明释放时间必须在 0.20 秒窗口内，服务端与客户端计时差最多允许 0.15 秒；极端网络抖动可能只结算普通满拉伤害。
- `UI/ColdSteelCrosshair.cpp`：节拍条在 ADS/实体瞄具的准星隐藏判断之前独立绘制；成功提示保留至多 0.45 秒，末段淡出。
- `UI/ColdSteelItemTooltipData.cpp`：武器详情补充真实窗口、加成与自动放箭规则。

没有新增美术资产、存档字段或修炼技能；所有弓沿用此通用规则。完美节拍在正常满拉伤害基础上乘 1.25，不改写面板的普通满拉数值。
