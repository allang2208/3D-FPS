# 枪械工作台收尾与弹药批量制作

用户已授权修复排查出的遗漏并优化交互。本批后台开发及必要构建，不启动编辑器、游戏或自动测试。

## 结构和状态

- 保留枪械／弹药双页、冷钢玻璃外壳和固定底部操作区。枪械配方使用现有 DevelopmentItemPicker，按实际武器类别分组；弹药按兼容口径分组，子项显示弹种与档位。分类标题不可选，所有回调使用稳定配方 ID。
- 弹药页顺序为配方、弹种说明及直接属性、适配枪械、袋内数量和批量、材料表。底部显示事务结果与制作总发数。长说明和枪械名单正常横向换行；短标签、按钮及数字单行。内容区滚动，页签及确认按钮固定。
- 批量为 1–99 份，支持减一、加一及最大；最大值同时受材料、F6 免材料状态与弹药袋剩余容量限制。可制作上限为零时明确显示零并禁用提交，不把一份报价当成可制作数量。
- UMG 宿主管理共享 Slate 下拉；Construct 绑定目录／库存和联机回执，Destruct 解绑及关闭菜单。库存变化、批量／配方改变和回执使内容失效；沿用现有刷新节拍，禁止每帧重建菜单或解析目录。

## 事务与工作台

- 枪械开工／继续的联机成功回执到达、有效工件写入本地镜像后，才进入小游戏。原工作台、交互 Actor、Pawn 和打开状态变化时不自动抢回镜头；工件仍可稍后继续。
- 弹药以服务器回执显示真实结果；等待期间禁用材料相关提交和选择。服务器使用目录配方与批量结算，客户端不发可信产量。
- 枪械开工／继续／结算及弹药制作传递实际工作台 Actor，服务端验证类型、存在、距离与视线；装配后续输入使用本次绑定的枪械台。恢复／领取／取消绑定当前 Job ID。
- 枪械与直接制作不修改建筑世界，失败回滚只处理库存／工件，避免通过重建全部构件把绑定的工作台销毁替换。
- 未完成工件可取消，已完成成品可废弃，均按历史实际支付量逐项向下取整返还一半；免费工件不返料。返料与清空工件同一事务，容量不足保留工件。配方删除／部件数量变化也能退出；无可靠实付记录时明确显示无法返料，不按新配方臆造材料。
- 不改变伤害公式和现有配方材料数值，不新增弹药小游戏或弹药工艺加成。
