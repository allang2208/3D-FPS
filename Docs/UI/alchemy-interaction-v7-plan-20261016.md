# 炼药交互与液流 V7

本轮按用户反馈逐件排查，不把已有源码和编译结果当作操作合格。使用 UE 调试、流体、冷钢 UI 和精确建模流程，后台制作、导入、编译；不启动游戏或视觉验收。

| 对象/路径 | 问题与定位 | 修改 |
| --- | --- | --- |
| 实际添加物容器 | 投料仍调用装成品的 Dose 动画，Ingredient 只作摆设 | 从已采用的材料模型拆出容器和瓶盖；选中哪件就取起哪件，开盖、倾倒、回位；Dose 只负责接成品 |
| 投料/装瓶液流 | 一根直圆柱瞬间显示/消失，液面提前变化 | 曲线细流、逐段粗细、平滑起止、有限滴落、接触涟漪；按实际瓶口/勺口/落点定位，进出液面与流动阶段对齐 |
| 结晶/催化剂 | 干燥晶粒也套用液体动画 | 单独使用少量颗粒流，颜色区分蓝结晶与紫催化晶 |
| 搅拌 | UMG 捕获后仍从控制器取鼠标位置；短暂停顿即发 Stop，反复触发 0.6 秒取勺 | 使用指针事件的屏幕位置转射线；按下即取勺，拖动期间零速度也保持拿着工具，松开才放下 |
| 火候 | 入口藏在锅身下方的符文环，难发现 | 在台面新增带档位刻度的独立火候旋钮，与同一个服务端火力相连 |
| 第三份材料/背景陈列 | 无清晰边界，背景瓶与实际材料难区分 | 本炉材料集中于独立备料托盘；背景陈列浮窗标明不可操作；逐项记录命中与输入路径 |
| 悬停反馈 | 只有底部一行文字，缺少物件轮廓 | 独立金色轮廓后处理，悬停真实网格；旁侧浮窗显示名称、剩余量、可用鼠标操作和当前不能操作的原因 |

玩法仍以原有短流程为基础：初级投主料、低火搅匀、装瓶；高阶才增加研磨与多段火候。手册给出配方知识，药色、温度、颗粒和沸腾反馈过程，玩家决定收尾；不恢复逐步答案提示。

轮廓只属于本地炼药镜头，不修改全局搜索轮廓或共享材料；透明瓶使用仅写自定义深度的同网格代理，以免玻璃不写轮廓。浮窗不截获鼠标，离开、开书、失焦和关闭均清理。

材料模型由已采用源文件派生，保留原 PBR 与标签；新包放 `InteractionV7`，在隔离无界面工程保存后安装。原物品模型、库存与配方不变。动画占用时长统一由公共定义取值，服务端与旁观台面同步使用。
