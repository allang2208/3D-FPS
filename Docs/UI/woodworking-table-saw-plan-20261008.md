# 木工台锯与小游戏升级（2026-10-08）

## 授权和范围

用户纠正为桌面露出锯片、桌下电机驱动的游戏台锯，明确要求小游戏结合刀口切割。停止 V3 手锯收纳架及自由圆刷方案。V4 Core（Library version 3）官方本机传输单次尝试返回 HTTP 403，未取得模型；现有 V2 资产、菜单和注册合同保留，不能声称已导入 V4。V4 模型后续使用完整母版，锯片需以自身轴心单独导出，不与主台焊接。

## 设备与木板

- 二维 mask 保持 512×256。木板姿态为工作平面平移和角度，像素中心经过同一变换用于绘制、抓取、刀口碰撞和损伤反馈。
- 刀口在设备坐标原点，沿 Y 方向固定。左键抓木料或同坐标的推料柄进退。接触期间禁止横向扫板；整张板退离刀口后才可 Q/E 以默认 5° 转向。
- 连续平移采用有限线段的完整凸扫掠区域及锯缝半宽判定，不依赖鼠标帧采样，也不直接把鼠标当切削位置。单次姿态位移上限为可调游戏参数，避免极端输入造成无界工作。
- 准备后点击“启动加工”才计时和驱动刀片。急停关闭切削及视觉驱动，计时继续；恢复不重置时间。急停时可在已有空隙退料，不能推入新木料。完成、失败、超时、放弃和关闭停机并取消拖拽。
- 撤销恢复上一笔及其废料剥离，同时恢复该笔开始时的木板姿态，不返还时间。空拖动不覆盖上一笔撤销。视图缩放/平移/复位不修改实体姿态、刀口比例、遮罩或计时。

## 可达练习数据

弓臂和法杖木芯保留 ID 与连接锚点，使用原轮廓凸包向外扩展的直线毛坯。所有边方向对齐 5° 旋转网格，没有封闭内孔或细凹槽，可从板缘逐段切入。静态理想支撑线切割分析包含离散角度和 0.9 mask 像素保留余量，两种毛坯可达到约 99.1% 清除率，因此保留原 98% 要求、完整度限值、评分权重与 90 秒时限。此分析不是 90 秒实际可玩性或手感验证。

`woodworking.json` 的 `saw` 是可调游戏参数：锯缝、刀口接触长度、旋转步长和单次移动上限，单位为 mask 坐标，不代表真实机械规格。修改旋转步长后需重新核查轮廓可达性。旧粗/细圆刷参数与交互退出。

## 面板及表现

- 准备/加工/结果分阶段主操作，练习明确“无消耗 / 无产出”；仅现有配方非空时才展示正式制作入口，领取仍由既有 Craft 单事务处理，不新增经济配置。
- 固定标题与主要操作，集中显示时间、清除率/要求、完整度/下限；详情 168px，窄于 1000px 默认收起，可切换。矮于 720px 收起目标缩略图与帮助；工具条横向可滚动。字体和 36px 按钮复用冷钢样式。
- 同一个画布跨窗口重排复用，保留 zoom/pan；只在布局档位或 DPI 改变时重建外壳。尺寸变化结束当前笔画，不重新选择或初始化工件。
- 木纹和断面由实际木料栅格绘制；目标轮廓来自 raster 边界，线宽按 DPI 保持。薄厚度、柔影和损伤半透明纹理只参与展示，不改变碰撞或得分。
- 实际去料事件才产生木屑和局部新损伤提示；最多 32 个木屑，每次最多 6 个、间隔至少 45ms、寿命 0.48 秒。切削声音提供软引用，预先异步加载，100ms 最短间隔、最多一个声音实例；当前没有合适素材，默认留空。
- 准备/加工/结果、释放、越界、失焦、应用失活、急停和关闭均收束拖拽。关闭确认阻止木板操作，计时继续。
