# 配方手册无法继续翻页修正

用户反馈手册无法翻页，询问是否只做了一页。

实际原因是阅读器的范围只包含当前配方，翻页、方向键和末页书签均按该配方的页数限制。自由炼制改造后，普通治疗药水、普通魔力药水仅 2 个步骤，中级生命药水为 3 个步骤，按现有排版各只有 1 组左右页；这些配方在阅读器内没有任何可翻的后续内容。高级配方有多组页面，但原来不能跨配方浏览。

本次将目录的 8 个配方组成完整手册，每个配方保留独立的成品、材料、工序与收存内容。按当前数据共 14 组左右页／28 页：

| 配方 | 步骤数 | 手册页码 |
| --- | ---: | --- |
| 治疗药水 | 2 | 1–2 |
| 中级生命药水 | 3 | 3–4 |
| 高级生命药水 | 7 | 5–8 |
| 特级生命药水 | 9 | 9–12 |
| 魔力药水 | 2 | 13–14 |
| 中级魔力药水 | 4 | 15–18 |
| 高级魔力药水 | 8 | 19–22 |
| 特级魔力药水 | 10 | 23–28 |

打开时定位当前选择／批次配方；随后拖页和左右方向键可跨配方连续阅读。两端书签跳整本首页／末页，页脚显示连续页码和总数。实际页数仍由当前配方数据生成，表格是本次诊断时的数据记录，不是写死的运行目录。

正在进行的旧批次保留其配方快照，替换同 ID 章节供阅读；存档中已从目录移除的配方可附在末尾。目录浏览只改变私有阅读状态，当前制作选择、已扣材料与存档事务不变；公共台面的页码同步仍仅发生于当前制作配方。

纸页组件允许跨配方翻转，并保留已显示配方、局部页码、全书页码与渲染目标；取消拖页时一起恢复，避免视觉回弹后内部仍留在下一章节。继续只持有当前／下一组两张页纹理，拖动不重绘全书。沿用 ManualV5 外观资产。
