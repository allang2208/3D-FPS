# 配方手册流程排查（2026-10-16）

用户要求检查打开、翻页、目录、书签跳转和关闭，并修复报错或崩溃。本轮在前次字体加载与测量 owner 修复之上进行。

## 路径清单

| 路径 | 实际入口 | 本轮检查内容 |
| --- | --- | --- |
| 打开 | `ColdSteelAlchemyWidget::Book` → `BookPreview::Configure/Loaded` → `AlchemyManualComponent::Loaded/DrawSpread` | 全部配方计页、异步加载、模型/材质/两张页纹理、双页内容 |
| 翻页 | 方向键 → `Flip/TurnTo`；鼠标 → `BeginPageDrag/DragPage/ReleasePage` | 正反向所有页、跨配方、首末页、提交、回退、输入取消 |
| 目录 | `ContentsAt` → `TurnTo` | 每个目录条目的坐标命中、长按后点击、配方首跨页 |
| 书签 | `BookmarkAt` → `TurnTo` | 左侧目录、右侧末页、边界禁止超翻 |
| 关闭 | B/Esc/RequestClose → `Book(false)`；离台 → `EndSession` | 拖动中、自动翻页中、异步加载中关闭，反复关闭和重开，终止后的回调 |

## 修正

- 目录条目在按下后经过 0.16 秒，原先会直接开始拖页并清空待点击条目。现在条目仍有效时保留点击，只有鼠标移动超过已有阈值才转为拖页。
- `Book(false)` 原先仅隐藏控件并取消输入，未释放私有预览的模型、捕获和页纹理。现在关闭时完成释放，重开会恢复预览世界的渲染场景并重建书本；重复使用同一世界壳，避免每次开关创建新的预览世界。
- 区分普通关闭与最终离台销毁：普通关闭保留页码回调、允许重开；最终释放解绑回调并禁止重新加载。关闭后拦截迟到的加载回调、翻页请求和鼠标事件。
- 销毁书本组件前清除 ready/open/turn/drag 状态与上下文，取消加载句柄，避免后续推进翻页时访问已经清空的零件数组。渲染准备也排除正在销毁的上下文世界。
- 桌面书本以相同配方、相同页码重新打开时，状态观察器不会再次调用 `SetRecipe`。关闭曾清空纸页目标，原先打开不重画会留下空白；现在 `SetOpen(true)` 会恢复保留的页面视图。
- 尚未排版的零尺寸几何不参与页面投影，避免除零及无效目录坐标。
