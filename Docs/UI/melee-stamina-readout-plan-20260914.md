# 右下角近战次数与体力回满时间

用户要求在右下角装备详情中，将近战武器的弹匣／备弹替换成当前体力可普通攻击次数与体力完全恢复时间。

- 布局：沿用现有 360px 冷钢右下角面板、武器名称与近战说明；左右标签改为“可普通攻击次数”“体力回满时间”。次数及秒数保持 24px 数字字体，暂停／不恢复使用 16px 中文字体。枪械和双持继续显示原弹药信息，切换时恢复标签、字体及颜色。
- 次数：`floor(max(当前体力,0) / 普攻体力消耗)`，只计算现有体力预算，不预支挥砍期间可能恢复的体力；消耗为零显示 ∞。零次标红、仅剩一次标黄。
- 时间：体力已满为 0.0s；否则 `剩余恢复延迟 + (最大体力-当前体力)/当前每秒恢复量`。每秒恢复量复用包含角色加成的 `StaminaRecoveryRate`。显示保留一位小数并向上取整，避免尚未回满时提前显示零。
- 状态：格挡／实际消耗体力的冲刺／角色不能恢复时显示“暂停恢复”；恢复率为零且体力未满显示“不恢复”。停止阻止恢复的动作后，按当前缺口和延迟继续计时。活动判断由体力 Tick 与只读估算共用，不在 HUD 复制判定。
- 数据与刷新：状态模型提供本地只读 C++ 估算接口，无 Blueprint 或 RPC 写入；现有 HUD Refresh 调用，不新增定时器、事件订阅、操作输入或存档字段。数值变化才刷新文字，面板仍 HitTestInvisible，打开背包时隐藏。
- 范围：FPSStaminaTuning／FPSStaminaModel、ColdSteelStatusModel 只读接口、ColdSteelAmmoReadout 与规则文档。完成必要 Editor 构建，包含上一轮尚待编译的关闭 X 和详细参数修改；不运行游戏或测试，由用户测试。
