## 目标与规则

- 弓限定被动战技，20 级；新档与版本 25 及以下存档迁移到版本 26 时获得 1 级，不重置其他技能。
- 从实际开始拉弦计时，连续超过 3 秒且满拉后，手动或持弓超时自动释放均触发。搭箭和举弓准备不计时；取消、收弓、换装、死亡结束该次蓄力。
- 快速拉弓不降低 3 秒门槛。有持弓时限的弓，总时限至少为 max(满拉时间, 3 秒) + 0.75 秒；原无限持弓配置不变。
- 伤害倍率相对同装备、同箭种的普通满拉箭，随后照常结算暴击、属性伤害和目标防御。全等级箭速 ×2，不额外耗魔、耗体力或增加冷却。
- 穿透为额外目标数：+1 / +2 / +3 对应最多 2 / 3 / 4 个目标。不穿实体墙、地形；每个目标继承整发箭倍率，不因穿透衰减。每箭每目标结算一次，只保留一支回收箭。
- 单箭伤害、速度、穿透与技能触发状态在发射时固定；服务器使用自身拉弓会话和技能等级计算，客户端不提交伤害数值。

## UI 计划

- 入口：技能页全部／被动分类，位于弓精通之后。被动技能无需快捷键，不新增拖拽或主动施法入口。
- 卡片：48px 共享图标、名称、横向标签、等级、修炼条；摘要两行直接给出触发时间、当前伤害、箭速与穿透数量，随等级实时更新。
- 详情：当前／下级对照，先展示核心收益，再说明触发、伤害基准、穿透与取消规则、修炼，最后列出完整 20 级成长表。1／8／16／20 级用主题强调色。
- 布局：沿用冷钢主题、页面滚动、窄栏效果行自适应；文字保持横向，长说明按段换行。
- 瞄准：沿用单圆弧与 120px 短条。完美节拍窗口期间保持原逻辑，窗口结束后短条显示穿心箭剩余蓄力；可释放时圆弧和短条变为银白。没有新增文字、圆环、B 提示或全屏特效。
- 状态来源：技能配置由 skills.json 加载至共享定义；游戏、联机、卡片、详情与升级通知共用 HeartPiercingArrow::Evaluate。绘制阶段仅使用弓组件提供的本次拉弓快照，不读文件、不构造资源。
