# 强化与附魔魔法工作台升级 · 2026-10-08

同日用户追加：背景改为更明亮的蓝／青／金近景工作台；下文三张暗色背景保留为 V1 编辑源，当前资源与构图以 [工作台 V2](arcane-worktable-v2-plan-20261008.md) 为准。

## 范围与资源

升级 `UColdSteelEnhancementWidget` 共用的强化／附魔工作台。移除其洞洞板背景引用，改用新生成的魔法场景；改造台自身背景不受影响。三版候选由内置 image_gen 分别生成，原始提示词与文件来源记在 `SourceAssets/ArcaneWorkbench20261008/generation.json`。A 余烬符文锻炉、B 月辉星仪殿、C 幽紫秘法书库均供用户参考；暂以 A 接入，用户可再指定替换。

## 信息结构与布局

- 顶栏固定：工作台名称、当前操作、灵魂／强化石／魔法粉尘余额、返回。
- 左侧：装备目录、搜索、装备位置及强化等级。搜索只筛目录，不自动扣款或换装备。
- 中央：顶部强化／附魔切换，真实独立装备预览、符文法阵、当前等级／目标等级及前后缀；底部材料或卷轴卡片。旋转、缩放和复位沿用原预览。
- 附魔卡片提供全部／前缀／后缀过滤；只列实际随身持有的卷轴，显示数量、粉尘、兼容及当前词缀状态。
- 右侧：更大效果说明区、前后数值表、真实消耗及消耗后余量。固定表头、正文独立滚动。
- 页脚固定：状态／阻止原因、取消、确认。确认成功后短时符文扩散与光点反馈，反馈不延迟已成功的原子事务。
- 中性冷钢玻璃、银白文字与选中边，暖金强化／淡蓝附魔只用于魔法图形与操作身份。标题、按钮、资源、数值保持单行；长说明可自然折行并提供全文 Tooltip。
- 内容宽度达到 1240px 且高度达到 650px 后使用三栏（宽屏 220／440px，紧凑 196／410px）；更窄或更矮时汇总下移、主体滚动；极窄窗口顺序纵排。页签／确认始终固定可达。

## 数据与交互

沿用 `UColdSteelEnhancementSystem::Supports/CanEnchant/Quote/Apply` 与 `UColdSteelStatusModel`。灵魂读取独立余额；强化石和粉尘沿用原材料范围；卷轴列表、报价、扣款只使用背包与已有夹层规则，不增加仓库卷轴消费。升级等级、附魔战斗效果、概率、库存容量、存档结构均保持当前规则。

无装备／无卷轴、无搜索结果、卷轴不兼容、同词缀、满级、材料不足各有明确状态。失效装备选择清除；已持有但不兼容卷轴禁用，粉尘不足仍可选择预览。成功文案对应刚完成的动作，不被下一次报价覆盖。失败不播放成功魔法反馈。

## 生命周期与性能

UMG 宿主承载 Slate。OnChanged 更新真实数据，图标完成只换图。新背景按项目现有 FImage 异步解码方式加载，游戏线程只创建瞬态纹理；关闭／重建时通过弱引用与请求代次丢弃过期回调。背景 PNG 保存到 Content 并加入 UFS 打包列表，无需启动编辑器导入 uasset。

符文图形为独立无交互 Slate 绘制，静态待机，只在原有短时成功反馈窗口内刷新动画；不引入新计时器或每帧业务解析。关闭清理绑定及独立预览，维持原控制器输入与焦点归还。
