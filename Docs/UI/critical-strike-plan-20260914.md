# 暴击技能迁移

阶段：UE 游戏接入。沿用当前技能页、单人角色存档与战斗入口，不新增操作键。

## 原项目依据

实际读取 game-dev 的 `data/skills.json:criticalStrike`、`src/ui/skill-manager.js:addCriticalStrikeExp`、`src/entities/player/subsystems.js` 与 `src/entities/damageable-entity.js`。

- 初始 1 级、最高 20 级，升级经验 = 等级 × 100。
- 暴击额外伤害 = 0.50 + 等级 × 0.05；幸运 +等级。1 级为额外 55%（1.55 倍），20 级为额外 150%（2.5 倍），不是在额外两倍伤害上再次叠乘。
- 暴击命中 +1 修炼经验，暴击击杀额外 +10，合计 +11；普通命中／击杀不为本技能提供经验。
- 幸运从等级派生，不写回基础属性。当前 UE 保留既有“实际要害命中、无随机暴击”规则，不移植旧概率暴击系统；因此幸运常驻显示为真实属性加成，不宣传其提供随机暴击率。

## 战斗与保存

枪械子弹／射线与符文剑通过同一 `ColdSteelSkills::ApplyHit` 入口处理暴击。伤害与技能增幅在发射／挥击开始时快照；升级或切换武器不改变正在飞行的子弹／本次挥击。实际头部骨骼命中触发，兼容当前怪物的 head 与 cranium 命名；命中反馈和技能结算共用这一判断。

暴击伤害按 `(原伤害 × 原步枪要害倍率) × (1 + 暴击额外伤害)` 向下取整，仅施加一次。保留步枪精通既有要害倍率。非要害普通伤害不变。符文剑保留每次挥击每目标一次的命中集合。

修炼目标需为存活、允许修炼的怪物；召唤物、禁修炼目标、空挥、墙体与持续毒伤不提供暴击经验。致死伤害将角色奖励、武器精通与暴击修炼放进同一保存事务；非致死命中的武器／暴击经验也合并提交，不靠升级弹窗修改属性。存档版本 5，仅补入暴击技能，保留所有已学进度与物品。

## 界面与资源

在 ColdSteelSkillPage 的全部／被动分类添加暴击概览，详情复用收益表、等级进度与独立修炼卡。收益显示暴击伤害加成、技能暴击倍率与幸运，说明暴击命中与击杀奖励叠加。角色状态增加暴击倍率并在幸运说明中显示基础值与技能加成。继续按实际抽屉宽度布局、短标签横排、长文本明确换行宽度，沿用滚动和返回焦点。

UMG 宿主持有模型／纹理，Slate 控件引用随页面释放。模型为数值与事务所有者，界面只读取；提交成功后触发升级通知。新版图标采用当前银灰拉丝六边形、石墨底与致命击碎护甲图案，由内置 image_gen 生成。运行时列表、详情、升级通知统一读取 `skills.json`，作者源、提示词和原配置快照保存在 `SourceAssets/CriticalStrike20260914/`。
