# 武器伤害分项面板与命中结算

用户要求：属性或其他来源的附加伤害先算入武器面板，攻击方式放大后，物理、魔法各自减伤；基础和附加分别结算。

- 数据：统一伤害结构保留基础物理、基础魔法、附加物理、附加魔法。总伤害为四项之和；当前侵蚀符文接入附加魔法。固定值、属性系数、基于武器基础值的比例共用附加伤害入口。
- 面板：物品摘要、详情、改造对比、加工预览使用同一求值；总伤害为主，基础与附加为明细。重击和连击保持独立的攻击方式倍率。
- 命中：攻击起手/开火快照 → 所有分项共同乘攻击方式/距离/暴击倍率 → 对应防御与状态减免 → 基础、附加两笔结果。伤害回执显式传给 HUD；一次接触只触发一次硬直、附效及奖励事务。
- 界面：复用 UMG 宿主和 Slate 自绘命中读数。存在附加伤害时扩展读数高度，分行显示基础与附加及类型，保持视口限制、主题字体及现有淡出时间。无附加伤害时沿用单值布局。
- 更新和输入：沿用现有档案/草稿刷新与命中回执；纯展示，无新增输入、焦点、保存字段或额外 Tick 绑定。
- 范围：即刻武器命中伤害。持续毒伤等按时间跳伤继续保留独立周期，不重复塞进单击面板；模型和动作不变。
- 执行：必要原生构建；按用户规则不运行游戏、测试或验收截图。
