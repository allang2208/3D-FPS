# 上挑主动技能接入

用户要求把既有上挑动画改为游戏内可随时使用的技能，暂不设置数值和修炼项目。

- 入口：现有技能页的全部／主动分类，增加「上挑」卡片；卡片可拖到 Q/E/X/1–4。详情显示持剑条件、轨迹和绑定用法；不显示等级、技能收益表、升级或修炼卡。
- 布局：复用技能页滚动区、卡片和响应宽度。标题／详情正文使用共享 ColdSteelUI 字体和颜色。图标为石墨底银色六边形及上挑剑形，无烘焙文字。
- 数据：`skills.json:swordUppercut` 只定义名称、说明、图标。技能默认可绑定，不新增技能成长存档项；快捷栏绑定仍由原事务保存和加载，保留所有现有绑定。
- 动作：URuneSwordComponent 选择已保存 Standard／LongGrip clip，使用原手模和武器挂接。预加载动画，不在按键或 HUD 刷新时同步读盘。使用独立动画时钟和动作占用，不进入普通攻击伤害、消耗、攻速、冷却或修炼路径。
- 状态：快捷栏显示「需要持剑」「动作中」「动作占用」「动作准备中」；动作完成后可再次使用。共用死亡／换装／菜单中断和高优先级快速进战规则。普通攻击、格挡和新的施法不会叠放到上挑动作。
- 文件范围：skills.json、技能定义与快捷栏模型、技能页／快捷槽、RuneSwordComponent／Guard；新增动作逻辑实现、图标作者源及说明。保留上次独立场景及原始动画制作源作为交付记录。
- 执行边界：后台制作和必要 Editor/Game 构建，不主动运行游戏、检查、测试或截图。完成后由用户游戏内试用。
