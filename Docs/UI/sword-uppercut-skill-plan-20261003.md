收益表增加「判定距离上限」与「距离倍率（相对突刺）」两行，当前／下一级共用技能效果公式 `1.25 × [1 + 0.01 × (等级 - 1)]`。距离根据当前装备剑的基础范围和改造倍率显示米数，未持剑时显示「需装备剑」。说明区区分距离上限、实际扫掠接触和角色前踏；升级通知同步显示距离倍率。图标使用已正式接入的人物圆角方框版；本轮不改布局框架或存档结构。

## 2026-10-04 V18 消耗与冷却

用户现已授权伤害与技能成长。上挑卡片复用普通技能 Overview 的图标、等级和经验条；详情沿用现有滚动区，显示基础伤害倍率、力量、升级经验的当前／下一级对照，以及释放／命中／击杀最高档修炼卡。宽／窄窗口继续使用原 EffectRow 与 TrainingCard 的布局和 ColdSteelUI 主题，不新增固定宽度栏目。数值来自同一份 `skills.json` 定义及 `MasteryProgress/Effect`；经验提交触发现有升级通知和数据刷新。图标、绑定、缺武器和动作占用提示沿原入口。
