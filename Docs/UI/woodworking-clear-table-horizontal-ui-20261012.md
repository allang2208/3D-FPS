# 木工台面、正面镜头与全系统横排修正

用户截图反馈：摆件阻碍加工，镜头斜看台面，木工选择面板需与打铁界面一致，按钮和短标签不可挤成竖排。授权为制作、相关源码/几何排查、必要构建与保存；不运行游戏、PIE或截图验收。

## 制作方案

- 从 V4 游戏版母版制作独立 V5Clean20261012：保留桌体、贴图/UV、锯片和挂点；主长桌让出进料空间，法杖夹具、刀架、手工具和磨刀石移至侧桌，弓形夹具、车床、台钳和拆下的靠山移到已有下层支撑板。整组移动，重建对应碰撞，保留旧版资产。
- 加工相机取消横向斜角，朝向沿主台纵轴，适度俯视以看清刀口。UI以实际可用控件几何计算宽高与断点，避免物理视口尺寸和 Slate 局部尺寸混用。
- 木工选择页参照锻造：靠右停靠的制造面板、工件下拉、模式横排、材料/条件卡、等比预览与参数、折叠操作说明、固定底部确认。
- 全系统排查 UMG/Slate 的按钮短文字、自动换行助手和显式竖排字符串。短文字关闭换行，长说明保留按需换行；升级侧签改为 64×36px 横排。
