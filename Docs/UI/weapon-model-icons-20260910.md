# 背包与装备栏枪械模型图标

背包、装备格和拖动图标读取 `UColdSteelWeaponIcons` 的透明底侧视图。M4 与 AKM 使用 `AFPSGAMECharacter::InitializeWeaponVisuals` 当前实际加载的模型和材质；M4 的瞄具、弹鼓、枪口沿用运行时装配函数及挂点。预览剔除手臂，按可见枪械及配件包围盒取景。

缓存键由武器定义和已保存的配件组合构成。同型号的不同改装保持各自外观，未应用的枪匠草稿不会覆盖背包图标。应用改造后只生成变化的组合；装备、移回背包与存档重载复用相同图片。每个游戏实例最多缓存 64 张 768×320 图，队列空闲时停止捕获。生成失败或尚未生成时保留物品名称。其他物品沿用已有图标。

独立预览世界不进入 BeginPlay，不挂接玩家档案，也不通过切换玩家装备生成图标。模型资产沿用宿主内容，未新增或公开提交商业模型、材质、字体或二进制资源。AKM 验证在当前物品目录启用 AKM 时执行。

## 验证

UE 5.8.2 Editor Development 编译通过。`Tools/UI/run_weapon_icon_acceptance.ps1` 使用独立 `WeaponIconAudit_*` 档案和新游戏进程，覆盖 960×540、1280×720、1920×1080，每个分辨率 22 项断言通过：透明边缘、五种外观、实例隔离、草稿/应用、按需缓存、装备转移、保存重载。每次生成 6 张不同配置的图标。

本机实机画面和透明图输出到 `Saved/WeaponIcons/`；`equipment-1920.png` 同时展示原装与改装 M4 装备格、改装 M4 和 AKM 背包格。原生更新需在重新启动的游戏或编辑器进程加载；已运行的旧进程不会自动替换模块。
