# 山鸣群山 V22：岩脊细化与连续辉光

> 历史方案；当前实现以 [mountain-echo-alpine-20261028.md](mountain-echo-alpine-20261028.md) 与发布清单为准。退役实物文件的恢复位置见 `Docs/Publication/HighlandBow20261028/archive-manifest.json`。

沿用用户认可的连绵群山与三次命中比例点亮，针对 V21 的粗糙感继续精修。

- 增加山肩、双侧岩脊、短雪线、分叉与断续细刻纹；保留原主峰位置和约 116 × 24 px 的主体范围。主线 0.66 px，内部线条约 0.23–0.42 px，远山降低亮度。山麓改为不规则、间断的细线，避免等幅波浪。
- 坡面过渡使用 6 段二次曲线；山峰／山谷转折保留尖锐程度，坡中转折更平顺。控制点在首次绘制时缓存。
- 运行时以 Slate 自定义顶点带替换五层加粗光带。9 列透明度采样连续插值构成软光，7 列细线采样软化边缘；每段首尾宽度和透明度递减。法线延伸有限，避免尖峰处光晕过度扩张。
- 保留 .38 秒推进至下一个 1/3、前沿短亮带、蓄满呼吸和一次山脊辉光；蓄满瞬时描边减弱并缩短外移距离，保留峰形。
- 绘制仍归原 NativePaint 路径，只读层数与时钟。无新控件、输入、资产加载、委托、计时器、玩法或存档变化。按单条山脊复用裁剪／顶点／索引缓冲，几何数量固定。

新版设计图与动图从当前 C++ 控制点生成。离线展示用同样的细线／透明度剖面和锥形端部，作为设计示意；UE 的实际渲染仍由用户测试。制作和构建记录位于 `SourceAssets/WoodSteelLongbow20261026/MountainEchoMarksV22`。
