# F6 巫婆生成入口

用户要求在 F6 交互开发面板 → 怪物生成 → 怪物类型中加入“巫婆”，供其自行测试。复用原 UMG 下拉列表、冷钢主题、内容滚动、数量 1–10、距离 3–15 m、前方生成和本面板清除按钮，不增设页签或改动布局。

目录 ID `Witch`，实际角色类 `/Script/FPSGAME.WitchMonster`，占地半径 65 cm。`DevelopmentSpawnComponent` 拥有目录和生成实例；面板读取同一目录，选择和生成都使用同一 ID。重复打开时保留现有选择规则、焦点和 F6/Esc 返回行为。落点和失败文案沿用当前导航、地面、障碍合同，不创建测试关卡或修改存档。

角色使用本任务 Meshy 本体、PBR、独立道具和五段本地重定向动作，导入 `/Game/Monsters/WitchMeshy`。共用怪物行为树负责决策，角色负责施法/掷瓶动作时钟；F6 清除角色时清理该角色生成的投射物和毒液区。

必要工作包括资源导入、原生 Editor 构建及加载新类。未要求自动测试或截图，由用户测试；手指抓握精修和伴生煮锅保持单独的未完成项。

2026-09-20 导航反馈修复：Witch 新增 34 cm 半径、192 cm 通行净高、40 cm 台阶的独立导航规格（胶囊总高 188 cm）。当前 DayNight_Lighting 构建并保存对应导航数据。F6 保留角色显式导航净高，分别显示无导航、体型不匹配、正在生成导航的原因；不放宽安全落点限制，也不要求用户自行修复场景配置。
