用户实机反馈：上一轮右手持锤的手肘、手臂仍扭曲。因此下方“完整骨段最短摆动”方案不再作为右臂当前方案，也不将其源姿态计算视为视觉验收。

- 原右臂只对齐上臂方向，未约束原生肘关节的屈伸平面；最短摆动可能把上臂放到反向弯折的一侧。现在由原生上臂／前臂方向确定铰链，上臂与前臂共享铰链轴，屈伸与轴向旋转分开。肩带支撑根据该平面求解，基础屈伸区间为 45–110 度；极限落点为保留肩端可达距离可减小屈伸。这些是本模型的作者角度，不是医疗意义的关节测量。

- 右前臂先建立完整的肘端坐标系，90 度的轴向旋转差通过原生两根 lowerarm_twist 辅助骨按沿臂位置逐段过渡；只分配纯轴向旋转，不把腕部折弯四元数按分数混合，也不向已旋转的父骨重复叠加累计角。上臂与前臂在肘端保持共同铰链，避免把掌向修正集中在肘尖。
- 相机肩端安全约束改为绕固定手腕摆动整条已弯曲骨链，保持肘部屈伸平面；不再独立搬动肩部后用最短摆动补偿肘部。锁骨与上臂保持同一骨段变形。左手持钳求解沿用上一轮。
