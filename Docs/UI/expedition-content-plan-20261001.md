- 概览明确三条固定组合及每条前后各 1–2 间过渡房，任选一路清理后经档案中心进入 Boss。显示全图 18–25 间与单路 8–11 间主要房间的口径，非本局已生成地图。
- 行前准备从当前状态模型、生命组件与弹药袋读取：生命、魔法、当前武器及其弹药、背包和夹层中的恢复品、主背包空格。只提示不足，不新增出征禁用条件。生命/魔法走廉价实时读取，其余只在模型变更时刷新，不逐帧重建。
