# 工匠大师 · 守备机械升级

研究「守备机械」后，在东门马厩对面的机械工坊瞄准工匠大师按 E。选择「升级守备机械」进入工坊页面。「闲聊」使用村民对话的逐字显示、数字选项和返回机制。

## 卡片与交互

升级页从屏幕右侧滑入，在常用桌面尺寸占宽约 38%。标题、余额、机械选择和收起按钮固定在顶部。两张机械卡使用模型图和马市曲边画框。未选中的卡片默认只显示图片，鼠标悬停或键盘导航聚焦时，名称栏从卡片底边滑出。选中后名称栏和选中圆点持续显示，移开未选中的卡片会收回名称栏。名称栏叠在图片上，属性列表的位置固定。面板高度低于 620 时使用紧凑缩略图，沿用同一交互。属性按伤害、装填冷却、专有属性、射程纵向排列，只有这一栏可以滚动。每行左侧对照当前值与下一级，右侧显示操作和灵魂费用。满级直接显示「已满级」，余额不足列出缺额，结算期间锁定购买，回执固定在底部。

点击「收起」、按 Esc 或手柄返回键会沿原路滑出，再回到工匠的交谈选项。开合期间拦截升级操作。返回交谈时显示简短回应，焦点回到「升级守备机械」。重新打开时恢复投石机页。

## 数值

每项独立三级，逐级消耗 200、400、800 灵魂。付款玩家承担费用，同一村庄中所有玩家、已有机械和新建机械共用等级。装填冷却从投射物离架起算。下表数字按界面精度显示。

自动索敌和手动瞄准读取同一射程。开火时锁定本发伤害、装填速度、爆炸半径或物理穿透；飞行中的投射物及已经开始的装填沿用开火时的数据。投石机红色虚线结束于石弹首次接触的表面。落点圆环按当前升级半径逐段投向地面或平台；冲击效果与伤害衰减使用同一升级半径。装填动作、声音和进度条按同一装填时长播放。

服务器核对对话、距离、世界、已显示的等级以及玩家余额；城防存档记录订单，角色档写入扣款回执，随后升一级。读档沿用城防恢复流程。旧世界各项默认为零级，村庄重置时清空。
