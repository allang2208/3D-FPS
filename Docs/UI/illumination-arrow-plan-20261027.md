# 照明箭 UI 接入

- 入口：现有技能列表（全部／主动／魔法分类），拖动绑定现有快捷栏；银色圆角方框图标与其他弓技能共用目录、详情、拖影、升级通知入口。
- 信息顺序：身份与修炼进度、当前／下级收益、操作与标记规则、修炼项目、完整 20 级成长表。
- 收益：扫描半径、沿途标记持续、直击标记／照明持续、承伤加深、实际释放冷却、实际法力消耗、升级经验；读取 `IlluminationArrowStats` 和共用 `ImpactDuration`。
- 修炼卡片：`ColdSteelUIStyle` 的 CardBrush、16px 内边距、名称左列／XP 右列，四项经验和去重规则。
- 响应：窄于 480px 的收益对照沿用两列堆叠；成长表新增直击／照明列，窄于 620px 改成每级分行，短标签和数值不逐字换行。
- 快捷栏：已搭箭金色状态、真实独立 CD 遮罩、未持弓／缺蓝提示；输入继续走统一绑定，不另建快捷键。
- 图标源：`SourceAssets/IlluminationArrow20261027/illumination_arrow_cold_steel.png`，内置 imagegen 生成。以当前元素火箭图为参考，保持银色圆角框、石墨底、对角箭矢，主体改为白金照明光和箭头双圆弧；无文字。复制到 Content 并通过作者脚本导入 UI Texture2D。
