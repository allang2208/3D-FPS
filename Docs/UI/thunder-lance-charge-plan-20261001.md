# 贯穿雷枪蓄力瞄准与提示

- 用户要求：蓄力时自由鼠标瞄准，杖前魔法阵，准星随 0～100% 收拢，未满充在准星内随机散射，满充提示“已充能完毕”。
- 数据：`FPSElectricMagicComponent` 唯一蓄力时钟；UI 只读进度与散射切线。初始半角 6°，散射切线乘 `(1-progress)`；以 `sqrt(random)` 在圆盘内均匀取样。用实际相机投影将散射半径映射到枪械十字准星的四条内端，适应视野和窗口比例；线条长度同步收短，100%只留中心点。
- 布局：准星位于屏幕中心，覆盖普通武器准星；文字复用体力／快捷栏上方的动作进度提示行，雷枪充能时优先显示。沿用现有字体、阴影、字号和红→黄→蓝→绿进度色，不新增面板或输入焦点。
- 交互：保留原地蓄力和最短 0.5 秒；允许鼠标转动，2.5 秒满充后保持到松键或再次点槽释放；死亡、控制、菜单及原有打断仍走原退款清理。蓄力持有继续排斥其他魔法。
- 场景表现：已有电团保留；白蓝双环与符文魔法阵直径64 cm，位于同帧杖尖前方24 cm，朝向当前相机前向，以相机右方向固定平面方位。加粗环线、14倍发光、起始覆盖.8，随充能提高亮度。空手继续使用原施法起点。
- 实现：电系组件、角色 Turn/LookUp、`ColdSteelCrosshair`、`ColdSteelStaminaHUD`、共用 `ColdSteelUIStyle` 进度颜色、技能说明、独立魔法阵作者脚本。
- 交付范围：后台资产制作／保存和 Game／Editor 必要构建；不运行游戏、截图或测试。
