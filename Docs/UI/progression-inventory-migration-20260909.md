## 交互

- `C` 属性页，`B / Tab` 背包；`Esc / B / Tab / C` 关闭。打开时停止持有的射击/瞄准，关闭释放输入锁和拖拽状态。
- 鼠标拖动移动、合并兼容堆叠、交换或穿戴；拖动预览只读，放下重新验证同一套规则。
- 双击使用/穿戴/卸下；`Shift + 点击` 拆半；操作区支持指定数量拆分、整理、保存及二次点击丢下。
- 消耗品拖入四个快捷槽绑定，右键解绑，游戏内 `1–4` 使用；恢复实际 HP/MP，满资源不浪费，冷却期间拒绝重复使用。
- `G` 切换已装备武器组；换弹只从背包扣对应口径弹药，并一次性增加该武器实例弹匣。
- 丢下保存为带地图/位置的地面实例，靠近 `E` 拾取；满包保留地面物品，重复拾取不重复获得。
- 键盘方向键选格、`F` 切装备/背包/快捷区、空格拿起或放下、Enter 使用、X 拆分、Delete 二次确认丢下。

## 状态、事务与存档

`UColdSteelStatusModel` 是本地单人状态所有者。物品具备 GUID、定义、完整加工/配件 JSON、数量、占格、位置、上次背包格、冷却及弹匣；成长保存等级、经验、六维、点数、击杀、活跃武器组、生命/魔力和快捷绑定。运行时 Pawn、控件、拾取 Actor、拖拽预览、死亡去重集合不序列化。没有网络同步或服务端 RPC；联网模式拒绝本地持久化写入。

所有背包/加点操作先在副本上生成方案、检查版本及容量，然后写盘校验成功才发布给角色与 UI。保存失败不提交物品变化。正式档为 `Saved/SaveGames/ColdSteelPlayer_A.sav` / `_B.sav` 与各自 `.sha1`；选择最高有效代次，最新损坏时回退前一代。读取先验证字节长度及摘要，再反序列化，避免截断 SaveGame 触发引擎断言。两个版本都坏时保留原文件并阻止写入。

保留 v1；并行仓库任务扩展到 v2，缺少字段使用默认值，下一次成功提交写为 v2。带有效摘要的 v1 可读取。此处不导入 Godot 用户现有个人存档。背包、加点操作即时保存；生命、弹匣、冷却每 5 秒及退出时保存，异常退出最多丢失该检查点间的纯运行变化。

验收全部使用 `-ColdSteelProfile=InventoryAudit_...` 独立命名空间，不更改正式玩家存档。
