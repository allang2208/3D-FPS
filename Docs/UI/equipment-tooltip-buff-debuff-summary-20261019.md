# 装备缩略浮窗增益/减益分组 · 2026-10-19

用户要求：装备浮窗重新调整显示格式；缩略浮窗上方一块显示增益（如防御+、施法速度+），下方一块显示减益（如移动速度-），颜色区分，增益用冷钢 UI 的金色，减益用黑色；遵守 UI 规则。

## 范围

- 只改物品浮窗的**摘要区**（缩略浮窗；详情浮窗顶部共用同一摘要）。
- 不改变物品数据、数值公式、强化/附魔/套装效果，也不改变武器、枪械、弓、近战和工具的核心数值。
- 摘要区只在“核心行全部是修正项”时分组：护甲、饰品、背包、魔法书等以 `bonusStats`/防御为主的装备。武器核心行含中性数值（伤害、射速、弹匣等），继续走原两列网格，避免把中性参数误标成增益；没有正负修正的纯中性物品也不强行分组。
- 分组摘要在详情浮窗的“详细参数”里不再重复列一遍；详细卡片、特效、装备对比保留原有绿/红语义色。

层级：分区标题 14px 加粗；属性名 14px 常规；数值 16px 等宽数字。增益/减益的标签与数值同色，靠字号、字重、标题色和两块之间的一条细分隔线区分，不靠背景色块。

## 判定规则

- `defense`（防御力）与 `equipment_magic_attack`（装备魔攻）固定为增益。
- `bonusStats` 按“数值方向 × 是否越低越好”判定：
  - 越高越好（施法速度、施法距离、魔法攻击力、暴击、暴击抵抗、眩晕抵抗、最大生命、最大生命%、近战物理攻击、移动速度、近战攻击速度、换弹速度、拉弓速度等“速度”词条）：正值为增益，负值为减益；
  - 越低越好（魔法冷却、魔法消耗、ADS 瞄准时间、近战体力消耗、奔跑体力消耗等“耗时/消耗”词条）：负值为增益，正值为减益。
  - 判定按**词条语义**而非单纯正负号：同样是 `-0.05`，移速/攻速/换弹是减益，冷却/消耗则是增益。
- 增益块在前，减益块在后；每块按固定显示字段顺序（防御、最大生命、暴击抵抗、眩晕抵抗、近战物理攻击、攻速/移速、换弹/拉弓/施法等）列出，不再截断为 4 行；两块之间只画一条 1px 中性暗线。
- 数值带真实符号：正增益显示 `+10%`，冷却/消耗类减益显示 `-25%`，防御显示 `+75`；不把减益强行写成正数。
