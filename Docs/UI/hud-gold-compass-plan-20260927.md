# 主 HUD 淡金与位置调整 · 2026-09-27

## 用户定稿与范围

以用户实机截图及其认可的预览为准：玩家生命、魔法、等级移至左下；移除常驻 F6 开发面板按钮；顶部中央为罗盘与真实命中目标状态；事件栏放在右上时钟左侧，收起时同宽同高、顶边对齐。保留技能快捷栏、体力、四个右侧入口及近战/枪械信息的原有布局与数据。

## 布局与样式

- UMG 保留原玩家状态和事件控件树及数据入口；罗盘和短金角线复用 HUD NativePaint，目标反馈沿用 ColdSteelCrosshair。
- 时钟和事件轨道共用 `HUDCornerWidth=286px`、`HUDCornerHeight=72px`、`HUDGap=12px`；事件展开按钮在轨道下方，不算入轨道高度。展开详情仅向下显示，轨道宽度保持不变，不移动或遮盖右侧时钟、中央罗盘。
- 左下卡片最大 440×136px，等级在左、生命与魔法上下两行在右。底部空间不足时上移至快捷栏上方，不缩小字体。
- 罗盘在宽屏顶部中央；当与右上组合空间不足时，放到该组合下方的独立行。怪物反馈始终位于罗盘下方。共享 ColdSteelHUDLayout 计算位置，避免各自读取上一帧几何。
- 新增 HUDGold #C7AA70、HUDGoldLight #E8D39A、HUDGoldDim #756447；仅用于角线、等级框、罗盘、入口快捷键和快捷槽交互强调。中性灰底、银白正文、品阶、加工标记、生命/魔法/体力颜色不改。
- 工程原 Noto Sans SC / JetBrains Mono、图标和背景继续复用。无新图片或第三方素材依赖。

## 数据、状态与输入

- 生命来自 FPSCombatHealthComponent，魔法和玩家等级来自 ColdSteelStatusModel；保持原 20Hz HUD 刷新。
- 罗盘只读本地控制器朝向，世界 +X 为 N、+Y 为 E，连续跨越 0/360。未接入任务导航数据，不显示假路标。
- 目标沿用已确认攻击的 GetMonsterHitFeedback，保留 4 秒显示/淡出、击杀与基础/附加伤害拆分；等级只在 MonsterCoreStats 能识别目标时显示。状态从该目标已有 StatusEffectsComponent 读取，随现有 20Hz 刷新最多展示六项及溢出计数，不创建玩法状态。绘制不扫描世界、不加载资源。
- 事件保留原真实天气/入侵数据、彩虹进度、展开/收起/详情、筛选与动画。浮窗按新锚点限位。抽屉打开期间与时钟一起让位。
- 仅移除屏幕上的 F6 按钮；保留键盘 F6 开发入口和原输入恢复。
- 快捷槽金边只在悬停、对应键按下或实际火球准备状态出现；不固定选中预览中的第一槽，不更改冷却、拖放有效/无效颜色和快捷键。
- 无额外线程、定时器、绑定；沿现有 WidgetTree 与 HUD 生命周期释放。无库存、战斗数值或存档结构修改。
