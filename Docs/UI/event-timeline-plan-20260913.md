## 来源与问题

game-dev 的 `src/ui/panels/hud-panels-misc.js` 保留“展开信息→事件轨道→展开按钮→独立详情”的结构，收起关闭详情。`game-style.css` 1620–1800 行使用360／560px宽度，宽度、内边距和箭头旋转约0.16秒 ease；事件位置另用0.18秒 linear。`src/world/world-event-timeline-system.js` 固定现在位置4%、未来事件向现在移动。

当前 UE `ColdSteelHUDWidget.cpp` 的外壳始终绘制较亮蓝灰轮廓，缩略只隐藏标题等子控件；宽度与内容直接跳变。正文混有9／10px字号、Windows符号字体和未经DPI换算的尺寸，详情固定高度并裁切内容。

## 实施结构

- 缩略态只显示无外轮廓的深色时间轨道、事件图标、现在游标和展开入口。主外框、玻璃背景、展开区和详情在收起结束后不绘制、不接收输入。
- 展开态采用当前黑灰玻璃和银白细边：标题20px，筛选14px，辅助与倒计时12px。中文／普通UI使用Noto Sans SC，紧凑时间数字使用JetBrains Mono；图形箭头由几何组成，移除系统符号字体依赖。
- 展开宽360→560px，服从视口两侧12px边距；缩略轨道30px，展开轨道含时间标签约52px；顶部避开实际生命魔法栏。筛选按钮2列等宽、36px高、4px间距。展开入口为56×24px的紧凑披露控件。
- 0.16秒CSS ease曲线驱动宽度、内边距、展开区高度、淡入和180度箭头旋转；中途反向从当前进度继续。结束时真正Collapsed展开背景和内容，避免残留边框。事件坐标0.18秒线性过渡，保留现在4%和未来时间换算。
- 详情与主栏共享主题，标题／关闭固定，主体ScrollBox滚动；按当前面板底部定位，宽高限制在真实视口内，窄窗详情从两列转为单列。点击事件图标可展开并打开详情，收起／无事件／Esc关闭详情。
- 保留实际UE天气模型、5日范围、雨势分段、手动天气、已有筛选和事件点击入口；不添加尚未接入的入侵事件或支援玩法。普通时间轴改为中性灰渐变，天气与雷暴标记保留业务语义色。
