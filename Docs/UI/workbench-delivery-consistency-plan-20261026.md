# 工作台交付 UI 一致性调整（2026-10-26）

用户要求将枪械交付区配色复用到木工、药剂、铁匠，并审计调整这些面板。范围为管理/交付界面，不更改制作公式、材料结算、存档或小游戏判定。

## 统一规则

- 四类工作台共用评分/增减颜色函数。评分从红到绿；实际修正正值绿色、负值红色、显示为 0.00% 时默认灰色，无正负零。
- 面板主标题 20px、分区标题/评分/统计 16px、收益和辅助说明 12px、正文 14px、按钮 36px，沿用物理像素及 DPI 换算。
- 各项指标独立着色，保持横向排列；窄窗口按整项换行。失败原因仍用文字明确表达，不只靠颜色。
- 完成时显示交付结果，完成条填满；领取失败工件的按钮明确不可领取。材料返还以已保存的本轮投入和面板说明为准。

## 源码审计发现及调整计划

| 面板 | 当前不一致 | 调整 |
| --- | --- | --- |
| 铁匠 | 材质与命中收益混在一条文本，0% 非中性灰；结束条按命中率未填满 | 拆分伤害/材质/命中，增加命中率折算评分；老工件只展示其真实总修正，保留旧规则说明 |
| 木工 | 整行按达标着色，损伤可被染绿；失败工件仍写领取成品 | 分别显示评分、清除、损伤；已达标成品显示实际物理/魔攻修正，未达标明确无成品可领 |
| 药剂 | 产量、偏差、评分整行同色；完成文字与其他工作台不同 | 拆分指标，偏差单独标红；按本炉配方快照显示实际产量相对基础产量的修正，不虚构药效加成 |
| 操作区 | 铁匠与药剂三个按钮挤一行；免材料时废弃按钮仍可能承诺返还一半 | 领取/废弃保留主操作行，冶炼/手册独立工具行；废弃标签统一，实际返还说明保留 |
| 公共布局 | 已有标题、菜单物理字体、材料表格、内容滚动与固定底栏 | 沿用既有一致实现，不重写选择器和业务流程 |

执行必要后台构建。按用户规则不启动编辑器，不运行游戏、自动截图或追加运行验收；视觉交付由用户测试。

## 源码 UI 审计结果

- 公共配色已抽到 `ColdSteelCraftingResultStyle.h`，枪械也改为使用同一实现。显示精度与颜色一起取整，避免看见 0.00% 却标成红/绿。
- 三个管理面板分别覆盖选方、未完成/暂存、完成、失败及领取后回到选方时的颜色和显隐重置。业务的保存、同步、背包与操作就绪门槛未改动。
- 铁匠新工件总修正读取 `System->Multiplier(Job)`，材质和命中单独显示；旧品质版本隐藏不适用的分项。新增百分制评分仅为命中率的显示换算，不改变伤害结算。
- 木工成品修正读取与领取一致的 `ColdSteelWoodQuality::FromScore`，区分弓物理与法杖魔攻。失败工件不显示虚构成品收益。返料区移除已成功工件重复的灰色评分/修正文案，失败原因保留。
- 药剂基础产量来自本炉保存的配方快照，产量修正为实际瓶数相对该基础产量的变化；没有改动单瓶药效。配方记录不可用时明确显示无法计算，不以当前目录配方代替。
- 检视了标题/菜单/正文/数值的字体与 DPI 路径、材料三列表格、主体滚动、参数区独立滚动、固定底栏和按钮高度。已有一致路径保留，新增结果项按整项换行，冶炼/手册行沿用共用按钮间距。
- 失败标题、损伤和偏差保留文字及红色提示；没有仅靠颜色传递失败原因。药剂原有的二次废弃确认仍保留。

本次审计为源码和数据流审计，未进行运行时视觉验收。
