# 常规工作台面板审计与调整（2026-09-28）

## 范围与依据

用户要求按打铁和枪械组装规则审计、优化常规工作台，保持直接制作，无小游戏。
本次以当前 `ColdSteelForgingWidget`、`ColdSteelGunAssemblyWidget`、`ColdSteelUIStyle` 和正式冷钢规范为准。执行源码与调用链审计、实现和必要后台构建；不启动编辑器或运行游戏验收。

## 审计发现

1. `UpdateInventoryLayout` 常规工作台仍按冶炼的剩余宽度再次减边距，不能保持与背包、打铁和枪械面板等宽；关闭时还会提前清空布局宽度。
2. `RecipeTitle` 只初始化为“—”从未刷新；下拉框缺少共享按钮、菜单、选中行和 DPI 样式。生成选项没有反射声明，且返回裸 USizeBox，未采用枪械面板修复过的 UUserWidget 生命周期。
3. 材料表先按旧批量计算，随后才钳制批量；材料为零时“最多 1”和按钮仍启用造成误导。
4. 固定高度的成品参数区没有内部滚动，长名称和参数可能溢出；图标固定 256×256 画刷破坏非方形图源的比例。
5. 缺少与枪械面板相同的开合输入门控，且未消费面板空白处鼠标事件。
6. 数据每 0.1 秒无条件读取库存、物品 JSON 和设置状态；预览却只按配方失效，角色数据改变后参数可能过期。

## 布局与样式

- 外壳与背包等宽、上下 12px、零缝贴合，沿用原滑出与收回动画；字体、玻璃、卡片、描边和按钮使用 ColdSteelUI。
- 固定标题和底部操作；中间依次为配方与材料卡、制作摘要卡、图标与成品参数、简短制作说明。
- 标题 20、分区 16、正文/控件 14、辅助 12px；批量加减和主按钮统一 36px；下拉菜单复用枪械面板的生成选项控件和样式。
- 制作摘要三列分别标识材料可制作份数、本次份数和产出件数。小宽度下预览改为上下排列，参数可滚动；不缩小正文。
- 已有升级侧栏保留，但说明明确尚未开放，不承诺不存在的升级效果。

## 数据与交互合同

- 配方目录、消耗和产出不变，仍由 CraftingSystem 管理。材料取背包与主仓库，普通产物入背包，弹药原有分流保持不变。
- `CanCraft` 与 `Craft` 共用准备事务：相同批量、材料与产物可放入判定，只有实际提交调用 CommitState。背包满、材料不足或保存失败均不产生部分扣料/产出。
- 先按持有材料修正批量，再同次刷新全部材料需求、摘要、按钮和容量原因；零材料时可制作份数显示 0。
- 库存 OnChanged、切换配方、调整批量与开台标记数据变脏；Tick 只做布局、动画和合并后的必要刷新。预览在配方或模型数据改变后失效。
- 开合期间禁止制作和切换，鼠标落在面板内消费输入；关闭和焦点恢复沿用 HUD。Model 事件 Construct 绑定、Destruct 解绑，下拉选项由 UUserWidget 管理 UObject/Slate 生命周期。
