- 固定标题／返回、目的地下拉栏、底部消耗与确认。单目的地也显示下拉；列表来自已有目的地数据，不添加未开放的虚构地牢。目的地可分别指定横幅，未配置时显示中性图形。

- 内容宽度不足 1000px 时上下排列，准备卡随情报滚动；奖励、路线网格随列宽重排。底部确认持续可达；长清单使用滚动，不挤成竖排文字。

## 数据与操作

准备卡常驻当前武器、食物、水与饮品、药水的实际名称与数量；只读背包和夹层，排除仓库。饮品显示剩余次数，区分半瓶；过期食品显示变质且不计可用量。武器备弹来自弹药袋并识别无限弹药、当前双持及独自副手；弹匣不计入备弹，法杖／近战显示无需备弹。以档案变更事件刷新，并缓存展示结果；NativeTick 只处理布局档位。

调整装备由控制器暂时隐藏原出征控件，复用 HUD 的个人主仓库和背包，存取／装备／保存走现有业务。关闭任一整备面板或 Tab／外部点击关闭背包时，恢复原控件、目的地、页签与滚动位置，立即刷新携带数据。Esc 保留先取消拖动／关闭详情的现有语义。最终退出或换图清除返回回调；HUD 析构不触发返回；移动／视角锁按各自所有者配对释放。
