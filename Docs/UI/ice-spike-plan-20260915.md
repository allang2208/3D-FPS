# 冰锥技能接入规划

按技能／魔法、冷钢 UI 标准实现，默认由用户测试。

- 入口：现有技能抽屉的全部／主动／魔法列表，冰锥置于火球之后；点击详情、拖动至七个混合快捷槽。保留已有绑定，迁移不覆盖槽位。
- 布局：复用 ColdSteelSkillPage 的卡片、固定页签与返回、独立滚动；480px 以下数值行分两列，正文按宽度换行。没有新增弹窗或输入模式。
- 样式：共享 ColdSteelUIStyle 与既有字体；冰蓝主体、银色六边框、石墨底。列表、详情、快捷栏、拖影、升级提示共用 skills.json 的图源。
- 数据：IceSpikeStats 同时供施放快照和当前／下级详情使用，显示每枚伤害、枚数、整轮理论伤害、固定项、魔攻和智力系数、魔法消耗、整组结束后冷却、射程、速度、悬浮时限。伤害明确为未扣魔防、未计暴击和额外套装增伤。
- 状态：快捷槽显示等待左手／凝聚／齐射／飞行／冷却，缺蓝沿用变暗与反馈。资源缺失时拒绝扣蓝；满级显示 MAX。数量读取真实活动投射物。
- 模型持有扣蓝、冷却、修炼与存档事务；组件持有施放与整组生命周期。旧存档补入等级 1 冰锥，不触发升级提示；中断的实体不恢复，保留预留冷却。
- 复用现有 Slate 生命周期、拖放取消、菜单锁定与关闭行为；图像由 UPROPERTY 持有，Slate 释放时重置按钮引用。实时值沿用属性绑定，布局只在尺寸变化时刷新。
- 本轮范围：Skills/IceSpike*、FPSIceSpike*、共享施法手势小接口、状态模型／快捷栏／技能页／角色组件注册、Content/Skills/IceSpike 与数据、来源和制作工具。无退役资源。
- 必要构建完成后交付；本轮不启动游戏、不制作验收截图、不运行测试。
