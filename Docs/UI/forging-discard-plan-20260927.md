# 锻造成品废弃与材料返还

用户要求：已打造、尚未领取的装备可直接废弃，返还一半材料。

- 页脚在领取与冶炼入口之间增加「废弃 · 返还一半」，沿用冷钢共享按钮、36px 高度、4px 间距和等宽布局；锻造中、未结算或没有成品时禁用。点击直接执行，无额外确认弹窗。
- 成品状态卡显示实际返还材料与数量。每种材料按本轮实付数量的 50% 向下取整；当前高地双手剑返还铁锭 4、木材 1。
- 新工件在扣料时把实际配方材料数量存入 ForgeJob，随角色档保存。已有旧工件没有该字段时使用对应配方作为兼容来源。
- 材料返还背包，使用现有堆叠和空间规则。先在角色快照中放入全部材料，再清除待领成品，最后一次 CommitState 提交；空间不足或提交失败时保留工件，不部分返料。领取与废弃共用同一份待领工件记录，成功后无法再次操作。
- 不改变锻打动作、品质公式、冶炼队列或自动入箱行为。按现有事件刷新材料与返还说明，不新增 Tick 或每帧读档。
- 完成必要后台构建；不启动编辑器或游戏，不主动测试、截图或验收，交由用户测试。

## 交付
