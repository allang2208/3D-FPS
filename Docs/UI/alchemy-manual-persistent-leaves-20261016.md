# 配方手册：可复用双面纸页

## 本次范围与结构

用户要求文字、图片始终跟随纸张翻动，落下后不刷新或切换显示；保留长按拖动和书签跳转。本次替换纸页载体和变形路径，保留现有封面、书签、字体配色、纸上排版、镜头取景与透明背景。

- UMG 宿主仍负责打开、B/Esc/Tab 关闭及焦点回收；预览控件仍负责目录、书签和长按拖动输入。
- `UAlchemyManualComponent` 负责三个纸页实例及两个 2048×1536 跨页 RenderTarget。配方和目录数据仍由现有 `FAlchemyManualView` / 页面控件提供。
- `UBookLeafComponent` 是可复用的双面骨骼纸页组件；没有专用配方、库存或存档逻辑。所有实例共用 `SK_BookLeafTemplate`，正反面各自使用动态材质。
- 初始打开和翻页准备阶段绘制目标内容。拖动、回弹、自动翻页只改变骨骼与层高。关闭仍释放页面纹理、页面控件和渲染器；销毁同时释放三个纸页组件。
- 现有按窗口尺寸限制的捕获、ScaleBox 布局与无背景模型显示保持。准备未完成时继续使用现有加载提示；不增加面板或操作栏。

## 连续纸页合同

当前左右页分别由两个实例显示，第三个实例处于被覆盖或隐藏状态。向后翻页时：

1. 当前右页本身成为翻动页；它的正面保留当前内容。起动前只准备仍不可见的背面和下面待露出的右页。
2. 背面的下一张左页随纸张逐渐转向镜头，下一张右页通过几何遮挡逐渐露出。
3. 同一张纸落在左侧并继续显示。完成函数只调整逻辑角色和页码，不写材质参数、不绘制纹理、不隐藏落下的纸页。
4. 被盖住的旧左页到下一次翻页准备时才被复用。向前翻页使用相反的角色分配。取消拖动将同一张纸原路放回。

支持页的层高在翻动过程中平滑移动一张纸的厚度，端点回到统一的阅读高度。目录及首末书签跳转使用同一套逻辑：起动前准备目标内容，目标内容随翻动面和下面的纸页出现。跳转不逐页播放所有中间配方。

## 模板与材质

- 原有细圆角纸页轮廓、48×24 网格及双面 UV 得以复用，厚度为 0.032 cm。
- 新模板含 `BookRoot` 及 `Page_00` 至 `Page_30` 控制链，权重由制作脚本生成。
- 骨骼沿等长度分段积分弯曲，标准蒙皮同时处理位置、法线和切线。纸页材质不再含顶点位移或动画 UV。
- `PaperWidth`、`PaperHeight`、`RestArch`、`TurnBend` 集中在纸页组件。改文字、图片和配方不需重新制作模板或动画。
- 新书壳 `SM_AlchemyManualBinding` 已移除固定印刷面的整个网格岛，保留书皮、书脊、纸叠和金属装饰，避免固定纸面遮挡新组件。
- 新资产使用 `ManualV9` 路径；书签仍引用现有 V6 网格和 V8 材质、等比例印字。保留既有资产和归属声明。

## 交互与接入

长按 0.16 秒后的拖动、松手完成或回弹、目录点击、首页/末页书签、键盘翻页和关闭均保留原入口。捕获白名单增加骨骼纸页，镜头取景继续由书壳和书签决定，避免翻页时镜头缩放。工作台与私人阅读器共享相同纸页组件。
