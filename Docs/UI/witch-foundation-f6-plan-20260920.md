# 巫婆动作基础候选：F6 接入

本次只向现有怪物选项数据源新增一项，不增加面板或改动抽屉结构。入口为 F6 → 怪物生成 → 巫婆·动作基础候选。沿用开发面板的冷钢样式、滚动、焦点、数量、距离、生成反馈和清除机制。

数据归属为 `UDevelopmentSpawnComponent::Monsters`；ID 为 `WitchFoundation`，原生类为 `AWitchMotionCandidate`，列表位置在原巫婆之后。原巫婆选项保留。候选沿用巫婆 34 cm 半径、192 cm 导航高度和 65 cm 生成占地规格，依赖已存在的巫婆导航数据。

该项仅用于第一阶段身体及持物动作判断：生成后接近玩家并停步；支持清除，不进入正式刷怪或存档，也不提供攻击、伤害与掉落。模型为完整人体动作基础，最终巫婆衣着在用户判断基础动作后继续制作。列表每次显示从现有组件读取；生成失败继续使用已有导航／空间提示。

不新增 UI 生命周期、保存结构、主题常量或替换旧怪物。按用户规则不自动测试、启动 PIE 或渲染。
