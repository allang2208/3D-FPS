# 符文长剑模块化与改造栏

阶段：制作并接入。沿用苍蓝星辉·双手符文剑 `ue_rune_sword`、既有动画、数值与 `gunsmith_parts` 存档。

- 五栏顺序：剑身Ⅰ、剑身Ⅱ、护手、握把、配重锤。剑身Ⅱ是刃面符文，其余为独立实体。
- 复用 UMG 宿主 `UM4GunsmithWidget` 与 Slate 冷钢工作台，保留背景、中央真实装配预览、左目录、右详情／组合实值、固定应用／取消。宽屏三栏，紧凑两栏、窄窗纵向滚动沿用现有响应布局。
- 选项图标使用符文剑专属实际模型 RGBA 图，完整等比显示；等待／缺失时回退类别符号，不借用寒晶专属外形。
- 卡片只写基本描述。右侧从 `ColdSteelMelee::Evaluate` 计算相对该栏原装的组合实值与差值，倍率由 `FMeleeModifiers` 提供。攻击耗时和耐力消耗越低越好；原装显示无额外修正。四段连击的第四段沿用第三段伤害倍率，单独显示。
- 模型目录按武器选择，保留原装接口、UV、法线、材质、驱动骨、攻击采样点。无独立外形的数值选项明确显示使用原装外形；符文只应用在独立剑刃。
- 持剑、改造草稿、物品预览、掉落共用 `ColdSteelModularSword`。实例身份及保存事务沿用 `UGunsmithSystem`，选项预览不扣物品、不写存档；应用才提交，取消恢复已装方案。
- 数据变化走原 `OnChanged`；窗口打开／关闭沿用 UIOnly／GameOnly、菜单停手、焦点返回。析构释放预览与委托，不新增 Tick 业务查询或弹层。
- 仅修改本次源脚本、独立模块资产、模块目录及改造展示，保留并行工作。必要原生编译使用编辑器内 Live Coding。

未要求预览、检查或测试；不启动 PIE，不制作验收图，由用户测试。
