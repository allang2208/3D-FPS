# 种植选择与开发开关 · 2026-11-07

## 范围与交互
- 继续使用工作台 UMG 宿主和既有 4×4 种植地，不改变作物数值、存档中的占地、成熟时间或产量。
- 作物改用其他工作台同款下拉栏：共享 36px 操作高度、14px 选项、菜单/按钮主题和 GC 安全的选项 Widget。
- 打开地块时无默认选择。单击空地只选一格；按住左键拖动按矩形选择多个空格，松开保留选择，点击另一格替换选择。已有植株保持整株详情和单株收获。
- 精确选择不隐式扩张。胡萝卜 1×1 可单格播种；番茄、土豆、小麦仍须完整连续 2×2 区域。奇数边长/不完整/被已有植株割开的选择明确禁用并说明原因，不偷偷补选或跳过未能播种的剩余格。
- 拖动拥有鼠标捕获；放开、捕获丢失、关闭面板、换台、失去输入就绪均停止拖动。拖动期间不允许提交。地图绘制和命中使用同一 SizeBox 实际几何，越界拖动钳制在地图边缘。

## 布局与生命周期
- 地块卡和右侧播种预览卡在同一 Grid 行垂直填满，顶部与底部对齐；窄栏仍按既有阈值上下堆叠，地图保持 4×4 正方形。
- 选择显示为单格高亮，预览列明选中格数、完整可播株数、每株与本批材料、原占地及原产量。没有完整占地时禁止播种。
- UI 继续使用现有模型 OnChanged 和种植序列变更；拖动仅在落入新单元时更新，最多处理 16 格，不新增每帧资源加载。
- F6 新增“无需种子也可种植植物”开关，继承现有自适应 UMG 卡片、OnChanged 刷新和收起/关闭生命周期。默认关闭，仅本次游戏会话有效，不新增持久化字段；关闭全部开关可重置。

## 数据与事务
- 新 PlantingSlots 仅携带最多 16 个真实格子索引。重复、越界、占用、不完整占地、无效身份/距离/视线/地块替换都由服务端重新校验。
- 批量按稳定行序生成不重叠锚点，在事务局部副本累计扣料和植株，全部成功后只提交一次。任一失败均不提交，沿用现有种植请求序号、服务端限频、共享世界日志和恢复规则。
- 免种子查询由权威会话 + 当前 GI 本地主模型决定。单人玩家或房主本人可开启；客户端和远端访客 ShadowModel 不继承房主开关，不接受客户端免费布尔。
- 免种子只跳过材料充足和扣料步骤，仍验证目录、模型、占地、数量上限和原生长/产出规则。正常模式仍从背包、夹层和主仓库扣料。
- 成功提交后清空选择；服务端失败保留所选区域和具体原因，避免把过期选择自动变为收获动作。

涉及 ColdSteelPlantingWorkbench、WorkbenchWidget 头文件/输入清理、PlantingSystem、PlantingNetwork、新增 PlantingSelection、InventoryRequestTypes，以及 DevelopmentTuningSubsystem / DevelopmentPanelWidget / DevelopmentTuningPanel。
本轮不启动游戏、PIE、截图或测试。必要编译结果另行记录；当前运行中的编辑器不能仅靠源码写入获得新反射布局。

## 用户追加：格内成熟进度与底部概览
- 16 个物理地格始终保留独立边界和进度轨道。2×2 同株的四格共享真实 PlantId 与成熟比例，点击其中一格仍查看同株，收获仍只结算一株。
- 条固定在格内底部：左右/底部 3px 内缩、8px 轨道高，轨道半径取按钮 6px 圆角减 3px 内缩。内容区另预留 15px 下沿；窄格先隐藏图标和次要文字，不隐藏进度条。
- 使用 `ColdSteelUI::ActionProgressColor` 的既定红→黄→蓝→绿随进度变化；不套顶部事件条的特例彩虹或生命/生存的低值警告阈值。
- 新原生 Slate 小控件由 NativeWidgetHost 承载。填充与扫光共用同一个圆角渐变网格，几何同时限于格内轨道，矩形裁切仅作额外兜底，边框最后绘制。不是用圆角背景掩盖会溢出的矩形扫光。
- 动效复用共享 `FColdSteelMeterTransition` 的短缓动，生长中的轨道以 30Hz 有界 active timer 显示低亮扫光；成熟瞬间 0.8s 内亮后稳定为绿色。空格和成熟静态轨道不保持定时器，面板关闭/换台/析构停止全部动效。只读现有 0.25s 成长快照，不新增高频世界/库存扫描、同步加载或材质资源。
- 底部为「种植概览」：空闲格数、种植中株数、可收获株数；最多列真实剩余时间最少的 3 株，按锚格去重，倒计时右对齐。没有生长植株时显示明确空态。
- 必要提示按成熟可收获/免种子/普通扣料状态显示，保留离线生长与拆除不返料警告。宽窄布局继续由现有滚动主体和固定操作页脚承担。
- 新增文件 `ColdSteelPlantingProgress.h/.cpp`。本追加仍只编译，不运行游戏/测试/截图；前一版 218 编译单元 + UHT 已通过（不链接），追加后的最终编译另记录。
