# 药水工作台交互 V7（2026-10-16）

本轮围绕玩家判断与实际器具操作修正：看手册决定投料、研磨、火候和圈数，观察药液融合后装瓶。初级生命／法力药水仍是自动基液、投入主料、低火搅匀两圈、装瓶；不增加计时或研磨步骤。

## 逐项排查与修改

| 对象／路径 | 问题与修正 | 玩家操作 |
|---|---|---|
| 基液瓶 | 从原模型拆分瓶身／瓶盖；自动基液配方显示“已加入”，不再误提示继续投料 | 旧配方需要时左键投料 |
| 赤脉花萃取液 | 投料原先移动成品量瓶；现在移动选中的萃取瓶。滴管先竖直拔出，再移开，倒完归位 | 左键投一份 |
| 蓝髓结晶 | 使用原结晶罐的瓶身／盖；固体以颗粒落料，避免全用液柱 | 左键投入，需研磨时右键选料 |
| 活化催化剂／第三材料槽 | 分别读取实际配方槽、模型和数量，瓶盖也参与同一命中；退出本炉后清除材料布局缓存，恢复旧批次重新读取配方快照 | 左键投入，配方需要时右键选入研钵 |
| 研钵 | 采用实际研钵与研杵边界命中，浮窗说明当前材料与按住／释放操作 | 按住左键研磨 |
| 搅拌棒与锅面 | 统一 Slate 事件坐标与视口反投影；按下即拿勺，短暂停顿发送零转速，直到松开才放下，避免反复重启取勺动作 | 按住左键绕锅心画圈 |
| 火候 | 增加台面上独立旋钮、四档实体刻度，取代难找的锅底加热环点击区域；旋钮方向匹配档位 | 左键加档，滚轮调节，右键关火 |
| 沙漏 | 独立命中和金边，浮窗明确十秒辅助计时；计时与步骤解耦保持原设计 | 左键翻转 |
| 成品量瓶与汤勺 | 量瓶仅用于装瓶；勺内液面随舀取出现、倒出减少。液流进入量瓶口，量瓶液面从固定底部上升 | 左键收火并装瓶 |
| 配方手册 | 使用当前书本各个可见网格命中、描边，保留已有实体翻书／书签流程 | 左键或 B 查阅 |
| 背景瓶架 | 显示“陈列物，不参与当前炼制”，不显示可操作金边 | 无炼药动作 |
| 悬停反馈 | 同一命中结果驱动光标、金色外轮廓、名称、用法、禁用原因；浮窗随鼠标并限制在视口内，不拦截点击 | 悬停查看 |
| 鼠标捕获 | 松开、失焦、翻书、离台时释放输入与高亮；拖动暂停不结束工具动作 | 支持连续搅拌 |
| 联机与库存 | 沿用拥有者验证、服务端扣料／进度、忙碌限制、领取与作废半退；投料 3.3 秒、装瓶 4.2 秒统一在共享常量中 | 客户端只提交操作 |

## 液体与模型

- 坩埚继续使用铁匠台冷却水网格及 `M_QuenchWater`，加入材料时液位、药色随实际倾倒逐渐变化。
- 新投料／装瓶液流为八段连续曲线，使用透光材质、细微形变、流量渐入渐出、落点水滴与涟漪。固体使用独立颗粒；实例池最多 24 个，不持续生成 Actor。
- 新模型共 14 个：四种材料各自的瓶身／盖、旋钮底座、旋钮、备料托盘、研钵轮廓代理、水面冲击环、颗粒。原库存物品网格没有被覆盖。
- 新材质共 3 个：液流、颗粒、金色轮廓。轮廓只加入本机炼药相机，使用独立 stencil 229；不改变搜刮容器的描边。
- 17 个资产已保存到 `/Game/Building/PotionWorkbench20261015/InteractionV7`，烹制目录已登记。

## 后台核对与范围

- 14 个导入网格的 UE 实际包围盒与导出数据逐个对比，误差不超过 0.02 cm；材质引用齐全。

- 检查两种初级配方仍只有投料与搅拌两个配方步骤，两个搅拌方向均可。
- 构建与交付回执位于 `SourceAssets/PotionWorkbenchDesign20261015/InteractionV7`。最终 Game／Editor 构建结果以 `delivery.json` 为准。
