# 强化与附魔：UI 审计与改造台风格同步

日期：2026-09-13。范围是枪械强化／附魔面板的源码 UI 审计和外观接入，依据当前改造台 `M4GunsmithLayout.cpp` 与冷钢 UI 正式规则。

## 审计发现与修改

| 原实现问题 | 本次处理 |
| --- | --- |
| 固定 1600×900 整体缩放、112px 左栏与 520px 右栏，窄窗依赖缩小全部内容 | 与改造台同步四档响应布局：208／438、184／394、上下排列、纵向排列；顶栏和确认固定，主体独立滚动 |
| 仅绘制半透明边框，没有真实背景模糊 | 左目录、项目卡区、右汇总使用三层真实 Slate 背景模糊，强度 5、半径 13；共享黑灰底色与顶部细高光 |
| 26／28／22 等非规范字号，像素数字直接传入 Slate 点数字体入口 | 统一为 20／16／14／12px，通过与改造台相同的像素换算加载 Noto Sans SC／JetBrains Mono |
| 左装备仅文字、窄栏断字；材料图标强制正方形比例 | 加入装备图标、名称、位置、强化等级；图像按实际尺寸等比显示，动态预览等待期间显示现有目录图 |
| 多行卷轴文字塞入一个按钮，完整描述易截断 | 264×142 图标卡片，独立名称／效果／词缀位置／选择状态／持有数；完整信息使用 Tooltip |
| 属性名和数字混合对齐，表头随整张汇总滚走 | 四列与改造台同比例，数字右对齐，表头固定，表体独立滚动；等级与层数改为整数 |
| 旧附魔效果减少时未标红 | 增强绿色、削弱红色、不变灰色；保留实际附魔伤害百分比行，与现有命中伤害计算并列 |
| 主标签和底部按钮尺寸不一致 | 标签与比较按钮成对均分，标准高 36px、间距 4px；取消／确认各宽 112px |
| 图标完成未独立通知选择栏；界面替换时可能丢失当前图标 | 图标完成事件仅 SetImage，不重建选择按钮；完整数据刷新显式使 Paint 缓存失效 |

历史截图 `Saved/EnhancementAudit/enchant-1280.png` 仅用于识别旧版排版，不作为本次运行结果。

## 实现与边界

- `ColdSteelEnhancementLayout.cpp`：Slate 外壳、玻璃、字体、按钮、四列表格和自适应重排。
- `ColdSteelEnhancementWidget.cpp/.h`：显示数据、图标、装备与卷轴卡片、选择反馈；保留公开确认／页签／旋转控件引用及原快捷键。
- `UColdSteelEnhancementSystem::Quote/Apply` 继续管理报价、Generation、重新校验、材料扣除与保存。此次未修改该业务系统、控制器、战斗公式或存档。
- 独立实时预览仍由 `UM4GunsmithWidget` 驱动，切换背包枪械只切换预览；旋转、复位、瞄准按钮调用原接口。没有有效实时捕获时显示目录图。
- `OnChanged` 刷新报价与内容；`OnReady` 只刷新装备图片。Construct 注册，Destruct 解注册并释放预览；Tick 仅更新布局档位与现有捕获，不轮询业务数据。
- 控制器继续负责 UIOnly、移动／视角锁定、返回背包和恢复游戏输入；Esc、Tab、K 和返回／取消沿用原关闭入口。Tooltip 使用 Slate 标准弹层。
- 主画面保留原 `/Game/UI/GunsmithWorkbench/T_WorkshopBackground`。此轮不生成或替换枪械、卷轴、材料贴图；金币原本没有 `ue_icon`，以“金”字标识展示。

## 后续调整：仅显示背包持有的附魔卷轴

用户检查预览后指定：附魔栏仅检测背包里的附魔卷轴，未持有的卷轴隐藏。实现如下：

- 同类型背包卷轴按堆叠合计，数量为零或仅在仓库时不生成卡片；卡片数量标注“背包”。已持有的卷轴继续遵守原兼容限制。
- 默认选择限定为背包已持有且兼容的卷轴；选中卷轴耗尽或移出背包后，刷新时清除旧选择。无卷轴时显示空状态并禁用确认。
- 报价与提交共用背包数量规则，卷轴费用只扣背包；魔法粉尘、强化石和金币维持原材料来源。
- 消耗汇总提示明确区分“卷轴仅计背包”和粉尘来源。
