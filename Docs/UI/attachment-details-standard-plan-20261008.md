# 配件详情统一结构

用户已授权游戏接入。参考现有握把的属性卡，适用于所有配件；本轮重点修正镇魔、金刚与蟠螭展岳。

- 顺序：名称／安装状态、简短外观描述、能力增减卡片、特效说明、基本配件说明、现有武器数值总览。
- 常驻数值卡片沿用 `AddValue`、`Calculate` / 武器 Evaluate、原厂槽位对照及收益方向。暴击率显示“改造暴击率（+25%）”，实值和差值使用 %；其数据仍按百分点相加。防御倍率增量标注百分比。
- 条件性效果单独分段：触发条件、效果、持续与刷新、解除。不得把高／中／低血量加成同时列成常驻能力，也不得因已有卡片而隐藏特效。
- 新目录字段 `special_effects` 保存独立说明；`effects` 继续服务列表／提示，不重复堆在详情。旧原生条件说明汇入同一个区块。
- 复用 `GunsmithUI` / `ColdSteelUI` 字体、卡片与颜色；数字右对齐，正文随详情列宽换行，段落小标题与正文分开。沿用外层滚动，固定按钮与完整总览不变。
- 选中变化刷新详情；切换选项滚至顶部，保留现有已装／待应用／原厂状态。不增加 Tick、业务写入、扣除或保存事务。
- UI 宿主仍为 UM4GunsmithWidget + Slate；现有打开关闭、输入焦点和解绑入口继续负责生命周期。
- 剑身纹样另更新原生矢量源及同路径遮罩，地面法阵和战斗数值保持当前版本。
- 必要交付：后台 Editor/Game 构建、剑身纹理实际导入保存；未要求测试、截图或验收，由用户自行测试。
