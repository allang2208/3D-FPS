# 战锤锻造瞄准跳动修复

## 用户现象与源码定位

在双手锤锻造中向锤胚上方移动敲打位置，瞄准点会突然落到下方。预期为鼠标向上时瞄准点连续向上，即使跨过锤胚边缘、中央孔洞或工胚阶段切换也不应发生屏幕位置跳跃。

第一处不连续位于 `AForgeInteraction::MoveAim`：旧代码先从 `Point(Aim)` 的当前高度生成视线，并与同一旧高度平面求交，只保存交点的 XY；随后 `Present` 又调用 `Point(Aim)`，按新 XY 改写 Z。`BlankSurface` 在外轮廓和孔洞内退回砧面 Z=91，而战锤工作面最高为 Z=96.9。于是相同输入在两个高度间来回切换，新的显示点不再处于刚移动的视线上。薄剑胚也共用此路径，但厚锤胚更明显。

## 修改

- Aim/StrikeAim 保存固定砧面上的视线坐标，鼠标灵敏度和 FOV 换算沿用原实现，不以表面高度作为下一次输入基准。
- 通过既有工胚剖面条带求视线与工作面的最近交点，跳过中央开孔；未遇到工作面时使用同一视线上的砧面点。光圈中心始终在同一视线上。
- 瞄准边界包含厚工胚的投影范围，远侧锤面仍可到达。
- 锤头和瞄准圈共用落点。接触时把落点换回原有工件 UV 给评分系统；中央孔洞/砧面不会冒充工胚命中。
- 目标光圈、配方、伤害加成和模型资产不修改。三阶段工胚使用各自剖面；纯 C++ 方法与辅助函数修改，没有新增反射字段或修改 Actor 内存布局。

每帧只遍历当前阶段的少量剖面条带，不读取渲染网格、不发起场景碰撞或动态资源加载。
