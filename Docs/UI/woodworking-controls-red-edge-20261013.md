# 木工操控与红色锯口修正（2026-10-13）

用户反馈：上罩悬空、旋转容易过头、拖动经常卡住、锯片边缘需要红漆并在小游戏中突出显示。

## 本次制作

- 从 V5 布局母版制作 V6：删除透明罩、两侧黄色包边、顶肋及支架／立柱／底座共整套上罩零件；桌体、锯片尺寸与挂点、摆件布局、放置尺寸保留。正式预览网格、无锯片桌体与独立转动锯片都重新导出并接入新修订路径。
- 锯片表面继续用原材质贴图与法线，外半径 14.4～14.6 cm 过渡到红色涂层，齿缘至 16.2 cm 涂红。整台预览与独立锯片分别使用各自正确局部枢轴。游戏用红线高亮实际木板上表面的切割弦线；练习画布同步采用红色锯口。
- 默认 Q/E 步进由 5° 改为 1°，Shift+Q/E 为 0.25°；状态栏显示当前角度。旋转不再取消鼠标抓取。
- 开机时允许横向微调和小角度切削，所有位移／角位移按固定锯口扫过的木料计入切削、损伤和原评分，未关闭损伤规则。
- 去掉旧旋转阻挡额外的一像素膨胀。停机时只阻止进入新木料，允许通过已有切口退料。旋转接近障碍时保留已经完成的细分角度，不把整次操作全部丢弃。
- 鼠标捕获期间经过控件边缘不会仅因 MouseLeave 解除抓取；离开游戏操作区、松键、失焦、关闭与结算仍结束拖拽。
