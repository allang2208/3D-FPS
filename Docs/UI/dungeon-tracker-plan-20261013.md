# 地牢探索追踪栏 · 2026-10-13

用户要求：左上状态栏下方增加透明背景、金白配色的任务追踪栏；主标题“地牢探险”，迎宾大厅与分流大厅同属第一阶段，副标题“迎宾大厅”。首个目标为击杀一只精英怪物，在分流大厅追加一只随机 M 系列精英。

## 界面与数据

- `ColdSteelDungeonTracker` 为主 HUD 内的透明 UMG 栏目，不获取键盘焦点或切换输入模式；采用共享 HUDGold/HUDGoldLight、TextPrimary 和 Noto Sans SC/JetBrains Mono。扩展排查后允许现有 Alt 鼠标模式滚动长列表与悬停全文。
- 顺序为主标题、区域副标题、阶段、目标与数量、进度说明。标题和数量单行，说明仅在宽度不足时正常横向换行。
- 左边距 12px，宽度上限 384px；起点在状态效果栏实际底边以下 12px，无状态时为 68px。窄视口避让罗盘和命中反馈区。状态效果增减、换行或视口变更后重新定位。
- 沿现有状态效果栏读取占位，不改动原生命/魔法/生存栏的位置。关闭或离开地牢时隐藏，控件由主 HUD 的 WidgetTree 持有和销毁，无额外全局委托或计时器。
- 每 0.2 秒从 TaskTrackingSubsystem 收集注册来源的快照；地牢来源读取运行中的节点和目标状态。仅变化时写控件，增删/重排复用任务和目标的稳定 ID；不读取磁盘、不重新解析目录、不扫描世界 Actor、不在 HUD 加载怪物。每个目标的完成划线仅在 0.45 秒动画期间逐帧推进绘制，不提高玩法数据查询频率。
- `DungeonRunSubsystem` 在绑定时从实际主题 `sequence` 缓存模块到区域的映射。一条 Route 包含两片区域，不能把整个 Route 当成一个区域。已接入货运区、医疗区、焚化区、生活区、生态区、动力区；目录未来可用 `display_name` 指定名称。
- 通过实际所在房间切换副标题，穿越连接通道和楼梯时保留上个房间，避免按直线距离跳到隔墙另一侧。未绑定或销毁的地牢不显示追踪栏；重新生成时重置房间与目标显示。
- 第一阶段显示精英击杀 0/1 或 1/1。按用户后续修订，击杀分流大厅的目标精英即可开启三个出口闸门，无需清理两个大厅的其余怪物；保留原闸门升起动画与动画结束后的碰撞解锁，不把大厅强行标为全部清理。闸门与 HUD 共用 `IsWelcomeEliteDefeated()`。
- 未完成时提示“精英位于分流大厅 · 击败后开启三处闸门”，完成时改为“目标完成 · 前往下一片区域”，移除大厅清理数量提示。
- 目标完成时，淡金删除线在 0.45 秒内从左向右以缓动划过目标文字；文字淡至 72% 并保留整条线，1/1 不划掉。重返已完成区域直接显示完成状态，不重播动画；切换到新目标或新地牢清除旧划线。
- 其他区域本轮接入名称与“探索当前区域”提示。后续各区域的具体战斗目标尚未指定，不伪造击杀数量、敌人或奖励。

## 精英生成

- `FacilityTransit` 额外加入一个精英槽位，迎宾大厅不另外刷第二只。2026-10-13 按用户反馈修订：进入迎宾/分流大厅、触发大厅战斗后，分流大厅的首次实际生成请求优先生成目标精英，随后再处理普通怪；精英不再等普通首波队列推进，不依赖普通怪击杀数或第二波条件。保留原职员与四只鼓囊、原第二波普通怪构成及原第二波触发比例；精英不参与普通第一波过半触发计算，但参与最终清场。
- 复用 F6 真实目录中的地面 M 系列：M-03、M-04、M-05、M-07、M-08、鼓囊 M-09、M-10、M-14、M-25、M-27、M-88。天花板悬钟需要独立附着点，未混入地面槽位。
- 用当前地牢种子与 `EliteSelection` 独立随机流选种类；相同种子固定同一个候选，不消耗布局或普通波次随机流。资源准备阶段仅追加这次选中的类，不预载整个精英池。
- 生成沿用大厅共享刷怪调度、原导航规格、胶囊/地面碰撞、玩家距离约束，并读取目录的实际占地半径。目标精英生成失败时保留原槽，下一次有界生成请求继续优先重试，成功前不推进分流大厅的普通怪生成。不会强制生成到碰撞体内，不把未生成目标当作完成。成功时记录 `[HallWaves] Objective elite spawned`，包含房间、实际类型、位置和当前普通首波击杀数。
- 在 `FinishSpawning` 前设置真实 `EMonsterRank::Elite`，接入现有韧性、战斗等级、击杀经验和灵魂规则。使用原 `DungeonEnemy.<RunId>.<Room>.<Slot>` 奖励去重，附加 `DungeonObjective.WelcomeElite` 标识，不额外发放任务奖励。
- 击杀状态由该槽实际怪物的权威生命值推进；普通删除、清理、重新生成和 F6 刷出的其他精英都不冒充目标击杀。现有运行重建会新建 RunId，追踪栏跟随该生命周期；本轮不增加跨新地牢继承目标的存档规则。
