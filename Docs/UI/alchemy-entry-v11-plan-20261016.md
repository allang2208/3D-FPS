- 栏目顺序：配方标题及下拉 → 材料三列表 → 状态卡 → 成品预览标题 → 左预览/右参数等宽区 → 操作说明。

- 初始材料数来自背包+主仓库；有批次时显示该批次实际托管材料，避免把已扣料又显示成缺料。配方、商品图标、效果、产量和温度来自现有配方/物品/批次数据。

- 管理页几何纳入 `HandleInventoryOutsideClick` 的保护区域，采用与打铁同样的可见性和命中规则。
