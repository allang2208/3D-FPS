# 技能栏与步枪精通

入口：`P`，或背包装备抽屉的“技能”页签。选择步枪精通卡片查看收益和修炼；`Esc` 从详情返回列表，再次按下关闭抽屉。分类中的主动／魔法目前是空状态。

## 被动成长

所有角色初始步枪精通1级，上限20级。每级需要当前等级×100修炼值；步枪击杀+10，有效要害命中+5，要害击杀合计+15。普通命中、场景物件、尸体、标记为 Summoned 或 NoSkillTraining 的目标不提供修炼。只计步枪直接伤害，不把后续毒伤归入精通。

| 每级累计收益 | 1级 | 20级 |
| --- | --- | --- |
| 步枪伤害倍率 | +1% | +20% |
| 步枪附加伤害 | +1 | +20 |
| 精神 | +1 | +20 |
| 步枪要害伤害 | +1% | +20% |

武器伤害为 `round(加工后武器伤害 × (1 + 等级 × 0.01) + 等级)`，之后加角色攻击。要害命中再获得精通的要害倍率。精神常驻，步枪伤害只在装备步枪时生效；换枪后已发出的子弹保留发射时的技能归属和要害倍率。

原作的随机暴击率与当前 UE 要害判定冲突，本次暂采用每级+1%要害伤害的迁移方案，不新增随机暴击。

## 升级反馈与保存

角色升级与技能升级共用顶部提示，按顺序弹出，每条约2.8秒，配原版升级音、黑灰玻璃卡、绿色收益文字和短暂低强度银白亮光。跨多级的同一事务显示起止等级与最终收益。提示排队、关闭面板和暂停不会撤销已经保存的等级；暂停冻结提示动画和音效。

使用现有 A/B 角色存档，旧存档补入1级0修炼。技能精神按等级计算，不反复写入基础属性。技能收益由保存成功后的模型状态提供，界面不直接改属性或扣除物品。

配置：`Content/ColdSteelData/skills.json`。当前版本固定1–20级；修改经验或每级收益时同步调整说明和技能版本合同。原图及音效来源记录：`SourceAssets/Skills20260913/provenance.json`。准备／恢复脚本：`py -3.11 Tools/UI/prepare_skill_assets.py`，需要本机原 game-dev 资源路径及 imageio_ffmpeg。
