# 强化材料与预览核对

强化石和魔法粉尘的写实 PNG 由本次内置图像生成工具原创生成，透明背景原图直接复制到 `Content/ColdSteelData/Icons/`，未引用外部商品图片。文件名为 `enhancement_stone_realistic_v1.png` 与 `magic_dust_realistic_v1.png`，分别以矿石、粉末试剂瓶表现。仓库、背包、详情与强化费用引用同一物品 `ue_icon`。

两种物品保持原 ID，分类为 `enhancement`（强化材料），`maxStack` / `stack_max` 均为 99999。`GrantEnhancementMaterials` 将旧实例的定义字段和上限更新，保留实例 ID、位置及其他数据；一次性把仓库库存补足到各 99999。已有超过该数量的库存不会删除。记录 `EnhancementSupplyVersion=1` 后不再重复补充，数量消耗按正常存档保存。仓库不足或保存失败时不部分发放，下次启动/开仓库重试。

已有编辑器进程需要重启加载新模块；正常存档在加载新模块后自动领取，本次验收只写独立测试存档，避免与旧编辑器同时写同一玩家存档。

预览核对：强化面板目前仍是 `ColdSteelWeaponIcons` 静态图片，不支持拖动旋转或视角切换。改造栏为 `M4GunsmithPreview` 实时场景捕获，默认 `SetSidePreview(true)`、零旋转，支持旋转及瞄准视角。两者都把枪轴向左对齐，但使用不同留白/缩放参数，因此不能称为同款默认构图。本次按检查范围记录差异，未改预览交互。

伤害核对：当前 M4 武器基础为 30，角色攻击为 `RoundToInt(10 + str*0.05 + dex*0.1)`；强化后命中基础伤害为 `(30*(1+L*0.05)+角色攻击)*(1+附魔damagePercent)`。例如力量/敏捷均为 10，角色攻击为 12，未强化 42，+5 为 49.5，+15 为 64.5。穿透和中毒为另行结算的命中效果。该公式用于实际 DamagePerShot；强化面板、背包详情和改造栏使用相同处理函数，刷新时从基础重算。
