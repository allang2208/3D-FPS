# F6 第三人称固定视角

入口为现有 F6 开发工具面板的「基本调参」页，在「玩家视角」下新增「第三人称固定视角」会话开关。F6 继续打开／关闭开发面板。

## 操作和状态

- 点击「未固定」自动进入第三人称，并缓存当前经障碍避让后的观察位置、朝向与 FOV，按钮变为「已固定」。
- F6 或 Esc 关闭面板后，仍可输入移动、攻击、旋风、冲刺、施法等指令。观察镜头固定在世界空间，不跟随角色位移、转身或动作相机反馈；玩法眼部与控制器继续正常工作。
- 再次点击解除固定，恢复第三人称跟随。调整位置和朝向后可再次固定。
- 原「玩家视角」切回第一人称时同时解除固定；「全部关闭」也解除固定。本次游戏结束后重置，不写档案存档。
- 死亡沿用现有死亡镜头优先级；新角色重新捕获观察位置。角色走到固定镜头附近时沿用近距离遮挡身体的规则。

## 布局和数据

复用现有 `FTuningRow`、共享 `ColdSteelUI` 按钮与卡片样式，不新增页签或外壳。标题为 16px，说明为 12px，按钮沿用 88px 宽与标准动作高度；窄内容区将按钮排到说明下方，主体仍由原开发面板滚动区承载。

`UDevelopmentTuningSubsystem` 保存开关并一次发布联动变化；现有 `OnChanged` 更新按钮状态。权限、禁用态、关闭时输入与焦点恢复沿用开发面板。相机快照保存在角色身体组件，复用 `CalcCamera`，不新增 Tick、计时器或资源加载；固定期间不重复执行跟随相机的障碍扫描。
