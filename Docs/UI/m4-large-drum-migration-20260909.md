# M4 大弹鼓迁移

操作：装备 M4，按 J 打开枪械改造，选择“大弹鼓 · 50 发”，点击“应用并保存”。“查看侧面”显示当前装备的实际枪体与配件，“瞄准预览”用于检查全息镜与机械瞄具组合。退出改造恢复手臂和正常持枪位置。

## 模型和材质

保留 Godot 大弹鼓的圆鼓、端盖、径向加强筋和内六角螺丝。压平过度鼓出的边圈，减少细小螺丝及共面区域的冗余面。26,380 三角面降至 13,908，减少约 47.3%；运行时为一个 StaticMesh、三个材质段。

连接颈取自当前 M4 原弹匣的真实上部轮廓，并向下构建鼓体过渡。安装后完整隐藏原弹匣材质段，拆卸后恢复。大弹鼓跟随既有 `WPN_SOCKET_Magazine`，不改变骨架或枪体网格。

外壳复用 M4 弹匣颜色和粗糙度纹理，使用深色非金属哑光参数；紧固件复用 M4 颜色纹理并单独设置金属属性。没有把旧弹匣的沟槽法线直接贴在新鼓体上。最终材质以 UE 游戏内截图为准，Blender 图片用于几何和动作检查。

粗糙度使用独立的 `T_M4Drum_Roughness` 线性副本，避免原贴图 sRGB 设置与 Linear Color 采样不匹配导致材质编译失败。验收脚本会拒绝弹鼓材质编译失败或资源加载失败的运行结果。

## 功能合同

| 项目 | 原厂弹匣 | 大弹鼓 |
| --- | ---: | ---: |
| 容量 | 30 | 50 |
| 开镜耗时 | 240 ms | 约 209 ms |
| 普通换弹 | 2.70 秒 | 4.725 秒 |
| 空仓换弹 | 约 3.467 秒 | 约 6.067 秒 |

沿用 Godot 的容量 +20、换弹耗时 ×1.75、开镜速度 +15% 合同。改造草稿仅改变预览；应用后由同一聚合结果驱动实际容量、换弹、ADS 和属性显示。拆卸装满的大弹鼓时，超出原厂容量的 20 发返还背包；无容纳空间或保存失败时整个操作回滚。配置属于具体枪械实例，重开游戏和切换武器均恢复各自配置。

普通场景消耗备用弹药；`DayNight_Lighting` 遵循项目已有的无限备用弹药与空仓自动换弹规则。

## 动画

先读取并渲染当前正常换弹和空仓枪机释放动作，再适配左手。保留 189 帧/229 帧源动作、原有右手、枪体、弹匣骨骼和枪机动作，仅调整左臂及手腕。左手避让偏移经时间平滑后重新解算手臂，避免接触点切换引起瞬间跳动。

运行时按照 Godot 弹鼓阶段映射拉长退匣与插入过程；机械音效跟随原动作事件时间映射。回填弹药必须等待完整换弹时长。该调整经过关键帧渲染和逐帧骨骼合同检查，不等同于每个手指、任意动画下的完整碰撞求解。

最终使用 `A_M4_DrumReload_Smooth` 与 `A_M4_DrumReloadEmpty_Smooth`。418 个源帧检查中，其他骨骼矩阵最大误差小于 0.000001；左手额外修正的相邻帧变化不超过 0.454 厘米。弹匣井上部轮廓最大位置误差约 0.000035 毫米。
