# 爆炸物屏幕边缘方向提示（2026-10-12）

## 目标与布局

根据玩家与爆炸物的水平相对位置、摄像机水平朝向，计算二维方位；由屏幕中心沿该方向与安全边框求交。正前方位于顶部，后方位于底部，左右分别位于两侧，斜向连续移动到对应边缘，不依赖投射物是否在镜头内。摄像机俯仰不影响方位。

箭头中心距屏幕边缘 48 个物理像素，黑底、描边和尖端均留在画面内；距离与数量标签沿方向向内退 44 像素，按文本实际尺寸收进视口。沿用 DPI 反向缩放，在极小视口下整体缩小。世界位置图标和避让准星区域保持原有逻辑。

## 警示表现与状态

- 箭头使用深色底、白色轮廓和实心填色，新增红色脉冲描边。轮廓最低亮度常驻，箭头主体不随闪烁消失。
- 对应屏幕边缘增加短红色线段和向内、向两端渐隐的光带，避免覆盖整个屏幕。
- 未落地时红边按 1.5 Hz 柔和脉冲；进入引信阶段后沿用真实引信进度的加速脉冲，越接近爆炸时刻光带越深。
- 可受爆炸影响但尚未进入高危提示条件时，箭头内部为共享警示黄；已触发引信且位于爆炸半径内为共享危险红，边缘光带也更亮。
- 受到场景遮挡时保留灰色低强调方向，不播放红色警示脉冲。
- 同方向 30° 内的多个爆炸物沿用原有聚合规则，以危险排序最靠前者决定方向、颜色、距离和引信，标签显示数量，最多八组。
