# 教堂修女对话与村庄建设方案

用户范围：双手交叠贴近小腹、衣料精修与去除十字架，接入冷钢对话、建设方案树及圣光传授。

## 页面与数据

- 交谈页位于画面下方，三段介绍村庄衰败、居民离去及恢复安全生产；结束显示“建设村庄”“学习魔法”。
- 建设子页复用当前技能树的卡片、连线、拖动与缩放；左侧树、右侧节点详情。根节点“村庄复兴”分出“修复围墙”“重建铁匠铺”。
- 本轮仅解锁建设方案，无资源扣除或即时建筑替换。状态区分可解锁、方案已解锁、建筑已修复。
- 魔法子页传授圣光，沿用角色 Lv15 条件。普通技能树不再提供圣光学习入口，保留既有已学进度与修炼、快捷栏。
- 共享 ColdSteelUI 字体、色彩、按钮与卡片，短文本横排，长说明滚动；小屏通过整体缩放，Esc 返回或关闭，关闭释放本面板的移动/视角锁。

## 权限与存档

PlayerController 的 ChapelDialogueComponent 拥有独立对话会话。服务器重新寻找近距离修女并判断距离、视线，建设方案写入当前丘陵世界存档后发布；同世界成员共享。圣光仅写入交谈者档案，远程玩家使用主机上的角色影子档案，保存成功后发布。

修女为各世界本地生成的教堂子 Actor。交谈只调整本机 Body 相对偏航，不改变 Actor 根变换、不复制朝向目标。不同客户端可同时看到她面向各自交谈者；退出后平滑回到原站位朝向。

## 已有建筑方案

- 围墙：`TemperateVillagePerimeter.cpp` / `CompleteVillageWallRepair`，Ruined A–D 与 Repaired A/B 独立网格，修复接口已有占用检查及存档写入。
- 铁匠铺：`HillsBlacksmith.cpp` / `CompleteVillageBlacksmithRepair`，`VillageShop.Ruined` 与 `VillageShop.Repaired` 两套部件，修复后启用现有铸造台。
- 两者都已有残破与修复设计。本轮树调用新增 `UnlockVillagePlan`，不会调用上述修复接口。未来建设任务完成时可调用现成修复接口。

模型检查仅按本次要求进行正面、侧面及手/袖口检查。必要构建与保存不代表联机或游戏操作已验收。
