# 手册连续翻页与书签字形（2026-10-16）

用户要求书签文字不要压扁；内容随纸张翻动逐步出现，不能在翻完后突然切换。

## 书签字形

V6 书签每侧贴图区域是 512×1024 像素，而实体为 1.84×2.35 cm。两轴像素密度不一致，使屏幕字形高度相对宽度仅约原比例的 64%。

V8 彩色字图改为 2048×1308（每侧 1024×1308），直接用 284 px 字号重新绘制“首页”“末页”，没有缩放文字图层。横纵密度约为 556.5 px/cm。现有封面书签模型与 UV 分区继续使用；先前的布纹法线、暗部补光、金属扣和独立交互反馈保留。

## 页面连续性

原活动页在自身局部空间保留向上的静态弧度，旋转 180° 后该弧度翻向下方，使落下的纸张钻到另一侧静止页下面。此外，下层内容曾在起翻后跨过 3.5% 进度时才更换。

本轮实现：

1. 活动页 UV1 记录原纸张中面的精确高度和从书脊到外缘的位置。正反面共用该坐标，解决原先镜像文字 UV 导致两面的卷角变形不一致。
2. 材质通过 `-2 × 中面高度 × TurnShape` 连续调整弧度，在 180° 时贴合另一侧静止页；纸张厚度保持 0.032 cm，并保留 0.008 cm 的微小表面间距。
3. 起翻前绑定全部四个面：前翻时为旧左页、新右页底层、旧右页正面和新左页背面；后翻时对称处理。新页从起始就存在，由活动纸页的遮挡逐步显露。取消原有的进度阈值换图。
4. 翻页结束只提交页码，把已经被落平活动页覆盖的底面接成相同内容，再隐藏活动页；不重新生成或重画页面。取消拖动则恢复原有两页。
5. 自动翻页时长改为 0.78 秒，松手后的收尾略放缓。页纹理仍只在目标页改变时绘制一次，拖动只更新变形与旋转。
