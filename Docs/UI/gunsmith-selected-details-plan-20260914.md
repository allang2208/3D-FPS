# 改造面板：当前配件详情与流动选中效果

## 范围与结构

按用户要求调整当前 UE 改造台。沿用 UMG 宿主中的 Slate、冷钢共享样式、工程字体与枪械库真实预览。左侧只生成当前武器允许且包含实际改造选项的分类；隐藏不可用分类及「待扩展」区域，分类选择与默认选择使用同一规则。

右上改为「当前配件详情」，只展示当前分类在草稿中选中的配件：名称、安装／待应用状态、该配件影响的当前数值及差值、完整说明。数值由现有 Calculate 分别计算当前草稿与移除该栏配件后的草稿，其他配件保持一致；不混入其他分类的独立效果。没有数值变化时展示已有功能效果或无额外数值修正的说明，原厂项也展示自身名称与说明。

右上取消 56／112px 小滚动窗，正文按实际宽度换行并自然向下展开。下方整枪总览随之下移，保留原有数值行、四列表头、比较按钮、收益颜色及表体滚动。下方至少保留 320px，右侧整体内容不足以容纳时可纵向滚动，保证所有说明和总览都可到达。窄窗重排后的右栏至少 600px；顶栏、应用／撤销及退出继续固定可达。

## 选中效果

真实配件在草稿中选中时显示绿色细边及从左到右的脉冲扫光；亮峰前沿较窄，后方平滑渐隐，每轮约 2.4 秒并留短暂停顿。扫光位于卡片边缘，不覆盖名称、图标和说明。原厂项保留中性选中边，已安装／待应用文字继续区分状态。

使用独立 Slate 绘制控件，颜色取共享 Success，亮峰与主文字色混合。动画只失效重绘装饰，不刷新武器预览、业务模型或重建配件卡片；切换选中后旧效果停止，新效果从左侧开始。控件不接管输入，释放随 Slate 树。

## 数据、输入与交付

继续使用 GunsmithSystem 的兼容数据、Draft、Installed、Calculate、Apply、Undo 和现有 OnChanged 通知；不修改配件数值、安装挂点、存档或库存。切换配件时详情滚动回到顶部，同一配件的被动刷新保留滚动位置。

文件范围：M4GunsmithWidget.h/.cpp、M4GunsmithLayout.cpp、M4GunsmithOverview.cpp、新增 M4GunsmithSelectedDetails.cpp 与 SAttachmentSelectionPulse.h/.cpp、本规划及冷钢正式规则对应条款。无新素材或字体。执行必要 Editor 构建；未要求运行、截图或测试，由用户自行测试。
