## 习得状态与存档迁移

现有存档里每个技能都至少是 Lv1（`ColdSteelSkills::Migrate` 会为缺失键补 Lv1），大量公式以 `Level>=1` 为前提，所以不用 Level 0 表示未习得，改为显式记录：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `FColdSteelProfile::SkillTreeVersion` | int32 | 0 = 旧存档，1 = 技能树已建立 |
| `FColdSteelProfile::LearnedSkills` | TArray<FName> | 已习得技能 |
| `FColdSteelProfile::SkillSpecs` | TMap<FName, FColdSteelSkillSpec> | 每个技能的专精投入：节点 ID → 等级 |

迁移（SkillTreeVersion 0 → 1，一次性）：

- 旧存档：技能树中的全部技能视为已习得（不回收任何已有能力）。用户规则「已有等级的技能直接算已习得」在旧数据里等同于全部已习得。
- 新档（角色等级 1、总经验 0、所有技能修炼值 0 且 Lv1）：只把根基技能（暴击、闪避、巧手）和各系初级起点视为已习得，其余按技能树前置解锁。
- 不在技能树里的技能（环绕飞剑、水晶照明等武器技能）不受影响，始终可用。

## 数据来源

- `Content/ColdSteelData/skill-tree.json`：由 `Work/SkillTreeMockup20261115/export_tree_json.js` 从认可的设计稿导出。包含分组、系别行、每个技能的列/行/前置，以及两套专精的节点、等级上限、点数、前置和效果参数。数值调整直接改此文件，前置等级可用 `balance.py` 重算。
- 技能名称、图标、描述、修炼经验仍由 `skills.json` 提供。

## 规则

- 前置：`{skill, level}` 技能等级；`{anyOf, level}` 任一满足；`{characterLevel}` 角色等级；专精内 `{pointsInvested}`。
- 习得：所有前置满足且未习得时可免费习得，提交 `LearnedSkills`，走 `CommitState` 存档事务。
- 未习得的技能：不能施放、不能放入快捷栏、不加修炼经验、被动加成不生效。
- 专精点：可用 = 技能等级 − 已投入点数。投入时校验等级上限、前置和点数。撤回只在 F6 提供（重置该技能 / 全部）。
- 效果标记 `implemented:false` 的专精节点在界面显示「开发中」，不能投入点数，避免点了没有效果。
