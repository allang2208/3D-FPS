# 本轮 HUD 改动专项审计 2026-09-27

范围：金色四角、事件轨道及横向展开、天气详情点击、图鉴入口资源。未扩展至其他玩法或资产。

## 发现与调整
- 已有修复：四角装饰从当前 PaintSpaceGeometry 绘制，UBorder 使用真实圆角半径，生命面板使用实际表面。避免 tick/paint 坐标混用及快捷栏固定半径被重复 DPI 换算。
- 新修复：窄屏事件栏展开原本只限制总体宽度，没有限制以固定轨道中心展开后的左界。现按中心至两侧安全边缘距离的最小值限制宽度，常规视口仍为 360px，窄视口减少扩张。
- 新修复：事件轨道 ClipToBounds，长天气标签不再绘出轨道范围。该设置在构建控件时应用，当前已存在实例需重新创建 HUD 后应用。
- 点击链：天气按钮刷新数据后按 bTimelineHasEvent 打开详情；重复点击保持打开，无事件关闭。全部筛选关闭详情、轨道标记切换详情、关闭按钮与 Esc 收起逻辑仍在。
- 图鉴入口直接读取 Navigation/codex_subject.png，既有目录暂存规则覆盖；PNG 为 1254x1254 Format32bppArgb，角像素 alpha=0。
