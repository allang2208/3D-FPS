# 冷钢 UI 正式规则 · UE5

版本：2.18 · 更新日期：2026-09-19。适用于当前 `D:/FPS3D/FPSGAME` 的 UI 开发。

本版收录用户已确定的改造台、装备背包、仓库和状态栏风格，替换旧规则中冲突的配色、透明度、字体和尺寸条款。旧网页与 Godot 文档是历史来源；当前 UE 实现以本文与 `Source/FPSGAME/UI/ColdSteelUIStyle.h/.cpp` 为准。

新建／改造面板、页签或栏目必须先按 [面板与栏目工作流](../../UI-WORKFLOW.md) 规划信息结构、布局、数据范围与状态，再按授权阶段制作。使用 [规划模板](panel-column-plan-template.md)，可复用经验收录到 [UE UI 技能](../../skills/ue5-ui-umg-slate/SKILL.md)。

2.16 将右侧三个栏目入口改为无底主体、双倍尺寸和 game-dev 悬停放大；保留原快捷键闪动、近战实时数据、浮窗参数、剑实时预览及冷钢主题。

2.17 把 F6「交互开发面板」纳入与背包装备相同的右侧抽屉规格（同尺寸、同弹出／收回动画、同打开让位），并写入抽屉贴右缘的现行条款；开发面板新增开发功能栏目，数值与产出仍走既有存档事务。

2.18 将建筑面板的分类、真实装配缩略图、字体角色、详情浮窗和缓存预算统一纳入第 15 节；修正旧示例中12px构件名称、ID缓存键和世界最长边取景的用法。

## 1. 视觉方向与单一来源

- 大背景使用中性黑灰，银白用于主要文字和选中强调；不使用蓝色染底、彩色装饰边框或整屏高亮。
- 改造台中央保留原枪械库背景和真实枪械预览，右侧完整详细信息汇总保留。
- 主面板、分区卡片、数据行依靠明度、细边、留白和字号建立层级。次级卡片共享主面板的模糊，不逐卡叠加模糊。
- 全局颜色、字体、标准按钮样式由 `ColdSteelUIStyle` 提供；`GunsmithUIStyle` 只保留像素字号兼容入口和同源别名，不维护第二套色板或字体加载器。
- 同类控件优先消费现有主题值。业务代码只负责专属布局、内容与数据，不复制另一套近似灰色规范。

## 3. 玻璃、边框与布局

- 背包、仓库、状态页所在抽屉使用真实 `UBackgroundBlur`：强度 **9**，覆盖半径 **21**；文字和图标绘制在其上方。
- 顶部生命／魔法栏及独立状态详情浮窗使用相同的玻璃和中性灰主题。主面板圆角 **10px**，分区卡片 **8px**，标准按钮 **6px**，轮廓 **1px**。
- 改造台保留已接入的三处 `SBackgroundBlur`，强度 5、半径 13；它是配合枪械库预览的工作台参数，不作为抽屉默认值。CSS blur 数字与 UE BlurStrength 不作一比一换算。
- 抽屉上下与左侧外沿保留 **12px**；右抽屉为第 13 节的持久入口预留右侧空间。背包装备／状态共用右侧抽屉，常规宽度为视口的 48%，限制在 720–1040px，并进一步服从实际视口空间。
- 仓库在左侧，保持 0.3 秒开合动画。两侧同时打开时等宽等高，中缝至少 12px，并随视口缩窄。
- 标题、页签、主要操作和页脚保持可达；主体独立滚动。超长名称换行或提供全文入口，不靠任意缩小字体塞入。
- 右侧抽屉（背包装备／状态／技能与 F6 开发面板）共用同一规格：贴视口右缘，外沿 12px，宽度为视口 48%、限制 720–1040px，并且不超过视口宽 − 12px；同一条 4.0/s 匀速进度驱动滑出距离、全屏 40% 压暗底与玻璃淡入。抽屉出现期间（含收回动画）右侧栏目入口、世界时钟与右下角武器详情同步收起，动画结束才恢复；仓库仍从左侧滑入。F6 开发面板位于视口 `ZOrder` 30（HUD 之上、改造台与拖影之下），使压暗底与玻璃覆盖 HUD 常规元素。
- 滚动条采用中性灰与约 **6px** 厚度；不改变既有滚动方向与输入消费规则。
- 装备栏与空间背包的物品槽卡片使用 `InventoryItemRadius` **5px** 圆角；卡片底色、冷却覆盖、外框与右上强化／右下改造／左下附魔角标共用同一实际矩形及不吸附像素的坐标。角标从卡片外缘内缩“当前边框宽度 − `ProcessingCornerUnderlap` **0.5px**”，半径同量减小，保持同心圆弧；普通／选中边框各为 **1／2px**，最后绘制在角标上方，以重叠消除接缝，禁止恢复固定 2px 内缩。朝内斜边保留三角形识别，轮廓使用 **0.5px** 透明过渡，扫光与底色共用圆角网格；小角标尺寸至少容纳实际圆弧半径，不再把半径截为角标尺寸的一半。沿用原语义色、动画周期和错相。仓库共享此物品绘制规则。实施记录见 [加工角标圆角匹配](item-processing-rounded-corners-plan-20260914.md)。

## 4. 字体与字号

| 角色 | 正式字体 | 字重／用途 |
| --- | --- | --- |
| `--bp-font-ui` 对应 UE `TextFont` | Noto Sans SC | Regular 400：正文、物品名称、普通按钮；Medium 500：标题、选中项 |
| `--bp-font-number` 对应 UE `NumberFont` | JetBrains Mono | Regular／Medium：纯数字、计时、坐标、堆叠、容量、紧凑数值 |

微软雅黑 UI、SimHei、宋体及 Consolas 不再是当前冷钢 UI 的首选字体。数字字体显式以工程内 Noto Sans SC 回退中文单位；武器名称、暴击条件等普通文字使用 UI 字体。

字号保留 **24 / 20 / 16 / 14 / 12 / 11px** 六档，一个面板通常使用其中四档：

| 像素档位 | 用途 |
| --- | --- |
| 24 | 重大展示标题，普通抽屉不用 |
| 20 | 面板标题、角色姓名 |
| 16 | 分区标题、等级、核心摘要 |
| 14 | 正文、属性名称／数值、按钮 |
| 12 | 辅助说明、职业、属性点提示、快捷键 |
| 11 | 极次要微型说明，不替代正文 |

状态页使用 **20 / 16 / 14 / 12px**。正文行高以 1.55 为排版参考，标题约 1.25；紧凑属性行通过垂直居中与留白保证可读，不缩字号。

`ColdSteelUI::TextFont/NumberFont` 接收 Slate 点数，保留既有调用合同：`Points = Pixels × 0.75 / PixelScale`。`GunsmithUI` 兼容入口接收经过 DPI 换算的像素值，在内部乘 0.75，不能重复转换。窗口布局变化时更新相关字体与控件尺寸。

四份静态字体统一位于 `Content/UI/GunsmithWorkbench/Fonts/`，由项目打包依赖带入；不依赖本机已安装字体或 `Saved/UIFonts`。来源、版本和 OFL 文本随同目录 `provenance.json` 保留。不得为换名或换路径复制一份同样的字体资源。

## 5. 按钮与仓库行为

- 同一行平级动作等宽分配、同高、等间距；普通操作统一深灰底与银白字，不通过不同宽度突出某一个动作。
- 仓库四个按钮依次为 **全部存入／取出同类／存入同类／整理仓库**。每个高度 **36px**，按钮之间 **4px**，等比填满可用宽度。
- “整理仓库”保留下拉菜单。标题相对整个按钮居中，左侧留白补偿右侧 8px 箭头与 4px 间隔。
- “存入同类”按操作开始时仓库已有的物品类型匹配，只存入背包中相同 Definition 的物品；**武器和全部可穿戴／副手装备不参与**，包括放在背包里的装备。
- 转移优先合并兼容堆叠，放不下的整组保留在背包，并继续处理其他同类物品；批量结果经一次保存成功后发布。原“全部取出”按钮取消。
- 加点是紧凑行内操作，采用 **24×24px** “+”按钮；仅有可用属性点时显示，仍调用原加点与保存入口。
- 悬停与键盘焦点采用银白边和较亮灰底；禁用态同步禁止动作。保留当前快捷键、焦点转移、滚动与关闭顺序，关闭不得穿透到世界攻击。

## 6. 状态面板

角色身份区将姓名／职业与等级／属性点分列；保留状态、基础属性、战斗属性、当前武器实值、详细信息、轮回信息。分区使用细边卡片、银灰标题标记和弱分隔，属性名称左对齐、数值右对齐，长武器名允许换行。

技能页按抽屉实际内容宽度布局：短标签、标题及数值横排，不用自动换行将其挤成单字竖列；长说明按明确的可用段落宽度换行。窄布局将等级、收益区重排到下一行，不缩小字号。修炼方式为独立细边卡片，名称左对齐、经验奖励右对齐，规则说明放在卡片底部。

生命、魔法、体力、经验沿用实际数据来源；缺少业务数值时继续显示“—”。六维加点、武器实值、详情说明、鼠标悬停／键盘焦点与存档逻辑保持既有合同。外观升级不生成占位属性或改变战斗公式。

## 7. 强化与附魔工作台

强化、附魔与改造台使用相同的中性黑灰大背景，中央保留原枪械库背景和独立实时预览。左侧装备目录、中央项目卡片、右侧汇总各使用一层 `SBackgroundBlur`，强度 5、半径 13、圆角 10px；内部卡片不再叠加模糊。

- 强化／附魔取消固定 1600×900 缩放画布。以实际内容区宽度重排：宽 ≥1450 且高 ≥520 时左栏 208px、右栏 438px；宽 1100–1449 且高 ≥520 时为 184px、394px。栏间距 12px，中央弹性填充。改造台按第 9 节使用加宽后的详情栏。
- 宽 740–1099 或高 <520 时，装备与预览在上、汇总在下；宽 <740 时顺序纵排。窄布局的汇总区至少 600px 高，以容纳项目、固定表头和材料汇总，外层主体滚动。顶栏和底部确认固定可达。
- 字体使用统一的 Noto Sans SC／JetBrains Mono，字号为 20／16／14／12px。通过 `GunsmithUI` 像素字号入口换算，不直接把 px 当作 Slate 点数。
- 左侧装备使用 48px 图标区域、名称、位置和强化等级。动态武器图标（含剑）未就绪时使用目录图标；图标就绪只刷新图片，不重建当前选择按钮。
- 加工面板中的剑从物品 `world_mesh` 创建独立模型副本，复用枪械场景灯光、最终色彩／覆盖率合成和短期贴图驻留。中央支持拖动旋转、滚轮缩放、双击／水平按钮复位；剑隐藏瞄准预览按钮。普通刷新保留视角，切换物品复位；预览操作不改变装备或角色姿势。背包和装备栏的剑图标使用同一模型、材质及图标队列，采用竖向构图适配 2×4 占格，工作台临时观察角度不写入图标。制作记录见 [剑的动态预览与图标](sword-preview-icons-plan-20260914.md)。
- 材料、卷轴卡片统一为 264×142px，图标区域 48px；名称、说明、状态与数量分开排版。卡片横向滚动，滚动条 6px；长名称和完整效果可悬停查看。附魔列表仅显示背包中数量大于零的附魔卷轴，仓库及其他位置不计入；未持有的卷轴直接隐藏。已持有但不兼容的卷轴禁用，粉尘不足时允许预览、禁止确认。没有卷轴时显示“背包中暂无附魔卷轴”。
- 同级按钮等宽，标准操作高 36px、相邻间距 4px；强化／附魔页签、当前／基础比较成对均分。底部取消和确认各宽 112px。只有最终确认使用银白主操作底色。
- 右侧按“项目摘要—数值比较—消耗汇总”排列，四列比例与改造台一致：1.55／0.94／0.94／0.83。表头固定，数据独立滚动，数值右对齐。收益用绿色、代价用红色、不变用灰色；耗时、后坐等越低越好的指标反向判断，不能一律增加标绿。数量、目标数、层数和等级显示整数。
- 强化和附魔继续读取现有报价、装备实例和材料数量；配件、弹药、库存位置、兼容限制与保存事务沿用原业务入口。金币没有图片资产，显示中性“金”字标识，不伪造材质图。
- 附魔卷轴的默认选择、卡片数量、报价数量和最终扣除统一只使用背包；卷轴移出背包或用尽后取消该选择并刷新列表。魔法粉尘、强化石与金币维持背包和仓库合计规则。

本次源码审计与升级记录见 [强化／附魔 UI 同步升级](enhancement-cold-glass-20260913.md)。旧强化台 112px 左栏、520px 右栏、固定画布和整页汇总滚动的条款由本节替换。

## 8. 冲突替换与交付规则

| 旧条款 | 当前替换 |
| --- | --- |
| 微软雅黑／SimHei／宋体 + Consolas 混用 | Noto Sans SC + JetBrains Mono，共享加载器 |

| 下拉标题默认左对齐 | 标题整体居中、补偿箭头占位 |

## 15. 建筑面板

- 分类源为 `DA_VoxelBuildPalette`，一级固定「材质／其他」；材质的「其他构造」展示公共形状与该材质归属的构件，「其他」只展示未归类构件。无效归属不得让条目消失，审计时列明。分类不从密度、颜色或文件名推导；栏目归属与实际表面材质分别处理。
- 保持右抽屉尺寸、动画、玻璃和让位规则。标题栏只放标题，选择／吸附／结构状态另行换行；页签固定、构件区滚动、页脚精简。空态说明可去哪里选择，不显示编辑器维护指令。
- 字体与第 4 节同源：Noto Sans SC 文字，JetBrains Mono 数值及单位；标题20、分区16、正文及构件名14、辅助提示12px。网格卡宽116px、最小高170px、图像104²、间距8px。名称铺满102px内宽并统一横向排版，放不下才换行；保留44px最小名称区，长名称增高，不缩字号、不裁掉下方行。括号附注及完整名称进入详情。材质行单独保留36px内容高与28px缩略图。尺寸、边距和字号一起响应 DPI。
- 滚动区固定预留6px滚动条，轨道宽度随DPI换算，禁止显隐时挤压卡片区。网格显式使用扣除边框、边距、滚动条和子级缩进后的宽度；展开另一材质不能让已有分类重新按默认宽度换行。1040px抽屉可容纳8张116px卡及8px间隔；较窄视口自然换行。
- 建筑详情为中性灰 `Tooltip/Border`，10px圆角，标准24px关闭按钮；标题固定、正文滚动，最大430×520px并受视口限制。中文描述与数字值按角色选字体，不能给所有详情值统一用数字字体。指针定位使用同一几何坐标空间，固定后的浮窗仍随视口限位。
- 缩略图复现实际静态模型与材质槽。逻辑构件展示装配后的框、扇等完整可见网格，在不播放的预览世界使用纯几何装配入口；不驱动世界逻辑、音频和粒子。固定正交视角，将各组件包围盒直接投影到相机坐标后合并，按投影中心居中、长边84%占幅留边；单格仍为半尺寸构图。图片使用 `ScaleToFit` 等比例居中适配，禁止拉伸、裁切填满或受文字挤压。共用工作台双通道透明合成。

## 16. HUD 径向控件（长按 R 弹种轮盘）

- 轮盘是**圆形 HUD 覆盖层**，不是抽屉内容：不给它加 `UBackgroundBlur`（矩形控件无法做圆形遮罩，硬加会破坏盘的形），改用分层中性玻璃表达同一套玻璃语言——连续底盘 `Content`→`GlassTint`、玻璃面、1px `Border` 细边，逐层叠加出厚度。
- 扇区填充保持中性玻璃；**等级／语义色只作标记**（内圈标识弧、图标底板），银白 `Accent` 只表示交互与当前状态（悬停、当前装填、活动盘、指针）。不得给扇区整片染色，也不做彩色描边。
- 整盘必须**读作一块面**：扇区之间只留发丝缝（≤0.0045 rad），缝下必须有连续底盘；内沿用一圈内圈环收口、外沿用一整圈 1px 细边收口。中心取消区允许留孔（它是取消手势与盘心文案的位置），但要用凹陷的两层玻璃中心与内圈环衔接，不能让扇区看起来是断开的片。
- 图标格用**中性凹槽**（深底 + 1px `Border`）+ **中心裁切的图**，不叠加等级色底板：等级图多半自带底板色（7.62 那套甚至是整块不透明等级色），再叠一层色块会把主体淹没。小格子里应当裁切取样放大主体（轮盘的 `FramedIcon`：复制共享画刷、只改 UV，比例一行常量），而不是把整帧缩下去；共享画刷不要为某个界面改 UV。
- 径向控件（弹种轮盘一类）格内的图标与文字**一律沿扇区中线用极坐标排布**（`Center + Dir(θ)·ρ`），不要用屏幕竖直方向的偏移：锚点在中线上并不够，偏移量加在屏幕 y 上会让非 12 点方向的格子整组内容偏向一侧（实测 30° 格子文字偏 63 px）。径向排布后扇区数与角度怎么改都保持居中。注意极坐标的几何上限：扇环可用径向空间要先算清（`Inner..0.97R`），图标尺寸 + 文字行高超出时只能牺牲其一，不要靠"再挤一点"。
- **数据缺失时的表现：缺图不留占位、不留空框**。物品/弹药图标字段为空时，不画图片也不画底板凹槽（弹药袋行不加图标槽、轮盘格不画凹槽），排版自动落到纯文字分支；**禁止拿别的口径、别的品类或别的档位的图充当占位**（本轮清掉了 `.45 ACP`/`.357 MAG` 指向 5.56 照片、`12.7mm` 指向 5.56 共 8 处跨口径引用）。有本口径素材就接入，没有就空着；新美术到位后只需把数据里的图标路径指回保留位置，不改代码。接入字段与机制见 [弹药图标接入](../Combat/ammo-icon-wiring-20260922.md)。
- **相邻元素要留净空，腾空间时逐对检查**。把某个元素挪进容器前，先算它和相邻元素的实际边界（不是中心距）：本轮图标凹槽内沿 123.0 与名称外沿 128.0 压了 5 px，就是因为只调了图标、没检查文字。做法：文字与图形之间至少留 4–5 px 净空，压缩空间时优先缩图形（本轮图标格 86 → 80 px），不要压文字间距到行高以下。
- **矩形元素按"整格内接"算，不能只算外沿**。轴对齐正方形相对中心在半径方向多出 `0.707×边长`（`√2/2`，45° 扇区最坏情况），只保证外沿不越界会让非轴向扇区的四角戳出圆盘（实测 96 px 格子角点 251 px > R 240）。做法：先定 `Rim=0.97R`、`HubOut=Inner+6px`，把 `0.7071×Side + Side/2 + 文字块` 从径向上限倒推边长，再令 `图标中心 = Rim − 0.7071×Side − 2px`；悬停放大**只向内长**（外沿与角点固定），否则放大动作自己会把角推出去。
- 层级顺序固定：外沿阴影 → 连续底盘 → 扇区 → 内圈环／标识／外沿 → 盘心 → 图标底板与文字 → 指针。悬停用外沿抬升（约 1.03R）+ 银白混色，不用放大整盘。
- 字号沿用第 4 节六档：扇区名称 14、扇区数量 20（数字字体）、盘心标题 16、说明与提示 12～14；选中项用 `TextFont(..., bMedium=true)`。非活动盘只压暗盘面顶点色（约 55%），**不调 RenderOpacity**，文字与图标保持清晰。
- 实施记录与参数见 [双持手枪：左右两盘弹种轮盘](ammo-wheel-dual-pistols-20260922.md)。
