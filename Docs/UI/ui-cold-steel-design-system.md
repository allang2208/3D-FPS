# 冷钢 UI 正式规则 · UE5

版本：2.3 · 更新日期：2026-09-13。适用于当前 `D:/FPS3D/FPSGAME` 的 UI 开发。

本版收录用户已确定的改造台、装备背包、仓库和状态栏风格，替换旧规则中冲突的配色、透明度、字体和尺寸条款。旧网页与 Godot 文档是历史来源；当前 UE 实现以本文与 `Source/FPSGAME/UI/ColdSteelUIStyle.h/.cpp` 为准。

新建／改造面板、页签或栏目必须先按 [面板与栏目工作流](../../UI-WORKFLOW.md) 规划信息结构、布局、数据范围与状态，再按授权阶段制作。使用 [规划模板](panel-column-plan-template.md)，可复用经验收录到 [UE UI 技能](../../skills/ue5-ui-umg-slate/SKILL.md)。

2.3 补充上述工作流入口并明确收益／代价颜色的判断方向；视觉参数与业务范围沿用 2.2。

## 1. 视觉方向与单一来源

- 大背景使用中性黑灰，银白用于主要文字和选中强调；不使用蓝色染底、彩色装饰边框或整屏高亮。
- 改造台中央保留原枪械库背景和真实枪械预览，右侧完整详细信息汇总保留。
- 主面板、分区卡片、数据行依靠明度、细边、留白和字号建立层级。次级卡片共享主面板的模糊，不逐卡叠加模糊。
- 全局颜色、字体、标准按钮样式由 `ColdSteelUIStyle` 提供；`GunsmithUIStyle` 只保留像素字号兼容入口和同源别名，不维护第二套色板或字体加载器。
- 同类控件优先消费现有主题值。业务代码只负责专属布局、内容与数据，不复制另一套近似灰色规范。

## 2. 配色与透明度

下列颜色为 sRGB；八位十六进制的最后两位是不透明度。

| 用途 | 主题值 | RGBA |
| --- | --- | --- |
| 主面板玻璃底 | `GlassTint` | `#1A1A1AF8` |
| 低画质回退 | `GlassFallback` | `#1D1D1DFF` |
| 顶栏叠层 | `HeaderTint` | `#64646416` |
| 内层深底／数值轨道 | `Content` | `#121212EB` |
| 分区卡片 | `StatusCard` | `#252525E8` |
| 弱行底 | `AttributeRow` | `#C8C8C809` |
| 主文字 | `TextPrimary` | `#E8E8E8FF` |
| 次要文字 | `TextSecondary` | `#B7B7B7FF` |
| 弱提示 | `TextTertiary` | `#919191FF` |
| 银白强调／选中边 | `Accent` | `#D6D6D6FF` |
| 普通细边 | `Border` | `#DEDEDE2E` |
| 按钮默认 | `ButtonNormal` | `#2B2B2BBE` |
| 按钮悬停 | `ButtonHover` | `#414141E6` |
| 按钮按下 | `ButtonPressed` | `#181818F0` |
| 按钮禁用 | `ButtonDisabled` | `#16161678` |
| 状态详情浮窗 | `Tooltip` | `#191919FC` |

“降低透明度”统一解释为提高背景遮挡：主底不透明度 **248/255，约 97.3%**。不通过降低整个控件的 RenderOpacity 调整底色，文字和图标应保持清晰。

生命、魔法、经验、危险、成功、稀有度、强化／附魔仍使用已有游戏语义色；颜色只服务对应数据与反馈。白色物品鉴定详情卡保留已有专用语义，不将其误作为深灰状态详情浮窗。

## 3. 玻璃、边框与布局

- 背包、仓库、状态页所在抽屉使用真实 `UBackgroundBlur`：强度 **9**，覆盖半径 **21**；文字和图标绘制在其上方。
- 顶部生命／魔法栏及独立状态详情浮窗使用相同的玻璃和中性灰主题。主面板圆角 **10px**，分区卡片 **8px**，标准按钮 **6px**，轮廓 **1px**。
- 改造台保留已接入的三处 `SBackgroundBlur`，强度 5、半径 13；它是配合枪械库预览的工作台参数，不作为抽屉默认值。CSS blur 数字与 UE BlurStrength 不作一比一换算。
- 抽屉四周保留 **12px**；背包装备／状态共用右侧抽屉，常规宽度为视口的 48%，限制在 720–1040px，并进一步服从实际视口空间。
- 仓库在左侧，保持 0.3 秒开合动画。两侧同时打开时等宽等高，中缝至少 12px，并随视口缩窄。
- 标题、页签、主要操作和页脚保持可达；主体独立滚动。超长名称换行或提供全文入口，不靠任意缩小字体塞入。
- 滚动条采用中性灰与约 **6px** 厚度；不改变既有滚动方向与输入消费规则。

## 4. 字体与字号

| 角色 | 正式字体 | 字重／用途 |
| --- | --- | --- |
| `--bp-font-ui` 对应 UE `TextFont` | Noto Sans SC | Regular 400：正文、物品名称、普通按钮；Medium 500：标题、选中项 |
| `--bp-font-number` 对应 UE `NumberFont` | JetBrains Mono | Regular／Medium：纯数字、计时、坐标、堆叠、容量、紧凑数值 |

微软雅黑 UI、SimHei、宋体及 Consolas 不再是当前冷钢 UI 的首选字体。数字字体显式以工程内 Noto Sans SC 回退中文单位；武器名称、暴击条件等普通文字使用 UI 字体。

字号保留 **24 / 20 / 16 / 14 / 12 / 11px** 六档，一个面板通常使用其中四档：

| 像素档位 | 用途 |
| --- | --- |
| 24 | 重大展示标题，普通抽屉不用 |
| 20 | 面板标题、角色姓名 |
| 16 | 分区标题、等级、核心摘要 |
| 14 | 正文、属性名称／数值、按钮 |
| 12 | 辅助说明、职业、属性点提示、快捷键 |
| 11 | 极次要微型说明，不替代正文 |

状态页使用 **20 / 16 / 14 / 12px**。正文行高以 1.55 为排版参考，标题约 1.25；紧凑属性行通过垂直居中与留白保证可读，不缩字号。

`ColdSteelUI::TextFont/NumberFont` 接收 Slate 点数，保留既有调用合同：`Points = Pixels × 0.75 / PixelScale`。`GunsmithUI` 兼容入口接收经过 DPI 换算的像素值，在内部乘 0.75，不能重复转换。窗口布局变化时更新相关字体与控件尺寸。

四份静态字体统一位于 `Content/UI/GunsmithWorkbench/Fonts/`，由项目打包依赖带入；不依赖本机已安装字体或 `Saved/UIFonts`。来源、版本和 OFL 文本随同目录 `provenance.json` 保留。不得为换名或换路径复制一份同样的字体资源。

## 5. 按钮与仓库行为

- 同一行平级动作等宽分配、同高、等间距；普通操作统一深灰底与银白字，不通过不同宽度突出某一个动作。
- 仓库四个按钮依次为 **全部存入／取出同类／存入同类／整理仓库**。每个高度 **36px**，按钮之间 **4px**，等比填满可用宽度。
- “整理仓库”保留下拉菜单。标题相对整个按钮居中，左侧留白补偿右侧 8px 箭头与 4px 间隔。
- “存入同类”按操作开始时仓库已有的物品类型匹配，只存入背包中相同 Definition 的物品；**武器和全部可穿戴／副手装备不参与**，包括放在背包里的装备。
- 转移优先合并兼容堆叠，放不下的整组保留在背包，并继续处理其他同类物品；批量结果经一次保存成功后发布。原“全部取出”按钮取消。
- 加点是紧凑行内操作，采用 **24×24px** “+”按钮；仅有可用属性点时显示，仍调用原加点与保存入口。
- 悬停与键盘焦点采用银白边和较亮灰底；禁用态同步禁止动作。保留当前快捷键、焦点转移、滚动与关闭顺序，关闭不得穿透到世界攻击。

## 6. 状态面板

角色身份区将姓名／职业与等级／属性点分列；保留状态、基础属性、战斗属性、当前武器实值、详细信息、轮回信息。分区使用细边卡片、银灰标题标记和弱分隔，属性名称左对齐、数值右对齐，长武器名允许换行。

生命、魔法、体力、经验沿用实际数据来源；缺少业务数值时继续显示“—”。六维加点、武器实值、详情说明、鼠标悬停／键盘焦点与存档逻辑保持既有合同。外观升级不生成占位属性或改变战斗公式。

## 7. 强化与附魔工作台

强化、附魔与改造台使用相同的中性黑灰大背景，中央保留原枪械库背景和独立实时预览。左侧装备目录、中央项目卡片、右侧汇总各使用一层 `SBackgroundBlur`，强度 5、半径 13、圆角 10px；内部卡片不再叠加模糊。

- 取消固定 1600×900 缩放画布。以实际内容区宽度重排：宽 ≥1450 且高 ≥520 时左栏 208px、右栏 438px；宽 1100–1449 且高 ≥520 时为 184px、394px。栏间距 12px，中央弹性填充。
- 宽 740–1099 或高 <520 时，装备与预览在上、汇总在下；宽 <740 时顺序纵排。窄布局的汇总区至少 600px 高，以容纳项目、固定表头和材料汇总，外层主体滚动。顶栏和底部确认固定可达。
- 字体使用统一的 Noto Sans SC／JetBrains Mono，字号为 20／16／14／12px。通过 `GunsmithUI` 像素字号入口换算，不直接把 px 当作 Slate 点数。
- 左侧装备使用 48px 图标区域、名称、位置和强化等级。动态枪械图标未就绪时使用目录图标；图标就绪只刷新图片，不重建当前选择按钮。
- 材料、卷轴卡片统一为 264×142px，图标区域 48px；名称、说明、状态与数量分开排版。卡片横向滚动，滚动条 6px；长名称和完整效果可悬停查看。附魔列表仅显示背包中数量大于零的附魔卷轴，仓库及其他位置不计入；未持有的卷轴直接隐藏。已持有但不兼容的卷轴禁用，粉尘不足时允许预览、禁止确认。没有卷轴时显示“背包中暂无附魔卷轴”。
- 同级按钮等宽，标准操作高 36px、相邻间距 4px；强化／附魔页签、当前／基础比较成对均分。底部取消和确认各宽 112px。只有最终确认使用银白主操作底色。
- 右侧按“项目摘要—数值比较—消耗汇总”排列，四列比例与改造台一致：1.55／0.94／0.94／0.83。表头固定，数据独立滚动，数值右对齐。收益用绿色、代价用红色、不变用灰色；耗时、后坐等越低越好的指标反向判断，不能一律增加标绿。数量、目标数、层数和等级显示整数。
- 强化和附魔继续读取现有报价、装备实例和材料数量；配件、弹药、库存位置、兼容限制与保存事务沿用原业务入口。金币没有图片资产，显示中性“金”字标识，不伪造材质图。
- 附魔卷轴的默认选择、卡片数量、报价数量和最终扣除统一只使用背包；卷轴移出背包或用尽后取消该选择并刷新列表。魔法粉尘、强化石与金币维持背包和仓库合计规则。

本次源码审计与升级记录见 [强化／附魔 UI 同步升级](enhancement-cold-glass-20260913.md)。旧强化台 112px 左栏、520px 右栏、固定画布和整页汇总滚动的条款由本节替换。

## 8. 冲突替换与交付规则

| 旧条款 | 当前替换 |
| --- | --- |
| 微软雅黑／SimHei／宋体 + Consolas 混用 | Noto Sans SC + JetBrains Mono，共享加载器 |
| 新字体仅限改造台、仍是候选 | 新字体已成为当前 UE 冷钢 UI 正式字体 |
| 蓝灰外壳与青色普通装饰 | 中性黑灰外壳、银白强调 |
| 抽屉 alpha 224/255 或沿用提案 0.72–0.84 | 主抽屉 alpha 248/255 |
| 固定 45% 贴边全高 | 当前留边自适应抽屉；仓库与背包装备等大 |
| “全部取出”作为第三按钮 | “存入同类”，排除装备武器 |
| 下拉标题默认左对齐 | 标题整体居中、补偿箭头占位 |
| 默认执行旧文档中的测试／截图／验收 | 仅用户明确要求时执行；必要开发与构建照常完成 |

历史方案与验收记录保留日期和当时结果，不再作为现行视觉规范。交付说明应区分代码修改、必要构建和实际测试；未测试时交由用户测试，不将历史通过记录当作本版结果。
