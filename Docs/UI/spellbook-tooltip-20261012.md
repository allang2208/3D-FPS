## 悬停浮窗

1. 图标、物品名称、魔法书类型、已有强化等级、所在位置；不显示装备稀有度。
2. 核心属性：**装备魔攻**。读取正在查看的魔法书及当前角色属性，包含该书强化等级。
3. 口径说明：按当前智力、精神与强化等级计算，装备于当前副手时生效。
4. **专注**：单独的金色机制标题，先说明搭配法杖、右键完全展开书本的条件，再以两列数值行显示施法速度 `+100%`、魔法消耗 `-25%`。加速与减耗都使用收益色。末尾简述开始合书、换装或专注中断时结束。
5. 沿用固定详情操作提示。

专注效果不混入常驻属性网格，也不依赖玩家已经进入专注才显示说明。数值仍取物品定义的 `focusEffects`，不是展示层写死的百分比。

## 固定详情

保留上述核心属性、口径和专注段，继续使用原有装备对比、详细参数和物品说明区。

- 物品信息为中文：分类“魔法书”、武器类型“魔法书”、装备槽位“副手槽”。
- 魔攻计算公式：`2+0.2×(智力+精神)`。
- 强化后魔攻公式：`2+0.4L+(0.2+0.08L)×(智力+精神)`，标题注明 `L=强化等级`。
- 两条公式合并相同系数项，使用既有全宽堆叠行（标题 12px、正文 14px），去掉多余空格及重复取整说明。
- 强化上限从强化系统读取，当前显示 `+15`。
- 专注在固定视图中只显示一次，不再复制进详细参数折叠区。
- 沿用物品原有背景描述，不向背景塞入实时属性或跨武器比较。
