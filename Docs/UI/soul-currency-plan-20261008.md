# 灵魂货币重构 · 2026-10-08

## 数据与迁移

金币退役为独立灵魂余额，兑换比例 1:1，数量不占背包格子、不拆分、不拖拽。`FColdSteelProfile` 新增带版本号的 `Souls` 字段，复用既有档案保存、事务和网络快照。旧档案内背包、夹层、仓库、已生成容器与遗留地面金币统一回收计入余额，删除旧金币实例和快捷绑定；迁移按剩余实例计数，可重复加载而不重复加钱。旧 gold 标识只保留迁移及旧调用的兼容识别。

击杀（含火球批量击杀）、地牢奖励、开箱、开发发放统一增加余额；强化与通用材料扣款统一从余额扣除，报价与实际扣款同源。战斗收益继续沿现有自动存档节奏，主动消费仍走原子存档事务。金币获取加成显示改成灵魂获取，旧 goldPercent 数据键继续兼容；金矿石、金锭等制作材料不属于货币。

联机沿当前库存客户端／战斗服务器分工，增加 `ServerSoulCredits` 累计授予水位。服务器收入通过未采纳的增量合并，客户端支付留在本地余额；同一镜像重复到达不会重复奖励，也不以最大余额回滚支付。字段随已有带名称序列化的档案传输。

用户追加规则（2026-10-08）：普通击杀与火球批量击杀的灵魂奖励，均直接使用该次击杀的最终角色经验奖励整数值（含等级差、怪物阶级与经验祭品加成）。例如奖励 120 经验，同时增加 120 灵魂；不再使用随机金币公式或额外乘以旧金币祭品系数。升级扣除经验进度不影响本次灵魂收入，技能熟练度经验不计入灵魂奖励。继续通过同一档案事务与服务器累计授予水位入账。

参考 [Elden Ring 官方入门指南](https://en.bandainamcoent.eu/elden-ring/news/elden-ring-starter-guide-tips-know-playing-the-game) 的独立持有数量与强化支付语义。本次是货币与显示重构，保留现有经验升级和死亡机制。

## 布局与反馈

- HUD 灵魂条贴在左下人物状态框上方，间隔 8px，随状态框窄窗上移；银灰冷钢底、金色火焰灵魂图标、单行名称与右对齐总额。图标同样用于背包余额及强化灵魂消耗，来源见 `soul-icon-plan-20261008.md`。
- 背包页签下、装备物品区域上方放置独立余额行；固定在滚动区域外，和 HUD 使用同一显示控件与同一余额。
- 总额变化以约 0.55 秒缓动滚动到目标，数字轻微弹跳；增加显示淡金 `+ N 灵魂`，减少显示暗红 `− N 灵魂`，上浮并淡出。短时同类变动合并，飘字最多三条。
- 初次读档和首次构建直接显示实际余额，不把存档余额当作新收入。隐藏的背包显示直接同步，重新打开不重播旧收益。
- 动画复用现有 HUD 刷新调用；无每帧 JSON 解析、存档写入或控件重建。
