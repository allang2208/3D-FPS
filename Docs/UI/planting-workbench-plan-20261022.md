# 种植地工作台与玩法接入（2026-10-22）

用户要求：选择番茄、土豆、胡萝卜、小麦种植；面板与此前其他工作台一致，包括尺寸和冷钢规则。

复用 `ColdSteelWorkbenchHUD` 的原挂载和 `UColdSteelWorkbenchWidget` 原外壳，增加种植模式，不另建窗口。
制作栏与背包等宽贴合、上下 12px，原 4.0/s 开合与输入门控；沿用右抽屉 48%/720–1040px 及双栏空间夹取。
`ColdSteelUIStyle` 提供 9/21 背景模糊、黑灰玻璃、1px 边框、10/8/6px 圆角、36px 操作高度。
共享 Text/Button/Card/UpdateScale，标题 20、分区 16、正文 14、辅助 12px；中文 Noto Sans SC，数字 JetBrains Mono。
作物使用与制作配方相同的下拉和 `UColdSteelGunRecipeOptionWidget` 行；选中/悬停/禁用复用共享样式。
主体独立滚动，固定标题、状态与提交；地块四列横排，保留完整标签及悬停说明，不逐字换行。

入口：已有 B→其他→种植地（2米×2米），放置后 2.5m 目视 E 交互，打开背包与同一工作台栏。
沿用 HUD 的 Esc/关闭/输入焦点/开合期间禁止提交、跨面板互斥；地块移除或超出 3.5m 自动关闭。

内容：作物选择 → 16 个作者种植锚点对应地块（大株占 2×2）→ 需求、库存、时间、产出、当前植株进度 → 播种/成熟收获。
空地可播种；占用不可重复播种；成熟后收获，背包不足保持植株不变。副占用格点击定位同一株。

没有找到独立种子目录；本轮默认每株消耗现有同名作物 1 个作种植材料，来源按普通制作的背包/夹层/主仓库合同。
可将配置 `input_item` 改成后续种子定义。没有增加种子商店或无关配方。
暂定平衡值（开发默认，非用户指定）：番茄 1800 秒/产 3、土豆 1200 秒/产 3、胡萝卜 900 秒/产 3、小麦 1200 秒/产 4。
0–50% 幼苗、50–100% 生长、达到 100% 成熟，使用实际 UTC 秒，离线继续生长，成熟后保留等待收获。
番茄/土豆/小麦占 2×2 格，胡萝卜占 1×1；统一随机缩放 0.9–1.0，朝向 0–360°，无额外位置抖动。
这些值集中在 `Content/ColdSteelData/planting_rules.json`，每株保存播种时的时间/产出/占格快照。

模型读取已导入的 `crop_models_v3.json`；变种 A/B/C、朝向、缩放、局部根位仅在播种时生成并保存。
地块根位来自种植地作者 manifest，米转厘米并按既有 FBX 转轴镜像 Y，多个占格取锚点平均。
只随阶段变化切换同变种网格；通过有上限的 36 个异步网格缓存和合批 ISM 显示，无逐株 Tick/同步 HUD 加载。

为使扣料/植株记录及收获/清地原子提交，新增植株数组直接保存在现有 `FColdSteelProfile`，使用 `CommitState` 的校验保存。
建筑档继续提供 WorldKey、构件 InstanceId 和摆位；不改 VBX 字节格式。旧档无新字段为空，不初始化覆盖旧字段。
地块移除后对应植株清除，不返还种植材料；同格新建地块的 InstanceId 不同，不复活旧株。
范围为单人闭环；本轮不新增游戏 RPC、共享地块所有权或外部联网服务。多人模式不提交种植操作，明确显示不可用。

已实现文件：Building/ColdSteelPlantingTypes、ColdSteelPlantingSystem；UI/ColdSteelPlantingWorkbench.cpp；工作台头/实现/HUD、WorldInteraction、VoxelBuildWorld 的窄入口；InventoryTypes/StatusModel 的档案字段；配置/Cook 目录。
