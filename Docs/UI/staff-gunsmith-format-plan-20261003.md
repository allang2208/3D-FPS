# 法杖改造栏统一格式（2026-10-03）

## 本轮范围

按用户指定，先统一法杖改造栏的格式。沿用现有 UM4GunsmithWidget 的冷钢三栏、独立模型预览、底部横向配件选择和固定应用／撤销操作，不新增法杖、改造件或战斗数值。

## 结构与布局

- 左栏：六槽分类图标、分类名及当前草稿件名称，与共用分类入口对齐。
- 中栏：保留真实装配预览；底部使用共用配件卡片、64px 等比图标、名称、简介、已安装／待应用标记及选中脉冲。法杖旧图通过共用图标容器展示，不重制 PNG、模型或材质。
- 右栏：当前配件名称 → 安装状态 → 外观说明 → 当前组合的数值与差值 → 完整配件说明 → 免费改造及激活条件说明。去除法杖提前返回导致的说明缺失。
- 总览：沿用项目／当前或原厂／改造后／变化四列及比较按钮。法术加成、元素效果和触发效果共用一份字段名称、单位、精度与收益方向定义；耗蓝增加为红、减少为绿，未变化显示「—」。杖头专精与杖冠激活状态分别显示实际配置。
- 继续使用共用宽／窄／矮窗重排、右侧整体滚动、正文换行、固定页头和底部操作。复用 GunsmithUI 字体、RowBrush、共享收益色与中性状态色。

## 数据与动作

数据来自 GunsmithSystem 的 Draft／Installed，以及 ColdSteelStaff::Resolve 后的实际 _craftEffects。所选配件差值与同一草稿恢复本槽原厂后的结果比较；总览与当前装备或原厂比较。其他槽保留，杖冠效果只在真实专精匹配时计入。

除已有百分比字段外，显示目录已有的冰锥数量、火球范围、闪电目标数、续疗／加速层数与时长、链式增益、寒冷、眩晕与灼伤参数，避免功能配件被显示成无数值效果。只展示改造增量与触发参数，不虚构最终法术伤害或新玩法。

选择、撤销、应用及实例保存仍走现有档案事务，保留免费改造。刷新仍由现有模型事件触发，不增加 Tick 解析、图像生成或整页重建。菜单输入、预览资源请求与清理继续由现有宿主管理。
