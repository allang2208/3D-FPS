# 图标异步回读与队列调度

用户授权继续优化。本轮沿用 F6 性能页及物品图标现有结构、主题、换行和滚动，只补充现有图标状态文本，不新增焦点、输入或业务操作。

- 同步 `ReadLinearColorPixels` 改为 `FRHIGPUTextureReadback`：最终捕获后排入复制，后续帧查询栅栏，确认就绪后在渲染线程复制 CPU staging 数据，线程池执行颜色/透明度转换，主线程只创建纹理与更新缓存、通知 UI。
- 每个图标子系统最多一项回读在途；GPU 对象只在渲染线程创建/使用/释放，工作线程不访问 UObject。退出、失败、取消时保留异步任务自己的数据生命周期，旧结果不得写入其他配方。
- 继续使用现有 RGBA16f 输入、反向透明度、SRGB 转换、有效像素门槛和图标尺寸。支持行跨度，禁止把整个 staging 行当成图标宽度直接复制。GPU/CPU 等待与执行时长分开表达。
- 资源等待约 2 秒且有其他已到重试时间的排队项时让出队首，单轮仍保留约 10 秒上限；延期后按 2/4/6/8 秒冷却。全部冷却时只轻量等待，不重复装配。等待 GPU 回读期间不换配方；超时走已知失败回退。
- 状态增加回读阶段、已等待时间、后台转换/拷贝耗时、冷却队列数及距下次可处理时间；快照复制数值后导出，未知时不当成零耗时。
- 源码范围：ColdSteelWeaponIcons、独立异步回读实现、FPSPerformanceMetrics/Export、DevelopmentPerformanceDiagnostics。必要 Editor 构建后交付，不自动运行 PIE、视觉或性能测试。

已知材质资产与目录回退图片修复仍需单独的资产接入；本轮先完成代码链路。
