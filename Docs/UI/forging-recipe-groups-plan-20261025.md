## 目标与结构

在铸造台的「配方 · 工件」选择条中，按武器类别显示不可选择的副标题，具体配方作为缩进子项。直接接入游戏，未要求预览或运行测试。

- 复用 `UDevelopmentItemPicker` 的冷钢分组菜单：16 px 中字重类别标题、灰黑底色、1 px 细线，14 px 单行武器名称，36 px 最小选项高度。
- 当前分为双手剑、双手锤、双手刀、单手刀。分类读取成品的 `weaponTypeTag`；战锤工胚将「双手钝器」细化显示为「双手锤」。组内保留配方原有顺序。
- 收起时居中显示「类别 · 武器名称」；展开时只允许选择具体武器，当前配方高亮。沿用冷钢字体、按钮与选中颜色，不新增图片资源。
- 菜单宽度至少跟随选择条，受视口边界约束；高度不超过 480 px 或半个视口扣除边距。矮窗滚动，长名称单行省略并提供完整名称提示。

## 数据、状态与生命周期

- 仅列 `ForgingSystem::Catalog()` 中的配方，选项键使用真实 Recipe ID，不使用分组后的下标或武器显示名称提交。
- 初始化时构建并缓存分组元数据，菜单控件仅在展开时创建。资料刷新只同步当前选项，不反复重建整表。
- 选择后沿用原有材料清单、成品预览与工胚刷新；不更改材料消耗、金属保底、命中奖励、存档或服务器制作入口。
- 正在准备、锻打、待领取或待结算时禁止更换；锁定、关闭面板、销毁或 DPI 变化时收起菜单。
- 分组标题没有按钮、焦点或选择回调；武器行沿用按钮键盘导航与滚动到当前选项。空目录显示「暂无可选物品」并禁用。
