# 手枪双持弹药栏

阶段：游戏接入，按用户规则不制作验收预览、不运行测试。

复用 `UColdSteelAmmoReadout` 与正式 `ColdSteelUIStyle`，保留 360 px 首选宽度、当前 DPI 和底部锚点；追加两行副手信息。主手沿用大号弹量，副手独立显示名称、口径、弹量／容量、备弹。长名称自动换行，矮窗继续由原 HUD 定位，新增内容按实际高度向上展开。

数据来自 `UPistolDualWieldComponent` 的两份装备实例和背包备弹计数。左右两行分别显示换弹、空仓、低弹和正常颜色；无限备弹显示 ∞。同口径两行显示同一备弹池，不相加。副手卸下时附加行折叠，主手标签恢复原文。

被动信息栏不接收输入，不写存档。控制提示为左键主手／右键副手；双持时取消 ADS。装备仍通过主手 6／副手 8 或主手 9／副手 11 的现有事务操作。
