# 满弓进度条脉冲

- 修改范围：现有 `ColdSteelBowRhythm.cpp` 的普通弓拉弓进度条，共享到猎弓和高地长弓等使用该条的武器。
- 状态来源：既有 `FBowDrawRhythm.Elapsed / FullDrawSeconds`；满弓且仍在拉弓时显示，释放和取消时停止。不依赖完美节拍或穿心箭是否解锁、是否就绪。
- 显示：到满弓时短亮 0.28 秒，整条银金色边框及光晕持续以 1.15 Hz 呼吸，叠加每 1.05 秒横向扫过的细流光。流光位于节拍刻线及穿心箭标记下层，原填充进度、刻度位置及语义色保留。
- 后续优化：穿心箭实际就绪后，整条光晕、边框及流光同步使用共享 `BowPiercingReady` 红色，并从穿心箭就绪时点重新播放短亮与扫光。普通满弓未达到穿心箭条件时继续银金色；不以 UI 填充位置代替技能判定，也不改变蓄力阈值。
- 归属与布局：现有 HUD 的 Slate 绘制，无新增控件、数据模型、焦点、输入、计时器、委托或资源加载；沿用原 DPI、中心锚点、可见性和生命周期。效果只在进度条上下约 9 px 范围内，不占准星或下方弦鸣印记的位置。
- 时钟：使用同一次拉弓动作的游戏时钟，暂停时冻结；下一次拉弓重新从实际满弓时点开始。
- 交付：必要 Editor/Game 后台构建，不启动编辑器或游戏，不执行测试或验收，实际观感由用户确认。
