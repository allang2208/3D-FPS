# 物品浮窗：白底与原项目布局

用户本次明确要求白色底。只读核对了 Godot 的 `ui/item_tooltip.gd`、`ui/tooltip_typography.gd`、`ui/gun_tooltip_rows.gd`、`ui/craft_effect_display.gd` 和 `UI-WORKFLOW.md`。实际 Godot 渲染现已被公共玻璃主题覆盖为深色，旧 `COLOR_TT_*` 仍记录白底配色；因此本轮采用用户指定白底，同时保留现行宋体及业务布局。

## 显示合同

| 项目 | 实现 |
| --- | --- |
| 外观 | #F5F5F5 白底、深色文字、细边、8px 卡片圆角；宋体 face0 / 0.5 字重公共入口，数字 Consolas；增益深绿、代价深红 |
| 卡片顺序 | 左附魔、中改造、右主信息；各自独立表面，间隔 18px |
| 最小宽度 | 附魔 300px、改造 600px、主卡 460px，按自然内容增宽 |
| 主卡顺序 | 44px 等比图标 + 名称与强化标记 → 类型/稀有度/等级 → 属性 → 分类与装备信息 → 条件参数组 → 数量 → 描述 |
| 条件显示 | 有附魔前/后缀才出现附魔卡；有有效已装配件或旧改造记录才出现改造卡；强化 >0 才显示强化标记；等级 >0 才显示等级；堆叠 >1 才显示数量 |
| 参数分组 | 枪械、防御、属性加成、套装、特殊攻击、消耗品按实际物品字段显示；药水不出现枪械/改造空栏 |
| 改造 | 实际已应用配件名称及逐条效果；效果自带利弊语义；下方按当前配件计算合计变化，耗时/散布减少视为收益 |
| 长内容 | 不自动折行、不缩字、不压说明列；超宽水平滚动、超高垂直滚动；默认滚到右侧主卡，关闭按钮固定在浮窗右上角 |
| 定位 | 优先光标左侧，空间不足翻转；上下翻转并保持视口留边 |
| 生命周期 | 悬停只读；点击固定；F1 固定并进入键盘滚动；方向键滚动；Esc 先关闭固定浮窗；拖动、面板切换、关闭背包/仓库清理浮窗 |

本轮统一背包空间格、装备位、背包快捷格、仓库物品入口。保留双击使用/穿戴/取出、右键仓库转移、Shift 拆分和原拖放交易。

## 数据与范围

`ColdSteelItemTooltipData.cpp` 从当前物品实例的完整 JSON、数量、弹匣和 `UGunsmithSystem::Installed/Calculate` 读取信息；不读取枪匠尚未应用的草稿。角色基础攻击/攻速按当前已接入的 UE 战斗计算显示。物品、成长、配件与存档数据均由原模型持有，浮窗不写入游戏状态。

存在枪匠目录时，已装配件逐条效果与最终参数走真实计算器。并行武器清理任务随后将枪匠目录置空、保留原生 M4A1；本轮保留该结果，M4A1 主卡从角色运行默认参数读取，未重新加入被删除的六把武器。旧 `_craftData` 展示尝试读取从原配置导出的选项说明；常见旧改造加成有合计显示。原项目尚未迁入 UE 的复杂特殊武器效果并未因此获得运行实现，也不宣称所有旧特效公式完成迁移。原项目保留的资源/单位和 UE 枪械米/毫秒参数分开处理。

公共暗色 `Tooltip` Token 保留给其他面板，物品白底使用独立 `ItemTooltip*` Token。旧仓库详情构建入口保留兼容，正常悬停与固定入口改用统一 Inspector。Godot 源文件及玩家正式存档未修改；只读渲染使用独立存档路径。

## 文件与验证

- `ColdSteelItemTooltip.h/.cpp`：UMG 卡片、双向滚动、定位、固定与生命周期。
- `ColdSteelItemTooltipData.h/.cpp`：只读信息分组与显示条件。
- `ColdSteelItemTooltipHUD.cpp`：HUD 唯一浮窗实例与来源坐标转换。
- `ColdSteelInventoryWidget.*`、`ColdSteelWarehouseWidget.*`：原生悬停、选择和键盘入口。
- `Tools/UI/reference_item_tooltip.gd`：读取原组件的实际 Godot 渲染，输出在 `Saved/ItemTooltip/godot-*`；原改造目录导出到 `Content/ColdSteelData/tooltip-reference.json`。
- `Tools/UI/run_item_tooltip_acceptance.ps1`：隔离存档启动真实 UE 进程；必须同时满足退出码 0、`ItemTooltip: COMPLETE ... failures=0` 且无 FAIL。
