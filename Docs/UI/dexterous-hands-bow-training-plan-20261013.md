# 巧手：拉弓速度与完美箭修炼（2026-10-13）

用户所说“快手”对应现有 `dexterousHands`（面板名“巧手”）。在此技能追加拉弓收益和攻击修炼，保留等级、经验、图标、敏捷、换弹及近战修炼。

## 数值与结算

- 20 级上限不变，拉弓速度每级 +1.25%，1/5/10/15/20 级分别 +1.25%/+6.25%/+12.50%/+18.75%/+25%。
- 与装备、改造、附魔的同类拉弓速度相加，进入现有 `耗时 ÷ (1 + 总速度加成)`；弓精通的独立间隔缩减照旧。仅此项满级时，1.4 秒变为 1.12 秒，不等同于耗时减 25%。
- 完美节拍手动射出的箭实际命中敌人并造成伤害：巧手 +4 修炼；该箭直击击杀再 +6，合计 +10（不再重复发放命中档）。
- 对照现有换弹 +5、近战命中 +2、近战击杀合计 +8，完美箭的精确释放和命中条件给予适度额外收益。等级所需经验仍为当前等级 ×300。
- 放空、射墙、尸体、友方、召唤物、NoSkillTraining 目标、自动力竭放箭、错过节拍、派生弹和后续中毒/流血跳伤不触发本项。原有弓精通、暴击的有效修炼仍正常结算。
- 完美标记在发射时冻结到箭矢快照；单机和联机服务器生成箭矢两条路径都赋值。联机沿用上一轮服务端计时判定，客户端不能申报修炼数值。
