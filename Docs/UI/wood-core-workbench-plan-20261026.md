# 木芯材料与木工工作台

本轮交付四种实心木芯模型、统一木质材质、实际模型图标、基础获取配置与木工全链路。后台制作、导入、构建；不启动游戏或追加测试。

## 材料和表现

原木芯、铁木芯、古树木芯、灵纹木芯分别保底 0%、2%、6%、10%。统一为 30×7×5 cm 去皮长木坯，圆钝加工边、实心截面、纵向木纹和端面年轮。木色与纤维密度区分材质；灵纹仅低亮细纹。金属度零，木质粗糙度与微表面独立制作。物品占格 2×1，图标透明、水平居中，由实际模型生成。

## 工作台数据合同

固定配方维持长弓 2 木材+1 树脂胶包+1 层压木条，长杖 2 木材；新工件额外消耗所选木芯 1。共享 InputsFor 提供展示、数量判断、扣料。开工原子记录木芯 ID、材质保底、品质版本、免材料标记和实际材料；暂停/继续不重复扣除，废弃只按实际记录折半返还。

新工件倍率 = 1 + 材质保底 + 0.15×最终评分/100。旧工件与成品保留旧倍率。运行显示加工贡献按清除进度/达标要求逐步计入，开工为零；完成后使用最终评分。弓仅影响物理伤害，法杖仅影响本件魔攻，继续复用现有公式入口。联机由服务器验证木芯选择及扣料，客户端不提供可信加成。

## 界面

保留现有抽屉、管理卡片、实景加工与交付流程。在配方下追加木芯下拉选择和保底/加工上限摘要；材料表追加木芯。新工件可选全部四类，不足时显示缺少数量并禁用开工，已有工件锁定选择。下拉复用当前 14px 字体与选项组件。交付分列材质/加工/总修正；绿表示正值，零灰、负值红，旧工件明确标为旧工艺。加工视图显示当前实际获得的三项值，木板/切屑/废料共用所选材质。长标签横排，整行在窄屏时换行，不挤成逐字竖排。

## 获取

普通工作台新增 2 木材→1 原木芯。现有维护类搜索池按容器用途加入铁木芯/古树木芯；地牢深度奖励与精英/最终奖励投放高档木芯。当前商人若无独立限购机制，不新增无限购买高级芯的旁路。本轮不新增树种，专用树木资源点后续接入。

## 生命周期与兼容

图标初始化缓存，材质异步加载；不逐帧读目录或同步加载。工件保存字段采用新旧版本区分，旧档默认旧版。F6 不扣任何材料但照常选择木芯，免费工件不返料。源码构建、已保存资产和用户运行结果分别记录。
