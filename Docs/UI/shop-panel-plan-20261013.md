## 界面与输入

- **O** 打开/关闭快捷商店，同时打开右侧背包；关闭背包、切换属性/技能/图鉴或进入其他工作台时关闭商店。Esc 在出售确认中先返回修改，再次按才关闭面板。
- 商店与仓库共用实际宽度及上下 12px 外边距；商店右边缘零缝贴住背包左边缘，以右侧背包的锚点计算位置。背包先到位，商店再从背包后方向左展开，运动中处于背包下层，到位后恢复正常点击层。共享冷钢玻璃、银边、金色灵魂和字体。
- 外壳、60px 顶部标题/余额/关闭栏参考仓库。内部购买/待售两区等高，各自用背包的 **18 列方格** 铺满可用整行，普通页的格宽为 `(面板内宽-24)/18`，物品按实际宽高和旋转状态占格，图标等比缩放。特殊高物品独占适配页，以完整显示占格。
- 两区各自自动装填与分页，页面标题右侧提供“上一页 / 页码 / 下一页”；鼠标悬停哪一区，滚轮就翻哪一区（与仓库一样循环翻页），按钮到首尾页禁用。数量改变、增删、窗口大小改变后重新装填并限制当前页，清空后保留一页空格。
- 点击格子选择物品，在该区底栏显示名称/单价、数量输入和购买/移出按钮；右键或双击商品快速购买 1 件，右键或双击待售物品移出。固定底部显示预计收入、清空、确认出售及反馈。紧凑文字单行，长名省略。
- 待售栏支持从背包/夹层拖入、右键加入；双击/Enter 同样进入待售，Shift+右键菜单显示“加入待售栏”。加入后自动定位对应待售页并选中该物品。已有选择不重复添加；可以修改数量、移出或一键清空。
- 拖入商店范围消耗拖放事件，不穿透成地面丢弃；只有下方待售区接收物品。沿用原拖动快照校验、跟手图片及取消清理。
- 点击“确认出售…”只生成并显示报价，弹层逐项列名称/数量/收入与总额；必须再点“出售并获得灵魂”才能成交。弹层阻止鼠标点穿背包，Escape/O/Tab 先关闭确认，不成交。

## 数据与保存

- `UColdSteelShopModel` 管理当前选择、报价及买卖，不增加临时存档容器或新的 Place 值。待售只是 InstanceId + 数量，物品在成交前仍属于原背包，关闭/取消不会扣物品或灵魂。
- 实际购买：同步运行状态 → 快照 → 快照扣灵魂 → Insert 完整放入商品 → 一次 CommitState。实际出售：核对选择版本、每项原始物品快照（忽略自然冷却）、数量和价格 → 快照扣除物品 → 快照增加灵魂 → 一次 CommitState。
- 保存失败不发布新库存/余额；重复点击时会因为已清空选择和版本变化拒绝重复结算。自动存档/无关资源变化不会仅因全局 Generation 变化而使报价失效，但待售物品位置、数量、内容或价格变化会要求重新确认。
- 物品模型 OnChanged 驱动格子展示数据与装填刷新；Tick 只在尺寸变化时重新计算格子和页数，Paint 不读取物品 JSON、不加载图片。常见售价规则按定义缓存，目录图片按首次需求缓存。
- 单机沿原角色事务结算；当前主客机已接入 PlayerState 的库存交易请求，由服务器校验对应玩家的权威库存、数量、价格及灵魂后结算并回传。主客机各自持有的物品和灵魂不合并。后续 NPC 可调用 HUD 的 `OpenShop()`，再按其距离、目录、库存及网络所有权扩展会话，不复制交易逻辑。
