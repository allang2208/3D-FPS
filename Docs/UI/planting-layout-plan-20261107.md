# 种植栏布局优化 · 2026-11-07

## 范围与层次

保留冷钢工作台外壳、固定标题/关闭按钮与固定底部操作。只调整布局和信息呈现，不修改目录、数值、种植/收获事务、存档或多人复制。

- 顶部：目录四作物的图标、名称和持有量，明确为下一次播种选择。无材料仍可查看，实际播种由现有 CanAct 决定。
- 中部：始终为真实 4×4 空间映射，不因窄窗变成 2×8。植株按存档 Footprint 连续占用整块区域，2×2 只有一个可点击主体；覆盖格不会抢占命中。空地选中后提示计划占地。
- 详情：空地显示所选播种作物的材料、占地、成熟时长和产量；已种植区域显示实际该株存档的产量、时长、占地、生长阶段、进度和剩余时间，避免与顶部下一次播种选择混淆。
- 底部：播种、生长倒计时、收获、等待服务端提交状态及真实失败原因。说明保留离线生长、材料来源、背包容量保护和拆除损失警告。

## 布局与样式

沿用 ColdSteelUI 主题、Noto Sans SC / JetBrains Mono 和既有字号。实际内容宽度不足 620 px 时详情移至地块下方；不足 380 px 时整枚作物按钮变为两列，文字不逐字换行。地块为最多 360 px 的正方形，坐标与命中来自同一归一化 4×4 网格。矮窗只滚动正文，主操作固定。小格优先保留名称与状态，空间不足时隐藏缩略图/细进度条，详情仍提供完整进度。

## 数据和生命周期

目录与材料读取 ColdSteelPlantingSystem / ColdSteelStatusModel。已种植详情读取 FColdSteelCropPlant 保存值，时间读取 NowTicks，动作仍经 CanAct / Act；ExpectedPlantId、0.35 秒防连点、床实例校验、距离与关闭入口保持。点击代理继续用独立 UPROPERTY 数组保活。选择后焦点返回面板。多人等待时禁用选择和提交，接收状态后刷新。

沿用可见面板 0.25 秒刷新与状态序号，不重建控件树。目录四图标在构建面板时预读并复用已有 IconBrushes；定时刷新不加载图片。没有新资源或存档迁移。
