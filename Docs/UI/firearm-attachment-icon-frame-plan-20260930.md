# 枪械改造图标金属框

本页记录枪械阶段的制作范围；后续弓、法杖、近战和工具已按同一规则制作，缺失项见 [最终补齐记录](remaining-attachment-icons-20260930.md)。下面的“其他工作台不变”和“4 个缺图”属于当时状态。

范围：枪械改造台的 48px 分类入口与 64px 配件选项。沿用现有栏宽、滚动、按钮、工具提示、草稿选择和应用事务；法杖、弓、近战及工具工作台不变。

图标使用用户认可的 muzzle_brake_framed_v2.png 作为生成母版：厚实金属方框、四角铆钉、内圆环、凹陷深色底及中央配件。每张以原有配件 PNG 为内容参考，统一银灰色金属与聚合物质感。图片直接携带完整边框；Slate 不再叠加旧细线框或 5px 留白。选中沿用卡片状态，已安装保留右下银色勾标，状态不烘焙到图片。

数据仍取 Draft/Installed；复用现有控件属性与图标缓存，无新增 Tick、加载任务或保存逻辑。关闭随工作台控件树释放。缺选项图时继续使用分类图回退。

实现：SFramedAttachmentIcon.h、M4GunsmithLayout.cpp。原 PNG 保留；新版 PNG 和 Texture 保存到 AttachmentIcons20260913/FramedFirearms。武器专属图优先于通用图，同一键新版优先于原图。枪械页面使用新版目录，其他工作台沿用原图。

制作来源、逐图提示与共用文件映射保存于 SourceAssets/FirearmFramedIcons20260930。manifest.json 将 208 个实际来源键按原始文件内容分成 146 组；相同原图共用生成结果。4 个原本缺图的选项维持分类图回退。使用 import_framed_firearm_icons_20260930.py 导入并保存 UI 贴图。仅进行必要构建及导入，未启动游戏或执行视觉验收。
