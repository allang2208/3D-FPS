# 左上角游戏菜单 · 2026-10-08

## 目标与来源

接入实际可用的游戏菜单。参考 game-dev 的 `src/ui/game-menu.js`、`ui/components/hud-layer.html`、`ui/panel-theme-backpack.css`：左上入口、返回游戏、设置分组、操作说明、Esc 分级返回。使用当前 UE 冷钢设计系统，不迁移网页专属窗口 API、RTS 单位开关或没有对应系统的设置。

## 布局与主题

- 常驻入口位于左上 12px，宽 124px、高 36px，显示“菜单 / Esc”；buff 栏顶部下移至 56px。
- 菜单卡片左上对齐，入口下方 8px；主菜单宽 320px，设置／操作说明宽 560px。窄窗限制外框宽度、保留横向滚动；矮窗正文纵向滚动，标题与返回入口固定。
- 全部文字单行，Noto Sans SC 正文 14px、标题 18px，JetBrains Mono 数值 14px；共享冷钢玻璃、银边、36px 按钮与淡金分区标题。主面板单层模糊，条目不各自模糊。

## 数据与动作

| 页面 | 内容 | 实际入口 |
| --- | --- | --- |
| 主菜单 | 回到游戏、设置、操作说明、退出游戏 | PlayerController 管理输入与暂停，退出前二次确认 |
| 设置：声音 | 总音量、主神空间音乐 | 当前音频设备、已有 HubMusic 组件；不影响音乐基准音量 |
| 设置：操作 | 鼠标灵敏度倍率、反转纵向视角 | PlayerInput 的 MouseX / MouseY 轴属性，保留各轴原有基准 |
| 设置：显示 | 垂直同步、帧率上限、窗口／无边框 | UGameUserSettings；显示模式在独立运行时可用 |
| 操作说明 | 移动、武器、交互、背包、状态、技能、图鉴、菜单 | 按 UE 当前输入配置与控制器行为编写，不照抄网页键位 |

设置更改即时生效，离开设置或关闭菜单时写入用户 GameUserSettings.ini；不更改 DefaultInput.ini，不在 Tick 写盘。退出调用当前角色与建筑保存入口后退出；失败保留菜单并显示原因。

## 状态与输入

- 游戏态 Esc 打开；已有面板／拖放／选弹的 Esc 优先收起原界面。
- 主菜单 Esc 回游戏；设置／说明／退出确认的 Esc 回主菜单。退出确认默认焦点在取消。
- 菜单打开时 UIOnly、停止武器动作、释放按键并屏蔽移动／视角；只解除自身取得的输入锁与单人暂停。联机不暂停世界，显示“联机游戏继续运行”。
- 启动／加载遮罩拥有输入期间禁止打开菜单；菜单打开期间不允许地牢输入恢复分支抢回光标。
- 页面只在导航时构建，设置值按控件事件更新；Slate 属性仅读取布局与可见性，不增加 HUD Tick 或运行时资源加载。
