# 枪械工作台跟随校准与选择栏调整

范围：枪械装配后的校准阶段、管理/交付面板及与铁匠共享的选择栏。UMG 管理/动作面板，Slate 分组下拉。

- 总时长 30 秒：开场准备 1 秒 + 5 组各 5 秒 + 4 次组间休息各 1 秒。倒计时不因出圈/松开左键停止；Esc 保存退出，失焦暂停。
- 判定圈基准半径从视口短边 4.7% 改为 2.35%，以工件 ID 固定随机种子平滑缩放至基准的 55%–145%；绘制与判定共用同一半径。黑色描边配白/青/绿色，明亮枪身上保持对比。
- 仅每组 5 秒计分，准备/间隔不计分。保持原有材质保底 + 装配/校准最高 15% 的伤害公式。
- 数据由工件系统拥有，存档记录规则版本、已用时间与命中累计；联机保持服务端结算。旧未完成工件按原校准完成比例迁移，保留已付材料、已装组件与质量收益；已完成旧成品不变。
- 游戏结束、成品保存完成即退出交互并打开交付界面；联机等待服务器确认，保留领取/废弃按钮。
- HUD 显示当前组、组内剩余/间隔倒计时、总剩余、有效跟随时间和实时伤害加成；避免旧的“出圈暂停”说明。长说明允许正常换行，按钮/选择标题不拆成竖排。
- 枪械、弹药和铁匠配方统一 14 物理像素正文/16 像素分类标题，和现有金属选择行保持一致；开发 F6 选择器尺寸不受影响。
- 刷新沿用现有节流；随机不每帧重置，退出沿用输入/视角恢复与委托解绑。下拉菜单沿用视口宽高限制及溢出省略。

按用户要求进行源码层 UI 审计及修改、必要后台构建，不启动编辑器或游戏测试。

## 源码层 UI 审计与调整记录

| 问题 | 调整 |
| --- | --- |
| 配方/弹药选择器以 14 pt 显示，金属选项以 14 px 显示 | 工作台选择器启用物理字号模式，正文 14 px、组标题 16 px；铁匠配方共用同一模式 |
| 分组选择器按钮样式使用反向 DPI 参数 | 工作台模式按正确 PixelScale 缩放边框与圆角，F6 原样式保留 |
| 判定与绘制各自写死 4.7% 半径 | 同一随机半径同时驱动命中计算与绘制，基准 2.35% |
| 亮枪体上的单线圆圈对比不足 | 黑色粗描边 + 青/绿细圈，鼠标准星黑白双描边；休息阶段灰色 |
| 松手/出圈暂停，时长显示实际是有效命中累计 | 固定五组时间线、独立显示有效跟随/总剩余/当前组，不再允许松手无限延长 |
| 初始说明仍写 Q / R，玩法说明和新规则不一致 | 修正 Q / E、滚轮、跟随/间隔、退出保存及自动交付文字 |
| 完成后额外停留 4.5 秒，回到面板可能沿用其他页 | 确认保存后立即返回，成品打开时固定选择枪械交付页 |
| 加成明细长句在窄视口易超出 HUD | 缩短文案并允许正常横向换行，组件/选择项保持单行 |

管理页继续使用可滚动正文和固定底部操作区；下拉菜单沿用视口限宽/限高、长选项省略及完整悬浮提示。交互退出沿用现有视角/输入恢复。网络 HUD 在权威快照间平滑时间显示，结算仍以服务端工件为准。

本次未启动 UE、未执行游戏或联机测试；这里只记录源码层审计及实现，实际视觉与操作体验由用户测试。
