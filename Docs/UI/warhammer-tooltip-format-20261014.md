# 战锤浮窗与缩略浮窗格式检查

用户要求按双手剑格式检查战锤浮窗，包括鼠标悬停的缩略卡。本轮按当前冷钢规则核对数据与源码，并调整发现的内容分区差异。

## 格式与修改

- 两者原本即共用 `UColdSteelItemTooltip`、宽武器图、标题／元信息、核心网格、字体、视口限位和折叠详情。缩略卡宽度上限 400px、固定详情 520px；两列核心网格在窄窗按同一断点转为一列，无战锤专用渲染分支。
- 缩略摘要由通用“前四项”兜底改为与双手剑共用近战字段顺序：武器总伤害、攻击间隔、体力消耗、最大攻击距离。锤无格挡机制，缺失的剑类格挡项自然省略。完整详情复用同一份核心摘要。
- 战锤的数值条件明确普通钝击、单次普通攻击耗体力及普通挥击范围；不继承剑的“最大距离含突刺”说明。
- 完整详情继续使用公共攻击力／强化公式生成器，六位系数格式可完整显示 0.909 和 0.621，并由公式目录得到力量／体质。总伤害、间隔、消耗和距离来自 `ColdSteelTool::Evaluate`，与实际战锤计算同源；重复核心行由共用布局去重。
- 攻击方式移入枪匠目录 `traits`，以和双手剑相同的“特殊性质”折叠区展示普通群攻、蓄力砸地及实际改造栏目。移除参数区与背景介绍中的第三段伤害倍率，背景只保留武器介绍。
- 新介绍同步运行目录和恢复参数；已有物品沿现有 `NormalizeProductionState` 的 `desc` 同步更新。强化等级、附魔与部件保留。

## 检查与交付范围

本轮检查覆盖摘要分支、完整详情、共享渲染、公式精度、字段顺序、数值来源、机制分区和已有物品文案同步。必要构建与定向数据检查的实际结果记录于本节；没有运行旧的枪械／药水浮窗全套验收脚本，也未将源码核对视为实机视觉通过。

### 实际结果

- 已解析运行物品、公式、战锤改造目录和恢复定义四份 JSON；公式属性为 `str/con`，系数为 `4.59+0.909L`、`3.6+0.621L`，基础间隔 2041.25ms、普通范围 3.6m。摘要和详情均从实际评估器换算，攻速加成后的显示值随角色变化。
- 特殊性质列出的五个改造名称与当前 `columns[].name` 一致；背景介绍 53 字，恢复定义与运行目录文字一致。
- 已有 Game Development 完整构建纳入本轮两个 C++ 文件：第 6/22 项 `ColdSteelItemTooltipSummary.cpp`，第 15/22 项 `ColdSteelItemTooltipData.cpp`，第 21/22 项链接 `FPSGAME.exe`，结果 `Succeeded`。回执保存到 `Saved/BuildEditor/warhammer-tooltip-game-20261014.log`。
- 尝试常规 Editor 构建时，保护脚本因正在运行的生态怪物资产导入 commandlet 拒绝覆盖 DLL；未中止该导入。Editor 目标仍待占用结束后更新，未执行新的浮窗截图或实机操作验收。
