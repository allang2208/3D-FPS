# 铸造台实景锻打

本次按用户授权，把原二维点击计分改为铸造台前的第一人称锤击。保留冷钢配方/材料/结果抽屉、原有背包尺寸和冶炼面板的弹出收回方式。资源异步准备完成后才能开始扣料。

## 操作

1. E 打开独立铸造台，选择现有高地双手剑配方并开始。
2. 双抽屉收回，镜头在 0.35 秒内转到实际铁砧，3 秒准备后进入原有 20 秒回合。
3. 鼠标控制剑坯上的落锤位置。左键执行完整 0.82 秒动作，0.34 秒锤头接触时判定落点和热区窗口，回锤后才可再次出手。
4. 左手持钳固定剑坯，按有效命中数显示三阶段剑坯。结束后提起、移向现有冷却桶、淬火收尾，然后回到结果抽屉。
5. 每热区最多计一次。10 / 20 次命中为基础品质，原有伤害倍率 0.75～1.25、扣料事务、待领取存档和背包满时保留成品沿用。
6. Esc / Tab 提前按当前命中数结算；设施失效时结束并恢复视角/输入。配方图只用于展示，不能再点图计分。

## 模型与抓握

- 原创旧钢横刃锻造锤：约 35 cm 木柄与头部，椭圆截面握把 28 × 24 mm；黑氧化主体、磨损敲击面和木楔。沿用项目已做旧铁砧材质与 Normandy 木材。
- 原创手持平口钳、三阶段剑坯、实体热区圆环与小型热氧化皮。无贴花或带黑底的粒子面片。
- 手臂母版使用现有 V7 裸手 M4 原生骨架；圆柱抓握来自项目已接受的 Manny 供体。制作阶段按锤柄椭圆截面及钳子双柄截面收拢指节，局部旋转限制在供体姿势附近。运行时保留原生骨长、骨骼缩放和蒙皮，只求解肩、肘、前臂扭转与手的姿势，手指采用固定抓握局部旋转。
- 锤子坐标：原点为握柄中心，+Z 指向锤头；锤面接触点为局部 `(6.8, 0, 21)` cm。目标落点反推工具位置，避免用手腕代替接触点。
- 动作时间轴由 `Content/ColdSteelData/forge-grip.json` 描述；Blender 源文件包含完整 V7 手臂、工具、抓握和同一套 0.82 秒动作关键帧（100 fps，接触第 34 帧）。运行时按真实落点进行整条手臂 IK。
- 敲击音为本次原创合成金属撞击音，无外部下载音频。
