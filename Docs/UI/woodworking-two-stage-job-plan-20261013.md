# 木工工作台两阶段与待领工件 · 2026-10-13

## 铁匠源码对照与目标

依据 ColdSteelForgingHUD、ColdSteelForgingWidget、ForgingSystem 的真实流程：管理面板选择与投入材料 → 独立实景加工 → 返回原管理面板领取或折半返料。木工已有的“领取才扣料、失败不消耗、成绩继续叠在切割视角”与此不同，本次整体接齐。

## 界面与状态

- 管理阶段沿用选择卡、材料卡、预览/条件卡及固定底部进入卡，贴背包左侧同宽显示，短文本横排单行；准备资源期间不扣料，资源就绪后创建付费工件再进入实景。
- 加工阶段保留木板小角度转向、空格切换调整/切割及暂停计时；进入时为调整状态。结束、超时或损伤失败都退出加工镜头并返回同一管理面板。
- 结果阶段由管理面板显示工件状态、评分/损伤、实付材料及折半返料明细；合格工件可领取，所有已完成未处理工件可废弃返料。背包容量不足则保留整个工件，不能重新开始覆盖。
- Escape/返回工作面板结束本轮并保存结果；关闭管理面板只收起界面，保留工件。再次交互恢复待领/待返料状态。正常完成或领取后不留切割成绩浮层。

## 事务、存档与网络

- 使用独立 FColdSteelWoodworkingJob，旧存档缺失字段默认无工件；稳定工件 ID、图样/配方 ID、成品快照、实付材料、结果及最终切割图保存到现有角色档案。
- 开始一次扣除背包＋主仓库材料，先扣料并保存工件；领取只放入已保存成品，废弃只按实付快照逐项向下取整返还 50%。返料/领取与清除工件同一 CommitState 原子提交。
- 未正常结束的已付工件在再次进入时作为未完成失败品保留，允许折半回收，不免费重开。正常关闭时按实际切割结果结算。
- 沿用已有木工服务器切割输入/遮罩同步，新增开始、领取、废弃交易及工件档案镜像；服务器拥有扣料、达标判定和结算权。保留正在并行制作的输入序号与分块同步。

## 制作边界

复用冷钢样式、现有库存事务和枪械/铁匠生命周期经验，不新增练习模式或虚构第二道木工工序。不主动打开 UE、不运行游戏、测试或验收；完成必要 Editor/Game 常规构建，真实体验由用户确认。备份和构建产物记录放 Saved/WoodworkingTwoStage20261013。

## 本版实现与落盘

- 已加入 WoodworkingJob.cpp：先支付并保存工件、按实际切割结果保存成绩与遮罩、原子领取和折半回收；已付工件不再被切换图样/关闭面板覆盖。
- 管理面板与背包等宽贴邻显示；准备资源成功后投入材料，进入实景时先调整、空格切割。完成/失败/主动结束后还原镜头并回管理面板，移除旧切割成绩浮层。
- 管理面板显示本轮工件、实付材料、完成指标、评分和返料明细；底部固定“领取成品 / 废弃 · 返还一半”。未达标不能领取成品；保存或容量失败保留工件供重试。
- 角色档案、库存回执、服务器存档合并及现有木工遮罩分块同步均携带工件；开始/领取/回收走服务器交易，保留并行新增的输入序号、旧包拦截和切割同步。
