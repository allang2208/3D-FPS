## 本次修改

- 枪械也加载已有目录图标；动态预览就绪后优先显示实时配件图，等待或失败时显示目录图标。
- 每次物品数据或图标完成通知后，使面板 Paint 缓存失效。背包、装备栏、仓库共用此流程，拖动预览也使用同一图标选择。

- 成功和失败退出均清理当前任务状态并通知界面刷新；失败的预览在本次子系统生命周期内继续使用目录图标。
