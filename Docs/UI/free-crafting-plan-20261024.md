# F6 制作不消耗材料

- 入口：F6 → 基本调参 → 会话开关，在“建造不消耗资源”之后增加“制作不消耗材料”。复用现有 UMG 卡片、88px 开关及单行按钮文字；窄窗沿既有布局换到下一行，整页保持原滚动和焦点逻辑。
- 数据：DevelopmentTuningSubsystem 的会话选项，默认关闭，结束游戏重置；沿用本地权威玩家编辑权限，仅影响本人的打铁、制药和木工。状态变更经原 OnChanged 通知材料面板刷新。
- 制作：绕过材料数量门槛与背包/仓库扣料，保留工件事务、小游戏、品质、领取和容量判定。炼药生成仅存在于本炉 Escrow 的配方备料，使开封、研磨、倒料仍可操作。
- 工件：三个 Job 增加带默认 false 的 bMaterialsWaived 标记，沿现有反射存档和工件复制保存。旧工件继续原支付规则；开关变化不追溯修改已开始的工件。免费工件不返料，打铁不走旧档配方返料回退。
- 显示：开始前显示本次消耗 0 / 免消耗；开始后显示本轮免材料与免费备料，废弃反馈明确不返料。
- 范围：DevelopmentTuningSubsystem、DevelopmentPanelWidget/DevelopmentTuningPanel、三个工作台业务与对应材料显示、ColdSteelInventoryTypes。无新资产，不修改材料目录、产物或品质公式。
- 交付：后台必要构建；未要求运行测试或预览，由用户测试。
