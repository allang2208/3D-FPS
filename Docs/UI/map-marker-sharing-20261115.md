# 地图标记可见范围 · 2026-11-15

> 2026-11-17 归档说明：本记录中的测试/构建日期和结果为历史证据；本次整理未重新运行。地图任务的 Saved 临时目录及截图已移入 `trash/map-system-20261117/` 下的原相对路径，详见 [发布与归档清单](../Publication/MapSystem20261117/README.md)。


用户授权制作并在联机情况下测试。本轮沿用冷钢 UI 与现有地图会话，不打开交互编辑器、不改玩家正式存档。

## 界面与行为

- 原标记编辑浮层增加同一行的「仅本人」「全队可见」选择，默认仅本人；保存时才提交，取消不改变已保存状态。沿用现有字体、玻璃、银白选中边界与按钮高度，短文字横排，窄窗由浮层整体滚动承载。
- 每名玩家最多创建 10 个标记，本人和共享合并计数。底栏区分自己的数量和队友共享数量，标签注明可见范围、创建者和区域/楼层。
- 队友标记只能定位查看。新增、改名、改色、切换可见范围和删除仅由创建者提交；本人和队友的选中/编辑状态分开。
- 共享同步地图、光柱和方位条，保持颜色、名称和位置一致。共享位置不会改变个人战争迷雾；未探索的地形仍隐藏。地牢光柱仍只显示当前层。

## 数据与生命周期

- 个人标记仍只保存在本地地图会话，不上传坐标或文字。
- 新增 PlayerState 所属的复制组件，仅存储该玩家主动共享的有界标记快照。服务端验证身份、容量、文字、位置、区域/RunId，再复制给同一合作房间中的队友；初始快照覆盖晚加入。
- 光柱继续是各端独立的非复制表现 Actor，绑定该端真实 ViewTarget；分享只复制数据。请求序号避免迟到失败覆盖更新后的可见范围，失败明确回退为本人标记。
- 同一地牢存续期间返程/重进保留标记；最后一人离开导致实例退役或开始新局时清理该局标记，保留主神空间标记。断线退出清除该玩家共享快照，不跨重启/重连恢复个人记录。
- 地图模型按复制修订和玩家集合变化刷新队友数据；地图关闭时仍沿现有导航更新入口工作。编辑器释放沿用既有输入锁、焦点及加载界面约定。

## 已授权的验证范围

完成实现与 Editor/Game 构建后，执行真实 UDP 监听主机/客机检查：默认私有、双向分享、名称/颜色/光柱拥有者、撤回/删除、只读与服务端身份隔离、每人上限、晚加入/断线清理与重连。另用已有地牢夹具检查旧 RunId、返程和新局清理，不把模拟地牢角色当成实际 UDP 地牢验收。使用隔离档案和日志，保留失败尝试与最终进程退出码；实际画面检查单独计证。

## 实现与构建

- `ColdSteelMapMarkerSharing` 是 `AColdSteelPlayerState` 的默认复制组件；本人标记不进入复制数组。共享的服务端快照按创建者、GUID 和当前地牢实例隔离，远端只读。
- `ColdSteelMapMarkerSharingView.cpp` 合并本人/队友导航数据；地图、光柱和方位提示使用同一份视图。共享楼层可被定位、缩放和选择，未探索层标注「共享标记」，不写入探索记录。
- Editor 构建成功：`Saved/MapMarkerSharing20261115/fixture-FPSGAMEEditor.log`；Game 构建成功：`fixture-local-FPSGAME.log`。测试隔离分支只在 Editor 的 `-MapMarkerWire` 模式跳过无关技能预加载，正常游戏不受影响。

地牢夹具另行覆盖共享不揭开队友迷雾、单人返回主神空间、同实例重进、实例退役、新 RunId、旧实例共享请求被拒绝并回退为本人标记。它使用模拟世界和角色，未把这些结果计作真实地牢关卡的 UDP 测试。

首轮 `normal-01` 在低内存、无关技能预加载同时出现时主动停止；阶段 0–8 的观测通过，但完整重连未结束，因此不计作整轮通过。日志和中断说明保留。后续测试限定了技能预加载，采用 `-Multiprocess` 避免重复 SDK 构建检查，并固定主模块及原生插件二进制。

本轮均为 NullRHI 后台测试，未做渲染画面、鼠标交互、专用服务器或公网验收；地牢夹具的 3 项 Slate 输入检查因没有 Slate application 而跳过。网络运行中还出现了与标记用例无关的 GameFeatureData 配置及 ToolsetRegistry/PythonTestRunner 启动日志，本轮未修这些插件启动项，亦不将它们计入地图通过范围。

本次启动的测试进程已退出。测试副本的 Content、Config 和插件资源/源码目录含 Junction；保留证据时不递归处理这些链接目标。
