# 村庄 NPC 对话

玩家在教堂修女或已修复铁匠铺的铁匠面前按 E 开始交谈。对话显示在本地玩家视口下部，上方保留场景和人物。对话页、圣光传授和村庄建设共用一次输入接管。

| 页面 | 内容与操作 | 数据与保存 |
| --- | --- | --- |
| 修女 | 显示说话人、逐段台词和话题选项，可前往建设或圣光传授 | 台词跟随本次会话，从子页返回时保留进度 |
| 铁匠 | 1 闲聊、2 交易、3 学习技能。闲聊可询问铁匠铺、他自己、村子或附近的消息 | 交易沿用商店与背包，学习技能进入当前角色的打铁修炼 |
| 打铁修炼 | 讲解品质、准备材料、锤炼和成品处置，学过后仍可重读 | 实际锻造操作推进角色进度，左上目标追踪栏显示当前步骤 |
| 铁匠商店 | 买入近战武器和采矿用十字镐，也可选取背包物品待售 | 共享货架及灵魂结算，货架的锻造修正随购买写入物品实例 |
| 村庄建设 | 沿用建设树、搜索、选中项目、修复反馈和返回 | 读取丘陵世界状态，沿用服务端解锁与世界存档 |
| 圣光传授 | 展示授课、学习条件、操作和结果 | 读取角色技能状态，沿用现有传授事务 |

铁匠货架收录运行时目录中的近战武器和采矿工具 `tool_pickaxe`，从物品定义读取售价。学徒长杖归入魔法武器。每种商品同时陈列一件，成功售出后补货。

铁匠站在一楼接待桌西侧，平时面向桌面。服务器确认交谈距离、视线和角色存活后，修女和铁匠在交谈者本机转向该玩家；结束对话后回到原朝向。两名玩家可同时与同一位居民交谈，旁观玩家看到其待机朝向。铁匠进货、成交和补货沿用共享权威库存。

普通商店、铁匠货架及待售栏沿用背包的物品浮窗。悬停显示摘要，单击或选中后按 F1 可展开详情。浮窗读取当前货号或玩家持有的物品实例，同时显示交易单价和操作提示。右键和双击保留原交易操作。

中文采用工程 Noto Sans SC，键帽采用 JetBrains Mono。冷钢玻璃对话框横跨视口底部，左上显示说话人姓名，左下横排选项。正文独立滚动，页头和操作区固定，窄窗的话题按钮整枚换行。

玩家用鼠标或键盘选择。交谈时独占本地游戏界面；离开、失去目标、距离过远或角色死亡会释放对话层和对应的移动、视角锁。服务器尚未回复时如果另一界面已接管输入，则取消本次进入。铁匠日常对话不提交修女的建设或授课事务。
