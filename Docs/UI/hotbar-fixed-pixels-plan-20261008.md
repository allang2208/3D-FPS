# 快捷栏固定像素与 1～0 扩展 · 2026-10-08

## 排查范围与原因

用户反馈改变分辨率会改变底部快捷栏大小，并要求补齐数字键 5～0、避免与长剑／法杖 G 功能冲突。源码中槽位尺寸、间距和字体只在创建时按 DPI 换算，窗口变化后未一起更新；圆角与拖放描边还有未换算的固定逻辑单位。数字键 8 先于快捷栏分派，被铁铲快捷入口消费。

## 实施合同

- 复用现有 UMG HUD 与 QuickSlot，不重建技能、冷却、物品、拖动事务。48×48px 槽、8px 间隔、9px 外边距、底部 12px；DPI 改变时统一更新尺寸、字体、图标与描边。
- Q/E/X 加 1～0，共 13 个可绑定槽；F 和 G 是独立只读槽。G 保留现有按装备分派的符文长剑／法杖功能，不加入数字绑定数组。
- 宽窗口单排；放不下时 Q/E/X/F/G 单独上排、数字槽下排；更窄时数字分 1～5 和 6～0 两排，槽位和字不缩小。体力、蓄力提示、人物状态和弹药显示按实际快捷栏范围让位。
- 旧版本七槽存档升级为 13 槽：原索引不变，新增六槽为空；旧四格 Hotbar 镜像继续只映射 1～4。拖放、交换、解绑、消耗品与技能按现有业务执行。
- 铁铲入口改为 Shift+F7，F7 继续收起；更新实际帮助文字。数字 1～0 的战斗快捷栏与建造模式原有数字选择按模式互斥。
- 普通功能区与 G 槽不参与拖放；显示／隐藏 G 仅重排布局。布局变更有缓存，沿现有刷新调度，不新增资源加载与全量控件重建。

## 交付

完成源码与必要后台构建，不主动启动 UE 或游戏。用户要求的排查限定在上述尺寸、输入、存档与拖放路径；不追加游戏验收，由用户测试。
