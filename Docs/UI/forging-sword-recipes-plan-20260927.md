# 三把剑共用剑胚与锻造配方

## 目标与范围

将已存在的苍蓝星辉·双手符文剑、寒晶·双手剑接入铸造台，与高地·双手剑共用现有红热剑胚、三阶段成形、锻打、淬火和品质结算。使用当前正式武器定义生成成品，不另做模型、不修改武器基础属性。用户已授权接入；未要求预览或测试。

## 材料设计

| 成品 | 铁锭 | 银锭 | 木材 | 石英石 | 魔法粉尘 | 用途 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 高地·双手剑 | 8 | 0 | 2 | 0 | 0 | 保留现有入门配方，铁质剑体与木芯握柄 |
| 苍蓝星辉·双手符文剑 | 8 | 4 | 2 | 0 | 6 | 银质符文导路、粉尘注魔 |
| 寒晶·双手剑 | 6 | 4 | 2 | 8 | 8 | 铁质剑芯、银质导路、寒性石英晶体和较多注魔材料 |

仅使用现有 `ironIngot / silverIngot / wood / quartz / magic_dust`。数量是游戏制作成本，不是现实铸造质量配比；寒晶成品的晶体性质以注魔与淬火完成解释。高地配方保持不变，两种进阶剑增加冶炼、矿物和魔法材料成本；不引入额外独立小游戏、燃料计费或新资源。

废弃按已支付材料快照逐项返还 50%，全部偶数无舍入损失。成品领取及返料仍要求背包容得下全部结果，否则保留待处理工件。只统计背包和主仓库原有范围，不从祭品池、已装备栏或世界储物箱另行扣料。

## UI 布局与状态

- 继续使用 `UColdSteelForgingWidget`，尺寸、冷钢灰黑底板、滚动内容和固定页脚保持现有合同。
- 配方卡片：编号及成品全名 → 同高等宽的“上一配方 / 下一配方”按钮 → 已有/所需材料。横向空间不足时名称在标题区域换行，按钮保持单行；长材料列表随正文滚动。
- 轮廓区改名“成品预览”，显示各剑已有目录图。制作时三把剑均使用当前通用剑胚，不将成品复杂造型直接拿来锻打。
- 字体沿用 `GunsmithUI` 的冷钢字体入口：标题 16px、按钮/正文 14px、说明 12px；按钮为共享 ActionHeight，间距为 ActionGap，随现有 PixelScale 更新。
- 配方来自 `UColdSteelForgingSystem::Catalog()`，按 JSON 顺序切换、首尾循环；新增剑无需再增加按钮或分支。当前选择不写存档。
- 正在锻造或有尚未领取/废弃的工件时锁定配方切换，并显示其所属配方。结算、领取或废弃仍由系统事务保存。关闭重开时恢复待处理配方，避免预览与实际成品不一致。
- 材料不足时允许切换和查看，既有开始按钮提示实际缺料；选择变化立即刷新材料和目录图，库存变化复用 OnChanged 脏标记。关闭与焦点沿用现有 HUD，不增添世界输入入口。

## 共用剑胚与后续接入

`forging-recipes.json` 的 `sword_blank.points` 集中保存现有八处锻打区域，配方未自定义 points 时复用。原有显式 points 格式仍可读取，已有任务保存结构不变。
