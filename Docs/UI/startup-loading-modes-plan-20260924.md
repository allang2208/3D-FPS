# 启动主界面与两档加载

用户已授权制作并接入，未要求启动游戏测试。复用 TransitLoadingSubsystem 的 Slate 容器和 ColdSteelUIStyle。

首次本地玩家进入时显示不透明主界面，暂停游戏；选择后恢复场景准备。PIE、独立运行均显示，本次游戏内跨地图沿用选择，不重复弹出。保留现有默认地图和出生逻辑。

## 界面与输入

- 固定标题「无尽轮回」、副标题「选择进入方式」，下方两个纵排选项：快速测试／完整预加载。
- 快速档说明：优先进入，高清纹理随后逐步加载；仍保留原有地面、碰撞及导航等待。
- 完整档说明：等待当前场景、装备和高清纹理准备后进入；需要更长时间和更多显存。
- 共享中性灰主题、Noto Sans SC 及 JetBrains Mono。标题 24px，选项标题 16px，正文 14px，辅助 12px；标准按钮不缩字。
- 内容宽度上限 680px，窄窗跟随可用宽度，说明自动换行，矮窗主体滚动。鼠标点击、Tab/方向键焦点、Enter/手柄确认；Esc 不跳过选择。选中方式保存 GameUserSettings.ini。
- 加载失败显示原因，提供重试与返回选择；不自动降档、不把超时计为成功。

## 资源合同

选项只控制加载方式及有界纹理预算，不改分辨率、光追、Lumen、材质或模型。快速档保留当前 30% 自动池；完整档按 RHI 可用图形内存的 45% 设置纹理池，同时保留显存限制。退出 PIE 恢复被该会话修改的控制变量。

完整档在既有场景准备完成后收集当前世界已注册组件所用材质，包含玩家及其附属组件；去重、分帧处理。等待实际材质可渲染、允许且已安装的纹理 mip、当前异步资源及 PSO 工作完成。不预加载整个 Content 仓库、未生成的开放世界区域或未选择的装备。

只对当前世界的所需纹理暂时保护流出；总需求超预算时明确报错，不设无限池、不关闭流送。地图切换、取消、退出时释放保护；加载期间暂停玩家移动并临时免伤，结束后恢复。完成前再次收集，以覆盖装备的延迟装配；准备期间新到资源会继续加入。

## 文件与交付

TransitLoadingSubsystem.* 接入菜单、模式及加载状态；GameResourcePreparation.* 实现分帧准备；PlayerController BeginPlay 仅加入主界面入口。必要 Editor/Game 构建，不自动运行测试或截图。源码、实际二进制完成状态分别记录。
