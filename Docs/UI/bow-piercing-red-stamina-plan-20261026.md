# 穿心箭红色脉冲与持续拉弓耗体

## 用户调整

穿心箭进入判定后显示红色脉冲；取消持弓超时自动射箭，持续拉弓参照重击持续消耗体力。本记录替代原统一节拍方案的银白就绪，以及穿心箭初版的自动释放／0.75 秒释放宽限。

## 实际规则

- 从实际 Drawing 拉弦阶段开始，Holding 满拉保持期间继续耗体，搭箭／举弓准备不计。与重击共用 HeavyChargeStaminaPerSecond：基础每游戏秒 2 体力，乘当前动作耗体倍率，技能等级不改变该速率。
- 使用 UColdSteelStatusModel::TickStamina 的 Charging 分支，暂停自然回体、刷新恢复等待时间；停止拉弓后依既有恢复规则恢复。无每帧 RPC 或每帧存档。
- 持续拉弓超过 3 秒且满拉仍为穿心箭就绪条件。体力允许时可一直保持，只有真实松开输入会射箭；没有持弓超时发射路径。
- 体力为零时进入既有力竭状态并取消拉弓：平缓收弓，清除就绪／释放提示，箭仍在弦上，不消耗箭支、不造成伤害、不获得修炼。体力零不能开始新的拉弓。
- 出箭仍另付原本的射击体力成本，和重击的“蓄力持续扣、出手另扣”一致。出箭体力不足则缓收弓；已消耗的拉弓体力不返还。
- 原 hold_seconds 及改造倍率继续控制满拉呼吸抖动增长；UI 显示为“满弓稳定时长”，不再代表发射倒计时。

## 联机与取消

- 本地拥有者由弓组件 Drawing／Holding 驱动同一体力更新流程。
- 服务端通过既有可靠的拉弓开始／结束请求维护会话，影子角色的 TickStamina 同速扣费。PlayerState 在体力更新前处理死亡、换武器、翻越、冲刺和施法占用等取消条件；没有远端第一人称模型依赖。
- 体力耗尽时服务器清除会话，并通过 ClientCancelBowDraw 通知拥有者收弓；通知同时限定 Pawn 与武器实例，避免影响其他角色／装备。
- 射击仍由服务器校验会话、真实拉弓时间、体力和箭支后结算；已移除原持弓时间上限，释放成本与本地同样应用动作耗体倍率。
- 新 RPC 只用于取消；不接受客户端提交的耗体数值，不重复扣每帧资源。

## 红色提示

- 复用 120×4px 连续进度条、下方圆弧和末端菱形。普通拉弓与完美窗口保持淡金色；穿心就绪使用独立共享主题色 BowPiercingReady（#E84B4B）。
- 就绪后以 1.35 Hz 平滑脉冲改变亮度、轻微线宽和进度条周围的低透明红光；不闪灭、不扩散为准星外围圆环、不增加文字或新图标。
- 红光限于短条周围约 9px 高度；弧线宽度约 1.9～2.35px，短条约 4～4.65px。动画读取实际拉弓时钟，暂停时冻结。
- 与完美时机重叠时保留金色窗口边线，红色仍表达穿心就绪。松手成功后保留红色反馈 0.15 秒并淡出，取消不播放成功反馈。
- 绘制只增加固定数量的线／矩形，不新增纹理、材质、资源加载或 HUD 控件。
