## 玩法

每层拉弓速度+20%，最多5层（Buff满层+100%），常驻+20%保留。前五层仍由正常节拍放箭获得；未满层失拍清空。

满层且尚未过期时，每次成功手动射出箭都算节拍成功，无需满弓、无需命中目标：刷新4秒持续时间，保留5层，箭矢节拍快照与下一箭原节拍加速+25%也随之成立。最低拉弓比例50%、箭矢/体力消费、有效拉弓会话和射击间隔仍沿原入口；取消、低于最低比例或发射失败不会续期。穿心箭保持独立蓄力条件，箭雨等独立施法不新增触发。

服务端读取当前实例、装备、生命和未过期层数来决定自动合拍，不采信客户端的满层声明。本地表现使用同一组件条件，最终沿现有射击回执校正；不新增逐帧 RPC，不把临时层数写入存档。

满层腰射扩散−50%、物理伤害+20%沿用原计算。4秒无有效射出、切武器、拆弦或死亡清空，之后重新正常叠层。
