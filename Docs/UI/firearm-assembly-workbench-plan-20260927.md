# 枪械工作台：原枪分件拼装制作

## 目标与交付阶段

用户已确定：参考打铁的亲手制作感，利用原有枪械分件做小游戏；用途为「散件拼装，制作新枪」。

本文件记录 M4 枪械工作台小游戏。用户先要求接入实体工位，随后明确要求完成整个小游戏。本轮继续完成真实分件、桌面操作、校准、材料事务、品质与成品领取；下方第一阶段为此前交付记录，第二阶段为当前实现。

制作流程：选择配方 → 投入材料 → 桌面出现散件 → 拖动／转向／入位 → 完成校准 → 成枪展示 → 领取。

## 核心操作与节奏

### 桌面拼装

- 固定斜俯视工作垫；中央为枪身，周围分区摆放五个可装组件，保持互不遮挡。
- 左键按住组件拿起，鼠标拖动调整位置，滚轮调整桌面内朝向；松开落下。拖拽区域限于工作垫，组件不会因误操作飞走。
- 拿起组件后显示对应安装位置的淡银色轮廓；接近时只加强反馈，松开满足位置和角度容差才吸附入位。
- 拖动到错误位置不消耗零件，不破坏整枪；回到最近的安全摆放位置，给出「位置未对准」或「朝向未对准」。
- 五个外部组件可自由选择；每件只结算一次。选件与对位是主要内容，避免拆成大量不可辨认的小件。

### 入位与校准

- 组件接近接口后由短行程装配动画完成最后入位；手掌跟随组件，机械声在接触时播放，完成后组件固定。
- 首版只在少数关键工序使用一次短暂的锁定时机，普通组件对位后直接装入，避免每件重复同一蓄力条。
- 全部安装完成后进行一次约 4～6 秒的持稳校准：鼠标修正缓慢漂移的游标，在目标圈内累计时间；短暂出圈暂停累积，不清零。
- 最后拿起完整枪械展示，返回工作台领取。目标总时长约 30～45 秒；以主动操作为主，不插入长等待。

### 品质规则

- 记录对位误差、转角误差及校准表现，连续评分，避免只分「成功／失败」。
- 普通失误降低该环节评分，不损毁零件或整枪；不会因一次失误丢失已投入材料。
- 品质跟随产出的枪械实例，优先影响精度与稳定性。具体加成幅度在实现时与现有枪械公式统一，不预先改目录基础伤害，也不复制锻造的伤害倍率。
- 完成表现、品质分、实际收益分别展示；没有接入实战公式的属性不得写成已经生效。

## 界面与视觉

| 阶段 | 信息 | 布局与输入 |
| --- | --- | --- |
| 配方选择 | 枪型、材料需／持有、成品基础参数、开始按钮 | 沿用工作台与背包配套抽屉；标题、主操作固定，配方与详情各自滚动 |
| 正在拼装 | 当前组件、已装数量、简短操作提示、品质预估 | 大面积保留真实工作垫，下方窄信息条，不用面板遮住零件 |
| 校准 | 中心区域、游标、累计进度 | 读数靠近操作位置；短暂偏出只提示状态变化 |
| 已完成 | 枪械名称、品质、实际收益、领取按钮 | 成枪居中，操作固定；背包满时明确显示「成品保留待领」 |

主题使用 `ColdSteelUIStyle`：中性黑灰、银白轮廓、成功／警示语义色；中文 Noto Sans SC，数值 JetBrains Mono。沿用 V7 裸手标准。手部需要新做拿取、送入、释放及成枪检查的接触动作；已有打铁动作仅参考节奏，不直接套用锤子握姿。

窄窗优先保证操作区域与主按钮，材料和参数改为折叠详情；不整体缩小到难以选中组件。小组件的点击区域可适当扩大，但不能盖过相邻组件。

## 接入与数据合同

- 现有 `ColdSteelWorkbenchWidget`／`ColdSteelWorkbenchHUD` 和 `CraftingSystem` 提供工作台入口与材料事务参考；当前斧、镐即时制造保留。枪械配方必须进入拼装流程，不能从即时制造接口直接获得成品。
- 菜单改造继续走 `UGunsmithSystem`；本功能产出新枪，不把玩家已有枪作为隐含消耗，也不改已有枪的配件配置。
- 材料目录、显示持有量与实际扣除统一使用背包＋主仓库口径，排除独立箱子。配方成本由独立数据定义，不硬编码在 Widget。
- 开始时先完成必需资源准备，再以单次事务扣料并保存工件。作业保存唯一 ID、配方、已付材料、已完成组件、评分及最终成品，防止关闭重开重复收费或重复领取。
- 暂停／离开工作台保留已付工件，下次继续；不会进入未完成状态便发枪。读档后恢复同一作业，校准可从当前阶段重新开始。
- 领取时将实际成品放入背包并清除待领状态，共用一次库存保存事务；背包满或保存失败时保留成品。
- 成品的目录身份仍为 `ue_m4a1`，装配品质独立于改造与强化数据。装备、切枪、背包说明、改造总览及存档读取共用同一品质计算入口。

## 运行职责与资源范围

- 业务子系统负责作业、材料、进度、评分、品质与领取；Widget 只显示与传递操作。
- 工位交互 Actor 负责相机、组件、手部接触、音效及鼠标命中。组件装配关系由导出配置提供，每枪可复用同一套交互逻辑。
- 进入时收起抽屉，暂停战斗输入，保存原镜头与输入归属；退出、工作台销毁、角色失效时恢复。失焦立即停止拖动和计分。
- 操作只更新当前抓取组件与必要动画；静止零件不逐帧重建，不新增常驻 SceneCapture，不在 Tick 读取 JSON 或同步加载资产。
- 预期新增：枪械拼装业务、工位表现、操作提示控件、配方／装配配置、原分件导出／导入脚本，以及独立的工作台分件资产目录。
- 预期局部接入：工作台制作分流、输入仲裁、库存存档结构、统一武器品质计算与提示。原枪模型、实战骨架、配件挂点和锻造流程继续保留。

### 第二阶段：完整 M4 拼装小游戏

- `GunAssemblySystem` 读取 `Content/ColdSteelData/gun-assembly.json`。当前一把 M4 消耗铁锭 12、铜锭 4、木材 2，取背包与主仓库，排除独立箱子；资源准备完成才允许开工。
- 在同一角色存档事务中扣材料并写入唯一工件、待产出物品、实际支付材料；任一失败不提交。工件是 `FColdSteelGunAssemblyJob` 可选标签字段，旧档默认无工件，未修改存档版本。
- 六个静态网格由原 M4 作者文件导出：枪身包含原扳机，其余五件独立，保留原材质和共同装配坐标。资产已通过当前编辑器桥导入保存于 `/Game/Building/GunWorkbench20260927/Assembly`；回执 `Receipts/assembly-import.json`。
- `GunAssemblyInteraction` 固定工位相机，直接显示真实桌面和组件，不增加 SceneCapture。鼠标左键抓取／松手安装，滚轮或 Q/R 每步旋转 5°，右键放回；Tab 将指针移到下一个未装小组件；Esc 保存返回。
- 拿起显示对应组件的半透明轮廓，位置和角度同时满足时变绿。位置容差 5 cm，角度容差 18°；不要求按特定组件顺序。成功后 0.32 秒送入，接触时播放原 M4 机械声。失误放回托位，降低本件评分，不丢材料、不发枪。
- V7 裸手沿用项目原生骨架和抓握源，双臂通过肩肘腕链求解，左手支撑枪身，右手随抓取与送入移动；原实战手臂和动画不覆盖。
- 每件装配后保存完成位与分数。装完后按住左键完成累计 5 秒持稳校准；出圈暂停累积，松手暂停，失焦停止抓取和校准。校准进度在正常退出时保存，自动存档沿用角色机制。
- 评分为 70% 对位分＋30% 校准分。对位分含位置、角度与失误惩罚；品质为精工（≥90）、优良（≥75）、合格（≥55）、粗制。最高后坐力降低 12%、腰射散布降低 15%，伤害不受工艺影响。
- 完成后展示组装成枪及品质，Enter 或约 4.5 秒后返回领取页。领取使用同一物品插入和清除工件事务；背包满或保存失败保留成品。成品空弹匣，不附赠弹药。
