# 元素箭 V4：资源与搭箭表现

本轮由用户要求实施：提高三元素箭蓝耗、持续拉弓扣体力与魔法、降低火焰成长，并补全队友搭箭阶段表现。

## 界面

- 沿用元素技能详情的 Cold Steel CardBrush、三张来源卡、TrainingCard 及完整 20 级表，不新增页面。
- 来源卡保留来源学习状态与 CD，将蓝耗标明为“射出 N MP”。
- 同款深色卡显示射出费用倍率、持续费用、搭箭待机规则及资源不足收弓规则。文字横排，窄屏按句换行。
- 数值来自统一 ElementalArrowTuning 与 ElementalArrowStats；轮盘、准备验证、释放结算和详情同一口径。

## 数值与交互

火焰 1.50→2.75；寒冰/闪电 1.25→2.50。2–10 级每级 +0.05，11–20 级每级 +0.08。射出费用为对应魔法 ×1.5，向上取整；实际持续拉弓 3 MP/s，体力沿用普通弓耗体，不重复计费；自然回蓝暂停。已发生的维持消耗不因取消返还，缺少射出蓝量时收弓，资源不足不自动射箭。

第三人称复用现有元素 Niagara、箭雨流动材质及照明圆弧/灯光。服务器决定附魔类型，身体动作包提供箭杆姿态，观察端就地重建。第一人称和第三人称根据本机镜头互斥显示，收弓、换装、死亡等清除持有特效。

后台编译 Editor/Game，不启动编辑器，不运行游戏或自动测试，不重新打包。现有资产直接复用，无待导入新资产。构建记录位于 `Saved/ElementalArrow20261027/BalanceV4_ThirdPerson/`，视觉效果和多人运行由用户测试。
