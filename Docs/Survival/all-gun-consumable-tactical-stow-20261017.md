# 全枪械进食收枪：镭射与手电

范围：按当前 `gunsmith.json` 的 19 个枪械条目逐条读取战术件目录、主手创建入口、第二槽能力、副手创建入口、本地 F6 世界副本及远端配件清单。开始排查时为 18 条，期间新加入的 Saiga 12K 也已纳入。这里只记录源码／配置排查，不代表逐枪实机或联机测试。

## 发现与修复

1. 原本本地仅在 `IsTwoHanded()` 时隐藏独立光效。吃普通面包、法棍、鸡腿、羊肋排、香肠等单手食物时，副手枪也会收起，但降低／回位阶段仍可能亮灯或发出镭射。现先读完整 `IsStowingOffhand()` 状态，再按设备实际宿主区分主副手；双手大羊排关闭全部枪械设备，单手消费关闭正在收起的副手枪。仍握持的主手枪维持原行为。
2. `ReadLaserSample()` 使用同一宿主判断，并拒绝 `bPresentationHidden`，避免身体组件在设备 Tick 之前复制上一帧残留落点。
3. 远端的 Consume 判断改为按实际 Rig 的 `AttachHand` 区分：全部消耗品收起左手枪，大羊排同时收起主手枪。手电和镭射采样共用此判断，覆盖同步状态中的降低、使用、抬回，不新增网络字段或 RPC。
4. 远端手电创建曾仅允许 M870／Super90。现在像镭射一样，从每把枪的实际已安装配件清单创建；复用该配件网格、轴线、Rig、Part 和 Schema，不替换为其他枪的配件。

所有处理只改变当前发光输出，不改设备配置或启用状态；结束／取消后按正常可见性与原设置恢复。取消、死亡、翻越及更换装备沿用现有动作打断和设备销毁逻辑。

## 喝水／喝药专项跟进

按用户后续要求，沿实际入口补查饮用、恢复和取消路径。结果：以下饮用动作已由上述共用修复覆盖，本轮没有新增源码或资产修改，也没有重复构建。

| 饮用品 | 定义／状态 | 收枪关闭与回位恢复 |
| --- | --- | --- |
| 矿泉水 | `mineral_water`，满瓶／半瓶（remainingUses=2／1） | 同一执行器；两次饮用均覆盖 |
| 普通生命／魔力药水 | `hp_potion`、`mp_potion` | 覆盖 |
| 中级生命／魔力药水 | `hp_potion_medium`、`mp_potion_medium` | 覆盖 |
| 高级生命／魔力药水 | `hp_potion_high`、`mp_potion_high` | 覆盖 |
| 特级生命／魔力药水 | `hp_potion_special`、`mp_potion_special` | 覆盖 |
| 汽水 | `soda_can` | 同组件顺带核对，覆盖 |

这些饮用品当前为单手动作：存在副手枪时，放下副手枪；未收起的主手枪维持原行为。本地设备以实际宿主匹配副手，F6 复用本地设备并核对世界枪械显隐，远端设备按复制的 Consume 状态和 Rig 的 AttachHand 判断。收枪前导 0.28 秒、饮用全程及回位 0.26 秒均在 `IsStowingOffhand()` 生命周期内。

`HideEffects()` 只隐藏光束、落点和手电并清除镭射缓存／归零混合，不改 Kind、配件配置或设备 Tick 启用状态。正常结束或取消后，在该视角的武器恢复可见且原设备仍启用时恢复发光；原关闭／未装的设备不会因此开启。药水取消后若需要展示弃瓶，世界身体保留既有最长约 0.3 秒弃瓶尾段，期间武器和光效保持一起隐藏；尾段结束再随武器恢复。

喷泉交互只执行补水与音效，当前没有收枪动作，不在本轮额外添加收枪或改变枪械开关。
