# 食品腐败（2026-10-15）

本批规则：生肉 3 个自然游戏日，熟食 4 日，面包类 8 日，面包优先。当前目录覆盖四类生肉、四类烤肉、普通面包和法棍；饮料、药剂不腐败。腐败食物不可食用、无效果或配方，1×1、每堆最多 10。每次转换份数为原单件占格面积乘件数，旋转不改变产量。

## 时钟与实例

`Items/FoodSpoilage.*` 从权威目录缓存读取寿命，实例 JSON 不能延长或禁用寿命。实例保存时钟域、采样日和累计年龄；拆分、搬移、丢下、拾取、容器、读档均保留。只有出生点完全相同的食物才能合并，避免新食物刷新旧批次。

`Items/FoodSpoilageClock.*` 累计现有 `AFPSWeatherManager::GetNaturalDayProgress()` 的自然增量，不驱动天空、不用固定 108 分钟计时。暂停、离线和手动跳时不增加年龄。没有权威天气时钟时不猜测日长。档案保存自然日 checkpoint；换时钟域或恢复较新的共享 checkpoint 时先物化已累计年龄，避免倒退返鲜。无旧时间字段的食物在首次迁移开始寿命。

个人库存每秒及操作前结算，已共享世界每五秒及操作前结算。未到期只扫描字段，不克隆整份库存或写盘；客户端仅显示服务器时间。OwnerOnly 小时钟样本每秒发布，完整镜像和库存差量携带同一时钟；晚到镜像不覆盖同域新样本。库存版本与服务器已知实例年龄保护拒绝旧上传恢复过期食品。

## 转换与保存

转换先在副本中完成：移除所有本轮过期项，合并同一容器已有腐败堆，再使用原物品释放的格子，每堆不超过 10。现有食品全部单件一堆，产出必能放回释放空间，满包无需丢物品。异常旧数据若无法完整放下，则保留整批原过期物品、禁止食用／烹饪并提示，不截断数量。地面产出保留位置、所属地图与世界标识。

个人档案沿用校验和 A/B 保存、库存事务版本和失败保护；共享世界转换有完整 After redo 日志，写盘未确认不发布 live 状态，恢复失败保留现场。新地面实例 ID 通过原掉落 Actor 同步路径替换；已打开容器通过原 revision 失效刷新。

## 篝火

活动原料、队列原料和待领取成品保留完整 `FColdSteelItem` payload。原料等待或断火仍老化，过期不能继续烹饪。熟食从真正完成的自然时钟位置起计时；未领取也老化，领取和拆除退料不重置。离线烹饪沿用现有 UTC 燃料合同，但离线自然日不前进，所以新产出不补扣离线寿命。批次 payload 只保存、不向全员复制整份 JSON；公开食物和数量仍走原共享快照。

建筑 VBX 追加 v13 食物字段，v10–v12 主体字节布局不变；旧队列与成品在首次读取时迁移。超过原烹饪槽 60 份的面积换算产物完整保留，不按槽上限截断。满包领取失败保留产出。
