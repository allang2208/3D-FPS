# 通用枪管与距离伤害衰减

## 数据来源与当前规则

枪管数值来自 Godot 归档标签 `archive/godot-before-ue5-20260910` 的 `scripts/barrel_variants.gd`。旧版占用历史 `foregrip` 槽，本次映射为 UE 的 `barrel` 槽；不占用前握把，不修改模型。

| 属性 | 轻型短枪管 short | 重型长枪管 long |
| --- | --- | --- |
| ADS 开镜耗时 | -20% | +20% |
| 腰射随机散布 | ×0.5 | ×1.5 |
| 后坐力 | ×1.15 | ×0.85 |
| 镜头抖动 | ×1.15 | ×0.85 |
| 有效射程 | ×0.8 | ×1.25 |

没有额外改变弹速、近距离基础伤害或模型。用户随后指定 ADS 改为百分比：短枪管 -20%、长枪管 +20%，通过 ads_percent 与其他配件的 ADS 百分比相加，最终遵守现有 1 ms 最小耗时。此项覆盖 Godot 原版固定 ±200 ms。

旧归档未找到对应距离伤害衰减实现，用户明确改为新开发：有效射程内 100%，超出后线性衰减，最低 10%。本次将衰减终点定为有效射程的 2 倍：

`倍率 = 1 - 0.9 * clamp((命中距离 - 有效射程) / 有效射程, 0, 1)`

例如有效射程 100 m：100 m 内 100%，150 m 为 55%，200 m 及以后为 10%。这只是公式示例，不修改现有枪型基础射程。当前目录中的步枪基础有效射程为 1000 m，M1911 为 50 m；枪管在各枪基础值上乘算。

## 接入

- `gunsmith.json/common_options/barrel` 是唯一通用数值定义，目录加载时合并到全部枪械，包括 M4、AKM、QBZ191、M1911 和后续新增目录枪械；同 ID 的枪型专用选项优先。
- 使用现有草稿、应用、恢复原厂、实例保存与装备属性通道，不增加存档格式。面板继续使用统一 Calculate 结果，原“最大命中距离”改为“有效射程（全伤害）”。
- `WeaponDamageFalloff.h` 供实体弹道、即时命中及穿透命中共同使用。距离从枪口累计，实体弹丸在发射时保存有效射程；同一帧穿透多个目标也按各自命中距离结算。
- 距离倍率作用于送入既有技能/部位结算的直接枪击伤害，既有中毒等独立效果保留。
- 有效射程与子弹消失距离分离：最大飞行/射线距离为原默认上限与 3 倍有效射程的较大者，使满伤害、衰减段及最低伤害段都能存在。

本次按用户规则不进行自动检查、玩法测试、存档回归或渲染。仅进行开发所需构建；构建结果见 build.log，游戏效果由用户测试。
