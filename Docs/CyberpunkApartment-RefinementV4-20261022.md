# 公寓 V4：柜体设计与逐组件 PBR 升级

用户要求升级储物柜的赛博朋克造型、去除突兀的卡片式贴片，并逐个检查房间组件、改善材质和法线细节。本轮沿 `asset-model-workflow` 的规则几何、表面分区、法线／粗糙度、实际安装面与共享资源流程实施。

**已导入并保存 `/Game/GameMaps/L_CyberpunkApartment`。** 本轮不改房间尺寸、家具位置、45 个容器的 ID、开关动画或储物内容。原地图备份见 `SourceAssets/CyberpunkApartmentRebuild20261022/RefinementV4/installed.json`。

## 储物柜

- 重做 13 类柜体的门面／抽屉与柜身细节，共 26 个网格，替换地图内 86 个柜体部件实例。冰箱原模型继续复用，其表面参与材质升级。
- 原独立卡片式大屏、悬浮文字片从柜门作者源移除。新门板具有真实铣削凹槽、嵌入式识别部件、凹入把手、实体金属收边、内嵌状态灯和独立合页。
- 内部保留可见隔板、背板、抽屉托盘，增加内衬、加强条和安装件。锁具与把手位于原门扇包络内，铰链与抽屉原点不变。
- 灰黑主体分为细颗粒涂层、深色阳极氧化面板、拉丝金属边条和内衬；没有用大片高亮贴片替代结构。

## 材质

建立 23 类公寓专用 PBR 表面，覆盖墙体、天花、地板、门窗框、柜体、床品、窗帘、地毯、沙发、桌椅、厨房电器、卫浴、电脑壳体和健身设备。

| 表面 | 法线与高光处理 |
| --- | --- |
| 柜门／设备面板 | 项目阳极氧化法线与粗糙度；局部蚀刻高度场导出的法线使用 RNM 混合 |
| 金属边框／器材 | 项目拉丝、喷砂钢材法线，合理金属度与粗糙度范围 |
| 涂层／墙面／天花 | 按用途区分颗粒强度与物理重复尺寸，避免整面强噪声 |
| 布料／床品／地毯 | 复用实际织物、条纹与地毯 PBR，按作者 UV 和网格密度调整尺度 |
| 木饰面／台面／地面 | 复用木纹、大理石、混凝土表面，保持灰黑配色 |
| 陶瓷／橡胶／内衬 | 细微釉面、橡胶颗粒与独立粗糙度，保持材质差异 |

共复用 38 张项目已有纹理，新增两张共用运行纹理（蚀刻 Normal 和 ORM）。蚀刻由 40 微米物理高度场求导，附带高度源；它不是从颜色阴影猜出的凹凸，也不宣称是实拍扫描或高模投射。新法线采用 DirectX 约定、不翻绿；现有库纹理不改写压缩或色彩空间。

色彩按线性参数进入材质，BaseColor 按来源 sRGB 采样，Normal 采用正常法线采样，ORM 为线性 Masks。法线、粗糙度与蚀刻共享坐标；保持 Mip 和纹理流送。使用 76 个共用／按 UV 尺度适配的材质实例，不新增逐帧逻辑、动态灯或 POM 搜索。

透明玻璃、屏幕内容、发光体、液体、植物及已认可的外景按各自用途保留，不把微表面法线强套到天空或显示图像。139 个专用材质槽在清单中注明保留；隐藏碰撞体和外景单独列明。

## 用户要求的逐项检查

- UE 地图：修改前后均为 **275 个网格组件**，保留组件位置与用途。
- **155 个作者源网格**完成有限坐标、UV 存在性、零面积三角形与退化 UV 检查；这四项均未发现异常。
- 本轮 **895 个升级材质槽**按保存后的组件引用逐项核对；预期法线资源没有缺失绑定。
- 检查读取有效材质实例参数及源材质图。在 NullRHI 下编译纹理列表可能为空，不能以空列表判断“没有法线”；本轮采用源图和实例参数补全来源。
- 没有运行游戏、PIE、视觉验收渲染或性能采样。上述检查不证明运行时无穿模、无闪烁或视觉效果已获认可，也不把作者面数当作实际帧率。
