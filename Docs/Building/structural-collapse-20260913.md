# 20 cm 建筑承重与倒塌

本次为 UE 5.8.2 的本地单人建筑系统实现。宿主为 D:/FPS3D/FPSGAME。保留原有四个世界入口、材质资产、默认吸附、F 连续自由放置和圆角表面。没有新增付费美术依赖。

## 行为

- 建造位置按实际碰撞、接触面与地基连通性判断。绿色表示位置允许放置；放置后的实际重量仍可能导致连接断裂或构件压坏。取消吸附后坐标不量化，预览以 10 Hz 更新合法性，点击时重新计算实际位置。
- 删除承重柱不再被旧的“会失去支撑”规则禁止。失去地基连接的部分组成残骸，在静态碰撞更新后由 Chaos 下落。
- 构件自重、已登记的外部荷载、部分接触面积、抗压／抗拉／抗剪强度、弯矩和已有损伤参与承重判断。旧的固定 2 m 悬挑参数不再决定倒塌。
- 枪击和爆炸通过现有 ApplyPointDamage／ApplyRadialDamage 路径接入。点伤只作用于命中的体素，范围伤害按距离作用于接触范围。
- 残骸落地或撞击建筑会消耗冲击能量，使接触范围内的体素受损、消失或继续分离。两个建筑残骸的接触只由一方登记冲击，避免重复计算。较大的冲击也会伤害角色。
- 落地残骸保留碰撞、材料和可破坏性；建筑模式右键可拆除瞄准的残骸单格。物理破坏发生后清除旧撤销记录，避免撤销复活已经倒塌的结构。

## 材料初始参数

以下是可调的游戏参数，不是工程材料认证值。木材偏轻且连接较韧；石材较重，抗压较高，拉伸连接较弱。

| 材料 | 密度 kg/m³ | 单格质量 kg | 抗压 Pa | 抗拉 Pa | 抗剪 Pa | 耐久 | 每点冲击损伤 J |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| wood | 600 | 4.8 | 350000 | 80000 | 60000 | 180 | 6 |
| stone | 2600 | 20.8 | 3000000 | 12000 | 40000 | 500 | 15 |

已有 Palette 资产自动按材料 ID 取得这些默认值。启用材料条目的 bOverridePhysics 后，可在 Physics 里独立配置。接触检测允许 2 mm 接缝误差，但按真实重叠面积计强度；最小计入接触面积为 4 cm²。共享接触材质摩擦为 0.8、恢复系数为 0.03。

## 计算与物理的分工

VoxelSupportGraph 保存世界坐标下的面接触关系，可跨自由放置体积连接。编辑更新局部节点及邻接关系；后台任务只取得相关连通区域的快照。节点版本用于识别过期结果，因此修改另一栋无关建筑不会废弃已经完成的求解。

NVIDIA Blast 5.0.6 的 StressProcessor 负责六自由度约束力／力矩求解，输入使用米、kg、秒，输出用 N 和 N·m。项目适配器按每个接触面的材料强度和剩余耐久判断失效。它是准静态游戏承重估算：不模拟连续弹性形变、裂纹扩展或完整有限元材料模型。

每次后台求解先尝试 256 次迭代，必要时增加到 512、1024、2048。未收敛的数值不会触发不可逆压坏或断键，界面会显示未收敛状态；完全失去地基连接的部分仍可按连通性直接脱落。

脱落后使用 UE Chaos 的合并简单碰撞体。规则整片地板优先保持为整块；复杂形状超过每块碰撞形状预算时再做空间分块。总质量和质量重心按材料质量设置，转动惯量由合并碰撞体估算。残骸再次破坏后保留平移及旋转产生的速度。

该实现使用固定版本的 Blast 内部应力内核，通过独立 C ABI 隔离；没有引入旧 UE4 Blast 插件或 PhysX 刚体系统。EBS V10 仍是已有参考资产，没有成为承重求解器。

## 性能预算

| 项目 | 默认值／方式 |
| --- | --- |
| 静态体素 | 16³ 源区块，按世界空间合并显示组件；自由放置保持独立数据 |
| 静态碰撞 | 贪心合并解析盒体，不随编辑烹饪三角碰撞网格 |
| 快照收集 | 每帧最多 512 个结构节点，约 1 ms 软预算 |
| 静态网格后台任务 | fps.Building.MeshWorkers = 2 |
| 静态网格／碰撞提交 | fps.Building.MeshAppliesPerFrame = 1，约 1.5 ms 软预算 |
| 新残骸 Actor 创建／激活 | fps.Building.SpawnsPerFrame = 8 |
| 新激活刚体准入预算 | fps.Building.MaxActiveBodies = 128 |
| 活跃碰撞盒准入预算 | fps.Building.MaxActiveShapes = 2048 |
| 单残骸碰撞盒 | fps.Building.ShapesPerBody = 64 |
| 残骸网格准备 | 一条后台队列 |
| 接触荷载采样 | 每 0.25 秒最多 32 个已登记接触对象 |
| 保存 | 0.75 秒合并编辑；运动期间约每 3 秒请求一次快照 |

以上是准入限制和软时间预算，不是恒定帧率保证。一项组件提交可能超过软预算；休眠的 Chaos 刚体受到撞击后自行唤醒，也可能让实际活跃数短时超过准入值。超预算的脱落部分保留并排队，不会为了满足数量而直接删除。落入世界 KillZ 以下的残骸按世界边界移除。

稀疏圆角网格只计算占用区域附近的采样。连续自由放置产生的源网格也并入空间分组，避免每次单格放置都永久增加一个独立显示组件。静止且未改动的建筑不重复运行承重求解。后台工作只持有纯数据／几何快照，不读取或修改 UObject。

## 荷载接口

角色及可模拟物理的道具接触建筑后会登记荷载，随后以接触点向下追踪确认承载面；离开接触面会移除该荷载。落在建筑上的残骸同样可传递静态重量。

非物理业务对象可调用 Blueprint 接口 SetAppliedLoad(LoadId, ContactPoint, MassKg)。ContactPoint 使用世界坐标的承载顶面；同一 LoadId 会更新原荷载，MassKg = 0 移除。拥有者负责在恢复、移动或库存重量变化时登记，其物品数据不写入建筑存档。

DamageBuilding(Position, Amount, RadiusCm) 提供世界坐标的点／范围建筑伤害入口。Save() 表示保存已排队，不代表磁盘写入已经完成。建筑面板显示承重、倒塌队列和保存失败状态。

## 存档及迁移

继续使用原来按角色档案与世界标识生成的 Voxel20_* 槽位。V3 保存静态格、自由体积原点、耐久损伤、断键、残骸材料及格数据、位置／旋转、线速度／角速度和休眠状态。

旧 V1／V2 的所有建筑保留，不在迁移时自动受新强度规则破坏。主动编辑或损伤相关连通结构后才启用新规则；这项迁移保护也会写入新档。原始旧档首次升级时另留 .pre-structure 文件。

主线程取得状态快照后，纯数据编码、CRC 和写盘在后台单写入队列中完成。先写 .pending 文件，再使用 Win64 替换 API 更新正式文件；不使用先删除正式文件的通用 Move 流程。写入失败保留内存状态及原有正式文件，面板提示并重试。退出世界时等待在途写入并保存最终状态。

静态网格与残骸之间的交接明确分阶段：新残骸准备期间保存原静态格；交接后保存残骸。损伤分裂期间保存新的残骸数据并排除被替换的旧对象，避免同一部分同时保存两次。残骸获得独立体素身份，重建原来的网格坐标不会把旧残骸的断键接回。

## 源码及依赖

- VoxelBuildWorld*：世界数据、队列、战斗接入、保存与交接。
- VoxelSupportGraph：面接触图、连通性和 Blast 适配。
- VoxelBuildGeometry／VoxelSurfaceMesher：圆角表面、合并碰撞及分块。
- VoxelCollapseFragment：复合刚体和接触事件。
- VoxelBuildPersistence：兼容旧槽位的新格式与后台文件写入。
- Source/ThirdParty/Blast：固定版本源码、适配器与许可。
- Tools/Building/build_blast.py：本地构建静态依赖；首次恢复源码工程时先执行，再构建 UE 工程。
