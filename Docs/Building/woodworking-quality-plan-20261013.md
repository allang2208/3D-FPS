# 木工成品工艺修正

评分沿用现有 0–100 分工艺成绩，倍率 = 0.75 + 0.005 × 分数；50 分不变，80 分 +15%，100 分 +25%。通关仍要求废料清除至少 80%、主体完整至少 80%、关键连接完整。

弓：倍率仅乘物理伤害分项，附加魔法伤害不参与。法杖：倍率作用于本件法杖提供的魔法攻击，进入原有法术公式；角色自身魔攻、副手魔法书和挥杖物理伤害不受此倍率直接修正。

持久化：新增成品 JSON 的 `_woodworkingQuality`，记录版本、分数、倍率和作用通道，不修改基础配方数值。权威完成加工时一次写入；旧版已完成待领取工件按保存分数补入，已领取且无评分记录的装备维持原数值。失败品仍只能折半退款。

联机：服务端切割与评分决定品质；领取、继续、废弃等事务绑定工件 ID；已知成品品质以服务器快照为准，阻止同库存版本的旧上传覆盖品质。客户端回执与镜像保留成品品质，使用相同伤害评估器。存档、仓库、掉落及改造沿用整个物品 JSON。

UI：成品预览、背包详情和公式说明显示对应品质与修正，替换“评分不改变属性”的旧说明。正常底部操作和 80% 通过标准保持现有设计。

后台编译落盘，不启动 UE 图形编辑器、不运行游戏或联机测试。运行效果交由用户测试。
