# 木工锯齿红色提示修正

用户反馈：锯齿不明显，之前要求的红色高亮未达到实际使用效果。

本轮修改：

- 锯片红色漆边的遮罩起始半径从 14.4 cm 改为 13.2 cm，覆盖实际齿尖和齿根附近；保留中心钢材表面。红色发光从 0.1 提高到 1.5，并按曝光反向补偿。
- 单独旋转锯片的所有材质槽显式绑定同一局部径向漆边材质，覆盖各 LOD 仍引用原图集的槽位。
- 修正制作脚本对已有漆边材质直接返回的行为，已有材质也执行升级和保存。
- 加工提示改用独立、不透明、无光照的顶点色材质。固定在锯片插槽坐标中，沿真实接触弦绘制；红色中心宽度对应现有切缝，深色描边仅用于增强辨识。
- 调整状态显示红色虚线，切割状态显示红色实线；备用平面操作界面同步。实际锯齿由本体漆边着色，不再用光滑圆弧套管代替锯齿轮廓。
- 新提示材质目录加入打包清单。

素材通过 Saved/WoodworkingSawHighlight20261013/MaterialHost 的独立无界面工程生成，完成后仅安装指定材质文件。源码构建与材质保存分别记录在同目录交付回执中。

未启动图形编辑器、游戏、PIE、截图或运行测试；实际可见性由用户体验确认。
