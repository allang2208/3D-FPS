# 蛋糕塔喷泉：边缘溢流 V7（2026-09-19）

用户认为本版方向正确；当前续篇为 [V8 自然随机性](fountain-overflow-v8-natural-20260919.md)，
复用本版几何与距离预算，替换水膜/飞沫的规则排列。本页保留 V7 制作记录。

用户已认可盆中水体，本次授权改进边缘落水的固体感/贴图动画感，并兼顾多座构件的性能。
保留 `SM_RomanFountain_WaterWaves`、`MIC_FountainWaveWater`、盆中泡沫/湿痕/焦散、主体与调色板数据。
本轮不运行游戏、截图、渲染或性能测试；下文为实现与制作预算，不是视觉验收结论。

## 实现

- 新资产位于 `/Game/Props/RomanFountain20260917/OverflowV7/`。
- `SM_FountainOverflowV7`：四段单层水膜，共 6,979 顶点、12,992 三角形（作者生成计数）。
  从实际盘沿短膜过渡到抛物线离唇轨迹；沿下落方向细分以支持 WPO。无实体内壁、无碰撞、无阴影。
- UV0 = 环向位置/归一化飞行时间；UV1 = 层号/该层飞行总时长。关闭自动光照 UV，保留 UV1 数据；
  使用全精度 UV，局部位移经 Local→World 向量变换，支持构件平移和绕竖轴旋转。
- `M_FountainOverflowNearV7`：Default Lit 半透明，基础不透明度 0.22，法线/菲涅尔、下落扰动、
  中下段渐进缺口与局部白沫；无大面积白色自发光、无 SceneColor 折射采样。
  花纹相位使用 `时间 - 飞行时间`，与几何下落加速对应，不再按高度匀速滑动。
- `M_FountainOverflowFarV7`：减少波形计算与位移幅度，用于 40–62 m。每座材质实例有独立相位。
- `NS_FountainLandingSprayV7`：一个 GPU 发射器覆盖四段落点。复用本地已制作的雨水飞溅发射器
  框架副本，移除其碰撞/重力积分/形状等模块，使用局部空间解析轨迹与寿命。
  落点半径与水帘生成数据同源；喷起高度约 5–16 cm，寿命约 0.204–0.357 s，返回接收平面时结束。
  材质为原创的程序化小水滴，无下载或新增第三方内容。

## 运行接入与预算

`AColdSteelFountain` 新增 `CascadeMesh` 和 `LandingSpray`。仅在旧 `WaterFxMesh` 组件的槽 2
覆盖 `M_FountainHidden`，保留旧资产作为恢复来源；现有盆水与其他槽不改。新建与已有逻辑构件在
BeginPlay 采用同一配置，建造存档字段与占格保持原有规则。

| 距离（相对相机） | 表现 |
| --- | --- |
| ≤20 m | 细节水膜；获预算的喷泉有完整附加飞沫 |
| 20–40 m | 细节水膜；飞沫出生率随距离线性递减 |
| 40–62 m | 简化水膜材质，关闭附加飞沫 |
| >62 m | 关闭附加水效及塔尖粒子，盆中水面继续显示 |

- 每个世界统一每约 0.25 s 更新飞沫候选，依据最近渲染状态与距离，最多选 4 座。
  先关闭失去名额的系统，再开启新系统；未换名额的系统不会每次重置。
  `fps.Fountain.MaxSpraySystems` 支持 0–4；限制只针对新增落点飞沫，不隐藏其他喷泉的网格水帘。
- `fps.Fountain.Quality 0`：仅盆水；`1`：默认 360 粒子/s；`2`：480 粒子/s。
  发射器再次将出生率限制在 480/s，按最大寿命估算稳定态约 172 个附加粒子/座，默认档约 129 个。
  这是制作预算推算，未测 GPU 帧时间，不能由粒子数直接得出 FPS。
- 水效组件排除光追几何和距离场，无逐粒子场景碰撞、无每座流体网格/渲染目标。
- 近景距离档恢复为 0 后，已有占位水声的近距离条件也恢复可达；音频资产与播放配置未替换。
- 专用服务器不运行这些表现层 tick，销毁构件时释放飞沫及世界预算登记。

- 原生构建记录：同目录 `build-editor.log` / `build-game.log`；两目标均返回 `Succeeded`。
  Editor 已生成本轮模块 DLL；Game 构建器报告 `Target is up to date`，未追加游戏运行测试。
- 执行中编辑器被打开，后续资产制作转入现有编辑器进程。新增 C++ 组件通过独立模块后缀构建，
  用户下次重启编辑器加载。未热重载 UPROPERTY 布局、未关闭用户编辑器。
- 编辑器构建同时给 `FPSGAME`、`AutoFootstep`、`AutoFootstepEditor` 指定 `9191730` 后缀，
  避免覆盖编辑器占用的插件 DLL。此方式保留 `-NoHotReloadFromIDE`，不加 `-NoHotReload`；
  后者会禁用模块后缀并尝试写回原 DLL。这里只生成供重启加载的二进制，未调用运行期热重载。
- 整体构建遇到 `VoxelBuildWorldPrefab.cpp` 对 `FVoxelBuildRuntime` / `FVoxelSupportGraph` 的
  不完整类型错误；只补入 `VoxelBuildRuntime.h`，保留该文件中并行会话的其余实现。
