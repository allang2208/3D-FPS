# 配方手册预览尺寸修正

用户反馈：打开配方手册后正文区域看似空白，没有正常显示书本模型；截图左上角有一个很小的书页形状。

`UColdSteelAlchemyBookPreviewWidget::NativeOnInitialized` 将预览 `UImage` 加入 `UOverlay` 后没有设置槽位对齐。`UOverlaySlot` 默认左上对齐，而材质画刷保留默认的小尺寸，因此书本渲染结果只占阅读区域左上角的一小块，书页文字也随之缩小。外层 `USizeBox` 的 1400×1100 设计尺寸并不会自动让这个子控件铺满。

在 `Source/FPSGAME/UI/ColdSteelAlchemyBookPreview.cpp` 中将该图片槽位的水平、垂直对齐均设为 Fill。外层现有 ScaleBox 继续等比适配窗口。沿用现有三维书本、翻页、配方内容与页面材质；本次没有重制模型或改变制作流程。
