# 木工第一批表现升级：木板本体与加工标记

用户已要求开始实施升级方案。本批完成板面、侧边、端面、微倒角与高对比加工标记；切削音效/掉料动画与配方专用毛坯属于后续两批。

## 制作与接入

- 原始工件仍由真实 Wood/Target/Damage 遮罩驱动；不更改切割精度、计分、配方、存档或锯片接触面。
- 板面用 XY、顺纹侧壁用 XZ、端面用 YZ 展开；修复旧侧壁 UV 忽略厚度的问题。沿板局部坐标制作连续程序木纹、端面年轮、细纤维、少量木结及粗糙度/细表面法线。木材不发光、非金属，避免油漆般高反光。
- 可见上边缘制作不超过 0.45 mm 的内收微倒角。内区仍使用贪心合并面，仅边界带细分。原轮廓、孔洞、连接与底面不变；复杂切口超过原几何预算时只省略微倒角，保持实景工件。
- 白色粉笔线加深色衬边；废料使用低覆盖度斜线，保持底下木纹可见；损伤仍用红色标识。标记为木板局部几何，遮挡与实际物体一致，不采用固定屏幕偏移。
- 沿用一个后台几何任务、revision 合并更新与 15 Hz 上限。资源异步加载，制作阶段在独立无界面材质工程保存新版本资产。
- 新资产只写 `/Game/Building/WoodworkingSurfaceV2_20261026/`；旧材质保留。源脚本、HLSL、创建回执与构建日志放 `SourceAssets/WoodworkingSurfaceV2_20261026/`。

## 边界

复用当前木板尺寸与既有动态网格，模型母版即生成代码；本轮不重做桌体、锯片或已认可的工具模型。没有改变管理/交付面板结构及公共配色。

执行必要的资产制作、保存与 Game/Editor 构建。不主动启动交互编辑器、游戏、PIE、截图、渲染预览或验收测试；运行观感由用户测试。
