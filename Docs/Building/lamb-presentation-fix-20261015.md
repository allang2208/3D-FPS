# 羊排穿杆与第一人称进食修正

用户反馈：羊排要被中间烤杆穿过，进食倾斜且几乎不进入镜头。

## 原因与修改

大份羊排原始网格的包围盒中心为 `(1.374, 1.853, 5.237)` cm，位于肋骨之间的空隙。原显示代码把这个点对到烤杆，原始三角形求交结果为烤杆轴线完全不穿肉。现在使用 `(Bounds.Origin.X, -4, 2.7)` 的肉块内部位置，X 方向连续穿肉约 17.21 cm。普通羊肋排也明确使用肉块内部点 `Y=-0.6, Z=2.3`。生熟模型共享几何，修正覆盖两者。最多五份混合展示仍沿用原间隔和缩放。

大份羊排此前改变了双手握点和物品朝向，却继续补偿到面包的咬食轨迹。进食主段约 65° 倾角把肉块移到镜头下方，接触前握点 X 最小为 -0.258 cm，已在相机后方。此次让肉端朝嘴、双手位于各自一侧，抬起后先在画面内展示，再接近嘴部。主段倾角改为 18–30°，保留小幅不等间隔变化。普通羊肋排保留单手骨端抓握，单独提高抬起位置、减小倾角并调整接近路径。

运行数据在 `Content/ColdSteelData/potion_use_motion.json`，两个 `grip_profile.json` 同步保存；制作配方为 `SourceAssets/FoodGrip20261003/lamb_food_motion.py`。两个羊排握持作者脚本调用同一配方，避免后续重制重新覆盖为面包轨迹。大份羊排的左手握姿已按新方向重新用 V7 手型离线拟合。没有重导食物网格、贴图或修改其他食物轨迹。

## 排查范围

`SourceAssets/LambPresentationFix20261015/review_geometry.py` 使用原始三角形、UE 旋转约定、生产轨迹的 Hermite 和四元数插值，计算每秒 60 个采样。它不启动游戏或渲染。

- 按默认 75° 垂直视野，在抬起至接触的主段，大份羊排平均位于视锥内的顶点比例由 4.33% 改为 98.29%，普通羊肋排由 38.16% 改为 92.71%。这是网格顶点的投影统计，不是画面面积或实际视觉验收。
- 大份羊排主握点 X 最小为 10.657 cm，两手没有交叉，肋骨横轴的空间倾斜不超过 0.221°。
- 烤杆半径 0.85 cm，分别按 1–5 个展示模型的缩放采样中心及周向射线；两种羊排都穿过实际肉块。没有运行时顶点扫描或新增 Tick。
- 两种羊排全部动作时钟保持不变；其他食物数据与本次修改前一致。库存扣除、恢复效果、燃料、烘烤与存档事务没有修改。

`FPSGAMEEditor` 和 `FPSGAME` 后台构建均返回 `Succeeded / Target is up to date`；当前二进制晚于本次原生修改，构建结果保存于 `SourceAssets/LambPresentationFix20261015/20261015-185638`，交付记录为同级 `delivery.json`。未启动编辑器或游戏，最终第一人称画面、手指接触观感及第三人称表现由用户实际体验。

用户随后反馈拇指穿模、食物仍偏远。该版的顶点投影统计保留为历史记录；后续握持与收近修改见 [羊排拇指与镜头距离修正](../Items/lamb-thumb-close-20261015.md)。
