# 击水水花可见性修复

2026-09-24。用户反馈：上一轮涟漪／水花细化后，水花几乎不可见。

## 排查证据

- 用户实际运行日志已出现 `RIVER_PILOT ready`，种子为 `-1871694467`，测试段中心厘米坐标为 `(-29675.61, 3924.39, 5120.90)`，水花指向完整 Niagara 对象路径。本次没有再次发生首版的包路径错误。
- 后台读取实际保存的 `NS_RiverBulletSplash`：`WaterDrops`、`WaterCrown` 两组发射器的渲染器均启用；材质引用以及颜色、尺寸、朝向、动态材质参数绑定存在；`bEnableCameraDistanceCulling=false`。读取结果保留于 `SourceAssets/RiverSplashVisibility20260924/saved-setup-before.json`。
- 保存资产中的水冠透明度为 `0.62`，在归一化寿命 `0.28` 后开始淡出。材质主体再乘 `(0.20 + 0.32 * ribs) * holes`，使大部分水膜密度进一步降低；水滴中心的密度系数也由旧轮廓的较高覆盖改为约 `0.38`。
- 水滴宽度为 `1.6 * (0.70 + 0.65 * seed) * User.Strength` 厘米。较弱强度下可小于一厘米，在射击距离上非常细。
- 上抛速度直接叠加 `User.Flow`，而该值由入射方向生成，垂直分量可能向下；它会抵消部分上抛速度、进一步缩短寿命。该问题早于细化版存在，是本次一并修正的可见性因素。

以上确认了保存参数和加载状态中的问题；本轮未取得实机帧序列，不将资产读取当作完整渲染验收。

## 修复

- 水冠保留连续可见主体，破碎纹理改为密度起伏，避免大面积把主体抹除。粒子透明度改为 `0.88`，淡出起点从寿命的 `28%` 后移至 `60%`。
- 水滴主体密度基值从 `0.38` 调整为 `0.74`，基础宽度从 `1.6` 调整为 `2.6` 厘米，粒子透明度为 `0.96`，末段淡出。
- 仅在表现层将强度约束至 `0.85–1.25`，水冠初始尺寸为 `28 × 40` 厘米再乘变化系数，保证较弱命中也有可见水花。
- 入射方向仅贡献水平漂移，上抛速度独立计算。水冠上抛基础速度 `170–205 cm/s`、水滴 `225–330 cm/s`，再乘表现强度；寿命按同一垂直速度的重力回落时间计算。水冠总寿命约 `0.29–0.52` 秒，水滴约 `0.39–0.84` 秒。
- 明确初始化出生帧的大小、朝向、旋转及 UV，避免第一帧沿用火焰模板的显示值；保留受光材质，增加少量基础散射亮度。
- 单次仍为 3 片水冠、14 颗水滴，运行时仍为 12 个组件池、8 个涟漪记录。此次未改动涟漪材质、弹道检测或 C++。
