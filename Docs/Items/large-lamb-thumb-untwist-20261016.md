# 大份羊排拇指扭转修复（2026-10-16）

用户继续反馈双手进食动作不合格，尤其是拇指扭曲。本修订承接当天的自然抓握版本；前版离线记录不代表用户已认可。

## 定位

实际第一人称入口为 `FPSPotionUseComponent::ApplyHandPose`，大份羊排使用 Traversal V7 双臂，左右分别调用 `PotionArmPose`。数据由 `potion_use_motion.json` 的 `roasted_large_lamb` 提供。当前问题是运行时指骨坐标系重建，不是需要重导入动画序列的关键帧问题。

旧算法对每节指骨用掌面法线重建目标朝向。拇指的原生关节朝向不同于四指，逐节独立对齐会在保持指骨指向的同时引入轴向旋转。2.75 秒握持姿态的诊断中，相对沿父关节自然传递的姿态，左拇指三节多出约 4.16°、24.11°、33.33° 轴向旋转，右侧约 1.05°、19.92°、29.30°。这些是各节最终朝向的差值，不是应逐节相加的局部角度，也不是临床关节限位。

## 修改

`FPotionDigitPose` 增加可选 `preserve_native_roll`，默认关闭。仅大份羊排左右 `thumb` 开启：先继承父关节与原生局部绑定的完整朝向，再用最短弧旋转对齐作者给定的指骨方向，避免为对齐掌面额外拧转。骨长、局部位移、缩放、绑定和权重不变。

当前运行 JSON、`FoodGrip20261003/large_lamb_natural_grasp.json` 重制配方和 `LargeLamb20261014/grip_profile.json` 同步保存。四指、掌向、双手握点、羊排轨迹、6 秒时长与 4.65 秒接触时间保持原值。

## 范围与交付

本轮按用户要求进行了针对拇指的源码、骨骼与完整混合蒙皮离线排查。诊断源和回执在 `SourceAssets/LambThumbUntwist20261016/`，修改前文件保存在其 `Before/` 中。

离线还原中，关节点变化约数值精度量级，指骨指向不变。受影响皮肤边长比的下端改善：左侧最小值 0.337 → 0.449，右侧 0.333 → 0.441；这是变形诊断数据，不能作为画面合格结论。编译结果见同目录 `delivery.json` 和构建日志。
