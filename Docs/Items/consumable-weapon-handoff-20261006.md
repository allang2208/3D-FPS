# 持武器时进食、饮水与药水的手部交接 · 2026-10-06

用户反馈：双手持剑时使用消耗品没有提示、没有动作，要求检查所有持武器状态。食品、矿泉水、汽水、HP/MP 药水共用 `FPSPotionUseComponent::TryBegin`，背包和快捷栏最终都进入这条路径。

## 定位与修复

原入口直接调用 `IsLeftHandBusyForCast`。该施法判断会读取未装备枪械的状态与 ADS，也拒绝双手剑格挡／收势，以及背包暂时隐藏的法杖（`CanBeginCast` 要求网格可见）。这些条件不等于不能临时腾出左手进食。原手模选择还按当前可见网格遍历，关闭背包的同一帧可能跳过当前武器而选中备用手臂。

新增专门的 `CanBeginConsumableUse`、`PrepareForConsumableUse` 和 `ConsumableHands`，只由消耗品入口使用，不改变魔法的占用规则。先确认动作与资源可用，再收起背包、让出姿势，最后启动原消耗品动作。手模按实际装备归属解析，不依赖背包关闭当帧的可见性。

| 持有状态 | 消耗品开始时的交接 | 仍需等待的动作 |
|---|---|---|
| 双手剑／长柄剑／唐刀等 RuneSword 家族 | 待机放开支撑手；退出格挡、收格挡和检视，沿原左臂动作进食并回握 | 装备、攻击、蓄力／回收蓄力、升龙、旋风、格挡受击和破防 |
| 全部单持步枪、机枪、狙击枪、手枪、左轮 | 放下 ADS、清除瞄准按住意图、退出检视，使用本枪原生左臂 | 装备、换弹、快速近战 |
| 双持手枪／法杖加副手枪 | 保留原左枪放低、隐藏、饮用、抬回流程，使用左枪手模 | 左枪射击输入、射击动作、换弹及待发动作 |
| 弓 | 取消拉弓，保留已搭箭，不触发松弦；原收弓逻辑与备用左臂承担饮用 | 装备、搭箭、放弦及回收、快速近战 |
| 法杖 | 使用当前法杖手模；背包隐藏状态不再当作左手被占用 | 装备、攻击和施法 |
| 双手斧、镐及铲等工具 | 使用原生手模释放左手支撑，结束回握 | 装备和挥击 |
| 空手 | 使用当前空手手模 | 已有拳击／左手动作 |

翻越、重复饮用、施法等已有动作互斥继续生效。恢复值、冷却、矿泉水剩余次数和唯一接触结算未改动；接触前不扣物品、接触后通过原库存事务提交的逻辑保留。

快捷栏当前仅给技能显示手部占用提示，并不展示消耗品的 `Model->Message`，因此用户看到“没有提示”不能单独证明快捷键没触发。本次没有扩展 HUD；修复的是已定位的动作判定与手模交接。未在用户原现场复现按键与画面。
