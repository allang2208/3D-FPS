# 羊排拇指穿模与镜头距离修正

用户反馈上一版进食拇指仍穿模、羊排离镜头偏远。本轮保留篝火穿杆位置，修改普通羊肋排及大份羊排的进食握持和距离。

## 修改

- 拇指拟合覆盖实际 V7 皮肤，包括拇指根部混合掌骨、前臂辅助骨的权重。旧作者流程只取权重完全归手部的皮肤，漏掉根部，且直接镜像左右手参数。
- 普通羊肋排只改拇指旋转。大份羊排两侧形状不同，分别制作左右拇指；主握点向掌外留出 1.0 cm，支撑握点留出 1.2 cm，解除拇指根部被肉块包住的情况。其余四指的关节角度、骨长、原生权重和模型保持不变。
- `FPotionUseMotion` 增加可选 `right_thumb`，由原来的右手求解读取。仅大份羊排提供该配置，其他消耗品保留原有镜像规则。
- 抬起展示段整体向镜头收近 5–6 cm，随后偏移逐渐减小，在原咬食点归零。没有缩放羊排或更改相机 FOV；大份羊排仍为 6 秒／4.65 秒扣料，普通羊肋排仍为 4.8 秒／3.72 秒扣料。

## 制作源与接入

- 轨迹：`SourceAssets/FoodGrip20261003/lamb_food_motion.py`。
- 固定拇指与握点配方：同目录 `lamb_thumb_profiles.json`；两个原羊排作者脚本在最终发布阶段应用此配方，避免重新引入旧姿态。
- 实际运行数据：`Content/ColdSteelData/potion_use_motion.json`，两个原 `grip_profile.json` 同步保存。
- 拇指制作入口：`SourceAssets/LambThumbClose20261015/author_thumb.py`；用当前 Traversal V7 原生骨架、整段手臂解算和完整拇指皮肤制作。手部与羊排表面关系使用斜向射线奇偶性判定，避免仅凭最近面的法线把外部点误判为穿模。
