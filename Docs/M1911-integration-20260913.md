## 使用入口

重启 UE 编辑器后进入游戏，现有军械库补发逻辑会向仓库添加一把 M1911（7 发）和 70 发 `.45 ACP`；按已有流程取出并装备到主手武器槽。补发标记保存在 `ArmoryReceived`，不会每次启动重复领取。仓库空间不足时本次补发保留到下次启动。

左键每次按下发射一发，右键 ADS，R 换弹。沿用现有切枪、输入繁忙、弹药结算、仓库转移、丢弃拾取和存档机制；DayNight_Lighting 原有无限备用弹药规则继续适用。物品占用 3×2 格，双手持枪占用主副手空间。

枪匠目录记录该枪的独立数值；首版为原厂配置，没有开放步枪瞄具、前握把、枪托或弹鼓。枪械图标、独立模型查看与世界掉落调用同一 M1911 模型来源。`.45 ACP` 弹药包装图标暂复用已有弹药盒图标。

## 首版动作与业务时间

| 动作 | 时长 | 内容 |
|---|---:|---|
| idle / idle_empty | 3.0 秒循环 | 双手支撑待机；空仓套筒保持后退 |
| aim / aim_empty | 静态瞄准姿态 | 通过该枪准星、照门标记计算 ADS |
| fire / aim_fire | 0.4 秒 | 射击套筒后退、复位与扳机行程 |
| fire_last / aim_fire_last | 0.4 秒 | 最后一发后套筒保持后退 |
| reload | 1.8 秒 | 退匣、取新匣、插入与双手回握 |
| reload_empty | 2.6 秒 | 换弹后左手过顶抓套筒、回拉、释放与回握 |
| equip_charge / equip_charge_empty | 0.9 秒 | 装备时左手拉套筒；无弹版本保留空仓状态 |

60 fps 作者时间轴，120 Hz 烘焙导出。换弹接触帧为 18 / 78 / 84；空仓增加 116 / 124；装备为 28 / 34。事件和动画共用角色状态时钟，换弹属性改变时整段同步缩放。补弹仍由现有 `FinishReload` 结算。

套筒和枪管按原模型材质分区建立独立刚性权重；保留扳机、击锤、弹匣释放、套筒释放、保险、弹匣、托弹板和弹药的机械身份。手臂保留项目统一的 `SK_Manny_Arms_Export` 网格和 M4 当前绑定材质。

- 枪体：Xeradev 的 [M1911 (FREE)](https://www.fab.com/listings/77247d26-33a3-4dba-a840-7a7d8c92bb9c)。用户本地资源为 `D:/FPS3D/VaultCache/FabLibrary/M1911__FREE_-77247d26/fbx/source_extracted/Rigged_M1911.fbx`。保留原 FBX，未公开提交第三方二进制。
- 此次下载的 FBX 文件夹没有图片，引用的 `Untitled` 图片未嵌入且路径指向原作者电脑；无现成动作轨道。商品页宣称包含贴图并不代表本地 FBX 已带贴图。
- 经用户明确授权，钢材复用 `/Game/Weapons/AKMIntegration/SourceMatched/M_AKM_FabGunsteel`，底层使用项目已取得的 [Fab Dirty Metal](https://www.fab.com/listings/17d58a5d-f1a8-4417-9e6f-f21ed6fc7031) 粗糙度/污渍贴图；分别创建枪身、套筒、枪管、弹匣材质实例。握把复用 `/Game/Weapons/AKMIntegration/WalnutFab/M_AKM_SatinWalnut`。不是该模型原版专用贴图。
- 手模与手型：现有 `SourceAssets/M4TacticalToss20260910/M4_Hand_MAT_Editable.blend`，采用现有 Manny 待机手型和弹匣抓握手型作为制作参考；已查看现有非空仓换弹分帧图并读取源动作时序。手枪支撑、换弹轨迹和过顶套筒动作在本机另行制作。
- 射击声音：[The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library)，作者以 CC0 发布；下载自 [fps-asset-kit](https://github.com/petroulacl/fps-asset-kit) 的 `1911/A_34P.wav`，裁切为 1.5 秒单声道片段。机械接触声音暂复用项目现有枪械声音；未做听感或同步验收。
