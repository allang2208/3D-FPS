# 直连运行中的 UE 编辑器（MCP over HTTP）

本轮之前，对 UE 的检查只能靠命令行 commandlet（离线导入资产）或 `FPSGAME.exe` 无头夹具；后者在 `Content/ShaderCodeLibrary` 缺失时启动即失败（`Failed to initialize ShaderCodeLibrary … missing from ../../Content/`）。2026-09-18 查清：**运行中的编辑器自带 MCP 服务，可以直接用 HTTP JSON-RPC 驱动**，不需要任何 Codex 端配置改动。

## 端点与握手

- 先找编辑器进程与监听端口：`Get-Process UnrealEditor` → PID → `Get-NetTCPConnection -State Listen | Where-Object OwningProcess -eq <PID>`；本项目实测为 `127.0.0.1:8000`（另有 `0.0.0.0:1985`，非 MCP）。
- 端点路径固定为 `/mcp`（streamable HTTP）：`GET /mcp` 返回 **405**，`POST /mcp` 走 JSON-RPC。
- 握手：`POST http://127.0.0.1:8000/mcp`，body 为标准 `initialize`（`protocolVersion 2024-11-05`），响应头带 **`Mcp-Session-Id`**，后续请求都要带这个头，`Accept: application/json, text/event-stream`。

## 三个元工具与调用约定（踩过的坑）

`tools/list` 只暴露三个元工具：`list_toolsets`、`describe_toolset`、`call_tool`。本项目实测 54 个工具集。

```json
// 列工具集
{"name":"list_toolsets","arguments":{}}
// 看某个工具集的工具与输入 schema —— 参数名是 toolset_name（不是 toolset！）
{"name":"describe_toolset","arguments":{"toolset_name":"editor_toolset.toolsets.scene.SceneTools"}}
// 调具体工具 —— tool_name 不带工具集前缀，工具集单独给（拼在一起会 "Tool ... not found"）
{"name":"call_tool","arguments":{
   "toolset_name":"editor_toolset.toolsets.programmatic.ProgrammaticToolset",
   "tool_name":"get_execution_environment",
   "arguments":{}}}
```

## 与配件/弹匣工作相关的工具集

- `editor_toolset.toolsets.scene.SceneTools`：关卡、放置/删除 Actor、**关卡相机**、Outliner。
- `editor_toolset.toolsets.static_mesh.StaticMeshTools`、`material.MaterialTools`、`material_instance.MaterialInstanceTools`、`asset.AssetTools`、`object.ObjectTools`。
- `editor_toolset.toolsets.programmatic.ProgrammaticToolset`：**沙箱 Python 批量编排**。契约：先调 `get_execution_environment` 拿说明；脚本用 `execute_tool(tool_name, json_input)` 调任何已注册工具，必须定义 `run()` 并返回 `dict`；schema 只描述输入，解析返回值前先查输出 schema。
- `Vibe3D.ModelingService`：编辑器内用 GeometryScript 程序化建/改网格（含 `GetDynamicMesh` 直通 `unreal.GeometryScript_*`）。
- `EditorToolset.LogsToolset`、`SlateInspectorToolset`（读日志 / 查 UI 实际显示）、`AutomationTestToolset`。

## 用法边界

- 这条路只对**运行中的编辑器**有效；编辑器关掉端点就没了。
- Codex 自己的工具清单里不会自动出现 UE 工具（本机 `config.toml` 只注册了 `blender`、`node_repl`）；用 PowerShell 走上面的 JSON-RPC 即可，等价于自己接上。
- 依旧遵守 AGENTS/`WORKFLOW.md`：不抢占他人编辑器、不覆盖并行改动，最终验收仍以用户实机/工作台为准。
