# 背包、战斗腰带与减耗公式源码发布

本批从本机 `D:/FPS3D/FPSGAME` 发布至 `allang2208/3D-FPS` 的 main。范围是本次七款背包修订、两款新战斗腰带及非箭袋腰带占格统一；保留共享工作区的其他修改与已有暂存内容。发布日为 2026-10-26，制作批次沿用 20261024／20261025 名称。

## 已纳入源码

- 七款背包的男女穿戴配置、衣物配对、刚性包体与背带衔接、受支撑的重力下垂、异步换装的身体身份与清理；开拓者夹层 10×6，远界主背包 +4 行／夹层 12×6，特勤 +5 行／夹层 14×6。
- 正面展示与七款图标制作器、独立库存展示件、背包浮窗容量摘要：`+N格子（N行）`、夹层横×竖。
- 破阵近战、星律导能腰带的原创建模器、接入器、男女原生配置与属性配方。星律使用 ModelR2／KeeperFixR2，修正带环重复局部变换导致的头顶组件。
- 战术弹匣、破阵、星律统一横 3 × 竖 2；箭袋保持横 2 × 竖 3。正面图标策略，以及旧实例／共享箱子／世界掉落的占格迁移。

- 物品、武器、魔法与复制技能的对应经验。个人维护源与仓库镜像同时更新，本批只提交对应条目。

`publication-manifest.json` 记录本批文件、配置键与散列。共享 JSON 仅合入本批物品和男女装备键，未覆盖工作区的其他动作／衣物。旧战术和箭袋模型来自此前 Equipment20261025 发布，保持原有依赖。
