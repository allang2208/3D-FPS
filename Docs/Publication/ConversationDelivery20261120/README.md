## 已有运行记录

下列数据来自 11 月 20 日开发工程的历史运行。每项记录的来源、结果与原始文件散列保存在[证据摘要](historical-evidence.json)。

| 场景 | 当时记录 |
| --- | --- |
| 工匠服务和防卫 | 独立监听服及客机的急救、恢复交谈、档案隔离与重连共 35 项通过。再索敌与回岗专项 25 项通过。重启主机后恢复五名店员及修复过的店面。 |
| 商店与药草师 | 三家商店有 36 条购买、拒绝、离店与重连事件。药草师闲逛期间由真实客机触发对话，一级和闲聊菜单 16 项通过；生产村庄地图另有 28 项检查，第二位交谈者由服务器控制器模拟。 |
| 穿戴与进食 | 本机 UDP 穿脱、混搭及重连 14 项通过；独立食用结算 9 项通过。两种身形的 18 条穿戴路径共 152 个材质槽。食物 46 组采样的最大咬点误差为 0.63 毫米。M870 腕口覆盖按 13 段原动画、319 帧采样。 |
| 灯光与轮廓 | 离屏几何场景中，目标店员的 HDR 红通道从 4.02734 降至 2.81250，另一名店员和暗部维持原值；分别选择两名店员时，绿边跟随选中者。游戏与编辑器目标均有后台构建成功记录。 |

上述记录覆盖本机模拟延迟与丢包下的独立网络进程。公网、打包专用服务器、同机分屏购物，以及全部店内灯位和服装组合的玩家视角仍待实机覆盖。药草师 HeadR3 与参考图的眉眼和下颌仍有可见差距。整理发布期间没有启动 UE 或重新执行玩法测试。

## 归档

本机 `trash/ConversationDelivery20261120/summary.json` 指向四批逐文件清单。开发和验收阶段的退役文件共 4,718 个、19,082,449,524 字节，包含 478 个图像或视频文件，GIF 为零。774 个隔离宿主链接另存为目标路径记录，避免还原时误写共享目录。[归档批次和清单散列](retirement.json)

找回文件时，根据清单确认原路径空闲，按 SHA-256 核对后放回。药草师肖像对照使用的四张原图、装配需要的暂存包和三视图仍在制作链中。11 月 19 日记录的 `04-bar.png` 在本次整理前即已缺失，本批归档中也没有找到与旧散列相同的副本。
