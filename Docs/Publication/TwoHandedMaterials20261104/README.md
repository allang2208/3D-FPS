# 双手武器材质、星髓长锋充能与联机发布

本批包含九把双手武器的材质配置、符文表现和改造台说明，以及符文长剑、魔晶双手剑和高地双手剑的专属效果。魔晶与时砂秘金限定符文长剑。红魔晶和高能魔晶限定魔晶双手剑，其汲取独立于所装剑身。黑棘钢和白鹿秘银限定高地双手剑。

## 源码与恢复

- 星髓长锋保留攻击距离 +25%、魔法攻击 +10%。按 G 消耗最大魔法值的 20%，进入 30 秒充能，期间攻击伤害增加 30% 并转为魔法伤害。客机预测手势，服务端按武器实例结算。剑身网格和实例都匹配后才显示剑火。裂穹长锋的第三击使用瞬时剑形和整段命中查询。
- 正式源码与配置位于工程根目录。作者程序位于相应的 `SourceAssets` 目录。主机、客机和专服的检查记录在 [Evidence](Evidence)。目录覆盖、通过的源码检查、联机通道和 UE 资产的本机保存是分别记录的事实。
- 共享源码按路径列在[源文件清单](source-manifest.json)。部分多人和 UI 宿主比公开主线更新，如通用 `SkillWireAudit` 场景和经验浮字宿主。对应 `Integration` 补丁只包含本批改动。恢复到完整工程时，先按 LF 文本计算 SHA-256。匹配 `after_sha256` 表示该文件已有本批接入；匹配 `before_sha256` 时可从工程根执行 `git apply --check --unidiff-zero <补丁>`，再应用并核对结果散列。其他散列需要按实际宿主合并。部分文件同时提供公开主线可直接承接的版本和本机完整宿主补丁。
- [公开基线差异](public-baseline.json)列出较新宿主才有的四个冷却字段。公开版在符文长剑的回响材质上直接读取当前装备的修正值。完整本机工程使用共用物品读取入口。两端联机证据来自完整本机宿主，公开源码快照没有单独进行 UE 构建。
- `Content/ColdSteelData` 是已跟踪的文本配置。UE 包、材质母版、Meshy 原件、图标、参考视频、完整骨架/动画采样及编译产物保留在本机和项目内容备份。恢复包时保留原 `/Game` 路径。剑身、剑火、动作、快捷图标及进度条应从 `/Game/Weapons/FrostCrystalSword20260915` 及符文长剑、高地剑对应内容目录恢复。动作制作依赖第一版轨迹、V6 姿态、V7 作者数据、实际标准柄和长柄待机。源文件清单中的制作配方不能单独替代这些输入。

## 本机归档

[归档汇总](archive-summary.json)记录原路径组及两份逐文件清单的散列。17,138 个文件共 6,648,463,891 字节，移动后已逐项核对 SHA-256。本机恢复入口为 `trash/TwoHandedMaterials20261104/manifest.json` 和 `supplement.json`。遇到目标路径已有新文件时先比对散列，避免覆盖新工作。

退役项包括三宝石 HUD、旧叠层与法术过载安装器、飞行突刺实现、被回退的手部试作和早期剑火画面。UE 资产注册表显示旧 HUD 材质与纹理没有外部包引用。保留的关键输入包括 V1 原动作、V3 的骨架和数学工具、V4 的时序、V6 作者姿态、V7 直接回待机动作、`VariationV2` 被现用剑火导入的代码和最终离屏画面。四个 `hand_fit` 字段与回退后采用的版本一致。

## 已有证据

9 把武器、4,182 种组合、113,422 项材质检查全部通过。38 项充能动作与状态检查通过。监听主机和专用服务器分别与客机通过真实本机 UDP 连接，配置为 80 毫秒模拟延迟和 2% 丢包。两轮均观察到正确实例扣蓝、拒绝旧请求、迟到状态按原时间到期以及减益刷新后清除。专用服务器不创建可见剑火。

本批整理仅运行发布检查。上轮没有覆盖公网长时间断线重连，也没有逐招联机实打时砂回响和裂穹长锋突刺。动作轨迹与作者数据一致，不代表对所有装备外观的穿插验收。
