# M24 碳纤维后托、快速近战与止鸣

本批发布 2026-11-05 上次 M24 收尾后的后托接缝、瞄具导轨座、改造依赖恢复、两款后托手部差量，以及 M24／SVD／SVCh 通用特殊消音器「止鸣」。GitHub 保存源码、原创制作配方、配置、SKILL 和精简证据；模型、纹理、音频、手模与 UE 包保留本机，不构成完整工程资产备份。

## 当前实现与恢复

- 玄脊使用用户指定 `Meshy_AI_Carbon_Stock_1105135808_texture.glb`。当前水平接缝来自 `SourceAssets/M24JointClean20261106`，按真实边界环缝合，保留主体 UV、面角法线及 NormalDX。原厂／先进机匣分别使用匹配金属。瞄具座由 `M24NaturalStockRail20261106` 制作并以 `RailSeats20261106` 接入，不移动瞄具瞄准接口。
- 当前玄脊图标为用户批准的碳纤维材料徽章，母图在 `M24CarbonMaterialIconInstall20261106/Selected.png`；根目录与 FramedFirearms 两处 PNG、Texture2D 均已替换。此前 `M24StockIconStandard20261106` 的透明模型图只是未采用候选，不是当前成图。骨架狙击枪托归为特殊改造。
- 快速近战最终源是 `M24HandContinuity20261107`。八种后握把／弹匣家族各有骨架与碳纤维 Profile，共 16 份；恢复时保留其读取的 `M24StockQuickMelee20261106` 动作、蒙皮、JC、可编辑源，以及更早 R3 右臂运输函数。0.9 秒动作和 0.25 秒命中时钟不变。当前资产路径和散列保存在本机 `publication.json`。
- 卸下先进枪机时，依赖它的后托、后握把和战术挂件先移除，再从目录恢复原厂件；归一化与选项锁定共用资格判定。
- 止鸣当前为 `SniperZhiming20261107/Concept/Zhiming_Round_v06.blend`：圆筒、M24 原消音器金属、无汉字的暗金声纹及简洁装饰。按各枪实际单位、前轴和挂点接入，共用最终 `Muzzle` socket；不能直接套同一 transform。
- 「止鸣」三枪枪口槽均为特殊改造，继承 M24 原消音器被动：后坐力 -30%、稳定性 +20%、弹速 -10%、开镜耗时 +10%；另有暴击伤害 +15%，直接子弹暴击命中存活敌人时眩晕 0.25 秒。反弹、非暴击和死亡目标不追加触发。
- `SniperSuppressedAudio20261107` 保留九段消音声的采样长度与 pitch 1.0，调整频谱及包络。M24 指向 Warm，SVD／SVCh 使用各自变体库。音源及其授权继承原始录音，未经核准的音频与派生包不公开。

制作脚本见 [authoring-files.json](authoring-files.json)。脚本依赖的私有 GLB、FBX、Blend、PNG、WAV、GZ 密集蒙皮／动作和原生 UE 包必须从有权使用的本机备份恢复。不要因为旧目录已出现替代版本就移动仍被脚本读取的输入。

## 共享宿主的发布边界

[integration-manifest.json](integration-manifest.json) 区分直接发布的专属源码、已独立合入的共享增量和仅提供定向补丁的共享增量。后者的私有宿主仍含其他开发任务，未整文件夹带进本批。之前的 M24 基础接入依赖见 [11 月 5 日发布](../M24_20261105/README.md) 与 [11 月 1 日发布](../M24_20261101/README.md)。

补丁的 `private_pre_sha256_lf` 是“当前本机宿主移除本批精确增量”的参考前像，不冒充历史源码快照。恢复时在独立副本将 UTF-8 BOM 去除、换行统一 LF，核对前像、应用对应补丁，再核对 `private_post_sha256_lf`；已经等于结果散列则跳过。取得匹配宿主之前，不将补丁强套到不相容源码。

公共检出仍不是完整私有宿主的可直接运行副本；本批没有在干净克隆中编译或打包。下面的构建及联网证据来自完整本机工程，不能转述为公共源码加全部资源已经独立恢复成功。
