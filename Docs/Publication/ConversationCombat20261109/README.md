## 源码与恢复边界

`Source/` 只提交能从当前公开基线精确重放的本轮代码：独立动作/声音助手、装备身份绑定、蓝焰模拟时序、图标处理及标签。锤座七处目录/作者字段按 `conical_seat` 精确合并，不发布其他锤座和在途雷神之锤修改。

`integration-manifest.json` 为每份定向补丁记录本机前置和结果 SHA-256；它们不是互不依赖的自动补丁队列。已直接进入公开 Source 的条目不用再次应用。`ColdSteelPlayerState.cpp` 的装备身份检查已进入 Source，伤害快照仍依赖本机 PreItem/命中前置。未公开完整共享宿主时，恢复到匹配前置后再应用对应补丁，不能把补丁失败当作覆盖当前文件的理由。

`Integration/RuntimeSections` 保存与本任务直接相关的原生左臂、主手避让、恢复、检视和公式函数/分支，附完整原宿主散列。它们是人工整合参考，不是可批量应用的补丁；声明、现有材料/身体/战技/法杖前置继续由相应共享宿主提供。这样保存具体实现而不替其他会话发布整份共享文件。公开树没有在本轮独立构建，不能视为已完整恢复的可运行游戏。
