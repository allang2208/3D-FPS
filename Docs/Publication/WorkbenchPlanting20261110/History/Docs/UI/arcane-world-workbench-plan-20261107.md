# 强化／附魔实景工作台

## 目的与入口
用户要求 V6 去台钳模型接入为 `arcane_workbench`。E 对准真实工作台进入，K 与背包右键不绕过世界距离。原强化／附魔公式、装备实例、成本来源和属性比较保留。

## 布局与视觉
左侧黑灰玻璃操作栏：装备摘要、强化／附魔页签、材料／卷轴、属性比较、消耗汇总；右侧使用现有背包，中央直接显示世界台面及真实武器，不使用旧背景图或第二个 SceneCapture。固定顶部退出和底部确认，内容独立滚动。操作栏随窗口夹取 320–420 px，背包在此会话中占约 36%，狭窄窗口优先保留中央台面。字体、按钮与语义色复用 ColdSteelUI/GunsmithUI。

## 数据与事务
初始魔法阵为空。右键“放到魔法阵”或拖放仅保存已有实例 ID，不搬移、复制或创建库存武器。展示 Actor 禁用拾取、碰撞和掉落光束。背包改变时刷新报价与实例；物品消失清空选择。服务器使用现有背包 Workstation 事务重新计算费用、验证距离/遮挡与修订；等待回执禁用重复确认。成功后刷新实例展示，不提前播放成功反馈。

## 输入与状态
只接受有效当前拖动快照；拖到中央魔法阵选择武器，拖到无效区域取消，不掉到世界。关闭/退出/失去台面/死亡或换 Pawn 时清理展示、还原相机与输入；背包关闭与工作台同生命周期。保留进入前背包与鼠标状态。不足、卷轴不兼容、最高等级、网络失败沿用明确原因。操作不改变正式存档；开发不运行游戏和自动测试。

## 文件范围
Enhancement Controller/Widget/Layout、HUD 抽屉和拖放/右键接入；独立 EnhancementWorldView 与现有服务端事务；V6 导入源、UE 资产与 prefab 注册。保留预先存在的未提交更改，不修改 player_body.json 或正式存档。后台必要构建与导入后如实区分已完成和未测试部分。
