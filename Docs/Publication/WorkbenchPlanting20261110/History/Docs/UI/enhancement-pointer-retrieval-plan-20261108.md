# 强化工作台实体取回交互
- 范围：保留左侧强化/附魔面板、右侧背包和原取回按钮；增加台上装备悬停轮廓、右键取回和拖入背包。
- 输入：场景区域单独接收 UMG 指针事件，不覆盖背包；按下装备后达到系统拖动阈值才创建取回意图。松在装备栏、台面或外部不提交。关闭工作台沿既有 CancelDragDrop 取消。
- 展示：用实体定向包围盒命中，复用炼药台金色轮廓材质和 stencil；异步加载，关闭时取消并释放。仅影响本地展示副本，不启用世界拾取碰撞。
- 数据：独立拖拽对象保存暂存物快照；释放复核来源与会话。背包预览沿现有 Insert/转向回退计算自动安置格，不交换已占格物品。
- 提交：右键和拖放均复用 SelectItem 空 ID → Transfer → enhancement.retrieve；服务器 ExpectedBenchId、Pending、防重复、空间不足和持久化失败规则不变，收到成功结果才移除台上展示。
- 制作边界：后台源码制作与必要构建；未启动游戏、未执行运行测试或视觉验收。构建结果另行记录。
