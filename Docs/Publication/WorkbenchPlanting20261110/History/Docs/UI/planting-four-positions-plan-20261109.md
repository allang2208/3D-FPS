# 种植栏四位置布局 · 2026-11-09

## 范围与原因

本轮按用户要求把种植位置改为 2×2，每位一株、每床最多四株。原界面直接暴露存档的 4×4 小格，番茄、土豆、小麦每株占四小格；胡萝卜仍为一小格，造成容量口径不一致。新播种胡萝卜也统一占一个完整种植位。生长时间、产量、材料来源与自由种植模式不变。

## 布局与交互

沿用冷钢共享玻璃、字体、按钮以及工作台固定标题和底部操作区。正文顺序为作物选择、四位置地图及详情、简洁种植概览。可用宽度 560px 起地图与详情左右排列，较窄时上下排列，正文独立滚动。四格地图最大 288px，位置不因窗口变窄而改为列表；每格显示编号、作物、成熟倒计时和原有生长条。删除重复的最近三株列表，避免四株内容重复占用竖向空间。

单击空位选择一株，拖动框选若干完整空位批量播种；点击已有植株查看并按原事务收获。等待服务端期间禁用提交、切换及拖动，关闭/失焦沿用释放鼠标捕获；状态更新后移除被占用的过期选择。不新建 Tick、加载队列或图标资源。

## 数据、旧档与多人

`ColdSteelPlantingLayout` 统一四位置与旧 16 小格映射，新位置锚点仍是 0、2、8、10。序列化类型、网络字段、旧植物 ID/槽位/占地/位置/时钟均不变。选择消息仍传完整小格集合，服务端只把完整种植位打包为一株；单株入口也约束固定锚点、完整位置无占用与每床四株上限，旧客户端不能绕过容量。

旧档超出四株、单小格胡萝卜或非对齐植株不删除、不搬移。四位置根据实际占地收集植株，同一位置存在多株时明确标记并可重复点击轮换，保留逐株查看和收获入口；跨位置的一株只统计一次。收获入口先于新播种限制执行，旧株仍可正常收获。新播种需清空对应位置，已有总数加本批数量不得超过四株。批次继续采用原库存/世界事务与版本校验。
