# 未知人形敌人：战斗、数值与联机生命周期

本批保存本次对话中未知敌人的实现、共享玩家动作接入补丁、怪物伤害调整，以及客机受击、重连、死亡重生和换图清理的修复。正式运行源码仍在 `D:/FPS3D/FPSGAME/Source/FPSGAME`；本目录是精确范围的源码恢复包，不加入 UE 编译搜索路径。

## 内容与恢复边界

- `Sources` 保存 37 个独立源码文件；`source-manifest.json` 记录原路径、源文件散列及发布文本散列。包含四类未知、装备与等级、战术、表现、魔法入口、怪物伤害限制、共享身体辅助算法和非 Shipping 诊断入口。
- `Integration` 保存 49 份共享宿主补丁。`integration-manifest.json` 记录基线来源和前后 LF 文本 SHA-256。基线来自本次修改前快照，或从当前完整宿主中反向移除明确属于本批的改动；**不是公开仓库 HEAD**。先核对基线，再按实际共享宿主合并；禁止整文件覆盖较新工作。
- 共享文件保留其他任务的夜袭、野生动物、武器动作、冷加入外观和技能树等改动。早期已接入的完整玩家身体／技能宿主仍是前置条件，本批没有重新发布那些混合实现。F6 分类与生成入口、第三人称枪械瞄准、头发组装、脊柱混合、命中时钟和最新联机修复有定向补丁。
- `prerequisites.json` 列出本机头文件依赖、共享配置散列和源码中直接出现的资源路径。它不是全部链接依赖或动态资源的穷举清单。完整武器目录、玩家装备／技能、动画、身体、服装和特效必须另行恢复；公开克隆不能仅凭此包独立构建。
- 可复用工具保留在 `Tools/UnknownNetworkAudit`、`Tools/UnknownJoinAudit`、`Tools/UnknownLifeAudit`；运行它们需要完整宿主及明确的检查授权。临时进度显示脚本已退役。

## 行为与修复

未知按近战、枪械、魔法、弓四类提供 10／20／30 级入口，使用服务端确定的玩家模型、性别、装备与属性模型。近战穿锁子甲，魔法穿法袍并持法杖／魔法书，弓类近身切双刀、拉开后回弓。枪械无限备弹仍走换弹，魔法无限资源仍走冷却和动作约束。近战、弓与魔法的动作限制、目标记忆、撤退、遮挡、避让和朝向由各自战术入口处理。

怪物伤害调整与玩家原始武器／魔法数值分开，限制整轮多弹、持续脉冲及灼烧预算；等级与武器差异保留。详细范围见 [数值审计](../../Monsters/monster-damage-balance-20261115.md)。

客机受击读取自己的权威档案，未绑定期间拒绝临时默认角色结算；真正接受的伤害通过调用栈局部回执返回，免伤和过量伤害不会误触发附加效果，最后一击及时同步运行档案。客户端 BeginPlay 保留已复制血量。冰墙不重复注册非复制生命字段，持续效果按服务器阶段时间恢复。

未知目标与命中入口排除死亡、EndPlay、不同 World 及不再被控制器持有的旧 Pawn；失去旧目标时取消待击、连发、蓄力和引导。未知死亡立即收尾暴风雪，换图由各组件 EndPlay 清理持续实例。旧角色的附身灼烧不移到新生命，合法的独立场景区域也不会因某个受害者死亡而全局消失。
