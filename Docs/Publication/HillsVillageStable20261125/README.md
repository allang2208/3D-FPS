# 东门马厩、骑乘与马匹名册

本批覆盖东门马厩、管理员、马匹的骑乘和跟随、上下马、跳跃、受伤逃离、召回、个体外观与成长、马市和马具。当前院落保留石槽，前后院打通。管理员采用 R6 双视图头部和 R7 背手待机。正式骑乘跑步采用海滩参考的 R14 版本。

## 从源码恢复

1. 将 [专属源码](Implementation/Source/FPSGAME) 按内部工程路径合入匹配版本的 UE 宿主。这里有 61 份带出处的文件，涵盖骑乘、碰撞、身份、马市、UI、对话注视和复核入口。[源码指纹](Implementation/files.json)
2. 共享宿主按版本顺序合入 [变更清单](Integration/deltas.json) 中的 139 份差异。每项记录逻辑路径、前后 LF 文本 SHA-256 及其来源版本。较早仅有制作成品快照的宿主按[调用位置](Integration/host-hooks.json)与对应版本归档合并。应用前比对基线，避免把旧版人物、战斗或存档文件覆盖到新宿主。
3. 正式马具的四条物品定义及四条制作台配方已加入公共数据表。[配置摘录](Configuration) · [制作和导入工具](../../../Tools/WorldGeneration/VillageStable) · [马匹操作](../../UI/stablemaster-horse-market.md)
4. 通过 [资产指纹](Recovery/assets.json) 和 [49 个版本压缩包](Recovery/versions.json) 恢复本机内容。NAS 相对位置以 `备份/FPS3D/HillsVillageStable/` 为起点。战马模型和衍生网格、动作、马图图集、模型接触采样、引用媒体、声音原件、UE 包及母版均在本地资产库。新生成的四件基础马具背包图标随各自物品定义发布。[制作依赖](Recovery/recipe-dependencies.json)

公共主线上的共享宿主与本机完整工程存在其他版本前置，本次采用仓库既有的独立实现与定向补丁交付方式。完整本机工程的编译和联机记录见[历史实测数据](Evidence/results.json)。2026-11-25 的结果覆盖监听服加一名客机、错槽、穿脱和重连、坐骑经验与受伤召回。管理员主动培养、马具属性加成、独立行囊储物和穿戴后的三维换装仍待开发。
