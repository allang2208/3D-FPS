# 工匠与酒馆源码恢复

公开主线中的独立组件包括逐句对话、独占视口和酒馆陈设。依赖 ResidentConversation 的居民原地转身，以及工匠、交易、教学和场景实现位于本批 Implementation 目录，按路径放入已恢复村庄和工坊系统的本地工程。Configuration 中的 JSON 按配方或物品键并入对应共享目录，保留其他条目。

Integration 中的补丁按 gameplay-baselines.json 记录的基线恢复。public 表示以指定远端提交中的同名宿主为输入。local-feature-preimage 表示根据当前开发宿主裁剪出本次增量，其接入点依赖另行恢复的本地宿主。哈希使用 UTF-8 文本与 LF 行尾。共享宿主混有其他开发，不宜覆盖整个文件。

先恢复丘陵存档、村庄子关卡流送、旧教堂和修女、村墙修复及工坊事务宿主。已公开的相关集成资料在 HillsScenery20261118、HillsVillageLifecycle20261118、VillageNetwork20261118 和 SkillTree20261117。木工教学使用普通木芯、学徒长杖、已支付工件和评分通过标志；铁匠教学使用铁锭、唐刀配方、刀坯命中或实际接触标志。工作台需要材料报价、权威检查点、个人材料收据及档案事务。背包货架依赖图标缓存、物品详情、法杖目录和物品品质计算。原宿主还包含其他交易与角色系统，本批仅提供本功能接入点。

村庄修复位为围墙 1、铁匠铺 2、木工工坊 4、酒馆 8。此裁剪版本承认村庄方案版本 1 至 4，遇到更新版本时应由支持该版本的宿主处理。库存动作 ArtisanLesson 保留生产协议数值 22。主客机应使用同一完整版本，签名计算依赖真实酒馆模型与正式村庄关卡。本批联机探针另依赖 VillageNetwork20261118 发布包的 VillageNetworkAudit 支持函数。

酒馆女店主、草药铺、居民战斗和急救由各自功能维护。公开包未进行独立编译或运行测试。恢复完整外观与碰撞还需本机正式 UE 资产。
