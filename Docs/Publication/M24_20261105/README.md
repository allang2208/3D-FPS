# M24 换弹、补栓与联机修订

本批包含 M24 普通与扩容换弹、握姿与肩根修订、按射击中断状态选择装备动作、栓动配件倍率、战术挂件、开火声、原厂枪托接缝及客机收枪后的命中处理。公开目录是源码与制作配方。UE 包、带手模的 Blender 工程、密集姿态、图像与录音从有权使用的本机备份恢复。碳纤维枪托沿用现有槽位，后续造型工作已暂停。

## 代码与配置

独立源码按工程路径发布，包括 M24 发射记录、装备与抽壳、基础动画路径和时钟。枪匠目录只更新 `weapons[id=ue_m24]`；打包配置补入活动目录，包括按字符串寻址的战术挂件。用相同修订构建主机和客机。未执行完整 cook。

共享宿主含其他未公开的动作、弹药和网络框架。[接入清单](integration-manifest.json)按文件标出根目录源码、可重放到公开基线的修改和仅以补丁交付的修改。要在对应私有宿主重建，先取得清单记录的前置版本；对去 UTF-8 BOM、统一 LF 后的整文件核对 `private_pre_sha256_lf`，再在工作副本运行 `git apply --check <patch>`，应用后核对 `private_post_sha256_lf`。已等于结果散列的文件跳过。上一次 M24 宿主补丁及前置依赖见 [11 月 1 日发布说明](../M24_20261101/README.md)。当前公共检出的独立构建未验证。

## 本机恢复顺序

1. 恢复原生 M24、V9 手模、关节修形、握把等授权输入，以及各制作目录实际读取的 JSON、GZ、纹理和 FBX。当前游戏枪托依赖 `M24CarbonSpineConcept/ArtSource/concept.py` 和初版织纹。原创作者脚本按其目录关系列在[制作源清单](authoring-files.json)。
2. 普通／扩容与各握把使用十份握姿配置。参考 `M24LocalMagazineGrip20261104` 和 `M24ArmContact20261104` 恢复换弹；快速近战和拉栓修订依次保留 `M24QuickMeleeGrip20261104`、`M24QuickMeleeFactoryR2_20261104`、`M24QuickMeleeRightHandR3_20261104`、`M24BoltShoulder20261104` 的局部差量。先恢复装备的抬枪轨迹，再恢复 `M24EquipConditional20261104` 的短抬枪与肩根修正。旧发布脚本带输入散列和落盘保护，只按对应前置恢复。
3. 材质与装配见 `M24FinishUnified20261103`、`M24Tactical20261104`、`M24CarbonSpineGame20261104`、`M24FactoryStockSeam20261105`。最后一项单独处理先进枪机与原厂后托的交界。当前贴图和模型属于本机二进制依赖。
4. 普通与消音开火声来自用户提供的 `M24.mp3`。两者保留各自的音色，制作时匹配单次射击的 K 加权能量。公开配方在 `SourceAssets/M24FireAudio20261104/`。录音、成品声音和 B 站参考视频及抓帧仅保留本机。

## 已有证据和归档

本机正式 Editor 模块曾构建成功，真实本机 UDP 监听主机、客机和新加入客机经过两轮六阶段，双方各设 60 ms 延迟、5% 丢包。切枪后迟到命中验证到服务端命中准备。详细覆盖及尚待实测的内容见[复查报告](../../Weapons/m24-network-review-20261105.md)、[主机记录](Evidence/host.json)与[资源核对](Evidence/disk-and-catalog.json)。本次整理只核对归档及发布内容。

被否决的设计图和较大织纹版本、过时预览与编码临时帧、旧试跑及隔离导入的普通文件，均按原相对路径移入本机 `trash/m24-retired-20261105/`。清单列出原路径、归档路径、字节数、SHA-256、判断依据及保留项。2,578 个文件共 1,595,656,889 字节，逐件读回一致。原隔离目录的 294 个联接点已排除在遍历、移动和散列之外。[归档回执](archive-receipt.json)
