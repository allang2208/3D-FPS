# 单手斧第三人称动作修复与联机检查整理

本批对应第三人称双斧三连击第三段下劈、利隼重击与回拉的手臂修正，以及观察端首次刀光缺失和旧符文测试数据迁移。第一人称误改已撤回，原动画包按散列恢复。本次整理没有启动 UE、重新构建或重跑游戏测试。

## 主树内容与接入边界

- 直接合入观察端刀光材质准备与持有、近战执行器停帧速率的复制，以及斧头第三人称动作键选择、刀光窗口与秒制参数头文件。
- `player_body.json` 只合入 Jason/Kaitlin 的 10 个 `Kukri.Falcon.*` / `Kukri.Hatchet.DualChop` 角色键，包含两个未改动的单手蓄力依赖。未把其他身体、衣物或动作配置夹带进来。
- 合入本轮作者与保存脚本、显式检查入口、技能参考和结果记录。
- 共享全身动画宿主、利隼武器执行器和附魔迁移尚未在公开 main 同步齐全。`Integration/` 保存精确的本轮夹具/诊断补丁与动作消费者片段；这些内容**尚未作为对应 Source 文件合入 main**。前提和当前本机宿主散列见 [integration-prerequisites.json](integration-prerequisites.json)。不能把本批称为可独立运行的完整动画/附魔系统。

这延续既有 [战斧发布](../Hatchet20261104/README.md) 的共享宿主边界，不把其他会话的大块未提交实现作为本批前提强行发布。临时索引仅用于构造提交；裁剪后的内容不会覆盖真实工作文件，已有其他暂存内容保留。
