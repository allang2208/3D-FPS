# 高地双手剑的第三人称、誓约与风誓翼锋护手

本批承接 `HighlandSword20261106`，保存第三人称横扫与强化突刺、冲刺步态及两倍突进、阔锋剑座材质边界、金色誓约符文和裁决剑气、实心羽翼护手及击杀返体与迅捷。

## 当前制作与行为

- `SourceAssets/HighlandThirdPerson20261106` 保存 Jason、Kaitlin 两种体型和两种握柄的12个全身动画制作配方。18个配置路径见 `body-roles.json`。重击落点接横扫与待机接横扫分别使用适配源，突刺蓄力与释放共用接缝。冲刺突刺复用普通冲刺的骨盆与腿部，以实际位移驱动步态，保留完整上肢握柄。
- 棱脊穿甲刃冲刺距离在技能快照中乘2。判定随实际玩家位置移动，矩形长度保持剑的招式距离，避免再次加上突进距离。
- 阔锋材质从剑座向剑尖统一。护翼、镶边和宝石保留原材质，五款原有护手和新羽翼护手分别使用适配网格。
- 誓约符文为特殊改造。重击物理伤害+15%，持续蓄力体力消耗-20%。首次满蓄后0.35秒内释放触发裁决，重击物理伤害再乘1.35，韧性伤害再乘1.5。首次有效命中返还实际出手体力的25%。强化突刺重击进入相同伤害链，第三段与冲刺保留各自招式身份。
- 刀身誓约刻纹与叠层均为金色，按可见剑身尺寸展开；改造图标为灰阶银框。裁决在原空间扰动轨迹上加入金色剑气，残留0.82秒，第一人称和观察端各用实际武器轨迹。
- 风誓翼锋护手为特殊改造，奔跑体力消耗-10%，攻击体力消耗-20%。击杀敌人后返还本招实际消耗的体力，含重击蓄力和武技。每招返体一次，再次击杀刷新移动速度+25%、持续3秒的「迅捷」。此前已由誓约返还的部分从待返金额扣除。零体力武技返体为零并可触发迅捷。状态目录仅有一个完整名称为「迅捷」的条目，既有「雷电迅捷」继续使用独立机制。
