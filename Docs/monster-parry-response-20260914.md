## 当前衔接修订：倒放攻击 0.3 秒后进入硬直

用户反馈直接切硬直仍显僵硬，指定从弹反发生的攻击节点倒放 0.3 秒，再进入硬直。

- 在弹反入口保存实际 ActiveClip 与 ClipTime，保持当前攻击姿态，从该时刻以原速倒放 0.3 秒。例如 0.65 秒触发时，倒放到约 0.35 秒；到片段起点则保持起点，不绕回片尾。
- 这 0.3 秒仍处于业务 Stagger 状态，攻击判定与行为树已被中断。Sequence Evaluator 仅采样倒放姿态，不触发新的伤害、Notify 或根运动。
- 倒放结束后接入现有 `A_FatZombie_Stagger`，以最后可见倒放姿态做 0.08 秒短过渡。此过渡同样由受控时钟推进，避免 Stagger 时普通动画 Tick 提前返回导致混合停住。
- 胖子去除共用弹反表现的 0.1 秒提前采样，保证倒放从实际触发节点开始，完整持续 0.3 秒。非攻击中受击继续使用直接硬直。
- 击退在弹反当下发生；原 1 秒控制包含倒放与之后的硬直，不额外延长控制。死亡和后续状态切换清除待接片段，已中断的攻击时钟不能继续覆盖倒放。

本轮只修改动画播放衔接，未重新制作或覆盖动画资产。下面保留上一轮命中窗口与独立硬直片段的原因记录。

## 共用弹反入口已保留的调整

- `ReceiveParry` 原先只登记击退，首次位移等待后续组件 Tick。现在弹反回调内先扫掠移动总距离的 20%，剩余 80% 沿原有 0.16 秒减速曲线完成；两段共用碰撞扫掠，遇阻停止，总距离不额外增加。
- 专用受击片段跳过 0.1 秒起势，并在回调内以零动画增量刷新骨骼。后续共用反应时钟保持该表现偏移，避免下一帧退回起势；控制时钟不提前消耗。胖子现已使用上述独立片段。
- 击退方向在中断动作前根据本次弹反者计算，不沿用最近一次受伤方向。
- 手脑的 `DealSlam` 在伤害回调中被弹反后，旧 Tick 分支仍会执行 `ShowRing`，重新显示已清除的砸地预警。现在伤害回调返回后立即确认仍在砸地状态，否则退出剩余目标和后续表现。护士及继承它的胖子同样禁止被中断的攻击分支继续写入收势状态。
