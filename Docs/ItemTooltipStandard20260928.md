# 物品浮窗标准格式（武器与工具）

2026-09-28 制定。依据当天的浮窗一致性审计与修复批落定；后续新增武器/工具/数值行按本标准执行。

## 适用范围

物品浮窗 = `UColdSteelItemTooltip`，是背包、装备页、仓库、热键栏、角色面板共用的唯一 inspector。
内容由 `BuildColdSteelItemTooltip`（`Source/FPSGAME/UI/ColdSteelItemTooltipData.cpp`）生成，
摘要网格与装备对比由 `ColdSteelItemTooltipSummary.cpp` 生成。改造工作台（M4Gunsmith 系列）、
图鉴（ColdSteelCodexPage）与浮窗共用同一套标签词汇。

## 一、总体结构（自上而下，不可调换）

1. **头部**：图标 + 名称 + 元信息行（`类型 · 稀有度 · Lv.N · 强化文案`）+ 位置行。
   - 强化文案：武器 `已强化 +N`；采集工具 `强化 Lv.X · 材质名`（外观档位语义，不进武器数值）。
2. **核心属性**：≤4 格摘要网格，键位按家族固定（见第三节）。
3. **口径说明**（ValueScope）：一句话说明数值口径与未计入项；"越低/越高越好"类方向提示写在这里，不写进标签。
4. **处理卡**（仅有则显示，顺序固定）：锻造工艺 → 枪械装配工艺 → 附魔效果 → 改造项目。
5. **主卡**：物品信息 → 战斗参数 / 采集参数 → 公式行 → 数值行 → 机制段（如工具的「采集规则」）。
6. **固定详情折叠区**（按 F1 / 点击固定后）：装备对比 → 改造与附魔 → 详细参数（含完整装备对比）→ 物品说明 → 特殊性质。

## 二、语言与命名规则

- **全中文**。物品信息段三行（分类 / 武器类型 / 装备槽位）禁止出现目录原始英文键；
  映射表在 `ColdSteelItemTooltipData.cpp` 的 `Category()` 与 `EquipSlotLabel()`，新类别/槽位先补映射。
- **同一数值全游戏只有一个名字**。标签唯一出处 = `Source/FPSGAME/UI/ColdSteelWeaponText.h`；
  新增标签先在该头文件登记常量，浮窗、摘要、改造台、图鉴一律引用常量，不许就地写 `TEXT("...")` 字面量。
- 单位后缀跟在值后（`1.35 s`、`520 ms`、`12 m`、`1.15×`、`+8%`），不把单位写进标签。

### 单位约定

| 度量 | 单位 | 说明 |
| --- | --- | --- |
| 攻击/射击间隔、开镜、回稳 | `ms` | 一律毫秒整数 |
| 耗时类（换弹、拉弓、弹反窗口） | `s` | 两位小数 |
| 距离（攻击、采集、射程、飞行） | `m` | 一律米，不用 cm 展示 |
| 判定宽容、击退 | `cm` | |
| 倍率 | `×` | |
| 百分比增减 | `%` | 正负号由 Delta 自动带 |
| 枪械稳定性 | `/100` | 值写作 `38.5 /100` |
| 后坐力指数 | 无单位 | 数值越小越好（口径说明注明） |
| 理论射速 | `发/分` | |

## 三、各家族核心属性（摘要网格）与主卡行序

### 枪械（11 件，gunsmith.json 白名单）
- 摘要：武器总伤害 · 攻击间隔(组内射击间隔) · 弹匣容量 · 有效射程 · 普通换弹 · 空仓换弹
- 主卡战斗参数行序：攻击力计算公式 → 强化后攻击力公式 → 武器总伤害/基础物理/附加物理/附加魔法 → 子弹数 → 弹药 → 弹种效果 → 弹药修正后伤害 → 攻击间隔 → 理论射速 → (连发组三行) → 普通换弹 → 空仓换弹 → 开镜耗时 → 后坐力指数 → 枪械稳定性 → 首发上跳 → 连射上跳 → ADS 水平两行 → 回稳90% → 有效射程 → 子弹速度 → 腰射散布倍率 → (暴击伤害加成，有才显示)
- 无握持行（标准格式不要求）。

### 弓（bow_dark）
- 摘要：武器总伤害 · 拉弓耗时 · 搭箭耗时 · 最大飞行距离 · 体力消耗 · 开镜耗时
- 主卡：公式行 → 伤害分项 → 暴击伤害加成 → 拉弓/搭箭耗时 → 子弹速度 → 最大飞行距离 → 体力消耗 → 满弓保持 → 瞄准晃动 → 腰射散布半角 → 开镜耗时 → 弹药三行 → 握持。

### 双手剑（符文/寒晶/高地）
- 摘要：武器总伤害 · 攻击间隔 · 体力消耗 · 最大攻击距离 · 格挡伤害减免
- 主卡：公式行 → 伤害分项 → 快速近战五项 → 三连击两行 → (魔法系数三行) → 攻击间隔 → 突刺时间 → 最大攻击距离 → 普通挥砍距离 → 体力消耗 → 硬直/韧性 → 穿透 → 格挡减伤 → 弹反判定 → (成功弹反三行) → 格挡体力消耗 → 握持。
- 「成功弹反」值统一写 `承锋·瞬重斩 · X s`（不再是"下次普攻瞬发重击"）。

### 长杖（ue_apprentice_staff）
- 摘要：武器总伤害 · 攻击间隔
- 主卡：公式行 → 伤害分项 → 攻击间隔 → 装备魔攻（由目录 `matkFormula` 拼写，与 `EquipmentMagicAttack()` 同源）→ 握持。
- 目录 stats 里的静态"物理攻击/魔法攻击"行被抑制，不与计算行重复。

### 采集工具（伐木斧 / 矿镐）
- 摘要：武器总伤害 · 攻击间隔 · 体力消耗 · 最大攻击距离
- 主卡两段：**战斗参数**（公式行 → 伤害分项 → 暴击率 → 韧性伤害倍率 → 攻击间隔 → 最大攻击距离 → 体力消耗 → 握持）+ **采集参数**（装备方式 → 采集距离 → 命中宽容半径 → 采集产出倍率 → 额外产出几率 → 矿镐"所需有效命中" / 伐木斧"伐木伤害+采集规则"）。

### 铁铲（tool_shovel，特例）
- 不进武器槽、无战斗参数、无强化档位；仅「物品信息」+ **采集参数**段：
  装备方式（按 8 取用 · F7 收起）→ 单层范围 → 左键挖掘 → 右键回填 → 回填上限 → 挖掘下限。
- 数值读目录 `production_tools.json` 的 `dig` 块（footprint_cm / layer_cm / soil_per_layer /
  rise_limit_cm / drop_limit_cm），是 TemperateHills 挖填实现的展示口径；改机制时同步两处。

## 四、静态 stats 抑制（防重复行）

目录 `stats` 数组是 2D 时代快照，凡浮窗已有计算行的字段不再显示静态行：
- 枪械：跳过 `物理攻击`、`弹匣容量`、`弹巢容量`（转轮）。
- 双手剑、长杖：跳过 `物理攻击`、`魔法攻击`。
- 其余类别（防具/饰品/消耗品）维持现状。

## 五、快照与迁移（新增展示字段必读）

物品实例的 `Data` 是创建当时的目录快照；**目录是唯一事实源**。
`UColdSteelStatusModel::ReloadProfile`（`ColdSteelProfileRuntime.cpp`）读档时按白名单把目录字段刷回实例：
目前同步 `weaponType`、`desc`、`name`、`weaponTypeTag`、`dig`。
给目录新增纯展示字段时，必须同时在迁移处补一个同步块，否则旧存档不生效。
数值/改造件/附魔/锻造等实例字段永不同步。

## 六、改造台与图鉴的联动口径

- 改造台总览/对比（M4GunsmithOverview / M4GunsmithSelectedDetails / M4MeleeGunsmith / M4ToolGunsmith）
  与浮窗改造合计卡用同一批标签常量与同一评估入口；本次已统一后坐力指数、枪械稳定性（`/100`）、
  最大攻击距离、韧性伤害倍率、魔法值消耗倍率、剑刃攻击命中魔法易伤、近战命中额外减少魔法冷却、
  快速近战流血、快速近战命中方式、成功弹反保留时间、承锋重击两行、采集三件套。
- 图鉴采集工具页与浮窗同源（ColdSteelTool::Evaluate），标签已统一为 攻击间隔 / 最大攻击距离 / 采集距离。
