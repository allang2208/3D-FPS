# 晴天疏云与雨前多云（2026-09-13）

## 本轮调整

- 温带丘陵晴天持续使用现有体积云层与动态材质，云随天气风移动。原先晴天退出云参数更新、恢复旧材质的负覆盖偏置，导致晴天云量不足。
- 自有材质 `MI_HillsClouds` 的晴天覆盖偏置改为 `0.008`；天气组件在晴天也写入该值，因此既有本地材质不必重新保存才能获得运行时调整。多云覆盖偏置为 `0.028`，随天气混合平滑变化，雷暴上限仍为 `0.045`。这些是引擎材质的偏置参数，并非屏幕云量百分比。额外密度偏置仍为零，保留原材质的噪声与侵蚀。
- 复用已有 `Cloudy` 枚举，界面名称由“阴天”改为“多云”，不改变枚举顺序。多云增加云量并沿用现有阳光衰减，晴天恢复正常光照。
- 自动天气使用同一确定性时间表：原本排在降雨之前的晴天时段改为多云，包括跨日情况；游戏状态与 HUD 预报读取同一规则。默认一天 2160 秒，每段 270 秒。
- 从干燥状态请求小雨、中雨或暴风雨时，先进入多云。`RainCloudLeadSeconds` 默认 30 秒，且不短于云雨渐变时间；已经持续多云的时间计入准备阶段。随后沿用原有渐变雨量与雷电逻辑。
- 连续请求降雨或更改待开始的雨势不会重置聚云计时；选择晴天或多云可取消待开始的降雨。正在下雨时调整雨势沿用原渐变。手动模式仍暂停自动天气。
- F6 面板显示聚云倒计时，事件预报将待开始的降雨显示为即将发生，不提前标为进行中。
