## 姿态修改的理由与实现

v12 给所有草片使用实例的 Z 轴作为旋转起点。原本向不同方向倾斜的草片，在同样追加角度后仍会呈现不同高度和朝向，部分草片可能过度旋转；这不利于形成清楚的低伏轮廓。

现有两个草地实例材质已经带有 `X-Vector And X-Extent Texture` 参数，分别绑定 PN 草包的 `grass_03_08_VEC` 与 `grass_05_03_VEC`。v13 复用此参数，以同一 UV1 读取草片轴向，并调用引擎原有 `ms_PivotPainter2_DecodeAxisVector` 转换为世界方向。

新形变计算 authored stem → target stem 的最短旋转，再由压力强度控制旋转比例。目标方向主要顺着行进方向，保持少量侧向变化；核心草片朝相同低伏姿态靠拢。74° 目标倾角对应理想直线草轴约 27.6% 的剩余竖直高度，**这是目标公式，不是实测草尖高度**。

继续绕 PivotPainter 根部整片刚性旋转，统一限制整片最大角位移，保留草片长度／宽度。原先逆着行进方向倾斜的草片需经过更大的旋转弧，因此整片位移预算从 260 增至 300 cm，主材质 WPO 边界从 300 增至 320 cm，为弱风留余量；超过预算时仍整片限角。未添加逐顶点方向场、逐顶点截断或压缩；根部与轴向在同片内一致，避免重回早期宽三角问题。原草片的纹理、曲率和未受压姿态保持不变，因此不能仅凭本次算法调整声称所有细碎感已消除。

新增一次现有轴向数据纹理采样及轴向旋转计算；RT 数量、每事件两次绘制、10 Hz 接触记录、连续恢复和 3% 低伏风保持。未新增 CPU 逐草循环或物理碰撞。
