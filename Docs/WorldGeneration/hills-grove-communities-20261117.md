# 丘陵树簇与伴生地被

用户本轮明确两点：地面植物、灌木、石块和树枝缺少多样性及关联；树木应形成一簇一簇的分布。沿现有 PCG 图、按世界种子确定的候选点和分块流送制作，不更换村庄、道路、河湖、世界种子或 WorldId。

## 本轮实现

- 新增独立的 `TemperateForestGroves.h` 树簇场：64 m 选址扇区内抖动中心，长轴半径 23–41 m，随机短轴比例和朝向，连续扰动边界。扇区用于枚举，不是方形树丛边界；邻近树簇可以相接，同时保留间隙。
- 原 12 m 树候选坐标和采集 ID 保留，通过共享树簇权重改变出现概率。`LegacyCanopy` 兼容入口同步使用树簇，避免原有基础概率绕过新规则、重新填满林间空地。仍保留少量孤立树；雨林树簇内部保持较高密度。
- 同一个树簇场供 PCG 植被、林缘、落叶地表及远景使用。树种和林下植物的优势形态优先跟随所属树簇，保留个体差异。树簇参数属于独立源码中的构图参数；既有生态密度设置继续有效，本批未制作新的图形化参数面板。
- 新增 `TemperateHillsHabitatCompanions.cpp`：复用已确定的树和岩石，按偏湿蕨丛、林缘灌木、岩脚碎石三套组合生成伴生植物、短枝、碎石、苔藓及少量菌类。组合偏向支承物一侧，具有大小和距离变化，不围成整齐的装饰圆环。
- 使用现有 `ForestShrubs`、`ForestFerns`、`RainforestTwigs`、`RiverPebbles`、`ForestMoss`、`ForestFungi` 数组。材质及网格未重写；本轮扩展现有资产的组合和出现位置，未新增下载或导入资产。
- 温带林下的小型碎屑群由仅树枝扩展为树枝与碎石，增加枝条尺度变化。现有倒木伴生规则保留；大崖体仍沿地标搭建规则，避免围一圈微型装饰。
- 复用每个 PCG 邻域已有的树、岩石空间数据，一次生成局部伴生列表，再由地被分条输出。跨块使用最终位置的半开区间归属；保留道路、村庄、教堂、水体、坡度和岩石占位避让，无新增逐物体 Tick 或同步资产加载。

## 边界

树簇改变的是哪些固定候选出现，旧树木的候选 ID 未重编号，正式存档不重写。此前砍伐的树仍由既有采集／再生存档路径维护；本轮未做读档或联机测试。装饰身份不参与树木或矿石采集。绿色雨林草与黄色丘陵草的资产绑定保留。

原 `TemperateHillsWorld.cpp` 超过 800 行，本批未修改它。若后续需要修改树候选内部布局，可先将树候选与采集形态、普通岩石／灌木候选、世界生命周期分别拆成独立源文件，再在后续批次接续；本轮通过已有共享生境入口完成树簇控制。
