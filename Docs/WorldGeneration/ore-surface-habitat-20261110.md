# 温带丘陵矿物表面与分布

本阶段在已完成的矿块尺寸归一与四种随机轮廓上，调整矿物表面和自然生成分布。复用现有 Normandy 岩石纹理与 Forest Floor 地表纹理，无需添加外部资源。

## 矿物辨识

同一个岩石母材质保留灰褐色宿主岩，使用世界空间噪声与岩面纹理生成不规则矿纹、细碎矿点和少量浅色伴生边缘。金属度只作用于矿纹，自发光为零。

| 矿种 | 表面处理 |
| --- | --- |
| 金 | 较细的暖金色矿纹、少量深色表面污迹，保留明显的宿主岩 |
| 银 | 冷银色矿纹，配深灰色斑驳，以反射与粗糙度区分普通灰岩 |
| 铜 | 铜红色矿纹与局部暗绿氧化斑，氧化部分减少金属反射 |
| 铁 | 暗铁褐色矿纹和锈色斑驳，反射较弱、表面较粗糙 |

岩石表面按世界空间三向投射底色、打包表面属性和法线；法线使用几何顶点法线计算投射权重并变换回切线空间。矿纹不是整块统一染色。参数通过四个矿种父实例调整，四种形态各自继承，不复制四套母材质图。

## 与地面衔接

- 每个模型形态使用自己的源模型 `Min.Z` 和高度，通过实例局部坐标生成下部泥土／落叶色过渡。它不依赖整组 ISM 的合并包围盒，避免一片矿石共用错误的接触高度。
- 底部复用当前 Forest Floor 底色与 2 m 世界投射比例，增加粗糙度、轻微接触暗部并抑制金属反射；继续使用上一阶段的贴坡和埋入量。
- 接入现有 `MPC_FPS_Weather.WeatherWetness`，雨后岩石与土色部分变暗并降低粗糙度，不增加 Actor 或 Tick。
- 此处是表面色与粗糙度的接触过渡，没有新增地形融合几何或运行时地表采样；尚未进行画面验收。

## 自然分布

`RockOreDefinition()` 保留原候选 XY、采集身份及矿种选择阈值，调整候选成为含矿岩块的权重：

- 使用与当前碎石地表一致的扭曲噪声区域，加上坡面暴露度，让矿脉倾向出现在碎石与露岩位置。
- 叠加 140 m 和 42 m 尺度的矿化噪声，使附近候选形成疏密变化，而非各处均匀散布。
- 平坦、浓密林下的含矿概率降低，给落叶层与植被留出更连贯的空间。
- 修复原来的河岸加权：`Bank == 0` 的普通陆地此前也会获得加权；现在只在实际河岸覆盖、且距离河道边缘不超过 750 cm 时按距离衰减。

铁／铜／银／金原有选择阈值、采矿生命、奖励、存档结构、四种随机轮廓及尺寸范围均沿用既有规则。分布权重改变后，部分既有候选会在普通石头与含矿石头之间转换；候选身份没有重编号，不保证旧位置的矿种分布完全不变。显示与采集解析继续共用同一判定函数。
