# 温带丘陵植被层次、占位与根部支撑

本轮调整树木、灌木、幼树、蕨类和草丛的生成关系，延续前一阶段的岩块避让。目标是减少树干／浓密中心穿插、根部悬空和跨入不合适地表，同时保留林隙、蕨丛、林缘与河岸的自然过渡。

## 根部与地形

- 使用实际几何的底部作为贴地依据。骨骼植物采用 `GetImportedBounds()`；静态植物从扩展包围盒中扣除正负方向的边界扩展，避免为风动／剔除设置的额外空间把植物抬高。
- 每株植物在根部中心及四个方向采样地形，比较其自身底部平面与地面的高差；超过该类植物可接受的高差就取消该候选。
- 树木、单株幼树、灌木和蕨类按根部范围采样，不用整个树冠或叶片宽度要求地面完全平坦。草簇按多根茎覆盖的范围采样；低草更贴合坡面，高草和芦苇保留更直立的姿态。
- 只调整 Z，不移动候选 XY。低处支撑加轻微埋入，避免整株搁在单个高点；原有坡度筛选继续保留。
- 树根、灌木、蕨类和旱地草有各自的水位余量与道路限制；芦苇和河岸低矮植被保留已有的浅水／水边生境，不用旱地规则清空整个水岸。

## 分层占位与自然交叠

`GetVegetationPlacements()` 统一处理原来的普通灌木层、林下骨骼植物层和草地层：

1. 按同一树木候选收集树干／根部保护区。原树被砍后仍保留其保护区，避免分区重载时突然长出密集杂草；已有再生树位置也预留成熟根部范围。
2. 普通与河岸灌木、榛树和幼树共同选择占位。同类按种子与候选 ID 决定保留者，避开过度重叠的浓密中心，允许外围枝叶有限交叠。
3. 蕨类避开已保留木本植物的中心，在外围用平滑概率逐渐恢复密度。蕨类之间保留群落结构，只拒绝过度挤在一起的根部与叶丛中心。
4. 草丛避开树根、灌木核心和蕨类根部，在灌木及蕨丛边缘逐步恢复。草丛之间只限制过近的根簇，保留草叶交错，不强制把整片草地划成互不接触的方格。

沿用原来的林冠、湿润度、林下斑块、共同树形和随机大小字段；不提高全局密度去补被剔除的点，也不取消原有林间空隙。新的筛选可能降低局部数量，实际疏密需由用户进场观察。

## 分区与成本

- 空间查询覆盖本分区外的完整依赖范围：草丛依赖已保留蕨类，蕨类依赖木本植物，木本植物依赖邻近候选；范围同时考虑模型尺寸、偏心枢轴与根部偏移。
- 通过局部空间桶查询邻居，同一中心只登记一次；同一批次缓存物种分类和几何包围盒。
- 不新增植物 Actor、逐株 Tick、物理射线或同步资源加载；所有筛选沿现有 PCG 批次运行。保留 CPU trace scope 供以后明确要求性能采集时使用，本轮未采集性能数据。
- 岩块避让仍使用上一阶段的统一占位结果，最终植物不会因为本轮重新分层而绕过岩块筛选。

## 采集与生长

主树种仍为山毛榉，少量黑杨混生；不改变树种比例、候选身份、伐木奖励、生长时钟和存档结构。原树、树桩和再生树的显示与采集反查共用修正后的根部贴地计算，继续使用保存的偏移位置，避免砍伐后树桩回到旧的固定高度。植被占位针对生成／重新生成时的场景状态，不新增每次生长变化后的全区域重建。

再生树先按成熟根部范围确定支撑，再绕固定根部缩放；支撑半径不随生长比例不断变化，避免幼树在生长中途因为扩大采样范围而被新规则突然剔除。

树桩／再生树查询先判断该候选是否有采集／生长记录，再运行主树候选和根部采样，避免既有每秒生长更新对所有未砍伐树位重复计算支撑。
