# 温带丘陵天气接入

适用地图：`/Game/GameMaps/L_TemperateHills_Initial`。

原地图为植被样地，保存的天气管理器关闭了自动排程，且云层与日夜控制的地图名单没有包含丘陵。本次将丘陵接入现有天气系统：

- 启动时启用自动天气，沿用八个三小时天气时段、种子 122 和现实 36 分钟一天。
- 无蓝图天空时钟时从游戏时间 09:00 开始，由天气管理器驱动现有太阳和天空光，云层按天气平滑变化并施加一次光照衰减。
- 复用雨滴、雷电雷声、稀疏远距水坑、地面湿润、屏幕边缘水珠及已有枪械湿润材质。丘陵地形原有的 `Wetness` 绑定继续读取同一管理器。
- 事件栏与详情沿用管理器的真实时间和预报，区域名称显示“温带丘陵”。

已有地图在运行时启用自动排程，不需要重新生成地形或保存地图；作者脚本也改为默认开启自动天气。编译后的编辑器需要重新打开以加载新模块，再通过主场景已有的丘陵门或 `Tools/WorldGeneration/Open-TemperateHills.ps1` 进入。

本次没有改变天气存档规则：地图重新进入会重置天气时钟，天气种子仍独立于丘陵地形种子。固定种子初日从 09:00 开始为晴天，首场自然降雨在游戏时间 21:00，约现实 18 分钟后；不代表进入场景就立即下雨。屏幕水珠与枪械湿润沿用现有渐湿、渐干和瞄准保护。

没有购买或导入新美术资产。按用户规则，本次不运行游戏、测试、截图或验收；新增场景的天气画面与事件栏交由用户测试，先前的三地图验收记录不涵盖本次接入。
