## 逐项结果

| 组件 | 定位到的问题 | 处理 |
| --- | --- | --- |
| 床头饰面 | 墙体与侧条/收边相交 | 前移到真实墙面之外；补齐四个墙面支座，保留分块软包与实体通风片 |
| 床边供电脊 | 上端插入床头饰面，底部支座压进踢脚线 | 缩短上端、调整下支座标高，保留端口与实体旋钮 |
| 两盏阅读灯 | 原灯罩是实心块，出光片嵌在实体内 | 改为空腔灯罩、内嵌扩散片与墙面支座，光源对齐实际出光面 |
| 床头托盘 | 手机和腕表未落到内衬面 | 补齐四边框并按内衬表面降低手机、腕表 |
| 床头书杯 | 书面文字与杯把接触细节欠完整 | 限制字宽；杯把与杯壁连续接触，保留书页与书脊分层 |
| 床体与床品 | 原床垫/枕头/被褥局部互穿 | 保留床架和变换，重做支撑平底枕头、床垫、被褥与缝边；登记原休息合同的网格别名 |
| 床尾搭毯 | 搭毯及流苏穿入被褥侧边 | 与实际被褥共享曲面，保持独立厚度，流苏越过被褥外缘后下垂 |
| 地毯 | 与床脚、两侧床头柜及拖鞋相交 | 改为床尾独立地毯，保留低绒厚度、滚边与短流苏 |
| 窗边软包凳 | 未发现外部穿模 | 保留软包缝边、框架、六个简单碰撞体；作为折叠布料的实测承托面 |
| 折叠织物 | 原布面悬浮且缺少真实折叠厚度 | 改为三层闭合折叠体，落到座垫上，补连续包边和轻微表面起伏 |
| 编织篮 | 布面穿过篮沿，篮体离地 | 篮底接地；内侧自然下垂、越过圆形篮沿后沿外侧下垂，织纹 UV 连续 |
| 壁架 | 支架压入墙面 | 按墙面重定位，补齐安装隔柱，保留上下层书本与陶盆位置 |
| 桌面陈设 | 物件压入桌面、杯子压进音箱、便笺挡住电源面板 | 按实测桌面落位；重排杯子与便笺，保留键鼠、电源按钮和音箱净空 |
| 耳机与支架 | 底座压入桌面、耳机压进显示器 | 移至显示器右侧空位，调整头梁支撑高度和底座接触面 |
| 走线托盘 | 穿过抽屉、桌腿和后侧支撑 | 收窄托盘、调整吊架；线缆避让桌腿并接到机箱侧后部 |
| 桌面信息横栏 | 支座压入桌面，横栏过宽 | 缩窄横栏、将立杆移到音箱外侧，底板落到实测桌面 |
| 拖鞋 | 鞋底压进地毯 | 跟随床尾地毯重排，并依据地毯顶面设置高度 |
| 书桌抽屉 | 全行程与桌腿及后梁相交 | 整体向桌内和桌前各移 8 cm，并对齐桌底；储物 ID、开合行程保持 |
| 书桌椅 | 脚轮入地，抽屉前空间不足 | 后移 14 cm 并抬至 1.8 cm 地板面，保留原模型、材质和碰撞 |
| 原书桌与机箱组件 | 原家具按铺装前高度摆放，脚部入地 1.8 cm | 书桌、机箱、玻璃、风扇、键盘字和桌面附件按同一地板基准同步调整 |
| 电脑电源面板 | 底座嵌入桌面 | 按面板实际底面校准高度，设备引用及开关功能保持 |
| 键盘字面和桌面螺钉饰面 | 字面倒角与螺钉外圈局部沉入承托表面 | 按实际网格分别抬高 0.6 mm 与 3 mm，保留字样及固定位置 |
| 四个衣柜储物格 | 脚部入地 1.8 cm | 整组按地板面抬高，柜门、铰链随所属 Actor 同步移动 |
| 窗边花盆与植物 | 花盆底部入地 1.8 cm | 盆与植物一起抬高，保留原植株及材料 |

## 本轮实际检查

- 从已保存的 UE 资产读取 **75 个相关组件**的 SourceModel LOD0 和世界变换，包含原房间、家具、柜门与新增陈设。
- 新增陈设原有 16 组跨 Actor 穿插已消除；随后扩展到卧室家具、电脑附属件、柜体和花盆，保存后未处理的布局穿插为 **0**。使用网格三角面判断，不是仅用包围盒。
- 保留并单独记录 4 组正常装配接触：植株入土、机箱玻璃嵌装、主板连接件安装和玻璃固定螺钉。这些记录仍可在 `intersections.json` 的 `installation_contacts` 查看。
- 7 个储物格累计 **460 个开合位置采样**，旋转步长不超过 1°，抽屉步长不超过 1 cm；与周边可见组件相交为 **0**。同一容器内部的安装接触不作为外部穿模。
- 独立检查床垫/两个枕头实体与被褥、篮上布料与篮沿/编织条，相交为 **0**。缝线与被褥的预期缝合接触单独分类。
- 15 组承托关系检查未发现向下穿入；当前实测间隔约 0–2.2 mm。
- 输出床区、床头、书桌、篮体、窗凳、壁架及俯视的保存几何检查图。图中采用诊断材质，不等同 UE 最终光照画面。

检查没有启动游戏或 PIE；角色动作、实际操作和运行时观感仍由用户体验。离线开合采样不替代连续运行时物理测试。
