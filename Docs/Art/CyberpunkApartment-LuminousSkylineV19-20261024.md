# 公寓外景 V19：窗灯密度、条形照明与空中广告

## 本轮方案

用户反馈 V17 窗灯削减过多，要求恢复约 40% 点缀、写字楼使用条形灯，并新增 3–5 个广告及向夜空投射的 AR 灯效。本轮在 V18 场景上局部接入，不更改建筑位置、河宽或室内。

| 项目 | 实施 |
| --- | --- |
| 亮灯比例 | 四类办公立面每 768 个窗格亮 306 个（39.84%）；住宅／退台立面亮 307 个（39.97%） |
| 办公室 | 每条灯带跨 3 个窗格，按楼层和部门形成亮区、暗区，保留原有轮廓灯 |
| 住宅 | 暖冷混合的独立窗灯，分布固定，未加入逐窗闪烁 |
| 外墙广告 | 新增 Arcade、Metro 两块面向公寓的屏幕，复用现有动态广告图集，不重复生成图片 |
| 空中广告 | 新增 AETHER／SKY NETWORK 与 ORBIT／HARBOR TRANSIT 两组，含矢量标志、清晰字体、缓慢旋转和柔和扫描 |
| 投射装置 | 两套前排屋顶投射器，避开原屋顶中央设备，光束与灯头出光面、空中广告位置对应 |
| 水面 | 六类新窗灯重烘静态城市倒影；新屏幕、悬浮广告和投射光束使用可见物相同的时钟、位置和图形函数 |

40% 指制作图集中的亮灯窗格比例，不是整幅画面亮部像素占比。远处楼群保留较低发光强度，避免再次形成满屏亮点。

## 制作与性能范围

- 新增 7 个网格、1,832 个源三角面。实体支架使用 Nanite；屏幕是 2 三角面网格，光束是有界开口锥壳。
- 空中广告使用加法材质，黑色区域不遮住天空；文字来自可编辑字体模型的生产贴图，动画图形通过材质计算。随已有太阳方向夜间显现、白天淡出。
- 无新增 CPU Tick、实时场景捕获、投影动态灯或碰撞。广告平面与光束参与透明绘制，水面增加对应有界反射分支；没有进行性能测量，不宣称零开销。
- 复用 V16 广告图集、V7 金属 PBR、V17 结构灯母版和 V18 水体。新增两个 1024² 字形贴图，显式 mip、渐变边界和反射足迹过滤用于控制远景闪烁。
- 静态倒影不烘入活动广告平面或光束，避免静态与动态倒影重复叠加。
- V18 重建链在 V19 已安装后继续调用 V19，保留本轮材质与广告。
