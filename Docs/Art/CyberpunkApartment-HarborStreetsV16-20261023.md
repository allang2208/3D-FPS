# 对岸广告、扫灯与街景 V16

## 广告清晰度

用户截图中广告主体成片模糊。读取原始 1024×1536 广告图集可见其人物、产品和车身原图仍有细节；V10 通过 Custom 节点显式选择 Mip，并使用可流送 TextureObject。此种取样缺少普通 TextureSample 的 UV 使用信息，驻留分辨率和显式 Mip 都会影响最终清晰度；本轮没有取得运行中的纹理驻留数据，不将流送问题声称为唯一根因。截图中的单面广告仅占几十像素，原来的细字也不适合这一视距。

制作调整：可见屏幕改为梯度取样，使用温和的 0.85 梯度系数；原图和横条各复制一份专用共享纹理，保留 Mip、设置局部常驻及 2048 上限，不修改全局流送池。减少 UV 缩放晃动并取消微小平移，降低夜间亮度上限以保留图案对比。保留四套原广告图和轮播，水中广告继续使用稳定的显式预过滤，不套用屏幕锐化。

## 探照灯

六组屋顶探照灯继续沿既有 GPU 材质驱动灯头、支架和光束。水平扫动范围扩大到左右各 118–144°，俯仰基准为 32–40°，变化幅度 17–21°；周期 19–32.5 秒，各组相位不同。六组在水中的解析光束倒影使用同一组参数。保留实际天气太阳方向控制的昼夜强度，没有新建全局时间或动态灯。

## 道路与车辆

沿现有中段岸线、在滨水平台和第一排楼群之间布置双向道路、路缘、人行区、标线与三个短服务出入口。道路追随岸线转弯，两端使用低速视觉回转段连接，形成约 6.3 km 的往返闭合线路。路侧增加 94 株实心低模树冠和简化树干，避免远景透明树叶闪烁；另有路灯外形和路口标识。

制作 Coupe、Shuttle、Freight 三种低模车辆，每种 12 辆，总计 36 辆。每辆约 240–252 个三角面，保留车身、车顶、车窗、轮胎、轮毂、前灯和尾灯。车流速度 16 m/s，使用一张 2048×1 RGBA32F 路径数据纹理驱动整车位置、朝向与法线，循环路径不在可见端点瞬移。所有车辆是远景展示对象，没有车辆 AI、物理驾驶或碰撞。

新对象分为道路、树木、街道设施、路口和三组车流，共七个 Actor，源三角面合计 18180。静态部分启用 Nanite；车流保留普通网格以支持较大 WPO 位移，并扩展边界。无新增 CPU Tick、实时捕捉、远景光追实例或动态灯。
