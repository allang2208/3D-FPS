- 布局规划保持原局部坐标及随机种子；运行时几何、导航、房间判定、入口和环境特效统一加实例位移。生成 Actor 继续归属生成器所在子关卡，卸载仅清理该实例。
- 个人最终返程只提交本人的通关状态，其他人的任务与宝箱操作继续。保留实际库存事务，不补发未拿走的奖励；个人领取提示不再依靠别人是否已领取。
- 主神空间和地牢的环境显示、音乐、任务栏、开发默认弹药、建造及场景交互判断改用本地/实际玩家区域，避免持久地图名称误判。
