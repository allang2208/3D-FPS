后续武器动画排查与修复见 [2026-10-13 武器动作与联机表现](weapon-animation-sync-20261013.md)，包含远端弓/工具初始化、装备实例过滤、开火后坐时间和动作快照节奏。

## 确认的问题与修改

| 动作 | 原因 | 修改 |
| --- | --- | --- |
| 第三人称专注魔法书 | 旧悬浮世界书固定 OwnerNoSee，未接入 F6 可见性；远端没有浮书位姿/书页数据 | 共享身体表现通道同步书本的身体空间变换及封面、书页的实际骨骼姿态；世界副本使用 F6/远端共同的可见性规则，普通合书、受击打断均读取同一份原始姿态 |
| 远端副手书 | 服务端远端 pawn 不装备仅拥有者使用的手臂，装备采样误以为没有书 | 从玩家自己的服务器影子档案发布闭合书及握持骨架的资源描述，沿用现有装备复制 |
| 客户端翻越/攀爬 | 原入口明确拒绝 NM_Client，远端服务器也没有执行器启动路径 | 可靠请求只传动作编号；服务器从自身位置重新探测并执行逐段碰撞扫描，拥有者收到批准后跟随同一时间线；远端身体读取服务器实际进度、手撑点，退出位置/速度由服务器回传 |
| 翻越后的深落差 | 必须在网络结束后保留落体出口速度、模式 | 继续使用既有无限落差判定及 Falling 出口，不把客户端推进后的落点当作权威位置 |
| 闪避 | SavedMove 只存本地回放数据，不能自动把客户端创建的 RootMotionSource 发给服务器 | 扩展 CharacterMovement 移动包，同步闪避编号、方向和进度；服务器用影子档案检查体力、距离与动作门禁并创建自己的 RootMotionSource；重复包不重复扣费，拒绝时取消本机预测 |
| 突刺、配重、上挑、冲刺攻击位移 | 本机动作可播放，但客户端突进/空中惯性入口被禁用；服务器没有位移请求 | 同一移动包传递动作编号与累计已扫过距离；服务器按持剑、技能、距离预算和收势间隔核准，重新扫描碰撞；累计量避免重复执行，并补偿中间移动包丢失；预测回放保留分帧位移与惯性状态 |
| 滑铲 | 衰减在角色 Tick 中，服务器网络移动与客户端帧率不同，回放又缺少原来的滑铲计时 | 将滑铲物理推进到 CharacterMovement::PerformMovement；SavedMove 保存年龄、剩余时长和下坡状态用于回放 |
| 滑铲接跳跃 | LaunchCharacter 只在拥有者执行，没有服务端起跳意图 | 移动包增加单次起跳编号，服务器保留自身水平速度并施加相同的 650 cm/s 起跳速度；重发不重复起跳，回放恢复起跳 |
| 换武器时旧动作残留 | 只校验接触数据的武器身份，动作/换弹/弓状态仍可能沿用旧包 | 武器与家族匹配后才复制对应的动作、双手进度和弓表现 |
| 格挡收手 | 进度速度被截为非负，回程只能阶梯式更新；大步回程还被误判为动作重启 | 接受负向进度速度，格挡回程不按进度倒退触发可靠重启包 |
| 旧动作上报接口 | 服务器自行递增客户端序号，可能吞掉下一份真实样本 | 服务器离散事件不再占用客户端样本序号 |

- 普通装备、换弹/空仓换弹、检视、双手枪独立动作、弓、施法手势、工具、饮用和推门已有身体状态/接触样本分支；本次没有据此宣称实机全部同步正常。

- 翻越先等待服务器批准，会包含网络往返延迟。批准期间关闭该次自动路径的普通位置误差纠正，始终不启用客户端位置权威；完成确认、超时或组件结束会恢复原设置。
