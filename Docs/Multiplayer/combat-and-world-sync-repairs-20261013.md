# 联机战斗与世界状态修复

适用工程为 `D:/FPS3D/FPSGAME`，范围为双人监听服务器。本批延续采集、建造、工作站、神龛和组队换图的接入，修复后续源码排查发现的战斗、奖励、交易与环境同步缺口。源码已落盘；联机运行效果由用户测试。

## 玩家归属与交易

- 怪物原有击杀奖励入口统一按击杀者查询档案，保留小手召唤物等奖励限制。经验、灵魂及同次击杀修炼进入对应玩家档案。
- 怪物伤害公式从实际攻击者读取献祭、装备穿透等加成。感染与生存状态更新按角色查询档案；旧客机上传不覆盖服务器正在推进的感染。
- 客机商店购买、批量出售通过拥有者 PlayerState 请求。服务器重新计算目录售价、验证实例与数量，并在同一库存事务中保存扣款、扣物及产物。
- 档案增加默认值为零的 `ServerSoulDebits` 累计扣款字段，与原 `ServerSoulCredits` 一起合并重复或延迟回执。原有档案按带字段名的序列化补默认值，不另建存档格式。
- 余额确认仅影响商店请求；采集、拾取等库存操作继续使用原短请求，避免货币变动导致重复上传整份档案。

## 战斗状态与怪物

- `FPSStatusReplicationComponent` 在玩家及共用怪物基类上提供状态副本；原组件仍负责服务器伤害和效果结算。
- 中毒、恐惧、感染、通用增减益及状态栏记录接入同步。倒计时采用服务器截止时间；在客机还原剩余时间，不由客机执行持续伤害。
- 狂暴、赌注和沉着冷静的层数、持续时间及数值同步给本地动作和后坐力读取。恐惧减速改为派生速度乘区，避免逐帧累乘基础移速。
- 护士系、狼系、手脑、毒蛆、皮肤手和百目炉渣补充生命与生命上限复制；初始化不覆盖晚加入时已收到的服务器生命值。
- 护士、手脑、毒蛆、狼和皮肤手补充客机动作时钟。手脑同步拍击落点与预警，巫婆的施法／投瓶选择由服务器决定。保留原动画资产与战斗时序。

## 投射物与世界状态

- 毒蛆毒液和巫婆投射物复制实体与移动，远端仅播放表现；巫婆毒池复制落点、范围边界及开始时间。
- 胖僵尸死亡脓液池按初始种子、设置和服务器开始时间重建外观，伤害仍由服务器处理。
- 普通玻璃复制破碎状态。地牢生成对象采用已有稳定名称，追加即时破碎通知和世界快照补发，同步可见性与碰撞。
- 天气由服务器发布低频快照；客机按服务器采样时间推进显示时钟，并写回已有天空时钟。雷电传递同一次事件的时间、强度及雷声选择。
- 无天空时钟的关卡将查找重试限制为每秒一次；世界状态继续沿现有分片限速通道。持续状态按 10 Hz 采样，天气按 2 Hz 采样，字段未变时沿引擎差量复制。
