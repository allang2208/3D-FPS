# 联机扩展覆盖修复

本轮继续按用户要求检查调用链、修改源码并后台编译。没有启动 UE、游戏、PIE 或自动化测试，运行体验由用户测试。

## 本轮问题与处理

| 功能 | 确认的缺口 | 本轮修改 |
| --- | --- | --- |
| 副本搜寻柜与宝箱 | 副本生成器关闭生成 Actor 的复制，搜寻柜的 `bSearched` 因此不能到达客机；已开宝箱只有即时消息，后加入者没有开启状态。生成期间收到的世界快照也可能过早被消费。 | 非复制搜寻柜通过玩家所属通道广播打开；世界快照保存已搜寻柜、已开宝箱，补齐开启姿态与标记。等待本地生成器完成后应用场景快照。 |
| 法术释放、取消和失败退款 | 150 ms 通用限频会静默丢弃部分释放/取消；圣光、闪电本地目标失效只退款本机，服务器预留未解除；释放拒绝与死亡/换 Pawn 也有残留预留。 | 只对新凝聚限频，释放/取消继续结算；圣光/闪电目标失效发送取消，服务器释放失败回收预留，死亡或换 Pawn 清理未释放法术。客户端记录实际预扣法力到回执完成，释放失败后恢复法力与冷却，已本地取消不重复退款。 |
| 闪电过载 | 链式主体使用客机影子档案，但过载递归重新取了主机 GameInstance 档案。 | 主链与每级过载传递同一施法者档案，伤害与修行结算保持正确归属。 |
| 门窗等构件脱落 | 物理模拟发生在子网格，Actor 移动复制跟随不动的空根；脱落标记、碰撞关闭、备用网格没有完整应用到客机；寿命结束只销毁营火子件。 | 使用网格作为构件根，复制备用网格与脱落状态；客机同步停止子件交互与碰撞。服务器销毁脱落父件时同时清理其逻辑子件。 |
| 体素倒塌残骸与回收 | 客机通过快照另造本地残骸，没有服务端 Actor 引用，不能正常作为回收 RPC 目标；只在建筑版本变化时更新位置，客机碰撞也未启用。 | 残骸 Actor、身份和物理运动复制；既有分片快照与异步工作线程只负责给对应复制 Actor 装配几何，不再另造替身。补齐客机碰撞/物理状态，旧几何快照不回写旧位置，撞击伤害只由服务器结算。 |
| 组队换图结算与失败反馈 | 就绪保存发生在工作站收尾之前，后续保存返回值被忽略；失败与超时没有通知全队或立即撤销本次等待。 | 先取消未释放法术、结束已投入工件，再保存并标记就绪。工作站、角色、建筑保存失败或服务器拒绝换图时，终止本次请求并通知队员。 |

## 实现与范围

- 复用现有场景分片、玩家 RPC 和 UE 移动复制；不修改建筑承重、掉落比例、法术伤害配置。
- 残骸几何仍依赖世界快照到达和异步装配，因此刚产生的残骸在客机可能延迟出现；运动与交互使用服务器对应 Actor。
- 保留工作区已有副本进度小状态复制、工作站持久化和远端枪械表现改动。
- 编译接入时补齐 Super90 主机开火调用新增的武器身份与服务器时间参数，使其符合当前远端枪声/枪口表现接口。
- 修改前备份、编辑脚本与本轮编译日志：`Saved/MultiplayerExtendedCoverage20261013/`。备份不能整体覆盖工作区后续改动。
