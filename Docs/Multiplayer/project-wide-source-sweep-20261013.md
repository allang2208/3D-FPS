## 本轮新增修复

| 类别 | 确认的遗漏 | 本次修改 |
|---|---|---|
| 强化后的武器属性 | 武器计算已经传入客机档案，但强化公式内部又读取主机 GameInstance 档案 | `ProcessedDamage`、`AttackFormulaAttribute` 接收实际使用者档案；枪械、近战、弓和生产工具的计算传入该档案，UI 预览仍可使用本地默认值 |
| 村庄刷怪器 | 非复制刷怪器的客机本地实例也可能拥有 Authority 角色，单独检查 `HasAuthority()` 无法阻止重复刷怪 | 手脑与毒蛆刷怪器显式排除 `NM_Client`；毒蛆的玩家安全距离覆盖所有连接玩家 |
| 女巫投掷物 | 瓶子的落地探测只忽略第一个玩家，可能把客机角色当作地面 | 忽略当前世界所有玩家 Pawn，保留原有地形探测逻辑 |
| 训练靶 | 靶子不复制；服务器命中统计、浮字和摆动无法回到客机 | 靶子复制身份和累计/DPS/命中数，服务器统一统计；命中表现用组播，晚加入可收到当前统计；窗口统计随时间清除过期命中 |
| 建筑世界计时 | 自动存档起始时间、残骸失败回收重试时间保存在文件静态变量中，跨地图和同进程 PIE 世界共用 | 将两类时间记录移动到每个 `FVoxelBuildRuntime`，保留原存档间隔和重试间隔 |
| Clearwater 水面 | GameMode 在运行时补建的水面只存在主机，客机没有对应对象 | 复制该静态水面 Actor 的身份，各端继续自行建立水面和水下表现 |
| 建筑/世界快照 | 建筑修订号在整个快照编码成功前就被记作已发送；世界变化后旧分块、等待状态和相同修订号可抑制新世界首包 | 成功排入发送流后才记修订号；同时比较建筑 Actor 身份；世界切换清理流上下文；快照携带地图名并拒绝不属于当前地图的数据 |
| 会话钥匙 | 钥匙拾取后场景对象销毁，但钥匙只在 Pawn 内，死亡更换 Pawn 会丢失 | 在 PlayerState 保存会话钥匙，仅复制给拥有者；无缝换图时复制到后继 PlayerState，不写入磁盘档案 |
| 冰墙 | 客机冰墙落地结算使用主机档案，技能经验及奖励可归错；受伤后的 `NetHealth` 不更新 | 落地和寒冷光环按实际施法者查档案；受损时发布血量并由 RepNotify 更新客机镜像 |
| 再生树碰撞 | 再生树可见范围已覆盖所有玩家，但生成树干碰撞时仍只比较主机距离 | 碰撞范围使用同一组玩家观察位置，覆盖与主机分开的客机 |
| 焚化炉拆除 | 拆除前的暂存物检查只读取主机档案，忽略请求人的暂存物 | 使用请求上下文档案，并检查当前在线玩家的服务端档案；有暂存物时拒绝拆除 |
| 脚步插件 | 同一动画通知 UObject 被多角色共享；异步查询回调读取最后写入的 MeshContext，可能串角色甚至串 PIE 世界 | 查询委托绑定原始骨骼组件的弱引用，回调临时使用该上下文；AI 听觉仅服务器上报，专用服务器跳过声画效果 |
| 采集完成反馈 | 砍倒树、敲碎石块和劈开树桩的完成碎屑只在执行结算的主机播放，树桩开裂声也未同步 | 由丘陵世界组播完成事件，各端生成本地碎屑和树桩开裂声；沿用倒树原有复制和落地效果 |

焚化炉检查使用服务器已持有的在线档案；个人暂存物依然属于个人档案，未将其改成公共容器，也未增加离线档案全集扫描。

## 明确保留的限制

- 当前交付针对现有主机开房/客机加入链路。丘陵源码明确声明专用服务器不受支持，工程也没有 Server Target；其准备流程依赖渲染、资源预热和玩家就绪。此次没有通过删除限制把不完整的专用服路径伪装成已支持，也没有新增专用服务器产品目标。
- 这是一轮全项目范围的原生源码入口排查，不是全部 `.uasset` 蓝图图表或地图资产的逐一运行审计。未启动编辑器、PIE、打包游戏或自动回归。
- 声画瞬时事件采用不可靠组播；持续状态和统计通过复制/快照恢复，不重放晚加入之前的短暂碎屑与浮字。
- 编译成功只能确认相应目标能构建，双人联机的实际操作、延迟和长时间游戏表现仍由用户测试。

## 用户复测重点（未代为执行）

1. 主客机使用不同属性档案，客机分别使用唐刀、枪械、弓和工具；观察结果是否仍受主机属性影响。双方击打同一训练靶，查看累计数字及客机浮字。
2. 客机施放冰墙击中怪物，查看客机自身技能经验和奖励；从另一端攻击冰墙，查看受损状态。
3. 客机拾取门钥匙后死亡、重生并返回对应门；组队换图后再查看会话钥匙行为。
4. 主客机在丘陵分开较远活动，客机接近再生树并采集；双方观察采集碎屑、树桩开裂和倒树。
5. 运行较长时间后组队换图，再建造、等待自动存档；客机晚加入或换图后确认建筑和构件出现。焚化炉仍有玩家暂存物时尝试拆除。
6. 进入村庄观察是否出现客机本地额外怪物；多人同行时观察脚步声/噪声归属；进入 Clearwater 地图确认客机水面存在。
