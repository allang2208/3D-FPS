## 本轮发现与修改

| 功能 | 缺口 | 修改 |
| --- | --- | --- |
| 普通双手剑、唐刀格挡与弹反 | 本地 `bGuarding` 没有通用服务器入口；旧远端分支仅在装备特定蟠螭配件时工作。普通格挡、唐刀弹反效果在客机缺少权威结算。 | 剑组件增加所属玩家格挡意图通道，按服务器装备、角色存活、动作占用和破防状态校验。主机、客机共用原格挡伤害函数；服务器状态同时参与体力恢复和行动限制。 |
| 格挡耗体力、反应与破防 | 旧专用远端分支只扣服务器体力，拥有者缺少扣费回执、格挡音效和反应动作。 | 可靠回执发送实际耗体力与格挡/弹反结果；客户端处理反馈。破防的输入锁复制到达时重新衔接破防动作，保留原定时解除与按住格挡恢复逻辑。 |
| 弹反配件与承锋瞬重斩 | 唐刀玄云龙、反击鼓舞等效果依赖未接通的通用弹反；高地剑承锋状态只在本机产生，服务器复算伤害时也没有承锋倍率。 | 弹反后沿原服务端配件处理发放效果；拥有者得到按服务器时间修正的承锋窗口。承锋出手有独立攻击标识与序号，服务器消费一次窗口并为同一挥的目标重建物理和韧性倍率，同时覆盖其裂斩波。 |
| 客机法术命中反馈 | 火球、冰锥、冰墙、暴雪、圣光伤害、闪电和火系伤害等调用了服务器角色的命中显示函数，但未转发给所属客机。 | 公共命中显示入口转发给角色拥有者，衔接命中标记、目标血条和提示音。已有弹道弹、弓箭、符文飞刃的专用回执保留，避免双播。 |
| 近战和技能命中声音 | 通用客机命中回执固定当作枪械命中，抑制了原有近战/技能确认音。 | 回执携带实际枪械标记；普通枪弹继续使用枪弹接触音，近战、飞刃、裂斩波恢复原确认音。 |
| 蟠桃续命提示 | 致命伤时先发送零血量“等待重生”，随后服务器才原地续命；金色续命提示只在服务器屏幕输出。 | 续命完成后发送实际剩余血量，并向拥有者提示“已原地复活”，立即发布权威血量。 |
| 远端换装/销毁干扰主机动作 | 剑组件的取消和 EndPlay 直接取 GameInstance 主机档案结束快速近战。 | 使用角色对应档案完成收尾。远端第一人称组件不推进本地输入/攻击状态，远端装备与动作显示继续使用身体复制路径。 |
