# 裸手表面 V8：母版与全部派生修复（2026-10-16）

用户反馈：现有手模有穿孔漏空和表面纹理问题，导致每把武器都要单独调整。用户要求在现有手模上升级优化，修复范围定为"母版加全部派生"，纹理问题通过统一升级共享皮肤材质解决，UE 资产在 UE 关闭后由后台批处理读写。本轮没有改掌形、骨架、权重、UV 或动画。

## 原因

- 09-25 的掌面补洞在掌心和拇指根部左右各补了一块扇形面，补片在凹形边界上翻折（同一条边被两个面按相同方向走过）。皮肤是单面材质，翻折面会透出背景，看起来就是穿孔漏空。
- 10-14 修复只改了当时找到的 13 份派生网格和 20 份可编辑 Blend，母版与 20 份 Authored JSON 里仍有翻折。之后从这些源派生的武器又把缺陷带了回去，所以每把武器都要单独修。
- 掌心另有两组小于 0.03 mm 的微小边，产生面积为零的退化面。
- ASH12、M16 的原生参考姿态是预变形的，但写入的仍是规范姿态的法线。约 5–10% 的手臂面积法线方向错误，在手指、前臂和上臂上表现为暗斑或光照反向。其手套伴随皮肤、Super90／M870 和部分手枪派生也带有少量同类法线错误。

## 修复方法（`SourceAssets/BareHandAudit20261016/`）

`generic_fix.py` 是不依赖对应关系的局部修复器，每份网格都按它自己的静止姿态计算：

1. **微小边合并**：把短边的一端改指向另一端，删除退化面。
2. **翻折**：取翻折面和旧补片中心的整圈扇形面，按外侧相邻面的方向对边界做耳切三角化，保证不再翻折（与 10-14 派生修复同法）。原补片中心等少量内部点退出表面，局部最大偏移约 1.5 mm（M16 预变形姿态下约 2.6 mm）。
3. **法线**：与网格自身平滑法线偏差超过 35° 的角点法线，改用平滑法线。

所有保留顶点的位置、权重，以及新面每个角点的 UV、颜色和法线，都从原角点复制；骨架、材质槽和 LOD 数量不变。

## 共享皮肤材质

`skin_recipe.py` 把 Super90 SkinClean（10-11）和 JointSurface（10-12）里通用的部分合进了共享父材质：

- 微细节和颜色细节加了滤波，皮肤与掌面的微法线、坡度上限都降低了；
- 解剖法线在手背和腕部减弱，掌纹保留；
- 原贴图里的描黑线压到 3.5%；
- 腕部手与前臂之间的过渡加宽到约 4.3 cm；
- 增加了小幅的大尺度色温和粗糙度变化。

Super90 硬编码的腕部坐标没有带过来，共享材质继续使用自己的 WristOrigin、WristForward、WristDorsal 参数。

已升级 5 个父材质：`M_BareFamily_Arms`、`M_BareFamily_Hands`、`M_BareNative_Default`，以及 M16 的 `M_M16ThumbHands`、`M_M16ThumbNative`。Super90 的两个 JointSurface 父材质本来就是这套效果，没有改动；第三人称 `M_PlayerBodySkin` 不在范围内。
