## 当前制作入口

1. `python Tools/TrouserFit/prepare.py`：读取各旧家族与靴口制作输出，生成逐路径记录和六份收束源。原始输入快照保存在 `SourceAssets/TrouserFit20261018/Inputs/`。
2. Blender 后台运行 `Tools/TrouserFit/save_editable.py`：保存带原生骨架、纹理和全部变体的 `Tailored_Trousers_Editable.blend`、六份 FBX 与两个正式物品图标。
3. `Tools/TrouserFit/run_asset.ps1`：沿用共享批次互斥，有真实编辑器时用现有桥，否则使用无界面 commandlet。保存六个穿戴模型、两对图标／掉落模型、LOD 配置与图标贴图。续传跳过源哈希一致的已保存模型，每个模型完成后释放临时内存。
4. 保存与图标导入成功后，批次自动调用 `Tools/TrouserFit/publish.py`：依据保存回执，只合并两款物品的外观路径与图标，不改数值、存档或其他装备；也可单独重跑该发布入口。

完整重建可运行 `Tools/TrouserFit/rebuild.ps1`。首次无界面导入因工程 Editor 模块缺失而未执行脚本，随后必要 Editor 构建成功（`editor-build.txt`）。部分资产保存后的内存不足已改为按回执续传和逐模型回收；最终状态仍以本目录保存与发布回执为准。

旧家族作者脚本仍是原始形体和靴口的上游输入。重建后须经过本目录腰口收束步骤，再用本目录发布入口；不要将上游旧椭圆腰口直接重新发布。重复制作应在原有上游输入上进行，避免重复施加收束。

新资产目录：`/Game/Characters/ModularOutfit20260924/TrouserFit20261018`。未覆盖旧包或正在加载的旧资产。源码、可编辑文件、导出、保存回执分别记录；完成状态以 `saved_assets.json`、`published.json` 为准。未启动游戏或进行动作、蹲姿、换装视觉验收，交由用户测试。
