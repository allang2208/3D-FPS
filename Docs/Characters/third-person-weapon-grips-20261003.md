# 第三人称枪、弓、法杖握持接入（2026-10-03）

后续动作接入见 [第三人称动作与手指接入](third-person-action-contacts-20261003.md)。该后续改动将枪、杖和工具从装备时的待机握持扩展为实时动作接触，并新增有界手部/机械表现快照；以下记录保留本阶段原设计。

## 原因与范围

Jason 的手指有骨骼和蒙皮。此前枪械只使用通用身体姿态与手腕 IK，没有将具体枪型、握把配件的手指姿态传到身体。法杖使用手腕挂点，缺少掌心接触偏移。弓缺少完整的第三人称装备、动作及弦箭呈现链路。剑使用此前保存的 `A_Jason_SwordGrip`，继续保留。

本次复用项目已经保存的第一人称网格、动画、握持配置和弓部件，在装备建立时生成身体手指姿态；弓在播放中更新。没有新增需要导入的动画资产，也没有改变命中、弹药或装备存档规则。

## 实现

- `FPSPlayerBodyGrip` 根据掌骨构建来源与目标掌心坐标系，修正武器相对手腕的偏移；映射五指三节，按 Jason 的原生骨长解算前两节接触，并处理有权重的半旋转辅助骨。保留身体的骨长和缩放。
- 枪械读取已解析的持枪 Idle（包括弹鼓/空仓变体）、握把姿态及 `WeaponGripProfile`。两手分别映射，副手位置由实际主手位置推导；双持手枪和法杖副手枪按各自手别接入。
- 法杖复用 `StaffGripPose` 的掌心、杖身接触点及握持变体，将静态杖体和身体手指放进同一坐标关系。
- 弓使用隐藏的来源骨架采样当前动画，生成左右手腕目标和手指姿态。左手先完成身体 IK，右手从左手实际位置推导。换片段时以局部姿态进行短暂过渡。
- 第三人称弓复用现有弓体、配件、弦、箭与弓臂弯曲组件。持弦时使用当前采样姿态的 `bow_nock`；释放后使用逻辑弦回弹位置。搭箭过程使用取箭方向和落弦进度。
- 弓挂点只取动画标记的位置与旋转，使用配置中的弓体尺寸，避免导入骨骼的缩放被重复施加。弓子组件使用唯一名称，允许第一、第三人称组件同时存在。
- 手指覆盖放在身体手腕 IK 之后；攀爬、施法、换弹按原有动作占用规则释放相应手，避免永远锁成握拳。手指集合使用网格骨索引，兼容身体网格与骨架资产索引不一致。

## 联机与生命周期

沿用身体呈现快照与离散状态 RPC。弓增加片段、时间、播放速度、弦位置、搭箭和持弦状态；服务器仍依据权威装备决定武器族。远端只从装备携带的动画清单解析片段，不接受客户端资产路径，也不传逐骨骼变换。

复制的装备清单使用可复制的数组结构保存弓动画引用。换装销毁旧部件并重建缓存；枪、杖的手指映射在换装时生成，弓仅在采样时间或换片段过渡发生变化时更新来源姿态。新增资产读取均在装备建立阶段完成。
