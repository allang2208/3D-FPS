# M4 裸手 V3：移除腕口结构与皮肤细节素材

用户提供持枪截图后确认：V2 仍有明显的环形手套腕口、手背护垫轮廓，皮肤又过于平滑。因此 V2 未获外观接受；它的保存回执不能视作视觉通过。

## 几何处理

本次没有继续对旧腕口做小幅削平。以原 M4 手型为基础，分别切开腕关节后 4.3 cm 与前 2.7 cm 的边界，移除两侧各 2,607 个旧腕口区域面，再用连续腕部网格连接原前臂与手部。两端沿原切口位置接合，内部 11 圈、每圈 72 个顶点。

手背采用宽范围曲面拟合，去掉护垫和装饰压纹形成的高频轮廓，重新加入浅层原生掌骨轮廓。这个改动覆盖 V2 保守平滑没有解决的部位。

保留原骨架、绑定坐标和动作资产。掌面／指腹的抓握位置沿用原网格；保留面继承原权重，切口顶点使用原表面插值，新腕部顶点沿两端的原始权重插值。**本版腕部拓扑有变化，不能再声称全网格顶点、权重及 UV 完全不变。** 仅皮肤区调整 UV 排布，为新腕部预留区域，衣袖和原前臂 UV 继续保留。

作者源：`SourceAssets/ModularOutfit20260924/OriginalShapeBareM4/RefinedSkinV3`。其中 `refit_authoring.json`、`wrist_authoring.json` 记录制作过程；不代表动画或外观验收。

## 免费皮肤素材

采用作者 Katsukagi 发布的 [Skin Human 002](https://3dtextures.me/2019/01/24/skin-human-002/)。作者 [许可说明](https://3dtextures.me/about/)明确全部贴图为 CC0，可商用。网页标注的免费版为 1K，本次作者公开下载目录实际返回 2048×2048 PNG；下载来源、文件摘要和许可页面保存在 `External/SkinHuman002/provenance.json` 与同目录文件中。

已获取 COLOR、DISP、NRM、OCC、SPEC。实际使用 COLOR 的局部变化与 DISP 的皮纹结构，不把素材称为真实扫描，也不把名为 SPEC 的文件直接当粗糙度使用。材质没有直接套用其橙色；原有肤色和解剖颜色贴图保留，加入适量源细节变化。

## 为什么 V2 毛孔不明显及本版处理

V2 将微细节按约 2 cm 平铺，并在每像素 4–14 个纹理像素范围迅速衰减。在用户截图的手部屏幕尺寸下，这会过早弱化细节。此次加入适合通常持枪视距的浅层皮纹，并保留更细的近景毛孔。

- 8 cm 尺度的 CC0 皮纹高度与本地细毛孔合成为一份厘米高度场。
- 法线、高度和粗糙度按同一高度源制作；颜色细节也使用相同偏移坐标。
- 梯度 mip 采样负责主要过滤，衰减范围扩大到 24–96 纹理像素；粗糙度保留过滤后的表面变化。
- 使用独立皮肤散射配置，将平均自由程参数设为 0.15 cm，并减小散射混合，减少过度柔化的蜡感。
- 仅有界的微高度偏移，没有顶点位移、细分或多步 POM 射线循环。

这是针对当前手部材质的制作调整，没有运行 FPS 测量，不能量化性能收益。

## 制作入口与接入范围

`Tools/ModularOutfit` 下按顺序执行：

1. `acquire_skin_human_002.py`：下载公开 CC0 源并保存来源。
2. `prepare_refined_handshape_m4.py`：手背修形。
3. Blender 执行 `author_refined_wrist_m4.py`：移除旧腕口、连接新腕部并保存可编辑模型。
4. `bake_refined_skin_m4.py`：烘焙新拓扑的皮肤图和细节层。
5. Blender 执行 `finish_refined_skin_blend_m4.py`：保存带材质的制作源。
6. 编辑器关闭时经 `Run-Authoring.ps1` 后台 commandlet 执行 `import_refined_skin_m4.py`；编辑器已开启时使用现有 UE 桥。建立新网格、材质、贴图与 LOD，保存后才发布 M4 配置。

目标目录：`/Game/Characters/ModularOutfit20260924/OriginalShapeBareM4RefinedV3`。仍限于 M4 未装备模块衣服／手套的候选分支。原版战术手套继续恢复旧手模，其他武器未批量替换。

离线模型、贴图及 UE 网格、材质、实例、散射配置和三级 LOD 均已保存。由于编辑器已关闭，本次使用后台 Python commandlet 完成导入；实际保存回执位于作者目录 `saved.json`，构建日志为 `import-background-01.log`。M4 的 `bare_arms_candidate` 已从 V2 更新到 V3，下一次进入游戏时读取。

未打开 UE 编辑器、启动游戏、播放动作、生成验收截图或进行性能测试。后台导入成功仅表示资产制作与保存完成，外观和动作表现交由用户测试。

## 用户反馈后的面朝向修复

用户随后提供橙黑色破面、手臂糊成一团的截图，首次 V3 不可作为可用外观。读取原始资产和导入资产后定位到 `author_refined_wrist_m4.py` 的导出绕序错误：Blender 面已经依据原生外法线统一方向，转换回 UE 的 Y 轴反射足以转换绕序；再次反转三角面，使整套手臂外表面朝向反了。

原 M4／V2 衣袖和前臂的三角面叉积与外法线点积全部为负，失败 V3 的这两部分全部为正。与此同时，已导入 V3 的 20,388 个顶点与制作源位置一致（最大约 0.0000044 cm），UV、材质分区和权重也一致，骨架绑定姿态与原 M4 一致；因此本次修复集中在导出绕序，没有再调整抓握或换骨架。

已修正作者入口，并执行 `repair_refined_skin_winding_m4.py`：反转 37,158 个三角面的索引及对应 UV／法线的角顺序，保持位置、权重、物理 UV、法线方向及贴图像素。失败导出文件与原回执保留于作者目录 `WindingRepair20260924`。

编辑器已有会话且游玩已结束，经现有互斥桥执行 `import_refined_skin_winding_fix_m4.py`，重新生成并保存同一路径的网格、三级 LOD 和材质。保存回执为 `Saved/M4RefinedSkinRepair20260924/import-fixed-01.txt` 及更新后的作者 `saved.json`。未自动进入游戏或生成验收截图，实际效果仍由用户确认。
