# 法袍原地转身：完整腿部与裙摆边缘修订

用户继续反馈原地转圈时腿部缺失、局部腿面穿出裙摆。本轮依据用户截图和现有制作/显示代码修改，未运行游戏复现或追加测试。

## 修改依据

- 旧内搭作者脚本在膝上约 0.4 倍小腿长处裁切全部裤装和腿部皮肤。所谓连续小腿并不包含完整大腿；裙摆抬起、腿部转动后仍可能露出裁切边界。
- 法袍的 `rig_world_covers` 也传给新增内搭分区，导致对应上腿/髋部材质继续被隐藏。完整内搭需要单独遵从裤子、鞋靴和身体自身的覆盖规则。
- 旧材质以顶点到左右脚骨的最小距离计算脚踝保护。换脚交叉时，另一只脚也会让当前小腿退出收束。
- 旧收束在裙摆高度上方 6–8 cm 内仍只施加部分位移；原位置在布面外时，混合结果可能仍在布面外。没有交点时还可能用最小半径的 70% 强行收束，产生错误缩进。
- 旧包络仅覆盖三圈、每圈八点，最高圈在裙摆高度的 75%，不包含腰部；本轮保留完整上腿后也需要覆盖到腰部。

这些是源码与作者几何中的具体缺口，不能据此宣称用户截图中的全部动态原因已经逐帧复现。

## 实现

1. 从原始皮肤、裤装、鞋靴重新派生独立版本，保留完整原生表面、UV、法线和权重。皮肤沿原脚踝线分材质，不裁掉膝上几何、不增加封盖；裤装和鞋靴整体属于下肢，直接继承完整原模型及原有 LOD，仅替换材质，由同一参考姿态遮罩固定脚部，无需人为增加几何接缝。
2. 原始身体分区仍按法袍隐藏；追加的内搭腿部分区只接受身体自身、手套、裤子及鞋靴覆盖，避免上衣再次隐藏腿部。
3. 脚踝保护改用 PreSkinnedPosition 的原生高度，与作者脚踝分界共用计算。左右脚的动态相互接近不再改变另一条腿的收束范围。
4. 包络改为四圈、每圈十六点，共 64 个固定采样，覆盖下摆至腰部。继续沿用同帧布料回写前置及停用布料时的蒙皮回退，不做全网格逐帧转换、GPU 回读或额外布料求解。
5. 高度截面继续使用连接三角面，先按整条带的高度排除无交集区域；边缘过渡在下摆下方完成，布面以上完整施加约束。没有交点时保留原腿面，移除猜测半径收缩。

不改转身 IK、动作、裙摆外观、Chaos 碰撞体或布料参数。世界与本机身体继续共用换装路径，各角色使用自身的布料数据；不新增网络消息或存档字段。
