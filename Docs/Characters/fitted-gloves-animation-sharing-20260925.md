# 贴合手套与动画复用

新增手套、衣袖通常只新增装备模型、材质和外观配方，不复制整套武器动画。现有 `FPSModularOutfitComponent` 使用 `SetLeaderPoseComponent(Source)`，手套读取正在播放武器动作的源手模骨骼姿态。手套自身没有第二套动画状态机。

## 本次制作范围

棕色 `ue_field_gloves`、黑色 `ue_field_gloves_black` 共用一套贴合外形，替换各自 20 个第一人称骨架配置中的旧手套引用。包含枪械、双持左右手、剑、斧、镐、施法和攀爬手模。`Body` 第三人称资源仍用现有版本；第一人称的匹配不代表第三人称骨架也可直接引用同一个资产。

原版战术手套 `ue_original_gloves` 保留原手套及袖子的恢复行为。裸手仍是基础视模默认外观；物品 ID、装备槽、属性、库存、存档格式和已有动画不变。

## 拟合方式

- 使用当前 V7 裸手的手部材质区 2 作为表面母版，包括已经修整的掌形、虎口及腕部过渡。按原顶点对应关系继承各武器的原生蒙皮权重。
- 掌心、指腹厚度约 0.15 mm，外侧约 0.70 mm。手指接触方向按各指节的局部朝向定义，避免弯曲手指仍按整只手的单一平面加厚。
- 腕口沿当前裸手的实际分界，边缘位移为零，6 mm 范围渐变到皮革厚度，附加约 0.25 mm 的浅卷边。手套覆盖整个被隐藏的手部区，腕口边界继承相同坐标与权重。
- ASH12、M16 等不同参考姿态按各自原生绑定变换制作；双持只抽取对应侧。保留源骨架层级、骨长、局部轴、五指权重与握点，不重新用 FBX 往返生成绑定。
- 每个手套资源只有皮革材质区，沿用两种既有颜色材质；构建 3 级 LOD，复用现有装备异步加载和姿态跟随。没有新增 Tick、实时拟合、布料模拟或动画求值。

皮革厚度仍可能影响极窄握把、护圈和双手交叠，实际观感交由用户测试。本轮没有执行动作测试、预览或运行游戏，不能将同权重视为所有姿态均已验收。

## 后续装备标准

| 新增内容 | 需要制作 | 动画处理 |
| --- | --- | --- |
| 同版型换色、换皮纹 | 材质实例及物品配方 | 完全复用 |
| 薄皮手套、贴身布手套 | 母版外形、蒙皮、覆盖范围；生成原生骨架派生网格 | 默认复用 |
| 带护板或厚衬垫的手套 | 优先让护板避开掌心、指腹和指缝，保持接触包络 | 必要时按抓握类别补局部手指修正 |
| 新衣袖 | 拟合肩肘腕、蒙皮和袖口遮挡边界 | 默认复用手臂动作 |
| 会改变操作方式的装备 | 例如不可弯曲的机械手，需独立定义动作合同 | 才考虑专门动作家族 |

工作流为：确定装备版型 → 在标准参考手型上制作 → 复制/局部转移蒙皮 → 按各骨架参考姿态生成网格 → 接入覆盖配置。原生骨架派生的 20 个网格是自动生成的数据，不是 20 套新动画。

新拓扑转移蒙皮时要按左右手、手指和掌腕区域限制对应面，再做三角形重心插值；不能仅用全局最近顶点，把相邻手指的权重互相混入。保持指腹接触包络与腕口共同边界后，再加背侧的缝线、护板或材料厚度。

厚手套若确需调整，用“步枪握把、手枪握把、剑柄、工具柄”等少量接触类别组织局部修正，继承原动作时序；这属于将来按具体装备需要实现的修正层，本次没有新增通用厚手套修正系统。不得按装备 ID 复制全部动作。

动画库主要随武器操作和动作类别增长。若采用每件装备复制全部动作，资源量是“装备数 × 动作数”；多装备组合会使制作/核对成本进一步膨胀。因此模型适配与动作制作分离。复用动画不等于免除装备适配；需要验收时选择握枪、拉栓、换弹、持剑、张掌、极限屈腕等代表姿态，发现局部问题再定位，不重做所有动画。仅在用户明确要求时执行这些测试。

联机时同步装备 ID 和动作状态，第一、第三人称分别取各自骨架的装备网格。两套视角的动画体系可以不同，均不因新增一个外观装备而整套复制。
