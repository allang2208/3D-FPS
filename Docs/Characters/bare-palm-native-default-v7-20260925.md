**用户确认（2026-09-25）**：当前这套裸手、裸臂确定为以后新增动画的开发基准，同时保持为游戏默认手模。后续枪械、近战、工具、施法和攀爬动画沿用该手型及各原生骨架派生；手套作为装备匹配该基准。可执行约定见 [认可的裸手基准](../../skills/ue5-fps-arms-animation/references/accepted-bare-hands.md)。这是用户对基准的认可，不是新增运行测试记录。

## 掌面制作

以已接入的 V6 为母版，局部拟合掌面连续曲面，淡化原皮革衬垫凹槽。每侧调整 667 个顶点，最大位移约 1.57 mm；渐隐到腕部、手指与虎口边界。掌骨权重属于掌面，不再误当作指节保护区。手指握持面、已接受手腕收缩、拓扑、骨骼与所有权重保留。掌面重建连续法线，掌侧解剖法线缩放到 0.58，毛孔物理尺度与高度场维持原值。

源目录：`SourceAssets/ModularOutfit20260925/BarePalmV7/`。`author_bare_palm_v7.py` 制作母版并迁移到 20 个现有第一人称 profile；`save_bare_palm_v7_blends.py` 保存对应可编辑 Blend；`import_bare_palm_v7.py` 导入独立 V7 裸臂资源，尚不改基础视模。

## 默认外观机制

原流程是先显示带手套的武器源网格，再加载裸臂 follower 并隐藏原手臂。预加载只能缩短等待，不能使原始默认网格变成裸手。

本次通过 `bake_native_bare_defaults_v7.py` 将新裸臂写入每个基础视模的原手臂材质区，保留枪剑工具本身的 LOD0 顶点、原骨架、socket、部件材质索引及动画引用。材质区数量和原槽名保持不变，使用顶点 R 区分手掌与手臂，共享统一皮肤材质，避免新增手部槽导致第三人称武器副本露出第一人称手臂。原有 LOD 数量保留并重新构建。

配置 `native_bare_arms=true` 表示源模型已经是裸手；未装备衣服/手套时，外观组件不再加载或创建裸臂 follower。进入游戏、首次切枪与脱下装备均使用基础视模的裸手。

## 原手套恢复与保存边界

每个源模型修改前保存两个恢复来源：`BarePalmV7/OriginalSources/` 中的 UE 资产副本，以及作者目录 `NativeDefaults/Packages/<Profile>.uasset` 中的原始磁盘包。单独抽取原生蒙皮的旧手套与袖子，保存为 `BarePalmV7/OriginalGloves/SK_<Profile>_OriginalGlovedArms`。

原版战术手套物品继续使用同一个 `source_arms` 配方标识，已烘焙裸手的 profile 通过 `original_gloved_arms` 加载这份原手套；旧 profile 继续使用旧恢复行为。普通衣服/手套仍按既有覆盖关系显示。没有物品数值、库存或存档迁移。

基础模型写入必须在 FPSGAME 编辑器关闭后，通过已有批次互斥包装运行，避免修改被另一编辑器的已加载状态覆盖。单 profile 在资产成功保存后更新配置并写回执，可续接中断。
