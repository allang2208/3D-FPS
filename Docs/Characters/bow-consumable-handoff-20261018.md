# 持弓进食、饮水与恢复衔接

## 源码排查发现

- `ConsumableHands()` 仍为弓返回空值，使单手食物、水和药水走备用左臂；弓的显示判断和第三人称显隐又把整个 Consume 状态视为收弓。
- BowArms 的专用骨骼收尾没有调用消耗品层。即使只放开显示，左手也不会拿起食物。
- 消耗品结束前后的展示资格会影响弓的 Stage，可能再次进入 Equip；单手结束缺少交回弓把的独立过渡。
- 第三人称原来全量退出 Sparrow 层。如果简单恢复 Sparrow，原有指型覆盖规则又会把左手的食物抓握覆盖回弓握姿。

## 本次接入

单手使用复用已接入的右手持弓交接。右手接稳后才启动实际使用时钟；不提前吞咽、消耗物品或抛出瓶塞。弓的取食、喝水和施法使用同一个支撑进度，禁止在换手或回握期间同时射箭。

消耗品原有 Layer 恢复段回到实时弓握点，再交还弓。中断单手使用时保留当前左臂局部姿态，以 0.18 秒回握；右手继续支撑，随后反向换手。正常收尾保留原有物品动作时长和接触事务。

双手大羊排继续使用已保存的专用双手食物手模与原生第三人称动作。第一人称沿用装备整体下放/抬回的父节点，弓不再因消耗品占用进入 Stowed 并重播 Equip。第三人称在完整收低后隐藏弓，食物恢复后再抬回；新增同步双手标记、收弓权重与变化率。

第三人称单手饮食保留 Sparrow 支撑弓的右臂，原生 Consume 层继续负责胸部、嘴部和左臂。弓跟随最终右腕；换手等待阶段保留原持弓指型，再按实际 Consume 层权重渐变为食物/水瓶/药瓶指型，收尾反向恢复。之前修复的移动胸部稳定处理保留。
