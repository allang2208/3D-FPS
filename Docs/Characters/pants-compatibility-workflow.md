# 裤装与上衣搭配接入

2026-10-23 起，全部服装的总入口升级为 [上衣裤装腰部工作流](garment-waist-workflow.md) 和 `Tools/GarmentWaist/run.ps1`。本页及 PantsCompatibility 保留为野行上衣／裤腰 guides 的子流程；单独运行它不会补齐其他上衣。

适用当前 Jason 原生身体。用户于 2026-10-22 确认 RealisticCutV3 皮裤接入成功，并要求覆盖所有现有与后续新增裤装。实际制作与发布回执位于 `SourceAssets/PantsCompatibility20261022`。

## 运行时选择

野行上衣按以下顺序选择世界身体和本机可见身体版本：

1. 当前靴型选出的实际裤子网格，在 `pants_mesh_fit_meshes` 中的专用配对。
2. 裤子物品 ID 在 `pants_fit_meshes` 中的配对（兼容既有配置）。
3. `pants_fit_default` 中的通用深扎腰版本，覆盖尚未生成专用配对的新增裤装。

未装备裤子时恢复正常下摆。已有换装异步加载、完整外观切换和原生 Leader Pose 保持；无新增逐帧网格扫描或碰撞解算。武器第一人称手臂不使用身体配对网格。

蓝色法袍优先使用 `underlayer_meshes` 内的原生裤装适配。未登记的新裤型使用 `pants_underlayer_default`，按所穿靴型选择完整腿部的通用内穿版；避免原始宽裤直接进入裙摆。专用内穿版仍保留自身材质与款式，通用版本只承担被法袍遮挡时的回退。

## 新增或重做裤装

1. 完成原生绑定、材质、普通裤型和实际需要的靴型，保存 UE 资产后按字段接入 `modular_outfits.json`。保留其他物品及身体配置。
2. 从工程目录运行 `Tools/PantsCompatibility/run.ps1`。它自动枚举槽 15 的物品与全部 `shoe_fit_meshes` 分支，读取保存的原生网格，按真实裤腰形状和绑定生成上衣配对。相同裤腰共用产物；变化的腰型生成新修订。
3. 只有资产保存完成后才写入配对引用。法袍专用内穿版应沿已有 NativeFit 与裙摆可见性材质流程制作；未提供专用版时，运行时保留通用内穿回退，不把普通宽裤作为回退。
4. 新增其他身体骨架，或重做野行上衣本体时，先提供对应的作者源和原生绑定，再扩展该流程；不把 Jason 的形状、尺寸或蒙皮直接套到另一个身体。

`-AuthorOnly` 只准备作者源；它不表示资产已经导入或接入。重复运行会沿用未变化的裤腰配对；修订适配算法时应在独立修订目录重制受影响组，而不是覆盖已认可的其他组合。

## 当前制作覆盖与边界

本轮清单包含蓝色法师长裤、ST6 战术长裤、烟灰七分裤、写实皮裤、锁子甲裤、牛仔裤、工装裤，共 7 类、22 个唯一穿戴网格。靴型的腰部只有相同形状和绑定才共用配对。用户已认可的皮裤组合直接复用。

牛仔裤和工装裤按倾斜腰线处理：统一低位开口保证搭接，前侧和侧面仍读取自身高度的裤腰截面。通用扎腰版从当前裤腰内侧共同包络派生，保留更深搭接。

此流程提供新增裤装的默认覆盖与离线适配入口，不将任意未来极端低腰、异形或另一骨架自动视为已验收。仍遵守用户规则：后台制作、构建和保存，不自动启动游戏、截图、回归或验收。仅用户明确要求时进行相应检查。
