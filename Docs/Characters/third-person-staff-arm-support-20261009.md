# 第三人称法杖整臂支撑修正

> 这是对应阶段的制作记录。当前接入、替代关系和恢复依赖以[第三人称动作发布说明](../Publication/ThirdPersonActions20261010/README.md)为准；旧手工抓握表及被否定的腕臂姿态不作为当前基线。

用户最新截图继续否定持杖手臂：肘部过度收拢，上臂与前臂的轮廓挤在一起。本次处理肩、肘、腕支撑与辅助骨，保留此前复用的第一人称抓握手型及空闲左手闭拳。

## 修改

- 原普通持杖目标固定在身体组件坐标 `(-27,29,128-40*Crouch)`。新目标使用实时右肩位置，加身体组件空间偏移 `(-18,32,-16)*PoseScale`：握点位于肩部外侧、前方、下方，随原步态肩部和蹲伏高度移动。上臂与前臂继续按原生骨长解算，不缩放骨段。
- 原 `FitStaffArm` 最后只覆盖上臂、前臂、手腕主骨。现在在缓存骨架时收集右臂的 twist、corrective、bicep/tricep 等辅助骨；主骨解算后，以原生局部绑定按父子顺序重建它们的组件变换。避免用普通步态的辅助骨偏移配合已重新求解的持杖主骨。
- 辅助骨列表排除手腕和所有手指后代。右手抓握、拇指、掌骨以及法杖在掌中的挂接关系沿用现有第一人称复用；没有改手套网格、材质、指节长度或武器属性。
- 施法、挥杖仍使用既有动作与时序，最终整臂辅助骨处理共用上述路径；左臂动作及副手装备继续由原动作层接管。

参考 `skills/ue5-fps-arms-animation/references/staff-grip-camera-space.md` 与 `grip-arm-refinement.md` 的完整骨段、原生绑定及肩肘支撑方法。截图中的具体变形原因尚未经过本轮游戏运行确认，代码修正与视觉验收分别记录。
