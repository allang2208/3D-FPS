# 裸手 V9：M4 样板（2026-10-17，待用户体验）

用户要求针对现有裸手解决三件事：去除错误纹理和线条、表面过于光滑不像人类皮肤、手腕和肘部关节凹凸不对。检查结论与方案见本次对话；用户选择"自然写实、修形加弯曲矫正、先在 M4 上一次做完、不出对比图"。本文记录 M4 样板的实际交付。其他武器保持 V8 原样，推广等用户认可后再做。

## 检查发现（摘要）

- **线条**：
  - 手和前臂在腕上约 4.5 cm 处是两块网格拼起来的：交界有几何折痕（相邻面夹角中位数 7.2°，前臂其他地方 2.5°），法线断开（平均 5.6°、最大 11°），两侧材质也不同。
  - 肘上方 V6 上臂接合处同样有一圈折痕，肘部前侧还有几处几乎对折的细碎三角（夹角 175°）。
  - G18、Pit Viper、HK416、RSH12、LMG201、斧、镐等由 FBX 导入的武器，UV1–3 里存的皮肤坐标是坏的（V 被翻转两次或错层），细节会被拉成条纹。10-10 修过，随 MPFB 一起被回退。本样板不依赖这层坐标，其他武器推广时再修。
- **太光滑**：
  - 原手部贴图是程序平涂；前臂、上臂只有一个固定颜色，没有法线细节。
  - 唯一的毛孔层被历轮"清理"压到原强度的约 12%（倾斜上限约 3°），颜色细节约 1.4%，次表面散射强度 0.10。
- **关节**：
  - 前臂截面接近正圆；腕部在最后 3 cm 突然收紧，像袜口；没有尺骨头、肘尖等骨性起伏。
  - 线性蒙皮下，肘窝会捏褶，手背折硬褶。
  - 腕部旧交界处权重梯度有折点，一弯腕就折出一道棱。

## 改了什么（只改 `/Game/Weapons/M4HK416Replica/SK_M4_FoldingSights_HK416`）

1. **静止形状**（`geometry.py`）：
   - 腕部旧交界、肘上接合两圈做有界抹平（最多 1.5 mm），两圈折痕中位数从 5.6° 降到 3.2°。
   - 肘部对折细碎三角展开（最多 1.2 mm）。
   - 前臂截面改为近端略椭圆、向腕部逐渐变扁（近端宽深比约 1.1，腕部约 1.45），不改变截面面积。
   - 加入尺骨头、桡骨茎突、肘尖、肘两侧骨突和四个指节的轻微隆起。
   - 单点移动最多 3 mm，静止姿势没有翻面。
2. **法线**（`normals.py`）：没动过的顶点保留原法线；移动过的顶点按几何变化旋转原法线；两圈旧接缝附近直接用平滑后的几何法线，接缝两侧完全一致。
3. **权重**（`weights.py`）：
   - 只在两圈旧接缝 ±2.2 cm 内做邻域平均，去掉权重梯度的折点。最大改动 0.064，骨骼集合和每顶点权重总和不变，带外不动。
   - 弯腕 40° 时，接缝处的局部起伏从 0.075 cm 降回 0.035 cm（与静止时相同）。
   - 这一项不是重新分配前臂权重，和 10-11 被否定的 Super90 权重方案不同。
4. **新 UV0**（`blender_unwrap.py`）：
   - 沿原有岛边界重新展开、重新排布。手和前臂约 57 texel/cm（原来 33–40），上臂约 36。
   - 左右不再共用，也没有重叠。UV1–3 原样保留。
5. **自然写实贴图**（`fields.py`、`blender_bake.py`，4096）：
   - 颜色：手背和前臂背侧略深、掌心和前臂内侧偏浅偏粉；指节、指尖、肘尖偏红；有低频斑驳、稀疏的小斑点，静脉带轻微冷色；指甲、甲半月、甲缘分别着色。
   - 起伏：
     - 手背静脉网、前臂浅静脉、伸肌腱、拇长伸肌腱、腕掌侧肌腱，都做成宽而柔、时隐时现的形态。
     - 指节背侧皱纹、手指掌侧屈纹、指根纹、掌纹（沿用原贴图的掌纹遮罩）、腕横纹，以及肘后不规则皱纹和肘窝浅纹。
     - 全身连续的皮纹沟（约 0.8 mm 一格，掌面更细）和毛孔。
   - 遮罩：遮蔽、粗糙度、凹陷、透光量。
   - 所有特征按三维位置生成，用平滑权重过渡，不按网格分区切换，所以旧接缝上不会出现颜色或纹理跳变。
6. **材质** `M_M4SkinV9` / `MI_M4SkinV9`：
   - 全部从新 UV0 采样，不再用三向投影，也不读 UV1–3。
   - 次表面散射强度 0.70（原 0.10），新散射配置 `SSP_M4SkinV9` 的平均自由程 0.25 cm（原 0.15）。
   - 高光按凹陷遮挡，透光量在指甲处降低。
   - 可调参数：`NormalStrength`、`RoughnessScale`、`RoughnessOffset`、`SkinSpecular`、`CavitySpecular`、`AOStrength`、`ScatterStrength`、`SkinTint`。
7. **弯曲矫正**（`correctives.py` + `FPSArmJointCorrectiveComponent`）：
   - 每侧 7 个矫正形状：肘部 75°/110°/135°，腕部屈伸各 40°、桡偏 20°、尺偏 35°。
   - 目标做法：肘外侧和两侧在线性蒙皮基础上叠加 Delta Mush（保留静止时的细节）；肘窝和腕部受压的一侧只做褶皱松弛；肘部屈曲时肘尖更明显。
   - 运行时组件每帧按上臂与前臂夹角、以及手在 `lowerarm_twist_01` 坐标系里的偏摆设置权重，所以旋前不会被当成弯腕。偏摆超过约 95° 的非生理姿势会把腕部矫正淡出。
   - 只作用于带 `JC_` 矫正形状的网格。控制台 `fps.Arms.JointCorrectives 0` 可整体关闭。
8. **动画扭转检查**：M4 的待机、开火、换弹、上膛、垂直握把、冲刺动画中，`lowerarm_twist_01` 承担约 100% 的手部扭转，`twist_02` 承担约 50%，分配正常，没有改动画。

## R2：左手细小漏洞（2026-10-17，用户实机反馈）

用户截图：左手掌心有细小的黑色漏洞，手模没有贴合。逐帧蒙皮排查后确认，皮肤是单面材质，凡是相对自身顶点法线翻过去的三角面，都会被背面剔除，看起来就是针孔。V8 只按绕序检查翻折，查不出"绕序一致、几何上却折回去"的情况。这次找到四个来源：

1. **静止形状本身就有折回**：左右拇指根掌面各 5 个面，是 09-25 补片留下的。V8 和第一版 V9 都在，截图里掌心那个小黑点就是这里。
   - 已在静止形状里局部展开，最多移动 1.1 mm，这里改用几何法线。
   - 肘窝前侧几处几乎对折的细三角也同样处理，并改用几何法线。
2. **握枪时指根掌侧会折穿**：M4 握持时，中指、无名指、小指的掌指关节比绑定姿势多弯 20–55°。原线性蒙皮下，左手指根掌侧有 6 个面翻转。
   - 单根手指的关节矫正形状试过，四指一起握时无效，已放弃。
   - 改为按持枪姿势做矫正形状：取左右手的 `A_AKM_idle`（待机、瞄准、开火、上膛共用这一握姿）和左手垂直握把待机。在完整姿势下、其他矫正形状按运行时权重叠加之后，展开整条手臂上的全部翻折，再还原到参考姿势。
   - 新增三个矫正形状：`JC_Grip_L_6_19_41_52`、`JC_Grip_L_48_48_48_48`、`JC_Grip_R_0_52_55_54`。
   - 运行时按四指掌指关节相对绑定多弯的角度做径向基匹配（σ = 12°），示例角度直接写在形状名里。
3. **持枪时左肘伸直到约 27°**（绑定姿势 39°），肘窝有几个面会翻。新增伸直矫正 `JC_ElbowFlex20_L/R`，只展开翻折。
4. **矫正形状自己造成的翻折**：每个矫正形状在生成后都会做翻折检查和局部松弛，保证它在自己对应的姿势下不留翻折。

**结果**：对实际动画逐帧计算，统计整条手臂相对顶点法线翻过去的面（每侧，括号里是游戏里原来的数量）：

| 动画 | 左臂 | 右臂 |
| --- | --- | --- |
| 待机 | 0（27） | 0（19） |
| 垂直握把待机 | 0（23） | 0（19） |
| 瞄准 | 2（25） | 0（19） |
| 开火 | 2（29） | 3（21） |
| 换弹 | 7（27） | 0（20） |
| 空仓换弹 | 29（39） | 0（20） |
| 战术冲刺 | 6–10（16–27） | 2（18–22） |

换弹、冲刺和右手上膛（13）都是过渡姿势，还有残留，没有为它们单独加持枪姿势：只按四指角度匹配时，这些帧会和其他握姿混淆，上一轮试过反而让垂直握把待机变差。

已撤销第一版 V9 的写入，从 `Before/` 的 V8 原包重新写入，共 19 个矫正形状；写入后读回，位置误差 4e-6 cm。运行时组件新增肘部伸直矫正和持枪姿势矫正的驱动。
