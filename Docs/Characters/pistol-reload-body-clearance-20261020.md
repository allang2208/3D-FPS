# 单持手枪第三人称换弹：躯干穿入修正（2026-10-20）

用户反馈单持时左右主握换弹都会进入身体，明确要求排查、优化，并保存关闭 UE 以继续正式构建和后台骨骼／模型检查。本轮按手臂技能的全身表现规则处理：保留第一人称动作、机械接触与业务时钟，修正第三人称的整组握持和操作臂。

## 实际问题

旧版只约束两手是否同时够得到，未约束真实躯干表面。上一轮 1,700 项挂接／接触检查不能证明不穿身。本轮隔离夹具运行真实原生动画图，对当前 Jason 身体蒙皮与世界枪械取样，复现以下问题：

- 右主握同时叠加通用 `Pistol.Reload` 上身动作和原生手腕动作，肩部又被通用层带向身后。
- 第一人称取弹轨迹直接迁移到全身后，操作手会经过腹部／胸部；两手共同可达的平移还可能把枪和手拉回身体内。
- 左主握时，右操作臂沿外下方弯曲会让前臂横穿肋部；仅修腕点不足以修正肘部及扭转辅助骨。

修改前记录在 `SourceAssets/PistolReloadBodyClearance20261020/before.json`。该文件的几何记录是基线，旧检查器尚未将穿入深度加入失败断言，不能把其退出码 0 解释为无穿模。

## 修改

1. 单持手枪换弹由原生动作和双手接触层统一控制，不再叠加通用换弹上身层。普通装备、真正双持和其他武器的动作入口保持原有归属。
2. 对源动作中前后间距过大的双腕，连续转动整个枪械／双手接触组；保留双腕距离、掌向相对关系、手指和机械骨，限制转向幅度。前握把让支撑手过度前伸时也会把主握手挤回胸前，不能只限制向后取弹。
3. 在当前躯干坐标中保留前方空间，再让两个腕点同时满足原生手臂可达范围。长伸出的弹鼓等部件提出不可达的避让平面时，取双臂可达交集最靠前的位置；不再退回未避让的内侧解。没有拉长骨骼或使用负缩放。
4. 操作肘优先向身体前方弯曲；按原生绑定重建操作臂滚转和扭转／修形辅助骨，保持已经求得的腕部接触。
5. 使用当前世界武器的枪根／枪口及可见附件包围盒角点，约束整组枪械的空间。该数据跟随已经接受的机械姿态和挂点，以值数组交给动画线程；不新增网络字段，不读取相机位置。
6. 几何探针仅由显式 commandlet 参数运行，不在游戏每帧计算网格碰撞。已有其他武器的双臂可达求解规则保持原样。

当前身体配置是 `/Game/Characters/ModularOutfit20260924/JasonPlayer20261003/EquipmentFit20261003/SK_Jason_Base`。其基准躯干前表面相对 `spine_03` 约 10.54 cm；腕部前方平面为 26 cm，枪根／枪口／附件角点平面为 16 cm，并随实际身体姿态和比例变化。这是当前人物的适配值，不是其他骨架的通用标定。

每种配置均覆盖左右主握。快速检查为基础五枪、站立；完整检查增加蹲姿和配件配置，以中立视向采样表中代表性源片段。

探针使用实际求值后的蒙皮顶点，测量左右前臂／手部、可见枪械材质段和可见静态附件进入躯干表面包络的深度，同时记录双腕接触误差。躯干包络由 8,214 个原模型三角面构成；穿入失败阈值 0.2 cm，接触误差阈值 0.5 cm。

这不是布料、上臂／肩部、头部／腿部的完整碰撞检测，也不是连续播放或联机验收。没有打开 UE 界面、运行 PIE 或截图；自然度、收势、移动／转向换弹和衣袖表现仍由用户实机确认。

## 最终后台结果

`after-final.json`：10 种配置 × 左右主握，104 个动作／姿态组合，每组 41 个采样，共 **4,264 个姿态、652 项检查、0 失败**；commandlet 退出码 **0**。

| 测量 | 修正前五枪基础站姿最大值 | 最终全部配置采样最大值 |
| --- | ---: | ---: |
| 右前臂／手部进入躯干 | 7.167 cm | 0 cm |
| 左前臂／手部进入躯干 | 14.647 cm | 0 cm |
| 可见枪械蒙皮进入躯干 | 11.894 cm | 0 cm |
| 可见静态附件进入躯干 | 基线未记录 | 0 cm |
| 双腕接触位置误差 | 约 1.35e-13 cm | 约 1.42e-13 cm |

“0 cm”只指上述真实蒙皮采样对躯干包络的结果。前后采样集合不同：基线为 504 个基础站姿，最终为更密并包含配件／蹲姿的 4,264 个姿态。

中间回执保留作问题定位：`after-03.json` 的 504 个快速采样通过，但完整 `after-full.json` 仍有 25 项失败；不能再以少量关键帧代替配件和更密采样。增加枪体空间后，`after-full-04.json` 仅剩 G18 弹鼓两项失败，最终通过可达交集最前方解消除。

正式 `FPSGAMEEditor Win64 Development` 构建成功（`build-fix-editor-05.log`，45.25 秒），`FPSGAME Win64 Development` 构建成功（`build-game-final.log`，53.03 秒），均退出码 0。较早的 `build-fix-editor-04.log` 因用户重新打开的 UE 占用正式 DLL 链接失败；用户保存关闭后已完成链接和后续最终构建。
