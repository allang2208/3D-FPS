## 本次排查发现的形变风险（修复前快照）

对每个条目选取“当前避让造成肘点位移最大”的采样点，计算当前衣袖三档 LOD 的边长与拉伸。它不是逐帧全网格碰撞检测，不能把增幅直接解释成可见穿模。

1. **M16 装备约 0.452 s，右肘混合权重区**：原装 `A_M16_equip_charge` 与握把派生均出现拉伸增加。最大边长倍率从源姿态约 **3.395 升至 4.925**；定位到 LOD0 边 `[2400,2792]`，参考长 0.169 cm、修正后约 0.834 cm。这是局部蒙皮拉伸，不是整条手臂伸长 4.9 倍。右肩原在相机后方约 9.8 cm，避让仍以约 0.627 的权重下移肩点，肘点位移最大约 13.5 cm。检视、快速近战及部分弹鼓空仓条目也有较小增幅。优先继续定位误触发与关节体积。
2. **LMG201 部分握把近战及弹匣空仓换弹**：近战代表样本最大拉伸约 **2.279 → 3.150**；Magazine24 空仓代表样本约 **2.103 → 2.687**。属于右肘附近的定向复查项，尚无实机可见性证据。
3. **SVD 空仓换弹约 1.297 s 的动作展示构图**：最大拉伸约 **1.670 → 2.188**。与之前插匣后左肘锁直的时段不同。初轮仅按腰射锚点计算，本轮补上动作展示锚点后发现此项；不能将“左肘回握恢复”推广成整段换弹无其他形变。

M4 目录中的一个拉伸增幅条目属于 `M4ContactImpactFinal/A_M4_HK416_reload`，当前基础换弹路由使用 TacticalTossFinal，故不把旧目录的对照动作列为已确认的当前 M4 故障。
