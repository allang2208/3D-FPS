# 第三人称双持手枪：独立持握与身体相对动作 V1

用户反馈第三人称枪械脱手，左手尤其明显，右侧仍像双手持枪；要求参考第三人称已有处理经验，避免镜头牵引手臂造成穿模或错位。

## 来源与修改范围

双持制作源 `SourceAssets/PistolDualWield20260914/author_dual.py` 为左右侧分别制作真实解剖手臂，左侧使用 `hand_l`。此前第三人称 `CaptureEquipment` 却把两侧都绑定到 `hand_r`，使左枪的握点、指形和机械姿态以错误的手为基准。普通双持身体还使用 `Pistol` 单持动画族，动作腕点则直接来自第一人称世界变换。

| 路径 | 本次处理 |
| --- | --- |
| 双持右枪 | 原生 `hand_r` → 身体 `hand_r`，独立握姿、射击与动作进度 |
| 双持左枪 | 改为原生 `hand_l` → 身体 `hand_l`，同步手型、枪根及配件 |
| 法杖副手枪 | 同一左枪资产入口同步改用 `hand_l`，保留主手法杖层 |
| 双持站姿与移动 | 使用既有 `Unarmed` 对称移动基底，再分别适配两条持枪臂；停用单持手枪的双手拔枪／换弹上身层 |
| 待机与瞄准 | 每把枪从自身原生待机握点缓存掌向，目标以各自肩部为起点；瞄准旋转整个肩前持握组，无相机位置输入 |
| 走跑与射击 | 共用身体步相，左右错相摆臂；后坐读取各手实际开火时间 |
| 拔枪与换弹 | 沿各手执行器的进度采样既有动作，仅传原生持握起点的相对变换，不传镜头空间绝对腕点 |
| 快速近战 | 沿原动作主攻侧、时钟与收尾转枪，机械旋转保留在相应枪与手的相对层 |
| 手臂与衣袖 | 复用法杖／书本的原生肘平面、前臂滚转和腕部限角处理；肩前空间、骨长和辅助骨一起适配 |
| 枪身与改造件 | 同步存为各自握持手的相对姿态，避免分别插值逆腕矩阵与绝对机械骨导致漂移 |
| 施法与消耗品 | 保留原动作优先级与副枪隐藏；双持左手施法走身体相对的施法／回位，消耗品继续接管自己的手臂 |
| 装备切换与远端快照 | 握点和坐标版本纳入外观缓存及 schema；手型／动作样本随本枪实例和机械姿态匹配后使用 |

## 实现与资产

新增 `FPSBodyPistolMotion.h`、`FPSBodyPistolPose.inl`，其余改动位于身体装备、动作采样、动画实例、共享整臂修正和表现样本注释。每枪的握持方向在装备时缓存，动作线程不加载资产、不读取镜头或移动角色。

本版复用现有双持原生手枪动作、Jason 骨架和移动片段，没有新导入动画包。共用入口涵盖当前双持组件加载的 M1911、DW715、RSH12、G18、Pit Viper 及混搭；这是代码接入范围，不代表逐枪观感验收。第一人称动作、开火与换弹事务、伤害、弹道和弹药结算沿用现状。
