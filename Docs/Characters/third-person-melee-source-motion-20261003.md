# 第三人称近战动作缺失修复（2026-10-03）

用户反馈第三人称使用近战武器时几乎看不出攻击。本轮修复动作来源及身体联动，沿用现有已导入动作与 Jason 骨架，不改伤害、命中范围、攻速或第一人称动画资产。

## 源码中的缺口

1. 剑的世界装备没有 `PoseFamily`。实时动作采样遇到空家族且不是检视时直接跳过，因此普通攻击、重击、突刺等都没有获得正在播放的双腕、手指与武器姿态。
2. 原身体层主要使用空手行走/待机，再用通用手腕曲线表现近战。普通横斩、突刺、柄击、重击缺少配套的胸腰发力和步伐；动作状态枚举存在不代表动作制作完整。
3. 剑的长握柄作者差量没有交给世界装备的待机消费者，静态握距与真正源动作可能不一致。
4. 法杖普通攻击没有进入实时腕部驱动，其身体接触阶段也未使用法杖自身的接触常量。

以上是本次源码定位结果。没有启动游戏复现，不能据此宣称已覆盖用户画面中的每一个问题。

## 接入方式

- 显式标记 `Sword` 家族，保留源网格的实际握姿配置。剑和斧/镐直接采样原执行器完成后的双腕、五指和握柄关系，包含普通挥砍、连击、蓄力/释放、突刺、柄击、冲刺下劈、既有上挑、旋转和格挡/恢复；不另起一套攻击时钟。
- 以每件装备应用握姿配置后的待机姿态作为轨迹参考，将实际手腕位移映射到第三人称胸前的准备姿态。保留源旋转和双手相对握点，剔除第一人称眼位和相机反馈造成的整体偏移。
- 主手按身体原生骨长求解后，副手从主手实际达到的位置及源握距推导。世界剑体和模块配件沿同帧握点连接；指骨只转换姿态，继续保留目标骨长及参考缩放。
- `FPSBodyMeleePose.h` 添加与源接触阶段同步的胸腰扭转、肩部前送、屈膝和跨步：正反横斩方向相反，重斩加大发力，突刺前踏，柄击短促前送，下劈加载再压重心，上挑先沉再起。旋转沿用角色真实旋转，不叠加第二次整圈旋转。
- 攻击期间保留脚底高度修正，释放站定脚锁和原地转步，避免新跨步被地面锁脚抵消。腾空和翻越仍沿用原本的动作优先级。
- 法杖普通攻击读取实际右腕，并使用 `StaffPrimaryAttackMotion` 的接触/收势比例。铲子现有程序动作继续使用身体轨迹与握柄，不新建回填动作。

## 后续约定

新增武器家族时同时接入装备身份、动作采样、动态握点、手指、身体发力及相应联机表现。不要将“未声明家族”当作“无需动作”的默认值，也不要把普通待机握姿作为完整攻击姿态。

手腕轨迹、武器姿态、配件和指节必须来自同一帧。跨第一/第三人称转换以待机握点和角色瞄准坐标为基准，不将第一人称眼前坐标直接用作全身手腕位置。
