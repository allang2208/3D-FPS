# 钢甲护手覆盖重做

历史阶段：本页的长翻边、固定指根罩随后因弯指和换弹穿插而被替换。当前结构、动作修正与落盘范围见 [小拇指关节重构](steel-gauntlet-articulation-plan-20260928.md)。

用户反馈：甲片过窄、间隔过大，看不出装甲手套。旧版指背宽度按手指半径的 0.60 倍展开，指节前后合计空出约三分之一长度；腕部还留有明显皮革带。

本轮制作调整：

1. 将五指的小矩形片改为沿真实皮革外形拟合的弧形硬壳，横截面覆盖指背与上侧面，张角约 152 度。指腹继续保留皮革。
2. 指甲壳由指骨长度约 2.5% 处起，非末节延伸到约 98% 并带向内收的圆弧关节罩；末节采用收拢的指尖壳。关节采用内外搭接，不再留大块裸露指背。
3. 四个指根增加圆弧护罩，后裙沿手背主甲拟合并随 hand 骨骼运动；拇指掌骨增加朝外偏转 42 度、展开 76 度的短侧护甲，只覆盖该骨段约 24% 至 84% 的范围，保留虎口活动区。避免该段背面护甲钻入主甲边缘形成尖片。
4. 护腕加长，并增加随手腕运动的腕部搭接甲，补上原先的大块皮革空白。
5. 保留钢材拉丝、边缘抛光、刻线、铆钉和独立钢材图集；保留原生皮革内衬、各片单骨骼刚性权重、既有物品 ID 和动作。重新制作实际模型图标、掉落模型并派生全部 22 套原生装备。

旧版源文件与贴图备份：`SourceAssets/MetalGauntlet20260927/SteelGauntletV1/FullCoverage20260928/Before/`。

仅进行后台制作、烘焙、导入和保存。游戏握持及动作效果交由用户测试，不将构建或导入成功称为运行验收。
