# 第一人称袖口与手套腕部覆盖（2026-09-29）

用户报告锁子甲与棕色露指手套组合，在弯腕持枪时袖口可透见背景。
当前衣服通过 profile.shirt_covers=[0,1] 隐藏整个前臂材质区；手套使用自己的皮肤伴随网格。原袖口相对裸手分区只有约 4–6 mm 轴向搭接，不能保证变形后的腕部底面仍存在。

本次制作把原生基底中手腕后方 8 cm 范围内的前臂三角面分配至独立 WristUnderlapSkin 材质段。整个边界三角面一并保留，避免裁切产生新开口。该段复用前臂皮肤材质，保持原坐标、权重、UV 和法线；衣服仍隐藏其余上臂／前臂，手套仍按自己的覆盖配方隐藏手部。保留在袖内的原生皮肤作为底面，随同一骨架运动，不增加逐帧处理，也不改变锁子甲小幅摆动或武器动作。

- 制作入口：Tools/ModularOutfit/build_wrist_coverage.py。每份当前原生基底及露指手套皮肤伴随网格复制至独立 WristCoverage20260929 目录，重建三档 LOD 并保存。
- 发布入口：Tools/ModularOutfit/publish_wrist_coverage.py。全量保存后才精确更新 profiles 的基底路径及手套 skin_meshes；不修改衣服、手套实体、材质外观、物品属性和存档。
- 作者计划、保存回执和发布记录：SourceAssets/WristCoverage20260929/。
- 仅作用于第一人称；第三人称 Body 的材质分区和衣服版型另有合同，不套用本次腕部规则。

## 后续衣服及手套接入合同

新长袖沿用活动 profile 基底，shirt_covers 不得包含 WristUnderlapSkin 段。新增独立手套皮肤伴随网格时，同样保留该段；不要恢复早期整段隐藏的基底引用。材质索引因皮肤／皮革槽数量不同而不同，应依据槽名处理，不能假定固定为 3 或 4。

袖口和手套仍需自身具备内壁、端面、搭接与匹配的蒙皮；此保留区补充袖口内部的身体连续性，不替代具体版型制作。原裸手资产保持不变；裸手状态继续使用原默认基准。新装备用活动配置为输入，不重跑早期注册脚本覆盖已经发布的基底。
