# 法袍与宽松裤装：独立内穿版

用户确认完整腿部修订改善了原地转身，但换成锁子甲等宽裤后仍会穿模，并询问是否可以直接不渲染膝盖以上。

## 采用的处理

固定隐藏膝盖以上能消除该区裤面穿出，但不能处理宽小腿或靴筒；裙摆抬起时也可能再次露出裁切断口。当前下摆已经有动态覆盖，继续给每种宽裤扩大裙摆或碰撞体，会把装备兼容问题转成裙摆造型和布料稳定性问题。

本轮采用法袍专属内穿裤型：穿法袍时，原始宽松裤型不参与角色显示，改用同材质、同骨架的贴体版本；脱下法袍后仍显示原装备模型。装备身份、属性、图标、掉落外观和库存不变。

现有目录共 22 条裤装基础/鞋靴适配路径：ST6 长裤四条、七分裤两条、皮裤三条、锁子甲三条、牛仔裤三条、工装裤三条、法师裤四条。只更换这 22 条法袍内搭引用，皮肤与六种鞋靴的现有映射不变。

## 制作方法

- 以当前原生身体的真实三角面截面确定贴体轮廓。作者阶段按高度和角度采样，左右腿各从自己的腿骨轴向外求交，不把两腿之间空隙当成腿部体积。
- 裤装各局部截面整体收束到身体外约 3.5 mm，尽量保留锁子甲、金属与内衬的层次；孤立突出细节也受同一贴体轮廓约束。不是对所有裤子套同一个整体缩放比例。
- 保留完整腿部和原始拓扑、UV、材质槽、骨骼权重；没有膝上裁切或脚踝封盖。裤脚底部约 1.5 cm 固定，向上约 6 cm 平滑过渡，按原生身体比例换算，以保留各鞋型衔接。
- 修改原始 DynamicMesh 的顶点位置，重建法线、切线和三档 LOD。保存为独立版本，原装备资产不改写。
- 保留上一轮同帧 64 点裙摆覆盖材质作为第二层约束。此次贴体制作全部烘焙进资产，不新增运行时碰撞、逐顶点 CPU 处理或网络消息。

这项修改消除的是宽裤额外体积对法袍的影响，不能把它表述为所有布料折叠、靴筒和极端动作都已零穿模。实际转身、楼梯及联机观感由用户试玩确认。

## 制作入口

`Tools/BlueMageRobe/author_underrobe_fit.py` → `save_underrobe_fit.py` → `publish_underrobe_fit.py`。

作者输入使用 `TurnLegContinuity20261020/inputs.json` 的完整原始源；新增或重做裤装时先运行 `capture_hem_sources.py` 更新来源，再制作内穿版。现有来源通过散列复用，避免把此前已经裁过或收束过的内搭作为新源而反复收缩。

`SourceAssets/BlueMageRobe20261018/UnderRobeFit20261020/` 保存作者位置、原生身体来源、每种裤装的制作参数、资产保存回执和目录切换回执。UE 保存每批最多四件，并按源散列续接；全部完成后才切换目录。通用法袍发布入口保留现行内搭映射。
