# 户外工作套装制作记录

用户已认可设计方向，并指定上衣名称为「工装夹克」。本次范围为新增夹克、精修现有野行奔尼帽，将工装裤、系带皮靴、厚皮革手套、野行奔尼帽和工装夹克接成五件套。

## 造型与表面

夹克使用灰卡其油蜡帆布、棕皮肩肘补强、蓝色加固线和黄铜扣。几何包含有厚度的胸袋与袋盖、门襟、斜插袋口、肘片、袖口、后背活动褶和腰侧扣带。各物理表面由原创高度场生成 BaseColor、Normal、ORM，保留离线高度源；法线为 OpenGL，UE 导入翻绿。旧四件原有单件数值保持。

奔尼帽采用软布帽冠、较窄且有自然起伏的帽檐、多圈压线与裁片接缝，保留内汗带、棕皮帽带、黄铜扣气眼和后收帽绳。原头部连接基准保留；Jason 和 Kaitlin 分别沿其原生头部适配。后檐沿既有有限角度弹簧，不新增整帽布料模拟。

## 穿着与配对

穿法为外穿夹克加内层扎腰片。按法师裤、ST6 裤、七分裤、锁子甲裤、牛仔裤、工装裤和皮裤的腰线生成七组，外摆搭接约 3.4 cm，外层留约 0.65 cm 余量，内层向裤腰内侧留约 0.45 cm。扣带及衣摆按裤腰高度同步移动。每组包括世界身体与本人低头身体；Kaitlin 使用其原生骨架与已存在的身体表面对应场派生。武器第一人称衣袖复制活动原生衣袖、替换本套材质，保留已有几何、绑定和动作。

新裤型或身体不能仅复制旧配对键：先刷新实际腰部作者源，重制受影响配对，保存后才更新路径。`Tools/GarmentWaist/policies.json` 登记专用外穿流程；不能将夹克送入普通短衣裁切器。

通用腰部流程遇到新增或变更裤装路径时，会要求先刷新该外穿夹克的专用作者配方，不能跳过夹克后仍将整批认作完成。当前 `WorkwearSet20261024` 为冻结修订，变更裤型须新建生产修订并更新实测腰部源。

夹克短于原野行长衣，不继承原款对下腹／髋部 7、10、14 分区的遮盖；这些部位由裤装管理，卸下裤子仍保留原生身体覆盖。
