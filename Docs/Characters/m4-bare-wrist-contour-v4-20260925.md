# M4 裸手 V4：腕部收形

用户已认可修复朝向后的 V3 进展，本次只处理截图中手掌与前臂近乎等粗的问题。基于 `RefinedSkinV3` 已修正绕序的作者数据制作独立版本，保留 V3 以便恢复。

## 局部轮廓

- 修改范围为沿手部轴向的 -4.3 至 +2.7 cm，最强收形位置为 -0.65 cm。横向最大缩放至 79%，掌背方向至 77%；两端以五次平滑函数渐隐，原边界位置不动。
- 以原腕部环截面的中心线收缩，避免绕偏置的骨骼原点缩放。前臂、腕部和掌根形成连续的粗细变化。
- 拇指侧和小指侧分别加入错开位置的浅骨点，幅度为 1.0／1.3 mm，再叠加局部包络。手背肌腱最高起伏约 0.45 mm，掌侧约 0.28 mm，随腕部范围渐隐。
- 掌侧烘焙两条短而弯曲的浅腕纹，横向逐渐消失，不形成环绕手腕的手套袖口线。

形态方向参考美国手外科学会的 [腕部肌腱资料](https://assh.my.site.com/handcare/safety/tendons) 与 [手腕方位、关节资料](https://assh.my.site.com/handcare/safety/joints)。具体收形比例和起伏数值是为当前模型制作的美术参数，不是人体扫描测量。

## 保留范围

V4 不重新切割拓扑、不转移权重、不换骨架。直接保留 V3 的三角连接、正确 UE 面朝向、UV 布局、全部顶点绑定、动画和握持位置；只改腕部位置及邻接面的法线。超过 +2.7 cm 的手掌／手指接触区位置不变。法线按局部曲面变化旋转，保留原有分裂法线差异。

沿用 V3 的 CC0 皮肤细节、高度幅度、平铺尺度和散射参数，重烘焙 4K 解剖颜色、法线及表面遮罩。没有新增运行时 WPO、细分、材质采样流程或每帧塑形逻辑。性能未测量。
