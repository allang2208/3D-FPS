# 另外三款手套：高模细节与材质同步制作

用户范围：沿用黑色皮革手套 V4 的高模、细节烘焙与近距离材质处理方式，调整另外三款现有手套，并同步装备栏图标。

## 对应装备

| 装备 | ID | 制作内容 |
| --- | --- | --- |
| 棕色露指皮革手套 | `ue_field_gloves` | 高模针脚起伏、针孔压痕、双线裁片、接缝轻微磨损、边缘短绒；保留露指开口和原有内衬 |
| 原版战术手套 | `ue_original_gloves` | 全指皮革裁片、浅护垫边界、嵌线和针孔、手背与抓握区域的粗糙度差异、缝线短绒 |
| 钢甲护手 | `ue_steel_gauntlets` | 实际高模刻槽、金属表面微起伏、方向性拉丝细节与细密金属内衬高模浮雕；保留已有连续手背/手腕/拇指甲片形状 |

## 制作管线与保存内容

- 源目录：`SourceAssets/GloveCompanionDetail20260928/{Fingerless,Tactical,Steel}`。
- 引擎目录：`/Game/Characters/ModularOutfit20260924/GloveCompanionDetail20260928`。
- 三款均覆盖原有 22 个 Body / 武器 / 独立左右手 / 攀爬 / 弓配置；露指款另有 22 个皮肤与手套组合网格。
- 游戏网格由活动资产复制，保留原生骨架、蒙皮权重、低模结构、LOD 配置与形状。新高模只用来烘焙。
- 露指款组合网格仅替换手套材质槽，皮肤材质槽保留；继续使用 `glove_in_base`、`skin_meshes` 的现有接入方式。
- 每款原有装备 ID、装备属性、换弹与拉弓速度数值均保留；没有制作或替换动画。
- 现有黑色手套 V4 不在本次资产修改范围内。

细分后实际移动高模顶点形成针脚、针孔、刻槽及金属编织浮雕，并执行高模向原有低模 UV 的法线烘焙。保留每种不同 UV 布局的独立母版，身体版本使用 2K，主要第一人称母版使用 4K。露指 Body 的裁片坐标改用归一化骨骼基进行换算，消除旧制作字段中单位骨骼轴与百倍骨骼轴混用的问题；游戏位置和权重不变。

皮革输出 BaseColor / ORM / Normal / Relief。高度来自同一高模，Relief 的蓝通道由真实 UV 岛生成边缘衰减；沿用黑色手套的变形表面导数 POM，共同偏移所有材质通道，最大 8 texel，6 步搜索加 2 步细化，并按距离、掠射角和 mip 衰减。细节深度为 0.06 cm，短绒局限在针脚及皮革边缘。

钢甲使用独立 Default Lit 金属材质，不使用皮革 Cloth 模型，不把金属度置零。外甲片与全覆盖灰色内衬分别绑定，内衬保持原先 0.7 × 0.6 mm 的物理重复尺度。

扫描皮革沿用项目已有 `Fabric_Generic_Leather_Top_Grain_Brown_xjghdgl` 源；原始元数据复制为源目录下的 `leather-source-metadata.json`，未引入新下载资产。

## 图标和拾取

- 三张图标均是原有真实空手套造型，独立单只，320 × 320 RGBA 透明底，约 91% 填充。
- 图标使用本轮生产 PBR；战术手套内侧继续使用较暗内衬，钢甲保持灰色全金属。
- 图标位于 `Content/ColdSteelData/Icons/GloveCompanionDetail20260928`。
- 拾取资产复制原已保存的网格并按槽更新材质，因此保持原有形状和 LOD。源目录同时保留对应 FBX 与图标编辑场景。
- 更新露指 / 钢甲的后续图标入口与战术款装备注册入口，使本轮活动家族继续引用当前生产资产。
