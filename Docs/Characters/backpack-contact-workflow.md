# 背包与新增衣服的贴合制作

统一入口：`Tools/BackpackFit/run.ps1`。工作目录为 `D:/FPS3D/FPSGAME`，默认后台制作、保存与按字段接入，不打开编辑器、不运行游戏或验收。`-AuthorOnly` 仅制作源；中断保存后用相同 `-Revision` 和 `-ResumeSave` 续接。

## 配对来源

从当前物品目录枚举背包，从 `modular_outfits.json` 的上衣槽枚举衣服，覆盖 Jason 和 Kaitlin。上衣表面包括普通路线及实际裤网格对应的扎腰变体；裤腰保护读取普通和靴型裤子。新上衣必须先保存两个身体各自的原生模型，不能以裸身回退代替配对。

`fit_registry.json` 记录实际保存模型和所选配方的散列。新上衣、上衣源更新、身体或裤腰源更新、背包源更新会触发相应组合重制；没有变化则直接结束。该文件是制作依赖记录，不代表动作或联机验收。

`Tools/WorkwearSet/run.ps1` 与 `Tools/GarmentWaist/run.ps1` 在衣物发布后调用此入口。其他服装制作器也应在保存并发布原生衣物后调用它；仅手动添加物品 ID 不会在游戏运行时生成模型。

## 包体、背带与动态

- 保持安装高度、倾角、外侧货舱、UV、材料槽、原生骨骼与动态遮罩。先分离完整货舱几何岛与肩带缝接端，不能把遮罩为 1 的背带端盖误判为货舱背板。
- 双肩包按实际身体和衣物表面处理贴背侧，保留中央通风槽；包体外侧细节不整体压扁。粗三角面同时处理面内接触，不能只看顶点。
- 固定肩胸段使用平滑的角度/高度变形场；内外表面同移。重建带子的截面，保留厚度和宽度，小扣件保持刚性。缝接端跟随对应包体位置。
- 分离包体的款式使用 `rigid_pack.mesh_by_shirt` 与 `location_by_shirt`；肩带使用 `world_mesh_by_shirt`，按同一上衣 ID 成套选择。默认包体仍供裸身或未制作的旧物品回退，回退不能视为贴合合格。
- 斜挎包沿用已认可的重力方案。新增/变化衣物同步更新固定带段、悬挂中心、接触探针、躯干骨骼凸代理、支撑点局部坐标和保留松量的带长。已有未变化的斜挎配对不重制。
- 六款双肩包使用显式世界重力在躯干局部切向上的受力下沉，当前按款校准 0.4–0.6 cm；双肩带和贴背结构承受法向力。惯性仍保留，向后避让限于 0.65–0.75 cm，超出时先减小摆角，不能靠把整个包一直推离背部来避穿。
- 运动支撑边界只取完整货舱，不能混入前胸固定背带。`backpack_motion.support/support_by_shirt` 与所选上衣包体配对，包含对应枢轴和货舱边界。
- 本地、复制外观及预加载共用成套选择；只预加载当前所选变体。材质/纹理由模型依赖携带，新配对目录显式加入 Cook。

## 落盘与按需检查

新版本写入独立 `/Game/Characters/BackpackFit20261024/<Revision>/`。保存 UV、材质、骨骼权重和遮罩，更新法线及原有 LOD。`saved_assets.json` 完整后才通过 `config_transaction.py::commit` 发布具体配对字段；同时核对实际制作源未被并行修改。不得覆盖其他配对或整个 `player_body.json`。

用户要求检查时，先用 `prepare.py`/`capture.py` 读取实际保存的几何，再运行 `classify_cargo.py` 与 `analyze.py`。`run_stage.ps1 -Stage contact -NullRHI -Revision <检查目录>` 使用当前七款/双身体/全部已配上衣的原生组件，在独立无界面世界稳定悬挂姿态，并检查起步、转向、停步后的重力、离背位移和稳定状态；不创建 GameInstance，不读写玩家档案。参考姿态网格分析要应用实际 CPD 重力场，分离包体则使用稳定后的组件变换。

间隙报告应说明三角面射线采样、参考姿态、衣物路线和通风槽范围。斜挎包应使用稳定后的刚体变换与接触探针，不能用初始挂点判断悬浮。后台几何/组件结果不等于跑动、蹲伏、布料动态和实际多人画面验收。

## 联机检查入口

仅用户要求联机检查时，使用 `Tools/BackpackFit/run_network_review.ps1`；默认七款顺序执行，可用 `-Packs` 限定。保持正常世界重力、异步预加载、每端 60 ms 延迟和 3% 丢包，正式玩家档案与测试档案隔离。主连接覆盖男女身体、换衣换包、卸包、快速重配和角色重建；重连使用同一测试档案检查最终状态。特勤款额外启动晚加入观察客机。结果与输入散列写入 `SourceAssets/BackpackFit20261024/NetworkReview/Run_*/`。

新增身体或异步装备接入时，装备请求键须包含身体类型和原生身体网格；切换骨架前取消旧请求并销毁旧装配。旧动画和骨架的曲线元数据先在 commandlet 中备份并保存，避免编辑器链接的无界面游戏进程在旧格式迁移时访问空编辑器事务。以上是制作与检查规约，实际通过范围以当轮回执为准。
