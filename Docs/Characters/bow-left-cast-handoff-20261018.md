# 持弓时的左手施法交接

本次需求：持弓施法与发射时保留右手和弓，并衔接左手离握、施法、回握。

## 已接入的行为

弓原有动作为左手握弓、右手持弦。进入共享左手施法手势前，用 0.38 秒完成换手：右手先握住弓把较低处，随后将弓移向右侧，左手再执行既有凝聚或发射手势。两手接触错开 5 cm；手指使用左右骨骼各自的参考坐标转换握持弯曲，不复制异侧欧拉角，也不缩放手臂骨骼。

左手施法结束的恢复段以实时弓把为目标。恢复完成后反向交还弓，右手退出支撑，最后用 0.12 秒过渡恢复原持弓姿势。连续施法可从当前换手进度重新进入。

拉弓状态进入施法会取消本次射箭，弓弦在接握阶段回到松弦位置；已搭箭保留，不生成箭矢、不消耗箭。共享施法时钟等待右手接稳再推进，技能原有触发回调、资源和权威发射逻辑不变。换手和回握期间暂停弓攻击输入。

## 路径记录

| 路径 | 实现 |
|---|---|
| 第一人称显隐 | 弓的展示条件允许共享左手施法；使用条件仍阻止同时射箭。 |
| 第一人称手臂 | BowArms 复用现有 FPSCastingMesh 左手施法层；右手承托弓，弓把标记独立保留。 |
| 凝聚、发射 | 共享 Fireball 手势执行器等待换手结束；火球以及使用 TryBeginSpellGesture 的技能沿用同一入口。 |
| 回握、连续施法 | 左手回到实时接握点后反向换手；再次施法从现有进度接续。 |
| 移动、蹲起 | 持弓移动层、进入混合和蹲起时钟保持更新；保留此前第三人称胸部稳定修复。 |
| 第三人称 | Sparrow Carry 保留上半身和右臂支撑；单独驱动左手施法与恢复，弓按最终右腕位置挂接。 |
| 第三人称手指 | 右手保留换手握弓指型，左手使用共享施法指型及恢复。 |
| 联机呈现 | 同步换手进度和方向；开始、结束、反向走可靠状态边沿，连续帧沿用快照和有限外推。 |
| 换装、死亡、翻越 | 沿用原有装备身份、姿态租约和中断条件；新装备清除弓换手进度。 |

## 交付边界

这是 C++ 运行时姿态接入，无新模型或动画资产导入，不修改已保存的手模或 Sparrow 动画文件。构建结果记录在 `SourceAssets/BowLeftCastHandoff20261018/`。

按照用户规则，本轮未启动编辑器、游戏、PIE、视觉检查或联机测试，也未执行自动化夹具。既有 Sparrow 夹具中“施法隐藏弓”的旧预期已随需求更新，但没有运行。动作自然度、穿模、手指接触和真实主客机表现由用户进游戏确认；构建成功不代表这些视觉与运行表现已验收。
