# 原版战术手套

物品 ID：`ue_original_gloves`。手套槽装备，2×2 格、不可堆叠，复用现有棕色手套图标和掉落展示模型。

## 使用

新增物品目录在进入游玩时读取。如果当前正在游玩，结束这一局再进入一次。

在 F6 开发面板的「服装与手套」分类选择「原版战术手套」，加入背包并装备到手套槽。

- 穿戴：恢复当前武器原有的整套第一人称手臂、手套和衣袖。已有上衣仍在装备栏，第一人称显示以原版整套手模为准。
- 卸下：重新计算当前外观。M4 在没有模块化上衣/手套时显示写实裸臂候选；其他武器维持各自当前默认。
- 换另一副手套：继续使用该手套原有的模块化外观配方。

## 实现范围

`modular_outfits.json` 的新配方使用 `first_person_mode=source_arms`。运行时停止该角色第一人称的替换表现，取消旧加载并恢复原材质区；不复制枪体，不修改骨架、蒙皮、动画或全局裸臂开关。切枪时仍沿用各武器自己的原手模。

复用现有物品 Definition、手套槽、背包、仓库、掉落和装备存档逻辑。没有自动赠送或直接改写玩家存档。重新运行 `register_equipment.py` 也会保留本物品。

这是第一人称原版外观恢复装备；第三人称不会因为此物品额外生成第一人称手臂，上衣外观仍沿用原身体换装流程。本轮没有新增第三人称原版手套网格。
