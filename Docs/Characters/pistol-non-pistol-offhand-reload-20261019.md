# 主手手枪与非手枪副手的换弹交接

2026-10-19。按用户设定，非手枪副手带来明确的换弹负收益。

- 先收起副手 0.55 秒；结束后才启动原来的换弹动作与机械事件时钟。
- 最后机械接触后开始取回副手，贯穿剩余换弹尾段及额外 0.40 秒；不等源动画先回握把。整个期间仍占手。
- 完整流程额外增加 0.95 秒，独立于枪械换弹速度加成。空副手与双持手枪保持原流程。
- 按当前主武器对应的实际副手槽位判断，只排除手枪，不把规则写死为魔法书 ID。

## 实现

`FOffhandReloadHandoff` 提供 Lower、Reload、Raise 三阶段；`AFPSGAMECharacter` 在现有武器更新中推进。按 R、空仓自动请求、左轮后坐结束后的换弹、切换弹种和中断后补机械动作，继续使用 `ReloadPressed`。装弹扣除、拉栓、弹巢、音效和镜头事件仍从实际换弹开始计时，收副手阶段不提前装入子弹。

收起/恢复阶段同时占用开火、ADS、新施法、进食和快速近战的入口。保留按住射击/瞄准的原有输入意图，完整交接结束后恢复。武器/副手实例变化、菜单、死亡、翻越及优先级中断清理挂起请求；普通换弹中断可从当前收起权重恢复，不重复扣弹。切换弹种保留目标直到实际装入或取消。

魔法书第一人称复用进食的整条手臂退场位移。书收起后，主枪原生支撑手接管换弹；随后恢复同一持书姿态。第三人称以肩部为支点旋转原生完整左臂和辅助骨，书跟随手掌，使用身体相对空间。网络身体状态同步阶段和收起权重，阶段变化沿用可靠过渡上报。

后续非手枪副手自动具有同样的玩法时间代价；新装备的表现组件需接入 `GetOffhandReloadPhase()`、`GetOffhandReloadLowerWeight()`，按 Lower/Reload/Raise 实现自身的整臂退场、隐藏、归位。不能只按 `IsReloading()` 在第一帧突然隐藏道具。

## 取消换弹尾段回握把（用户反馈后的修订）

用户反馈上一版仍先回握把再切到书。根因是表现交接等到了原生换弹片段完整结束，片段里的左手回握已经播放。

- 在弹药提交、机械准备完成后接管：M1911/G18/Pit Viper 普通换弹同时等到压实弹匣接触，空仓等滑套释放，左轮等合膛；保留两个源帧的离手间隔。
- 武器原始换弹计时、机械骨和音效继续到原终点，左手表现提前进入取书。恢复窗口为剩余换弹尾段加 0.40 秒，结束时不重新开始取书，因此完整占手成本仍是原换弹加 0.95 秒。
- 第一人称主枪保留最后显示的完整左臂（手指与辅助骨一并缓存），连续下移退出，不再采样后面的回握把动作；退出段结束后才切给画面下方的持书手。
- 第三人称在隐藏书期间也持续执行取书手臂层。提前离手后停止接受主枪左手样本，右手、主枪与机械部件继续使用相对运动；不把主枪后续回握轨迹重新写到取书左手。
