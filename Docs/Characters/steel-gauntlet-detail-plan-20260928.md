# 钢甲护手细节与材质提升

本文件记录 2026-09-28 较早的细节与钢材阶段。用户随后指出指甲覆盖不足，当前结构已按 [覆盖重做方案](steel-gauntlet-coverage-20260928.md) 改为宽弧形甲壳；下文的窄片范围、32 块甲片与三角数属于历史版。钢材、压边和铆钉制作继续沿用。

范围：`ue_steel_gauntlets` 的生产模型、钢材、图标和掉落模型；沿用 22 套原生绑定。先读取当前装备图标、模型生成器及 UE 导入器，再按下列方案实施。

## 现状

当前结构已从 44 块减到 32 块，主甲与手掌侧腕甲一体化，虎口和指根有活动空间。主甲缺少加工细节；小指甲轮廓偏直，铆钉在图标里难以辨认。现钢材将高对比度各向噪声直接写入颜色和粗糙度，呈大块斑驳；各片、边缘和铆钉没有明确的表面加工层次。

## 制作计划

1. 保留拟合底面、外轮廓和单骨骼刚性绑定，主甲表面向外增加不超过 1.5 mm 的浅脊与压边；不新增跨关节甲片。指甲只收小外角，不向指缝扩大。
2. 主甲、指甲、短腕甲增加连续细刻线与克制的边缘抛光；纹样通过独立制作 UV 烘焙，不增加运行时贴图采样或材质槽。
3. 铆钉沿甲片真实曲面法线安装，主甲帽径约 3.1 mm、座圈约 4.1 mm，指甲帽径约 1.7 mm；帽底加入浅座圈并保留自身所属骨骼。
4. 钢材采用缎面冷灰底色，降低斑块反差；细拉丝控制粗糙度，锻打起伏与微划痕进入低强度法线。压边略亮、刻线略暗，避免全表面均匀做旧。
5. 保留三张 2K BaseColor／Normal／ORM、两个运行时材质槽及三级 LOD。细节由离线制作承担，不增加运行时 Tick 或程序材质计算。
6. 由实际生产模型重做装备图标与掉落模型，派生并保存全部 22 套装备资产，沿用物品 ID、数值与存档。
