# ST6 袖身漏空、交叠与袖口修复

用户画面为双手剑张掌姿态，左前臂有大块露肤，两侧袖身存在交叠，袖口细节不完整。

现役 `ue_st6_sleeves` 的 RuneSword 分支仍引用 `Super90Source20261006/RuneSword/SK_RuneSword_ue_st6_sleeves`。作者源经 Super90 → M4 → 其他骨架变换；双手剑源共有 4,286 顶点、8,442 面、130 条开边，最长边约 9.57 cm。这些开边包括正常袖身端部，不能全部判作截图缺口；较粗跨关节拓扑和不同参考绑定需要替换。

同时，配方 `covers=[]` 保留裸臂，上臂、前臂材质又由 `base_material_overrides` 涂成布料，形成实体袖身与原生表面两层显示。裸臂腕部另有材质 3 补片，当前覆盖关系没有包含它。用户画面是视觉问题证据，离线来源分析不冒充同步姿态复现。

## 定向制作

- 从每个当前第一人称 profile 的已保存 `native_bare_skin` 读取完整源几何、骨架、权重；不转换活动 Leader Pose 组件。
- 共 23 个第一人称 ST6 分支，Body/Jason 的世界身体、颈口与本机躯干装饰保持现有独立路径。
- 直接复用原生肩肘腕拓扑。袖口延伸到腕关节近端 1 cm；肩端按解剖方向裁切。左右臂由骨骼影响区分，单臂派生只生成实际存在的一侧。
- 袖身、内衬和翻边共享顶点对应、权重与连续变形。厚度 1.2 mm，外层腕部余量约 3.4 mm，袖身约 5.9 mm并带受限浅褶；这些数值仅属于本件款式。
- 袖口分区通过实际切边生成，内外层只在明确边界环连接；不自动填肩口、不重复 Solidify。
- 独立的深灰防撕裂材质、暗色内衬与袖口双道缝线，复用 ST6 下装的物理尺寸织纹贴图。细节法线受控，不用大幅 WPO 或高光掩盖几何问题。
- 三档近景 LOD 保留配对拓扑；新路径保存后再只替换本件衣服的第一人称引用，覆盖原生 0/1/3 槽并移除其布料底层覆盖。保留手掌与手套显示职责、动画时序和握点。
