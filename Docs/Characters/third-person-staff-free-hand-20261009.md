# 第三人称持杖空闲左手复用

> 这是对应阶段的制作记录。当前接入、替代关系和恢复依赖以[第三人称动作发布说明](../Publication/ThirdPersonActions20261010/README.md)为准；旧手工抓握表及被否定的腕臂姿态不作为当前基线。

用户要求：左手复用第一人称空手手势，主要用于奔跑时的手臂与手型组合。

## 接入

- 持杖且副手无装备时，左手直接读取第一人称当前运行表 `UnarmedAuthoredLocomotion20261001` 的闭拳姿态。该表的 Idle、Walk、Run 共用闭拳指节，包含拇指和四条掌骨；不使用旧的 `UnarmedAuthoredIdle20261001` 表。
- `FPSUnarmedHandPose::Build` 从源骨架原生绑定构造手型，复用现有 `FPSBodyStaffGrip::Transfer`，通过原生掌坐标迁移到身体骨架。保留身体手指骨长、缩放及半关节辅助骨；装备构建时计算并缓存。
- 只叠加手腕以下的手指和掌骨。肩、上臂、肘、手腕沿用第三人称 Unarmed Walk/Jog 步态及已有步频混合，不复制第一人称镜头空间的手腕位置，不新增逐帧解指节或隐形手臂组件。
- 左手出拳、照明、施法、饮用和推门仍由现有动作层覆盖。副手持枪或持书不应用空闲闭拳；采集法杖左手动作时也排除正在展示的法术书。
- 原先第三人称右手的第一人称法杖抓握复用保持有效。没有改动甲手套资产、攻击消耗或命中时序。

## 构建与交付

必要的 Game / Editor 构建记录位于 `SourceAssets/ThirdPersonStaffFreeHand20261009/`。最终状态见同目录 `delivery.json`。

本次未启动编辑器、运行游戏、截图、渲染或进行测试。跑步摆臂与手型的实际观感由用户测试。
