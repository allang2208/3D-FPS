## 已执行的检查

- **53 份当前源网格**：位置、法线、UV、权重归一化、重复面、退化面和多面共边。未发现剩余退化面或重复面。PKM / LMG201 手套各有 7 个顶点带一个小于 0.000046 的第九微小权重，其有效影响仍不超过 8；保持原生绑定。
- **25 个手部/身体 profile、66 个来源别名**：法袍与手套没有缺失分支；裤、靴走 Jason 共用身体路径。没有声称逐把武器的所有动作都经过画面验收。
- **89 个实际保存的骨骼网格、267 档渲染 LOD**：包括当前内搭与五款组合鞋，均可读取，非空且顶点有限，材质引用存在。四个法袍身体/本机版本仍有真实布料资产、对应物理资产和 4 次子步进。84 个法师家族资产完成分区修正落盘。
- **五套图标与拾取引用**：透明 PNG、标准路径、家族路径、UE UI 纹理、展示网格和拾取网格均存在；PNG 路径内容一致。模型导入与图标显示来源分别核对。
- **七款裤装与新靴子**：从当前保存资产提取位置和权重。18–37.2 cm 靴筒覆盖区没有顶出内壁的点，最小测得余量约 6.4 mm。
- **81 段当前移动/持握源动作，1,377 个采样姿态**：覆盖弓、枪、法杖、双手锤等共用下身动作。静态检查全量下腿顶点，动态每件最多约 1,806 个代表点；采样点均在现有法袍腿脚碰撞包络内，最小包络余量约 3.1 mm。

## 实际联机检查

监听主机 + 一个客机，使用真实本地 UDP、正常档案分片上传、服务端影子档案、装备槽复制和客户端外观重建。使用独立测试档案/用户目录/19943 端口，每端设置 60 ms 延迟和 3% 丢包；日志确认这些网络模拟参数生效。

每轮七个用例：整套穿戴、摘帽、脱袍、脱靴、同帧快速脱穿、全部脱下、恢复整套。客机退出后用同一档案重新加入，再执行一轮，共 **14 / 14 通过**。

最终一轮中的十个用例让主客机穿不同组合，例如主机脱靴而客机摘帽、主机全脱而客机保留裤靴，专门检查人物之间的装备归属隔离。独立记录三个测试进程的退出码。

每个用例分别比较服务端影子库存、复制装备槽、主机看到的客机、客机自身和客机看到的主机；记录五件装备的实际组件数量、绑定来源、帽子挂点、法袍 CopyPose、裤脚和法袍内搭选择。未发现错槽、重复装备、脱装残留或内搭选择不同步。

当前衣物 ID、骨架、材质等外观由目录决定；网络传输装备身份和角色姿态。帽尖摆动与裙摆布料在各显示端计算，不要求逐顶点网络同步。专用服务器不创建这些显示组件。
