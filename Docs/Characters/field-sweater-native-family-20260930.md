# 野行长袖：全第一人称原生袖身重建（2026-09-30）

用户再次报告多把武器的尖刺和错边，要求统一调整，不再逐个动作打补丁。本轮范围是 `ue_field_sweater` 的全部 22 个第一人称绑定，包括 SVD、201、双持、近战、法杖复用的 M4、弓及 Traversal。

## 原方案的不足

上一轮 `FieldSweaterSurfaceRepair20260930` 只重建了 Body 和 Traversal。其余分支仍在使用 `FieldSweaterCameraRepair20260930`：多数从旧 M4 袖身修权重后变换到原生绑定，SVD 还保留了历史局部袖身。这并未统一解决旧关节拓扑与原生裸臂表面的差异。

前次定向诊断已显示：清除躯干权重后，旧 Traversal 肘部的粗边仍能在翻越时拉到约 5.18 cm。原生臂的肩肘腕参考姿态也不统一；ASH12、M16 是不同的弯曲绑定，弓采用旋转后的坐标方向，双持网格可只有一侧手臂。不能用世界 X 正负识别全部绑定的左右臂。

本轮仅只读取得已经运行的玩家组件，当时持有 LMG201/Cover10、LOD0，但已没有可见的野行长袖组件。因此这不是截图发生时的同步捕获，不能把该截图确定归因为低 LOD，也不伪称已复现全部尖刺。

## 统一重建

1. 每个 profile 直接使用其当前 V7 原生裸臂表面和原生权重。只选择上臂、前臂与腕部材质区域；按上肢骨骼权重识别左右臂，单臂派生仅生成真实存在的一侧。弓使用当前 ContactV9 对应的裸臂来源。
2. 合并原生臂材质边界的重合点，再沿各自上臂方向裁出肩端开口。只连接内外层厚度环，禁止自动封住整个肩口。
3. 内外层、切口与 UV 接缝出自同一张连续表面，成对顶点使用完全相同的权重；肘部保留原生细分，不再通过旧衣服的长边跨越关节权重区。
4. 针织外层间隙从腕部 0.24 cm 平滑过渡到袖身 0.55 cm，实体厚度 0.20 cm。保留原生手掌边界和罗纹袖口材质区，复用现有针织、收口与内衬材质。
5. 袖身 UV 在肘部连续过渡，去掉此前上臂、前臂坐标帧的突然切换。几何相连的材质区与内外层不会因此采用不同的蒙皮字段。
6. 这件第一人称衣袖的三个 LOD 索引均保留完整配对拓扑、最多 8 个骨骼影响，不对内外层和边缘分别简化。双臂约 2.63 万三角面、单臂约 1.31 万；这是近景几何取舍，不是帧率优化结论。第三人称 Body 沿用此前独立修复及其 LOD。

`Tools/ModularOutfit/garment_ue.py` 新增可选 `lod_triangle_ratios`；原调用默认仍为 1/0.9/0.8，本轮调用指定 1/1/1，并明确保留 8 个骨骼影响。没有增加每帧衣物解算、物理模拟或修改枪械动作。
