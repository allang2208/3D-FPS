# ST6 战术长裤与靴子：细节升级和背包图标

用户于 2026-10-24 反馈 ST6 长裤和鞋子在装备／背包栏没有图标，并要求提升模型与材质细节。本轮沿用两件既有物品 ID、原配色、属性和套装效果。

## 图标问题与修复

`items.json` 中两件物品已有 PNG 路径，但同时保留非空 `ue_equipment_icon_mesh`，优先走网格捕获。旧实例又未纳入已有的目录图标刷新分支。

本轮从升级后的实际模型制作正式 PNG，使用生产 PBR、透明背景、正交镜头和约 91% 主轴填充。两件均为 2×3 占格，输出 320×480：裤子竖直完整展示，靴子只展示单只空壳，不包含皮肤、人体或第二只遮挡物。曝光依据生产底色有限校准，未另外生成验收渲染。

发布入口将 `ue_equipment_icon_mesh` 明确置空，统一走目录 PNG，并同步历史 PNG 回退。`ColdSteelProfileRuntime.cpp` 为两件物品加入既有的外观迁移分支，刷新旧实例中的 PNG、网格图标字段和掉落模型；强化、附魔、实例身份和库存位置沿用原数据。

## 模型与材质

- 长裤新增贴合腿袋的双道扩展褶、翻盖扣件、袋角套结加固线、护膝抓地纹和后膝弹力裁片压线。
- 靴子新增沿真实裁片边界排列的弧形针脚、鞋舌边线、后拉环加固线、鞋底分层沿条、短鞋带尾和金属绳端套。
- 原有腰口、裆部、裤脚和靴筒主体不变。新增构件使用现有表面的原生权重；普通裤及三种裤靴配对继续各自保留原始几何。
- 灰色防撕裂布、卡其皮革、黑色橡胶、弹力织物、枪灰金属和线体分别制作真实尺度的表面高度场，以及同源 BaseColor／Normal／ORM。共 24 张作者贴图，其中 18 张进入运行时，6 张 Height 保留离线制作。
- 布料和皮革使用 2K，其余 1K，线体 512；保留 mip 和流送。OpenGL 法线导入 UE 翻绿，布料／线体增加有限绒面响应。
- 图标／掉落用空壳作者源为长裤 104,928、成对靴子 234,747 三角形。该统计不含穿戴资源的原生皮肤补片，也不表示实测绘制成本。普通穿戴保留 LOD0，距离档位制作比例为 50%／22%；法袍内穿资源保留既有几何及 LOD，只更新对应材质。

## 制作源与入口

- 制作目录：`SourceAssets/ST6LowerDetail20261024`。
- 可编辑完整源：`Exports/ST6_LowerDetail_Editable.blend`；独立细节构件源与 5 份 Jason FBX 同目录保存。
- `Inputs` 冻结原版源与配置；`Authored` 保存两套身体的新增细节及空壳展示源；`Before` 保存发布前文件。
- 正式图标：`Content/ColdSteelData/Icons/ST6LowerDetail20261024/ue_st6_tactical_pants.png` 和 `ue_st6_tactical_boots.png`。
- 重制顺序：`Tools/ST6LowerDetail/prepare.py` → `make_textures.py` → Blender 后台 `author_detail.py` → Python `fit_kaitlin.py` → Blender 后台 `save_editable_icons.py` → PowerShell `run_all_assets.ps1` → Python `publish.py`。
- `prepare.py` 已有本轮清单时复用冻结输入，避免将已升级的网格再次当作基础追加重复细节。后续变更基础款式应另建修订输入。
- 普通／靴型完整作者 JSON 同步保存在 `Authored/`，`Tools/TrouserFit/prepare.py` 对本轮新路径读取这些来源，避免后续腰部制作回退到旧版模型。
- `run_all_assets.ps1` 每批最多保存 4 个穿戴／内穿资源，使用共享 UE 批次锁，逐模型保存回执并释放 Python／UE 临时内存。
- 旧存档兼容源码修改后使用 `Tools/ST6LowerDetail/build.ps1` 后台构建 Editor／Game；只重制外部模型或图标时不重复构建无关源码。
