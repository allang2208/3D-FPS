# 钢甲护手

物品 ID：`ue_steel_gauntlets`。装备槽：手套（3），背包占用 2 × 2，单件堆叠上限 1。

## 制作内容

当前造型为 2026-09-28 连续过渡版，详见 [连续外壳记录](steel-gauntlet-smooth-transition-20260928.md)。手背、腕部和拇指改为左右各一张连续钢质外壳，主甲边缘与拇指根共用顶点；取消独立腕甲和分离拇指小甲片。其余四指保留 24 块逐指节硬甲，全套保留 24 颗小铆钉及 2 个细密金属软护层。同日用户进一步要求全手去皮革，掌心、指侧和袖口内手套改用同款灰色金属护层，见 [全手金属材质](steel-gauntlet-full-metal-20260928.md)。

主甲稳定区域跟随手骨，腕部向前臂骨渐变，虎口及拇指沿原生拇指骨链渐变，按用户要求允许适度弯曲以优先保证视觉连续。其余四指的硬甲与铆钉仍采用单骨骼权重。所有部分合并为每个原生 profile 的一个装备骨骼网格，使用现有 Leader Pose 跟随与穿脱流程。此前的小拇指旋转和毫米级副手避让曲线保留；本次不改源动画、动画时钟或装备逻辑。

钢材为本地硬表面建模和程序材质制作：真实壁厚、边缘倒角、弧面、指端退让、表面微粒及克制的粗糙度变化。2K BaseColor、Normal 和 ORM 图集已烘焙；ORM 通道为 AO／Roughness／Metallic。Normal 为 OpenGL 约定，UE 导入翻转绿色通道。皮革沿用 OriginalLeatherV2 中已认可的材质结果，Body 保留独立 UV 和皮革图集。

当前方案见 [小拇指关节重构](steel-gauntlet-articulation-plan-20260928.md)。细节材质与覆盖文档保留为历史阶段。`steel_gauntlet_finish.py` 制作主甲一体压边、浅中央脊线、铆钉座圈、缎面钢材及细密金属护层；`steel_gauntlet_coverage.py` 配合 `steel_gauntlet_motion_fit.py` 按指骨筛选表面并拟合弧形硬壳。局部尺寸 UV 上的细刻线、方向性磨纹和边缘抛光烘焙回原三张图集，制作节点不增加运行时采样。

右手单件掉落模型与 512 × 512 透明装备图标来自完整生产模型，使用相同生产贴图。图标展示姿态只用于图标与掉落模型。

## 原生适配

按当前 `ue_original_gloves` 已保存网格提取 22 套原生绑定和皮革输入：Body、M4、AKM、QBZ191、ASH12、M16、M1911、DW715、A762、SVD、PKM、RuneSword、FrostSword、FrostArms、Axe、Pickaxe、DW715_l/r、M1911_l/r、Traversal、Bow。

钢甲按每根骨骼的参考朝向和位置派生。输入几何与位置已是 UE 厘米，骨架导入根比例不同（M4 为 100、Body 为 1），因此传递甲片厘米偏移时使用归一化参考轴；实际 UE 网格仍复制完整原生骨架和绑定。双持只保留该侧原生皮革上实际存在的手。

当前 LOD0 面数记录在作者源目录的 `manifest.json`，距离 LOD 由现有装备制作器生成。上一版小拇指重构阶段的双手第一人称为 90,606 三角、Body 为 93,124 三角，该数值不代表本次连续外壳。此为几何制作记录，未进行性能测量。

## 手背覆盖修正（2026-09-27 历史阶段）

用户在手枪持握和装备预览中发现手背露出过多。原因是旧母版以四指根骨中心的跨度估算手掌宽度，并使用偏短的梯形前缘；这不能覆盖真实手背两侧及指根附近的轮廓。

主甲现按皮革内手套的实际手背轮廓重新拟合，扩展两侧，前缘随四指根的位置延伸，腕部保留与独立腕甲的抬高搭接。真实壁厚、倒角和手掌骨刚性绑定保持原制作方式，铆钉随新边界移动。装备图标与掉落模型继续由同一母版生成。

本次按用户要求进行的静态模型诊断，以背向射线采样手掌及掌骨权重占比至少 65% 的区域，统计皮肤前方的钢甲覆盖。旧母版双手约为 62.8%，修改后右手 97.34%、左手 97.14%；边缘和活动过渡区仍保留少量皮革。这是参考姿势几何覆盖记录，不代表持枪动画穿插测试。诊断输入与报告保存于 `HandBackDiagnosis/`，旧母版和图标保留于 `BeforeHandBackFix/`。

M1911 和 DW715 派生模型使用各自原生手骨坐标重复了上述问题范围的诊断，结果同为右手 97.34%、左手 97.14%，报告分别为 `after-M1911.json` 与 `after-DW715.json`。未启动游戏，也未运行开火、换弹等动作测试。

## 握枪碎片感修正（2026-09-28 历史阶段）

用户的左轮瞄准截图显示指根和虎口处有尖锐交叉边。读取 DW715 已保存装备网格，钢甲 15,164 个顶点都保持单骨骼权重；问题不是钢甲被混合蒙皮拉裂。旧结构在参考姿势已有指根小甲片相交、腕甲互插和皮革穿出，握持后进一步放大。上一阶段的手背投影覆盖率并不能证明结构或握持无穿插。

新版从原生 DW715 待机、瞄准姿势提取内衬相对于各甲片所属骨骼的形状，连同参考姿势作为拟合输入。主甲使用平滑曲面包覆内衬，避免逐点复制皮革褶皱；手掌侧腕甲并入主甲，前臂短护腕后移；删除四指重复的独立指根小甲片和虎口拇指掌骨甲，指甲缩短并收窄侧边，保留钢甲刚性与柔性关节。游戏动画和原生皮革权重没有改动。

`GripFix/` 保存原资产、姿态输入、问题范围的几何分析及旧母版。该轮只分析参考姿势和左轮待机／瞄准源姿势，未运行 PIE、换弹、射击或全武器回归。相邻指节及双手紧贴的接触区仍有几何交叉记录，不能宣称所有动作完全无穿插；后续实测应重点观察这些部位。图标与掉落模型使用新版生产母版。

该历史版作者源的三种姿势中，双手主甲与内衬的交叉三角形对从 1,033／859／840 降到 0；同一只手的甲片互相交叉从 1,762／2,167／2,577 降到 0。待机／瞄准仍有 2／3 组跨左右手的甲片接触，以及部分相邻手指内衬接触。用户随后指出窄片和大关节空白缺少装甲感，因此覆盖结构已重做。这些计数仅描述旧版源几何，不能用于新版的动作或穿插结论。
