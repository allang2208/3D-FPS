# 第三人称步枪动作与战术激光

## 问题与处理

| 动作 | 代码中定位的问题 | 本批调整 |
| --- | --- | --- |
| 待机、行走、奔跑、冲刺 | 世界身体使用全身 Rifle Walk/Jog，支撑手却每帧读取第一人称冲刺的松手姿态；Jog 还叠加一次程序下压和旋转 | 用装备已适配的持握姿态维持双手接触，映射到当帧枪体坐标；保留全身跑步动画，移除步枪额外冲刺偏移 |
| 瞄准、开火 | 手部持握和机械状态混在同一源姿态中，单纯冻结整套会丢失枪机/后坐表现 | 只稳定持握，枪体、枪机和各改造件继续取原执行器当帧机械姿态 |
| 普通换弹、空仓换弹 | 手腕直接位于第一人称相机空间；双臂分别求解可能夹断可达范围；世界枪械根和弹匣各自平滑 | 双手动作改为相对原生持握的差量，安置在当前全身躯干；双手成组限制可达范围；枪械骨骼与弹匣/改造件统一到同一右手坐标系 |
| 装备、检视 | 同样读取相机空间腕点，衔接时手部历史停在旧躯干位置 | 使用与换弹相同的相对持握采样，过渡历史随当前躯干移动 |
| 转向、楼梯、下蹲、滑铲组合 | 步枪固定肘极不随全身动作弯曲平面变化 | 肘部方向来自当前全身动作的肩肘腕平面；骨长保持原值，骨盆/腿部继续由现有动作负责 |
| 激光、手电 | F6 可见的是世界枪械，但发射点和枪管朝向仍取隐藏的第一人称附件 | 按源组件身份解析对应世界枪械/附件；从可见枪体的 Emitter 与枪管轴发射；第三人称不套用第一人称瞄准镜覆盖层的光束隐藏 |

## 动画来源与接触约定

沿用 `player_body.json` 中已重定向到 Jason 的全身 `Rifle.Idle`、八方向 `Rifle.Walk` 和八方向 `Rifle.Jog`。本批未引入新素材。现有动画足以承担步态，先修正原生枪械接触采样与全身动画叠加的空间冲突。

每把步枪仍由自身换弹执行器决定弹匣、枪机、弹药结算、声音和普通/空仓时序。支撑手与弹匣复用同一时刻的原生机械样本，不把通用全身换弹动画的时间直接套到每把枪上。

`FPSBodyRifleMotion::UsesHoldSpace` 仅用于双手步枪的换弹、空仓换弹、检视和装备；原有架枪、施法、消耗品、门交互、翻越等专用接触通道仍由原执行器负责。双持手枪不采用步枪持握修正。激光/手电沿用当前本地玩家效果系统，本批修正 F6 发射坐标，未新增远端玩家光效复制协议。
