# UE5 第一人称手臂标准

现行入口：[手臂与换弹动画技能](../skills/ue5-fps-arms-animation/SKILL.md)。

沿用当前 M4 运行网格中的手与手套，以真实加载为准；旧 Godot Cubic 手模文档已退役。统一外观不等于跨骨架复制旋转，新增衣料/手套要验证 UV、权重和关节空间。

当前接触与动作：[M4 基线](../skills/ue5-fps-arms-animation/references/m4-baseline.md)。通用方法：[姿态与接触](../skills/ue5-fps-arms-animation/references/pose-contact.md)。编辑：[MAT 操作](../skills/ue5-fps-arms-animation/references/mat-editing.md)。验收：[运行与音画](../skills/ue5-fps-arms-animation/references/validation.md)。
