# 丘陵树荫光照调整 — 2026-09-13

用户反馈树木阴影下过暗。本次针对 `L_TemperateHills_Initial` 的运行时光照调整，现有世界与新建丘陵世界共用，无需重新生成地图。

## 修改依据

- 当前丘陵作者脚本将天空光设为 `0.9`，后处理曝光最小值和最大值均为 `1.0`。项目开启扩展亮度范围，因此这两个曝光值的单位是 EV100；相等时关闭眼睛适应。
- 用户最近一轮运行日志记录丘陵日夜控制器绑定的太阳强度为 `5.0`、天空光强度为 `0.9`，与作者脚本一致。
- 天气组件原本在暴雨时将天空光再乘以 `0.72`，并将云底天空光遮蔽推向 `0.22`。树冠遮挡直射光时，这些设置进一步减少暗部照明。
- 本次依据源代码和已有运行日志调整参数；未通过新一轮实机画面确认各因素的视觉占比。

## 实现

| 项目 | 新设置 |
| --- | --- |
| 白天天空补光 | 缓存的作者基线 × `1.8`；当前丘陵晴天白天为 `1.62` |
| 白天曝光范围 | EV100 `0.25–1.0`；相对原固定曝光最多允许 `0.75` 档提亮 |
| 曝光适应速度 | 进入亮处 `3` 档/秒，进入暗处 `1` 档/秒 |
| 局部曝光暗部对比度 | 白天 `0.65`；使用现有 Bilateral 局部曝光机制 |
| 入夜 | 额外天空光倍率平滑回到 `1.0`，曝光范围回到原固定 EV100 `1.0`，暗部对比度回到项目默认 `0.8` |
| 暴雨天空光倍率 | 丘陵由 `0.72` 调至 `0.90` |
| 暴雨云底天空光遮蔽 | 丘陵目标值由 `0.22` 调至 `0.10` |

`AFPSWeatherManager` 在丘陵运行世界创建自有、临时的 `HillsCanopyExposure` 后处理组件，优先级为 `10`。只覆盖曝光相关字段；已有地图包不需要修改或重建。昼夜更新仍以原有 10 Hz 节奏从缓存的灯光基线计算，天气组件在之后施加一次天气倍率，避免逐帧累乘。太阳直射强度、阴影投射和其他地图的调光值保持原设置。

可在天气管理器 `Weather | Hills Lighting` 调整 `HillsDaySkyLightScale`、`HillsShadeExposureAllowance`、`HillsDayShadowContrast`。本次没有添加逐树灯光、额外阴影光源或提高 Lumen/云采样质量；开放小幅自动曝光会启用对应眼睛适应处理，实际性能影响未测量。
