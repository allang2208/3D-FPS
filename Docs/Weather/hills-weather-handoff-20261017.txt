丘陵高度雾交接到 UDS（2026-10-17）

范围
接续用户确认的丘陵天气迁移收尾，移除旧远景模块与新天气之间的雾颜色重复控制。源码后台制作及 Editor/Game 构建；不启动交互编辑器、游戏或测试，不改怪物数量、战斗规则或全局画质开关。

实现
1. TemperateHillsBackdrop 不再遍历全世界并改写所有高度雾/大气组件，也不再每 0.25 秒根据自己的昼夜公式重写雾颜色。删除对应弱引用、计时状态及失效 include；远景地形、植被、遮罩制作继续保留。
2. FPSUDSHillsAtmosphere 在 L_TemperateHills_Initial 的 UDS Actor 开始运行且天气快照就绪后执行一次。重新绑定天空时重置一次性状态；主机和客户端都执行自己的本地表现绑定，不增加 RPC。
3. 复用 UDS 已配置的 Custom Height Fog Actor；没有显式配置时，只查找丘陵 PersistentLevel 中作者脚本创建的 ExponentialHeightFog_0。不会根据 Actor 遍历顺序接管其它流送层或局部雾对象。该旧 Actor 不存在时沿用 UDS 自身的高度雾组件。
4. 使用实际读取过的原生 Configure Height Fog with Feature Toggle：它设置 Height Fog Component，并在使用外部雾 Actor 时隐藏 UDS 内置高度雾，避免同时创建另一套控制目标。
5. 将丘陵晴天的基础密度 .008、基础衰减 .20、最大起雾距离 16000 cm 交给 UDS 配置；只迁移仍等于蓝图默认值的参数，保留已明确调整的 UDS 值。保留体积雾开启、原 Actor 的体积雾距离与消光；没有原 Actor 时使用丘陵作者基线 85000 cm 和消光 1。
6. 雾颜色、天气密度变化及昼夜变化继续由 UDS 处理。保留远景雾截断距离与天空大气透视比例；不触碰局部河雾/山谷雾的模型和材质。
7. 没有调用 Static Properties - Height Fog，因为本机蓝图的该函数还会写全局 Lumen/云层 CVar。本次只调用雾目标绑定接口并更新相关组件，未更改全局渲染 CVar、光追或 Lumen 质量。
