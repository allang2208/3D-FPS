# 暴风雨云层与日月透光调整（2026-09-19）

用户反馈暴风雨云层过黑、太阳和月亮完全消失。本次继续使用现有 UE 体积云与唯一天气控制器，在 `UStormCloudComponent` 内调整运行时材质和灯光倍率。

原实现同时叠加了高密度云层、云底遮蔽、天空光降亮、直射光降至 25%、日月光盘降至 0.5%。现在保留云层本身的遮挡，减轻额外的整体压暗。厚云仍可遮挡日月，薄云和间隙应保留柔和亮区；不将日月光盘绘制在云层前面。

## 满暴风雨参数

| 项目 | 原值 | 本次值 |
| --- | --- | --- |
| 云消光密度 `StormCloudDensity` | 0.010 | 0.0065 |
| 云覆盖偏移 `Cloud_GlobalCoverage` | 0.045 | 0.012 |
| 风暴云形权重 `StormClouds` | 0.22 | 0.12 |
| 云层厚度 | 1.1 km | 1.0 km |
| 云底天空光遮蔽 | 丘陵 0.10 / 其他 0.22 | 0.06 |
| 天空光倍率 | 丘陵 0.90 / 其他 0.72 | 1.00，沿用昼夜基线 |
| 日月直射光倍率 | 0.25 | 0.55 |
| 日月光盘额外倍率 | 0.005 | 0.65 |
| 普通云 RGB 反照率目标 | 0.92 / 0.94 / 0.96 | 0.96 / 0.97 / 0.98 |
| 风暴云 RGB 反照率目标 | 0.58 / 0.62 / 0.67 | 0.76 / 0.79 / 0.82 |

日月光盘倍率不等于最终屏幕亮度；其后仍受光源、云层及大气影响。材质向量 alpha 从原材质读取并保留。所有目标值沿现有天气过渡插值，退回晴天时沿用原恢复路径。旧关卡中保存的 0.010 密度在 BeginPlay 迁移为 0.0065，其他自定义密度保留。

夜间仍由原昼夜控制器提供较低的太阳／月亮和天空光基线，不新增灯光，不抬高全局曝光，不修改闪电与枪口火光，也不导入另一套 Fab 云系统。
