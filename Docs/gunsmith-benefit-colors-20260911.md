# 改造栏增强/削弱颜色

按用户要求统一改造项目说明、改造后数值与变化列的颜色：增强使用 Success 绿色，削弱使用 Danger 红色，无变化使用 TextSecondary 灰色。移除本面板削弱项原有的琥珀色，页脚图例同步修改。未更改其他界面的通用 Warning 颜色。

差值仍是“改造后减比较基准”，颜色按指标收益方向决定：

- 后坐力指数、垂直/水平后坐角度、抖动、腰射散布、开镜/换弹/射击间隔和回稳耗时：降低为绿色，提高为红色。
- 枪械稳定性、伤害、容量、射速、距离和弹速：提高为绿色，降低为红色。
- 原厂/当前比较基准保持中性色，变更颜色只用于改造结果与差值；无数值变化显示灰色破折号。
