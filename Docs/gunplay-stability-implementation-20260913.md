## 已修改内容

### ADS 高频抖动

`FWeaponHandling::ADSJitterMultiplier = 0.45`。`AFPSGAMECharacter::ApplyShotFeedback` 用当前连续的 `WeaponADSFactor`，把高频位置和旋转脉冲从腰射的 1 平滑缩放到完整 ADS 的 0.45。枪械及镜头共用该脉冲，只在源头乘一次。

该系数仅用于高频 jitter，不额外缩放弹道后坐角度、枪体主要后坐冲击或 FOV。原有 ADS 额外阻尼、瞄具姿态限制及镜头噪声设置继续使用。45% 是来源于 Godot 归档的初始调校值，本轮没有运行手感验收。

### 双向评分与连续恢复

`FWeaponHandling::FromIndices` 保留原厂参考校准及抖动与恢复的平方根关系：

1. 基础幅度 `q = clamp(ShakeIndex, 0, 400) / 100`。
2. 基础评分 `B = 100 / (1 + 0.5*q + 0.5*sqrt(q))`。现有四把枪的基础值不变；原来极低幅度区用于评分的下限被移除，使基础零抖动连续趋向100分。
3. 目标评分 `S = clamp(B * 所有稳定性倍率的乘积, 0, 100)`。增益和减益都经过这一步，不再仅在倍率大于1时处理。
4. 当 `S >= 25`，严重程度 `v = 100/S - 1`。低于25分时，使用该反函数在25分处的切线延伸 `v = 3 + (25-S)*0.16`；低分段的值和斜率在接点连续，0分也有有限的反馈参数。
5. 求解 `x*x + x = 2*v`，以避免相近数相减的形式 `x = 4*v / (sqrt(1+8*v)+1)` 实现。实际抖动幅度为 `x*x`。
6. 反馈弹簧时间倍率为 `max(0.25, x)`。保留解析弹簧与阻尼比，最短恢复时间倍率为原厂参考的四分之一。

100分时抖动幅度为零，恢复时间倍率连续落在0.25，不再递归切换回0.5。枪体主要后坐仍保留正常回弹；控制瞄准点不会自动回原位。零分在反函数延伸段中具有有限幅度和恢复时间，不会除以零。

`ADSRecoveryMilliseconds` 始终给出同一弹簧的理论90%包络恢复时间，最短约50.06ms；不再在零抖动处强行显示0ms。面板提示已解释其含义与作用边界。
