# 191 / A762 开火前后往复：与 M4、HK416 对照

用户反馈 M4、HK416 的后坐力动画较好，QBZ-191、A762 表现平淡，要求排查并参考调整。本批读取实际 UE 压缩动画和当前握姿配置；没有启动游戏、录制画面或进行实机手感验收。

## 本轮排查结果

沿 `LoadAKMAnimation`、`UpdateGunplayAnimation`、`ApplyShotFeedback`、`UpdateViewmodel` 的当前加载与消费路径读取以下资产。以 `WPN_RearSight` 到 `WPN_FrontSight` 的枪轴投影 `WPN_root` 位移，按 240 Hz 采样，不将不同枪型骨骼的局部 XYZ 直接比较。

| 武器 | 腰射动画后退峰值 | 到峰值时间 | ADS 动画后退峰值 | 前向回弹 |
| --- | ---: | ---: | ---: | --- |
| M4 | 1.934 cm | 33.3 ms | 2.323 cm | 约 0.150 cm |
| HK416 | 1.934 cm | 33.3 ms | 2.323 cm | 约 0.149 cm |
| QBZ-191 | 0.488 cm | 66.7 ms | 0.471 cm | 几乎没有 |
| A762 | 约 0 cm | — | 约 0 cm | 没有 |

当前 M4、HK416 的基础开火轨迹几乎一致。191 的原动画冲击更小、更晚；762 的 0.1 秒开火动画保留机械/手部来源，但枪根几乎静止。这里是**动画层**数据，不是游戏内总位移：191、762 已有额外程序补偿及弹簧层，不能据此说游戏中的 762 完全不后退。

现有补偿在 33 ms 到峰值后，仅按 0.11 秒时间常数指数衰减，没有 M4 的前向回弹。191 使用“参考峰值减自身峰值”作为幅度，但两条曲线峰值时刻不同，补偿并未真正对齐整段运动。实际 M4 在约 0.15 秒已越过归位点，旧程序曲线此时仍有明显后退残量；因此仅看峰值相近，不能说明每发往复节奏相同。

当前 A762 的基础后坐力索引是 75、稳定性倍率为 1.25，射击间隔约 66.7 ms；191 后坐力索引为 100、间隔 90 ms。A762 本来就有较弱、恢复较快的程序弹簧；本批保留这些设计数值。未读取或改变玩家当前改装、强化、技能或存档。

实际配置中，HK416 的 5 份、191 和 A762 各 4 份握姿 Profile 均没有改写开火时的枪根轨道，也没有保留另一份开火序列。因此这次对 191、A762 基础曲线的补偿同时适用于这些握把。M4 各握把保留自己的作者序列，本批仅以基础 M4 为参考，不改动它们。

## 已实施

- `Source/FPSGAME/Weapons/RifleAxialRecoil.h`：由本轮 UE 资产读数生成 60 Hz 紧凑曲线，保留 M4 实际的后冲、过零、回弹和衰减；不在运行时读取文件或采样参考资产。
- `Source/FPSGAME/FPSGAMECharacter.cpp`：仅对 191、A762 替换轴向补偿。191 按同一时间扣除自带的弱脉冲，避免与新曲线重复叠加；A762 使用完整参考轴向曲线。横向、转角、镜头抖动、弹簧和其他枪型保持原实现。
- 腰射目标为 M4 原动画约 1.934 cm 的轴向行程。ADS 使用同一参考动作的曲线形状，但峰值控制在 **1.5 cm**，只加直退，不增加转角；沿用现有瞄准位移上限。该幅度是表现配方，不是包含弹簧后的游戏内总位移。
- 这两把枪的补偿与开火动画都从 `LastShotWorldTime` 计算实际经过时间，避免新一发先被推进整帧，再与原动画错相。实际射速、补弹、伤害、散布、控制器弹道后坐力、枪匠索引不变。
- 动画资产和稀疏握姿差量均未修改，因此不需要重烤或重制 Profile。
