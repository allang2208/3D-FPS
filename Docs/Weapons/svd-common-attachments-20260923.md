## 目录与运行行为

| 槽位 | 选项 |
| --- | --- |
| 瞄具 | 原厂 PSO-1；全息；全景红点；2× 棱镜；1–6× LPVO |
| 枪口 | 原厂消焰器；普通消音器；战术消音器；制退器；钛金制退器 |
| 前握把 | 原厂护木握持；垂直；战术垂直；45° 侧倾；棱镜阻手器；共振二代 |
| 战术设备 | 无；激光；手电 |
| 枪管 | 现有通用标准／轻型短／重型长的数值选项，外观保持原枪管 |

15 个实体通用配件沿用现有选项 ID 与数值，SVD 基础伤害、弹药、射速、弹匣和换弹时钟保持原设置。目录在 `gunsmith.json` 的 `ue_svd` 条目中独立登记；枪管继续由 `common_options` 合并。

安装通用瞄具时隐藏原厂 PSO 的镜体、夹具和镜片，显示 SVD 私有侧置导轨桥；选择原厂选项后恢复完整 PSO。原厂为 4×，红点／全息为 1×，棱镜为 2×，LPVO 为 1–6×，概览、ADS 倍率与分划使用同一状态。原厂 PSO 不占用跨枪配件 ID `pso1_4x`，该 ID 仍只开放给 AKM、A762、PKM。

枪口件替换原消焰器完整材质分区，使用实际后端连接面和明确出口方向，枪口烟火／射击起点随附件出口更新。消音器接入已有消音音效分支。移除后恢复原消焰器。

激光／手电沿用现有照明、遮挡和 ADS 汇聚逻辑，保留发射口 Socket；发射方向仍由枪械瞄准轴确定，不使用插座横轴猜测方向。

## 几何、材质与动作

- 新增模块化 SVD 骨骼网格，保留原 UV、几何、Manny 手臂及绑定；只为原厂消焰器增加可独立隐藏的材质分区。原 PSO 三个分区继续使用已有表面材质。
- 私有瞄具侧桥、握把底座和战术侧座通过实际 SVD 网格表面求交制作，包含封闭接触垫、桥臂、导轨和固定螺栓。配件主体轮廓和已接受的抓握区不做非等比缩放。
- 17 个静态网格包含 15 个选项、LPVO 活动倍率环和瞄具侧桥。瞄具保留各自光学局部坐标；握把和战术件直接表达在 SVD `WPN_root` 米制局部空间，运行只做 0.01 骨架单位补偿。
- 按 SVD 最新 Receiver 表面参数制作两张 4K 涂层纹理，使用 5 cm 物理尺度 UV2；复制源材质图保留 UV0 结构法线、刻字、聚合物、橡胶、钛金装饰、光学分区与镜内消光。干湿映射独立保存在 `DA_SVD_AttachmentWetMaterials`。
- 四个接触动作族（垂直、侧倾、阻手器、共振）各 12 段，共 48 段，120 Hz；战术垂直复用垂直接触族。覆盖待机、ADS、两种射击、装备、普通／空仓换弹、检视、快速近战和冲刺进／循环／退。
- 指组来自项目已采用的 AKM 同骨架抓握；按本枪安装变换适配手掌、肩肘和扭转骨。换弹保留原 SVD 的取匣、插匣、压实、右手拉栓及机械轨道，仅在退握与回握区间过渡；快速近战保留现有节奏、命中时刻及枪托路径。

枪匠预览、草稿应用、取消、动态武器图标和保存继续使用现有装配入口，新增专用资源预加载。没有改写用户存档。
