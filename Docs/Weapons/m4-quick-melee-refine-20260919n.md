# M4 快速近战 N：右手换向与自然腕臂衔接

用户反馈 M 腕部仍呈直角并要求检查。诊断发现：M 接触帧的腕轴折角约 105°，即使在固定肩位与握姿下重新选择肘位，理论最小仍约 97°。因此只补 forearm twist 或小幅转肘不能修复。

N 从 K 作者源制作，允许整只右手绕后握把轴线换向，再根据手掌自然方向求肘位与前臂支撑。保留手指原抓握形状，但不再声称整只手相对枪的朝向不变。枪械轨迹、左臂、肩位、骨段长度与 0.9 s / 0.1667 s 时序保持。

六套已在当前编辑器内导入保存。已完成本次要求的源骨链、接触邻近、模型预览与 UE RAW/COMPRESSED 姿态检查：接触腕轴折角约 18°，全动作最大约 23.4°；压缩后结果一致。未启动游戏或执行其它玩法回归，等待用户实机反馈。
