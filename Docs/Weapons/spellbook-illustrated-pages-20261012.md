# 魔法书新增十六面插画内页

用户要求增加有内容的书页，延续现有图案风格，并减少在原有几页之间反复翻动的重复感。

## 制作内容

- 7 张真实双面薄纸，每张有 8 节弯曲骨骼；加上左右两侧固定内页，共 16 个不同插画面。
- 草药：根茎解剖、菌菇孢子、蕨类种子、花叶结构。
- 炼金：蒸馏装置、研钵矿粉、药剂器皿、坩埚炉具。
- 星象：星盘、月相、元素转化、水晶晶格。
- 符文：保护法阵、羽翼与气流、生命树、四元素图式。
- 纸张延续暖褐旧纸、棕色细墨线、低饱和植物色及细小手写批注。新增插画使用内置 image_gen 生成，未将原作者图片标作生成内容。
- 四张 2×2 贴图对应 16 面，各页正反面分别分配；图集纹理与薄纸边缘使用不同材质，避免把插画拉到纸边上。
