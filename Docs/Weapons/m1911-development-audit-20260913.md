## 发现与修复

| 问题 | 原因与处理 |
|---|---|
| 卸下或切换后，旧配件可能再次出现 | 档案刷新最后递归显示枪体子组件，覆盖配件自身的装备可见性。末尾改为只设置枪体可见性，配件保持各自状态。原厂枪口销毁枪口实例的既有处理一并审计。 |
| 全息与红点切换可能留下错误材质 | 同一静态组件的旧材质覆盖继续作用于新网格槽位。换网格前清除覆盖，然后按新配件重建金属、玻璃及雨滴材料。 |
| 尝试加载不存在的手枪检视动作 | 当前认可动作集没有检视片段，去掉虚构的 `A_M1911_inspect` 加载。 |
| 关闭改造台后枪身与双手消失，只剩静态配件 | 实际复现为导入参考包围盒未覆盖动画后的蒙皮顶点。遍历 12 个现用动作、904 个姿态及全部 LOD0 蒙皮顶点，按测得范围加 10% 余量，设置 M1911 `BoundsScale=4.17`；换回其他枪恢复 1。修复后实际持枪截图中枪体和双手恢复。此值属于当前资产，不能套给所有手枪。 |
| 改造台显示错误口径、初次进入没有选项 | 标题将非 7.62 统一标成 5.56；默认选中手枪不支持的弹匣类别。按弹药 ID 显示 .45 ACP / 5.8 / 7.62 / 5.56，初次进入改选该枪支持的首个类别。 |
| 编辑器可加载，但打包可能遗漏主体或动作 | 字符串加载目录只列了近期配件。补齐 RearFinish、Contact、ReloadReady 和 Integrated/Audio 的 AlwaysCook 路径。已有 ColdSteelData UFS 暂存机制继续使用。 |
