# 伐木斧双手奔跑摆动

按用户要求，移动以当前 H4 双手待机为基础：斧刃朝外，左手降低约 2.2 cm、右手抬高约 2.2 cm，双手保持现有握点与手型，斧头、手腕、前臂和上臂整体随步伐摆动。姿势及装备动作见 [H4 持握与 V5 攻击](axe-h4-pose-family-20260919.md)。

## 接入

- 斧头移动改为持续采样当前 `Idle`（H4），不再加载或播放旧单手 `Walk`。镐的原有动画分支保留。
- `ProductionAxeLocomotion.cpp` 叠加整组位移与旋转，旋转中心取当前双手的中点，避免绕相机大幅甩动。奔跑层复用待机资产，不需要另一套手型或独立奔跑 FBX。
- 节拍直接取 `UFPSFootstepAudioComponent`：两次落脚组成一次左右摆动，每次落脚对应一次上下起伏；转角略滞后于位移，表现斧头的重量。
- 慢走／冲刺通过实际移动速度和冲刺状态控制幅度；起跑、停跑使用指数平滑。停止、离地、滑铲、闪避以及动作占用时摆动归零。
- 挥砍起势时快速退掉奔跑层，确认命中时完全归零，保持原有镶嵌停帧。原有攻击轨迹、采集判定、伤害和命中镜头时序不变。
- 换工具时清理累计姿态，防止斧头摆动残留给镐。

## 初始调参

相机空间 X 前后 / Y 左右 / Z 上下，以下为平滑前的目标半幅。实际表现还受速度与过渡权重影响。

| 参数 | 慢走 | 冲刺 |
| --- | --- | --- |
| 前后位移 | 0.30 cm | 0.65 cm |
| 左右位移 | 0.80 cm | 2.80 cm |
| 上下位移 | 0.55 cm | 1.65 cm |
| 俯仰 | 0.30° | 1.20° |
| 偏航 | 0.35° | 1.20° |
| 侧倾 | 0.65° | 2.40° |

参数入口为 `UProductionToolComponent` 的 `Production | Axe Locomotion`。平均持斧位置保持待机高度，取消斧头原有冲刺后移 3 cm、下移 6 cm 的偏移。
