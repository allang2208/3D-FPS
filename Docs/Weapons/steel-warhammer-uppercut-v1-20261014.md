# 双手战锤上挑 V1

按用户要求参考当前双手剑上挑，扩大握距和挥动幅度。第一人称作者源取 `SwordUppercut20261003/GripRecoveryV15/LongGrip`，以当前战锤 `NormalComboV4` 待机作为首尾。运行时继续使用双手剑当前的独立上挑时钟。

## 动作与握持

- 右下蓄势、前踏挑起、高位制动、支撑回收，保留源动作的慢蓄势和快速释放节奏。
- 作者动作长 2.05 秒、240 fps。共用当前上挑前踏映射后，实际动作约 2.28 秒：1 秒准备、0.28 秒前踏，主挥动结束约 1.305 秒，接触窗结束约 1.355 秒。
- 挥击阶段两掌沿柄轴目标握距 29 cm；从战锤待机约 22 cm 平滑分开，收势回到同一待机。右手保持靠锤头一侧，左手保持靠柄尾一侧，右手轴向握点在扩大握距时向前滑到 34 cm。
- 源剑和锤的原生绑定朝向不同，先通过各骨的参考绑定做完整形变传递；没有直接复制局部欧拉角。扩大握距通过两侧完整肩臂组沿柄轴搬移；上臂、前臂、手腕与手指沿用源动作的相对关系，不附加拧腕、不缩放骨段。
- 整个肩臂与武器组增加低到高约 17°、横向约 10°的随身摆动，配合约 7 cm 高低位差和 4.5 cm 前送。扩大的是动作弧线，没有修改武器模型尺寸。
- 上挑进入时清除砸地的地面接触约束；使用原生 V7 手模、既有皮肤材质和原有装备外观。

## 现有技能接入

装备双手锤后使用快捷栏已有的“上挑”，不新增技能 ID 或存档。双手剑保持原分支；采集斧、镐、铲仍不能使用此分支。快捷槽显示动作准备、冷却、体力和“上挑中”，技能说明补充双手锤。

伤害使用同一上挑等级和同级重击 70% 公式，读取实际战锤的伤害与改造；削韧类型为钝击。单目标命中、基础体力 25、基础冷却 8 秒、距离成长和最高档修炼沿用原上挑定义。成本与冷却在释放点提交，释放前取消不扣费。动作速度不受普通武器攻速影响。

客户端预测动作，服务器独立验证装备、占用和资源并结算。前踏复用现有 150 cm、0.28 秒连续胶囊位移及遇障／断崖处理；远端服务端不重复推进位移。接触方向取同一作者轨迹生成的锤头弧线，范围与宽容半径沿用上挑口径，服务器无需加载第一人称骨架。每次最多命中一个目标，不附带砸地冲击波或额外重击眩晕。
