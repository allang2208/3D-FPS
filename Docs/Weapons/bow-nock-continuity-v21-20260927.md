# 搭箭动作连续性 V21

用户反馈右手搭箭僵硬、不连贯。本次检查当前 V16 搭箭作者曲线、手腕/肘部解算和运行时状态切换，完成三个新片段与衔接修改。未启动游戏或制作验收截图。

## 找到的具体原因

- V16 快速动作在 90% 接触处直接改为固定弦口位置，但进入该点的 Hermite 切线不为零。源曲线有限差分显示此处约 147 cm/s 的运动直接停下。
- 手指在接弦之前已经完成大部分勾弦，携箭阶段缺少腕部转动和接触后的分指收势。
- ChainNock 从释放位置绕回很低的待机取箭点，0.20 s 内右手往返路程偏长。
- 手工 Nock 末帧与 Draw[0] 不同：源作者坐标中，右腕位置相差约 29 cm，弓握点相差约 20 cm。运行时先转 Ready，再走额外 DrawEntry，造成退手、抬弓和重新接弦。
- 原搭箭入场使用静止旧姿态与持续播放新姿态混合，会削弱新动作前段的运动，随后恢复速度。

以上为源动作及代码诊断，不是游戏实测距离或渲染结论。

## 动作修改

- `Nock`、`QuickNock`、`ChainNock` 改用固定接弦终点和连续携箭路径；明确让到达接触点的切线归零，避免接触瞬间硬截断。
- 携箭时加入小幅腕部转动，接触后渐渐回正；承力三指与拇指、小指分时收拢，末帧仍回到原有已拟合勾弦手型。
- 缩短连续射击时右手的右下补箭弧线，并对源肘轨迹做相邻帧插值，避免短动作中按整帧跳选肘部引导。
- 三段均按 240 Hz 烘焙，保留原 V7 裸手、Bow 原生骨架、骨长、手掌与弦的最终接触。没有更换手臂网格或扩大骨骼。
- Nock 结束姿态调整到 Draw[0]；已搭箭 Ready 保持该接弦姿态。继续按住左键时直接开始拉弓，带入跨过动作末尾的本帧余量；稍后再次按左键也不再额外等待入场。
- 新增 `CaptureCarry`：对新动作首帧与当前姿态的局部差值做短暂衰减，新动作本身保持播放速度。既有 Release 随动与其他动作的混合方式保留。

快速入场仍为 **0.20 s**；R 键搭箭仍为原 **0.68 s** 及箭台改造倍率。Release/Recover 中仍可立即开始下一轮，未恢复后摇输入锁。箭在约 34% 进度随手显示，快速搭箭 90%、手工搭箭 82% 的接弦音效时点保留；成功放箭才扣箭。
