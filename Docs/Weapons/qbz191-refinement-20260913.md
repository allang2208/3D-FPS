# QBZ-191 材质、动作与导轨配件修正（2026-09-13）

本轮按用户要求检查原素材、当前材质图和动画源，完成修改与接入。没有进行修改后的游戏测试、截图、渲染验收或回归，最终观感由用户自行确认。

## 原因

- 本地下载包只有一份嵌套 OBJ 源模型及枪体/弹匣的 BaseColor、Normal、Metallic、Roughness。原枪 19,048 顶点、37,883 三角面，八张相关贴图均为 4096×4096。未发现独立高模或 LOD 文件，不能认定用户误下了低模版本。[作者页面](https://www.fab.com/listings/7b90d34d-2654-4965-8e82-074ea1784e1d)也只列 OBJ 与这些贴图。
- 原始作者图集及轮廓的精度有限；初版重建网格时还丢弃了源自定义法线并将全枪设为平滑。上一轮 SurfacePolish 已补充倒角与加权法线，枪体升至 112,263 顶点、224,486 三角面，仍不是另一份高模。
- 当前实际加载的三种 SurfacePolish 材质都存在确定的粗糙度断线：脚本给 Clamp 使用 `Input` 引脚名，但引擎实际是无名输入；调用失败未被处理。保存后的 Clamp 输入均为 None，原粗糙度贴图不参与着色。金属遮罩、法线贴图与色彩空间仍有连接，因此不能把问题统称为“贴图没加载”。
- 原 QBZ 普通/空仓换弹在 28.5–29 帧出现枪根半帧约 18.4° 转动，42.5–43 帧左臂半帧约 60° 跳变。异常存在于 Blender 源姿态；只降低 UE 插值或延长混合不能修复。
- 装备沿用 AR 后拉柄手位，空仓换弹将同段动作追加到普通换弹末尾；手位和运动不适合 QBZ 左侧拉机柄。配件原先只开放全景红点，其挂点仍用 M4 瞄线偏移；四类握把没有 QBZ 动画映射。

诊断原始数据：`SourceAssets/QBZ191Refine20260913/source_diagnosis.json`、`ue_diagnosis.json`、`authoring_measurements.json`。这是修改前的检查，不是修改后通过报告。

## 已完成的修改

- 新增独立 Refined 材质，修复 Clamp 无名输入，恢复原粗糙度图的变化；保留原色彩、金属遮罩及法线细节。枪体/弹匣/瞄具分别绑定，当前手臂材质不变。保留已经完成的硬边倒角几何，没有再通过全枪细分堆面数。
- 以原动作的 29/76/95 帧取匣、插入、压实合同为基础，重写连续枪根运动、甩匣和取新匣轨迹、左右手的完整手臂求解。握持段让手相对弹匣固定；退握、回握走侧方过渡，保留手指骨长、局部位移与缩放。
- 空仓和装备改为 QBZ 侧拉机柄的手位与行程。拉栓时弹匣固定在弹匣井；装备的拉动/释放音按同一 0.72 秒时钟调度。普通换弹 2.1 秒，空仓 164/60 秒不变，弹药结算及改造倍率沿现有系统。
- 制作并导入 35 段动画：基础枪械及垂直握把、45°侧倾握把、棱镜阻手器、穿孔三角握把，每族各有 idle、aim、fire、aim_fire、reload、reload_empty、equip_charge。接触动作以 240 Hz 烘焙、其余 120 Hz，使用连续四元数和现有视模压缩设置。
- 垂直、侧倾、阻手器复用已接受 VRE 成组指型；三角握把复用其专用手型。按 QBZ 安装面移动整手及肩肘支撑，没有把 M4 动画直接挂到 QBZ 私有骨架。
- 枪匠开放已有四种瞄具和四种前握把。安装以源模型导轨为基准：顶部冠面 Z=0.096473 m，下方接触面 Z=0.040546 m，前握把纵向 Y=-0.295 m。三角握把额外抵消其已有 M4 bind-space 烘焙变换；安装矩阵与动画作者参数共用 `mounts.json`。
- 配件仍走现有角色、枪匠草稿/应用、物品实例与展示入口。本轮复用范围为导轨瞄具和前握把；弹鼓、枪托、枪口没有新增兼容项。
