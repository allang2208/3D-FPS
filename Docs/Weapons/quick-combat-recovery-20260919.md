# 枪械快速近战：recover 直接衔接当前待机

用户反馈收势先到接近待机的位置，再二次回正。本次调整运行时表现切换，保留已制作的 M4 N、QBZ191 O、AKM/ASH-12 与手枪动作资产。

## 修改原因

`UpdateViewmodel()` 原先在整段忙碌状态下保持动作展示位置。即使近战动画回到原握姿，组件仍处于 `M4ActionViewmodelLocation`；状态结束后才通过另一次指数插值返回腰射位置。另一个时钟 `ActionElapsed += DeltaSeconds` 也可能和动作状态的绝对时钟错开，步枪结束状态时还会留下活动动画直到它自己的计时结束。

## 当前行为

- 整组枪械/手臂的动作展示偏移从动作总长的 60% 开始回到腰射锚点，至结束严格归零。0.9 s 步枪对应 0.54–0.90 s。
- 动作末尾 22% 平滑交给动画图下层的实际待机/瞄准/移动姿态，使用当前枪械、弹匣和握把分支。0.9 s 步枪对应 0.702–0.90 s；手枪按自身实际时长换算。
- 两段交接使用端点速度和加速度均为零的五次曲线；组件偏移在 recover 中完成归零，不延迟到动作结束后。
- 快速近战姿态读取 `WeaponStateElapsed`，与状态截止时间一致。结束时步枪和手枪都清除活动动作，并把组件偏移设为终点，避免近战组件晚一个 tick 结束时重新引入偏移。
- 保留击打、手指抓握、动画时长、命中时刻、音效、伤害及冷却。

实现位于 `Source/FPSGAME/FPSGAMECharacter.cpp`；纯计算参数位于 `Source/FPSGAME/Weapons/QuickCombatRecovery.h`。没有新增反射字段、对象或网络状态，仅改变本地第一人称表现。
