# RSH-12 弹巢残留与装填孔位修复

范围：用户明确要求排查和修复弹巢右侧模型残留、子弹装填偏孔和入座缝隙。沿用五发容量、715 非开火动画与现有 RSH-12 单动开火／拨锤流程。

## 原因与制作改动

- 715 原枪几何已由原导入脚本移除；保留的 donor 几何只有手臂。
- 原 RSH-12 后端退壳盘 `13_l` 被默认绑定到 `WPN_root`，开巢时留在枪身上。改绑 `WPN_Extractor`，随弹巢开合和退壳行程移动。
- `4_l` 的三个独立壳体中，前端同轴退壳杆被当作吊臂。将杆单独绑定到 `WPN_Extractor`；其余壳体保留 `WPN_Crane`。
- `12_l` 包含枪身前端固定件和右侧解锁按钮，原来整件绑定退壳器。改绑枪身，避免按钮随退壳器漂移。
- 旧孔位按 `(x=0, z=50.485 mm)` 和 `14.85 mm` 半径估算。现在从五个内膛口的各十二个点独立拟合孔心，并使用真实孔心布置五发子弹；弹巢轴心约为 `(x=-0.0188, z=51.4365 mm)`。
- 弹壳各自绕膛轴旋转，使十二边截面与相应孔口的面方向一致。保持原模型尺寸、UV 和源材质。
- 入座以弹壳底面定位，避免拿突出的底火最高点作为底面；底面置于真实后端面外 `0.01 mm`。子弹装填／退壳轨迹沿真实膛轴运动并保持对应入座端点，手部接触补偿仍沿用现有原生手臂 IK。
