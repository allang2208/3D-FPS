# 上挑 V15：对角镜头、左手支撑与握柄回位

2026-10-03。用户要求蓄力时镜头向右下移动、瞬间发力时甩向左上，微调左手，并明确要求重新检查 recover 中的手剑脱离。

## 定位与修正

读取当前标准柄和长握柄上挑的 SOURCE / COMPRESSED 指定姿态，与 V14 原生关键帧比较。读回位置与作者源相差约 0.002 cm，选定帧的 SOURCE / COMPRESSED 位置一致。运行时回位没有使用快速近战的 idle 混合层；问题已存在于作者关键帧。

旧回位继承早期 Slash2 换握过渡，武器和手腕分别经过父链插值，末段的握柄圆周接触失效。1.833 秒附近，标准柄左右腕到柄轴的半径分别比握持时多出约 21.0 / 29.3 cm；左手回位单帧跳移曾达 15.4 cm。这里衡量的是腕点相对原握持半径的变化，不把腕点到柄轴的正常距离误称为悬空。

V15 将握持写成「剑柄刚体变换 × 绕柄轴旋转 × 待机握点」。蓄势和回位的手掌沿实际柄轴圆周转动，握距及半径固定；右手仍靠护手，左手拇指／食指仍靠右手。剑柄、双手和辅助 IK 骨用同一帧重建。回位不再读取旧 Slash2 的末段漂移路径，而是从已认可的竖剑收势平滑返回同一个待机端点。蓄势也在既有待机与右下镜头外端点之间保接触过渡。

左手围绕柄轴微调 8°，联动肘极与前臂支撑，降低腕部折弯的代价阈值；保留手指局部抓握和骨段长度，没有反转拇指／小指排列。标准柄主收势的腕轴相对折角由约 24° 降至约 20°。主攻击及收势停留中的右手、右臂、武器轨迹仍来自 V14；不扩大到普通攻击。

## 镜头与节奏

- 蓄势：镜头局部向右、向下，并伴随小幅俯视／右转。
- 释放：保持 1.000–1.075 秒的快速上挑，同步转为向左、向上甩动。
- 制动后随回位平稳归零，保留原短促制动、前踏和落脚反馈；不修改控制瞄准朝向。
- 继续保留 75 cm / 0.16 秒前踏、1 秒蓄势、约 0.783 秒 recover、2.05 秒总时长及普通攻击双层音效。
- 不新增伤害、消耗、修炼或额外冷却。
