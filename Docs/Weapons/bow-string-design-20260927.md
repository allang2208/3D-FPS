## 1. 紧捻稳弦

- 稳定 ID：`steady_twist_string`；槽位：`string`。
- 定位：提前拉弓、精细瞄准。与原有轻量快弦的快速拉放路线区分。
- 卡片描述：紧密绞合的弦身便于稳定控弓，减轻瞄准晃动和腰射扩散并提高伤害；拉至满弓需要更长时间。
- 外观：炭灰双股紧捻主弦，夹一根低对比灰麻细线；螺旋紧密、纹理细，表面为消光纤维，无金属反光或发光。当前弦半径保持 0.09 cm，主要通过编纹与色调区分，不加粗挤占三指接触空间。
- 用户确定参数：`sway_mult: 0.85`、`spread_mult: 0.90`、`damage_mult: 1.05`、`draw_mult: 1.10`。
- 效果：瞄准晃动降低 15%，腰射扩散系数降低 10%，伤害提高 5%；拉满耗时增加 10%。子弹速度、满弓保持上限和耐力消耗沿用其余装备结果。
- 瞄准说明：当前满 ADS 随机扩散已经为零；本件的瞄准收益来自降低晃动，不能宣传为继续降低满 ADS 随机散布。

## 2. 柔芯长持弦

- 稳定 ID：`softcore_hold_string`；槽位：`string`。
- 定位：快速拉弓、节省单次射击耐力，适合连续狩猎。名称保留用户选定的“柔芯长持弦”，本次不提供满弓保持时间加成。
- 卡片描述：柔芯与编织外层组成的弓弦缩短拉满耗时，并减轻单次射击耐力消耗；子弹速度稍低。
- 外观：深棕主弦与暗橄榄色交编外层，编织节距比紧捻稳弦更疏，呈柔和蜡封光泽；保持纤维质感，不做橡胶软管或粗麻绳轮廓。当前弦半径保持 0.09 cm。
- 用户确定参数：`draw_mult: 0.90`、`stamina_mult: 0.90`、`speed_mult: 0.95`。不配置 `hold_mult`，保持其默认倍率 1。
- 效果：拉满耗时降低 10%，单次射击耐力消耗降低 10%；子弹速度降低 5%。取消原设计的满弓保持时间增加 20%。当前耐力在成功射击时按拉距结算，本件不引入持续扣耐力或恢复耐力机制。
- 子弹速度代价作用于现有初速度；不同时修改重力、箭种、伤害或额外写入射程倍率。

## 通用范围与制作合同

1. 两款作为传统弓弦的共享改造类型；首批适配当前猎手长弓的原装、游隼、磐木、静枝四款弓体。这四款共用现有中央接触与弦挂点。未来新弓按结构、长度、端部和手部接触配置适配，不能自动发放同一完整模型；复合弓、弩不默认兼容。
2. 沿用两段动态弓弦；弦梢、弦结点、箭尾及三指接触点全部取宿主弓。不得在弓体模型里再烘焙一根静态弦，不改现有 V7 手型、拉距或弓臂形变。
3. 首批以两份独立纤维材质表达编纹与色调，保持原程序化弦几何。编纹尺度随实际弦长处理，避免拉弓时大幅拉伸纹理；细纹主要通过底色与粗糙度表达，法线强度克制。
4. 模型贴合、材质和数值均由当前 string 改造选项进入同一装配、面板与射击计算；不在角色 Tick 中另叠倍率，不复制另一套弓数值。
5. 不赋予减噪加成：当前猎弓已有无声射击机制。耐久、断弦、淬毒、连射、自动搭箭均不属于本轮设计。
6. 改造件图标使用实际动态弦挂点、透明背景和统一灰阶；游戏中的弦保留本色。两张 1024 RGBA 图标已制作，图标线宽按统一规范作可读性补偿，游戏弦半径保持原值。材质由物理尺度纤维表达式制作，不使用概念图替代已导入资产。
