# 动作优先级与施法中断

2026-09-22 用户规则：切换武器优先级最高；快速近战第二，可以打断切换武器以外的动作。积蓄中断返还魔法值；发射但尚未成功阶段中断保留消耗、取消发射，之后不补发。

## 动作仲裁

- 切换主武器、单双持组合或手持工具：装备事务成功后，立即取消旧动作、旧输入和待执行请求，再应用新装备。失败的装备事务不取消正在进行的动作。
- 单持步枪、单持/双持手枪和剑的快速近战共享角色优先级入口；可中断换弹、检视、普通攻击、蓄力、格挡、旋风、突进、施法、翻越、闪避和滑铲。先确认当前武器具有对应快速近战动作，再清理旧动作。
- 拔枪/装备动作期间拒绝快速近战和射击/瞄准抢占。移除单持手枪通过开火或瞄准提前结束拔枪的例外；双持换弹也不再覆盖拔枪。
- 快速近战自身仍遵守原有冷却，不通过连按刷新或跳过冷却。菜单、死亡和没有可用武器时不启动攻击。
- 已结算的换弹插入点、枪内弹数及待拉栓标记仍跟随武器实例。快速近战后只恢复必要的拉栓/闭合尾段，不重复装弹。

角色入口：`FPSGAMECharacterActionPriority.cpp`。`IsSwitchingWeapon` 汇总单持、双持、剑与工具的装备阶段；`CanStartQuickCombatPriority` 给出高优先级动作的入场条件；`InterruptActionsForPriority` 清理低优先级动作。

## 施法阶段边界

| 当前阶段 | 高优先级动作到来时 | 魔法值 | 已发生效果 |
| --- | --- | --- | --- |
| 排队，尚未起手 | 清除请求 | 未扣费 | 无 |
| 积蓄/凝聚 | 施法失败，移除未完成实体 | 返还本次实际扣除值 | 无 |
| 已凝聚的火球/冰锥悬浮，当前没有施法手势 | 清除旧按键预览与排队请求，保留悬浮实体 | 保留 | 仍需玩家再次主动发射 |
| 发射前摇、推出但尚未成功发射 | 施法失败，取消回调与未发射实体 | 保留消耗 | 不延后补发 |
| 已成功发射/生效后的保持与收手后摇 | 立即让出动作 | 不返还 | 投射物、伤害、治疗、陨星、焰甲继续各自生命周期 |

火球/冰锥是两段式法术：`Raising` 是独立积蓄；之后的 `ReadyingRelease` 已属于发射前摇，不能按“尚未接触”一概退款。闪电、圣光和陨星为一次起手的法术，其初始 `ReadyingRelease` 是积蓄前摇，进入 `Releasing` 后即为不可退费的发射阶段。焰甲在 `Raising` 完成接触时生效，生效后的收手不能撤掉已产生的焰甲。

使用已有接触提交标记 `bLaunchCommitted` 区分发射成功前后，不以动画播放结束作为成功判据。中断先解除发射委托，再清除请求与手部占用，避免实体销毁回调把旧收手动作重新放回来。环绕飞剑清除未执行的连发请求；已发出的飞剑继续飞行。

`RecordGesturePayment` 记录扣费事务前后的实际魔法值差额，因此无限魔法、词条减耗和施法后换装不会按新属性多退或重复退费。魔法值返还沿用档案事务和上限约束。冷却沿用各法术原有规则，本次没有新增冷却重置。
