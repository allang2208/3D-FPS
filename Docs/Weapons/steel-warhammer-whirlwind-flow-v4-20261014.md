用户否定 V3 的位置、动作与顿挫，随后认可 V4 的挥动方向，但认为松手、单手外甩与回握没有表现出来。正式资产现已更新为 [V6 下垂出镜与双倍外甩](steel-warhammer-whirlwind-drop-v6-20261015.md)，保留 V4 的前段方向，按用户最新要求重做后半段。以下记录为 V4 当次制作情况，不能视为交接设计已获认可。

## 本次重做

V3 自定义了多组来回换向的位置／方向节点，并对每个分量使用换向处归零的切线；很多短段在同一位置同时减速，连续函数仍可能表现为反复停顿。左手在跟柄、固定世界撤手点、回柄之间反复混合，进一步改变了方向和速度。

V4 读取双手剑 `WhirlwindRecover_Manny_Editable.blend` 的完整连续姿态，前段以其肩、肘和右腕运动作为支撑及位移来源，锤柄跟随剑的方向，保持战锤原双手握点和手型。已核对正式剑运行路径：`A_RuneSword_WhirlwindV5` 的尾部由 `RecoverV6/import_recover.py` 写入 V6 收势；路径名 V5 不代表未更新。

末段从作者时间 1.16 秒开始，接入原轨迹的速度、加速度；只有一次右前方外送和一次回收，不再串联多次抬手、下摆、前送、反拉。外送顶点在作者时间 1.48 秒，右腕目标为相机坐标 `(0.22, 0.50, -0.245)` 米，避免继续使用 V3 过远的右侧目标。顶点无固定停留段。

左手先松指，再沿一条连续净空弧线离柄，经过左下侧回到握点后合拢，不再停在固定世界位置等锤子。右手全程保留完整手掌到锤柄矩阵；骨段长度、绑定、权重和原生手模不改。肩肘支撑从剑的完整姿态求解，前臂旋转保持连续。

收势曲线按实际播放时间制作，并烘焙回作者时钟：当前实际阶段为 `0.5 / 1.0666667 / 0.52` 秒，作者片段阶段为 `0.5 / 0.8 / 0.52` 秒。惯性段和离柄弧线跨越旋转／恢复交界时补偿采样速度差，避免在交界处突然变速。没有修改技能的真实时长或伤害角度时钟。
