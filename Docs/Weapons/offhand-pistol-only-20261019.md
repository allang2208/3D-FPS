# 主手空置时的左手手枪：续修（2026-10-20）

> R1 已被用户截图与反馈否定：屏幕中央仍有多余弹匣，右键会抬枪但瞄具偏离中心。下文 R1 的构建记录仅证明曾编译，不代表问题解决。当前续修见 [R2：弹匣显示与求值后 ADS 对齐](offhand-pistol-r2-20261020.md)。

用户否定此前持枪调整。本轮继续使用已经落盘的真实左臂网格和左手作者动画，修正运行时驱动；不重新启用负缩放或逐骨镜像，不替换现有 V9 手模。此前文档混合了数版互斥方案，原文保存在 `SourceAssets/LonePistol20261020/Before/Docs/Weapons/`，不能作为当前实现说明或成功证据。

## 当前合同

主手空置、副手槽装手枪时，左键开火、右键 ADS、R 换弹、快速进战使用左手持枪动作。物品归属仍在原副手槽，`ActiveFirearm()` 提供当前枪械身份；动作和弹药时钟统一由 `PistolDualWieldComponent::Hand(1)` 维护。主手视模只保留已有配置用途，不显示，不播放第二套单枪动作。双持两枪、法杖配副手枪保留原控制方式。

## 本轮源码修改

| 问题 | 修改 |
| --- | --- |
| 把 ComponentSpace 坐标再次乘组件逆变换，标定位置错误 | 从左手 `idle` 的动画骨轨直接累计到组件空间；按 UE 的 child × parent 次序；组件缩放仅应用一次 |
| 装配首帧、实时收枪动作被永久缓存为 ADS 基准 | 固定采样作者待机，包含实际姿态差量，不再强制 TickAnimation/RefreshBoneTransforms 来读当前动作 |
| 20 cm 的逐分量“近零”阈值把有效照门／准星排除，退回枪根至枪口 | 使用实际前后瞄具，不再用枪口轴替代瞄准轴；横滚读取武器的上方向 |
| 安装红点仍按铁瞄定位，弹道读隐藏的主手附件或错误的前准星 | 克隆附件时保留左手瞄具引用与实际 SightRear/Front/Up；无三点插槽时沿用该瞄具现有局部瞄点；标定和射击都读这套左手挂件 |
| ADS 与上一帧枪姿态互相反馈 | 手臂腰射会聚目标固定读取相机准星；ADS 的刚性定位和会聚使用同一个交接权重 |
| 每发射击把 ADS 混回腰射，覆盖后坐／蹲起／跳跃 | 开火片段保留 ADS；先混合基础机位，再叠加原有后坐及运动，保持枪与左手接触 |
| 换弹/拔枪/砸击期间继续瞄准，恢复入口不统一 | 非开火动作退出 ADS；动作释放后根据仍按住的瞄准键恢复；隐藏的主手状态机不再推进同一把枪 |
| 快速进战进入右手片段，左手路径又要求主手必须为法杖 | 左手单持进入已有左手砸击；允许无主手时保持该动作；身体表现与接触通道标记 PistolBashLeft |
| 弹量显示缓存、双持专属射击和换弹规则用于单枪 | 同步 Hand(1) 的弹量；ADS 射击沿用单枪精确瞄准；单枪 bloom 与换弹时长不再叠加双持惩罚 |
| 隐藏不存在的右臂分支、每帧诊断日志 | 删除额外骨链隐藏与临时 PROBE/MESH/LONEADS 输出；真实左臂资源原本只导出左臂几何 |
| 左轮倍率镜遮罩只隐藏主手视模 | 遮罩读取当前实际左手视模及其附件 |

适用现有左手家族：M1911、G18、Pit Viper 2011、DW715、RSH-12。按装备与附件变化失效标定，不在 Tick 同步加载资产。

## 落盘与构建

本轮修改 C++ 源码，复用原有已保存网格、动画和附件；没有生成或重导入 `.uasset`。修改前源码保存在 `SourceAssets/LonePistol20261020/Before/`，本轮构建日志及最终交付状态记录在同目录的 `build-*.log`、`delivery.json`。

正式 `FPSGAMEEditor Win64 Development` 和 `FPSGAME Win64 Development` 均返回 `Result: Succeeded`，基础 `UnrealEditor-FPSGAME.dll` 与 `FPSGAME.exe` 已链接落盘。日志分别为 `build-editor.log`、`build-game-completed.log`，产物大小与时间见 `delivery.json`。

初次 Game 构建在本轮新增的 `GetStaticMesh()` 返回类型推导处报错，已改为显式 `const UStaticMesh*`。第二次被并行新增的 Kukri 类缺少定义阻塞，等待其源文件落盘后完成构建，没有修改该任务的实现。保留两次失败日志，不作为成功证据。
