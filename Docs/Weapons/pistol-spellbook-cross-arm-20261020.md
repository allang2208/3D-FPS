## 动作分支

| 分支 | 表现职责 |
| --- | --- |
| 手枪＋书待机、行走、蹲姿 | 右腕驱动支撑点，整条左臂保持横向支撑轮廓 |
| ADS、开火、空仓待机 | 读取同帧右腕，沿用主枪瞄准线及后坐动作 |
| 冲刺 | 0.24 秒退出支撑，恢复原低位持书步态；停止后重新进入 |
| 换弹收书 | 冻结已显示的支撑目标和权重，再由原收书位移带整臂退出 |
| 换弹取书 | 沿用提前离手/取回时钟，在空手退出段开始恢复支撑目标，抬书回到横臂姿势 |
| 进食、喝药 | 原收书及消耗品动作继续占手，完成后回到此 carry 目标 |
| 施法、撞门、书本推击 | 动作层覆盖 carry，捕获现有姿态入场，恢复阶段接回 carry |
| 换武器、换主枪网格、翻越 | 清除支撑目标，按新装备重新进入 |
| 第三人称 | 使用原身体相对持书层，不将此第一人称镜头目标传入身体 IK |
