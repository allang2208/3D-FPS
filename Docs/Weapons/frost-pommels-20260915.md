# 寒晶剑：5080 配重锤与改造数值

## 本次范围

制作硬化配重、符文配重、魔力球配重三个独立模块，安装到现有 `frost_hilt_v1` 配重锤接口。可编辑源、生成回执及导入入口见 [作者目录](../../SourceAssets/FrostSwordPommels5080_20260915/README.md)。原装配重锤及旧候选源保留。

按用户选择，硬化配重保留已经开始的 `1024_cascade`；另外两款改为 `512` 级几何，三款均使用 4K 纹理母版。生成几何经本地减面和结构法线烘焙，复制原装安装口并制作连续过渡面，再作为独立静态模型导入 UE。

金属表面沿用原剑的纹理与材质参数。魔力球的蓝色区域从原剑刃纹理取得颜色和粗糙度，采用独立半透明水晶材质；安装座与金属肋保持不透明。符文配重的银白图案使用轻微周期发光。

## 改造规则

| 改造 | 结算 |
| --- | --- |
| 硬化配重 | 重击倍率直接 +0.15；击退距离 +10%；攻速 −10%；耐力消耗 +10% |
| 符文配重 | 魔法技能冷却 −15%；魔法值消耗 −15% |
| 魔力球配重 | 魔法伤害 +10%；魔法值消耗 +15% |

- 用户确认基础击退 **20 cm**，硬化配重 **22 cm**。击退与硬直时间独立，通过角色移动碰撞扫描推退；碰到阻挡停止。
- 同一次挥击的基础伤害与附加伤害全部结算后只推退一次。属性附加伤害继续提前计入武器面板，重击等动作倍率随后放大，各伤害类型再分别减免。
- 重击倍率加值单独累加。例如基础倍率 2.50，硬化后为 2.65；旧的乘数型改造保留兼容。
- 耐力消耗修正覆盖轻击、重击及防御受击。魔法消耗修正覆盖现有火球和冰锥。
- 改造台与物品摘要显示实际重击倍率、击退距离及魔法值消耗倍率。
