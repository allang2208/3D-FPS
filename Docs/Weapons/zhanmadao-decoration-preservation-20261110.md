# 斩马刀全部刀身的装饰色保护

按用户要求排查当前 `zhanmadao-modules.json` 的全部 8 种刀身，读取实际网格槽、目录覆盖材质及对应旋风材质，共 22 份材质图。再读取导出 FBX 的 LOD0 UV，以实际刀身覆盖的纹理区域区分装饰色与钢材底色。

| 刀身 | 排查结果与处理 |
| --- | --- |
| 原厂 | 原生图集中实际被刀身使用的区域有少量暖色细节；原保护遮罩为 0，已补保护。 |
| 延锋刃 | 保留原厂 UV，存在相同的暖色细节，已补保护。 |
| 重脊刃 | 保留原厂 UV，存在相同的暖色细节，已补保护。 |

| 腾云游龙刀身 | 鎏金纹样与钢材共槽，原保护遮罩为 0，已补保护。 |

| 逐风 | 青色嵌脊与青灰钢材共槽，原保护遮罩为 0，已补保护；独立银色旋流装饰槽不受覆盖。 |

22 份材质包含 11 个常规槽材质与 11 个旋风对应材质。旋风版本仍使用原生 PBR，没有剑身材质覆盖分支，因此本次无需修改它们。

## 实现

暖色细节从各自原生底色采样的正红色色度提取，保留原 UV、纹理过滤和渐变边缘。逐风单独使用其作者配方 `Metallic = .98 - .25 * band`，从原生 ORM 的金属度通道识别青色嵌脊，避免把整把青灰钢材都排除出改造范围。没有新增纹理采样。

同一保护区域接入底色、粗糙度、法线、金属度、各向异性和切线。钢质主体仍按原剑身材质模式变化；符文发光连接不变。

新增配方为 `SourceAssets/ZhanmadaoDecorationPreservation20261110/decoration_material.py`，复用上一轮的表面接线函数。共用材质安装器、背嵬刀身派生安装器及逐风安装器均接续该配方；重新制作派生材质时同时更新继承遮罩的输入合同。
