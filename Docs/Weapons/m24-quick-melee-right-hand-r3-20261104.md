# M24 快速近战右手 R3（2026-11-04）

用户在 R2 GIF 后指出右手手势仍不自然，要求参考原厂继续处理扭曲和穿模。本轮只调整改造组合的右侧肩肘、前臂、掌腕和手指；保留 R2 枪托前送路线、左手支撑、0.9 秒源时长及 0.25 秒接触。

## 判断与处理

- R2 握稳击打时的腕轴折角约 15°，主要问题是右侧转掌接近半圈；换握和回握中途则出现约 34–48° 的腕部偏折。腕轴指标与视图共同定位，不能把两种问题都交给腕骨。
- 原厂托握的动作顺序仍复用，但旧托握拇指局部旋转在当前原生手模中形成过强内扣。改用当前正常 idle 的拇指方向，只进行受限屈伸／小幅对掌适配，不再照搬旧拇指根部旋转。
- 按真实骨架枪托实体框架重新放置掌面；结合完整右臂支撑求解，而不是只用指尖到表面的距离决定姿态。保留原生大小臂长度与 scale，肘位在精确双骨圆上连续变化，辅助骨承接所属骨段。
- 持握区间直接固定枪根空间的完整掌指目标，避免过渡输入残差继续叠入握稳段。接近与退出时沿外侧避让，保留原厂松指／回握节奏，并分别适配默认、平衡、幻影和防滑握把。
- 实际皮肤的 JC 修形参加接触拟合，避免只用骨点或未修形皮肤得到静态无相交的假象。腕臂边界仅渐变旋转，不线性混合肘位来缩短骨段。
- 右侧差量以 240 Hz 烘焙，对齐基础动作的全部 30 Hz 帧点，减少差量插值跨越基础帧边界时出现的指尖位置尖峰。另用有界手指局部旋转细化拇指绕框和其余指尖接触，掌腕及手臂路线不随这一阶段改变。

## 源与保存范围

源目录为 `SourceAssets/M24QuickMeleeRightHandR3_20261104/`：

- `inspect_right.py` / `right_before.json`：原厂与 R2 的定向比较。
- `right.py`：右侧原生铰链和有界肘极支撑。
- `fit_stock_grip.py` → `refine_contact.py`：自然拇指与实际修形皮肤接触制作。
- `author.py`：在当前 R2 条目上只替换右侧轨道；左侧和枪械原轨道原样保留。
- `refine_finger_path.py` / `finger_path.json`：从 `arm_path_patch.json.gz` 进行手指局部避让，不对已经细化的输出重复叠加。
- `fit_clearance.py`、`fit_return_thumb.py`、`release_arc.py`：接近时从枪托下方抬手，退出时先打开钩在框边的指尖、降掌，再横移到独立后握把。默认和防滑握把分别拟合回握拇指的侧向开合。降低掌位时肘部重新跟随，保留大小臂长度。
- `M24_QuickMelee_RightHandR3_Editable.blend`：八种组合的可编辑动作及 JC 轨道。
- `preview_right.py`、`Review/`：本次判断右手用的掌侧／手背近景。
- `review_contact.py`、`right_contact_review.json`：右手及右臂顶点与真实枪体的定向采样；不代表完整三角形或连续时间的零相交证明。
- `publish.py`、`publish_receipt.json`、`BeforePublish/`：八份改造 Profile 的实际保存与发布前备份。

仅替换八份 `DA_M24_skeleton_*` 的 quick_melee 条目。原厂供体 Profile 和其他角色（含普通／扩容换弹）保持当前数据，无 C++ 或武器属性改动，不需要原生构建。本轮没有启动 UE 编辑器界面或游戏；右手近景与局部接触采样服务于用户本次提出的姿态／穿模判断，实际游戏观感仍待用户确认。

八份正式 Profile 已后台保存，`publish_receipt.json` 记录了每份资产的路径和保存后摘要。防滑握把的 5 发和 10 发版在枪身坐标中共用同一套右手轨迹，两者分别保留自己的装配、左侧动作和起止握姿。

对八种组合各取 58 个时间点，以带关节修形的手臂皮肤和枪体表面采样。射线奇偶、射线命中朝向和最近三角形内侧同时支持的最大进入深度为 0.746 毫米，出现在防滑握把回握的无名指。射线与表面朝向不一致的读数保存在 `ray_only_max_mm`。这些数据仅涵盖采样点，游戏内动作混合尚未测试。
