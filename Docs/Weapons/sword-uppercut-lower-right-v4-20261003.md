# 上挑 V4：右下出镜后按待机握法上劈

本版已按用户新要求替换为 [突刺握法上劈 V5](sword-uppercut-thrust-grip-v5-20261003.md)。以下为 V4 的历史制作与构建记录。

2026-10-03。用户否定 V3，明确要求先将手臂与剑移到屏幕右下端、移出镜头，然后保持待机持剑的方式快速向上劈。此次轨迹按用户描述制作，网络视频不再作为当前动作基准。

## 动作

| 时间 | 阶段 |
|---|---|
| 0–0.42 秒 | 当前待机姿势整体收向右下方，并略向内收，移出画框 |
| 0.42–0.49 秒 | 短暂保持出镜位置 |
| 0.49–0.67 秒 | 0.18 秒快速向上劈，剑刃沿用待机朝向 |
| 0.67–0.73 秒 | 小幅向上惯性余量 |
| 0.73–1.20 秒 | 平滑回到原待机 |

本版重新读取标准柄与长握柄的当前待机帧，整组搬运原生手臂、手指和武器骨骼。关节的相对旋转、骨长、辅助骨与双手握点保持待机关系，不再逐帧重新寻找剑柄滚转或肘极。位移烘焙在原生根骨关键帧内，关闭动画根运动提取与强制根锁；该位移属于第一人称视模，不驱动角色胶囊。

出镜位置按项目 75° 垂直 FOV、16:9 画框制作，另留手臂表面与剑身长度余量。当前作者位移为向右约 71.5 cm、向内 22 cm、向下 50 cm；此为视模摆位，不是角色肩宽或骨段伸长。制作计算不等同于用户屏幕上的实机验收。
