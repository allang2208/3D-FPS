# 战锤攻击、强化与普通攻击距离／间隔

按用户要求，以玄螭镇岳的攻击／强化公式为 100%，战锤全部公式系数取其 90%。用户随后明确战锤的属性来源为力量／体质，镇岳的精神系数对应到战锤体质项。普通攻击距离采用无延长部件的双手剑，基础攻击间隔为普通双手剑的 1.15 倍。

## 攻击与强化公式

`L` 为强化等级，`S`、`C`、`W` 分别为共用公式入口读取的力量、体质和精神。

- 镇岳：`round(45 + 5.6L + (5.1 + 1.01L)S + (4 + 0.69L)W)`。
- 战锤：`round(40.5 + 5.04L + (4.59 + 0.909L)S + (3.6 + 0.621L)C)`。

战锤最终使用力量／体质项；在强化等级、力量输入相同且战锤体质输入等于镇岳精神输入时，取整前公式为镇岳的 90%，沿用项目逐阶段四舍五入。不同体质／精神配点按各自公式计算。现有加工、武器精通、附魔、符文与各攻击段倍率继续按各自规则结算。

仅用于说明系数的算例：输入 S=C=W=10，+0 镇岳为 136、战锤为 122；+15 镇岳为 475、战锤为 428。未计外部加成，这些是公式计算值，不是实测结果。

真源为 `Content/ColdSteelData/combat-weapon-formulas.json:ue_steel_warhammer`，`AttackFormula` 按定义 ID 优先读取，已有强化等级和附魔数据继续保留。物品目录的旧基础占位 `melee_damage` 从 55 调至 49.5；改造台原厂基数同步来自目录，`ProcessedDamage` 的 Base／目录基数比仍为 1，不会重复扣除 10%。

## 普通攻击距离与节奏

- 普通双手剑基础距离 180 cm，经 `RuneSwordCombatTuning::ScaledReach` 的现行 ×2 得到 360 cm。战锤 `combat_reach_cm=360`，其近战扇形查询、单人／服务器接触以及浮窗／改造面板共用该有效距离。`melee_reach_cm=180` 保留为原始基准，未采用镇岳 225 cm 的长刃距离。
- 普通双手剑基础间隔 1.775s；战锤 `attack_seconds=swing_seconds=2.04125s`，即 1.775×1.15。角色攻速、附魔、部件和武器精通仍按各自原有路径作用；这里调整武器的基础间隔。
- 战锤接触点设为 1.24125s，沿用当前普通命中回收 0.8s，因此挥空结束和命中回收结束均为 2.04125s，再由原有 RateScale 换算。通过 `ProductionBluntCombo` 的现有作者时间映射驱动动作／镜头／声音及服务器接触时钟，无需重导已认可的 NormalComboV4 骨骼动作。
- 保留当前扇形角度、碰撞容差和战锤专属重击／冲刺／冲击波规则；只调整本次要求的普通攻击距离、攻击公式和基础间隔。
