# M24 改造材质统一（2026-11-04）

用户反馈改造后的整体材质不统一，要求排查并修复。本轮沿实际装配代码读取 29 个网格、59 个材质引用，覆盖原厂枪身、先进机匣、两种骨架后托、原厂及独立后握把、5/10 发弹匣、消音器、脚架、原厂六倍镜、七类通用瞄具及其活动环，并单独处理碳纤维枪栓的运行时覆盖材质。

## 原因

- 当前枪身使用 `StockContinuity20261031/MI_M24_Regional_host`：深色底色 `(0.026, 0.029, 0.032)`，原图颜色混合权重 0.04。其材质图把金属粗糙度下限设为 0.48；实例中名为 `Roughness` 的 0.40 并不是这块区域的实际基础粗糙度。
- 消音器、贴腮板和扩容弹匣上段仍使用旧 `MI_M24_Body_Static`：颜色、原图混合权重 0.20、细纹强度及区域粗糙度都与当前枪身不同。
- 先进机匣、脚架座的亮钢颜色最高约 `(0.082, 0.090, 0.100)`，原粗糙贴图权重达 0.80–1.00；骨架后托原图颜色混合权重 0.15，且没有按金属／聚合物分别处理基础色。后托生成素材的金属贴图又把大部分框架记成低金属度，单独统一底色仍会偏灰白。
- 脚架腿直接引用 PKM 表面；通用瞄具混用 M4、HK416、KV、热成像镜各自材质。先前部分瞄具仅调整粗糙度，没有匹配颜色、非金属区域或细纹。
- 碳纤维枪栓直接覆盖整个 `M24_Body` 材质槽，其母图仍是旧区域版本，安装该改造会让非碳纤维部分也回到旧枪身表面。

## 修复

以当前原厂枪身为参考，保存 31 份 M24 专用材质实例、16 份所需私有母材质，并重绑 27 个当前装配网格；原厂枪身与已经采用同版表面的原厂六倍镜保持原引用。统一同类金属底色、0.48 的基础粗糙度、克制的细颗粒与低频变化；先进机匣及脚架座保留自身结构贴图、AO 和遮罩，降低造成不同反光的过强粗糙贴图权重。

| 范围 | 处理 |
| --- | --- |
| 消音器、贴腮板、扩容弹匣上段 | 使用当前区域母图的静态专用副本，保留原 UV 图集、材料身份与刻字 |
| 机瞄、弹匣延长段、先进机匣、后托连接座、脚架座 | 匹配当前枪钢基础色、粗糙度及细纹，保留各自结构法线和遮罩 |
| 骨架后托 | 依实际局部坐标识别金属框架、托腮垫、肩部胶垫，替换错误的生成金属度遮罩；基础粗糙度分别为 0.48／0.59／0.72，保留源 UV、法线与标记；湿润分支也使用相同金属身份 |
| 后握把 | 保留聚合物、橡胶及防滑法线；匹配同类区域底色，保留合理的材质粗糙度差异 |
| 通用瞄具、倍率环 | 在 M24 私有实例／母图中适配；EOTH 在原湿润层之前调整干燥表面，KV 保留自身 UV 底色和法线，热成像镜只调整石墨金属壳 |
| 脚架腿 | 从 PKM 材质派生 M24 专用实例，保留原结构与湿润层，不修改 PKM |
| 碳纤维枪栓 | 保留织纹遮罩和织纹表面；其余枪身区域接回当前区域配方与法线强度；更新代码实际引用的稳定材质路径 |

镜片、分划、显示屏、刻字专槽、消光内腔、橡胶、电缆和刻意保留的铜／钛色饰件没有强制金属化。未修改共享母材质、几何、UV、法线切线、挂点、动画或本聊天上一轮换弹时钟。修改位于实际装配网格的保存材质槽，角色、改造展示及其他使用同一装配资源的入口继续读取这些网格。
