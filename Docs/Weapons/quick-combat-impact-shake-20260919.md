# 通用快速进战判定帧强震

## 当前行为

剑类、手枪、自动步枪的独立快速进战技能在执行伤害查询的同一帧触发一次强震，包含挥空。剑的普通攻击连击不使用这条曲线。伤害、范围、击退、眩晕、冷却和命中音效的结算条件保持原有规则。

`Skills/QuickCombatImpactShake.h` 提供共用曲线：起始为完整冲量，随后反向回弹并叠加较轻的高频振动，0.38 s 内衰减归零。主振动角频率为 44 rad/s，指数衰减系数为 9；附加振动为 90 rad/s、衰减系数 16。剑类的额外动作倍率不再放大这条统一冲量。

默认角色 `CameraMotionScale = 0.45` 时，起始镜头旋转冲量约为俯仰 -11.7°、左右 4.05°、侧倾 3.6°，再叠加原有动作随动。位置冲量仍走角色的平滑插值。镜头反馈不修改控制器瞄准方向，也不改变伤害判定方向。

伤害查询后调用 `RefreshQuickCombatCamera()`，以零时间步重新采样镜头，使组件在角色相机更新之后判定时也能立即显示旋转冲量。冲量由原有单次接触标记控制，动作正常结束后保留短暂余震；新动作或取消动作清除旧标记。

ASH 保留之前的起手 1.4 倍、收势 1.2 倍速度，以及有效伤害确认后 50 ms 动作停顿；挥空只震镜头，不增加停顿。
