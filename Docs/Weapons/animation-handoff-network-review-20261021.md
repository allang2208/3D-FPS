范围：本对话的战锤第三人称恢复、手枪双持/消耗品、手枪与非手枪副手换弹、第一人称书本 ADS 姿态，以及防止共享配置回退的工具。保留后续其他任务的修改。本轮不提交或推送，不运行玩家档案或打开交互编辑器。

## 发现并修复

| 问题 | 触发与后果 | 修复 |
| --- | --- | --- |
| 服务器换弹等待漏掉副手处理时间 | 客机持手枪加书时，本地先收书再换弹，服务器枪械弹匣账本却仍按原换弹时长计算最低等待 | `GetReloadSeconds` 使用该 Pawn 的权威/本地档案，非手枪副手增加 0.55 + 0.40 秒；双持、无副手和非手枪主手不增加 |
| 非枪械实例未参与动作包匹配 | `HasMatchingMotionRig` 仅比较 `GunInstance`，书和工具该字段为空；装备与表现复制乱序时，同布局旧物品包可能通过 | 优先比较 `ItemInstance`，兼容旧枪械身份；弓挂左手但按主手实例匹配 |
| 战锤恢复未补打包入口 | 39 个入口引用 21 个动态加载资产，原包装配置没有对应制作目录；编辑器本地有资产不代表分发客户端能加载 | 精确加入 V7、V8、V16、V17、V18 的五个 Animations 目录，不打入全部历史候选 |
| 远端历史包含旧提交被当作当前内容仍存在 | 发布检查只验证祖先关系；新提交删除动作后，旧提交仍在历史中，可能误报完成 | 同时检查远端当前分支尖端的具体动作值、必要源码和显式 Cook 目录；不可读取时不判通过 |
| 共享配置第一次加入父对象失败，类型替换可绕过删键保护 | 首次加入头部装备时缺少 `head_equipment`，按叶字段声明会被拒绝；将整个已有对象改为 null 等标量则隐式删除子键 | 对新对象逐叶核对归属并仅创建缺少父对象；拒绝用非对象替换已有对象 |

服务器改动只补齐原有最低换弹等待的副手时间，并没有将通用枪械改写为完整的服务器换弹状态机。现有通用弹匣账本以耗尽时刻等事实计算等待；本次不能据此声称全枪械反作弊或所有取消路径已完备。
