# M1911 通用配件与动作时间

## 本次接入

- M1911 `optic` 开放现有通用 `holographic`、`panoramic_red_dot`，`muzzle` 开放通用消音器 ID `true`；沿用原选项属性和实例存档结构。
- 共用配件几何来自工程已经使用的 M4 全息、全景红点和消音器。M1911 另存安装与表面处理变体，原共享资产不变。
- 两个瞄具都包含后套筒安装座，桥座为保留的机械照门留出下部空间。运行时绑定 `WPN_Slide`，ADS 从同一安装骨和瞄具光心计算，保留手枪 38 cm 眼距。
- 消音器带枪管延长接头，通孔调整为 13 mm。绑定 `WPN_Barrel`，跟随枪管运动；火光、弹道起点与方向使用消音器出口。
- 金属表面从当前 Hero M1911 套筒的烤蓝 PBR 制作 10 cm 物理尺度贴图；原始 UV0 法线、AO、玻璃、分划、标记和非金属细节继续使用来源材质。
- 当前持枪、枪匠预览、动态背包图标和掉落物通过原来的共享装配入口调用上述分支。原厂无配件图标保持不变。

## 换弹和输入

原 Contact 动画导入长度为普通换弹 `2.233333349 s`、空仓换弹 `2.733333349 s`，原 JSON 数字本来就与它们一致。用户反馈这一版仍等待过长后，进一步缩短实际动画的回握尾段：当前运行使用 **普通 1.75 秒、空仓 2.25 秒** 的 `ReloadReady20260913` 动作。制作过程见 [M1911 换弹归位时间](../../SourceAssets/M1911ReloadTiming20260913/README.md)。

枪匠现在直接读取当前导入动画作为 M1911 基准时间；运行换弹以实际选用片段长度和改造倍率计算持续时间，原速换弹为 1×。姿态采样、接触音效和补弹完成沿用同一状态时钟。手枪的结束混合缩短到 25 ms，完成时清除旧动作层，避免已经回到持枪画面后仍留着旧动作状态。

手枪拔枪动作仍可完整播放，但开火或 ADS 输入会立即结束 `Equipping`，清除动作层，并以输入时刻结算锁定；不再等到原来的约 `0.933 s` 截止时间。切换前已按住的开火／瞄准输入会在新枪弹药与属性设置完成后恢复。持续按住扳机仍只触发一次半自动射击。换弹、检视和翻越锁定继续按各自规则处理。
