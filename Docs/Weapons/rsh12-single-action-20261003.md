# RSH-12 单动开火与拨锤

> 历史方案：用户同日改为双动，当前运行时不再使用本页的射后拨锤设计。当前入口见 [双动重制与接入](rsh12-double-action-20261003.md)。

用户参考：[BV1pj411e7Jw](https://www.bilibili.com/video/BV1pj411e7Jw/)，1:42–1:44。片段已取得并逐帧阅读，用于动作时序参考。没有提取视频中的模型或声音作为游戏资产。

## 本次制作

- RSH-12 改为单动击发；一次按下扳机发射一发，随后自动由持枪手拇指拨回击锤。长按不会变成自动射击。
- 单持以右手操作击锤。双持右枪和左枪分别由该手拇指操作；法杖副手沿用左侧动作。
- 专用开火动作的源时长为 1.00 秒：起始击锤落下，约 0.06 秒枪口上跳达到峰值，约 0.22 秒完成主要后坐恢复；0.30 秒拇指接触击锤，0.34–0.60 秒拉回击锤并转动五发弹巢，0.85 秒拇指回握，1.00 秒回到准备姿态。
- ADS 开火包含快速枪口上跳、短后坐、拨锤时的轻微侧倾及回瞄。手掌保持握柄接触，整臂由原生骨长解算随枪移动；拇指按实际手模指腹与击锤尾端制作。
- 下一枪的输入锁定和拨锤音效都使用当前动作的源时钟。轻型快速扳机同时加速动作与射击循环，默认间隔 1.00 秒，轻型扳机 0.80 秒。换弹排在本轮开火/拨锤之后；快速近战不能跳过正在播放的拨锤。
- 五发容量、12.7 毫米弹药、逐发换弹以及其余 715 动作复用方式保留。新增的是四条机构和时长不同的开火动作，没有重新导出整套 715 动作。
