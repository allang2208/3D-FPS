# Super90 下方单挂件与散布调整

本轮范围：Super90 战术挂件数量、安装位置、腰射激光方向，以及散布数值。保持手臂、骨架、握姿与换弹时钟。

## 行为

- Super90 仅允许一个 `tactical` 挂件，安装在护木前段下方。普通激光、赐福激光与手电共用此位置。
- `SupportsSecondary` 和目录 `allowed` 同步取消 Super90 第二槽。旧实例经 `Normalize` 优先保留有效主槽；只有第二槽时迁到主槽。已有双槽不再同时获得两件效果。下一次应用改造沿原有保存事务写入归一化配置。
- 基础腰射偏移系数 `spread_mult` 从 1.5 调整为 2.25；原有配件倍率继续相乘。
- 每颗弹丸的随机圆锥半角从 2.5° 调整为 3.75°。ADS 状态使用 0.75 倍，即 2.8125°。ADS 状态判定与现有精确瞄准分支一致。
- 枪械自身的腰射偏移和每颗弹丸的扩散分别放大 1.5 倍；ADS 继续使用现有精确瞄准方向，仅保留收紧后的弹丸扩散。
- 激光腰射直接使用 Super90 新挂件的 `Emitter → AimGuide` 枪管轴，不再把前后瞄具方向投影到原生 `WPN_root` 的错误上轴平面。保留 ADS 到位后的短时归零、墙体遮挡及镜内光束处理。

## 资产与源码

正式挂件目录：`/Game/Weapons/Super90/TacticalBottom20261012/`，共 `SM_laser`、`SM_flashlight`、`SM_blessed_laser`。

制作源：`SourceAssets/Super90TacticalBottom20261012/`。`author.py` 复用已接受的三种主体和材质，移除侧面旧承座，依据原生枪体护木表面生成封闭的下方承座。源 `.blend`、FBX、插座及安装变换保存在该目录。枪体组件空间安装点为 `(0, -32, -84)` cm；挂件局部 +X 沿枪管，+Z 朝枪体。

`TacticalDeviceVariants` 为运行组件与图标资源准备提供相同路径；图标加载不再依赖 Super90 支持双槽。

源码改动前快照仅限本轮相关文件，保存在 `Before/`，包含修改前已有的并行工作；不可用 Git HEAD 替换这些工作区文件。
