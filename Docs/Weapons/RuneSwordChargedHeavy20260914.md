## 操作与伤害

- 左键点按触发完整普通攻击；按住左键蓄力，固定 2 秒蓄满，不受攻速加成缩短。继续按住保持最终姿势，松开才释放重击。右键暂不绑定剑的动作。
- 点按与长按由同一输入处理：空闲时按下开始计时，0.20 秒内松开按普通点按处理；较长按住继续使用蓄力提前释放规则。2 秒从最初按下算起。每次输入只提交一次攻击。
- 不足 2 秒松开接普通 `Slash1` 攻击，使用普通伤害、速度、接触窗口、镜头和空间扰动。按已播放的抬剑进度映射至普通动作的对应蓄势位置，再完成剩余普通斩击；不会先收回待机再抬剑。
- 蓄满释放时按当前武器、强化和角色攻击力快照计算 `SwingDamage = Damage × 2`，仍接入既有暴击、护甲、技能、毒与确认命中流程。实际扣血受目标防御等原有规则影响。
- 普通攻击和重击均在松键成功发起攻击时扣一次体力，沿用普通近战的 `MeleeCost`。蓄力期间不重复扣费；释放时体力不足则收回。
- 蓄力/失败回收属于武器忙碌状态，左键不插入攻击；提前释放的普通斩与蓄满重击都可在收势时用左键衔接镜像下一斩。换武器、打开阻断操作的界面、死亡、翻越等中断会清除蓄力。
- 原先左键普通斩击的两段动画、V8 时序与 V10 镜头数值保留。收势/装备期间的左键点击沿用普通连斩缓冲；物品提示显示左键点按与蓄力操作。

## 姿态与时序

参考既有 V4 手部渲染与 V6 右后高举、右上向左下的斜劈路径。右手靠近护手、左手支撑剑柄下端；剑柄由侧前方抬起，向右后方收紧，再进一步提至高位。蓄满剑柄坐标约为作者视角 `(28, 27, 16) cm`，剑轴比普通蓄势再后收 13°。

蓄力与挥砍作为一条连续全身骨骼路径求解，联动肩肘、腕部与扭转辅助骨，再在共同蓄满姿态处分成两段。沿用 Manny 模型、骨长、rest、权重、两手握持关系；剑刃攻击方向独立于待机剑面翻转。

| 阶段 | 时间（基础攻速） |
| --- | --- |
| 侧移举剑 | 按下后 0–0.65 s |
| 向右后方收剑 | 0.65–1.60 s |
| 高位收紧 | 1.60–1.90 s |
| 定姿蓄满 | 1.90–2.00 s，之后按住保持 |
| 快速重斩 | 松开后 0–0.075 s，243° 斜劈 |
| 顺势制动 | 0.075–0.2375 s |
| 停重 | 0.2375–0.2875 s |
| 侧向回收 | 0.2875–0.5875 s |
| 回握落稳 | 0.5875–1.00 s |

重击快速段由普通斩的 115 ms 缩短到 75 ms；释放后的整段动作按释放时攻速快照播放。使用 480 Hz 动画和接触子采样，碰撞继续沿真实 `Blade_Base`/`Blade_Tip` 轨迹查询，保留前半球、射程上限、遮挡和单次命中去重。蓄力、保持和回收无伤害窗口。
