## 动作设计与关节来源

| 时间 | 动作 |
| --- | --- |
| 0–0.34 秒 | 在镜头内转前臂、翻掌，先让反手姿态可见 |
| 0.34–0.52 秒 | 保持闭握，将剑与双手收至右下方出镜 |
| 0.52–0.60 秒 | 短暂停顿蓄势 |
| 0.60–0.80 秒 | 剑刃由右下快速扫向前上方 |
| 0.80–0.98 秒 | 继续向左上带出并卸力 |
| 0.98–1.50 秒 | 沿现有挥剑回位关节轨迹恢复当前待机 |

使用当前标准柄 `A_RuneSword_Slash2` 的完整关节动作作为供体。将其收势段反向重定时，得到待机到右侧低位的翻掌过程；将实际下斩段反向重定时，得到低位向上的反手斩。跳过供体的静止等待区间，收尾接回当前待机。

手指保持包握，左右手不交换，剑刃继续从虎口侧伸出。手掌、前臂、肘部、上臂和 twist 辅助骨一同采用供体在同一时刻的姿态，不单独扭手腕，不把 V5 的整组俯仰作为翻掌替代。仅额外添加右下出镜与回位所需的整组位移，不修改骨长、蒙皮权重或手指形状。

长握柄按当前 `DA_Sword_LongGrip` 的 Slash2／Idle 基础动作和差量制作，保留其原有握距。制作源使用 V7 裸手、裸臂；未修改普通攻击的动画、配置和事件时钟。
