# SVCH 快速近战右肘 R5（2026-10-20）

用户反馈 R4 右肘仍扭曲。本轮针对右肘重新修订；不更换 V9，不修改原有握持、枪体轨迹、近战时长及接触时刻，不修改换弹、拉栓和其他动作。

## 原因与修订

R4 沿用的剑类肘部支撑算法按两根主骨计算接缝，但 SVD/V9 的肘侧上臂皮肤主要受 `upperarm_twist_02_r` 控制。它只获得一半的补偿，与前臂的旋转不匹配；收势帧 70 仍有明显斜向夹折。只校正肘端四根骨骼会把扭转转移到上臂，已否定该候选，未接入。

最终复用 SKILL 所记录、用户曾认可的 `M870QuickMeleeElbowR3_20261017/author_elbow.py` 方法：上臂与前臂共用实际皮肤肘弯轴，前臂轴向旋转按原生站位以 0/50/100 分配，同时联动肩部支撑与肘弯平面。SVD 的两根上臂辅助骨同步跟随，保持骨长与原生局部位移；肩部位移属于支撑适配，手掌、手指、枪械和左臂的作者矩阵保持不变。

真实动画图的入场／退场混合会改变固定手掌的最终位置。因此修正仅在原动画图拥有完整动作姿态的窗口内生效：第 5 帧后渐入，第 84 帧前渐出；原动画时钟、所有权和回位时序保持。检查以 `check_preservation.py` 的实际动画图读回为依据，不能只看作者轨道的零偏差。
