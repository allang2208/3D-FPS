# M24 ADS 左手握持修正

本次依据用户提供的 ADS 截图修正左手指尖翻折。遵循第一人称手臂 SKILL 的原生绑定、掌面先行、MCP/PIP/DIP 分关节弯曲、保留骨长与局部位移的要求。

## 来源与修法

- 原生 V9 手的物理指轴为局部 `+X`；旧 M24 重定向在没有下一根子骨时以 `+Y` 推导末节朝向。源待机无名指、小指末节相对绑定旋转分别约 160°、173°，其余末节也存在大幅旋转。
- 保留原左手腕、护木托点、掌骨以及四指 MCP 指向；去掉 MCP 的轴向拧转，使用原生掌面推导 PIP/DIP 弯曲轴。拇指保留对握与前两节指向，修正末节翻折。
- 用实际手部蒙皮与本枪护木表面做有界制作拟合。四指独立分配弯曲，不按统一 Euler 值卷成拳头，不通过移动或缩放指骨贴合枪身。
- 待机、瞄准、持枪射击/拉栓、装备、检视和近战持握共用该手型；换弹离开护木时退出修正，回握时渐进恢复。冲刺保持原撤手轨迹与松握安排，收枪回到修正后的手型。

## 保存方式

`/Game/Weapons/M24/SupportGrip20261027/DA_M24_SupportGrip` 是普通弹匣的左指姿态差异；`DA_M24_Mag10` 合并相同左指差异与上一轮已保存的扩容换弹左臂差异。两组修改作用于不同局部骨骼，扩容托底轨迹按原数据复用。

没有替换骨骼网格、V9 材质、JC 矫正形状、原生 rest、权重、原动画或机械时钟；枪身、右手和左手腕轨道保持。制作 FBX 只用于烘焙差异，不保存为另一套运行时完整动画。

作者目录：`SourceAssets/M24SupportGrip20261027`。`M24_SupportGrip_Editable.blend` 为可编辑源，`author_grip.py` 为重制入口，`authoring.json` 保存各指制作参数；`install.py` 保存两份运行时数据资产，`support_profile.json`、`mag10_profile.json` 为其重建数据。
