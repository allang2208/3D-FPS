# 观峰高倍准星 V3：方案与接入

## 改善计划

本轮针对上一版观峰 3–6 倍镜的简单十字与固定中心点，重做高倍分划。保留独立镜内成像、镜框／手臂投影、实际瞄准射线以及所有武器属性。

1. **轮廓**：用峰脊细针、断开的横线与下方参考刻线建立光学分划；中心为细小圆点，周边留白，不用大面积亮十字遮挡目标。
2. **光学刻度**：刻线按当前捕获视角的真实角度投影绘制，随平滑倍率连续放大。主刻度通常间隔 2 mrad，极小镜口简化为 4 mrad；1 mrad 细刻度只在像素间距足够时显示。它们是角度参考，不宣称对应某个箭种的米制弹着点。
3. **动态**：外围双弧随拉弓收束，节拍窗口以侧边短金刻线提示；满弓与穿心就绪的红色沿用现有 UI 语义。撒弦后弧线短促外扩并衰减，变倍时外侧机械刻线短亮，所有反馈读取当前弓的动作与判定状态。
4. **准确性与可读性**：中心点及角度刻线与捕获相机／射击方向一致，不添加随机漂移或移动弹道。只有外侧装饰弧受微弱眼位反馈影响。分划限制在镜片安全区域内，较小镜口自动减少细节。
5. **性能与交付**：用缓存顶点／索引合批绘制，复用原有弓更新时钟和 SceneCapture；不引入贴图加载、额外捕获、灯光、网络消息或武器数值变化。完成必要 Game／Editor 构建，运行、视觉、性能和联机测试由用户进行。

## 实施范围

- `BowScopeOptics` 从现有 `GetDrawRhythm`、放弦年龄、显示倍率读取表现状态。
- `BowScopeReticle` 负责分划几何与柔和边缘；替换旧四条直线与方形中心点。
- 保留准星下方原有进度条、山峰与疾律纹样，镜内反馈仅用于靠近瞄准点的提示。
- 本轮升级观峰 PiP 分划。固定 2／4 倍镜与单相机性能模式仍使用各自已有实体镜片分划。
