# RSH-12 五发快速装填器

用户要求参考 715 制作五发快速装填器。该版本在枪匠「装填方式」中新增「五发快速装填器」，原厂逐发装填仍可使用，不自动修改玩家存档中的选择。

## 动作与模型

- 使用原生 715 的单持及左右双持 `speed_0` 基础动作，保留取出、压入、释放、抽离和回握节拍；新增本枪姿态差量，不恢复已否定的 DoubleAction 整套动作。
- 后部握持面和旋钮保持原生尺寸。前部重建为五孔承载结构，孔位来自 RSH 枪体的实测弹孔，每孔有独立的保持环。
- 五颗弹药随装填器形成同一弹组；单持左手与装填器一起进行空间适配。入座释放后，弹药留在弹巢内，装填器随原手轨迹抽离。
- 继续沿用上一轮真实吊臂轴心和逐发手部接触修订。非速装动作隐藏装填器；右手持枪与其他主体动作不因该配件改写。
- 双持沿用 715 各自单臂装填动作，容量、显示与结算均限定为本枪五发。

## 玩法与音画

单持原动作长 3.85 秒；普通与空仓使用同一退空装填流程，未击发余弹按 715 现有规则丢弃，不返还背包。按可用弹药最多装入五发，原有速度加成和双持时长倍率继续生效。补弹、机构音效与开巢镜头抖动使用同一源时钟。装填中断及入座后的闭巢续接保留原有合同。

制作目录：`SourceAssets/RSH12Speedloader20261003`。当前引用仍为 `/Game/Weapons/RSH12/Native71520261003` 的单持、左右双持网格与 Profiles；共享基础动画保留在原生 715 路径。新增材质放在同根的 `Materials`。
