# 下蹲腰射拉弓：左臂根部露口修正

用户反馈下蹲腰射拉弓时，整条左臂进入镜头，能看到内部空的部分。

## 定位

当前手模为 ContactV9 的 V7 原生弓手臂，Draw 为 ElasticV15。运行时 `UpdatePoseLayers` 将包括肩根在内的整个视模绕握点进行 **−55°** 下蹲侧倾，再对齐箭轴与腰射准星。肩根因此从画面下方转到相机前方。

对当前作者源、真实蒙皮权重和相同腰射变换做离线定位（75° 垂直视场、16:9、1 cm 近裁面）：满拉时左肩关节在相机局部约 `(21.84, -22.30, -1.88) cm`，截断开口有 51 个源顶点落入画框。侧倾收为 −12° 后，左肩约 `(22.03, -25.41, -31.80) cm`；所采样的拉弓首帧、25%、50%、75%、末帧均未将开口顶点投进画框。此处是制作定位数据，不是游戏验收。

源网格的 UV/材质分割边只在诊断副本上焊接以识别真实开边，没有修改模型、蒙皮或材质。

## 已落盘调整

仅修改 `Content/ColdSteelData/bows.json`：

- `bow_crouch_cant_deg`：−55 → **−12°**，保留轻微侧弓，同时减少整臂横扫镜头。
- `bow_crouch_offset_cm`：`-1.5,-2,-0.5` → **`-1.5,-2,-3.5`**，下蹲时再降低 3 cm，为肩根留出画框余量。
- `bow_presentation_revision` 升至 34，沿用现有旧存档表现迁移。

已有 CrouchProgress 与 ADS 混合继续工作。下蹲只影响腰射一侧的目标；满 ADS 仍使用原瞄具位置与箭轴对位。手、弓、弦、箭仍共享同一刚体变换，拉距、伤害、50% 发射门槛和新移动动画均保留。
