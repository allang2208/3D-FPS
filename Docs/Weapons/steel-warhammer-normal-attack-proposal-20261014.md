# 战锤普通攻击优化方案与定格手部阴影

本次用户要求排查定格时手部发黑，并参考双手剑提出普通攻击优化方案。普通攻击的以下动作调整是方案，尚未制作或替换运行资产；重击和冲刺砸地的 0.7 秒停顿保留。

## 发黑的已知设置与修正

截图中皮肤仍有纹理及暖色边缘光，表现与强阴影吻合，仅凭截图不能排除所有材质或间接光因素。代码确认 `ProductionToolHands` 不投影，但原先没有进入 FirstPerson 像素分类；隐藏的世界身体、衣物和武器副本仍使用普通阴影分类。这使世界身体/手部副本可以遮蔽同位置的第一人称手部。

当前工程启用 VSM。UE 5.8 的 `VirtualShadowMapProjection.usf` 明确将 WorldSpaceRepresentation 的独立阴影贴图应用到非 FirstPerson 像素。此次修改将持战锤时的手、武器及相机子层放入 FirstPerson pass，将本机世界身体、服装、武器副本标为 WorldSpaceRepresentation；地面影子与场景遮挡继续保留。FOV 和渲染深度倍率保持原值（战锤 Scale=1），不改皮肤材质、曝光或整场灯光。第三人称、死亡视角、换武器时恢复原分类，原手枪深度方案保持。

这证明原配置存在该遮蔽路径，不等于截图的全部发黑已获实机确认。读取结果与构建回执保存在 `SourceAssets/SteelWarhammer20261014/HandShadeDiagnosisV1`。

当前运行实例读取结果：`ProductionToolHands` 使用正确的 V7 Arms/Hands 材质，Hands 实例无额外标量/颜色覆盖，分类为 None；`CharacterMesh0` 为 OwnerNoSee、CastShadow 与 CastHiddenShadow 开启，分类同样为 None。原始截图保存在同目录 `reference.png`，修正前实例记录为 `shading_before.json`。未进行修正后的画面对比，不把配置读回当作视觉验收。

交付：正式 `FPSGAMEEditor` 构建于 2026-10-14 18:10 完成，基础 Editor DLL 已更新；本轮没有运行游戏或重导材质、动画。普通攻击部分仍仅为方案。热编译曾因工程内 M66 与远景植被的两个局部变量遮蔽成员而失败，改名保留逻辑后完成正式构建；原文件保存在 `BuildPrerequisites`。独立 Game 目标未运行。

## 普通攻击为何仍显僵硬

- `ComboV1/author_combo.py` 把矿镐的完整下砸轨迹绕前向旋转正负 45 度，再把握持组收回双臂可达空间。它没有双手剑那种独立设计的侧向蓄势、横跨身体、反侧卸力与回握轨迹。
- 战锤基准时序已经有约 0.85 秒蓄势、0.12 秒释放；双手剑当前 V8 的快斩是 0.115 秒。因此单纯继续加速或延长蓄力并不能解决空间轨迹与收势问题。
- 命中时仍复用 `ProductionPickaxeImpact::SourceHitTime`：前 0.42 作者秒保持接触骨骼采样，中间还有采矿式撬动。这对攻击敌人表现为较长僵停。
- 普通挥空镜头也沿用矿镐的小幅曲线，前后位移约 1 cm 量级；剑的独立负载/贯穿曲线为 10–16 cm 量级，并有横向偏航与侧倾。二者还会经过角色统一的镜头倍率，不能把作者值当最终画面位移。

参考：`RuneSwordRhythm.h`、`RuneSwordComponent.cpp::GetCameraMotion`、`DiagonalHeavyV6/authoring.json`、`CompactRecoveryV8/authoring.json`；剑的两击共用约 64 cm 的护手横向起止跨度，但不能原样套到锤柄握点。

## 建议采用的动作方案

1. **扩大可见横向轨迹。** 保留右上→左下、左上→右下、过顶下砸的三段方向；前两击重做独立握持组轨迹，先以可见横向跨度增加约 20–30% 为制作目标。肩带轻微转动配合，锤头切过画面并落到另一侧下方；所有尺寸服从原骨长、肩口净空和双手握点。
2. **保留慢蓄力，改善发力曲线。** 继续约 0.85 秒蓄势与 0.12 秒快速释放，释放段加速，触后约 0.10–0.15 秒顺向卸力。力度来自动作范围、快慢反差和锤头惯性，不整体缩短动画。
3. **换掉矿镐命中回收。** 战锤单独使用约 0.06–0.08 秒确认命中的短停顿，接顺向小回弹与回握；取消普通攻击的 0.42 秒锁姿及撬动。矿镐采集和重击砸地定格不改。
4. **制作战锤普通攻击镜头曲线。** 参考剑的后拉蓄势→向前、向挥击侧带出→触后制动；初稿可用后拉 6–8 cm、前送 12–16 cm、偏航 6–10 度的作者值，再经过现有角色倍率。镜头不锁定锤头，不调整全局相机参数。
5. **连击顺势衔接。** 第一击落在左下后顺势进入左侧蓄势，第二击反向，避免每击先回正中再重抬。单次攻击仍完整回待机；双手始终以锤柄为共同握持参考，肩肘腕整链适配。

普通前方群攻判定、伤害、体力、第三击 1.25 倍系数和重击/冲刺行为均保留。具体轨迹和握姿以制作阶段求解为准，上述幅度与短停顿数值为拟采用初稿值，尚未经过游戏体验。
