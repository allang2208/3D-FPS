# M16 奔跑左臂与撞门腕部修订

## 本次用户要求

M16 进入奔跑时左手仍扭曲；撞门时腕部仍明显变细。复用其他正常步枪的现有左臂与腕部处理，保持自然衔接。

## 定位到的来源

- M16 使用已保存的原路径 `SK_M16_Manny`，裸手与装备皮肤沿用该原生骨架。此前 `M16Repair20261002/NeutralBind` 已将 19 根左掌骨与指骨改为共同 V7 中立参考，但保留了 `hand_l` 的旧持枪参考旋转。
- M16 手腕局部参考与共同 M4 V7 相差约 80.162°，前臂辅助骨的局部参考则相同。旧表面在线性预蒙皮时已经缩窄，再直接复用 M4 护拳时又经历一次混合形变。上一版只测了后一次变换，漏掉了已烘进表面的压缩。对当前 224 个无手指权重的腕部顶点，预蒙皮与上一版运行旋转的合成最小奇异值约 0.853；这是用户要求的来源诊断，不是游戏或渲染验收。
- M16 奔跑源本来已取 M4 动作，但每帧继续调用 `shift_arm`，即使左手离枪、偏移为零也重新解算，并以参考局部变换覆盖辅助骨。M4 的现有 `hand_at` 则保留完整源骨段与辅助骨的相对关系。
- 当前握把运行使用基础动画与 `WeaponGripProfile` 差量，因此基础动画、握把作者动画及对应 Sprint 差量必须一起更新。

## 制作与接入范围

- 沿用现成 NeutralBind 制作工艺，将 M16 的 `hand_l` mesh-local 参考旋转改为共同 M4 V7 的自然腕部参考，保留已中立化的 19 根指骨与掌骨。从共同裸手及未压缩手套壳重新制作相应几何，避免对旧压缩表面继续叠加绑定。
- 保留原生上下臂、四根辅助骨、层级、局部位移、缩放、权重、共享动画 Skeleton 和既有非奔跑动画。同步原有 M16 裸手、装备皮肤和手套资产。
- 从 M4 对应握把动作复制完整左臂，保留 M16 的右手、枪体与机械轨迹。覆盖 Base、Drum、Angled、Vertical、Canted、Prism 的 Enter／Loop／Exit 共 18 段；仅刷新五个握把 profile 的 15 个 Sprint 条目。
- `DoorPushPoseLayer.cpp` 撤掉上一版 M16 分数扭转特例，回到整条作者左臂的局部插值与 FK。保持现有拳形、整臂轻摆、0.30 秒护拳、0.36 秒开门反馈和 0.197 秒恢复，不新增逐帧求解或缩放。
