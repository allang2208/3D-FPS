# 持弓移动与奔跑优化

## 问题与实施计划

现有 Ready 无行走循环；搭箭后锁定 Draw[0]，无法进入 Run；旧 Run 仅固定 0.8 秒平移摆动，缺少肩肘节奏、速度驱动和停步缓冲。

1. 在原生 V7 弓手骨架上制作 Walk、Run、LoadedWalk、LoadedRun、LoadedIdle 五段动画。左手保留完整握把手型；搭箭时右手保留勾弦，空弓右手放松随步摆动。弓、手腕、肩、肘采用不同相位，形成缓冲与重量感。
2. 步态相位由地面移动速度推进，走路/奔跑使用同一个连续周期。以平滑权重混合待机、行走、奔跑；低速、蹲行、ADS 收敛幅度；离地停止推进脚步周期。
3. 转向、横移和起停用有界阻尼随动；在现有腰射/ADS 对位之前合成，保留准星、机械瞄具与箭轴对位。加载后的待机循环替代完全静止的 Draw[0]。
4. 混合后对搭箭右臂做保骨长的接触修正，保持弦结点在 brace；移动转拉弓保留当前姿态并短时衰减差值，不新增攻击等待时间。
5. 后台导出、实际导入并保存动画，更新表现版本与打包目录，完成原生编译。按用户规则不启动游戏、不截图、不追加测试。

## 制作参数

- 一个循环为左右两步；标准步幅周期：行走 430 cm，奔跑 490 cm；450/700 cm/s 时约 2.09/2.86 步每秒。
- 空弓行走位移约 0.6–1.0 cm；奔跑有放低内收姿态，叠加约 1–2 cm 的步伐弧线。肩肘落后于握点，右臂反相随动。
- 搭箭行走/奔跑保持双手约束，幅度比空弓分别缩小至 72%/62%。蹲行再收至 48%；ADS 循环权重收至 12%，最终机械瞄具仍按原规则对位。
- 起停与跑走权重采用临界阻尼；动画采样只读取状态，不重复推进动作时间。
