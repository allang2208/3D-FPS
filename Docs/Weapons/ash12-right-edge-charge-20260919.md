# ASH-12：镜头右侧伸入拉栓，再从右侧收回

用户要求的是屏幕空间的右侧进出路径。此前两次肘部偏向和手枪整体小幅右移没有满足要求，本版从原始已接受的换弹源重做拉栓尾段。

## 动作编排

- 1.91 秒弹匣压实结束后松手，至 2.08 秒退到镜头右侧外；2.16 秒开始由右侧伸入。
- 2.28 秒靠近拉机柄，2.34 秒接触；2.34–2.60 秒抓柄后拉，沿用原机械行程及事件时点。
- 2.70 秒松开并向右退让，2.84 秒撤到镜头右侧外；2.96–3.16 秒从右侧下方恢复握把。
- 总长仍为 3.30 秒，枪体、弹匣、枪机及左手沿用原动画。

相机坐标沿用当前 ASH-12 的瞄准轴、18 cm 眼距和腰射视模偏移。右手进出目标在眼点右方 42 cm、前方 16 cm；右肩使用镜头右侧的独立视模姿态，右肘向右侧展开，避免原有跨到中心偏左的弯曲路径。

掌面绕原拉机柄抓握点调整进入方向，手指保留局部姿态；右肩、上臂、前臂、腕部和扭转辅助骨联动求解，骨段长度不变。接触区间跟随原拉机柄曲线。
