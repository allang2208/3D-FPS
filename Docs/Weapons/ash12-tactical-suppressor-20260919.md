# ASH-12 专属战术消音器

用户要求参考截图的大型消音器造型，按配件标准工作流制作 ASH 专属配件。

已制作大直径筒身、八道纵向凹槽、宽斜纹套环、后接座及深色端口，提供独立 PBR 和透明配件图标。模型 +X 为前方，枢轴位于实际后安装面；装配保留 ASH 原枪口端面基准，火光位置使用新模型前端。

`gunsmith.json` 新增 `ue_ash12 → muzzle → ash12_tactical_suppressor`，显示名为“ASH 战术消音器”。其他枪械目录没有该 ID，角色装配函数也仅在 ASH 时接受。沿用现有预览／应用／实例保存／掉落装配，以及消音音效和火光逻辑。数值采用现有战术消音器基线。

外部三类材质已添加湿润和水珠版本，并合并到 ASH 私有天气映射，保留既有映射；新增资产目录已加入 Cook。作者文件及导入回执见 [制作目录](../../SourceAssets/ASH12TacticalSuppressor20260919/README.md)。
