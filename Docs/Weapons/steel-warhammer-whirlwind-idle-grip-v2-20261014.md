# 双手战锤旋风：固定待机握姿与外送收势 V2

> 当前状态：用户认为本版武器摆动与位置变化不够，已由 [旋风摆动与左手松握 V3](steel-warhammer-whirlwind-release-v3-20261014.md) 替换。以下为 V2 历史制作及当时检查记录，不代表当前版本或用户认可。

用户要求旋风保持待机双手握姿，不再刻意缩短握距；旋转完毕再向外延伸锤子，表现重量，并检查整段动作。

## 本次调整

- 双手到锤柄的完整位置、掌向和手指姿态锁定为当前战锤 `NormalComboV4` 的共同待机。两腕间距约 22.165 cm，全段不再混入剑的紧凑握姿，也不在入场和结束时滑动换握。
- 继续参考原旋风的武器弧线和两圈节奏，肩臂为固定握点提供支撑。对两条原生手臂使用连续两骨圆求解，保留上臂、前臂长度；小幅旋前分布到原有前臂辅助骨，手指保持原握柄姿态。
- 旋转结束后，握柄中心向外送约 11.5 cm，伴随轻微侧送与下沉；锤柄逐渐扶正，上身前送支撑，先减速承重再回收。外送峰值位于作者时间 1.48 秒，即旋转结束后的约 0.18 秒。
- 作者时长仍为 1.82 秒、300 fps，继续按运行时 0.5／当前技能旋转时长／0.52 秒分段映射。旋转角度、技能伤害、判定范围、命中停帧、体力、冷却、音效和镜头代码没有修改。
- 运行时原有 0.1 秒入场衔接保留：从当前显示姿态进入该固定握姿，避免从走跑状态直接跳帧。动作主体与回收全段使用待机握距。

## 整段检查与修正

检查时发现，直接继承 V1 的后半段回收，会在作者时间约 1.685 秒出现一次姿态跳变，半帧手部位移约 38.5 mm，并带来中间插值的握柄偏移。该段已改为从准确的旋转终点连续外送、扶正、回到待机，不再采样旧版换握回收轨迹。

修订后对完整源片段按 600 Hz 读取 1093 个姿态：握点最大误差约 0.094 mm，骨段长度误差低于 0.001 mm，相邻采样最大手部位移约 1.70 mm，关节相邻采样最大旋转约 0.60°；首尾位置与朝向相同。已查看待机、蓄势、旋转、外送和回收的第一人称源姿态图，以及外送时的侧面肩肘支撑图；所查看第一人称姿态没有出现手臂末端侵入画面。

导入后从正式运行资产读取 SOURCE 与 COMPRESSED 各 221 个姿态。压缩后握距约为 22.1649–22.1658 cm，握点误差约 0.0111 mm，SOURCE／COMPRESSED 骨点最大差约 0.0023 mm，检查通过。数据分别见 `whole_clip_check.json` 与 `saved_pose_check.json`。这些是源姿态与已保存资产的检查，不等同于游戏中完整渲染或联机验收。
