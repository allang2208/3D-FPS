# 山鸣／疾律弓弦完成度与联机检查

用户要求检查本段制作是否完成、是否遗漏，重点联机。范围为两款传说弓弦、阿尔卑斯／疾律HUD、共用弓射击提交、状态与原箭／弦影箭结算。保持用户原档、现有编辑器及并行工作。

## 已发现并修复的代码问题

1. 客机本地预测节拍成功后，服务端判为成功射击但未中节拍时，没有显式纠正本地预测。旧的复制bool保持false时也不会通知。改用带射击序列的现有库存回执携带权威节拍／穿心结果，按角色、武器实例和释放GUID应用；拒绝射击保留之前真正获得的加速，但不显示成功放箭反馈。移除本机预测与陈旧复制bool的OR读取。
2. 服务端下一箭节拍加速只存bool，空闲时死亡、切弓和更换Pawn没有统一失效。现在绑定Pawn及武器实例，权威Tick与开始拉弓时处理失效；本机切换实例和死亡同时清预测。
3. 疾律到期或叠层消息滞后时，两端各自计算的拉弓时长可能不同。每次拉弓使用GUID，服务器确认固定满弓时长；客机保留已经流逝的秒数，并据此重算满弓／穿心窗口。旧拉弓确认、取消和射击不能误操作下一次动作。权威放箭仍用原有服务器时钟和有限时差校验，不接受客户端伤害或倍率。
4. 山鸣10秒到期时间原来不复制，客机需等清零包才能熄灭。现在复制服务器到期时间，本机HUD和第三人称弦光都按同一个时钟读取有效层数；到期后同层数的新命中仍可刷新点亮反馈。
5. 魔法箭雨成功释放原来只清理拥有者的节拍加速，服务器残留的加速可能影响下一次普通箭。资源提交成功后同步清理服务器状态，并使释放箭雨前的旧射击回执失效；失败／取消不额外消耗奖励。

上一轮材质断线已在D3D12/SM6后台修复，两个实际材质已保存；见 `Docs/UI/resonance-hud-material-repair-20261028.md`。本轮不重导这些已修复资产。
