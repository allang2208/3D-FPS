# RSH-12 通用前握把

本次只给 `ue_rsh12` 开放通用 `underbarrel` 槽，沿用五款现有配件的 ID、数值和图标：45°侧倾握把、战术垂直握把、垂直握把、棱镜阻手器、共振二代前握把。其他武器目录保持原值。

## 制作与动作

- 制作源：`SourceAssets/RSH12Foregrips20261004`；沿用已有通用模型的主体、比例、UV 和材质，增加贴合 RSH 16.536 mm 下导轨的夹座内衬。
- 安装位置统一位于 RSH 原始模型坐标 `(0,-0.094,0.0194712)` m；跟随 `WPN_root`，使用与 RSH 原生单持／双持一致的坐标换算。
- 单持基底为已接入的 `RSH12UnifiedGrip20261004`，保留右手、枪体、弹仓、弹壳、弹药与快速装填器轨道。
- 左手使用四套已接受的步枪接触家族：vertical、canted、prism、angled。两个直握把沿用通用设计的 vertical 接触家族。使用掌面方向适配、手臂两段 IK 和原生骨段长度，离线写入稀疏 `UWeaponGripProfile`，不增加运行时 IK。
- 覆盖待机、ADS、腰射／ADS 开火、装备、检视、冲刺、快速近战、各余弹数单发换弹和五发快速装填。换弹前 0.18 s 松开，最后 0.30 s 回握，中段沿用原装填接触；快速近战前 0.09 s 松握并下放，最后 0.16 s 回握，沿用原击打动作及计时。
- 双持继续使用原有双持姿态层，不应用单持前握把姿态。左右枪仍显示安装件，左枪沿用现有装配副本管线。

2026-10-05 共振握把左腕修订：`SourceAssets/RSH12ResonanceWrist20261005` 对 `angled` 家族增加 RSH 专用肩肘支撑与前臂 twist 分配，保持原手掌、手指接触。沿用既有松握／回握时序，覆盖全部 24 个单持片段。总作者已引用同一修订；导入保存凭据见该目录 `import_receipt.json`。没有改其他握把或双持姿态；未做游戏测试或验收渲染。

同日检视返修：用户反馈整臂闪动、锁子甲破形。`SourceAssets/RSH12InspectArmRepair20261005` 替换 `angled` 的检视左臂轨道，用已拟合待机支撑连续跟随掌面，移除供体松手肩部急转和逐帧扭转分支切换；其他片段保持。按本次排查范围做了作者姿态与当前锁子甲网格的离线对比，未运行游戏。细节和保存状态见该目录 README 与 `import_receipt.json`。

## 双持结算

仅对 RSH 的 underbarrel 槽逐字段屏蔽收益，保留减益；其他槽和武器不受影响。主手、独立副手结算和已装备物品的枪匠／提示面板采用相同规则。

|配件|双持时保留的效果|
|---|---|
|45°侧倾握把|稳定性降低 15%|
|战术垂直握把|无有效属性变化|
|垂直握把|开镜耗时增加 5%|
|棱镜阻手器|无有效属性变化|
|共振二代前握把|开镜耗时增加 10%|

卸下前握把恢复已接受的 RSH 原握姿。切回单持恢复通用握把完整数值。已存在的归一化、装配保存、图标配方和拾取模型流程继续使用同一配件 ID。枪匠详情增加当前双持规则说明。
