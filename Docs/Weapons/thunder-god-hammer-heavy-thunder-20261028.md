# 雷神之锤：重击落雷

用户确定数值：追加 100% 当前魔法攻击力、半径 3 米、眩晕 1.5 秒。

## 战斗接入

- 武器：`ue_thunder_god_hammer`。仅蓄满后的重击释放触发，普通攻击、未蓄满释放与冲刺攻击保留原行为。
- 服务端在释放时快照重击面板与角色 `Derived(matk)`，在锤头接触真实地面时产生雷击。落点继续使用既有重击地面定位；没有有效地面时保留近身接触回退。
- 现有重击伤害保持；在重击倍率计算完成后向同一伤害面板的 `AddedMagic` 加入一次 `1.0 × matk`。雷击不再乘重击倍率，分别沿用物防／魔防与对应穿透结算，共用一次武器暴击判定。
- 3 米范围在接触时一次结算，目标去重；视觉余波不再寻找新目标。保留友军过滤、地面高度和墙体遮挡。
- 眩晕为 1.5 秒，继续使用战锤既有控制规则：普通敌人可控制，精英以上需处于破韧状态。该次伤害可先造成破韧，再施加眩晕。
- 主从端共享复制波的落点、开始时间、净空高度与外形随机种子；客户端只播放表现。

- 首次亮闪后在约 95 ms 与 205 ms 回闪，整体 0.65 秒内消退；地面复用专用电击爆闪和已有重击碎石、尘土。
