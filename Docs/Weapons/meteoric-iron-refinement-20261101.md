# 陨铁晶片材质 V2

用户反馈原版交错银白线条廉价，2026-11-01 认可“深灰金属底色、低对比晶片、随角度显纹”的优化方向。

## 制作内容

- 移除 V1 三组贯穿剑面的高对比条带，改用离线制作的非周期晶片分区；大小与方向由两级不规则分区控制。
- 基底采用接近的深银灰色，晶片色差围绕 0.30 小幅变化；主要层次来自粗糙度和拉丝方向。
- 剑面粗糙度中心 0.31，晶片间差异约 ±0.026；几何刃缘收至 0.215，保持清亮。
- 拉丝高光随各晶片方向变化，方向先从物体坐标转换到当前网格切线空间，再接到 Substrate Tangent；没有把物体空间向量当成 UV0 法线。
- 移除 V1 额外的晶带法线偏移，完整保留原剑的结构法线和符文刻纹。
- 新增一张 1024×2048 RGBA 数据纹理，线性 BC7，使用 mip 与正常流送。RG 为拉丝方向，B 为低反差色调，A 为粗糙度。细拉丝按屏幕导数衰减；没有运行时 CPU Tick 或程序分区循环。

适用范围仍为符文长剑材质模式 5，沿既有遮罩覆盖剑身和剑根；两套金／银原生符文主材质同步。寒晶、时砂、其他材质分支，以及原生发光、湿润、数值和存档合同保留。

## 作者入口

`SourceAssets/MeteoricIronRefinement20261101/author_crystal_field.py` 生成晶片数据纹理，`field-recipe.json` 记录通道和物理映射。

`install_materials.py` 在当前两套主材质中原位替换 V1 陨铁分支，接入方向反射并保存，再只修改目录里的陨铁外观说明。修改前资源另存到同目录 `BeforeAssets`，旧版本模式标记保留以避免旧初始化器再次叠入 V1。重建时在整段剑身覆盖、寒晶与时砂素材流程之后执行本脚本。

`run_asset_task.ps1 -Script install_materials.py` 沿现有批次互斥接入已有编辑器或后台 commandlet；不启动编辑器界面或游戏。
