# 观峰 3–6 倍镜：主相机光学表现 V4

日期：2026-10-28

## 表现与行为

- 观峰镜使用玩家主相机的真实 FOV 完成 3–6 倍变焦。删除独立 SceneCapture 和镜片 RenderTarget；镜内世界与主画面的光照、后处理和遮挡来自同一画面。
- 镜口稳定直径为受约束视口短边的 68%。开镜后段由实体举弓动作过渡到圆形光学镜框，仅有 4% 的入镜收敛；滚轮改变倍率时镜口尺寸不变。
- 沿用已有单相机光学镜框：细金属边、浅方向性内阴影、很弱的边缘镀膜，外围遮黑。瞄准中心不添加覆盖反光。
- 第一人称弓和手臂使用独立 FOV，举弓构图与当前倍率分开。镜框接管后只对本人设置 OwnerNoSee，不修改源骨骼的 Visibility / HiddenInGame，世界弓的动作采样和远端身体继续沿用原流程。
- 身体可见性刷新读取观峰镜的投影和隐藏请求，防止定时刷新把手臂重新显示出来。退出瞄准、切武器、改装、菜单、弹药轮、第三人称或不可展示武器时释放状态，恢复原相机设置，并重新应用死亡/休息/第三人称可见性。
- 保留 V3 中央细准星、角刻度和满弓/节拍/穿心箭反馈。角刻度按当前主相机投影计算，不参与修改箭矢发射方向。下方准星竖线缩短，给拉弓进度和弓弦图案留出位置。
- 拉弓、山鸣/疾律图案与经验提示统一随镜口向下避让；HUD 子控件绘制在镜框遮罩之上，Buff 栏继续显示。
- 保留既有滚轮倍率平滑和基于光学 FOV 的鼠标灵敏度。未修改倍率范围、弓弦技能数值、联机 RPC 或服务端命中判定。

## 范围与开关

仅高地长弓的观峰 `Scope3to6V11/SM_Highland_Peakwatch3to6` 使用此镜框。其他弓瞄具和枪械光学镜保持其现有路径。

新显示开关：`fps.Bow.Scope.OpticalPresentation`（默认 1）。关闭只停用镜框和独立武器构图，世界仍由主相机变焦。旧 `fps.Bow.Scope.PiP` 与 `fps.Bow.Scope.MaxResolution` 随独立捕获路径一同移除。
