# 弓握把缠带系列 V20

用户要求继续下一个改造件系列。弓体已有游隼、磐木、静枝三款，瞄具已完成 V19 木座与弧臂；本次扩展五槽中的 `grip`。原装绿色缠带和原有 `waxed_linen` 保留，新增三个互斥选项，不强制切换已装备握把。

## 实际制作

Blender 从 V13 已分离的中心缠带和中央木体取表面，建立包握外轮廓及内衬表面。三款的根、单位、安装轴保持一致；纹路、压边与缝线向轮廓内侧收，不靠放大握把制造厚实感。造型适配原接触面，手部动画不变；实际手掌接触仍待用户游戏确认。

- 编织蜡麻：交错低凸纹、两端双股编绳；38,176 三角面。
- 薄革速握：八圈斜绕纹与压边；28,928 三角面。
- 软革稳握：包面凹缝、34 针实体缝线、两端卷边；33,920 三角面。
- 每款独立 1024² BaseColor／ORM／Normal，共九张程序制作贴图；不新增外部素材。保留亚光纤维、柔和皮革粗糙度与低强度法线。
- 三张 1024² 透明 PNG 图标由实际新模型制作，安装前向朝画面左、上向朝上；只用于改造栏生产资源，不是游戏验收截图。

## 接入与使用

模型及材质在 `/Game/Weapons/DarkBow20260925/GripSeriesV20`；专属图标名为 `bow_dark_grip_<选项ID>`，PNG 与 UE Texture2D 同步保存。

`Content/ColdSteelData/bow-gunsmith.json` 新增 `woven_linen_grip`、`slim_leather_grip`、`padded_leather_grip`。每项指定独立握把网格并清空旧材质覆盖，沿用已存在的预览、异步装配、图标配方、数值详情和 `gunsmith_parts` 保存流程。`Config/DefaultGame.ini` 增加该资源目录的烘焙引用。没有改原生 C++，无需新增模块编译。

下次进入游戏，在弓的改造台选择“握把缠带”，选择新握把并应用。默认绿色握把不会自行替换。

源文件与制作入口：`SourceAssets/BowGripSeries20260927/`，含 `Bow_GripSeries.blend`、`Bow_GripSeriesIcons.blend`、FBX、贴图、图标和作者脚本。保存/安装进度以该目录 `import-receipt.json`、`install-receipt.json` 为准；共享文件旧版在 `Saved/BowGripSeries20260927/Before`。

按用户规则，本次不进行游戏测试或验收渲染，手感、接触、改造操作与平衡交由用户测试。下一建议系列为弓弦，其后为箭台；本次不提前改动这两个槽。
