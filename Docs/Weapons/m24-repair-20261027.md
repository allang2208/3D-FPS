后续持枪排查发现本版还遗留手臂中间动作错误、JC 形状单位错误及腰射上轴错误。
手臂、动作和腰射部分由 [M24 持枪修正](m24-hold-20261027.md) 接替；
本版枪体表面、材质、独立配件和目录图继续使用。以下为当时修复记录，不能视为
手臂动作或游戏画面已合格。

本记录接替首次导入和模块化交付中的模型、动作与图标版本。用户报告放大和贴图问题，

## 原因与改动

原制作场景 `M24_V9_Rig` 的对象缩放为 100，FBX 导出又做米到厘米换算，导致 UE
参考骨架和动作多出 100 倍比例。独立静态配件本身单位正确，但原配准代码把配件
追随放大骨架。本次统一骨架对象缩放为 1，重新导出枪体、三个配件和八段动作，
使用新骨架接收，不通过角色整体缩小掩盖问题。

旧模型来自 FBX，但 PBR 贴图来自 glTF；UV 与贴图不匹配。14 个枪械零件按原始
glTF 三角形角点重建 UV 和自定义法线，保留原始几何位置及各机械骨骼权重。
导入保留法线和切线，关闭重新计算，启用完整精度 UV 和高精度切线基。
glTF 法线图继续使用线性采样、Normalmap 压缩和一次绿色通道翻转。

实际 UE 渲染还发现两种镜片材质的 OneMinus 节点没有接入透射贴图，导致材质
编译失败并显示默认材质。已修复输入连接，在修复版镜片材质中保存，并同步修正
生产脚本的该连接；后续重建会保留修正。

保留 V9 手部表面、81 个 JC 形状（制作源含 Basis 共 82 个）、既有动作曲线及
动作时长；修复版服装配置使用实际手臂材质槽 `[0, 1]`。旧版本包保留作历史，
运行代码指向 `/Game/Weapons/M24/Repair20261027/SK_M24_RepairedV9`。
三个独立配件和八段动作也改为同目录，枪匠的默认组合和明确拆除选项保持。
枪机、弹匣等仍按各自骨骼独立运动，本版共用原生枪体材质。

目录图导出此前错误访问未初始化的枪匠子系统；改为纯数据原装组合，离线生产
不加载玩家档案。M24 已加入目录批量导出清单。配件图标从修复后的模型重制，
保存十二个 PNG 键和十二个 UI Texture 包；旧 PNG 保留在本任务的 `BeforeIcons/`。
