# 换弹装入检查点与机械动作续播

2026-09-22。按本次用户要求，替换“整段动画结束才补弹”的旧规则。

## 行为

- 弹夹装入时，将弹药袋扣除、枪内弹数、弹药种类和后续机械状态作为同一次档案事务提交。右下角弹数使用原有实时读数路径，当帧刷新。
- 装入前中断不增加弹数；装入后中断保留已装弹药，不退回弹药袋，不在动画结束时再次补弹。
- 空仓换弹在装入后保留“尚需拉栓/释放套筒”状态。中断后恢复操作，或切回这把枪，只播放机械动作及归位尾段。尾段不再次扣弹，不重复发放换弹经验；完成之前不能开火。
- 菜单、攀爬、死亡、切换装备与施法占用可以中断呈现；状态跟随武器实例。双持左右枪各自保存和续播。
- 左轮逐发装填仍在每发入膛时提交，快速装弹器在释放子弹时提交；已装入后中断，续播收回装弹器/关闭弹巢的尾段。
- 普通、扩容和弹鼓保留各自既有动画与速度映射。无限备用弹仍保留虚拟弹药标记，切换弹药种类仍只花费实际拥有的目标弹药。
