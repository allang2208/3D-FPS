# 弓手模开口与勾弦接触 V9（2026-09-25）

用户提供 V8 游戏截图，指出手模漏洞、穿模、未闭合、弦穿掌和动作僵硬，并明确纠正“不是抖动，是漏洞”。本轮按网格开口与接触错误处理，没有修改相机防抖或增加抖动相关逻辑。

## 图像及作者源定位

截图可见右手呈张开的爪形，拇指伸直，弦进入掌内。V8 虽区分了各指角度，仍使用固定腕部偏移 `(7,-1,0.4)` cm 作为弦触点。将实际指骨转到统一手部坐标后，末节指根主要位于 X≈11–12、Y≈-5 cm；原触点落在掌部，并非指腹。

源手模还存在局部开放边与翻折的细小掌面三角。两类问题分别处理：修补表面连接，再按蒙皮表面建立勾弦关系；不继续把标记位置正确等同于手指贴合。

## 弓专用表面修补

以认可 V7 裸手为来源，在新的弓专用副本中处理左右掌面共四处局部区域。合并手部重合位置的接缝顶点，保留按三角角点存储的 UV 和法线边界；以连续外轮廓重接损坏区域，90 个旧三角改为 54 个连接面，并填合内部小开口。

中心顶点的权重和材质场由边界插值，保留原生参考骨架、骨长和其余表面。没有覆盖共享裸手母版，也没有把皮肤改为双面材质来遮盖开口。具体区域和面索引写入 `surface_repair.json`。

## 右手与弦

- 参考 [World Archery 教练手册](https://extranet.worldarchery.sport/documents/index.php/Coaches/Accreditation/Coaching_Levels/MANUAL_COACHING_LEVEL_1.pdf) 的三指勾弦、掌部放松关系；角度依本手模的原生解剖轴制作，不跨骨架照搬。
- 掌骨支撑、拇指和小指取自现有 M4 原生完整右手姿态，保留局部旋转关系；解决只在开放参考姿态上增加统一弯曲角造成的爪形轮廓。
- 在实际蒙皮的末节指腹选取接触区域，分别为搭弦、半拉、满拉拟合三指及手内接触点；将弦的半径纳入作者侧表面约束，避免以指节中心或腕部原点代替皮肤接触。
- 三个接触姿态随拉距混合。腕位由当帧手型的接触偏移反推，右手和弦保持共同参照；拇指与小指不再充当勾弦手指。
- 满拉弓根调整为 `(70,-16,-8)` cm，弦触点局部 X 改为 `-50` cm，为重新定位后的整手留出镜头距离。仍保留左侧单手待机与朝屏幕右侧拉弦。
- 取箭路径通过连续曲线连接中间点；拉距曲线保持原参考采样值，改用连续切线衔接，减少逐段停顿。放弦后手指张开，随后恢复轻屈并退出镜头。

作者拟合与局部表面约束属于制作过程，不代表所有中间姿态、装备外观或 UE 运行画面已验收；本轮没有运行游戏或渲染。
