# 手枪持枪位置与奔跑动作升级

用户指定参考：[BV1x6AgeTEPd](https://www.bilibili.com/video/BV1x6AgeTEPd/) 的 29～34 秒。覆盖现有 M1911 与 Dan-Wesson 715，取代此前 `pistol-sprint-idle-20260914.md` 的整套视模横摆。

## 已观看的参考与制作选择

B 站页面读取超时后，通过公开播放接口读取指定时间附近的视频帧，以 10 Hz 查看动作。分析帧仅在本机 `Saved/Reference/PistolBV1x6AgeTEPd20260914`，不放入游戏 Content 或公开素材包。未复制视频中的模型、纹理或动作数据。

- 29.0～29.2 秒：双手持枪靠画面中央下方，枪口保持前向；右手握柄，左手承托。
- 29.3～30.3 秒：加速时左手松开，右手带枪向右侧收回，形成上下、前后和侧倾相互错开的摆动。部分时刻枪明显接近画面边缘。
- 30.5～31.6 秒：短暂回正后再次进入单手摆动，左手会在下方出现，左右手承担不同动作。
- 31.8～33.2 秒：转向和加速交替，左手离握与回握、右手摆枪和回稳连续切换。
- 33.4～34 秒开始进入交火，不将受击、射击和镜头快速转动混入循环。

这段实战画面还包含镜头、加减速和转向；本次提取持枪构图、单手奔跑、错相摆动和回握意图，再适配现有枪型。没有将屏幕轨迹声称为精确三维运动捕捉。原视频公开流为 360P；10 Hz 是分析采样频率，不是源帧率。

## 持枪与动作

| 项目 | M1911 | 715 |
| --- | --- | --- |
| 腰射视模位置（相机空间 cm） | `(-2, 3, -6.5)` | `(1, 3.2, -7)` |
| 原位置 | `(0, 6, -5)` | `(0, 6, -5)` |
| 奔跑枪根中心位移（cm） | `(-3.2, 2.2, -2.5)` | `(-2.6, 2, -2.5)` |
| 奔跑前后／左右／上下幅度（cm） | `0.9 / 2.8 / 2.0` | `0.8 / 2.3 / 1.7` |
| 枪口俯仰中心／幅度 | `12° / 9°` | `10° / 7°` |
| 左手脱离位移（相机空间 cm） | `(-8, -14, -16)` | `(-8, -14, -16)` |

以上是作者参数，不是实机测量结果。715 使用较小的主摆幅，区别于较短的 M1911。

三段独立循环：M1911 `sprint`、`sprint_empty` 和 715 `sprint`。每段 1 秒代表一个完整左右步周期，作者场景 60 FPS、骨骼采样 120 Hz。运行时用脚步相位映射到片段时间，不将“1 秒”作为固定游戏奔跑节奏。循环中的枪体和右手共用绕右腕的变换，沿用原握柄及手指关系；左手在独立视模空间退开、反相摆臂，肩肘腕由既有整臂求解器调整，twist 辅助骨跟随对应完整骨段。

原片段来源为 M1911 Contact 的 `M1911_Contact_idle/idle_empty` 和 715 Upgrade 的 `DW715V2_idle`，均从当前作者文件取样。M1911 空仓循环保留后定套筒；715 使用闭合弹巢，现有 cartridge pose 继续按真实装弹数显示子弹。未替换当前 Chrome／RearFinish 网格、手套或材质。
