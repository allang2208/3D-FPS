## 制作入口与状态

- `author.py`：读取原文件，转换轴向、适配握柄、导出 FBX 和可编辑 Blend。
- `author_icon.py`：制作库存灰阶 PNG 资源，不生成验收截图。
- `register.py`：按独立物品键追加目录、公式、专属外观目录与打包目录，保留并行改动。
- `build.ps1`：等待当前 UBT 结束后，后台构建 Editor / Game 目标。
- `import_assets.py`：无界面导入网格、PBR、UI 纹理并实际保存。网格启用 Nanite 和完整回退几何；材质仅声明静态网格实际用途。
- `record_delivery.py`：整理制作、构建、保存回执和共享动作清单。

实际保存资产见 `import_receipt.json`，构建结果见 `build_receipt.json`，交付汇总见 `delivery.json`。编译与保存不代表游戏效果验收；本次不启动编辑器界面、游戏、PIE 或运行测试，握持、动画观感和联机效果交由用户测试。
