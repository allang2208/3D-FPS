# Super90 左臂与衣袖蒙皮修复

用户截图中，腰射与 ADS 的左臂都存在肘旁拧折。前一轮骨轴修复解决了动作整体错位，但不代表本次腕臂外观已获认可。

本次定位到两个迁移问题：

1. M4 上臂两根辅助骨的权重合并到了 Super90 上臂，但几何变换仍分别以辅助骨起点对齐到肩点。两段长度倍率因此达到约 1.30 和 2.59，产生不连续的表面拉伸。现在这些权重共用完整上臂段的同一个变换，保留原网格的相邻关系。
2. 原作者衣袖在肘端使用 `twist_arm_1`（导入名 `lowerarm_aux`）承载皮肤；迁入的裸臂与装备却使用了 `lowerarm` 控制骨。待机时该辅助骨与控制骨存在约 55.9 度的旋转差，造成近肘端的扭转分布突变。现在近肘端权重沿用原作者的第一扭转站，其余两站和腕部继续使用各自对应骨骼。

重制范围是 Super90 主视模中的 V7 手臂、独立裸臂，以及 8 份 Super90 装备/配套皮肤。枪体几何、参考骨架、手指抓握和 11 段动作轨迹不变，其他武器的装备派生不在本次重制范围。

制作源已同步修正，避免下次生成恢复旧映射。专项入口位于 `SourceAssets/Super90ArmSkinRepair20261007/`：

- `author_skin.py`：从 V7 母版重制原生皮肤。
- `author_equipment.py`：仅重制 Super90 装备派生。
- `import_skin.py`：实际保存网格、材质绑定、装备 LOD 和本枪覆盖配置。
- `Before/`：保留修复前可编辑源与两个 FBX。
- `import_receipt.json`：实际导入保存后记录产物。
