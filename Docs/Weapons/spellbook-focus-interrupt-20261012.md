# 魔法书专注限制与受击打断

本次按用户要求加入移动减速、禁用快速近战和受击打断惩罚，并制作区别于正常合书的独立回收动作。

## 状态与结算

- 从右键开始进入专注时，移动速度乘以 `0.67`，与既有移动状态相乘。完全展开之后，继续保留施法速度 ×2、魔法消耗 ×0.75。
- 开书、阅读、正常收书和受击回收期间，快速近战入口直接拒绝；删除旧的“先合书，再排队书本推击”行为。
- 正常开始合书时结束增益与减速。受击时在伤害实际被接受后立即解除专注，再播放回收；手动收书及换装取消不扣蓝。
- 打断损失 `最大魔法值 × 0.25`，当前魔法值最低扣到 0。这不是施法成本，不经过专注减耗，也不要求余额足够。
- 打断标记先于资源更新；同一次回收中的后续伤害不重复扣蓝，也不重启动画。回收结束前不能重新开启专注。
- 伤害入口位于 `UFPSCombatHealthComponent::OnDamage` 的实际扣血之后，因此闪避、完全格挡、无敌及月影免伤等拒绝的命中不触发。饥饿、缺水等生存扣血不视为受击；其他被接受的伤害包含持续伤害。
- 魔法值即时更新，沿用战斗进度的自动存档队列与现有通知，不在受击帧同步写存档或重新应用装备。开发面板的无限魔法继续免除魔法值扣除。

本次专注仍沿用现有本机玩家组件；没有新增多人专注状态、减速或扣蓝的服务端复制协议。

## 独立打断动作

总长 **0.72 秒**，不调用正常 `BeginCloseFocus`，不倒放整段开书。

| 时间 | 动作 |
|---|---|
| 0–0.07 秒 | 捕获实际左臂与书页姿态；整条左臂短促后撤，书本轻微失稳，金光快速熄灭。 |
| 0.045–0.28 秒 | 封面快速合拢，七张页片错峰收拢并短暂颤动；从当前翻页姿态收束。 |
| 0.08–0.34 秒 | 肩肘带动左手接书，手指稍晚握紧；书本沿独立轨迹靠近同帧手部握点。 |
| 0.34–0.72 秒 | 书本已闭合且重新挂到左手，保持刚性接触一起收回，最后混合到实时持书待机。 |

已在开书早期受击、书尚未脱手时，保留持握关系，只做手臂后撤与回收，不强行把书弹出再接回。死亡、换装或现有高优先级动作继续沿原清理路径收尾。

动作由运行时姿态层实现，复用已接受的 V30 骨段、手型与握点。新可编辑时序和冲击参数位于 `Source/FPSGAME/Weapons/Spellbook/SpellbookFocusInterruptMotion.h`，姿态与书页轨迹位于同目录 `SpellbookFocusInterrupt.cpp`；没有新增或替换动画 uasset。
