# 碳钢战斧数值与通用斧刃设计（2026-11-02）

本轮为 `ue_tactical_hatchet` 接入独立攻击力与强化公式、攻击间隔和普通攻击体力消耗。后续按用户“继续”要求，三款斧刃已完成模型、PBR 和共享改造图标的实际导入保存，并登记到游戏“斧头”槽。制作源与回执见 `SourceAssets/OneHandAxe20261101/BladeVariants20261102/`。

## 原装战斧

`S` 为公式入口使用的有效力量，`D` 为有效敏捷，`L` 为强化等级（沿用现有武器强化上限）；`round` 沿用游戏的 `floor(x+0.5)`。

| 项目 | 尼泊尔弯刀 | 碳钢战斧 |
|---|---|---|
| 未强化攻击力 | `round(24 + 2.1S + 2.7D)` | `round(32 + 3.4S + 3D)` |
| 强化后攻击力 | `round(24 + 2.95L + (2.1 + 0.42L)S + (2.7 + 0.53L)D)` | `round(32 + 4L + (3.4 + 0.68L)S + (3 + 0.6L)D)` |
| 目录伤害基准 `melee_damage` | 30 | 40 |
| 基础普攻间隔 | 0.8 秒 | 1.05 秒 |
| 默认普通攻击体力 | 7.5 | 10 |
| 基础攻击距离 | 220 cm | 220 cm |

目录伤害基准用于原生回退与改造比例，实际攻击力优先走上面的独立公式，不能把 40 当作无属性角色的公式攻击力。攻击力系数提高并偏向力量，敏捷仍参与攻击力和近战攻速；不在最终结算末端叠加一层“战斧增伤”。

同属性、同强化、同其他修正时，战斧的每一项公式系数均高于弯刀。由于力量／敏捷权重不同，增伤比例随配点变化。基础普攻间隔增加 31.25%，对应攻击速度降低约 23.81%；默认单次普通攻击体力增加约 33.33%。

### 配置推算例

以下按有效力量=10、有效敏捷=10，没有锻造品质、装配品质、精通增伤、加工、附魔或其他加成；是公式推算，不是游戏实测。

| 强化 | 弯刀攻击力 | 战斧攻击力 |
|---|---:|---:|
| +0 | 72 | 96 |
| +5 | 134 | 180 |
| +10 | 197 | 264 |
| +15 | 259 | 348 |

敏捷=10 时，仅计 `1+0.02D` 攻速，普攻间隔为弯刀约 0.6667 秒、战斧 0.875 秒。强化只沿用现有伤害增长，不额外改变基础间隔和体力。

## 接入

- 正式数据：`Content/ColdSteelData/items.json` 与 `combat-weapon-formulas.json`。
- `ColdSteelMelee::AttackStamina` 读取目录已有同步字段 `melee_stamina`，它表示经过单手／双手口径后的完整基础消耗；未声明时保留原先全局近战体力及单手 0.5 倍规则。战斧明确设为 10，之后仍按装备、配件、临时状态、套装和既有最低消耗规则结算。
- 普攻、连段、重击释放及双持双方分摊继续共用 `AttackStamina / ComboAttackStamina / HeavyReleaseStamina`；双持仍各按自己的武器消耗计算后分摊，不把两把武器倍率相乘。
- 主手／副手普攻继续使用现有 `Evaluate` 和 Kukri 动作时钟。攻击速度影响普通攻击及连段；重击蓄力、上挑、风车、快速近战等武技保持既有独立速度与技能消耗规则，不把新的普通攻击体力重复扣到技能消耗上。
- 攻击力、强化提示与实际结算继续调用 `UColdSteelEnhancementSystem::AttackFormula / ProcessedDamage`，原有制作、精通、配件、附魔与伤害通道的阶段取整保留。
- `ColdSteelProfileRuntime` 已有目录刷新和网络物品清理入口包含 `melee_damage / attack_seconds / melee_stamina`。旧战斧会在正常档案载入／同步时刷新这些字段，实例强化、改造、附魔、位置和旋转保留；本轮没有直接改写用户存档。
- 初次注册脚本 `SourceAssets/OneHandAxe20261101/register_hatchet.py` 同步新的目录数值，避免未来复用时重新复制弯刀基准。

## 三款通用斧刃方案

与通用弯刀的轻型迅刃、厚背重刃、百炼均衡刃一一对应。下表百分比以原装战斧为基准；相同特色的斧刃装在战斧上，与相应弯刀组合相比，物理伤害更高、攻击速度更慢、体力消耗更多。

| 斧刃 | 外形与材质 | 物理伤害 | 攻击速度 | 攻击体力消耗 | 韧性伤害 |
|---|---|---:|---:|---:|---:|
| 轻型钩月斧刃 | 窄月牙刃、短斧须、两道浅减重槽；石墨灰碳钢配窄银色磨刃 | +5% | +10% | -5% | -5% |
| 厚背重劈斧刃 | 宽腹厚脊、三段楔面、截短下刃角；深灰锻面配宽银色刃口 | +30% | -15% | +20% | +30% |
| 百炼弧锋斧刃 | 圆润扇形弧锋、短圆斧跟；银灰百炼流纹与独立素面刃口 | +15% | -5% | +5% | +15% |

轻型方案在战斧内部提供较快的选择，相比轻型迅刃弯刀仍慢且耗体更多。厚背方案强调单次冲击，百炼方案保留中等质量与稳定弧锋。均为直接属性改造，不新增破甲、流血、元素或动作替换特效。

### 同特色对比（+0，S=D=10）

攻击力为对应公式及刃面物理伤害倍率的配置推算；公式阶段先取整，物理通道倍率随后保留小数，不额外按界面格式取整。间隔列先不计角色攻速，以便直接比较武器与斧刃。计入敏捷=10 时两者间隔都再除以 1.2。体力按默认调参，没有其他减耗。

| 特色 | 弯刀攻击力 / 基础间隔 / 体力 | 战斧攻击力 / 基础间隔 / 体力 |
|---|---|---|
| 轻型 | 68.4 / 0.6957 秒 / 6.375 | 100.8 / 0.9545 秒 / 9.5 |
| 厚背 | 86.4 / 0.8889 秒 / 8.25 | 124.8 / 1.2353 秒 / 12 |
| 百炼 | 79.2 / 0.8000 秒 / 7.5 | 110.4 / 1.1053 秒 / 10.5 |
