- 正式目录：`/Game/Weapons/Super90/RearGrips20261012`。
- 可编辑源、FBX、制作脚本、保存回执：`SourceAssets/Super90RearGrips20261012`。
- 输入为当前安装的三款 M4 通用握把及 `SK_Super90_V7` 导出件，包含已在用的后握把表面细化。输入路径和 SHA256 保存在 `inputs.json`。
- 移除通用件旧 M4 接头。以 SUPER90 原握把握持区两处中心线进行刚体定位，保留下半部尺寸和纹理；原装上端保留至组件空间 Z=-82.3 cm，以连续过渡网格连接新握把。对本次生成的静态件仅局部处理退化微面和塌缩 UV。
- FBX 在 SUPER90 骨架组件绑定空间制作，UE 单位为 cm。运行时附着 `WPN_root` 并使用其完整参考变换的逆变换；不使用其他枪型的固定 0.01 缩放。

- 原生骨架网格仅调整这一组面的材质分区，没有重做顶点位置、UV、蒙皮权重、骨架或动画。原文件备份位于制作目录 `Before/SK_Super90_V7.uasset`。

## 材质

沿用现有 WeaponSurface WS1 表面和雨水响应，为静态件建立私有母材质 `M_Super90RearGripSurface`。原生接头沿用 SUPER90 的法线及遮罩 UV；新增过渡使用独立 UV；通用握持区使用原模型的顶点分区和打包粗糙度，不套用枪体图集。

- 阳极金属：线性色值 `(0.020, 0.021, 0.022)`，粗糙度 0.46，金属度 1。
- 聚合物：线性色值 `(0.019, 0.019, 0.018)`，粗糙度 0.55，金属度 0。
- 稳固防滑握持区：线性色值 `(0.0103, 0.0103, 0.0103)`，粗糙度 0.62，金属度 0；保留源模型的指槽和防滑几何。
- 不添加大面积划痕或磨白。干湿过渡继续使用 `WeaponWetness`；私有母材质纳入现有雨水材质识别。
