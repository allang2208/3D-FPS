## 动画（P1 / P4 / P5）

- **按运动弧长重排时钟**：以锤头、双手、双肘的实际位移累积弧长为时间轴重新采样，原矿镐源里的三处死停（起手 0.17 s、蓄满 0.13 s、伸展冻结 0.09 s）全部消失；各段改为明确的速度曲线：起手即动 → 柔和到顶并保留微漂移 → 下劈持续加速 → 接触 → 挥空减速 → 欠阻尼回位。
- **出击不再瞬移**：下劈段从约 0.07 s 拉长到 0.22–0.30 s；锤头峰值速度从 65–70 m/s 降到 24–29 m/s；单帧最大关节位移从约 11.5 cm 降到 3.6–4.1 cm（300 fps）。
- **挥空顺势**：原源动作接触后只有约 13 cm 余程会硬停。挥空时手臂绕肩继续带锤前行 30°（第三段 36°），以接触时的角速度起步、约 0.07–0.13 s 内刹住再回位；肘部引导随手腕整体转动，手腕额外弯折 ≤ 6.3°。命中则保留硬停 + 短暂反弹。
- **动作层次**：下劈时锤头最多滞后双手 6°、接触瞬间甩直（接触帧不变）；蓄满时手指略松、出击握紧；整套手臂与锤子有随刀势的整体前送/回弹（刚体，不改关节关系）。
- **三段差异**：第一段下劈 0.25 s；第二段（含换手）更干脆 0.22 s；第三段蓄得更早、下劈 0.30 s 更沉，命中停 0.10 s（前两段 0.07 s），并带镜头前压下沉。

## 运行时（P2 / P3 / P6 / P7）

- **连击承接（不改 DPS）**：已缓冲下一击时，从当前一击的挥空回转点（第二段在换手换回之后；命中则在命中停之后）就开始播放下一击的蓄力，手不离柄地过渡（0.16–0.45 s）；玩法上下一击仍在原时刻开始，接触与服务器计时完全不变，只是下一击的前段蓄力被拉长、提前可见，锤子不再回到待机停住。联机若服务器判定的段数不同，或命中确认晚到，都会从当前可见姿态平滑接管。
- **攻速非线性**：攻速提升时，下劈和挥空刹车最多加快 15%，其余由蓄力和回位吸收；接触与总时长仍严格等于攻速换算值。挥舞声按各段下劈时刻同步。
- **镜头**：头部领先手臂约 30 ms；下劈前有一次小幅预备回收；收势改为约 8% 回弹的阻尼回位；第三段前压下沉更重，命中顿挫 ×1.3。第三人称身体随新的时钟与段别。
