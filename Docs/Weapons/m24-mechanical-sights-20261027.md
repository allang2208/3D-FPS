# M24 机械瞄具接入补全

本次承接用户反馈“没有构建匹配的机械瞄具”，补全无光学镜状态的实体照门、准星与 ADS。前一轮 `Surface20261027` 已保存独立模型，但只有选中 `m24_palma_iron` 才装配；`none`、`false` 和空值会删除附件，随后沿用原六倍镜瞄点。该分支不能作为可用的机械瞄准状态。

## 模型与瞄线

保留早期 M24 的侧置调节照门、觇孔圆盘和护筒准星造型，参考 [TM 9-1005-306-10 图 2-22 / 2-23](https://usarmorment.com/pdf/sws24.pdf#page=64)。这是适配当前游戏枪模的美术模型，不是实物制造尺寸。

在原作者文件上修订照门横向支架与托座，使其位于觇孔通道下方；旧横梁上表面越过瞄准中心，形成遮挡。修正环形网格的面绕序，使外壁朝外、孔壁朝内，保留实体孔洞，不使用双面材质掩盖错误。保留与当前枪体一致的安装坐标、前后瞄点和准星尖端；枪体、手臂和动作资产没有替换。

新资产为 `/Game/Weapons/M24/IronSights20261027/SM_M24_m24_palma_iron`，沿用当前 M24 的静态 WS1 金属、孔内哑光与标记材质。作者目录 `SourceAssets/M24IronSights20261027` 保留可编辑 Blender 场景、FBX、脚本和挂点记录。

## 装配与界面

- `M24Attachments::OpticPart` 将无光学镜状态统一映射到实体机瞄；显式机械瞄具选项继续兼容。装六倍镜时替换同一个组件，保持互斥。
- ADS 从机瞄网格的 `SightRear`、`SightFront`、`SightUp` 求完整坐标系，机瞄使用独立眼距；六倍镜眼距和倍率保持。机械瞄具倍率为 1，不启用六倍镜分划。
- 第一人称、改造预览、物品图和掉落装配共用原 setter；图标准备也解析无光学镜对应的实际资产路径。
- 附件注册和配置时继承宿主可见状态；原本隐藏的武器不会因为配置附件而强制重显。
- 目录保留存档 ID `none`，文案改为“拆下光学镜”并说明自动换上机瞄。此选项与机械瞄具复用已有的灰阶金属框图标 `optic_m24_palma_iron`。
