# 武器基础与附加伤害统一规则

2026-09-15 按用户要求实施。适用于即时武器命中，包括当前近战、即时射击和飞行子弹。

## 1. 面板就是攻击快照的输入

伤害数据保留四个分项：基础物理、基础魔法、附加物理、附加魔法。面板总伤害是四项之和；当前普通武器的基础部分为物理伤害。

基础沿用既有武器公式、强化、制作、精通和附魔次序。附加部分先把固定值、属性系数和基础伤害比例换算成数值；属于攻击者自身的魔法增伤也在此阶段计入。当前侵蚀符文的智力×10%＋精神×10%进入附加魔法。

面板不含尚未确定的重击/连击段数、目标防御或目标易伤。起手/开火捕获全部分项和穿透，飞行途中升级或换装不会改写已发出的攻击。

## 2. 每次命中的顺序

1. 面板四分项共同乘这次攻击的倍率：重击、连击段数、距离衰减，以及已有的要害和暴击倍率。
2. 基础、附加中的物理部分分别按目标物防与物理穿透计算；魔法部分分别按目标魔防、魔法穿透与魔防削减计算。
3. 对相应伤害类型应用目标状态，例如冻结的物理增伤、魔法易伤，再应用目标最终承伤倍率。每个非零分项独立取整。
4. 得到基础和附加两笔伤害结果，再合计扣除生命。生命不足时，基础在前、附加在后占用剩余生命；实际扣血回执之和等于生命损失。

防御公式沿用 `CoreCombatFormula::Defense`：有效防御经过穿透/削减后，取 `max(floor(伤害×60/(防御+60)), floor(伤害×10%))`。本次不调整防御曲线。

例：面板基础物理100＋附加魔法20，总伤害120。2倍重击先得到200物理＋40魔法；若有效物防60、魔防60，且无其他状态，则分别结算100和20，总扣血120。这是规则举例，不是运行测试结果。

一次接触共享一个暴击判定、一个硬直/附效触发、一个击杀和经验事务。两笔伤害通过显式回执传给 HUD，避免把附加伤害重新当作另一刀而重复触发奖励或命中效果。

持续毒伤等按时间跳伤继续使用自己的周期，不计作每刀立即发生的附加伤害。

## 3. 新增附加来源的数据入口

武器实例/定义的 `additionalDamage` 可声明物理、魔法来源，单位均为原始伤害数值或小数比例：

```json
{
  "additionalDamage": {
    "physical": {"flat": 5, "baseRatio": 0.1, "attributes": {"str": 0.2}},
    "magic": {"flat": 0, "attributes": {"int": 0.1, "wis": 0.1}}
  }
}
```

`baseRatio` 读取已经处理过的武器基础伤害，不读取包含附加部分的总和。属性支持现有六属性，`int`/`intt` 同义；`atk`/`matk` 可读取角色派生攻击。缺省来源为零。本例仅说明接口，没有添加到其他现有武器上。当前侵蚀符文仍读取原改造配置，通过相同求值入口合入魔法分项。

以后新的即时附伤先进入 `ColdSteelWeaponDamage::Evaluate` 的面板结果；命中时消费捕获的数值，不在目标结算末尾再次读取属性补算。
