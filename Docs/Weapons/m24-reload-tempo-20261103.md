# M24 拔匣节奏续修（2026-11-03）

用户反馈拔出弹匣仍有停留，要求加快且自然。本轮只调整共用运行时换弹时钟及配套基础时长，继续使用当天 `M24SurfaceGrip20261103` 已保存的抓匣姿态。没有重写手指、掌腕、弹匣或枪械资产。

## 本轮节奏

`Source/FPSGAME/Weapons/M24ReloadTiming.h` 原先将源帧 18–29 的拔匣、松手和退手拉长到约 1.2222 秒。本轮将对应运行时区间从 36.6667 个节拍缩到 18.6667 个节拍，即约 0.6222 秒，缩短 0.6 秒。继续使用单调三次插值及相邻段的连续速度，让抓稳、快拔、松手和退手相接，避免逐段停住再启动。

`Content/ColdSteelData/gunsmith.json` 仅按字段修改 M24 两项基础时长：普通 `4.7 → 4.1` 秒，空仓 `6.3666667 → 5.7666667` 秒。保留其他目录改动。换弹速度属性仍按既有规则缩放全段；各配件分支继续使用共用时钟。

手臂基础序列、握持增量、弹匣、机械音效、弹药接触和换弹镜头继续沿既有 `ReloadSourceTime`／`ReloadRuntimeTime` 入口取时，不另设独立播放倍率。覆盖原厂、10 发及独立后握把 Profile 的普通／空仓换弹。
