# 金银符文改造说明精简

本次只修改 `Content/ColdSteelData/melee-gunsmith.json` 的金色、银色符文说明，并同步 `SourceAssets/RuneSwordGoldSilver20261030/edit_sources.py` 中对应生成文案。保留原有 ID、stats、玩法与其他改造。

原因：两项没有显式 `special_effects`，将机制写进了普通介绍和旧 `effects`。改造详情只有在没有属性卡且没有特效条目时才回退旧 effects；银色符文已有魔法冷却属性卡，因此其条件攻速未独立显示。

处理：外观分别精简为“原生刻纹呈鎏金色。”“原生刻纹呈银白色。”；金色拆为近战回流、飞剑回流，银色填写魔法激励。特效使用已有共享渲染路径，标题与正文均取 `ColdSteelUI::Success`；常驻魔法冷却-20%继续由属性卡显示，不在特效段重复。攻速说明明确仅近战、10s、刷新不叠加。

目录由 GameInstance 的 GunsmithSystem 初始化读取。已运行的试玩需要结束后重新开始，独立游戏需要重新启动；仅重新打开改造面板不会刷新当前实例的目录。

本轮为目录与文案源修改，无需 C++ 构建或 UE 资产导入。未启动编辑器、试玩或截图验收，交由用户查看实际显示。
