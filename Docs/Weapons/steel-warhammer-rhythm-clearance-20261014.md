# 战锤挥击节奏与手臂开口位置

针对用户反馈的均速感和手臂末端露进镜头，本次修改战锤普通三连击的采样时钟、肩部姿态与组件更新顺序。

## 攻击节奏

参考 `RuneSwordRhythm` 的分段 Hermite 节奏，新增战锤自己的 `SwingSourceTime`。用户随后要求蓄力稍长，现将蓄力从 0.70 秒延长到 0.85 秒；快速挥出和收势时长保持。以当前默认 1.75 秒挥击为例：

| 阶段 | 动作时间 |
| --- | --- |
| 缓慢起势、蓄满减速 | 0–约 0.826 秒 |
| 蓄满停顿 | 约 0.826–0.85 秒 |
| 快速挥出到接触 | 0.85–0.97 秒 |
| 挥空随势、减速 | 0.97–1.08 秒 |
| 制动 | 1.08–1.12 秒 |
| 回握、逐渐收稳 | 1.12–1.75 秒 |

三段动作共用此时钟；攻速继续按现有倍率换算。挥空声移至 0.89 秒，镜头曲线读取相同的重定时源位置。物品目录同步将接触时刻移至 0.97 秒，服务器计时器和已有库存实例沿现有迁移规则更新；命中停顿与恢复分支、普通伤害及第三击 1.25 倍倍率保持原合同。本轮只调整时间，不重导骨架、动画或姿态修正资产。

## 肩部开口位置

当前 V7 作者网格两侧肩端各有一个 61 顶点的开口环，约 70.8% 权重在 `upperarm_twist_01`、27.1% 在锁骨、2.1% 在 `upperarm_twist_02`。原抬举姿态使开口接近镜头侧缘；本次以实际蒙皮开口环拟合臂根位置，采用 82 度竖向视角、16:9 和 2 厘米余量作为制作包络。

六个攻击/恢复片段共用臂根后收 2 厘米的修正，起止平滑归零。完整上臂与前臂使用原骨长，肘弯平面由原姿态连续运输，新增轴向差按原前臂辅助骨站位分配。两只手和锤体作为同一握持组，必要时少量后移以保持可达，不拉伸骨骼、不改手指抓握。

修正保存为 `DA_Warhammer_Clearance`，由现有 `WeaponGripProfile` 在基底动画上应用。覆盖第一、第二段斜挥、第三段下砸以及各自命中回收。原矿镐动画、战锤视模几何和材质保持原资产；导入的六个制作片段只作为临时差量烘焙输入，运行时仅引用原动画和修正数据资产。

战锤组件改为 `TG_PostPhysics` 并依赖角色移动组件，确保手臂姿态在相机缓存前更新；其他生产工具继续原更新组。
