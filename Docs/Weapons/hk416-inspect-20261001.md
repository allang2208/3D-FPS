# HK416 通用步枪检视

用户要求参考其他步枪，为 HK416 增加通用检视。原 `HK416_base_inspect` 来自旧 `M4_inspect`；读取源轨道后，其 3 秒片段仅有待机轻晃，M16 使用同一来源。

本次参考 `AKMIntegration20260910/Native/AKM_MannyNative_Editable.blend` 中 `AKM_Native_inspect` 的完整枪体轨迹，SVD 的既有检视也使用这条动作。将 120 fps 下 0–745 帧映射到 4.2 秒，旋转幅度取 42%、位移取 55%，在首尾加入平滑权重，形成抬枪、侧转查看、回位的通用检视。

## 握持和接入

- 原厂、垂直、斜握把、棱镜阻手器、直角握把和弹鼓分别读取自身当前作者待机姿态。双臂完整骨链、五指和枪体部件共同移动；不单独掰腕，不解算或重置肘关节，不在检视中取下弹匣或操作枪机。
- 每套动作首尾采用对应待机的精确姿态。枪口、瞄具、后托、后握和战术配件继续跟随既有装配骨。普通与扩容弹匣共用相应握把的检视；弹鼓保留独立托握，装前握把时沿用现有优先级。
- 替换现有 `/Game/Weapons/HK416/Reworked20260930/Animations/<family>/A_HK416_<family>_inspect` 六条动作，120 Hz 烘焙，保留 HK416 原生骨架及已有压缩配置。
- 同步重烘 `/Game/Weapons/AnimationProfiles20261001/ue_hk416/DA_<family>` 五份资料的 inspect 项。保留各资料的空仓拍击、换弹、装备、射击和奔跑项。
- 继续使用现有 L 键 `InspectWeapon`、动作占用、退出瞄准及恢复待机逻辑。时长从动画读取，不增加运行时求解、加载或新输入。

## 制作入口与落盘

源文件、六份 FBX、可编辑 `HK416_Inspect_Editable.blend`、导入与源目录发布脚本位于 `SourceAssets/HK416Inspect20261001/`。

1. Blender 后台执行 `author_inspect.py`。
2. 现有编辑器通过批次互斥桥执行 `import_assets.py`；正在 PIE 或目标资产有未保存改动时保留现场。
3. 外部 Python 执行 `publish_sources.py`，仅在收到完整保存回执后更新共用动画目录表。

共用 `HK416CommonAttachments20260930/author_animations.py` 增加 `--only-inspect`，完整制作也调用新检视制作入口；共用导入脚本会刷新相应握把项。仅检视入口输出 `inspect_animations.json`，不会重导其他动作。

资产保存状态记录于 `import_receipt.json`。本次无 C++ 修改，无需原生编译；未启动游戏、截图或进行测试，实际观感交由用户确认。
