# 弓改造预览中空：面朝向修正

用户要求排查并修复整体弓体及改造件预览中空的问题。本次沿实际装配目录检查弓体、握把、箭台、瞄具和预览合成代码。

## 原因

当前四款骨骼弓体继承了供体朝内的三角面绕序。原装 23,985 个面、游隼／磐木／静枝各 9,216 个面均朝内；带符号体积均为负。四者使用不透明、单面 UE 材质，外侧三角面被正常的背面剔除隐藏，因此看起来像空壳。更改缠绳接触面只能处理局部穿插，不能解决弓体外壳被剔除的问题。

V22 原装贴合缠绳、V20 三款握把、两种箭台和 V19 木制瞄具的面朝向正常，不在本轮重制。预览 UI 对覆盖通道使用 `1 - Alpha`，符合其 SceneColorHDR 捕获语义；没有将阴影或深色木纹接到透明度。没有修改共享预览材质或强制双面。

排查记录：`SourceAssets/BowSurfaceRepair20260927/source-surfaces.json`、`ue-materials.json`。

## 修复

在保留的 V15 骨骼母版上重新统一四款弓体向外的面朝向，清除不再适用的导入自定义法线并生成匹配新绕序的法线／切线。保留原有顶点位置、UV、材质、11 根骨骼和每顶点蒙皮权重，不重做弓的几何造型或动画。

制作脚本对四款弓体的修复前后顶点、权重和骨骼矩阵做了定向比较，均一致；朝向修正后各网格带符号体积转为正。结果在 `authoring.json`。这是用户要求的模型排查，不代表游戏视觉验收。

源文件：`SourceAssets/BowSurfaceRepair20260927/Bow_ElasticBodies_Outward.blend`；四份 FBX 位于同目录 `Export/`。导入到原有 `/Game/Weapons/DarkBow20260925/ElasticV15/SK_Bow_Flex_*`，保留既有骨架引用、材质槽和配装引用。导入脚本在修改前备份对应 `.uasset`，不修改骨架参考姿态、不导入动作。

同时修正模块拆分、三款弓体生成及弓体绑骨作者脚本的面朝向处理，避免后续重制继续沿用朝内网格。原 C++、存档结构、战斗数值和相机无改动。

## 状态

修正后的 Blender 源、FBX 和四个原路径 UE 骨骼网格均已保存，回执为 `SourceAssets/BowSurfaceRepair20260927/import-receipt.json`。已备份被修改的原资产，无需切换目录或重新编译模块。

从 UE 将四个实际保存资产导出后，独立读回检查面朝向：原装 23,985 面、另外三款各 9,216 面，反向面均为 0，带符号体积均为正；记录在 `saved-surface-check.json`。这一步确认修正已经进入引擎资产。没有启动游戏或生成验收渲染，实际改造界面观感仍交由用户确认。
