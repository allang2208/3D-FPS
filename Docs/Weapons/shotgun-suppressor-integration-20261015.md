# SUPER90 散弹枪消音器

用户最初要求制作新散弹枪消音器，仅提供消音、减弱火光与降低敌人听声范围；后续要求将三款散弹枪枪口件统一为特殊改造，并为消音器设置数值。以下为当前版本。

SUPER90 原有枪口只有原厂、收束器和鸟笼消焰器。本次新增 `shotgun_suppressor`；入口为 SUPER90 → 枪口 → 散弹枪消音器。

- 新外观：深灰圆角长壳体，上置出口、下置主体、纵向侧筋和独立接座。可编辑 Blender、三档 FBX/GLB、图标与作者脚本位于 `SourceAssets/Super90Suppressor20261015`。
- UE 正式资产：`/Game/Weapons/CommonShotgun/Suppressor20261015`，含模型、五组材质、平面法线、图标与专属消音声。安装回执记录实际保存结果。
- 装配：沿用当前真实上枪管安装面和 WPN_root 层级，前端插槽负责枪口特效位置；原生枪体、骨架与动画未修改。
- 功能：`IsMuzzleSuppressed` 增加 SUPER90 专用 ID，沿用现有火光、烟、听声和第三人称消音状态传递。已有本地/服务端消音听声范围分支共用，不增加第二套 AI 规则。
- 声音：从当前 SUPER90 普通声设计独立消音声，装备初始化与挂件刷新绑定专属音源；普通枪声保持原样。音色尚未经用户试听。
- 数据：消音器后坐力降低 25%、枪械稳定性提高 20%、子弹速度降低 15%、开镜耗时增加 10%，保留消音特效；弹丸散布与伤害不变。存档沿用既有枪口 ID，切换原厂/收束器/鸟笼走原流程，不叠加效果。共用图标与打包路径已加入。
- 分类：收束器、鸟笼消焰器和散弹枪消音器统一归入特殊改造。收束器的弹丸散布减少 35%、鸟笼的后坐力降低 15% 与腰射随机散布减少 15% 保持原值。

初版模型接入的 Game 与 Editor 常规构建均成功，证据分别保存在 `Super90Suppressor20261015` 目录的 `build_game_receipt.json` 与 `build_editor_receipt.json`。后续分类与数值调整使用 `ShotgunMuzzleSpecial20261015` 下的独立构建回执，不把初版构建当作后续版本的成功证据。

用户明确同意结束试玩、保存三个配件图标并关闭 UE 后，实际编辑器已退出、相关图标包已保存。本任务没有重新打开编辑器。没有进行游戏、视听或多人验收，交由用户自行体验。
