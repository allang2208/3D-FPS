## 模型与安装

复用已使用的 TacticalDevices20260913 激光和 HunyuanV3 手电主体；保留原有 UV0、光学纹理、结构法线，不重新生成主体。通过 Vibe3D 删除 M4 底座，制作 ASH 导轨夹座，转为厘米 / +X 前向 / +Y 外侧。装配以 ASH 前后瞄具建立的参考骨骼坐标为准，父骨骼 WPN_root。用户要求改为左侧后，安装原点改为 (29.5, -3.19, -8.25) cm，并绕局部 X 旋转 180°，使夹座朝内、主体朝外；不镜像网格，不改变模型大小。左轨数据位于 left_rail_geometry.json，旧右轨数据留作排查记录。

外壳使用 ASH 黑色金属色与独立涂层 UV；镜片、发射口保留独立遮罩。激光发光仅限局部发射口，雨滴材质加入 ASH 私有天气材质库。Emitter / AimGuide 由旧模型随同刚性变换得到，维持同轴照明。
