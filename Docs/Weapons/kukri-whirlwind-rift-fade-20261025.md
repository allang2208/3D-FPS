# 尼泊尔弯刀旋风剑气淡出

2026-10-25，用户反馈旋风剑气保留太久，形成完整圆圈，希望更快逐步消失。

原因是 `KukriSkillRift.cpp` 创建 380 度环带，第一圈展开后一直保持至第二圈结束，然后才用 0.32 秒整体淡出。

本次把环带改为 120 度短弧。起转时逐渐展开，之后随实际旋转角移动，仅保留刀后的一段拖尾。UV 将共享材质原有的尾端渐隐覆盖到短弧后部 60%，已扫过的部分沿尾端逐步消失。旋转结束或取消后，以原有平滑曲线在 0.12 秒内淡出。

复用原有材质和动态网格组件，无需新资产。采样站数从 96 减为 32，角度细分密度近似原值。只调整弯刀旋风剑气；冲刺斩、普通攻击、技能伤害和动作时钟沿用现有实现。

源码：`Source/FPSGAME/Weapons/Kukri/KukriSkillRift.cpp`。Editor 与 Game 目标均已构建成功，构建与交付回执：`SourceAssets/KukriWhirlwindRiftFade20261025`。未启动可视编辑器或游戏，未进行观感测试。
