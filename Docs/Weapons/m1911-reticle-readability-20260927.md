# M1911 红点与全息分划可读尺寸

用户反馈小型化后的红点、全息在 ADS 下看不清分划。此次从刚完成圆角底座修订的两个母版继续制作，只调整分划自身尺寸。

| 部位 | 本轮前 | 本轮后 |
| --- | --- | --- |
| 全息分划承载面 | 4.4 × 4.4 mm | 11 × 11 mm，原分划整体放大 2.5 倍 |
| 全景红点圆点 | 直径 1.395 mm | 直径 2.79 mm，放大 2 倍 |

以既有光心为中心，仅放大分划顶点的 Y/Z 分量。保持 X 深度、瞄准中心、套筒挂点、镜体、圆角安装座、原分划图样、材质和 UV；分划法线按局部缩放调整，其余面角法线保留。这里的数字是作者空间尺寸，不是实测 ADS 像素或实际武器 MOA。

本轮采用几何分划尺寸修正，没有修改通用分划材质、曝光、HUD、射线或其他枪械。全景红点此前已从原始缩小版放大 2.5 倍，此轮是在当前版本上继续放大 2 倍。

作者目录为 `SourceAssets/M1911ReticleReadability20260927`，保留可编辑 Blender、FBX、两张更新后的灰阶 UI 图标和导入前备份。导入继续使用现有两个配件路径，保存精确的现行 AimCenter / MountForward / MountUp 挂点；资源更新无需 C++ 编译。

两副当前瞄具网格、两张 UI Texture2D 与运行用 PNG 已通过后台 commandlet 实际导入并保存。`import_receipt.json` 状态为 `imported_and_saved`，进程正常退出；本轮无需 C++ 构建，未启动交互编辑器。

按用户规则未进行游戏运行、ADS 截图或验收测试；实际可读性及尺寸观感由用户在游戏中确认。
