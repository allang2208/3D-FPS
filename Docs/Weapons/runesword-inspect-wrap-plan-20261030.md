## V82 与参考的差距

V82 在视模相机下的渲染与量测见研究目录的 `compare_ref_v82.jpg`、`v82_measure.json`。

1. **张手过早、过久，像托盘。** 握柄权重在约 75°–338° 之间低于 0.1（约 0.50–0.75 s，占整圈约 70%）。这段手掌朝上平摊，前臂几乎水平前伸。手指只按标量从握姿混回绑定姿态，没有扇形分指，拇指最多张开 0.30。参考只在约 95°–270° 张手（约 0.13 s），掌心朝镜头，手是竖着的。
2. **剑像钉在销轴上，没有和手接触。** V82 把转轴固定在虎口的一个蒙皮点，滚动迁移限制在 4 mm 以内。渲染里 164°–284° 时柄悬在掌心上方，看不到贴合。参考里接触点在手上移动了几厘米：指根 → 虎口 → 拇指外侧 → 收拢的四指 → 掌心。
3. **手和手臂不发力。** 转动期间 V82 的手在屏幕上几乎不动（0.53–0.83 s 内 NDC 变化不到 0.05），接刀时也没有回提。腕部限幅在位置 IK 之后执行，把手的朝向拉回前臂锁定关系。下甩诊断量到这一步会回拉约 11°，作者给的手姿因此丢失。参考的前 95° 由拳带着剑转，接刀时有一次回提。
4. **节奏前快后慢，没有刹车。** V82 的峰值在中段（0.50–0.57 s 约 1330°/s），到 360° 前 60 ms 已经降到约 225°/s，之后加 4.2° 让力，落点是软的。参考在 180° 处几乎停住，最后半圈最快（约 2600°/s），握死那一帧速度骤降，余量交给整臂随动。力量感主要来自这种末段加速加急停。
5. **方向相反。** V82 在屏幕上逆时针（剑刃 上→左→下→右），按 BV1zz4y117f6「正向转刀」制作，当时用户认可了方向。参考是顺时针（上→右→下→左）。参考的几个手形（托指时四指朝上、张掌时掌心朝镜头、拇指在柄外）都依赖这个方向。保留逆时针时，对应的张掌只能是掌心朝上或朝下，做不出参考的手形。
6. **时长。** 参考的核心 360° 用 0.267 s，V82 转刀窗 0.40–0.8224 s 共 0.42 s、378°。

## 升级方案（建议版本号 V84）

### 1. 手形关键姿态库

在 V7 裸手上为右手单独作者六个手形。只写旋转，不改骨段平移、缩放与骨长，不再用「握姿→绑定」标量插值代替：

| 手形 | 内容 |
| --- | --- |
| K0 握拳 | 现有待机握姿 |
| K1 带转 | 仍闭握，剑按 `Hand × inverse(Grip)` 跟手，由腕背伸、前臂外旋和肘部带剑转约 90° |
| K2 托指 | 小指、无名指、中指按此顺序松开，食指和拇指维持支撑，柄从指根滚向虎口 |
| K3 张掌虎口 | 四指扇形分开、稍伸直，拇指外展在柄外侧，掌心朝玩家，柄在虎口转 |
| K4 勾收 | 食指、中指先勾住扫过来的柄，无名指、小指在 1–2 帧内跟上 |
| K5 握死 | 回到完整握柄变换，指屈多压 5–8% 再回落，读作攥紧 |

### 2. 握柄接触求解

- 在 V7 实际蒙皮上取一条接触路径：掌心 → 食指根横纹 → 虎口 → 拇指近节内侧 → 接刀时食指、中指中节。每个相位指定路径上的接触位置，剑柄按柱面与该点相切放置，柄轴保持切向。用这一步替换 V82 的单点虎口销轴和 4 mm 迁移上限。
- 手指在托指与接刀阶段按「指腹到柄面的距离等于 0–2 mm」迭代屈曲量，不再固定开合值。
- 穿插检查改用真实网格距离场：仿照 `SourceAssets/DualKukriIdle20261025/kukri_sdf.py`、`contact_dual.py`，为剑柄和护手建 SDF，逐帧检查手指、掌、腕与柄、护手的穿入深度和接触间隙。V82 渲染中 0.70 s 护手从腕部上方扫过，是否穿插尚未量测。2026-10-30 新增的星落、双星护手模块需按最宽一款的包络一起检查。

### 3. 手先定，臂来支撑

先确定手的位置与朝向，再依次分配：肘部绕肩腕轴的摆位、前臂旋前/外旋（沿用 V46 扭转站点分布到 `lowerarm_twist_*`），最后由腕部补足。腕部给出明确的解剖范围：背伸 ≤45°、掌屈 ≤40°、桡偏 ≤15°、尺偏 ≤30°，腕扭转仍 ≤18°，皮肤扭转 ≤70°。超出时调整前臂方向，不把手朝向拉回去。参考中前臂竖直托手，所以张掌阶段肘部要比 V82 低，前臂要比 V82 竖。

V83 曾在下甩段试过「由手驱动」，被否定。这次的不同在于：目标手姿逐帧取自参考，而且先过关键姿态确认（见第 5 步）再做动画。

### 4. 节奏与发力

- 准备与下甩沿用 V82（0–0.40 s，含 −18° 反向预备）。
- 带转 0.40–0.47 s（0°→约 100°），托指与入虎口 0.47–0.57 s（→180°，逐渐减速），在 180° 处挂约 30 ms。
- 收转 0.60–0.67 s（180°→360°），一路加速；手向上、向内回提约 6–8 cm，手领先剑身。
- 360° 处不缓入，一帧内降速约 80%。之后手、前臂、剑作为整体顺转 15–25°，由肘肩吸收，约 0.15 s 回位。左手沿用 V82 的分步回握，回到双手待机。
- 转刀核心约 0.27 s（V82 为 0.42 s），总长控制在 V82 的约 1.16 s 以内。

### 5. 制作顺序与确认点

1. 参考逐帧读取：转角、手的屏幕位置、手形标签，大部分已在本轮完成。
2. 只做 K0–K5 六个静态关键姿态，与参考同转角、同屏幕区域并排出图，请用户先确认手形和握柄位置，再进入动画。
3. 制作动画：30 Hz 对照拼图，加逐帧报告（接触间隙、最大穿入、腕部四向角、皮肤扭转、剑尖最小进深 ≥0.10 m、角速度曲线）。
4. 普通柄与长柄分别制作，保留 V82 包备份以便精确回退。通过 commandlet 或 MCP 批次互斥接入，不启动游戏。观感由用户试玩判定。

### 6. 可选：运行时反馈

不在本方案默认范围内，需要改 `URuneSwordComponent` 并编译：收转时加一声挥风，握死时加握柄撞击声，镜头约 0.3–0.5° 一次性回弹，收转半圈加淡剑身拖影。建议在动画认可后再决定。
