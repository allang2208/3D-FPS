# 四款元素杖头清洁表面与反射 V42

用户在原厂白水晶 V41 抛光版后，要求尝试以同样方式调整其他杖头。本轮仅调整现用冰晶、熔岩、翠灵和风暴外壳的表面粗糙度、法线与相关反射设置，保留各自材质身份。

| 杖头 | 表面处理 | 保留内容 |
| --- | --- | --- |
| 永冻冰晶 | 去掉细碎凹凸，用原晶面法线；粗糙度 0.12，突出白冰切面和原有倒角高光。 | V38 不透明白冰、原颜色与霜纹、造型、照明。 |
| 熔岩晶核 | 岩壳粗糙度 0.55，依据原熔融遮罩向 0.24 过渡；原法线扰动降至 0.25 强度。 | V38 不规则圆球、暗色岩壳、橙红裂隙、发光与脉动。 |
| 翠灵水晶 | 去掉微表面凹凸；原矿物分布映射为 0.13–0.18 粗糙度，表现完整的玉石高光。 | V37 绿玉矿纹、次表面散射、原造型与照明。 |
| 风暴核心 | 外壳去掉细碎凹凸，粗糙度 0.065；启用材质屏幕空间反射和天空环境图过渡混合。 | V38 紫色与透明覆盖率；中心八股主电弧、四分叉的 12 Hz 路径变换及移动亮点完全不改。 |

## 实现范围

- 直接在现有材质图上替换 Roughness / Normal 输入，其余图保留原样。冰晶、熔岩和翠灵不会改成透明玻璃；风暴不会新增实体中心或外壳几何。
- 四种模型、材质槽、金属安装座、杖冠、符文、握柄与尾饰、原厂白水晶 V41 均不修改。
- 颜色、Opacity、次表面散射、Emissive、`StaffLightAmount`、G 键点光源及风暴内部 WPO 动画均不修改。没有新增 C++、Tick、光源、贴图或全局渲染设置。
- 现有第一人称、掉落及背包／改造台装配共用稳定材质路径，因此无需新的资源加载或 UI 映射。风暴 SSR 是否可用取决于视图的历史缓冲及反射设置；间歇预览继续有工作室光照与环境反射，不承诺与世界画面一致。
- 新节点采用 `ElementPolishV42:` 标记，重复制作只替换本轮节点，避免累积法线或粗糙度变换。冰晶、翠灵和风暴不再使用原凹凸图输出；熔岩复用原法线，保留岩石感。

## 制作与接入

作者目录：`SourceAssets/ApprenticeStaff20260927/ElementPolishV42`。

- `parameters.json`：四款独立表面参数。
- `author_surfaces.py` / `Staff_ElementPolish_V42.blend`：保留 V38 冰晶／熔岩／风暴，载入 V37 翠灵的 Editable 集合，保存纯材质修订。没有导出或重新导入模型，也没有烘焙新贴图。
- `ue_material.py`：仅修改表面输入的共用配方；`apply_installed_surface` 供旧版材料重建入口保留已接入 V42。
- `install_ue.py` / `run_install.ps1`：备份四件原材质，先保存四件独立候选，再保存四件正式材质。
- 正式路径沿用 `/ElementHeadsV38/Materials/M_StaffCraft_{Ice,Magma,Storm}_V38` 与 `/ElementHeadsV37/Materials/M_StaffCraft_Jade_V37`，前缀均为 `/Game/Weapons/ApprenticeStaff20260927`。
- V37／V38 安装器在保存材料前应用已完成且 active 的 V42 配方；V37 安装器生成脚本同步保留此入口，V38 生成器继承它。整杖重导继续读取原路径，保留其他并行改造分支。
- 改动前材质保存在本轮 `Before/Content` 和 UE `/ElementPolishV42/Before`。撤回时应恢复这四件材质，并关闭本轮回执 active。
