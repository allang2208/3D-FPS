# 矿镐攻击：双侧肘部支撑与命中制动

后续精调见 [第三版肘部衔接与上下行程](pickaxe-elbow-arc-20260919.md)。当前导入入口已切换到 `SourceAssets/PickaxeElbowArc20260919`；本文保留第二版制作记录。

用户反馈双臂扭曲，要求从身体左右自然伸出，举顶蓄势后快速下砸，命中像斧头一样短暂停顿。本轮只调整矿镐 Swing / HitRecover；保留待机、装备、奔跑、物品身份和采矿规则。

## 问题来源

按用户要求读取上一版实际 Blend 关键帧、手掌相对镐柄变换、Manny rest 与辅助骨，并查看既有符文剑 V52 举顶动作表。上一版 300 Hz，运行 1.16 秒，接触在 0.60 秒；源动画 0.68 秒、源接触 0.24 秒、源回收 0.44 秒。

- 待机镐柄近似横向，直接把这套固定手掌相对姿态用于竖直举顶，左右前臂被要求从相近方向靠近手柄。腕部折角不是单纯的前臂旋前，不能只调整 twist 骨解决。
- 旧版左肘在举顶 X=+0.005 m、接触 X=+0.044 m，越过身体中线。接触左腕折角约 118°，右腕约 72°。
- 原求解限制肘部不能高于手腕；下砸阶段这个限制妨碍自然屈肘。工具整体过度前伸又触发肩部前移补偿。

## 修改

起势时手掌沿实际镐柄截面轴转握，左手从左侧包住柄，右手从右侧支撑；手指局部弯曲和沿柄握距保留。左手主要换握在举起阶段完成，接触和命中停顿期间不滑握。入场、回握有有限环绕角拟合，避免工具姿态、手掌绕柄和肘部展开不同步。

两肘使用独立向外、略向后的连续方向，逐步从原待机弯曲平面转入动作。下砸时允许肘高于手腕，不再以手腕最直为目标自由搜索肘部方向。肩部抬升配合举顶，工具接触位置收近并压低；使用原上、下臂长度，不用拉伸或增加肩部前冲补偿。

上臂与肘部使用同一个弯曲平面，前臂父骨从肘铰链方向开始，旋前沿实际 Manny 蒙皮站点分配给辅助骨。上臂不再额外分担手腕旋前。两端渐变回原待机；进入命中回收直接复用完整接触姿态和连续旋转状态。

| 阶段 | 运行时 | 节奏 |
| --- | --- | --- |
| 举起 | 0–0.32 s | 五次缓动，双臂展开随绕柄换握同步 |
| 蓄力 | 0.32–0.47 s | 后收约 2 cm、增加后倾，末尾约 45 ms 保持 |
| 下砸 | 0.47–0.60 s | 0.13 s 的幂曲线加速，末端硬制动 |
| 命中 | 0.60–0.80 s | 完整双臂和矿镐保持 0.20 s |
| 抽回 | 0.80–1.16 s | 一次轻微后上抽动，再平滑回握 |
| 挥空 | 0.60–1.16 s | 惯性下沉至约 0.685 s，随后回握，不播放命中停顿 |

采矿判定保持 0.60 s、挥动音保持 0.50 s、总时长保持 1.16 s，因此不需要改 C++ 或重编译 DLL。300 Hz FBX 密集采样记录非线性路径；相邻采样点的线性连接不等于动作匀速。
