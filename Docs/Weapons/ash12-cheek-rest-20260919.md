# ASH-12 贴合式托腮板

新增 ASH 专属的低矮鞍形托腮板，以现有后托表面构造连接面，搭配独立软垫、侧面固定片与凹入式紧固件。安装时保留原厂后托，随 `WPN_root` 运动。

入口：枪匠 → ASH-12 → 枪托 → **ASH-12 贴合式托腮板**。移除选项为 **原厂后托**。本次为外观配件，没有调整开镜、后坐力或稳定性数值。

三组 PBR 材质匹配本枪聚合物与枪钢，已接入私有水珠映射；正式配件图标使用实际模型制作。沿用当前枪匠、装备实例、保存、整枪图标和掉落装配路径。
