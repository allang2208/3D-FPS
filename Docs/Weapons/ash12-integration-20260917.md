## ASH-12 攻击力公式（2026-09-18）

- 口径来源：`Content/ColdSteelData/combat-weapon-formulas.json` 的 `ue_ash12`，运行时由 `UColdSteelEnhancementSystem::ProcessedDamage` 读取；不是 `gunsmith.json` 的 `base.damage`。
- 基础攻击：`12 + 0.45 × (智力 + 精神)`。
- 强化攻击：`12 + 0.9 × L + (0.45 + 0.08 × L) × (智力 + 精神)`，`L = 强化等级`。
- 参数映射：`base = 12`、`enhanceFlat = 0.9`、`int` / `wis` 各 `base = 0.45`、`perEnhance = 0.08`。
- 既有次序保留：公式取整后仍按 `Gunsmith.Damage / base.damage` 应用枪匠配件倍率，再走制作、精通、附魔；不追加末端统一乘数。
- `items.json` 的静态“物理攻击 48”仍是武器基础/枪匠基准口径；武器卡“当前伤害”由公式计算。

## 关键实现点（可复用）

1. **姿态参考必须在骨骼定位之后采样。** M4 的 `WPN_SOCKET_Magazine` 在全部动作里 basis 恒为 0，意味着它的 rest 位置就是它的动画位置。若沿用定位前的采样做刚性绑定，弹匣会整体偏移新旧 rest 之差（本轮 26 cm）。修正后的绑定式：`v' = rest[bone] @ base[bone]⁻¹ @ base[root] @ xf @ v`，其中 `xf = base[root]⁻¹ @ A`，A 是 idle 姿态下的宿主空间装配矩阵。
2. **连通体分类给机械件身份。** 该网格 215 个连通体，扳机是其中之一（165 顶点），据此把扳机绑到 `WPN_Trigger` 并保留动作驱动；提把、导轨、侧轨等一并按包围盒识别。
3. **材质槽命名即运行时契约。** 含 `Magazine` 的槽在弹匣被替换时隐藏，含 `Flash_Hider` 的槽在枪口件装配时隐藏；手臂槽含 `Manny` 供图标/拾取模型剔除。
4. **源 gloss 图不可用。** `*_s.tga` 蓝通道恒 0、绿通道恒 240、红通道 std 0.018，没有有效的粗糙度变化，改为按部件常量（0.35–0.55）与金属度（0.05–0.60）。
5. **换弹动作按斗牛犬左右手分工重写。** 旧版曾按“弹匣井位移量”平移左臂，现已退役：两条换弹都改为枪身侧滚、左手锁护木、右手走握把→弹匣井→回握把；`reload_empty` 额外有右手取拉机柄和枪机释放段。cue 帧与表格见 README 4b/4c。

## 用户实测反馈（2026-09-17）

- **ADS 里枪身歪（弹孔仍落在准心上）**：根因是**源模型枪身相对自己的瞄准标记线带 4.7° 右倾**，接入时按"枪口 +Y、上方 +Z"当成正的绑定；ADS 标定只对齐视线轴、不约束滚转，于是开镜时是顺着斜枪身看出去的。判据（三条独立测量一致，主判据为枪身上表面面积加权法线）：M4 基准 aim −0.03° / idle +0.37°，本枪修正前 aim +3.92°。修法：`build.py` 装配矩阵绕握把接触点反向旋 4.7°，修正后 aim +0.19° / idle +0.72°，与 M4 同量级。**属网格绑定改动，无需编译。新枪接入必须做这一步滚转核对。**
- **模型在引擎里扭曲粗糙**：硬边在导出时全丢（先设自定义法线后设 `use_smooth`，Blender 会丢弃），判据与修复见 README 第 7 节。
- **开镜眼距**：照门在提把中段，沿用 M4 的 12 cm 会让相机贴住枪尾，默认改为 18 cm。
- **光学瞄具**：共享挂点把鞍座压在标记线下方 3.2 cm（M4/QBZ 约定），本枪标记量在导轨面上，已加 `OpticRailDrop=0`。

## 换弹按参考重做（斗牛犬编排，2026-09-17 起，2026-09-18 第二轮）

参考（2:06–2:10）里枪身**向射手左侧滚约 60°**、**左手扶护木不动**、**右手**离握把去拔插身后弹匣井的弹匣并拉机匣右侧的拉机柄——与本工程 M4 基底的分工相反。四项分层与实现、逐帧实测数值、可达性预算与做法见 [SourceAssets/ASH1220260917/README.md](../../SourceAssets/ASH1220260917/README.md) 第 4b 节，此处只记结论与踩到的坑：

- **cue 帧就是编排帧。** `bUseASH12` 走 `bUsingM4Infima`：空仓换弹的机械音效在片段 21/54/80/130 帧触发，普通换弹在 29/76/95 帧触发；上一版为使节奏贴近参考而加的 `TIME_WARP` 把姿态推到 cue 之后（旧弹匣实际 44 帧才离井，声音早 0.38 s；压实早 0.83 s）。已删掉重定时，节拍写回 M4 原始帧。
- **基底动作会污染每一层机械。** M4 空仓换弹自带的 `WPN_SOCKET_Magazine` 有 0.7 m 的甩出弧线、右手全程钉在握把、机匣自身滚转到 ±100°。本枪的弹匣/枪机/拉机柄改为按机匣局部坐标整体改写，机匣表演改为取片段帧 0 的矩阵再叠加本片曲线；否则本条弹匣会跑到井下 0.55 m。
- **手指也要一起冻结。** 只锁手骨不够：M4 片段的手指仍会做取匣开合，左手扶在护木上却张合五指。现在两手连同五指按帧 0 的机匣局部矩阵整体放置。
