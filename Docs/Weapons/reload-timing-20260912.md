# 换弹时钟与整体播放速度

2026-09-12，适用当前 UE M4 / AKM。

## 诊断与修改

当前 `gunsmith.json` 的基础值已与源动画一致：M4 普通 2.1 秒、空仓 2.7 秒；AKM 普通 3.333333 秒、空仓 4.291667 秒。不能把历史 C++ 默认值 2.7 / 3.466667 秒当作当前所有枪的实际时长。此次将 M4 默认后备值也与当前数据对齐。

发现独立计时缺陷：输入刚开始换弹，`UpdateActionPose` 却累加整帧 `DeltaSeconds`，包含输入发生前的时间；动作可以比绝对时间控制的换弹状态提前退场。在长帧中差距会放大。现在动画 elapsed 直接使用换弹状态 elapsed，持续时间在按 R 时一次性确定，动画退场和开火解锁共用边界。自动存档重新发布属性不会改变进行中的动作时长。

AKM 移除旧的运行时分段变速，整段源动画按统一倍率播放；拔匣、插入、压实和拉栓声音仍由相同源时间映射触发。M4 弹鼓保留已接受的接触重定时曲线，属性倍率缩放整套已接受动作，不能直接删除该曲线恢复旧版弹鼓动作。

换弹混合的入场、退场时间同样随播放速度缩放。没有重做、裁切或导出 Blend / FBX，也没有更改手臂模型、握姿、配件资源或弹药损耗规则。

## 后续枪械与配件数值

在 `Content/ColdSteelData/gunsmith.json` 中：

- `base.reload_time` / `base.empty_reload_time` 是最终基础动作耗时，单位为秒。
- 配件 `stats.reload_mult` 是**耗时倍率**，默认 1，同时影响普通和空仓换弹。多个配件相乘。
- `reload_mult: 0.8` = 耗时减少 20%，整套动作速度为 1.25 倍。
- 若文案为“换弹速度 +20%”，则填 `reload_mult: 0.8333333333`，对应播放速度 1.2 倍，不能误填 0.8。
- M4 弹鼓已有独立的基础动作时长修正，保留其现有计算；新配件继续在完整动作上叠乘。

统一关系：`播放速度 = 动画源长度 / 最终换弹耗时`。M4 弹鼓以现有源时间曲线作为基础动作，再统一缩放时间。枪匠面板读取同一套 `Calculate` 结果，实际换弹开始时锁定该结果。不需要为更快的配件制作一份新动画。

例：M4 普通 / 空仓 2.1 / 2.7 秒，耗时乘 0.8 后为 1.68 / 2.16 秒；动作和接触事件一起提前，开火不再等另一条旧计时器。

## 验收入口

`Tools/AssetPipeline/run_reload_timing.ps1` 使用唯一 `ReloadTiming...` 标签及隔离存档，在真实渲染进程中覆盖两把枪、两类弹匣、普通 / 空仓和 1 / 0.8 / 1.25 耗时倍率，共 24 组合。数值倍率为测试夹具，不修改正式配件数据；配件装配走真实枪匠应用路径，并轮换前握把。

检查加载动画、时钟一致、400 ms 输入前长帧、重复 R、换弹锁枪、完成当帧持续开火、弹药守恒，以及机械事件位于动作内。`-Audio -Video` 可录制实际混音和代表性动作采样；固定模拟步长结果不代表实测 FPS。

结果保存在 `Saved/ReloadTiming/ColdSteel_<Label>/result.json` 和同目录 `runtime.log`。现有用户编辑器不会因磁盘 DLL 编译完成而自动更新，应在保存工作后重启加载；验证进程均新启动，不关闭其他任务的编辑器。

## 本次结果

- Editor 原生模块两次编译成功（91241 / 91242）。共享工程另一个构建生成的 9121922 DLL 同样含本次修改，首轮通过进程模块列表确认；未回写旧模块清单。
- `ReloadTiming30v1`、`ReloadTiming60v1`、`ReloadTiming144v1`：各 24 组合、385 项检查，零失败。是固定模拟步长的渲染回归，不是性能跑分。
- `ReloadTimingAVv1`：实时运行、60 FPS 上限、实际混音，同样 385 项检查零失败；录制开销下有长帧，完成至第一枪仍在同一游戏帧。
- 四次共 1540 项检查通过。未修改玩家存档；加速/减速倍率只在审计夹具中设置。
- 实际混音中的 M4 原速与加速拔匣/插入/压实六个声音，源波形相关性均大于 0.99。相对画面记录时间有 116–157 ms 偏移，中位数约 137 ms，扣除统一偏移后的最大残差约 21 ms。原先试设的绝对 150 ms 门槛有两项超过；最终检查区分事件间隔与公共录音/输出延迟，不能据此宣称设备绝对音画零延迟，未移动任何声音修饰结果。
- 原速/加速实际预览：`Saved/ReloadTiming/ColdSteel_ReloadTimingAVv1/reload-speed-preview.mp4`。按真实采集墙钟与同次混音合成。M4 原速片段最大采集间隔 391 ms，其他代表片段最大 80–130 ms；缺采样期间沿用前图，视频容器 30 FPS 不代表真实采集率。数值上限与开火边界以每 Tick 审计为准。

后续可运行 `make_reload_timing_preview.py <Label>` 重建预览、`check_reload_timing_audio.py <Label>` 检查录音中的接触间隔。
