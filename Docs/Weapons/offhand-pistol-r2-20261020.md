# 左手单持手枪 R2（2026-10-20）

后续反馈：用户明确回复“成功了”，并要求继续制作 Pit Viper 2011 的左手主握、右手支撑版本。R2 为已接受基线；新版独立记录于 [左主握双手版](pit-viper-left-two-hand-20261020.md)。

## 用户反馈与范围

R1 正式构建后，用户的 Pit Viper 2011 截图仍显示屏幕下方中央有一块孤立弹匣。用户补充：右键会抬枪，但红点／瞄具偏离画面中心。日志中该实例配方为扩容弹匣、全景红点、SI 补偿器、祝福激光和全自动扳机。

本轮复用现有左手网格和动画，修显示归属与最终姿态驱动。没有把先前编译成功作为画面合格证据。

## 中央弹匣

`ApplyColdSteelProfile()` 隐藏了主手视模及附件，但 `AFPSGAMECharacter::Tick()` 稍后执行 `UpdateDrumDropVisual()`；其 ext_mag / G18 弹鼓分支无条件 `SetVisibility(true)`，将隐藏主手保留的静态弹匣重新显示。这与左手已经克隆并显示的扩容弹匣是两个组件。

当前在这个逐帧显示入口识别 `IsLoneOffhandPistol()`，保持旧主手弹匣隐藏并退出该分支。左手自己的弹匣仍随真实弹匣骨播放原换弹动作。未修改其他武器的弹鼓抛出流程。

## ADS 求值层

此前组件层缓存固定 idle 第 0 帧并按骨轨手动累计，然后把组件摆到缓存的目标变换。该方案未约束动画最终输出，用户实机仍报告偏离。

R2 删除该固定骨姿态缓存与组件层 ADS 移位，使用已有 `FPistolDualAimNode` 的中立姿态求值：

1. 中立片段使用当前 idle / idle_empty 的同一采样时钟，包含实际骨架、压缩采样和稀疏握姿差量。
2. 铁瞄直接读求值后的前后瞄具及武器上方向；红点读左手实际安装骨、附件局部变换、SightRear/Front/Up（缺少三点插槽时沿用该瞄具现有局部瞄点）。
3. 在组件的既有 -90° 腰射基底中，把后瞄点移到眼轴，瞄轴及上方向一起对齐。只对根姿态施加一个单位缩放的刚性变换，不逐骨反射，不改变枪体比例或手指接触。
4. 同一次变换施加到最终动作姿态，保留开火相对中立姿态的后坐。换弹、装配和砸击沿已有权重交还给原动作。呼吸和走路的额外偏移随 ADS 收敛到零。
5. 腰射会聚沿既有路径，ADS 权重为零时不改变原有双持会聚参考。
