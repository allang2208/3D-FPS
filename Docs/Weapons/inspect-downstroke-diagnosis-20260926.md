# 近战检视起手下甩：姿势辨识度排查

用户反馈向下发力阶段的姿势不明显。本轮只排查，未修改动画资产、作者参数或运行代码；未启动 UE 编辑器界面或游戏。

## 结论

确认下甩发力的姿势反差不足：有实际下移，但动作读起来主要是手下移、松指、接转剑。腕部约束、提前松指、剑身近乎竖直及低位停留很短，共同削弱了这一拍。

检查对象为当前正式普通柄／长柄 `A_RuneSword_Inspect`（V80 加同日新待机边界），不是已退回版本。两套片段均为约 1.266667 秒，源模型 120 Hz。

## 具体证据

| 项目 | 观测 |
| --- | --- |
| 右手下移 | 从约 0.275 s 到 0.400 s，手骨 Z 从 −13.798 cm 到 −19.416 cm，下降约 5.618 cm。下压并未丢失。 |
| 最低姿态的可读时间 | 手骨距离最低点不超过 1 cm 的采样区间约 0.358–0.417 s，只有约 0.058 s。0.450 s 已回升到 −16.041 cm。 |
| 腕部约束的影响 | 在作者求解器内存复放中，0.400 s 最终腕部限制将目标手朝向回拉约 10.933°。弯曲轴夹角由限制前约 22.750° 变为约 18.242°；这是同时满足扭转与弯曲限制的结果，不等于单纯裁掉超出 22° 的部分。 |
| 腕部姿势反差 | 0.275 s 腕轴夹角约 22°，下压峰值反而约 18.24°，没有形成明显更深的甩腕姿势。 |
| 剑身轮廓 | 0.275–0.400 s 剑轴相对水平面仰角约 77–84°，保持近乎竖直。手下降时，剑的整体倾倒轮廓反差有限。 |
| 松指提前 | 0.400 s 无名指／小指开指控制值已达 0.95／1.00，中指约 0.755；握柄约束混合权重已降为 0.38。这些是动画控制值，不能解释为实际握力百分比。 |

最终腕限制会把手向前臂锁腕参考姿态回拉。当前右腕扭转限幅 18°、弯曲限幅 22°，在这一段与设计的甩腕目标发生冲突。不能只继续加大目标腕角，否则仍可能被最终约束拉回。

## 已排除的因素

- 0.28–0.50 s 的待机靠近姿态权重为 0；与本轮待机改动前轨道相比，锚点差约为浮点误差。因此下甩弱不是新待机偏移造成的。
- 同区间源姿态／压缩姿态的所测骨骼最大位置误差约 0.000484 cm，没有发现导入压缩抹掉下压。
- 源 Blend 右手轨迹与正式资产换算到同坐标后，最大位置差约 0.000198 cm；可用本轮源关键帧图观察这一段。
- Inspect 运行时以真实秒数采样，不乘攻击速度。入场快照过渡最多 0.1 s，在下甩发生前已结束；正常转剑段没有继续混入 Idle。
- 普通柄与长柄的右手下甩表现一致。长柄自身的左手握距未纳入改动。

## 建议的修正方向（本轮未实施）

保留短促的起手下甩，将可读的发力更多分配给前臂／肘部带动，让最终受约束的腕姿也能读出这一拍；协调剑轴的前下倾倒；把无名指、小指的大幅松开推迟到发力传递之后，并适度延长低位姿势的可读时间。修正应落在起手局部，保持转刀方向、手柄接触和回待机衔接。
