# 符文战锤本段制作与联机复查（2026-10-23）

本次按用户要求，复查符文战锤、两种魔力符文、两款传说锤头、双重重击、原装件图标与能量条顶部。发现的问题已经修改并完成 Editor / Game 后台构建。以下证据按资源引用、服务端运行和真实网络分别记录，不把无画面测试当作视觉验收。

## 本次修复

1. **持续刻印只有不可靠广播。** 原来6秒镇魂刻印依赖 `NetMulticast,Unreliable`，新出现的角色副本无法补到已有刻印。新增有界 `FinalTollSealState` 复制快照和 RepNotify，携带武器实例、目标、相对位置、开始与结束时间。苏醒属性晚到或目标尚未映射时继续等待恢复。完成瞬间的短暂爆发仍使用不可靠表现广播。
2. **旧重击可能跨配件变化结算。** 双重击第一、第二段都核对服务端攻击编号、武器实例、出招时配件数据与当前镇魂钟选项；第一段也恢复出招时的伤害快照。中途换锤头或配件后，旧计时器不能使用新装备继续结算。
3. **刻印消费后，重复命中回调可能重新挂印。** 新增最多64条“目标＋攻击序号”回执；刻印消费后也保留去重记录。刻印与削韧增益同时核对武器实例，过滤旧实例的回调。
4. **动作速度中途变化可能让表现偏离服务端时点。** 双重击在出招时固定动作速率，第一人称推进、第三人称状态速率与服务端两段计时使用同一出招速率。
5. **生命周期清理不完整。** EndPlay 补清第二段计时器；单机命中回调取消动作后立即停止后续双重击推进，避免同一帧继续结算下一段。
