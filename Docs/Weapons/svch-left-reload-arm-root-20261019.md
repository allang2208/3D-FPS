用户报告普通／空仓换弹中左手扭曲、臂根进入镜头，并明确要求使用认可手模，禁止错误拉伸或扭曲关节及组织。用户确认外观为裸手／裸臂。本轮范围仅为这两种换弹的左臂。

- 取新匣、插匣和回握阶段，上臂近根区域过于靠近相机并进入画面。此前整臂锁骨配准相对共享源的肩点移动约 15–17 cm，不能直接把源肩点恢复：部分阶段腕点已超出原肩点可达范围，强行恢复会拉长骨段。
- 松手回握阶段近腕辅助骨相对手掌有小幅轴向差；保持当前手掌和手指目标，通过原生前臂辅助骨修正衔接。

## 修改方式与保留项

只更新上述 SVCh 配置中的 `reload`、`reload_empty` 两个片段，源 SVD 动画、机械时钟及其文件没有改写。

1. 以当前肘点—腕点为轴调整近端肩部支撑，肘点和手掌世界位置不动。上臂作为刚体转向画面外，肘角和骨段长度保持不变。
2. 前臂辅助骨承担轴向变化的渐变；近腕辅助骨保持手掌端的方向关系，只校正残余轴向差。手指局部曲线、手掌世界姿态和抓匣轨迹保持原配置。
3. 进出修正窗口采用平滑曲线，首尾姿态等于原配置。没有缩放骨骼、修改网格、改权重、改 rest、截断手臂或移动整枪来掩盖问题。
4. 右手、拉栓接触、枪机／弹匣轨迹以及其余动作配置保持原值。

修改轨道为左侧 `clavicle`、`upperarm`、`lowerarm`、两组 twist 辅助骨和 `hand_l` 的局部补偿；`hand_l` 局部补偿用于抵消父骨变化，最终手掌并未被重新摆姿态。

离线计算与 UE 的 FTransform 一致，采用四元数与分量缩放组合，而非会产生微小剪切的完整矩阵乘积。保留源中原有的微小缩放误差，不新增骨长变化。
