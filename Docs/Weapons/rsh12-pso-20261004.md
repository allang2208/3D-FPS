# RSH-12 PSO-1 导轨改造

后续用户要求恢复 PSO 原侧挂架与锁杆，见 [侧挂架修订及落盘状态](rsh12-optics-refit-20261004.md)。下文记录第一版上导轨支柱方案，恢复工程时应最后应用后续修订。

用户指定 RSH-12 归入可使用 PSO 的俄式枪械。现有五种通用瞄具和原厂机瞄保留，新增 `pso1_4x`；选项名称、效果和数值复制当前 AKM 的同 ID 选项，描述按 RSH 的上导轨安装方式改写。

## 模型与接入

- 复用已修复镜筒接缝和材质分区的 `PSO1_PKM_Editable.blend` 中镜体与镜片，保留原尺寸、UV、法线、橡胶、内壁和光学身份。原侧挂低脚会穿入 RSH 枪身，因此裁除光学镜筒以下的低脚，封闭新安装面，重做夹座、开孔支柱、承托面、螺钉和止退键。
- 下层使用 RSH 已制作的 78 mm 通用导轨转接座；PSO 的夹爪匹配其 20.8 mm 冠面与 22.8 mm 斜肩，止退键落在横槽内。镜体与安装座随固定 `WPN_root`，不随弹仓转动。运行挂点沿用 `RSH12OpticAssets` 的导轨坐标和一次单位转换。
- 镜筒光心移到导轨中心平面，`AimCenter` / `SightRear` / `SightFront` / `SightUp` 同步转换。固定 4×、尖点分划、镜内展示、弹道瞄准和视模隐藏沿用现有 `HasPSO1Scope()` 路径；ADS 累计已认可的 RSH 握姿层。
- 私有 PSO 枪钢材质引用当前 RSH 导轨颜色/粗糙度。原 PSO 外壳遮罩保护内壁、橡胶和标记；结构法线与 AO 保留，雨水在现有单层图中处理，并追加到 RSH 雨水映射。
- RSH 运行分派、俄式 PSO 支持表和库存预加载均能解析新模型。共享预览和副手沿用同一组装通路。实例选项保存继续使用 `gunsmith_parts.optic`。
- 将已有金属框灰阶 PSO 图标提升为共享 `optic_pso1_4x` 键及对应 Texture，按共享图标规则复用，没有新增图标渲染。

## 保存与恢复

运行网格：`/Game/Weapons/RSH12/PSO20261004/Meshes/SM_RSH12_PSO1`。

作者目录：`SourceAssets/RSH12PSO20261004/`。`read_inputs.py` 获取实际 PSO 资产/材质/光心，`author_pso.py` 输出可编辑 Blend、FBX 和坐标配方；`import_assets.py` 保存新模型、私有材质和雨水表。`publish_catalog.py` 只更新 RSH 的 PSO 选项；`publish_icon.py` 复用既有图标。当前共用瞄具的头文件生成器同步保留 PSO 路由。

`run_stage.ps1` 的 Read / Import / Icon / Build 阶段均使用既有 UE 批次互斥。实际保存与构建状态分别记录在 `import_receipt.json`、`icon_receipt.json`、`catalog_receipt.json` 和 `build_receipt.json`，不能用脚本存在代替完成状态。

PSO 原镜体来源为 LeroyCake 的 SVD Dragunov，CC BY 4.0；沿用 [署名记录](../../ThirdPartyNotices/SVD_DRAGUNOV.md)。本轮新增 RSH 安装结构和私有表面适配，未改源枪资产。完整第三方模型、贴图、UE 包保留本机。

本轮后台保存、必要编译；未打开图形编辑器，未运行游戏、截图、渲染或测试，实机效果由用户测试。
