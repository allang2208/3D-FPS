# 伐木斧右拇指握柄修正

用户明确要求排查右拇指穿模与扭曲。本轮执行了该部位的源骨架、变形网格及近景排查，没有启动游戏或运行无关回归。

## 原因与修改

H4 沿用了早期通用手型：`thumb_01_r` 局部旋转近乎零，`thumb_02_r` 和 `thumb_03_r` 各沿局部 Z 弯曲 24°。手腕已适配新斧柄，但拇指根部的对握方向未跟随粗斧柄调整，中段进入握柄，近景显示狭窄折弯。

以当前实际斧柄表面约束拇指三节，并限制轴向位移、指腹离柄距离与关节旋转。最终局部旋转（作者骨架 XYZ，非人体关节角）为根部 `(3.5, 34.5, -22.5)°`、第二节 Z `50°`、末节 Z `40°`。根部向外展开、远端回包，指腹靠近斧柄外侧；没有改动腕骨、其他四指、骨长、局部平移、缩放、蒙皮或模型材质。

仅替换四条动画中的三个拇指旋转轨道：Idle、Equip、Swing、HitRecover。H4 左低右高持握、双手位置、装备节拍、V5 肩肘链和攻击/停帧/拔出时序均继承原源。奔跑复用 Idle，因此使用同一拇指手型。

## 局部排查结果与边界

- 旧待机源的拇指主导蒙皮顶点（拇指三骨总权重 > 0.65）有 274 个采样点进入握柄，最深有符号距离约 -21.06 mm。新姿态该集合为 0 个，最小间隙约 0.40 mm，指腹接近区平均约 2.88 mm。
- 实际交付 Blend 的近景与三个旋转轨道已读回。`delivered_player.png` / `delivered_side.png` 以橙色标记拇指参与蒙皮区域，仅用于局部几何诊断。
- 更宽的拇指参与集合（总权重 > 0.25）包含大量主要由掌骨、食指掌骨控制的虎口内侧顶点；仍有 84 个采样点在柄内。这部分原有掌部交叠没有通过移动整手或修改共享蒙皮处理，不能把本次结果称为整只手零穿模。表面采样也不等于 UE 压缩后的全时段验收。
- 未运行 PIE 或游戏内测试，最终视觉由用户确认。
