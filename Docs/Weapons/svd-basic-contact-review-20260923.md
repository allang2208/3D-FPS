# SVD 基础动作接触检查（2026-09-23）

> 本文保留该阶段的制作与检查记录。当前认可的换弹手型、最新材质／接口及归档恢复边界，以 [SVD 发布说明](svd-publication-20260923.md) 为准；旧版本的导入成功不代表最终手型获认可。

后续已按本次问题制作手部修复，见 [SVD 手部修复记录](svd-hand-repair-20260923.md)。本页图片与测量保留为修复前证据，不代表修复后的状态。

本轮检查确认了用户反馈：不贴合已经存在于源动作。主要问题是原厂左手支撑没有完整适配、换弹缺少自然包握，以及生成手指姿态时错误改写了局部位置。右手拉栓的运动方向和跟随机械件的关系成立，但手指表面变形不正确，不能判定整套拉栓动作完成。

本轮仅新增检查脚本、读回数据和诊断图片，未修改正式 C++、FBX、Blend 或 UE 资产。使用后台 Blender 和只读 UE commandlet，没有启动交互编辑器或运行游戏。图中左手蓝色、右手橙色、弹匣浅黄、拉机柄红色，均为内存中的诊断配色，不是当前游戏材质。

实际入口为 `Weapons/SVDWeaponAssets.h` 中的 `/Game/Weapons/SVDDragunov20260922/Accessories20260923/SK_SVD_Modular`；原厂动作来自 `Complete20260923/Animations/A_SVD_*`，四个前握把动作族来自 `Accessories20260923/Animations/A_SVD_{vertical,canted,prism,angled}_*`。UE 读回的源文件与这些制作目录相符。

1. **优先修正手指姿态生成，再处理接触位置。** `SourceAssets/SVDCompletion20260923/author_svd.py:164–169` 在更新父指骨后，使用已经变化的父矩阵与尚未更新的子骨世界矩阵计算 `basis`，再把其中的 `loc` 写回。这样即使父子距离几乎没变，子骨局部位置方向也被改写，蒙皮会折叠或塌陷。普通换弹帧 128 的 `ring_02_l` 局部位置相对待机变化约 62.36 mm，空仓同帧约 67.30 mm；装备帧 100 的 `middle_02_r` 约 50.54 mm，空仓帧 350 约 50.63 mm。当前 UE COMPRESSED 轨道中也能读到这些变化，不仅存在于 Blender 预览。应先缓存原始局部姿态，保留局部平移与 scale，再按父子层级传播有限旋转。

2. **原厂左手只是平移适配，尚未完成护木包握。** `author_svd.py:120` 从 AKM 待机手腕加偏移得到 SVD 目标，手指则随整手刚体移动。SVD 护木截面与 AKM 不同；在实际网格上可见拇指、前两指局部挤入，而后两指离开护木。应按护木支撑面重新确定掌面、拇指对握及四指包裹，连同腕、肘、前臂一起处理。不要把左手改成抓运动的枪机或拉机柄。

3. **弹匣中心对齐不是包握适配。** `fit_contacts.py:11–12` 将 M4 供体弹匣包围盒中心平移到 SVD 弹匣中心，复制供体手指旋转；未建立 SVD 短弯匣的掌面与对握约束。普通持匣帧 128–240 中，手部 `hand_l` 主权重区域距弹匣最近约 69.55 mm，拇指约 50–54 mm；这些是指定顶点分组的最近距离，不是精确的掌心解剖测量。掌侧画面同时显示手掌敞开、弹匣挂在指尖。手腕相对弹匣在这些采样帧的漂移小于 0.001 mm，因此继续锁紧手腕或增加烘焙采样率不能解决错误握姿。

4. **退手应显式松指和避让。** 当前帧 240 起就把手腕从持匣关系插值回护木，握指权重到帧 244 才开始退出、帧 272 才归零，期间容易带着弯指扫过弹匣。普通帧 252、264 与空仓帧 268 已出现实际手套/弹匣三角面交叉。修复应在正确包握基础上安排松指、外侧退让和回握，不只把整手插值路径横移。

右手拉栓的手腕与拉机柄在装备帧 64、80、94 保持同一相对关系，采样平移漂移小于 0.001 mm；动作按源轨道后拉约 75 mm 后释放。单根食指与拉机柄最近点很近，但这不能证明自然勾握，后止点近景已经能看到异常手指形状。应保留正确的机械轨道与事件时钟，修复整组手指、接触和退手。

本次对应 Skill 沉淀：

- [姿态与接触](../../skills/ue5-fps-arms-animation/references/pose-contact.md)：先掌面、拇指对握和四指包裹；父子目标先缓存，再按层级重建；保持骨长、局部平移、rest 与权重；近点、零相交、手腕锁定都不是单独的正确标准。
- [配件手部与整臂优化](../../skills/ue5-fps-arms-animation/references/grip-arm-refinement.md)：复用成熟手型须包含整条支撑链；同时看掌侧、手背及袖口，不能只转腕或复制供体指尖。
- [换弹收尾](../../skills/ue5-fps-arms-animation/references/reload-handoff.md)：先区分源动作、混合和组件锚点。本轮主问题在源动作，不应先改镜头或把末帧混合当成根因。

建议制作顺序为：手指局部变换算法 → 原厂待机护木握姿 → SVD 弹匣完整包握 → 拉栓勾握与释放 → 松匣回握 → 同步四个前握把分支及冲刺端点。保留弹匣/枪机机械轨道与声音时钟，接触时点有变化时再同步事件。

检查范围与限度：读取 60 个 UE 动画、340 个 SOURCE/COMPRESSED 姿态样本；五个动作族各做 35 个表面采样，生成 31 张关键帧诊断图。UE WORLD 坐标已用枪口标记和继承缩放核准，最大压缩位置误差约 0.00621 mm，旋转误差上界约 0.0561°。LOCAL 指骨坐标须包含父链约 100 倍导入缩放后才换算物理毫米，不能直接乘 10。表面距离取实际变形顶点，三角面交叉只用于定位，未用数量作为品质评分。没有完成连续时间扫掠、运行时动作混合、全部握把外形逐件检查或第一人称实机验收；本报告不声称这些已通过。
