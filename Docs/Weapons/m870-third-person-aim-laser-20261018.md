# M870 第三人称瞄准、泵动与激光

用户反馈第三人称 M870 不跟随准星摆动、激光表现不正确。本轮参考现有 M4/HK416 的身体持枪、抵肩及激光链路，读取当前保存的 M870、三种战术件和射后泵动骨骼采样。

## 定位与修正

1. `FPSBodyRifleStock::Find` 只有既有十种步枪，缺少 M870。`BuildFPSBodyRifleHold` 提前返回无效标定，身体动画没有进入通过枪管方向反求双手抵肩姿态的路径。补上当前原厂枪托接触点，单位遵守原表的含 100 倍 FBX 根缩放坐标。五种改装后托按本枪配方识别，包括名字不含 Stock 的 skeleton、qr_performance 和 tactical_telescopic。
2. M870 继承的骨架 `WPN_root` +Z 沿枪身纵向。普通步枪算法把它当向上方向，投影后留下的轴线与真实瞄线相差约 89.75°。仅为当前 M870 使用实测瞄线的完整上方向；其他枪型保持原标定。标定仍在装备构建时生成，由本地及远端身体动画共用现有俯仰/偏航输入。
3. 通用持枪采样在普通状态冻结双手关系，M870 开火仍处于 Idle，因此把射后泵动中的支撑手也冻结了。当前源动画中支撑手相对右手移动约 10.5 cm。M870 正在播放射后泵动时改用同帧真实握持关系，第三人称的肩肘仍由全身持枪层求解，不接入相机空间手臂轨迹；机械骨及配件继续共用原动作时钟。
4. 激光 Ready 使用了 `IsWeaponBusy()`，把 M870 正常泵动作为退出准星归零的条件。改为已有的 `IsWeaponBusyForAim()`，与 ADS 保持一致；下一枪的泵动闭锁仍由原开火逻辑控制。换弹、检视、冲刺、近墙、近战等原有互斥保留。

三个战术件的当前 Emitter→AimGuide 均沿安装网格 +X，挂座变换也已有 M870 专用分流。本轮保留它们的实际网格、挂点和发射口，不重做模型。第三人称可见发射口沿用世界副本，命中点沿用本地确定性瞄准射线，远端继续消费复制的激光落点。
