# 雷息／震霆配重封闭重建与顺序落雷

用户反馈两款配重漏空、可以看见内部且细节不足，要求对照原参考图和模型标准重做；同时将震霆三道追加雷改为由近及远、每道间隔 0.25 秒。

## 漏面原因与几何处理

针对当前作者源的定位结果：雷息同位置点焊合后仍有 653 条开放边，震霆有 497 条；外壳、雷窗底、接颈等分开生成并分别重算面朝向，部分外表面的绕向反转，单面材质因此剔除表面。原脚本的独立凹槽封底未与壳体共边，接颈采样也没有直接使用真实切口边界。

本轮改为连续结构表面：雷窗、折雷面板的侧壁和底面与八面主体共用顶点，底盖同样共边；按原厂真实切口的顶点环连接接颈。倒角避开受保护的安装边，避免倒角挪动切口点。完整封闭后统一几何面朝向，保留面角 UV 和作者法线，平面与倒角各自有合适的着色。

- 雷息：保留菱形雷窗、多面收束主体及底部菱形雷印；雷窗有实体凹槽和不透明底面，周围是贴合肩线的嵌银边。
- 震霆：保留三阶锻肩、三重折雷纹、八面鼓形主体与宽底部雷印；主面板是真正封闭的浅凹槽，折雷嵌银和蓝白雷槽分别有实体厚度。
- 两款：保留原厂安装口和上下唇边，仅重做原来粗糙的中央接颈编纹带；新的交织银带下方有封闭钢制基底。主体侧面编结按肩线转折点取样，避免横跨转角后埋进壳体。
- 新制金属 BaseColor／ORM／OpenGL Normal 为 4K。金属反射色按线性值编码入 sRGB 图，细节高度先低通再生成法线，避免噪点式的粗糙表面。雷息激励的材质参数和蓝白雷核功能保持。

制作源：`SourceAssets/ThunderGodHammer20261028/PommelClosedRefineV2/{LeiXi,ZhenTing}`。两款导出阶段统计均为 0 条开放边、0 条多面共边。记录范围是本次漏面修复的几何制作约束，不代表游戏内视觉、碰撞、联机或性能验收。

现行源三角形数量：雷息 82,338；震霆 114,282。面数主要用于真实编结、倒角、原厂接口和实体凹槽；保留 Nanite 及显式切线，未降低近景轮廓精度。两款独立可编辑 Blend、FBX、贴图、实际模型灰阶图标源与正式金属框图标一起保存。

## 由近及远的落雷时序

原落雷仍在接触／释放时生效。三道追加雷从原落点向前依次在 0.25、0.50、0.75 秒生成，彼此间隔 0.25 秒；位置仍为 6、12、18 米，半径仍为 3 米。普通重击、贯雷落地和疾雷共用此逻辑，原有伤害与感电规则保持。

落点和伤害在提交时保存，后续转动视角不改变已提交的排列。服务器定时创建独立的复制雷击 actor；定时器绑定攻击来源而非寿命短的原雷击 actor，因此第三道雷不会因原特效销毁而丢失。攻击来源销毁时弱绑定回调失效。

## 接入状态与恢复

使用新的 `PommelClosedRefineV2` 网格包，保存资产后再切换模块目录中的两款模型引用；保留旧制作源和发布前目录／图标备份。正式图标根据本轮最终真实模型生成，使用原有图标键。两个改造 ID、特殊品质、被动属性与存档归属保持。

`model_manifest.json`、各子目录 `import_receipt.json`、总 `import_receipt.json`、`build-*-receipt.json` 与 `delivery.json` 分别记录几何导出、资产保存、目录发布、后台编译和最终交付状态。未由本任务启动 UE GUI，未运行游戏、联机测试或性能验收。
