# ASH-12 快速近战节奏与命中反馈

后续更新：用户要求所有武器的快速进战在伤害判定帧强震，镜头部分已被[通用快速进战强震](quick-combat-impact-shake-20260919.md)替代。下文保留本轮最初的参数记录；当前挥空也触发镜头强震，ASH 的加速和有效命中 50 ms 停顿保留。

## 原有节奏

当前动作引用、制作脚本和导入回执中的 M4、AKM、QBZ191、ASH-12 快速近战均为约 0.90 s，源动作接触点为 `5/27`，即约 0.1667 s。ASH 的四种通用前握把近战也是同一份 0.90 s 基底，并没有单独降低播放倍率。

参考现有 M4 N `Review/timeline.jpg`：持枪起势、枪托向画面前方送出、接触后保持前伸、收势归位。两手随枪运动，当前 ASH 的适配手型和路径保留。本次只调整运行时节奏及命中反馈，不重新制作骨骼姿态。

此前角色状态按世界时间结束，近战组件另行累计动作时间；没有命中停顿，镜头沿用通用步枪冲量。ASH 本次改为由角色在更新姿态和镜头前推进近战组件，状态、动作采样、相机阶段和收势共同使用组件的源动作时钟。

## 本次参数

| 项目 | 原有 | ASH 本次 |
| --- | --- | --- |
| 起手至接触 | 1.0 倍 | 1.4 倍 |
| 接触之后至收势 | 1.0 倍 | 1.2 倍 |
| 接触时点 | 约 0.167 s | 约 0.119 s |

| 有效命中停顿 | 无 | 0.050 s |
| 有效命中总长 | 约 0.90 s | 约 0.780 s |
| 命中镜头曲线 | 52 rad/s、衰减 12、窗口 0.30 s | 40 rad/s、衰减 9.5、窗口 0.34 s，曲线增益 1.35 |

时长为当前 0.90 s 片段的理论值，最终状态退出有帧边界取整。起手和后段的时间在接触处精确分段，命中当帧的剩余时间也计入停顿，避免帧率改变停顿长度。

仅在对有效怪物造成伤害或击杀时暂停动作。挥空、无效目标不暂停，也不增加命中冲量。停顿同时冻结源动作时间及动作展示位置的过渡，镜头冲量使用实际经过时间继续播放，形成接触后的后坐、下压和一次衰减回弹；不修改世界时间或人物移动速度。

命中前单次求值当前快速近战的准确接触姿态，枪托判定点来自该姿态，避免加速后仍从上一帧蓄势位置发出判定。动作开始立即发布对应 clip，避免大帧间隔下误用上一个开火动作。

覆盖 ASH 基础握持、原有弹匣分支及垂直／侧倾／棱镜阻手器／共振四种前握把。其他步枪、手枪原有节奏和镜头参数保持；伤害、距离、技能冷却、眩晕、击退及命中音效的结算规则保持。原来日志将 ASH 标为 M4 的枪型分支也已修正。
