# 高地双手剑手臂穿帮：相机前更新修正

依据 [复查报告](highland-arm-opening-review-20260923.md)，用户授权实施后，先修正已定位的突进／相机缓存时序。

## 实际修改

- `RuneSwordComponent.cpp`：将双手剑组件固定为 `TG_PostPhysics`，使其突进位移和最终手臂姿态在 `PlayerCameraManager` 缓存视角前完成。保留角色 Tick 前置依赖，并明确加入角色移动组件前置依赖。
- 在 `BeginPlay` 同步设置 TickGroup，覆盖旧实例可能序列化的 `TG_PostUpdateWork` 设置。
- `RuneSwordWhirlwind.cpp`：移除技能进入／结束时单独切换 TickGroup 的代码。大旋风结束、动作取消、切枪或快速近战中断不会将剑组件退回相机缓存之后。

实施时将草案中的“只在攻击期间切换阶段”改为固定更新顺序：输入开始攻击时，本帧 Tick 可能已经排队，临时切组可能漏掉首帧。固定顺序覆盖起手、攻击、收招和取消，保持同一个动作时钟，不引入首帧等待或重复刷新相机。

作用于共用该组件的双手剑，包括高地双手剑标准柄／长柄、冲刺下砍、第三段突刺、配重锤前踏以及大旋风。没有修改枪械组件。

本轮未重新写入六条 V1 动画或手模；手指抓握、双手与剑的接触、动作时长、伤害窗口、攻击距离、突进曲线及 Shift 蓄势保留规则保持原有实现。此前同步视角的模拟未显示对应截口，本轮没有依据再缩短手臂伸展或添加封口几何；是否还有局部残留须由实际游戏画面判断。
