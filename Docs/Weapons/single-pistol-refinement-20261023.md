范围：Jason 身体的右手单持与左手主握单持，M1911、G18、Pit Viper 2011、DW715、RSH12，现有扩容弹匣、G18 弹鼓及 RSH 四种前握把。第一人称源资产、Twinblast 双持源、弹药交易和存档协议保持原有实现。

## 完成的制作

- 双手握点作为一个刚体组进入两条原生手臂的可达范围，修复 RSH 长枪体加前握把时的支撑手悬空。骨段长度保持原值。
- 以完整源姿态的肩、肘、腕及蒙皮辅助骨为基础，在两骨圆上选取合适的肘部弯曲面，同时约束掌向、肘部高度、身体中线和躯干净空。前臂承担部分轴向旋转；辅助骨继续从当前源姿态搬运。
- 半自动换弹复用该枪第一人称相对待机的掌向，在退匣阶段完成转掌。根据实际弹匣插入行程提前准备胸前装填空间，避免长弹匣/弹鼓出现时突然抬枪。
- 弹匣壳体与操作掌使用同一接触关系。整段插入都执行双手共同可达适配，而非只在目标侵入胸口时适配。接近动作提前到 0.55 秒，释放、出现、装入仍为 0.3167、0.78、1.05 秒。
- 左轮自由手按躯干外形避让，保持原弹巢、抛壳、逐发/快速装填器时钟。自由运动沿用已平滑的完整源起手。
- RSH 前握把的持枪组偏移随撤手阶段逐渐释放，避免支撑手一松开、枪体立刻前跳；装填肘位限制随持握接触平滑进出，避免蹲姿收尾过早压肘而掰腕。
- 长握把撤手记录起手时握点相对原动画的额外位置偏移，并在胸部坐标系内逐渐消除，只释放增加的前伸距离。避免每帧重新混向已经移动的握点、压住原动画行程后再追赶。它与枪体回位使用起手前半段平滑曲线；进入持握和重新接触仍保留原插值。仅缩短或延长旧混合窗口的候选均未通过连续帧差检查，未作为最终结果。
- 肘部平滑保存实际显示的方向与肩腕轴，并在移动的胸部坐标系中搬运。旧实现保存相对于每帧源弯曲面的标量角度，源平面变化时会把历史角度套错，导致开火、移动或撤手时肘部跨过身体中线。修正保留角速度限制，不再使用该错误历史基底。
- 长前握把分支在待机和装填时均约束肘部留在对应侧，上臂与前臂一起避让；胸部上下边缘包含肢体半径，防止肘点刚好在检查边缘之外、蒙皮仍侵入上胸的遗漏。普通手枪保留先前通过的前臂与装填姿态约束，避免把长前握把限制全局套用后造成装匣腕折。
- 长前握把的双手共同可达解增加主握侧约束，保持枪体在主握肩一侧。避免蹲姿最短平移解把枪推向支撑手一侧，令持枪腕横折；仍由两条原生手臂的共同可达区域决定最终位置。

## 检查方式与联机

运行用户已授权的正式 DLL 只读副本检查，无界面、无资产保存、独立玩家存档。连续检查覆盖普通/空仓、逐发补满、只补一发、快速装填器、站姿/蹲姿及左右角色；使用实际动画图、机械部件和 CPU 蒙皮，不以骨骼点无 NaN 代替穿模检查。

每个连续场景先进入自己的待机/蹲姿，避免把前一场景的蹲姿收尾当成下一场景的起手；随后从第一帧起记录帧差。检查保留原穿身、接触与骨长阈值，并补查持枪手腕轴。

联机检查保留实际 UDP 主客机、延迟/丢包和重新连接。动态掉匣场景增加观察端装备/机械姿态就绪屏障，避免测试自身错过释放边沿。单持换弹接触改用当前弹匣操作关系；左轮自由手阶段不再拿第一人称腕点当第三人称必须重合的目标。上述屏障与断言只属于开发检查入口，没有增加玩法 RPC。

冻结采样的真实 UDP 检查暴露了右手单持的换弹标识问题：其 `ReloadStartedAt` 随“当前时间－采样进度”变化，造成每帧可靠切换消息；加载资源停顿时曾发生 `ReliableBufferOverflow`。现在右手单持与副手一样，读取动作实际开始时间并转换到服务器时钟。播放进度、弹药交易和 RPC 类型不变，停帧不再被视为反复开始新换弹。检查入口也为主手设置真实起始时间，并验证冻结观察期间的起始标识稳定。失败证据保留在 `refinement-20261023-final-v5`。

联机配置原将 `InitialConnectTimeout=120`、`ConnectionTimeout=60` 放在 `GameNetworkManager` 节，未应用到实际 `IpNetDriver`；现移动到正确节，并让地址解析/连接阶段沿用初始连接时限，避免另一个 20 秒时限截断首载。`v6` 失败发生在进入任何测试场景之前，同时存在失效 Zen 缓存地址的反复超时；它不是换弹标识修正失败的证据。检查启动器改用现有文件缓存，并在主机地图加载完成后才发起客户端连接。

`refinement-rsh-final-11` 曾在后台采样中以非法指令异常退出；故障地址反汇编为普通读取指令，当前证据不足以归因，未据此盲改动画代码。保留崩溃记录，并用相同构建重新运行对应 RSH 连续覆盖。

Editor 与 Game 已构建成功，回执分别为 `refine-editor-final-21-exit.json`、`refine-game-final-11-exit.json`。
