# ASH战术制退器

按用户参考图设计的 ASH-12 专属枪口配件：短粗八棱外壳、四个贯通侧窗、倒角前口和多环后接座。全件使用 ASH 当前黑色金属材质，沿用其细法线、粗糙度和湿润水珠映射；不采用参考图的橙色。

入口：**ASH → 枪匠 → 枪口 → ASH战术制退器**。目录 ID 为 `ue_ash12 / muzzle / ash12_tactical_brake`，其他枪械没有该选项，运行装配也要求 ASH 身份。沿用现有预览、应用、装备实例存档和掉落展示，拆卸恢复原厂枪口。

- 后坐力 −25%：`recoil_mult = 0.75`。
- 枪械稳定性 +15%：`stability_mult = 1.15`。
- 开镜速度 −10%：用户已明确确认变慢；系统按开镜耗时存储为 `ads_percent = 1/0.9 - 1`，单独安装时耗时增加约 11.1%。

模型长 8.4 cm，局部 +X 向前，后接触面为 X=0。使用 ASH 原有枪口接口，枪口特效端点随新件前端同步。制退器不产生消音效果。

作者入口、可编辑源、FBX 和图标位于 [制作目录](../../SourceAssets/ASH12TacticalBrake20260920/README.md)。运行模型：`/Game/Weapons/ASH12/TacticalBrake20260920/SM_ASH12_TacticalBrake`。
