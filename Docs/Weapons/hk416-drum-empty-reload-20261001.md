# HK416 大弹鼓空仓换弹：恢复枪机释放拍击

后续状态：本版拍击经用户反馈再次返工，当前使用 [M4 完整拍击与机瞄分区方案](hk416-slap-sights-20261001.md)。本页保留第一次修复记录；当前方案同时刷新实际运行优先使用的握把修正层。

范围：`ue_hk416` 的 `base / vertical / canted / prism / angled` 五套 `drum_reload_empty`。普通换弹、标准弹匣、其他武器、枪械及手臂网格均不重导。

## 原因

`HK416CommonAttachments20260930/author_animations.py` 从 M16 配件制作流程沿用了一段不适用于 HK416 弹鼓的尾段混合：源帧 88–111 逐步切入普通弹匣空仓动作，使弹鼓原有第 116 帧拍击改成普通弹匣的第 130 帧；动作长度也从 148 帧变成 162 帧。运行时 `M4DrumReloadTiming` 仍以 148 帧结束、116 帧触发枪机释放声音。

同时，前握把系列在 88–111 帧恢复握持姿势，覆盖了整个拍击阶段。因此带前握把时拍击消失；基础动作则存在拍击与音效、恢复窗口错位。

## 修改

- 直接保留已使用的 `M4_DrumContact` 弹鼓空仓完整时序：80 帧压实、116 帧拍击，随后枪机闭合，148 帧结束；移除普通弹匣尾段混合。
- 88–108 帧平滑施加 HK416 原生挂机按钮位置差，120–137 帧沿回弹逐渐取消。固定肩部、保持两段骨长、整体移动掌指，保留原有手指和扭转骨的相对旋转。
- 四款前握把均等到 128 帧才开始回握，148 帧到达各自持握姿势。插鼓、拍击和回弹阶段不会被提前覆盖。
- 保留现有非线性播放时钟、116 帧音效及 `RifleReloadHandoff` 回位逻辑；无需修改或编译 C++。
