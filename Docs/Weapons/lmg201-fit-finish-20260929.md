## 本轮改动

| 部位 | 制作内容 |
| --- | --- |
| 机匣盖 | 按分段安装轮廓重建规则盖壳及连续内皮，各段宽度分别定义，与机匣上肩采用同一轮廓依据 |
| 机匣开口 | 删除旧拆分大顶封板，沿真实边界建立上沿、内侧壁和下沉托面；盖内细节同时局部适配 |
| 护木安装端 | 修整后上端过渡，接回共同高度映射，保留下部握持区域 |
| 前端连接 | 按导气管端部轮廓重塑接头后端过渡；保留现用枪口—枪管接口和前端主要轮廓 |
| 法线与贴图 | 保留旧件 UV0/结构法线，形变处搬运角点法线；新盖体独立展开，烘焙 2K Normal/AO，UE 单次绿通道转换 |
| 主体材质 | 机匣、盖壳、前端涂层采用共同配方和细纹尺度；裸露钢件、内腔及机瞄保留明确差异 |
| 旧件与配件 | 弹匣、脚架及配件外壳按原分区制作 201 私有材质副本，保留结构贴图、刻字保护、聚合物及光学分支 |
| 接入 | 按槽名保存实际绑定，更新现有天气表；主体、分件和配件继续使用当前加载路径 |

原生动画轨道和骨架未改；V7 手臂、弹匣/布袋状态分区、机瞄活动头部及运行挂点保留。FactoryMuzzle、FactoryStock、FactoryRearGrip、Magazine、Cloth33 等原有分区身份继续使用。

## 材质配方

| 表面 | 本轮制作值 |
| --- | --- |
| 基础涂层 | 线性颜色 `(0.010960, 0.014444, 0.017642)`；粗糙度中心 `0.60`；Specular `0.28` |
| 完整涂层 | Metallic `0`，依据原始材料分区识别涂层，不用处理后的金属度反推区域 |
| 裸露缎面钢件 | 独立表面，粗糙度 `0.50`、Metallic `0.65`，用于指定盖内钢件及扳机等 |
| 内腔 / 消光机瞄 | 粗糙度分别为 `0.70` / `0.65`，不套不相关的结构图集 |
| 湿润膜 | 满湿颜色 ×`0.90`，粗糙度 ×`0.85`，下限 `0.48`；配件保留原保护区域 |
| 主体微纹 | 本枪 5 cm 局部空间粗糙度纹理，幅度 `0.016`；不新增强噪声法线 |

主体图集仅在原涂层区域收敛颜色与粗糙度，保留自己的结构法线和 AO。新盖体使用独立法线/AO；机匣新内侧不采样盖体贴图。布料、弹链、聚合物、透镜不按涂层覆盖。这些参数尚未获用户视觉认可，不作为其它枪型标准。
