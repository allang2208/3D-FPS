# M4 / M16 换弹：左手抓握精度修复（2026-09-25）

用户反馈 M4 与 M16 换弹插入弹匣时左手"还是没有精准抓握弹夹"。本轮先量后写，定位为**跨枪配准**问题（M16）加**弹匣截面系内的几毫米残差**（M4），并按已认可的 AKM 包握重做配准；未启动游戏、未跑 PIE、未做真机截图，观感由用户实机判读。

制作入口、参数、回执与全部未覆盖项见 [SourceAssets/M4M16ReloadGripFix20260925/README.md](../../SourceAssets/M4M16ReloadGripFix20260925/README.md)；可复用方法沉淀在 [弹匣抓握跨枪配准](../../skills/ue5-fps-arms-animation/references/magazine-grip-registration.md)。

## 结论

以用户已认可的 AKM 包握为基准，同一套量测（各手骨顶点云到弹匣壳的中位间隙）：

| 部位 | AKM 基准 | M4 修复前 | M16 修复前 | M16 修复后 |
| --- | --- | --- | --- | --- |
| index_01 | 20.9 | 15.8 | **-0.5** | 22.3 |
| middle_01 | 10.1 | 8.2 | **-3.5** | 11.3 |
| pinky_02 | 14.9 | 18.1 | **31.0** | 8.6 |
| pinky_03 | 8.7 | 11.8 | **29.3** | 1.8 |
| thumb_02 | 1.3 | 5.5 | **14.9** | 4.5 |

- **M16 的左手确实没抓在弹匣上**：食指近节埋进壳内 21 mm，小指浮在壳外 16–20 mm。对基准剖面的误差平方和 2530 → 269。
- **M4 的左手本身来自已认可的 AKM 手型**，与基准只差几毫米；本轮把它在弹匣截面系里的残差收掉，并修掉压实末段拇指插进机匣 19.6 mm 的问题（→ 3.5 mm）。

## 根因

M16 换弹复用 M4 的整条左臂，但两段是用**武器空间里一个手估的固定平移**接起来的（`transplant.py` 的 `contact_shift = (-12.1, -9.6, -20) mm`，`author.py` 沿用）。两枪弹匣壳相对挂点的位置本来就不同：一个常量既表达不了握持高度，也表达不了壳截面的位置，于是把食指推进壳里、把小指推离壳外。M4 用的 AKM 局部切线对齐方向正确，但只在弹匣截面系里留下约 10–15° 的扭转和几毫米偏差。

## 做法与关键判据

1. **抓握存成弹匣自己的关系** `R = (MagDeform @ ShellFrame)^-1 @ hand_world`。`ShellFrame` 全部由弹匣自身网格算出：长轴取脊线拟合，方向按该 clip 的插入方向（底盖 → 供弹口）定向；薄轴指向掌侧；原点取握持高度处的壳包围盒中心；高度按"距底盖"计。该关系与坐标基底无关，因此可以跨枪搬运。
2. **高度约定的选择必须用数据定**。M16 弹匣比 M4 长 29 mm：按"距底盖等高"重建，对基准剖面误差 268；按"距供弹口等高"重建，误差 3475（手被推到弹匣颈部，明显错）。脚本把两条都算一遍再按误差选，不靠猜。
3. **M4 用有界刚体校正**：在弹匣截面系里搜 6 个自由度（≤10 mm / ≤12°），目标是对齐 AKM 剖面并计入机匣净空。手网格只求值一次、每个候选按刚体移动即可，因此搜索很便宜（数百个候选秒级）。**不加机匣净空项时，最优解会把拇指推进机匣 23.6 mm**；加上后剖面略有让步但机匣穿透降到 3.5 mm——两个指标要一起看。
4. **量测的口径要一致**：最近面法向的"内外"判据对远离表面的顶点会误报（曾出现 -128 mm 的假穿透），深度的统计必须只在贴近表面（<25 mm）时采信；中位间隙比最小值稳健。
5. **搜索与出图必须用同一套坐标约定**。第一轮搜索在"弹匣 rest 系"里量、却把校正施加在另一个基底上，写出来的动画与搜索预测对不上；另一次是握持高度参考点用了腕点而搜索用指根，等效于把旋转支点挪了 46 mm，同样对不上。现在出图脚本在下笔后按同口径复量一次，预测与实测一致才算过。
