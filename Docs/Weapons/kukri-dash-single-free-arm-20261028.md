# 单持冲刺下劈：左臂扭转修复 V4

本轮对应用户反馈「单持状态下副手手臂仍扭曲，改为自然摆动后甩」。范围为 Jason、Kaitlin 的 `Kukri.FullBody.Dash` 左臂。来源是当前已保存接入的 `DashHandsV3`，保留右臂、躯干、腿部、位移和命中时钟；双持入口继续使用上轮专用动作。

## 排查结论

V3 将左手拉到预设肩部空间位置，同时让肘部朝固定方向偏转。目标穿过身体侧面时，肘弯平面大幅旋转：Jason、Kaitlin 的上臂相对原生绑定轴向偏转峰值分别为 128.80°、131.29°；120 Hz 下相邻帧上臂局部转角峰值约 15.86°。这部分扭转已存在于动作源，辅助骨同步承受该扭转。不是仅把手腕朝向转回来就能解决。

运行接入代码中，无副手装备的单持攻击不保留旧左臂；`NativeSwordGrip` 标记使完整原生动作跳过第二次双手 IK。当前修复只需重制动作资产，不需要修改或重新构建 C++。

## 修改

左肩采用从原待机上臂方向到后摆方向的最小旋转，去掉围绕肩腕连线转动的肘部目标。左肘仅沿原生弯曲轴活动，肩部先后摆，肘部稍后舒展；约 0.54–0.68 秒形成后甩，再随身体收势。肘部保持弯曲，手掌放松并随前臂运动。上臂与前臂辅助骨按同一原生姿态更新。

序列仍为 120 Hz、161 帧、1.333333 秒，命中窗 0.367–0.467 秒；首尾严格匹配原待机。非左臂轨道、骨骼位移与原版逐值一致。
