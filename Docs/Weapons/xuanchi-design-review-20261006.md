# 玄螭镇岳设计回查与修复（2026-10-06）

范围：镇岳目录、模块与图标引用、两款传说符文的代码路径、攻击距离和旧存档迁移、联机命中结算。用户本轮明确要求排查并修复；没有启动编辑器或 PIE，隔离测试未加载玩家存档。

## 已定位并修复

1. **金刚符文：联机客机的武器命中未在服务端吸血。** 单机路径在 `NotifyConfirmedWeaponHit` 调用 `ConfirmAttack`；客机则由服务端 `ServerReportHit` 扣怪物生命，再向客机发送反馈。客机反馈中的吸血被组件的 Authority 条件拒绝，服务端原先没有对应调用。现在在服务端确认实际伤害后执行吸血结算，使用 `Applied`，继续遵守低血量刷新、友方排除及切武器清除规则；客户端仍不能改生命值。
2. **金刚符文：恰好 30% 生命可能错误进入低血量状态。** 原式 `float(MaxHealth * float(0.3))` 在最大生命 100 时得到 `30.000001907348633`，30 点生命因此错误满足“小于 30%”。改为以双精度生命比例比较目录阈值，保留 `[70%,100%]`、`[30%,70%)`、`[0%,30%)` 三档定义。
3. **金刚符文外观说明遗漏。** `ModularSwordVisual::Appearance` 原先落入通用“剑刃表面符文”分支，现补为金刚经行草、金色渐变、镇岳专属传说说明。
4. **蟠螭展岳目录分类字段遗漏。** C++ 原先已经把它列为金色特殊改造，但 JSON 及重新安装脚本缺少 `tier: special`。两处补齐，避免目录消费者与重新生成结果不一致；不改已有数值。
