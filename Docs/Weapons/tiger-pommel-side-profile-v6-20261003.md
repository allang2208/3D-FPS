# 虎头配重：侧面、拼接及下颌鬃 V6

用户认为 V5 不够还原，重点是侧面。V5 的整体下部前移仍形成连续楔形，没有区分原参考的后脑鬃部与前下颌；球形后壳还会在侧向投影中遮住眼窝和脸部。此次重新建立侧面深度轮廓。

## 制作方案

- 后脑保留圆厚体积和向下的后鬃；按用户圈选位置收短下颌鬃尖约 6 mm，根部拓宽最多 9%，用浅拱过渡连接侧颊，减轻孤立垂挂感。
- 用额头—眼窝—鼻吻—上唇—口角—下颌—须尖的逐高度深度站点控制侧面。口角落后于上下颌，口腔内壁、唇缘和牙齿保持连接关系。
- 虎脸和侧壳共用轮廓，用前后切向的 Hermite 曲面重建连接带，移除旧的球壳覆盖和截断处理；下颌也沿同一曲面衔接。红石、眼圈和眼睑使用同一局部切向基底。
- 侧颊制作六组、每组三缕的向后下方长鬃浮雕，同域制作 2K BaseColor/ORM/Normal。保留后部云纹，原正面纹饰继续复用。
- 按共享边界把面部颜色及 ORM 烘入侧壳图集，在线性颜色空间过渡到后部纹样；微法线渐入。图标对脸部和侧壳使用相同灰阶映射。
- 外侧前脸改用侧鬃的空间投影，高度与颜色使用同一场；正面中央保留原有眉鼻口及下颌纹样。生成正面 4K 与侧壳 2K 两组 PBR。
- 尾环和冠饰不使用侧颊纹样，继续取原云纹高度函数；冠饰增加独立槽复用旧材质。真实柄尾切口、接座、挂点及长握柄偏移保持原值。
- 新网格、侧鬃材质及对应旋风材质使用独立 V6 包。主改造 ID 和数值不变。
