# 单持第三人称冲刺下劈 V2（2026-10-28）

本轮按用户反馈重做挥刀幅度、向下刃向和短距离位移后的腿部承重。制作范围为 Jason、Kaitlin 单持第三人称；第一人称动画、伤害、命中窗、冲刺距离和相机参数没有修改。

## 原因与改动

- V1 将第一人称肩腕路径的前向分量压到 65%，有效下砍段仍有明显屈肘，低位随挥时刀尖主轴仍向上。V2 使用肩部空间的完整弧线，举至头部右后上方，肩膀先带动、肘部展开，再向前下方斩落。握持和刀身共用同一手掌变换。
- 举刀与回收使用弧线插值，避免低位到高位的直线插值令手腕靠近肩膀、肘部突然折叠。举刀在约 0.22 秒完成，0.27 秒肩部开始带动，快速劈砍穿过原有 0.367–0.467 秒命中窗。低位保留短暂随挥，然后抬回待机。
- 主手整臂一起分配持刀方向，肘部路径连续限制，前臂与辅助扭转骨同时生成。手腕采用有限弯曲与轴向旋转，右手指沿用当前抓握。左臂先前上摆平衡，再向身体侧后方回摆；弯肘平面连续运输，左腕不单独拧转，手指略放松。
- 前脚在 0.09–0.32 秒屈膝提起、向前落地承重；后脚在 0.24–0.49 秒蹬地后跟进。双脚保持各自一侧，脚尖轻微外开，膝盖跟随脚尖。击出时骨盆前移并下沉，胸背配合前压，再错峰收步回到原待机。

## 位移衔接

实际执行路径是 `FPSGAMECharacter.cpp::FirePressed` → `BeginMeleeDashMomentum`，保留进入技能前的实际速度，由 CMC 以地面 1800 cm/s² 制动，并非固定动画根位移。没有修改这条玩法路径。

`FPSPlayerBodyAnimInstance.cpp` 现在让空副手的 Kukri `SprintAttack` 在松开奔跑状态后继续依据真实速度保持跑步；移除这段技能的额外速度滞后。腿部提前由跑步渐入落脚支撑，高残余速度时保留部分步态，实际停下后使用完整支撑动作。收势时再交还移动步态。空中、滑铲与翻越仍使用既有层权重。

`FPSBodyKukriMotion.h` 调整同一命中时钟下的腿部接管窗口。未给动画根节点写入前冲，避免重复移动角色。运行时自然度仍需用户实测，离线制作不等同于接地、衣物或联机验收。
