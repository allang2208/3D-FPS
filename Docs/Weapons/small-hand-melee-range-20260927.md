# 小手近战受击范围（2026-09-27）

用户授权：落实移动碰撞与近战受击查询分离、低位范围补充；攻击不锁定目标，仅按玩家朝向做范围判定。

## 接入

- 新增 `Source/FPSGAME/Weapons/MeleeSmallTargetQuery.h/.cpp`，供剑及枪械、弓快速近战共用。
- 小手继续使用原来的移动胶囊，不阻挡玩家；近战用 Pawn **对象类型**查询读取胶囊，不依赖其对 Pawn **追踪通道**的响应。没有放大小手模型、导航体积或枪弹碰撞。
- 快速近战保留原打击点、技能距离、球半径、接触时刻和单目标结算。原 Pawn 通道扫掠之外补充同轨迹的小手对象查询；实际接触优先，未命中活怪物才使用低位扇区。
- 剑保留原剑刃连续扫掠。每个与有效攻击窗口相交的帧，在当前窗口末端的玩家瞄准参考系追加一次低位查询，共用 `HitActors` 及现有伤害、削韧、击退和反馈入口。
- 冲刺下砍、旋风的已有立体扇区保持原实现；没有增加自动朝向、追踪、目标黏附或手臂瞄准。

## 首版参数

| 项目 | 值 |
| --- | --- |
| 范围 | 玩家稳定瞄准眼位在地面的投影，到小手胶囊中心的水平距离最多 120 cm，且不超过当前攻击距离 |
| 普通挥砍、快速近战 | 前方总角度 60° |
| 突刺补充 | 前方总角度 30°，仍为单目标 |
| 上下层限制 | 双方胶囊底部高度差不超过 45 cm |
| 抬头限制 | 瞄准方向 Z > 0.35（约向上 20°）时停用低位补充 |
| 适用对象 | 活着、可受伤的 `AFleshHandMonster`，且 `bMinion=true` |
| 遮挡 | 眼位到命中点、小手高度到命中点都必须无遮挡 |

低位命中不穿墙、矮墙和地板；普通挥砍可命中扇区内多只小手，每刀每只一次。突刺、配重锤和快速近战只补充一个目标，实际轨迹已有命中时优先保留该命中。

## 开销及交付

无额外怪物 Tick、组件或物理模拟，也不全场遍历 Actor。只查询玩家附近的 Pawn；普通剑在有效窗口每帧最多一次局部 overlap，快速近战每次动作只在接触时刻查询。候选先做类型、死亡、距离、高差和角度过滤；每次低位查询最多对最近 16 个候选执行遮挡射线，每个最多两条。已命中者在后续帧先行排除。此上限是实现预算，不是实测帧率结论。
