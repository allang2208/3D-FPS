# SVD 护木支撑、握匣与拉栓修复

> 本文保留该阶段的制作与检查记录。当前认可的换弹手型、最新材质／接口及归档恢复边界，以 [SVD 发布说明](svd-publication-20260923.md) 为准；旧版本的导入成功不代表最终手型获认可。

后续用户反馈握匣仍不贴合且弹匣内部镂空；弹匣模型和 10 条普通／空仓动作继续由 [弹匣内部与前后包握修订](svd-magazine-fit-20260923.md) 接续。本页的首次握匣结果不作为已获用户认可的模板；其他动作保持本页版本。

用户要求参考其他枪械与手臂 Skill 沉淀，修复 [上一轮检查](svd-basic-contact-review-20260923.md) 中的不贴合问题。本轮重做相关手部动作并同步四种前握把分支，沿用现有运行资源路径，未修改 C++、枪械业务、音效或模型材质。

接入已完成：原厂及 vertical、canted、prism、angled 各 12 条，共 60 条动画已通过后台 commandlet 导入并保存到上述现有运行路径。五批导入均已结束，最终保存回执为 60 条；原动画包已逐项备份。此状态只说明制作与资产落盘完成，不代表修复后动作测试通过。

核心修正是手指的父子变换：先缓存整组局部旋转，随后按层级重建，保留 rest-local 平移、缩放和蒙皮。旧生成器在父骨已经变化后，用旧子骨世界矩阵求局部位置，导致换弹和拉栓时指骨偏移、手套塌陷。新生成器替换了这一方法。

供体采用当前 M4 `M4_MAT_reload` 的完整握匣姿态，按 SVD 短弹匣重新配准掌面、拇指对握及四指包裹。旧 SVD 脚本虽然打开了当前 M4 的组合 Blend，实际选的是其中保留的旧 `M4_HK416_reload` 动作。原厂护木单独适配掌面和五指，右手使用 ASH12/A762 成组拉栓手型，按 SVD 实际拉机柄与机匣外形调整整手。

装匣后的动作分为压实、逐指松握、向外避让、回握。保持源帧 240 的压实事件，250 起侧撤，268 起回收，302 完成对应原厂或前握把握姿。手腕与弹匣的接触阶段保持固定关系，手指开合通过局部旋转完成。右手保持现有拉栓机械轨道与事件时钟，接近、释放和回握沿外侧过渡。

腕、肘和前臂一起支撑目标握点，前臂 roll 使用掌面横向轴的投影，辅助骨随完整骨段运动。四个握把动作族保留自身成组手型，同步修复后的换弹和右手拉栓；冲刺起止渐进衔接对应 idle。快速近战沿用原枪体轨迹并使用修复后的握点。
