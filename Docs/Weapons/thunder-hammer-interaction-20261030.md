# 贯雷与疾雷交互迭代（2026-10-30）

用户要求贯雷与疾雷同等精度但有区分度、贯雷投出以锤头向前旋转，以及疾雷逐步抬高手臂、渐强特效并加入电磁音。

## 贯雷

新源 `SourceAssets/ThunderGodHammer20261028/GuanLeiReturnC8` 从原厂中央锤座实体继续修改。贯雷采用宽厚回折锻肩与闭合嵌银回环；疾雷保留三路向上的引雷纹和低矮引雷尖。原厂圆徽、锤头及柄颈安装接口保持，专用 4K BaseColor、ORM、Normal 和正式灰度金属框图标同步更新，仍是雷神之锤专属特殊改造。

原去程围绕模型局部 X（两端锤头轴）翻转，圆徽面容易朝前。改为离手后 0.10 秒绕握柄平滑转正 90°，使锤头两端进入竖向前翻平面，继续以 1080°/秒旋转。首帧对齐作者释放姿态，服务端和客户端使用相同的初始姿态、时间计算。瞄准轨迹、落点伤害、召回路径、接锤和用户选定的召回音效不变。

## 疾雷

`JiLeiMotionV5` 沿用 V4 的原生骨长、完整支撑臂、右手握点、手指和左手松开。举手由原先 1.34 秒提前结束，改为 0.10–2.00 秒完整蓄力进程；后段肩与腕共同再上移 8 cm、前移 10.5 cm、右移 1.2 cm。动作仍按实际蓄力时长映射，释放第一帧接当前满蓄力终点。

蓝白电弧共用蓄力进度：两条细电弧逐步激活到八条，范围、管径和亮度渐强。继续使用既有有界网格池与形变调度，不改变重击落雷伤害公式、范围和瞄准圈。

`JiLeiChargeAudioV1/S_JiLei_ChargeElectromagnetic.wav` 为原创合成的 4 秒无缝单声道循环。包含低频磁性嗡鸣和电流噪声，运行时按蓄力进度调整音量、音高和低通开放度。松开、取消、换装时 80 ms 淡出；结束时销毁组件。本人预载，远端随可见特效异步加载并距离衰减；远端电弧和声音共用复制的服务器起点及时长。
