# Super90 R21：装填发力反馈与抓握拉栓

用户确认当前动作正确，继续要求降低机械感，优化武器、右手与屏幕的自然抖动，并将最后食指／拇指捏拉机柄的观感改为抓握。基线为 R20，保留完整推动、播放速度、左臂根避让和所有机械／音效时点。

## 发力与屏幕配合

`SourceAssets/Super90LoaderR21_20261010/motion.py` 在原 60 Hz 源时钟上制作小幅受力响应：取装填器、对接、推动阻力、压实、松脱、拉栓止点与复进，各自有不同的起幅、反向回弹和衰减时间。它是叠在原动作上的细节，不重定时或缩短换弹。

枪与仍握住它的手共用刚体运动，以当前枪托底为支点，肩部只作毫米量级的压缩。右手保持枪根空间的握把关系，右前臂的弯曲方向稍后跟随，避免整个右臂像硬杆一起旋转。左侧沿用 R20 臂根避让；微调抓握腕点时固定肩位、保持骨长并重建前臂辅助骨。

相机继续使用 R16 对齐后的参考视频背景轨迹，另外承接较小、稍迟的发力反馈。新增跟随混合 1.4／3.0 源帧延迟，俯仰／偏航／侧倾分别取枪体新增角度的约 26%／20%／14%。通过现有 `Super90LoaderCameraReference` 曲线消费，声音回调不另加冲量；不增加随机 Tick 抖动、对象加载或另一套累计弹簧。

## 抓握拉机柄

重新用原生 V7 手型与本枪拉机柄几何制作手型。食指、中指弯曲承拉，环指、小指自然收拢；拇指采用本枪推动杆抓握的侧向支撑关系，不再向食指尖捏合。抓住前逐指收拢，后拉保持，复进前逐指放开，再接原来的回握。

只允许解剖屈曲和小幅腕部刚体校正，不平移指骨、不改骨长／权重。作者目标的腕部局部位移约 1.4 mm、转角约 4.6°；其权重局限在原拉栓接触段。原装和四类握把同步制作，包含七个空仓数量分支与 cycle-only，普通分支仅增加发力响应。

## 制作与接入入口

- `prepare_hand.py`：读取 R20 源姿态、V7 蒙皮与真实拉柄。
- `fit_grasp.py`、`grasp_target.json`：闭合抓握作者目标。
- `motion.py`、`author_r21.py`：15 个 loader 动画及四份握把差量；可编辑源 `Super90_Speedloader_R21.blend`。
- `prepare_camera.py`：更新 `Source/FPSGAME/Weapons/Super90LoaderCameraReference.h`，覆盖前头文件位于 `Before/Source/`。
- `import_r21.py`、`run_r21.ps1`：只替换 loader 动画条目，保留其他动作、idle 和 retained 引用；覆盖前 UE 包留在 `Before/Content/`。
- `build_r21.ps1`、`build_receipt.json`：后台 Editor／Game 构建记录。

本轮不运行游戏、渲染预览、自动测试或验收；素材读取与几何拟合是制作输入。导入保存、原生构建和实机观感分别记录，效果交由用户体验。
