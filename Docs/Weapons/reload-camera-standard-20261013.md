# 枪械换弹镜头标准 RC1（2026-10-13）

## 排查结论

此前并非所有枪械换弹都有屏幕反馈，也不是同一数值。角色的旧入口限定了部分枪型；双持被整体排除，Super90 仅快速装填有分支，RSH-12 主要覆盖开关弹巢。旧配置 `Strength=2.8`、`FollowStrength=2.0`、`ImpactStrength=2.6` 叠加各枪不同的作者曲线；其中 Impact 在实现里还被截到 2.0，配置值与实际值并不一致。

本次把**换弹**从这组装备/旧动作倍率中分出，使用 `ReloadStrength=1.0` 与统一机械接触表。旧三个字段只供原来的装备反馈和兼容调用，游戏中的换弹入口使用新轨道。全局 `fps.Camera.ActionShake` 继续有效；最终仍乘角色 `CameraMotionScale` 和 ADS 抑制。

## 强度与节奏

统一的是强度口径、接触类型和总量上限，各武器保留真实动作及接触时刻。

| 接触 | 俯仰峰值基准（度） | 回弹时长（作者秒） |
| --- | ---: | ---: |
| 取出弹匣 | -0.65 | 0.22 |
| 插入弹匣/快速装填器 | -0.75 | 0.18 |
| 压实 | +1.25 | 0.24 |
| 拉柄后止 | +0.65 | 0.22 |
| 枪机/套筒闭锁 | -1.65 | 0.22 |
| 开盖 / 放弹链 / 关盖 | +0.60 / -0.45 / +1.40 | 0.22 / 0.18 / 0.24 |
| 打开弹巢 / 退壳 / 关闭弹巢 | -0.80 / -0.50 / +1.10 | 0.22 / 0.18 / 0.22 |
| 装入单发 | +0.45 | 0.16 |

以上为公共舒适度倍率前的基准，完整偏航、侧倾和位移表位于 `Source/FPSGAME/Weapons/WeaponReloadCamera.h`。接触反馈沿用推入—短暂承重—小幅反向回弹—归零曲线，没有整段随机震动；取弹等待段保持安静。

- 手枪系数 **0.8**；普通步枪/狙击步枪 **1.0**；ASH-12、机枪、Super90 **1.1**。RSH-12 使用 **1.0**。
- 缓慢跟随与机械接触分开处理：已有 M4/ASH-12/PKM/201 布袋/RSH 曲线保留时序与方向，统一跟随权重 **0.35**；其余使用接触前后的小幅准备与回收。Super90 的记录背景轨迹保留采样与 FOV 换算，纳入相同输出上限。
- 两手同时换弹使用独立源时钟和镜像方向，叠加除以 **1.6**；同拍同幅反馈相当于单手 **1.25 倍**，然后再经过公共上限。
- 用连续饱和曲线限制换弹总输出：舒适度倍率前俯仰 **3°**、偏航/侧倾各 **1.5°**、位移向量长度 **0.85 cm**。在默认 `CameraMotionScale=0.45`、未 ADS 时，对应上界为 **1.35° / 0.675° / 0.675° / 0.3825 cm**。这是上限，并非每次接触都达到该值。
- 正常结束在最后 **0.08 作者秒**收回；取消、切枪或打断后从最后反馈在 **0.10 实秒**内归零。中断后只补闭锁时，过滤恢复点之前的事件。
- 只改变镜头输出，不修改换弹时长、逐发数量、弹药提交、动画、音效或攻击后坐；已完成的冲刺减半标准继续生效。

## 后续枪械接入

1. 普通弹匣枪沿用 `BuildReloadCameraTracks` 的公共分支；独特机构增加语义接触，引用其既有动作/机械常量。
2. 新枪使用上述三档之一，不再单独乘整段临时强度；特殊作者背景轨迹只做跟随，机械冲量只来自公共表。
3. 使用换弹源时钟；不能使用独立累加时间或音频预卷时刻。区分正常、空仓、逐发、快速装填、只补闭锁，以及双持独立动作。
4. 统一从 `UWeaponActionCameraComponent::Apply` 合成一次；不得再单独启动叠加的随机 CameraShake。
