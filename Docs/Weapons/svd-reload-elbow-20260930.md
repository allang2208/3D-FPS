# SVD 插匣后回握：左肘避让修正（2026-09-30）

后续用户仍反馈上臂扭转。进一步定位到源动作本身的屈肘平面/轴向朝向错误，已直接重制十条换弹动画，见 [上臂与肘部重制](svd-reload-arm-plane-20260930.md)。本文的“恢复作者姿态”只解决当时的运行时误干预，不代表源动作本身符合自然肘形。

用户反馈装备锁子甲时，SVD 插匣后恢复握把的左肘发生不自然扭曲。本次定位并修复了 2026-09-29 新增镜头避让对回握姿态的误干预。沿用手臂动画 SKILL 的整臂联动与接触保留要求；没有改写已制作的插匣、手指、拉栓或握把动作。

## 原因与改进

`FPSOutfitArmClearance::Apply` 原来从肩点 Z=-26 cm 开始参与避让；回握左肩约在镜头下方 20 cm，本已离开需要保护的上方区域，仍会得到约 0.25–0.35 的修正权重。

同时，原来的可达性上限为“上臂长 + 前臂长 - 0.01 cm”。把肩点后移后，肩腕距离很容易触及这个上限：canted 回握末段原约 27° 的弯肘被拉到约 2.2°。骨长和手腕接触虽然没变，肘仍会近乎锁直，弯曲方向和袖子轮廓随之改变。前一次只看骨长、手部不变量和上方视锥，没有覆盖这一副作用。

本轮修改：

- 上方区域的垂直触发区间改为 -12 至 -4 cm；已在下方的回握左肩保留作者姿态。
- 避让目标的最大肩腕距离限制为该帧原本的肩腕距离，保留原有弯肘余量，不再以几乎完全伸直作为默认可达解。
- 先运输原来的肩—肘—腕弯曲平面，再求两骨解。上臂、前臂及对应 twist 骨同段旋转，避免各自独立最短旋转叠加额外肘部扭转。
- 保持原手腕、手指及枪械骨矩阵。裸臂、锁子甲、手套继续从同一个源组件取得最终 Leader Pose；本轮不新增独立衣袖偏移，也不改网格、权重、袖口、轻摆或 15 套已接入衣袖引用。

这是对已有运行时避让函数的修正，不是重新烘焙十条换弹动画。适用范围仍为装备锁子甲的可见第一人称枪械。
