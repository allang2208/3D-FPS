## 接入

`TacticalDeviceComponent::Configure` 按枪型、配件、槽位加载独立模型，角色、第三人称、掉落武器和各预览沿用现有组件入口。`ColdSteelIconResources` 按同一规则预载。原有正缩放安装变换、双光束、最强数值、存档槽名及改造选项均保留。

配件原主体材质和 UV 保留。新增安装座使用现有金属涂层或赐福石墨材质，普通镭射与手电仍保留原材质槽名及运行时表面覆盖规则。

`mount-comparison.jpg` 提供 M16、201 的前后对照。检查视图用金棕色强调安装座，实际材质以正式资产中的绑定为准。

回读时发现 FBX 导入器默认清理小三角面，造成普通镭射外壳及赐福激光光学细节部分缺失（最大约 0.24 mm）；承接面自身差异小于 0.001 mm。已同时在这批模型的导入任务与现存资产导入记录中关闭 `remove_degenerates`，重新导入保存，最终回读确认缺失已消除。保存回执中 `revision: 3` 表示此修正。

原生构建：Editor 记录为 `Saved/BuildEditor/build-20261008-152333.log`，Game 记录为本轮目录的 `build-game-fit.log`；均返回 `Succeeded`。使用常规构建产物，没有依赖 Live Coding 补丁。
