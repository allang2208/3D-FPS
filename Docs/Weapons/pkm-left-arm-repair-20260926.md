# PKM 左臂、肘部与配件待机修复（LeftArm48）

后续腕口截图确认本轮遗漏了手套、衣袖绑定同步。服装衔接和换弹肘腕配合继续见 [ArmJoint49](pkm-wrist-elbow-joint-20260926.md)；后续制作优先使用其最终轨道，不能再用本目录旧换弹覆盖。

用户指出待机和换弹仍有明显问题，本轮接续排查 Elbow39/41/42、Sprint44/46 和后续已回滚的阴影/皮肤调整。

查明两项制作缺陷：换弹仍使用逐帧切换强度的 Elbow39 算法；四种配件待机误选了通用旧 action，覆盖了已制作好的各自握持。实际原生网格已包含当前 V7 权重，RAW 与压缩动画差异很小，未发现上述现象来自“制作源没有导入”。

实施方式是恢复配件 Contact15 正确动作源，重做整段左上臂/小臂的皮肤旋转框架，并重建 PKM 左前臂到手腕的连续权重。基础肩肘腕关节轨迹、手掌接触轨迹及枪械时序保留；配件待机恢复其各自原有接触姿势。基础与四种配件共 60 条动作统一处理，原生武器与独立裸臂资产同步保存。

制作计划、具体证据、脚本与可重放 JSON 轨道见 [LeftArm48 制作记录](../../SourceAssets/PKMLowpoly20260922/LeftArm48/README.md)。实际落盘结果以该目录 `install_receipt.json` 为准。

旧 Elbow39/41/42、Sprint44 算法与 FBX 属于历史版本，不能覆盖本轮最终资产；尤其不能再从 `PKM_Game_idle` 制作配件 idle。当前动作直接经原生 AnimDataController 写入，后续应从 LeftArm48 的轨道源继续编辑。

默认后台制作与保存；没有启动游戏、进行截图或渲染验收。视觉效果由用户实测。
