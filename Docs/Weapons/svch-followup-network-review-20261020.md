# SVCH 后续完成度与联机复查（2026-10-20）

本轮由用户明确要求检查完成度、遗漏和 bug，重点联机。核对范围为本会话的 SVCH 新枪体、机械瞄具、KV 镜、弹匣、通用握把、消音器，以及 R2–R7 快速近战修订。没有启动交互编辑器，也没有改动 V9 或重制认可的动作。

结论：R7 五套姿态确已落盘，已实现功能的服务器和表现检查有明确结果；但不能把整段开发标为全部完成。通用枪托外观适配仍有遗漏，真实快速近战输入到命中的联网闭环及游戏画面仍有覆盖边界。

## 本轮修复

### 快速近战的双时间轴

`UFPSQuickCombatComponent` 按动作加速倍率推进源时间，而 SVCH 的 `UpdateWeaponState` 原来按墙钟推进动画。普通倍率时两者还会受 Tick 顺序影响；加速状态下组件先结束，动画仍在收势中，下一帧清空动作会跳回待机。服务器收到的持续时间又来自组件，因此本地画面、动作占用和服务端窗口不是同一时钟。

复用 ASH 已有的角色侧推进方式，仅将 SVCH 步枪快速近战纳入：

- 角色在姿态和相机求值前推进组件一次，组件 Tick 不重复推进。
- `WeaponStateElapsed` 读取组件源时间；命中、视模和第三人称动作采样共用该时间。
- 动作完成按实际完成时刻释放射击锁，不再保留加速前的未来截止时间。
- 没有改动 0.9 秒源动画、接触比例、枪路、V9、R7 握点及其他枪械动作。

### 命中时的旧姿态探针

SVCH 原来不在 ASH/M870 的准确接触帧采样分支内，跨过接触点的大帧可能使用前一次网格求值位置查询。现在开始动作时即发布正确 clip，并在命中查询前求值既有接触帧。这是探针时序修复，伤害、查询半径、判定距离与服务器规则不变。

### 默认瞄具说明

目录的 SVCH `optic / false` 仍写成“SVD 原厂 PSO-1 四倍镜”。现已保存为“原厂机械瞄具”和无放大的折叠机械瞄准说明；只修改这两个文案字段，配件 ID、倍率实现和数值不变。执行状态见 `catalog-label-receipt.json`。

3. **连续画面与消音器实战。** 未完成多玩家实际画面的快速近战/换弹连续穿模检查、音频试听，以及首发击杀/未击杀时其他怪物警觉的实战复查。此前与本轮的数值和传输检查不能替代这些结论。
