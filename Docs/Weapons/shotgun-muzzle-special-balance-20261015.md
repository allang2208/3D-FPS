# 散弹枪枪口特殊改造与消音器数值

用户要求收束器、鸟笼消焰器、散弹枪消音器归为特殊改造，并授权配置消音器数值。

`ColdSteelModification::Tier` 按枪口槽和这三个稳定 ID 返回 `Special`，改造面板沿用已有特殊改造分组、标签与样式。没有更换 ID、槽位或模型，也没有改变配件互斥与存档规则。

| 改造 | 当前属性 |
| --- | --- |
| 收束器 | 弹丸散布减少 35% |
| 鸟笼消焰器 | 后坐力降低 15%，腰射随机散布减少 15%，减弱火光 |
| 散弹枪消音器 | 后坐力降低 25%，稳定性提高 20%，子弹速度降低 15%，开镜耗时增加 10%；保留消音、减弱火光与降低敌人听声范围 |

消音器以开镜与弹速为代价提供控枪与隐蔽收益，不接收束器的弹丸聚拢效果，也不增加鸟笼的腰射散布加成。数值为游戏平衡初版，未经实战测试。

权威数据为 `Content/ColdSteelData/gunsmith.json` 的 `ue_super90.options.muzzle.shotgun_suppressor.stats`：`recoil_mult=0.75`、`stability_mult=1.2`、`bullet_speed_mult=0.85`、`ads_percent=0.1`。旧列表说明与 `effects` 同步，绿色消音特效说明保留，外观文案不复述数值。原消音器目录作者脚本同步更新，避免后续恢复成初版空数值。
