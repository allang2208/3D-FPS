## 模型、动作与材质

原包是无骨骼、无动作的 Unity FBX 分件模型。保留原几何尺度、UV、刻字及 4K 贴图；弹巢组件按连接岛分配为摇臂、旋转弹巢和退壳杆，六颗弹药分别绑定，扳机、击锤和速装器使用独立骨骼。新骨架保留项目统一 Manny 手臂、手套、权重及材质身份。

参考 `M1911Contact20260913` 的 P9 派生待机、ADS、射击、拔枪和检视姿态，先读取既有动作矩阵及时间范围再制作。左轮换弹为本次三维编排，不声称是源包自带动作或实机确认的手部接触。动作烘焙采样为 120 Hz。

普通换弹源时间：开巢 0.40 s、退壳 0.82 s、速装器插入 1.92 s、压实 2.15 s、合巢 2.73 s、回握完成 3.20 s；空仓同序列延展至 3.45 s。机械声音和姿态均消费当前武器动作时钟，枪管换弹倍率缩放整段。

材质使用源 Albedo、Normal 和 Unity MetallicSmoothness，转换为 UE 的 AO/Roughness/Metallic，其中 Roughness = 1 − Alpha Smoothness。保留原金属、握把非金属分区；接入现有天气材质映射。源模型自带第二套握把贴图保留在 Original，首版使用 Base Set。

## 作者输入和重建

- `extract_source.py`：从本机 Fab Unity 包解包，保留来源 metadata 和原文件。
- `read_source.py`：制作前读取分件、枢轴、连接岛和既有手枪姿态。
- `author_weapon.py`：制作骨架、速装器、动作，保存 `DanWesson715_Manny_Editable.blend`、`SK_DW715_Manny.fbx` 和 `Animations/A_DW715_*.fbx`。
- `fbx_bind_pose.py`：导出时添加覆盖全骨架和全部分件的绑定姿势。`export_complete_bind_pose.py` 可从已保存 Blend 重新导出，不重新制作动作；当前 Interchange 导入仍提示绑定姿势警告，见下方交付记录。
- `prepare_surfaces_audio.py`：转换 PBR 通道，制作枪声和机械声音。
- `import_assets.py`：用 UE Python commandlet 导入模型、8 个动作、材质、音效和天气映射。
- `integrate_runtime.py` 是本次一次性源码接入记录，不应在已修改工程中重复运行。

实际加载入口为 `Source/FPSGAME/Weapons/DanWesson715WeaponAssets.h`；角色按实例切换枪族，枪匠、库存动态图标和掉落展示使用共同的持枪网格。动态图标在用户运行游戏时沿现有机制生成，本次未执行目录图标渲染。
