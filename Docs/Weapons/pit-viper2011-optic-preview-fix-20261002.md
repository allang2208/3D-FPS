# Pit Viper 2011 瞄具衔接与改造栏预览修订

用户反馈三款瞄具衔接欠佳、部分位置悬空，枪匠预览呈白膜。本轮按该范围读取实际材料、作者模型与预览源码，在后台制作修订；没有启动编辑器、游戏或截图验收。

原版本的底座只覆盖沿枪轴 16 mm 的短区域，并未随三款镜体底脚改变支撑范围。中心表面采样存在接触并不说明外围支撑自然。镜体、接触面及固定滑套安装帧需要一起处理。普通全息的旧光心还用了固定缩放值，实际分划中心与其相差约 3.6 mm；这不是应该沿用的瞄点。

枪匠主颜色捕获明确启用材质、照明、镜面与环境反射。新增仅属于本枪的预览补光配置：主光 2.2、填充 0.5、环境 0.25，并沿用低填充软箱比例。此前通用长枪配置为 6 / 3 / 1。该调整用于保留黑色涂层、铜色和粗糙度层次；覆盖通道继续保持独立，不以白色覆盖捕获代替颜色捕获。其他枪继续使用各自已有配置。
