## 检查结论（旧第二段）

读取正式 `NormalComboV4/A_Warhammer_Slash2` 并渲染第一人称、正面、俯视三视角（`SourceAssets/SteelWarhammer20261014/NormalComboSwapV5/Diagnosis/`）：

- 旧第二段始终保持“右手在上”的握法，却从**左肩**后方蓄力。蓄满时（0.85 s）右手要越过头顶伸到左上方，右肘抬到眼睛高度以上（z ≈ +0.16 m）、正挡在视线前；接触与随势阶段右肘仍外翻上抬（z ≈ −0.06 m），左肘夹在胸前。双腕相对待机的弯折达 L 67° / R 52°，均大于第一段（L 53° / R 42°）。
- 第一段是“右手在上、右肩蓄力”的顺手动作。两段原本共用同一条矿镐挥击轨迹，只把锤子挥动平面镜像了，握法没有跟着镜像，这就是别扭的根源。

## 换手设计

- **挥击本体 = 第一段的左右镜像**：左手在上、右手在下，从左上蓄力、向右下劈。双臂关节、手到锤柄关系、速度节奏和机身带动都与已认可的第一段完全一致（实测镜像误差 < 0.001 mm）。锤体按局部 Y 反射保持锤柄与锤头方向。
- **起手换手（0.28–0.58 s）**：从共同待机举锤，旧第二段的右手在上上举在 0.40 s 正好经过竖直、几乎对称的位置，此时“右手在上”和“左手在上”握的是同一把竖直锤子：右手先沿柄滑到左手上方 → 左手张开离柄、外绕 8.5 cm 越过右手，在上方握住 → 右手继续滑到下方。随后锤子后倒进入镜像第一段的左肩蓄力（0.82 s 到位）。
- **收势换回（1.12–1.40 s）**：在随势前指时（新旧两套的锤柄方向完全一致）按相反顺序换回：左手下滑、右手绕过到上方，随后沿旧第二段的回收路线回到右手在上的共同待机。因此第三段、待机、冲刺、技能等全部仍从原待机开始，不需要改代码。
- 握持手滑动时手掌绕实测锤柄中线做圆柱插值，半径不变；空中的手先张开再在锤柄上合拢。手臂用原生骨长，从两套已认可的参考姿态按每只手的换握进度混合后求解，肘部引导只随手腕位移平移，避免掌向大转时肘部翻转。

时序仍为：蓄力 0.85 s、接触 0.97 s、挥空 1.75 s；命中停 0.07 s、命中回收 0.80 s（命中回收沿用 V4 的回收时钟，复用本挥击接触后的连续轨迹，首帧等于接触帧）。伤害、范围、体力、攻速映射、镜头侧向和挥舞音效都未改。

## 制作量化（非游戏验收）

- 接触前后的最快单帧位移（≈11.5 cm/帧 @300 fps）来自第一段本身的快速出击，镜像后数值相同；在挥击本体以外，没有超过 3 cm/帧的关节跳变。
- 骨长误差 < 0.007 mm；前臂扭转 L −13.8~13.8°、R −6.5~19.2°；两手最近 8.5 cm；换手时手腕相对参考的最大弯折 36°，肩部辅助位移 ≤ 5 cm。
- 首末帧等于共同待机；命中回收首帧等于接触帧。
