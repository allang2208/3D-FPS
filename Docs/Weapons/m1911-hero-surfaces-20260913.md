# M1911 近景模型与空仓可见结构精修

后续后部零件转轴与双手接触修正见 [握姿与转轴调整](m1911-contact-pivot-20260913.md)。Hero 网格和材质继续使用，动作已转至 `Contact20260913`。

用户已确认 P9 迁移动作和修正后的朝向，本轮按 QBZ191 的模型提升过程完成局部几何制作、分区 UV/PBR、导出与接入。模型观感和空仓换弹效果未作游戏测试或新增预览渲染，由用户测试。

## 采用的 QBZ191 方案

参考 [整体升级计划](qbz191-visual-upgrade-plan-20260913.md)、[近景表面制作](qbz191-hero-surfaces-20260913.md)、[机械小件修整](qbz191-machined-sights-20260913.md) 和 [轻度磨损](qbz191-contact-wear-20260913.md)。本轮沿用以下制作方法：

- 保留已接受枪型、骨架、动作和装配，近景缺失结构局部重建。
- 大平面、木握片、钢制小件分别处理边缘半径，保留高模可编辑倒角。
- 最终低模先三角化、重新展开 UV，再烘焙分区 BaseColor、ORM 和切线法线。
- 微表面尺度、颜色、粗糙度、金属度分开制作，少量凸边磨损保留表面层次。
- 新模型导入独立目录，游戏中的持枪、展览、图标和掉落继续共用角色装配入口。

## 原模型输入与修正

读取当前 `M1911_P9_Manny_Editable.blend` 的枪体分件和骨骼归属，制作输入记录为 `SourceAssets/M1911Hero20260913/author_inputs.json`。旧枪体约 12,080 三角面、39 个连通零件。这个数字是源模型制作信息，不表示画质或性能结论。

旧集成按材质名覆盖部分机械权重，造成枪口衬套、下方端盖随枪管运动，击锤随套筒运动；原 `Grip` 材质还覆盖了多处金属小件。本轮修正这些归属：

| 部位 | 本轮处理 |
|---|---|
| 套筒、枪身 | 整理共面边，制作有区别的近景小倒角和加权法线，保留原槽口及轮廓 |
| 枪管 | 按现有外轮廓重建连续圆弧外壁、枪口口沿、后部可见罩面及暗色内腔遮挡；继续绑定 `WPN_Barrel` |
| 枪口衬套、下方端盖 | 保留原外形，改绑 `WPN_Slide`，与套筒保持一致 |
| 套筒下方露出区 | 补充独立可见导向表面，绑定枪根，与枪管分离 |
| 击锤 | 改绑已有 `WPN_Hammer`，使用现有动作内的击锤轨道 |
| 两侧木握片 | 保留原包握外形，改善边缘、重新制作木纹和中央菱形防滑纹法线 |
| 握片螺钉 | 局部重建圆头及真实凹槽，改用金属材质 |
| 弹匣、托弹面、瞄具和其他小件 | 沿原几何细化边缘、独立表面制作；活动骨骼身份保留 |

套筒源网格没有开放边，因此本次未给它额外叠加整层厚壳。新增内腔遮挡服务于游戏视模的外观，不是完整内部机构重建。

## 七组新表面

| 图集 | 分辨率 | 材质处理 |
|---|---|---|
| Slide | 4096² | 深色处理金属、细微颗粒、少量边缘磨损 |
| Frame | 4096² | 较哑光的枪身涂层，与套筒区分 |
| Grip | 2048² | 油润胡桃木、方向性木纹、中央防滑纹，非金属 |
| Steel | 2048² | 枪管、衬套和小件的方向性细加工纹；腔内单独消光 |
| Magazine | 2048² | 弹匣钢材、细微粗糙度变化 |
| Sights | 1024² | 深色、低反光瞄具 |
| Ammo | 1024² | 弹壳色金属表面 |

共 21 张 PNG。ORM 为 R=中性白 AO、G=Roughness、B=Metallic，没有把活动件的阴影永久烘进枪身。Blender 使用 NormalGL，UE 在导入法线图时翻转绿色通道一次。手臂和手套继续使用原网格、权重、UV 和材质。

枪体最终约 37,826 三角面，不包含 Manny 手臂。主要新增几何用于圆弧、口沿、局部补面、螺钉和倒角；并非整枪细分或从零重做所有零件。

## 制作与接入结果

Blender 已保存可编辑源、紧凑 FBX 和 21 张贴图。最终 UE 导入完成新网格、七个材质和贴图保存，`import.json` 记录新网格仍引用已接受的 P9 私有 Skeleton，未重新导入动作；日志到达 `M1911_HERO_IMPORT_COMPLETE`。

第一次导入脚本误用了骨骼网格不提供的 `allow_cpu_access` 属性，已删除该调用并完成再次导入。最终 Commandlet 返回 1，仍记录项目 GameFeatureData 规则缺失、8000 端口占用，以及 Interchange 的绑定姿势零时回退提示。导出已清空当前 Action 和骨骼姿态后写出静态绑定；未将仍存在的绑定提示报告为已修复。

必要原生构建完成，模块 `UnrealEditor-FPSGAME-9131803.dll`；记录为 `SourceAssets/M1911Hero20260913/build_native.log`。保存并重启编辑器、重新装备现有 M1911 后使用新资源，空仓可见结构和表面效果由用户测试。
