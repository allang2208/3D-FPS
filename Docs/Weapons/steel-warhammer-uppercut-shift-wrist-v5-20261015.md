# 战锤上挑 V5：左腕旋转修正与整体右下撤出

用户指出 V4 的左腕明显扭曲，且手与武器缺少整体向右下撤出的位移。本次处理左臂旋转分配和整组位移，保留已接入的快速挑击时钟。

## 制作依据与修改

读取现有 V4 骨骼输入时，蓄势 0.4／0.6 秒处，近腕前臂辅助骨与手掌的蒙皮旋转差分别约为 107°／141°，同时左腕骨轴折角约 50°。V4 在随源姿态变化的辅助骨参考上继续叠加 roll，会在中段产生明显不匹配；不能只移动手的位置解决。

- 左臂改用双手剑 `GripRecoveryV15/arm_support.py` 的整臂支撑方法，从固定待机腕臂关系求解肘部弯曲平面和总轴向转角，再沿当前原生蒙皮站点分配前臂旋转。保留双手接触和原生骨长，不拉伸骨段、不新增逐指修形。
- 肘位解算保留连续性和有界运动：240 Hz 作者采样对应每帧最多 5° 的肘平面调整。起止渐入原姿态，源时间 1.05 秒后保留原挑起与收势。
- 将“换成左高右低握姿”与“整组撤出”分开排程并重叠衔接。握姿在 0.42 秒完成；从 0.18–1.00 秒，双手和武器共同右移 **15 cm**、前送 **2 cm**、下沉 **13 cm**。肩带跟随部分位移提供支撑。
- 蓄势末端左腕目标约 `(0.165, 0.400, -0.255)` 米，右腕约 `(0.326, 0.396, -0.535)` 米；左手仍在较高的后握点，两手与武器一同向画面右下边缘撤出。
- 释放从新的整组偏移位置直接接入原正前方挑击，并由烘焙骨架重写 `WarhammerUppercutArc.h`。发力、音效、镜头、前踏与资源提交时钟沿用现有版本；伤害和距离数值不变。

以上为原输入分析与新制作约束，未对新版本进行游戏测试或预览验收。
