# 715 换弹基础力度与右手持枪运动

用户反馈：上一版甩腕仍不明显，换弹中段右手几乎静止。本次直接提高动作的基础姿态和开闭甩动数值，再按装填阶段制作右手跟随、承力和回稳。继续使用已认可的左开弹巢、固定捏弹手型与稳定肘部求解。

## 原因与方案

Split 版 `wrist_motion` 只在开巢、空仓退壳和闭巢时有变化；中间若干秒的装填期间，枪根一直保持约 `(18°, 8°, 7°)` 的固定角度及 `(16, 48, 20) mm` 的固定偏移。因此提高前后两次甩腕仍无法消除中段僵硬。

本次将持枪运动直接烘焙到 `WPN_root`，由右手固定握把关系带动腕、前臂和上臂。每一发按“取弹时调整枪身—对孔时稳住—压入时承力—退手时放松”的顺序运动，空仓按压和速装器另有对应曲线。

## 基础参数

以下为作者关键帧参数，单位是源模型米制坐标／角度，不是屏幕测量值；基础姿态与甩动分量合成。

| 参数 | 上一版 | 本次 |
| --- | --- | --- |
| 装填姿态俯仰／侧倾／偏航 | 18° / 8° / 7° | 30° / 14° / 12° |
| 装填基础位移 XYZ | 16 / 48 / 20 mm | 32 / 70 / 36 mm |
| 开巢主侧摆分量 | +45° | +66° |
| 闭巢主侧摆分量 | -46° | -70° |
| 开巢横移分量 | +47 mm | +80 mm |
| 闭巢横移分量 | -44 mm | -78 mm |
| 开巢／闭巢偏航分量 | +21° / -19° | +32° / -31° |
| 开巢爆发区间 | 0.22–0.30 秒 | 0.22–0.29 秒 |

开闭都补充俯仰、纵向和高度变化，避免只绕枪轴旋转。反向预摆扩大，主摆后有一次制动回弹，最后回到持枪姿态。

## 中段右手配合

- **逐发取弹和回手**：随左手取弹的阶段调整枪身方向，单循环俯仰分量约 -4° 到 +6°，偏航约 -4.5° 到 +5°；纵向位移约 -15 到 +12 mm，高度约 -8 到 +13 mm。相邻几发只做轻微幅度差异，循环端点完全归零。
- **对孔与压入**：接近弹孔前先回稳；入膛时给枪体约 2.8° 的承力俯仰和 8 mm 纵向位移，随后一次回稳。左手、弹药和枪体使用同一个枪根变换，保留沿孔轴推进及入膛后短暂停稳。
- **空仓退壳**：右手配合抬枪翻腕；左手从前方按压时，枪身有小幅承力和回收。仍只在空仓执行按压退壳，非空仓直接补弹。
- **速装器**：取速装器时稍收枪，对孔时把枪身送回，压入释放时承力回稳；不是静止拿枪等待左手操作。
- 采用有明确起止点的平滑关键帧，没有新增运行时随机抖动或持续震荡。右手始终握住原位置，左手仍用 Split 版稳定肘部平面求解。
