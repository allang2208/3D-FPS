# 战锤通用柄尾配重设计

状态：三款外形已完成建模、图标制作及 UE 后台导入，见 [建模接入记录](common-hammer-pommels-build-20261014.md)。首个适配宿主为锻钢战锤 `ue_steel_warhammer` 的 `pommel` 槽。下表保留初始玩法方向，属性以用户最终数值表为准：镂笼追加攻击体力消耗 -10%，双盘调整为攻击体力消耗 -20% 并追加武技冷却时间 -20%。

已按用户要求制作 三款并排设计图（本机文件 `SourceAssets/CommonHammerPommels20261014/ConceptV1/three-pommels-design.png`，不随 Git 发布），包含主体、正面、侧面和底面参考。由内置图像生成工具制作，[提示词](../../SourceAssets/CommonHammerPommels20261014/ConceptV1/prompt.txt) 同目录保存。它是造型参考，真实连接面与尺寸以建模阶段的原装接口数据为准。

## 三款方案

| 名称／稳定设计 ID | 外形与材料 | 建议属性取舍 |
| --- | --- | --- |
| 八棱镇击配重 `octagonal_impact` | 短颈连接饱满的八棱金属坠体，上肩收窄、下腹加厚，底端为宽倒角平底。主体保留锻钢细锤痕，八条棱线略磨亮；端面嵌入一枚齐平的八角锁盖 | 强打方向：提高物理伤害与韧性伤害，以攻击速度下降、攻击体力消耗增加作为代价 |
| 镂笼灵巧配重 `caged_agility` | 紧凑的圆钝笼形尾帽，六根弧肋连接顶部安装圈和底部小圆盘，侧面形成六个纵向贯通窗口。肋条外缘磨亮，内壁为暗色锻钢；底盘中央保留内凹紧固件 | 灵巧方向：提高攻击速度，以物理伤害下降作为代价 |
| 双盘平衡配重 `twin_disc_balance` | 沿柄轴排列两枚厚实圆盘，短圆柱芯把它们刚性连成一体。靠柄端圆盘略小、尾端圆盘略大，两盘之间留清楚的环形凹槽；外围大倒角，表面有浅同心车纹，底面用齐平圆锁盖收束 | 续战方向：降低攻击体力消耗，以韧性伤害下降作为代价 |

以上是游戏属性设计方向，不是从模型质量自动推导的物理模拟结果。最终数值通过直接属性字段接入；武技冷却是常驻倍率，不新增触发技能。

## 造型分工

- 八棱镇击配重突出完整实心体积：侧面是上窄下宽的短坠形，八角端面在小图中仍可辨识。大倒角保持金属厚重感，纹饰仅作浅凹刻。
- 镂笼灵巧配重突出真实负空间：窗口贯穿笼体外壳，能看见背侧肋条；窄连接颈仍为完整封闭结构。六根肋条有实体厚度，窗口边缘圆钝。
- 双盘平衡配重突出横向分节：两枚圆盘分别形成剪影，连接芯完整可见；环形凹槽是两盘之间的结构间距，所有零件固定连接。
- 三款均沿柄轴居中。最大外扩安排在包覆末端以下，连接颈贴合原装轮廓；靠近手掌处保持圆顺，保留双手握点和包覆长度。
- 金属材质沿用宿主锻钢基调，以粗糙度、边缘磨损和形体区分；内部及凹槽略暗。三款不用宝石或发光符文，符文继续由现有独立槽管理。

## 装配依据

- 接口来源：`SourceAssets/SteelWarhammer20261014/ModulesV1/interfaces.json`，`parts.pommel` 的 `tail` 连接面。作者单位为米，柄轴沿 +Z。
- 原装分界位于武器坐标 Z = -0.085 m；配重局部原点沿用该安装面，UE 装配偏移 Z = -8.5 cm。新主体从该面向柄尾方向延伸。
- 建模时复制真实边界环及邻近过渡带，保留其 UV、材质和法线。不能用整件包围盒、估计圆柱或任意插入深度代替连接面。
- 原装包覆与三款通用包覆均保留了下端接口，新配重围绕同一接口制作。轮廓最大尺寸及延伸量在建模时依据原装尾件和手部空间确定，此阶段不编造精确尺寸。
- 原装配重作为 `factory` 选项保留。替换时只替换 `pommel` 实体，不把包覆、金属长柄或其他配件并入配重。
- 通用目录已保存为 `Content/ColdSteelData/common-hammer-pommels.json`。共享设计 ID、名称、属性和图标；其他锤类使用各自真实接口适配后接入。
- 当前剑类共享配重资产及其快速近战属性仍按剑类接口使用。本组三款是锤类柄尾设计，属性范围以后续明确的锤类数值表为准。
