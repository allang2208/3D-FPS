# 近战攻速倍率以本武器原厂间隔为基准（2026-10-27）

本轮修正尼泊尔弯刀在未调整配件时已经达到 `4.00×` 的问题，同时统一共用近战评估的倍率口径。

- 原厂基础间隔取该武器实例的 `attack_seconds`。无角色、装备、改造、强化、精通或临时加速时，显示倍率为 `1.00×`。
- 常规加速乘区仍沿用原公式和 `0.20×–4.00×` 范围，但先相对本武器限幅，再换算动画时钟。基础间隔快慢不再占用加速额度。
- 狂暴、雷光极速仍按原来的限幅后乘区生效，本轮不改变两者的特殊规则。
- `AttackSpeedMultiplier(Item)` 从 `attack_seconds / AttackSeconds` 推导面向玩家的实值，不另存一份倍率。`AttackRate = 1.775 / AttackSeconds` 仅用于现有动画、命中窗口、镜头与位移时钟，不能直接显示为武器攻速倍率。
- 弯刀 `KukriAttackTiming::PlayRate` 只换算播放速度，移除原有 `0.3–3.0` 的重复限幅。客户端和服务器双刀突刺恢复共用此入口。
- 双持两刀分别读取自己的原厂间隔、改造与强化并结算倍率；顺序挥砍按各手速度，双刀同时突刺仍按两个动作时长的平均值确定共用姿态速度。原有左刀收势规则保留。
- 普通攻击与连段使用本轮攻速；武技及重击独立动作时钟保持原有规则。

界面沿用原有能力卡布局：直接加成（如 `攻击速度倍率+15%`）、当前组合实值、相对该槽原厂的差值。攻速实值改用 `AttackSpeedMultiplier`，并附一行原厂基准说明。真正达到限制时，仍显示配件直接加成、实际零差值和受限说明。物品浮窗、改造总览及强化预览的攻击间隔继续读取同一个评估结果，不新增分段派生行。
