# 步枪换弹收尾接入统一腰射位置（2026-09-30）

用户反馈统一腰射构图后，换弹结束会闪回待机位置。本次只修八种步枪／狙击步枪的运行时交接：M4、HK416、QBZ191、M16A2、AKM、A762、ASH-12、SVD。机枪和手枪不进入新分支。

## 修改

此前枪械动作仍使用原工作空间。M4/HK416、AKM/A762、ASH-12、QBZ191 空仓缺少换弹内的展示回位；已有回位分支与姿态混合使用不同的收尾规则。

新增 `Source/FPSGAME/Weapons/RifleReloadHandoff.h`，由 `FPSGAMECharacter.cpp` 在换弹展示和姿态混合中共同使用。位置与旋转沿现有统一腰射标定回收；回收权重按源时钟直接求值，采用起止速度、加速度为零的五次曲线，不再把展示回位留到退出换弹状态后。

两层均在同一个源时间终点归零，但保留不同起点：整组枪与双臂在机械接触后的收势段回位，骨骼仍播放原有回握轨迹，到末段才混入当前握把／弹匣的待机。不能把整段回握提前混向 idle，否则手可能直接穿过弹匣／机匣。待机继续使用原呼吸相位，不冻结到第零帧。

| 枪型 | 普通换弹展示回位起点 | 空仓展示回位起点 | 末段姿态混合窗 |
| --- | --- | --- | --- |
| M4 / HK416 | 源帧 98 / 60 Hz | 标准匣帧 132 / 60 Hz + 0.17 s；弹鼓帧 116 / 60 Hz + 0.17 s | 0.12 s |
| QBZ191 | 源帧 98 / 60 Hz | 源帧 151 / 60 Hz | 0.10 s |
| M16A2 | 源帧 108 / 60 Hz | 源帧 143 / 60 Hz | 0.12 s |
| AKM / A762 | 源帧 278 / 120 Hz | 源帧 362 / 120 Hz | 0.18 s |
| ASH-12 | 1.91 s | 2.65 s | 0.12 s |
| SVD | 结束前 102 / 120 s | 结束前 123 / 120 s | 0.10 s |

这些是本轮制作的运行时窗口，不代表本轮实机测量结果。M16 保留既有起止时段，回位曲线改为平滑起止；SVD 保留已有窗口。AKM/A762 普通回位晚于弹鼓松手段，空仓晚于拉栓闭合；ASH-12 保留作者源的末段姿态交接。源依据为现有 `WeaponReloadStages`、武器头文件和对应作者脚本。

所有时间通过 `ReloadSourceTime` 求值，终点使用 `ReloadSourceTime(WeaponStateDuration)`，不直接假定动画长度等于映射终点。M4/HK416 弹鼓继续使用原非线性播放曲线。换弹速度属性、动作时长、弹药提交、机械音效、拍击和拉栓时序不变。

完成时八枪统一清除旧活动动画、动作权重及展示权重，随后沿原流程恢复按住的 ADS／开火请求。没有改动画资产、手指、蒙皮、机械层级或机枪行为；无需资产导入。
