# 伐木斧 V4：左腕与左臂联动

后续当前版本为 [H4 持握 / 装备与 V5 攻击](axe-h4-pose-family-20260919.md)，继承本版左臂方法并适配左低右高的待机姿态。

用户反馈挥砍时左手腕关节扭曲，同时要求优化左臂。本轮只制作并导入 Swing / HitRecover 动画，保留当前模型、材质、H3 待机、双手握点、右臂和 V3 武器轨迹。前一轮敌人伤害与采集判定不变。

## 制作输入

读取 V3 可编辑源的实际关键姿态，以及 H3 抓握作者源；参考 `two-handed-melee.md`、`pose-contact.md` 与 `casting-arm-volume.md` 中已接受 Manny 完整骨段和肩肘联动的方法。沿用此前 KayKit Slice/Chop 的动作意图，不重新导入参考角色。

`V4/author_inputs.json` 保存旧源姿态读取：右后蓄满时左腕折角约50.15°，肩部保持固定；接触时折角约16.53°。V3 的前臂主骨、辅助骨与手腕采用不同轴向旋转量，折角较小时仍可能出现大的相对扭转。此为作者骨架输入，不是实机蒙皮验收。

## 修改

- 保持 `hand = WPN_root × H3_grip`，不改变手指抓握、柄上位置与方向。
- 左肩朝中立前臂所需的肘位提供支撑，采用连续 tanh 曲线，补偿上限9.5厘米，进出动作通过既有包络归零。上臂与前臂仍按原有两段长度求解。
- 左肘在可行圆上求解，保持向外、向下的姿态偏好，减少跨身体握持时由手腕代偿的折弯。
- 左前臂按掌面和肘腕连线构造完整旋转，辅助骨随所属骨段保留完整 rest-local 变换。上臂从同一前臂框架沿肘部弯曲搬运，逐渐过渡回 H3；左侧不再使用 V3 的分数扭转梯度。
- 右侧沿用 V3 求解。全部目标先求世界矩阵，再按层级还原局部关键帧，统一四元数符号。
- 保持0.48秒接触、75毫秒停帧、撬柄/拔出、空挥1.10秒、命中1.40秒；停帧仍复制完整接触姿态。

作者输出的蓄满附近样本（0.40秒）左腕折角约29.32°，接触样本约6.38°。这些仅用于记录制作参数，不表示外观已经由用户接受。
