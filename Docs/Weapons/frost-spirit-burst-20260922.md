# 寒晶自带侵蚀与精神迸发

寒晶双手剑自带「智力×10%＋精神×10%」附加魔法伤害，移除其普通侵蚀符文改造，新增专属精神迸发，使自带部分翻倍到「智力×20%＋精神×20%」。其他符文剑保留原来的侵蚀改造。

精神迸发初版使用紫晶节点和双重菱形波纹，后按用户反馈调整为冰蓝晶光、圆润波纹、错峰淡入淡出和更低的表面覆盖，制作源见 [冰蓝融合修订](../../SourceAssets/FrostSpiritBlend20260922/README.md)。伤害计算、改造限制、草稿预览、物品说明和旧寒晶侵蚀选项转换一并接入；旧物品在正常加载档案时通过既有存档事务更新。

制作源、数据字段、材质和图标、接入及必要构建记录见 [FrostSpiritBurst20260922](../../SourceAssets/FrostSpiritBurst20260922/README.md)。本轮不运行游戏测试，由用户测试。
