# 战锤旋风 V6：左臂下垂出镜、双倍惯性外甩、下方回握

用户否定 V5 后半段交接，明确要求左手自然放下并退出镜头，右手保持握柄继续外甩，甩过角度翻倍，随后恢复双手持握。本次仅替换旋风动画资产。

## 动作顺序

1. 左手从作者时间 1.00 秒开始松指，1.12 秒离柄。放下时联动肩、肘、前臂，手指随后放松成轻微弯曲，不在镜头内摊掌等待。
2. 1.34 秒到达低位，左腕目标约 `(-0.191, 0.190, -0.668)` 米；低位按原生上臂／前臂长度和待机腕臂关系构造，肘部保持余量。到 1.50 秒间在镜头下方小幅延续下落、回摆。
3. 右手全程保持原手掌到锤柄的矩阵。以作者时间 1.16 秒的外甩起点为基准，朝 1.48 秒顶点的旋转从 **36.1926° 加倍为 72.3852°**，同轴同方向延续；右腕顶点由 `(0.22, 0.50, -0.245)` 调整到 `(0.30, 0.52, -0.25)` 米，由肩肘提供支撑。
4. 右手只有一次外甩和一次回收，顶点带连续回复加速度，避免减速到顶点后出现平坦停顿。位置、旋转曲线按实际播放时钟连接速度及加速度。
5. 左手从 1.50 秒起由下方回到锤柄，接柄前重新张成接握手型；1.72 秒接触，接触后用 0.08 秒逐指合拢，1.82 秒恢复原双手待机。

放手到接触约 0.66 秒实际播放时间。指骨平移、原生骨段长度、骨架、权重与右手抓握均沿用；左臂支撑参考在挥动姿态和自然下垂姿态间衔接，前臂扭转使用既有连续分配方式。以上为制作参数，画面表现与关节外观尚未经用户试玩确认。
