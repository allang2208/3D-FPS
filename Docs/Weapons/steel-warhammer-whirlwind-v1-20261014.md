# 双手战锤旋风：迁移双手剑 V5 / V6 动作

用户要求参考双手剑旋风，尽量复刻。沿用当前剑的实际来源：`Whirlwind20260920/ImpactV5` 主体和 `RecoverV6` 收势，运行参考仍名为 `A_RuneSword_WhirlwindV5`。没有复用已被否定的战锤三连击 V2 / V3 关节解。

## 动画

- 原生主肩、肘、腕和根骨参考坐标一致；以剑的完整 FK 关节姿态迁移整臂、手腕、手指及辅助骨，不重新搜索肘极，不给手腕额外补转，不缩放骨段。
- 旋转主体继承剑的横持、两次连贯送出与制动；收势继承 V6 向外送出、卸力、归位。
- 起始 0.22 作者秒从战锤待机过渡到紧凑握距，左手沿柄收拢；最后 0.28 作者秒回到战锤待机。右手保持锤柄轴向握点，锤子按两掌握点对齐，保留模型原尺寸。骨链运动先确定，武器对齐握点，不反过来强扭手腕追目标。
- 动作源 300 fps、1.82 秒，三阶段为 0.5 / 0.8 / 0.52。运行按当前技能数据分段映射，当前 `spinSeconds` 为 0.8 / 0.75，因此与当前剑共用实际旋转速度，不按旧说明中的 0.8 秒强行提速。
- 镜头两圈由运行时 `turnDegrees`（当前 -720°）驱动，FBX 没有另烘焙旋转，避免双重转圈。

## 接入

装备双手钝器后使用已有“大旋风”快捷栏技能。技能面板、冷却、体力消耗、等级倍率、范围与修炼继续读取同一个 `whirlwind` 数据定义；按实际锤子面板计算技能伤害，快栏不再误提示“需近战”。没有另建技能 ID 或存档字段。

本次添加双手钝器的施放分支，仍不允许斧、镐、铲等采集工具施放。客户端预测动画，服务器验证实际装备、占用与资源，提交一次体力／冷却并独立扫掠、结算、修炼。两圈共用目标去重集合，沿用剑的范围扫掠接口及实心遮挡语义，削韧使用实际战锤快照的钝击类型。眩晕和击退读旋风技能自身数值，不叠加砸地重击的 2 秒眩晕。

动作时钟独立于武器攻速；镜头、武器、角度扫掠及命中停帧共用相位，命中停帧沿用每次 45 ms、总预算 135 ms。技能全程占用近战动作、移动、跳跃和视角输入；退出、取消、切武器及死亡恢复。第三人称发布旋风阶段与转向时钟，继续使用当前工具身体适配。

复用剑的背景旋转模糊材质，前景手、护甲及锤子通过相同模板遮罩保护；仅在材质 shader 就绪时挂载。进入时暂时关闭全屏运动模糊，退出恢复原设置与模板。没有修改皮肤／护甲材质或全局 TSR 设置。

旋风使用现有“钝器挥舞”音效，按两圈相位各触发一次；不调用砸地音或地裂效果。普通三连击 V4、重击、冲刺砸地及已有数值保持原分支。
