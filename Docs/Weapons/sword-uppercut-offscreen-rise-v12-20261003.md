# 上挑 V12：镜头外蓄力、更高更快的上挑

后续用户反馈本版过高且手臂仍扭曲，由 [V13](sword-uppercut-supported-finish-v13-20261003.md) 降低收势、重做肩肘腕支撑，并改为剑尖向上的倾斜收势。本页为 V12 历史制作记录。

2026-10-03。用户要求整个武器和双臂在蓄力阶段移出镜头，扩大上挑幅度、抬高手臂、加快上挑，并接入普通攻击音效。

## 动作与握姿

- 沿用 V11 的待机来源左手、原右手握法和剑面朝向。左手拇指／食指仍靠右手，不新增翻掌、倒握或绕柄滚转。
- 起手 0–0.267 秒，整组双臂和剑向右下收出画面。蓄力及停蓄段 0.267–0.800 秒保持在画面下方，出镜由骨骼整体位移完成，不切换可见性。
- 作者空间向右移动 24 cm；标准柄向下约 56.14 cm，长握柄约 56.69 cm。位移根据原生 V7 裸臂表面及武器骨点包络制定，使用比默认 75° 垂直视野更宽的底边斜率及 10 cm 余量；这属于制作参数，未做实机画面验收。
- 0.800 秒突然出手，主攻击段在 0.875 秒结束，共 0.075 秒；V11 对应为约 0.113 秒。随后的惯性上提在 0.925 秒达到终点，1.000 秒开始收回，1.650 秒恢复待机。
- 在原来的上挑轨迹上增加握剑组最高 20 cm 的上提、5.5 cm 前送和 2.5 cm 左移，形成从镜头外低位到更高终点的较大行程。手和剑成组移动，腕部不单独折弯。
- 高位动作按 V11 各帧的肘弯平面解算双臂，保留骨段长度，前臂旋转按 twist 骨位置分配；只有达到臂展边界时才最小移动臂根。五指局部关键帧保留 V11。
- Blender 编辑源使用完整参考绑定矩阵转换，包含 UE 骨架的 100 倍比例抵消；原生 UE 关键帧保留其现有骨架比例。

## 音效接入

`BeginUppercut` 将已有 `bSwingCuePlayed` 复位，并把当前动作的 `ContactStart` 设为 0.800 秒。独立上挑分支跨过这个时刻时播放一次普通攻击现用的 `AttackLayerSound` 和当前剑的 `SwingSound`：前者音量/音高为 1/1，后者为 0.72/1.1，与原普通挥砍的基础混音相同。

声音和动画共用 `Elapsed`。蓄力期间不播放，提前取消不会延时补响；不经由普通攻击伤害、裂隙、剑气或修炼逻辑。没有新增组件成员或反射属性，复用已加载声音，不在 Tick 中加载资源。技能仍无数值、消耗、修炼或额外冷却。

## 制作、保存与编译

源目录为 `SourceAssets/SwordUppercut20261003/OffscreenRiseV12/`。包含固定的 V11 输入、双版本原生关键帧、可编辑 Blender、实际导出的 FBX、制作与安装脚本、制作记录及旧包备份。

修订号 `OffscreenRiseUppercutV12`。通过现有编辑器 MCP 批次互斥实际保存标准柄、长握柄和预览循环，继续沿用「上挑」技能原有 V1 资产路径。主动画各 1.65 秒，预览循环 2.30 秒。结果见 `install_receipt.json`。

保存前结束了正在运行的 PIE。之后现有编辑器退出，Live Coding 日志显示本次热编译取消，未把桥的返回成功当作编译成功。待进程退出后改用后台常规构建，`FPSGAME Win64 Development` 和 `FPSGAMEEditor Win64 Development` 均成功，正式 Game 产物与 `UnrealEditor-FPSGAME.dll` 已落盘。回执见同目录 `build_receipt.json`，日志为 `build-FPSGAME-20261003-211227.log` 及该回执中列出的 Editor 日志。
