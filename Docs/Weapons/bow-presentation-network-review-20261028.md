# 高地长弓近期表现与联机复查

范围：观峰镜 V4/V5 主摄像机放大与开放外围、全高倍镜战斗 HUD、弓快速近战 V8，以及山鸣／疾律弓弦的现行规则。用户明确要求检查遗漏与联机问题；本轮使用后台构建和隔离 commandlet，不打开 GUI 编辑器或游戏地图，不改玩家实际存档。

## 本轮修复

1. **客机弓近战缺少碰撞反馈。** `ColdSteelSkills::ApplyHit` 在客机转发后返回 0；旧分支仅在本地伤害大于 0 或目标死亡时设置 `ImpactStrength` 并播放撞击音。客机打活怪因此没有新加的停顿、回弹及接触音。现在活体物理接触立即产生本机阻力反馈；伤害、击退、击杀修炼和命中标记仍由服务端确认。挥空不产生碰撞反馈，撞墙保持 0.8 强度。没有新增客户端伤害结算。
2. **远端短暂停顿可能错过采样。** 身体状态原来只将弓播放速度的正负号变化视为可靠事件，正速度变为 0 再恢复仍等周期快照。现在仅 QuickCombat 的停顿／恢复边界触发可靠即时提交，普通拉弓速度变化仍走已有采样。服务端继续按角色、武器实例和有序序列接收，播放速度只用于表现。
