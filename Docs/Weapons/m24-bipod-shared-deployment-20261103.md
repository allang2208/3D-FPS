# M24 脚架与机枪共用架设规则

用户要求核对 M24 与机枪脚架的进入判定和视角越界解除问题。本次仅调整共用脚架组件与对应原生检查，不修改已认可的换弹手型、抓匣轨道或脚架手部动画资产。

## 原因

虽然 M24 已使用 `UWeaponBipodDeploymentComponent`，但存在三组额外规则：

- `FindSupport` 和 `ResolveServerSupport` 对 M24 额外检查腿长／方向和枪身净空，导致机枪可接受的支撑被 M24 拒绝。
- `ApplyPresentation` 在最终姿态无法让双腿够到旧落点时调用 `Release()`。镜头转动、瞄准摆动和净空退让都会改变枪体与固定落点的关系，因此还没失去实际支撑就可能解除架枪。
- `HandlingBlend` 受本地 `bM24PlacementReady` 控制，显示姿态不满足时，架枪加成和开火许可也会失效；服务端没有对应的显示姿态。

## 修复

- M24、PKM、LMG201 共用双脚落点、接触面积、坡度、距离、静态支撑与遮挡判定。实际脚间距仍取各枪自己的几何数据。
- 本地候选和提示补齐与服务端相同的支撑遮挡检查；枪身／镜头的净空扫掠仍保留在显示位置修正中，不再单独否决 M24 的有效支撑。
- 旋转镜头继续由共用 `ClampAim` 限制在部署朝向水平 ±30°、平视俯仰 ±12°。过大的进入俯仰随原部署曲线收回窗口；不增加进入俯仰门槛。
- 位置修正受阻时共用减半退让；仍受阻则不执行该帧平移，保持架枪、移动锁和已确认的加成。
- M24 保留 0.72 秒展开／收起与 0.48 秒源动作采样，以及原有声音、拉栓后收架、先收架再换弹、快速重新瞄准的交接。展开后固定默认下垂姿态，与机枪一致；不再用固定世界落点驱动双腿 IK。
- 移除本地显示就绪标记。加成和开火许可继续取服务器确认、请求序号与部署进度，不因镜头或腿部显示改变。
- 真正的退出条件保留：取消 ADS、支撑移走／消失、人物位移超过 2 cm、武器或配件失效，以及已有动作中断条件。保持只在进入 ADS 时尝试架设，持续按住 ADS 不自动重新吸附。
- M24 安装合法性、展开动作资源和拉栓时序检查仍保留；这些是装备与动作约束，不是更苛刻的支撑范围。
