# 双手战锤三连击（2026-10-14）

用户反馈后的当前节奏和肩部位置修订见 [慢蓄力、快挥出与开口保护](steel-warhammer-rhythm-clearance-20261014.md)。本文件保留三连击基础接入记录。

本次修改 `ue_steel_warhammer` 的普通攻击：第一击从右上向左下斜挥，第二击从左上向右下斜挥，第三击沿用现有过顶下砸。前两击伤害倍率为 1，第三击为 1.25；倍率作用于本次攻击完整伤害面板，在护甲、暴击和目标结算之前应用。没有改变基础伤害公式、攻击距离、攻速或每击体力消耗。

## 操作与时序

- 普通左键依次执行三个阶段。接触点之后可缓存一次下一击，当前收招完成时接续。
- 收招后超过 0.85 秒未继续攻击，下一次回到第一击；装备变化和动作取消也重置连击。
- 原有右下拖锤冲刺持握保留。冲刺后首击进入第一段斜挥，使用现有双手握点约束的姿态交接。
- 原有 1.6 秒挥击、0.82 秒接触及命中停顿/回收节奏继续由物品与攻速控制。新增序列沿用源动画 0.68 秒、接触点 0.24 秒及 0.44 秒恢复片段的采样约定。
- 单机和多人服务器使用同一倍率函数。服务器独立推进阶段、扣体力和结算接触；客户端只预测表现，服务器返回阶段及本次攻击编号，旧攻击回执不覆盖新攻击。
- 第三人称继续消费工具视模的双腕和握点动作样本，并携带斜挥阶段标记。
