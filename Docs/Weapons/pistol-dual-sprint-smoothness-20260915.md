# 双持奔跑流畅度修订：SprintSmoothV5

用户确认 [SprintReferenceV4](pistol-dual-sprint-reference-20260915.md) 的整体方向正确，但双枪摆动有顿挫；场景和转动视角正常。本次按用户明确要求检查并优化双持奔跑，保留 V4 抬枪方向、左右高低与主要摆幅。

## 定位

复现场景为两把手枪处于稳定奔跑，无射击、换弹或施法。预期是连续摆臂；用户观察到周期性的短暂停顿。排查顺序为源曲线、导入采样／压缩、运行相位与播放节点。

- 在 UE 命令行进程读取 V4 的全部 6 条奔跑动画，对原始数据和运行压缩数据分别按 240 Hz 求值，包括导入帧之间的时刻。
- 全部动画为 1 秒、121 个采样点、线性插值；未出现相邻枪口采样完全相同。最大位置压缩误差约 0.00046 cm，循环接缝的位置差异小于 0.001 cm；不支持“导入帧不足或压缩丢帧”的判断。
- V4 `keys()` 对每一个中间关键点都使用零端点斜率的平滑段，导致重复减速再启动。落脚曲线从 0 到最低点只有 0.05 源秒，在项目 700 cm/s、单步 205 cm 的默认奔跑节奏下约为 29 毫秒。
- UE 枪口轨迹的加速度尖峰集中在这些短促下沉段，6 条动画的峰值约 5495–6145 cm/源秒²。源曲线是本次修正的首个异常层。
- 播放节点使用显式时间、线性插值；脚步相位包含 30 Hz 音频更新之间的行进距离。保留现有相位来源与跑停混合，本次没有修改脚步音频或全局帧率设置。

## 修改

- 主摆动采用从 V4 提取的两个低频谐波，保留不对称节奏和原有幅度，去掉中间关键点的强制停顿。循环的函数值、一阶及二阶导数连续。
- 落脚下沉改为宽缓周期曲线，肘部／肩部位移和俯仰震动幅度减半；保留每步一次的节奏。
- 继续让枪、手和前臂成组运动，保持 NaturalAimV3 握点、V4 的右高左低姿态、原骨段长度与迟滞关系。
- 仅 `sprint`／`sprint_empty` 改为加载 SprintSmoothV5；其他动作继续使用 NaturalAimV3。

## 制作与检查入口

- `SourceAssets/PistolDualWield20260914/author_dual.py -- M1911 --sprint-smooth`，715 使用 `DW715`。
- 新参数、可编辑 Blend、FBX：`SourceAssets/PistolDualWield20260914/SprintSmoothV5/`。
- 导入参数：`import_dual.py -DualSprintSmoothUpdate`。
- 只读采样：`SprintSmoothV5/inspect_sprint.py`，用 `-DualSprintRevision=SprintReferenceV4` 或 `-DualSprintRevision=SprintSmoothV5` 选择动作。
- 对比：`SprintSmoothV5/compare_samples.py`。读取两个独立 UE 进程生成的数据，检查采样、循环、握点、骨段长度、摆幅、平均持枪位置和加速度变化。
- 这些诊断工具只在明确执行时运行，不加入正常游戏或默认导入步骤。

## 交付结果

6 条新版奔跑动画及 4 份可编辑源已制作并导入，Editor 原生构建成功。相同 240 Hz 采样下，6 条动画均通过对比检查：

| 指标 | 相对 V4 的结果 |
| --- | --- |
| 枪口加速度峰值 | 降低 86.9%–87.3% |
| 枪口加速度均方根 | 降低 72.7%–73.5% |
| 枪口轨迹均方根幅度 | 保留 96.8%–96.9% |
| 平均枪口位置变化 | 约 2.9–3.2 mm |
| 最大循环位置接缝 | 小于 0.005 mm |
| 最大压缩位置误差 | 小于 0.005 mm |

持续摆动中没有重复枪口采样；握点关系及骨段长度检查通过。上述加速度是同一源时间采样下的骨骼运动指标，不能解读为帧率提升。

数据和结果保存于 `SprintSmoothV5/pose-samples-SprintReferenceV4.json`、`pose-samples-SprintSmoothV5.json`、`comparison.json`。对比脚本退出码为 0。

导出、导入和构建进程均正常完成。新版只读采样脚本执行成功并写入全部数据；该 UE 进程最终退出码为 1，日志唯一错误是用户重新打开编辑器后 HTTP 插件无法绑定本机 8000 端口。该错误未中断姿态采样，未关闭用户编辑器，也未修改插件配置。

本次检查范围是实际 UE 动画资源与相关播放代码；没有运行完整场景性能测试，最终操作手感由用户体验。
