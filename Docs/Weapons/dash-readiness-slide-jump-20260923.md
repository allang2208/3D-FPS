# 冲刺攻击就绪跨滑铲／跳跃保留 · 2026-09-23

用户要求：近战冲刺攻击判定已经就绪后，持续按住左 Shift 的滑铲、跳跃和滑铲跳跃不再中断就绪资格。

- 准备阶段仍要求持近战武器进行有效地面冲刺；未满的准备进度不在滑铲或空中补充，也不改为提前就绪。
- `RuneSwordDashAttack.cpp` 将满进度作为已就绪状态；保持 Shift、有移动速度且角色／武器可用时，滑铲、腾空和滑铲跳跃的待起跳帧保留满进度。落地继续冲刺后可直接发动，不需重新准备。
- `SprintReleased` 立即清除准备进度，包含同帧松开再按下，避免继承上一轮资格；只清准备，不取消正在执行的攻击。
- 停跑、地面停止冲刺、闪避、格挡、施法占用、切换／取消动作等继续沿用原清除条件。攻击成功消耗资格，下次重新准备。
- 就绪提示在滑铲／腾空期间显示“冲刺攻击就绪 · 保持 Shift”，地面冲刺恢复“冲刺攻击就绪 · 左键”。
- 冲刺攻击出招仍限地面冲刺。空中／滑铲按左键沿用原普通轻重攻击入口，不因满准备条而吞掉输入；主动进入其他攻击仍按动作占用规则清除准备。
