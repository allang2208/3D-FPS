# Super90 R8：快速近战右腕与手臂

用户截图指出 R7 的右腕关节与手臂不自然。读取当前安装的原生动作后，在击打后止附近重现了右腕压缩和枪托进入前臂。问题位于作者姿态；当前 Super90 最终支撑节点只处理左臂，不会修正右臂链。

## 修订范围

保留 R7 的“左臂向身体竖直收拢，右手前送枪托”结构、整枪路径、命中时钟和 0.9 秒源长。右手改为围绕后握把进行有限的三维转握，并让五指沿握把表面重新包握；右肘与前臂随后沿新的掌向支撑。修改右侧锁骨、上臂、前臂主骨、肘部辅助骨、两根 twist、手腕及十五根指节，共 22 条轨道。

实际 V7 蒙皮的腕部与拇指根由手掌、拇指和前臂辅助骨共同影响，只改没有蒙皮权重的 lowerarm_r 不足以处理折压。R8 将掌向分配到远端辅助骨与中段，保留上臂和前臂原长，肩部留在身体侧，起手枪托经过上臂时加入有界的下移／后收避让。枪托真实几何的分段表面及实际蒙皮点参与避让，动作参数作连续平滑。

完全固定旧掌向的前三次局部候选导致肘部深折或肩根进入镜头；第四次单轴转握仍有枪托重叠，第五次按时间正向贪心拟合选入了不合适的避让路线，并将手指强迫拉回旧接触点，亦予以否定。最终从击打帧向前后两端延续转握，再单独补起手的肩肘避让。上述候选均未保存到生产，记录保留在作者目录的 Iteration1–5。
