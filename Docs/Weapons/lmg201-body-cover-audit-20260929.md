## 2. 枪身材质：色值局部接近，表面体系仍不统一

### 2.1 确认的主要差异

当前机匣贴图按各部件真实 UV、三角面积加权取样后，机匣、护木、导轨及多数枪管金属区域的底色中位值已经接近：线性 RGB 约 `(0.01096, 0.01444, 0.01764)`，粗糙度中位数约 `0.604`，金属度约 `0.329`。因此不能把全部问题归因为“主枪身各件底色完全不同”，继续统一调暗也缺乏依据。

实际缺口如下：

| 部位 | 当前粗糙度 / 金属度基准 | 表面通道 | 判断 |
| --- | --- | --- | --- |
| 机匣 R36 Receiver | 约 .604 / .329，来自图集取样 | 底色、结构法线、ORM/AO | 目前用作局部采色参照，尚非用户认可的最终涂层 |
| 盖壳 R36 Coat | .604 / .329，纯参数 | **无连接的纹理 Normal、AO** | 中位颜色一致，但细节频率、磨损与遮蔽来源和机匣不同 |
| 护木、枪管、枪口外壳 S32 Surface | 多数金属区域约 .604 / .329 | R29 法线、S32 图集 | 大体色值已接近；与 D35/R36 的法线处理及湿润公式不同 |
| 前端新制钢件 S32 Steel | .56 / .65 | 纯参数，RGB `(.022,.026,.031)` | 底色高于机匣，金属响应更强；容易形成单独的亮块 |
| 原装弹匣 Material21 | 中心 .36 / .74 | 旧颜色混合、旧法线、细纹 | 未跟随本轮主体低反光涂层收敛 |
| 扳机 Material21 | 中心 .31 / .88 | 旧颜色混合、旧法线 | 必须明确是否作为裸露金属保留，不能靠版本遗留决定 |
| 脚架基座 Video26 | 中心 .40 / .82 | 旧图集、细纹 | 与主体涂层差异显著；脚架需要作为同一金属家族处理 |
| 全息等旧配件涂层 | .35 / .78 的配方仍存在 | A762 衍生分支 | 有 201 私有路径，但参数仍是旧亮金属配方 |

表中“中心/基准”是当前节点或实例参数，不等于每个像素的最终粗糙度；裸钢、橡胶、布料、光学件的差异本身可以合理，问题是目前缺少统一的材料身份与覆盖规则。

### 2.2 干燥颜色对齐并没有覆盖湿润状态

- S32 外表面：湿润底色乘 `.87`，粗糙度乘 `.80`，外表面粗糙度下限 `.44`。
- R36 机匣/盖壳：湿润底色乘 `.90`，粗糙度乘 `.85`，下限 `.48`。
- 同样从干燥粗糙度 `.604` 出发，完全湿润后分别约 `.483` 与 `.513`。
- 干湿目录里已有 R36 映射；**映射存在不代表各家族的湿润响应一致**。

这会让本来干燥时较接近的相邻金属表面再次分离。应统一基础涂层及湿润函数，再让聚合物、内腔等通过明确参数保留差异。

### 2.3 当前取样修复的边界

Repair36 把机匣区域的中位色、粗糙度和金属度赋给纯参数盖体，解决的是明显的均值差异。盖体的轮廓、倒角、高光走向、结构法线、AO 和表面微变化没有因此变成同一套来源。

Surface32 曾把金属图区域整体乘 `.42`，使大量主体像素金属度落在约 `.329`；这属于本轮美术调整，不能直接固化为“201 枪钢标准”。后续应先区分涂层、露钢和非金属，再确定反射模型；不能从已经调低的 metallic 图反推原始材料身份。

D35 的 `normals(ob,48)` 会清除指定对象的自定义法线并重建加权法线，作用范围是整个 Receiver/TopCover/前瞄具底座对象，而不是只处理局部平面。机匣仍使用此前烘焙的图集法线，仅局部滤波。这是应受控对比的着色风险，**本轮没有把它判为已证实的全部反光问题根因**。

R29→UE 法线单次绿通道转换的修复已有 R36 回执。本轮直接确认材质图的连接与源文件；未以游戏渲染再次判定凹凸方向。

依据：当前读出的材质图（本机历史资料：`Saved/LMG201Audit20260929/materials_current.json`）、[R36 配方](../../SourceAssets/LMG20120260927/Repair36/materials.py)、[S32 配方](../../SourceAssets/LMG20120260927/Surface32/materials.py)、纹理采样结果（本机历史资料：`Docs/Weapons/lmg201-body-cover-audit-20260929/analysis.json`）。

## 3. 机匣盖：尖刺修复与装配修复是两个问题

### 3.1 现有检查只证明没再出现巨大尖刺

旧 `check_saved_geometry.py` 的主要几何门槛是盖体处于一个宽约 90 mm 的范围、最长边不超过 150 mm，以及布料 UV 有效。它没有测量盖体与机匣之间的边界贴合、开口轮廓、相互穿插或动作扫掠空间。

当前盖体总宽约 73.15 mm、长度约 141.15 mm，但总包围盒不足以决定该缩窄多少。使用实际三角面和平面相交，得到下列示例：

| WPN_root 的 Y 截面 | 盖体横向范围宽 | 同截面机匣范围宽 | 解释 |
| --- | ---: | ---: | --- |
| −220 mm，靠前端铰链区 | 50.69 mm | 67.47 mm | 此处不能随整件再缩窄 |
| −180 mm，中段 | 56.34 mm | 63.52 mm | 外轮廓和内部构件需分别处理 |
| −150 mm，中后段 | 67.03 mm | 50.05 mm | 盖体明显宽于下方主体；右侧突出更大 |
| −100 mm，后端附近 | 65.29 mm | 56.26 mm | 后沿也需独立定义台阶、唇边与接缝 |

这些是包含结构突出部分的截面范围，不是直接可套用的“加工配合宽度”。参考中可能存在供弹侧的非对称外扩；已有左右侧参考不足以决定精确俯视宽度。因此不建议按 `50/67` 整体压缩，也不应强制左右镜像。

当前盖体与机匣截面（本机历史资料：`Docs/Weapons/lmg201-body-cover-audit-20260929/cross_sections.png`）

### 3.2 已确认的表面交叉

当前盖内新增滚轮、导条、回边，与机匣仍保留的封口面存在实际交叉，不是仅靠两个包围盒推断。

- 在 Y=−180 mm 截面，机匣封口约 Z=65.55 mm；盖内圆形构件和侧导向件穿过这个面。
- 在 Y=−150 mm 截面，封口约 Z=68.41 mm；盖内侧回边、导条和圆形构件仍有交叉，右侧构件还穿过机匣侧壁。
- 这些交点来自保存 FBX 的截面线段求交，见图中黑叉；这是静态美术几何干涉证据，不等于游戏物理碰撞测试。

盖内表面与机匣封口交叉（本机历史资料：`Docs/Weapons/lmg201-body-cover-audit-20260929/fit_intersections.png`）

制作链解释得通：R29 从整体模型切出盖体后，对余下机匣保留了反向封口；D35 删除了**盖体自身**的大平板封口，并向内部加厚和加入内构件，却没有同步建立相匹配的机匣开口/侧壁/可见托面。R36 又只修复了失控的内壁偏移。

因此应联动处理两侧接触几何。只在盖下加更多滚轮/方块，或把整个盖体升高，无法闭合这条制作链。某些隐藏相交在游戏资产中可能被有意接受，但本件存在开盖展示，不能直接把这些交叉视作已认可的隐藏处理；实际开盖可见性和运动范围本轮未测试。

依据：截面与交点原始数据（本机历史资料：`Docs/Weapons/lmg201-body-cover-audit-20260929/fit_intersections.json`）、[R29 拆分](../../SourceAssets/LMG20120260927/Refine29/author_parts.py)、[D35 盖内构件](../../SourceAssets/LMG20120260927/Detail35/model.py)、[R36 尖刺检查](../../SourceAssets/LMG20120260927/Repair36/check_saved_geometry.py)。

## 4. 枪口及前端：分清已连续的接口与需要重做的过渡

### 4.1 枪口件与枪管

在接口两侧各取 0.05 mm 的截面，投影至同一横断面并双向采样轮廓，枪口件与枪管的最近距离中位数约 0.047 mm、最大约 0.103 mm。它是离线源轮廓的近接证据，不代表所有内孔、法线和实机外观已合格；但**目前没有依据整体缩放枪口件或整根枪管**。

这一段应先处理同涂层、局部倒角/硬边和纹理尺度，保留有效的现有连接轮廓。

### 4.2 前端导气组件

重建的 GasFrontHardware 和保留的 GasTube 在所取截面有明显不同的轮廓，双向轮廓距离上限约 3.0 / 5.35 mm。台阶、套接和内孔本来就可能具有不同直径，**该数字不能直接叫作 5.35 mm 裂缝**。

该处的建议是围绕真实连接边界重做局部过渡和法线，同时统一 S32 Steel 与主体涂层。已有形状、亮度两方面的差异，应分开处理；不要用一个额外套圈掩盖可能不连续的表面。

### 4.3 护木与前段机匣的适配风险

Install30 对多数部件使用共同的分段高度映射，却为 Handguard 单独设置了高度变换以保住握持外形。对若干原始高度取样，两种变换的差异达约 5–11 mm。

这证明分件原来共用一条切割边，并不保证适配后仍共边；它是明确的重查理由，**不是逐点测得的实际缝宽**。继续制作时应冻结手掌接触区，仅重建护木安装端的过渡，使其与机匣/盖体前端共用边界合同。

依据：前端测量及映射差异（本机历史资料：`Docs/Weapons/lmg201-body-cover-audit-20260929/front_interfaces.json`）、[Install30 适配](../../SourceAssets/LMG20120260927/Install30/author_fit.py)。

## 5. SKILL 审查

现有技能方向大体正确，但此次制作结果没有完整落实，而且 201 的新补充主要在记录最近一次局部故障。

| 文档 | 已有有效要求 | 201 当前不足 / 建议补充 |
| --- | --- | --- |
| `weapon-finish.md` | 同时匹配底色、粗糙度、金属反射、尺度；保留结构法线、AO 和材料身份 | “机匣 UV 中位采样”只能校准均值；补充图集主体与纯参数新件之间的细节密度、干湿响应及覆盖清单 |
| `generated-rifle-refinement.md` | 几何先于材质；新面独立 UV；旧烘焙法线不能随意套新表面 | 增加“修内盖同时审查机匣反向封口”，并区分越界消除、装配贴合和用户认可 |
| `modular-part-interfaces.md` | 按连接边界而非包围盒装配；匹配两端轮廓和斜率 | 201 应记录多个横截面、盖壳内外边界、安装端以及固定/活动件归属 |
| `integration.md` | 几何、法线、材质槽、游戏与预览来源一起维护 | 开头仍有默认战术手套、历史 M4 路径表述；与更上层 V7 裸手规则冲突，不应据此恢复旧手模/资产 |

可复用标准建议补充四点：

1. **同色不等于同材质**：纯参数盖体不得仅凭中位色相同被标记为材质统一。
2. **相邻分件必须有共享边界依据**：分别适配后重新确定接口，不用整体包围盒或历史切割面替代。
3. **可开盖资产要处理双方可见内部**：盖内壁、机匣开口/侧壁/托面共同设计，不能留拆分时的通用大封板再叠内部装饰。
4. **检查强度与完成声明对应**：没有尖刺、绑定正确、已保存、视觉认可分别记录；不把无越界作为宽度贴合通过。

本轮仅审查，未修改个人技能或工程镜像。后续若维护技能，应同时更新两份，并保留用户“默认不额外测试/不打开 UE”的规则。

## 6. 建议的实施顺序

### 第一阶段：冻结当前有效部分，建立这一轮唯一基线

- 以 R36 完整装配和实际保存绑定为起点，在独立候选目录保留可编辑源与恢复路径。
- 冻结 V7 手臂、动画轨道、握持区、枪口/机瞄/光学挂点、弹匣与布袋状态身份。
- 列出本轮有效部件及材料身份：涂层金属、裸露金属、聚合物、内腔、布料、光学。先覆盖主体，再延伸旧部件；不按历史槽名批量涂色。
- 不重新生成整把枪，不回退首轮废案，不为了面数整枪减面或细分。

产物：本轮候选源、实际部件/材质绑定表、需保持的接口列表。

### 第二阶段：局部重建盖体—机匣—护木的接缝

- 以机匣现有外形、参考剪影及手部接触为约束，分别确定前铰链区、中段、供弹侧、后锁合区的截面；不要设置一个全盖统一缩放系数。
- 盖体大平面与折边采用可控的规则拓扑和连续厚度；复杂凹角不继续依赖无界等厚补偿。
- 删除不应保留的旧机匣封板，建立游戏开盖时看得到的内壁、上沿和托面；与盖内构件同步适配。没有参考的内部只完成必要可见层次，不扩成机械机构重建。
- 新内构件遵从盖壳内侧和机匣可见空间，修复本轮确认的交叉；不靠整体抬盖或隐藏全部内部逃避贴合。
- 护木接触区保持，重做其接口过渡。枪口与枪管已连续的轮廓保持，前端导气接头单独处理。
- 保留原 `LMG201_Cover` 枢轴及权重；若仅改盖壳接触几何，先不要联动重做整套换弹。

产物：独立可编辑的主体/盖壳/前端候选，闭合与开盖可见结构的分件关系、UV、法线及原绑定。

### 第三阶段：统一主体涂层及表面层次

- 先完成机匣、机匣盖、前端金属这组三件的共同涂层。当前机匣深灰颜色可作为过渡参照，最终以用户要求的参考观感决定，不把 R36 参数自动升级为认可标准。
- 共用一套 201 私有的基础涂层函数和湿润规则；结构法线、AO、刻字和各件 UV 仍分开保留。
- 盖体和新建接口烘焙自己的倒角/结构法线与 AO；旧件只在法线/拓扑发生变化的范围重烘焙。不可把整张机匣图集直接铺到盖体或接头。
- 微纹按物理尺度统一，强度先克制；用粗糙度变化表达表面，不用强噪声法线伪造金属质感。
- 涂层与裸露金属采用明确遮罩；聚合物、布袋、弹链、镜片、刻字、内腔保留身份。不能把所有区域设成同一个金属度。
- 主体形成稳定配方后，按原装弹匣 → 脚架 → 配件金属外壳的顺序收拢旧配方；扳机/轴销若保留裸钢，必须是有意且一致的材料分区。

产物：统一的 201 材质家族、各部件结构贴图与区域遮罩、同一干湿映射和可重建配方。

### 第四阶段：在后续获授权实施时完整落盘

- 通过后台方式导入候选并保存，显式按槽名绑定；保留游戏原有 section 隐藏合同和机械骨骼身份。
- 同步主体、原厂分件、枪匠/掉落展示、相关配件及湿润目录，避免只更新某一个预览资产。
- 保存新的唯一重导入口及当前材质覆盖表，避免历史脚本重新把旧纯色或旧亮钢绑定回来。
- 本轮是方案，不执行上述替换。后续制作完成后如实交付源码、导出件和已保存资产状态；游戏及最终视觉效果由用户测试。只有用户另外要求时，再按指定范围做中性光照对比、开盖过程与干湿检查。

## 7. 优先级与停止条件

| 优先级 | 工作 | 不应采取的替代办法 |
| --- | --- | --- |
| P0 | 盖内构件与机匣封口交叉；双方可见内部不匹配 | 继续往盖内追加方块/滚轮、整体抬盖 |
| P0 | 盖体分段宽度、供弹侧与后沿接缝 | 整盖按单一百分比缩窄 |
| P1 | 主体图集、纯色新件、前端钢件的表面与干湿统一 | 整枪调暗、金属度统一拉满、增加颗粒噪声 |
| P1 | 护木安装端及前端接头过渡 | 改动已稳定握持区、给所有前端件整体缩放 |
| P2 | 原装弹匣、脚架和改造件余项；更新制作入口与技能 | 把全项目其他武器一起重做 |

**本轮建议停止继续堆叠局部“精修版本”，转为一次范围明确的主体表面与接口整理。** 重建只针对盖体、相邻接缝和确认有问题的前端过渡；已经接近的枪口接口、现用手臂与动作应保留。
