# A762 Refine06 表面精修（2026-10-01）

用户明确优化目标：缩小 Meshy 生成枪械与 AKM／HK416／M4 精修成品的近景质感差距，先做 A762。本轮已通过后台 commandlet 保存 **83 个现有材质实例和 4 张新纹理**；保留 7 个内腔实例及光学特殊材质。不是仅生成清单或导入脚本。

## 本轮落地

- **部件层次**：在既有深色处理金属外观内区分机匣、上盖、枪机、枪管、导轨、瞄具与托架。没有把所有金属统一成同一个粗糙度。
- **干净表面**：以新周期粗糙度纹理替换大尺度斑驳来源，普通金属颗粒强度从 .03 调为 .012，斑驳强度从 .02 调为 .005；降低程序亮边和凹腔对比，保留几何倒角提供的反射。
- **弱微法线**：仅在 11 个原本使用 DefaultNormal 的重建表面实例上增加很弱的金属／聚合物／橡胶微纹。约 .35 UV/cm 的既有 UV0 保留；机匣、枪机、后握把及带结构法线的配件继续使用原法线。新增微纹不代替硬表面几何。
- **握持部件**：护木、后握把、枪托接缝和软垫分别保留聚合物或橡胶响应；程序防滑颗粒收浅，不新增粗大凹坑。
- **弹匣与配件**：原装／加长弹匣和弹鼓统一到同一深色金属外观家族。曲面主板继续关闭容易形成假轮廓的程序亮边和磨损，唇边单独保留轻微高光。配件仍按金属、聚合物和橡胶分别匹配。

以上继续采用项目的深色处理金属外观近似，不作为裸钢、裸铝的实测标准。材质身份与数值边界沿用 [WS1.1](weapon-surface-contract-20261001.md)。

## 与已有成果的关系

保留 V5 的局部网格去噪、真实倒角、曲面细分、就位 AO 和 UV 布局。本轮没有修改网格、蒙皮、动作、转轴、手臂或材质槽绑定，也没有重复全枪平滑。新纹理使用已有采样接口，没有扩展母图。

现有 Clean 配方的 `SourceColorWeight=0`、`SourceRoughnessWeight=0` 继续保留。因此本轮没有处理不会进入最终输出的 Meshy 底色图，也不将去光照归一化描述为已发生的改善。

父实例仍继承 `/Game/Weapons/WeaponSurface/Master/M_WeaponSurface`。原 `WeaponWetness` 自动识别、UV 雨珠尺度和湿润叠加顺序继续沿用；未新增天气表、私有母材质或 C++ 改动。**未进行雨天运行测试。**

前期准备文档中把 A762 弹匣写成“聚合物”不准确；本轮从实际加载的实例读取确认其基线为 `CleanSatinSteel`，按金属身份精修。ASH12 的聚合物弹匣不因此改变。
