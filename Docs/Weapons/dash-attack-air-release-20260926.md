# 冲刺攻击：滑铲跳保留与空中释放（2026-09-26）

按用户要求，已蓄满的冲刺攻击在滑铲、滑铲跳和普通跳跃中保留，可以在空中按左键释放。依然需要按住冲刺键；松开冲刺、切换武器、发动其他动作或落地后停止奔跑，沿用原有取消规则。未蓄满的进度不在空中继续积累，释放消耗一次就绪和一次技能体力，不能在一次跳跃里无限重复施放。

## 接入

- `RuneSwordDashAttack.cpp` 将地面有效奔跑的速度要求放到积累分支。蓄满后的滑铲／跳跃不再因空中减速清零。`PendingLaunchVelocity` 覆盖 `LaunchCharacter` 尚未被移动更新消费的起跳帧。
- `DashReadyFraction()` 同时用于左键入口、持剑姿态和技能释放，移除后两处额外的“必须正在地面冲刺”限制。滑铲中成功释放会结束滑铲；体力不足时不消费就绪或结束滑铲。
- 原 0.25 秒前摇、向前 100 cm 突进、60°扇区、伤害、击退和收势时间继续沿用。空中前摇使用胶囊扫掠推进相同水平距离；碰撞阻挡后停止推进。已起跳的竖直速度由原有动作锁保留，重力和落地由移动组件继续处理。
- 同帧排队中的滑铲跳保留竖直 Launch 速度，清除其水平 Launch 速度，由技能接管水平位移，避免滑铲惯性叠加到技能突进。
- 接触窗口的扇区横向中心仍在首次接触锁定，高度跟随角色升降；每个目标仍只结算一次，伤害不延迟到落地。
- `RuneSwordSprint.cpp` 从同一个就绪结果决定保留高位持剑，不再用第二个水平速度门槛使空中姿态提前退回待机。技能数据说明和技能页文字同步更新。
