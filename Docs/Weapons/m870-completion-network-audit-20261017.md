# M870 完成度与联机检查

用户明确要求检查并修复遗漏和 bug，重点是联机。**已完成三处联机修复，57 项权威逻辑检查与 6 组真实 UDP 主客机检查通过；Editor 和 Game 已有成功构建。** 当前结论不包含手部/配件的视觉验收，也不覆盖弱网压力和完整断线重连场景。

## 已修改的三个问题

1. 客机换 Pawn/重生时，`TickSuper90Recovery()` 没有清理 M870 泵动中断预测；随后回执因 Pawn 身份已经更新而不会再清理。现在新生命同时清除预测和旧 server-ready 集合，等待对应 Pawn 的服务器状态。
2. `ClientSuper90Ammo()` 在改写弹仓、弹药袋和待闭锁状态之前没有检查回执的 `SourcePawn`。旧 Pawn 的延迟回执可能写入新 Pawn。现在必须等来源身份与当前 Pawn 相同才合并；新 Pawn 的回执若早于占有同步抵达，先等待，避免丢掉初始化回执。
3. 旁观端 M870 抛壳定时读取旁观角色的本地射击参数，轻量化扳机安装后可能与实际泵动节奏不同步。现在由已确认的开火多播携带权威泵动速率，远端排队后扣除已过去的网络时间，再安排抛壳。

修复涉及管式霰弹枪共用的弹药回执与开火多播，因此同时保留 SUPER90 的调用兼容。正常玩家存档、手模和动画资产未在本轮改写。
