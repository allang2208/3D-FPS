# 715 金属材质升级

目标：改善现有左轮粗糙、发灰的金属观感，以缎面不锈钢枪身、略抛光弹仓及细加工钢件形成有层次的反射。

制作使用已有高低模与 UV0。减轻旧底色暗斑的参与程度，调整金属反射底色，重做低幅度、定向的加工细纹和粗糙度。源刻字法线与高模几何倒角分开处理，保留刻字、机械接口、凹腔及各类非金属分区。枪身与弹仓保留 4K，新增 BC7 底色/ORM 压缩及对应湿润材质。

作者参数、源资产、可编辑 Blender 工程、12 张贴图和导入入口见 [作者说明](../../SourceAssets/DanWesson715MetalFinish20260914/README.md)。运行网格改为 `/Game/Weapons/DanWesson715/MetalFinish20260914/SK_DW715_Manny`；通过复制现有骨骼网格并更换材质槽接入，沿用已认可的动作、音效、逐发/速装机制和所有骨骼绑定。

按用户规则，本轮只制作、导入及必要构建；未启动游戏、截图、渲染或测试。实际视觉效果由用户测试。
