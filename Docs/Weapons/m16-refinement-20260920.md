# M16 手指、原开火声与配件接口修正

> 当前发布与本机恢复顺序见 [M16 发布记录](m16-publication-20260920.md)。下文保留本阶段制作历史，最终动作来自 M16RemovalMelee，枪托来自 M16RecoveryStocks；用户已确认最新修复成功。

本轮按用户明确要求，仅检查并调整换弹手指、旧项目 M16 枪声、瞄具安装与透明窗口、均衡后握把接口。

## 换弹手指

M16 之前的接触段来自较早的 M4 手型；当前实际 M4 普通弹匣已经使用 `ExtMagContact20260919` 的完整包握修正。本轮沿用这套手指局部旋转，保留指骨长度、缩放与蒙皮，普通/空仓共 10 段覆盖原厂、垂直、倾斜、棱镜和斜握把。战术垂直握把仍复用垂直握把动作。

普通换弹与参考动作的弹匣轨迹不同，因此抓握变换在 M16 自身弹匣空间计算；肩肘沿既有 M4 接触适配方法联动。握持以外的动作沿用原 M16，空仓第 111 帧之后的右手拉机柄、机械轨道与声音时钟保留。普通/空仓时长仍为 2.1 / 2.7 秒，120 Hz 导出。本轮没有替换弹鼓动作。

针对用户报告检查了源模型接触图及 UE RAW/COMPRESSED 指骨姿态。11 个采样时点的最大局部旋转差约 0.036 度，骨段缩放误差小于 0.000004。此读回只说明导入压缩保持了本轮作者姿态，不代替完整实机换弹体验。

## 原版 M16 开火声

用户指定 `D:/FPS3D/资产/音效/M16-fire.mp3`。复制原件并解码为 48 kHz 双声道、0.552 秒 PCM16 WAV，未裁切、调音高、均衡或改节拍。UE 资产为 `/Game/Weapons/M16A2/OriginalAudio20260920/S_M16_OriginalFire`。

`LoadAKMSound` 对 M16 单独加载该文件，普通开火变体库只添加该原声，避免通用 M4 声库在装备时覆盖。现有逐发播放、三连发节奏、尾音并发和独立消音分支保持。声源及散列记录在 `SourceAssets/M16Refinement20260920/Audio/source.json`；该文件为用户指定的原项目素材，本轮仅本地迁移，未推送或再分发。

## 固定提把上的瞄具安装

资料依据：[A.R.M.S. #02 M16 Scope Mount](https://armsmounts.com/shop/mounts/a-r-m-s-02-m16-scope-mount/) 和 [EOTECH mounting documentation](https://www.eotechinc.com/pages/help-center)。固定提把的 M16A1/A2 可使用嵌入提把槽、经中间孔以旋钮固定的专用安装座，上方提供瞄具接口，并保留机械瞄准通道。模型是按本枪几何制作的适配表现，不是厂商安装座的尺寸复刻。

四种瞄具的旧方块连接件替换为连续导轨、沿源提把槽采样的两侧支脚、通视通道、中央螺柱和滚花旋钮。安装座位于提把上，枪型仍是固定提把 M16A2。保持瞄具本体坐标与既有瞄准中心，ADS 自动对齐继续使用原分划几何中心；全息镜局部瞄准点为 `(-0.653782, 0, 5.175324)` 厘米。

## 全息镜窗口与 UV 根因

窗口的两组镜片原先混在 `Holosight` 表面中，本轮将 490 个面分入独立双面透明玻璃材质，外壳与分划分别保留自己的材质。玻璃使用 0.07 透明层不透明度、0.08 粗糙度。

另外发现拼接时的通道错误：Blender 按 UV **名称** 合并，UE 材质按 UV **索引** 读取。新增连接件成为活动对象后，原始 UV 被排到了后面，UV0 中的空值使分划消失，也影响外壳贴图。已恢复本轮五个配件的源 UV0/1/2，并统一所有拼接零件的四通道命名；UV3 留给 M16 表面处理。旧通用制作脚本的导出步骤也修正，防止后续制作重复产生该问题。

`ue_holographic_glass.png` 使用实际导入的 UE 网格和材质，蓝黄背景可透过窗口，红色分划可见。相机沿运行时光轴，800 × 650 图中的红色分划质心约为 `(398.80, 324.67)`，距图像中心约 1.25 像素；这是局部光轴检查，不是完整游戏 ADS 回归。

## 均衡后握把

去掉直接压缩的 M4 颈部和方形搭接块。下部握持外形保留，上部使用原厂 M16 握把与机匣相接的实际轮廓；中间采用连续截面收口，恢复源 UV，避免压缩接口的突兀折线和悬空。

本轮进行了用户指定问题的局部检查与渲染，没有启动完整 PIE 回归，也未试听枪声。完整操作和主观听感交由用户测试。

交付时发现同一工程有两个 Editor 实例，导入桥先后连接过两个节点；最后一次资产导入与最终全息镜截图在同一节点完成，磁盘资源已保存。另一个已加载资源的窗口可能仍保留旧缓存，测试使用的窗口应重开工程后观察。
