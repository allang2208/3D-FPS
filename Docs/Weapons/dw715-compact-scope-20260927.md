- 作者目录：`SourceAssets/DanWesson715CompactScope20260927`。精细机械件使用 Blender 后台建模，未调用图生模型或下载第三方网格。

- 复用现有主相机倍率与屏幕光学层，固定 2×；没有第二次 SceneCapture。镜外区域遮黑，因此不提供“镜外原倍率、镜内放大”的双画面渲染。
- 手枪镜独立采用双粗细十字分划、无测距刻度、无发光点；稳定镜口直径为视口短边 66%，与 LPVO/PSO 的 85% 区分。采用现有薄边镀膜与眼位阴影；不套用步枪镜固定口径的后处理折射。
- 新分支进入同一 `GetScopePresentationAlpha`：镜内射击方向、持枪者模型隐藏/恢复、HUD 隐藏/恢复和镭射淡出共用既有状态。固定倍率不消费 LPVO 滚轮变倍事件。

- 枪匠目录、倍率概览、异步图标资源收集、独立左手附件复制与湿润材质库沿用现有入口。安装/卸载与存档沿用既有选项 ID 事务，无新存档结构。
