# 弯刀普攻／冲刺联机收尾

承接 `kukri-single-dual-audit-20261028.md`，范围为单持、双持弯刀的普通三连击、冲刺下劈的开始、扣费、命中、位移和结束；不在本批重做动画资产。

## 本次修改

- `AColdSteelPlayerState` 新增普通连击／冲刺攻击回执。开始、命中和结束使用同一可靠 actor channel，编号绑定角色、主手、副手、动作阶段及武技训练序号。
- 客机开始动作只预演和检查可用体力，实际消费由服务端计算一次；确认后合并既有 `UppercutStaminaSpent` 累计账本。取消、换武器、角色重生不吞掉已接受的资源确认；重复或旧回执不会重复扣费。单机／监听主机本地继续原本的直接扣费路径。
- 服务端使用当前攻速和原作者快慢曲线计算普攻接触时刻；双刀顺序挥砍分别使用左右刀攻速，双刀突刺用共同时钟；冲刺按独立武技速度计算，不混入普通攻速。
- 每把刀分别记录已命中的目标，允许左右刀各命中一次，拒绝同一刀重复命中、伪造训练序号、提前接触、错装备和过期攻击。双刀冲刺仍是一次合并伤害，副手不能再单独申报第二份。
- 服务端从 CMC 奔跑意图、地面速度与已赚取的准备时间决定冲刺是否可用；滑铲／空中只延续已经完成的准备。
- CMC 累计移动包携带同一次弯刀攻击编号。移动包早于可靠开始请求时等待；已拒绝、取消、换副手或死亡后的编号不恢复授权。双刀突刺按阶段限制累计前踏；冲刺只承接真实水平惯性，不另加固定瞬移。
- 新查出的客机冲刺击退和技能训练遗漏一起修复：由服务端确认命中后施加击退，在攻击完成、取消、断线或换图前结算技能经验。训练资格在伤害前采样，击杀不漏记。没有在客户端重复奖励。
- 双刀突刺击退绑定已确认的第三段攻击，不再依赖前踏的短期 CMC 窗口；前踏结束后仍处于有效接触期的命中能够击退，后续普通挥砍不能借用旧窗口。
- 上轮三个第三人称路由／副手身份／收刀修正继续保留。本次不改变已接入的上挑、旋风、下劈动作文件和镜头方向。
