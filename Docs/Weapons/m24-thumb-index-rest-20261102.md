# M24 换弹拇指沿食指外侧放置：自查与修正（2026-11-02）

用户要求“自己检查一遍”后，已对实际 Kaitlin 原生手模、混合蒙皮虎口、5 发／10 发弹匣和十个运行时 Profile 做离线检查，并修正检查中发现的问题。

## 发现的问题与本次修正

上一版已保存，但把“顺着食指”误解成跟随食指朝弹匣内部弯曲的近节方向，导致抓匣时约 12–14 毫米穿入弹匣。原来的发布成功不能作为动作合格的证据。

本次改为以弹匣外侧表面约束拇指方向，同时保留拇指与食指间距。使用原生关节轴、参考绑定和蒙皮，不强行把拇指根部轴向扭转归零；中末节形成自然伸展，抓匣时沿食指外侧放置。进入抓匣手型延后至手离开护木之后，并对离开护木的短暂过渡增加小幅根部避让。枪械、弹匣轨迹与整体换弹时序不变。

第一轮表面约束候选曾与食指相交，已弃用。正式版本包含食指表面分离约束及实际面片相交检查，不使用骨骼方向代替表面接触判断。

## 实际修改范围

- 十个 Profile 的二十段普通／空仓换弹。
- 仅替换 `thumb_01_l`、`thumb_02_l`、`thumb_03_l` 的旋转曲线。
- 保留掌位、腕臂、其余四指、三个拇指关节的局部位移与缩放、动作时长、弹匣轨迹和其他动作。
- 未改动枪械网格、材质、脚架动作或 C++；无需重新编译 C++。

## 检查结果及边界

使用原生 Kaitlin 几何、权重及现有 JC 修形进行离线蒙皮。先检查十个配置全部普通／空仓换弹的连续帧，再仅对最后调整的离开护木区间加密复查；区间外的拇指曲线逐值比较保持一致。

修改区间共计 3640 个姿态样本，检查拇指及混合虎口对枪身、弹匣的表面接触，以及对食指的实际三角面片相交；最终没有失败样本。关键帧侧面、背面近景和连续预览已查看，未见新增折指或跳变。

起始持枪承接姿态未修改：其原有约 0.193 毫米枪身接触仍保留，不能把本次结果描述为整段动作绝对零接触。检查范围截至源动画第 46 帧（30 fps），此后保持原有动作。

十个正式 Profile 已后台保存，并通过独立 commandlet 重新从磁盘加载，核对内容及散列；仅上述三个拇指轨道变化，每个 Profile 的两段换弹时长均未改变。未打开 UE 图形编辑器，未运行游戏；不代替游戏内第一人称观感验收。
