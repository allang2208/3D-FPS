# 尼泊尔弯刀双挂坠精修 V2

本轮范围：按用户要求检查并升级「百折·连锋坠」与菱形「藏锋·一决坠」。用户随后明确取消的 Azure_Crownblade GLB 未使用。

## 检查结论与制作路线

采用 asset-model-workflow 的精细近景小件 Blender 精确建模路线，以及 ue5-weapon-workflow 的实际挂点、材质、图标和资源接入规则。已确认的叠片和菱形主体保留。

旧版已有实体厚度、真实镂空、有效 UV 与末端动态绑定；主体未发现退化面或非流形连接。它仍有精修空间：扭转扁带式挂绳、较基础的连接座与背面、均匀粗糙度及仅噪声法线，且没有独立倒角高模和距离 LOD。一决坠的两张释放光片有 8 条预期边界边，属于双面特效，不作为破面填补。

## 已制作内容

- 两件保留实际穿柄孔的原安装环；沿已适配的曲线重建下方三股连续绳，外径约 2.42 mm，绳股节距 3 mm。末端进入压接套，吊耳加承力座，保留闭合双环。
- 连锋坠保留十级叠片与逐层亮缝，补充侧边护条、下端铆钉、背面嵌板、三道压片、背脊及沉头铆钉。
- 一决坠保留菱形镂空和烟紫晶核，补充正背面冠形棱盖、背面银边、四向托爪承座与固定销。
- 窄倒角、面积加权法线与明确硬边改善移动高光。独立高模烘焙到游戏网格；金属拉丝、编绳细纹、局部粗糙度和实际 AO 分开制作。
- 每件保留 2048 × 2048 BaseColor、ORM、切线法线三张贴图。ORM 为 R=AO、G=Roughness、B=Metallic；BaseColor 使用 sRGB，ORM/Normal 使用线性数据，UE 法线采用绿色通道翻转。
- 从实际精修网格制作 1024 × 1024 灰阶金属框图标，图标材质只作用于独立图标场景。

以上为源游戏网格三角数。近景增加的几何承担真实绳股、连接件、托座及背面结构；微细表面由贴图承担。使用现有小型 WPO 网格路线，保留非 Nanite 设置。LOD 屏幕尺寸阈值为 1.0 / 0.04 / 0.012，近景使用完整几何。本轮未测量帧率，不由面数推算性能收益。

两件的三档 LOD 均通过本次模型专项检查：退化面、非流形接点、异常开边、退化 UV 三角形及末端绑定错误均为 0。减面后按实际导向深度重新生成离散皮肤索引，避免索引插值导致绳尾脱离。

UV0 为 PBR 图集；UV1 保留连锋的 0～10 分区与一决的 0/1/2/3 分区；UV2 为动态绑定。主体、扣环、压接套及末端绳统一绑定 guide 5，上段沿既有导向柔性过渡。UE 导入后已逐档检查末端 UV2、坐标单位和材质导向常量。

检查画面为 Blender 实际源模型的正面、侧面和背面，保持同一相机与光照；不作为 UE 游戏画面。
