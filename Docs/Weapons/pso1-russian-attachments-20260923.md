# PSO-1 俄系枪械改造件（2026-09-23）

已把现有 SVD 的 PSO-1 制作为可安装／拆卸的枪匠选项 `pso1_4x`。仅 AKM（`ue_akm`）、A762（`ue_a762`）、PKM（`ue_pkm_lowpoly`）开放，目录选项与运行白名单使用同一范围。SVD 继续使用原厂固定 PSO，不增加本改造入口。

后续状态：用户随后要求为 SVD 接入通用改造件，原厂 PSO 已支持被通用瞄具替换并恢复，见 [SVD 通用改造记录](svd-common-attachments-20260923.md)。`pso1_4x` 自身仍只开放给上述三枪。

## 制作与接入

- 三套独立侧座按当前枪械源模型的机匣表面制作，包含贴合垫、桥臂、燕尾接口、止退块及螺栓，保留原 PSO 夹具和锁杆。镜体保持源模型尺寸，未用非等比缩放改变镜筒。
- 每套均挂在 `WPN_root`。PKM 安装位置位于机匣左侧、供弹区和提把之后，不跟随 `PKM_Cover` 开盖；当前制作位置依据源模型静止轮廓，动态间隙仍待用户实机确认。
- AKM 使用当前侧座涂层参考，A762 使用当前上机匣涂层参数与微纹，PKM 使用当前机匣金属贴图区域。新制六张 4096² BaseColor／ORM，保留修复后的源 UV0、完整结构法线、橡胶和镜片身份；新增物理尺度涂层 UV 与内壁保护区域。
- 六个干燥材质对应六个雨天材质，通过私有 `DA_PSO1_WetMaterials` 接入天气映射。光学玻璃不进入雨滴替换表。
- 固定 4×，使用现有 PSO 分划与镜内展示。ADS 标定读取各自网格的 `AimCenter`，并使用附件实际挂接骨骼；不额外修改开镜耗时或其它枪械数值。
- 接入既有枪匠目录、应用／拆卸、枪械预览、物品图标构建与 `gunsmith_parts.optic` 保存通路。旧枪匠系统继续负责选项规范化；本次未修改用户存档。
- 三个选项图标由对应实际模型和涂层制作，1024×1024 透明底、枪口朝左，保存 PNG 和 UE Texture。它们是 UI 生产素材，不是游戏效果验收截图。
- AKM、PKM 的改造概览显示固定机瞄；A762 沿用安装光学瞄具时的机瞄折叠／拆卸恢复逻辑。
