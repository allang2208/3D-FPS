## 本轮修改

| 纹样 | 本轮结构 | 使用刀身 |
| --- | --- | --- |
| Flow 回流套纹 | 纵向拉长的不规则闭环与多圈回流 | 原厂、加长、赤霄、逐风 |
| Twist 雨滴闭环 | 不同大小、角度和圆度的雨滴／玫瑰状同心套纹 | 厚脊、腾云游龙 |
| Feather 羽状回卷 | 围绕纵向中心线成对展开的羽枝与回卷细线 | 轻刃、破锋雁翎 |

- 每个纹区使用不同的中心、形状和尺度，弯曲的交界取代整齐的规则网格；主钢层之间配有较细的次级层纹。
- 三张数据图改为 2048×4096，对应 12×88 cm 纹场，提高细线的采样密度。沿刀身采用种子固定的轻微非线性偏移，使长刀上的重复位置错开；平均 mip 和流送继续使用。
- 提高钢层色差，粗糙度随层纹变化；蚀刻峰谷差约 6.5 微米，保持浅表面。
- 收窄刃缘的纹样衰减区，使图案延伸到靠近刃口的位置；最外缘保留窄亮抛光。
- 继承当前物品 ID 派生的固定种子、8 款刀身弧线、原生装饰遮罩及符文中段布局。C++ 与存档结构不改，本轮只需材质编译和资产保存。
