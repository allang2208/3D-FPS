# Super90 侧倾连续装填

用户要求一次按下换弹后保持枪身侧倾，逐发填满；其他动作接管时停止续填。

旧非空仓流程把每次装填限制为一发，每次完整播放单发换弹并归位，再重新调用换弹入口。新流程只进入一次换弹状态，根据缺弹数和可用备弹确定本轮装填数量；原作者的连续装填轨迹贯穿整轮，最后才收枪。备弹不足时装完可用弹药后收枪。

新增普通换弹 `A_Super90_reload_continuous`：复用原作者连续七发装填的 0–360 帧，枪机全程使用待机的关闭姿态，接原单发动画 60–99 帧的回握，前 12 帧消退接缝差量。使用修复后的原生骨架及 V7 蒙皮，不改网格。空仓仍使用现有 `reload_full`，最后释放枪机。

逐发接触为源时钟 `44/60 + n * 50/60` 秒；收尾从 `1 + (count-1) * 50/60` 映射至源 6 秒。弹药提交使用未跳段的连续时钟，动画与机械音效使用相同的收尾映射，跳过的装填段不增加弹药。普通换弹速率沿用原单发基础时长及已有技能/改造速度；整轮不重复进入待机，也不重复发放每发的完成换弹经验。

射击或新的瞄准按下请求停止续填：当前已开始的一发入座后统一收枪，空仓保留必要的枪机释放。换弹前已按住瞄准不会被误判为新的打断。换枪、施法、近战、翻越、菜单等仍走已有动作接管/中断入口；已提交弹药保留，未入座的子弹不结算。只有待完成的枪机循环沿用原有恢复合同。

运行时改动：`FPSGAMECharacterSuper90.cpp`、`FPSGAMECharacter.cpp`。没有新增反射字段或网络消息，弹药继续通过现有 `ColdSteelStatusModel::ConsumeAmmo` / `CompleteWeaponReloadCycle` 存档事务落盘。

制作源与回执位于 `SourceAssets/Super90ContinuousReload20261007/`。独立作者脚本从当前修复后的 `Super90_Gameplay_Editable.blend` 重建普通连续装填，不覆盖已有动画或蒙皮母版。400 帧 FBX、可编辑 Blend 和 UE 动画资产均已保存；`FPSGAMEEditor` 后台构建成功，日志为 `Saved/BuildEditor/build-20261007-010509.log`。本轮未运行游戏、截图或视觉测试，由用户体验确认。
