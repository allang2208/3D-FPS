# 尼泊尔弯刀：第一人称双臂迁移至第三人称快速近战

## 动作来源

直接读取当前已安装的 `/Game/Weapons/Kukri20261020/Animations/A_Kukri_QuickPommel`，使用其 120 Hz 双臂、双掌和手指曲线。源骨架为 `SK_FrostSword_Arms`，动作长 1 秒，刀把在 `11/30` 秒接触。

先前第三人称 `FullBodyV2` 的 Pommel 是通用全身拳击改编。本次保留其身体与腿部发力作为底层，并对齐当前命中时钟；双臂、双手改用第一人称实际动作：

1. 左拳先向前打出，右手持刀向右上蓄力。
2. 左手张开并向侧面撤回，右手让刀把朝前砸下。
3. 右手回弹、短暂制动、降刀，随后回到当前第三人称待机。

第一人称镜头俯仰、翻滚与 FOV 曲线不属于身体动画，不复制到人物头部或相机。

## 原生骨架适配

Jason、Kaitlin 各自使用当前身体和待机资产。源视模的前向为 -Y，第三人称身体前向为 +Y，采用整体坐标变换，不互换左右手。

- 手腕与肘部位置按肩根和原生臂长适配；原始双手动作时间保持不变。
- 左右掌分别通过各自的掌心骨架坐标映射，保留源掌向与双手配合，避免直接复制不同骨轴的局部四元数。
- 右手保持项目现有 Kukri 握柄和装备挂接；刀把朝前、刀刃朝后的砸击方向来自第一人称源。
- 左手逐帧转移五指，包括握拳、张开、回收，处理原生指节长度和 half-joint 辅助骨。
- 上臂、前臂 twist 辅助骨随原生腕臂链生成；连续处理旋转角分支。
- 起手和结束回到当前待机的整条手臂姿态，右手握刀姿势贯穿动作。

视模中刀刃收向镜头的动作在完整人物上可能接近头部。作者过程使用带余量的头部包络和实际刀具尺寸范围，在固定掌向、固定握柄的条件下求可达的手腕位置，连同肘部一起调整；不单独转刀或掰腕。该包络是制作约束，不是完整头部、头盔、衣物组合的实机碰撞验收。

## 播放与接入

输出两份 `QuickFirstPersonV3/A_Kukri_Pommel_FirstPersonArms`，每份 121 帧、120 Hz、1 秒，分别接入两个角色的 `Kukri.FullBody.Pommel`。

`Contact=11/30`，`Release=Contact+0.12`。这里 Release 是现有第三人称采样器的时间映射锚点，与 `SampleKukriState` 保持相同值，使整段按第一人称作者时钟直接取样；不把源回弹结束的 0.433 秒误用成该锚点而再次拉伸动作。

`NativeSwordGrip` 标记保留原生手臂解算，装备手指层保持右手抓握；左手使用新动画中的张合曲线。现有副手占用规则沿用。

只修改共享配置中 Jason 和 Kaitlin 的两个 Pommel 字段，使用 `Tools/PlayerBody/config_transaction.py`。未修改第一人称、伤害、命中暂停、音效、上挑、旋风和三连击。

## 作者源与交付

`SourceAssets/KukriQuickFirstPerson20261025/` 包含：

- `prepare.py`、`inputs.json`：从当前安装资产提取的源曲线、现有身体和待机边界。
- `author.py`、`*-actions.json`、`authoring.json`：重定向轨道、臂长比例和整臂位置适配记录。
- `save_assets.py`、`run_commandlet.ps1`：经 UE 批次互斥后台保存新动画包。
- `assets-saved.json`、`save_assets-commandlet.json`：实际资产与退出状态。
- `publish.py`、`published.json`、`delivery.json`：按字段本地接入与最终交付记录。

本次没有 C++ 修改，不需要重新编译模块。按用户规则，不启动 UE 编辑器或游戏，不执行运行测试、截图、渲染验收。重新开始游玩后可通过 F6 固定第三人称观察 F 快速近战，观感和穿插由用户体验确认。未提交或推送 Git。
