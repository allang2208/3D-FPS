# QBZ191 近景表面与材质升级

依据 `qbz191-visual-upgrade-plan-20260913.md` 开展本地制作。用户于 2026-09-13 授权继续；没有运行游戏、截图、效果渲染或回归测试。

## 本轮制作

- 从原始源取回分裂法线，按原有绑定变换转入 QBZ 私有骨架空间。源参考集合保留完整原图的直接 PBR 接线。
- 机匣、护木重新整理共面表面，分别制作不同边缘半径和高低模表面；聚合物、弹匣和钢制活动件沿原形体修整。不是从零重建整枪，也没有改为其他枪型。
- 两段顶部导轨重新制作底部截面、槽口和端部，共 31 个冠面齿段，保持原安装高度及原齿段分布。接合处保留分段；没有移动现有改造件挂点补偿几何。
- 原机械瞄具的扩大孔径、准星尖端、独立头部与固定底座继续保留。本轮重新展开 UV、制作外壳与消光内壁的表面贴图，没有再次改变 ADS 孔心与折叠轴。
- 六组新 UV 和材质烘焙：枪体 4096²，聚合物、弹匣、钢件、导轨各 2048²，瞄具 1024²；每组 BaseColor、ORM、Normal，共 18 张图。
- 新颜色与粗糙度来自独立材质节点：枪体、处理钢材、聚合物、弹匣和瞄具分别制作微表面尺度。枪体保留 18%、聚合物保留 12% 的原色彩图贡献；原图里的刻字和纹样并非全部重新手绘。
- 高模保留原结构法线并叠加单独的微表面起伏，再向最终低模重新烘焙；取消上一版运行材质的整图法线衰减和粗糙度统一重映射。
- ORM 的 AO 通道为中性白，粗糙度与金属度为新烘焙通道；本轮没有制作整枪固定接触阴影，以免把活动件的阴影永久画到枪体上。
- Blender 导出 NormalGL，UE 导入时翻转绿色通道一次；Blender 可编辑源继续按 OpenGL 方向显示。低模在烘焙前完成三角化，导出使用相同 UV0、法线与切线。

## 保留的装配与动作

枪体沿现有 `WPN_root`，弹匣、扳机、拉机柄分别保留机械骨骼的刚性绑定。弹匣继续应用 MagazineSeat 的绑定几何修正，并保留独立作者对象。五套抓握族、10 段 MagazineSeat 换弹及其余 Refined 动画继续复用，没有改动补弹或音效时序。

前后瞄具仍使用原铰轴、90° 折叠和原运行过渡机制；本轮仅切换到新表面版本的独立头部资源。

## 作者文件与接入入口

- `SourceAssets/QBZ191Hero20260913/QBZ191_Hero_Editable.blend`：`QBZ_SOURCE_REFERENCE`、`QBZ_HIGH`、`QBZ_LOW`、`QBZ_CAGE`，以及现有骨架、动作。原参考和高模集合默认隐藏，可自行打开编辑。
- 同目录 `build.py`、`prepare.py`、`export_mesh.py`、`import.py`：源输入整理、建模与烘焙、紧凑 FBX 导出、UE 导入脚本。
- 同目录 `Textures`：18 张新烘焙 PNG；`SourceTextures`：原包贴图副本。
- 同目录 `SK_QBZ191_Manny.fbx`、`SM_QBZ191_RearSight.fbx`、`SM_QBZ191_FrontSight.fbx`：引擎导出资产。
- `authoring.json` 和 `textures.json` 是制作清单，不是视觉通过报告。
- 新资源目录：`/Game/Weapons/QBZ191/Hero20260913`；角色加载入口与折叠头部加载入口切换至此目录。原 MagazineSeat 和 Folding 资源保留。
- 未购买或引入新的第三方模型、插件；沿用用户提供 QBZ 素材及现有 Manny 手臂来源。

FBX 将枪体静态零件及钢制活动件合并为一个带各自骨骼权重的网格节点，弹匣和手臂各保留一个节点，避免把上百个作者零件逐一作为骨骼网格节点导入。可编辑 Blend 中仍保持分件。

必要原生构建遇到并行 UI 文件 `ColdSteelProgressNotification.cpp` 使用不存在的 `SOverlay::Slot().Padding_Lambda`。本轮只将该调用改为引擎支持的 `Padding(TAttribute<FMargin>::CreateLambda(...))`，保留同一动态边距表达式。未调整 UI 设计或行为。

## 交付边界

新材质是可编辑节点制作并烘焙的分区表面，仍复用原结构与部分纹样；不称为全枪手绘重制。机匣/护木保留原基本拓扑和轮廓，真正重新构建的主要形体为顶部两段导轨。

模型近景观感、折叠遮挡、弹匣插入和配件抓握效果交由用户测试。本轮不宣称达到宣传图或已与 M4/AKM 的实机效果一致。

## 制作与导入结果

Blender 完成全部六组烘焙和 FBX 导出，保存可编辑源。紧凑导出后的 UE 导入保存了枪体、两只折叠头部、六个材质和十八张贴图，记录为 `import.json` 和 `import-compact.log` 中的 `QBZ_HERO_IMPORT_COMPLETE`。

Commandlet 仍因工程原有 GameFeatureData 配置错误返回 1；骨骼导入也继续提示绑定姿势无效、使用零时姿势回退，未宣称修复这项提示。必要原生构建成功，输出 `UnrealEditor-FPSGAME-913122611.dll`，记录在 `build_native.log`。已有编辑器需要重启才能加载新模块与新资产引用。

这些是制作和接入结果，不是游戏或视觉验收通过记录。
