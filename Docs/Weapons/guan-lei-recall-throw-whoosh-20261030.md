# 贯雷召回复用投出划空声

用户要求旋转飞回时也播放投掷出去的划空声。本轮复用实际投出分支使用的 `WarhammerAudioPaths::Uppercut`（`S_Warhammer_Uppercut`），同样从 0.25 秒开始、原速原调播放；共用偏移常量，未新制或覆盖声音资产。

召回阶段添加独立音频组件，跟随飞行锤子，按实际旋转进度轻微起伏音量。长距离召回在音频结束后接续同一录音，保持一个播放组件，不叠加重复声部；资源异步准备完成较晚时按召回经过时间定位。音频一直保持到实际接锤阶段，随后淡出，actor 结束时停止。

原有金属嗡鸣、用户选定的循环划空录音和独立接锤声保持。投出、旋转、伤害、召回轨迹与接锤动作公式不变；旋转累计圈数抽为共享函数供外观和声音使用。专用服务器不创建音频组件。
