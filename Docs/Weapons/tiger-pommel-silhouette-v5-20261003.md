# 虎啸镇岳配重锤：正侧面轮廓 V5

## 依据与差异

用户要求对照原参考及技能，尽可能还原正面、侧面并实施。原图：`SourceAssets/TangDaoMeshy20261002/TigerPommel20261002/Reference/TigerPommel_Reference.png`；当前起点为 ConnectorV4，另读历史正面、侧面图。历史正面图是上一轮下颌记录，侧面图为 V4；没有新生成验收图。

应用技能：asset-model-workflow 的 ornamental-relief-and-solid-shapes、modular-part-interfaces，以及 ue5-weapon-workflow 的模块化与图标规范。

- 正面：原参考的张口占比更大、双眼更外展，现有大颊壳包着较小的脸口。
- 侧面：原参考的口鼻、下颌前探，后底壳圆厚；V4 整个底壳向中部尖底收束，虎脸更像贴在球面上的一层。
- 冠饰：原图为较高的弧顶、带状红石与渐收层次；V4 冠顶偏矮扁。
- 底图连接环左右重复，与侧视不一致。仍以正、侧视为结构依据，单一后环不变。未显示的背面纹饰由现有设计延续，不能称逐点复刻。

## 实施计划

1. 建立独立 `SilhouetteV5` 源与 UE 网格包，保留 V4 可编辑源和资产。
2. 头壳、虎脸、口腔、牙齿、眼石共用连续坐标变形：横向扩大脸部和张口，放大口腔垂直跨度；后底壳抬起并圆收，下颌向前，不再把整头底部收成一个锥尖。
3. 重新制作加高冠顶：连续旋成穹顶、分层细边与红石带。沿用原纹饰高度源、六组 PBR 和 UV，接口、尾环、接座不参与变形。
4. 后台导出可编辑 Blend、FBX/GLB 与三档 LOD；同步真实模型灰阶改造图标。
5. 通过后台 commandlet 保存新网格和图标，成功后仅切换 `tiger_mountain` 的模型与外观说明。保留所有改造 ID、数值、长握柄 `pommel_offset_cm`、材质路径和其他改造。

## 边界

原图是带透视和局部设计差异的概念图，不能同时精确配准每个像素。此次优先恢复可共同成立的正侧面体积与表情比例，保留现有卷云纹饰语言，不声称花纹逐根相同。

本轮不启动交互 UE、游戏或 PIE，不做自动检查、测试、验收渲染。UI 图标渲染是制作资产。具体制作、导入与引用切换状态随交付记录补充。

## 制作结果

V5 的 Blend、FBX、GLB 和真实模型图标素材已后台生成。三档导出三角数为 803,702 / 417,924 / 176,814，沿用原来的近景浮雕与距离 LOD 路线；本轮没有性能测量，也不宣称这些面数已获用户认可。

下颌采用连续变形，后底壳最多抬起 8 mm、下部向前位移场最大 24 mm，过渡在口鼻之前淡出。眼心间距设计值为 32.6 mm；嘴部扩大时连同唇缘、闭合内壁及牙列一起处理。冠饰在最终坐标重建，基部直径 60 mm，总高度约 26.5 mm。数值为作者配方参数，不是从概念图测得的真实物理规格。

V5 保留原装接口和六组材质身份，单独导入新网格；因此不需要改旋风材质映射或编译原生代码。同步图标使用 V5 真实模型灰阶素材与既有金属框，通过内置 imagegen 合成。提示词已随源目录保存。
