# 唐刀

用户指定的 `Meshy_AI_Dragonforged_Saber_1002040045_texture.glb` 接入为新武器「唐刀」，定义 `ue_tang_dao`。
双手持握，仓库一次性发放，占 2×4 格；沿用三段普通连击、蓄力重击、突刺、格挡、近战技能、
库存实例、快捷栏、强化、仓库、丢弃拾取与存档。

保留原模型的刀身弧度、龙纹、护手与环形柄尾，适配当前 V7 裸手。五个改造栏目使用同一装配目录，
三款刀刃、三款护手、三款握柄及六款共用配重已制作对应模块／转接件。基础公式沿用现有双手近战标准。
原色库存图与新版灰阶金属框改造图一起接入。

必要 Editor 构建成功；16 个模型、三张 PBR 贴图、四种材质和 29 张 UI 贴图均已实际导入并保存。
保存回执和成功导入日志保留在作者目录。源码、配置、可编辑 Blend、原 GLB、导出 FBX 和 PNG 一并落盘。
未主动打开或重启编辑器、启动游玩或进行测试；持握接触、动作表现和完整游戏流程由用户测试。
