# 枪匠配件调参、表述与详情百分比（2026-09-17）

用户要求：1) 二倍镜减慢 5%、1–6 倍镜减慢 10%、大弹鼓减慢 10% 的 ADS 瞄准速度；2) 配件卡片只保留基本描述，所有增减细节移到右侧「配件详情」的详情行旁（例如钛金制退器在开镜耗时后标红色（+15%））；3) 握把（前握把）配件详情此前为空，按同一规则补齐。

## 1 数值调整（`Content/ColdSteelData/gunsmith.json`）

ADS 字段 `ads_percent` 存的是开镜耗时倍率增量（`ADS = 基础 × (1 + Σads_percent)`）；需求按速度口径给出，换算为 `耗时增量 = 1 / 速度倍率 - 1`。

| 配件 | 需求（速度口径） | `ads_percent` 旧 → 新 |
| --- | --- | --- |
| 紧凑型二倍棱镜瞄具 `prism_scope_2x` | 减慢 5% | 无 → `+0.0526316`（耗时 +5.26%） |
| 1–6× 低倍可变瞄准镜 `lpvo_1_6x` | 减慢 10% | 无 → `+0.1111111`（耗时 +11.11%） |
| 大弹鼓 `large_drum` | 减慢 10% | `-0.1304348`（实际加快）→ `+0.1111111` |

大弹鼓原值符号是反的：它让 ADS 变快，与「装填耗时更长」的描述矛盾，本轮一并修正。三条数值在 M4A1 / AKM / QBZ-191 目录项同步（脚本断言各 3 处）。

## 2 表述与详情行

- 卡片描述只保留基本描述；消音器、战术消音器、两种制退器、稳固防滑后握把、两种轻量化扳机等原先手写的百分比已从 `description` 移除。
- 详情行百分比由目录倍率推导，不再手写：乘性项取 `After/Before-1`（换弹、射速、后坐力、稳定性、抖动、腰射散布、射程、子弹速度）；ADS 行直接显示 `ads_percent`，也就是**开镜耗时**口径——`-` 表示更快（绿色增益），`+` 表示更慢（红色减益），与用户书写符号一致。这是 2026-09-13 稳定性复核中「卡片与详情应来自同一计算来源」的收口。
- 口径统一时把历史上「先算速度再取倒数」写进数据的四个配件归一成整数百分比，使其显示值与既有描述一致：钛金制退器 `0.17647→0.15`、战术消音器 `0.05263→0.05`、幻影后握把 `0.17647→0.15`、稳固防滑后握 `0.11111→0.10`。效果方向不变，惩罚略微收窄（原值比描述多 1–3 个百分点）。
- 实现位置：`Source/FPSGAME/UI/M4GunsmithSelectedDetails.cpp::RefreshSelectedOption`，`AddValue` 增加百分位参数，标签行渲染为「名称（+15%）」，颜色与详情差值一致。
- 口径提示：制动器数据是耗时 +10%，按速度口径显示（+9%）；骨架枪托与轻型短枪管（耗时 -20%）显示（-25%）；可调节伸缩枪托（耗时 -5%）显示（-5%）。若要统一成耗时口径，把 `AimSpeed` 换成 `Ratio` 即可。

## 3.5 步枪基础调参（2026-09-17 同日）

用户指定：有效射程 M4 = 70 m、191 = 85 m、AKM = 100 m；射击间隔 M4 = 80 ms（当日追加，初版为不变）、191 = 90 ms、AKM = 100 ms。这里按三把步枪理解（M4A1 / QBZ-191 / AKM），改的是 `base`：

| 武器 | 有效射程 | 射击间隔 | 改动 |
| --- | --- | --- | --- |
| `ue_m4a1` | 1000 → **70 m** | 120 → **80 ms** | 射程下调，射速提升到 750 发/分 |
| `ue_qbz191` | 1000 → **85 m** | 85.7 → **90 ms** | 射程下调，射速略降 |
| `ue_akm` | 1000 → **100 m** | 120 → **100 ms** | 射程下调，射速提升 |

有效射程是全伤害距离；超出后按 `WeaponDamageFalloff` 线性衰减，到 2 倍射程时为 10%（M4 140 m、191 170 m、AKM 200 m）。命中距离上限仍由 `TraceDistance`（默认 1000 m）控制，所以更远处仍能命中，只是伤害衰减。射击间隔同时影响连发节奏、后坐力图案的跨发间隔和 ADS 抖动恢复窗口（后者按 `FireInterval` 比例计算）。
