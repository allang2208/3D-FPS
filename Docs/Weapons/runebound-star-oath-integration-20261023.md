# 符文战锤 · 星誓封界之砧接入

用户于 2026-10-23 确定最终机制：苏醒期间每 3 次有效攻击触发 2.5m 范围爆震，基础伤害为 200% 魔法攻击力；破坏符文变红并使爆震伤害翻倍；迅捷符文保留 5 次苏醒及 +10% 攻速；本锤头常驻提升 10% 物理攻击力、10% 魔法攻击力。

制作源与回执位于 `SourceAssets/RuneboundWarhammer20261022/StarOathIntegrationV1/`。模型复用上一阶段本地精确建模成果，以新静态网格、四材质和三张 4K 贴图独立保存，不改写原装锤头和中央锤座。新模型配置复用双手锤已有第一/第三人称、改造预览、世界装配及实例恢复路径，动画文件未改动。

物攻、魔攻提升作用于当前装备实例的角色派生属性，爆震直接读取该次当前魔攻，不重复应用这两项加成。改造详情和总览按安装/草稿组合显示两项攻击力；物品浮窗展示改造的具名机制。

有效接触沿用服务器攻击序号去重，击中多个敌人不直接跳满层数。爆震独立延迟结算，使用统一魔法防御和目标状态公式，排除友方，兼容 `MagicOcclusion` 的实体墙/楼板及镂空遮挡规则。爆震不会反过来触发新的苏醒充能、爆震计数、近战修炼或附魔。

表现通过原有粒子池扩展：核心闪光、扩散光环、猛烈喷射光丝、碎屑与缓慢漂浮微粒；破坏符文切为红色。单个组件固定四组爆发容量，避免每次命中创建临时粒子组件。
