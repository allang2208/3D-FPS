# Super90 快速装填 R17：反手拉栓手型

用户反馈推完后的反手拉栓手势不对，并明确“手臂没问题，主要是手部”。本轮从 R16 继续，只修改拉栓窗口内左手五指的 15 条旋转轨道；腕部朝向、腕点、肩肘及辅助骨、右手、枪体、装填器、时长和所有声音／镜头／弹药时钟保留。

## 手型来源与改动

- 参考仍为用户录制的 `C:/Users/allan/Videos/NVIDIA/Delta Force/Delta Force 2026.10.09 - 09.55.46.01.mp4`，对照既有 60 Hz 拆帧 293、298、302、308。
- 旧 `HOOK` 由张掌与装填器推动杆握法混合得到，拉栓阶段仍沿用推动杆的卷指形状。本轮改为食指主勾、中指辅助弯曲、无名指及小指轻屈、拇指张开的手型。
- 屈曲轴取本枪 V7 实际蒙皮及关节关系，食指按真实拉机柄外侧几何制作接触；没有用统一 Euler 轴硬套五指，也没有缩放骨骼或修改蒙皮。腕部旋转、位置不是制作变量。
- 在原绕行段逐步形成勾指，原后拉段保持；枪机复进前先展开手指，再接回 R16 原回握。推进及甩脱前段不变。
- 普通换弹来源的闭锁与这段左手反手勾拉不同，因此没有直接替换成普通换弹整段动作。
