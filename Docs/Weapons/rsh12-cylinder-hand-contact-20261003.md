# RSH-12 弹巢分离与逐发装填接触修订

后续五发快速装填器在保留本版逐发接触的基础上另行制作，见 [五发快速装填器](rsh12-speedloader-five-20261003.md)。

用户反馈当前 715 动作版本的弹巢分离和单发装填与手部接触仍不正确。本轮针对部件运动和持弹／入座接触制作，不改双动设计、开巢镜头抖动或换弹玩法时钟。

## 制作改动

原 `Native71520261003` 制作源将吊臂轴心设为 `(6,10,35) mm`，而模型 `4_l` 下端圆形铰链的拟合轴心为约 `(13.180,16.876,20.219) mm`。本轮采用真实铰链，沿枪体自身膛轴方向旋转吊臂，保留 715 的开巢角度时序。弹巢、后退壳盘和前退壳杆沿该层级共同运动；固定枪框不跟随开巢。新轴心同时用于逆绑定几何和动作差量，避免只改动画而不改绑定。

原脚本还将子弹的完整位移投影到膛孔轴，并在改过的弹巢父坐标中混合旧局部位置。这样会丢掉取弹中的横向移动，且不能保持子弹与原手势的关系。本轮保留完整三维位移，单持逐发装填进一步使用实际手部接触约束：

1. 从原生 V7 手模读取拇指、食指靠近弹壳的表面点，保存其全部骨骼混合权重；每帧按当前 715 姿态计算这些点的位置。
2. 取弹／持弹时，根据两处指腹与弹壳半径确定子弹轴心，使用原生子弹朝向，不把两指中点直接当作弹壳中心。
3. 每颗弹独立对准 RSH 的五个真实孔位，在原生装填步的接近段转入同轴压入；手和子弹使用同一刚体修正，避免子弹单独滑离手指。
4. 只在接触窗口调整装填侧手腕及原生固定骨长手臂，保留指骨局部手型和持枪侧动作。入座后子弹留在弹巢，装填手沿原动作抽离并淡出局部修正。

吊臂及完整子弹运动修订覆盖单持和左右双持网格／profile。指腹接触修订用于单持的装填手；左右双持原生网格没有另一只装填手，不增加第三只手或将其描述成同样的双手持弹流程。

## 制作与接入入口

制作目录为 `SourceAssets/RSH12ContactRepair20261003`：

- `mechanical_contract.json`：源模型铰链轴心。
- `prepare_contacts.py`、`single_contacts.json`：实际蒙皮接触输入。
- `contact_motion.py`：持弹、对孔、压入和离手修正。
- `author_contact.py`：三套 FBX、可编辑 Blend、机械及接触 profile 的完整制作入口。
- `import_assets.py`：通过已有编辑器桥保存到当前 `/Game/Weapons/RSH12/Native71520261003`，不改变 C++ 资源路径。
- `BeforeSource`、`BeforeAssets`：此次制作前的相关源和六份资产备份。

后台 commandlet 已实际导入并保存三网格、三 profile，共六个资产。`import_receipt.json` 记录 `revision=native-715-contact-v2`、`complete=true` 及完整保存路径；交付记录见 `delivery.json`。编辑器在接入前已自行退出，本轮没有主动打开或关闭编辑器。没有运行代码修改，无需编译 DLL。

未运行游戏、截图、试听或验收渲染。上述数字和接触点是制作输入，不是游戏视觉验收结果。
