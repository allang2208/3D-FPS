# M16 拔匣手指与快速近战整臂修正

> 当前发布与本机恢复顺序见 [M16 发布记录](m16-publication-20260920.md)。下文保留本阶段制作历史，最终动作来自 M16RemovalMelee，枪托来自 M16RecoveryStocks；用户已确认最新修复成功。

用户反馈拔下弹匣时手指仍扭曲，快速近战手臂扭曲，并要求参考其他枪械。此次接续 `m16-m4-insert-20260920.md`，保留其已修改的插匣和原有空仓拉机柄阶段。

## 来源与问题

当前运行资产的导入源已通过现有互斥桥读取，记录在 `SourceAssets/M16RemovalMelee20260920/runtime_sources.json`。

- 当前 M4 普通／空仓换弹来源为 `ExtMagContact20260919`。上一轮 M16 只在普通第 30–43 帧、空仓第 21–35 帧切换到该来源，前面的离握／拔匣阶段仍带着旧 M16 曲线。
- 当前 M4 快速近战为 `M4QuickMeleeRefine20260919N` 的六个握持版本；QBZ191 为 `QBZ191QuickMeleeGrip20260919O`。两者都是 0.9 秒，命中时刻 1/6 秒。
- 原 M16 基础快速近战经过 `shift_arm` 调整左臂后，将扭转辅助骨重置到父骨 rest 关系。配件版本又把整条左臂作为枪根局部的固定持握姿态使用。查看源模型时，直立握把的左肩随枪转到机匣上方，左臂横过枪体；这不能只靠单独旋转手腕或手指修复。

## 修正内容

### 拔匣阶段

- 用当前 M4 普通／空仓的完整动画头段替换旧来源，包含指骨、腕、大小臂及扭转辅助骨，以及同一动作的枪体和弹匣轨迹。
- 第 0–10 帧从各版本原持握进入 M4 的释放动作。使用完整局部骨链混合，不平移指骨，不重新生成手型。
- 保留上一轮 M16 弹匣装配基准。普通第 43 帧起、空仓第 35 帧起直接沿用上一轮源姿态，因此插匣、坐实、回握和空仓拉机柄段均不重新设计。
- 更新基础、直立、斜握把、棱镜阻手器、倾斜握把的普通／空仓动作，共十条；弹鼓换弹没有改动。

### 快速近战

- 分别采用 M4 N 的 Base、Drum、Angled、Vertical、Canted、Prism 完整动作，而不是将一个通用左臂姿态锁在枪体上。
- 每个版本先从 M16 对应 idle 读取实际握点，再对该版本的 M4 整条手臂做刚体适配。读取结果为：四种前握把只需约 2.443 mm 高度平移，基础护木约前后 12.000 mm／高度 10.852 mm，弹鼓约前后 -17.621 mm／高度 8.062 mm；这些版本的握点朝向差均为 0°。没有必要额外重求手指或另造一条 IK 挥击。
- 肩、肘、前臂、腕和辅助骨一起沿用同版 M4 的运动，保留完整骨段的蒙皮关系。右手同样采用对应 M4 N 版本。
- 机械部件按 M16 自身 idle 装配关系随枪运动。前 4 帧和最后 10 帧衔接该版本原有起止姿态，保留 0.9 秒时长和既有命中时钟。
- 共六条近战动画，含弹鼓持握和四种前握把。
