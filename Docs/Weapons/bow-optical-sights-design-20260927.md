## 清野二倍镜

- ID：`bow_clearfield_2x`；槽位：`sight`；固定倍率：2×。
- 定位：轻巧、快速辨认中距离目标，适合边移动边寻找射击机会。
- 外形：薄圆框夹持一片玻璃，镜框后方完全开放；轻巧弧形侧臂从原瞄具安装面伸出。深色木质底座搭配哑光黑钢镜框和侧臂，边缘少量暗黄铜压圈，保持手工猎弓风格。
- 初始建模规格：外径约 4.5 cm、镜框轴向厚度约 3–4 mm；玻璃可带轻微曲率。不设置镜腔、后筒或第二片镜片。制作时按实际安装面与手／箭扫掠调整，不能通过缩放整弓适配。
- 镜片：单片玻璃中心通透，边缘浅青灰镀膜与克制的掠射高光；保留真实边缘厚度和窄压圈。腰射及三维改造预览能看到实际玻璃，镜面不涂成不透明色块。
- 分划：细十字与小中心点；准心周围留白，不用粗竖杆挡住目标。
- 确定功能：真实 2× 视野放大。
- 已配置代价：开镜耗时 +10%，`ads_mult: 1.10`。其他基础数值不变。
- 卡片描述：薄框单片玻璃装在弧形侧臂上，镜内采用细十字和小中心点，便于辨认中距离目标。

## 远望四倍镜

- ID：`bow_farwatch_4x`；槽位：`sight`；固定倍率：4×。
- 定位：更细致地观察、瞄准远处目标，以较慢的举弓开镜换取放大能力。
- 外形：同样为薄圆框夹持单片玻璃，镜框后方完全开放；沿用同一木座和弧形侧臂语言，可在侧臂增加浅加强筋。通过镜片曲率、分划和细节区分两款，不以镜筒长度区分倍率。
- 初始建模规格：外径约 4.8 cm、镜框轴向厚度约 3–4 mm；单片玻璃可比二倍款稍凸。保留弓的长目距和原箭道，取消原设计的 5.8 cm 镜筒、遮光筒、目镜筒及前后双片结构。
- 镜片：单片玻璃中心保持清晰，边缘有弱灰紫镀膜反光；玻璃与薄框分别成件和分材质。避免整片染色、强烈眩光或厚边框占据镜内视野。
- 分划：细十字，下方附两枚无距离标注的落点参考刻线；作为瞄准参照，不宣称自动测距或适用于所有箭种、拉距及子弹速度的固定米数补偿。
- 确定功能：真实 4× 视野放大。
- 已配置代价：开镜耗时 +25%，`ads_mult: 1.25`。其他基础数值不变。
- 卡片描述：薄框单片玻璃配细十字与下方参考刻线，便于观察远处目标，举弓开镜稍慢。

## 数值与用途

| 项目 | 清野二倍镜 | 远望四倍镜 |
| --- | ---: | ---: |
| 固定放大倍率 | 2× | 4× |
| 开镜耗时 | +10% | +25% |
| 当前 0.30 s 基准下的入镜耗时 | 0.330 s | 0.375 s |
| 伤害、子弹速度、射程、搭箭与拉满 | 不变 | 不变 |
| 瞄准晃动／腰射扩散／满弓保持 | 不变 | 不变 |

上述耗时为设计计算。当前 `ads_mult` 同时作用于弓的入镜和退镜时钟，采用该字段时沿用这一口径，不宣称只修改入镜。倍率提高会让已有角度晃动在屏幕上更明显，但不额外叠加晃动数值。

满 ADS 随机散布当前已经为零；光学瞄具提供放大与观察收益，不另加“满瞄准精度”百分比。4× 不改变弓本身的飞行上限、重力或伤害衰减。

## 玻璃与真实倍率表现

1. 未开镜时显示单片玻璃、薄框、窄压圈和固定座；玻璃、分划和框架分别建模、分材质槽。每款只有一片实体玻璃，放大由弓相机视野计算实现。
2. 用户要求参照现有枪械 `prism_scope_2x` 的实体瞄具表现。两款均保留弓、手臂、实体镜框和周围视野，主相机按各自倍率平滑放大；不进入全屏圆形高倍镜模式，不设置 85% 屏幕镜口或黑色遮罩。
3. 使用已制作的单片玻璃和跟随镜片 UV 的抗锯齿分划。用户反馈原细线看不清后，分划调整为低亮度绿芯、窄暗边、约 3.6 渲染像素中心点及最小 1.15 渲染像素线宽，长刻线向镜框逐渐减光；通过 EyeAdaptationInverse 稳定亮芯。原亚像素刻线几何由材质隐藏，三份实际材质已保存。玻璃透明度与 Fresnel 掠射反光保留。后续拖影修订为分划区域增加深度／速度输出和局部 Temporal Responsiveness，保留 After DOF 与深度测试，透明区域不覆盖背景运动信息；两份玻璃材质已后台保存，见源目录 `ReticleReadability/TemporalStability/`。高倍镜屏幕分划、镜筒后处理及枪口闪光、积尘图层不参与弓 ADS。像素值为着色器设计值，未做实机测量或拖影验收。
4. 以原装弓的满 ADS 视野为统一 1× 基准，按 `FOV(M)=2*atan(tan(FOV(1)/2)/M)` 计算同一轴向的目标视野。不能直接把 FOV 乘 0.5／0.25 充当真实 2×／4×，也不能在弓与角色两处重复应用倍率。
5. 主相机方案不提供“镜外仍然是 1×、只有镜片内放大”的画中画效果。当前需求未指定画中画，因此不新增第二次场景捕获；若后续明确需要，则另行设计镜内捕获与性能预算。
6. 弓 ADS 保留游戏 HUD 与实体视模，箭、弦、手臂照常显示和运动。角色 `GetScopePresentationAlpha()` 对所有已装备弓返回 0，独立的弓倍率计算继续生效；也避免继承上一把枪的高倍镜模式。
7. 两款固定倍率，不增加滚轮变倍。瞄准灵敏度跟随实际显示倍率；过渡沿用弓当前平滑权重，倍率、视模与分划不要各自使用不一致的进度。
8. 镜内中心分划与弓现有射击方向共用相机瞄准基准；箭仍有真实重力和飞行时间。4× 参考刻线不能直接冒充弹道解算器。
