# A762 大弹鼓供弹塔与弹仓衔接修复（2026-09-25）

用户问"A762 大弹鼓跟弹仓衔接的部分扭曲了，是当时处理模型没做好还是有意这么设计的"，随后确认要重做供弹塔。本轮先量后写，确认是**有意做的套壳处理、但不是设计造型**，再按目标枪自己的弹匣外包络重建塔身并重导。未启动游戏、未跑 PIE，观感由用户实机判读。

## 结论

扭曲来自供弹塔上段的一次**仿射重映射**：A762 大弹鼓直接沿用 AKM 大弹鼓（供体 `SM_AKM_LargeDrum_Upgrade`），接 A762 弹匣井时把塔身 z=45→75 mm 用 smoothstep 渐变映射到井口（`Accessories05/author_geometry.py` 第 63–70 行）。后果：

- 中心线是 S 形，渐变带出现**折角/棱线**（用户看到的扭曲）；
- 截面被压小：前后 −13%、左右 −10%（供体恒为 67.1 / 21.9 mm），而 A762 弹匣在该高度是 72–75 mm 深——**既折角又塞不满井口**。

## 重建做法

1. **塔身 z<45 mm 与鼓体完全不动**（连续、且是换弹动画握持区）。
2. z≥45 mm 按**线性**（不是 smoothstep）渐变到目标截面，得到一根**直的斜棱柱**：没有 S 形折角，首末位置与出货件一致。
3. **目标截面取 A762 原厂弹匣的逐高度外包络 +1.5 mm**（它本来就通过弹匣井），不再手拍缩放系数；包络按 ±6 mm 窗口平滑以滤掉弹口/加强筋噪声。
4. **前表面钳制**：塔身不得比当前出货件更靠前（出货件的机匣净空已验证），重建只向后延伸填满井口。
5. 材质槽沿用出货命名 `A762_drum_0/1/2`，导入后按槽名回绑原材质。

重建后：z=60 中心 33.4、前后 62.7（出货 40.2 / 62.2，供体 19.6 / 67.1），前后表面位置与出货件同侧且不更靠前；装配净空 z 55–65 最深 **−1.64 mm**（与出货件相同，不引入新穿透），z 75–90 −0.18 mm（出货 −2.59 mm，转好）。

## 未覆盖与风险

- 未启动游戏、未跑 PIE、未做真机截图；塔身在井口内的实际观感由用户确认。
