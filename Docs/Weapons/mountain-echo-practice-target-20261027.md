# 山鸣弓弦训练靶判定修正

## 用户现象与原因

用户在主神空间训练靶上测试，满弓且已满足穿心箭条件，命中后弦鸣印记不亮；对怪物命中则正常。`ABowArrow::ApplyHit` 原先要求目标具有存活的怪物/生命组件，且通过怪物敌对筛选。`AFPSPracticeTarget` 只接收点伤害/径向伤害事件，没有这些组件，因此在进入 `ConfirmHit` 前被排除。满弓时间门槛不是本次故障原因。

## 修改

- `BowArrow.cpp` 在山鸣的命中资格中显式接纳可受伤且未销毁的 `AFPSPracticeTarget`（含派生类）。使用实际类型，不以普通可破坏物、墙壁或场景标签代替训练靶。
- 靶子命中沿用同一个权威叠层入口，每支满弓箭最多一层，仍为三层上限、十秒刷新及下一次满弓释放回响。
- 同一资格也允许原箭在训练靶上记录物理伤害与暴击结果，供弦影箭继承。弦影箭自身不叠层。
- 怪物资格、友方筛选、穿心箭门槛及目标穿透数量沿用现有逻辑；不修改主神空间场景或靶子资产。
