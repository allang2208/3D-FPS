# 全武器动作复用与姿态差量（2026-10-01）

本轮将 SVD 的「基础动作＋稀疏姿态差量」接入扩展到其他枪械及双手剑。只处理现有变体的重复完整动画；各武器的攻击、机构、声音、补弹和命中时钟继续由现有状态机负责。

## 覆盖范围

| 武器 | 本轮整合内容 |
| --- | --- |
| M4、HK416、AKM、QBZ191、ASH12、M16A2、A762、PKM、201 | angled、vertical、canted、prism 四个握把家族；适用的装备、换弹、冲刺、检视和枪托近战；M4／HK416／M16 的独立弹鼓托握姿态 |
| SVD | 沿用上一轮已保存的四份配置和最新换弹肘部修订，接入名称改为通用接口 |
| M1911、G18、DW715 | 双持左右手的 fitted／long 配件近战差量；保留左右手职责、空仓分支和转枪恢复；单持机械动作与逐发装填组合仍独立 |
| 双手剑系列 | 已有系列共用 Azure 基础动作；长握柄的 19 个动作改用基础动作＋原作者差量，覆盖攻击、格挡、冲刺、近战与收势 |
| 法杖、弓、斧、矿镐及工具改造 | 当前已通过程序姿态、部件装配或共同动画前缀复用；本轮保留，不为缩减计数把挥砍、采矿、拉弓等不同动作互相替换 |

本轮新增制作清单为 52 份配置、564 组基础／变体输入。输入配对数量不是最终减少数量；同一动画可能被两把枪引用。最终有效配置、去重后的替代动画数、保留的特殊动画与资产大小以制作回执为准。

## 保留与取样规则

- 只使用当前 C++／武器目录实际引用的已保存动画；不从旧版本或回撤目录挑选同名片段。
- 基础与作者动画的原生骨架必须与活动视模相同，且源时长相同，才制作差量。不同骨架或时长的条目在配置中直接保留原动画，不自动重定向或改变节奏。
- 弹鼓、201 弹匣／弹鼓／布弹箱保留自己的基础换弹机构和事件时钟；只去掉握把变体重复的全身轨道。
- 以 120 Hz 提取原作者轨迹，省略恒等轨道，常量轨道只存一帧，其他轨道缩减冗余关键帧。不重做手型、不重新求解肩肘，不沿用已回撤的 SupportFingers59 修改。
- 枪械各通道先叠加差量再混合。双持手枪按实际启动动作选择对应配件层，并沿用共用接触时钟。
- 剑的差量在原有入场、快速近战收势、施法与最终骨骼／插槽发布之前应用；命中采样仍读取同一帧的最终骨骼。
- 不同剑型装配同一个长握柄时，再按实际手臂骨架选择配置；不匹配的剑型继续加载原作者动作。
- 腰射定位继续消费当前握把姿态；配置、骨骼或序列切换时刷新缓存。资源在武器装配时加载，热路径只用内存引用。
- PKM／201 在使用新作者差量配置时不再同时叠加旧 GripLayer56；未具备新配置时保留旧加载分支。

## 文件与制作入口

- `Source/FPSGAME/Weapons/WeaponGripProfile.*`：共用差量资产、关键帧取样、制作 API、特殊完整片段保留。
- `Source/FPSGAME/Weapons/WeaponGripProfileNode.*`：枪械动画通道层。
- `Source/FPSGAME/Weapons/WeaponGripComponentLayer.*`：剑的单节点动画层。
- `Source/FPSGAME/Weapons/SVDGripProfiles.cpp`：沿用文件位置，现包含通用 `InitializeWeaponGripFamily`／`WeaponGripProfileFor` 接口。
- `SourceAssets/WeaponAnimationSharing20261001/make_manifest.py`：从当前明确的加载路径生成制作输入。
- `SourceAssets/WeaponAnimationSharing20261001/install_profiles.py`：制作与保存；记录输入散列并拒绝覆盖未保存或来源发生变化的资产。
- `SourceAssets/WeaponAnimationSharing20261001/run_install.ps1`：使用现有 UE 批次互斥；默认完整制作，`-Weapon` 可单独重制一个分组。
- `SourceAssets/WeaponAnimationSharing20261001/install_receipt.json`：实际保存结果、独立保留条目、去重前替代列表、字节数、关键帧数。
- 新资产目录：`/Game/Weapons/AnimationProfiles20261001`，已加入显式 Cook 目录；SVD 原资产目录保持原位置。

初次制作遇到尚未加载的新原生 API 时，配置会标为 `pending_*`，运行时不会选用。完成原生编译后重新运行制作入口，补齐独立保留条目后才发布为有效配置。

源动画保留作为重制和回退输入，不删除工程资产；没有将配置数量下降换算成磁盘、内存或帧率收益。按用户规则仅制作、构建、接入和保存，不启动游戏、截图或验收，实际效果由用户测试。
