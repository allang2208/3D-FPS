# 715 速装器整组退弹与余弹损失

用户指定：已应用六发速装器改造后，即使弹仓仍有实弹，换弹也要退出整组弹药，未击发子弹丢失；动作与空仓换弹相同，并在改造面板说明。

## 当前行为

- 仅已应用的 `reload_device=dw715_speedloader` 启用该规则。枪匠草稿不会提前影响换弹，默认逐发装填继续保留非空仓余弹并按缺弹数装填。
- 所有速装器换弹统一使用 `LeftRecovery20260914/LoaderStow/A_DW715_speed_0`，包含左手从前方按压退弹、取速装器、装入、释放、闭巢及自然回握。沿用已有骨架和动作资产，无新动画烘焙或模型修改。
- 普通与空仓基础耗时均为 3.85 秒，继续受巧手和配件换弹倍率影响。原 3.60 秒常量只保留为作者接触表的换算基准。声音与动作统一走空仓时间映射，非空仓也播放退弹声。
- 余弹保留至退弹完成接触：作者时间 `1.28 * 3.85 / 3.60` 秒（约 1.369 秒），使用现有动画源时钟映射至实际播放时刻。此时将枪内实弹数和弹壳数同时清零，提交存档；不增加背包弹药，不生成可拾取弹药，不奖励换弹经验。
- 退弹前中断保留原余弹；退弹提交后中断，已丢弃实弹保持丢失。存档提交失败则沿用现有取消动作处理，不继续整组补弹。
- 换弹完成继续从实际备弹成组装入，最多六发；不足六发按实有数量装入，完成结算只奖励一次换弹经验。无限备弹开发选项继续按已有规则补满。
- 原有满仓/无备弹换弹限制，以及等待最后一发开火动画结束的逻辑沿用。
