## 本轮处理

| 用户反馈 | 实际归属与处理 |
| --- | --- |
| 机瞄与下方导轨漏空 | 后照门是独立静态件，固定底座与导轨属于骨骼枪体。重做照门下桥、缺口片和底座；导轨底面按当前机匣顶面采样形成连续接触，夹座底部进入导轨基板。保持原机瞄转轴、导轨冠面与光学附件挂点。 |
| 右侧拉机柄粗糙 | 截图中后部右侧外形粘连在 Receiver 外皮上，与现有原生活动控制件不是同一份几何。局部切除后重建圆角柄颈、连接台和扁圆端头；该外观仍随枪体主根，不改原拉栓动画及其控制件。新表面不用原损坏区域的图集法线。 |
| 机匣盖下中空 | 保留 R38 活动盖壳和内饰，在固定机匣上补有厚度的托面、侧壁、端部回边和接缝翻边。保留可见小开口，开口内侧有背衬；两侧开口不贯穿互望天空。 |
| 弹匣未插入 | 以当前 idle 动作的实际姿态定位，不按参考骨架静态位置判断。只延长原弹匣上端连接段最多 4.2 mm，并建立固定弹匣接口；主要握持区域、UV、材质槽名和原骨骼保持。 |
| 扳机区域粗糙 | 替换旧粗块扳机和旧护圈，制作独立弧形扳机与圆角护圈。先在 idle 姿态中制作，再逆变换回原 WPN_Trigger 绑定空间；沿用原动作轨道。 |

上述尺寸都是当前游戏模型的局部配合数据，不是实物尺寸或 1:1 测绘结论。参考来源沿用 `Surface32/References/User_Left.png`、`User_Right.png` 和 `Video26/Reference/weapon_01.65.png`、`weapon_07.65.png`；本轮反馈截图用于定位缺陷。
