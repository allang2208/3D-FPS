# 元素炼金魔法书：魔攻、强化与专注

日期：2026-10-12。物品：`ue_alchemy_spellbook`。

## 数值

沿用学徒法杖的魔攻公式结构，将基础项、属性系数以及每级强化系数均设为法杖的 40%。设 `I` 为当前角色智力、`W` 为精神、`L` 为魔法书强化等级：

- 基础魔攻：`round(2 + 0.2I + 0.2W)`。
- 强化后魔攻：`round(2 + 0.4L + I(0.2 + 0.08L) + W(0.2 + 0.08L))`。
- 每级强化增加的未取整数值：`0.4 + 0.08I + 0.08W`。
- 最高强化等级沿用武器强化上限，当前为 +15；费用与材料走现有强化系统。
- 装备魔攻按现有法杖口径四舍五入，因此最终整数相对法杖可能有取整偏差。

例如智力、精神各 10 时，魔法书在 +0 / +5 / +10 / +15 分别提供 6 / 16 / 26 / 36 魔攻；对应法杖为 15 / 40 / 65 / 90。这是公式示例，不是运行测试结果。

被动只计算当前武器组的副手魔法书，未激活武器组和双手武器锁定的副手不计入。进入生产工具模式时不计魔法书。被动与主手法杖魔攻相加，并进入既有角色魔攻及魔法伤害计算。

## 专注

法杖与魔法书组合右键展开，在开书动作完整结束后生效。开始合书、切换装备或中断专注即不再给予新的施法加成。

- 施法速度乘 2：施法动作按原有施法速度通道加速，时长减半。
- 魔法消耗乘 0.75：在技能、符文与法杖改造的既有消耗结算之后计算，不额外进行整数取整。
- 强化只增加魔攻；这两个专注倍率固定。
- 开合书动作仍使用 V30 的 1.12 秒节奏。
- 专注作用于发起施法时的数据快照，不追溯改变已支付、已生成的技能；冷却、投射物速度、效果持续时间和玩家主动蓄力时间沿用既有规则。

火球、冰刺、冰墙、暴风雪、闪电、圣光、火系扩展法术和电系扩展法术使用同一个专注修正入口。电系派生法术先取得未应用专注的闪电基础数据，在自身最终消耗结算后应用一次，避免倍率重复。
