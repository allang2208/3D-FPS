# 战锤快速近战左腕与前臂修正 V7

用户提供裸手快速近战截图，指出左手、腕臂关节扭曲。本版只修正 V6 左侧锁骨、大小臂及其辅助骨；左手、手指、右臂、武器和原有握柄接触的组件空间矩阵保留。

## 来源定位与方法

读取 V6 作者源可见左手相对前臂存在明显轴向差，并非只有手腕折角：源 0.09 秒约 -117°、0.15 秒约 -84°、回收 0.4 秒约 -174°。这是该绑定坐标中的排错指标，不是人体医学关节角度，不能据此直接套用医学旋前范围。

原求解器继承了参考动作的前臂朝向，又只分配额外转掌旋转，手掌最终朝向与实际前臂没有完整对齐。新制作从实际左手接触倒推支撑：约束腕轴弯折，按原生肘铰链确定弯曲平面，肩部补足支撑，保持大小臂骨长；前臂朝向完整衔接手掌，辅助骨按实际蒙皮站位连续分担旋转，轴向角跨 ±180° 连续展开。

修正渐入覆盖源 0–0.045 秒，在源 0.42–0.5 秒连续交还原待机。候选支撑点先作对称五帧平滑，再重建双骨链，避免离散搜索造成跳肘。起止姿态精确使用原 V6；不移动手指、拉长手臂或缩短前伸。

源中命中与最大伸展附近腕轴折角由约 29°/45°调整到约 18°，腕部剩余轴向差收敛；对应肩部支撑位移约 4.4–7.2 cm。数值仅为制作诊断，不代表 UE 压缩后表面或最终画面验收。早期候选将原生绑定角误当作医学范围，造成超过 30 cm 的肩位移动，已在导入前废弃；当前使用原生坐标求解，不沿用该候选。
