# QBZ191 视觉问题判断与 Blender 升级计划

日期：2026-09-13。本文保留执行前的源资料诊断与制作计划。用户随后授权继续，已完成的本地制作与接入见 [近景表面升级记录](qbz191-hero-surfaces-20260913.md)；未进行实机测试或效果渲染。网页价格、格式和授权标识为诊断时的检索快照。

## 当前判断

原素材存在需要适配游戏的装配问题，但目前不能把整体观感差全部归为原模型缺陷，更不能认定下载了错误的低模版本。我们的导入和后续处理也造成过确定的问题。下一轮应先恢复原素材的正确着色基线，再针对第一人称近景重建形体和烘焙贴图。

## 推荐的本地制作路线

目标：让待机、ADS、换弹时靠近镜头的机匣、导轨、瞄具及弹匣达到与本项目 M4、AKM 相近的细节与材质层次。以实际可见表面为优先级，不用总面数或贴图分辨率代替美术质量。

### 1. 恢复原始着色基线

- 独立建立 `SOURCE_REFERENCE` 集合，读取原 OBJ，保留其 UV、原始法线信息及原始分件关系。
- 为原图建立直接的 PBR 接线：BaseColor 使用颜色空间，其余按数据贴图处理；明确 OpenGL/DirectX 法线约定，只在确定需要的位置转换一次绿色通道。
- 此基线不叠加全枪倒角，不使用现行整体法线衰减和粗糙度重映射。将结构法线与后续微表面法线分别控制。
- 将当前 MagazineSeat 作者源作为另一独立集合，保留已有整枪比例、骨架与游戏装配关系。
- 如用户后续要求对照预览，再固定相机、光源、曝光，分别看原始、现版和升级样段。尚未执行这项渲染。

意义：先分清哪些细节只是没有正确显示，避免把原本可恢复的表面全部重建。

### 2. 先做一个完整近景样段

第一制作单元为“后机匣可见面 + 顶导轨 + 后照门”。该单元贯通高模、低模、UV、贴图，不只交一块增加倒角的灰模。

- 重建连续大平面与转折，给轮廓边、接缝、孔口设置有区别的倒角；修正局部曲面分段和厚度。
- 顶部导轨重复几何用阵列或参数化源制作，端部单独收口，保留既有配件安装面。
- 孔口、螺钉、遮挡轮廓用真实几何；浅刻字、涂层颗粒及细小划痕进入贴图。
- 后照门保留现有 ADS 孔心、开口与折叠轴，在此基础上精修内壁和铰接外观。
- 保留可编辑修改器及独立零件；着色器模拟倒角只能作预览补充，交给 UE 的轮廓和烘焙需要可导出的几何依据。

### 3. 扩展整枪形体

| 优先级 | 部位 | 制作内容 |
| --- | --- | --- |
| P0 | 上下机匣、顶部导轨、机械瞄具 | 第一人称的大平面、边缘高光、接缝与遮挡轮廓 |
| P1 | 护木、配件接触区、拉机柄外观 | 开孔内壁、台阶和边缘；保持配件贴合，不通过移动挂点掩盖形体问题 |
| P1 | 独立弹匣 | 侧壁加强筋、底板、接缝和口部可见外形；保留已修正的装配位置及抓握区域 |
| P2 | 枪托、握把、枪口外观 | 聚合物层次、注塑接缝、橡胶区别及侧面轮廓 |

所有尺寸调整服务于游戏外观与现有装配，不制作实体枪械加工图或内部工作机构。

### 4. 重新做 UV 与完整 PBR 烘焙

- 建立 `HIGH`、`LOW`、`CAGE`、`RIG` 集合。最终低模的硬边、UV 分割和三角化与烘焙版本保持一致。
- 重建过的零件重新烘焙结构法线，不能继续假定旧切线空间法线与新几何完全匹配。按零件烘焙，避免枪体与活动弹匣互相投射。
- 初始纹理分配建议：近景机匣/护木 4K，枪托/握把等另一组 2K–4K，弹匣独立 2K–4K，瞄具与小件集中图集。最终分配按近景占屏大小与现有两枪预算调整；不是直接把全套升到 8K。
- 做出涂层金属、裸露边缘、聚合物、橡胶的差异；颜色变化、粗糙度变化和法线起伏独立制作。磨损集中在合理接触处，避免满枪同尺度灰斑。
- 输出 BaseColor、DirectX Normal、ORM（R=AO、G=Roughness、B=Metallic）；可编辑源保留分开的原始通道与材质 ID。
- 微细划痕、涂层颗粒使用适合近景的尺度；刻字按参考制作清晰贴花或局部高密度区域。AI 放大旧图不能代替这一步。
- 三角面预算以必要轮廓、圆弧和平面质量为依据。当前增面网格不作为必须继续增长的下限。

### 5. 接回现有动画和改造件

- 以 `SourceAssets/QBZ191MagazineSeat20260913/QBZ191_MagazineSeat_Editable.blend` 作为绑定与装配参考，原 QBZ 私有骨架不改名、不修改 rest。
- 枪体、弹匣、拉机柄保持独立活动权重。弹匣继续作为独立作者对象输出，不重新焊死到枪体。
- 机械瞄具继续保留固定底座与活动头部，沿现有 M4 参考机制折叠；不把新活动件烘焙成枪体静态部分。
- 保留前后瞄线标记、现有导轨安装平面、配件挂点和抓握接触关系。需要改变可见外形时围绕这些接口建模。
- 保留 MagazineSeat 的 10 段换弹、Refined 的其他动作与五套握把族；仅在新外形确实改变抓握接触面时调整对应手姿，不无差别重做全部动画。
- 新资产先使用独立升级目录；保留旧资源用于用户对比和回退。模型/材质制作与必要导入完成后交给用户测试，未经用户明确要求不启动游戏、截图、跑回归。

当前参考入口：运行枪体 `/Game/Weapons/QBZ191/MagazineSeat20260913/SK_QBZ191_Manny`；折叠头部在 `Folding20260913`；当前材质源在 `Machined20260913`。

## 决策建议

优先在本地采用“恢复正确着色 → 做完整近景样段 → 重建重点部件并重新烘焙”的路线。这样可以利用现有骨架、换弹、导轨和折叠工作，同时真正提升形体与表面信息。外购作为备选，目前检索到的候选还不足以支持直接购买替换的结论。
