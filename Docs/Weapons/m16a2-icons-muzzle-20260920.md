# M16 背包图标与枪口安装修正

## 用户问题与现有资料

用户反馈 M16 装备栏、背包贴图调用与其他枪不一致，改造枪口没有对准枪管中心、未覆盖原厂枪口。

实际 UE 网格的 13 个枪体材质槽均已绑定 `M_M16A2_PBR`，其中护木为 `M_M16_Foreend`，枪口为 `M_M16_Flash_Hider`，手臂为两个 Manny 材质槽；没有改动材质或重导入骨架。背包、装备栏及提示共享 `UColdSteelWeaponIcons`，已有 M16 支持。

已有用户运行日志在 07:44:36 记录 M16 动态图标材质准备超时并回退到目录 PNG；07:54:12 又记录同一改造配置生成成功。这说明暂时准备失败不应永久加入失败缓存。旧目录 PNG 是此前复制的 Godot 图标。

## 实现

- `ColdSteelWeaponIcons.cpp`：材质/贴图准备超过 10 秒时将该请求移到队尾，保持 pending，随后重试；不再将一次准备超时缓存为整场游戏的永久失败。真正的材质编译错误和图像读取失败仍使用原来的失败路径。
- 使用共享 `ColdSteelWeaponIconCatalog` 的真实 M16 装配、材质、灯光和透明背景，制作并覆盖 `Content/ColdSteelData/Icons/ue_m16a2.png`。正常背包与装备栏仍优先显示含当前改造件的动态图标；等待期间使用新的目录图。目录批量导出列表补入 M16。
- `M4MuzzleVisual.cpp`：M16 改为使用 `WPN_M16Muzzle` 安装骨骼的后端膛轴中心，前向与上方向取枪根局部坐标，不再拿旧枪口出口标记减一个前后距离，也不以略有倾斜的瞄准线作为枪管轴。
- 原厂件按明确的 `M_M16_Flash_Hider` 材质槽随配件装卸隐藏/恢复。消音器与制退器沿用共享网格、尺寸和安装原点。
- 原厂状态下的特效出口也从同一个安装骨骼推导到原件前端；改造后的出口继续使用配件自身出口。

几何依据为迁移源 `manifest.json` 和 `authoring_reference.json`：原厂安装点为源空间 `(74.538742, -0.001199, 9.227880)` cm；前端 X 为 `78.648079` cm，原件长度 `4.109337` cm。旧出口标记 Z 为 `9.816999` cm，比原件膛轴高约 `0.589119` cm。已绑定骨骼保留同一安装点，经现有单位/坐标转换后直接用于装配。
