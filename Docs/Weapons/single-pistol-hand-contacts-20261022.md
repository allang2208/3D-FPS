## 持握

- 持枪手继续使用本枪掌心挂接与原生手指映射，并叠加当前第一人称的食指等局部动作。
- 支撑手接入对应枪型、左右角色及当前握把配件的待机掌心关系与手指。准备握持与换弹操作使用独立接触数据，避免取弹动作覆盖待机握点。

## 弹匣

适用于 M1911、G18、Pit Viper 的第三人称单持，包括现有扩容弹匣与 G18 弹鼓。

- 旧弹匣从插槽退出后掉落，取弹期间隐藏重复弹匣；新弹匣在插入口外出现并沿本弹匣轴线插入。
- 接触时刻沿用第一人称源秒数：退出 0.25、释放 0.3167、出现 0.78、装入 1.05。原普通与空仓源分别约 1.75、2.25 秒，装入键相同，不能按总时长百分比拉开。
- GitHub Reload.Init / Loop / End 的相位现在使用同一组出现、装入时刻，空仓与普通换弹不再因总时长不同而错拍。
- 装填手的接触关系先存入实际弹匣壳体坐标，再随第三人称弹匣的显示行程搬运。弹鼓使用实际配件框架，不把弹匣插槽框架当作鼓体抓握点。
- 手指、掌心、部件使用同一份已平滑的第一人称接触采样。支撑手在 0.65—0.78 秒进入接触，装入后至 1.20 秒松手，再回到源动作及持枪支撑。
- 沿用已保存的掉落几何、材质、实例匹配与释放边沿规则；中途变为相关的远端玩家不补生成旧掉落。没有新增弹药交易、RPC 或存档字段。
