## 动作与机械

先查看既有 M4 拉栓的玩家视角第 12、18 帧及第 18 帧掌侧图，再使用 `M4WrapGrip20260910/M4_Hand_MAT_Editable.blend` 中实际作者动作 `M4_MAT_equip_charge`。其作者范围 0–38 帧，60 Hz，不循环；右手双指勾住后方横柄，左手承枪。采用该动作的完整肩、臂、腕、手指与 twist 骨关系，整体平移到 M16 接触点，不重新解算腕肘或重置扭转骨。

- 换匣前段沿用 M4 WrapGrip 空仓源至第 88 帧。
- 第 88–111 帧接入已有 M4 普通换弹的脱匣回握尾段，让左手先回护木。
- 第 111–162 帧接入已有右手拉栓动作，按接触阶段重定时，并按 M16 横柄实际位置调整整条右臂。
- 第 125 帧勾柄并开始后拉，第 137 帧到后止点，第 139 帧松手，第 143 帧拉机柄复位，第 162 帧回到握把。
- 拉柄行程采用 M4 源动作的最大后移量；手在接触期间跟随同一行程。松手后手臂走原 M4 离柄路线，柄自行复位。
- 空仓枪机在前段保持后方；拉机柄先单独移动，接到枪机后继续后拉，松手后共同复进。释放钮自行解除挂起，不再出现手掌按压。
- 锁扣使用实际网格前端位置作为动画旋转支点，接触前解锁，随后跟随拉柄移动并在复位时归位。

源动作仍为 162/60＝2.7 秒，以 120 Hz 导出；游戏换弹时长继续由现有 M16 数值和公式控制。
