# M870 ADS 开火退瞄修复

触发：按住右键进入 ADS 后开枪，M870 的射击／泵动动画仍在播放，下一帧退出 ADS，动作结束后才重新瞄准。

原因：`IsWeaponBusy()` 为防止泵动期间再次射击或启动其他动作，将 M870 的开火动画计入忙状态。`RefreshMovementState()` 同时用这个门控更新 `bIsAiming`，把正常泵动当成了必须退出 ADS 的动作。

修订：提取 `IsWeaponBusyForAim()`，共享原来的换弹、装备、检视、近战、推门与翻越等占用条件，但不把射后泵动作为退瞄条件。普通 `IsWeaponBusy()` 继续包含泵动限制，射击间隔及其他动作门控保持原规则。瞄准按下入口使用同一瞄准门控，泵动期间不调用待机恢复，保留射击／抛壳时钟；松开右键正常退出。

只改 `FPSGAMECharacter.h/.cpp` 的状态逻辑，没有修改动画、握姿层、手模或枪械配件。没有新增反射类型、对象字段或资产依赖。
