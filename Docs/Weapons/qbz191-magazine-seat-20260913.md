# QBZ191 独立弹匣装配与换弹插入修正

用户指出原枪体、弹匣拆分并要求保证插入。本轮先读取原 OBJ 导入源、当前绑定及旧换弹参考画面，再制作；未进行修改后的实机测试或渲染验收。

## 原因与处理

原 OBJ 导入为一个包含 99 个不相连几何部分的对象，弹匣为其中独立组件 93，使用独立 Magazine 图集。此前已将弹匣绑定到 `WPN_SOCKET_Magazine`，该骨骼是 `WPN_root` 的子节点；当前精修弹匣的 4,620 个顶点保留这一刚性权重。因此问题不是未分配活动骨骼，而是之前直接继承了源模型的未就位装配位置。

制作前的源测量显示：弹匣口中心在枪根 X 约 -12.529 mm，而枪身中心是 +0.688 mm；弹匣顶端 Z 约 14.949 mm，弹匣井下沿 Z 约 27.259 mm。横向错位约 13.217 mm，并且顶端低于井口约 12.310 mm。旧插入动画返回这一位置，所以即使骨骼回到起点，也未正确插入。

- 可编辑源将弹匣拆成明确的 `QBZ191_Magazine_Export` 独立对象，保留材质、UV、外形及原机械骨骼；全匣权重归一到该骨骼，不和枪身混绑。
- 整匣在装配坐标中横向回正 13.217 mm、上移 32.310 mm。设计就位时弹匣顶部进入井口 20 mm；这是模型装配位移，不是整枪缩放或改变骨架 rest。
- 修正烘焙在弹匣的绑定几何中。待机、ADS、射击、装备及空仓末段拉栓继续使用同一装好位置，不会换一个动画又恢复原偏移。
- 枪体和弹匣以独立作者对象共同导出到 UE 骨骼网格，保留各自权重。共用一个运行 SkeletalMesh 不等于焊死为一个活动部件。

## 插入与左手

重制基础、垂直握把、侧倾握把、棱镜阻手器及三角握把五个系列的普通/空仓换弹，共 10 段。保留甩旧匣、镜头外取新匣、侧方接近的动作意图，左手跟随已修正的弹匣接触关系，保持现有成组手指姿态并联动肩肘腕。

| 源帧（60 FPS） | 作者动作 |
| --- | --- |
| 72 | 弹匣口对齐井口，停止侧向调整 |
| 76 | 弹匣顶端到达井口，进入轴向插入段；沿用原插入声时点 |
| 91 | 剩余 2.5 mm 压实行程 |
| 95 | 完全就位；沿用原压实声时点 |
| 98 | 左手开始脱离 |
| 106 | 左手先沿弹匣外侧退开 |
| 126 | 回到对应前握把；空仓分支转入侧拉机柄段 |

所有新换弹按 240 Hz 烘焙；普通 2.1 秒、空仓 164/60 秒及既有弹药结算不变。安装瞄具时的前后机械瞄具折叠沿用上一轮。
