# SVCH 表面检查与升级计划 R12

2026-10-18。状态：完成当前资产身份核对、制作链读取、网格统计和 8 个离线灰模视角；本轮仅检查、制定计划，未修改运行枪体、材质、动作或 V9。

## 结论

当前问题主要是局部形状与曲面过渡仍沿用原始低模，面数分配和纹理密度不足以支撑近景精度。整枪增加细分、统一圆滑或仅换高分辨率贴图，都无法完整解决。

实际加载网格是 `/Game/Weapons/SVCH/Refined20261018/R8Surface/SK_SVCH_R8Surface`，当前文件散列与此前直接读取的 UE 几何一致。枪体 72,304 三角面，内嵌手臂另有 37,086 面；本计划的枪体预算不计手臂。活动握持配置为 R11，保留其已修好的普通／空仓换弹、拉栓和回待机。

检查入口：`SourceAssets/SVCHRefinement20261018/R12SurfaceAudit/geometry_audit.json`。灰模读取 R8 制作源，按当前共享 idle 放置机械部件；使用中性材质排除贴图干扰，不是 UE 材质效果图。

## 检查发现

1. **原形体未细化。** R8 对大部分壳体增加 0.12–0.35 mm 的窄倒角，握把、贴腮铰接和托垫等保留旧形。灰模仍能看到明显分段轮廓、短直线拼成的转角，以及缺少圆滑连接的支架。握把 891 三角面、贴腮铰接 536、托垫 272；这些数字用于定位，单纯增加面数不是修复目标。
2. **瞄具局部提升不完整。** 照门孔与前护翼已有圆曲面，但底座、侧盘外轮廓、支撑臂与导轨的过渡仍显块状。准星的瞄准刃、六角螺栓和导轨齿本就需要硬边，必须与应圆滑的部分区分。
3. **活动件及弹匣仍有拼块感。** 扳机护圈内弯由少量直段转折；弹匣筋条为多段独立凸条，端部、弯曲处与壳体的连接缺乏细致圆角；拉柄表面与小控制件也需要局部加工边。
4. **不是所有曲面都需要重做。** 枪管／枪口组件约 13,972 三角面，照门孔约 2,304，前瞄准头约 2,364。灰模中圆筒和瞄孔已经相对平顺，优先保留，只对孔口、连接肩和局部高光修整，避免重复堆面。
5. **4K 不等于小零件细节充足。** 机匣、护木、导轨、枪托、瞄具等共享主体图集，实测主表面约 2.5 像素/mm。R8 烘焙半径 0.18 mm 仅约 0.45 像素，0.35 mm 也不足 1 像素，经过过滤后很难稳定提供小倒角细节。现有结构法线主要来自当前网格上的 Bevel 节点，并无独立精修高模恢复遗漏结构。
6. **材质需在几何之后调整。** R8 配方已关闭大块斑驳、划痕与假磨边，颗粒粗糙度扰动也很小。此次灰模仍显低模，证明只继续调材质不足。当前网格包含自定义法线；本轮未把“法线缺失”当成已证实原因，UE 构建后的切线及法线贴图组合留到候选对照时分别核对。

## 分部件升级清单

| 优先级 | 部件 | 具体处理 | 保留约束 |
| --- | --- | --- | --- |
| P0 | 前后瞄具底座、侧盘、支撑臂 | 沿原外形局部重拓扑；圆形外轮廓按近景投影增加分段；补连续圆角、支架厚度与连接肩；圆面、平面分开设法线 | 瞄孔中心、准星高度、ADS 视线、底座安装面和原有机构轴 |
| P0 | 机匣、上盖、护木、导轨根部 | 大平面保持平整；上肩和转角增加支撑环；孔口、抛壳窗、接缝补真实唇边与局部倒角；统一连续高光 | 枪体长宽高、导轨冠面和节距、枪管轴、全部装配位置 |
| P1 | 枪托、贴腮、握把、托垫 | 沿现有截面和曲率补环线；处理折角式外轮廓与转接处；硬质骨架、聚合物接触面、橡胶边缘分别设圆角 | 托长、总体剪影、已认可的掌心／手指接触面 |
| P1 | 扳机护圈、扳机、保险、释放钮 | 护圈内外弧做连续曲面，保留截面厚度；小件局部精建，补真实分缝和加工边 | 扳机行程、骨骼归属、手指活动空间 |
| P1 | 弹匣壳、筋条、底板 | 保持弯曲轮廓与筋条数量；增加壳体曲面分段；圆顺筋条端头与根部，细化唇边和底板连接 | 插匣接口、弹匣轨迹、R10 左手握持接触区 |
| P1 | 拉柄／枪机外露部分 | 外观边缘精修；拉柄握持面以 R11 实测表面为锁定基准，增加细分而不移动接触轮廓 | 拉栓轴和行程、握持面、R11 接触与松手时序 |
| P2 | 枪管、枪口、销钉与紧固件 | 保留已较圆的主体；局部修孔口、肩部、倒角和法线；六角头保留六角身份 | 枪口坐标、孔洞数量、现有外形及附件接口 |

倒角拟以零件实际尺度分档：小型加工边约 0.15–0.35 mm，主体转角约 0.3–0.6 mm，聚合物外缘按原曲率局部放宽。以上是候选起点，不是全枪统一半径；对瞄孔、薄壁和接触区逐处限制。

## 制作顺序

**第一步：局部样件。** 先做“后瞄具总成、机匣与拉柄周围、握把／枪托转角”三个样件，保留原件并排。先看灰模剪影、曲面和移动高光，再加入材质。用同机位前后对照决定全枪做法，避免再次交付只有面数和版本号变化的整枪。

**第二步：扩展几何。** 按清单完成局部重拓扑和必要重建。保留原整体尺寸、主要轮廓、机构身份；不对全枪应用统一细分或平均法线。可见孔洞、厚度与连接由真实几何承担，微小车削纹、颗粒和浅刻痕交给贴图。枪体 LOD0 初步按约 9–12 万三角面分配，增量集中在近景曲面与机构，按效果调整；该范围不是性能承诺或必须凑足的目标。

**第三步：高低模与 UV。** 建独立的精修高模和游戏网格。固定最终三角化、硬边和 UV 后重烘法线、AO、粗糙度。优先重排现有 4K 图集，让瞄具与机匣近景区域获得更高密度，关键小件暂以 8–12 像素/mm 为候选；不足时再加独立机械件 2K 图集，控制新增材质分区。高低模成对隔离烘焙，避免活动件互相投影，也不把旧法线直接贴到新拓扑。

**第四步：材质细化。** 延续本枪深色外观，在 WS1 的本枪实例上区分阳极铝／涂层、裸露钢、聚合物与橡胶。结构法线和微纹分开；金属保持连续加工高光，聚合物细纹以实际毫米尺度控制，橡胶保持较柔和反射。保留刻痕、孔槽和分缝；不靠粗颗粒制造细节，不通过加深黑色或提高粗糙度掩盖折面。沿用现有湿润接口，不改其他枪的共享预设。

**第五步：候选接入。** 使用新资产路径保留 R8。继承当前原生骨架、材质分区、瞄点、附件接口与 R11 配置，V9 网格及认可动画不动。几何改变的区域重新处理 UV／法线／遮罩，重导后核对真实使用的材质覆盖表。候选完成后再按授权范围检查腰射、ADS、检视和两种换弹。

## 判定标准

- 第一人称近景的圆曲轮廓无明显折线，平面仍平整；导轨齿与六角头保持准确硬边。
- 机匣和机构的移动高光连续，不沿随机三角线断裂，也不呈整体塑料融化感。
- 瞄具通道清楚，瞄准标记、导轨接口、枪口坐标不漂移。
- 弹匣与拉柄仍按原动作接触；不会为了外观再扭曲源手或另创动作。
- 在同视角、同光照、同缩放下能直接看出改善；面数、贴图尺寸和脚本成功仅作制作记录。
