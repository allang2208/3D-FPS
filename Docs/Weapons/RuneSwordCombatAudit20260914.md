# 双手符文剑攻击范围与判定审计

**历史 V11 审计：下列 62 项结果与距离只适用于当时的两段挥砍，不能作为后续重击、突刺、范围翻倍或防御的测试结论。** 本轮整理未重跑审计；当前参数见 [符文剑基线](runesword-baseline-20260914.md)，源码与报告恢复范围见 [发布说明](melee-publication-20260914.md)。

日期：2026-09-14。版本：CombatAuditV11。保留已接受的 CompactRecoveryV8 动画和 CameraHeavyV10 镜头参数。

## 范围结论

| 项目 | 实际数据 |
| --- | --- |
| 剑刃长度（剑根至剑尖） | 77.6 cm |
| 动画剑点离稳定眼位的最大半径 | 127.2 cm |
| 最远前方投影 | 124.7 cm |

两刀互为镜像宽幅斜扫。判定仅覆盖实际剑刃经过的前方区域；身后、墙后以及只有剑气表现经过的区域不额外结算伤害。大型目标的中心可能更远，但仍需其碰撞表面接触剑刃。

## 修复内容

- 将伤害判定坐标改为稳定眼位和玩家控制朝向，镜头震动不再改变攻击距离或摇偏碰撞轨迹。
- 同刀可穿过角色身体继续命中其他目标，每个目标仅结算一次；实体墙体和掩体继续阻挡。
- 根据真实剑长加密扫掠点，间距由 7.76 cm 降到 3.88 cm，补足剑刃边缘的小目标覆盖。
- 排除快斩出画尾段造成的背后误伤。
- 对移动和转向在帧内插值，覆盖低帧率、高攻速，以及单帧卡顿跨过命中窗口或整个动作的情况。
- 伤害、攻速和距离在攻击开始时取快照；起势、定剑和收势无伤害，中止攻击会清除后续判定。

## 验证结果

**62 项通过，0 项失败。必要构建成功，最终测试进程退出码 0。**

测试实际加载正式剑模型、压缩动画和护士僵尸蓝图，并在独立 UE 物理世界运行碰撞查询、原生攻击计时和伤害函数。包含 5/15/30/60/144 FPS、0.5/1/4 倍攻速、薄目标、多目标、距离边界、背后目标、墙体遮挡、镜头大幅运动、移动卡顿及中止攻击。两段挥砍对护士真实物理碰撞体均正常结算一次伤害。

旧判定在同一组碰撞夹具中复现了边缘漏判、第一名怪物挡住后续目标及背后误伤；也确认表现相机能改变旧世界空间剑端点。相应修复后的用例均通过。

测试不初始化玩家资料子系统或加载存档，不启动关卡、AI BeginPlay 或人工 PIE；未进行新的动画渲染或手感验收。
