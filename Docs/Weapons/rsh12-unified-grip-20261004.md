# RSH-12 双手握姿与 ADS 同步修订

本次对应用户反馈：待机双手握姿不自然、检视右食指扭曲、腰射进入 ADS 时手枪与手部出现间隙。此前 `RSH12InspectGrip20261004` 的右手拟合未获认可，本次以五发快速装填器版本的原生 715 动作为基底重新制作。

## 修改

- 右手掌与左手支撑同时重新定位。手指仅沿源姿态识别的屈曲轴调整，保留掌骨朝向、骨长、缩放、蒙皮与参考骨架。原生 V7 和实际钢制手套完整混合权重参与接触制作。
- 右手中指、无名指、小指在握枪阶段使用共同包握形状；食指随 715 原动作伸展，检视伸指端点没有额外关节拟合旋转。离枪阶段渐退私有握姿层，沿用原单发装填与五发装填器接触数据。
- RSH 单持 ADS 使用与待机相同的序列、采样时刻和握姿层，由已有视模型组件变换完成瞄准移动。ADS 开火使用同一腰射开火序列；准星仍由该姿态的实际照门与准星骨位置计算。
- 钢制护手不再对 RSH 的待机与 ADS 叠加 715 通用左手偏移和小指修正。其他枪械与已有装填护手曲线沿用原路径。

## 制作与接入

目录：`SourceAssets/RSH12UnifiedGrip20261004/`。

- `fit_grasp.py`：双手掌位和受限单轴屈曲制作，输出 `grasp_r.json`、`grasp_l.json`。
- `unified_grip.py`、`author_profile.py`：在原生动作与五发装填器 Profile 上写入双手手臂轨道。
- `Single/profile.json`、`Single/RSH12_TwoHandGrip_Editable.blend`：正式导入载荷和可编辑源。
- `import_profile.py`：保存 `/Game/Weapons/RSH12/Native71520261003/Profiles/DA_RSH12_base`；修改前资产存于 `BeforeAssets/`。
- `run_pipeline.ps1`：使用既有 UE 批次互斥，后台导入、保存并构建基础 DLL；不启动游戏或图形编辑器。
- `import_receipt.json`、`build_receipt.json`：分别记录资产保存与本次 DLL 构建结果，不能以脚本存在代替这两项结果。

本次按用户排查范围观察了待机/检视的离线钢制手套局部几何视图。它们用于判断指节形状与双手关系，不代表游戏内 ADS 过渡、材质或整套动作已经验收。没有运行 PIE、游戏回归或性能测试；实机效果待用户测试。
