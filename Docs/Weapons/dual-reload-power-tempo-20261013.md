# 双持换弹发力节奏 R1

## 目标与方案

用户要求先完成全部枪械换弹镜头标准，再加强双持左轮甩开弹巢、普通手枪甩出弹匣的力量感。换弹镜头 RC1 已完成正式 Editor 构建，见 [统一标准](reload-camera-standard-20261013.md)。

现有双持左轮 `RevolverReloadFlickV6` 已包含反向蓄力、外甩、回弹的姿态；RSH 私有 profile 还包含开仓下移和独立弹壳。普通手枪也有抬腕、甩匣和低位装填轨迹。缺口在于运行时用固定 `ActionRate` 推进整段，准备、发力和回稳之间的速度反差不足。

本次沿用实际加载的动作、握姿、骨长、机械轨迹及配件 profile，增加两套局部时间曲线：

- 弹匣手枪：放慢抬腕准备，把主要甩匣压进短发力段，甩出后减速回稳，再交回装填。
- 左轮：延长反向蓄力，快速通过甩腕与开巢，保留回弹停留，再接原有装填。快速装填器按原有 3.85/3.60 源时钟比例映射。
- 总换弹时长、枪匠换弹属性和双持 1.33 倍耗时继续有效；镜头继续采用 RC1 统一强度和双手合成上限。

## 参数与覆盖

曲线使用秒制单调三次 Hermite 插值；起点和结束点速度均为 1，结束后回到原始时钟。下面是「线性源时间 → 实际采样的作者源时间」，不是固定的游戏实秒；实际速度还由该枪 clip/source 长度及换弹属性决定。

| 阶段 | 弹匣手枪 | 左轮标准机械时钟 |
| --- | --- | --- |
| 起点 | 0 → 0 | 0 → 0 |
| 准备末段 | 0.19 → 0.11 | 0.22 → 0.14 |
| 短促发力 | 0.29 → 0.33 | 0.32 → 0.34 |
| 发力收束 | 0.36 → 0.41 | 0.40 → 0.48 |
| 回弹停留 | 0.52 → 0.46 | 0.54 → 0.55 |
| 接回原时间 | 0.72 → 0.72 | 0.76 → 0.76 |

适用 M1911、Pit Viper 2011、G18、Dan-Wesson 715、RSH-12 的双持、混搭和副手枪。普通/空仓、左轮逐发/快速装填沿用各自原有 clip。单持控制器不采用这套双持曲线。

## 接入与同步

- `Weapons/DualPistolReloadTiming.h`：两类前向时间映射和逆映射。所有曲线段保持向前，跨帧事件继续只触发一次。
- `PistolDualWieldComponent::SampleActionTime`：共用绝对时间入口，驱动原动画实例；手臂、枪体、弹匣、弹巢及手指一起采样。第三人称发布的每手进度继续来自该实际动作时间。
- `FPSGAMECharacterReloadCamera.cpp`：在角色镜头先于手部控制器更新时，使用同一采样函数，避免镜头落后一帧或继续走匀速时间。
- `PistolDualWieldCombat.cpp`：机械事件、逐发入膛和闭锁继续读实际源时间。快速装填录音先将接触时刻逆映射成运行时间，再减去录音自身提前量；RSH 弹壳从精确脱离姿态生成，离开后的重力运动年龄也用逆映射计算。
- 中断后只补闭锁，从已有闭锁恢复点接回，不重播开仓或甩匣；原有取消音频与一次性事件集合沿用。

本次修改运行时采样节奏，未重烘焙或替换已保存的动画资产。RC1 的接触幅度表、上限及冲刺抖动减半设置保持原值。
