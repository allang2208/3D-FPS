## 发现与处理

| 发现 | 本轮处理 |
| --- | --- |
| 旧测量把源模型坐标和动画武器空间混用，重复逆变换产生约 70 cm 的错误枪口差值 | 以实际持枪帧的 WPN_root 为唯一坐标系；枪口、抛壳口、PSO-1 前后镜面点逐帧烘焙进本枪动作 |
| 拉机柄/弹匣按原骨架 rest 直接绑定，播放动作后装配位置漂移 | 按本枪 idle、共享骨架 rest 和各件目标骨矩阵重新求刚性绑定；保留共享手臂蒙皮与骨长 |
| 右手扳机位置过高、左手停在机匣附近 | 调整右手握把位置和左手护木支撑，双臂 IK 保持骨长并处理扭转骨 |
| M4 空仓 slap 与 SVD 右侧拉机柄不匹配 | 空仓换弹与装备动作改为右手食指钩住右侧拉机柄，后拉约 7.5 cm、释放并回握 |
| 原复用动作插匣时左手张开 | 采用沉淀的 M4 包握整套手指，按 SVD 短弹匣位置拟合；保持包握到锁定，再由外侧松手退开 |
| 没有可随拉机柄运动的枪机表面 | 新增小型倒角枪机载体，连同拉机柄绑定 WPN_bolt；没有改动原机匣拓扑 |
| 开镜只有机械对齐，M4 枪声会覆盖本枪 | 接入固定 4 倍镜、PSO 风格中心尖点分划、镜内射线与灵敏度；4 个本枪设计音色及独立机械音时间点 |
| 缺少独立冲刺、近战动作；拾取与动态图标白名单遗漏 | 补齐进入/循环/退出冲刺和枪托近战；拾取、资源预载、动态图标、图标导出接入本枪；拉机柄不再被“手臂材质”规则隐藏 |

## 沉淀的具体复用

- 使用项目共享 Manny 的骨架、皮肤和当前手臂材质，不更换整套手模。
- 普通动作来源为项目现有 AKM native / ReloadPolish；每段动作重新拟合到 SVD，不能直接回退到 M4 原动作。
- 插匣包握取自 `M4TacticalToss20260910/M4_Hand_MAT_Editable.blend` 的已接受手型，按弹匣几何中心差调整整手；保留完整五指组。
- 右侧拉栓参考 `A762RightCharge20260922` 中已记录的 ASH12 钩握姿态；接触点改用本枪右侧拉机柄。源帧 310 的食指蒙皮最近点距离约 3 mm，此读数只说明该关键帧的源接触。
- 换弹弹药提交、循环完成和音效使用同一 source-time 时钟；动作尾段回到 idle 时同步收回整体持枪偏移。
- 倍镜复用项目既有光学遮罩呈现与相机 FOV 通路，固定 4 倍；分划不提供未经标定的距离数字。

## 用户反馈：ADS 模型周期闪现

源码定位到拥有者可见性冲突：角色每帧隐藏镜内枪械/手臂后，身体组件在角色 Tick 之后每隔 0.2 秒又把第一人称相机子组件的 `OwnerNoSee` 置为 false；下一帧重新隐藏，形成模型瞬间闪现。

已让身体组件保留瞄准镜登记的隐藏状态，去除重复登记，并在退出 ADS 时保留第三人称隐藏请求。修改覆盖 SVD 与共享逻辑的 LPVO，未更改模型资产或相机倍率。代码证据、构建状态及未运行的用户复测场景见 [ADS 闪现修复记录](../../SourceAssets/SVDCompletion20260923/ADSFlicker/README.md)。
