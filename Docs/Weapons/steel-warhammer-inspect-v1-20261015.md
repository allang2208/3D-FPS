# 战锤 L 检视 V1：双手拨弄后沿握柄转一整圈

用户已确认方向。行走中自动播放的转锤半段（×3 速度与力度）见 [战锤行走检视 V1](steel-warhammer-inspect-walk-v1-20261015.md)；L 仍播放本页完整动作。

用户要求：双手钝器（锻钢战锤）按 L 检视，双手拨弄后让锤子**围绕握柄**做 360° 转动。本版新增动作与接入，未改动其他战锤动作和数值。

## 转轴

- 实测作者网格握柄段（WPN_root 局部 z −0.08～0.38 m）截面包围盒中心，得到握柄中线：WPN_root 局部 +Z，过 (−0.8 mm, −0.9 mm)。握柄半径约 1.5 cm，左右掌根距中线约 6.5/6.8 cm。
- 锤体只绕这条中线旋转。握持时两手与锤柄保持原待机握持矩阵；松握时手掌只绕同一中线公转，半径不变，圆柄在掌内滚动，不会切入锤柄。改造件挂在 WPN_root 上，随同一骨骼旋转。

## 动作（3.34 s，300 fps）

| 时间 (s) | 内容 |
| --- | --- |
| 0–0.52 | 双手把锤举到画面右上方展示（锤柄方向 (0.70,0.35,0.62)，绕柄预转 −15°） |
| 0.52–1.52 | 双手拨弄：握紧绕柄来回拧 +22° → −18° → +14° → −16°（最后一下为蓄势）；左手 0.60 s、右手 0.96 s 依次食指到小指错峰抬指再扣回 |
| 1.42–1.52 | 左手松成环握 |
| 1.52–1.66 | 右手发力拨转：−16° → +24°，出手角速度 420°/s |
| 1.66–2.66 | 锤在松开的双手中自由转动，只减速不加速（v = V(1−u^k)），到 1.70 s 右手停在 +32° 后滚回；2.48 s 起双掌合拢制动，刚好在蓄势起点后整一圈（+344°）处握住 |
| 2.66–3.34 | 握紧、补回最后 16° 并放回待机；末帧等于待机首帧 |

- 手指松握：向绑定姿态打开约 26–32%（拇指 10–26%），掌骨不动。
- 手臂：原生骨长；肘部取原生肘圆上最接近“待机肘部 + 70% 举起运输”的位置；不推肩，避免臂根开口靠近镜头。举起时左手掌沿圆柄整掌换握 −6°，右手 0°（搜索结果，见 `search.json`）。
- 制作量化（非游戏验收）：腕部相对待机的弯折变化最大 左 22.0° / 右 33.0°；前臂扭转 左 −15.4～14.3°、右 0～25.0°；骨长误差 < 0.001 mm；单帧关节位移 ≤ 0.15 cm；锤体到眼最近 0.476 m；手臂蒙皮表面到眼最近 0.215 m；展示与转动期间锤头顶点 100% 在 75° 竖向、16:9 画框内，锤头中心约位于 NDC (0.57, 0.45)。

## 运行接入

- 资产：`/Game/Weapons/SteelWarhammer20261014/InspectV1/A_Warhammer_Inspect`（3.34 s），随战锤装备异步加载；缺失时不影响装备就绪，仅 L 无效。
- `UProductionToolComponent::BeginInspect` / `CancelInspect` / `IsInspecting`（`Production/ProductionBluntInspect.cpp`）。独立真实时钟，不受攻速影响，不计入 `IsBusy`，不消耗体力、无判定。
- `AFPSGAMECharacter::InspectPressed`：装备战锤时退出冲刺并开始检视；再次按 L 从头播放。
- 打断：左键/蓄力/旋风/上挑/快速近战等任何动作开始、冲刺、跳起、滑铲、闪避、翻越、左手施法、切换/卸下武器、菜单，以及所有调用 `InterruptWeaponInspection` 的输入（开火、瞄准、换弹、F、G、E 交互、快捷栏技能）。行走可继续检视。
- 进入检视用 0.14 s 姿态衔接；中途打断或结束离开检视时，手掌沿锤柄圆周衔接（`bPreserveShaftGrip`），避免松握中的手直线插值穿过锤柄。
- 第三人称身体与联机远端没有单独的检视身体姿态；但战锤的第三人称双腕、手指与锤体骨骼始终采样第一人称视模（工具族常驻驱动，随身体状态以 25 Hz 发送），按代码路径检视的双手与转锤也会出现在第三人称与远端（2026-10-15 复核更正，未实机验证）。
