# M24 表面、机械瞄具与改造图标升级

2026-10-27。背景制作和 UE commandlet 导入已完成，接入代码的 FPSGAMEEditor Development 构建成功。本轮没有启动交互编辑器或运行游戏，也没有进行游戏截图、动作回归或视觉验收；游戏内表面、机械瞄准视野与装配效果待用户确认。

## 已保存的枪体表面

运行枪体切换到 `/Game/Weapons/M24/Surface20261027/SK_M24_SurfaceV9`。以当前 Hold V9 资产为副本，仅替换枪体材质，保留原网格、UV、法线切线基础、骨架、手臂材质、蒙皮、校正形态和已完成的 ActionLayout 动作路径。三个原有静态配件也保存到 Surface20261027，镜片沿用此前已修复的专用玻璃材质。

从项目 `M_WeaponSurface` 派生 M24 混合区域版本，保留 WS1.1 的细颗粒、边缘与动态雨水层。源 ORM 的金属通道划分金属和非金属，源 AO 单独进入标准 AO 通道；使用零件区域贴图控制粗糙度。标记、结构接缝和弹壳颜色继续来自原图，降低大面积旧磨损色和粗糙噪声的权重。没有把全枪改成单一金属。

| 区域 | 基础粗糙度 |
|---|---:|
| 枪身金属 / 枪托聚合物 | 0.40 / 0.54 |
| 枪栓 / 后栓件 | 0.31 / 0.34 |
| 扳机 / 弹匣 | 0.36 / 0.38 |
| 消音器 / 镜筒 | 0.44 / 0.43 |
| 贴腮板 / 橡胶尾垫 | 0.58 / 0.72 |

枪体 2K、镜身 4K 结构法线在保留原 UV0 与原结构信息的基础上烘入克制的边缘倒角。法线使用线性 NormalMap 压缩，OpenGL 绿通道仅在 UE 翻转一次。原枪体轮廓和拓扑没有重制；这部分的提升来自表面分层与倒角法线。

骨骼与静态配件分别使用对应的材质用途设置，避免静态配件继承手臂蒙皮用途。三个派生母材质已加入标准雨水识别，沿用同一雨水层。

## 机械瞄具

新增改造 ID `m24_palma_iron`，显示名「M24 觇孔机械瞄具」。外形参考早期 M24 的侧置调节照门与护筒准星：[TM 9-1005-306-10，图 2-22 / 2-23](https://usarmorment.com/pdf/sws24.pdf#page=64)。参考原件和插图保存在作者目录 References。

作为一套可拆改造件保存到 `/Game/Weapons/M24/Surface20261027/SM_M24_m24_palma_iron`。模型含侧安装底座、调节座、旋钮连接轴、觇孔、准星护筒与前准星，共 19,060 三角形。作者尺寸按所选游戏模型适配，非实物制造尺寸。可编辑 Blender 场景、FBX 和作者脚本均保留。

复用 M24 现有静态配件安装坐标变换，新增 SightRear / SightFront / SightUp 挂点供 ADS 使用。与六倍镜共用 optic 槽，装配互斥；机械瞄具为 1 倍，不启用六倍镜屏幕分划。新枪默认六倍镜、消音器和贴腮板的组合保持原设定。角色、改造预览和物品图资源加载使用统一的新配件路径。

## 图标

从真实源模型生成灰阶独立部件素材，再以已批准的 `FirearmFramedIcons20260930/muzzle_brake_framed_v2.png` 为框体参考，通过 imagegen 制作四张最终图：六倍镜、消音器、贴腮板、机械照门。机械瞄具图标仅展示照门。厚倒角金属方框、四角铆钉、银色内环与深色底板统一。

已同步正式 FramedFirearms PNG 和 7 个对应 UI Texture2D（4 个配件键、3 个原装兼容键），保留被替换 PNG 副本。UI 纹理设置 sRGB、EditorIcon、NeverStream、无 mip，最大纹理尺寸 1024。分类入口复用共享 category 图，三个拆除选项直接复用现有 `tactical_false` 中性减号图，不另生成一套武器专属图。
