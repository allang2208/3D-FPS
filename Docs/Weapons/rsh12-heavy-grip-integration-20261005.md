# RSH 加重后握把接入

用户于 2026-10-05 授权接入，并选定：稳定性 +15%、后坐力 −10%、开镜耗时 +5%。

- RSH 专属改造 ID：`rsh12_heavy_grip`，独立槽 `grip_body`（握把本体）。三种通用防滑纹继续使用 `reargrip`，可与原厂／加重握把组合。
- 效果：`stability_mult=1.15`、`recoil_mult=0.90`、`ads_percent=0.05`。单持及双持都有效；前握把既有的双持收益限制只影响 `underbarrel`，不影响加重后握把。
- 模型沿用 `SourceAssets/RSH12HeavyGrip20261004` 的已制作版本，当前接入资料在 `Integration20261005`。
- 原生单持与左右双持网格分别把原件 `9_l` 分配到 `M_RSH12_FactoryGrip`。保持原几何、UV、法线、骨架、权重和动作，只使原握把能独立显示／隐藏。导入前保存三份 `.uasset` 备份。
- 原厂状态显示原握把，防滑纹沿用原覆盖网格；加重状态隐藏原分区，显示加重握把本体与新制收边表面。新表面止于金属底座上方并避让装饰紧固件；防滑纹只替换这块表面的材质。
- 静态件使用已认可的组件参考坐标及 `WPN_root` 逆绑定，无额外美术偏移。握持接触区域不改形，既有单持、前握把姿态层、检视、换弹和双持动画保持不变。
- 独立握把栏只加入 RSH 的 Slots/Categories/Defaults，不增加其他枪械的栏目。通用保存、已装配方、主／副手、枪匠预览、背包图标和掉落物装配共用同一 ID。
- 新橡胶、金属 PBR 为 2K，DirectX 法线。运行本体的橡胶壳使用物理 UV0，避免 UV1 法线与 UV0 切线不匹配；可编辑原件仍保留原 UV0。湿润参数接入 RSH 材质映射。
- 加重与原厂握把各有对应金属框图标。原厂图使用实际 `9_l` 网格为形状参考；图标 PNG 与 UE UI Texture 副本一并落盘。
