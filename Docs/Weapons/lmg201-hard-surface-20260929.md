## 红圈的真实归属

两个红圈中的突出楔形片来自独立静态资产 `Production20260927/SM_LMG201_BipodBase`，不是只存在于骨骼枪体的导气管或护木上。原底座沿枪长方向约 148 mm，前后端分别露在前端小件后方和护木前下方。仅修枪体会遗漏它。

证据：原底座导出（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/Exports/Before_BipodBase.fbx`）、部件边界（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/bipod_geometry.json`）、运行装配 `Source/FPSGAME/Weapons/LMG201WeaponAssets.h` 与 `PKMBipodComponent.cpp`。

新版用紧凑弧形承座、两侧耳板和轴头连接现有管件与腿部铰链；取消两端长楔片。沿用原腿部资产、转轴、脚底接地点和展开控制代码。新座不能只缩短旧楔体后悬在管下，承座曲面必须接到当前管件表面。

## 用户要求的检查

检查对象包括 UE 实际保存后导出的枪体/底座、当前活动准星与原脚架腿，不只检查作者 Blend。记录见 几何与硬边检查（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/saved_check.json`）、材质及保存记录核对（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/asset_check.json`）。

范围：红圈残余楔片、新建表面闭合性、退化面与横向离群点、硬边是否在导出后保留、平面遮罩是否有效、脚架腿及转轴是否保持、局部侧视/下视/机匣灰模对照。按材质子集统计的机匣和护木边界包含与其它材质相接的分区边，不作为“整枪通孔数量”。

开发中发现底座细小倒角面在静态导入链被删，作者源闭合不等于保存资产闭合；关闭该私有部件导入及构建的 `remove_degenerates` 后，实际保存导出的底座从 72 条开放边恢复为 0，保留下来的小面不是零面积退化面。该选项不推广到其它资产。

最终定向结果：新前端规则件、保留的 R38 盖壳、新脚架座均为 0 条开放边、0 个近零面积面、0 个横向超界点；前端 205 个顶点保留大于 25° 的角点法线差异。机匣和护木平面遮罩分别覆盖对应材质三角面角点的约 12.86% 和 7.77%，其它区域继续使用原法线图。两条脚架腿的资产散列保持不变，主资产和天气表保存记录匹配。

灰模检查见 前端侧视（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/saved_front.png`）、前端下视（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/saved_front_under.png`）、机匣近景（本机历史资料：`SourceAssets/LMG20120260927/HardSurface39/saved_receiver.png`）。导出的 `UCX_` 碰撞体不参与外观渲染，否则旧碰撞壳会被误看成没有清掉的外观楔片。原本的冲压凹槽边缘仍带有生成源的不规则细节，不能把局部平面修整称为全枪精确重建。

本轮没有开启游戏或运行换弹/脚架动作回归，灰模对照也不替代 UE 场景中的最终材质观感。

## 沉淀的经验

沿用 skill 中“先判定几何/法线/贴图层”“保留硬边设置顺序”“精确小件本地重建”“不靠粗糙度遮丑”的条款。补充：截图中的小碎片可能属于运行时另外装上的静态组件；排查先核对装配归属。保留握持纹时应明确冻结整片纹理区域，不能让平面拟合跨入条纹坡面。几何已整平后仍须局部同步角点法线和旧法线图；小三角面位移后的面法线可能剧烈旋转，不适合作为旧角点法线的逐面旋转依据。本轮保留未拟合区域的原角点法线，只对拟合面做有界混合。
