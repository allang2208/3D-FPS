# 战锤旋风 V5：左手松握、右手外甩、连续回握

用户认可 V4 的挥动方向，但认为左手松握、右手惯性外甩和连续回握没有表现出来。V5 后半段随后也被用户否定，明确改为左手自然放下出镜、右手外甩角度翻倍。当前正式资产为 [V6](steel-warhammer-whirlwind-drop-v6-20261015.md)；以下为 V5 历史记录，不能作为认可的交接动作。

## 动作制作

V4 的离柄量是叠加在锤柄上的短暂偏移，左手仍跟随武器。其末段位置还落到较低的画面区域，不利于看清松指。

- 左手从作者时间 1.00 秒开始张指，随后在 1.12 秒离柄；拇指先松开，其余手指依次跟进。
- 离柄阶段改为独立空间轨迹，不再用随柄偏移。经过点为 `(-0.185, 0.345, -0.14)` 米，在原低位撤手点上方；经过该点时继续运动，不固定停手等锤。
- 保持 V4 一次向右前方外甩、制动后回收的武器路径。左手在整个外甩顶点保持打开且离柄，右手保留原手掌到柄的握持矩阵。
- 左手沿连续弧线追上锤柄，1.72 秒重新接触，接触后才用 0.08 秒逐指合拢；随后双手收回同一待机姿势。
- 离柄到接触共约 0.66 秒实际播放时间。曲线按实际时钟连接速度、加速度，中间经过点切线非零，不重复起停，也不在旋转／恢复交界突然变速。
- 张指只使用原手型到原生张手姿势的局部旋转，保留轻微弯曲；骨段长度、手指平移、骨架、权重及右手抓握不改。沿用完整肩肘支撑与连续前臂扭转分配。
