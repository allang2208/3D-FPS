# Gunplay V11：以射击视线为先的轻烟

用户反馈：V10 在站立不动射击时，烟雾累积遮住目标，偏离了增强 Gunplay 质感的设计目的。本轮将设计优先级明确为：持续射击和瞄准时看得清目标，同时保留短暂的喷烟、连续扩散和轻微余烟。

## 调整

| 项目 | V10 | V11 |
| --- | --- | --- |
| SmokeOpacity 默认值 | 0.72 | 0.45 |
| 腰射单层透明度系数 | 0.27 | 0.20 |
| 普通 ADS／LPVO 系数 | 0.27／0.23 | 0.12／0.085 |
| 主烟连续生成率 | 60–80 层/秒 | 44–48 层/秒 |
| 主烟单层寿命 | 2.1–2.5 秒 | 0.55–0.85 秒 |
| 停火主烟供给 | 0.26–0.55 秒 | 0.18–0.24 秒 |
| 余烟生成阶段 | 1.1–2.3 秒 | 0.45–0.80 秒 |
| 余烟初始生成率 | 12–20 层/秒 | 10–14 层/秒，持续减量 |
| 余烟单层寿命 | 2.1–2.5 秒 | 0.80–1.10 秒 |

主烟到余烟的过渡发生在供给窗口的最后 0.10 秒。每层透明度随年龄下降，并加入扩散稀释：扩散面积越大，密度越低。高热量时不再提高单层不透明度，避免连射逐步加厚烟幕。原先较宽的扩散形态仍保留。

烟在出生时获得少量相机右侧的漂移速度，出生后保持世界空间；即使玩家原地不动，也会往枪口侧方飘散。余烟保留轻微上浮，并缩短生成时间与停留时间。

`M_MuzzleSmokeSheetV11` 复用已修复 Niagara Sprite 使用标记的 V9 连续密度材质，在瞄准中心的宽缓区域进一步降低透明度：中心保留 25% 权重，逐渐向周围恢复，避免硬边或挖空的圆圈。过渡按当前视口尺寸计算，仅作用于本地枪口装饰烟，不作用于其他环境烟或战术遮挡效果。

瞄准状态在每次更新时决定新粒子的透明度，切入 ADS 不必等待下一发。已有烟保持各自出生参数，并通过材料中的视线柔化和短寿命淡出。
