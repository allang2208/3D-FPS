# 主手弯刀＋副手手枪

2026-11-01。沿用现有单手刀动作和法杖＋副手枪的左手资源，不新增动画资产。

## 操作与动作占用

- 左键及刀技能继续使用 `UKukriWeaponComponent`：普通连击、突刺、冲刺攻击、蓄力/重击、F 快速近战、上挑和风车保持原有动作、镜头及命中时序。
- 右键驱动副手枪，R 使用副手枪原有换弹流程。副枪保持原有腰射收敛，不进入主手枪 ADS。
- 刀动作优先。刀忙碌时副枪向左下方避让，暂缓射击和换弹；包括刀的装备和收势阶段。
- 避让进入为 0.075 秒，恢复为 0.18 秒，跟随现有闪电加速动作倍率；整个左手网格刚性移动，保留握把、手指及枪械机械骨关系。
- 刀结束且副枪完全复位后才允许开火。自动枪保留按住状态，半自动枪只保留尚未发出的按下请求；松开右键即取消，不补发已完成的半自动射击。
- 刀冲刺攻击期间按右键只排队；副枪恢复后才请求退出冲刺，不用副枪输入打断刀动作。

## 换弹衔接

复用 `PistolDualWieldComponent` 的普通/空仓换弹、转轮逐发装填、快速装填器、换弹种、闭锁续作、音效及弹药提交节点，沿用副手枪 1.33 倍换弹时长。

刀动作打断换弹时，立即停止换弹计时和机械音，并取消对应网络换弹请求。最后显示的换弹姿势短暂冻结并淡出，配合副枪下沉，避免直接切回待机姿势。已提交的插弹、退壳和待闭锁状态沿用现有弹药账本；收势后根据当前状态重新选择剩余换弹流程，不继续推进被打断的旧时钟。

F 的全局优先级打断会清空输入及动作，因此由刀的 F 入口单独保留副枪的按住/待发请求、待换弹请求及目标弹种。换武器、菜单、死亡、攀爬等其他全局打断仍走原有取消路径。

## 接入位置

- `Weapons/PistolMeleePair.cpp`：刀动作占用、左手避让、换弹退出姿势和恢复。
- `Weapons/PistolDualWieldComponent.{h,cpp}`、`PistolDualWieldCombat.cpp`：组合识别、输入排队、射击及换弹门控。
- `Weapons/Kukri/KukriQuickCombat.cpp`：F 打断后的副枪请求保留。
- `Multiplayer/ColdSteelPistolAuthority.cpp`：允许主手单手刀组合发起副枪换弹，沿用独立武器实例账本。
- `UI/ColdSteelAmmoReadout.{h,cpp}`：同时显示刀体力与副枪弹量，复用法杖组合的副枪读数，标明避让/待换弹。

支持现有 `IsKukri` 刀类与 `IsDualPistol` 手枪族；第三人称继续使用已有主手刀动作和副手枪装备/枪械事件路径。

本次只进行开发接入及后台构建，不启动 UE 编辑器或游戏，不运行测试、预览或验收。视觉衔接和联机实际表现由用户测试。
