## Source split and animation content

The source has separate glove, sleeve, loose cartridge and gun meshes. The glove mesh also contained uncovered arm skin; equipment extraction removes that skin surface and keeps the actual glove. The gun has independent Main, Slider, Trigger and Load bone-weight regions, now exported as body, bolt, trigger and loading gate. The stock, barrel and handguard are retained in the factory body; this source is not a complete interchangeable attachment kit.

The eight author clips are idle, walk, run, fire, last-round check, one-shell reload type 1, full reload type 1 and one-shell reload type 2. Type 2 is an alternate one-shell feed, not a complete empty-chamber reload. The runtime empty reload therefore uses the full-feed source and retains its final bolt closure.

The author clip is transported to one native shotgun skeleton. V7 geometry is fitted to that skeleton and remains the default; the source gloves/sleeves are equipment overlays. Equip and quick melee are complete-rig derivatives; inspect reuses the non-firing part of the last-round check. These additions are not original source clips.

## Gameplay and data

- Item `ue_super90`, weapon type `shotgun`, ammo group `ammo_12g` / 00 Buck.
- Semi-automatic; capacity 7; eight independent pellets per cartridge. The damage panel and enhancement formula show whole-cartridge totals. Each pellet receives one eighth before hit/armor processing. The canonical legacy Super90 coefficients are multiplied by eight for this aggregate representation.
- Factory timing: 0.65 s firing interval, 1.65 s normal one-shell reload, full empty source 424/60 s; reload speed modifiers apply through the existing stat pipeline.
- Normal reload alternates the two one-shell feeds: insertion at 44/60 s (type 1) or 54/60 s (type 2), each source clock scaled to the current one-shell reload stat; can continue to capacity, and can be stopped by fire/aim. Empty reload retains only the required complete feed loops then maps into the source bolt-closing tail. Each insertion commits ammunition through `ConsumeAmmo`; interrupted pending closure remains in existing weapon save data.
- Imported last-round check finishes before a queued reload. Muzzle, ejection, sights and loading port have dedicated authored marker bones. Ejection uses the source red shotgun cartridge mesh.
- Inventory, warehouse, ammo pouch, gunsmith factory recipe, enhancement formula, shotgun mastery, weapon icon/preview/pickup allowlists and cook directories are registered. The existing armory migration grants one gun, 42 reserve cartridges and the two new equipment items once.
- Factory options are exposed; new interchangeable optics, muzzles, stocks and grips have not been authored in this delivery.
- Equipment IDs: `ue_hardknuckle_gloves` (gloves slot), `ue_st6_sleeves` (armor slot). The second item is a pair of sleeves, not a complete shirt; the source contains no torso garment.
