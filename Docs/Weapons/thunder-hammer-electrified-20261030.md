# 雷神之锤落雷感电层数（2026-10-30）

用户要求普通重击落雷、贯雷投掷落地雷击和疾雷召引均在命中后叠加 2 层感电。

三条路径复用 `AWarhammerShockwave`：原先仅疾雷进入的感电处理扩大到所有原生锤雷击，层数统一来自 `ThunderHammer::ElectrifyStacks=2`。每次有效命中存活且可受状态影响的目标，在同一份去重命中结算中追加一次感电，不因冲击波和雷击共用命中而重复叠层。
