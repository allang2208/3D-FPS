# 拉弓反馈优化计划 · 2026-09-27

状态：已进入制作与接入，实施记录见 [木弓受力与放弦反馈 V15](bow-elastic-feedback-v15-20260927.md)。方向为克制的木弓受力反馈：拉开有阻力、满弓有张力、脱弦利落、回收有余势。

## 当前依据

本次读取当前配置与源码，并沿用 2026-09-26 资产和离线动画检查（仅本机：`Saved/BowAnimationInspection20260926/inspection.md`）；本次没有重新运行游戏或资产检查。

- 手臂使用 ContactV9 的 V7 裸臂与 SightContactV11 动作。已有非线性拉距曲线，不能把问题归结为完全线性播放。
- 原装、游隼、磐木、静枝均为静态弓体，只整体跟随左手。弓臂不参与受力，是本轮优先补齐的缺口。
- 弦由两段细杆组成，弓梢端点固定，中点跟随右手接触标记；拉开时总弦长增加。
- 释放时弦中点约 75 ms 回位，没有弓臂回弹；镜头已有指数衰减反馈，满弓已有周期晃动。只增加这些幅度不能补齐木体与双手的发力关系。
- 手臂阶段已经有姿态混合和半拉释放衔接。需要调整速度与余势，不能直接用更长混合掩盖接触问题。

## 保留的体验合同

- 待机到拉弓首帧仍为 0.20 s；不额外增加输入等待。
- 原装拉满 1.40 s，游隼 1.12 s、磐木 1.75 s、静枝 1.54 s，继续接受已有改造/人物公式修正。第一轮不改伤害、箭速、耐力或满弓保持数值。
- 沿用当前已使用的拉弓与放箭音源及原速约定。
- 保留 V7 手型、握把包握、箭台、木制瞄具和约 28.5 cm 满拉行程。手臂保持骨长，指腹接触与弓平面是硬约束。
- ADS 仍无额外随机散布。镜头、瞄具、箭轴与发射方向使用一致的空间关系；释放冲击在取得射击方向之后发生。
- 五槽改造、箭种、存档、装备图标和弓快速近战继续兼容。

## 第一阶段：建立弓体受力联动（最高优先级）

先完成原装弓的整条链，再复用到三款弓体。

1. 为弓体建立统一轻量骨架：中央固定根、上下各四节弓臂、上下弓梢，共 11 根骨骼作为初版。中央握把及附件安装区保持刚性，形变从安装区外平滑开始。
2. 在 Blender 中为四款弓体制作蒙皮和拉距对应姿态。先以 0/25/50/75/100% 作为制作控制点，再烘焙连续曲线；不是在游戏里只切换五个姿态。
3. 依据现有指腹接触轨迹，离线拟合弓臂弯曲，使弓臂长度、弦长近似保持。保持手指—弦结接触，不能靠缩短箭杆或整体缩放弓体迁就弦。
4. 弦端点改为读取弓梢骨骼位置，弦中点继续使用实际勾弦点；弓臂形变由同一动作时间与拉距驱动。
5. 使用可复现的动画/曲线驱动，不引入会改变射击时机的运行时软体模拟。弦的释放振动使用受限的小幅曲线。

接入必须覆盖 `BowPartComponent` 的骨骼网格承载、异步资源加载/表现签名、`BowAssembly` 的改造预览与装备图标。每个槽仍只有一个正式模型来源；同一骨骼弓体在展示时使用零拉距姿态。旧静态自定义部件仍可加载。原装与三款目录引用、官方旧资产迁移和打包资源一并接续，不能只让手持端换成骨骼网格。

骨骼弓体使用适配骨骼用途的材质派生；缠带、箭台、瞄具等静态附件保留原材质用途。图标/预览沿用现有按配方异步加载与有界缓存。

## 第二阶段：调整双手发力与阶段衔接

目标是产生“搭住—拉开—承力—稳定”的节奏，避免所有关节同时匀速移动。

| 环节 | 计划调整 | 必须保留的约束 |
| --- | --- | --- |
| 0.20 s 入场 | 延续当前姿势和移动趋势，先抬到位再压实三指接触，末端不突然刹停 | 不提前增加拉距；中途松手仍取消 |
| 拉弓前段 | 手腕自然进入发力方向，左臂稳住握把 | 指腹不沿弦滑动，不重新扭转已匹配的掌向 |
| 拉弓主段 | 右肘后开，肩肘与前臂分担动作，左臂有克制的前撑感 | 弦结仍按共享拉距轨迹运动，不随意偏离弓平面 |
| 接近满弓 | 关节动作减速并出现短促、连续的稳定过程 | 准时达到满拉，不新增蓄力门槛或提前满伤害 |
| 满弓保持 | 低幅呼吸叠加轻微承力微动，随现有保持阶段逐渐增强 | 避免手指相对弦漂移、重复机械摇摆及额外随机弹道 |
| 放弦与回收 | 承力三指脱弦，右手继续短距离随动，左手吸收冲击后回稳 | 半拉从当前姿势释放，不能先跳到满拉；Release/Recover 连续 |
| 主动取消 | 从当前拉距受控卸力回位，区别于真实射出的快回弹 | 不发射、不重复扣箭；高优先级打断及时退出 |

继续按阶段时间采样手臂。Draw 片段本身已有非线性拉距，不再用 DrawFraction 对片段时间进行第二次映射。微动施加在肩肘和整体受力关系上，最终用接触约束求得腕手姿势。

## 第三阶段：放弦冲击、声音与镜头同步

以下是第一版调节区间，不是已经确认的物理参数或最终效果：

| 反馈 | 初版目标 |
| --- | --- |
| 弦快速前冲 | 视觉主行程约 25–40 ms，脱弦音头与箭离弦同一事件触发 |
| 弓臂余振 | 主回弹后 1–2 次小幅衰减，在约 120–200 ms 内稳定 |
| 右手随动 | 脱弦后继续约 60–100 ms 的短促运动，随后进入现有回收阶段 |
| 弓体/左手吸收冲击 | 从约 0.3–0.6 cm 的视模位移量级起调，方向来自弓的局部受力平面 |
| 镜头脉冲 | 第一版从约 0.15–0.30° 起调；替换/整合现有反馈，不重复叠加当前 1.1° 系数 |
| ADS 视觉附加反馈 | 从腰射的 35–50% 起调，优先保证木制瞄具清晰与回稳；不额外改变既有稳持数值倍率 |
| 拉弓声边缘 | 提前放箭/取消时使用约 10–25 ms 短淡出，减少硬截断；不人为延迟释放 |

保留原来的 Release 0.30 s + Recover 0.34 s 总阶段预算；上述反馈发生在预算内。半拉时由释放瞬间拉距决定冲击强度；取消动作不触发射击冲击和放箭声音。

声音继续使用已有视频参考音源的原速与原音高。取箭、搭弦、拉动、脱弦按各自事件同步；不把原录音强行循环或随游隼/磐木拉满时间变调。若原音源不足以覆盖某一阶段，先通过留白与包络处理，素材增补另行列出。

## 第四阶段：复用到三款弓体

四款共享动作语义、握持接口和驱动骨架，各自保存形变曲线与反馈配置。材料较厚不直接等同于固定的弓梢位移大小；形变首先满足实际模型、既有拉距与弦长关系，再调整观感。

| 弓体 | 反馈性格 | 已有代价继续保留 |
| --- | --- | --- |
| 原装 | 中等阻力和短促回弹，作为统一基准 | 原装数值 |
| 游隼 | 操作轻快，进入稳定姿态利落，余振较短 | 单箭伤害/箭速较低 |
| 磐木 | 肩肘承力更明显，释放冲击较厚重，余势稍长 | 拉弓慢、耗力高、保持短 |
| 静枝 | 过渡平顺、横向微动低、回稳干净 | 拉弓和 ADS 略慢 |

不再次乘上已有改造晃动倍率，避免把静枝等方案强化两遍。快速近战、切换箭种、收弓、施法/翻越打断时清除上一轮形变与振动状态，防止换装残留满拉姿态。

## 制作顺序与交付

顺序为：原装弓骨架/弦联动 → 双手发力与衔接 → 放弦与音画反馈 → 三款差异化及全部展示入口接入。

实现阶段交付可编辑 Blender、骨骼 FBX、已保存 UE 模型/动画/材质、C++ 构建产物和数据配置，并记录正式资产与回退路径。后台制作与保存，不主动启动交互式 UE 或游戏。

完成后供用户重点体验：腰射/ADS/蹲姿下的半拉与满拉、拉弓中切 ADS、主动取消和连续射击、四款弓体换装。关注弓臂确实受力、三指不脱弦、箭不穿握把、瞄具不遮挡、半拉释放不跳姿势、射击节奏不被反馈拖慢。这些是后续体验关注项，本计划不自动授权或执行测试。
