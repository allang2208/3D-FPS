# 弓拉距门槛与伤害（2026-09-27）

用户要求：至少拉到 50% 才能射出；半弓造成基准伤害的 50%，满弓造成 150%。

## 当前规则

- 用 `UBowWeaponComponent::DrawFraction()` 的实际拉距判断，与现有拉弓曲线和 HUD 同源，不使用动画播放时间百分比。
- 拉距不足 0.5：松手进入现有平滑 `LetDown`，箭留在弦上；不生成弹体、不扣箭、不扣射击体力、不播放射出音效。
- 拉距达到 0.5：允许发射，伤害倍率为 `2 * DrawFraction - 0.5`，满弓封顶 1.5。
- 50% / 75% / 100% 拉距对应 0.5 / 1.0 / 1.5 倍基准伤害。
- `full_damage` 保留原键名与基准值 46；仅作为未乘蓄力倍率的基础输入。无任何其他加成时，上述三档为 23 / 46 / 69。角色、强化、改造、箭种、暴击与目标防御仍按原有流程结算。
- 满拉后保持超时的自动撒弦同样按 1.5 倍处理；连射接续、箭速、ADS 和腰射散布沿用现有规则。

## 接入

`Weapons/Bow/BowStats.h/.cpp` 集中定义最低拉距和伤害曲线；`ReleasePrimaryAttack` 先处理收弓，`LooseArrow` 在生成／消耗前共用门槛。射击快照保留未乘蓄力的基准，发射端只乘一次；命中端沿用快照拆分物理、魔法与附加伤害。

`ColdSteelBow::Evaluate` 输出满弓面板，现有装备详情、对比和改造页面共同取得 150% 后的数值；强化预览也使用相同倍率。说明文字明确门槛及百分比的基准。HUD 和状态文字向下取整，避免实际 49.x% 时显示 50%。

目录删除已退役的 `min_damage_ratio`。旧存档即使保留此字段也不再读取，新规则由代码直接生效，无需重新领取弓，也不改写既有强化、配件或弹药。未提升表现版本号，未重导入模型／动画资产。
