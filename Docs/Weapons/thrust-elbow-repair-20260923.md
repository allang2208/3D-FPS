# 第三段突刺：双肘扭曲修正

日期：2026-09-23。对象：高地双手剑使用的标准柄、长柄两套 `A_RuneSword_Thrust`。

## 原因与责任范围

对比 `MeleeArmOpening20260923` 保存的修改前姿态、V1 肩部后收后的姿态，以及真实手臂网格和蒙皮权重，双肘在突刺伸展阶段的扭转塌陷在 V1 前已存在。V1 保留了原来的上臂/前臂轴向错位，同时把手臂进一步伸直；上次防穿帮处理没有解决这个问题。之后的相机 Tick 顺序修改没有改动画骨骼轨道。

在 0.579167 秒，标准柄左肘的相对轴向错位从 V1 前约 -163.65° 变为 V1 后 -163.73°，右肘从约 171.84° 变为 171.86°。离线蒙皮图中，两个版本都呈现肘部细颈塌陷。这只能证明问题早于 V1，不能推断它从最初原始素材起就存在。

旧 WristLocked V4 只在接近待机时为突刺提供肘部支持；离开待机后的大部分攻击阶段不受该修正覆盖。

## 本次修改

- 仅覆盖两套突刺动画的 14 条上臂、前臂、辅助骨及手部补偿轨道。
- 固定肩、肘、腕的世界位置，保留当前后收肩部与握剑轨迹。
- 保留手掌、手指、腕侧 `lowerarm_twist_01` 的世界变换。
- 肩部开口环约 70.8% 权重来自 `upperarm_twist_01`、27.1% 来自锁骨：固定这两个支撑，沿上臂向肘侧逐步分配旋转，避免整段旋转重新暴露袖口。`upperarm_twist_02` 依据实际站位承担约一半上臂修正。
- 按实际前臂轴处理旋转，上臂最大分担 70°，肘侧前臂最大修正 100°；近肘辅助骨根据实际蒙皮站位递减分担，腕侧保持原样。
- 起止各 0.12 秒使用平滑权重接回原姿态，保留 1.25 秒时长、601 个采样姿态和原有动作时序。
- 不修改骨架、蒙皮权重、战斗逻辑、伤害窗口或相机 Tick 修正。

离线真实网格的伸展关键帧中，细颈状塌陷已明显消除，双臂轮廓连续；标准柄该帧双肘残余轴向差约 33.55° / -25.05°，长柄约 38.53° / -25.05°。这些数值是本次定义的相对骨架轴向指标，不是人体关节角度。
