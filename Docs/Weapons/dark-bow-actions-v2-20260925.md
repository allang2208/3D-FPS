## 动作与接触

| 资产后缀 | 导出时长 | 内容 |
| --- | --- | --- |
| Idle | 2 s | 未搭箭待机、低幅呼吸 |
| Ready | 2 s | 已搭箭待机，右手维持接触 |
| Equip | 0.45 s | 从画面下方举弓 |
| Nock | 0.68 s | 右手取箭、送箭、三指勾弦；34% 时箭进入手上表现，82% 为搭箭音效触发点 |
| Draw | 1.4 s 基准 | Sparrow `RMB_Drawback` 的 0…2.333 s 手部间距轨迹，归一为 17 点拉距曲线；参考肘轨迹确定肘平面 |
| Hold | 2 s 循环 | 满拉保持与轻微呼吸；默认 2.2 s 后力竭释放 |
| Release | 0.64 s | 张指、右手随动、回收；Release 0.30 s 与 Recover 0.34 s 连续采样，不重新播放 |
| Run | 0.8 s 循环 | 低持弓奔跑 |

动作以 120 fps 烘焙。左手握把、右手三指勾弦；弦释放后约 0.075 s 回到弓档，不跟随右手回摆。提前松手从当前姿态进入 Release，局部骨段混合过渡不缩短骨长。Sparrow 的 Idle 提供低幅位移参考；Release 使用其 Fast Fire 节奏作为参考后按第一人称接触重新制作，并非整段骨架照搬。

`draw_seconds` 经既有弓术／攻击间隔倍率缩放，开始拉弓时更新；动画按阶段进度映射到实际片段全长。伤害和箭速读取同一拉距曲线。左键按住搭箭后继续拉开，松开发射；R 只搭箭；右键稳持。菜单、翻越、施法、切工具等中断不发射。满拉力竭是另一条明确的发射条件。

- 表现资产根：`/Game/Weapons/DarkBow20260925/ArmsV2/`。

- 可编辑源：`SourceAssets/DarkBow20260925/ArmsV2/Bow_BareArmsV7_Actions.blend`、`WoodArrow_Editable.blend`；`Export/` 保留 FBX。
- 制作入口：同目录 `export_authoring_inputs.py`、`author_actions.py`、`author_arrow.py`、`import_assets.py`、`bind_outfits.py`。

## 来源与边界

弓体沿用项目已有 Fab dark bow 资源，Sparrow 沿用项目已有 Paragon 包；源信息承接首版记录，本轮未重新核对商店许可。V7 裸手与衣袖／手套沿用项目认可资产；新箭为本轮 Blender 精确建模。第三方原始文件及其派生二进制仅在本地工程保存，本轮无公开发布。

现有系列仍有后续内容：弓臂本体为静态网格，尚无受力弯曲；缺专用拉弦／放弦／搭箭音效和背包图标；弓部件数据口已接入但还没有专用改造界面和箭种选择交互；未开放枪械附魔卷轴给弓；箭命中后插住 8 秒消失，尚无拾回功能；尚无独立第三人称弓动作。以上不算本轮已完成项。

UI 结构和数据合同见 `Docs/UI/bow-readout-plan-20260925.md`。旧首版文档只作历史记录，本文件与当前 `bows.json` 为现行制作说明。
