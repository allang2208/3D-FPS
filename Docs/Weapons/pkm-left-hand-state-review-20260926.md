# PKM 左手状态复查（LeftState50）

用户明确要求再次检查射击、握把和换弹状态。本轮读取当前 UE 实际网格及动画，在既有 ArmJoint49 修复基础上检查；没有重导入旧动画，也没有修改正式资产。

## 范围与结果

覆盖基础握持、斜握把、偏置握把、垂直握把、棱镜阻手器，分别检查 idle、aim、fire、aim_fire、reload、reload_empty，共 **30 条动作、8,730 个原生采样帧**。同时比较 RAW/COMPRESSED 数据，检查 **165 个瞄准/换弹入场混合姿态**，并制作、查看 **55 张关键姿态图**。

本次范围内未发现新的左手滑握、肘腕接缝开裂、前臂辅助骨独立拧转或换弹回握跳变。

| 检查项 | 当前实测结果 |
|---|---|
| 棕色、黑色手套左腕口 | 各 87 个边界点；全部动作最大分离约 0.000744 mm |
| 裸臂肘部上下段 | 50 个唯一接缝位置完全相同，权重完全相同；相同姿态下不会拉开 |
| 裸腕与手掌 | 87 个唯一接缝位置完全相同，权重完全相同 |
| 持握、腰射与瞄准射击的手指 | 相对枪身最大位置变化约 0.0000052 mm，仅数值误差 |
| 射击/换弹首尾与对应握持 | 检查手、肘、肩及三根指端，最大位置差约 0.00176 mm |
| 压缩姿态与原始姿态 | 所取关节最大位置差约 0.208 mm，最大旋转差约 0.0343°；未发现压缩导致的新变形 |
| 瞄准混合时的手掌接触 | 最大变化不足 0.0003 mm |

静态持握的腕轴折角分别为基础 17.83°、斜握把 12.35°、偏置握把 30.49°、垂直握把 33.87°、棱镜阻手器 33.81°。换弹保留 ArmJoint49 的肘腕配合，最大约 66.43°。这些是游戏骨架的几何指标，不是医学活动度判断。

## 画面与运行路径

- 查看了各握把掌侧、左臂侧面、腰射/瞄准射击、普通/空仓换弹的关键姿态及回握位置。腕口连续，所选姿态未见新的肘部绞缩。
- 检查代码中的握把动作表、时长匹配和选择分支；射击、换弹选择对应家族，服装使用同一个 LeaderPose。
- 图像使用本轮从 UE 读取的实际网格、原生分裂法线和压缩姿态，以中性材质离线渲染；没有使用历史 Blend 中的旧手臂。
- Workbench 的投射阴影曾在前臂产生直线条纹，关闭诊断阴影后消失；该条纹没有被当成蒙皮缺陷，也没有因此修改游戏阴影设置。
- 侧面诊断视图可看到第一人称网格的肩部裁切末端；它不能被误认成腕口或肘关节裂缝。16:9 构图按代码中的基础/动作锚点生成，**未复现运行时动态相机、后坐力和实机渲染层**。

本轮没有启动 PIE 或操作玩家存档。因此结论是当前资产、混合姿态及离线关键画面检查未发现新增问题，不能写成完整实机操控验收。检查前后 39 份相关资产的散列一致。
