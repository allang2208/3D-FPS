# 双手战锤旋风：明显摆动、左手松握与单手惯性收势 V3

> 用户已明确否定 V3：位置、动作和连贯性均不合格，存在反复顿挫。该版不再是当前运行版本，已由 [连续轨迹 V4](steel-warhammer-whirlwind-flow-v4-20261014.md) 替换。下文仅保留历史制作记录。

用户否定 V2 的摆动和位置变化不足，要求接近旋转结束时松开左手，由右手持锤继续向外惯性甩出，最后回到双手待机。

读取双手剑 `RecoverV6` 实际关键姿态及 `ImpactV5/whirlwind_motion.py`，沿用蓄势、两次连续发力、外送制动的阶段结构。V2 将旧锤轨迹以 0.65 权重混回待机，且全段固定双手；本版按战锤原握距重制武器轨迹。

- 蓄势向右上带锤，随后两次明显横摆和前送。第二次带锤后衔接右前方外甩，方向和位置同时变化。
- 右手全段保持原待机的完整手掌到锤柄关系。左手起始保持原待机握距，末段先张指，再沿锤柄径向退出并向左下收手；右手继续带锤前送。
- 回收先将左手从侧下方带回握点，再依次合拢手指。首尾完整姿态与现有战锤待机一致。
- 肩、肘、腕使用既有肩带支撑与两骨圆解算；保留原生骨段长度、骨架、权重、V7 裸手和右手握姿。左指使用本骨架自身静止开掌方向做有限松握，不平移指骨或改绑定追随目标。
- 曲线使用分段五次 Hermite、共享节点速度和零节点加速度；准备、快带、外甩和收回分段定速，不使用全片匀速或突然定格。
