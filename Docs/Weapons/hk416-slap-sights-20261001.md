# HK416：M4 拍击动作与独立机瞄分区

本轮按用户 2026-10-01 的要求继续返工大弹鼓空仓动作，并接入“安装光学瞄具后隐藏机瞄”。上一版只恢复弹鼓动作、再以两骨 IK 调整手掌的方案不再作为当前拍击实现。

后续普通及扩容弹匣已采用同一整臂适配方法，制作与接入记录见 [普通／扩容空仓拍击](hk416-standard-extended-empty-20261001.md)。各分支保留自身接触帧及总时长。

## 拍击

已查看 M4 实机拍击分帧 `SourceAssets/M4SlapImpact20260910/Delivery/拍击接触分帧.jpg`。动作直接取同目录 `M4_Hand_MAT_Editable.blend` 中的 `M4_MAT_reload_empty`；M4 源帧 130 对应弹鼓源帧 116，沿用现有弹鼓运行时长和机械声音时钟。

复制范围包括左锁骨、上臂、肘、前臂、腕、五指和 twist 骨。源帧 88–108 从插鼓后脱手过渡到完整 M4 动作，108–134 保留其完整关节关系；之后按原弹鼓及所装前握把回位。四款前握把的持握姿势从 128 帧开始接回，148 帧结束。

用当前 V7 裸手的实际表面及 HK416 挂机按钮上部表面配准。整条左臂在枪根坐标内平移 `(0.000704320148, 0.011797219515, 0.008466903120)` 米，接触预留 0.8 mm。这里不再单独解算肘、转腕或重置 twist；M4 的屈肘、掌向、手指形状与骨长一起保留。配准记录为 `SourceAssets/HK416SlapSights20261001/slap_contact.json`。

基础及 vertical / canted / prism / angled 共五套 `drum_reload_empty` 输出在本轮目录。保持原正式动画路径，普通弹匣及普通换弹不重导。动画作者源为现有 `HK416CommonAttachments20260930/author_animations.py` 与 `drum_empty_contact.py`，限定重建参数仍为 `--only-drum-empty`。

实际运行还会优先加载 `/Game/Weapons/AnimationProfiles20261001/ue_hk416/DA_<family>` 的已烘焙修正层。只替换五个 AnimSequence 不足以更新握把版本：旧层是在旧拍击及 2.7 秒动作上计算的，会继续覆盖新基础动作。因此本轮同时重烘四款前握把的 `drum_reload_empty` 项；其余待机、开火、普通换弹等条目保持不变。`import_grip_profiles.py` 已接到正式导入入口，后续重导此动作时同步刷新运行层。无前握把的 drum profile 若没有此动作条目则沿用新基础动画。

## 机瞄

原模型的 `ironsight_low` 已包含前准星、后照门及各自底座。保留其 33,267 个顶点、32,920 个源多边形、原 UV、法线、权重和位置，只分配独立的 `M_HK416_FactorySights` 槽。该槽继续绑定枪体已有上机匣材质，不建立不同外观的新材质。

`SetGunsmithOpticVariant` 的 HK416 分支按实际改造状态显隐该分区，覆盖全息、红点、2 倍镜、LPVO 以及复用全息接口的 EOTH。卸下光学瞄具立即恢复。EOTH 的同型号快捷路径也重新应用隐藏状态。

装备、枪匠草稿预览、动态图标和世界拾取展示原本共用这一装配入口，因此沿用同一状态规则；ADS 标记骨骼保留，原厂机瞄数据和裸枪目录图不变。新增分区可能改变手臂材质索引，导入时仅同步 HK416 的 `hide_source_materials`，保留现有裸手及服饰配置。
