# 201 后握把衔接、右手接触与材质改造

## 定向排查结论

1. 原厂握把顶部约在根空间 Z=-6.44 mm，三个改装握把约为 -5.6 至 -6.3 mm；对应枪身底面约为 +2.6 至 +4.6 mm。截图里的脱接有实际几何间隙，并非仅由照明产生。
2. 现用待机姿态中，右手接触区与后握把中心线错开。应从实际动画姿态调整整条右臂，不通过拉长手指骨骼或改动全枪位置弥补。
3. 原厂握把的有效面片使用 `FactoryRearGrip_R30_Surface`，此前绑定共享金属表面材质；旧的聚合物槽虽然存在，但不能代表实际面片使用情况。
4. 改造栏在 `M4GunsmithPreview.cpp` 同步当前模型和有效材质，最终 UI 材质读取场景捕获纹理，没有发现旧静态截图或强制灰模替换逻辑。现用新側板材质没有法线输入且粗糙度变化很弱；宽泛的预览补光也会削弱平面与倒角的区分。未做渲染对照，不能把截图问题归结为照明单一原因。

## 实施

几何：补充连续的握把肩座，顶部延伸至 +6 mm。三种改装握把的接触区增宽 22%，按各高度的实测截面向原厂握把中心线调整，端部平滑过渡。原始 UV、细节和枢轴保留。原厂握把与肩座均使用可被现有改装逻辑识别的 `FactoryRearGrip` 槽名。

动作：在武器根空间施加目标偏移 (-10,-33,-30) mm，通过固定骨长的两段手臂 IK 求解右臂旋转并保持手部朝向。修正作用于待机、瞄准、开火以及各类换弹回握；离开握把后的姿态逐步退出修正。86 段动作的时间、其他轨道与枪械机械骨骼保留。

材质：以深石墨涂层、聚合物和缎面钢三类表面统一整枪。新建微颗粒、低频粗糙度变化和稀疏细划痕贴图；新平面不用旧模型图集凹凸。小范围倒角顶点色控制露底，避免整面发亮；原有零件保留法线/AO和非金属分区。旧湿润叠层关闭，统一为新的 `WeaponWetness` 响应。私有材质和贴图位于 `/Game/Weapons/LMG201/GripFinish43/`。

预览：仅当场景内可见 201 枪体时，把主方向光从 6 调至 2.5，补光从 3 调至 0.65，天空光从 1 调至 0.28；矩形主光/补光/轮廓光分别乘 0.75/0.45/0.9。切换其他武器时恢复原值。参数是本轮制作设定，尚未经过渲染验收。
