# 学徒长杖：晶辉照明

用户要求右键点按水晶照明，无冷却、无消耗，复用法杖施法蓄力动作。

## 行为与接入

- 当前主手为 `ue_apprentice_staff` 时，右键点按切换照明，松开右键不关闭。不经过技能付款、冷却、修炼、耐久或弹药结算，也没有持续时间限制。
- V32 按用户纠正改为一次完整动作：复用 `StaffCastMotion::Raise` 的完整肩、肘、手部与杖身姿态，0.20 秒非线性抬杖，蓄光停留 0.12 秒，再用 `Recover` 以 0.42 秒收回普通待机。动作结束后照明保持开启；不再将持杖姿态绑定到灯的开关。
- 照明不占用战斗动作锁。普攻从实际当前手姿进入，施法沿现有姿态快照交接，两者收势目标仍为普通待机。重复右键立即切换灯光；空闲手臂从当前动作位置重新播放一次循环，不增加冷却。行走、跳跃等移动规则保持原有逻辑。
- 收起、更换武器、改造装配及结束游戏时关闭并清理；死亡立即熄灭。菜单中的鼠标右键不切换照明。开关仅为当前持械的临时状态，不写入物品存档。
- `StaffIllumination.cpp` 随装配定位实际杖头组件，仅对该组件具有 `StaffLightAmount` 参数的晶体材质创建 MID。原装白水晶及四种替换水晶共用开关，木材和其他共享材质使用者不受影响。
- 单个可移动点光源位于实际杖头包围盒中心，暖白色、1000 lm、8 m 衰减半径，保留墙体遮挡阴影。V32 设置 `InverseExposureBlend=1`；自发光的新增照明分支使用 `EyeAdaptationInverse`，避免发光辨识度随场景曝光改变。单人本地持械使用；预览、掉落物不生成照明灯。
- 动作和亮度渐变在相机前推进；V32 将灯光与 MID 输出移到法杖姿态更新后统一提交。无新增独立 Tick，稳定状态不重复更新材质和灯光强度，装配时缓存材质与灯光引用。
