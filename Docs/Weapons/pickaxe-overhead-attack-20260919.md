# 矿镐双手举顶下砸

后续双臂/肘部修正先见 [第二版自然双臂与命中制动](pickaxe-natural-arms-20260919.md)，最新精调见 [第三版肘部衔接与上下行程](pickaxe-elbow-arc-20260919.md)。当前导入入口读取 `SourceAssets/PickaxeElbowArc20260919`，下述内容保留为第一版制作记录；命中保持由 0.085 s 改为 0.20 s。

用户要求：双手持握举过头顶，向正前方砸下，联动手臂与各关节，避免扭曲。

## 动作来源与设计

当前握姿来自 `SourceAssets/RusticPickaxe20260919/RusticPickaxe_TwoHand_Editable.blend`，保留已经按细镐柄适配的双手握点、手指和当前 Manny 手臂。参考现有符文剑 `AzureRunesword_OverheadV52.blend` 的举起—蓄势—下劈—回握顺序，读取其真实关键姿态、120 Hz、2.60 秒时长和已有渲染动作表；矿镐使用独立空间轨迹和更短的采集节奏，不直接移植剑的握点。

矿镐全程不换手、不滑动抓握。上举时把双手自身抬高，镐柄在头顶略向后倾；下砸主要沿正前方的竖直平面，镐尖转向前下，命中与挥空使用各自收势。没有追加镜头振动。

| 运行时阶段 | 时间 | 行为 |
| --- | --- | --- |
| 双手举起 | 0–0.36 s | 从当前待机经连续曲线抬到头顶上方 |
| 蓄势 | 0.36–0.46 s | 保持整组手臂与工具姿态 |
| 加速下砸 | 0.46–0.60 s | 沿正前下方下砸，0.50 s 播放挥动声 |

| 命中制动 | 命中后 0–0.085 s | 保持共用接触姿态 |
| 命中回收 | 命中后 0.085–0.56 s | 小幅回弹、后收，回到双手待机 |
| 挥空 | 0.60–1.16 s | 下方跟随惯性至 0.69 s，再回待机 |

## 肩、肘、腕与蒙皮

- 双手固定在镐柄局部坐标中；从这两个目标同时解两条肩—肘—腕链，使用原上、下臂骨长。
- 上举由肩带前送和抬升配合，接近最大伸展时补充肩部支撑，不拉长手臂。
- 肘部弯曲平面定义上臂方向，限制肘部转向，同时考虑手腕折角与左右臂向内交叉。求解携带前一帧状态，避免逐帧换解。
- 上臂额外轴向分担限制为 25°；余下旋前按当前 Manny 蒙皮站点分到前臂辅助骨。前臂父骨从肘方向起步，不在已完整扭转的父骨上再叠分数扭角。
- 手指仍使用当前局部旋转，不改指骨位置和缩放。所有骨骼先计算完整目标，再统一还原父子局部矩阵；输出连续四元数符号。
- Swing 接触与 HitRecover 开始共用整套姿态和求解状态。两端包络交还原待机，蓄势与命中停顿冻结完整姿态。

上述为制作约束，不代表已经完成游戏内形变验收。
