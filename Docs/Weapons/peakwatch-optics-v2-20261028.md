# 观峰 3–6 倍镜：独立镜内成像 V2

> 历史方案；当前实现以 [peakwatch-open-periphery-v5-20261028.md](peakwatch-open-periphery-v5-20261028.md) 与发布清单为准。退役实物文件的恢复位置见 `Docs/Publication/HighlandBow20261028/archive-manifest.json`。

2026-10-28 后续分划升级见 [观峰高倍准星 V3](peakwatch-reticle-v3-20261028.md)：简单十字已替换为峰脊细针、角度刻线与拉弓／节拍／穿心反馈。本文件保留独立成像的实现与首次交付记录。

用户要求优化整体屏幕变焦的僵硬感。本版仅为高地长弓的观峰变倍镜开启独立镜内成像；保留现有模型、改造属性、弓动作、节拍／穿心箭与两款传说弓弦机制。

## 表现

- 主相机保留普通弓 ADS 的轻微聚焦，倍率只改变镜内景物。
- UE 第一人称投影保持原来最低 3 倍时的手臂／镜框构图；从 3 倍调到 6 倍时，这些前景模型不再继续膨胀。退出 ADS、切弓或切回性能模式时恢复原投影与组件状态。
- 镜内图像投到原有镜片的实际轮廓：中心取当前弓的瞄准锚点，半径沿用作者脚本的 `1.115 × 1.75 = 1.95125 cm`，跟随弓体变换、画面比例与 DPI，不额外覆盖一个全屏黑圈。
- 滚轮仍每格 0.5 倍。显示倍率采用帧率无关的指数过渡，约 150 ms 完成一次变化的 95%；镜内视野、鼠标倍率与机械环共用该显示值。固定 2／4 倍镜继续原有成像，变倍平滑逻辑不改变固定倍率。
- 中央细分划与箭矢发射相机同源；镜片偏移只改变采样区域，不改变箭矢射向。独立镜内图像覆盖原玻璃的分划，再绘制清晰细十字与小中心点。
- 边缘保留轻微方向性阴影与冷色镀膜，转向、呼吸与撒弦的现有相机动作会影响镜缘反馈。中央不添加强模糊或不透明反光。
- 镜内绘制位于命中反馈、拉弓进度、穿心箭及山鸣／疾律纹样下方，保留当前 HUD 提示。

## 资源与运行范围

- 新增 `BowScopeOptics` 原生对象，沿用弓的更新时钟；只为本地玩家创建场景捕获。无新增复制属性、RPC 或伤害公式。
- 每位本地持弓者至多一个捕获组件和一个渲染目标。关闭瞄准、打开菜单、收弓或第三人称时停止捕获；卸下对应瞄具或角色结束时释放资源。
- 镜内分辨率按实际投影面积在激活时分配，范围 256–1024，普通退出／进入 ADS 复用。捕获不包含自己的手臂与装备；不永久修改远端玩家模型。
- 直接使用运行时纹理与 Slate 圆形网格合成，无新增需导入的材质或贴图资产，不修改已保存的镜体／镜片包。
- 不使用 GPU 回读、同步资源查找或每帧重建渲染目标。SceneCapture 仍有额外渲染成本，实际帧率尚未测量。

## 控制项

- `fps.Bow.Scope.PiP 1`：默认独立镜内成像。
- `fps.Bow.Scope.PiP 0`：单相机性能模式，保留平滑变倍和机械环同步。
- `fps.Bow.Scope.MaxResolution 1024`：镜内渲染目标最大边长；256–1024，下次开镜应用。
