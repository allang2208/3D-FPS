本次限定 RSH 双持换弹。715 共用动作不替换，单持已认可的握姿、五发快速装填器接触和弹药事务继续沿用。

原实现只在退壳点清除库存里的弹壳数，蒙皮弹壳被遮掉后没有独立模型承接；空仓单发装填的清除时点还落在源动作缩小弹壳之后。手臂到退壳末段才下移。

## 制作与接入

- 两侧私有 base profile 的换弹动作增加整组下移轨迹：源时间 0.08–0.48 秒随开仓渐降 18 cm，再平滑交回源动作已有的低位装填段。保留握持相对变换和装填接触。

- 退壳时先采样精确源时间的骨骼姿态，再提交已有退壳事务，最后由有界 FX 池接续独立重力、转动、碰撞反弹及落地停留。显示期间不会跟着枪或镜头移动。
- 空仓单发装填在源时间 1.03 秒接续；快速装填映射同一个 715 退壳时点；部分装填在开仓后清除空壳，保留未发射弹。切换弹种保留原来的插入时提交规则。

- 旧装填器导入入口沿用最新双持 profile；单持 profile 不在本次导入范围。
