用户要求：逐把检查弹壳抛出位置，错误的进行调整。范围为当前 16 款枪械及 10 套左右手双持网格；14 款采用逐发抛壳，两款左轮保留弹巢退壳。

## 依据与结果

从当前正式 UE 网格读取 mesh bind pose，并导出当前几何作离线侧面、顶部对照；同时读取压缩后的 fire / aim_fire 姿态。不能只依据共享 Skeleton 的参考位置：A762、AKM、SVD、PKM、201 的动画另有挂点平移。下表的“原位置”均以实际开火姿态为准。

| 枪械 | 处理 |
| --- | --- |
| M4 | 原挂点在抛壳窗另一侧且偏后上方；移至实际右侧窗口。 |
| HK416 | 实际开火挂点已在窗口内，保留位置。 |
| QBZ191 | 从另一侧的后上方移至实际窗口。 |
| A762 | 动画内的实际挂点正确，保留位置。 |
| AKM | 动画内的实际挂点正确，保留位置。 |
| ASH-12 | 从前护木附近移至弹匣上方的后机匣出口区域，前后纠正约 30.4 cm。 |
| M16A2 | 从防尘盖铰链附近提高至抛壳窗。 |
| SVD | 实际开火点位于窗口前下方，移入机匣开口；不是将参考姿态的瞄具附近挂点当作运行时位置。 |
| PKM | 保留开火姿态中正确的前后和高度，只向外让开约 4.4 mm；侧向速度改为出口朝外。 |
| 201 | 挂点从窗口后缘前移约 2 cm，侧向速度改为该模型出口朝外。 |
| M1911 | 出壳点向前移入套筒窗口，继续跟随套筒。 |
| G18 | 从窗口后下缘移至窗口中部，继续跟随套筒。 |
| Pit Viper 2011 | 改正左右侧并抬入窗口，继续跟随套筒。 |
| Super90 | 从后方拉机柄轨道移至前方抛壳窗；修正由瞄具骨旋转轴导致的反向抛出。 |
| DW715 | 射击不执行逐发抛壳；保留 WPN_Case 各弹巢骨骼的原装退壳动画。 |

PKM 的弹壳口与上方出链口分开处理；其弹壳从左侧机匣口排出，见原厂结构资料对应的 [PKM 技术手册，0002–0003 节](https://thekalashconnection.com/pdf/TM-8370-50107-PKM-Org-RPSTL.pdf)。游戏中的具体坐标仍取自当前资产。

## 接入

- `Source/FPSGAME/Weapons/CasingPortCalibration.h`：14 款逐发抛壳枪的当前网格校准表，单位为枪根坐标中的物理厘米。
- `FPSWeaponFXComponent::Initialize`：按当前网格绑定位置，将校准点转换到机匣或套筒坐标。方向由参考姿态中的准星、照门和枪口位置构造，避免将手枪 / Super90 的瞄具骨轴误认作枪身上方向。
- `SpawnCasing`：从实际枪体采样一次出壳变换，沿该枪出口的外侧抛出；离开后保持世界空间运动。手枪也使用各自枪身坐标和持枪者速度，适用于转枪、左右手双持和既有第三人称变换。
- 左手枪体没有镜像：M1911 / G18 / 2011 的左右手继续使用同一物理窗口，不能只因在左手就翻转出壳方向。
- 弹壳池、出壳频次、弹药、开火间隔、镜内隐藏规则保持原有逻辑。无需重导入整枪或覆盖已有动画、材质。
