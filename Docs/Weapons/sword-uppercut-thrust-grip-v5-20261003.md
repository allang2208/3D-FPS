# 上劈 V5：第三段突刺握法与向上挥劈

用户再次反馈动作不符，并最终明确为「虎口侧出刃、翻掌转前臂后的反手上挑」。当前版本见 [翻掌反手上挑 V6](sword-uppercut-backhand-v6-20261003.md)，以下为 V5 历史制作与保存记录。

2026-10-03。用户要求将上劈持刀动作改用普通攻击第三段的突刺手型，并重新处理上劈动作。V4 的待机整组平移不作为本次动作基准。

## 本轮动作

- 0–0.42 秒：采用当前第三段突刺从待机到蓄势的完整腕肘与抓握关系，同时向屏幕右下方藏剑。
- 0.42–0.48 秒：短暂蓄势。
- 0.48–0.70 秒：手臂绕肩线自下向上挥动，同时复用突刺伸臂的关节配合。剑身随手臂在前上方扫出上升弧线，出手段为 0.22 秒。
- 0.70–0.77 秒：小幅上挥余势。
- 0.77–1.317 秒：复用突刺的收臂并解除上挥摆角，末帧回到当前待机。

持握供体为当前安装的 `A_RuneSword_Thrust`。标准柄读取 `/Game/Weapons/AzureRunesword20260913`；长握柄按当前运行的 `DA_Sword_LongGrip` 中 Thrust／Idle 的基础动作与局部差量还原，而非照搬旧长柄文件。两套母版均使用当前 V7 裸手、裸臂。

制作时对完整供体骨架施加围绕肩线的统一俯仰变换；腕、肘、手指及 twist 辅助骨保留供体在对应动作时刻的相对关系，避免为追剑刃单独掰腕或另设肘极。出手时额外俯仰从 −60° 到 +55°，余势到 +60°；这是视模整体运动参数，不是腕关节角度。供体自身伸臂与弯肘继续变化，不是冻结一帧后平移。

此制作方法与作者参数不等于实机视觉验收。未改变普通攻击第三段本身，也没有改手模权重、骨长、技能数值、修炼、人物位移或镜头。
