# PKM / 201 左上臂解剖铰链修正：ArmHinge55（2026-09-30）

用户反馈：PKM 和 201 换弹时，左手上臂被拉伸拧转，看上去比小臂还细，属于明显的模型动画处理错误；要求检查原模型上臂与肘关节结构，并重新调整。

## 原模型结构（排查结论）

- PKM V7 裸臂（201 使用同一套）的上臂蒙皮**完全不绑主骨 `upperarm_l`**：肩侧一半由 `upperarm_twist_01` 带动（根部环带另有约 16% 锁骨权重），肘侧一半由 `upperarm_twist_02` 带动；肘带由 `twist_02` 与 `lowerarm` 混合。前臂按 0、1/3、2/3 三个站位分给 `lowerarm`、`lowerarm_twist_02`、`lowerarm_twist_01`，腕部接 `hand`。
- 绑定姿势中，肘部绕上臂辅助骨的局部 Z 轴弯 39°。这个轴就是这块皮肤的解剖铰链。

## 错误原因

PKM LeftArm48 引入了"连贯骨段"约定（201 的 ClothReload44.2/44.3 也照此制作）：前臂整体跟随掌宽方向，上臂辅助骨再把这个框架沿肘弯传递回去，等于把手掌的滚转带进了上臂。支撑和换弹姿势下，上臂辅助骨偏离实际弯曲轴的角度：

| 动作 | 偏离 |
| --- | --- |
| PKM 待机 / 扶握 | 约 159° |
| PKM 换弹 | 最多约 ±176°，快速换手时每帧可达 60° |
| 201 基础待机 | 115°（手臂接近伸直） |
| 201 换弹 | 2–111° |

肘部因此逆着皮肤的解剖方向折弯，上臂绕自身轴拧转，截面显得比小臂细。

## 修法（`SourceAssets/PKMLowpoly20260922/ArmHinge55/`）

逐帧保持肩、腕位置和手的世界矩阵，手指、右臂、枪械、弹链及其他轨道都不动，骨长精确保持：

1. **上臂**：辅助骨的局部 Z 对齐实际肘弯轴，肘部回到纯铰链弯曲。
2. **前臂**：从解剖肘端到手掌之间的旋前/旋后，按真实站位 0、1/3、2/3、1 线性分配，上限 ±110°（用户选择）。
3. **肘位微调**：肘部可在肩—腕圆上移动，最多约 6 cm（平滑后最大 7.4 cm），用来减少超出上限的部分。仍然超出的那部分，以较小角度留在上臂，并同时作用于肘两侧，肘部仍是纯铰链。
4. **稳定性**：
   - 手臂接近伸直时，弯曲轴沿用上一帧，避免弯曲平面失稳。
   - 旋前取 −180..180° 的解剖分支。
   - 肘位与前臂分量做时间平滑；片段首尾固定为逐姿势的确定值，保证同一待机姿势在各个片段里完全一致。

**范围**：PKM 与 201 左臂的全部现用动作，共 160 条。
- PKM 60 条：基础与四类配件的待机、瞄准、开火、装备、检视、冲刺、近战、换弹。
- 201 100 条：BeltFeed08、Accessories22、Magazine24、Drum46、ClothReload44 目录下的全部动作，包括已退役的金属弹链换弹资产。

## 离线结果（`check.py` / `check.json`）

- 手持稳定且肘弯超过 30° 的姿势里，上臂偏离铰链：最大 179° → 54°。退役金属弹链资产 `A_LMG201_reload_belt` 仍为 167°，它不在运行时加载路径上。超过 45° 的只剩 2 条，超过 30° 的 19 条（大多是 PKM 待机衍生姿势约 37°：前臂已到 110° 上限，剩余部分留在上臂）。
  - PKM 待机：159° → 37°，前臂 −110°，肘位约 −24°。
  - 201 基础待机：115° → 约 3°。
  - PKM canted 待机：16° → 0°。
- 源动画中手快速翻转、经过解剖上不可能区域的片刻，前臂会在约 8 帧内反转，上臂短时滚转。原动画在同样位置本来就有每帧 60° 的上臂急转。
- 手的世界矩阵误差为 0；骨长误差小于 1e-13 cm；片段首尾与对应待机最大相差 1.6°。

## ArmHinge55b：肘窝月牙凹陷与废案排除（同日）

用户截图：201 换弹时手肘内侧有一道错误的凹陷。

**排查**：在 201 换弹大角度弯肘的时刻（1.74、4.30 s 等）出了肘部特写（`Diagnostics/elbow/`），用排除法定位：
- 月牙形折痕只在 ArmHinge55 之后出现，之前只有正常的肘窝横褶。
- 改变前臂旋前的分配，或者完全去掉旋前，月牙都还在，所以和前臂旋前无关。
- 只做绑定铰链上的纯屈肘测试（左右臂各一），只有普通折褶，说明不是权重本身的问题。
- 把上臂与肘端整体绕肢体轴扫 −30° 到 +45°：0° 到 −30° 出现月牙，+15° 到 +30° 只剩正常的肘窝横褶。

结论：这块皮肤建模时的肘窝褶皱，和绑定姿势的弯曲轴偏了约 20°。修正前那一版的上臂正好偏了 15–19°，所以没有月牙。

**修正**：解剖肘端框架加 +20° 的褶皱校准（`author.py` 中的 `CREASE_ROLL`）。肘弯 30° 以下不加，70° 以上加满，前臂 110° 上限和剩余量的逻辑不变。修正后 201、PKM 的肘部特写都只剩正常褶皱（`Diagnostics/elbow/final.jpg`）。

**废案排除**：运行时不加载的 20 条 201 旧动作不再处理，并把它们的包恢复成本轮之前的原字节（`exclude_retired.py`、`retired_restore.json`；ArmHinge55 v1 的结果另存于 `Retired_ArmHinge55_v1/`）：
- BeltFeed08 的 `reload`、`reload_empty`、`reload_belt`、`reload_belt_empty`；
- Accessories22 四类握把各自的同名四条。

`reload`、`reload_empty` 在运行时实际读的是 Magazine24，金属弹箱已退役。现在的范围是 140 条：PKM 60 条，201 80 条。

**接入**：`revision=ArmHinge55b`，后台 commandlet 分两次写入，共 140/140（`delivery.json`）。
