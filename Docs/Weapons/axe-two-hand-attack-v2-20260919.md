# 伐木斧双手攻击 V2：腕肘支撑与非匀速节奏

后续用户确认方向，并要求右后蓄势、左下快劈、嵌入撬柄和同步镜头；最新为 [V3](axe-two-hand-attack-v3-20260919.md)，本页保留 V2 记录。

用户反馈 V1 手腕扭曲、攻击过于线性，要求查找 GitHub 双手武器动作并继续优化。本版仍是单击一次完整采集攻击，保留 H3 待机、双手柄上握点和指形；仅制作并接入 Swing / HitRecover。

## V1 问题与 V2 制作方法

读取原 V1 的接触姿势时，左腕中立前臂方向与实际肘腕线夹角约 108.5°，带出约 117.3°；这是源姿态的腕折角，不是皮肤相交率或视觉验收。原轨迹把柄轴转到 158°，手掌已朝向后侧，而肘仍按固定向下/外极向解算。

本版同时改动空间与关节支撑：

1. 旋转范围改为蓄势约 -14°、接触 48°、带出 82°；右上提举主要由柄轴仰角 55° 和双手位置共同完成。挥砍向左下移动，回收绕低处形成弧线。
2. 握点保持 `hand = WPN_root × grip_local`。用掌面对应的中立前臂方向在两骨肘部可行圆上确定肘位，保留向外/向下偏好及有限转角。骨长、缩放、手指与蒙皮权重不改。
3. 上臂从 H3 待机的骨段框架连续搬运，肩部在有限范围内承担肘缝的轴向差。剩余旋前才分配给前臂骨和 twist 辅助骨；分配位置从本斧手模的实际主导权重顶点读取，不硬套剑案例比例。
4. 不在已完整扭转的父骨上叠加另一份分数扭角；所有目标先缓存世界矩阵，再按父子层级还原局部姿态。两端包络回到 H3，四元数符号连续。
5. Swing 接触处的完整姿态与求解状态直接交给 HitRecover，并在短停区间冻结整组姿态，避免只停斧头而手臂继续变化。

以上是已实施的制作方法，不是新版本关节画面已通过的结论。

## 节奏

| 实际时间 | V2 动作 |
| --- | --- |
| 0–0.06 s | 轻微下沉、回收作为预备 |
| 0.06–0.245 s | 连续弧线向右上提举 |
| 0.245–0.312 s | 蓄势短停，约 5 mm 的压实变化 |
| 0.312–0.435 s | 开始发力，逐渐加速 |
| 0.435–0.52 s | 主要快速挥砍；0.48 s 保持唯一采集接触点 |
| 空挥 0.52–0.73 s | 左下惯性带出并开始收回 |
| 空挥 0.73–1.10 s | 低处弧线回握，末端减速 |
| 命中 0.48–0.508 s | 双手与斧头共同制动约 28 ms |
| 命中 0.508–1.10 s | 轻微回弹、低位抽回，再恢复待机 |

姿态参数由分段单调三次 Hermite 曲线驱动，中间过路姿势不逐段归零速度；只有蓄势与动作末端明确停下。300 Hz 烘焙样本间采用 LINEAR 插值，用于保留作者曲线，而不是让整段动作匀速。

总时长仍为 1.10 s，接触 0.48 s，挥动声沿既有时钟在 0.312 s 触发，与 V2 发力段起点一致。作者片段仍为 Swing 0.68 s / 接触 0.24 s，HitRecover 0.44 s，不改运行时代码、存档、体力或采集结算。
