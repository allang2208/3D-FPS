# 两款传说挂坠连接与连锋 Buff 修复

用户要求：修复连锋坠、一决坠未接绳；将连锋叠层接入左上角状态栏；检查实际伤害结算。

## 连接问题与修复

- 原穿孔绳来自 Blender 作者坐标，末端中心在 Y≈+7.28mm；新坠体与环扣误用了导入后的 UE 坐标 Y≈−7.28mm。正视图看不出前后错位，实际两者相隔14.55mm；最接近的环扣表面距绳面仍约9.71mm／9.52mm。
- 保留原绳与刀柄穿孔的连接，将两款坠体、环扣及附属发光几何整体沿作者 Y 移动+14.55188mm。保留造型、UV0贴图、材质槽、UV1发光分区；不移动原穿孔绳。
- 修复后的连接环与绳面最小顶点距离分别约0.051mm／0.048mm。此为几何测量，不替代游戏视觉体验。
- 重新分配8个物理导向点：绳子下端、环扣和刚性坠体统一绑定导向段5，柔性绳在上方连续插值，避免把扣环与坠体绑到互不相干的摆动段。主体、晶核、光痕共用刚性变换。
- 作者与运行坐标明确分开：model.json保留author_guides_cm，运行spec按FBX的(1,−1,1)映射写入guides_cm；材质常量、运行配置、两个光源局部位置一起更新。
- 原始母版保存在 SourceAssets/KukriPendantRepair20261030/Relentless_Before.blend 与 Decisive_Before.blend；修复后的可编辑母版、FBX及图标仍在各自ProductionV1目录。作者脚本同步修正，重制不会恢复错误接口。

## 左上角连锋状态

- 复用 StatusEffectsComponent → StatusEffectsHUD，不另建角落文字或独立倒计时。
- 主手、副手分别显示「主手连锋」「副手连锋」，使用叠片造型图标和层数角标；满10层为金色。
- 提示内容读真实组件：本刀当前层数、下一次出手伤害增益、韧性增益及下一次减层倒计时。每层伤害+3%、韧性伤害+6%，满层+30%／+60%。
- 层数在一次出手首次有效命中后增加，新层从下一次出手生效。同次攻击多目标不额外加层；双持各自叠层。停止命中4秒后进入每0.5秒减层，首次减层在4.5秒；切换、拆卸或死亡清除。
