# SVD 弹匣内部与换弹包握修订

> 本文保留该阶段的制作与检查记录。当前认可的换弹手型、最新材质／接口及归档恢复边界，以 [SVD 发布说明](svd-publication-20260923.md) 为准；旧版本的导入成功不代表最终手型获认可。

用户反馈上轮握匣不贴合、弹匣中间镂空。本轮先补原厂弹匣可见内部，再参考 AKM／A762 后续抓握经验重新适配左手。

接入已完成：1 个模块化视模与 10 条换弹动画已在现有 UE 会话中经互斥批次导入并保存，逐项保存回执位于本轮作者目录。未新开或重启编辑器，旧资产已备份。

模型沿实际口缘补厚边、内壁和下沉托弹板，保留原厂外壳、冲压纹路、UV、材质与骨骼座位。新增内部绑定同一弹匣骨骼，换弹时随原部件运动；使用已有 SVD 接口钢材及其干湿映射。

抓握采用用户认可的“四指绕前缘、拇指从后缘对握”方向，以 `RifleMagazineGrip20260922/IndexClearanceV4` 的成组姿态为输入，再按 SVD 的真实短匣截面调整掌面、指腹、整手方向与腕臂。前后分区与固定指腹表面共同参与制作，不再使用早期 M4 手型对整个弹匣凸包寻找任意最近点。保持原骨长、局部位置、缩放、rest 和蒙皮。

普通／空仓的原厂及四种前握把共 10 条动作同步。取匣时准备张开的对握手型，持匣和压实保持固定手匣关系，压实后分指松开并向外侧退让，再恢复对应护木或前握把。保持 120 Hz 源时钟、动作总长度、右手拉栓、弹匣机械轨道和补弹/音效事件。待机、射击、装备、冲刺、检视和快速近战沿用上一轮资产。

完整源、导入入口与回执见 [SVDMagazineFit20260923](../../SourceAssets/SVDMagazineFit20260923/README.md)。沿用现有运行模型与动画路径，无 C++ 修改；旧资源逐项备份。

没有运行修复后的渲染、PIE、游戏或动作回归。制作中的接触参数不代表实际视觉通过，旧检查图片也不作为本轮结果。实机观感由用户测试。
