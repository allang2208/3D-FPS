# 步枪与狙击步枪统一腰射构图（2026-09-30）

用户要求步枪和狙击步枪统一规格，机枪由其他任务调整，本轮不改机枪。

## 适用范围

仅 `ue_m4a1`、`ue_hk416`、`ue_qbz191`、`ue_akm`、`ue_m16a2`、`ue_ash12`、`ue_a762`、`ue_svd`。PKM、201 轻机枪、手枪和其他武器不进入新标定。

## 统一规格

以当前 M4 `/Game/Weapons/M4ContactImpactFinal/A_AKM_idle` 的第 0 帧为参照。使用现有 `M4HipViewmodelLocation=(0,7,-7)` cm、基准旋转 `(0,90,0)` 和原模型比例。

每把步枪读取自身待机动画的右手腕 `hand_r`、枪根 `WPN_root`、前后瞄点。AKM 使用现有 `AKMSoviet::Rear/Front` 实测局部点，其他枪使用动画内的标记。求出整组枪与双臂的刚体位置和旋转，使：

- 右手腕在相机空间的位置和深度与 M4 相同。
- 前后瞄点定义的枪身朝向，以及枪根定义的上方向，与 M4 参照一致。
- 模型尺寸、双手与枪的相对接触、枪口和配件挂点保持原样。

这定义了共同握持位置、透视深度和朝向；枪管长度、机匣外形、瞄具高度不同仍会产生不同轮廓，不拉伸模型或要求整枪包围盒重合。

## 状态与性能

`FRifleHipFraming` 在换枪时建立参照，在实际待机动画因前握把或弹鼓切换时重新求解。仅缓存当前动画和结果，逐帧相同动画直接返回；不追随当前帧骨骼，不抵消呼吸、后坐力或动作，不在 Tick 加载资源。

原 `HipViewmodelLocation` 保留为动作空间及资源缺失时的回退；活动腰射使用新求解结果。原 M4 系列的换弹/检视/快速近战继续回到 `M4ActionViewmodelLocation`；AKM/A762 的这些动作保留旧腰射锚点作为其原工作空间。位置与旋转按同一动作权重过渡，拔枪从新腰射位置开始。ADS 继续独立使用原有前后瞄点、眼距及倍率标定，新腰射参数不叠加到 ADS 目标。

后续用户反馈换弹结束闪回，已补充[换弹收尾交接](rifle-reload-handoff-20260930.md)：保留动作工作空间，但在换弹结束前回到统一腰射位置与旋转，末段接续当前握姿。该项编译及未测试状态独立记录，不沿用本页初次构建结论。

没有改模型、手模、动画资产、机枪文件、弹道、数值或存档。不需要导入新资产。
