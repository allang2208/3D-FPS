# 贯雷切换武器后无法召回

后续交互以 [贯雷投掷、切装与收纳](guan-lei-throw-lifecycle-20261031.md) 为准：投出和落地等待期间允许切换，主动召回至接稳期间暂时锁定切换。本文及末尾 32 项结果保留为此前修复记录，并不代表后续生命周期变更已测试。

用户反馈：投出贯雷锤子，切到另一把武器再切回，普通攻击键无法收锤。

## 原因

切回时 `RefreshHeldTool` 的异步资源完成回调无条件把本地 `EquipElapsed` 设为 0，进入装备动画。锤子在外面时，`UpdateHandPresentation` 在装备时钟推进前直接返回；返回／接锤分支也会提前返回。因此装备状态不会结束。角色 `FirePressed` 首先通过 `IsSwitchingWeapon` 检查装备状态，输入被拦截，无法到达 `HandleThunderPrimary`。

场上锤子的 `ThrownHammer` 和 `ThunderAwayInstance` 原本就跨切换保留，本轮继续沿用这套实例归属。

## 修改

- 切回已投出的同一武器，资源完成后使用待机取样，跳过手持装备动画；武器和手臂仍按原有投出／召回状态显示。
- 手臂更新时清退已有的装备计时，兼容网络投出状态晚到、资源回调先完成，以及旧会话中已经卡住的计时。
- 等待手部资源完成后才接受召回；加载期间不创建缺失动作的接锤过程。
- 切换／取消本地动作时清理召回手势和本地等待标记，保留场上锤子及其返回阶段。切回返回中的同一锤子时恢复手势和接锤回执。
- 不改变投掷、旋转、召回轨迹、伤害、音效、落雷或装备数据。
