# SVCH 快速近战右手修订 R3

用户再次否定 R2：右臂和手掌仍有明显扭曲。R2 的骨长、接触点检查不能代表手部表面合格。

## 原因与修订

- R2 回位段分别混合关节位置和旋转，导致上臂、前臂的原生骨轴没有对准下一级关节；子骨骼的局部平移被用来补偿旋转。主关节的世界位置和骨长看起来正常，但手腕及扭转辅助骨骼偏离原生局部位置，蒙皮随之拉扯手掌。
- R3 恢复主骨骼朝向与原生局部关节偏移，并连续分配右前臂旋转。V9 网格、绑定、权重和原有修形不变。
- 右手使用当前认可的待机握把手形。枪体与双手围绕原有枪托接触点调整角度，减轻腕部侧弯；保留 0.9 秒时长、1/6 秒接触时间和枪托接触轨迹。左臂整体随枪，保留原有局部肘腕姿态。
- 实际动画图视角复查发现 SVCH 宽枪托与右前臂相交，再增加右肘向外避让：手掌和枪体固定，支撑链绕手掌整体转动，骨长与原生局部关节偏移保持不变。制作端逐帧枪托/前臂邻近表面检查已不再检测到画面内超过 0.5 毫米的穿入。
- SVD 原生蓝色法师手套没有 V9 的关节修形，握持时本来就有局部布面翻折。按原生手指与左右侧映射 27 个已有 V9 右手修形，并在握持修形中局部整理布面，额外位移最大 2.505 毫米。手套静止网格、绑定、权重、材质槽不改。
- 肘部避让后，手套拇指局部又出现两片近乎共线的小面；用最小位移约束修正握持修形，单步最大约 0.017 毫米，未扩大整片手套平滑范围。
- 五套 SVCH 姿态只替换 `quick_melee`。普通/空仓换弹、左手拉栓、检视、SVD 共享动画文件均保留。

## 文件与范围

制作目录：`SourceAssets/SVCHReplacement20261018/QuickMeleeHandR3_20261019/`。

`author_hand.py` 生成姿态；`check_surfaces.py` 使用安装的 V9 网格和实际修形评估手表面；`glove_correctives.py`、`install_glove.py` 制作/安装手套修形；`install_profiles.py` 仅合并目标动作并核对其它动作未变化。

最终制作顺序还包含 `avoid_stock.py` 和 `refine_glove_thumb.py`；重新生成时应使用这一最终顺序，不能只运行第一版姿态脚本。

`SVCHReview.cpp` 增加显式 `-SVCHHandOnly` 无界面诊断分支，输出实际 Gunplay 动画图的骨骼、动作混合量、修形权重和外观载体。该分支不改变正常游戏行为，不写玩家存档。

构建另遇到 `ColdSteelProfileTransfer.cpp` 引用不存在的四个 `Property*.h`，以及容器分支外重复的非法 `else if`。包含改为这些类型所属的 `UObject/UnrealType.h`，删除外层重复分支；保留容器分支内原有的负数处理及其它联机逻辑。

后续增量构建遇到 `TransitLoadingSubsystem.cpp` 忽略 `[[nodiscard]]` 返回值，将本来就要裁剪的局部密码字符串改用 `TrimStartAndEndInline()`。
