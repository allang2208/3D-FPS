# Super90 R22：按其他枪械标定换弹屏幕反馈

用户要求参考其他枪械的屏幕抖动强度。本轮只调整 Super90 快速装填的相机接触反馈，保留 R21 已保存的枪体、右臂与抓握拉栓，保留 R20 左臂避让、完整推动、动作速度、原声、一次补满及 60 ms 射击间隔。

## 项目内强度来源

实际消费者为 `Source/FPSGAME/Weapons/WeaponActionCameraComponent.cpp`。M4／HK416 共用普通／空仓换弹响应；PKM 的换箱主段复用 M4，拉栓段采用 ASH-12 的强度。

当前默认 `Strength=2.8`、角色 `CameraMotionScale=0.45`；`ImpactStrength=2.6` 在消费者中上限为 2，因此接触输出倍率是 **2.52**（非 ADS，`fps.Camera.ActionShake=1`）。本轮沿用此实际倍率，不改全局配置或其他枪械。

| 接触 | 参考源俯仰 | 默认输出俯仰峰值 | Super90 用法 |
| --- | ---: | ---: | --- |
| M4／HK416 压实 | +2.00° | +5.04° | 较强参照，本轮不直接照搬 |
| ASH-12 对接 | -0.35° | -0.882° | 对接使用相同角度和位移；推动阻力使用一半 |
| ASH-12 压实 | +1.10° | +2.772° | 推到底使用相同角度和位移 |
| ASH-12／PKM 后拉 | +0.35° | +0.882° | 空仓与 cycle-only 后拉使用相同角度和位移 |
| ASH-12／PKM 复进 | -1.25° | -3.15° | 空仓与 cycle-only 复进使用相同角度和位移 |

表中数值是代码接触脉冲的设定峰值，不包含参考轨迹、跑动或其他反馈的叠加，不是实机测量。

## 曲线与接入

R21 将枪体附加角度的小比例延迟响应烘进相机曲线，且随参考背景一起归一化；没有进入其他长枪共用的接触强度层。本轮移除这部分 R21 相机附加曲线，继续保留 R16 的实测参考背景轨迹，并在 `Super90Loader` 中单独生成接触冲量。

对接、推动、压实、后拉与复进均读取 `Super90LoaderAudioReference` 的既有源帧。相机反应延后 1.4 源帧，使用项目共用的起幅、短保持、反向回弹、收敛包络。角度和厘米位移一起通过共用 `ImpactScale`；仅参考背景轨迹继续归一化。没有额外侧倾冲量，侧倾沿用参考视频轨迹。

普通补弹不出现拉栓反馈；空仓补满保留完整后拉／复进；cycle-only 使用自己的接触帧。末次冲量在源动作结束前归零。机械声音回调不追加相机冲量。
