# 符文长剑模块化与改造栏

物品沿用 `ue_rune_sword`。本次完成原装剑刃、护手、握把、配重锤四类拆分；三款护手、三款握把使用原装安装端，配重已升级为六款剑类共用设计，剑身Ⅱ沿用剑刃表面符文。剑身Ⅰ三个既有数值选项继续使用原装外形，界面明确标注。

共用装配入口按武器 ID 读取独立模块目录，连接持剑、改造预览、物品预览和世界掉落；长柄同时移动配重锤并选择现有长柄动作家族。原整剑、原始手模身份、普通动作和存档实例保留。攻击刃端继续读符文剑原动画骨轨道；柄尾砸击取装配后的实际柄端。

改造栏顺序为剑身Ⅰ／剑身Ⅱ／护手／握把／配重锤，新增符文剑专属实际部件图标，保留原冷钢背景和响应布局。右侧显示相对本栏原装的组合实值／差值，数值来自原业务求值；总览显示三段连击、独立快速近战、重击总伤害与条件激励倍率。没有改变改造倍率或保存字段。
