# 通用弓体重新定位（BalanceV5）

适用猎弓与高地长弓的共享弓体目录。高地长弓的远峰重弓体继续作为专属上位参照；未改变模型、瞄具、手部姿态或箭种。

| 弓体 | 收益 | 代价 |
| --- | --- | --- |
| 强拉力弓胎 | 物理伤害 +5%，穿心箭伤害 +30% | 体力消耗 +50% |
| 游隼弓体 | 拉弓速度 +35%，体力消耗 −30% | 武器总伤害 −20%，最大飞行距离 −25% |
| 磐木弓体 | 最大飞行距离 +20%，武器总伤害 +15%，子弹速度 +15% | 拉弓速度 −30%，体力消耗 +50% |
| 细枝弓体（原静枝） | 腰射散布倍率 −40%，拉弓速度 +15%，搭箭耗时 −25% | 武器总伤害 −15%，最大飞行距离 −25%，体力消耗 +20% |
| 远峰重弓体（专属参照） | 最大飞行距离 +30%，武器总伤害 +25% | 拉弓速度 −25%，体力消耗 +40% |
| 穿云弓体（专属特殊改造） | 最大飞行距离 +45%，暴击伤害 +75%，物理伤害 +10% | 拉弓速度 −35%，体力消耗 +55% |

体力变化分别写入放箭消耗 `stamina_mult` 与持续拉弓消耗 `charge_stamina_mult`，上述六种弓体两者同幅变化。属性面板分开显示单次体力与每秒持续耗体，不将速率误标为持续时间。角色动作耗体修正仍只乘一次。魔法箭雨沿用独立魔法技能的资源规则，不套用普通弓箭的持续耗体改造。

说明沿用统一百分比口径：暴击伤害写 `+N%`，内部额外伤害比例仍累加。详细面板对应字段为“暴击伤害加成”“拉弓速度加成”“体力消耗”“持续拉弓耗体”；范围统一为“最大飞行距离”，箭矢初速沿用共享字段“子弹速度”。这次仅统一说明，原有数值与计算方式不变。

强拉力于 2026-10-27 按用户要求调整：物理伤害 +5% 同时乘基础物理与附加物理，魔法伤害部分不变；学会穿心箭、完成满拉并超过蓄力门槛后，在技能原有伤害倍率上乘 1.30。体力消耗改为 +50%，删除原普通拉弓速度 −30% 和穿心箭专属蓄力速度 +20%，不修改穿透次数、箭速或等级成长。

穿心箭与普通拉弓统一使用相同速度倍率。无加速时基础门槛仍为 3 秒，实际门槛为 `3 × 本次实际满拉耗时 / 武器基础满拉耗时`；装备、改造、附魔、技能和完美节拍的拉弓加速同时影响二者。既有满拉要求与从实际拉弦开始计时的规则保留。现有本地释放、服务端释放、蓄力进度条共同调用 `HeartPiercingArrow::ForModel`，运行时传入本次拉弓会话的满拉耗时；技能详情的当前值与下一等级值读取当前装备，完整成长表保留技能基础值。

游隼以持续快拉与节省资源换取单箭威力和远射能力；细枝将快射收益更多放在搭箭间隔和腰射散布，持续耗体反而上升。磐木的伤害和射程低于远峰且拉弓、体力代价更大，以独有箭速增益形成侧重。强拉力以少量常驻物理增伤和穿心箭条件增伤形成侧重，承担比远峰更高的耗体代价，没有远峰的射程加成。远峰已去除暴击伤害加成；穿云新增物理伤害 +10%，同时作用于基础物理与附加物理，魔法伤害部分不变。

## 退出满弓稳定时长

`Hold` / `hold_mult` / `HoldTime` 退出属性计算与面板，当前 `bows.json` 不再提供 `hold_seconds`。呼吸晃动沿用固定 2.2 秒渐增，仅为表现参数；持续持弓与穿心箭由体力和松手控制，耗尽时取消，不自动射击。

曾使用稳定时长的其他配件改为实际持续耗体：棕色蜡麻 −10%、编织蜡麻 −8%、薄革速握 +10%、软革稳握 −20%、轻量快弦 +10%。保留各件原有其他属性，说明去掉过时的稳定时间文案。持续耗体走已有每帧体力更新的本地／权威模型，读取物品使用项目已有 128 项 JSON 缓存，不重新计算整套伤害面板。

## 删除与旧存档

删除可选项 `woodcrafted_heavy` 和高地长弓对应外观覆盖。原静枝保留稳定 ID `steady_limb`，仅显示名改为细枝，因此既有装备继续有效。

旧保存的手制磐木在 `Normalize` 中按 `heavy_limb` 读取；原始 ID 作为已付材料记录保留到下一次成功应用改造。应用时通过既有材料事务返还两件 `woodworked_bow_limb`，再写入正规磐木或玩家选择的弓体。背包放不下时保持原配置与材料记录，提示整理背包；失败不会吞掉弓臂，也不会反复返还。木制弓臂物品和其他木工生产内容未删除。
