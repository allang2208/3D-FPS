## 动作

| 时间 | 处理 |
| --- | --- |
| 0–0.32 秒 | 从当前待机翻掌、转前臂，形成视频中的双手关系 |
| 0.32–0.54 秒 | 两手与剑向右下方下沉蓄势 |
| 0.54–0.60 秒 | 短蓄势 |
| 0.60–0.83 秒 | 右手带护手快速前送、抬升，左手跟进控制柄尾；剑柄从下倾转为上倾 |
| 0.83–0.94 秒 | 沿正前上方延续上挑，切段保留连续速度 |
| 0.94–1.06 秒 | 收住惯性 |
| 1.06–1.70 秒 | 降手、转回原待机，首尾使用当前待机姿态 |

参考主要来自视频第二次示范 6.2–9.4 秒：起手握姿、7.6 秒低点、8.3 秒抬升、9.3 秒带出。视频未完整显示肩肘、游戏待机切入和回位，这些部分为适配第一人称骨架的新制作。

主攻击段使用新写的正前方纵向剑路，不再反放 V6 的斜劈轨迹。柄尾侧与护手侧在同一个刚性剑柄上，靠俯仰变化形成两手不同的抬升量。切段保持双手相对握距和握柄接触，刀刃宽轴沿切削平面。翻掌与回位沿柄周转动抓握接触，避免把接触点直线插值穿过柄心。

手形复用原生 Slash2 的闭握与回位关节供体，分别结合标准柄和当前长握柄差量。双段手臂按原有骨长求解；前臂随手掌携带旋转，再以最短摆动对齐肘腕方向；上臂沿同一旋转基准对齐肩肘方向。前臂、上臂的两根 twist 辅助骨及锁骨分别跟随完整骨段变换。未更换 V7 裸手模型或修改蒙皮权重。
