# 冲刺下砍与第三段突刺的手臂开口处理

> 2026-09-23 用户复查：V1 已落盘，但高地双手剑仍反馈穿帮，不能视为问题已解决。下文是当时基于源姿态的制作记录；后续发现突进发生在相机缓存后的时序风险，详见 [高地双手剑复查与新方案](highland-arm-opening-review-20260923.md)。

本次按用户授权先修动作，覆盖标准柄、长柄的 `Thrust`、`Overhead` 和 `SprintOverhead` 共六条动画。

将伸展时过度向前随动的肩部小幅收回，再按原骨长、原肘弯曲平面求解双臂。突刺肩部最多后收 4 cm／下移 2 cm，下砍最多后收 2 cm；手与剑保持同一持握整体，最多回收约 3.45 cm。修正覆盖露出区间及其前后平滑过渡，保留原动作时长、掌指握姿、伤害时钟和一米突進逻辑。

基于当前手模的实际上臂开口及其蒙皮制作约束后，所选参考视野下无需增加隐藏延长段；本次未改手模拓扑、材质、FOV 或近裁剪距离。
