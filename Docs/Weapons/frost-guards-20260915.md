# 寒晶剑护手改造

新增壁垒护手、反击护手、轻量护手。三款使用5080的TRELLIS.2多视图生成模型，保留生成轮廓进行本地重拓扑、倒角、接口适配和法线/AO烘焙，安装到原剑的V形安装座。统一沿用原护手的古铜纹理与材质。

配置：`Content/ColdSteelData/melee-gunsmith.json` 的guard栏目，适用寒晶·双手剑。属性按用户表格接入；反击护手成功弹反时获得6秒反击激励。

模型选择贯通第一人称、改造台草稿、应用/撤销、库存预览、掉落和实例存档。拆回原装恢复原护手。剑身符文、剑身Ⅰ、握把等改造继续保留。

源模型、设计图、生成任务记录、具体安装方式、材质和导入脚本见 [制作入口](../../SourceAssets/MeleeGuards20260915/README.md)。
