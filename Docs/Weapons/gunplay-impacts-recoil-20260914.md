# 表面命中反馈与枪型后坐力节奏

本轮按用户选择实施此前建议的第 1、3 项。枪声主体/环境尾音分层建议不在本轮内；新增声音仅是子弹命中表面的短音效。保留已接受的 V12 枪口烟雾、曳光、V10 火光及高倍镜隐藏弹壳行为。

后续用户确认肉体血雾升级并反馈落地可见性，Flesh 当前表现以 [肉体落血 V2](flesh-impact-ground-v2-20260914.md) 为准；下方保留首次接入的预算记录。当前预留 24 雾/96 滴实例、活动总数最多 192，血迹使用独立 48 个贴花，普通弹痕保留 24 个。

## 表面命中反馈

入口仍为 `UFPSWeaponFXComponent::OnImpact`，物理子弹和即时命中都接入同一个 `UFPSImpactFXSubsystem`。只处理本地视觉和声音；特效被裁剪、限流或池满不会跳过命中伤害、穿透、附魔或已有确认命中准星。

| 表面 | 表现 |
| --- | --- |
| Metal | 短促定向火星、少量细屑、浅色擦伤/暗色弹痕、短金属响 |
| Wood | 细长旋转木屑、棕色粉尘、拉长弹痕、干燥短撞击 |
| Stone / Concrete / Rock / Brick / Gravel | 短石粉、小颗粒、磨损弹痕、硬质碎裂短音 |
| Dirt / Soil / Mud / Grass / Sand | 棕色短土尘、少量土粒、较闷命中声 |
| Glass | 小薄片、很淡的粉尘、浅色弹痕、短碎裂响 |
| Flesh | 很小的暗红命中雾和闷响；不生成石屑或墙面弹孔 |

材质选择顺序：

1. 命中组件或 Actor 上的 `Impact.Metal` / `Impact.Wood` / `Impact.Stone` / `Impact.Dirt` / `Impact.Glass` / `Impact.Flesh` 显式标签；兼容组件原有 `Metal` 等简短标签。
2. 命中 Physical Material 的已配置 Surface Type 名称；兼容现有 `PhysM_Wood` 等物理材质名称。不重排现有工程或资产包的 SurfaceType 数字编号。
3. Pawn 默认归为 Flesh；盔甲可用第 1、2 层覆盖。
4. 体素建筑按实际命中单元的材料 ID 读取，避免合并网格统一走第 0 材质槽。
5. 利用现有弹道查询返回的 FaceIndex 取得命中面的材料及其物理材质；无有效面时仅单材质组件允许退回第 0 槽。材料名称无法识别时沿材料实例父链查找，最多 8 层。
6. 已知地形默认为 Dirt，其他未知表面保守回落 Stone。没有物理材质、标签且名称不含材质信息的资源，无法凭外观自动准确分类，可补组件标签，无须复制整套材质。

## 性能处理

以下为实现预算，不是实机性能测试结果：

- **全世界共享一份池**，独立于枪口/弹壳/曳光池：48 火星、24 粉尘、32 碎屑，总上限 **104**。多个调用者、穿透和同帧补发均共享限额。
- 三个 `InstancedStaticMeshComponent` 分别批量绘制火星、尘卡和小立方体碎屑；共享三个材质，以实例自定义数据传颜色与透明度，没有逐粒子组件或 MID。
- 世界开始时一次分配槽位，开火路径不创建 Actor、组件、刚体或材质，不加载资产。没有活粒子时停止子系统 Tick。
- 每组有变化时每帧批量提交一次实例变换。运动按出生时间解析计算，不逐碎屑射线、碰撞子步或启用 Chaos；所有粒子关闭阴影、碰撞、导航影响、距离场光照及接收贴花。
- 全局令牌桶默认 **40 次命中表现/秒**，桶容量及单帧上限均为 **8**；同一组件 6 cm 内、25 ms 内的重复命中合并表现。
- 满细节距离默认 25 m，超过后减少火星和碎屑，60 m 后只保留主要反馈，120 m 后裁剪。距离按镜头 FOV 折算，最低折算系数 0.28，高倍镜保留更远处可读反馈。声效仍按实际距离衰减。
- 粉尘只生成一张小软卡，寿命约 0.26–0.42 s；肉体 0.18 s。材质无采样纹理，主要使用低成本解析轮廓；火星约 0.12–0.24 s，碎屑约 0.22–0.38 s。
- 弹痕共享 **24** 个组件，30 m 折算距离内生成，同组件 4 cm 内不堆叠，停留 6 s 后用引擎淡出 1 s。满额轮转旧槽位，带屏幕尺寸裁剪；跟随命中组件。土壤、肉体及可破坏合并体素网格不贴弹孔，避免拆除后悬空。
- 声音共享 **6** 个组件，最短触发间隔 35 ms，60 m 实际距离外不播放；声音忙时跳过额外音效，保留既有尾音。3 个变化/表面，禁止紧邻重复，轻微音高变化。关闭音效遮挡查询，不增加射线开销。
- 表面对象分类缓存上限 256；组件/物理材质/材料变更使用当前命中数据，体素材料不缓存。场景退出销毁池内组件和清空引用。

可调性能入口（距离单位 cm）：

```text
fps.Impact.MaxDistance 12000
fps.Impact.DetailDistance 2500
fps.Impact.BurstsPerSecond 40
```

粒子数和贴花数量是硬上限；上述参数可进一步缩小表现范围和触发频率。未增加逐命中灯光、镜头振动或命中时资源导入。

## 后坐力表现

- `FPSVisualRecoil.h` 提供 M1911、左轮、M4、AKM、QBZ 的轻量参数；现有动作骨架、机械动画、火光大小不改。
- 手枪减少轴向后退，增加短促上跳；左轮保留更重、更慢的脉冲。M4/QBZ 以轴向后冲为主，减少横摆和滚转；AKM 保留更重的后冲。
- 相隔足够时间的第一枪视觉冲量为 1.12 倍；连续射击后续冲量逐步收敛至 0.86 倍。此系数只作用于枪身反馈，不乘到伤害或弹道后坐力。
- 每发初段使用较有弹性的弹簧，约 65–120 ms 后转为接近临界阻尼的回稳，松开扳机可提前进入回稳，但至少保留 55 ms 初始冲击。
- 用世界时间推进枪身弹簧，在开火、松开扳机和 Tick 之间共享时间戳，防止新生冲量消耗开火前的时间；跨初段/回稳边界分段解析积分。
- 开镜进出沿现有 ADS 权重过渡，高倍镜额外按视场角收敛枪身横向位移和角度，保留轴向后冲。没有修改实际控制器后坐力曲线、散布、弹速、弹药和枪匠数值计算。
- 换枪清掉旧枪的视觉弹簧和连射计数，避免新枪继承旧枪冲量；相机弹簧与其枪匠稳定性回稳公式沿用原实现。
