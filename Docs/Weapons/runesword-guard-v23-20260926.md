# 格挡 V23：参考魔法释放的张掌支撑

用户要求将 V22 的左拳支撑改为五指张开抵剑。参考现行魔法推掌释放的掌向、轻弯指形和外展拇指，适配到符文剑原生骨架；四指增加自然分开，掌心朝剑身、手背朝玩家。

左臂以 V7 裸手表面重算贴合位置并联动腕肘肩，举起时张掌、受击时保持、破防撤手后再合指回待机。沿用 V22 剑位、25° 斜向横挡和右手握柄。普通柄、长柄各自 Guard / GuardHit / GuardBreak，仅改左臂及手指轨道，时长及玩法计时不变。
