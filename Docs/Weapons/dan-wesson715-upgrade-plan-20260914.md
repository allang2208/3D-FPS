# Dan-Wesson 715 模型与动作升级方案

按用户反馈实施；参考 [QBZ191 整体升级方案](qbz191-visual-upgrade-plan-20260913.md) 与 [M1911 近景表面制作](m1911-hero-surfaces-20260913.md)。保留当前武器实例、六发弹巢、库存结算、枪匠选项及统一 Manny 手模。完成制作、必要构建与导入，不主动启动游戏或制作验收渲染，由用户测试。

## 1. 开火歪斜

作者源中的弹巢骨骼局部 Y 轴在枪体坐标中约为 `(-0.087, 0, 0.996)`，旧脚本却把它当作沿枪管的轴。保持骨架 rest 和网格权重，以枪体空间中的实际轴与转轴位置构造旋转，再转换回骨骼局部轨道；弹巢、摇臂、退壳杆、击锤和扳机各自处理。射击只旋转弹巢，摇臂保持闭合。

## 2. 近景模型与材质

- 保存原始模型参考、高模、低模和烘焙笼，保留可重建脚本与现有枪型轮廓。
- 重建弹巢连续圆弧、槽口与可见孔口；枪口口沿、内腔遮挡、速装器、弹药和小件补充近景几何。
- 枪架、枪管护罩、橡胶握把分别使用合适的边缘半径；击锤、扳机、照门等小件细化倒角与硬边法线。
- 分区重新制作和烘焙 PBR：不锈钢主体、加工钢件、橡胶握把、消光瞄具、黄铜弹壳与聚合物速装器分开处理。保留原枪体刻字，重新构建的几何使用新 UV 和结构法线。
- 手臂、手套网格、权重、UV、原材料身份不改变。新资源使用独立目录，并将共同装配入口切换到新版本，覆盖持枪、库存、枪匠、动态图标和掉落展示。
