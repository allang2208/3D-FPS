# 火球左手占用与动作阶段（2026-09-14）

用户要求：凝聚时左手缓缓抬起、掌心向上；发射时快速前伸、掌心向下。后续已收到两张参考照片：四指靠拢但保留轻微弯曲，拇指自然向外张开。按照片制作三维手型、前臂翻转与肩肘伸展，并接入原有动作时钟和互斥机制。照片没有给出完整运动过程，抬手／收手轨迹属于本次三维动作设计。

后续按用户要求改为脱手施法：凝聚完成后自动恢复左手，火球独立保留在原有悬浮偏移位置；再次发射只执行一次手势，火球从当前悬浮位置飞出。悬浮期间不占用左手，恢复正常武器／工具动作。

## 时序

- 左手空闲后才开始施法、扣除 MP、生成火球。换弹、装备、检视、近战、采集或 ADS 已在进行时，只保留一个等待请求，不打断当前动作。
- ADS 由玩家松开瞄准键，瞄准退出混合完成后开始等待中的施法；不会因输入施法强行退出现有 ADS。
- 凝聚手势：Raising 0.95 秒 → Recovering 0.44 秒 → None，总长 1.39 秒；实体仍是已就绪的悬浮火球，手臂不常态保持托掌。
- 独立发射手势：从当时的持武器／空手姿态进入 ReadyingRelease 0.26 秒 → Releasing 0.34 秒 → Recovering 0.44 秒 → None，总长 1.04 秒。发射接触在前伸阶段第 0.20 秒，即独立手势开始后 0.46 秒，全部时间可在组件默认值调整。
- 凝聚期间再次按技能键保留一次发射请求，凝聚完成后可直接接前伸；凝聚收手时按键则等收手完成后进入独立发射。悬浮期间若正在攻击、采集、换弹、装备、检视或 ADS，保留一次发射请求，等左手空闲后执行，不重新扣蓝／生成火球。发射方向在接触时按当前准星计算。
- 火球大小跟随凝聚进度。凝聚／发射收手后解除左手占用，不等待火球发射或命中才恢复手部动作。手势期间火球被回收时进入收手；已经脱手的火球到期消失，不再触发手部动作。
- `GetHandPhase` / `HandPhaseFraction` 驱动 `UFPSCastingMeshComponent` 左臂骨骼层。前伸第 0.20 秒翻掌完成并发射，手臂继续少量前送、减速至第 0.30 秒落稳，第 0.34 秒开始收手。实体发射与手势接触共用 `LaunchContactTime`。

## 动作规则

- 凝聚／发射手势、收手或已有等待请求时，禁止新的近战、连击、采集、检视、ADS 和换弹。正在进行的动作自然结束。手势期间禁止装备切换；纯悬浮状态释放左手，允许所有这些动作与切换装备。
- 武器状态的 `IsWeaponBusy` 不包含施法，因此枪械腰射仍走既有射击、弹道、后坐与弹药逻辑。
- 最后一发子弹射出时记录延迟换弹，包括半自动手枪；收手后按既有弹药规则换弹。施法期间手动按 R 不开始换弹；空弹匣会保留延迟换弹请求。
- 装备切换在玩家数据提交前拒绝，不改变存档或视模。MP、经验、弹药与非当前手持物品的库存变更仍可正常提交。
- 不给奔跑、滑铲、普通跳跃、闪避加入施法限制；移除火球实体因进入攀爬／翻越而被销毁的旧规则。已经进行的攀爬／翻越结束后才开始等待中的施法。施法中开始攀爬／翻越时，右臂沿用接触动作，左臂由施法层接管。
- 死亡／组件结束回收实体并清空等待与动作状态；现有火球冷却和已消耗 MP 的规则保留。

## 骨骼动画与特效接入

- 在枪械、符文剑、采集工具及翻越手臂共同使用的骨骼组件层处理左臂，放在原动画评估及翻越接触修正之后。保留右臂和武器骨骼的最终姿态，左手不会被腰射、奔跑或工具待机覆盖。
- 托掌与发射方向以掌面／手指的语义方向描述，按各当前骨架的参考姿态换算。上臂／前臂由固定骨长的两骨 IK 求解，蒙皮辅助骨随所属骨段完整变换；超出支撑范围时前移肩带，保留肘部弯曲，不修改手模网格、骨长或权重。
- 凝聚时从当前握持姿态沿弧线离开握点、开指和抬腕，肩肘先启动、翻掌稍后跟上；发射先向侧面翻掌再转向下方，同时伸肘；收手沿经过左下方的连续弧线回到当前武器姿态。初始抬手与最终恢复在局部骨骼空间混合。
- 凝聚过程中火球跟随托掌轨迹；凝聚完成后保持既定的角色视角相对悬浮偏移，不随收手或发射手势改变位置。发射直接使用当前实体位置，包括已有的墙面避让，不向手腕／前伸位置瞬移。球体对场景的扫掠阻挡保留。
- 空手或翻越收放武器的显示间隙，由同一 Manny 手模的单左臂补充显示；实际装备手臂可见时不重复显示。
- 运行时参数：`Content/ColdSteelData/Skills/fireball_hand_pose.json`，由组件开始时读取。起始姿态随当前武器捕获，游戏内使用程序化骨骼动画，未把某把枪的完整双手 FBX 强制覆盖到其他武器上。
