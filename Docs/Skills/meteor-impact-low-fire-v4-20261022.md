# 陨星爆燃与低矮残火 V4（2026-10-22）

用户反馈落地缺少爆炸冲击、碎石抢占主体，残留火焰过高且高度接近。本轮修改命中爆燃和地面残火，保留伤害、作用范围、眩晕、灼烧、修炼、施法预览及服务器事务。

## 表现与时序

原爆燃主体持续约 0.9–1.1 秒，外观整体随范围乘约 4.65 倍；烟、火的高度和水平距离一起放大。V4 使用实际厘米半径驱动水平扩散，组件缩放固定 1，纵向尺寸只做有限调整。

- 中心爆燃 1 片，寿命 0.32 秒，快速展开；随后 5 个不等大小的爆燃团，寿命 0.42–0.62 秒。
- 4 个短促翻卷火团衔接爆炸与残火，寿命 0.48–0.72 秒。
- 最多 9 团低矮扬尘快速向外扩散，各团距离和尺寸不同；最多 4 团短余烟补足体积与地面接触感。烟尘共用现有数量预算、天气风及接触面修正；击水时关闭地面灰尘，余烟沿原湿命中配色。
- 爆燃材质派生自现有 12×12 原生爆炸图集，保留透明度解码和唯一的曝光补偿，增加短时能量；不修改原火球、龙息或旧爆炸材质。
- 复用原有无阴影点光，在落地瞬间增强并快速衰减，持续阶段降低到较弱火光。保留原音效与镜头冲击，不新增灯、相机震动器或碎石组件。

## 残火差异

保留一个流体网格和最多 37 个贴地燃点；燃点仍经过分帧地面、遮挡及净空采样。每次施法的稳定种子来自复制的开始时刻，每个燃点的位置决定其不同强弱与节奏。

| 参数 | V3 | V4 |
| --- | --- | --- |
| 源粒子基础上升速度 | 135–220 cm/s | 22–80 cm/s |
| 速度注入倍率 | 0.9 | 0.8 |
| 温度浮力 | 0.18 | 0.06 |
| 温度消散率 | 1.2 | 2.8 |
| 密度消散率 | 1.8 | 3.0 |
| 源产生率上限 | 444/秒 | 296/秒 |
| 源寿命上限 | 0.46 秒 | 0.36 秒 |

燃点宽度、温度和上升速度不再取接近的统一值；各自错开起伏，仅少数较热燃点偶尔扬起短火舌。网格仍保留足够上方空间，降低火焰主要通过动能、供热和消散完成。上述是配置值，不是实测火焰高度；未承诺具体画面厘米高度或帧率收益。
