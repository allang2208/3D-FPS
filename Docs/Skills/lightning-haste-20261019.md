# 雷电迅捷（2026-10-19）

新增主动电系自身强化 `lightningHaste`。无需法杖，短暂引雷后在手臂和脚部出现细电弧；更换武器保留增益。技能页、详情、独立图标、快捷栏拖放、状态栏、开发工具等级设置、存档及联机施法一起接入。

## 成长与结算

令 K＝等级−1，上限 20 级。下表为基础值，原有装备蓝耗、施法速度和冷却修正继续生效。

| 属性 | 公式 | 1 级 | 20 级 |
| --- | --- | --- | --- |
| 移速增加 | 10%＋1%×K | 10% | 29% |
| 其他动作速度增加 | 5%＋0.5%×K | 5% | 14.5% |
| 持续时间 | 20＋0.5×K 秒 | 20 秒 | 29.5 秒 |
| 魔法消耗 | 40＋2×K | 40 | 78 |
| 基础冷却 | 50 秒，生效时开始 | 50 秒 | 50 秒 |

动作速度乘数 A＝1＋动作加成，实际时长＝原时长÷A；不是直接减去相同比例的时长。移速单独相乘，不再叠动作倍率。施法开始预扣蓝并占用冷却，未生效取消退款；成功释放重置完整冷却。生效期间拒绝重复施放，不叠层。

修炼在本次结束时统一入账：成功施法 1 XP，每个有效击杀 3 XP；严格超过 5 名（第 6 名起）额外 15 XP，严格超过 10 名（第 11 名起）额外 40 XP。仅计最高击杀档，基础及逐个击杀经验保留。6 杀为 34 XP，11 杀为 74 XP。沿用现有技能进度结构，升下一级所需经验为当前等级×100，满级停止积累。

权威死亡通知接入 `ColdSteelSkills::NotifyKillByOwner`，逐受害者去重，排除自己、友方、召唤物和不提供修炼的目标；持续伤害沿原击杀归属进入同一路径。死亡、主动离场和 EndPlay 结算已得经验。版本 24 迁移补新技能与冷却；活动状态不写入存档，重进不恢复增益。

## 动作接入路径

下表记录实现入口，并非运行测试结果。优先复用动作已有的统一相位、接触、音效和动画时钟；没有采用全局时间膨胀。

| 动作 | 实现入口与计时 |
| --- | --- |
| 行走、跑动、蹲行、滑铲移速 | `CombatStatusFormula::MovementMultiplier`；角色移动读取同一移速乘数 |
| 枪械射击、机械循环 | `EffectiveFireInterval`；枪械动画、RSH12、M870、Super90 和双持射击节奏使用对应实际间隔；权威限流同源 |
| 普通／空仓／逐发换弹 | `ReloadSpeedMultiplier`→`WeaponStatEvaluation::ReloadSeconds`；原装填、抛壳、拉栓和声音接触跟随动作时钟 |
| 剑类普通攻击、重击蓄力 | `MeleeWeaponStats::Evaluate`；攻击速度与蓄力秒数分别计一次 |
| 重击释放、主动上挑、大旋风、冲刺攻击、剑柄快击 | 技能 `SwingRate` 单独乘 A，保持普通武器攻速与武技独立；位移总距离不变 |
| 锤类普通攻击、蓄力、重击与冲刺砸地 | `ProductionToolStats`、`BluntMotionRate`、升锤与重击源时间映射；客户端与权威接触定时一致 |
| 锤类上挑与大旋风 | `HasteActionRate` 推进独立技能相位；位移、扫掠、声音、镜头同一时钟 |
| 快速近战、空手拳击、法书推击 | `FPSQuickCombatComponent` 保存动作倍率，业务相位与剩余时长统一换算 |
| 法杖普通攻击 | 开始时缩短 `Duration`，轨迹／接触按归一化动作采样 |
| 弓拉弦 | `WeaponStatEvaluation::Interval` 的弓分支缩短拉弦秒数；箭速与满弦持握窗口不变 |
| 弓搭箭、入手、放弦、收弓和装备 | `StageActionRate`，跨阶段剩余帧时间换算回真实秒，避免拉弦重复加速 |
| 法术施放与雷枪蓄力 | 统一 `ApplySpellbookFocus` 施法速度；雷枪最短／最长蓄力另缩短，持续伤害跳频不动 |
| ADS、检视、装备、切换 | 枪械、双持、弓、剑、工具、法杖与空手分别接入各自动作计时 |
| 举盾／举武器格挡与收势 | 剑／工具主动抬落阶段加速；受击、破防与被施加的控制时长保留 |
| 闪避、翻越 | 缩短动作时长并同步动画与固定路径，距离不额外放大 |
| 采集工具 | `ProductionToolStats` 的挥动／接触／恢复时间统一换算 |
| 食物、饮水、药水 | `FPSPotionUseComponent::Age`，入手、进食、物品提交、抛弃及武器复位同源 |
| 撞门 | 本地与服务端动作保存倍率，同步手掌接触及开门时刻 |
| 法书开合、法杖照明手势 | 主动开合与手势计时加速；受击打断计时沿用原控制规则 |

技能冷却、增益／减益寿命、DoT 跳频、弹速、跳跃高度与重力、冲刺武技就绪要求和世界生产时间仍按原有规则计算。属性在状态开始／结束时刷新，避免缓存换弹时间保留过期加成。
