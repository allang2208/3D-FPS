- 主动锁定魔法，20 级；一次命中／治疗 +5 修炼，直接击杀 +10，升级需求 `100+(L-1)*100`。
- 基础量 `floor(5+5L+魔攻*(0.25+0.25L)+智力*(1+0.5L)+智慧*(1+0.5L))`。伤害与治疗各自应用原有法杖词条；治疗不继承伤害、链式增伤或暴击，敌伤可随机暴击但不虚构要害。

- 活着的 player／companion／Friendly 同组互疗；建筑和尸体不能治疗或锁定；僵尸分类双倍伤害。沿用既有角色／怪物生命存储，治疗不复活。
