# 冰墙寒雾（2026-09-30）

用户要求冰墙增加类似冰锥的寒雾。新系统 `/Game/Skills/IceWall/ColdMistV1/NS_IceWallColdMist` 从现用冰锥 `/Game/Skills/IceSpike/FrostV2/NS_ColdMist` 派生，复用 `MI_ColdMist` 与原 8×8 烟雾图集，不重建冰锥素材或修改原系统。

## 表现与生命周期

- 法杖凝聚时围绕冰块产生少量寒雾；发射时转为短世界空间拖尾，不随冰块移动已有雾片。
- 墙体生长及成形后，从两侧冰面均匀散出灰蓝色薄雾，缓慢下沉、向外散开，并响应现有天气风与屋檐遮蔽。风查询位于墙体碰撞盒外侧，避免冰墙自身被识别为屋顶。
- 出生区域随该次施法快照的墙宽扩展，粒径保持固定。高墙最高出生位置为墙高的 80%，矮墙为 50%（当前 50 cm），给 100 cm 顶面及机枪视线留出空间。
- 建筑预览不生成寒雾。取消、销毁、自然到期及关卡退出随所属墙体清理 Niagara 组件；不遗留持续发射器。
- 寒雾仅为装饰，冰墙的宽度成长、共享生命成长、阻挡、寒冷光环、法杖条件、施法付款与修炼口径沿用现有实现。

## 制作与预算

作者入口 `Tools/Skills/build_ice_wall_cold_mist.py` 仅写入新冰墙系统。运行入口 `FPSIceWallComponent` 异步预加载，`FPSIceWall` 沿原 Tick 更新；预加载尚未完成时，已有凝聚冰块或墙体会在资源到达后接入寒雾，不在 Tick 同步读取资源。

每面真实墙仅一个世界空间 CPU Niagara 组件。墙面发射率 `clamp(墙宽cm × 0.065, 20, 72)`，再乘生长强度和共享装饰分配比例；单片寿命 1.05–1.55 秒。沿已有至多四面实体墙的限制，未降级时理论上界约 448 片墙面雾，另有当前凝聚／飞行种子的小雾。每 0.2 秒分配细节预算及更新遮蔽风，数量不足或远距时减发射，玩法不受影响；这些数字是实现容量，并非性能采样结果。

粒径约 28×34 cm 起，逐粒子至多 ×1.4 变化，寿命末段扩张 ×1.6；灰蓝透明度 0.26 乘原材质增益与淡入淡出，使用原材质的近景和深度淡化。按真实墙宽更新包围盒，不把整团寒雾随技能等级放大。
