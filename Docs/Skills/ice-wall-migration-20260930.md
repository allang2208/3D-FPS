## 使用方式与本次改动

在技能页把「冰墙」拖到快捷栏，**装备法杖后**使用。第一次按绑定键凝聚冰块种子；凝聚完成后自动出现建筑式墙体预览。移动视角选择落点，按 **R** 在高墙与矮墙之间切换，再按同一绑定键，通过发射手势把种子射往已显示的位置，落地后在 0.5 秒内生长成墙。

绿色预览表示可放置，红色表示超距、地面不平、遮挡或有人占位。发射时冻结当前预览的位置、朝向与形态；发射手势和飞行期间不重新瞄准。途中遇到实体障碍则破碎；敌人在成墙瞬间统一结算伤害与推离。

高墙 **260 cm**，矮墙 **100 cm**，主体厚度 **62 cm**；一级宽度 **210 cm**。每级增加两个 42 cm 段，最高 20 级。高墙阻挡移动和采用碰撞查询的投射物；矮墙使用同一碰撞体，顶面可被现有脚架探针识别。矮墙采用两层、高墙五层冰块，半块错缝拼接；四种有缺角和不规则表面的模块保留平整接缝和顶面。

预览与凝聚种子不参与碰撞或导航。实体墙使用一个连续碰撞盒、动态导航障碍和四组实例网格，避免可见接缝成为通行孔洞。墙体到期后取消碰撞、移除导航影响并破碎。R 只在冰墙放置预览可见时消费输入，其余时候沿用换弹输入。

## 原项目规则及单位

来源为 `E:/无尽轮回/长期备份/2026-7-13-1/game-dev` 的 `src/entities/components/ice-wall-system.js`、`data/skills.json` 与技能 UI。原版直接创建线段冰墙；本次按用户要求改为凝聚、建筑预览、两种形态和发射后生长。

| 项目 | 迁移规则 |
| --- | --- |
| 物理伤害 | 向下取整 `10 + 10 × L + INT × (1 + 0.25 × L) + WIS × (1 + 0.25 × L)`；一次成墙每目标一次 |
| 蓝耗 / 基础冷却 | 100 / 30 秒；开始凝聚扣蓝，成功发射后冷却开始递减 |
| 持续时间 | `10 + 0.5 × (L − 1)` 秒，从实体成墙起计算 |
| 段数 | `5 + 2 × (L − 1)` |
| 施法距离 | 原 500 单位 → 750 cm；原单位按 1.5 cm 转换 |
| 寒冷光环 | 原 100 单位 → 150 cm；每秒叠 1 层，单层减速 3.5%，持续 2.5 秒 |
| 推离 | 原 50 单位 → 75 cm，另加穿入距离的两倍；使用扫掠移动 |
| 修炼 | 有效命中 3、直接击杀 10，同次至少两目标额外 10；空放、尸体、友方和召唤物不刷经验 |

这是原版 INT/WIS 物理成墙伤害，沿用物理防御，不套用火球或冰锥的魔攻／暴击公式。本次复用当前法杖成本、距离、冷却、施法速度、连锁和急速接口，使用持杖手势及杖尖发射。初次迁移未添加持杖限定，2026-09-30 按用户补充要求设置 `iceWall.requiresStaff=true`；无当前法杖时拒绝施放，未释放切走法杖取消并退蓝，快捷槽置灰提示「需要法杖」。详细范围见 [法杖限定](staff-required-magic-20260930.md)。

技能数据统一位于 `Content/ColdSteelData/skills.json`。技能页沿用当前卡片、详情和修炼布局，提供图标、当前／下级效果、拖动绑定与快捷槽凝聚／形态／冷却提示。

## 阶段、资源和存档

施法排队不扣蓝。实际开始时保存一份等级、属性与装备效果快照，并预留蓝耗与冷却。凝聚结束后释放手部占用；预览阶段仍可正常执行其他动作。最多保留 30 秒，未释放取消、死亡、超时或施法优先权打断时退还未释放的实际蓝耗并撤销预留冷却。

菜单、弹药选择和建筑模式隐藏墙体预览并撤销待发射请求。退出时清理凝聚种子、预览和已释放临时墙，不把临时墙恢复到下次进入。技能存档迁移到版本 17，补充冰墙等级、经验、冷却和未释放实际蓝耗字段；加载时退还不能恢复的未释放付款，并清除预留冷却。已提交发射的冷却保持原有持久化策略。
