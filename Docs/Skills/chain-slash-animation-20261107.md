# 连斩 · 双手剑武技动作

参考视频区间为 00:35–00:40，独立动作取其中 00:37.30–00:40.00 的四次连续挥斩和收势。标准柄及长柄各有一条 2.70 秒的第一人称动画，按 120 Hz 烘焙，每条 325 个关键帧。两个版本分别从项目现有的对应握姿起手并收回待机。[视频参考](https://www.youtube.com/watch?v=NTrzxPIXer4&t=35s)

## 当前摆幅

`author_motion.py` 在已有肩肘轨道上增加横向摆动。主要挥斩段的剑柄横坐标相对画面中线放大 35%，同时保留每一帧原有的剑柄高度和镜头深度。双臂和握柄一起向两侧转动，额外转角受肩口深度余量约束。换向时随原轨道连续过渡，起手与收势逐渐回到原握姿。游戏内手感与镜头表现待玩家实测。

## 镜头、折射和命中反馈

`Feedback/fit_camera.py` 从参考片段 37.30–40.00 秒匹配背景特征点，按项目默认垂直视野将画面运动拟合为 60 Hz 的俯仰、偏航和横滚。163 个采样随动作时钟插值，最后在收势中回正。用户反馈初版过弱后，俯仰、偏航和横滚分别放大到 2.8、3.5 和 4.5 倍，各斩另加随换向回摆的曲线。镜头强度设置继续生效。画面跟踪无法唯一分解原始相机的平移、旋转和视场变化。

第一斩的源动作 0.18–0.48 秒压缩至实际 0.18–0.36 秒，速度由 1 倍平滑升至 2 倍再回到 1 倍。两种握柄、参考镜头和折射展开共用加速后的动作时钟，伤害窗口仍读取同一源动作标记。整段挥空耗时为 2.58 秒，确认命中的停帧额外计入实际耗时。第一斩的命中回弹强度提高到原来的 1.25 倍。

`Feedback/bake_effects.py` 直接采样 UE 动画的剑骨骼。标准柄和长柄使用相同的剑轨，四斩分别使用一张带时间 UV 的折射网格。每道折射从本斩标记前 125 毫秒开始，至标记后 105 毫秒展开完毕，然后在世界空间消散。刀光表现和前方伤害判定各自取样。

权威端确认有效伤害后，每斩首次命中触发动作停帧、方向性镜头回弹和接触面折射波，同时增强当前刀痕折射。前三斩停 50 毫秒，末斩停 70 毫秒。同斩其余目标保留各自的接触效果和伤害数字。挥空时只播放参考镜头和刀痕。停帧只消耗这次武技的动作时间。

## 上一版肩口修正与复查记录

首版在换向时出现上臂跳转、腕部额外弯折和局部肘部挤压。修订时保留了手指及手掌相对剑柄的握姿，重做了肩肘的运动过渡，并用参考画面中的护手、剑尖及手臂轮廓调整了镜头内投影。第二斩原本因透视缩短而几乎看不清的剑身已恢复，第三斩中央的手臂遮挡也已减轻。

复查上一版发现，默认 75° 垂直视野下，标准柄有 30 帧、长柄有 31 帧露出肩根截口。新版限制剑出画后继续牵动肩部的幅度，联合拟合肩、肘和握柄。最大肩部位移从距待机位置 137.8 厘米降至 31.9 厘米以内。冲刺进入连斩时，武器根节点现在逐帧回正。

在两套实际手模上分别采样 325 帧，检查左右肩口各 61 条边与摄影机视锥的相交情况。75°、16:9 下两种握柄均为 0 帧入镜。套用模块握持修正后也为 0 帧。85°、21:9 下肩口与画面下边界平面至少相隔 4.1 厘米，冲刺接招的默认镜头模拟也为 0 帧入镜。复查覆盖裸臂网格，服装袖型和游戏内完整镜头叠加由实机确认。

当前烘焙相对待机的最大额外腕部弯折为 18.44°，最大握点漂移为 0.0022 毫米，两套动作的首尾蒙皮顶点位置一致。120 Hz 下最大的手臂相邻帧转角为 26.2°。折肘处仍可见局部压缩，最差一帧有 8.9% 的肘部采样边短于待机长度的六成。

画面对照仍能看到差异。第一斩入画时手臂高度不同，第三、四斩的肘部轮廓与原片不同，第四斩前臂会遮住一部分握柄。离线预览使用项目手模和剑模型，游戏内镜头与装备叠加尚未实测。

## 继续编辑

`read_idle.py` 和 `grip_poses.json` 提供两套项目待机握姿。`RootClearance/fit_arms.py` 用参考画面坐标、`Standard-fit.json` 及实际武器握持修正共同拟合两套肩肘轨道，输出 `RootClearance/arm-path.json`。在 Blender 后台运行 `author_motion.py` 即可由这份轨道重新烘焙两套动画。需要复查肩口时，先用 Blender 运行 `Review/sample_blend.py` 采样，再运行 `RootClearance/check_opening.py`。

`save_motion.py` 保存 UE 原生动画。`Review/asset_batch.ps1` 在共享互斥下选择已有编辑器桥或无界面 commandlet。`saved-assets.json` 记录两套已保存资产。

## 技能栏与正式成长

在技能页「全部」或「主动」分类中点击「连斩」可查看等级、当前／下一级效果和修炼。将技能卡拖到快捷槽，装备双手剑后按绑定键发动。旧档迁移为1级，保留其他技能进度；单手弯刀、法杖和双手锤不满足装备条件。

两种握柄按装备选片，四个命中窗口跟随动画标记。权威端按角色瞄准方向、双手剑普攻挥斩距离和实体遮挡判定前方目标，并沿用低位小目标的补充判定。同一敌人每段至多受击一次。

固定10点伤害测试阶段已结束。正式数值：1–20级每段武器伤害与韧性伤害倍率40%→120%、基础冷却25→15秒、基础体力40→60，均线性成长；起手前一次扣费并开始冷却。技能等级、修炼、存档、快捷栏CD与升级通知共用数据。完整规则见 [连斩数值与修炼](chain-slash-balance-20261107.md)。
