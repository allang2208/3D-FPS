# 冰锥数值重定（2026-09-16）

用户要求：① 冰锥不再单独计算智力，参考火球只吃魔攻；新公式伤害取现在公式的约 30%；蓝耗随等级增长、冷却按火球口径降为 12→8 秒。② 确认冰锥定位为单体高伤害——击杀目标后其余冰锥应继续飞向后方，需要排查是否已实现。③ 后续要加魔杖，先预留魔杖乘数接口并接到火球公式上。

## 1. 伤害公式

旧（迁移保留的原版口径，[ColdSteelIceSpikeModel.cpp](../../Source/FPSGAME/Skills/ColdSteelIceSpikeModel.cpp)）：

```
每枚 = floor( floor(30 + 5L + 魔攻×(1.2+0.25L) + 智力×(1.2+0.25L)) × 法杖改造增伤 )
```

现行（与火球同口径：只有固定项 + 魔攻，没有独立智力乘区）：

```
每枚 = floor( floor(21 + 3.5L + 魔攻×(1.4+0.2917L)) × 法杖改造增伤 )
数量 = 2 + floor((L−1)/5)（+ 法杖 iceSpikeCountDelta）
```

用户口径是「比原来低 30%」，即新值约为旧公式的 70%：固定项 ×0.7、魔攻系数 ×0.7÷0.6。魔攻系数之所以要放大，是因为旧式同时吃魔攻与智力（角色魔攻本身已经是 `floor(1.5×智力 + 0.5×精神)`），去掉智力项后只有把魔攻系数提高约 1/0.6 才能让总量落在旧值的七成附近。四档属性的比例（公式推导，非实机）：

| 属性档 | 新/旧（各等级稳定） | L1 整轮 / 火球 | L20 整轮 / 火球 |
| --- | --- | --- | --- |
| 魔攻20／智力10 | 0.74（−26%） | 116 / 170 = 0.68× | 1175 / 360 = 3.26× |
| 魔攻60／智力35 | 0.73（−27%） | 252 / 510 = 0.49× | 2625 / 1080 = 2.43× |
| 魔攻120／智力75 | 0.72（−28%） | 454 / 1020 = 0.45× | 4795 / 2160 = 2.22× |
| 魔攻100／智力67（精神≈0） | 0.70（−30%） | 386 / 850 = 0.45× | 4070 / 1800 = 2.26× |

削减幅度随智力占比在 −26%～−30% 之间浮动：精神型配装原本吃到的智力项占比更大，所以掉得略多一点；`魔攻 ≈ 1.5×智力` 的标准配装正好是 −30%。低等级仍明显低于火球（L1 约 0.45–0.68×），L15 之后回到单体的 2.2–3.3 倍，保持「单体高伤害」定位而不是原先的 3–4 倍溢出。数值全部在 `Content/ColdSteelData/skills.json` 的 `iceSpike`，改数据即可调整，不需要编译（重启编辑器／游戏加载）。

## 2. 蓝耗与冷却

- 蓝耗：`30 + 2×(L−1)`（30→68 MP），法杖耗蓝系数与链式耗蓝继续乘算，与火球 `50+2×(L−1)` 同节奏。
- 冷却：`lerp(12, 8, (L−1)/19)`，再乘现有减冷却与法袍／符文系数，与火球完全一致（1 级 12.0 秒 → 满级 8.0 秒）。原「整组结束后开始倒计时、悬浮超时取消」等规则不变。
- 新增配置字段 `manaCostPerLevel`、`minimumCooldown`，与火球同名字段对齐；`intBase`／`intPerLevel` 与 `FIceSpikeCast` 的智力字段一并删除。

## 3. 击杀后剩余冰锥继续飞行（此前未实现）

排查结论：**改动前没有实现**。整组冰锥朝同一个瞄准点齐射，每条冰锥在 `FPSIceSpikeVolley::Tick` 的飞行扫掠里只要命中任何目标就 `Shatter`，尸体也会吃掉冰锥，所以先击杀的那一枚之后的冰锥会全部浪费在尸体上。

现已按用户设定修改 `AFPSIceSpikeVolley::Tick`：扫掠命中时先判断目标是否已经是尸体——是尸体就加入忽略列表并继续扫掠，直到打到活体敌人或墙体才停下；原本「一次冰锥直径内结算重叠接触」的规则、墙体截止与命中特效保持原样。效果是同一轮的后续冰锥会穿过尸体继续飞向后方目标，或飞到瞄准点／射程终点静默结束。技能详情页也补了一句说明。

## 4. 魔杖乘数接口（预留）

- 新增 `UColdSteelStatusModel::MagicImplementMultiplier()`：读取当前主手装备数据里的 `wandSpellMultiplier`（默认 1，非正数按 1 处理）。目前没有任何物品定义该键，因此恒为 1，现有伤害不变。
- 火球与冰锥都已接入（2026-09-17 补齐冰锥）：`火球 = floor(魔攻 × 系数 × 魔杖乘数)`，`冰锥每枚 = floor(floor(固定项 + 魔攻贡献) × 法杖增伤 × 魔杖乘数)`。后续做魔杖时在物品数据写 `wandSpellMultiplier` 即可，当前没有物品定义该键，乘数恒为 1。
