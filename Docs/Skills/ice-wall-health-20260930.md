# 冰墙生命值与中立受击

2026-09-30 用户要求冰墙可被怪物和玩家攻击摧毁，按中立物品处理，不显示在生命值栏中。

- 用户随后要求生命随技能等级成长：`生命 = maxHealth + maxHealthPerLevel ×（等级 − 1）`，当前基础 300，每级增加 50。1／5／10／15／20 级分别为 300／500／750／1000／1250；高墙、矮墙使用同一公式，各自整面共享生命，不按冰块重复增加。数值经 `FIceWallTuning`、`IceWallStats` 和凝聚时的施法快照传到墙体；升级后新凝聚的冰墙使用新生命，已生成墙体不自动补血。
- 技能详情增加“墙体生命”数值行，当前级与下一级共用实际生成公式；战斗血条仍不显示冰墙。
- 只有完成生长、开启实体碰撞后的墙体接受伤害。凝聚、飞行和预览模型不承受伤害；墙体接受玩家、施法者和怪物的实际伤害，无阵营免伤或怪物角色护甲。
- `AFPSIceWall::TakeDamage` 扣除墙体生命，归零走原碎裂声音／粒子并移除碰撞、导航和寒冷光环；原持续时间到期同样碎裂。摧毁接触只结算一次。
- 墙体是带 `Neutral`、`NoSkillTraining` 标签的普通 Actor，不增加怪物战斗组件、角色生命组件或血条组件。现有命中生命栏读取怪物 Pawn，冰墙不会成为其展示对象，不发放杀敌、修炼或掉落奖励。
- 护士、胖子、毒液僵尸、狼／僵尸犬、突变体、手脑和巨手在既有攻击的接触时刻处理前方墙面。已记住玩家的怪物在墙面进入攻击距离后可攻击挡路冰墙；保留各自攻击动作和冷却。巨手小手的接触攻击也能伤墙。
- 巫婆和毒蛆的视线若被实体冰墙挡住，允许沿现有施法节奏攻击；其投射物在首个墙面接触处扣墙体生命并停止。无毒层、恐惧等角色状态附加到墙体上。
- 玩家枪械、弓箭、剑刃和快速近战沿既有命中入口伤墙，快速范围近战包含首个挡路墙面；火球与冰锥补上实际直击墙体结算。火球先结算原爆炸的遮挡，再结算直击墙体伤害，冰锥命中墙体不继续穿过墙。
- 未新增扫描全部墙体的 Tick；墙面查询随现有 AI 决策与攻击接触执行。
