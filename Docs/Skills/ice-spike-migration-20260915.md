## 保留的数值与机制

令 L 为技能等级，1–20；M 为施法时魔攻，I 为施法时智力：

- 每枚基础伤害 B = floor(30 + 5L + M×(1.2+0.25L) + I×(1.2+0.25L))。
- 法杖改造后的伤害 = floor(B×(1+通用魔法增伤+冰系专精增伤)×(1+消费链式层数×链式增伤))；随后进入已有魔防、穿透、额外增伤与暴击结算。
- 基础数量 N = 2 + floor((L−1)/5)，再加当前法杖 iceSpikeCountDelta，最低一枚。
- 基础魔法消耗 30，基础冷却 10 秒；最大悬浮 30 秒。没有套用火球的蓝耗增长或 12→8 秒冷却。
- 原速度 1600、射程 800，以既有 1 原单位 = 1.5 cm 换算为 24 m/s、12 m；目标碰撞半径 12 换算为 18 cm。
- 消耗 = max(0,floor(30×(1+改造耗蓝比+链式层数×链式耗蓝比)))。
- 冷却 = 10×max(0.2,(1−法杖冷却缩减)×(1−法袍冷却缩减))，整组结束后才倒计时。
- 修炼门槛 100L；全组有效命中 H、直接击杀 K：经验 = 4H+12K+(H≥2?10:0)+(K≥2?10:0)。同一敌人被多枚命中按多个命中事件统计。召唤物、尸体、友方和无修炼目标排除；独立暴击修炼合并提交。

首次按键凝聚整组并扣一次魔法，再次按键同时射向该次接触帧的准星目标点。各枚从真实悬浮位置出发；固定直线、不追踪目标。到达目标点或接触后碎裂，达到最大射程静默消失。悬浮超时取消，不自动朝前发射。所有冰锥完成后统一释放冷却、结算修炼。已凝聚的一组保持等级、装备、属性及冷却快照。

默认直击头部／cranium 要害必定暴击，普通直击独立随机暴击；二者只应用一次暴击倍率。碰撞传递完整 FHitResult，碎裂粒子没有额外范围伤害。

## 原版问题与 UE 适配

1. 原详情页分别取整魔攻和智力贡献，可能比真实公式少 1 点。UE 详情和施放共用 IceSpikeStats，以实战总和取整为准。
2. 原飞行中重新读取技能等级，途中升级会改变已生成投射物。UE 固定在凝聚时快照，避免枚数、伤害或冷却中途变化。
3. 原同帧碰撞循环允许一枚伤害多个重叠敌人。UE 保留近距离重叠接触结算，但把连续扫掠中的接触群限定在首接触后一枚直径内，且墙体截止；不复刻帧率越低穿透越远的行为，也不是爆炸 AOE。
4. 首轮将 2D 身后环绕改为角色周围的立体悬浮；用户后续改为头顶横排、各枚独立小幅连续漂移，取消绕身旋转和自转，尖锐前半部分露出屏幕上方。靠墙收回并隐藏过近镜头的主体。只在凝聚／齐射手势期间占用左手，复用当前火球已认可手势；悬浮时可换装。复用入口 TryBeginSpellGesture，不再生成另一套手臂。当前美术见 [5080 与寒气升级](ice-spike-frost-v2-20260915.md)。
5. UI 显示的整轮伤害是全部冰锥有效命中的理论值，不能当作保证伤害或 AOE 总伤害。
6. 原版普通冰锥无内置寒冷。仅法杖 iceChillSlowPercent 非零时叠寒冷：减速比例按层数线性相加，剩余移速最低 1%；重复命中延长时间，20 层扣 10 层并冻结。冻结中不再叠加寒冷，冻结时物理承伤 +50%；冻结中断复用怪物受控入口，视觉沿用现有受控表现，未复刻旧 2D 冰块包裹画面。

法杖挂钩包含额外枚数、魔法／冰系增伤、穿透、暴击率、耗蓝、冷却、射程、施法速度、寒冷、链式与施放后加速。加速每层 +10% 移速，层数与时长累加；链式每次结束加一层／10 秒，下一次冰锥凝聚成功消费。状态免疫拒绝获得这些状态。这里实现的是冰锥消费已有装备改造数据；原项目全部法杖模型、改造台目录、其他魔法及其链式互通不属于本次全部迁移的声明。
