# 右手法杖施法 · 2026-09-27

用户要求装备法杖后改用右手持杖施法：举杖对应积蓄，向前挥杖对应发射。未装备法杖继续使用已有左手动作。本轮制作第一人称程序化姿态，不新增 FBX 或替换共享手模。

## 动作设计

| 阶段 | 默认时长 | 表现与业务时点 |
| --- | --- | --- |
| 积蓄 | 0.95 s，沿用 RaiseDuration | 从当前行走／奔跑持杖姿态进入；肩肘带动右手抬高，杖头适度前倾，保持上段入镜。V6 的正手抓握整体随杖运动，不另转腕或改手指。 |
| 独立发射准备 | 0.20 s | 已有悬浮火球、冰锥或直接释放的法术，从当前持握短促举杖到同一准备姿态。火球凝聚期间已排队发射时，从积蓄末端直接前挥，跳过重复准备。 |
| 前挥 | 0.28 s | 先用 0.035 s 稍作后引，再向前挥出；前挥第 0.18 s 触发原技能释放事件。右肩、肘与法杖同步前送，不松开握柄。 |
| 随挥与收势 | 终点停留 0.10 s + 收回 0.42 s | 接触后有 0.16 s 的轻微整体回震，然后沿弧线收回当时的持杖姿态。常规独立发射总长 1.00 s。 |

移动阶段继续使用已有施法速度快照；终点停留维持实际 0.10 s。蓄力与发射共用现有技能阶段时钟，姿态和释放判定都读取这套时钟，没有新增动画定时器。提前取消时先记录当前姿态再收回；切武器／高优先级动作沿用现有中断合同。

## 接入

- `Weapons/Staff/StaffCastMotion.h`：可编辑动作参数、正手持杖接触变换、肩肘支撑、前挥、回震和回收曲线。
- `Weapons/Staff/StaffWeaponComponent.*`、`StaffArmsMeshComponent.cpp`：法杖与右手使用同一握持变换，右肩／肘使用同一动作采样。保留 V6 手指接触、上段握点和 V5 走跑表现。
- `Skills/FPSFireballComponent.*`、`FPSStaffCasting.cpp`：手势开始时选择持杖或左手分支并捕获入场姿态；持杖时 `IsOccupyingLeftHand()` 为 false，通用施法占用仍阻止重叠技能／近战。备用左臂也不会出现。法杖尚未加载或仍在装备、挥击时继续排队。
- 火球从杖头前方凝聚，积蓄结束后停留在确定的悬浮偏移；后续释放和换武器不把球拉回杖上。继续使用现有墙面避让、实际悬浮起点发射和弹道预览。
- 冰锥共用举杖／前挥，保留既有悬浮队列和齐射逻辑。闪电共用前挥并改从当前杖头出光；圣光（含自愈）用持杖动作代替左手推掌／握拳。陨星用前挥；灼锋焰甲沿用积蓄末端生效，但动作由右手举杖完成。
- 伤害、消耗、冷却、修炼、命中结算、已释放实体和未释放退蓝规则继续由原技能管理。等待提示统一为“等待施法”。
