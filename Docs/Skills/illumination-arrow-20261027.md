# 照明箭 · 制作与数值合同（2026-10-27）

## 操作与规则

- 弓限定，选择技能后搭上一支照明箭。按住左键正常拉弓，松手发射，随后恢复普通箭。兼容完美节拍、穿心箭的伤害／箭速／穿透；与元素箭、魔法箭雨的准备状态互斥。
- 基础 12 MP 与 1 支箭在成功发射时扣除，独立冷却从发射开始。取消不扣蓝、箭支或冷却；持续拉弓只沿用普通弓耗体。装备减耗／冷却缩减按共同入口生效。
- 箭头两条白金弧带绕箭轴旋转，局部点光源提供短程实际照明；扫描半径与灯光衰减半径独立。
- 服务器沿实际飞行段作连续球扫，通常每 0.1 秒一次，额外以半径 35% 的路程上限补扫；物理命中前补扫到碰撞点。标记前用共享 MagicOcclusion 身体多点判断，实体墙／楼板遮挡、明确镂空栏杆沿原规则传播。
- 每目标每箭最多扫描标记一次，从该目标被扫到时计时；实际直击另从命中时刷新为双倍持续（20→60 秒）。穿心箭穿透命中的每个目标都适用。后续扫描不会缩短同一玩家已有的较长标记，击杀仍只归属最新一支箭。
- 实际命中留下独立照明光源，持续与直击标记相同（20→60 秒），怪物命中点随组件／骨骼移动，地面与墙面命中点固定；箭被拾回或继续穿透不影响光源。光源只照明，不继续扫描或造成持续伤害；箭矢停止或销毁后不再扫描，已有标记继续至到期。
- 红色轮廓高亮：复制绝对结束时间，独立深度代理使用 stencil 236，原模型与其他轮廓的状态不改写。标记后敌人躲到遮挡物后，剩余时间内仍能看见轮廓。
- 标记令目标承伤提高，进入通用伤害链，与已有通用标记取较高值而不连乘。同种重复施加不叠层；不同施放者各自保留时效，最强有效标记生效。
- 螳螂即时解除隐身、恢复材质与移动，标记期间不能重新隐身；不触发隐身突袭伤害奖励。净化／免疫清理、死亡与移除清理标记。

## 修炼

- 本人击杀仍有本人有效照明标记的敌人：12 XP。
- 同一支箭累计 3 杀：额外18 XP；5 杀：额外30 XP；7 杀：额外48 XP。每档每箭一次且可叠加，三／五／七杀累计54／108／180 XP。
- 升级所需=当前等级×300 XP，1→20共57,000 XP。无满级后储存。
- 不限补刀武器，沿用 NotifyKillByOwner 的本人击杀归属；本人持续伤害有效，队友击杀不计本人修炼。友方、召唤物、NoSkillTraining、重复死亡、标记到期后的击杀不计。
- 同一玩家重新标记同一目标，后续击杀归属最新一支箭，不跨多支箭重复奖励。每个目标自己的标记有效期决定是否计入该箭的档位。
- 伤害期间只累加待结经验，伤害调用者完成其原有奖励事务后，在技能组件 Tick 合并交给 StageTraining，保留原有弓精通／武器／魔法经验。
