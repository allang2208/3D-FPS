# 暴风雪室内施放优化方案

状态：用户已授权按本方案实施，制作与交付状态见 `blizzard-indoor-implementation-20261012.md`。方案依据室内无特效、无伤害的反馈及源码制定；未运行游戏复现，未认定现场某个具体 Actor 是唯一原因。

## 目标

暴风雪在所选地面所在的室内空间形成局部冰雪风暴。天花板只改变表现高度，不作为施法失败条件。保留真实墙体、关闭的门及楼板的隔断，避免隔墙／跨楼层伤害；等级成长、持续时间、伤害、施法距离、两阶段操作和资源事务保持现状。

## 当前存在的具体限制

1. `FPSBlizzardComponent::SelectGround` 仅接受准星首个命中且法线 Z≥0.45 的表面。室内瞄到梁、灯、天花板或装饰时直接失败，没有在命中前的同室空间向下寻找地面。
2. `ValidateGround` 另做 ±24 cm 地面重验及相机到地面上方 12 cm 的视线检查。预览没有使用同一完整判定，所以可能选点成功、接触释放时才失败；目前原因合并为“落点被遮挡或超距”。
3. `UpdateCloudClearance` 取整个云足迹内的最低净空，盒体从地面上方 25 cm 开始上扫。桌板、矮设施或局部横梁可能把整个云压到接近地面；25 个高度最后只留下一个全局数值。
4. `DamageTick` 已独立于装饰冰锥，但只用距地面 35 cm 的单条连线判断遮挡。台阶、桌脚、地面凸起都可能切断它；目标脚底与中心表面的高度差还固定限制为 100 cm。
5. 区域初始化依赖全部 15 个资源以及多个特效组件创建成功，缺一项就销毁整个区域。此为另一条“没有表现也没有伤害”的失败路径，不能直接认定用户现场一定是资源问题。

## 推荐实现

### 1. 先让室内落点可靠

- 将选点、预览、释放接触帧及服务端重验收敛到同一局部落点函数，返回明确原因。
- 准星直接命中合法地面时保留现有落点。命中墙／梁／顶时，从阻挡前留出间隙的位置，在有限高度内向下寻找同室可见地面；不从屋顶外或上一层向下穿透找点。
- 查询分别处理地面、施法通路和顶部净空。角色、自身装备、特效不参与环境阻挡；真实墙、楼板和门继续阻挡。装饰仅在已有明确标记／碰撞语义允许时忽略，不能用“隐藏”或 WorldDynamic 一概排除。
- 无合法地面时保留已凝聚的云并提示“未找到室内地面／落点被墙体挡住／超出距离”等实际原因；不进入冷却，不重复扣蓝。

### 2. 把局部障碍与整个房间的天花板分开

- 复用当前有界 5×5 采样预算，为采样单元保留地面、净空及通路结果，不再让一个桌板决定全区最低云高。
- 云主体按中心所在可达空间确定高度；低梁／桌柜所在单元压薄或减少局部粒子，墙外单元不生成降雪。低顶只缩小视觉高度，不修改技能数值半径。
- 保留每区最多 3 个 Niagara、现有 ISM 池和每人最多 4 区，不引入全场 Actor 遍历。动态门／障碍沿现有 2 Hz 环境更新节奏处理。

### 3. 三档表现，最低空间仍然可见

| 空间 | 表现 |
| --- | --- |
| 室外／高顶 | 乌云、完整降雪和落冰，保留当前主体风格 |
| 普通室内 | 天花板下薄云，缩短落冰起点和行程，雪与寒雾填充室内范围 |
| 极低顶／密集横梁 | 以贴地卷动寒雾、横向飞雪、短冰晶爆散表现，减少或淡出大云与长冰锥 |

空间档位平滑过渡；不用关闭深度测试让特效穿墙。预览、实际粒子、受影响地面读取同一份有效足迹，避免画面落在屋顶外而伤害发生在室内。

### 4. 伤害与屋顶／装饰落冰解耦

- 权威区域按原频率和椭圆范围结算，云的位置、粒子是否撞顶、装饰冰锥是否成功落地均不控制伤害。
- 目标归属以有效地面及楼层关系判定。楼梯／坡道使用对应局部地面高度，避免仅靠中心高度差排除同一楼梯上的目标，同时保留楼板隔断。
- 用目标身体的低／中／高几个受限通路替代唯一的 35 cm 连线；小凸起或桌脚不应屏蔽整个目标，完整墙体和楼板仍阻挡全部通路。
- 区域玩法创建与完整装饰资源创建分开。高级云／冰锥暂未就绪时保留基础地面寒霜、局部飞雪及伤害；若连基础可见反馈也不可用，则明确失败并走原退款流程，避免静默的隐形伤害区。

### 5. 保留联机和资源事务

权威端重新确认合法落点与区域创建后才提交释放。失败继续现有退款／保留凝聚规则；客户端接收区域中心、空间档位和所需表现参数，使用现有服务端时间与剩余寿命，不重开一份完整持续时间。客户端不自行结算伤害。

## 实施顺序

1. 共用落点函数、失败原因、区域权威创建与表现依赖分离。
2. 目标通路与局部地面判定，让正常室内目标稳定受伤且楼板／墙体继续有效。
3. 有界空间采样与三档 Niagara 表现，实际后台保存资产并更新运行引用。

建议用户之后重点体验：普通房间、低顶走廊、横梁／灯具、桌柜旁、上下楼梯、隔墙和上下层目标；本轮没有执行这些测试。
