# 本对话改动复查与联机边界（2026-10-20）

结论：此前“制作、保存、编译完成”不能视作整批联机验收完成。本轮发现并修复了陨星网络事务及刀剑精通修炼的问题；另确认了仍未制作的鼓囊飞行音优化、未覆盖远端玩家的双手锤出手声，以及 M870 普通声的素材来源边界。

## 本轮修复

| 问题与触发 | 原结果 | 修改 |
| --- | --- | --- |
| 客机陨星施法中移出距离、切掉法杖或中断 | 本地退款／收手后，服务器仍可能保留这次施法，阻挡后续法术；陨星也未进入持续技能预留超时回收分支 | 陨星 Prepare、Release、Cancel 共用 CastId；失败分支立即取消预留，服务器加入死亡、切杖、超时回收 |
| 陨星释放遭拒，或其他法术的新请求先发出 | 客机释放时已清空 CommittedSkill，拒绝回执没有原支付金额；通用“最近请求序号”过滤可能丢弃旧回执 | 保留实际支付金额，以本次陨星 CastId 接收回执；拒绝仅退款一次并清冷却，成功后不再退款；旧回执不影响新施法或其他法术 |
| 客机上报陨星落点 | 服务端只检查横向距离与客户端法线，未确认实际地面／实体遮挡 | 复用暴风雪的地面验证，服务端求实际落点、法线与可见地面；保留原 15% 网络距离容差 |
| 刀剑范围快速近战同次命中多个敌人 | 缺少多目标精通奖励；击杀目标被排除在累计命中数之外 | 第二个有效敌人给予一次额外修炼，击杀同样计为有效接触 |
| 普通刀剑部分击杀路径、友方接触 | 计数依赖特定动作的反馈分支；友方可能参与局部命中计数 | 使用共同有效敌人规则，按实际伤害或直接击杀计数；旋风精通使用同一服务端接受命中计数，不再另行按旋风总命中数补发 |

陨星释放后的装备附加施法增益改为收到成功回执后才在客机应用。新旧程序的陨星请求规则不同，联机各端需使用本次新构建。
