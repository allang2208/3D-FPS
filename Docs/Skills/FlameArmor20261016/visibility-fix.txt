灼锋焰甲不可见：定向排查与参数修复（2026-10-16）

用户现象：施放后有持续状态，但看不到身体和武器火焰。

已获取的证据
1. 运行日志显示 flameArmor 预载完成。保存的三个新版系统均可加载，发射器与渲染器启用。
2. 独立后台 Niagara 模拟中，Body / Weapon / Arrow 都激活成功，有非零粒子数、非零尺寸和非零 Alpha。
3. 隔离的焰甲组件复现通过正式 NetRelease 入口激活，持续时间由 12 秒降至 11.33 秒。
   周身与武器组件均 active=true、visible=true、hidden=false、rendering=true，Fade 与 Detail 非零，并有粒子输出。
   该复现检查组件逻辑，不等于用户装备的实际画面或挂点验收；测试角色没有完整初始化所有武器资源。

明确发现并修复的问题
新版作者脚本把 TorchFire 的动态材质参数沿用了另一套火焰的偏移形式：
    错误：float4(0, 颜色曲线, 溶解曲线, 0)
TorchFire 材质实际使用 X=Emissive 颜色幂曲线、Y=Dissolve Alpha 幂曲线。
篝火原作者中的“Index 0 Param 1 / Param 2”是从 1 开始编号，对应 X / Y。
修复为：
    float4(1.15 + .25*粒子随机值, .9 + .4*寿命后段平滑淡出, 1, 1)
主火焰恢复与原材质一致的通道合同，避免把颜色幂指数写成 0，溶解参数也回到正确通道。
另外将未被渲染器读取的 Particles.SpriteUVScale 改为实际绑定的 Particles.UVScale=(1,1)。
UV 缺失时引擎原本有 (1,1) 回退，因此此项是绑定纠正，不作为单独的不可见根因。
