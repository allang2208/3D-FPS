## 使用与施法合同

在“魔法”或“主动”技能页找到暴风雪，拖入任意技能快捷格。瞄准地面按该格绑定键施放。短时手部动作结束后执行；有效起手才扣蓝并开始冷却，锁定该时刻地面位置及数值，施法手势接触帧生成区域。角色移动不会带走区域；角色施法时保持既有魔法移动规则。

按用户此前“只限制陨星和冰墙”的要求，**暴风雪不加法杖限定**，配置为 `requiresStaff=false`；法杖装备词条仍正常生效。这是对原版法杖门槛的明确适配。双持手枪占用左手时拒绝新施法并显示现有占用提示。

缺蓝、超距、无地面或素材仍在加载时不扣蓝、不开始冷却。释放帧检查锁定点距离及遮挡，失败退蓝并清除此次冷却。死亡、打开菜单、优先动作打断及退出取消未释放动作。模型保存实际扣除量；无限蓝下付款为0，避免虚增魔法值。付款释放成功后清空，防止重复返还。

旧档迁移至技能档案 v18，新建暴风雪1级进度，不改变已有快捷栏绑定。级别/经验/绑定及冷却随现有 Profile 存盘；重新加载发现未释放付款时返还实际蓝耗并清除该次冷却。已生成的短期战斗区域不跨地图/读档恢复，死亡/离场清除未结束区域且不结算该场修炼；角色击杀经验即时处理，不等区域结束。

## 数值

使用原版配置而不是组件备用默认值。原坐标单位统一换算为1.5厘米，等级 L=1..20。

- 每拍基础伤害：`floor(5 + 2L + (魔攻 + 智力) × (0.12 + 0.02L))`；再乘魔法实现倍率、法杖冰系/魔法及链式词条并向下取整。命中走既有魔防、魔法增伤、穿透和暴击，伤害类型继承冰系，不触发焰甲火伤钩子。
- 椭圆半轴：`Rx=(200+8L)×1.5 cm`，`Ry=(124+5L)×1.5 cm`。1级全轴6.24×3.87米，20级10.80×6.72米。长轴沿起手时相机右向落地投影。
- 持续：`5 + floor((L−1)×5/19)` 秒，5→10秒；冷却：`40 − floor((L−1)×5/19)` 秒，40→35秒。
- 蓝耗150；施法距离650×1.5=975厘米。现有法杖、套装及符文的消耗/冷却/距离/施法速度修正继续生效。
- 每0.5秒一拍，释放时立即首拍，持续终点不多结算一拍。1级10拍，20级20拍；每个目标每拍最多一次。坠冰只是视觉，不另算命中伤害。
- 每拍施加1层寒冷，持续2.5秒，每层减速3.5%；后续叠层、冻结、免疫与状态显示由现有 `CombatStatusFormula` 接管。
- 每次有效命中+1、直接击杀+6；任意一拍命中至少2个修炼目标+5一次；整场击杀至少2个+10一次。持续自然结束统一汇总；友方、尸体、召唤物与 `NoSkillTraining` 目标不刷修炼。随机暴击同步修炼暴击技能。每级经验100×当前等级，最高20级。

区域伤害通过局部对象碰撞查询取得候选并按 Actor 去重，不逐帧遍历全世界。脚底与区域平面高度差超过100厘米或椭圆外不受伤；区域中心到目标脚底存在阻挡则跳过。装饰细节预算不影响区域尺寸、伤害频率或霜痕主体。

新资产归属仅 `/Game/Skills/Blizzard`；现有冰锥/冰墙/Fab素材为只读依赖，没有改写。资产作者实际执行 `Tools/Skills/build_blizzard_assets.py`，回执为 `Saved/BlizzardMigration/asset-authoring.json`，不是仅提供待导入脚本。

`DefaultGame.ini` 纳入暴风雪运行时异步路径及复用起手音目录的 Cook 清单，技能 PNG 目录沿 UFS 暂存。Fab 材质/贴图随专属模型与霜痕的资产引用携带；没有实际运行 Cook、打包或打包验收。

- `NS_BlizzardCloud`：灰色羽化云团，使用现有冰锥烟雾图集的独立材质实例，发光值0。
- `NS_BlizzardSnow`：细小白色落雪及横向风，沿落地法线下落并在地面淡出。
- `NS_BlizzardMist`：低空薄寒雾，复用冰锥材质/图集，避免放大烟片覆盖玩家视线。
- `M_BlizzardFrost`：地面椭圆霜痕，采样已纠正为 Color sampler 的 Fab 冰面纹理，柔化边缘和低幅呼吸。
- `SM_BlizzardHail`、`SM_BlizzardSpike`：后台 Blender 制作、FBX 导出并实际导入。冰锥复用 `FabIceV3/M_IceWall`，雪团独立高粗糙度材质。

每区域最多48个坠冰/碎冰实例（2个 ISM 各24个），雪团/冰锥比例55%/45%，约每0.05秒尝试出生一件。落地碎冰复用同一48槽上限，每次最多3片、寿命0.35秒；接触薄雾走共享冷雾池。每玩家最多4个暴风雪区域，包括无冷却模式。资源在组件 BeginPlay 异步预载并持有；新付费施法不执行同步加载。风与远距细节每0.2秒从共享流体调度取得；装饰碰撞复用共享几何查询预算，没有每粒子 Actor、逐粒子灯光或额外全屏后处理。

云顶创建时探测中心上方屋顶并降低高度；雪团/冰锥沿落地法线坠落，装饰碰撞预算耗尽时退回区域平面。伤害遮挡使用独立玩法查询，不被装饰预算裁掉。死亡/离场停止并销毁区域组件；自然结束汇总经验后保留0.6秒视觉淡出。
