# 范围技能与镂空障碍（2026-10-13）

用户反馈：楼梯栏杆另一侧的怪物无法被闪电／雷暴领域攻击。此次统一范围伤害与连锁的遮挡规则。

## 实现

- `Source/FPSGAME/Skills/MagicOcclusion.*` 提供共同判定。法术视线使用复杂碰撞，避免简单凸包将网格孔洞封死；目标身体中心被遮挡时，再取身体内的上、下、左、右点，任一点露出即可命中。
- 复用现有 `Traversal.GuardrailDrop` 标记。组件直接带标记，或独立 `AStaticMeshActor` 栏杆的本体组件，可供范围技能穿透。只忽略命中的栏杆组件，然后重新查询同一整段射线，栏杆后方的墙体仍然阻挡。每条射线最多处理 16 个连续栏杆组件。
- 新制作的网格／镂空装饰若仍使用封闭的简单碰撞，可在其独立组件上加 `Magic.Permeable`。该标记只影响本次接入的范围／连锁判定，不改变角色、子弹或普通近战的物理碰撞。楼板、墙体、封闭门及包含这些结构的合并组件不能加此标记。
- 未标记的障碍通过实际复杂碰撞孔洞与身体采样判断；完整墙、楼板、关闭门继续作为阻挡。玻璃仍沿现有可击碎目标合同处理。
