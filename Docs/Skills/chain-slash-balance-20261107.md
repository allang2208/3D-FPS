# 连斩：数值与修炼（2026-11-07）

用户要求：双手剑限定，四段攻击；1级每段40%、20级每段120%；CD从25秒降到15秒；体力随等级增加且释放前支付；修炼包含释放、击杀和多杀。

## 成长与结算

令 t=(等级−1)/19，等级1–20。每段倍率=0.4+0.8t；基础冷却=25−10t秒；基础体力=40+20t。体力40→60按用户后续要求调整，采用同一线性进度；执行保留小数，面板显示一位小数。

四段使用同次起手的武器伤害、技能倍率和武技伤害修正快照，沿用共用武器伤害、防御、暴击及武器精通通道。韧性伤害由每段实际伤害推导，共用同一40%→120%等级倍率，保留武器削韧修正和目标韧性抗性；不再重复乘等级倍率。攻击范围保持普通前方挥斩，每段独立去重。攻击动画、手臂姿态、空间折射、命中停帧和独立动作时钟沿用现有版本。

先确认装备、动画、动作占用、技能等级、冷却和体力，然后在起手前一次扣足整次费用并开始CD。体力不足拒绝施放；已起手中断不退款、不清CD，已经发生的击杀仍结算。体力使用共用装备/改造/临时/套装减耗公式，正基础费用至少保留20%。联机由服务端先确认并扣费，拥有者收到确认费用后开始本地动作；延迟回执沿共用累计近战费用账本合并。

## 修炼

- 释放技能：+1 XP（确认起手后，空挥也计）。
- 击杀目标：每个直接击杀+12 XP。
- 击杀多个目标：同次技能直接击杀至少2个，额外+20 XP，每次限一次。

奖励叠加，完整四斩／取消时统一结算一次。同目标死亡去重；只计命中前存活的敌人，排除召唤物、NoSkillTraining及附带持续伤害或连锁的击杀。每次升级需100×当前等级XP，满级停止积累。修炼只在权威端结算。技能存档版本30为旧档补1级连斩，已有技能保持；冷却沿现有实际游戏时钟递减和保存。
