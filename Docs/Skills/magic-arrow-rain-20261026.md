# 魔法箭雨：玩家端第一版

制作日期：2026-10-26。技能 ID：`magicArrowRain`。弓限定主动范围魔法。

## 操作和反馈

1. 在技能页学习，并将卡片拖到快捷栏；装备弓后按绑定键准备。
2. 复用弓的右手搭箭动作。已有搭好的箭时继续使用，箭身叠加缓慢流动的绿色脉冲。
3. 长按鼠标左键拉弓；准星圆弧和下方进度条使用绿色。地面范围圈随镜头选点，满蓄后轻微脉冲提示可释放。
4. 满蓄后松开左键，沿用最后显示的圆圈落点发射；保持按住可以持续瞄准，资源持续消耗，不自动射出。松手与服务端确认阶段均不重新选点，服务端仍检查该点的地面、射程、视线、净空和实际箭尖起飞路径。
5. 无效落点显示红色提示。未满蓄、落点无效或资源耗尽时收弓；再次按技能键、切换装备、菜单及动作打断也取消。

魔法箭雨期间不叠加普通弓的完美节拍或穿心箭收益。画面沿用原有圆弧和下方进度条，没有增加独立瞄准面板。

## 效果节奏

- 离弦：保留清楚的弦音和短促风切，引导箭带细绿色尾迹。
- 空爆 V4：0.24 秒的不规则亮核快速膨胀后转翠绿，错开 0.035 秒的两层气浪扩张（主气浪默认可见宽度约 7.8 米），配合 14 条加粗放射光痕。18 片灰绿翻卷烟团最长 0.9 秒，中心在 0.09–0.27 秒变薄，外圈向外冲出并缓慢消散。没有全屏闪光、相机震动或动态灯。
- 箭雨 V3／光效 V4：全部从空爆点出发，向判定圆内以圆锥形散射。空爆后 0.10–0.30 秒分布发射，无遮挡飞行段 0.125 秒（原 0.25 秒的两倍速度）；箭尖整个下落段保持绿色高亮，最长 3 米的尾迹半径增至 2.6–3.2 cm，采用亮绿芯和柔化边缘。每个目标仍只结算一次伤害。
- 落地 V3：每根箭按实际接触时刻在接触表面触发绿色闪光、贴面冲击圈、三点绿色碎光和两团低位烟尘。冲击闪光 0.13 秒、薄圈 0.19 秒、碎光 0.16–0.28 秒、烟尘 0.55–0.80 秒；箭体短暂留下后缩退。整组声音仍只播放一次。
- 遮挡：实体墙、顶板和楼层阻断选点、引导箭或下落路径。引导箭途中被挡只在碰撞处碎散，不触发远端箭雨。

三层声音是首版混音：出箭使用原有合法 CC0 弦音和风切源，空爆与落地为合成声。空爆播放增益 0.48，落地 0.8；源文件也分别限制峰值，不把空爆做成压过细节的大爆炸。尚未试听验收。
