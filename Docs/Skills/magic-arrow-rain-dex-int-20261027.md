## 正式公式

令 `K=技能等级-1`，当前等级范围 1–20：

```text
基础伤害 = floor(70 + 8*K
    + 敏捷*(21 + 1.25*K)
    + 智力*(10.5 + 0.625*K))
```

敏捷与智力的直接伤害系数及其每级成长始终为 2:1。属性读取模型的有效总值，包含装备、精通和当前状态修正；不要求玩家按 2:1 分配属性点。参数替代旧的面板魔攻项，没有总伤害乘 0.75，也不读取玩家的陨星等级或陨星伤害。

参考陨星的基础中心爆炸强度进行标定，不包含熔火、灼烧或法杖专属倍率。在箭雨敏捷80/智力40、对照陨星智力80/智慧40且无额外装备魔攻/增伤/暴击的设计样本中，1级为2170对2880（75.35%），10级3367对4482（75.12%），20级4697对6262（75.01%）。这是一组参数标定，不表示任意属性分配和装备都恒定为75%，也不是游戏测试结果。
