# 魔法箭雨后台检查与修复

用户于 2026-10-26 明确要求“自己检查一遍”，本轮在该授权下检查、修复并运行隔离用例。未启动 UE 编辑器界面、PIE 或实际游戏地图，未使用正常玩家存档。

## 发现并修复

1. **首次加载遗漏**：`Gather` 有资源路径，但 `SkillCatalog` 没有 `magicArrowRain`，导致已学技能队列没有对应作业，组件可能一直显示“素材加载中”。补齐目录并归入后台魔法作业；不把弓技能加入法杖专用魔法轮盘。
2. **未满蓄反馈串线**：普通弓的 50% 门槛先于箭雨分支，提前松手会显示错误提示。箭雨先执行自己的满蓄/取消规则。
3. **蓄力计时跨帧误差**：搭箭结束后已进入拉弓的帧内余量只在本地生效。权威计时现在采用与普通弓一致的有界余量，保留独立 1.2 秒时钟。
4. **准备和取消状态**：新准备先绑定当前弓，避免被旧武器 ID 拦截；取消等待期间不接受新准备，过期准备回执不能重新搭箭；已经提交释放时再次按技能键不会改变弓的动作。
5. **近距离瞄准敌人**：原服务端使用“视线到脚下夹角”拒绝点位，合法的近距离头部瞄准会被拦截。现在服务端复用镜头选点逻辑、比较实际投影落点，再复核引导箭路径。
6. **斜坡范围和落箭**：预览材质按世界水平距离绘制，与伤害半径一致。箭从各落点正上方竖直下落，保留地面法线以确定下坡探测深度和伤害高度；烟尘包围盒按实际落点生成。
7. **无限备弹入口**：准备阶段与真实发射使用同一无限备弹判定，不再在空箭袋时提前错误拒绝。
