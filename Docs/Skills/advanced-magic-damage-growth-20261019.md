# 高级魔法伤害与成长调整

用户反馈高级魔法伤害过低，要求参考其他魔法调整公式和成长。本轮覆盖冰墙、陨星、暴风雪、雷暴领域、贯穿雷枪和龙息。

## 参照与设计

当前火球伤害为 `魔攻 × (8.5 + 0.5 × K)`，K 为等级减一，1–20 级为 8.5–18 倍魔攻。冰锥每枚为 `21 + 3.5L + 魔攻 × (1.4 + 0.2917L)`，整组由 2 枚成长到 5 枚。两项保持现状作为参照。

旧高级伤害多沿用早期固定项＋魔攻＋独立智力的公式；暴风雪每 0.5 秒仅有 0.14–0.52 倍魔攻，陨星火场仅 0.28–0.85 倍。对高消耗、长冷却技能来说输出不足。新参数区分瞬间范围爆发、蓄力贯穿、地面持续区域、随身自动攻击和持续喷吐。

## 新公式

令 `K = 技能等级 − 1`，`M = 施法时魔攻`。先向下取整，再沿现有路径计施法媒介和装备增伤；目标防御、暴击与状态伤害继续在命中时结算。

| 法术 | 基础伤害公式 | 1→20 级魔攻系数 |
| --- | --- | --- |
| 陨星撞击中心 | `80 + 10K + M × (20 + 1.20K)` | 20→42.8 |
| 陨星地面熔火，每 0.5 s | `10 + K + M × (1.30 + 0.09K)` | 1.3→3.01 |
| 暴风雪，每 0.5 s | `12 + K + M × (1.60 + 0.12K)` | 1.6→3.88 |
| 雷暴领域，主落雷每 0.9 s | `20 + 3K + M × (2.20 + 0.16K)` | 2.2→5.24 |
| 贯穿雷枪，蓄力乘数之前 | `80 + 12K + M × (18 + 1.25K)` | 18→41.75 |
| 龙息，每 0.5 s | `25 + 3K + M × (3.40 + 0.24K)` | 3.4→7.96 |

雷枪满蓄力继续乘 1.3，命中前感电层数继续提供条件增伤。上述法术取消独立智力伤害项，智力通过角色魔攻间接影响伤害。

冰墙保留物理砸落与智力／精神定位：`80 + 12K + 智力 × (3.5 + 0.35K) + 精神 × (3.5 + 0.35K)`，之后计原有链式增伤并按目标物防结算。仍为每个目标一次落地伤害，墙体持续存在不会重复造成砸落伤害。

仅伤害相关成长改用 K；施法距离、影响范围、持续时间、数量、控制、资源和冷却继续使用原有各自公式。上轮的双倍施法距离和陨星三倍影响范围保留。灼锋焰甲与基础魔法的参数和等级口径不随这次调整变化。

## 参数设计对比

以下只用于公式设计：假定魔攻、智力和精神各为 100，装备增伤乘数为 1，不计防御、暴击、灼烧、感电与连锁。按参数数学值取整，运行时浮点和逐阶段取整可能有个位误差；不是实机伤害或回归结果。

| 技能／计量 | 1 级调整前→后 | 20 级调整前→后 |
| --- | --- | --- |
| 火球参照 | 850→850 | 1800→1800 |
| 冰锥整组参照 | 386→386 | 4070→4070 |
| 陨星中心撞击 | 677→2080 | 2520→4550 |
| 陨星熔火每拍 | 67→140 | 238→330 |
| 暴风雪每拍 | 35→172 | 149→419 |
| 雷暴主落雷 | 129→240 | 395→601 |
| 雷枪满蓄力，无感电 | 728→2444 | 2457→5827 |
| 龙息每拍 | 120→365 | 367→878 |
| 冰墙砸落 | 270→780 | 1410→2338 |

持续伤害不能直接与火球单次伤害比较：暴风雪有效覆盖 5–10 秒，有 10–20 次伤害机会；龙息需要维持喷吐；雷暴会分配给最近目标并逐跳衰减；陨星地面伤害还要求敌人留在火场。未把所有敌人、所有跳数都命中的理论总量当成实战结果。
