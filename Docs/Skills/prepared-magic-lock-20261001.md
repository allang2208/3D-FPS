# 积蓄魔法持有期间的施法互斥

2026-10-01 用户要求火球、冰锥、冰墙等积蓄魔法完成积蓄后，未释放前不能使用其他魔法。

## 交互规则

- 火球或冰锥仍未脱离、冰墙仍持有凝聚块时，阻止启动其他魔法。该限制独立于手势：积蓄后收手完成、切换快捷槽或打开菜单不会解除持有状态。
- 当前魔法的再次点按、长按瞄准后松手释放继续有效；冰墙建筑预览及 R 切高矮墙继续有效。冰墙确认位置到接触释放之间也保持占用，释放失败并返回预览时继续占用。
- 拒绝的魔法请求直接清除对应待施法队列，快捷槽提示“先释放已积蓄魔法”，不扣蓝、不开始冷却、不消耗连锁施法状态，不在当前法术发射后自动补放。
- 投射物实际发射、冰墙实际提交召降后，持有占用解除；后续收手仍遵守原手势互斥。已飞行的法术、已生成的墙或持续领域不占用这一持有锁。
- 雷枪现有蓄力期间也应用同一规则。已有到期、死亡、取消和装备变更清理沿用原技能生命周期，占用从实体及组件状态即时派生，不增加需要单独复位的锁标志。
- 这次互斥限定魔法施放；武器、药水及移动行为继续依照原动作仲裁。

## 源码接入

`FPSFireballComponent::HasOtherPreparedSpell(Requester)` 是共享只读判断。查询火球/冰锥的未飞行实体、冰墙 `HasUnreleasedCast()` 和雷枪 `IsCharging()`，排除请求组件自己的持有状态，以允许原法术释放。不增加 Tick、世界扫描、资源加载或持有注册表。

火球、冰锥、冰墙、圣光、闪电、陨星/焰甲、暴风雪和电系魔法的 Trigger 与队列服务均在支付/启动前接入；共享 `TryBeginSpellGesture` 同样使用该判断。火球直接进入凝聚的路径也接入，避免绕开共享手势入口。
