# 陨星燃烧表现 V6 — 2026-11-14

本轮按用户指定顺序制作撞击爆燃与余烟，再制作包覆火焰与尾迹。沿用既有岩体、V4 低矮残火、焦痕、声音、镜头、施法和全部玩法数值。仅后台生产、编译和资产保存，不打开交互 UE，不运行游戏、测试、截图或预览渲染。

## 素材与制作路线

借鉴 Can It Code 视频的“完整效果分层、独立动态素材、脚本组装”方法。此次使用项目已有 Blender Mantaflow 管线制作原创燃烧场，未调用 Seedance、未下载视频帧作为游戏素材、未购买或使用视频作者的付费资产。

- `impact`：四个不对称短脉冲燃料源，96 格最长轴、72 帧，先向外扩张再上升冷却。
- `wake`：三个错相持续燃料源，80 格最长轴、104 帧，取预热后 72 帧并做 8 帧重叠循环。
- 两张 2048×2048 图集，每张 8×8、64 帧，单格 256 像素，四像素边界。固定画幅，整段统一归一化，不按单帧自动增益。
- R 为火焰积分，G 为火焰加权热量，B 为烟密度积分，A 为烟形体明暗，**A 不是真实透明度**。材质从 R/B 计算覆盖率，烟与火分别着色。
- UE 使用线性 Masks 数据、双线性过滤与本图集专用的无 mip 配置。材质自行插值相邻帧；Niagara Renderer 保持 1×1，避免重复 SubUV。两图 BC3 级纹理数据理论约 8 MiB，不代表实测显存或整项特效成本。
- 保存 `.blend`、VDB 缓存、原始投影数据、PNG、通道清单和生产日志。没有生产摄影机，也没有生成验收图片。

## 撞击与余烟

继续使用现有落地事件和约 35 ms 岩体接触停顿。原伤害帧、岩体碎裂、焦痕与声音不变。

- 0 ms：一个短接触闪光，沿用 V5 材质。
- 25 ms：一个中心爆燃；45 ms：四团大小和扩散距离不同的爆燃。
- 130 ms：三团较弱翻卷火舌过渡到现有低矮火场。
- 最多八团贴地尘、五团翻卷余烟、三团细灰，错峰出现。余烟寿命 1.65–2.30 秒，火与烟独立密度、颜色和衰减。
- 总计最多 25 个瞬时系统粒子，其中 16 个烟尘粒子受现有共享预算管理。仍使用一个池化撞击系统，不增加灯、运行时流体网格或相机反馈。
- 水面命中关闭贴地尘，余烟沿既有湿命中配色；保留天气风与共享烟尘接触平面。

## 包覆火焰与尾迹

- 两层局部空间包覆焰，基础产生率合计 30/秒；较紧的表面热焰与较疏的拉长火舌分开控制，随原 Fade 起燃。
- 世界空间尾迹为热焰、撕裂火舌、冷却烟三层，基础产生率合计 55/秒。出生位置取实际前后两点之间的扫掠段，离体粒子不再跟随岩体。
- 火焰按寿命降低发光并消散，烟逐渐扩散；每个粒子有稳定相位与水平翻转，避免整条尾迹同步播放。
- 速度积分采用 `Velocity + Force * DeltaTime` 后乘指数阻力；持续运行不依赖固定帧率。无新 Tick、碰撞查询或复制粒子。
