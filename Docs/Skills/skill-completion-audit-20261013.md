# 技能代码与数值完整性检查

用户要求重出扭曲的弓精通图标，并检查技能代码和数值是否填充完整。本轮范围为当前 25 个可升级技能及 2 个装备能力；读取配置、定义加载、计算函数、战斗／修炼入口、面板、快捷栏和存档迁移，进行离线配置与源码注册检查。不启动游戏，不宣称逐技能实战或联机验收通过。

## 发现并修复

1. F6 技能目录漏了 **上挑、冰墙、陨星、焰甲**，导致无法通过现有技能调级入口选择。已补齐 25 项；冰墙另外补上 `DevelopmentSkillDefinition` 的专属分派，避免回退到步枪精通。
2. 六个后加技能重新带入了不被读取的 `maxLevel`，圣光另有无消费者的 `experienceBase`。已移除这些假调参入口。技能与存档继续使用既有统一 20 级上限，经验仍读取各自 `experiencePerLevel`；没有改变升级需求。
3. 冲刺攻击的旧 `speedMultiplier`／`bounceRatio` 已无运行时消费者，现行位移直接按厘米计算且不回弹。已连同废弃结构字段和读取项清理，现行动作和位移不变。
4. 剑精通配置残留敏捷 +1/级，但属性结算未应用、详情也明确不显示；通用升级提示却会报属性收益。已把该无效项明确置零，保留当前真正生效的固定伤害与攻速，避免提示虚报；没有给角色额外增加或扣除实际敏捷。
5. 陨星详情仍写“可以直接施放”，与法杖限定冲突；快速进战详情仍声称受普通攻速加速；巧手详情误称技能敏捷参与体力恢复。已按当前实际规则修正。
6. 角色敏捷来源说明遗漏弓精通，实际总敏捷已经包含它。补入来源说明，不改变结算。
7. 快速进战通用被动计算中的“占位技能”旧注释已修正：它已有主动伤害、资源和修炼实现，通用被动收益为零是职责分离，并非未开发。
