# 大旋风 V5：风车参考与打击感强化

用户要求参考[《消逝的光芒2》技能演示](https://www.bilibili.com/video/BV18b4y1774T/?t=180)的 3:00–3:04，强化现有大旋风动作与打击感。本轮已读取大旋风、连续蓄势、双手近战相关 SKILL 和 `whirlwind-migration-20260920.md` 开发记录。默认不做游戏测试或验收。

## 参考观察与适配

通过 B 站公开视频接口读取指定片段，本机保留 179.5–184.5 秒参考与每秒 6 帧的观察图。约 180 秒仍为技能菜单；181–182.8 秒可见举起武器、压至横持位、双臂靠近身体蓄力；约 183–183.7 秒快速横扫转向，刃线基本横向伸出，击中时敌人出现明显侧折与血效；183.8 秒附近双臂带着惯性收拢。关键借鉴是蓄势与快速横扫的反差、明确刃线、命中阻力和收势重量。

片段来自第三方成品游戏，仅用于动作观察；没有提取其动画、模型或音效用于游戏。参考视频、抽帧和临时播放地址留在本机，不作为项目可再分发素材。原片停帧毫秒数与音效分层未测量，本文数值均为本项目作者参数。

## 动作

以已获用户接受的 V4 为来源，保留 Manny 网格、手指握姿、双手握点、骨段长度与前臂辅助骨，由同一整臂求解器烘焙。保留 0.5 秒连续蓄势、前 0.1 秒实际姿态衔接，以及 0.8 秒反向两圈、0.52 秒收势。

- 横扫中增加两次连贯发力，第二次只作小幅回带再送出，没有插入第二段停顿蓄势。
- 第一圈出刃时握柄更向前、向左送；第二圈持续横持，略变高度和进深，避免整段像固定架旋转。
- 旋转结束后前约 94 毫秒让剑及双臂继续带出、压低制动，再在剩余收势内回到原待机。
- 全轨迹继续使用共享节点速度、节点加速度连续的五次 Hermite 曲线。普通柄和加长柄各有独立 V5 资产；加长柄沿用原 18 毫米握距适配。

源时长 1.82 秒、480 Hz 烘焙，资产仍按阶段归一化映射。完整转身由运行时驱动，没有重复烘焙进 FBX。

## 镜头、挥风和命中

`RuneSwordWhirlwindFeel.h` 集中表现参数。转动曲线改为短加速、持续横扫、明确减速：旋转阶段前 12% 加速、后 18% 制动，积分后仍严格映射到既有 -720 度；两圈连续通过。相机控制朝向、横扫判定与背景模糊读取同一曲线，伤害/半径/成本/冷却/修炼及每目标一次的规则保持原实现。

专属镜头表现包含蓄势小幅反向侧倾、出刃顺势侧倾、收势下沉和确认命中后的反方向短反冲，不向控制器朝向或命中几何叠加这些表现偏转。继续在 PostPhysics 完成最终相机与骨骼姿态发布；子步只推进转向与战斗，最终每渲染帧一次更新相机并采样骨骼。技能期间相机位置直接使用当前阶段目标，避免新偏转配上上一动作帧位置。

两圈分别在转动进度 3.5% 和 53.5% 播放挥风声，第一圈较厚、第二圈较轻且稍高；复用当前武器已有的合法声音资产。命中声音与反冲独立于停帧预算，预算耗尽后仍可产生反馈。相邻 65 毫秒动作时间内的命中合并表现，避免密集目标叠成持续噪声；不合并或删除实际伤害。群体命中或击杀只小幅增强反冲。

45 毫秒单次停帧与 135 毫秒整次预算保持原值。停帧同时冻结动作、转向、判定与命中反冲时钟；背景模糊归零，沿用 V2 前景遮罩、V3 时域材质及既有恢复逻辑。结束/取消清除本次冲击；不延续到普通挥击。全阶段移动/跳跃限制沿用当前源码。
