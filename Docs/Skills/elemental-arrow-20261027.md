# 元素箭：玩家交互与接入

## 操作

弓专属主动技能 `elementalArrow`，独立修炼至 20 级；三种附伤读取对应原魔法等级和释放时当前属性，再乘元素箭等级决定的调用倍率。沿用技能列表、详情、拖放快捷栏和档案补项。已有 1 级进度原样承接，无存档结构变更。

短按绑定键准备一支箭；长按 0.3 秒打开与选弹圆盘同手感的三分圆盘。移向元素、松键确认；中心或 Esc 取消选择。默认火焰，选择保持至下一次切换。未学习对应魔法时不可用。左键按住拉弓、松手发射；再次短按技能键取消附魔。与魔法箭雨准备互斥。

冷却期间长按仍能打开圆盘，放箭/回收动作中也允许打开选择界面。三元素分别读取 FireballCooldown / IceSpikeCooldown / LightningCooldown，射出只写入本元素对应的那一路，不存在元素箭公共 CD。每种元素与对应原魔法共用冷却，射出蓝耗为原魔法的 1.5 倍（向上取整）。轮盘显示三路剩余时间，冷却元素仍可选；确认冷却元素只记住选择，不消耗资源、不自动出箭，结束冷却后短按搭箭。切至已就绪元素在弓动作允许时搭箭。快捷栏随当前元素切换图标和 CD 蒙版，冷却不再将选元素入口整体置灰。

每次只准备一支，射出后回到普通箭。原弓的搭箭、瞄准、重力、散布、节拍与穿心箭保留；穿心箭只增强物理伤害、箭速、目标穿透，元素爆发每支箭首次接触时只触发一次。实体阻挡可提前引爆，不远端穿墙结算。

## 资源与效果

2026-10-27 V4 平衡：射出时消耗一支当前弹种箭、正常射击体力，以及 ceil(对应魔法当前蓝耗 ×1.5) MP，同时沿用对应魔法冷却。实际拉弓/保持满蓄时额外消耗 3 MP/s，并沿用普通弓持续耗体，不重复叠加另一笔体力费用。拉弓期间停止自然回蓝；搭箭待机和圆盘选择不扣维持蓝量。蓝量不足以支付射出费用时自动收弓，不自动射击、不扣箭、不进入冷却；已发生的维持消耗不返还。离弦后的快照不随再次选择或装备改变。

- 火焰：当前火球基础魔法伤害 ×1.50～2.75，当前火球爆炸半径 ×2。沿用真实直击要害、随机暴击、直击全伤及半径内 100%→50% 距离衰减。爆燃、余烟、热浪环和短促暖色闪光共用实际爆炸半径。
- 寒冰：同一半径内每个可见敌人一枚冰锥，沿真实直线路径飞行，途中扫掠障碍。每枚伤害为当前冰锥魔法伤害 ×1.25～2.50；首目标同样受伤。首目标及冰锥命中者获得 5 秒寒冷，每层减速 30%，延续既有寒冷叠层与免疫。一次箭爆对同一目标至多一次元素伤害。所有冰锥归同一个奖励事务。
- 闪电：同一半径内全部可见敌人各承受当前闪电伤害 ×1.25～2.50 和 1.5 秒眩晕，首目标也受影响。放射状独立闪电，不套用原连锁的跳数上限或跳跃衰减，不递归产生第二轮放射。

范围使用多点身体暴露和现有 MagicOcclusion 实体遮挡，友方、已死目标不作为攻击目标。穿心箭的后续物理贯穿保持独立。元素箭修炼、原魔法修炼、击杀与暴击奖励合并在原法术的同一次结算中。

## 20 级成长与修炼
