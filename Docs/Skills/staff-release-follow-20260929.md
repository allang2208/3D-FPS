# 火球与冰锥释放前跟随

用户反馈：下达发射指令后，投射物提前留在原地，要求继续跟随玩家一小段时间再发射。

原实现的 `CommitAimPreview` 固定预览弹道，`bPreviewLaunchLocked` 使悬浮更新提前返回。因此按键确认到前挥接触之间，玩家已经移动，投射物仍停在确认时的位置。

本次处理：

- 松手仍确认预览瞄准的世界目标，投射物保持相机悬浮跟随和原有避障，直到动画的释放接触点。
- 接触回调先刷新当帧悬浮位置，再确定实际弹道起点，避免回调先于投射物 Tick 而使用上一帧位置。
- 火球和每枚冰锥从新的起点重新朝已确认目标计算初速；冰锥同时重算剩余射程和目标终点标记。离手后继续使用原解析弹道、碰撞及伤害结算。
- 不另加独立延迟计时器：默认法杖为准备 0.20 秒加接触 0.18 秒，随施法速度缩放；排队、非持杖施法保留自身手势时钟。

涉及 `FPSFireballProjectile`、`FPSIceSpikeVolley`，新增的瞄准点仅为瞬态运行数据，不修改玩家存档或技能数值。技能参考的工程版和个人版同步更新。
