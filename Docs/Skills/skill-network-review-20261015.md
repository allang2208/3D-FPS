# 近期技能与面板联机复核（2026-10-15）

范围来自本对话：法杖／战锤状态面板与浮窗、战锤数值、重击持续耗体、力竭、法杖十格快捷魔法与专注、暴风雪持杖限制、陨星、龙息、已学技能后台准备、上挑击飞。其他会话新增的武器改造、场景、工作站不是本轮完整验收范围。

## 已定位并修正

1. **双手剑上挑的权威提交不完整**：此前客机只提交命中，耗体、冷却启动和修炼依赖档案补传，缺少一次攻击的服务端授权和单目标去重。现在由 PlayerState 的可靠 RPC 先提交；命中携带同一序号，校验角色、当前武器、有效时窗和唯一接触。耗体／冷却失败取消动作；服务端按释放／命中／击杀最高档结算一次。缺失结束包、换装、死亡、断线和换图均有收尾。
2. **上挑扣费与慢档案相互覆盖**：新增随体力快照保存的累计确认金额 `UppercutStaminaSpent`，沿用专注扣魔的累计回执办法。旧上传补扣差额，镜像与回执不重复扣费；覆盖体力时同步对应累计标记。旧存档默认零，原始文件校验不受新字段影响。客机发布的武技冷却不再重置服务端上挑冷却。
3. **陨星远端重播／素材绑定玩法**：新增复制的服务器起始时间，远端按实际剩余阶段恢复；素材异步到达后应用当前阶段，晚到不补旧爆炸、碎块及落地提示。伤害不再以视觉／音效素材加载成功为前提，专用服务器跳过视觉加载。仍从标定点上方 1320 cm 落下，途中不做掩体碰撞。
4. **陨星离场修炼归属**：开始时固定权威奖励模型，断线和换图先结算各陨星已确认命中再保存，不重新查询并回退到主机模型。完成标记先于奖励回调，重复收尾不重复奖励。保留死亡清场规则。
5. **陨星准备后换掉法杖的服务器释放缺口**：火系服务端释放再次按技能定义检查持杖要求，由现有拒绝通道取消预留并退回未释放法耗。

## 其余链路的源码结论

| 功能 | 本轮检查到的实现 |
| --- | --- |
| 战锤伤害／强化／体质 | 统一公式目录和共享伤害面板；普通攻击、上挑及重击由工具组件的服务端接触路径结算，通用客机命中上报不会再结算一份。 |
| 法杖／战锤 HUD、完整和缩略浮窗 | 使用玩家自己的模型与共享武器派生数值；没有把浮窗或 HUD 当作伤害权威。 |
| R 轮盘／专注 | 魔法分支只释放瞄准与旧预览，不调用会取消专注的 FireReleased；远端专注由会话和实际书／杖实例验证。 |
| 快捷魔法配置／选择 | 十槽、去重、空槽／中心清除；客机接收档案时优先保留本地快捷绑定及当前选择。施法继续走各技能已有服务端 RPC。 |
| 暴风雪 | 本地准备、权威预扣、权威落区均检查持杖；释放拒绝进入已有退款收尾。 |
| 龙息 | CastId 区分准备、释放、取消和停止；伤害先于表现就绪判断，远端权威无需 GPU 实例；固定客机奖励模型、退出先结算，旧停止不能取消新一轮。 |
| 重击／力竭 | 双手剑和战锤的远端蓄力均有服务器状态，影子模型按游戏秒持续扣体力；零体力取消动作。力竭独立五秒计时、状态复制、移动包及重放均禁冲刺，恢复体力不会解除计时限制。 |
| 后台准备 | 本地已学战技再魔法，场景放行且遮罩退场后启动；远端角色独立异步请求，不借用主机学习列表。单项等待有界，龙息组件继续自动准备；不重新加入进场门槛。 |

## 验证入口与范围

- `SkillNetworkAudit` commandlet：独立影子角色档案，调用生产权威入口；检查拒绝／重复／超时、耗体、力竭、龙息归属、陨星时钟与离场、快捷配置。
- `SkillWireAudit` 专用空地图 GameMode：只有显式 `-SkillWireAudit` 时运行；主机与客机使用真实套接字，生产上挑 RPC、力竭复制和陨星 Actor 复制。固定隔离测试档案，以避免污染玩家存档；完整登录档案交换不属于这个线级用例。
- 之前上挑击飞的 30 组／110 项后台物理检查记录保持独立，不冒充本轮真实网络结果。

## 覆盖边界

真实网络用例使用隔离档案和固定装备，并关闭测试 PlayerState 的自动档案上传／镜像 Tick；因此它证明生产 RPC 与上述状态、Actor 的跨进程传输，不代表完整登录档案交换、断线重连、多次换图或延迟／丢包环境已验收。累计回执与旧档案合并在原生隔离用例及源码审查中覆盖。

`-nullrhi -nosound` 不渲染、不试听：本轮没有重新验收火焰颜色、龙息 GPU 首次可见性、喘息音效、面板布局或怪物落地动画。龙息先前的实际画面证据仍见 `dragon-first-cast-regression-20261015.md`；本轮只检查其权威释放、旧停止包隔离和客机修炼归属，未修改 R6 火焰外观或把后台准备重新加入进场条件。

无界面运行日志包含编辑器 Toolset Python 初始化错误、隔离护士未加载网格／行为树的提示，以及 NullRHI 无法完成 GPU 准备的超时日志。它们没有使以上逻辑用例失败，但不能把这些日志称为“无错误”或据此宣称相关音画资产通过。
