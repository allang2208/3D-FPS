## 接入错误与本次修改

原角色源码将模型、动画、枪声路径误写为两层 `Integrated20260913/Integrated20260913`，实际目录只有一层。模型读取失败后会进入通用 AKM 网格回退；P9 迁移前的用户画面因此不能视为首版 M1911 作者文件的可靠展示。本次以 `M1911Source::AssetRoot` 统一新模型及动作入口，枪声指回已存在的原 M1911 音频。

手枪不再使用 M4 的动作居中位移。ADS 根据本枪的照门、准星和枪身向上轴构建完整朝向，眼距保留 38 cm，腰射偏移为 `(0, 6, -5)` cm。实际遮挡与手部外观未做游戏内确认，不能宣称视觉问题全部消除。

### 待机不可见修正

用户反馈朝向反转、待机无模型。读取用户既有运行日志可见，M1911 瞄准姿态的照门为 `(2.64, 48.31, -1.49)`、准星为 `(2.47, 66.81, -1.55)` cm，即导入后枪口朝组件 `+Y`。旧待机却共用步枪 `+90°` yaw，将整套模型转到相机 `-X` 后方。P9 源作者坐标为 Blender `-Y`，不能沿用旧步枪的组件旋转。

新增 `GetViewmodelBaseRotation()`，M1911 使用 `(0, -90, 0)`，其他枪沿用原配置；初始化、拔枪起点、逐帧腰射及未校准 ADS 的回退共用此入口。实际 ADS 仍由照门/准星校准。此次只修改组件朝向，保留动作、绑定、材质、时序与玩家存档，未启动游戏自测。

朝向修正的必要构建返回 `Result: Succeeded`，模块为 `UnrealEditor-FPSGAME-9131712.dll`，记录为 `SourceAssets/M1911P9Retarget20260913/compile-orientation-fix.log`。保存并重启编辑器后生效，画面由用户测试。

## 动作适配

直接读取旧 P9 的原始 Infima FBX，不使用旧裸手/拟合手模的姿态覆盖层。完整肩肘腕轨迹来自源动作；以 Manny 原有上下臂长度从接触手腕向肩部重建，保留源肘部运动方向。手掌与手指通过参考姿态及掌面坐标适配，Manny 新增掌骨保持局部参考姿态，前臂 twist 分配腕部轴向转动。

Manny 网格、UV、顶点权重及参考骨架保持原样。M1911 按握把体积对齐源握持空间，保留真实尺寸；弹匣、套筒、击锤使用配套枪械轨道，枪管与扳机保留独立机械表现。按 120 Hz 烘焙，网格在真正的绑定姿态单独导出。

| 动作 | 时长/处理 |
|---|---|
| idle / idle_empty | 3 秒静态持枪循环；空仓套筒后退 |
| aim / aim_empty | P9 原始瞄准姿态 |
| fire / aim_fire | 0.733 秒 |
| fire_last / aim_fire_last | 同源射击，末发套筒保持后退 |
| reload | 2.233 秒 |
| reload_empty | 2.733 秒 |
| equip_charge / equip_charge_empty | 0.933 秒，内容为原始 Unholster 拔枪，名称沿用现有角色接口 |
| inspect | 4.967 秒 |

机械事件按源轨道映射：退匣 `0.316667s`、插入 `1.05s`、压实 `1.066667s`、空仓套筒释放 `1.6s`。更新了武器目录换弹时长；音效与动画仍共用角色动作时钟，原有补弹、输入打断、弹药与保存业务保持现有入口。

**源 P9 的空仓末段是套筒释放，不是过顶抓握拉套筒。** 原轨道套筒在 0–1.55 秒保持后退，约 1.6 秒复位；旧 Godot 从 1.75 秒开始裁切的装备片段已错过机械动作。因此本次使用原始拔枪作装备动作，删除原有虚构拉栓音效；没有宣称完成独立过顶拉套筒动作。
