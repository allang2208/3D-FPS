## 计划落实

1. **房间用途与地面**：一般通道、货运、加工、档案、医疗、生活、生态、机电、泵房分别使用独立饰面参数。组合结构材质仅在原水平分支改变地面表面，保留墙面扫描、有限步数视差和顶棚分支。排水间单独使用泵房湿区配方，不因主题标签为 Medical 而变成医疗涂层。现有瓷砖和活动地板保持真实分缝，只细化粗糙度及微表面。
2. **墙面和顶棚**：沿用已制作的扫描混凝土、剥落、既有墙裙和管线。新增检修盖、通风滤网及其对应拆下部件，以局部接触污痕解释维护历史；不对每面墙均匀堆积破损，不重建已有倒角、螺栓和大设备。
3. **近景模型**：新增通风检修框、拆卸滤网托盘、折叠包装和连续打包带、档案设备维修托盘、灌溉歧管、空花盆与滴灌线圈、卷曲落叶共七种原创建模组合。复用上一批检修盒、阀组和维修托盘。模型承接真实安装面和支撑面，有限候选、固定排序，不消耗运行时布局随机数。
4. **专用材质**：现有皮革座椅接入已有皮革法线和粗糙度，保持原有底色；玻璃在现有透明度、Fresnel 和折射图上叠加低强度边缘污迹；灯罩只调整表面颜色和粗糙度，保持发光及故障分支。电视和显示屏不纳入玻璃处理。运行时门扇若没有材质覆盖入口，制作独立网格副本并保留原几何与碰撞。
5. **有来源的废弃状态**：新增布景按用途配对：检修框与拆卸滤网、货运包装与打包带、设备接口与拆下零件、灌溉组件与替换管线。已有接待区删除项不恢复。无法找到合适空位的连接段和设备密集区域保留现状。
6. **生态区**：从已有植物分布中选择两个局部衰败中心，用现有正常灯具的相对距离作为作者布景参考，形成局部衰败与疏空。该参考不是照度或光合作用模拟。计划 133 个实例使用衰败材质，45 个实例形成空位；新增少量落叶组合承接真实土壤高度，不增加总体植物实例数。保留其余植物模型、阴影、蒙版、风动和材质家族。
7. **局部灯具配光**：仅在非接待区已有灯光函数上加入轻微遮光曲线，保持原故障、相位和亮度时序；最大侧向调整为 7.5%，不新增灯光函数使用者。此为作者配光，不冒充实测 IES。没有现成合适 IES 时不安装新插件或强行更换全场灯光。

LightVector 在 Light Function 中使用灯具局部坐标，实施依据为 [Epic 向量材质表达式文档](https://dev.epicgames.com/documentation/en-us/unreal-engine/vector-material-expressions-in-unreal-engine)。复用已有函数入口，不增加额外使用者，考虑了 [Light Function 的渲染成本说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-light-functions-in-unreal-engine)。上述不是运行时配光或性能验收结论。
