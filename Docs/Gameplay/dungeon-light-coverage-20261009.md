# 其他地牢房间的灯光射程补查（2026-10-09）

前一轮扩大射程只处理了接待大厅；此前全目录检查针对灯具匹配、发光面和方向，并不代表其他房间的落地覆盖已经合格。本轮按用户要求补查其他房间。

## 范围和依据

- 37 个其他有灯模块：305 盏；固定起始区：13 盏。接待大厅沿用上一轮修改。
- 从正式关卡生成器读取当前目录，从 UE 已导入的 117 个结构网格读取向上的地板、踏步、夹层表面，按部件真实变换计算每盏灯下方最近承接面。
- `optimized_radius_cm` 才是优化开启时的实际射程；只改原始 `radius` 会被旧的 3 米补光限制覆盖。本轮同时写入两个字段。
- 地下层、阶梯、夹层分别按实际表面高度计算，没有把所有房间的地板假定为 Z=0。样本包括泵房夹层、焚化室地下层、三种升降坡道、蓄能控制室。
- 对普通照明，确认 26 盏灯的下方地面已超出射程。另有一批地面处于衰减末段、横向范围偏窄的灯。
- 工作台定向灯、神龛裸灯泡和植物展示柜树冠灯按对象照明保留；永久熄灭的灯仍保持零亮度。未发现本轮其他定向灯配方的发光法线向上。

## 调整

31 个模块的 154 盏灯及固定起始区 5 盏灯调整射程；其他灯保留原值。普通灯在射程/离地高度不足 1.5 时调整到 1.75 倍高度，高度至少 5 米的主灯在不足 1.65 倍时调整到 2 倍高度，向上取整到 50 厘米。此比值是本轮制作留出的衰减余量，不是 UE 强制标准或实测照度保证。

| 区域 | 部分射程变化 |
| --- | --- |
| 泵房主吊灯 | 10.5 → 15 米 |
| 泵房高位补光 | 6.5～7.2 → 11.5 米；夹层局部灯保持原值 |
| 交通站高位灯 | 10.05～10.35 → 12.5～14 米 |
| 中转大厅主吊灯 | 11.44 → 14.5 米 |
| 中转大厅夹层 / 夹层下方 | 4.84 → 6 米 / 4.4 → 6.5～7 米 |
| 隔离病房主灯 / 局部灯 | 6.7 → 10.5 米 / 3.3～6 → 5.5～7.5 米 |
| 宿舍、淋浴间、活动室进出口 | 3 → 5.5 米 |

亮度、颜色、朝向、光锥、故障灯材质、灯具位置、房间布局不变。扩大范围的灯启用真实投影遮挡，其中 97 盏原来没有阴影；不依靠穿过墙体或楼板照亮其他区域。现有房间/门洞调度和最大绘制距离、渐隐距离保留，没有新增运行时扫描或灯光 Actor。阴影成本会增加，未测量帧率。
