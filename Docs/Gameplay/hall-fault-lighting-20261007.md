# 大厅故障灯可见性调整（2026-10-07）

用户反馈：降低亮度后，看不到灯坏了的闪动效果。

## 排查结果

- 检查了接待大厅和衔接大厅的三个已保存样板：`L_ReceptionHall_Subject`、`L_FacilityTransit_Subject`、`L_FacilityTransit_Alternate_Subject`。它们分别绑定了 4、8、8 盏故障灯（后两个地图均包含接待大厅）。灯光函数与灯管材质引用完整。
- 从 UE 静态网格读取顶点：两个大厅所有指定故障灯的局部位置遮罩都覆盖到灯管顶点，没有发现故障区域落在模型外。
- 现有编辑器读取到 `r.LightFunctionQuality=1`、`r.LightFunctionAtlas=1`、`r.Deferred.UsesLightFunctionAtlas=1`，并未关闭灯光函数。
- 原故障循环为 21.7 秒，较长的稳定亮灯时间容易使短时间观察错过故障；灯管自发光仅 0.65–0.8，明暗差也偏弱。以上是配置上的可见性问题，未宣称已经复现了用户视角下完全不闪的现象。
- 原有三个故障主材质在后台实际 D3D12 / SM6 编译完成，没有发现最终已保存材质的编译失败。

## 本次修改

- 每盏故障灯使用独立相位与 6.4–8.6 秒周期，短暂接触不良后熄灭 0.98–1.43 秒，再用 0.55 秒恢复亮度。
- 灯管和照明共用同一段故障函数，保持同步。故障灯管自发光提高至 1.8 / 2.2，以拉开亮灭差异；正常灯、原有常灭灯、灯光流明和大厅曝光不变。
