# ASH-12 撞门护拳整臂修正

用户报告 ASH-12 撞门时整条左臂位置或朝向错误。原通用转换在固定护拳肩根的同时，把 M4 作者动作相对参考绑定的旋转变化叠加到 ASH-12 原持枪绑定上，造成肘、腕沿原持枪偏转执行 FK。此前只读排查从当前原生骨架计算出护拳关键帧肘位约 46.34 cm、腕位约 41.97 cm 的目标偏差。

当前 ASH-12 与作者 M4 使用相同 Manny 骨段局部关节点、长度及骨轴约定；参考旋转差来自不同持枪姿态。27 根动作骨的父子关系一致，除锁骨根位置外，局部骨段位移最大差约 0.000323 cm，局部 scale 最大差小于 9.54e-7。V7 派生脚本通过原生参考绑定与 M4 参考绑定之间的蒙皮映射生成 ASH-12 表面，保留原生骨架和权重。

修正在 `FDoorPushPoseLayer::Capture` 中为实际 ASH-12 Surface 主视模及它的 BarePalmV7 派生选择完整作者目标朝向，按目标原生关节点、scale 和层级重新得到父子局部姿态。肩、上臂、前臂、腕、四个扭转辅助骨、掌骨及五指一起消费既有护拳目标链。原生绑定、骨长、权重、手模几何和材质不变。

运行资产采用 `ASH12WeaponAssets::MeshPath` 的正式路径识别；不按“无托步枪”类型泛化，也不影响其他枪械的动作转换。现有手套、袖口继续从同一原生 leader 接收姿态。

继续复用当前可编辑母动作 `SourceAssets/DoorPush20261002/DoorPush_LeftFist_V7_20261002.blend` 和版本 2026100211 的运行表，不新增一套 ASH-12 动画资源。保留 0.06 秒入场、0.30 秒护拳停留、整臂轻摆、0.197 秒恢复、成功撞门音效和屏幕抖动。入场仍捕获当前 ASH-12 姿态，恢复仍混合到当前实际持枪姿态。
