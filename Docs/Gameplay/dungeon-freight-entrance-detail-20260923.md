# 装配间货运门与按钮盒细化

修改目标是 `FreightTransfer` 房间既有 `SM_RS_FreightTransfer_Lift`，保持房间坐标、门洞尺寸和现有布景用途。

## 模型

- 门框改为有真实凹槽的 C 形导轨，增加滑动摩擦条、底座、锚栓及顶部检修盖。
- 21 片门帘重新制作压型截面、卷边与阴缝；下端加入橡胶密封和低门槛。
- 前层护栅增加分层剪叉连杆、分离的交叉面、铰接销和上下滚轮轨道。
- 中央门锁包含锁边、锁座、钥匙孔护圈、弯管拉手及紧固件。
- 右侧按钮盒包含背板、箱体、密封垫、浅色面板、防滴罩、面板螺钉和标识。
- 琥珀色指示灯及上下箭头按钮分别有金属护圈、嵌入灯罩或橡胶按钮帽。
- 接线通过实际电缆密封接头和沿墙弯曲的金属管进入门顶，补齐管夹。

按钮与门仍属于环境网格；本次没有新增开门或电梯交互逻辑。

## 材质

使用本任务独立的九种表面：旧漆面、导轨钢、护栅钢、按钮盒搪瓷面板、橡胶、琥珀灯罩、标识、铭牌底及局部警示漆。配套原创程序化细节纹理和 DirectX 法线，区分漆面微粒、金属方向纹理、擦痕、粗糙度与小片腐蚀。

网格顶点色分别控制藏污、磨亮和锈蚀，腐蚀集中在近地及下沿；按钮面板保持足够清晰。指示灯使用克制的琥珀色自发光，标识不自发光。
