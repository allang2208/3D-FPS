## 1. 结论

| 问题 | 结论 |
| --- | --- |
| 能做异形房间吗 | **能，且推荐做**。做法是"格子集合 + 自动砌墙"，**不是**"一间间预制异形房" |
| 代码复杂吗 | **不复杂**。核心约 700–800 行 C++（含离线校验），1–2 周；算法等价于 2D 游戏的自动瓦片（autotile），是成熟模式 |
| 真正的成本在哪 | 不在算法，在两处：**构件公约**（pivot/尺寸/朝向）与**件的覆盖度**（内角/外角/T/十字必须齐）。这两条锁死，异形房就是免费的 |
| 对标《全境封锁》 | 它的做法（手工模块 + 程序装配）与你们已定的路线一致；真正值得抄的是它的**目标房、环境危险、指令**三件套，不是它的房间造型 |

## 2. 异形房间怎么实现

### 2.1 数据表示：房间 = 格子集合

房间轮廓从"矩形 (x, y, w, h)"改为**400 cm 网格上的格子集合**（多边形拼块）。L 形 = 两个矩形格子集合的并集；十字形、凹形同理。生成器只在"轮廓"这一层变化，连通性/最短路径/门位/楼层逻辑全部不变。

### 2.2 自动砌墙（核心算法）

对房间的每个格子、四条边逐条判断：**邻格属于同一房间 → 无墙；否则 → 该边是墙边**。然后按角点入射的墙边数选件：

| 角点入射墙边数 | 放置件 |
| --- | --- |
| 1 | 墙端头（或用直墙收边） |
| 2 共线 | 直墙穿过（两块 400 直墙相接） |
| 2 垂直 | **转角件**——按房间在转角哪一侧分两种：房间在"内侧"用**外凸角件**（A5），房间在"凹口"用**内凹角件**（A4） |
| 3 | T 字件（A6） |
| 4 | 十字件（A6） |

- **A4（内凹角）是异形房的关键件**：L 形房间的凹角、凹字形房间的内侧转角都靠它。没有它，异形房会在内角出现缺口。它必须在 P0 而不是 P1。
- 门 = 边界上的特殊件（A7 门洞墙，居中 200 洞口）；拱门 / 栅栏 = 可透视件（A8），承担"门外偷看"。
- 对角相触（两格只在角上相邻）不算连通，装配时按四个墙边相遇处理，可顺手放一根柱子。

### 2.3 不需要预制异形房

英雄房（Boss 房、事件房）**也用同一套件自动砌**，差别靠"装饰清单 + 特殊道具"（祭坛、发电机、物资箱、王座）表达，而不是靠手搭一间房。预制房只在确有需要时做（例如神殿式中庭），不进 v1。

### 2.4 楼梯与多层

楼梯格 = 一种连接件（和走廊同一层级），装配时在上层楼板生成开口 + 护栏。多层仍按方案 §2.3 的严格堆叠规则，异形轮廓不影响堆叠。

### 2.5 性能

无额外负担：墙件数量只随**房间周长**增长（异形房周长比矩形约多 10–20%），全部进 HISM。异形房的遮挡剔除反而更好（角落更多）。

## 4. 代码复杂度评估

| 模块 | 估量 | 说明 |
| --- | --- | --- |
| 房间形状（格子集合） | ~200 行 | 生成器"轮廓"层改造；连通性/最短路径逻辑不变 |
| 自动砌墙 + 件判定 | ~250 行 | 逐边判断 + 角点查表；纯函数、可离线测 |
| 门/连接件放置 | ~150 行 | 边界边 + 朝向；v1 无需"模板门槽"（见下） |
| 离线校验扩展 | ~150 行 | 随机多边形：边界闭合、无缺口、门可通行 |
| **合计** | **~700–800 行** | 1–2 周（含自测），风险低 |

**为什么不做"预制异形房 + 门槽"路线**：那需要为每种形状手搭一间房、为每个门槽定义接口，美术与协调成本远高于自动砌墙，且改一次公约全部返工。自动砌墙 **更便宜也更灵活**——同一套件能长出任意的 L/T/凹/凸组合。预制房留到确有特殊造型需求时再补。

## 5. 《全境封锁》Underground 核实到的事实

以下来自官方 Wiki（`thedivision.fandom.com/wiki/Underground`）原文口径：

- 定位：第一年付费扩展（2016-06-28，Patch 1.3），PvE 向；**"randomly generated mazes of subways, tunnels and sewers"**、**"randomized, procedurally-generated dungeons"**。
- 每次出勤**布局与目标都不同**："Each time an Operation is selected, the layout and objective of the Underground changes"。
- **Phases（阶段）**：一次出勤可选 1~N 个阶段（普通只能单阶段，英雄必须多阶段），阶段越多奖励越高。
- **Directives（指令）**：最多 5 条，是"buff + 代价"的玩法修正（有 Drawback），需消耗 Directive Intel；直接抬高奖励。
- **目标类型 6 种**：Surgical Strike（击杀高价值目标 + 2 副官）、Critical Infrastructure（守住 3 台发电机，最后一台守到 JTF 到达）、Missing Patrol（搜救巡逻队，第三队要保军官）、Recovering the Report（找回情报官，开路拿钥匙、最后 3 波强攻）、Supply Depot（限时摧毁 3 个物资箱，4/3/2 分钟）、Target of Opportunity。
- **环境危险**：松脱电线（接触触电）、燃气管道喷火、**Alarm Zones**、**Steam Filled Rooms**、诡雷等。
- 最终波必有 **Named Enemy Boss**。
- 入口是 TOC（战术行动中心）+ Operations Panel 配置界面。

> **关于"手工模块 + 程序装配"**：社区与业界对它的通行理解是"手工制作的房间/段落模块，由规则拼接"；本次检索通道对该游戏名持续解析失败，未拉到开发者原始访谈，**此点标注为待核实**。但无论其细节如何，"手工模块 + 程序装配"是这类 3A 随机地下关的通行做法，也正是你们方案已在走的路线。

## 6. 值得抄的 / 不抄的

### 抄（按性价比排序）

1. **走廊是"地方"，不是填充物**（最重要）。它的地下感来自走廊本身有身份：地铁站台、隧道、下水道。**修正现有方案：主通道从 3–4 m 提到 6–8 m**（站台/主隧道），支线维持 3–4 m。宽走廊同时改善 FPS 战斗与观感。
2. **目标房而非只有清房**（见 §8 映射）。这是让每局"有差别"的关键，比房间造型更能改变体验。
3. **环境危险**：电线、燃气火、蒸汽房、警报区。用现有 Niagara + 伤害体积即可，成本低、氛围收益高。
4. **指令（Directives）**：opt-in 的"难度修正 + 代价 + 奖励提高"。你们已有祭品系统（`OfferTribute`），指令可作为**独立一类**加在出征面板（对奖励系数生效），几乎零新系统。
5. **多阶段（Phases）**：层 = 阶段的天然映射（每层一个主题/目标），Boss 在末层；"阶段越多奖励越高"直接对上你们的档位。
6. **可透视的预见性**：栅栏、半开卷帘、玻璃能看到房内敌人——继续保留并强化拱门/栅栏件。
7. **枢纽即房间**：T 字/十字路口做成有掩体的小房间，而不是纯通道。

### 不抄

1. **掩体射击的节奏**——它是 TPS 掩体战斗，你们是 FPS + 丧尸近战/技能，房间比例与掩体密度要按你们的手感重定，不照搬。
2. **它的垂直度**——它基本是"同一层网络 + 局部夹层/竖井"，不是多层堆叠迷宫。你们方案的 3–4 层是差异化，保留；但**建议 v1 以两层为主 + 局部三层**，楼梯间做成地标（见 §7）。

## 8. 目标房映射（Division 6 目标 → 你们的房间类型）

| Division 目标 | 你们的实现 | 需要的新东西 |
| --- | --- | --- |
| Surgical Strike | 精英房（已有概念） | 无 |
| Critical Infrastructure | 守点房：祭坛/发电机守满 N 秒，波次递增 | 守卫计时器 + 目标道具 |
| Missing Patrol | 救援事件房：护送/保护 NPC 到门口 | 简易友方 AI 或"保护道具"（v1 可用宝箱代替 NPC） |
| Recovering the Report | 宝箱房：击杀掉钥匙 → 开门取宝 | 钥匙掉落 + 门锁（门系统已有） |
| Supply Depot | 限时摧毁房：N 个物资箱，限时 | 计时器 + 可摧毁道具 |
| Target of Opportunity | 随机精英遭遇（走廊触发） | 走廊刷怪触发体 |

**建议 v1 只做其中 2 个**（守点房 + 宝箱房），其余留 P5 内容期；两个都已有的系统（门/宝箱/波次）就能支撑。

## 9. 风险与待拍板

| 项 | 说明 |
| --- | --- |
| 构件公约 | 内角/外角件的 pivot 与朝向必须在制作前定死；改公约 = 全部返工 |
| 件覆盖度 | 每个件都要有正确的碰撞（A4/A5 的 L 形碰撞不能漏） |
| 走廊加宽 | 加宽主通道会增加外壳实例数与可视距离，需在 P1 样板里看帧时间 |
| 垂直度 | 两层为主是对的；四层堆叠在 Lumen + 多光源下压力大，先验证再加深 |
| 瞄准辅助 | 宽走廊 + 掩体柱子会改变怪物寻路与玩家掩体习惯，P1 需实机手感验收 |
