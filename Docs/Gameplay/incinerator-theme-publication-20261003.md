# 焚化炉主题采用与发布 · 2026-10-03

用户认可焚化炉三间房及共用探险宝箱优化，授权正式接入、废案归档、SKILL 沉淀和普通推送。

## 正式内容

正式地图为 `/Game/GameMaps/L_Dungeon_Randomized`，固定核心为破损支护室（ShoredBreach）→ 焚化处理厅（AbandonedIncineratorHall）→ 烟气净化站（AbandonedFlueGasStation）。完整楼层、端口、占位 cells、碰撞、灯光和现有遭遇数据保留；不拆散核心，也不改变其他主题的顺序。

五类新容器为检修工具箱、防护用品柜、耐热器材柜、停尸间档案柜、滤芯运输箱，使用独立可动门、盖和抽屉。三房合计随机选择 17–20 件实体、22–25 个独立搜寻入口；候选位按实际几何贴墙布置，避让通道、门扇及开启行程。场景搜寻储物页沿用既有实现，奖励填充沿用后续奖励表阶段。

烟气净化站二层平台下添加一个共用探险宝箱。共用箱本轮提升实体框边、卷叶、分节铰链、锁孔、内底板、四壁内衬及盖内筋；原创两套金属 PBR，木内衬引用本地许可素材。新版几何写回原正式网格对象，保留骨架、动画、碰撞尺寸和关卡引用。制作源约 19.3 万三角面，未做性能测试。
