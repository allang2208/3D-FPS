# 其他武器撞门左臂绑定排查

本轮按用户要求只读排查其他武器是否存在 ASH-12 同类整臂位置、朝向错误。读取了 26 份当前原生资产绑定，含活动枪械、双持左侧、剑臂、斧镐、弓和共同作者骨架，另含两份非改造剑回退资产。没有修改运行时代码、动画、UE 资产或配置，没有实机运行、截图或渲染。

## 结论

其他现用枪械、剑和斧镐的护拳保持阶段没有发现 ASH-12 那类明显偏转。弓的护拳保持同样使用共同作者左臂，但它的跨骨架入场与恢复存在另一个旋转补偿问题，应单独修正交接。

| 实际使用状态 | 当前转换 | 本轮结论 |
| --- | --- | --- |
| M4、HK416、AKM、QBZ191、201、A762、SVD、PKM | 原生视模上的通用参考旋转差量 | 相关参考骨架与作者骨架一致，没有同类整臂目标偏差 |
| M1911、DW715、G18、PitViper 单持 | 同上 | 没有同类整臂目标偏差 |
| 上述四类手枪的双持左手、法杖副手 | 独立左侧原生视模上的通用差量 | 没有同类整臂目标偏差；右侧不是撞门姿态源 |
| 符文剑、冰晶剑、苏格兰巨剑、唐刀 | 原生 sword arms 上的通用差量 | 没有同类整臂目标偏差；后三者共用 FrostSword arms |
| 双手斧、双手镐 | 各自原生工具手臂上的通用差量 | 没有同类整臂目标偏差 |
| M16、ASH-12 | 已有完整作者目标链分支 | 当前护拳目标链没有此前的整臂偏转 |
| 空手、法杖空左手、无原生手臂的静态工具 | canonical M4 作者链 | 不经过其他枪械参考绑定差量 |
| 弓 | 护拳用 canonical M4；入场、恢复采样原弓 | 保持阶段正常；跨骨架交接存在额外旋转补偿问题 |

M4/HK416 正常主枪仍使用通用差量，不能仅因名称有 M4 就视为作者骨架分支。实际读取表明它们的相关参考绑定兼容，因此本次没有将它们判为异常，也没有更改其逻辑。

## 护拳数值依据

对当前 `FDoorPushPoseLayer::Capture` 的旋转转换、原生位移和 FK 公式，在 0.06、0.135、0.21、0.285、0.36 秒五个护拳关键帧重现骨架目标结果。22 份通用转换资产（包括两份非改造剑回退）最大的腕部目标偏差约 0.00001981 cm，最大的肘部目标偏差约 0.00001946 cm，最大的手骨朝向差约 0.00007603°，均属于导入/浮点精度级别。

这说明“使用通用差量”本身不等于有问题。ASH-12 的原生参考持枪旋转与母版不同，因此此前产生约 42 cm 的腕点偏差；其他上述资产没有这种参考姿态差异。当前 M16/ASH-12 已使用完整作者目标朝向，原生骨长及绑定仍保留。

这些数值描述原生骨架与当前源码公式，不代表手指接触、衣袖蒙皮、动画中间帧或实机画面已验收。

## 弓入场与恢复的额外问题

当前弓手臂为 `/Game/Weapons/DarkBow20260925/ContactV9/SK_Bow_BareArmsV7`。它与作者骨架的肩、肘、腕参考组件旋转都相差约 90°；差异来自整个骨架根坐标系绕 Z 轴旋转。相关子骨局部旋转最大差仅约 0.00005107°，组件姿态扣除共同根坐标旋转后最大剩余差约 0.00003676°，所以不是每根腕臂骨具有另一套局部骨轴。

`DoorPushPoseLayer.cpp:144` 的入场 `EntryCamera` 和 `:199` 的恢复 `ExternalSource` 分支先把原弓骨姿态转换到相机或目标 Mesh 空间，随后又用 `SourceRest.inverse × TargetReference` 追加每骨参考旋转修正，并在 `:164`、`:205` 使用目标原生局部位移重建 FK。这会把整套骨架坐标差当成各骨的轴差，改变原弓实际姿态中父骨到子骨的方向。

从当前绑定数据计算，追加这层修正后的骨段向量，与实际源骨段向量在原生绑定单位中的差值分别为：锁骨至肩约 24.89 cm（88.67°），上臂至肘约 22.64 cm（48.11°），前臂至腕约 30.75 cm（68.70°）。误差范数与相机和 BowPivot 的刚性旋转无关，现有撞门收弓旋转已经包含在 Source 的组件变换中，不能抵消这层错误补偿。这是单骨段方向误差的量化，不是某一实机帧的整体腕点偏差；实际整体位置取决于当时的原弓姿态。

影响范围是 0–0.06 秒入场及 0.36–0.557 秒恢复。0.06–0.36 秒护拳阶段使用 canonical M4 作者链，不受这层原弓绑定差量影响。修正方向是按相机/目标 Mesh 空间中的原弓真实整臂姿态交接，避免再次把统一根坐标差作为每骨旋转补偿。无需改变护拳手型、0.3 秒停留、撞门音效或屏幕抖动。
