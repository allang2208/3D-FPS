# 废弃设施：大厅主题区域统一封门（2026-10-12）

用户要求以一个主题区域作为完整战斗单位；迎宾大厅和分流大厅全部怪物清理完成前，后续三个通路由落下的铁栅门阻挡。

## 当前规则

- `FacilityReceptionHall` 和 `FacilityTransit` 是同一个大厅主题区域，内部连接口保持畅通。
- 地牢装配完成时准备两厅编成和三座打开的伸缩铁栅门。玩家进入任一大厅后统一启动：三处出口立即启用完整门洞的 Pawn 阻挡，铁栅门在 1.4 秒内平滑落下，两厅开始各自的刷怪流程。
- 三个封锁点来自分流大厅在本次布局清单中的真实出口位置、朝向、宽度和高度。与迎宾大厅相接的第四个口属于区域内部，不安装战斗门；不封玩家来路入口。
- 每厅两波、每波 12～15 只普通接待员／安保员／研究员不变；各厅首波实际击杀严格超过一半时，分别从本厅检修门补第二波。
- 两厅共享区域身份及封门完成条件，进厅不再给所有怪物直接分配玩家目标。怪物通过主动发现、受击延迟确认或 12 米内同区域同伴的预警参战；确认后的追击在两厅内部不受普通 24 米出生点牵引限制。攻击、受控、死亡继续由现有行为树和战斗组件处理，详见 `Docs/Monsters/MonsterAwareness20261012.md`。
- 只有两厅都登记清除，才统一抬起三个出口铁栅门。每厅清除仍以两波所有槽位实际死亡为条件，包括尚未生成的第二波及生成失败待补名额；第一波死完、只清一厅、离开房间体积或玩家死亡都不提前放行。
- 开门期间保留整洞阻挡，三个门板全部升到净空以上后同步解除。尸体销毁不参与放行判定。新一局重新生成区域和门；旧局解绑或生成器销毁时清理本组门、计时器和遭遇对象。

## 实现范围

新增 `ADungeonThemeEncounter` 接收成员房间节点与区域出口，只负责区域进入、共同完成条件及门体生命周期；房间自己的 `AFacilityHallEncounter` 继续负责波次、待生成名额和击杀。当前实际绑定的是已有新刷怪规则的大厅区域；旧普通房、精英和 Boss 自动刷怪仍为退役状态，不因此恢复。

复用现有 `ADungeonRoomGate` 和 `EliteGate20260926` 的四轨伸缩铁栅资产及真实阻挡；门体依赖加入生成器既有异步准备阶段，没有另造模型、运行时同步导入或新增地图保存步骤。区域状态由 0.1 秒定时器处理，逐帧更新只在门运动的 1.4 秒期间开启，清除后停止定时器。

本批首波改为区域进入后启动，避免玩家进入前游荡怪先走出尚未关闭的出口。检修出怪门与三处推进铁栅门各自负责原有职责；检修门关闭不代表区域完成。
