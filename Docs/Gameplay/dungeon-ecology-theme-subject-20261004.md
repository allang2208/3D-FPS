- `Scripts/prepare.py`：当前制作入口，保留标识图集并调用 `prepare_v7.py` 生成修订布局。
- `Scripts/prepare_v7.py`：读取保留的 V6 配置，把桌面组合件和柜体成组移到靠墙位置，保留现有植物布局。

- `Scripts/install_background.ps1`：持有现有 UE 批次互斥后执行无界面导入，当前默认执行 V7 局部接入。
- `Scripts/install_v7_patch.py`：复用生产导入配方，仅替换三项修订网格和移动指定办公室 Actor，保留其他场景内容。
- `Scripts/install.py`：材质/网格构建、保存、植物和容器装配、四张地图保存。
- `Scripts/install_existing_editor.py`：编辑器已打开时使用现有桥；保护未保存内容，结束安装后恢复原地图。
- `Scripts/diagnose_window_native_v6.ps1` 与 `Source/FPSGAME/Development/EcologyWindowDiagnosisCommandlet.*`：仅用户要求的窗口翻越定向查询，不播放或保存地图。

- `Scripts/record_delivery_v7.py`：汇总本轮三张地图的局部保存、家具布局和未测试状态。
