# 工作间工具、灯具与使用痕迹细化 / 2026-09-21

## 本轮计划

依据现有房间几何、材质、灯光摆放和用户上一张实景图开展制作。目标是让工具能辨认用途、固定方式与工作状态，让灯具有真实结构并围绕工作面照明。已有工具柜、白板、货架和拆修电机继续保留。

1. **台面工具**：重做台钳的铸造主体、活动钳口、夹持齿、丝杆、转盘与固定螺栓；增加棘轮、套筒轨、开口扳手、螺丝刀、卡尺和分区零件盘。耗材增加瓶肩、盖子、油嘴和标签，物件围绕拆修任务分组，留出操作面。
2. **墙上挂具**：把简化杆件改为有开口钳口/梅花孔的扳手、带转轴的钳子、不同刀头的螺丝刀与锤子；补挂钩、支架和编号，保留空挂位。孔板继续遵循工业制造的规整结构。
3. **屋顶灯具**：只替换组合灯具网格中的工作间部分；其余房间保持原样。制作密封灯体、扩散罩、密封条、卡扣、端盖、安装吊杆和接线盒。采用与灯面尺寸匹配的向下区域光，另补工作台上方照明。
4. **额外表现提升**：细化台灯关节、灯罩和电线；重做木台面长向纹理及端面、带褶皱和厚度的擦拭布；在台钳、维修区、墙边形成有位置依据的磨损、油印和积尘。同步移除旧工具柜位置不再适用的磨损片。
5. **保存与接续**：新资产使用独立目录，指定 Actor 替换并保存；旧引用留档。把这一轮加入现有 V2 重建入口，保留完整可编辑源。

不修改遗迹、走廊、战斗、交互或运行时随机生成器。按用户规则，本轮不额外启动游戏、截图、性能/碰撞测试或验收渲染；制作结果由用户查看。
