# 搜索容器四类分组标准

2026-10-12。搜索容器采用用户确定的四个大类：日常用品、文件材料、检修设备、机房设备。前三类分别提供生存补给与售卖杂物、换取灵魂的文件物品、装备制作材料；第四类提供高价值信息设备。

2026-10-13 已按下述31个稳定容器ID接入运行时搜索池和共享库存；具体概率、存档与联机边界见 [两厅与服务器柜搜索池](facility-search-loot-20261013.md)。售卖与新增制作配方不属于此次投放开发。对应逐容器清单见 [分组数据](search-container-groups-20261012.json)。它取代先前 `Saved/HallContainerReview20261012/search-pool-proposal.json` 中的七类分组提案。

设计清单为 [四类搜索物品清单与制作配方 V2](search-item-catalog-v2-20261012.md)：22件物品与15条具体制作配方。实际搜索池使用21件已有物品，暂不包含未制作的纪念腕表。用户确定设计按实用性与稀有度两条轴展开；每件物品必须能解决明确需求，或者具备足够的出售价值。V2取消低收益填充物，并将细碎制作耗材合并为少量核心资源。物品稀有度与占格以运行时 `items.json` 和后续用户调整为准；配方仍按各制作台的实际接入状态区分。

| 大类 | 稳定标识 | 包含内容 | 主要用途 |
| --- | --- | --- | --- |
| 日常用品 | `daily_supplies` | 水、食物、日常杂物 | 水和食物满足生存需求；日常杂物出售换取灵魂 |
| 文件材料 | `documents` | 卡片、U盘、设备资料盘、行政资料等 | 出售换取灵魂 |
| 检修设备 | `maintenance` | 零件、半成品、加工耗材 | 在铁匠台、枪械组装台、木工台制作装备时消耗 |
| 机房设备 | `server_equipment` | 显卡、机械硬盘、内存条等高价值信息设备 | 高价值搜刮物，V2统一用于出售换取灵魂 |

机房设备不作为普通装备制作的必需材料。实用性、稀有度和占格收益共同决定物品定位，不为补齐颜色档位而增加无用物品。

日常用品复用现有矿泉水、罐装汽水、普通面包和法棍面包，并保留有明确出售价值的纪念腕表；文件材料保留U盘、档案磁带、加密资料盒和签章档案；检修设备采用合金坯、装配组件盒、树脂胶、层压木条和精密机件；机房设备沿用高价值硬件方向。香皂、牙膏、普通杯具、低价纸质资料等不再作为V2拾取条目，仍可作为场景装饰。

容器只绑定一个大类。具体物品可以再带水、食品、生活杂物、行政文件、电子资料、五金、木工耗材等筛选标签，用于同组不同场景的投放差异；这些标签不增加大类。

文件材料与机房设备按物品身份区分：U盘和承载记录的资料盘归文件材料；作为硬件设备存在的机械硬盘、内存条、显卡归机房设备。硬盘内可能存有数据，不因此自动改归文件材料。检修设备中的零件和耗材则以真实制作配方用途为依据。

上述归属覆盖两厅29个入口和当前源配置中的2个服务器入口。两厅容器已经在上一轮读取正式地图配方及三个样板核对；服务器本轮依据当前生成源配置和制作记录定位，没有新增实机或地图读取。两张衔接样板均包含接待大厅副本，不重复计入投放点。柜体外壳、装饰文件矮柜、垃圾桶、桌面电脑和纸张不自动变成搜索容器。

防护用品柜保留日常用品分组，V2取消无实用功能的口罩与眼镜杂物，改按水和食物等员工应急补给筛选。文件类物品统一承担换取灵魂的用途，不附加通行权限、主路解锁、研究或情报兑换系统。

检修设备的物品卡必须列明使用它的制作台、配方及消耗数量。当前已存在铁匠配方 `Content/ColdSteelData/forging-recipes.json`、枪械组装配方 `Content/ColdSteelData/gun-assembly.json` 和木工配方 `Content/ColdSteelData/woodworking-recipes.json`，后续在这些实际入口扩展，不另建一套并行制作系统。当前配方仍使用各自已有材料；记录候选零件不代表它们已经参与扣料和产物结算。

分组与稀有度独立。非装备物品继续沿用现有普通、优秀、稀有、史诗、神话、传说六档；V2的白绿物品只保留生存补给与明确制作材料，纯售卖物不使用廉价品填充。武器、装备和可装备工具继续遵守工程既有的无物品稀有度规则。

物品卡按“拿取理由 → 使用或售卖出口 → 稀有度与灵魂价值 → 占格和堆叠 → 图标与模型 → 容器池和数量权重 → 实际功能接入”制定。V2已有设计价格及配方用量；后续投放按区域总收益控制数量和稀有概率，不以填满柜子为目标。目录品种比例不等于掉落概率。
