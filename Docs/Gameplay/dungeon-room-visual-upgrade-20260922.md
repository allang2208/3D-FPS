# 地牢差异房间：墙面与结构细节升级

用户认可现有三种房间布局，本轮仅提升其背景与近景结构表现。目标地图 `/Game/GameMaps/L_Dungeon_AuthoredExpansion`，现有 `DGN_RS_` 实例继续引用原路径下更新的网格；不调整房间摆放、楼面标高、灯光、锚点与原样板。

## 墙面继承

房间旧做法只有规则整砖与随机缺块。新生成器 `SourceAssets/DungeonRoomShells20260922/Scripts/corridor_surfaces.py` 读取通道最终 `DungeonTileFracture_Source.blend` 的南／北墙段，并保留逐面原始 UV、材质槽、法线平滑标记和毫米级厚度。重复拼接按稳定墙段 ID 选择，边界及门洞只裁切不拉伸。

继承的是实际最终结果：边缘粘附的厚陶瓷残片、釉面薄唇、陶瓷芯、粘结层、2.5 cm 网格的砂浆起伏及原有近景高度材质。未调用简化缺砖算法，也不生成另外一套剥落三角片。该母版及它的所有材质／贴图是必须保留的制作依赖。

## 构件细化

- 排水格栅：每端三个可拆格栅单元，外围框、密排承重扁钢、下横条、沟边承托和固定件；格条顶面近乎贴合楼面，替代悬空的稀疏黑条。
- 管道：32 边圆截面和平滑法线，连续圆弧弯头、内壁及开放端口、切口唇边、双法兰、垫片、八组穿栓和螺母。圆柱 UV 随管轴走向连续，顶点色控制局部氧化，吊杆依照实际顶棚和梁底终止。
- 破洞：断口轮廓具有不同尺度的缺口，四个深度层形成有凹凸的断面，裸露面采用已有矿物砂浆材质并加入嵌入骨料；替代原来的大块锯齿形平截面。
- 钢筋与碎石：钢筋有不同长度、埋入深度、直径、弯曲程度及真实肋纹，底部碎石改为不等切面凸块，保持主通行区。
