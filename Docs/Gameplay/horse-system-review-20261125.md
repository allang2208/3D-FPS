## 修复与性能

- 物品事务继续同时更新背包与马具。仅更新出战、召回状态的可靠消息移除了重复装备明细；接收端按马匹 ID 合并。个人名册直接生成卡片所需的身份、出生版本和等级，消除了逐匹查找整本名册的平方级开销，升级刷新保留滚动位置。忙碌期马具请求未提交时有提示。
- 马像高度现在有上限，同名编号移至毛色行。生命和体力在窄栏中允许分行。正式详情与离屏复核都移除了滚动区底部意外出现的遮挡条。
- 当前机器 RTX 3080 Ti，DX12 1280×720，固定机位、临时补光、同一院内两匹马，顺序为显示／隐藏／隐藏／显示，两种状态各 360 帧。显示时 GPU 中位 5.08 ms、P95 6.04 ms；隐藏时中位 4.87 ms。中位差约 0.22 ms，属于整个视图对照。贴地求解单马约 0.03 ms、八匹奔跑合计中位约 0.26 ms。逐帧记录
- 本轮使用监听主机与一名远端玩家，没有覆盖专用服务器、大量玩家长期并发、整村混战、所有装备的实战命中，以及长期受阻时各种动态障碍物。骑乘镜头的步态系数在源码中为 0.70，未做主观舒适度验收。
