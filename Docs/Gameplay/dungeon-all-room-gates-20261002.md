# 全战斗房封门规则

2026-10-02，用户要求每个房间刷怪后落闸，清理完成才能继续，避免抵达档案中心后才发现前段漏怪。本规则替代此前普通清路房开放、推进房入口开放的处理。

## 运行逻辑

- `DungeonSpawnDirector` 为所有有怪物编成的普通房、公共前段、过渡房、主题核心房及档案室创建房间遭遇，全部按真实连接门安装现有四轨闸门。精英抽选只影响编成与等级，不再决定是否封门。Boss 保持原有独立遭遇。
- 主入口估算仅用于辅助触发。封门依据节点实际 `Doors`，不会因为估算入口失败而跳过其余合法门洞。
- 玩家完整进入并离开入口安全区域后，同一流程锁定门口、生成怪物并播放落闸动画。安全区域包含门外接缝和角色完整胶囊，避免在玩家尚未进门时锁在外侧。
- 每道闸门增加只阻挡 Pawn 的全门洞战斗碰撞，在锁定时立即启用，覆盖落闸动画尚未封住的空隙，阻止玩家或怪物在门运动期间穿过。既有门板继续承担随动画移动的实体碰撞，清除后取消战斗碰撞并正常升闸。
- 封门状态锁存。玩家靠门、离开房间判定体积均不再开门；存活怪物与待生成槽位都清零才登记清除并升闸，不等待尸体回收。死亡时沿用开门重试，保留怪物和未完成状态，重新进房再次锁定。
- 全局存活上限仍有效；新房完全没有生成容量时暂不开战，已有部分怪物的房间保持封门并补齐剩余编成。保留原有导航、碰撞落点校验与有限重试；无法生成的槽位按现有放弃规则结算，不凭超时消灭已生成的怪物。显式零怪房保持开放并登记完成。
- 货运和档案原有推进闸门继续执行自己的条件。房间战斗闸门安装在门洞内侧的既有轨道位置，不改作者模型或房间布局；档案出口仍要求任意一路完成并清除档案室。

更新仍由现有遭遇轮询和门动画时钟驱动，完成后停用 Tick；没有新增全场 Actor 扫描、每帧加载或常驻门 Actor Tick。本次不改怪物品阶规则、掉落、主题组合、随机房数或房间美术资产。
