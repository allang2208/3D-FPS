# 墙面残砖修整方案与实施（2026-09-22）

## 本轮问题

用户截图中的残砖轮廓以尖三角和长直切边为主，局部显得薄、离墙，破口周边的小片密度过高。上一轮只处理砂浆基层，保留的旧残砖现在成为明显的近景问题。

现有作者代码中的缺砖残角与 Voronoi 碎片提供了破损位置，本轮保留这些位置作为输入，不继续沿用每个小碎片的形状。墙面材质和工作间布景沿用上一轮。

## 实施方案

1. 按已有瓷砖格计算釉面覆盖，保留大面积完整砖。只重制已有局部破损砖格，维修补丁单独排除。
2. 残砖优先留在与完整砖相接的破口边缘，每个砖格保留一个有体量的主残块；没有邻接支撑的孤立小片移除，不在破口中央补新的装饰碎片。
3. 断口使用数段较长折线与不同尺度小崩口，避免等长锯齿和满墙尖三角。完好铺装边仍保持直线。
4. 釉面、约 6–8 mm 的陶瓷胎体及背面粘结层分开制作；胎体断面采用独立粗糙颗粒 PBR。背面粘结层下沉接入已有起伏基层，残片不悬空。
5. 使用独立源目录、UE 网格和材质目录，完成后只切换原有 8 个墙组 Actor 的网格引用；原版仍可恢复。更新整场景安装顺序与可编辑装配源。
