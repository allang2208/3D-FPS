# M16 拇指表面与贴门撞门触发 V9

本轮针对拇指贴图外观及门碰撞导致前进速度归零后无法撞门的问题。

- M16 拇指采用有限参考坐标区域的独立材质处理。减轻原有褶皱的涂黑效果，补充浅层指腹细节，细化甲床、甲缘与指甲的粗糙度变化。保留现有原图、UV、材质参数，以及上一版手型和腕掌蒙皮。
- 持续按住 Shift 并向前输入时，闭门碰撞将移动速度降为零也允许撞门。删除实际速度门槛及速度关联的距离条件，使用 210 cm 最大探测距离，没有最小距离限制。
- 保留 0.21 秒持续冲刺输入、正对关闭的原生交互门、动作占用、同门防重复触发，以及 0.3 秒护拳停留、轻摆、恢复、成功开门时的用户音效和屏幕抖动。
