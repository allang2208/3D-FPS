# 地牢房间细节提升方案 / 2026-09-21

状态：方案分阶段推进。用户确认优先复用 Fab 库后，土坡、砂砾、碎石和门槛/石缝衔接已完成一轮制作与接入，见 [Fab 土石改造记录](dungeon-ruin-fab-earthwork-20260921.md)。墙石、石拱、维修间及灯光部分仍待执行。以下方案依据此前四张 UE 实景和已选概念图；土石改造后未新增截图或运行测试。

## 目标与判断

目标仍为“写实地下设施，融合被掩埋遗迹与异常事件”。这轮优先把两间房做成可信的物理空间。视觉优先级依次为轮廓与接缝、材质层次、使用痕迹、灯光层次。

- 维修间已有功能布置，但台面像新木板，布像折纸，罐体和灯罩的折面明显；新制小件与旧电柜、电机的精细度不一致。
- 遗迹的主要问题是整齐的方块轮廓、连续深黑接缝、近乎同色的石面，以及红褐色生成土石块与浅色程序土坡之间的硬边。
- 概念图的自然感来自有原因的局部变化：墙石磨蚀、灰缝被土填充、坡脚碎屑渐稀、踩踏路径露出石板、工作台附近集中磨损。只随机旋转、换颜色或铺满污渍无法达到这个目标。

## 第二优先：材质真实度

1. **石材分层。** 墙石以灰褐色矿物、细小孔洞和剥蚀层为主；地石增加磨平区域与细裂；灰缝更松散、暗一些。共同维持一种地质来源，避免逐块随机染成花墙。色差在局部成片变化，细节尺度对应真实尺寸。
2. **土体统一。** 生成砌体块和程序坡体统一到同一灰褐色土家族。近坡脚及低洼处局部较暗、较湿，上部较干。湿润通过颜色与粗糙度共同变化，避免一整块发黑或一整面镜亮。
3. **大中小三层。** 大尺度控制渗水和积尘区域，中尺度控制层理、剥落、颗粒团，微尺度控制孔隙与细砂。轮廓缺口由模型承担，浅表细节由法线/高度信息承担，实际来源和通道分别记录。
4. **表面映射。** 修正近景纹理密度及明显拉伸；木纹沿板材长度，端面有独立纹理。土石接触处使用共享尺度和局部混合遮罩，必要时加有厚度的过渡片与碎屑，避免用一条贴花掩盖断层。
5. **金属分层。** 油漆和锈层按非金属表现，露底处使用金属响应；积尘、油膜和磨亮区有独立粗糙度。避免所有表面只靠同一种噪声区分。

主材质需要调整结构时创建房间专用修订资产和实例，沿用现有安全导入方式；在接入时只切换本轮两间房的指定引用。

维修间的自然感允许规整的工业结构继续存在；孔板、管线、柜体不做无依据的随机扭曲。

## 第四优先：灯光与画面层次

在材质和几何完成后调整，避免用压暗掩盖细节问题。

- 维修间：台灯照亮拆修电机和局部台面；顶灯提供基础可读性，门口保留较冷的走廊环境光。把当前台面和灯下发白区域作为优先调整处，使金属、木料、布料仍可区分。
- 遗迹：施工灯从侧面擦过粗糙墙石和土坡，突出前后层次；入口和雕像保留足够可读性，拱顶与边缘逐渐暗下去。整体暖灰褐，避免所有表面均匀金黄。
- 阴影软硬匹配灯具的发光尺寸，并保留接触处阴影。参数值在接入时基于实际灯具与地图设置确定，不从截图反推一个固定曝光值。
- 后续若用户要求对比截图，复用此次记录的相机、视角和分辨率，记录照明变化；当前方案不触发新的渲染。

## 自然随机性的约束

- 固定房间功能，再选使用状态，最后选择摆设与磨损变体。
- “正在拆修”对应电机、工具盘、抹布、少量耗材和近台油污；“局部坍塌”对应断口、落石、坡脚土屑和清理出的通路。
- 变化优先来自部件状态和成组搭配，再使用小幅位置、角度和颜色变化。
- 落地、挂接、台面接触及通行区域是摆放约束；贴花和碎屑与附近事件位置关联。
- 本轮目标是做出可复用的房间资产与布置规则。运行时随机生成器的种子接入、事件逻辑和导航属于后续独立工作，不能用固定作者种子的场景代表已经完成。

## 推荐执行顺序和交付

1. 遗迹：局部接触区域 → 全房墙石、石拱、地面与土石过渡 → 分层材质。
2. 维修间：平滑法线与抹布 → 台面、道具身份与使用痕迹 → 局部地面和墙面痕迹。
3. 灯光：材质可读性 → 焦点与明暗层次 → 保存指定场景资产。

交付应包括可编辑 Blender 源、游戏网格、材质与遮罩、来源、作者脚本和精确接入回执。最终由用户判断是否达到概念图方向；目前只完成上述 Fab 土石部分的制作和接入，其他方案项未执行，未进行运行测试或新增截图。
