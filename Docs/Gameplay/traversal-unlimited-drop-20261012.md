# 翻越另一侧不限落差（2026-10-12）

用户确认：矮墙／栏杆另一侧即使有很深的落差，也允许翻越，越沿后进入自然下落；迎面障碍的可抓高度继续使用现有规则。

## 当前开发进度

现有实现已包括空格点按、空中抓墙、独立双手接触、浅平台落脚、标记栏杆双向跨越，以及第一／第三人称专用手臂可见性处理。第三人称仍使用程序身体动作与接触解算；此前找到的 Epic 全身动作候选不属于本次新增接入。

原探测要求另一侧存在可站立落点，普通地面／空中落差范围分别为 60／200 cm，带 `Traversal.GuardrailDrop` 的栏杆放宽到 300 cm。因此单纯提高落差数值仍不能支持探测范围外或没有地面的出口。

## 本次修改

- 保留既有可站立落点分支，新增不限最终落差的自然下落出口，普通矮墙和已标记栏杆共用。
- 出口必须先测得障碍背面与允许厚度，并通过完整胶囊的抬升、越沿和近处下落通道扫掠。只搜索既有厚度范围及近处净空，不向深渊无限延伸找地面。
- 新分支不要求另一侧落点，也不将未探测到的地面伪装成可站立支撑。规则层显式接收实际几何探测批准的下落出口。
- 到达障碍外侧后使用现有 `bReleaseIntoFall` 交给 CharacterMovement 的 Falling，后续重力、碰撞、落地与既有落地后果照常处理。远处落地组件不再作为翻越动作的手部支撑依赖。
- 自然下落分支将越沿横移延续至动作结束，去掉原先到达出口后占末段 22% 的空中等待。动画长度、抓扶／松手／收手、镜头与持物恢复共用原有时钟。
- 保留迎面高度、墙厚、距离、视角、过快下落抓墙、稳定抓点、头顶和沿途碰撞约束；高墙登顶仍要求真实顶部落脚。

修改文件：`FPSTraversalComponent.cpp/.h`、`FPSTraversalRules.cpp/.h`、`FPSTraversalExecution.cpp`。没有修改动画源资产、场景碰撞或关卡包，也没有新增反射字段或改变反射结构布局。
