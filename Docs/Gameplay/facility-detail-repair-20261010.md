# 分流大厅细节与玻璃残痕修复（2026-10-10）

## 任务范围

按用户五张截图处理第二大厅入口门套、员工区信箱/钥匙/壁灯、配电区隔离开关柜，以及维护墙设备重叠；排查所有共用玻璃破碎入口的攻击残痕。保留现有吊灯和照明参数、上一轮楼梯/角落灯、事件杂物、路线拓扑、门口净宽与可交互工具箱。

## 制作

- 入口墙和最后 36 cm 走廊增加门套安装槽，门套与墙体不再共享侧面/顶面；钢衬内侧仍保留 3 m × 3 m 通行截面，走廊护条终止于门套前。
- 员工区三格信箱重建折边外壳、投递槽及挡板、门缝、铰链轴、锁芯和编号牌；钥匙增加实际齿形、贯通匙环和挂签，挂钩留出空位。原先遮挡钥匙的回收牌移开。
- 圆柱壁灯改成有壁厚的透光筒与独立金属端盖，消除闭合筒底圆面和端盖共面；保留原光源。
- 配电组件增加柜门/密封条/折边、真实铰链、四分之一转锁扣、带防滑纹的隔离开关及挂锁孔、瓷绝缘子伞裙、端子夹、紧固件、压线接头和接地编织带。铭牌分离标示设备编号、额定值、开关状态和警告。
- 维护区工作台移到柱间；墙上从左到右排列断路器面板、带真实扳手/螺丝刀的挂板、电话/按键/卷线。指示牌移到独立上方，楼梯标牌另置；两只交互工具箱随台面移动，保留存储 ID 和开盖方式。
- 独立资产目录 `/Game/Dungeons/FacilityDetailRepair20261010`：19 个网格、1 张 2048 铭牌图集、1 个铭牌材质及 1 个无残痕玻璃破碎 Niagara。既有 PBR 材质继续复用；细小编号与钥匙网格不用 Nanite，大型细节组件使用 Nanite，标签保留完整 UV 精度。

## 玻璃问题定位与修正

`UWardBreakableGlass::BreakAt` 是枪击、法杖、快速近战、工具和其他玻璃伤害的共用破碎入口。现有逻辑已隐藏玻璃、停用碰撞并清理附着贴花，但原 `NS_Impact_Glass` 的 `LightDecal` 中还有使用 `MI_BulletHole_Glass` 的 emitter-source 裂纹精灵；仅停发射器并不等于禁用该渲染器。

制作独立 `NS_GlassShatter_NoMarks`，禁用玻璃裂纹精灵及弹孔贴花渲染器，保留碎屑、火花/闪光及声音。共用破碎对象预载此资产；原来的默认玻璃冲击系统走无痕副本，其他明确自定义效果保留。`FPSImpactFXSubsystem::AddDecal` 同时排除玻璃与不接受贴花的组件，避免近战/枪击路径重新留下投射痕迹。原样例冲击资产不覆盖。
