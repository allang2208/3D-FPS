# 焚化厅灰渣接收区 V3

**后续布局已替代：** 用户将原坑位改为负一层停尸房楼梯，接灰装置保留并移到右侧炉旁。当前场景以 [负一层主体设计](dungeon-incinerator-morgue-b1-20260930.md) 为准，以下尺寸记录为 V3 历史版本。

用户要求扩大原来的小灰渣坑，并用 Blender 构建接灰设备和提示牌。本轮沿用主体、炉门及已加入的护栏翻下行为，制作新的下沉接灰检修区。

后续：「注意高差」牌已按用户截图调整到两根立柱之间并向通道外移，使用独立 V4 标牌网格，详见 [告示牌位置修正](dungeon-incinerator-caution-sign-fix-20260930.md)。接灰设备与栏杆保持 V3。

## 空间与用途

原坑为 2.8 × 3.8 m（10.64 m²），扩为 **4.4 × 5.0 m（22 m²）**，面积约为原来的 2.07 倍。保持下沉 1.2 m；边界为作者坐标 `x[-13.0,-8.6]、y[-7.65,-2.65]`。这仍是厅内局部下沉区，没有新增地下二层。

楼梯从 1.2 m 加宽到 **1.6 m**，移至西侧 `x=-11.95`，保持 8 级、每级高 15 cm、进深 30 cm。接灰设备放在东南侧炉旁，楼梯下口至设备前推手之间按约 1.23 m 留出检修通道。主作业通道保持原来的布局，设备不放在楼梯口。

重做了主地板的真实开口、坑底/挡墙、楼梯和护栏；旧小坑的地板、坑壁、台阶和栏杆引用均需由本批安装器替换，不通过叠加盖板假装扩大。

## Blender 设备

- **炉侧导灰管**：接至左侧炉体侧面，带矩形管壁、连接法兰、螺栓和支撑。管线在设备上方进入接灰斗，说明灰渣从何处来到下沉区。
- **密闭干式接灰斗**：有板厚的锥斗、折边、焊缝、上盖、检修盖板，以及带锚栓的固定框架。
- **手动隔离闸门**：闸体、丝杆、轴座、手轮和下部柔性防尘连接。
- **抽拉式接灰箱**：独立制作，带真实内腔、围沿、密封接灰口、轮组/刹车、前推手、导向槽与后限位。当前展示停用和就位状态，不新增抽拉交互或灰渣流动模拟。
- **中文提示牌**：入口“灰渣接收·检修区 / 下行 1.2 米 / 设备停用·检修前隔离”；设备“密闭干式接灰装置 / 先关闸门，再抽出接灰箱”；坑沿“注意高差 / 保持检修通道畅通 / 请走楼梯”，另有闸门和接灰箱标牌。

标牌使用原创中文排版纹理，映射到有厚度底板的唯一正面，延续上一轮避免重叠文字面闪烁的修正。设备复用本厅已有烤漆、钢、橡胶 PBR；没有重新下载第三方整套设备。中文以本机微软雅黑渲染为图像，不随资源分发字体文件。

新护栏维持 8 cm 扶手与立柱、每段连续 UCX 和复杂几何分离；保存 `Traversal.GuardrailDrop` 标记，继续使用已编译的“最多 3 m、真实落点和完整路径成立后，撑过并交回重力下落”规则。本轮没有改原生 C++。
