# 仓库可搜寻容器

用户要求将四类仓库容器制作出来，并随机放在仓库合理位置。制作源在 `SourceAssets/WarehouseContainers20261002`，资产命名空间为 `/Game/Dungeons/WarehouseContainers20261002`。

## 容器与活动部件

| 类型 | 外观构造 | 开启动作 |
| --- | --- | --- |
| 加固运输木箱 | 木板、叉车支脚、金属护角、加固带、铰链、锁扣和物流标签；复用已认可工作台木材 | 后缘翻盖 105 度 |
| 塑料周转箱 | 有厚度的中空箱体、加强筋、实际提手孔、厚边沿、三种配色 | 后缘翻盖 105 度 |
| 金属运输箱 | 中空内壁、金属护角、密封条、把手、锁扣和设备标签 | 后缘翻盖 108 度 |
| 维护工具柜 | 柜脚、内部层板、门板、把手、独立上层抽屉和抽屉导轨 | 下门侧开；上层抽屉向外拉出 34 cm |

四类合计十个网格。箱盖、柜门及抽屉为独立网格，箱盖围绕本地 X 轴转动；原有容器门板偏航、抽屉和开放书架动作继续沿用。标签按图集原比例建面，木材使用现有材质所需的 UV1 和顶点颜色输入。

继续使用 `ColdSteelSceneContainer`、现有宝箱界面及聚焦轮廓。玩家朝向容器大致范围时显示绿色未搜寻、黄色已搜寻状态，打开后的活动部件保持开启。工具柜下门与抽屉有不同容器 ID，可分别搜寻。奖励配置后续设计。

## 随机摆放

`CargoWarehouseContainers::Compose` 在生产目录组装阶段，按局种子及房间节点生成固定可复现的选择，不在运行中持续扫描或随机挪动。

- 从 8 个原地面货物点中选择 4–5 个，交替采用木箱、金属箱，并给予小角度变化。
- 从 5 个可接近的货架下层点中选择 3–4 个，采用绿、蓝、灰周转箱，位置向走道侧调整；保留原货架及上层货物。
- 从 3 个预留空墙维护点中选择 1–2 组工具柜，柜门与抽屉分别构成容器。

总计每间仓库 9–13 个可搜寻容器。选择来自已有货物占位与预留空墙点，门口及主通道不作为候选。选中货物点只移除该点原来的 `CargoStack`，不叠加生成。运行 ID 包含局种子、节点和作者点位。
