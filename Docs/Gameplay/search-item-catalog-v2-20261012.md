# 四类搜索物品清单与制作配方 V2

2026-10-12。物品必须有明确实用用途，或者足够的出售价值。有限背包中的选择应是“当前需要什么、计划制作什么、带回什么更值钱”。没有拿取理由的物品保留为场景装饰，不进入拾取目录。

本版由40件收敛为22件：日常用品5件、文件材料4件、检修设备5件、机房设备8件。取消14种低收益杂物和普通资料；7种细碎制作耗材合并为2种核心材料；行政资料保留有完整性与身份的签章档案。仍覆盖现有15条制作配方，每条最多新增两类材料。

2件白色物品是矿泉水与普通面包，4件绿色物品是汽水、法棍及两种木工材料，其余16件为蓝色及以上。本统计仅指目录品种，不能当作掉落概率。V2替代V1设计；四件文件材料模型已保存为 UE 资产，售卖、新配方及新增物品搜索池尚未接入。完整物品ID、外观规格和配方输入见 [结构化清单](search-item-catalog-v2-20261012.json)。

## 两条设计轴

| 设计轴 | 必须回答的问题 | 保留依据 |
| --- | --- | --- |
| 实用性 | 现在能恢复什么，或者具体用来制作什么 | 生存效果或明确到制作台与产物的配方需求 |
| 稀有度与出售价值 | 为什么罕见，值得占多少格带回 | 物品身份、后续产出稀缺程度，以及出售收益 |

白绿物品可以存在，但应靠实际用途成立。补给充足时可以不拿食物，不准备造弓时可以不拿树脂胶；有明确需求时，这些物品的意义不由颜色决定。纯售卖物则必须让玩家看到明确收益。

V2对纯售卖物采用“单件基础出售价值至少300灵魂/格”的暂定设计筛选线，避免靠攒满一叠才变得勉强值得拿。生存补给和制作材料按实际用途判断，不套这条线。该数值尚未经经济实测，后续应与单次探索成本和区域总收益一起调整。

后续占格以用户确认值为准：U盘、档案备份磁带为1×1，加密行政资料盒、签章行政档案为2×2。签章档案保持900灵魂设计价，因此为225灵魂/格，作为这条暂定筛选线的明确例外，不因扩格自动涨价。

## 容器与奖励节奏

四类容器归属不变。寄存柜偏补给与有价值随身物，防护用品柜暂按员工应急补给配置；记录抽屉产出完整资料或数据载体；工具箱产出核心制作材料；服务器柜产出信息硬件。

减少无意义物品后，用产出数量与稀有概率控制区域总收益。允许空容器或较少但有意义的物品，不要求每个柜子塞满。蓝紫金红的发现反馈必须由实际稀缺性与价值支撑，不能只改颜色。高价值物品的出现地点与概率仍在后续搜索池阶段制定。

高价值收藏、紧缺材料和当前需要的补给各自形成取舍；不要求所有物品在所有状态下都必拿。V2只确定内容与价值方向，未宣称经济平衡已经测试。

## 制作与交付
