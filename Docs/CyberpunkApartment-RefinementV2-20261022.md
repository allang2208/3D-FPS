# 公寓截图反馈修订 V2

目标地图：`/Game/GameMaps/L_CyberpunkApartment`。本次以用户六张实际游戏截图和八项要求为依据，修订范围仅为公寓及其专属制作源。原版本和地图备份保留。

## 逐项处理

| 用户反馈 | 本次制作／接入 |
| --- | --- |
| 各门口闪动 | 排查五处开敞门洞与七处推拉门。原开敞门套的内侧与墙洞端面完全共面，改为有厚度的 U 形收口：喉部、前后返边、顶梁按边界相接；门柱与横梁改为端部相接。原门槛与地板顶面也同高，现门槛顶面高出地板 6 mm。 |
| 柜子灰黑、可开启搜索 | 重做空腔柜壳、背板、层板和独立门板／抽屉。厨房、玄关、客厅、卧室、办公室和健身室的柜格分别绑定现有 `ColdSteelSceneContainer`，使用原搜索 UI、存储、悬停描边和缓动开启动画。原冰箱分体网格也接为可开启容器。 |
| 客厅植物挡门 | 将卧室二门前的植物移到客厅前窗一侧，另一处植物离开沙发与侧柜之间的入口路径。盆与植物一起移动。 |
| 客厅书柜和旁边椅子多余 | 移除旧书柜、旧椅子；新制双列智能档案柜，具有内层板、通风槽、数据面板、状态灯和独立门体。客厅不再出现绿色旧书柜。 |
| 床头正对房门 | 截图对应西侧原主卧。移除该房的床、床头柜、旧衣柜与旧书桌，改为办公室：三屏工作站、独立主机、键鼠、供电线、办公椅、资料柜及墙面状态板；入口轴线保留空地。 |
| 毛巾篮放洗衣机上 | 使用原篮子，缩为适配洗衣机台面的尺寸，与洗衣机同向、居中放于顶面；底面按实际支撑高度设置。 |
| 镜子与相邻双卫 | 保留东侧小卫浴，替换绿色旧镜子为带黑色框和安装柱的透明玻璃；西侧较大的卫浴改为健身室，移除洁具和湿区墙面，新制跑步机、可调训练凳、双层哑铃架、训练储物柜、橡胶地垫和训练屏。 |
| 窗外夜景粗糙 | 完成当前源图／Cubemap 尺寸排查及 GitHub、Epic 案例研究。结论和具体分层路线见 [窗外夜景研究](CyberpunkApartment-BayResearch20261022.md)。本轮保留当前夜景，没有把调研结果宣称为新外景资产。 |

## 灰黑材质

公寓专属墙面改为中灰，顶棚为较浅冷灰，柜门与框架为石墨黑，金属饰边改为银灰。新制木饰面复用项目现有橡木颜色与法线贴图，将颜色转为烟灰木色；窗帘与软装引用现有灰色织物。

复用家具的绿色涂漆、橄榄色漆、木色与金属槽在公寓实例上覆盖，不改其他地图引用的共享网格或材质。植物的自然叶色保留。

## 搜索容器边界

- 每个可开启柜格有独立、稳定的 `Apartment.*` 身份；重新装配不随机更换身份。
- 柜壳由实际侧板、背板、底板、顶板和层板组成，内部没有原来的实心封堵体。
- 柜门以真实左侧铰点旋转约 102°；床头抽屉的前板、底板与侧板一同抽出。调用现有 0.65 秒缓动逻辑，空闲时不新增 Tick。
- 柜壳保留物理碰撞；活动门板采用查询碰撞，能够命中交互射线，开启时不挤压玩家。
- 复用原私有／共享库存和服务器交互路径；**公寓当前是可搜索、可存取的容器，没有新增随机首搜掉落**。地牢掉落表及其运行 ID／领取规则保持原范围，未将公寓伪装为地牢运行。
- 未更改共享 C++ 或库存配置；不声称联机、存档或动画已实测验收。
