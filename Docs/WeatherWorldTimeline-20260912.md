# 全世界天气与事件时间栏验收

范围为当前传送门开放的三个地图：`DayNight_Lighting`（天空基地）、`L_Normandy_FPS_Test`（诺曼底村庄）、`L_MilitaryTrench_FPS_Test`（战壕）。尚在开发、未开放的新世界不计入这次验收。

## 修正

- 时间栏直接使用 `AFPSWeatherManager` 的日期及同一份天气调度函数。此前 UI 从创建之时自行累计天数，跨日后新建 HUD 会按第 1 天预测，与正在运行的天气错位。
- 事件名称和详情中的位面按实际地图显示；不再把村庄、战壕的详情写成天空基地。
- 雨后天气提示读取本轮降雨结束时的真实排程，不固定写成阴天。无降雨事件时清除旧的进行中标记。
- 详情中的长提示自动换行，雨势强度变化也会触发详情刷新。
- 新建 HUD 的渐变纹理使用独立名称，避免覆盖旧界面正在使用的纹理并等待渲染资源释放。

保持每昼夜 2160 秒、每日 8 段及既有种子 122。自动天气是按种子生成的可复现随机序列；切图仍按原有地图初始化时间启动，不新增跨世界存档或改变每次进入的种子。种子 122 下，村庄和战壕第 1 日 09:00 到 21:00 的晴天段可持续约 18 分钟，长时间晴天本身不代表调度停摆。

## 复验

运行 `Tools/Weather/run_world_timeline_audit.ps1`。它用独立玩家档案和真实 D3D12 离屏渲染，连续进入天空基地、村庄、战壕并返回基地。每张地图先检查正常时钟，再将该地图实际使用的时钟加速至 60 秒/昼夜，自然运行到第 2 日的中雨和暴风雨；随机阶段不调用手动天气切换，不启用 `EventTimelineUIAudit` 的固定 UI 数据。

验收还记录提前显示的天气预报并等待它真实发生，检查跨日后的新建 HUD、Alt 鼠标交互、展开/详情/筛选、标记移动、手动天气与恢复自动、切图后的唯一管理器和 HUD。32 天排程抽样另查五种天气均可出现，不能将该抽样等同于五种天气都已逐一实时渲染。
