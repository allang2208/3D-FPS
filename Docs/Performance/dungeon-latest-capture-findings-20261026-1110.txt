后续先补齐一次有用证据，不再要求重复普通 JSON 来证明低帧：
1. 用户保存并退出 UE，通过根目录 Launch-F6-WddmCapture.cmd 启动，确认 Windows 权限提示。
2. 战斗前打开 F6 的“GPU 驻留/调度”，先确认“WDDM + UE 正在记录”；如果仍报权限错误，停在入口排查，无需再打一轮。
3. 保持当前质量、装备与通常路线，慢态后保留约 20 秒再导出整份 gpu-... 文件夹。无需额外打开资源清单。避免同时编译/烘焙或其他 GPU 重负载。
4. 将 WDDM 调度/驻留与 UE 队列、缓冲身份按时钟对齐。若仍缺少具体资源/硬件执行证据，再安排针对性的硬件 GPU Trace；WDDM 不保证单独解决全部归因。
不先关闭光追、阴影、Morph 或减怪来制造帧率改善；不在没有证据时改资源优先级、同步屏障或驱动设置。
