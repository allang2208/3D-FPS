# F6 性能面板：可靠性修订

日期：2026-09-22。用户授权先修可靠性，帧数优化留到后续。

本页是当前统计口径；早期 `dev-panel-performance-page-20260922.md` 作为历史记录保留，不能再按其中旧公式或瓶颈推断读数。

## 实际实现

- 在游戏/PIE World 生命周期内绑定 OnEndFrame，使用单调墙钟记录真实帧间隔，每引擎帧最多一次。采样与 UMG 分离，超过 125 ms 的长帧不截断；没有时间缩放、平滑或后台过滤。
- 保留以样本结束时刻划分的最近 10 秒滚动窗口，包含跨越窗口起点的完整帧。显示实际覆盖秒数、帧数、后台/暂停样本、样本年龄。环形缓存上限 8192 帧，容量截短会显示提示。FPS = 1000 / 同窗平均帧毫秒。
- Game、Draw、RHI、GPU0、等待和关键路径分别显示平均/P50/P95/P99/峰值与有效观察数。GPU 使用 RHIGetGPUFrameCycles(0)，不再使用 RHIGetFrameTime。线程/GPU 零值视为没有有效报告，等待零值在对应线程有效时可保留。
- 百分位改用 nearest-rank：sorted[ceil(p*n)-1]。少于 100 个样本显示尾部统计提示。预算阈值和颜色使用同一个 TargetFps。
- 线程/GPU 是引擎进程级原始观察，不是每个 World 的独占时间；各个计时异步发布，可能延迟或重复观察，不能当成同一帧的同步剖面。引擎 stat unit 屏显还会平滑，数值不要求逐字相等。
- 计数器按 World 累加，帧边界记录差分；读取快照不清零。窗口次数、次/秒、次/帧采用同一窗口；清空/重新开始时重建基线，不混入停录期间事件。
- 标志变化按实际改变字段数计；武器重建放在早退之后；补服装重建，区分主可见性刷新与世界可见性刷新，纳入身体阴影应用路径。它们不是引擎渲染重建次数，也不表示全部角色/全场景工作。
- 骨骼栏目分别统计配置、有效网格、已注册且启用 Tick、Leader Pose 跟随。移除“配置为 AlwaysRefresh 就是每帧执行”的命名。
- 静态 LOD 使用 GetNumLODs 枚举，不再添加不存在的零面档位；骨骼 LOD 为资产完整 section 的几何量。Nanite 仅显示 HasValidNaniteData，不据此声称当前渲染路径。
- 相机视锥来自当前本地玩家的投影矩阵与组件包围盒，去掉固定 90°/近处一律可见的近似；组件隐藏、Actor 隐藏、OwnerNoSee/OnlyOwnerSee 分开考虑。仍不获取遮挡结果，也不把阴影资格当实际 shadow pass。
- 同一次场景遍历收集资源和骨骼配置。补光源、音源、Niagara 激活组件、Cascade 粒子、ISM/HISM 实例和 DynamicMesh CPU 源几何，未知类别不再隐蔽地当成零成本。
- 排行改为网格资源复杂度：`(源三角数 + 0.1×顶点数 + 2500×材质槽) × 实例总量`。移除距离/视锥/阴影经验倍率，资产规模不冒充本帧成本；按截断前的全部候选计算分母和覆盖率，前 10/20/40/80 不再改变同一快照的分母。
- 场景/窗口构建计时覆盖窗口聚合、完整遍历及排序；列表和统计文本更新另记。两项不包含 Slate 布局/绘制/GPU UI 与模糊，不称为整个面板成本。
- 使用共享暗色卡片和有色 ProgressBar；按钮/页签禁止逐字换行，性能页有正确的选中样式；控制区允许换行，长对象名可换行并显示完整路径提示。

## 控件行为

| 操作 | 行为 |
| --- | --- |
| 冻结显示 | 保留显示快照；已开启的后台帧采样继续。状态行更新快照年龄 |
| 停止采集 | 保留最后帧时间/计数窗口；场景扫描仍可独立刷新 |
| 开始新采集 | 清空旧窗口及事件差分基线，从新帧边界开始 |
| 清空窗口 | 清空帧和观察开销窗口，重建事件基线；不改变采集开关 |
| 刷新间隔 | 只改变场景扫描/主体显示频率，不改变逐帧采样 |
| 导出 JSON | 导出当前显示快照，不暗中重扫；保存到 Saved/PerformanceReports，包含口径版本、来源、有效样本数、环境、覆盖率和显示条目 |

界面写明停止采集时，帧窗口可能早于当前场景扫描。导出是汇总快照，不是完整帧时间线或 Unreal Insights trace。
