## 制作范围

- HUD／角色属性读取：将原有物品标量缓存复用到战斗装备加成、套装、附魔、改造、技能与武器伤害面板的只读 JSON 访问。完整数据及定义共同作为键，区分大小写，最多各缓存 128 项。需要修改的 JSON 仍独立解析；不缓存最终战斗结果，装备、等级、技能、状态变化仍实时进入原公式。生命／魔法／体力上限等查询提前返回，避免先计算无关的整套战斗数值。
- 地牢旧灯：将起始区已有 Point／Spot／Rect 独立灯纳入现有房间连通性调度，仅作用于独立游戏的生成器保留区域。近房间和可见门洞候选保留，远房间渐隐，保留一秒滞后。无距离限制的旧灯设置 `max(40m, 衰减半径+20m)` 上限和 8m 渐隐；保留作者更严格的限制。原色温、强度、投影开关不变；重新生成、清理及退出时恢复旧灯运行时状态，不改写关卡灯资产。
- 地牢几何：按已导出的实际地牢网格清单处理高于一万三角的刚体。兼容且尚未启用的资产制作 Nanite 数据；已有 Nanite、小网格、流体和透明／动画材质分别保留。启用显式切线，保留 100% 回退三角和碰撞。Nanite 提供几何细节层级，本批不破坏性简化近景模型或强行替换原 LOD。楼梯和女神雕像导入脚本同步设置，避免重导后再次关闭。
- 纹理预算：`PoolSizeVRAMPercentage=30`、`r.Streaming.PoolSize=-1`，采用 RHI 的显存比例预算，替代 Epic 预设的固定 1000 MB。保留运行时显存预算限制，其余显存留给 RT、Lumen、几何和渲染目标。不是无限池，也不改贴图资源分辨率。配置在下次启动生效；本批未测量实际最终池容量。
- 武器图标：保留已有异步加载、分帧装配、异步 GPU 回读与目录图标。运行时仅请求适合捕获目标的 mip，最多 2048 像素；离线目录导出仍等待完整贴图。每个任务最多六次尝试，资源加载单次上限 20 秒、其余准备单次 10 秒，失败后回退目录图标，避免无限驻留重试。ASH-12 普通／潮湿弹匣图关闭错误继承的骨骼／变形／布料用途与自动用途扩展，保留原七通道 UV、接缝、法线和材质节点；制作脚本同步修正。
