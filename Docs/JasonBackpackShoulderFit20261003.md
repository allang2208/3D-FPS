# Jason 背包肩带调整

针对用户截图中胸前肩带扁平、锯齿边缘及贴入衣物的问题，单独调整原背包的两条肩带，保留包体、原三角形拓扑、UV 和材质。调整不涉及装备 ID、第一人称资产、存档格式或联机同步代码。

旧处理把肩带的各顶点分别投到裸身表面，既没有使用实际衣物外表面，也没有保留带状横截面。新处理使用连续截面整理宽度、弧度和厚度，以当前毛衣、深色毛衣、锁子甲和身体组成外轮廓，按整个横截面留出距离。肩部和胸前宽约 4.2–4.5 cm，下段收窄至 2.3 cm 并绕回包体下方。厚度设为 0.48 cm，非缝合端截面以衣物外 0.61 cm 为制作间距。

两端权重逐渐回到包体使用的 spine_03；中部从衣物轮廓转移权重并沿带长平滑，同一截面共用权重，避免独立顶点受不同骨骼牵引形成凹凸边缘。制作间距是参考姿势中的建模参数，不代表所有动作均已验收。
