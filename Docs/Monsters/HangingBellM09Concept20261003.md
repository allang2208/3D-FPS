## 角色定位与造型锁定

定位为室内天花／横梁上的伏击与区域压制精英。长臂是承重和换握器官，眼冠是感知、瞄准与摆锤器官，背叶是可收展的鸣震组织，腹前小手是护眼与近身防卫器官。四组器官有清楚分工。

保留原画身份：

- 恰好两条巨型悬挂手臂和两条腹前小臂；没有腿脚，没有肩上人头。
- 大手五指弯钩状扣住支撑物；金属腕箍和肩背环保留。肩背环是装具，实际组织根仍连接身体。
- 小手只出现在身体前侧，日常交叠护住眼冠上缘。背视不得再画一双腹前手。
- 眼冠位于身体最下方，向下渐尖，多眼嵌在有体积的皮褶中。大眼集中在前／侧，背面采用较小眼和连续背褶。
- 六片背叶是有厚度的活体膜，冷灰蓝血管与灰白肉色边缘；叶缘孔洞和裂隙保留在各自连续主片上，不拆成漂浮细条。
- 不是飞行翼，不加入拍翼飞翔动作。悬挂靠真实抓握支撑。

设计比例暂定从指尖最高点到眼冠最低点约 280 cm，静止最大宽约 160 cm。原画 2.8 m 标注的测量端点不充分，本次明确以上端点作为建模假设，尚未做三维量测。场景承重点高度建议 340–400 cm，使眼冠约处于离地 60–120 cm 的可交战高度；具体落点以最终握点到眼冠长度调整。两手并握间距先按 65–80 cm 制作可调参考。

三视图采用悬挂展示姿态，不能直接当自动人形绑骨的 T 姿。后续需另存专用绑定姿态：大臂稍外展、小臂与身体分离、手指逐根展开到可蒙皮间隙；姿态改变不改骨长和角色比例。

## 组织拆分合同

左右均按角色自身解剖方向命名；背视画面左侧等于角色左侧，正视相反。

| 对象 | 内容与连接 | 制作和驱动 |
| --- | --- | --- |
| M09_Body | 躯干、两条悬挂臂、两条小臂的连续主皮肤 | 一个共同骨架；手臂是语义骨链，不为拆分强行切开肩部皮肤 |
| M09_RootBand | 左右肩背至中背的肉质连接带 | 并入身体或使用一致的焊接边权重；跟随胸背，不参与末端摆动 |
| M09_Membrane_L1 / R1 | 上层、最外层短背叶 | 独立完整显示对象；覆盖 L2/R2 根部的局部轮廓 |
| M09_Membrane_L2 / R2 | 中层中长背叶 | 独立完整对象；与相邻叶有清楚前后层序 |
| M09_Membrane_L3 / R3 | 下层、内侧最长背叶 | 独立完整对象；末端延伸到眼冠侧上方，保留前侧手臂通道 |
| M09_EyeCrown | 下垂眼冠主体 | 与躯干连接颈组织连续，独立语义控制链；非硬接缝的可拔插头 |
| M09_Eyes | 眼球和眼睑 | 共享材质图集；主要眼控制凝视，其他眼分组低幅运动 |
| M09_Cuffs_Rings | 两个腕箍及肩背金属环 | 独立硬表面对象，刚性随所属骨段；不混入软组织权重 |

六片是独立制作对象，不等于六个游戏 Actor、六套独立材质或六套实时布料。装配可合为同一 Skeletal Mesh 的逻辑分区，保持共同骨架和较少材质槽。拆分是制作／驱动分工，首版不包含玩家逐片打断、动态撕裂或肢解系统。

每片结构采用固定附着基部和沿主脉延伸的 ROOT → MID → TIP 骨链：

1. 附着基部继承躯干，位置固定；开合转动在基部之后的可变形主脉上分配，不让整个根从身体拔离。
2. 中段承担主要展开弧度，末段跟随并小幅延迟。三个部分在同一连续弯曲平面协同，不绕长轴拧成螺旋。
3. 显示面从根到末连续蒙皮。UV 分裂产生的重合顶点使用一致变形权重；相邻片保持自己的 ID，不跨片捕获。
4. 片上裂口由连续外边缘和局部孔洞表达，不能通过删除长条三角形“稳定布料”。
5. 待机轻摆、受击余振和大幅攻击展开分别制作。鸣震的大幅开合使用动画主轨，末端弹性只作很小的附加量，不以弹簧或布料驱动伤害时钟。
6. 首版不制作 Chaos 粒子布料。以后确需柔软末缘，再按每片连续低密度代理制作，统一驱动归属；不要直接复用 M07 的失败代理或把每条血管都当独立模拟岛。

材料先分身体、膜、眼、金属四类。膜的厚度、血管和边缘靠真实几何与同源纹理表达；首版优先有透光感的双面／次表面外观，避免将整身多层膜直接做成大面积透明混合。法线、粗糙度和颜色图需后续正式制作，概念图不代表已具备 PBR。

## 悬挂与移动设计

首版使用关卡显式提供的握点／横梁路径。可在本段梁上交替换握和有限转向；转移时至少一只大手承重。换握中不同时发动攻击；目标离开可达梁段时回原位，不能把地面 NavMesh 平移到天花冒充悬挂寻路。

大手保持真实握点，胸背和眼冠在可达范围内摆动。动画移位、悬挂根和碰撞使用同一轨迹。摆锤不是双手固定后任意平移角色；最终姿态需根据肩肘可达性制作。

未指定任意墙面爬行、全地图天花导航或自由飞行。后续 F6 接入时，生成入口必须找到有效承重点，找不到时明确拒绝，不能半空无依托生成。这只是未来接入合同，本次未修改 F6。

## 攻击与玩家应对

下列时间和数值均为原创设计起点，未做游戏平衡或测试。D 表示该怪物配置中的基础近战伤害，不从既有怪物未经读取的数值推定。时间以攻击开始为 0，单位秒；伤害和动画共用一个时钟，区间采用左闭右开 [开始, 结束)。

| 技能 | 前摇／命中／收势 | 范围与伤害提案 | 明确信号和应对 |
| --- | --- | --- | --- |
| 钟摆横撞 | 0–0.85 蓄摆；0.85–1.20 有效；1.20–2.30 收势 | 实际眼冠／躯干扫掠范围，悬挂中线附近约 1.8 m；1.25D，轻击退，每目标一次；CD 4.5 s | 小手抱紧眼冠，背叶收拢，身体先向反方向压摆；玩家横向离开摆动平面，打空后有约 1.1 s 反击窗口 |
| 三叠鸣震 | 0–1.10 蓄力；1.10、1.45、1.80 各一次脉冲；1.80–2.80 收势 | 前向 100°、6 m 的可见压迫扇区；每次 0.30D，共三次；CD 8 s | 上／中／下背叶成对依次张开，发出由低到高的三拍低鸣；玩家退到扇区侧外或实心掩体后 |
| 群眼凝视 | 0–1.25 聚焦；1.25–1.85 放射；1.85–3.00 收势 | 最远 14 m、约 20 cm 宽单束；1.25、1.45、1.65 三次判定，每次 0.35D；CD 7 s | 群眼转向同一点，主眼变亮，淡预告线指示方向；0.90 s 锁定瞄准后侧闪或进掩体，也可射击暴露眼冠打断 |
| 护冠双爪 | 0–0.35 展臂；0.35–0.55 有效；0.55–1.10 回护 | 腹前实际双手扫掠，约 0.9 m；0.55D，每目标一次，两手共享去重；CD 2.5 s | 腹前小手先张开再向前抓；后撤或侧绕。只在目标真实进入前侧手部可达范围时使用 |

### 钟摆横撞

两条长臂继续承重，躯干带眼冠沿一个清楚的摆动平面横扫。不是伸长手臂、用眼冠锁定玩家后持续追踪。0.60 s 后锁定本次摆动平面；命中阶段不转弯。

暂定摆角约 30–35°，实际触及距离由最终握点、骨长和扫掠形体决定；表中的 1.8 m 是制作估计，不额外加一个看不见的远距离伤害球。眼冠提前闭眼护住自身，完成后睁眼；身体与眼冠共用本次命中去重。

### 三叠鸣震

六片膜按照 L1/R1 → L2/R2 → L3/R3 成对开启。组织是生物共鸣器，声源由主躯干和根带共同表现，不新增一张嘴或实体钟。攻击方向在 0.80 s 锁定，三次脉冲共用这个方向；不逐拍转向追人。

每次脉冲建议附带 0.45 s 的轻微减速，幅度 15%；刷新剩余时长而不层层叠加，不锁输入、不连续击倒。三拍全部吃到也只有一次完整技能的伤害预算。墙、封闭门等实心掩体阻挡本技能伤害；隔墙可能听到声音，但听到不代表受伤。

两侧膜张开后，根部与眼冠更加暴露；这给玩家一个选择：撤离压迫区域，或射击弱点抢打断。组织分片与三拍节奏对应，视觉结构直接服务玩法。

### 群眼凝视

所有眼同步聚焦，但只生成一束主攻击，不为每颗眼创建一个弹体或独立射线任务。0.90 s 锁定空间目标点，剩余约 0.35 s 的静止预警加实际放射阶段允许侧移脱离。束线从真实主眼位置出发，命中第一处有效遮挡即终止。

第一版不采用“玩家必须盯着怪物才受伤”或强制转镜头。危险来自可见束线所在位置，玩家应对规则直观。命中采样为 1.25、1.45、1.65，1.85 结束点不追加第四跳；每次采样每目标至多一次。

### 护冠双爪

用于惩罚直接站到眼冠正前方持续贴脸输出。两只小手共同完成一个动作和一次伤害，随后收回护冠；不制作无前摇抓取、持续吸附或不可挣脱处决。

## 弱点与打断

- 眼冠睁开时建议承受 1.5 倍弱点伤害；凝视蓄力阶段增加削韧反馈。闭眼护冠时恢复身体倍率，不能无提示无敌。
- 背叶本体仍算身体普通命中；展开时露出的肉质根部可提供削韧加成。根部不是金属环，不要求玩家射击极细的线状区域。
- 大幅失衡进入单手承重的“坠垂”状态：一手松握、身体下沉并摆回，眼冠暴露约 1.4 s，然后重新换握。全过程另一手保留支撑。
- 不把普通硬直做成双手松开后悬空定住。首版活体重击采用上述悬挂失衡；完整落地、生存爬行和重新攀上天花属于另一套动作，不在本次设计包声称已制作。
- 任何打断取消本次尚未发生的鸣震脉冲、凝视采样和近战窗口。攻击占用互斥，不允许鸣震期间再放凝视。
- 冷却从攻击起手开始计算，打断不重置成可立即重放；正常收势结束后建议保留至少 0.55 s 的全局间隔。

攻击选择原则：近身可达用护冠；短距落在摆动走廊用横撞；中距扇区可覆盖用鸣震；远距视线清楚用凝视。保持清楚的玩家应对机会，不按帧重新决策打断自身前摇。

## 动画与专用骨架制作清单

使用本物种专用骨架，不能把无腿悬挂怪强套普通双足自动骨架。至少包含悬挂根、胸背主链、两条五指承重臂、两条腹前手臂、眼冠摆动链和六条膜骨链；骨数按实际拓扑确定，不套 M07 总数。

| 动作组 | 所需片段与接触约束 |
| --- | --- |
| 悬挂待机 | 呼吸轻摆；双手保持握点，小手护冠，眼睛分组低频巡视 |
| 换握移动 | 左右各一套完整换握周期；旧手松开前新手已形成承重接触 |
| 转向／警觉 | 先群眼聚焦，再躯干有限转动；大手不沿横梁滑动 |
| 横撞左右 | 统一前摇、命中、收势，左右使用同一有效合同 |
| 鸣震 | 蓄力、三对膜依次开启、闭合卸力；脉冲点写入事件表 |
| 凝视 | 主眼聚焦、锁点、放射、熄灭、小手回护 |
| 双爪 | 展指、出手、一次接触、连续回护 |
| 受击／坠垂恢复 | 短受击不破坏握点；大失衡解除一侧支撑并按重心恢复 |
| 死亡 | 先取消攻击、闭眼失张力，再错时松握，之后自由落体与落地物理 |

死亡提案：约 1.0 s 的死亡交接片段，双手在 0.35 s 前后相继解除支撑，0.60 s 以当时姿态和速度交给受预算约束的布娃娃。实际时间需随正式片段制作，不能先写死后让动作追代码；解除握点不能拖到布娃娃落地之后。死亡无隐藏额外爆炸或落地伤害。

活体碰撞用于真实攻击查询和身体占位；死亡物理用于主要承重躯干、上臂、前臂、眼冠的有限形体。膜片首版不用逐叶刚体互撞，手指也不逐根配置碰撞体。

## 后续制作顺序

1. 以本次图与分件表冻结外观方向，进一步确定用户指定的三维来源。
2. 制作主体体积和六片连续背叶；金属腕箍／环及组织根接口本地建模。生成主体只作为候选，薄膜连续面和精确连接不能完全依赖自动生成。
3. 保存完整母版、独立分件和共同参考矩阵，再制作专用绑定姿态、UV 与 PBR。
4. 完成双手悬挂和换握基础，随后做横撞、鸣震、凝视与护冠；每个动作都保留承重和器官通道。
5. 接入承重点、共享怪物战斗接口、伤害与打断、死亡和 F6 实际资源入口。此时再执行必要后台构建和导入保存。
6. 根据用户明确要求开展预览或测试；不自动启动编辑器、PIE、截图、渲染或回归。
