# 怪物端六维剔除 · 防御常量化（2026-09-28）

## 决策

用户拍板：怪物端剔除六维（力/敏/智/体/精/运）。理由：怪不升级、不穿装，六维是**静态中间量**
（公式输出终生不变），攻击与生命本就走字面量覆盖，六维只喂防御四项 + 战斗等级 + 图鉴显示，
徒增认知与维护成本。玩家侧六维（`CoreCombatFormula`）不受影响。

## 行为差异（如实记录）

- **k=1 时数值逐位不变**：常量=原六维公式输出，且已并入全部字段覆盖；检查器按历史六维推导对照通过（0 问题）。
- **渐进感染减益的 floor 位置**：原实现先缩放六维再 floor（`floor((1.5体+.3力)·k)`），现改为 `floor(1.5体+.3力)·k`——与狼系字段的原语义一致，差异 <1 点防御，仅在怪物处于感染减益状态时出现。
- **实例字段覆盖失效**：此前对狼/大手/小手/手脑实例或 BP 的 `PhysicalDefense`/`MagicDefense`/`CriticalResistance` 字段改值会被运行时读取；现全部走常量表，改值不再生效（7 个 BP 的 CDO 已逐一核验等于常量，当前无实际损失）。调防具=改 `MonsterCoreStats.cpp` 常量表。
- 攻击与生命口径不变：仍是各类字面量字段 + `HealthMultiplier()`（现 1.0）。
