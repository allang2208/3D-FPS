# M07 V38：肩部与上臂根部布料固定

日期：2026-10-03 制作，2026-10-04 后台保存。用户反馈肩膀／上臂根部出现缺口，随后授权修复。

## 原因与修订

V36 用材质／组织标签直接决定布料活动区域，遗漏了第 3／6 片中属于肩部覆盖面的原蒙皮连接。先前定向源排查发现：左右分别 1,252／1,102 个主要跟随锁骨／上臂骨的顶点被开放为布料，附近代理仍有厘米级活动空间。原 V35 与 V36 导入三角形数均为 207,321，未见删面；V37 只补充了材质 Clothing 用途。

V38 从 V36 制作源继续：

- 原显示几何、UV、材质、V35 权重、83 骨参考及动作全部保留，只修订布料活动掩码和代理固定范围。
- 根据实际锁骨—肩—肘骨段和原蒙皮的手臂权重确定固定区，不再把组织标签等同于可动膜片。8,687 个肩／臂相关表面顶点保持原蒙皮驱动。
- 在虚拟焊接后的表面图上传播距离，固定区外额外保留 5 cm，再用 25 cm 表面距离平滑释放。跨材质及 UV 接缝共用边界；可见网格不焊接、不删面。
- 同步缩小代理在肩根附近的可活动距离，避免仅固定显示表面而让底下的代理继续游动。代理固定点从 234 增至 360，总规模仍是 1,170 顶点／2,128 三角形。
- 新增固定的原活动显示顶点为 10,824 个，源中仍有 51,280 个显示顶点保留布料混合。下方悬垂组织继续采用巫婆式 Chaos 模拟，最大位移 28 cm、12／16 m 距离渐退沿用。

以上计数来自制作过程，不是游戏或视觉验收。无新增运行时节点、求解器、Tick 或碰撞查询，不需要原生构建。
