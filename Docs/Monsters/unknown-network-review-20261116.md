# 未知与玩家第三人称：对话工作复核（2026-11-16）

本轮由用户明确要求检查遗漏和 bug，重点为联机。以当前源码、此前已经落盘的数值报告、后台构建和本轮独立联机记录分别说明完成程度，不把编译成功当作画面或实战验收。

## 本轮修复

1. **远端玩家枪口选中不同表面。** 之前每个观察端从各自的远端 Pawn 视点重新检测瞄准落点；蹲伏、网络平滑、门框附近可能与持枪玩家实际视点产生视差。现在持枪玩家采样最终游戏瞄准落点，随身体表现同步。服务器检查坐标范围，沿用武器实例身份和 0.6 秒表现有效期；此坐标只控制表现，不参与伤害裁定。
2. **未知冰甲缺少受击与近战寒冷反击。** 未知有独立 `TakeDamage`，此前没有调用玩家冰甲的已接受伤害入口，且该入口仅接受怪物攻击者。现在在服务器实际承伤后提供玩家来源和真实武器接触类型，复制破冰反馈；只有近战接触施加寒冷，远程命中只播放受击反馈，持续伤害不触发。未知不会给玩家训练档案增加冰甲经验。
3. **未知闪电链、圣光在客户端缺少释放声音。** 两个共享执行器仅在服务器本地播放声音，复制的电弧/光柱没有对应声音事件。新增未知专用客户端释放声音通知，服务器继续只播放一次；异步素材超过短时有效期不补播旧声音。
4. **圣光初次复制重新播放全程。** 光柱原来在每端从零累加年龄。改为复制服务器开始时间，新相关副本从当前年龄和消退阶段加入。此改动只影响表现。
