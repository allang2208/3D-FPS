## F6 使用与调整

普通咬击已按用户选择加入重心前送、肩颈跟进及前肢承重变化，见 [普通咬击 V2](WolfBiteV2.md)。接入仍使用 `AttackBite` 槽与原有命中窗口。

进入游戏后按 **F6 → 怪物生成 → 野狼**，设置数量（1–10）与距离（3–15 米），点击生成。沿用面板现有导航、地面与空间条件提示；“清除生成怪物”会清除本面板生成的狼。F6 目录 ID 为 `Wolf`，占地半径 100 cm。

UE 蓝图入口：`/Game/Monsters/Wolf/BP_WolfMonster`，父类 `AWolfMonster`。在 Class Defaults 的 `Wolf` 分类调整数值；动作引用和接触窗口在 `/Game/Monsters/Wolf/DA_Wolf_AnimationSet`。原生动画类为 `QuadrupedTemplateAnimInstance`，使用真实原生姿态图；状态机由角色和现有 BT 分工驱动。

F6 本次只扩充既有怪物目录行，复用原面板结构、冷钢主题、尺寸响应、选择高亮和按钮状态。数据范围为当前开发面板生成的临时怪物；生成结果继续显示成功数量或具体失败原因。没有增加独立弹窗、页签或地图入口。用户打开 F6 后即可选择，不需要手工放置狼。

## 动作状态与 AI

共用树以 Hold、Return、Attack、Pursue/Investigate、Idle 为优先级。AI 负责感知、目标记忆、导航和选择动作；狼角色负责唯一战斗时钟、接触、位移及打断。追击使用导航；丢失视线后调查最后位置，记忆过期或超出牵引距离时返回出生点，到家恢复生命并重置首次嚎叫。

| 状态 | 表现与退出 |
| --- | --- |
| Idle | 呼吸待机；发现目标后由 BT 决策 |
| Howl | 首次远距离遭遇嚎叫，1.20 s 通知附近未交战同类；打断则取消尚未触发的召集 |
| Chase / Returning | 走跑相位混合；追击 380、返巢 100 cm/s |
| Bite | 警戒起势 → 咬击 → Recovery；每次最多一次伤害 |
| Pounce | 警戒起势 → 锁定方向扑咬 → Recovery；可侧移躲开 |
| Stagger | 左、右、正面源受击片段；眩晕保持受击姿态后播放恢复尾段 |
| Recovery | 短暂停顿后交回 BT |
| Dying | 取消所有攻击，停止 AI、移动与活体碰撞，播放 Death 前 60% |
| Ragdoll | 交接当前死亡姿态，物理继续倒地；稍后休眠，尸体按寿命回收 |

附近同类收到嚎叫时获得最后目标信息，仍通过共用视线规则决定能否攻击，不连续传播嚎叫。受击／弹反中断当前扑咬并清除未消费伤害；死亡为终止状态。目标死亡、离场或脱战清除时取消当前攻击。每个攻击先消费命中，再回调玩家伤害，避免同步弹反后重复伤害。

## 源动作与时间合同

沿用 `WolfV1` 的 21 个动作槽，本角色实际调用 Idle、Walk、Run、IdleAlert、Howl、AttackBite、AttackPounce、HitFront/Left/Right、Death。其它休息、转向、奔跑咬击槽保留供后续行为使用，没有把每个槽都强行接进 AI。

制作前读取原包 Bite、JumpBite、Walk_RM、Run_RM、Death 和三向受击的 30 fps 骨骼样本，记录在 `SourceAssets/WolfMonster/reference_motion.json`。Bite 先左上起势，再向前横扫，下压后回正；JumpBite 先抬头抬躯，随后前压并恢复。保留源关键帧及左右差异。本次没有重新制作骨骼关键帧、没有运行视觉预览，接触区间仍待用户试玩调整。

| 动作 | 源时长 | 源接触半开区间 | 含额外起势的战斗接触区间 |
| --- | --- | --- | --- |
| Bite | 20/30 = 0.6667 s | [6/30, 11/30) = [0.2000, 0.3667) | [0.3200, 0.4867) s |
| JumpBite | 25/30 = 0.8333 s | [10/30, 16/30) = [0.3333, 0.5333) | [0.6333, 0.8333) s |

两个窗口只由角色自己的动画数据集读取。嘴部位置取 `Wolf_-Head` 向前 18 cm；接触同时要求距离、前方角度、视线和玩家胶囊最近表面在接触半径内。动画求值先于嘴部查询；大帧跨过窗口时仍消费该窗口的源姿态，伤害不依赖 Notify。

扑咬在开始时锁定朝向、起点与距离，在源 0.10–0.50 s 按碰撞扫掠推进胶囊；额外抛物弧高 25 cm，与源模型自身腾空叠加。撞环境终止伤害；碰到目标停止推进，接触仍必须通过嘴部空间条件。胶囊是唯一位移负责人，Root Motion 关闭。

源 `_RM` 容器根记录的整段位移／时长给出走速 92.7、跑速约 444.5586 cm/s，写入角色动画数据集作为步频参考；角色实际速度按 100／380 驱动相位。母版 140／450 的初始值保留。足相位与地形足 IK 未作新适配。
