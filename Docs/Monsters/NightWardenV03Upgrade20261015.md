## 查到的问题与实施

| 问题 | 实施内容 |
| --- | --- |
| 手指末端、巨臂内侧混入腿骨影响 | 清除 3,462 个顶点的腿骨污染；在实际连通表面上平滑权重，统一重合 UV 接缝的权重，保留本体几何和 UV。 |
| 近似指骨、旧四指合并链并存 | 依据实际手部表面校准 24 根独立指骨；四指与拇指统一经过掌部父链，手电挂点随掌部；8 根废弃四指骨和 2 根拇指末端辅助骨不再进入变形导出。 |
| 缺少可编辑的手脚控制入口 | 制作 4 个 IK 目标和 4 个极向控制，默认保持 FK。控件仅存在于 Blender 制作源，导出动画时需烘焙，不宣称 UE 已具有运行时 IK。 |
| 贴近的袖子和衣身被距离匹配混在一起 | 袖肩使用连续衣物自己的权重场；内外层只连接明确对应的顶点，不把空间接近当作同一衣层。口袋、包边、线迹继承最终衣片权重。 |
| 弯肘时上衣侧缝被前臂牵走 | 侧缝约束在躯干和上臂支撑之间，移除前臂／手部影响；修正同步到游戏网格，保留侧缝几何和 UV。 |
| 衣身 666 个、裤子 390 个退化 UV 三角面，织纹尺度不一致 | 重做专用 UV 图集；新增按每个岛的实际面积缩放的细节 UV，并保持两套 UV 的切线朝向一致。导出前另修复 1 个包边的退化 UV。 |
| 材质缺少部位差异、宏观褶皱和遮蔽 | 制作衣片专用 BaseColor、ORM、褶皱法线；磨损、褪色、污渍和粗糙度按缝边、肘、膝、下摆、靴面分布。褶皱由实际高模表面场烘焙，织物细法线复用已有巫婆 Fabric09 输入，按 4 cm 尺度平铺。 |

高模保留在作者文件的 `HIGH_NW3_*` 对象中，不参与游戏导出。游戏 LOD0 保持 369,166 三角面；没有通过把烘焙高模加入运行网格增加细节。材质使用切线空间 whiteout 法线混合，宏观图集和细节图集分别采样。
