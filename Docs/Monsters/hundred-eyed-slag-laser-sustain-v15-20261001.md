# 百目炉渣 V15：激光持续魔法伤害

激光由整次攻击只命中同一玩家一次，调整为存续期间按固定间隔持续造成魔法伤害。使用现有权威攻击时钟，不按渲染帧数计伤害；一次查询中的玩家胶囊和多个骨骼碰撞体按玩家去重，下一次伤害跳允许再次命中同一存活玩家。

| 默认参数 | 值 |
|---|---:|
| 蓄力 | 1.5 秒 |
| 激光存续 | 0.65 秒 |
| 伤害跳间隔 `LaserDamageIntervalSeconds` | 0.13 秒 |
| 每跳系数 `LaserDamageMultiplier` | 0.4 |
| 每跳基础伤害（`MagicAttack = 35`） | 14 |
| 完整命中基础总伤害 | 70（原为单次 56） |

伤害时间点为发射后 0、0.13、0.26、0.39、0.52 秒；首跳在进入发射状态后的首次更新执行，末端 0.65 秒不追加第六跳。低帧率越过多个时间点时补足已到期伤害跳；玩家每跳都需要仍在当时的激光判定中，并通过存活、玩家身份和遮挡过滤。实际扣血继续经过现有魔防、易伤、减伤及无敌公式。

光束端点每帧随当前遮挡更新，伤害使用同一截断光束。目标离开光束或进入掩体时停止承受后续跳，打断、眩晕、怪物死亡和技能结束后不会继续计伤害；没有额外后台伤害定时器。蓄力与收势没有伤害。

两个伤害参数继续位于角色 `Slag|EyeLaser` 分类；`LaserDamageMultiplier` 现在表达每跳系数。将间隔或存续时间调大／调小会改变总跳数和完整命中总伤害。已有蓝图或关卡若人为覆盖过旧伤害系数，需要按每跳口径调整；默认 F6 原生新生成角色使用本轮默认值。

V14 的贴眼红色能量材质、旋涡、吸入光丝和缩圈沿用现有已保存资源；仍为横扫、下劈、眼部激光三种攻击。没有本轮新增或重导动画、模型、材质或粒子资产。
