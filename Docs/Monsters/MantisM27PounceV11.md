# 螳螂-M27：飞扑镰刃方向排查与修正 V11

2026-10-07，用户反馈 V10 飞扑镰刀方向仍不合格，明确要求重新排查并调整。本轮定向读取、渲染制作源关键帧，并读回 UE 导入姿势；没有开启游戏、PIE 或执行战斗回归。

## 排查结论

V10 的 `overhead_turn` 仅将「肩部到 blade_mid」方向对准抬高/下挥目标。这只能决定镰刀的位置趋势，无法确定镰刃平面的翻转角。原重定向臂链残留的刃面朝向继续跟随，导致侧面看左镰在落地时接近横躺，像用刀面拍击，而不是用刃口下劈。左右镰的翻转角也不同。

证据来自 BindingV2 实际刚性刃面顶点的最小厚度平面、V10 动作矩阵和同源模型的正/侧面关键帧。以刃面法线对身体水平肩线的夹角作为该方向偏差（0 度代表刃面位于前后竖直平面）：

| 时刻 | V10 左 / 右 | V11 左 / 右 |
| --- | --- | --- |
| 空中 0.20 秒 | 66.01 / 47.57 度 | 0.48 / 7.12 度 |
| 空中约 0.48 秒 | 77.52 / 68.32 度 | 3.49 / 3.75 度 |
| 落地首帧 | 89.96 / 55.93 度 | 5.21 / 10.13 度 |

这不是刀口锋利程度或游戏命中率的测量，只用于确认刃面朝向问题。少量偏角保留给原身体转动、两侧分离和离地约束。

## 修正

- 仍从 V6 读取原动作，不叠加已否定的 V9、V10 姿态。
- 从真实刃面拟合平面，再以根部、尖端和曲线鼓出侧确定带方向的双轴坐标；同时控制镰刀长轴和刃面翻转角。
- 头顶举镰时，凹面刃口朝前；沿身前下挥时，刃口随同一条弧线转向下方。两把镰刀分居左右，维持原 0.60 / 0.65 / 0.80 秒三段时长。
- 只改变左右上臂旋转，整条手臂与刚性镰刀一同旋转。肘部、腕部局部动作、骨长、位移、缩放、原模型和权重保持 V6。
- 在制作中发现，沿用轴角平均处理完整刃面旋转会在四元数正负表示/180 度边界产生假旋转。改为对齐同一半球后的四元数加权，消除了该候选中的 138–178 度单帧跳变；最终空中最大单帧变化约 16.98 度，落地约 7.96 度。蓄力初段保留 V6 原动作的约 29.81 度最大变化，不将它宣称为本轮消除。
- 起跳衔接刃面旋转差约 7.12 / 7.91 度，落地衔接约 3.79 / 10.07 度，继续由现有 0.04 / 0.14 秒动画过渡接续。

## 导入与定向核对

三个 V11 动画及原 BP_MantisM27 的三段飞扑槽已后台保存，commandlet 退出 0。未修改 C++，无需原生构建。原 F6 入口、CombatV8 提前量与判定、破影双倍、致残 5 秒和流血概率不变。

在 UE 内按相同的 60 fps 精确源帧读取 RAW 动画轨：6 个关键时刻 × 左右镰 × 长轴/曲线方向，共 24 项方向比较。转换到同一模型朝向后，最大误差 0.0197 度。此项仅证明导入与制作源方向一致，不替代游戏中动画过渡和实际体验。

离线对比图将刚性左镰标为绿色、右镰标为紫色，只用于看清方向；正式材质未改变。上下两行分别为 V10 和 V11，三列为举镰、下挥、接地。
