## 几何、骨架与材质

背部 V02 保留纵向贯通的孔洞，细化孔缘及膜面过渡。身体表面、UV 和源纹理保留。近景模型为 625,042 顶点、1,250,160 三角形，未主动减面或创建减面 LOD；没有性能测量或帧率承诺。

按长度 2.6 m 等比落地，沿用实际 Meshy 身体比例。背拱、前肢、五指、蛙形后肢、头部和下颌分别绑定，最多四个骨骼影响。蒙皮使用解剖区域约束的骨段距离权重与表面边扩散；这批是初版专用绑定，尚无动画视觉验收。

材质分为原表皮与重建内拱，保留 BaseColor、Metallic/Roughness，原皮层保留法线。UE 导入转换 glTF 法线绿通道，使用原 UV 与全精度 UV 构建；不生成透明孔洞替代实体结构。

## 动作与攻击合同

| 动作 | 时长 | 用途 |
|---|---:|---|
| Idle | 3.00 s | 低姿态呼吸 |
| IdleAlert | 1.80 s | 警戒与攻击前状态 |
| Walk | 0.90 s | 100 cm/s 归巢慢爬 |
| Run | 0.60 s | 210 cm/s 低伏追击 |
| AttackBite | 0.85 s | 近距离压低、前探、咬合 |
| AttackPounce | 1.10 s | 蓄力、前肢前伸、短扑、落地 |
| HitFront / HitLeft / HitRight | 各 0.55 s | 三方向受击 |
| Death | 1.40 s | 重心下沉、侧倒，随后交给共享尸体物理 |

脚部接触轨迹在制作时用双段 IK 烘焙，运行时播放曲线，不新增逐帧求解器。动作均为本怪物新作，没有直接使用狼的骨架或原动画。

伤害由既有 `AWolfMonster` 捕食者执行层驱动，专属类 `ALurkerM08Monster` 配置参数。动画自身不发第二次伤害。

- Bite 接触窗口：动作源时间 `[0.30, 0.42]` 秒。
- Pounce 接触窗口：动作源时间 `[0.52, 0.64]` 秒。
- 扑击位移：动作源时间 0.16–0.54 秒，18 cm 弧高；遇碰撞沿用共享中断逻辑。
- 每次攻击沿用共享单次伤害消费、打断、死亡取消和服务器权威执行。
- `Wolf_-Head` 是口部兼容锚点，名称是运行时接口，不代表使用狼骨架。
- Blender `.L/.R` 名称经 UE FBX 导入转成 `_L/_R`；物理制作使用导入后的名称。
- 动画导入按绑定根的单位修复 FBX Armature 容器移除产生的缩放差异；没有修改子骨骼平移或动作时序。

初始数值：L8 普通怪；基础生命 340（仍经过项目全局成长），物防 24、魔防 14、抗暴 12、经验 300；近咬 32、扑咬 48。追击距离 14 m，归巢范围 22 m，扑击范围 1.9–4.2 m；这些是开发初值，尚未经用户实机调平。
