# 百目炉渣 BlackMistV17

用户要求：怪物背后黑色浓雾，遮挡玩家视线；进入后目盲 2 秒，在雾内持续刷新；激光伤害翻倍，普通近战伤害增加 25%。后台制作、保存、编译，效果由用户测试。

## 表现与状态

- 怪物脚底坐标系后方 245 cm、高 120 cm 生成半径 260 cm 的雾团，跟随怪物移动和转向，死亡或销毁时移除。
- 翻卷层复用项目已导入的 `M_RollingImpactSmoke` 和 `T_MuzzleSmokeMantaflowV14`，制作独立 `NS_SlagBlackMist`，黑灰色、多方向缓慢翻卷。既有共享烟雾材质不改动。
- 玩家独立后处理 `M_SlagMistView` 沿视线积累球体内的烟雾密度，并使用由场景深度重建的世界位置截断射线。远处目标经过雾团会被黑雾吞没，前景墙壁不会被身后的雾涂黑。后处理放在 tonemapping 之后，避免自动曝光提亮黑雾。
- 进入有效雾区，每帧把目盲截止时间延长到当前时间 +2 秒；离开后保留 2 秒，最后 0.2 秒淡出。近处 80 cm 保持清晰，80–250 cm 渐暗，250 cm 以外接近黑色。不改相机 FOV。
- 镜头在球体内且雾中心与玩家眼睛之间没有 Visibility 墙体阻挡才触发目盲，避免穿墙附加状态。玩家状态栏显示“目盲”，现有状态免疫、净化和死亡清除流程接入该状态。
- 每位玩家只持有一个后处理实例，多怪物共用。离开全部雾区且目盲到期后移除自己的后处理层，不覆盖其他天气或装备后处理。

## 预算

每个雾团 1 个 CPU Niagara 发射器，12 粒子/秒、最长寿命 2.8 秒，约最多 34 个粒子；不投射阴影，30 米距离剔除。每个玩家的后处理最多积分最近 4 个可见雾团，每团 3 个密度采样点，每点两次小尺寸噪声纹理采样。原创 256×256 可平铺灰度噪声纹理。游戏范围判定不依赖粒子显示或距离剔除。

## 伤害

- 激光：倍率 0.4 →0.8，默认魔攻 35，因此每跳基础伤害 14 →28。0.13 秒间隔、0.65 秒持续期仍为 5 次，完整命中基础合计 70 →140。原魔防和状态公式继续处理实际扣血。
- 普通横扫：新增倍率 1.25，默认物攻 42，因此基础伤害 42 →52.5。
- 下劈仍用物攻 ×1.4，默认基础 58.8；仍只有横扫、下劈、激光三种攻击。

## 参考与来源

参考 GitHub [IVSmoke](https://github.com/geb0598/IVSmoke) 的烟雾弹视线密度积分、场景深度遮挡思路；其主分支 GPU raymarch 着色器可见 `IVSmoke/Shaders/IVSmokeMultiVolumeRayMarch.usf`。本次按怪物局部雾团和项目预算独立实现解析球体截断及少量密度采样，没有复制该仓库的代码、插件或资产。翻卷烟雾图集复用项目已导入资源，密度纹理和后处理代码为本次原创。
