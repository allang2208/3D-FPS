# 硬直与眩晕分离

2026-09-26，按用户要求区分两种控制，并解决人形硬直长时间定格。

## 行为

- **破韧硬直**：削韧达到阈值后打断，仍使用既有 `ToughnessBreakSeconds` 与时长倍率；不设置眩晕标记，不进入 Dizzy。
- **明确眩晕**：闪电、感电过载、大旋风、陨星无法击飞时的回退，以及既有弹反规则。`ReceiveStun` / `AddStun` / `ReceiveParry` 才登记眩晕到期时间。重复眩晕取剩余较大值，不累加。
- **叠加控制**：破韧可以延长整体动作封锁，但不延长眩晕本身。眩晕结束即离开摇晃；若整体封锁还有剩余，动态 Idle 继续而 AI/攻击仍被控制。较短眩晕也不能把原硬直缩短。
- **击飞倒地**：由 Knockdown 状态独立管理，不再冒充 `bStunned`；倒地中的眩晕仍按既有规则延长倒地控制，不播放站立摇晃。
- **冻结/石化**：保持定格分支；不能因为改了动态硬直而让其身体继续卸力。非人形也从统一眩晕入口登记状态，但不新增人形摇晃资产。
- **普通枪击、状态 DOT、快速进战**：保留原规则；快速进战只推退及按伤害削韧，没有附加眩晕。清除了符文剑命中分支中相反的旧注释。

## 硬直动作

复用现有护士、胖子、突变体 3 和巫婆受击资产，不重做骨架或资产。`MonsterReactionTiming::StaggerSample` 仅重排采样时间：

1. 快速冲击段保留约 0.1～0.15 秒，短硬直按比例压缩。
2. 中段跳过源片段的静态保持，持续推进恢复段的前 45%，表现为身体逐渐卸力。
3. 最后至多 0.3 秒完成恢复，短硬直同步压缩；结束后恢复动态 Idle。

这次没有新增后撤步模板或循环摇摆，不在每帧重播受击，不改变胶囊位置、伤害窗口与控制时长。眩晕仍使用已有 Dizzy，冻结/石化保持固定受击姿态。弹反原有反向动作前段保留。

## 实现与性能

- `MonsterCombatComponent` 中 `ExplicitStunUntil` 使用世界游戏时间；由已有反应 Tick 更新标记，不新增 Tick、定时器、刚体、资源加载或逐帧组件扫描。
- `MonsterStunPresentation.cpp` 按真正的眩晕剩余时间进入、续接和退出摇晃。
- `NurseZombie.cpp`、`WitchMonster.cpp`、`FatZombieAnimInstance.cpp` 接入持续硬直采样；突变体复用 FatZombie 动画实例。
- `FinishReaction` 统一恢复人形动态状态，避免控制到期后继续卡住受击末帧。
