## 当前实现与巫婆的差异

| 环节 | 当前缚群代码事实 | 制作含义 |
| --- | --- | --- |
| 布料基础 | `BoundCongregateAuthoring.cpp` 已建立 `UWitchRebuiltClothingAsset`，复用有界显示捕获；V19 使用 4/6 次迭代、1 子步 | 不需要再发明求解器；复制同一机制不能解决裁片失配 |
| 披布形状 | V19 从固定中心按角度射线取身体外包络，加约 5.9 cm 基础余量并平滑；逐行限制半径收缩 | 外侧肉块可能把整片布撑开；这是一项根据构造方式提出的风险，未用新动态画面确认 |
| 褶皱 | 大披布使用规则正弦起伏；显示面仅 SIMPLE 细分 | 增加显示顶点不会自动产生受重力和承重点影响的自然褶皱 |
| 承重 | 整片披布统一 `body=0.35 / body_rear=0.65`，包括固定带 | 统一支撑可减少多足相互牵拉，但并未表达每个缝合位置与真实肉体的相对运动；固定区需按解剖局部重新制作 |
| 活动区 | 主披布最大移动 12 cm，袖口 1.8 cm；袖口只覆盖所在下肢的短区段 | 数值是失败候选的配置，不能当作推荐标准；形状不对时先改形状，再按裁片长度和空间定义活动区 |
| 衣内碰撞 | 仍由最大权重骨分组身体顶点、分象限并裁剪衣片包围盒，再拟合胶囊 | 已有局部裁剪，但融合肉体的骨权重不是完整的解剖分区；不能只把旧胶囊放大解决穿插 |
| 当前材质 | V8 材质已用 0.22 法线强度、0.94 固定粗糙度及织纹、磨边、污渍 | 不能把硬片感直接归因于强法线；材质优化应聚焦实际织纹尺度、细微粗糙度变化和褶皱阅读 |
| 巫婆布面 | Fabric09 统一母材质、UV0 微法线与粗糙度纹理，以物理面积计算重复尺度 | 可复用材质结构和织纹资源，保留缚群灰绿旧布及不同来源残衣的色差 |
| 顶点通道 | 巫婆用 Alpha 在两种织纹倍率间插值；缚群 Alpha 是 Anim Drive 遮罩，R 是活动距离、G/B 为磨损与污渍 | 不能直接套默认巫婆实例；不改布料通道语义。若复用该母材质，将两种织纹倍率设为同值，或以独立材质参数／UV承担尺度分区 |

## 推荐下一版：有重量的残袍

保留 V06 概念图的残衣身份、嘴部、背部肿块、多肢轮廓与触手根部开口，借鉴巫婆的布面连续性、垂坠和运动方式。无需把低矮宽体怪物整体包成落地长裙。

1. **先确定裁片和连接。** 背肩保留一块连续残袍主体，向两侧有限下垂；绕开嘴、触手根部和主要肢体摆动区域。与身体连接的肩背窄带按实际位置制作；自由衣摆不接受脚和触手攻击链的牵拉。两件残袖各随同侧肢体，保留可读的袖口和卷边，长度由实际关节空间决定。
2. **制作自然初始垂挂。** 从裁片和承重点进行离线重力垂布制作，保存静止形状，再加工不对称主褶皱。身体接触用平滑、按解剖分区的碰撞壳，避免逐个脓包拓印到布面。离线垂布属于模型制作，不是对游戏 Chaos 效果的验收结论。
3. **重建完整的破旧边缘。** 保留宽缓裂口、少量仍连接主体的垂条、局部翻折与缝线。主要体积由几何承担，细织纹进入表面材质；减少尖针、孤立三角片和等间距波纹，不对已有内外壳重复加厚。
4. **从成型衣物建立代理。** 每块连续活动衣片有明确固定区、过渡区、自由区；代理服务于最终垂挂形状。固定带按实际身体局部转移权重，自由披布沿所属承重点延续权重，不按整片统一比例或最大权重骨自动猜测所有连接。
5. **按衣片制作碰撞和动态范围。** 直接指定所覆盖的躯干肉块、邻近肢段与必要的近触手避让区域；胶囊按实际位置和骨局部单位制作。保留现有稳定捕获、距离暂停、有限求解预算。自由长度、最大位移和回拉强度应由新裁片决定，不直接搬巫婆的 45 cm 或失败 V19 的 12 cm。
6. **统一织物质感。** 复用巫婆 Fabric09 的哑光织纹结构，按缚群每片 UV 面积／实际面积设置重复尺度；增加轻微粗糙度变化，保留灰绿旧布、磨损、脏污及残袖色差。明确解决 Alpha 通道冲突，不改巫婆正式材质和资产。

## 制作与接入顺序

拟使用独立 `GarmentDrapeV20` 作者目录和新资产路径；这一名称仅为下一版预留，本轮未生成该资产。

- 从保留母版提取当前身体和骨架，在新场景中制作上述裁片、垂挂和表面，不沿用 V18/V19 的衣物几何作为成功模板。
- 同步输出可编辑源、显示网格、代理、UV／材质参数、解剖固定区和碰撞配方，继续复用现有导入和布料绑定入口。
- 新衣物拓扑需重做对应连续软体死亡嵌入，避免活体换衣后死亡回到旧衣或绑定错位。
- 完成实际导入保存后再更新原蓝图 VisualMesh；保留当前移动 120、源速度 50、加速度 300、制动 480、转向 50 度／秒、触手 CD 20 秒、120 度起手及 F 三次解缠合同。
- 按用户规则后台制作／必要构建／保存，不主动开启 UE、PIE、画面渲染、测试或验收；最后由用户体验。制作结果和实际效果分开报告。
