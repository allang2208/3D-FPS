# 百目炉渣：预测巨臂冲撞 ChargeV10

2026-10-01。用户要求冲锋加入现有代码的提前量计算，参考绿色巨手的冲刺设计，强化冲击反馈与专属动作。横扫、下劈及 V9 收势保留。

## 现状与设计

旧逻辑在开始攻击时取玩家当前位置，冲刺时仍以当前玩家位置的前向距离控制加速/停止；旧 SpecialCharge 只有低伏快速迈步，容易表现为加速追跑。V10 将“起手跟踪”与“锁定冲出”分开，使用独立四阶段动作和有限时长的角色移动源。

| 阶段 | 默认时间 / 参数 | 行为与表现 |
| --- | --- | --- |
| 选择 | 保持 300–600 cm 起手范围、5 秒冷却 | 共用 BT 的现有攻击入口，接地且未受位移控制才可选 |
| 蓄势 | 0.7 秒 | 低伏压重心、巨手后收再护于身前，三条支撑肢撑地；有限转速朝当前目标，脚边黑灰/余烬 |
| 起冲 | 标称 1000 cm/s，最长 0.85 秒 / 850 cm | 蓄势结束重新采样水平速度与接触时间，锁定预测方向；巨臂前顶，另外三肢快速推进，黑灰尾迹与余烬；全程直线、不再追踪转弯 |
| 首次接触 | 物攻 ×1.6、110 cm 击退、0.45 秒显式眩晕 | 掌部连续扫掠或原生胶囊阻挡触发；伤害实际生效且玩家存活才施加推退/眩晕；撞墙只播放反馈，不补伤害 |
| 碰撞回震 | 0.35 秒 | 立即撤销本次冲锋位移源，播放巨臂压缩、躯干反作用；地面冲击环、黑灰、余烬与炭化碎屑、共用撞击声及距离衰减短震屏 |
| 制动收势 | 0.65 秒 | 连续回到原待机臂链；落空、通道不可达、目标失效直接走收势；完成后交回现有 BT |

所有这些参数均为本轮制作的可调初值，不是已获用户认可的平衡值。默认物攻 42 时冲锋原始伤害为 67.2，最终伤害仍经过原防御、格挡、弹反与属性公式。没有将灰烬尾迹作为持续伤害区。

## 提前量与碰撞

直接参考 `FleshHandMonster.cpp::BuildChargeDirection`（同样源自 Mutant3 起跳重采样）：在蓄势结束时求解 `|相对位置 + 水平速度 × t| = 实际冲锋速度 × t + 双方胶囊半径和` 的最早正接触时间。时间不再包含已经过去的蓄势；实际速度包含当前减速倍率，预测强度默认 1，最大提前距离 260 cm。

先以玩家胶囊扫掠截断穿墙的预测，再按完整 / 半量 / 零提前量尝试至多三个候选，约束行程、可行走地面、75 cm 高差和冲撞胶囊直线通道。均不可用则取消起冲并收势。这些查询只在起冲前执行，不在冲刺过程中每帧预测。

原地动画只负责姿态。`FRootMotionSource_ConstantForce` 交由原有 `MonsterCharacterMovementComponent` 做原生扫掠、台阶、地面及悬崖处理；只取消自己持有的位移源。首次不可行走阻挡、掌部实际命中、位移停滞、最大时间/行程、失效或受控均停止冲刺。死亡、硬直、弹反保持原优先级；伤害回调内状态变化后立即退出，不追加眩晕、冲击动画或恢复攻击。

## 四条专属动画

`ChargeWindup` 0.7 秒、`ChargeRush` 0.4 秒循环、`ChargeImpact` 0.35 秒、`ChargeRecover` 0.65 秒，60 Hz 烘焙。巨臂几何坐标系与完整轴向偏移取自已认可的 V8 横扫第 20 帧（真实 Rampage Attack_Biped_Melee_A 的接触段），三条推进肢读取实际 Rampage Jog_Quad_Fwd 的骨点曲线。起势、护臂前顶、反作用回震及收势为本怪体型的专门编排，并非宣称原素材已有未改动的同款冲撞。

以当前 RampageRecoverV9 Blender 为母版，保持几何、权重、绑定、辅助骨及已保存横扫/下劈。固定上臂/前臂长度，运输完整肘平面；上臂、前臂、手腕与扭转辅助骨使用同一回位进度，不独立转腕拼接。手指只有现有的短爪骨，本轮为扣爪护掌，不宣称完整人类握拳。

导出仅包含四条新增原地动画。新 60 Hz Blender 副本对保留的 30 Hz 动作仅重排帧号，保留原来的秒制时长；已认可动作不重新导入。

## 性能与源码

- `HundredEyedSlagMonster.h/.cpp`：追加冲锋执行阶段及参数、加载四条专属动画、保留原 F6 原生类。
- `HundredEyedSlagCharge.cpp`：在已有角色 Tick 内推进冲锋，不新建常驻 AI 或组件 Tick。命中去重与伤害由服务器权威执行。
- `FPSImpactFXSlagCharge.cpp`：复用现有世界粒子池、四个冲击环槽、音频池及总量预算。蓄勢与尾迹节流，远距裁剪、池满丢弃装饰效果；不影响伤害、位移或控制。没有新增逐怪 Niagara、临时粒子 Actor、永久贴花、灯光、物理碎片。
- 击退复用 `UFleshHandPushComponent` 的有限距离碰撞扫掠；摄像机反馈复用现有 Mutant3 的短冲击震屏。
- 未扩展本怪原本的联机动画复制；本轮仍在现有服务器/单机执行架构内工作。
