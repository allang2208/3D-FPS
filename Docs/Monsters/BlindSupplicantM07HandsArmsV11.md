# M-07 OriginalV11：原手部、手臂模型与绑定修复

本轮响应手部尖刺、手肘扭曲和绑骨错误的反馈。以原 Meshy 表面及当前 V09/V10 母版为起点做局部修改，保留主体、原 UV、V09 六片鳃膜及 V10 大跨步时序。没有使用替代人体或重建整只怪物。

## 本轮排查得到的原因

- 原手指蹼部有不到 1 cm 的连接边，两端却分别几乎完全由不同指骨驱动。V07 对测地分区使用硬标签，使真实相连的指蹼在屈指时被拉成尖刺。
- 每只原手保留了一个小指旁的次级短分叉，产生第五根主手指之外的实体尖叉。
- 显示网格减面后的整数 `source_vertex_id` 被插值，不能继续作为原点权重索引。
- 旧十段动作残留无限制的腕部目标，右腕相对前臂中性姿态在待机超过 110°；攻击和恢复动作最高接近 150°。肘极向量逐帧独立求解，部分动作出现接近 100° 乃至 168° 的单帧平面翻转。
- 上臂局部 Y 轴与真实肩—肘方向相差约 88°。已有手指骨链及屈曲轴正确，未发现米级子骨平移、对侧手臂或腿/鳃骨大权重污染。

## 制作修改

原手指的远端保持独立，实际连接的掌骨、MCP 和指蹼采用软测地分区及连续过渡；肩、肘和腕按照自身关节位置重做局部权重。共用位置的 UV 副本采用相同权重。显示手臂从对应原高模三角形重心插值投射权重，最多保留八个影响，不再依赖减面插值后的原点编号。

实际修改 53,072 个原始顶点的权重；原范围内不足 1 cm、权重 L1 差异大于 1 的边由 610 条降为 0。制作后的高模和显示手部定向读取也没有该类硬切换。原腿部和鳃膜成员没有重做权重。

仅清理原手的小指次级短分叉并封闭局部切口，保留五根主要手指。上臂骨轴对齐真实肩肘，关节位置、骨名和父子结构保持一致；模型、布料构建源、碰撞和十二段动作共同导出到新 V11 参考骨架。腕部以跟随前臂的中性姿态为基准，限制残余弯曲和扭转；肘平面采用前一帧输运和连续变化，消除原硬翻转。V10 两段步态的周期、跨步长度和 90/145 cm/s 校准保留。

定向源数据读取中，两侧上臂轴误差为 0°，手臂/手指子骨动画平移为 0 cm；十二段动作最大腕部残余角约 16°，两段步态仍约 3.5°。攻击肘平面单帧变化从约 96–99° 降至约 13°；死亡和跌倒不再出现原 168° 翻转。切口采用原边界 UV 封面，现存原表面的 UV 保留。此结果仅说明本轮源数据修复，不等于实际 UE 表现已验收。
