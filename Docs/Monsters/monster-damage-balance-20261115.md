## 调整原则与隔离范围

- 保留玩家物品、技能 JSON、六维属性、生命、防御、移动与攻速公式；只转换怪物的伤害快照。实际装备和属性仍参与计算。
- 未知武器先取真实伤害的 55%，法术先折入真实装备增伤后取 45%，再按等级、武器/法术和完整命中次数进行平滑压缩。低于压缩拐点的数值不再压缩，高端武器仍保持单调差异。
- 压缩函数：上限 C、拐点 K=0.6C；D≤K 时不变，否则 K+(C-K)(D-K)/(C-K+D-K)。上限不是每次固定伤害，也不补高弱武器。
- 未知武器暴击伤害至多 +25%、弱点加伤至多 +10%；法术暴击伤害至多 +15%。物理/魔法穿透至多 20% / 15%。这些限制只作用于未知输出快照。
- 枪械保持原有 20% / 33% 命中率、无限备弹和换弹。自动枪单位时间原始伤害预算为 100 / 125 / 150，单发枪为 110 / 140 / 170；同时保留单发类型上限。霰弹全部弹丸共用整发预算。
- 双刀共用一轮两次命中的预算；冰刺共用整轮预算；穿心箭在技能倍增后再次压缩；元素箭额外伤害单独计入；箭雨是整次区域结算一次，不按 28 根表现箭重复计算。
- 龙息按完整持续时间和跳数分摊；暴风雪、风暴域、火甲与熔岩按跳伤间隔分配。雷枪预留满蓄力及感电增伤，感电每层至多 +2%，雷枪每层额外至多 +3%。
- 同一未知的燃烧只维持一层并刷新持续时间，不再被熔岩每半秒无限叠加；10 / 20 / 30 级每半秒最多 2 / 3 / 4 点。不同未知的燃烧仍独立，玩家施加的燃烧规则保留。
- 女巫施毒限制至 3 层；毒蛆、毒液僵尸、螺柱和沉匣毒气等怪物来源对玩家的毒限制至 4 层。玩家毒弹/附魔和已有更强的非怪物毒层不被降低。
