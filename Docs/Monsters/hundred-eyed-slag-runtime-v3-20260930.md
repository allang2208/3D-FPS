# 百目炉渣 RuntimeV3：游戏网格与四肢修复

用户反馈高面数、游戏卡顿及奔跑、攻击时四肢折叠扭曲。本次范围为该怪物的网格、蒙皮、动作、贴图、LOD 和物理资产。原 F6 ID、角色类、伤害与命中时序保留。

## 排查结果

- 游戏网格仍是 Meshy 原始 2,896,776 三角形 / 1,515,349 顶点高模；没有低面数游戏版本和远距离 LOD。V2 网格资产约 403 MiB。
- V2 仅重分足底，关节和上肢继续使用空间距离场，邻近肢体与躯干可能共同拉动皮肤。实际骨段没有断开，但 Run 右后腿最大弯折达到 148.3978 度。
- 旧 IK 没有完整最短可达距离与弯折角限制，投影参考肘膝方向接近奇点时不稳定；攻击仍引用 V1 片段，横扫末段目标跨过身体中线。
- 没有运行帧时间采样，不能把所有卡顿都归因于面数，也不能用减面比例换算 FPS。

## 已保存修订

- 游戏 LOD0 为 100,000 三角形；原高模独立保留。作者顶点 78,912，UE 渲染顶点 82,516，差异来自接缝口径。增加三档 LOD，远景目标为 LOD0 的 45% / 14%，屏幕尺寸门限 0.38 / 0.15；实际远景渲染顶点为 32,606 / 17,701。
- 按网格表面路径划分四肢解剖分支；UV 接缝在计算图中连接，不改 UV。上下肢按关节链弧长过渡，肩髋局部连接躯干，足底随脚掌刚性运动，最多四个骨骼影响。脚趾随脚掌，避免距离场将相邻足指拉扯到另一肢体。
- IK 采用 8–112 度弯折范围，保持真实骨长，参考弯曲平面通过平行输运保持方向连续。承重足有共同躯干高度可达区间；摆动目标不可达时限制目标，不拉长骨段。
- 奔跑改为 14/30 秒一周期、280 cm/s；缩短过长跨度，按速度和支撑时长匹配步幅。回程 20/30 秒、120 cm/s。重做横扫、砸击、冲锋、喷灰、受击、硬直、眩晕和死亡，共 16 条源动作；保留命中窗口及 0.42 秒布娃娃交接。
- 将原高模几何和原材质法线投射烘焙到游戏 UV，生成 2048² 法线，导入 UE 时转换绿通道。四张皮肤贴图运行上限 2048，启用普通 mip 流送，原始源图保留。原材质 Masks 采样修复保留。
- V1 与 PolishV2 两个网格均原位替换，历史摆放引用也不会继续加载原高模。19 个动画资产原位更新，包括兼容动作；全部预览网格指向游戏网格。16 个物理体 / 15 个关节按新权重重拟合。
- V2 网格资产现约 26.3 MiB，包含三档 LOD；F6 和原生 C++ 仍使用原路径，不需要重新构建 DLL。
