# 感染犬皮肤效果：2026-09-24 数据诊断

> 2026-09-25 整理：下文保留当时制作/诊断记录，旧路径不再表示现役入口。当前模型、动作、归档映射和恢复顺序见 [感染犬发布记录](InfectedDogPublication20260925.md)。

用户反馈绿色皮肤缺少皮肤质感，询问模型法线与蒙皮权重是否处理不当。本次读取作者文件、贴图、预览脚本及 UE 当前绑定，没有修改正式模型、材质、动作或玩法，也没有运行游戏或新增渲染。

## 已确认问题

1. **去毛流程丢失原自定义法线。** 原狼身体 3460 顶点、5679 三角面，带自定义法线；感染犬保留同一身体几何，但作者脚本显式清除自定义法线，只设置 smooth。原身体重合顶点位置的面角法线差超过 5° 的位置数为 0，感染犬为 514。由于 UV/原导入造成的拆点不会因 smooth 自动焊合，这会引入不连续受光。UE LOD0 当前 `recompute_normals=false`，继续使用导入法线；切线使用 MikkTSpace 重算。
2. **皮肤法线贴图缺少有效细节。** 用 BaseColor 非黑有效区排除 UV 背景后，共 1,899,600 个像素，其中约 97.6899% 的法线值与中性 `(128,128,255)` 各通道偏差不超过 1 字节。法线在 UE 已正确按 Normalmap/线性导入，并连接到材质；问题主要在烘焙内容，而不是未绑定或把法线当 sRGB。
3. **突变体皮肤没有完整迁移。** 当前只提取旧 Meshy 源图中约 4.9% × 5.1% UV 范围的颜色和粗糙度，再投射到全身。没有转移源皮肤 Normal，而是另用极浅的通用高度图烘焙；缺少按犬体结构制作的皱褶、拉伸纹理和部位差异。组织遮罩全为干皮肤，材质为共用 Default Lit，无真实皮肤散射。共用材质本身不说明这次贴图内容已经达到突变体效果。
4. **之前的动画对照预览不包含完整皮肤 PBR。** `preview_gallop_upgrade.py` 仅连接 BaseColor，将粗糙度固定为 0.54，未接入 Normal/ORM。因此不能把那份 Blender 动图作为 UE 皮肤材质评审结果。

## 权重与体型

按位置和骨名比较原狼身体与感染犬作者网格：3460 个保留顶点均找到相同原位置，权重没有变化；没有未绑定顶点，权重和最大误差约 2e-7，骨名一致。该结果支持“去毛没有改坏作者文件中的权重”，不能证明每种动作下都没有局部塌陷；本次没有对动态变形作结论。

当前身体就是原狼被毛下的几何，没有额外塑造无毛皮肤的肩胛、颈部褶皱、肘膝过渡。原被毛造型中的块面现在直接暴露；这与蒙皮权重是不同的问题。

## 修正顺序

先恢复原身体的连续自定义法线，按同一切线基底重新烘焙皮肤法线；接着补充适合犬体部位的中尺度皱褶、微细节与粗糙度变化，并明确鼻、爪、眼、口腔的材质语义。用完整材质检查静止造型后，才对确实存在的动态塌陷做局部权重修正。不能为了改善皮肤观感再次整体重绑或重定向已恢复的旧动作。

证据：`SourceAssets/InfectedDog20260924/SkinDiagnosis/geometry_weights.json`、`texture_statistics.json`、`ue_skin_binding.json`。读取工具为 `Tools/InfectedDog/inspect_skin_geometry.py` 与 `read_skin_material.py`。
