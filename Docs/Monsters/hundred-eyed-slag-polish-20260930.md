# 百目炉渣修订 V2

范围：游戏白模、快速奔跑、四肢接地与蒙皮、死亡到布娃娃的衔接。保留 Meshy 原模型、UV、37 骨 authoring hierarchy、既有攻击及眩晕动作。没有减面、重新生成模型或额外 API 费用。

## 已定位的问题

- V1 网格材质槽已绑定皮肤材质，但已编译材质报告使用贴图为零。直接原因是金属度和粗糙度为 `TC_MASKS` 压缩，节点却用 `SAMPLERTYPE_LINEAR_COLOR`：PCD3D_SM6 编译明确报采样类型应为 Masks，游戏使用默认材质。原脚本还未等待原生材质缓存与着色器编译。
- 追击只有 91 cm/s；原跑姿躯干几乎整块运动，步态为对角同步，脚掌回收速度在触地处不连续。
- 原四肢最低点混合躯干／上下肢权重，逐帧全身抬升补偿容易牵连承重脚。UE 骨名为 `front_palm_R`，伤害采样仍查 `front_palm.R`。
- 死亡动作 2.8 秒，按全局 60% 比例在 1.68 秒交物理，并清零所有刚体速度。旧动作的全身防穿地补偿最高 38.4 cm，抵消部分身体下落。自动物理资产未按这个异形骨架专门重做。

## 修订

- 创建独立 `PolishV2/Materials/M_HundredEyedSlag_Skin_V2`，金属度／粗糙度使用 `SAMPLERTYPE_MASKS`，同时连接四张原始 PBR 贴图到经典输出与 Substrate，完成原生编译、缓存更新和保存。后台需要 `-AllowCommandletRendering` 才会实际缓存用于渲染的着色器。V1 网格也绑定修复后的材质，兼容已经放置的旧网格实例。
- 新 V2 蒙皮仍为最多四个影响。重新分配 452,046 个下肢／足底顶点；足底稳定跟随脚掌，往上渐变回原关节权重。贴图、拓扑和静止骨架保留。
- 新奔跑 20/30 秒一周期，参考速度 280 cm/s；前后足分别承重、短暂腾空、低伏身形、胸部与骨盆分开起伏。脚掌承重时平放，回收采用连续速度 Hermite 轨迹。回程动作 1 秒周期，120 cm/s。运行时播放速率跟随真实速度，切换混合保留运动源相位。
- 新死亡动作 1 秒，先短促受击再失去右侧支撑；0.42 秒交物理，进入死亡时混合 0.12 秒。交接继承逐骨位置／旋转速度、部分移动速度及末次伤害方向。尸体只在低运动速度时进入休眠。
- 新物理资产由 16 个实际蒙皮区域拟合的碰撞体和 15 个关节组成。无细小手指刚体；脚掌包含指端。约 101.5 kg，不同部位不同质量，CCD、关节活动限制、原姿势相交体禁碰撞、适当阻尼。
- 修正大右掌伤害采样的 UE 骨名；F6 使用原怪物 ID 和原生类，新的默认网格及 Run/Move/Death 引用 V2。

## 本次编辑器异常

早期材质修复在正在运行 PIE 的编辑器中批量删除旧材质表达式，触发 `!IsRooted()` 断言，导致编辑器退出。加载后的材质在后台也会触发这个批量删除断言，因此最终直接修正现有采样节点，移除了批量删除调用。导入脚本在任何资产修改前拒绝活动游戏世界，使用现有桥的批次互斥后台导入，未主动关闭或启动交互式 UE 编辑器。
