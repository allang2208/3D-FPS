# 僵尸犬随机伤口 V4

2026-09-15：用户要求每只僵尸犬的伤口位置随机分布，保持既有精细皮肤、动作、攻击状态机和 AI。

2026-09-19 已继续制作 [伤口与残毛衔接 V5](ZombieDogRefinedWoundsV5.md)，使用四种独立图案、一处主伤与几处小伤、毛层对应身体定位及分层痂缘／血污。以下保留 V4 初版随机伤口的实现记录。

## 生成规则

`UZombieDogAppearanceComponent` 在角色构造和开始游戏时应用外观；仅在种子、数量或表面数据改变时重新计算分布。组件没有 Tick。普通狼的该组件默认关闭，僵尸犬蓝图开启。

1. `RandomSeed=0` 时选取一个正整数种子。生成前指定相同正整数种子和相同参数，可复现同一分布。运行中的犬保持已有布局；移动、攻击和布娃娃不重新抽取位置。
2. 从源网格皮肤表面提取 426 个可用三角形，记录休息姿态坐标、法线、面积和部位。以面积为权重抽取三角形，再用平方根重心坐标在面内均匀采样，避免网格密集区域获得不合理的额外概率。
3. 默认目标为随机 3～6 处伤口。最大容量 8 处，每个部位最多 2 处；最多尝试 192 次。若满足间距条件的位置不足，保留已生成的数量，不强行重叠凑数。
4. 躯干伤口半径为长轴 7～13 cm、短轴 3.5～7 cm；上段四肢为 4～7 cm、1.8～3 cm；颈部为 4～6.5 cm、2.5～4 cm。各伤口绕表面法线随机旋转，颜色混合强度为 0.72～1.0。
5. 两个伤口中心的距离至少为长半轴和的 0.85 倍。区域包含左右侧腹、左右肩、颈、背及左右上段四肢。采样范围和材质遮罩共同限制口鼻、眼周、脚掌、尾部与腹底的覆盖。

长短轴定义创面椭圆，另有较薄的法线轴限制穿透厚度，降低同一位置在身体另一侧形成对应伤口的可能。随机噪声轻微改变边缘轮廓和组织色差，脱毛区域略大于创面。断耳为真实几何缺口，其封口继续保留固定伤疤。

## 材质与骨骼

V3 的颜色、法线、脱毛与伤口原先合在烘焙贴图中。V4 从同一作者文件重新拆出干净毛皮色、精细皮肤色、两套切线法线和表面数据，去掉原先固定的身体创面。五张表面贴图为 4096，继续使用 V3 细皮肤参数。

独立的 2048 半浮点 EXR 在非镜像 UV 图集中记录休息姿态位置，单位为 cm，轴向为 X 左、Y 口鼻、Z 上。材质解码范围为最小值 `(-25,-115,-5)`、跨度 `(50,210,115)`。这张坐标图关闭 mip 并常驻，避免远处 mip 将不同 UV 岛的身体坐标混在一起。

伤口在该坐标图上计算，图集随模型蒙皮变形，因此不依赖角色当前世界位置，也不使用会滑动的世界空间贴花。皮肤颜色、干湿粗糙度、细节法线和残毛透明度使用同一伤口场。每只犬创建自己的动态材质实例，共享底层贴图。

## 使用和接入

- F6 继续选择“僵尸犬”，新生成个体自动选取种子。没有增加第二个僵尸犬菜单条目。
- 蓝图入口仍为 `/Game/Monsters/ZombieDog/V1/BP_ZombieDog`。新增资源集中在 `/Game/Monsters/ZombieDog/RandomWoundsV4`。
- `WoundAppearance` 组件提供 `RandomSeed`、`MinWounds`、`MaxWounds`。`RerollWounds` 蓝图函数／编辑器按钮会选取新种子并立即应用。
- V4 网格复制 V3 网格，仅重新分配材质；动画数据集复制切换前配置，仅替换参考网格。攻击窗口、行为树、数值和物理资产继续使用既有配置。
- 固定种子字段带 `SaveGame` 标记，但本次没有新增世界存档或多人同步协议。
