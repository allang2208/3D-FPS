# 巫婆衣物与投瓶修订（2026-09-22）

后续用户反馈的穿腿、死亡散落及近景细节修订见 [Refinement03](witch-refinement-20260922.md)。下文为上一轮历史记录，30 cm 衣摆、旧抓握及仅热编译状态不代表当前版本。

用户反馈：当前方向可用，步行和施法相对自然；衣物破碎、有脱离主体的布片，投瓶僵硬。本轮只改衣物、内衬、布料制作和投瓶。步行、举杖施法、待机、受击、死亡及转身动画资产没有重新导入；角色尺寸与业务攻击时钟不变。

## 发现与处理

| 问题 | 本轮处理 |
| --- | --- |
| 上袍与下袍在原重建源中分别有 13、12 个连通块，存在悬空碎片 | 从加厚前的源清理独立碎片、退化面与重合点，保留附着于主衣片的破边；最终两件外袍各为 1 个连通主体 |
| 原生成衣物已含折叠内外表面，再整体 Solidify 叠出第二层 | 取消这层加厚，使用不透明双面布料；外袍面数从 141,453 降到 68,184，保留原 UV |
| 垂袖低于腰部时按高度绑到骨盆；最近身体投射也会混入错误骨链 | 袖子按连续肩臂骨链赋权，肘、袖口平滑过渡并做邻接平滑；取消垂袖的骨盆高度锁定 |
| 外袍裂口、袖口出现成块皮肤和重叠闪烁 | 增加随人体蒙皮的深色内衬，只隐藏被内衬覆盖的渲染皮肤面；完整人体保留在 `Authoring/WitchRebuilt_AnatomySource.blend`，手、脚、颈部仍有原皮肤 |
| 旧外袍法线与明暗使破边显得像硬质碎块 | 独立 `M_WitchRebuilt_Fabric` 保留原颜色，法线强度降至 0.4，粗糙度映射到 0.65–0.9；原巫婆材质不改 |
| 模拟代理沿原破边采样会产生尖点，三角面朝内 | 平滑角向与纵向半径，翻正朝外面序；重新提取 `WitchRebuilt_WaistDrapePolish02` 并绑定最终显示网格 |
| 衣摆活动范围偏大 | 腰部固定带 6 cm，最大位移 30 cm，加强阻尼与回归蒙皮驱动；仍为单层活动下袍，内衬不做第二套布料模拟 |
| 旧投瓶 IK 对够不到的轨迹直接平移手骨，拉长前臂 | 重做短距离前抛：可达范围内的手轨迹、固定骨段、肩部带动、肘部伸展、轻微腕部收势与分指释放 |
| 制作场景中的护士脸部 morph Basis 仍保留原厘米坐标 | 从颈以下人体输入中清除无用面部 shape keys 后再进行适配，避免可编辑源的蒙皮显示被旧 Basis 覆盖 |

投瓶参考已实际查看原 `Reference/Original/attacking-2.png`，共 18 帧，原合同为 1.5 秒、0.75 秒脱手。新动作是按原短距离前抛意图重新编排的 3D 动作，不是直接复用动捕，也不是大幅棒球式后摆。左手保持原握杖姿态；投瓶源改为 60 fps、91 个采样，脱手与伤害仍由既有时钟驱动。

## 本次检查范围与结果

- Blender 几何连通性：上袍 1 个主体、下袍 1 个主体；保留正常破边。
- 右臂骨段在整段动作中的长度变化：旧版最大 **28.5823 cm**，新版最大 **0.0000464 cm**（数值精度量级）。新旧首尾手部位置差均为 0。新版相对参考姿态仍有约 0.6808 cm 的固定差异，来自保留的待机基础姿态，不是投掷中的拉伸。
- 已制作正面、背面和关键投掷姿态对比，以及带毒瓶的手部动作 GIF。预览不模拟 UE Chaos、法杖装配和弹道，不代替实机结论。
- UE 读回：活动布料为 `WitchRebuilt_WaistDrapePolish02`，投瓶长度 1.5 秒，导入采样率 60；衣物/内衬材质、模型、投瓶和布料已保存。
- 定性读图使用项目 DeepSeek 原生图片通道。问题限定为“是否有脱离主体布片及衣物连续性”；前图指出腰侧孤立碎片，后图未指出悬浮片。读图仅辅助，几何计数与骨段数据来自源文件计算。
