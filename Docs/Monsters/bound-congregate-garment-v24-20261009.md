# 缚群 V24：改为服装覆盖结构

2026-10-09，用户提供 V23 游戏截图，反馈「依旧穿模，我觉得你方向错了」。图中主布中部和下缘有多处肉块穿出，外观仍不合格。V23 的保存与同位置绑定成功不能作为解决问题的证据。

## 调整方向

此前将大面积贴身表面全部交给 Chaos，只固定一行缝口，并保留衣物下完整凸起肉面。近距离拟合、背挡、少量胶囊只能近似接触，不能保证两套不同变形的复杂表面始终分离。继续加碰撞和扩大布面会在穿模与悬浮之间反复。

V24 改为服装覆盖结构：贴身主体随身体蒙皮；仅末端破边参与布料模拟；当前衣物内部、由固定主体持续覆盖的身体面从该版本穿衣网格中裁去。完整身体母版继续保留。此为结构重制，不使用透明身体材质、深度偏移或运行时遮盖。

## 制作内容

- 贴身主体保留原身体的真实局部权重，不再把小抓肢、脚端等权重折叠到祖先骨而与底层身体产生不同变形。自由边沿用相邻固定缝口的支撑，不继续吸附下方活动肢体。
- 主布 1525 个源顶点直接随蒙皮、488 个末端顶点参与模拟；两只袖子各 416 个随蒙皮、128 个末端顶点参与模拟。源代理点数保持 3101，但大部分为固定点；未作运行性能测试，不据此报告帧率收益。
- 衣内裁切仅作用于固定布面内部，距固定区边界留至少 3 cm 的表面覆盖余量，并限制衣物与对应身体的蒙皮权重差；不会因为另一条活动肢体恰好靠近就裁去它。
- 作者回执记录从本版穿衣身体中移除 9507 个被覆盖的面，保留 188671 个面。裁切原面索引保存在 `covered_body_faces.json`；原始 `GarmentRebuildV19` 及 V23 资产完整保留。
- 固定区外还有独立的过渡／下摆。主布末端最大活动量 2.2 cm，袖口 1.5 cm；制作时给末端增加相应几何余量。显示／模拟仍共用点位与三角面，沿用巫婆 Fabric09 材质。
- 使用当前原蓝图，只更换衣物模型引用。FlurryV22 连拍、V17 撕咬、触手和战斗数值不改。身体表面发生裁切，匹配连续软体死亡模型和嵌入需同步重建。
