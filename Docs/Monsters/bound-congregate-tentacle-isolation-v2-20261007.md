# 缚群触手分离修复 V2

> 历史阶段记录。2026-10-08 用户否定整体衣物并暂停；V18、V19 均未获认可。当前状态、最新参数和已归档证据的取回位置以[暂停与发布记录](bound-congregate-paused-publication-20261008.md)为准。

2026-10-07 后续反馈：用户仍看到粗触手根部截断，且要求先向后蓄力再向前甩出。V2 的视觉效果未获认可；本记录保留历史制作与检查信息，后续修改见 [连续根部与后撤甩击 V3](bound-congregate-tentacle-whip-v3-20261007.md)。

用户反馈触手攻击牵动整只怪物，要求重新排查与调整。本轮只排查缚群的触手表面、蒙皮和攻击变形，不启动编辑器窗口、玩家地图或 PIE。

## 直接原因

- 原 `curl_00..05 → feeler_00..06` 共享蒙皮未与主体分区。153072 个源显示顶点中，51152 个受到这条链超过 0.001 的影响，33718 个超过 0.05；额头、嘴边和背部均有明显污染。V1 的长距离甩击放大了此前小幅摆动不易发现的问题。
- 原骨链以近似空间点布置，细触手部分与真实中心线偏离，包含了嘴边的皮肉。
- 原生成表面在嘴唇附近把细触手和主体焊接起来。仅清理权重会在这段连接处拉丝，必须拆开并补齐两侧表面。
- V1 在解算之后混合组件空间位置，会在中间权重下缩短弯曲骨链；每节独立求最短旋转也缺少连续扭转方向。

## 修改

从原表面按解剖区域分离 14672 个三角面，形成独立 `BC_AttackTentacle` 网格和材质 section；继续使用原皮肉贴图。保留原来游离的触手外表面，对根部封口和嘴旁焊接背面补面。原焊接短段按邻近真实截面收整，并向外留出约 3 cm 的间隙，避免分离后仍携带嘴唇表面的多余薄片。嘴边主体另行补齐，源主体已有的微小退化边不作为本次修复成果。根部原表面法线保留，避免内侧封口使外表面出现明显接缝。

新增专用 `attack_tentacle_00..56` 骨链，依据原表面截面中心重新布置。主体、十条肢体、衣物及其模拟代理全部移除旧 curl/feeler 影响，不赋予新攻击链权重。触手根部接缝固定到 body，在近端逐渐释放变形；原 56 骨骼和 RigV3 的七段动作仍保留。

攻击控制仅作用于新链，固定近端根部段。轨迹以完整骨链长度拟合宽弧，避免短轨迹把剩余长度挤成小折皱；沿链传递连续旋转，在父骨局部空间混合旋转并正向求位置，过渡期间也保留骨段长度。缠绕根据剩余实际链长调整圈弧，随拉近继续合拢，环绕半径放到目标胶囊外侧。命中采样同步改用真实新链末端。原攻击伤害、阶段时间与拖动玩法保留。

局部混合从上一帧实际姿势持续跟随目标，避免每帧重新选择“参考姿势到目标姿势”的最短旋转分支。按帧时约束所有链节点的位移，蓄力、挥出和收回分别采用有界速度；不只限制末端目标而放任中间骨段翻转。

原四块衣物继续使用原几何、材质、活动距离和 backstop，重新生成新网格的绑定映射。模型表面与顶点布局改变后，重新制作匹配的连续软体尸体资源。扩大触手展开所需的网格显示边界，不更改脚底下界。
