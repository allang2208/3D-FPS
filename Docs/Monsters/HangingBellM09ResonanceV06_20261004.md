# 悬钟 M-09：第一攻击「三叠鸣震」V06

2026-10-04。用户已反馈 V05 能成功生成和移动；本次继续制作第一招，不改变认可的天花板生成、握点适配和移动。V04 其余攻击仍为原型，本阶段自动战斗只使用三叠鸣震。

## 动作与战斗

| 时间（秒） | 表现与行为 |
| --- | --- |
| 0–0.60 | 上层背膜向身体外侧展开，小臂抱紧发声组织，躯干绷紧 |
| 0.30–0.82 | 中层背膜展开，左右相差约0.025秒，保留有机感 |
| 0.52–1.04 | 下层背膜展开，组成三层发声结构 |
| 0.80 | 固定发声原点和方向，之后不追踪玩家 |
| 1.10 / 1.45 / 1.80 | 上／中／下层分别压缩、弹震，释放三次独立脉冲 |
| 2.00–2.80 | 三层错时收拢，躯干和小手平缓回到待机姿态 |

- 双大手全程保留现有天花板 IK 支撑；无根位移，无体型缩放，不新增飞行或落地行为。
- 每片背膜保留原有四段骨链及蒙皮。末端约7.5 Hz的阻尼弹震由根部向末端延迟传播，最大额外摆角约2.8°。骨链的向外展开方向按原骨骼坐标修正，避免原型向身体中线卷入。
- 动画60 FPS、2.8秒、169个采样点，原创编排；不复用或覆盖待机、移动、死亡等片段。
- 每段伤害为0.30倍最终魔攻；默认魔攻38时每段基础11.4，仍经过项目防御／状态结算。范围6米、全角100°，每人每段最多一次。
- 命中附带0.45秒的15%减速；冷却8秒（从起手计），收势后至少0.55秒公共恢复。
- 命中点、锥形范围、实体遮挡均使用同一锁定发声原点到玩家上半身的关系。第三方移动掩体也会在每次脉冲时重新遮挡。
- 失衡或死亡切换状态时停止声音和波纹，取消余下伤害；沿用既有受击和支撑丢失行为。

## 声音与特效

原创本地合成音效包含膜片绷紧声、三次逐渐升高的低频鸣声及阻尼尾音。单声道48 kHz，三次起音与攻击时钟一致，无第三方音频采样。迟到的网络状态按当前动作时间起播。

声波为三条柔边球面环带组成的轻量静态网格，正轴为发射方向；每次脉冲向6米边界快速展开并在0.26秒内淡出。波纹是命中时的视觉余波，伤害在对应脉冲时刻即时结算。所有环带位于100°、6米的范围内，不再使用原型超过射程的放大平面圆环。

半透明加色材质带边缘羽化和场景深度交接，复用三个现有组件和初始化时创建的动态材质。运行时无新Actor生成、无资源加载、无额外全场景扫描。

## 接入和使用

- F6 → 悬钟 M-09（天花板），可继续使用已认可的主神空间有顶区域或 `m09.TestRoom`。
- 新实例的自动战斗先只使用三叠鸣震。玩家进入6米范围并被发现、双手完成抓握且冷却结束时可起手。
- 单独播放可用 `m09.AI 0` 后输入 `m09.Attack Resonance`；恢复追踪输入 `m09.AI 1`。攻击仍要求能看到玩家。
- 当前没有启动游戏、PIE、预览、渲染或自测；动作、打击反馈与平衡由用户体验。
