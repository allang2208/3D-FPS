# 合阙前踢：冲击节奏与 AOE V03

用户认可 V02 踢足球式的动作姿态，本次只强化节奏、重量反馈和范围命中。保留 V02 的承重、后摆、前踢、屈曲收腿、落脚路径；通过独立时间映射重排各阶段，烘焙成原生 120 fps 动画，不依赖整段 PlayRate。

| 时间 | 动作 |
| --- | --- |
| 0–0.36 秒 | 右侧撑稳，重心转移 |
| 0.36–1.26 秒 | 缓慢抬脚、屈曲后摆 |
| 1.26–1.48 秒 | 蓄到位短暂停顿，缝心、铁链仍有轻微滞后 |
| 1.48–1.66 秒 | 0.18 秒快速甩出；先启动上段，再猛然伸开下段 |
| 1.66–1.90 秒 | 急停、顺势摆过和回弹 |
| 1.90–3.16 秒 | 屈曲收回、重脚落地 |
| 3.16–3.60 秒 | 落脚下沉、恢复平衡 |

缝心和铁链按真实经过时间单独编排，避免跟随腿部的时间压缩而一同瞬间弹动。原创音效包含蓄势摩擦、迅速增强的破风、伸展低频重音、链条尾响和收势落脚声；中断时停止，通过攻击序号和服务器时钟同步。
