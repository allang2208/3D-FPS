# 人形死亡布娃娃交接修正

2026-09-26。用户反馈死亡后身体瞬间扭曲，随后像漏气一样飞向空中。本次修改 `UHumanoidKnockdownComponent`，覆盖使用共用组件的护士、胖子、突变体 3 和巫婆。以下原因来自源码定位，尚未进行游戏复现或视觉、性能测试。

## 源码问题与修改

1. **膝肘关节缩放丢失**。UE 5.8 的 `InstantiatePhysicsAsset_Internal` 会根据刚体导入缩放调整连接点，`CreateJoint_AssumesLocked` 再应用组件缩放。但运行时 `FConstraintInstance::SetRefFrame` 直接把传入坐标写给 Chaos。旧 `TunePhysics` 在关节已经建立后重新传入参考骨架的逆缩放坐标，同时旋转铰链中心 55°，丢失原有缩放处理。现在保留 Physics Asset 实例化后的四肢和躯干连接点、朝向及角度范围，移除这套运行时重建。
2. **辅助根骨与死亡姿态不一致**。胖子/突变体的 `FatZombieRoot` / `Mutant3Root` 是不碰撞的容器刚体，资产里与骨盆锁定。参考站姿连接关系不能直接锁住已经下沉、转动的动画骨盆。首次接管时，仅为这两个辅助根关节按当前刚体世界姿态重新建立连接关系，使用不含缩放的刚体厘米坐标；已经处于物理击飞时不重建。
3. **动画与物理交接次序**。在启用模拟前，以 `TeleportPhysics` + `DisallowDeferral` 把当前组件空间骨骼姿态同步给刚体；随后设置碰撞、质量、阻尼、约束和重力，再开启物理、清除残留力和力矩。辅助根在第一步模拟之前就关闭碰撞。
4. **初始速度互相冲突**。旧死亡流程逐骨采样并施加独立线速度、角速度，辅助根和骨盆可能同时收到不兼容的速度。普通动画死亡现在只采样骨盆的有限下落速度，整身一致，不继承向上的动画校正或各骨骼的独立旋转。活体击飞继续保留翻转，各刚体质心线速度补上统一角速度的 `ω × r`，形成一致的初始运动；已在物理击飞中死亡仍接续原运动。
5. **地面纠偏注入能量**。关闭关节 Projection，避免瞬移纠偏与地面接触反复争抢；穿透修正速度从 160 降到 80 cm/s。仍使用现有正常约束求解，不通过空中超时冻结掩盖问题。

- 姿态同步、辅助根连接和初始速度只在接管时处理，不增加逐帧骨骼修正，也不增加每步求解次数。
- 保留 8 个活跃角色、128 个刚体、4 个新尸体准入的世界预算；保留落地稳定后快照定姿、释放模拟与布料计算的流程。这些是数量约束，尚无本轮帧耗时数据。
