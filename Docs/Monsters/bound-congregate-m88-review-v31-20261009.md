# 缚群 M-88：V31 回查与命名

用户明确要求回查问题／遗漏并更名。本次范围为源码、现有蓝图引用与数值、缠绕及解除状态；不启动 PIE，不渲染，不将后台检查称为视觉或完整联机验收。

## 发现与修正

1. **名称入口分散**：F6 生成目录与 `MonsterCombatComponent::GetVitals` 各自保存旧名称。两处及缠绕状态描述统一为「缚群 M-88」。保留稳定 ID `BoundCongregate`、原 C++ 类型和蓝图路径，既有引用继续有效。
2. **触手命中错误回落到主体**：原 `IsTentacleHit` 同时判断部位身份、活动状态、生命和服务端骨段距离。触手刚被打断或联机报数抵达时位置已经变化，返回 false 后会进入正常主体伤害。现在分别处理部位身份与有效受弹接触；过期或不成立的部位命中不扣主体生命。
3. **独立触手生命仍触发主体附加效果**：弹道、直接射线、穿透和副手堵枪口命中后的外层中毒回调只接收 Actor，遗漏触手部位。新增接收完整 Hit 的回调，并将四类枪械路径接入；共享伤害入口对触手提前分流，避免触手命中触发主体碎弹／近战放电等后续逻辑。主体的原受伤规则保持原状。
4. **硬直期间解除会跳回触手待机形态**：之前为了保留硬直而跳过 TentacleRecover 状态，动画随即失去活动标记。新增独立复制的回收起始时间，硬直和撕咬可以继续占用身体状态，触手沿实际末帧按原曲线回收；结束捕获时保留实际缠绕权重。
5. **硬直下仍自动朝目标转身／客户端表现可被待机覆盖**：Tick 的硬直分支此前仅在到期时接管，其余帧可落入转向分支；保持缠绕时表现选择还会先命中触手待机分支。现为完整硬直分支，并让受击表现优先。
6. **空手没有挣脱入口**：F 入口会回落到未装备的枪械快速近战，空拳接触又明确排除了缠绕处理。被缠时 F 复用现有空拳动作，其真实接触和武器快速近战一样计入三次挣脱。
7. **无碎弹附魔的霰弹枪／机枪无法扣触手生命**：原判别仅覆盖步枪、手枪和有碎弹速度快照的武器，漏掉独立精通分类。补上霰弹枪／机枪精通判别，并纳入触手生命检查。
