# 非人形怪物连续软体死亡标准

2026-10-05，用户指定以螺柱 M-14 当前 V19 死亡方式推广到其他非人形怪物，后续同类制作沿用。人形及类人双足角色暂不应用。用户指定此制作方向，不代表本批推广已通过游戏测试。

## 本次范围

毒蛆、手脑、异变巨手、小皮肤手、野狼、僵尸犬、感染犬、伏窥者 M-08、悬钟 M-09、沉匣 M-10、涡电匣 M-25、螳螂 M-27。M-14 保留 V19 专用代理及 V20 战斗范围。

**M-数字系列属异形类（非人形）**，后续新增 M-编号怪物默认归入本标准范围，按各模型制作独立代理；人形特征的 M 编号成员例外单列。盲祷者 M-07 为类人形＋异形双标签（见 [怪物分类](monster-taxonomy-20261006.md)）：管理归异形类，死亡仍维持人形方式、不适用本标准。

护士、胖子、毒液僵尸、突变体-3、巫婆、盲祷者 M-07、百目炉渣维持既有人形／类人死亡方式。本次不改变其资产或死亡入口。

## 制作合同

- 复用 M-14 V19 连续 XPBD 求解、无回弹接触、内部耗散和伸长限制。每种模型单独制作代理和正重心权重，不能复用 M-14 的几何、骨骼编号或空间尺寸。
- 致命伤时捕获当前姿势，取消原死亡动画与旧刚体对表面的双重驱动；使用同一连续代理驱动完整尸体。尸体仍按原寿命回收，击杀奖励、攻击取消、死亡状态复制沿用。
- 金属／附件与主体共用连续绑定，需要硬度时加强局部边，不用跨身体的长拴接或独立变换混合制造拉丝。未来专用模型仍可提供不同加强区域。
- 主体表面、UV 和材质保留。手脑历史网格包含 `arm_mount`／`fan_mount` 两套重叠的攻击替身；只在新尸体副本剔除这两套原死亡动作本就隐藏的表面，保留活体源。
- 尸体使用独立骨架、网格、数据与材质。材质重建变形后的法线，保留 PBR 图和参数；运行时复制皮肤及随机伤口参数。源骨架与活体动作不重绑。
- 通用制作代理不超过 700 个点，复用原 120 Hz 固定子步与每帧最多六步、共享尸体准入预算。组件只在死亡计算期间更新，稳定后停止；未进行性能测试。
- 悬挂／攀爬角色死亡也进入重力下落，不继续固定在天花板／墙面；不把空中停止作为落地完成。
- 新尸体目前只保留重绑后的 LOD0，避免切回旧骨架权重的 LOD；活体 LOD 不变。后续需要尸体 LOD 时须为每级制作匹配权重。

## 公共接入

`UMonsterCorpseRagdollComponent::TryStartSoftDeath` 从实际活体网格的 `UMonsterSoftCorpseBinding` 读取已烘焙数据。网格携带硬引用，既支持蓝图角色，也支持原生类与共用网格的变体；死亡时不读制作文件、不在线生成网格。

新增非人形角色必须在死亡表现入口、且在播放旧死亡片段之前调用 `TryStartSoftDeath(GetMesh())`。返回 true 后由组件接管更新，角色仍完成原有攻击取消、奖励和尸体寿命设置。复制死亡状态到客户端时调用同一入口。制作源缺失时保留原死亡降级流程，不将其计为已接入软体。

工具顺序：

1. 后台完成 `FPSGAME` 与 `FPSGAMEEditor` 原生构建。
2. 无界面运行 `Tools/MonsterSoftCorpse/prepare_sources.py`，读取正式类引用，生成尸体副本并导出源表面。
3. 外部 Python 运行 `author_cages.py`，为每个实际网格制作连续四面体代理与表面权重。
4. 无界面运行 `install_corpses.py`，保存尸体网格、骨架、数据、材质，并将数据引用写入正式活体网格的附加元数据。

新增物种时扩展 `prepare_sources.py` 的目标类表，或按同一流程制作自己的代理；现有同网格变体复用绑定。不能只添加默认开关或脚本而不保存实际资产。

同一批次续接使用已经导出的原表面；修改源模型后应新建制作版本与目标目录，不用旧回执代表新源数据。中断于资产保存阶段时直接续跑 `install_corpses.py`。

## M-14 嘴部弱点

之前只有 `maw` 碰撞体，统一弱点函数没有识别它。本次将 `maw` 及其子骨加入 `ColdSteelSkills::IsCriticalHit`，限定 M-14 自身网格，供现有枪械、近战和法术直击共用。按既有弱点必暴与属性公式结算，不额外叠乘一遍伤害；致命命中后的反馈仍能识别口器。
