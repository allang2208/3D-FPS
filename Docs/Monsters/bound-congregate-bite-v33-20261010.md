# 缚群 M-88：撕咬起手与接触范围 V33

## 用户反馈与定位

用户反馈多次撕咬没有命中，要求排查触发时机和判定距离并优化。本次只读实际蓝图、当前 V28 压缩动画及相关运行代码，未启动游戏或渲染。

- 实际蓝图为起手中心距 350 cm、嘴部延伸 156.25 cm、接触 0.56 s。
- 实际压缩动画在 0.56 s 的嘴骨前探约 137.29 cm；玩家胶囊半径为 42 cm。正前方实际极限约 335.5 cm，比起手距离短约 14.5 cm。35 度边缘还会缩短；旧起手条件可以接受实际接触范围以外的目标。
- 原代码只在 0.56 s 检查一次，并在距离检查之前就消耗本次接触，即使目标随后进入仍在咬合的嘴部也不会再次判定。
- 原代码在 0.42 s 提前停止跟随朝向，而动作仍蓄力至 0.48 s。现在对齐实际快咬开始时刻，发力后继续锁定方向，可被侧向躲避。

原始读取在制作目录 `BiteV33/before-pose.json`；按实际胶囊与压缩动画计算的距离在 `range-diagnosis.json`。这些属于距离／时间定位，不等于实机碰撞或动画验收。

## 修订

- `BiteReach`：156.25→235 cm；`BiteTriggerRange` 保持 350 cm。正前方接触范围约 414 cm，给起手后的目标位移留下余量，不再次扩大起手造成相同缺口。
- 咬合窗口：0.54～0.65 s，跟随实际咬合与前探保持段；只在这个短窗口内重试漏空接触。低帧跨越窗口末端时可采样末端一次，长卡顿不追补过期攻击。
- 合法命中、格挡或被冰墙截住后消耗本次接触；范围外漏空不提前消耗。一咬仍只造成一次伤害、三层流血和五秒致残。
- 原生默认值与实际蓝图同步为 350 / 235 / 0.56，避免原生派生使用旧 280 / 120 / 0.92。
- 保留 V28 动画、认可拍击、V29 触手与衣物、V32 死亡、一次 F 挣脱及其他数值。

`read_bite_v33.py` 只读当前压缩动画和属性；`diagnose_bite_v33.py` 生成距离定位记录；`save_bite_v33.py` 幂等保存本次三个属性；`build_bite_v33.ps1` 常规构建 Editor/Game 并后台保存。

Editor 与 Game 常规构建均为 `Result: Succeeded`，记录位于 `BiteV33/build-FPSGAMEEditor.log` 和 `build-FPSGAME.log`。后台保存命令退出码 0，`delivery.json` 为 `saved: true`，原蓝图实际保存 350 / 235 / 0.56；保留当前模型、撕咬及拍击片段引用。保存前蓝图包备份位于 `BiteV33/before/`。

原有编辑器在接入期间退出，后续使用后台构建与保存，未主动重开编辑器。未进行游戏试玩、联机检查或画面验收；当前结论限于源码、实际压缩动画读取、距离计算、原生构建与蓝图保存。
