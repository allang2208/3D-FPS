# 怪物主动发现、受击发现与群体预警（2026-10-12）

## 本轮规则

用户要求将发现拆成主动发现和受击被动发现。两条路径确认玩家后，共用同一锁敌、局部预警和行为树追击入口。

| 项目 | 当前实现 |
| --- | --- |
| 主动发现距离 | 使用各怪物原有 `AggroRadius`，普通职员所继承的 Nurse 原生默认 1200 cm；保留各蓝图与特殊物种配置，不将所有物种强改成 12 米 |
| 主动发现条件 | 活玩家在真实三维距离范围内，满足朝向及该物种的可见性规则；普通怪物用视线遮挡判断，M07/M08/M09/M27 保留专有视线查询 |
| 视野 | 普通物种沿用半角 100°；M08/M25 沿用全向感知。只有确认前限制朝向，确认后转身不立即丢失玩家 |
| 首次受击发现 | 尚未确认玩家时，从首个有效玩家攻击开始随机等待 1～2 秒；期间停止游荡与寻路，保留原受击、硬直、死亡表现 |
| 连续受击 | 不刷新首次受击截止时间；已在战斗中的怪物不重复进入延迟。延迟期间缓存的视觉消息不提前跳过计时；附近同伴的明确预警仍可直接使其参战 |
| 延迟结束 | 活着且 AI 启用时确认攻击者，接入与主动发现相同的锁敌和群体预警入口。攻击者死亡或失效则取消；怪物死亡后不广播 |
| 群体预警 | 以发现者为球心、默认半径 1200 cm，通知范围内同主题区域的存活、启用 AI 的怪物；上下层按真实空间距离计入，不逐个要求与发现者之间无遮挡 |
| 传播限制 | 接收者直接确认同一玩家，不再次广播；已有存活战斗目标时保持原目标。每个发现者广播冷却默认 5 秒，仅新确认目标请求广播 |
| 目标记忆 | 默认 12 秒，M08 保留至少 30 秒。确认期间追击点跟随玩家当前位置；重新看见玩家或再次受到该玩家攻击刷新记忆。超过记忆时限后回到原有回巢／游荡流程 |
| 攻击约束 | 锁敌不绕过视线、射程、高差、攻击冷却、硬直和死亡约束；保留原有阻路冰墙攻击分支 |

听觉提供枪声／技能声音的调查点，不直接确认玩家或广播。调查点使用声音发生位置，枪声转为脚底导航高度；不会仅凭声音持续追踪玩家坐标。被墙遮挡且距离超过听觉范围 35% 的声音忽略，声音调查记忆为 6 秒；调查途中真实看见玩家后走主动发现路径。受击等待期间不插入声音调查。

## 与大厅区域的关系

`FacilityHallEncounter` 生成怪物时调用 `SetEncounterArea`，只绑定两厅共用的 `DungeonThemeEncounter`，移除原有每次更新给全部怪物强设玩家目标的行为。玩家进厅仍统一封住三个推进出口；未发现玩家的怪物保持半速游荡。

主动／被动确认后的局部预警可以跨越两厅内部连接处，前提是同区域且真实距离在 12 米内；不能仅因同属一个大区域就全员参战。默认无区域身份的野外怪物只与同为无区域身份的怪物互相预警。

确认后的追击双方都在两厅内部时，不被普通出生点牵引半径打断；记忆仍会失效。每厅两波、每波 12～15、严格过半击杀后补第二波、两厅全清后开三个铁栅门保持原规则。

## 参数与性能

`AMonsterAIController` 的 `MonsterAI|Alert` 暴露 `GroupAlertRadius`、`GroupAlertCooldown`、`PassiveDiscoveryDelayMin/Max`，供不同怪物蓝图配置；主动距离仍在物种的 `AggroRadius`，不新增第二份易冲突的索敌距离。

- 继续使用现有行为树 0.1 秒知识服务推进延迟和记忆；延迟执行精度约为该服务间隔，不新增每只怪物的决策 Tick 或独立计时器。
- 新确认时进行一次 Pawn 空间重叠查询、去重接收者；不遍历整关卡怪物，不为每个接收者追加视线射线。
- 所有发现者合计每游戏帧最多执行两次群体广播；未取得预算的请求留至后续服务更新。接收者不转播，阻止即时递归扩散。
- 保留已有导航节流、游荡预算、物种专用运动与攻击时钟。不以这些约束宣称已测得帧率收益。
