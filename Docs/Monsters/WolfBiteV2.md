# 狼普通咬击 V2：重心前送与前肢承重

2026-09-15，用户同意沿用当前普通咬击，吸收旧 Godot 狼的重心前送、肩颈配合与前肢动作。此次制作新动画副本并替换 `AttackBite` 槽，不改变普通咬击的战斗时钟。

## 动作设计

参考上一轮已查看的旧 Quaternius `Attack` 连续帧：前肢回收、前躯蓄力，再伸颈向前攻击。旧 Godot 的 2.5 倍速及 0.25 秒后提前切回移动不迁移。UE 源 `A_QP_Wolf_AttackBite` 作为基础，保留原有咬合、头部侧咬、尾部和收势关键帧关系。

- **蓄力**：源时间约 0.10 s，躯干比源姿态后收 2.5 cm、降低 1 cm；左前爪轻抬，右前爪继续支撑。
- **咬出**：0.233–0.300 s 躯干比源姿态前送最多 8 cm、降低最多 2.5 cm；肩部轻微前压，颈部稍后跟进。头颈横向甩动做适度收敛，让力的方向更朝向目标。
- **前肢承重**：左前爪在起势最多抬高 3 cm，向前落下 4 cm，在接触期保持支撑；收势时再次轻抬并收回。右前爪和后足以源足端位置作为约束目标。
- **收势**：重心回到源站姿，首尾姿态保留源帧。普通咬击不加入整只狼腾空或 Actor 冲刺，与大幅扑咬区分。

以上位移是动画在胶囊内的局部重心变化，不是 Character 位移。所有关键点及肩颈角度在 `SourceAssets/WolfMonster/BiteV2/motion_parameters.json` 中可编辑；数值为此次动作设计值，尚未经用户试玩调整。

## 蒙皮与支撑处理

本次保留 Skeleton、网格和蒙皮。通过组件空间的旋转修正肩颈，前腿使用两段 IK，后腿使用保留 `HorseLink` 的三段 FABRIK，离线求解后烘焙到普通骨骼关键帧。保持骨段长度与源脚掌朝向，不通过拉长肢体来追脚底。源容器 `root` 不动，重心位移写到其下的 `Wolf_`。

支撑约束是制作方法，不是已经通过游戏接地验收的结论。没有运行新动画预览、游戏、自动检查或测试，脚底、肩颈及接触表现由用户试玩确认。
