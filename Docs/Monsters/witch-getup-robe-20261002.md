# 巫婆击飞到起身的裙身与腿部衔接

用户明确指出的是双脚穿出裙摆／身体，主要问题不是脚穿地。

## 修改

- 原活体长裙在击飞、倒地和起身时仍独立运行布料；此前连接腿部权重的网格仅在死亡时切换。现在巫婆进入击飞控制后，临时复用已保存的 `SK_WitchRebuilt_CorpseFollow`，让长裙、内衬、完整腿部皮肤和双脚由同一姿态驱动。
- 切换发生在控制与预算准入之后、物理交接之前。保留进入时的骨骼快照、网格世界变换和活体身份引用；重复击飞不重新切换网格。整个控制阶段停止独立布料。
- 起身仍播放原有仰卧／俯卧标准动画，速率与控制时钟保留。巫婆动画代理新增 `FWitchRecoveryLegNode`，在最终姿态混合后、脚部目标复制前修正腿链：按该骨架的腿长和髋宽约束脚与膝的位置，限制双腿交叉、向躯干内收和不适合长袍的侧向张开；以两段 IK 保留腿长和原脚部旋转。
- 修正沿原快照混合权重逐步启用，第一帧仍接续实际倒地姿态；躯干、手臂和标准起身主体不重做。不在动画工作线程查询世界、布料或蒙皮顶点。
- 击飞／倒地／起身的控制姿态停用站立步幅、锁脚与二次腿 IK，避免零时间求姿态时仍沿用击飞前的 Walking 脚印，把快照腿部拉扯到裙身之外。站姿恢复后重新启用普通脚部图。
- 两次网格切换都重新创建巫婆动画实例，再恢复保存姿态，清除旧站姿的锁脚缓存；同动画类直接赋值会保留旧实例，不能代替这个交接。
- 标准起身及站姿过渡完成后，保留当时姿态切回原活体网格与动画代理，恢复原碰撞。布料在恢复站姿处重置，沿现有 0.35 秒淡入恢复，避免使用击飞前的旧布料位置。
- 控制中死亡直接保留连体网格并进入原尸体路径，不再恢复活体网格。本次没有修改已保存的死亡接地处理、枪击硬直规则和其他怪物的起身动画。

## 落盘范围

修改 `WitchRebuiltMonster.h/.cpp`、`WitchRebuiltAnimInstance.cpp`、`HumanoidKnockdownComponent.cpp`；新增 `WitchRecoveryLegNode.h/.cpp`。原模型、布料和标准动作资产保留，本次无需资产重新导入。
