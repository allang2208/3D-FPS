## 动作与战斗合同

| 阶段 | 默认设置 | 行为 |
| --- | --- | --- |
| 选择 | 目标在 450–1100 cm、可见且同层；角色接地、未受控且冷却完成 | 在共用 BT 的原攻击入口选择；近距离优先 GrandSlam / Slam，Hammer 已停用 |
| 蓄力 | 1.2 秒；起手立即进入 12 秒冷却 | 停止导航，蓄力期间朝目标转身；结束时重新读取目标速度，计算提前量并锁定冲锋方向；四指依次握紧，拇指最后从外侧横扣；脚下橙色环表示蓄力，不是伤害范围 |
| 冲锋 | 1100 cm/s，最长 1200 cm / 约 1.09 秒 | 保持闭拳，沿锁定方向直线推进；减速影响实际速度，不延长最长冲锋时间，不追踪转弯 |
| 命中 | 首次不可行走的阻挡接触 | 命中存活玩家造成物攻 ×3 的近战伤害，伤害实际生效且玩家存活后施加 2 秒显式眩晕；一次冲锋只结算一次 |
| 收势 | 0.7 秒 | 制动，先松拇指再逐指展开，恢复直立待机，交回 BT 重新决策 |

默认物攻 60 时，冲锋原始伤害为 180，最终扣血仍由原防御、格挡和弹反流程决定。没有把眩晕混成韧性硬直；状态通过 `UCombatStatusFormula::AddStun` 接入。

墙体、其他阻挡物、位移停滞 0.15 秒、行程结束或目标失效结束冲锋；受击硬直、恐惧、眩晕、冻结、石化与死亡沿原抢占入口取消攻击，束缚也会终止冲锋。伤害回调内被弹反/控制/击杀后立即退出，不补眩晕、不恢复旧攻击状态。移除冲锋自己的位移源，不清除别的技能位移。冲锋结束后不会补算一次落空伤害。

按用户要求参考 `Mutant3Feral.cpp::BuildPounceVelocity`：在蓄力结束、真正冲出前采样玩家当前水平速度，预测中不再加入已过去的 1.2 秒蓄力时间。蓄力期间以最高 540°/s 朝目标转身；冲出时一次性锁定预测方向，此后仍是直线冲锋。

突变体使用固定飞行时长，巨手使用固定冲锋速度，因此巨手按 `|相对位置 + 目标水平速度 × t| = 实际冲锋速度 × t + 双方胶囊半径和` 求最早正接触时间，并将时间限制在剩余冲锋时限内。减速后的实际速度参与计算。默认预测强度 1，最大提前距离 450 cm；两项均在蓝图 `FleshHand|Charge` 中可调。

沿用突变体的目标胶囊扫掠，截断穿墙的目标预测。按完整、半量、零提前量至多尝试三个候选，分别约束可达行程、可走落点、高差和巨手直线胶囊通道；全部不可用则取消冲出、转入收势后交回行为树。预测仅在冲出前计算一次，最多一次目标扫掠及三组地面/通道查询；不在冲锋过程中持续重算或追踪转弯。配置保存回执为 `Charge/prediction_installation.json`，本轮同样未进行运行测试。

## 握拳制作

参考工程技能 `ue5-fps-arms-animation/references/pose-contact.md` 和 `vertical-grip-family.md`：先确定掌面、四指包裹与拇指对握，再按各指 MCP / PIP / DIP 增量弯曲；不跨骨架复制 Euler 角，不平移指骨，不缩放骨长。

本怪实际掌面为 Blender `+Y`。作者脚本从本地绑定方向计算各指屈曲轴，使用实际蒙皮权重的指腹表面点与掌面目标，在关节角范围和姿态约束内拟合四指；无名指、小指加入少量掌骨内扣。拇指使用本怪三段骨链的语义方向横扣在拳外。按逐指闭合、拇指后扣和反向释放烘焙为 60 Hz 原地动画，保留原网格、UV、权重、骨架及 LOD。

作者输出：`SourceAssets/FleshHand20260926/Charge/FleshHand_Charge.blend` 与三条 `A_FleshHand_Charge*.fbx`；关节角与制作参数记录于同目录 `authoring.json`。原有八条动作与掌心副拳不被这次制作覆盖。
