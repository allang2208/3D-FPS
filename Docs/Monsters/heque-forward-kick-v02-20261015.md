# 合阙偏身碾扫：正前方踢击 V02

按用户反馈重制原偏身碾扫。旧版本以右脚为轴、整侧躯体转动约 110 度，用户认为僵硬。本版参考踢足球的发力次序，保留右脚承重，让左侧先屈曲后摆，然后上段带动、下段延迟伸展，朝角色正前方大幅踢出。

源模型前方为 -Y，UE 角色前方为 +X。支撑脚固定；上方拱体只做小幅开合转动与承重倾斜，不再带整侧身体大幅横扫。前踢在略向中线靠拢后沿前方展开，缝心和铁链滞后回摆。曲线在中间姿态保留速度，只有方向反转处停顿。

| 时间 | 动作 |
| --- | --- |
| 0–0.32 秒 | 重心移向右侧支撑，屈曲承重 |
| 0.32–1.10 秒 | 左侧折起后摆，脚掌收向后方 |
| 1.10–1.36 秒 | 上段先前摆，下段快速甩出，脚背绷紧 |
| 1.36–1.55 秒 | 正前方大幅延伸，顺势前摆 |
| 1.55–2.70 秒 | 屈曲收回，沿独立回收轨迹落脚 |
| 2.70–3.20 秒 | 落脚承重，下沉后复位 |

实际伤害只取 1.25–1.55 秒已向前甩出的阶段，后摆蓄力和收脚不带伤害。这个窗口位于原生 1.10–1.55 秒时段内，且总时长仍为 3.20 秒，因此无需修改 C++ 动作时钟或完整重编译。重新绑定踢击侧脚部／下段的真实蒙皮表面，导入时通过 UE 实际骨骼姿态生成接触帧。原攻击伤害、击退、冷却、起手距离和其他两招的配置保持现状。
