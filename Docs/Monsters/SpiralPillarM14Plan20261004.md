## 造型约定与设计推断

保留原画的高瘦肉柱、交织而非机械螺纹的粗肉束、顶部收束、真实贯穿孔、浅肉色湿润表面与蓝色细血管。左右各一个垂坠囊体；它们由组织膜和束缚链连接，不改成人类手臂或飞行翅膀。口器只有正面下腹这一处，背面无第二张嘴。M-14 铭牌位于前侧，后侧是金属束带。

原画标注高度 3.0 m，作为制作初始尺度。横向占地、体厚、口腔深度、螺旋肉束在遮挡处的连续路径，以及链条在后侧的固定位置，均需在三维制作时明确；三视图不证明这些尺寸已经准确。侧背遮挡结构属于设计补全。

中性姿态维持根裙接地、柱身直立、薄膜自然下垂、口器微张。模型统一厘米，UE 朝前 +X、向右 +Y、向上 +Z，根原点设在地面支撑区域中心。换视图只旋转观察方向，不移动囊体或链条来人为展示隐藏结构。

## 初始拆分设计与 V01 取舍

下表保留初始设计意图。V01 采用现有 Meshy 表面制作分区和骨骼驱动，未逐颗重建牙齿、逐节重建锁链或重新刻字。材质为 Body、Mouth、Membrane、Metal 四组；未增加新厚度贴图、布料模拟、独立滴液或断肢机制。实际完成范围以交付记录为准。

拆分是为了建模、材质和动作控制，不默认增加断肢、破坏、掉落或独立生命值。制作对象数也不等于运行时组件数；优先共用一套专用骨架。

| 制作分组 | 拆分边界与连接 | 制作和驱动计划 |
| --- | --- | --- |
| 主体肉柱与落地根裙 | 顶部、主要螺旋肉束、下部支撑根须保留同一连续组织关系；雕刻时可分对象，交汇处和主要支撑过渡须连续 | 沿用用户提供的 Meshy 高模，本地整理必要的贯穿孔及关节拓扑；专用柱体和支撑骨驱动。每条肉束不单独做刚体 |
| 口唇与口腔 | 口唇、齿龈连接主体；深喉可独立制作，但连接藏在连续口腔内部 | 制作有深度的口腔和闭合状态；使用径向开合控制，不能靠替换另一张嘴完成变形 |
| 牙列 | 与软组织分开建模；按齿龈扇区成组附着 | Blender 制作真实牙齿体积。齿龈变形、牙齿保持硬质形状；运行时合批，不给每颗牙新增组件或刚体 |
| 左右薄膜 | 左、右分别独立，固定边贴合主体、囊体和链条附着位置；主孔洞保留真实几何 | 本地制作连续膜面及稳定连接环。固定边不参与自由摆动；自由边预留少量骨骼摆动或后续受限布料，不把整片膜完全放开 |
| 左右囊体 | 左、右分别为有厚度的独立软组织，囊颈与膜面有明确封闭连接 | 骨骼控制摆动、压缩和回弹，复用主体骨架；不按单层布片处理，也不与膜面同时重复模拟 |
| 束带与铭牌 | 金属束带、正面铭牌、扣件为独立硬表面对象 | Blender 精确建模并制作可读的 M-14 字样；绑定稳定锚点，限制附近主体收缩，避免束带随肉体橡皮化 |
| 锁链 | 各条链独立制作，链端明确连接到金属扣与组织支点 | 制作链节，再合为少量蒙皮链组；近距需要时才启用受限摆动，不默认逐链节刚体 |
| 黏液与滴落 | 少量挂液随组织表面；游离滴液不并入主体固定几何 | 后续作为可选材质与有界特效处理，不以透明大面覆盖整只怪物 |

**不拆开的重点：**主柱与根裙的承力组织、口唇到主体的连接、薄膜固定边。将这些部位简单切断后分别蒙皮，容易在扭转和咬击时出现可见裂缝。

## 模型制作路线

1. 定稿轮廓与器官位置。独立正、侧、背图已按用户要求裁切并统一画布，保留原像素比例及方向记录。后续模型生成前再处理前景；当前尚未送入三维生成节点。
2. 主体沿用当前用户提供的 Meshy 模型，停止计划中的重新生成步骤。薄膜、穿孔、牙列、锁链、铭牌及连接位置按实际模型逐处定义，原模型中已有的有效结构直接保留。
3. 源 GLB 和可编辑 Blender 母版已保存。后续在独立修订中处理拆分和必要的局部结构补全；不重新调用生成服务，不产生本轮云端生成费用。
4. 按实际轮廓完成动画拓扑、UV 和材质分区。后续面数按近景占比、同屏数量和变形需求分配，不预先为凑数损伤根须、口器和孔洞；当前百万面高模完整保留，尚未制定或执行游戏网格减面。
5. 材质分为肉体、薄膜、牙齿和旧金属。保留可独立调节的粗糙度、法线、组织厚度表现及血管分区；湿润感不靠全身镜面高光，完整 PBR 不能只交一张颜色图。

## 专用骨架与动作建议

这是一只非人形软组织怪物，计划从零制作专用骨架。主链控制柱体弯曲和有限扭转，基底骨链控制支撑根须，径向口器控制负责开合，左右囊体和链组单独控制。薄膜的固定边继承实际连接部位，避免跨左右或跨远端的权重牵拉。

以下是本次提出的动作设计，原画没有提供动作或战斗设定：

| 动作 | 建议表现 | 需要在制作时记录的约定 |
| --- | --- | --- |
| 待机 | 肉柱缓慢蠕动呼吸，囊体略微错时起伏，链条随牵拉轻动 | 支撑根须保持接地，区分呼吸与移动 |
| 缓慢移动 | 根裙分区交替抓地和拖拽，柱体小幅倾斜后跟进 | 首版采用原地循环配移动速度；重心跟随支撑，不套人形走路 |
| 转向 | 根须分区换支撑，柱体逐步转向 | 不让整片根裙在地面连续打滑 |
| 主攻击 | 柱体先收紧蓄力，下腹口器前探咬击，再回收 | 明确预警、出击、接触与收势，以秒记录命中窗口；命中从口器实际运动位置结算 |
| 受击 | 受击侧肉束局部收缩，囊体延迟摆动 | 保留地面支撑，不让整体像木杆平移 |
| 死亡 | 失去张力后向受力方向折叠，根裙松弛，囊体落地 | 优先专用倒塌动画；是否接有限物理在接入阶段决定，不套人形死亡骨架 |

囊体可为以后喷吐或压缩攻击预留变形控制，但当前不确定其毒性、爆炸、破坏或掉落机制，也不据此增做器官。首版主攻击先聚焦口器咬击；具体技能、属性、移速、攻击距离和时长待玩法阶段再定。
