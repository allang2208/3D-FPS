# 感染犬：飞扑预判、攻击判定与寻路索敌

用户已确认 GodotRunNaturalV3 奔跑基本成功，可作为四足犬科模板。本次沿用该动作、MeshyV2 模型与 41 骨绑定，参照突变体 3 的狩猎逻辑优化感染犬攻击和 AI；不替换动画，不改变伤害、六维或感染三阶段规则。

## 行为与时序

| 行为 | 进入和目标来源 | 执行及退出 |
| --- | --- | --- |
| 追击 / 调查 | 现有视觉、听觉、受伤和群体警报提供目标或最后位置 | BT 负责选路；到有效咬击位置后停步，丢失视线只调查最后位置 |
| 普通咬击 | 活目标、无遮挡、目标胶囊进入咬击距离、冷却完成 | 前摇内限速转向，少量移动提前量；接触窗口开始后锁定方向，每次最多一次命中 |
| 飞扑 | 距离 260–600 cm、冷却完成、地面和飞扑路线可用 | 决策时评估，起跳前重算目标移动提前量；起跳后锁定路线，落地 / 碰撞 / 打断结束位移 |
| 恢复 / 受控 / 死亡 | 沿用现有动作状态和优先级 | 恢复结束交回 BT；受控或死亡立即取消后续攻击判定，弹反回调不继续伤害 |
| 返回 | 目标失效或 12 秒记忆耗尽 | 沿可用导航返回，恢复原有归巢处理；持续看见或记得活目标时不被旧出生点牵引距离强制拉回 |

## 飞扑提前量

起跳时读取目标的当前位置与水平速度，提前量为速度 × 实际移动时长 × 强度。当前移动源时间 0.10–0.50 秒，预测 0.40 秒，不重复加入已经过去的 0.30 秒额外前摇。

强度默认 1，水平提前量上限 260 cm。目标是 Character 时，以目标自身胶囊及碰撞响应截短会穿墙的预测。按完整提前量、半提前量、当前位置最多尝试三个落点；每个落点必须有可行走地面、高差不超过 90 cm，并通过 16 段犬体胶囊路线扫掠。

落点在预计目标前方留出 85 cm 距离，并至少保留双方胶囊半径之和加 4 cm。位移使用原动作同一权威时钟、原有弧高和碰撞移动，增加落点高度插值。起跳后不追踪玩家变向；起跳前路线失效会取消该次起跳，短恢复后继续决策，飞扑重试间隔最多保留 0.75 秒。

## 普通与飞扑命中

启用狩猎配置后，不再要求嘴部单点进入 30 cm 小球。范围按犬体中心至目标胶囊表面计算，胶囊边缘接触扇形两侧也算进入，仍保留背后躲避空间、垂直限制和遮挡条件。

| 配置 | 数值 |
| --- | --- |
| 普通咬击起手 | 原 BiteTriggerRange，默认 155 cm，改按目标胶囊表面距离 |
| 普通咬击接触 | 起手距离加 20 cm，前方 130° |
| 飞扑接触 | 190 cm，前方 130° |
| 脚底高度差限制 | 90 cm |
| 前摇朝向更新 | 最大 540°/秒；普通咬击最多预测 0.20 秒 / 65 cm |

接触仍使用动作数据集原区间：普通咬击 [0.20, 0.3667) 秒，飞扑 [0.3333, 0.5333) 秒。大帧跨越窗口时，沿接触区间与带碰撞位移分步判定，最多 16 段；不新增 Notify 或第二套伤害定时器。每次攻击最多结算一次，只有现有伤害入口实际扣血后才附加感染。普通 / 飞扑冷却仍为 1.25 / 4 秒。

## 寻路和索敌

复用突变体 3 的 NavigateFeralTo，增加显式启用的犬科适配。沿用 0.65 秒寻路间隔；正在移动却低于 25 cm/s 时允许重新规划，不因目标位置未变永久沿用受阻路径。必要时寻找目标周围八个可攻击站位，要求完整路径、有效攻击高度、无遮挡与首段胶囊通行，降低重复选择刚才受阻终点的优先级。

停步使用与咬击一致的胶囊表面距离、脚底高度及视线条件。动画追击状态取实际导航请求结果。视觉重获读取现有感知缓存，已经发现的目标采用现有 LoseSightRadius 维持跟踪，听觉 / 受伤记忆与死亡释放继续共用原系统。不增加每帧全场扫描，不复制行为树。
