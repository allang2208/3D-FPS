# 百目炉渣 HeroHandV4：大右手与躯干协调

用户要求针对奔跑、普通横扫和抬手重击重新调整大右手的表现及形变，并参考技能中已有的四足、长臂和全身动作经验。

## 制作调整

V3 已有骨盆、脊柱、胸部、背壳与前板骨骼，但目标动作把它们作为同一个刚体驱动；旧重击手掌目标只抬升约 29 cm。这次使用现有躯干骨骼分段驱动重心、扭腰、胸部发力和背壳滞后，增加的骨骼集中用于大右臂的皮肤变形。

- 增加右肩胛、上臂扭转、两段前臂扭转、肘支撑和腕支撑，共六根变形骨。保留原骨骼父子关系和参考姿态，作者骨架由 37 根增至 43 根，变形骨由 33 根增至 39 根。
- 右臂局部权重从原上臂、前臂和掌骨转移给新辅助骨，肘腕使用局部过渡，肩胛区域连接胸部。启用原有五根指爪骨的轻度收爪，承重时掌底维持接触姿态；每顶点仍最多四个骨骼影响。
- 奔跑加入肩胛前后运动、躯干反向协调、右掌离地与外摆，背壳稍后跟随。右前肢支撑比例提高到 48%，回程为 62%，足底后移速度继续匹配 280 / 120 cm/s 的原有移动速度。
- 普通攻击先向外侧后方蓄力，随后带动胸部横扫，最后收回承重位置；扩大右掌横向与前向轨迹。
- 重击先后移重心、抬胸和肩胛，大幅抬起右掌，短暂停顿后前移重心下砸，接触后回收。作者骨骼目标中右掌骨最高约 117 cm，起始约 16.5 cm。此数值是制作轨迹，不是游戏画面验收结果。
- 保持原骨长、连续弯曲平面和四元数方向。大右肘允许在抬手时弯曲至 128 度，其他三肢仍采用原范围；辅助骨分摊扭转和关节形变，角度限制本身不代表皮肤表现已验收。

制作范围为 Move、Run、AttackSweep_R、AttackSlam_R。其余十二条动作沿用 V3 轨迹，并加入新辅助骨的同步关键帧，使整个动画集与新骨架一致。

## 接入与预算

安装使用既有互斥批次，后台 commandlet 保存两份网格、公共骨架、两份物理资产和十九个动画资产。路径仍为 `/Game/Monsters/HundredEyedSlag/V1` 与 `PolishV2`；F6 的 `HundredEyedSlag`、原生角色类和引用无需修改或重新构建 DLL。

后台入口使用 `-nullrhi -multiprocess`。UE 的平台 SDK 查询会调用带文件锁的 `Build.bat`，可能等待现有编译；此处的资产导入跳过该 SDK 查询。新增骨骼也会使旧动画在导入进程内自动标记为待保存，后台独占进程按任务范围继续重导这些动画；编辑器内的未保存资产保护仍保留。

沿用 V3 的 100,000 三角形游戏表面、UV、高模烘焙法线、2K 贴图运行预算和三档 LOD。新权重对应的远景 LOD 重新生成；物理体按新权重重新拟合，沿用原有主骨骼物理链。

普通横扫仍为 1.4 秒，命中窗口 0.54–0.73 秒；重击为 1.8 秒，命中窗口 0.84–1.00 秒。其他攻击时序及死亡 0.42 秒转布娃娃保持原合同。

## 文件与状态

源目录：`SourceAssets/HundredEyedSlagMeshy20260930/HeroHandV4`。

- `HundredEyedSlag_HeroHandV4.blend`：可编辑游戏表面、骨架、权重与十六条动作。
- `Delivery`：新带骨模型 FBX 和十六个动画 FBX。
- `author_hero_hand.py`、`skin_weights.npz`、`animation_contract.json`：制作逻辑、权重和动作合同。
- `authoring_receipt.json`：制作过程记录的轨迹范围；不代表运行时或表面形变测试。
- `mesh_installation.json`、`animation_installation.json`、`installation_complete.json`：以实际生成的保存记录为准；缺少完成记录时安装仍待完成。
- `Before`：本次涉及的 UE 资产原始备份。
- `Rebuild.ps1`：默认制作并后台安装；`-Stage Authoring` 只导出，`-Stage Install` 安装已有导出。依赖保留的 V3 游戏表面与烘焙材质。

本次未运行游戏、PIE、截图或新增预览渲染。动作自然度、皮肤形变、地形接触与实际战斗由用户试玩确认。没有重新调用 Meshy。
