# 合阙：蓄力跃砸 V01

2026-10-15。接入原 `BP_HeQue` 和 F6 的 `HeQue` 条目。

## 动作与节奏

- 下蹲蓄力 1.50 秒：缓慢压低承重、短暂憋住，最后快速蹬地伸展。
- 原地垂直跃起，无遮挡时升高约 140 cm；双脚收起，悬心和铁链滞后摆动。
- 接近最高点时切换下砸姿势，向下速度设为 900 cm/s，随后仍受正常重力和碰撞约束。
- 实际落地触发砸地声、局部爆尘和环形尘浪。落地收势 2.60 秒，包含迅速压缩、回弹、停顿和缓慢撑起。
- 使用原骨架、原蒙皮及四段 120 fps 动画；角色升降由 CharacterMovement 驱动，不在动画根骨中叠加高度。

## 战斗参数

| 项目 | 数值 / 行为 |
|---|---|
| 使用距离 | 目标水平距离不超过 600 cm，脚底高度差不超过 100 cm |
| 冷却 | 14 秒，从蓄力开始计算 |
| 头顶空间 | 选择招式和起跳前各做一次胶囊上扫；根据空间降低跳高，可用高度不足 70 cm 时放弃起跳 |
| 中心重砸 | 半径 220 cm，75 点物理伤害 |
| 外围冲击波 | 0.85 秒内扩散至半径 700 cm，45 点物理伤害 |
| 外圈跳避 | 以玩家脚底相对落地平面的高度判定，波带高度为正负 65 cm |
| 重复命中 | 中心与外圈共享命中集合，每名玩家每次施放最多受伤一次 |
| 遮挡 | 沿用场景遮挡查询；墙体、完整楼板等阻断伤害，玩家彼此不充当掩体 |
| 攻击结束 | 收势完成后恢复行动，其他招式额外留 0.4 秒间隔 |

此次为物理跳砸，不附加悬心恸鸣的恐惧效果。起跳位置保持不变，不在空中追踪玩家。

服务端控制阶段、实际起跳、下砸、落地和伤害。阶段序号、起始时间、落点与地面法线复制给客户端。客户端按阶段时间播放动画、音效和扩散特效；不存在按固定动画时刻在半空提前触发的落地爆炸。受控、受击中断和死亡沿用合阙公共取消入口。腾空超时则取消攻击并保留正常重力落地。

## 特效与声音

两个预分配网格组件分别承担圆形前沿和局部落地爆尘。前沿扩散时保持约 55 cm 宽、46 cm 高，使用连续流动噪声和侵蚀消散；启动时限制宽度以避免内圈翻折。组件沿实际地面法线摆放，保持深度遮挡，边缘使用 DepthFade。复用已保存的 `T_HeQue_PsychicFlowV02` 流动纹理。外圈完成后 0.25 秒淡出，局部爆尘约 0.72 秒消散。

三条原创合成音源分别承担蓄力、起跳/下砸风声、砸地/链条/收势。起跳和落地声音跟随实际运动阶段；本轮未试听。
