## 实施方案

1. 原始 GLB 原样归档至 Source 目录，记录 SHA-256；下载目录原件未改。
2. 提取原位置、UV、法线、三角形和同位置点索引。编号用于跨 UV 缝确定表面连接，不将 UV 分裂当成组织边界。
3. 保护躯干、四臂、眼冠与肩背根带，在原表面上使用多点主脉引导、沿网格边的距离和折面代价区分六片背叶。左右与层数都有独立身份，不按固定高度横切。
4. 腹前小手沿各自跨身方向的解剖引导划分；大手指段沿弯曲指路划分，保留固定钩形的原表面。
5. 每个新切口从原边缘向内延伸闭合面；主要眼表面另补后侧体积。所有原表面三角形继续存在，新补面单独标记。
6. 只对自由背叶、小手及大手指段作有界位移，并保留固定接点编辑分组。
7. 打包原贴图到 Blender 源，导出完整装配 GLB 与 FBX。新文件保持 25 个独立命名制作对象，不替换 UE 正式资源。

这是一版按原表面划分的制作候选。分件配方中明确不宣称已经完成并验收的精确解剖切割；没有自动将整只怪物改成可动画游戏低模。

## 实际调整幅度

统一把 GLTF 原高度约 1.900409 单位映射到 2.8 米，整体比例因子约 1.473367。Blender 采用米、Z 向上、前方 -Y；GLB 通过正常 Y-up 导出。所有部件使用同一变换，不对个别部件重复乘 100。

下表是制作位移的最大值，已经换算到 2.8 米角色尺度，不是视觉测量或无穿模证明。

| 区域 | 原表面最大位移 |
| --- | ---: |
| 身体／根带 | 0 cm |
| 上层背叶 L1 / R1 | 1.92 cm |
| 中层背叶 L2 / R2 | 0.61 cm |
| 下层背叶 L3 / R3 | 1.36 cm |

小臂位移从原附着部逐渐进入自由部分，不整体移动肩根。左右采用不同前向位移，用于让原交叉动作具备前后区分，仍保留原交叠轮廓方向。

V02 的背叶固定区域只来自真实上方附着带，不将叶片之间新切开的长边一并固定。新切口边缘各自补面，后续可独立展开；叶片根部仍保持共同装配位置。V01 的全部共享边固定分组仅作过程留存，不作为本次交付依据。
