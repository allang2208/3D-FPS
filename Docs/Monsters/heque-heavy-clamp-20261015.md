# 合阙重夹 V01

在现有合阙骨架和蒙皮上增加第三招：两足撑稳、两侧肉壁缓慢外张和下沉，突然前压合夹。夹完后低伏停住，再吃力撑开和抬起。缝心与独立铁链滞后摆动，不增加肢体。

| 时间 | 动作与玩法 |
| --- | --- |
| 0–0.30 秒 | 小幅外撑落足，开始承重 |
| 0.30–1.50 秒 | 缓慢下沉、外张蓄势，末段短暂停住 |
| 1.50–1.70 秒 | 快速前压合夹，两侧向内汇合 |
| 1.50–1.75 秒 | 唯一伤害窗口，双方肉壁实际蒙皮表面扫掠 |
| 1.75–2.55 秒 | 压低、回弹后停顿，无伤害 |
| 2.55–4.20 秒 | 慢慢撑开、抬回，无伤害 |

夹空后有 2.45 秒完整收势窗口；命中也不缩短收势。整个动作锁住朝向并占用行动，不追踪侧闪目标，不因目标离开而切换碾扫或压鸣。硬控制、弹反和死亡沿用现有中断逻辑。

基础伤害 85，单次攻击每个目标最多命中一次；同层、正面 18 度内、距离 310 cm 内可起手，重夹冷却 6.8 秒。近距离重夹就绪时优先，随后可轮换原有碾扫；远距离／高平台保留压鸣。攻击结束后另留 0.4 秒其他招式起手间隔。

碰撞点来自两侧前部和内侧肉壁，UE 导入后按实际骨骼姿态重新蒙皮。伤害由服务端处理，墙体遮挡、无敌、格挡／弹反沿用现有近战通道；铁链不造成额外伤害。重夹不附加击退，玩家可以利用恢复段贴近反击。普通接地 IK 在此动作中停用，避免重写向内合夹的膝部轨迹。

原始合成音效包括蓄力摩擦、合夹低频闷响、身体落沉和稍晚的铁链回摆；通过攻击序号和服务器时间同步，中断时停止。音效未经试听。
