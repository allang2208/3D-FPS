# 突变体-3：动作过渡修订（2026-09-23）

当前版本与恢复顺序见 [突变体发布入口](Mutant3FeralPublication20260923.md)。本文保留阶段记录；其中 before/baseline 快照及已退役独立手臂求解已按归档清单移至 trash。

在已落盘的 KhaimeraV2 爪形、骨盆与贴地修订上，处理用户要求的动作衔接。此次修改运行时动画混合和步伐匹配，不替换模型或动画资产。

## 针对性检查发现

- 普通跑含三个步伐周期，高速跑含两个。原播放逻辑分别记住每个动画的时间，切换时不能保证左右脚处于相近的支撑/摆动阶段；直接按完整片段的归一化时间切换也不合适。
- 原混合只冻结离开的姿势。正常跑步切换时，离开的腿部动作会短暂停住。
- 蓄力末帧与腾空首帧、腾空末帧与落地首帧位置/旋转一致，但实际碰撞触地不一定恰好发生在腾空末帧。V2 的全身硬切能保住接地，却会突然切换上身。
- ClawA → B 的最大手部位置差约 42.29 cm；B → C、C → A 分别约 91.21、91.67 cm。原 0.06 秒混合过急。
- 落地末帧 → 待机首帧，最大手部位置差约 66.16 cm。恢复已开始播放待机后，父状态机进入 Idle 又启动一次相同动画的混合。
- 普通受击原为零秒混合；受控状态不走一般动画时钟，因此增加受击混合必须同时接入受击时钟。

上述距离来自最终 Blender 骨骼采样，表示片段姿势差异，不是游戏中测得的瞬移量。

## 修改

| 交接 | 处理 |
|---|---|
| 普通跑 ↔ 高速跑 | 用 V2 的左右脚/膝部位置及脚部运动方向建立双向时间映射。离开的稳定循环继续播放，目标按当前实际速度开始播放，混合 0.18 秒。 |
| 待机/奔跑状态切换 | 同一循环继续播放，不重新抓取快照或重置播放速度；若之前的混合尚未完成，使用实际可见姿势快照接续。 |
| 进入蓄力 | 混合 0.16 秒，蓄力总时长仍为 0.6 秒。 |
| 爪击与连击 | 混合最多 0.11 秒，并限制在 ContactTime 前 0.02 秒完成；默认 0.13–0.25 秒命中窗口、每段 0.5 秒和伤害不变。 |
| 腾空 → 实际触地 | 骨盆、根和腿直接采用贴地的落地动作；Spine02 及其上身分支混合 0.14 秒，避免将蜷腿腾空姿势混入落地支撑。 |
| 攻击/落地 → 待机恢复 | 混合 0.24 秒；战斗恢复计时不延长。恢复结束若再次要求相同待机，不重启混合。 |
| 普通受击 | 突变体专用 0.07 秒混合，由原受击时钟推进；保留招架倒放及其 0.08 秒交接。 |

死亡继续使用现有动画到布娃娃的交接。动画采样仍使用显式时间，不引入第二套伤害或根运动时钟。

`UFatZombieAnimInstance` 中新增选项默认关闭。仅突变体启用持续播放的循环源、指定目标时间和贴地下身混合；其他怪物调用保留原默认行为。

## 本次离线排查范围

使用同一套最终蒙皮，在腾空 0.20、0.40、0.55、0.65 秒分别模拟触地，采样后续 0.14 秒的过渡。贴地下身方案脚底最低点约为 **0.296–0.300 cm**；整身混合对照可出现约 **-19.25–16.56 cm** 的脚底高度。这是角色局部平地坐标下的离线蒙皮结果，不是 UE 实际地形、运行时线程或游戏观感验收。

检查及制作记录：`SourceAssets/Mutant3Khaimera20260923/transitions/`。

- `inspect_transitions.py`、`clip_boundaries.json`、`clip_poses.json`：动作端点与步伐采样。
- `build_gait_map.py`、`gait_mapping.json`：生成 `Source/FPSGAME/Monsters/Mutant3GaitPhases.inl`。更换 V2 跑步动画时应重新采样生成。
- `inspect_landing_blend.py`、`landing_blend_inspection.json`：此次用户指定的落地过渡排查。
- `before/`：本次编辑前相关源码快照，包含此前已存在的改动。
- `build-editor.log`、`build-game.log`、`build-game-retry.log`：后台构建日志。

构建交付：`FPSGAMEEditor Win64 Development` 成功，本次怪物动画修改已编入 Editor 模块。Game 首次构建遇到并行修改的建筑模块 `IsGroundAnchor` 声明不一致；该声明更新后重试，又在 `VoxelBuildWorld.cpp` 的 `*ColumnAnchored.Add(...)` 处遇到对 bool 解引用的编译错误。因此此次 Game 可执行文件未更新；未修改建筑模块或覆盖其并行工作。

没有启动交互式 UE 编辑器或游戏，也没有追加其他玩法回归。游戏内衔接观感由用户通过原 F6 怪物生成入口重新生成突变体-3 后确认。
