# 大厅二楼：普通 M 系远程异形设计（2026-10-12）

最新正式部署已调整为每厅 4 只鼓囊 M-09（一楼 2、二楼 2），额外加入首波，不替换职员；针射者仍为设计候选。部署源码、游荡接入读取与构建状态见 [大厅部署 V12](BellowSacHallDeploymentV12_20261012.md)，下文数量与旧进度为设计历史。

后续制作进展：鼓囊投掷者已由用户提供的 Meshy 原骨架接入，完成待机、移动、V02 蓄压吐弹、近身推撞和延迟破裂囊弹，已保存原 F6 入口；具体时序与首版数值见 [鼓囊投掷者 V02](BellowSacLobberCombatV02_20261012.md)。针射者仍为设计候选，两者均未部署到大厅正式波次。下文保留最初设计参数，已实现部分以 V02 文档为准。

用户希望为迎宾大厅、分流大厅二楼设计 1～2 种普通档次 M 系异形远程怪。本轮确定两个互补候选；名称暂定，不占用正式 M 编号。以下为设计参数，尚未制作模型、动画、弹体或接入刷怪表。

## 1. 棘背针射者

原实验体背部与肩胛增生骨质针囊，前肢细长、身体前倾，胸前两片骨瓣展开时露出发射腔。依靠鲜明的棘背轮廓与展开动作区分职员和第二种怪。行走为低伏双足，具备正常上下楼能力，不设置穿墙或飞行能力。

角色定位：直线压制，逼玩家利用柱体、廊边和房间掩体，并优先处理暴露的高位射手。

| 参数 | 首版建议 |
| --- | --- |
| 品阶／生命 | 普通；同等级安保员生命的 75%，不附加精英护甲 |
| 主动发现／舒适射距 | 18 米／7～16 米；群体预警仍为 12 米 |
| 攻击节奏 | 展开骨瓣、吸气蓄压 0.8 秒；接着连续射出 3 枚骨针，间隔 0.18 秒；恢复约 0.6 秒；恢复后随机冷却 3～4 秒 |
| 弹道 | 可见直线飞行弹体，初速约 20 米/秒，无追踪；起射前 0.25 秒锁定这次点射方向，整串围绕该方向小幅散布，玩家横移可躲 |
| 伤害基准 | 单针约同等级安保员一次普通近战的 30%；不附加减速或硬控，三针全中仍低于一次标准近战 |
| 应对 | 骨瓣展开与尖锐吸气声提示射击；进掩体、横移或破韧打断蓄压；已发出的弹体按正常碰撞飞行 |
| 近身 | 4 米内优先短距离换位；不能退路时使用一次弱推击，不反复无限后退 |

每轮射击从真实发射口检查枪线；栏杆、玻璃及墙体按真实碰撞阻挡，不能从墙后发射。玩家躲到楼梯或射手脚下造成角度遮挡时，沿廊道换位寻找射角；持续无法获得射角时沿楼梯追击。

## 2. 鼓囊投掷者

矮壮躯体由四条粗短肢支撑，背部长有一枚明显的充气囊，喉部延伸成向上弯曲的喷口。发射时先压低身体、囊体膨胀，再猛烈收缩抛出囊弹；用膨胀体积与低频鼓气声提供识别。普通地面行走，体型必须能通过现有楼梯和检修通道。

角色定位：低频落点威胁，迫使玩家离开原地，补充针射者的直线压制。

| 参数 | 首版建议 |
| --- | --- |
| 品阶／生命 | 普通；同等级安保员生命的 90%，不设置精英韧性条 |
| 主动发现／舒适射距 | 16 米／6～14 米 |
| 攻击节奏 | 鼓囊蓄力 1.2 秒，抛出一枚囊弹；恢复约 0.8 秒；恢复后随机冷却 5～6.5 秒 |
| 弹道 | 有重力的可见抛物线，无追踪；起抛前 0.35 秒固定目标地面位置，之后玩家移动不会修正落点 |
| 命中 | 接触实体后鼓动 0.65 秒再破裂，半径 1.4 米；墙体隔断伤害，不穿楼板；单次命中只结算一次 |
| 伤害基准 | 中心约同等级安保员一次普通近战的 70%，向边缘衰减；首版不叠加毒池、减速或击倒 |
| 应对 | 囊体膨胀／低频鼓气、空中弹体与落地鼓动均可识别；横移离开落点，破韧可打断尚未抛出的囊弹 |
| 近身 | 4 米内不投弹，短距离退让或弱推击；无路可退时正常近战，不贴身瞬爆 |

只对近期看见、且当次攻击仍有合理观察路径的玩家发起投射，不仅凭共享锁敌就隔墙轰炸。使用有限次数轨迹预测排除顶棚、栏杆和楼板阻挡，无有效抛射路径时换位。保留正常躲避时间，不落地即炸，不留下持续伤害场覆盖唯一楼梯。

## 二楼编成与空间使用

首版建议每厅首波从总数 12～15 中抽出两个名额，分别放 1 只针射者和 1 只投掷者；一楼普通职员为余下 10～13 只。第二波仍为既定检修门职员 12～15 只，不额外增加波数或总数量。这是新怪完成后的编成方案，当前运行刷怪表仍全部为已有三类职员。

- **迎宾大厅**：原作者布局有 4.5 米高的连续二楼回廊和两侧楼梯。针射者在能看见中央地面的开放回廊，投掷者放另一段侧廊；两者不要同时覆盖玩家进厅落脚点。办公室封闭玻璃后不作为默认射击位置。
- **分流大厅**：原作者布局为 4.2 米高西侧平台及两处楼梯。两只分别靠近平台两端可达位置，保持玩家从不同楼梯接近的选择；不放在封闭玻璃控制室内强行透墙输出。
- 精确落点跟随最终装配坐标与上层导航，采用楼层标记、可达性及物种胶囊约束，不能从当前只在 `Room.Origin.Z` 选点的首波逻辑直接假定已支持二楼。
- 两只都能沿楼梯下楼追击；射角长期受阻时主动换位，避免必须站到特定死角才能清厅开门。
- 未发现玩家时按共用规则以 50% 速度在出生点附近游荡。开战后的首次攻击随机错开：针射者 0.6～1.2 秒、投掷者 1～1.8 秒，再各自进入攻击前摇，避免警报后同时开火。
- 同厅两只射手最多同时保留一轮针弹和一枚囊弹；重复蓄力不积攒补射队列。以后扩展数量时再由厅级攻击名额约束投弹频率。

## 实现接续

两者共用本轮已接入的主动发现、受击延迟、单次范围预警及行为树；物种只实现移动、蓄力、发射、命中、受控和死亡动作。可参考已有 `SpitterZombie` 的弹体攻击接入，但骨针与囊弹应使用各自独立伤害、碰撞和动作时序，不通过改名把现有近战职员变成远程怪。

后续制作顺序：独立模型和绑定 → 对应步态／发射／受击／死亡资产 → 两种弹体与战斗入口 → 上层出生槽位与楼梯导航接入 → 编入首波计数。所有实际生成名额仍纳入厅级击杀与主题区域封门统计；未清掉二楼怪不能提前开门。

本轮完成行为与编成设计。没有生成或导入这两只新怪，没有修改二楼场景资产或把未完成怪物加入正式波次。未启动编辑器或进行运行测试。
