## 3. 韧性系统（本轮新增）

### 3.1 与旧机制的关系

旧的 `Poise`（累积伤害直接当削韧、超过阈值就眩晕）是一条**单一口径**的硬直条。本轮改为：

**命中 → 判定命中形式（锐器/钝器/冲击）→ 按该形式抗性折算成「韧性伤害」→ 累积到阈值才破韧造成硬直。**

三个关键行为变化：

1. **未达阈值的命中不再打断动作**。旧机制下每次命中都会进入 `StaggerDuration`（0.45–0.6 s）短硬直；现在只累积韧性，怪物的攻击/移动不会被轻击反复打断。
2. **同一记伤害在不同形式下削韧不同**。钝器系数 1.6、冲击 1.25、锐器 1.0，再乘 `(1−该形式抗性)`。
3. **韧性会自然回满**。连续 `ToughnessRecoverySeconds` 未受击即清空，不会跨战斗累积。

### 3.2 结算公式

```
韧性伤害 = 实际伤害（减伤后） × 形式系数 × (1 − 该形式抗性)
累积韧性 ≥ 韧性阈值  →  破韧：清空累积、进入 ToughnessBreakSeconds 硬直
```

- 形式系数：锐器 `1.0`、钝器 `1.6`、冲击 `1.25`（`MonsterToughnessTypes.h`）。
- 抗性上限 90%，负值会被夹到 0。
- 阈值设 0 = 每次命中都破韧（回到旧手感，用于对照调试）。
- `bAllowSubthresholdStagger = true` = 未达阈值的命中仍播短硬直（旧手感兼容开关）。

### 3.3 三抗性的设计定位

| 抗性 | 覆盖的命中形式 | 典型来源 |
|---|---|---|
| **锐器抗性** `BladeResistance` | 刃口切割与突刺 | 符文剑/寒晶剑的挥砍·连击·突刺·大旋风、斧刃、镐头、冰锥 |
| **钝器抗性** `BluntResistance` | 锤击、配重、枪托 | 配重锤（快速进战）、手枪握把底砸、步枪枪身/枪托砸、怪物爪牙对玩家的近战 |
| **冲击抗性** `ImpactResistance` | 爆炸、坍塌、撞击、未标注来源 | 火球、腐液、巫婆弹、嚎叫、体素坍塌、无类型伤害 |

> 枪械子弹仍走 2026-09-17 的「默认不硬直」闸门：**不累积韧性也不破韧**，只在目录声明 `"hit_stagger": true` 时才进闸门内。手持枪械发动的近战砸击（快速进战）已标记为近战打击，照常累积韧性——它本来就不是枪击。

### 4.4 运行时可观察字段

`UMonsterCombatComponent` 的 `Toughness` 分类下（只读）：

| 字段 | 含义 |
|---|---|
| `Toughness` | 当前累积的韧性伤害 |
| `LastToughnessDamage` | 最近一次命中实际折算出的削韧值 |
| `LastAttackForm` | 最近一次命中的形式 |
