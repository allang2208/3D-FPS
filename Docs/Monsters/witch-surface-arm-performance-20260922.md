# 巫婆 Surface06 / Arm06 / Drape06

用户反馈：上衣破碎感、持瓶肘部扭曲、投掷粗糙，以及巫婆存在时持续卡顿。本次保留人物尺寸和步行/施法主体，调整右臂、上衣表面及布料成本。

## 性能归因

同一 DayNight_Lighting PIE 中生成一只临时巫婆，固定位置和待机，保持相机、分辨率及画质；每阶段等待 2 秒，再采样 5 秒。采样期间临时关闭编辑器后台 CPU 节流，结束后恢复；使用桥的同一个 Windows 互斥锁覆盖异步采样等待，避免其他接入操作改变采样现场。只销毁本次临时角色并结束本次启动的 PIE，不保存地图或测试资产。

有效旧版结果：`SourceAssets/WitchRebuilt20260921/Revision06/performance_before_clean04.json`。

| 原设置 | 129.55 ms | 94.93 ms |
| 4 次目标迭代 / 6 次上限 / 1 子步 | 67.36 ms | 27.60 ms |

布料物理求解是这次持续退化的主要新增成本。简单材质与原材质的对照几乎没有中位帧时差异，不能把问题归为贴图分辨率。CCD 会增加成本；密集模拟网格、较高迭代上限与点面自碰撞也一并调整，但没有声称已单独量出每种自碰撞算法的成本。

前几次采样遇到 Python API 差异、后台节流或 PIE 被中断，只保留排错记录，不用于前后性能结论。`before_clean04` 的最后恢复阶段使用了已过期的 interactor 引用，其布料耗时字段无效；正文仅采用恢复前五个有效阶段。随后修正采样器，逐帧重新取得当前 interactor，并逐阶段记录实际迭代数。帧时间属于编辑器环境，存在场景、渲染和加载开销，不等于打包版 FPS。

## 上衣与布料

- 原细节 UV 按每个面的主方向切换投影，容易产生方向突变；上衣及内衬改用与基础 UV 对齐的细节坐标，UE 法线采样直接使用 UV0。
- 上衣清除旧自定义分裂法线，平滑内侧小幅几何噪声，保留真实破边和主要褶皱。新材质 `M_WitchRebuilt_UpperFabric06` 降低原法线与织物微法线强度、减小颜色反差、提高粗糙度；内衬使用 `M_WitchRebuilt_Lining06`。
- 旧上衣代理来自折叠、多重连接的显示面，普通减面仍停留在约 3,600 点。改成躯干/披布与左右袖子的三块规则模拟面，固定在原有肩领/袖口区域；源代理上衣 1,160 点、下袍 544 点，总计 1,704 点，旧源代理为 5,701 点。
- 上衣保留人体碰撞，取消昂贵的点面自碰撞和上衣 CCD；下袍保留人体 CCD，并改用球形顶点自碰撞。目标迭代 4、上限 6、子步 1。袖下活动上限由 17 cm 减到 9 cm，增强上衣回拉以减少大幅折返。
- Drape05 的有界显示绑定保留在 `UWitchRebuiltClothingAsset`，重建仍自动修正异常系数。未通过缩放角色或关闭全部布料达到性能目标。
