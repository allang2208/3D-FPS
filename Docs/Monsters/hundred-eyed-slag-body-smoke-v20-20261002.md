# 百目炉渣：身体冒烟与八秒残留 V20

用户要求烟雾从怪物身上产生、慢慢升空，产生后保留八秒再消散。本次沿用世界空间粒子和雾内目盲，修改烟的出生位置、漂移、形态与寿命。

## 发射与运动

在背壳 `carapace` 和两侧肩背 `shell_L`、`shell_R` 三个骨骼附近发射。发射点按当前姿态更新，出生时选定一个位置并保存世界位置与漂移；粒子更新不再读取怪物的身体位置。移除后向喷射分量，世界空间漂移为 `(4,-3,18)` cm/s，再叠加缓慢浮升 `0.45 * age²` cm、轻微翻卷及横向扩散。已产生的烟不会随怪物移动、转向或攻击动作被拉回。

发射点靠近焦黑外壳，以小范围散布开始，随后逐渐增大。三处共享一个 Niagara 发射器，连续产生；不创建三个独立烟 Actor。出生渐显约 0.45 秒，烟团保留至年龄 8 秒，再用 1.5 秒平滑淡出，总寿命 9.5 秒。死亡停止新烟，已有烟按剩余寿命继续升空消散。

## 目盲与现有玩法

每 0.3 秒记录三个身体位置的一组烟迹，最多 32 组，覆盖完整 9.5 秒寿命。浓烟核心沿与视觉相同的世界漂移和浮升运动，渐散阶段收缩；墙体遮挡逻辑、仅进入浓烟触发目盲、离开立即清除沿用 V19。

不修改 `M_SlagMistBlindView`：保留全屏失焦、轻微扭曲、烟灰污膜和清晰 HUD。三种攻击、激光倍率 0.8、横扫倍率 1.25、竖劈 2 秒眩晕、认可模型/动作和 V16 布娃娃继续使用现有实现。
