# M66 索敌与追踪接入

用户需要通过怪物真实追踪玩家查看移动动画。本次沿用公共 MonsterAIController、感知与行为树，不另建逐帧追踪器。

## 修改

- M66 生成和结束硬直/眩晕后保持 Actor Tick 开启。此前 `OnRep_Reaction` 在 None 状态关闭 Tick，而公共感知、游荡和追踪任务把它当成显式暂停，导致活着的 M66 无法正常索敌和移动。
- 无反应状态时不执行反应时间轴；尸体完成物理/动画接管后仍按原流程关闭 Actor Tick。公共受控、死亡、开发面板 AI 暂停开关继续生效。
- M66 加入现有行为树服务的玩家感知补查，每 0.1 秒沿用同一范围、视野和遮挡规则发现玩家，避免原生感知被同伴身体遮挡时漏掉目标。仅枚举玩家，不扫描所有怪物，也不忽略墙壁/楼板。
- 保留当前参数：主动发现范围 22 米、前向总视野 200 度、记忆 12 秒、出生点活动半径 32 米，接近同层玩家约 2.7 米停步；玩家离开停步范围后继续追踪。待机游荡仍沿用半速规则。
- 服务端决定目标和寻路，角色位移复制给客户端，原移动动画按实际位移推进。受控结束后重新交给行为树，不关闭索敌。

## 使用

从 F6 原“焚骸 M-66（受击·死亡）”入口生成，怪物面向玩家。在具备大体型导航覆盖的开阔区域，生成距离超过 2.7 米并向后移动，即可观察它追踪和转向。无需先开枪触发仇恨；既有角色蓝图和动画资源不用重新导入。
