# 废弃设施最终首领：合阙

2026-10-15。使用已保存的 `/Game/Monsters/HeQue/BP_HeQue` 替代旧手脑最终首领角色，接入随机地牢 `BossPumpHall` 终末泵机大厅。当前正式生成目录已退役旧手脑遭遇，只保留终点设施；本轮通过现有区域遭遇系统建立真正的首领生成、死亡和奖励推进。

## 区域流程

1. 进入终点区域后，追踪栏显示“废弃设施 · 终末泵机大厅 / 最终首领 · 合阙”，目标为“击败最终首领：合阙”。提示中间悬心弱点，以及泵机遮挡压力波、跳避落地冲击波。
2. 玩家完整进入泵机大厅后，沿用区域方向闸门封锁退路。外部队友仍可进入。服务器通过现有预算调度生成一只合阙，不附加第二波普通怪。
3. 实际击杀合阙后，入口解除封锁，后方奖励室机械门在约 0.9 秒内打开，最终宝箱解锁。旧击杀目标保留完成划线，同时追加“搜刮宝箱”和“进入传送门离开”。
4. 任意队员成功从最终宝箱取出至少一份战利品后，全队完成“搜刮宝箱”，返程门启用。打开面板、排序、合并或拆分原有物品、失败取物不算完成。
5. 使用返程门离开。单人沿用原 E 交互和延时换图；联机在最终保存前暂存本轮完成，确认全队档案保存成功后提交服务器换图，失败则回退完成状态。详见 [联机检查与修正](heque-network-audit-20261015.md)。

不把人物站到传送门附近、开始存档准备或取消换图当作撤离完成。各玩家的库存与战利品归属保持原机制，仅目标进度全队共享。
