# 巫婆 Fabric09：统一低成本布面

用户希望上衣在兼顾性能的情况下提升质感，并统一布料表面。本轮仅制作材质；沿用 Hands08 手部动作、Seams07 网格和 Drape07 布料求解。

## 修改

上衣原来使用 Surface07 的原贴图/修补布混合，裙摆使用 Detail03 的高强度原法线，内衬使用 Surface06，色调、纹理方向、粗糙度和细节强度不同。新建一个不透明双面布料母材质，以及上衣、裙摆和内衬三个实例。上衣、袖口、腰部、裙摆使用同一暗橄榄棕色与哑光参数，内衬保留相同织纹，仅将颜色压暗 18%。帽子、脸、头发、人体皮肤和道具保留原材质。

布料不再采样原巫婆全身底色/法线中的碎块与强反差细节；保留实际网格褶皱，以低反差织纹驱动细微颜色和粗糙度变化。织纹使用已有的 1024 px `T_Witch_FabricDetail_N/R`，没有新增贴图资产。原贴图和旧材质保留可恢复。

微法线统一沿 UV0 切线基底。按静止网格 UV 面积/真实面积计算约 4 cm 纹理重复尺度；上衣原区域与新袖口/腰片的 UV 密度相差较大，利用现有 `SeamRepair` 顶点 Alpha 选择对应重复尺度。仅使用材质参数，不重导入或修改 UV、顶点、权重或布料绑定。

| 部位 | UV0 重复倍数 | 修补区域倍数 |
| --- | ---: | ---: |
| 上衣 | 149.1501 | 14.5376 |
| 裙摆 | 177.9246 | 同左 |
| 内衬 | 43.8884 | 同左 |

这是每片材质区域的面积平均尺度，原 UV 的局部拉伸仍会影响个别部位，未宣称逐面密度完全相等。

## 成本边界

- 每个布料表面的纹理采样从原上衣/裙摆的 4 次变为 2 次；内衬仍为 2 次。共用同一母材质和两张已有贴图。
- 移除原上衣程序正弦染色及新旧底色/法线混合。不使用透明、额外布料层、世界三向投射、POM、位移或材质驱动风动。
- 不新增材质槽和显示网格分段；实例共享母材质不等于原有分段合并，不能据此宣称 draw call 降低。
- 不改碰撞、模拟粒子数、布料迭代或角色 Tick；本轮不重新测量帧率，不能将采样次数变化换算成实测 FPS。
- 默认贴图 mip 随距离过滤织纹。保留几何褶皱及衣物真实破边；材质不能修复几何孔洞。

## 源与接入

- 参数：`Tools/WitchRebuilt/fabric09_settings.py`。
- 制作：`read_fabric09_sources.py` → `author_fabric09.py`，仅更新母版和八个动作场景中的布料节点。
- 导入：`install_fabric09.py`，通过现有 MCP 桥执行，创建母材质/三个实例并保存网格材质槽。无需 C++ 重编译或网格/动画 FBX 重导入。
- `import_assets.py` 的布料分配优先保留 Fabric09，避免以后重建网格时切回旧布面。
- 母材质：`/Game/Monsters/WitchRebuilt/Materials/M_WitchRebuilt_Fabric09`。
- 源和参数：`SourceAssets/WitchRebuilt20260921/Revision09`；修改前可编辑场景与材质槽引用保留在该目录 `Before`。
