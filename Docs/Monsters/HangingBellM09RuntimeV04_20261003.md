# 悬钟 M-09：V04 天花板运行时与测试房

2026-10-03。接续 V02 组织拆分与 V03 专用绑骨，制作天花板限定的角色、动作、战斗和独立测试房。用户要求默认不主动测试，本轮不启动游戏、PIE、预览或验收渲染。

## 制作内容

- 保留原 Meshy 模型、UV、PBR 与 V03 权重；六片背膜使用独立四段骨链，眼球、小臂和大手钩指保留专用骨骼。
- 九段原创动作：待机、交替换握、左右钟摆横撞、三叠鸣震、凝视、护冠双爪、失衡恢复、松握死亡。动作由本地 Blender 编排，不是成熟动捕。
- 运行时末端 IK 固定大手抓点，换握时另一手保留支撑；身体和组织动画叠加在握点支撑之下。
- V05 放宽生成：只要求有真实碰撞天花板且下方能容纳身体，不要求 M09Ceiling 标签、预设握点或地面 NavMesh，也取消3–7米顶高筛选。已有握点图辅助绕障；无图时沿实际连续顶面分段移动，遇断顶或身体障碍停止。
- F6 专用生成分支只选有效天花板位置，沿用开发生成数量和清除功能。无顶面时拒绝生成。
- 复用既有 Behavior Tree、怪物属性、受击、格挡、血条、击杀奖励与尸体预算；悬钟不会被通用击退直接推离顶棚，击倒改为悬挂失衡。
- 七段原创合成音效，一种鸣震波纹模型，以及凝视蓄力和光束显示。
- 死亡动作 0.6 秒后交给共享布娃娃；预算不足时由碰撞胶囊承接坠落。活体失去所有支撑后终止攻击并进入死亡，不在地面恢复战斗。

## 攻击合同

| 动作 | 预警与命中 | 结算与限制 |
| --- | --- | --- |
| 钟摆横撞 | 0–0.85 秒蓄摆；0.85–1.20 秒眼冠扫掠；2.30 秒收势完成 | 1.25 倍物攻；左右交替；每人每次一次；器官实际扫掠 |
| 三叠鸣震 | 背叶展开，1.10、1.45、1.80 秒三次脉冲；2.80 秒完成 | 每次 0.30 倍魔攻；6 米、100°锥形；受实心遮挡；0.45 秒减速15% |
| 凝视 | 0.90 秒锁定方向；1.25、1.45、1.65 秒结算；3 秒完成 | 每次 0.35 倍魔攻；14 米；半径10厘米扫掠，遇第一处阻挡停止 |
| 护冠双爪 | 0.35–0.55 秒双手扫掠；1.10 秒收势完成 | 0.55 倍物攻；每人每次一次；高处够不到时不造成近战伤害 |

冷却分别为4.5、8、7、2.5秒，收势后还有至少0.55秒公共恢复。眼冠通常承受1.5倍伤害，横撞护冠阶段不加倍。数值是首版制作值，未做平衡测试。

## 用户进入和操作

1. 手动启动项目进入游戏，在控制台输入 m09.TestRoom。
2. 到达房间后按 F6，选择“悬钟 M-09（天花板）”，首次生成1只。
3. 主区顶高4.2米；北侧两间房分别3.6米和5.5米。侧区的不同高度握点图互不连接。
4. 主区有立柱、实心高掩体、低掩体、顶面天窗和坠落区域。
5. 返回时输入 m09.Hub，或靠近入口旁返回门按 E。

可选单项控制：

- m09.AI 0：暂停最近一只活体悬钟的 AI；已起手动作自然结束。
- m09.AI 1：恢复最近一只活体悬钟的 AI。
- m09.Attack SwingLeft / SwingRight / Resonance / Gaze / Claw / Stagger：单独触发最近一只的动作；每次只填一个动作名，攻击需要玩家在可见位置。
- m09.Drop：令最近一只松握并死亡。
- 使用 F6 原有清除入口移除开发生成的怪物。

这些命令是 Development 构建的操作入口，不会自动执行测试。主神空间的有顶区域也可以生成悬钟，无需布置握点图；露天区域仍需先有实体顶棚。专用房保留作为集中体验场地。

## V05 生成条件修订（2026-10-03）

用户反馈无法生成，要求“有天花板、空间够即可”。F6 向上查找真实天花板，先尝试指定前方距离，再向近处及两侧查找，最多25处。单次向上搜索距离100米，只是射线的有界搜索范围，不再把顶高限制在3–7米。

净空使用实际碰撞胶囊（半径85厘米、半高137厘米），取消额外排斥余量；通过该判断后直接生成，避免网格指尖又触发一轮更严格的出生拒绝。玩家及其他身体占位仍属于空间判断。没有有效顶面或空间不足时才显示相应提示。

出生初始化允许没有 Route，优先保留已找到的悬挂位置；抓点按实际顶面定位，梁或小顶板允许手掌向内收。存活期间也不再要求专用标签。没有握点图时复用已有0.65秒寻路调度，每段最多1.5米，逐段判断连续顶面与身体通道，不额外建立全图导航。
