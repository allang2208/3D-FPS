# 合阙：偏身碾扫 V01

后续用户反馈「靠近后停住不攻击、移动太轻松」的修订见 [攻击起手与重步态 V02](heque-combat-heavy-move-v02.md)。以下保留 V01 当时的起手合同和制作记录。

以已交付的合阙 RigV01 为母版制作第一招。角色身份、身体、材质、40 根制作骨骼、基础动作与连续软体死亡保持原资产引用；新增独立动作和战斗接入。F6 稳定 ID 仍为 `HeQue`，名称改为「合阙（偏身碾扫）」。本轮不加入随机地牢刷怪表，也不制作其余招式。

## 动作与数值

- 解剖右足承重，在原地以足心为轴转动；左侧身体抬起、向外展，再横扫正前方。右侧铁链逐节滞后甩动，缝心在躯干停止后回摆。
- 动作 3.20 秒、60 fps、非循环、无根运动。0～1.10 秒慢蓄势；1.10～1.55 秒发力与接触；随后回弹、短暂停顿和抬足复位。整段锁定起手朝向，玩家可以绕支撑侧外缘或撤出身体轨迹。
- 初版参数：基础物理伤害 60，实际扣血仍经过玩家防御／格挡等共有公式；对存活且实际受伤的玩家沿扫动方向施加最多 180 cm 的带碰撞推移。完全格挡、弹反、无敌或死亡不追加推移。
- 起手上限 355 cm，同时要求动画轨迹能触及玩家胶囊；停步 280 cm；起手方向容差 25°；同层高度差小于 100 cm；从起手计冷却 4.60 秒。
- 普通双足地面校正在本招期间让位于制作好的支撑足／抬足姿态，避免把扫动足拉回地面。

## 接入

`AHeQueMonster` 增加复制的攻击启停、序号和服务器起始时间。原生动画图按同一秒制时钟采样，反应和死亡优先；起止使用现有姿态混合。服务端完成命中和推移，客户端只播放动作。

接触由左侧足掌与下段躯体的 90 个实际表面采样点组成，每点使用 20 cm 球扫掠。28 组接触帧在 UE 导入后，按原蒙皮权重与导入骨骼变换重新生成；不是固定扇形伤害。一次攻击每个目标只结算一次；卡帧仍消费跨过的制作采样区间。墙体遮挡生效，冰墙可受共有近战伤害。铁链本次属于表现，不产生额外伤害。

硬直、眩晕、击飞、冰冻、石化、失去地面支撑、禁用 AI 或死亡会取消攻击。伤害回调内发生弹反／死亡时立即退出，不再伤害后续目标。普通枪击是否造成硬直仍由现有韧性规则决定。
