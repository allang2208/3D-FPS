# 巫婆 V05 下半身混乱与破碎排查

本次范围：针对用户提供截图，读取当前 Blender 源、实际交付 FBX、制作脚本及已有 UE 导入记录。没有修改模型、动画、材质或游戏资产，没有启动 UE / PIE。本机排查时未发现正在运行的 UnrealEditor，因此没有读取截图所对应实例的实时布料状态。

## 主因：保留下来的内部身体包含严重错误几何

`Witch_InnerBody.001` 源文件与当前 `Delivery/OriginalRobeV05/SK_Witch_OriginalRobeV05.fbx` 都包含 15,824 个顶点、28,976 个面。它没有隐藏，仍以独立不透明材质导出。源与 FBX 对应顶点世界位置最大差约 0.00000012 米，错误在制作源中已经存在。

1. `layered_v04.py:130` 只用面顶点高度 0.26～1.02 米筛选 Quinn 的“内部身体”，没有按身体部位排除手。原始主导权重统计显示其中 **9,846 个顶点属于双手及手指**。这些源骨骼没有对应映射，`donor_data()` 会向父骨寻找已有映射，因而错误地把手部几何归到躯干。V05 的 `original_robe_v05.py:92` 继续复制了这份错误部件。
2. `layered_v04.py:150` 将骨段长度比用于顶点相对骨骼位置的**全方向缩放**。Quinn 的 pelvis→spine_01 只有 **2.47184 cm**，巫婆 Hips→Spine02 为 **14.70563 cm**，得到 **5.94925 倍**。此比例不适合作为骨盆周围几何的整体缩放。
3. 适配后的内部身体宽 **141.0 cm**、前后 **133.8 cm**，明显伸出原裙静态包围范围（宽约 85.3 cm、前后约 50.0 cm）。部分边长相对源放大最高 **28.92 倍**，由不同骨骼适配变换混合造成严重拉长。
4. 该部件使用无原裙纹理的深色常量材质 `M_Witch_V04_InnerBody`，并未实际设置为不渲染。截图中的光滑大黑面，以及左侧类似游离手/碎片的轮廓，与这些已确认错误高度吻合；截图像素与具体三角面的对应仍属于静态诊断推断。

前次清理移除了模拟代理的渲染部分，也处理了重复布料记录，但遗漏了这份以“内部身体”名义保留的错误几何。不能把旧代理裙已移除等同于下半身已经清理正确。

## 次因：布料代理和部件接缝仍不合格

- 代理采用逐环射线投射，未命中时取最近点，然后强制改写高度。实际源网格存在零长度边、退化三角形，最长相邻边 **43.23 cm**；径向法线符号混杂，BVH 检出 670 对不共享索引顶点的重叠候选。重叠候选包含可能的重合接触，不能全部直接计为有效自穿透。
- 原裙 50,202 个顶点中，10,199 个到代理最近面的距离超过 **4 cm**，最大 **13.22 cm**。这说明代理没有均匀贴合原裙。4 cm 也是当前多三角映射核半径，但距离超过它不能单独证明绑定失败，需要区分最近映射回退和运行变形。
- 裙与脚之间有 **98 个共享源顶点**，拆成两个对象后分别由脚骨和布料驱动。对应裙侧最近代理点的允许位移约 **55.9～65 cm**，无法维持原来的连接关系，存在明显开裂风险。
- 上下衣分界按高度和自动蒙皮权重截取，并非干净的服装边界；上衣最低到 57.2 cm，下裙最高到 104.7 cm。袖口可能解释部分高度重叠，因此不能把全部重叠面都算作重复裙面。
- 裙摆最大允许位移 **65 cm**、动画驱动强度 **0.04**；这些设置会放大不良代理和接缝造成的形变，但没有进行实时隔离对照，不能把全部截图异常归于某一个布料参数。

## 建议修正顺序

1. 先从当前可见角色中移除这份错误内部身体及误带的双手；保留原巫婆的脸、帽、手、原裙和材质。需要内部腿时只提取真正的骨盆/大腿/小腿区域，按横截面与骨链分别适配，禁止使用短骨段长度比整体放大网格。
2. 在原裙上整理腰口、脚部与布条边界，清除误分小片并使连接处具有一致驱动。源部件保留可编辑拆分，但拆分不应产生两个自由运动的同一接缝。
3. 重做无退化、无折返的简单布料代理，先固定腰口及过渡区，再给下摆有限摆动；布料使用相应身体碰撞体。完成这些基础处理后再调行走姿态。

当前无需为定位出的错误重新付费生成整个人物。以上为诊断和修正建议，尚未执行修复或游戏验收。
