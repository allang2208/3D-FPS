# 百目炉渣 V12：跃砸关节与聚眼激光

本轮处理用户指出的跃砸像固定模型沿 Z 轴平移、缺少屈伸与落地压缩，以及激光没有抬手、没有眼区粒子蓄能的问题。

## 制作与接入

制作文件、FBX 与蒙皮数据位于 `SourceAssets/HundredEyedSlagMeshy20260930/ArticulationV12`。新网格、三档 LOD 与八段动画已后台导入保存，FPSGAMEEditor 目标内 FPSGAME 玩法模块的常规 UBT 构建成功，确认基础 DLL 已为最新状态。没有构建游戏可执行文件。实际保存与构建记录见 `installation_complete.json`。

- 支撑肢：重做小左前肢及左右后肢约 29812 个顶点的权重。肩／髋连接按骨链弧长渐变，膝、踝采用较短的连续权重环，足底主要跟随掌／脚骨。原先按世界高度赋予躯干权重的方式会限制腿部屈伸，本次移除该区域的高度依赖。大右手已有蒙皮保留。
- 骨骼：保持公共骨架与绑定姿态，使用现有骨链分别驱动骨盆、脊柱、胸部和四肢，没有新增骨骼。三条短支撑链的最大屈曲提高至 134 度，大右手限制为 118 度；离线两段 IK 保持骨长，完整段坐标系保留轴向朝向，腕部体积辅助骨与最终掌骨朝向同步。
- 跃砸：沿实际 Epic Rampage `Jump_Start/Mid/Fall/End` 参考的起跳、腾空与落地节奏制作八段中的五段。蓄力压低重心并折腿；蹬地后先伸腿、再在接近最高点收腿；下落伸展至落地姿势；接触地面后通过骨盆、脊柱和膝部屈曲吸收冲击，再恢复站姿。
- 起落同步：胶囊由原生 CharacterMovement 重力与碰撞驱动。动画承担关节及躯干动作；下落片段不循环，按最高点至当前地面的高度推进并保持落地伸展。物理伤害仍只由实际 `Landed` 触发，避免提前造成伤害。
- 激光：前摇 1.5 秒（运行时对旧实例较短的覆盖值也设置此最低值）。大右手参考已接入的 Rampage 下劈抬臂姿势抬起，另外三肢承重，躯干向支撑侧调整。射击结束再收手。
- 眼区粒子：一个 InstancedStaticMesh 组件复用 32 个粒子，螺旋向两个 `front_plate` 绑定眼区收拢，同时保留眼球发光、汇聚短束及激光主体。仅在蓄力期间更新粒子，射击、打断及死亡时隐藏；沿用现有激光材质，没有新增灯光。2600 cm 外剔除该视觉效果。
- 瞄准：采用玩家当前位置，前摇后段锁定方向，射击期不追踪、不使用速度提前量。魔法伤害、遮挡、每次施法每个目标最多一次伤害继续沿用已有合同。
