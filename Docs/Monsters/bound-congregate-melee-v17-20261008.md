# 缚群近战 V17：蓄力、爆发与动作回查

> 历史阶段记录。2026-10-08 用户否定整体衣物并暂停；V18、V19 均未获认可。当前状态、最新参数和已归档证据的取回位置以[暂停与发布记录](bound-congregate-paused-publication-20261008.md)为准。

2026-10-08。用户要求撕咬、正前肢连拍分开蓄力和快速攻击，并主动回查不自然动作。本轮检查仅覆盖这两段新近战及其动画管线。

## 动作

- 撕咬：0–0.48 s 压低蓄力、张口；0.48–0.56 s 加速咬下；0.56–0.60 s 接触停顿；随后反冲、小幅撕扯，1.40 s 收势结束。
- 连拍：左、右、左、右分别在 0.52、0.72、0.92、1.12 s 接触，每拍释放 0.08 s；随后重新蓄力，在 1.50–1.60 s 双肢重拍，2.15 s 回到支撑。
- 连拍接触停顿 0.035 s；抬手和回收沿身体外侧弧线，重拍后直接回落支撑，不重新抬到头顶。
- 各段分别使用缓入缓出和加速释放曲线，烘焙为 120 Hz；不是统一倍率加速。烘焙关键帧之间的线性插值仅用于高频采样，不代表动作的速度恒定。
- 来源是原 V14 骨架上的原创动作；仅参考接肢类怪物的攻击节奏，没有导入艾尔登法环资产或动画数据。

## 回查发现与修正

1. V16 连拍存在近 180 度插值翻转，采样的脚骨位置单次跳变超过 1 m。矩阵分解后的四元数必须保持相邻关键帧同半球；不能逐帧直接写入可能互为正负的四元数。
2. V16 支撑端最大漂移：撕咬约 15.7 cm，连拍约 27.1 cm。收小身体整体前冲，嘴部与前胸分摊发力，并离线约束身体位移，保留支撑脚目标。
3. 短上臂、长前臂的右前肢在直线抬手/回收时过折。改为外抬弧线，并使用完整屈伸平面定向，避免仅对齐骨段方向导致扭转不稳定。
4. 游戏接地节点原先对所有攻击仍使用站立参考膝面，会覆盖正确的烘焙肘部。仅 Bite/Flurry 改为保留当前动画的弯曲平面，继续修正地形落点；其余行为不改。
5. 连拍判定使用各拍 `StrikeStarts → Contacts` 的三个准确采样，不把蓄力包含在扫掠内。动画、接触音效、伤害和转向截止由同一秒合同驱动。
