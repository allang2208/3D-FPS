# 鼓囊 M-09 爆炸预警圆环贴合场景表面

用户反馈圆环偶尔斜立、悬空，并明确要求只附着场景表面，不附着玩家、单位或怪物。

## 修改

旧逻辑直接把首次球形碰撞的 `ImpactNormal` 用作整片静态圆环的朝向。该碰撞可以来自玩家胶囊或怪物，而整片平面也无法适应台阶、边缘和局部起伏。

- 保留囊弹原碰撞与爆炸规则，新增接触点和场景接触标记的复制数据；预警定位单独处理。
- 撞场景时以实际接触点重新查询精细场景碰撞。撞单位时向下寻找爆炸半径内的场景表面，不采用单位的碰撞法线。
- 查询包含场景静态、动态和物理物体，要求阻挡可见性；排除 Pawn、蒙皮组件、带战斗生命组件的实体及通过 Owner／AttachParent 关联的单位附件。
- 复用现有 `GeometryFramework` 与圆环材质，以 64 段动态环带替代平面静态网格。沿表面法线分别投射内外边缘，离面 0.6 cm，减少深度冲突。
- 按爆炸球与接触平面的交线确定环半径，尤其避免撞单位后把地面警戒范围画得过大。伤害半径仍为原值。
- 无支撑点、超出爆炸范围、表面朝向不连续或相邻采样跨越明显断层时不连接三角形，避免悬空及跨楼层竖直环带。现有屏幕危险图标与方向箭头独立保留。
- 警告网格使用绝对世界变换，不继承囊弹翻滚、膨胀或网络位姿更新。它是场景上的短时标记，不绑定单位组件。

## 成本与接入

每颗囊弹在引信阶段生成一次，最多 130 次短距离场景射线、128 个三角形；不逐帧重新采样，不扫描全部 Actor。动态环带无碰撞、导航影响、阴影和光追可见性；随原投射物销毁。未增加插件、材质或纹理资产。

运行入口为 `BellowSacProjectile` 和 `BellowSacWarningSurface.cpp`。继续复用原蓝图的 `TelegraphMaterial`；保留旧网格参数与资产引用兼容导入链，运行时不再绘制旧平面网格。4 秒攻击间隔、0.65 秒引信和 V06 落地蓄压静音不变。

`FPSGAMEEditor` 与 `FPSGAME` Win64 Development 后台构建均成功，分别见 `Saved/BellowSacLobber20261012/build-surface-v07-editor-final.log`（46.46 秒）和 `build-surface-v07-game.log`（60.99 秒）。首次 Editor 构建遭遇并行更新的 `FluidPresentationSubsystem.h` 与 UHT 生成代码行号不同步；未改动该文件，重新构建完成。

本次是原生组件替换，复用已保存材质，不需要重新导入资产或覆盖怪物蓝图。未启动编辑器、游戏、截图、渲染或自测，由用户确认贴合效果。
