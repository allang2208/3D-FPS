# 悬钟护冠双爪 V11

2026-10-04。按用户要求复用已认可的抓击动作开发悬钟第三种正式攻击。供体选择盲祷者 `LibrarySweepV27` 的左右 `Attack_D` 派生动作：其攻击主体已有用户认可，收势修订仍与本轮悬钟适配一样待用户体验。百目早期 ClawV6 后来已被替换，不作为认可模板。

## 动作与复用

从现存 `M07_LibrarySweep_V27.blend` 读取左右整条肩、肘、腕旋转，保留源动作的展臂、斜抓与随挥关系，通过恒定解剖参考坐标适配悬钟两条腹前小臂。悬钟和盲祷者骨架、比例不同，因此复用动作源，不能直接挂同一份动画资产。

两只小手从原交叉护冠姿态展开、挥出、连续收回；右手领先25毫秒，两手共享一次伤害。源0.50–0.70秒接触映射到悬钟0.35–0.55秒，前后采用连续变速。源站立转体只给下部躯干少量配合，平移和地面根运动不复制；根骨、承重大手、原蒙皮、网格与骨架不修改。大手继续由既有支撑IK抓住天花。

手指沿原骨链轻微展指、勾回，末帧回到原护冠。沿用已有 `S_M09_Claw`，其0.44秒挥动声与接触窗口相配；受伤反馈沿用玩家现有物理近战接口，不增加一套命中特效或伤害时钟。

## 战斗合同

| 项目 | 本轮接入 |
| --- | --- |
| 总长 | 1.10秒 |
| 命中窗口 | 0.35–0.55秒 |
| 伤害 | 物理攻击 × 0.55；默认42对应23.1，玩家减伤前 |
| 命中去重 | 两只手共享原 `HitVictims`，每目标每次动作至多一次 |
| 冷却 | 起手计时2.5秒；收势后保留已有0.55秒全局间隔 |
| 优先级 | 目标进入小臂可达的前侧空间时优先双爪；中远程继续原鸣震／凝视策略 |
| 范围 | 根据实际肩肘腕骨长、手爪长度及目标胶囊判断起手，高度不可达时不触发；伤害只认实际手爪扫过 |
| 碰撞 | 复用盲祷者手掌到爪尖胶囊扫掠方式，半径12厘米；延用悬钟已有有上限时间子步 |
| 遮挡与中断 | 眼部视线及肩到接触点遮挡；受击、弹反或死亡即时取消剩余接触 |

`CanAttack`／`StartAttack` 沿现有 Behavior Tree 执行接口接入，没有额外 AI 调度。伤害仍只在服务器权威分支执行，画面沿已复制的攻击状态与时间推进。`m09.Attack Claw` 仍可手动触发；钟摆横撞仍是手动原型，本轮不启用。
