# 突变体 3：飞扑距离与移动预判

当前版本与恢复顺序见 [突变体发布入口](Mutant3FeralPublication20260923.md)。本文保留阶段记录；其中 before/baseline 快照及已退役独立手臂求解已按归档清单移至 trash。

后续用户反馈：“基本成功”。本轮整理没有追加玩法测试。

用户确认上一轮材质优化成功，本次要求飞扑距离提高 50%，按玩家移动提前瞄准。

- 最大触发距离：750 → 1125 cm（7.5 → 11.25 m）。最小触发距离继续为 320 cm。
- 水平提前量：目标当前水平速度 × 实际飞行时间 × `PounceLeadStrength`，默认强度 1.0。`PounceMaxLeadDistance` 默认 450 cm，限制冲刺/击退等高速度下的外推。
- 决策阶段评估可用弹道；蓄力结束、实际起跳前重新读取位置和速度，因此不会重复加上已过去的蓄力时间。正常飞行时长仍为 0.65 s。
- 目标是 Character 时，先按目标自己的胶囊与碰撞响应扫掠预测位移，遇到墙或障碍截短提前量。
- 优先全提前量，地面或弹道不可用时依次退至半提前量、当前位置；最多三个候选。落点保持在预计目标前方约 90 cm，水平行程不超过最大飞扑距离。
- 每个候选都必须找到可行走地面，高差不超过 150 cm，并通过已有的 16 段胶囊弹道扫掠。候选全部失败时继续原来的追击/恢复流程。
- 起跳时锁定朝向和速度，飞行中没有追踪修正；玩家突然停步、变向仍能躲避。静止目标的提前量为零。
- 保留 120° / 250 cm 落地攻击区、三倍基础伤害、2 s 眩晕、5 s 冷却，以及当前手势、材质和落地反馈。
