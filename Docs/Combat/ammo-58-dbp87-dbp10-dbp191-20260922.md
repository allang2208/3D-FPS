## 命名设计

5.8x42mm 的真实命名本身就是按年代推进的型号串，正好能当"从低到高"的三档，不需要生造名字：

- **DBP87**——1987 年定型的初代 5.8 mm 弹，作为最低档、沿用组内原有 ID `ammo_58`，等价于 7.62 的 LP 与 5.56 的 M193。
- **DBP10**——2010 年的通用改进弹，作为中档、10% 物理护甲忽略。
- **DBP191**——为 QBZ-191 一族配套的新一代弹，作为高档、1.05 倍伤害 + 20% 穿透。

三档共用兼容组 `ammo_58`，`group_name` 仍是 `5.8 mm`（HUD 口径行显示 `5.8 mm · DBP10` 这一形式）。游戏里这套阶梯只是同一套数值规则套到该口径，**不代表真实弹道与穿甲数据**；名称与虚构的"穿甲视觉标识"都只用于游戏内辨识。若用户想换成别的型号（如 DBP95、DBP88 等），只改 `name` 字段即可，ID 不必动。

## 标识与兼容

- 最低档沿用旧 ID `ammo_58`：现有 5.8 备弹、枪内已装填、旧奖励条目与旧迁移逻辑直接接着用，**不重新发数量、不改 ID**。与 LP 沿用 `ammo_762`、M193 沿用 `ammo_556`、FMJ 沿用 `ammo_45acp`、SP 沿用 `ammo_357` 的处理相同。
- `DBP10`、`DBP191` 是新增类型，只进正式弹种目录，不自动赠送、不改掉落与价格；测试时用 F6 开发面板按弹种 ID 发放。
- 该组目前只有 QBZ-191（`ue_qbz191`，`gunsmith.json` 的 `base.ammo_item_id` 仍是 `ammo_58`）使用；组内共用袋中余额，一把枪的弹匣仍只装一种弹。
- `order` 为 20／21／22，落在 5.56x45mm（10–12）与 .45 ACP（30–32）之间，组内顺序固定为 DBP87 → DBP10 → DBP191。
- 中间档与高档显式 `allow_infinite_reserve:false`：训练场无限备弹不适用，也不能靠长按 R 免费解锁未获得的类型；最低档保留普通弹的无限规则。

## 顺带效果：QBZ-191 也有弹种轮盘了

加档前 5.8 只有一条兼容类型，`FPSGAMECharacterAmmo.cpp` 里 `ReloadInputPressed()` 的门槛会让长按 R 直接走普通换弹、不开轮盘。现在三条兼容类型，QBZ-191 长按 R 会弹出三分区的单盘轮盘（每档 120°），与 AKM／M4A1 的行为一致；数量为 0 的档位保留扇区并灰显、不可提交。
