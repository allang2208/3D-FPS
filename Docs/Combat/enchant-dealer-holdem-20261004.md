# 庄家：德州七张取最佳五张（2026-10-04）

用户要求按德州扑克概率调整抽牌并优化算法。原版直接从 52 张牌抽五张，普通无偏发牌的高牌理论概率约 50.12%；现改为两张随机底牌加五张公共牌，七张中取最佳五张，普通无偏发牌的高牌理论概率约 17.41%。采用真实不放回发牌和七张判牌，不按预设牌型权重制造五张牌。保留用户已确定的暴击同花顺偏向，因此包含暴击的整轮分布随暴击次数和已发牌变化，不能声称也严格等于无偏德州分布。

## 发牌与结算

- 每件附魔左轮在本轮首次有效命中时，先随机发两张底牌，再抽第一张公共牌。初始两张不受该次暴击干预；同日后续显示更新将两张底牌放在公共牌上方一起展示。
- 每次有效命中再抽一张公共牌，七张都来自同一份 52 张牌且不重复。前四次伤害仍正常，第五次命中加入第五张公共牌，再取七张中的最佳五张并乘原牌型倍率，结算前清空牌组防止伤害回调重复消费。
- 同日后续显示更新将两张底牌置于上排，五张公共牌保留下排抽牌位置；结算不再替换或重排牌面，而是在实际最佳五张的轮廓显示火焰。见 [两排七张与入选火焰](enchant-dealer-seven-card-selection-20261004.md)。
- 七个牌组件及七个复用轮廓片（只启用入选五个）、一个英文标题、一个高倍火焰层及一个笑声音部；各牌独立悬浮，×4/×5/×7 字效和笑声沿用。
- 每实例独立、主副手隔离、换弹保留、卸装／死亡清理、服务端抽牌和拥有者 RPC 保持原合同。后续显示版本 RPC 最多发送七张原始牌和一字节入选槽位掩码，不新增存档或持续复制字段。

## 随机与暴击

`DealerPoker::Draw` 使用 52 位已发牌／候选牌掩码；普通抽牌从未发牌集合取等概率索引。整数随机数经拒绝余数区间后映射到候选索引，避免浮点缩放或直接取模产生的桶大小差异；没有新种子重置、牌型保底或高牌权重。

四花色十种顺子，共 40 个同花顺窗口，编译期生成掩码。暴击逐窗口计算 `Missing = Window & ~Dealt`，只有 `Missing` 的牌数不大于剩余牌位，才把这些缺牌合并进候选。七张选五张允许已发牌中有两张不入选，不再要求七张都属于同一个五张窗口；保留全部已发牌，没有可完成窗口时回普通随机。窗口重复覆盖的同一张牌通过位或自然去重，不额外加权。

每次优先抽出的牌都保留至少一个可在七张内完成的同花顺窗口，因此五次命中全部暴击时会完成同花顺。单次暴击不会承诺后续普通命中也继续补同花顺。

## 判牌与最佳五张

`EvaluateBest` 一次读取七张牌，建立 13 个点数计数、四个花色点数掩码和总点数掩码，按最高牌型直接选择五张，不遍历 21 个五张组合、不排序临时点数数组。处理 A2345、TJQKA、重复点数下的顺子、六／七张同花、两组三条取葫芦、三组对子取最高两对、四条最大踢脚牌等七张情形。皇家同花顺继续使用同花顺 ×7。

同牌型按点数和踢脚牌取最高，牌面选择确定；等点数花色不参与伤害倍率，相同点数按牌 ID 选取，展示不消耗随机数。每实例牌数组预留并复用七张容量，常驻同花顺窗口共 320 字节，结算只生成五张展示输出。
