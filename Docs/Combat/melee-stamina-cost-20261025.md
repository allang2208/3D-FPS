# 近战体力费用与装备减耗（2026-10-25）

用户要求取消可叠到零消耗的装备算法，并授权制定基础值与乘区。破阵近战腰带保持基础减耗 10%、每强化一级增加 1 个百分点，强化上限 +15，即单件减耗 25%。腰带物品已通过 CombatBeltsIntegration20261025 接入游戏物品目录，实际游戏与联机由用户测试。

## 公式

每件装备先算带符号的属性值：

`b_i = bonusStats + bonusPerEnhance × 有效强化等级 + _enchantEffects`

`E = ∏ max(0.5, 1 + b_i)`

同件装备的基础、强化和附魔相加；不同装备的剩余费用相乘。每件装备最多减耗 50%，增加消耗的正值仍可正常生效。只统计已装备物品，保留原有非活动盾牌排除规则与物品强化上限。

`实际费用 C = B × max(0.20, E × W × T × S)`

- `B`：动作基础费用，先包含单手/双手差异。
- `E`：上述装备乘区。
- `W`：已安装或预览中的武器配件费用倍率；现有配件之间继续相乘。
- `T`：现有临时反击增益倍率；采集支路沿用无此增益的规则。
- `S`：套装乘区，户外工作套装完整时为 0.85，否则为 1。

所有乘区计算后，费用至少保留基础值的 20%。使用小数扣费，不向下取整。基础值在配置中明确设为 0 的关闭语义保留；任何减耗叠加均不能消除正的基础费用。`SpendStamina` 接收最终费用，不再重复应用倍率或为每次网络回执追加费用。

## 基础值

沿用 `Content/ColdSteelData/stamina.json` 的当前基线与现有单手比例。

| 动作 | 基础费用 | 减耗后最低费用 |
| --- | ---: | ---: |
| 双手近战普通攻击 | 15 | 3 |
| 单手近战普通攻击 | 7.5 | 1.5 |
| 徒手攻击（含法杖普通拳击） | 8 | 1.6 |
| 采集工具挥击 | 10 | 2 |

重击释放继续乘自己的动作费用系数，例如赤霄双斩为普通费用的 2 倍；它同时等比例放大动作基础值和最低值。战锤重击释放保留各配件既有系数。蓄力持续扣费、格挡、弓、闪避、冲刺及独立武技费用不在本次普通攻击公式变更范围内。近战减耗字段继续作用于徒手和采集，未随本次公式改动扩展到独立武技。

## 数值示例

以无其他武器或临时倍率的双手近战为例：

| 装备组合 | 费用倍率 | 每次费用 |
| --- | ---: | ---: |
| 基础腰带，减耗 10% | 0.90 | 13.5 |
| +15 腰带，减耗 25% | 0.75 | 11.25 |
| +15 腰带 + 厚皮革手套 | 0.75 × 0.90 = 0.675 | 10.125 |
| 上述组合 + 户外工作套装 | 0.675 × 0.85 = 0.57375 | 8.60625 |
| 四件各减耗 25% 的装备 | 0.75⁴ = 0.31640625 | 4.74609375 |
| 所有乘区的乘积低于 0.20 | 0.20 | 3 |

## 接入

- `UI/ColdSteelStatusModel.cpp` 的 `EquipmentBonusFor` 对 `meleeStaminaCost` 返回 `E - 1`，保留消费者的 `1 + bonus` 约定；后续法力调整将同一规则应用于 `magicCostPercent`，见 `spell-mana-cost-20261025.md`。两者共用 `Combat/ResourceCostFormula.h` 的单件上限与最终费用下限，其他属性的加法规则不变。
- `Weapons/MeleeWeaponStats.cpp` 的 `ModifiedAttackStamina` 统一合并乘区和最终下限。`AttackStamina`、`UnarmedAttackStamina` 及工具费用调用它。
- `Evaluate.AttackStamina` 调用实际费用入口并传入预览配件；修正武器浮窗、摘要、改造面板漏算装备减耗及单手费用的问题。
- `Production/ProductionToolStats.cpp` 使用同一公式。战锤预览在应用最终下限前传入预览配件，不再对已触底费用做倍率替换。
- 服务端战锤和采集既有执行路径继续读取同一费用数据；不新增 RPC、存档字段或重复扣费。

本次不自动运行游戏、联机、回归或验收；构建状态单独记录于 `Saved/MeleeStamina20261025/MultipliersR1/`。
