## 公式及接入

| 能力 | 原版公式（装备/技能后处理另列） |
|---|---|
| 物攻 | round(10 + 力量×0.05 + 敏捷×0.1) |
| 物防 | floor(体质×1.2 + 力量×0.3) |
| 魔攻 | floor(智力×1.5 + 精神×0.5) |
| 魔防 | floor(精神×1.2 + 智力×0.3) |
| 命中 | floor(80 + 敏捷×0.5) |
| 闪避 | floor(5 + 敏捷×0.3) |
| 暴击率/抗暴率 | floor(2 + 幸运) / floor(体质)，单位为百分点 |
| 攻速倍率 | 1 + 敏捷×0.02 |
| 原版显示移速 | floor(130.528125 + 敏捷×0.05) |
| 生命上限 | 100 + 体质×10 + (等级−1)×10 + 装备生命 |
| 魔法上限 | 100 + 精神×10 + 智力×5 + (等级−1)×10 + 装备魔法 |
| 体力上限 | 100 + 装备体力 |
| 体力恢复倍率 | 1 + 敏捷×0.01 |
| 每秒魔法恢复 | max(0, round((1 + 精神×0.08 + 智力×0.02)×100)/100) |

六维装备加成为 `bonusStats + bonusPerEnhance × enhanceLevel`。不写回基础属性，避免反复发布存档时累积。原版资源上限、魔法恢复、体力恢复使用基础属性加装备，不叠加仅用于战斗面板的精通属性。升级/加点/换装时按最大值差量增减 HP/MP，保留已经损失的数量。

物理与魔法减伤统一为：

`max(floor(D × (1 − 防御/(防御+60))), floor(D×0.1))`

执行时保留 JavaScript 双精度和运算顺序，不用代数等价式重排浮点运算。魔法选魔防，物理选物防。魔抗削减先限制在 0–95%，随后穿透取整；物理腐蚀在穿透后处理。10% 下限在后续格挡之前，低于 10 的原始伤害可以被减为 0，不强制保底 1。

已接入玩家 `DamageAfterArmor`、护士/胖子继承链、手脑、毒蛆的 `TakeDamage`。玩家先防御后格挡，生命组件跳过第二次防御。原版对应怪物防御：胖子 35/4，手脑 75/65（保留原配置显式魔防覆盖），毒蛆 35/36。护士无原版同名身份，保留 0/0。

武器核心伤害：`round(base + L×enhanceFlat + Σ 属性×(系数 + L×强化系数))`。导出配置在 `Content/ColdSteelData/combat-weapon-formulas.json`。

原始武器公式读取基础属性加装备。然后应用现有 UE 枪匠伤害比例、步枪/手枪精通、附魔伤害，并按阶段取整。去掉旧的统一每级 5% 强化和额外加一次角色物攻。运行时、武器提示、改造预览和强化预览共用 `ProcessedDamage`。M4 的伤害也改为读取枪匠结果，避免继续使用独立原生伤害默认值。

随机暴击率为 `max(0, 暴击率−目标抗暴率)`。物理暴击倍率先于减伤、火球魔法暴击后于减伤。保留 FPS 要害命中机制，但同一击不重复叠加随机暴击倍率。火球保存施法时暴击/穿透快照。魔法值在战斗中同样按秒恢复。

## 审计方法与结果

`Tools/Combat/generate_formula_reference.mjs` 实际执行原版 player/base.js、defense-formula.js 和 attack-formula.js，生成参考结果，不是把新 C++ 公式复制成期望值。文件 SHA256 保存在 `Saved/CoreFormulaAudit/reference.json`。

- 属性：60 组六维/等级 × 13 个字段，780 项。
- 防御：3072 组伤害、防御、魔法/物理、穿透、魔抗削减、腐蚀组合。
- 武器：6 种武器 × 60 组属性 × 4 个强化等级，1440 项。
- 独立 UE 世界：四种怪物真实 TakeDamage 入口，含魔法/物理扣血、零伤害、魔法暴击顺序，24 项。
- 资源装备加成和暴击率边界：5 项。

最终结果：**5321 项通过，0 项失败**。`CoreFormulaAudit` 进程退出码 0；UE 原生构建 `9142102` 成功。结果见 `Saved/CoreFormulaAudit/result.json`，日志见 `Saved/CoreFormulaAudit/runtime.log`。隔离世界不执行 BeginPlay，因此部分怪物出现未装配受击动画的警告；这些测试只覆盖扣血，不作为动画验收。此次未启动游戏地图或做整场 PIE 试玩。

## 保留的 FPS 适配与边界

实际移动继续使用 UE 厘米/秒与手枪移动被动；原项目本身也存在显示 speed 与实际 maxSpeed 不同的口径。命中/闪避的属性值已迁移，但不让随机命中率推翻 FPS 碰撞结果；主动闪避仍由动作无敌判定。

保留 UE 体力消耗、恢复基础速度和恢复延迟，以及枪械射程衰减、弱点、剑类动作倍率。未迁移所有怪物出生血量/攻击调参、地图成长倍率、套装、祭品、地牢增益、未接入技能和全部特殊状态组合。本次魔抗削减/腐蚀的算术已对照验证，尚无对应 UE 状态生产者的效果不宣称已完成玩法接入。既有穿透效果接入当前装备附魔数据，未把原项目所有改造效果整套导入。

原版武器低属性伤害小于此前 UE 临时伤害，而现有怪物血量调参仍保留，因此击杀时间会增长。公式对照和隔离伤害测试不等于整场战斗平衡或已打开编辑器中的 PIE 验收。原生代码完成构建后，需要重新打开编辑器加载新模块再试玩。
