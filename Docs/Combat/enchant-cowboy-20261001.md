# 牛仔：手枪滑铲补弹

## 玩法与物品

- 史诗后缀「牛仔」，`cowboy` / `enchant_scroll_cowboy`，效果键 `cowboyReload`。
- `pistol` 限制按物品 `weaponType` 判定，当前支持 M1911、G18、Dan Wesson 715。只作用于当前持有的附魔枪；后缀沿用互斥替换规则。
- 进入滑铲状态后，累计时间跨过 0.25 秒时触发一次。提前结束不累计时间；长下坡不重复触发。按触发时的持枪与附魔状态结算。
- 补入数量 = min(当前容量 − 实时剩余弹数，弹药袋中本枪当前弹种库存)。不切换弹种、不丢弃未射出的子弹；没有对应库存或已满时不操作、不响音效。
- 双持按主手、副手顺序独立结算；共享同种库存时先结算主手，两把均附魔也不会透支。法杖搭配副手手枪只处理副手。
- 不启动换弹动作。成功补弹后结束本枪正在进行的换弹，清掉本枪排队换弹与换弹种请求；射击、检视及另一把枪的动作继续按原流程运行。
- 左轮复用 `MagOut` / `SingleOpen` 的开弹巢单音，其他手枪复用 `MagInsert` 的插匣单音。只响一次，不播完整换弹声链，不新增音频资源。
- 成功补弹后，体力条上方现有动作提示栏显示绿色「已自动换弹」，持续 2 秒（最后 0.3 秒淡出）。单枪、双持和法杖副手共用事务成功回调，双持同时补弹只刷新同一条提示；零库存、满匣和保存失败不显示。提示不额外播放通知音，不进入顶部升级提示队列。
- 卷轴价格 4000、堆叠 99、附魔粉尘 800，沿用史诗附魔卷轴配置；加入深度 8 档掉落，权重 1、数量 1。卷轴外观复用现有资源。

## 实现

`FPSPlayerSlide.cpp` 在现有滑铲更新中检测 0.25 秒时间跨越，复用 `StartSlide` 清零的 `SlideAge`；无需新增 Tick、定时器或逐帧解析附魔。在有效滑铲帧中先结算到时补弹，再执行本帧衰减导致的结束判定，避免同帧越过阈值又结束滑铲时漏触发；碰墙、离地、移动禁用等提前退出仍取消触发。

`AFPSGAMECharacter::TryCowboyReload` 分流单枪与 `UPistolDualWieldComponent::TryCowboyReload`。每次只在阈值事件按武器实例读取附魔；持有武器的容量来自现有枪匠计算，因此支持扩容弹匣。

`UColdSteelStatusModel::ReloadCowboyPistol` 复用 `SyncRuntime → Snapshot → CommitState`：一次事务扣库存、增加本枪弹数、清除待闭膛标记、更新左轮弹巢占位。保存成功后才停止换弹和播放声音；失败时保留原动作与库存。`CommitState` 的档案发布同步单枪与双持计数，再处理下一只手。

严格消耗真实弹药袋库存，不调用靶场无限弹药装填，不新增虚拟子弹；原有虚拟弹数标记保持。被动附魔补弹不授予手动换弹修炼经验。沿用当前单机档案持久化规则，不增加联机 RPC。

四处数据同步接入 `enhancement.json`、`items.json`、`dungeon_loot.json`、`tooltip-reference.json`；附魔台增加效果摘要，武器悬浮提示显示条件、扣弹与单音规则。
