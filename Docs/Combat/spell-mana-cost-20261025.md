# 魔法施法费用与装备减耗（2026-10-25）

按用户要求，法力减耗采用与近战体力一致的单件上限、装备乘法叠加和最终最低费用。技能自身的基础法力与随等级成长的规则保留。

## 公式

每件已装备物品的 `magicCostPercent`：

`b_i = bonusStats + bonusPerEnhance × 有效强化等级 + _enchantEffects`

`E = ∏ max(0.50, 1 + b_i)`

同件装备的基础、强化和附魔相加；不同装备的剩余费用相乘。单件最多减耗 50%，正值增加消耗仍正常生效。沿用既有装备槽筛选、非活动盾牌排除和强化上限。

`实际法力费用 = max(0, B) × max(0.20, E × W × T × R × F)`

- `B`：当前技能、当前或预览等级的基础法力费用。火系与电系技能原有基础成长的取整保留。
- `E`：装备乘区，见上式。
- `W = max(0, 1 + magicMpCostPercent)`：当前法杖改造乘区。
- `T = max(0, 1 + 连锁层数 × chainSpellMpCostPercent)`：连锁施法状态乘区，与法杖基础改造分开相乘。
- `R = max(0, Rune.MagicCost)`：现有武器符文／配件提供的魔法费用倍率。
- `F = max(0, focusEffects.manaCostMultiplier)`：活动魔法书处于聚能强化状态时的倍率，否则为 1。

最终下限在聚能之后应用，始终保留正基础费用的至少 20%。减耗过程中不向下取整，实际扣费保留小数，避免小额法术被取整成零。配置中明确为零的基础费用仍为零；无限法力等既有调试模式继续绕过扣费。

## 数值示例

以基础费用 40 的法术为例，下列除腰带外的装备组合为公式示例：

| 条件 | 实际费用 |
| --- | ---: |
| 基础星律腰带，减耗 10% | 36 |
| +15 星律腰带，减耗 25% | 30 |
| +15 腰带，另有一件装备减耗 10% | 27 |
| 上述装备，法杖倍率 0.8、连锁倍率 1.2、符文倍率 1、聚能倍率 0.5 | 12.96 |
| 所有乘区乘积低于 0.20 | 8 |

星律导能腰带配方保持基础减耗 10%、每级增加 1 个百分点、+15 时减耗 25%。腰带已通过 CombatBeltsIntegration20261025 完成 UE 资产与游戏物品目录接入。本页记录全局施法费用算法，实际游戏与联机由用户测试。

## 接入范围

- `Combat/ResourceCostFormula.h` 统一单件减耗上限 50% 与最终费用比例下限 20%，体力与法力共用这些规则。
- `EquipmentBonusFor` 对 `meleeStaminaCost` 和 `magicCostPercent` 返回装备乘积减一，继续支持消费者的 `1 + bonus` 约定。其他属性，包括冷却属性，本次不改。
- `SpellManaCost` 合并所有费用乘区。火球、冰刺、冰墙、暴风雪、闪电、圣光、冰甲、雷电迅捷，以及火系／电系系列法术的属性数据、扣费和快捷栏可用判断共用它。
- `ApplySpellCastSpeed` 仅应用施法速度修正，避免属性构造完成后再次折扣法力。电系系列从闪电模板复制属性时，模板仍不应用聚能，系列法术自身只应用一次。
- 聚能中断的最大法力比例损失、取消施法的既有退款以及无限法力模式不属于减耗公式；不新增存档字段或网络消息。

按用户规则不启动编辑器或进行游戏、联机、回归与验收。必要构建的记录保存于 `Saved/SpellMana20261025/MultipliersR1/`，实际游戏表现由用户测试。
