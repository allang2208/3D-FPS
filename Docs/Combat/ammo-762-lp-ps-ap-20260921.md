## 已有穿透公式和接入点

检查发现已经存在 `CoreCombatFormula::Defense` 的比例穿透，`CombatFormulaRuntime::WeaponHit` 区分物理与魔法穿透。没有新增第二套护甲体系。

物理有效护甲按既有顺序计算：

1. `穿透比例 = clamp(武器已有物理穿透 + 弹种物理穿透, 0, 1)`。
2. `有效护甲 = floor(原物理护甲 × (1 − 穿透比例))`，再应用既有腐蚀修正。
3. 沿用现有护甲减伤、取整、伤害下限、暴击、受伤增幅等流程。

例如目标100护甲且没有其他修正：LP按100护甲、PS按90护甲、AP按80护甲结算。AP的1.05伤害倍率在护甲减伤前应用；穿透只改物理护甲，不改魔法防御，不等于最终伤害直接增加20%。

`ColdSteelSkills::Snapshot(..., bFiredRound=true)` 在每次发射时保存弹药穿透，与当次伤害一起随飞行弹保存。近距离枪口阻挡命中、单枪即时射线及双持路径也使用相同采样。之后换枪／切弹种不会修改已发射弹；枪托、握把及其他近战调用保留默认false，不继承子弹穿透。伤害倍率复用已存在的 `AmmoDamageMultiplier`，不会在命中端再乘一次。
