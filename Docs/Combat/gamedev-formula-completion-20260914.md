# 后续公式迁移与命中/闪避数值移除

本轮范围：补齐上一份审计列出的公式，明确排除怪物基础属性、出生血量、基础攻击和成长。只对命中/闪避进行用户指定的源码检查；其余完成开发与必要构建，不运行游戏、截图或回归测试。

## 命中率和闪避率的检查结论

原版 `data/combat-formulas.json` 和 `src/entities/player/base.js:85–96` 确有 `hit=80+敏捷×0.5`、`dodge=5+敏捷×0.3` 两个遗留派生值。搜索原项目实体和战斗入口，没有发现这两个值用于随机命中/闪避结算。因此不能把源码遗留字段说成原版实际玩法。

按用户要求，UE 已删除这两个派生接口、CoreCombatFormula 字段、角色栏目和刷新逻辑；源对照脚本/Commandlet 字段列表同步去掉。主动闪避技能、位移、无敌时间、消耗及修炼保留。枪械稳定性说明中的“不代表命中率”仅是文字说明，不是数值字段。

## 精通与面板

新增剑、机枪、散弹枪、弓精通的定义/每级公式、等级进度、修炼、保存和冷钢详情。源 `data/skills.json` 为参数依据，既有技能进度不重置，存档版本升至 7。

- 剑：每级固定攻击+1、攻击间隔−1%；命中+1，至少两个有效目标额外+3，击杀+10。
- 机枪：每级力量+1、伤害+1%/+1，扩散延迟系数+0.1。
- 散弹枪：每级体质+1、伤害+1%，击退系数+1。
- 弓：每级敏捷+1、伤害+1%/+5、攻击间隔−1%；命中+1、暴击+4、击杀+9。

机枪/散弹枪/弓的基础伤害与属性公式可由现有通用武器入口读取。当前 UE 尚无这三类正式可用武器，因此扩散延迟和击退等专用字段只在技能效果中提供，未伪称有不存在的武器执行器。剑原定义中的 dexBonus 没有被原版 player/base.js 消费，本轮同样不凭空加入敏捷。

## 可调用接口与玩法边界

`UCombatStatusFormula::GetOrAdd` 与 AddCorrosion/AddMagicResistanceShred/AddMagicVulnerability/AddHolyWard/AddBleeding/AddBurn 可由 C++/蓝图施加，角色及怪物承伤端已消费状态。现有附魔中毒直接使用修正后的实现。尚未移入 UE 的减抗盾牌、施法技能或怪物不会被替换成其它触发器；对应效果需由其玩法入口调用。

`OfferTribute` 接收背包实例，成功献祭消耗一件并提交存档；`ApplyDungeonFormulaBuff`、`CompleteDungeonFormulaBattle` 提供地牢事件入口。UE 当前没有祭坛和完整地牢事件流程，本轮没有冒充完成这些场景/交互。`TributeEffect` 提供金币、掉落等原始倍率查询，尚无对应掉落生产者的倍率不会自动生成新奖励。

这是公式与现有运行通路的迁移，不是全量主动技能、怪物、祭品特殊能力、祭坛或地牢场景的迁移。怪物基础属性/成长未改。

必要构建已成功（模块后缀 9142252），结果记录于 `Saved/Logs/FormulaCompletionBuild.log`。本轮未启动游戏或运行回归测试，也不沿用上一轮 5321 项作为新代码测试结果；新的数值与交互交由用户试玩。
