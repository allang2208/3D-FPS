## 四、问题清单

**P1｜SVCh 对 SVD 是严格优势。**
两把公式同档（面板 1022 vs 1024），而 SVCh 在其余每一项都更好：间隔 0.30 vs 0.35（爆发 +17%）、换弹 3.2/4.3 vs 3.6/4.6、射程 320 vs 300、弹速 545 vs 520、散布 4.6 vs 4.8、稳定 1.18 vs 1.15、后坐 118 vs 120。两把的改造槽位也完全一样。SVD 没有任何一项优势，同档期内没有选它的理由。

**P2｜两把枪的公式零区分。**
系数、成长、强化收益完全相同，只有 base 差 1.75（0.2%）。真正区分两把狙的是射速/射程/换弹这些枪械数据，而不是伤害公式——想做出「一把偏单发、一把偏节奏」的话，公式得分开。

**P3｜狙击的瞬时 DPS 是全枪械最高。**
SVCh 3413 高于 201 轻机枪（3187）、HK416（2667）、A762（2910）；SVD 2920 也高于除 A762/LMG201 外的所有步枪。持续 1403/1262 也高于全部步枪（最高 HK416 1212）和刚调整过的 201 轻机枪（1311）。狙击的代价只剩 10 发弹匣与 4.6–4.8 的腰射散布。

**P4｜狙击的持续输出超过轻机枪。**
上一轮刚把 201 轻机枪的持续提到 1311，让机枪在持续上压过步枪；现在 SVCh 1403 又压在机枪头上（只有 PKM 1579 更高）。如果「机枪=持续」是定位，这条要处理。

**P5｜0.30 秒间隔让 SVCh 更像 DMR。**
200 RPM 半自动 + 1024 面板，配合 +100% 暴击与 +30% 要害，节奏上已经不是「逐发点杀」。SVD 0.35 秒（171 RPM）也偏快。

**P6｜300/320 米射程在当前地图等同无衰减。**
伤害衰减从有效射程才开始（此后线性到 2R 处 0.1），而步枪 85–120 米已经在掉伤害、机枪 130–160 米。狙击在现有交战距离内永远满伤，这是它相对步枪最实用的一条优势，但没有对应的代价项。

**P7｜目录里两套「伤害」数字并存。**
`items.stats` 写「物理攻击 85/88」，公式算出来是 1022/1024。浮窗已经跳过静态行改用计算值，但改造台的 base `damage` 85/88 只作为部件归一化分母（`Result × Base / W->Base.Damage`），单独改它不会改伤害——两套数字容易让后续维护误判。
