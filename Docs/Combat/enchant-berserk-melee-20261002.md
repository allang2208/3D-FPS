# 狂暴的：神话近战前缀

用户指定：名称「狂暴的」，前缀、神话稀有度，仅近战武器；使用当前武器以任意攻击形式命中敌人时获得狂暴，每层攻击速度 +5%，上限 20 层。用户在本次对话明确选择：命中只增加层数，不刷新减层倒计时。

## 数据与物品

- 附魔 `berserkMelee`，卷轴 `enchant_scroll_berserk`，`restriction: melee` 复用 `ColdSteelInventory::IsMeleeWeapon`，包含剑类和可持有作近战的斧、镐。
- 神话等级 `rarity/grade: mythic`；实现默认价格 16000、附魔魔尘 3200、堆叠 99、占格 1×2。沿用正式卷轴图标与掉落模型。
- 同时接入 `enhancement.json`、`items.json`、`dungeon_loot.json`、`tooltip-reference.json`；高阶地牢池（深度 8 起）掉落权重 1、数量 1。附魔台摘要与武器悬浮提示从同一效果字段显示。
- 实例沿用 `_enchantData.prefix` / `_enchantEffects` 与既有附魔保存事务。同槽位替换，后缀保留，无存档版本迁移。

## 命中与攻速

- `ColdSteelSkills::Snapshot` 捕获实际攻击物品的实例 ID 与完整四键参数；统一 `ApplyHit` 在敌人死亡前记录命中资格，结算后为射手加 1 层。普通斩击、突刺、重击、冲刺下砍、配重锤快速近战、旋风和斧镐自卫均沿用此入口与攻击端的单目标去重。
- 裂空剑气继承本次攻击的狂暴快照；环绕飞剑在发射时捕获并在实际命中时提交。换下来源武器后，尚在飞行的武器攻击不会替其他武器加层。近战附魔的附加攻击不另造伤害递归。
- 只有敌人接触触发；空挥、墙面、采集资源、友方、伙伴、死亡目标、枪械砸击及独立施放的魔法不触发。敌人的防御把实际掉血降至零仍属于命中。
- 狂暴属于射手的临时状态，倍率为 `1 + 层数 × 0.05`；20 层为 +100% 攻速。换武器后已获得的层数按原时钟继续消退，不转存为物品属性。
- 属性 `aspd` 和剑类攻击求值使用实时倍率；每次挥击捕获动作速度，保持动画、接触、冲刺与收势同一时钟。斧镐动作与旋风也接入倍率，原有攻速上限先作用于基础部分，再乘狂暴，避免吞掉每层收益。旋风冷却、伤害、修炼与同目标去重不变。

## 固定减层时钟与状态栏

- `UCombatStatusFormula` 沿已有临时状态 Tick 承载狂暴，不增加独立 Tick、定时器或逐帧 JSON。首次获得时设置下一次减层时刻为当前游戏时间 +5 秒；后续命中与满层命中均不修改该时刻。
- 每次到期减 1 层，并将下一次时刻加 5 秒；长帧按游戏时间补足已经到期的减层，层数归零后结束。本次先减层、再加层，避免到期那帧命中延期。
- 例如首次命中 t=0、再次命中 t=4，t=5 从 2 层降为 1 层，t=10 归零；t=4 的命中不把首次减层延后到 t=9。
- 正式状态目录增加 `berserk` /「狂暴」；HUD 与状态图鉴共用目录。状态卡显示实时层数、当前攻速收益和下一次减层的剩余秒数。层数变化才发状态通知；不使用会延长剩余时间的通用 `SetTimed`。
- 死亡状态读取为零，复活清算 `PurgeTransient` 清除狂暴；切图/销毁随 Pawn 状态结束，不写入玩家存档。沿当前临时状态组件的权威命中规则；未进行联机验收。
