“效果一致”指与 7.62x39mm LP / PS / AP 同一套数值：基础弹 1 倍伤害 0 穿透、中间弹 1 倍伤害 10% 穿透、高阶弹 1.05 倍伤害 20% 穿透。7.62 的那组数字原先只是该口径的游戏设定，本轮由用户明确扩展到 5.56；写成当时其余口径（5.8、.45、.357、12.7、9 mm、7.62x54R）仍是各自只有一种普通弹，不要顺带套用。**2026-09-22 更新**：`.45 ACP` 与 `.357 MAG` 已由用户指定各加 3 档（为了双持手枪长按 R 时轮盘能弹出），见 [手枪三档弹种](ammo-pistol-45acp-357-tiers-20260922.md)；5.8 mm 已由用户指定加 DBP87／DBP10／DBP191 三档，见 [5.8 三款弹种](ammo-58-dbp87-dbp10-dbp191-20260922.md)；12.7 mm、9 mm、7.62x54R 仍只有一种普通弹。

## 标识与兼容

- M193 沿用旧普通弹 ID `ammo_556`，因此角色原有 5.56 备弹、枪内已装填状态和迁移逻辑都直接接着用，既有奖励条目（`ColdSteelProfileRuntime` 初始发放的 `ammo_556` 90 发、各审计夹具建的旧 `ammo_556` 堆叠、F6 目录）继续发 M193。与 LP 沿用 `ammo_762` 的处理相同：不改 ID 后重新发一份数量。**不要**把 `ammo_556` 改名成 M855A1 或 M995。
- M855A1、M995 是新增类型，只进正式弹种目录，不自动赠送，不改掉落概率、商店价格或初始档案数量；获得后可在弹药袋与 R 轮盘切换。
- 三者共用兼容组 `ammo_556`。`gunsmith.json` 中使用该组的武器为 M4A1（`ue_m4a1`）与 M16A2（`ue_m16a2`），组内共用袋中余额，一把枪的弹匣仍只装一种弹种。
- `order` 为 10 / 11 / 12，落在 7.62x54R（5）与 5.8 mm（20）之间，组内顺序固定为 M193 → M855A1 → M995。目录里已经是三条兼容类型，M4／M16 的 R 长按轮盘会自动产生三个 120° 扇区；数量为 0 的类型保留扇区并灰显，不可提交。
- M855A1、M995 显式 `allow_infinite_reserve:false`：训练场无限备弹不适用于它们，也不能靠长按 R 免费解锁未获得的类型。M193 保留普通弹的无限规则。

## 战斗效果接入

没有新增第二套护甲算法，也没有新增弹种专用分支。全部沿用现有入口：

- `CoreCombatFormula::Defense` 的比例穿透：`穿透比例 = clamp(武器已有物理穿透 + 弹种物理穿透, 0, 1)`，`有效护甲 = floor(原物理护甲 × (1 − 穿透比例))`，之后沿用既有腐蚀、减伤、取整与伤害下限顺序。目标 100 护甲且无其他修正时，M193 按 100、M855A1 按 90、M995 按 80 结算；M995 的 1.05 倍在护甲减伤前应用。
- `ColdSteelSkills::Snapshot(..., bFiredRound=true)` 在发射时保存本次弹种穿透与倍率快照，飞行弹沿用发射快照；之后换枪／切弹不影响在途弹，枪托与握把的近战调用仍不继承子弹穿透。
- 伤害倍率复用 `AmmoDamageMultiplier`，只在射击伤害计算处乘一次。

公式细节与代码路径见 [7.62 LP/PS/AP 接入记录](ammo-762-lp-ps-ap-20260921.md)；本轮与之同源，不再复制一套说明。

## 源码与配置

本轮**没有改 C++**。弹种目录在角色子系统初始化时读取，轮盘、弹药袋、HUD、枪械详情、F6 发放列表都按目录长度和字段动态生成，所以加弹种只需要配置：

| 文件 | 改动 |
| --- | --- |
| `Content/ColdSteelData/ammo_types.json` | 5.56 组由一条普通弹扩为 M193／M855A1／M995 三条，带等级名、等级色、图片路径、倍率与穿透 |
| `Content/ColdSteelData/items.json` | `ammo_556` 条目改名 `5.56x45mm M193`，描述与 `ue_icon` 指向新等级图；只是旧物品定义的显示字段，弹药本身仍不占背包格 |
| `Content/ColdSteelData/Icons/Ammo55620260921/*.png` | 三个占位图（见下） |

已确认按目录驱动、不需要改动的入口：`UI/ColdSteelAmmoRuntime.cpp`（目录、兼容组、余额、切弹事务）、`UI/ColdSteelAmmoWheel.cpp`（按 N 等分）、`UI/ColdSteelAmmoPouchWidget.cpp`（按组聚合与效果行）、`UI/ColdSteelAmmoPresentation.cpp`（图标缓存与效果摘要）、`Development/ColdSteelDevelopmentTools.cpp`（F6 目录遍历 `AmmoTypes`）。枪匠界面的口径串来自武器 `ammo_item_id`，M4／M16 仍是 `ammo_556`，显示保持 `5.56 mm`；`ColdSteelWeaponStats::AmmoName` 也只按武器的组 ID 取名，未装填的新类型不会进这张表，所以不必为 M855A1／M995 加表项。
