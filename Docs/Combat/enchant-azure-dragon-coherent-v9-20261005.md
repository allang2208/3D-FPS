## 能量条

Reference V7 的原图投影浅浮雕已经被用户否定。本版不再把图片细节投射在薄片上：水晶为十二棱闭合外壳、九个带倒角的独立内芯，分段环与晶体亮边都有真实厚度；龙首有 S 形颈部、两侧独立鳞片、角、眉、眼、开口上下颚、牙齿和龙须；螺旋符文带、边轨和 44 个符文均为实体几何。

火焰改为 39 条闭合曲面火舌，分别有独立相位，局部顶点动画使根部附着在同一个能量条空间。长度、亮度和可见范围与充能相关，顶部苍炎在接近满条时增强；不增加灯、Actor、额外 Tick 或正对屏幕的火焰平面。四个组件共享同一悬浮原点、缩放和倾斜，符文真实围绕晶柱慢转。材质按几何表面法线统一透明亮边和表面明暗，不采样旧认可原图。能量仍从下往上积累，激活期随剩余时间消耗。

四个模型共 50,032 个三角面，维持四个显示组件／四个 MID。无性能采样或画面验收；面数是制作导出记录，不能用于宣称帧率结果。

## 龙爪

保留用户选定 Fab Dragon Claw 的原几何、法线图集与共享苍绿半透明材质。旧文件虽包含指骨，但待机一直从伸指起始姿势采样，有限卷指与整体平移也没有满足用户要求；不能以骨架存在或旧检查记录代替实际动作观感。

新母版有腕根、掌骨和五条三节指骨链（17 根作者骨，UE 可另含 FBX 容器根骨）。每指重新分配连续指根／中节／末节权重，指甲刚性跟随末节。弯曲轴由真实关节方向与朝掌侧向量求出，再转换到该骨局部绑定坐标，不假定统一 Euler X；卷指集中在中末节，指根只适度收束，保留指间开口。参考来源是现有 Mutant3 `claw_reference_20260923/claw_skin.json`，没有复制整身动画或更改突变体资产。

动画 60 fps、0.6 秒：第 0 帧即是微钩待机；前摇抬腕并稍张开，接触起点前收束，挥击时进一步内钩和压腕，尾段保持抓形后恢复。各指有轻微错峰。左右双爪保留两倍尺寸、镜像、侧面待机角度与交替攻击；普通攻击采用由外上侧到内下侧的斜向抓掠，重击下抓、上挑上掠，突刺短促前探。不是五根直指整块平移。

动画仍由剑最终 `Elapsed`／接触窗口／旋风相位采样；组件播放速率为零，不产生独立推进时钟，关闭姿态降频并固定完整骨链 LOD。加大组件剔除包围范围容纳弯指后下垂的爪尖；原缩放规则外乘 2 保留。
