## 表现方案

- 身份：可以辨认掌心、鳞片肢体、爪指与钩形指甲的立体龙爪；截断腕部通过透明度与雾化自然消失。保留真实三维轮廓，不仅显示几条爪痕。
- 色彩：苍青绿色主体，建议初稿主色 `#58B99B`，亮边 `#9CDBCA`；主体透明覆盖约 0.35–0.50，鳞片与爪尖局部更清晰，边缘有窄亮线。颜色与透明度是候选制作参数，尚未经用户实机确认。
- 位置：玩家前方约 1.2–1.6 m、略偏挥击侧；初稿爪宽约 0.8–1.0 m，掌心避开准星。以稳定攻击朝向建立局部空间，跟随实际挥击方向与短距离移动，保留真实透视；受场景深度遮挡，贴墙边缘用柔和深度衰减处理。
- 普通斩击：跟随本刀由右向左／左向右的扫动，约 0.35–0.45 秒，先聚出爪尖与掌形，快速扫过后留下短促苍绿轨迹并消散。
- 重击／下砍：龙爪从侧上方压下，轮廓放大约 20%–30%、轨迹稍厚，约 0.45–0.60 秒。增大的是视觉尺寸，实际剑击范围保持原值。
- 突刺：龙爪沿攻击方向探出，技能上挑从低位向上，冲刺下砍读取对应攻击阶段。用户进一步要求每个手指绑骨：当前在原模型上新建五条三节指骨链，加腕根／掌骨，共 17 骨；张爪、各指错峰抓握、随势收指和回弹均为新制作动画。
- 旋风：按实际旋转阶段依次扫过，不按每次命中或每帧重复生成一只爪；短轨迹跟随爪尖，有固定并发和寿命。
- 起点：攻击进入实际出手阶段就出现，空挥也显示；蓄力、检视、格挡和被取消的未出手攻击不生成爪击。不能把「攻击时」改成「命中敌人后才出现」。

## 运行接入设计

现有 `URuneSwordComponent` 有 `StartSwing`、`ContactStart` 和独立上挑／旋风时钟。新增 `RuneSwordAzureDragon.cpp`，普通攻击在 `bSwingCuePlayed` 的出手边界同步挥剑声音、`StartRift` 和剑气；上挑沿自身接触边界，旋风在两次实际转身出手阶段各触发一次。新特效不额外调用伤害函数，不进入 `ApplySwingHits` 的攻击判定，不触发感电、狂暴、吸血等命中附效。

附魔标记随档案／装备刷新缓存，在每刀开始捕获所属武器实例；龙爪表现不按帧或按命中读取物品 JSON。使用 `sword` 限制键，排除枪托快速近战、弓、法杖与采集工具。已添加附魔／物品／深层掉落／tooltip 四处数据及两处 UI 说明，卷轴 ID `azureDragon`、效果键 `azureDragonClaw`、物品 ID `enchant_scroll_azure_dragon`，传说后缀；价格／附魔粉尘沿用传说卷轴档。

异步预加载蒙皮网格／材质／手势，复用两只骨骼组件，仅活动爪采样骨骼动画；手势采样、透明度及整体轨迹共用特效年龄。单次动作时间按攻速缩放到 0.12–0.65 秒，旋风受击暂停时同步暂停；无动态灯、无碰撞、无阴影、无射线追踪。腕部渐隐、苍绿亮边、原模型法线细节及 12 cm 深度衰减一同制作；装备移除／死亡／动作取消／销毁时清理。保留原生近战动作、镜头、伤害和攻速。
