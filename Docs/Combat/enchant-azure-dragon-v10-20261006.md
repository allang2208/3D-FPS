# 苍龙附魔 V10：HUD 能量条与原创新龙爪（2026-10-06）

用户恢复开发后选定的返工路线：能量条走 **2D 屏幕 HUD 分层**，龙爪**放弃 Fab 手套底模按参考新建**。本文记录接入结构与边界，不代表用户已认可实机效果。

## 能量条 V10（屏幕空间 HUD）

- 分层源：百炼 `wan2.7-image` 图生图产出龙首等高清素材（`HudV10/Generated`），`author_hud.py` 离线烘焙五张贴图到 `HudV10/Export`：`T_AzureDragonHudEmpty / Full / Mask / Noise / Glyphs`，并量出参考图晶柱中心、角顶与九档充能高度写入 `Export/layout.json`。
- 材质：`M_AzureDragonHudV10`（UI 域、加法、无光照），`AzureDragonHud.hlsl` + `HudLayout.hlsl` 合成空晶柱／充满晶柱／符文带／晶片／火焰噪声，参数 `Fill`、`Age`、`Pulse`、`Burst`、`Reveal`。
- 呈现：`UAzureDragonEnergyComponent`（`Source/FPSGAME/Weapons/`）改为 HUD 桥；`SAzureDragonEnergyHud` 用 `FGameViewportClient::AddViewportWidgetForPlayer` 挂到 ZOrder 15（Cold Steel HUD 之下）、HitTestInvisible、volatile，每帧一个加法盒。充能只来自 `SetEnergy`：九击充满、激活期按剩余时间回落、击杀脉冲 `Pulse`、召唤绽放 `Burst`；位置按参考图比例随视口高度缩放，带漂浮与转向惯性偏移。
- 资源异步加载一次（材质牵引五张贴图），无每帧磁盘或重建；死亡／卸装／切武器按既有合同清空。
- 透明度修订（2026-10-06 用户反馈“能量条太透明”）：材质由加法改为 UI 半透明。晶柱玻璃体按遮罩遮挡背景（`BodyOpacity` 0.85 × 0.70–0.90，充能越多越实），龙首按自身纹理亮度遮挡，外围辉光区加 8% 暗衬；alpha 不低于像素亮度，颜色 = 原发光色 / alpha，暗背景下观感基本不变，亮背景下不再发白透底。入场淡入仍走 Slate 色调 alpha。`hud_preview.py` 同步为预乘合成，并输出亮背景新旧对比 `hud_bright_old_vs_new.png`。

## 龙爪 V10（原创新网格）

- 网格：`ClawV10/author_claw_v10.py` 在 Blender 程序化生成：四指三段骨节、关节鼓包、末端钩爪带根环、掌骨嵴、腕部七条烟须加两层包络。体素融合后 decimate 至约 4.3 万三角形（体 3.55 万／钩爪 0.46 万／烟 0.31 万）。

- 接入：`RuneSwordAzureDragon.cpp` 路径改指 `ClawV10` 三个资产；左右双爪、交替、镜像、待机侧面、激活期常驻、接触窗口内抓掠采样剑时钟等全部沿用既有代码，伤害与充能合同不变。烟须撑大包围盒后，`SphereRadius` 自适应缩放与 `FitClawCenter` 视锥压缩会自动把爪形压回画面内。

## V10.14：持续时间结束后龙爪化为粒子随风消散（2026-10-07）

用户要求：持续时间结束后，龙爪化为粒子随风消散，注意性能优化。

- **触发**：只有 30 秒自然到期才播放（`TickAzureDragon` 记录到期时刻）；死亡、切换武器、移除附魔仍立即隐藏。到期时正在出招的爪子边出招边消散。新一次召唤会取消残余消散。
- **爪体侵蚀**（`AzureDragonClawFabV10.hlsl`）：一条侵蚀前沿在 1.2 秒内扫过整只爪，爪尖和迎风面先消失。前沿带有颗粒感的亮青白边缘：颗粒噪声复用着色器里已经采样的鳞片细节和脉络雾，不增加贴图采样。C++ 每帧给出前沿进度（`Disintegrate`）、中心（与 WorldPos 一样相对相机）和方向（已除以爪长）。侵蚀过程中残余爪体顺风漂移约 1.4 米，手臂末端火焰同步熄灭；前沿扫完后爪子停止渲染。
- **粒子**：
  - 一个固定拓扑的动态网格承载两只爪的全部微粒，每个微粒是一个面向相机的四边形，只更新顶点位置（与火焰、裂痕相同的做法）。
  - 每次消散只播种一次：在爪子的蒙皮顶点中随机取有限数量，用 CPU 计算其蒙皮位置（引擎默认为骨骼网格保留 CPU 数据，即 `r.FreeSkeletalMeshBuffers=0`；没有时退回沿骨段取点）。
  - 每个微粒在侵蚀前沿经过它的那一刻诞生，诞生位置跟随爪子当时的漂移。之后受风（约 5.2 m/s，从玩家左侧吹向右后上方）、阵风湍流和上升力影响，寿命 0.75–1.15 秒，先长大再缩小消失，颜色由青白转为深蓝并闪烁。
  - 微粒材质 `M_AzureDragonClawDustV10`（`AzureDragonClawDustV10.hlsl`）：柔和发光颗粒，自身网格同样有近处遮挡。
- **性能**：
  - 数量：自己的龙爪每只 512 个；其他玩家的每只 256 个，60 米外不生成粒子（侵蚀照常）。
  - 每帧只移动正在飞的微粒，未出生和已消失的保持塌缩不再处理；整个效果约 2.4 秒，结束后组件隐藏，不再有每帧开销。
  - 播种时最多计算 1024 个顶点的蒙皮位置，且只算一次，不遍历整个网格；帧间隔上限 0.05 秒，防止卡顿后粒子跳跃。
  - 爪体渲染在前沿扫完后关闭。
- **联机**：拥有端在消散期间置位 `AzureFlags` bit6；其他玩家从首次看到该位起播放完整消散（服务端清洗掩码改为 0x7F）。
- 资产：本次安装（修订 10.14）保存 9 个资产，含新增粒子材质与更新的龙爪材质，材质编译无错误。安装脚本里设置网格 CPU 访问的尝试在 Python 中无法访问 `lod_info`，已移除，改为依赖引擎默认加运行时回退。FPSGAME 与 FPSGAMEEditor 构建成功（Editor 首次构建被另一会话编辑中的 `BoundCongregateTentacleGround.h` 阻断，对方修复后重试通过）；未实机测试。

## V10.15：所有消失途径都接入粒子消散（2026-10-07）

用户要求：死亡、切换武器、移除附魔等消散都接入这个效果。

- `BeginAzureDragonDissolve(Rate)` 统一入口：只在拥有端、龙爪正在显示、尚未在消散时启动，只影响表现；能量与激活窗口等玩法状态仍立即清空。
- 接入途径：
  - 30 秒自然到期（速率 1）；
  - 死亡：加速播放，速率 = 2.4 /（重生 2 s − 0.2 s）≈ 1.33，全程约 1.8 秒，赶在重生替换角色、黑屏淡出之前完成；
  - 切换武器、收起武器、换成另一把剑、移除附魔（`RefreshAzureDragon` 实例变化），以及附魔召唤次数参数变化。
- 消散不再依赖仍持有该剑：`LocalAzureDragonFrame` 中龙爪激活、出招和蓄势只在持有苍龙剑时成立，消散按开始时间独立播放。`ClearAzureDragonEnergy` 不再重置消散；新一次召唤才会取消残余消散。
- 顺带去掉两处“瞬间消失”：
  - `CancelAction` 不再调用 `StopAzureDragon`。原来每次取消动作都会让龙爪闪一下并丢掉跟随惯性，现在取消的出招按既有过渡回到待机。
  - 龙爪显示不再要求 `CanUse()`：打开菜单、翻越、建造期间龙爪保持显示，原来会消失再突然出现。
- 联机：拥有端在收起剑或死亡后仍上报苍龙表现字段，服务端转发不再限定持剑；`AzureFlags` bit7 表示死亡加速，所有 8 位都有定义，不再做掩码。
- 立即消失仍保留在一种情况：角色被销毁（EndPlay，例如断线、关卡切换）。组件随之销毁，无法继续播放。
- 物品附魔说明补充了这四种消散情形。
- 只改代码和附魔说明，无需重新导入资产。首次 Game 链接被另一会话进行中的 `ZhenmoRuneComponent`（缺少函数定义）阻断，对方补齐后 FPSGAME 与 FPSGAMEEditor 均构建成功。未实机测试。
