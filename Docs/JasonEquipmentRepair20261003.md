# Jason 背包与服装贴合修复

用户反馈：第三人称背包包体不可见、背带外翻悬空，锁子甲与身体穿插。截图与当前装备记录对应 `ue_mountain_backpack`、`ue_chainmail_shirt` 和 `ue_steel_gauntlets`。

## 原因

- 背包原提取脚本把 `X,-Z,Y` 这个行列式为 +1 的纯旋转当作手性反射，额外反转三角序。UE 的 OBJ 导入又处理了手性，最终包体朝里，外侧被背面剔除。
- 挂载参数按 OBJ 导入前的轴方向配置，但已导入静态网格的 Y 轴相反，背带位于 -Y。包体因此进入躯干，背带向后。
- 服装适配脚本用常规逆时针三角形叉积计算 UE 顺时针表面的法线，得到朝内的法线，并沿它施加“留量”。
- 身体 `SkinRest` 同时包含下肢与被长上衣覆盖的髋部；此前保留整个区段，腰部内衣会从下摆穿出。不能通过隐藏整个区段修复，否则腿也会消失。

## 制作与接入

`fit_jason_equipment.py` 先运行修正后的服装适配，再制作背包的 Jason 姿态与权重：

- 七件现有服装/手套保留原拓扑、UV 和材质；改为实际身体三角面的投射和重心权重转移，按向外法线留出贴合间距。
- 长上衣共同覆盖的髋部另设 `SkinCoveredHips`（材质区段 7），在下摆内留出边缘余量。装备上衣时隐藏，脱下后显示；腿部保留。
- 背包恢复外向三角面，按已导入网格方向旋转、缩放并移至 Jason 背部。包体绑定 `spine_03`，肩带接触段按肩背/胸部蒙皮，挂点根部和自由尾段保留包体跟随关系。
- 静态背包派生资产继续供应物品图标与静态回退；新的骨骼背包负责人物装备显示。`ApplyOutfit` 只有在未创建骨骼装备时才显示静态回退，避免绘制两个背包。
- 复用原装备 ID、存档和第三人称装备复制；本地和远端使用同一模型配置，不新增网络消息或每帧求解。

`save_jason_equipment.py` 将派生模型保存到 `/Game/Characters/ModularOutfit20260924/JasonPlayer20261003/EquipmentFit20261003`。保存完成后 `publish_jason_equipment.py` 更新当前身体、七件服装和背包引用，并保留其他配置修改。

原资产与改前配置保留在本机。后续重建入口同步修正了三角序、法线和髋部覆盖，避免重新引入旧错误。第一人称装备保持现有资产路径。
