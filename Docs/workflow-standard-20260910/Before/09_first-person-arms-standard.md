# 第一人称手模统一标准

AKM、P9 和后续 HK416 统一使用现有 Infima `SK_FP_CH_Default_Cubic` 手臂网格作为外观基准。新武器不再沿用下载模型附带的其他角色手臂。

## 外观真源

- 网格：现有 Infima 免费样包中的 `SK_FP_CH_Default_Cubic`，694 个原始顶点。保持低多边形手型、袖口、手套、拓扑和 UV；适配不同枪械时允许调整绑定姿态与关节位置。
- 贴图：`T_FP_CH_Camo_001_001_D.png`，与现有 AKM／P9 一致。
- 材质：沿用 `scripts/infima_viewmodel.gd` 的手臂参数：albedo tint `(0.62, 0.59, 0.53)`、roughness `0.88`、metallic `0`、specular `0.08`。贴图与材质乘色只应用一次，避免二次变暗。

## 动画适配

- 统一外观不意味着直接互换不同骨架的动画。保持各武器已有动画驱动，通过显式的肩、肘、腕、五指关节映射适配标准网格。
- HK416 保留 BURNER 的动画骨架及枪械机械骨骼；标准网格已按解剖关节方向映射到该骨架，Infima twist 权重合并到对应上下臂。原始 Infima 网格与 AKM／P9 资产不改动。
- 握持点、瞄具、枪口和弹匣是每把武器单独校准的数据；不能因统一手模而共用坐标。
- 后坐力应作用于整套视模。ADS 不额外驱动腕部去追逐每帧移动的瞄具；沿用现有稳定握持设计，接入新骨架时单独验证。

## 接入检查

检查腰射／ADS／开火／装备／普通及空仓换弹／收枪；检查手指握持、腕部扭转、袖口接缝及镜头裁切。逐帧骨骼有限值和包围盒检查仅用于排除数值错误，实际视觉及游戏运行仍需分别验收。HK416 继续使用 `weapon_data/hk416_audio.tres` 中已选定的 game-dev 音效。
