# ADS 水平后坐与数值显示

实际后坐、改造栏、装备浮窗共用 `FWeaponHandling`。ADS 水平控制角度新增固定九发循环（度）：`+0.180,+0.240,-0.300,-0.360,+0.420,+0.480,-0.540,-0.600,+0.600`，正值向右。循环独立于垂直第九发后的封顶，长连射继续左右偏转。垂直后坐恢复到首发时水平循环也从首发开始。

水平每发角度乘以已经结算的 `RecoilScale`；因此减后坐配件同时缩放垂直和水平后坐。稳定性/抖动不会重复缩放控制角度。腰射沿用原水平模式；ADS 在取样射击方向之后添加水平后坐，下一发跟随新瞄点，零随机散布合同保留。

改造栏与装备浮窗均显示三位小数：首发上跳、连射上跳/发、ADS首发水平/发、ADS水平上限/发。水平显示的是绝对值，原厂参考后坐指数100时分别为 0.180°、0.600°；垂直对应约 0.361°、1.123°。改造栏提供当前、改造后、差值和收益色，提示说明固定左右节奏与单发绝对上限。装备浮窗显示已安装配件结果。

例如减后坐20%与10%的配件相乘后为原厂72%，水平首发显示0.130°、上限0.432°；改造栏水平上限差值为-0.168°。这些来自与角色实际偏转共用的方法，不是独立填入的说明文字。
