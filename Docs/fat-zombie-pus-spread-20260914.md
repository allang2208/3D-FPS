# 胖子死亡脓液逐渐扩散

用户已确认主场景能看到脓液，本次按要求增加铺开的过程。

## 表现与时间

- 死亡时立即出现尸体脚下的一小片液体，初始半径约为最终半径的 6%。默认在 1.6 秒内铺成完整液洼，前段流得快，接近外缘时逐渐减速。
- 按既有随机轮廓向外显现，不移动地面采样点、不缩放整张网格。液体继续贴合原地面，保留已确认的黄绿色、水体法线、湿润粗糙度和浮沫。
- 外围液滴使用每片已有的随机值错开出现，并从各自中心逐渐铺开。扩散不会每帧重新随机外形。
- 可在胖子的 `FatZombie|Pus → DeathPus → SpreadSeconds` 调整扩散秒数；默认 1.6，设为 0 为立即铺满。运行时上限为伤害持续时间，以确保消退前完成扩散。
- 按用户后续要求，伤害期调整为从生成起计 20 秒，随后 1 秒干燥消退；扩散过程包含在这 20 秒中。各怪物尸体默认统一在死亡后 15 秒回收，脓液独立保留至消退完成。死亡动画和后续布娃娃时序保持原有设置。

## 伤害与显示同步

顶点颜色 B 保存液体到达该点的进度，A 继续保存最终覆盖。材质 `SpreadProgress` 控制软化的扩散前缘，默认材质参数为 1，Actor 在生成时改为初始进度。

扩散阶段按每帧的世界时间更新进度，结束后回到原来的 0.05 秒材质更新间隔。伤害仍每 0.5 秒一次；伤害节拍使用相同进度，将地面三角形裁到已铺开的部分，再计算角色脚下接触。尚未出现的外围区域不会提前造成伤害，脚掌与扩散边缘相交时仍可接触。完整形态后的判定、阵营与离地限制保留。
