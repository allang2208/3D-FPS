# 双持弯刀：镜像左臂、双刀动作与双刀拔刀（2026-10-25～28）

来源：尼泊尔弯刀双持（`SourceAssets/DualKukriIdle20261025`，记录 `Docs/Weapons/dual-kukri-idle-20261025.md`）。任务是"一把刀一套动作"扩到"左右各一把同时打"。按问题读取；历史验收不授权自动重测。

## 左臂不要另拟合，直接当镜像右臂解

- **共享剑手臂骨架左右是精确对称的**（每根 `*_l` = `Rot_X(180) · mirror(*_r)`，绑定位置差 < 0.6 cm）。所以左臂的解法是：先在**镜像空间**里当作右臂，用已认可的右臂求解器（`kukri_rig.arm_eval` / `pose`）解出世界旋转，再逐骨换到左链：
  `world[k_l] = T(world[parent].point(base_local[k_l].p), qfrommat(ROT_X180 @ qmat(src_r.q)), s)`。
  位置取左骨自己的局部平移，旋转取右骨的镜像——两条都要，少一条就对不上。
- **左手刀 = 右手刀绕刀面镜**：`left_kukri(K) = T(to_left(K.p), qfrommat(F·qmat(K.q)·FY))`，`F=diag(−1,1,1)`、`FY=diag(1,−1,1)`。刀网格本身关于刀面对称到 0.13 cm，所以左手的刀柄握持就是已认可的右手那一套，不用重新验收握法。
- **目标也镜像**：参考读数只量右手的屏幕目标，左手目标就是把 x（屏幕横向）和"向自身一侧"的分量取反，交给同一个虚拟右臂 fitter。左手的解剖诊断同样是镜像空间的量（伸/屈、尺/桡偏符号按左手约定再读）。

## 双刀动作的编排：两只手永远不同时占同一块空间

- 单手动作直接搬过来时，两只手会撞。有效做法是**错开**，而不是让两只手同时走各自的路径：
  - 连击 1/2（`author_dual_attack.py`）：右手先按单持该段挥完并沉到画面下方垂手位，左手在偏移（56/120、60/120 s）后按镜像再挥一次；两把刀各用自己那一段的命中窗、打击时刻、镜头和剑气（左手的左右分量取反）。
  - 第三段双刺（`author_dual_attack.py` 的 `THRUST` + `fit_dual_thrust.py`）：两只手从画面下角**同时**沿刀身直刺，左右镜像但左拳低 3 cm / 近 8 cm，让两把刀一上一下错开（严格镜像会在刀尖相交处切进去约 0.5 cm）。
  - 双持重击（`author_dual_heavy.py`）：两只手同时交叉 X 斩，左手按"与右手同时刻的胶囊间距"约束单独拟合（`fit_dual_heavy.fit_pair`），交叉之后左拳略深略低从右臂下面滑过去。
- **清隙用真实网格距离场，不用胶囊**（`kukri_sdf.py`）：刀与刀、刀与对侧手臂蒙皮。段胶囊只能查手臂之间；换了更长的刀身模块（猎手刀身 +10 cm）必须换成对应包络重查（`KUKRI_SDF_VARIANT=hunter`）。
- **镜头**：双刀同时出手的动作，镜头曲线要两只手合成——同时出手的相加（或取更强的那个），先后出手的把第二段延迟 `DualSweepOffset(Stage)` 再叠一次（左右分量取反，`KukriRhythm::DualSweepCamera`）。

## 双刀拔刀：把"刀离手"的飞行镜像到第二只手

- 单持拔刀的刀在 `WPN_root` 上飞行，握持锁按作者偏离量淡出/淡入（≤0.6 cm 锁死、≥2.5 cm 放开）。**第二把刀不是骨骼**（它是挂在 `hand_l` 上的组件），所以它的飞行不能写进 clip：要把"相对手"的变换按 60 Hz 烘成一张表，运行时读表驱动组件。
- **表的口径和运行时挂点一致**：`OffhandHandToBlade()` 是"位置 cm/100、缩放 0.01"，表也要按这个单位写（`{qx,qy,qz,qw,x,y,z}`，FQuat 的顺序是 x,y,z,w）；写错顺序表现为刀在手里乱转。
- **镜像的飞行会撞**：单手拔刀在空中越过画面中线、接住后刀身也横过中线，严格镜像两把刀会在空中和接刀后各撞一次。做法不是改飞行轨迹，而是**给两只拳（连同手里或空中的刀）加恒定的外移和前后错开**，用手臂 IK 平移手的位置、保留手的朝向/手指/前臂扭转；外移要在刀出手之前（手还在画面下方）就完成，飞行形状不变。
- **接刀的前后错开**要接到双持握姿的真实前后关系上，这样从拔刀进握姿是自然的，不用额外混合。

## 运行时记录

- 双持族（Idle/Walk/Run/连击/重击/拔刀）用一个 `IsDualClip()` 判断，左臂进出这一族时单独淡化 0.25 s（`CaptureLeftEntry`），右臂仍走 clip 自己的进入混合。
- 双持运行时会让右手握持锁一直锁死（为了冲刺反握），**拔刀 clip 要例外**，否则右刀飞不出去。
- 握刀的那只手做动作时要把左手刀的跟随关系一起算：命中判定、剑气镜像、镜头左右分量、视模冲击左右分量，都是成对改的。
