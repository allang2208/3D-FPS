# 弹匣抓握的跨枪配准与精度修复

2026-09-25，M4 / M16 换弹左手"没有精准抓握弹夹"的排查与修复。这里记的是可复用方法，不是某一把枪的数值。案例入口见 `SourceAssets/M4M16ReloadGripFix20260925/`，量测表见 `Docs/Weapons/m4-m16-reload-grip-precision-20260925.md`。

## 先把抓握存成弹匣自己的关系

换弹的左手握持是一个**弹匣坐标关系**：

```text
R = (MagDeform @ ShellFrame)^-1 @ hand_world
hand_world' = MagDeform' @ ShellFrame' @ R
```

`ShellFrame` 必须完全由弹匣自身网格算出，不能靠挂点或武器空间猜：

- **长轴**：按弹匣脊线（逐切片质心）拟合，不用整体 PCA 的弦——弯弹匣的弦与握持处的局部轴差好几度。
- **长轴方向**：按该 clip 的**插入方向**定向（底盖 → 供弹口）。插入方向 = 弹匣挂点在**武器空间**中从取匣帧到入匣帧的位移，再转回弹匣 rest 系；直接比较挂点自身位置恒为零（弹匣随骨刚性运动），这是个容易踩的空测量。
- **薄轴**：取截面内最短轴，符号指向掌侧；符号错一次手就跑到弹匣另一面。
- **原点与高度**：原点取该高度处壳包围盒中心，高度按"距底盖"计。高度参考点（指根/腕点）在哪一步用，后面每一步都要用同一个，否则旋转支点被挪动，校正量会悄悄变。

R 与坐标基底无关（世界系、挂点局部系都一样），所以可以直接跨枪搬运；`ShellFrame` 的约定必须两边一致。

## 跨枪搬运：常量偏移做不到

把一条已认可动作搬到另一把枪时，**不要**在武器空间里加一个手估平移。两枪弹匣壳相对挂点的位置本来不同，常量既表达不了握持高度也表达不了壳截面；实测该做法让食指近节埋进壳内 21 mm、小指浮出 16–20 mm（对基准剖面的误差平方和 2530，重做配准后 269）。

搬运步骤：

1. 从已认可动作取出 R（在它自己弹匣的 ShellFrame 里）。
2. 目标枪按自己的弹匣壳算出 ShellFrame'，高度按**同一约定**取。
3. 不同长度弹匣的高度约定要用数据选：把候选高度各算一遍，按对已认可剖面的误差挑，不要凭直觉。30 发直弹匣案例里"距底盖等高"误差 268、"距供弹口等高"误差 3475（手被推到弹匣颈部）。
4. 只重写左手链与肩肘，按 clip 自己的握持权重进出；弹匣轨道、另一只手、枪根与全部机械 cue 不动。

## 在弹匣截面系里做有界刚体校正

若现有动作本身可接受、只是偏了几毫米（例如手型来自另一把枪的已认可包握），不要重跑整手拟合，先在弹匣截面系里搜 6 个自由度：

- 手网格只求值一次，每个候选按刚体移动；搜索因此是秒级，可以多跑几轮随机 + 局部细化。
- 界要收紧（案例用 ≤10 mm / ≤12°），目标写成"各部位中位间隙对齐已认可剖面"。
- **同时把机匣净空写进目标函数**。案例里不写这一项，最优解会把拇指推进机匣 23.6 mm；写了以后剖面略让步、机匣穿透从 19.6/17.5 mm 降到 3.5/3.5 mm。只优化弹匣接触会把问题挪到枪体上。

## 量测口径

- 逐骨分组统计**到壳面的中位间隙**，分组用主导顶点组；`hand_l` 组含腕背，中位数天然在 40 mm 量级，别把它当成掌心间隙。
- 最近面法向的"内外"判据对远离表面的顶点会误报（实测出现过 -128 mm 的假穿透）。穿透深度只在贴近表面（<25 mm）时采信，其余按 0 计。
- 以**已认可动作**做基准，而不是绝对零间隙：已认可的 AKM 包握在小指中节本身就有约 15 mm 间隙，把"到处都贴住"当目标会做出僵硬的手型。
- **出图脚本要在下笔后按同一口径复量一次**，预测与实测一致才算过。案例中出现过两次"搜索预测与导出对不上"：一次是搜索在弹匣 rest 系量、校正却施加在另一个基底；一次是握持高度一边用腕点一边用指根，等于换了旋转支点。两者都不是搜索不收敛，而是坐标系用混了。

## 渲染与判读

在弹匣自身的 rest 系里画对比图（原点取壳包围盒中心、三轴取弹匣自己的轴），前/后/基准三张图里弹匣位置完全相同，肉眼能直接比较手指是否包住壳，比固定视角的局部图可靠。截图只做定性确认，最终观感仍由用户判读。
