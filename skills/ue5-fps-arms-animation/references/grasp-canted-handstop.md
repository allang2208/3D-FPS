# VRE 抓握扩展到 45° 握把和阻手器

2026-09-12 案例：`SourceAssets/VREGripExtensions20260912/README.md`。用户认可垂直握把的改善方向后，授权用相同方式更新 M4 / AKM 的 45° 侧倾握把与棱镜阻手器。本轮四个动作族仍待用户视觉评价。

- 复用已实际查看的 VRE `GrabAnimation` 手型，保留指骨之间的相对关系、目标骨长、局部位置和缩放。整手适配挂点；不要为了每根手指避开模型而再次破坏成组包握及拇指对掌。
- 先确定配件真实本体轴和握持中心，再参考现有手臂来向调整整手。腕轴近乎共线仍可能伴随过大前臂扭转；同时检查前臂 twist、肘部和实际玩家视角。此例严格按斜握把轴定手型会扭臂，最终围绕握持中心混合到原腕方向的 75%，保留同一套指骨姿态。
- 45° 握把使用 80% 原始闭合幅度。短阻手器使用 90%，手整体包住短件；用户明确允许阻手器内部穿模，此许可不能扩大为所有配件的零检查。记录可见外形及内部交叠，二者分别判断。
- 各族含 idle、aim、fire、aim_fire、equip、reload、reload_empty、drum_reload、drum_reload_empty。只改变左臂持握、退握和回握，保持原取弹、插入、压实、枪机接触和右手/机械运动。验证四元数时接受 q 与 -q 的旋转等价，不把符号连续化误报为接触变化。
- M4 新路径为 `M4VREGripExtensions/{Canted,Prism}`；AKM 为 `AKMIntegration/SovietFab/GripVREExtensions/{canted,prism}`。保留 `GripVRENatural/vertical` 与原 angled 分支，运行时读取实际加载路径。
- 本轮 36 条源合同和 36 条 UE 保存后回读通过，四个新游戏进程用于改造/保存重载、瞄准开火、装备、四类换弹、回握、拆卸及跨枪切换验证。查看 `Final/validation.json` 的实际运行结果，勿以数值通过代替用户视觉认可。
- 交付每族含 9 动作的可编辑 Blend、逐条 FBX、源姿态前后图、真实 UE 玩家视点/掌侧/腕肘和换弹序列。截图序列视频按日志时间重建且无声，不称为原生帧率录屏或音效验收。并行会话改变了手套材质时，保留当前素材，明确源图与实机材质不同。

来源、镜像和许可遵循 [现成抓握源](github-grasp-donor.md)。未核准原始素材、导出的动作矩阵与二进制留本机；公开作者脚本、验证摘要和精确运行接入补丁，并说明外部依赖。
