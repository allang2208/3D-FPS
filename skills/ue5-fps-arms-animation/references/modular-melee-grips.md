# 改造握把的手部适配

用于同一把近战武器在不同握把长度间切换。寒晶长柄在 2026-09-19 获用户确认符合预期；保留当前动作身份，不将此案例参数套到新武器。

## 输入与接触

先查看已有动作参考，并读取当前实际加载片段的时长、帧数、骨架父子关系、驱动骨空间和左右腕位置。区分握柄、扶剑、松手、重新握持；仅按动画名称无法判断左手职责。

本例现有左腕握柄时在武器空间 z≈-0.173063 m，挥砍时会绕柄旋转；格挡时左手移到剑身，检视与装备有离手阶段。用纵向位置与径向距离的平滑权重识别实际握柄区域，避免把左手整段固定在柄上。

## 制作与切换

1. 普通握把保留原接触轮廓，优先继续使用已接受动作。长柄保持上端和右手区域，柄尾与配重锤联动平移。
2. 在独立目录复制当前动作家族，保留原时间轴、武器/右手轨迹及手指局部曲线。按武器轴为左手生成握持目标，不改手指来弥补腕部错位。
3. 通过完整左臂链调整关节转动，保留骨段长度和原肘弯曲方向。优先两骨解算；接近伸直时加入锁骨支撑。超出可达范围时收敛新增握距，不拉长骨骼。
4. 松手、扶剑与入场区间平滑退出握柄偏移；源动作中的离手意图与接触时钟继续有效。
5. UE 可用 `AnimPoseExtensions` 按源帧采样，`AnimDataController.set_bone_track_keys` 写入副本的指定骨轨道。先完整读取源数据，再写副本，避免采样到半改状态。
6. 保存逐帧可编辑数据及 FBX/动画资产。包含许可不明源动作的密集姿态数据仍属于本地资产，不随普通 JSON 公开。
7. 运行刷新同时比较武器、手臂网格和动画目录；只换握把时也切换到对应家族。基础格挡/弹反音效不从新动画目录找。

寒晶实现仅调整 `clavicle_l / upperarm_l / lowerarm_l / hand_l` 的旋转轨道，保留其余既有轨道与局部平移/缩放；14 个源片段均保持原时长。17.7→20.5 cm 的柄长变化对应配重锤下移 2.8 cm、左腕最多下移 1.8 cm。作者入口为 `SourceAssets/FrostSwordGrips20260919/author_long_grip_animation.py`。

模型/槽位接口见 [近战武器拆分](../../ue5-weapon-workflow/references/modular-melee.md)。默认由用户进游戏测试；不因写入成功或构建完成宣称已自动验证手部表现。
