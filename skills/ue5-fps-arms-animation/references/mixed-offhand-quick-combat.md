# 混合主副手的斧头下劈与恢复

主手手枪或法杖、副手单手斧时，优先直接采样已安装 `PairAttack3KH` 的原生左臂第三击和 `hand_l` 握点。2026-11 的旧右臂镜像 `OffhandHatchetChop.h` 已退役，不再重建它。镜像规则仍适用于没有原生同侧动作的其他武器，不能把这次退役推广到所有镜像动画。

- 待机保留用户认可的肩、肘和前臂位置，只在手腕/掌指与斧柄接触处调整角度；斧柄尾部可朝镜头偏转，刃向前，避免旋转整条手臂来迁就模型。
- 主手避让跟随副手的准备、出力和收势分段，采用有缓入缓出的弧线；不用整个动作一条线性位移。手枪从起手实际姿态接入，法杖支撑偏移和武器同时淡出。
- 收势目标每帧读取当前待机姿态，包含移动/呼吸；中断保存当时双手避让量，再向当前待机恢复。不要在收势末尾切到另一张静止快照造成卡顿。
- 本次成功起手时保存 `QuickActionRate`，执行、恢复、权威占用期限和第三人称进度共用这个倍率。迅捷中途到期不能改变同一次动作速度；命中停顿按原独立时钟处理。
- 空间扰动取实际副手刃部扫掠，远端采用对应身体动作分支。动作数值/复制检查与指节接触、穿模和主观节奏分开交付。

入口：`OffhandAxeQuickMotion.h`、`OffhandQuickClearance.h`、`OffhandKukriStrike.cpp`、`StaffOffhandQuickMotion.h`。本地案例与范围见 `Docs/Publication/ConversationCombat20261109`。
