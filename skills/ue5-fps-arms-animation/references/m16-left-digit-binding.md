# M16 开掌时手指变细的绑定修复

施法和换弹开掌时手指变细，先区分缺少三角形、隐藏／缩放与混合绑定压缩。本例源与渲染网格都有五指、完整权重及公共 V7 拓扑，运行没有隐藏指骨；根因是将中立公共手预蒙皮到 M16 卷曲 mesh bind 后，动画又对该卷曲 inverse bind 混合蒙皮。只调整烘焙顶点或把第一次 LBS 换成 DQ 仍会留下问题，用户已否定位置补丁。

当前修复只把 19 根左指骨参考旋转（含掌骨）换为公共 V7 中立旋转，保留局部位移、尺度、层级、手腕／前臂、右手、机械骨和共享 USkeleton。用公共 V7 原坐标重制裸手，手套从修改前源恢复后按同一中立参考重绑。`SkeletonModifier` 提交 per-mesh 参考姿态并重建 inverse reference matrices，再写匹配几何和现有 LOD；保留动画及材质槽。

必须确认现有动作包含被修改参考骨的关键轨迹；本例保留的 50 条 M16 原厂／配件动作覆盖这 19 根骨，动画仍提供原生握姿。程序施法从网格参考姿态派生指轴，组件重载后采用中立参考。

入口为 `SourceAssets/M16Repair20261002/NeutralBind`。初版废案在 `trash/weapon-arms-publication-20261003`；原目录八份 `position_patch.json` 和 `installed.json` 是新安装器比对之前已装位置及包哈希的依赖，不能跟随旧脚本一起移走。八个正式网格已保存，修复后观感仍由用户测试；公共 V7 源已获认可不等于本次 M16 派生已获认可。
