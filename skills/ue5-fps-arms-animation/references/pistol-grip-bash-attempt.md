# 手枪握把砸击程序化尝试（2026-09-17，未获认可挂起）

单持手枪的快速进战近战：松开左手、右手持枪以握把向前猛砸。程序化姿态层 V2（参考 COD4 UZI 枪托近战节奏，B 站 BV13K421e7Rw 45–47s）被用户否决，**挂起待下次开发**。实现入口 `Skills/FPSQuickCombatComponent.*`、`Skills/QuickCombatPistolMotion.h`、`FPSCastingMeshComponent::ApplyQuickCombatPose`；案例与数值见 `Docs/Skills/quick-combat-placeholder-20260917.md`。本页记录可复用的机制结论与未解决项，不把挂起状态写成可用功能。

## 可复用的机制结论

- 双臂+武器组的入场快照与局部混合沿用火球模式：链骨走向两骨 IK 解（恒骨长、93% 肩带支撑、前臂继承掌侧 roll 的闭式解），手指/子骨按类别跟随；**锁骨保持动画驱动**，避免肩部僵死。
- 视模武器不挂在手骨链下时，脱手/砸击类动作需把武器组当刚体搬运：目标 = 「目标手 × 入场手⁻¹」差值作用到入场武器根，再**一次性**转回网格空间。乘法顺序或空间转换错一次，武器每帧吃一个垃圾变换直接飞出视模——本案实际发生的失败，位置在 `ApplyQuickCombatPose` 的武器搬运段，已修未验。
- 左手手指张开度可借用火球的手型配置与逐指延迟曲线（同一副 Manny 手模），不必另做一套语义。
- WPN 组挂接关系（挂手/挂骨架根）须运行时检测，不能假设 M1911 与 715 骨架一致；两种情况分别对应「手腕自然带动」与「整组差值搬运」两条路径。
