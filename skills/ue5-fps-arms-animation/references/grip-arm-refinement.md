# 配件改造后的手指、腕部与肩肘优化

跨枪复制抓握、45° 安装倾角、目标安装座避让及 RAW/COMPRESSED 求值差异，另见 [45° 握把与 AKM 迁移](canted-akm-migration.md)。

用于握把缩放、穿孔手指数改变，或“已经抓住，但手腕与胳膊衔接僵硬”的反馈。先按 [改造配件标准](../../ue5-weapon-workflow/references/attachment-standard.md) 确认当前模型和动作，再按本页选择修改层。不要把手指接触问题与整臂支撑问题混为一次重新拟合。

## 1. 先固定已接受的部分

- 区分用户要改的是配件尺寸、握持方向、手指参与方式，还是腕肘衔接。若抓握已被接受，先缓存枪根局部的手腕矩阵、手指局部姿态和实际手套接触，优先只调整肩肘与前臂；不能默认重新卷指或旋转整只手。
- 查看同一姿态的第一人称、掌侧、手背至肘部近景。记录真实加载的动画分支、骨架 rest、袖口与权重；手指无相交不能证明腕部自然，单一掌侧截图也会遮住腕背折角。
- 若肩肘调整仍不能满足自然支撑，再按用户允许范围改变整手方向或接触位置，并重新检查穿孔、对握及退握路径。不可用缩放手臂、拉长骨段或移动手指关节来追目标。

## 2. 腕部折弯：先诊断整条链

将枪根、手腕和肘部放在同一坐标系，分别看前臂方向、手腕相对 rest 的方向与轴向扭转。可用以下轴线夹角辅助比较同一 rig 的修改前后：

```text
forearm_dir = normalize(wrist_position - elbow_position)
rest_dir = normalize(rest_wrist_position - rest_elbow_position)
hand_aligned_dir = hand_pose_rotation * inverse(hand_rest_rotation) * rest_dir
wrist_axis_bend = angle(forearm_dir, hand_aligned_dir)
```

此角度是骨架轴线指标，不是人体医学关节角，也不是验收阈值。先排除局部轴和骨架适配错误；折弯与绕前臂的扭转分开诊断，不因折弯大就增加 twist 补偿。

- 手腕位置正确、前臂却接近伸直时，固定握持关系，检查肩部可达范围与肘部弯曲平面。让肩带支撑姿态、双骨链肘部 pole、前臂 roll/twist 共同适配，而非只旋转腕骨。
- 支撑肩带的偏移或旋转应从实际姿态测量。第一人称无躯干视模可以有专用支撑姿态；全身角色需把躯干、锁骨活动与肩部连续性一起约束，不能直接照搬视模的平移补偿。
- 上臂和前臂长度、rest、蒙皮与手指尺寸保持。检查锁骨到肩的连接、袖口、肘形和相机遮挡，不能靠隐藏胳膊掩盖问题。
- 检查最终求解结果而不只看输入参数：自动伸手补偿可能抵消肩带调整。记录偏移相对哪个源动作、是否替代旧补偿，以及实际肩肘腕位置；不能把相对原源的参数误报为相对上一版的新增位移。
- 世界目标先缓存，再按父子层级重建局部矩阵；具体公式见 [姿态与接触方法](pose-contact.md)。不要边写父骨世界矩阵边读取未更新的子骨。

## 3. 配件缩放与穿孔手指数变化

- 用户明确要求缩小配件时，以安装接触点为枢轴缩放几何。例如缩小 25% 是三轴尺寸乘 0.75；作者导出和 UE 实际网格包围盒均验证比例。手、骨架、安装坐标不能跟着整体缩放；保持原配件 ID 时同步描述与实际资源引用。
- 明确哪些手指穿孔、哪些在外侧对握或贴合。不能只移开指尖就判定“小拇指未穿孔”；看实际变形手套、近节与中节的路径、外缘贴合和掌侧/背侧渲染。
- 先定掌面与手腕整体位置，再在已辨认的局部屈伸轴上有限调整 MCP/PIP/DIP。搜索可综合相交、外侧约束、贴合距离、姿态连续性与偏离原姿态的惩罚；零相交或单一最近距离不能作为唯一目标。
- 某指留在孔外时，退握不能自动套用“全部手指展开”的旧曲线，否则稳定帧正确，中间帧仍可能重新穿孔。

## 4. 缩小开口后的退握与回握

静止无相交不保证能顺利松手。保留弯指直接侧抽可能擦过后缘；展开再侧抽也可能碰到前支撑边。先检查实际扫掠，再按各指空间安排松指、侧退和小幅根关节屈伸，不把固定先后或某条避障位移当作所有配件的模板。

- 对碰撞集中的短区间密集采样，按手指及配件部件记录首次碰撞。先用受限候选比较局部路径，再按正式采样率烘焙；候选低频报告不能验收最终 FBX。
- 可分别求解三根手指的小幅 MCP 修正，并保持 PIP/DIP 自然连续；检查关键帧之间与 UE 压缩后姿态。掌骨大旋转、长混合与盲目增加采样都不能代替正确路径。
- 回握可从已通过的退握路径反向构建，但仍独立检查与原动作混合的中间帧。肩带支撑也随接触权重退出/返回，避免换弹中突然跳肩。
- 只修改支撑、脱离与回握区间。取弹、插入、压实、拍击、右手、枪根、弹匣轨道及业务时钟保持；普通和空仓、普通弹匣和弹鼓分别验证。

## 5. 验证层与证据

1. 对原动作检查上臂/前臂长度、骨骼缩放、手指局部平移、非目标侧及保留接触段。若握姿不改，再单独对上一版比较枪根局部手腕/手指位置与旋转，避免“更自然”悄悄改变已接受抓握。
2. 记录腕部轴角、肘部余量和实际肩位变化，用同视角前后图确认袖口连续、腕背轮廓和肘形。角度改善不是单独的视觉通过依据。
3. 检查稳定姿态、装备、退握、回握及换弹接触的真实表面；注明采样密度、范围和对象。手指/配件采样无交叉不等于整个手臂、整枪和连续时间绝无穿模。
4. 导入新动画目录并读回时长、骨架与 RAW/COMPRESSED。仅修改胳膊时复用原配件模型和材质，不为动作优化重导一套同样的静态资产。
5. 新进程确认实际动画路径、第一人称及腕背近景，并验证受影响的 ADS、射击、装备与四种换弹回握。保留 Blend/FBX、参数、前后比较和运行记录；未改声音不另编排音轨，静音预览只作视觉证据。
