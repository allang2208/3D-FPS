# 手枪动作迁移与 M1911 经验

沿用项目统一 Manny 手臂/手套，优先参考现有手枪动作。系统接入、装备打断、配件与展示见 [手枪工作流](../../ue5-weapon-workflow/references/pistols.md)。

双持自然握姿与准星、连续奔跑、左右甩仓和单持退壳避让见 [双持手枪与左轮动作](pistol-dual-revolver.md)。该页记录当前入口、已否定版本及待用户测试的候选边界。

- 迁移前区分 donor 的手臂动作与枪械动作；记录双手相对枪柄、弹匣的接触，而不是将 donor 的世界位移直接写到另一个参考骨架。清理参考姿态与局部轴之后，再适配整手、腕肘和手指。
- 枪体不能用手模的整体缩放掩盖方向问题；将枪械主根和模型作者坐标明确分开。M1911 曾出现反向/画外和手部扭曲，分别属于朝向/取景和重定向/接触层。
- 动态保险、击锤、枪管和套筒按各自机械身份赋权。空仓关键帧需要核对后方保险是否仍属于枪体，枪管倾斜后新暴露的面是否完整，不能只按闭膛外观调整。
- 握持修正应覆盖待机、ADS、射击后回握、拔枪和两种换弹的恢复段。保留已接受的右手枪柄接触；左手支撑与弹匣接触按实际部件分别处理。通用对称指形不能替代该枪的包握。
- P9 源 Unholster 是拔枪，不能把 clip 名称含 `equip_charge` 当成实际拉套筒；M1911 空仓换弹复用 donor 的套筒释放动作，不擅自加入 M4 的拍击合同。
- 缩短换弹时保留机械接触段，再调整回握尾段。普通/空仓导出独立短片段，运行、声音与完成结算采用同一时间映射；当结束仍残留动作层，修运行状态，不继续削掉接触帧。
- Blender 导出静态绑定网格前清空 active Action 和 pose basis；仅将骨架显示切成 REST 不会清除 FBX 导出的动作通道。最终可编辑源仍保留动作，不将导出准备过程破坏性应用到唯一源文件。

当前具体参数以 M1911 的 Contact / ReloadReady 作者清单和运行路径为准。原动作取得与可再分发许可分别记录，第三方镜像不能替代原包许可。授权审计时区分源码/时序检查、真实画面和同次混音证据；不把导入或编译成功当作握姿与音效验收。

## 手枪奔跑待机横摆（2026-09-14）

此段为历史方案，后续已由 `PistolLocomotion20260914` 的独立循环取代。当前单持与双持奔跑规则见上面的双持手枪与左轮动作分卷；下文参数不可作为当前默认值。

用户要求手枪奔跑围绕待机位置左右摆动。M1911/715 的 `bUsingM4Infima` 代表共用 Manny 播放路径，不代表应采用步枪的固定抬枪姿态；奔跑表现按 `IsPistolWeapon()` 分流。沿用 idle/idle_empty 的握持，整套视模横摆，当前位置幅度为 ±2.2 cm、上下 ±0.22 cm；无固定抬枪，角度小幅滞后随动。步相位读取脚步音频已有的累计距离与左右交替，并补足两次音频采样间的实际位移；不要再另设一个近似步频。起停平滑收放幅度，行动状态加快收束。详细参数与实现见 `Docs/Weapons/pistol-sprint-idle-20260914.md`；此次未实机测试，数值不视为已接受的通用标准。

## 715 合仓时左手脱离与回握（2026-09-14）

左手离开弹仓后继续乘枪根 `G` 和动态 `clearance(D)`，会把右手合仓主甩叠到空着的左手上。`LeftRecovery20260914` 从末次逐发轴向退让结束／速装器释放后的撤离起点，改用独立视模空间曲线；整条左臂一起重解。左手向下退开，再从外侧回到原支撑握点，最后渐进闭合手指；保留右手与机械、音效时序。尚拿着的速装器跟随左手，不能随枪甩走。用户此次指定的源动画尾段检查及前后模型预览见 `Docs/Weapons/dan-wesson715-left-recovery-20260914.md`，不等同 PIE 或全流程回归。
