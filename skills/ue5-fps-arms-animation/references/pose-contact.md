# 手臂姿态、接触与重定时

## 自然抓握先于指尖贴合

先确定掌面与弹匣的位置、拇指对握、四指包裹方向，再调整 MCP/PIP/DIP 弯曲。每根骨骼先辨认局部弯曲轴；不同 rig 不能直接复制 Euler 数值。保持骨长、scale、rest 和权重，不平移手指骨去追接触点。

M4 失败案例：无约束优化指尖误差会把掌骨扭转、DIP 过度折叠，探针接触更近但手指更畸形。修正保留原掌骨朝向，接受的四指 PIP 约 58–64°、DIP 约 30–43°；这些只是该姿态的参考范围，不能当跨骨架限位常量。拇指尤其要检查根部和从开放到闭合的扫掠路径。

手与弹匣可能无网格相交但仍然悬空或呈捏持。验收同时看掌心间隙、指节连续性、完整包握和手背/掌侧实际渲染；BVH 三角相交数只是一部分证据。

## 整条手臂与坐标

令枪根为 W、弹匣为 M、手腕为 H，握持关系 G = inverse(M) × H。在保持抓握的区间使 H = M × G。右手通常保持相对枪根的握把关系；左手取弹/插入时保持相对弹匣关系。接触区间外要显式松手和退让。

手腕刚性到位不代表前臂正确：一起检查锁骨、上臂、肘、前臂、腕、twist 和袖口。当前 M4 曾出现黑色三角/前臂遮屏；使用原生 `M4_reload` 第 146 帧的有效整臂关系，结合现有手指抓握和渐进过渡解决。不能只扭手腕或剪去上臂来掩盖。

对整个链做世界空间位移时，先缓存所有目标世界矩阵，再按层级重建局部姿态。Blender 同时逐个写父子 `pose_bone.matrix` 而未正确更新，可能产生重复变换。当前作者脚本用：

```text
local_rest = inverse(parent_rest) × rest
basis = inverse(local_rest) × inverse(parent_pose) × pose
```

用连续四元数符号（相邻 dot < 0 时取负）、旋转球面插值和有限值检查；不要任意缩放骨长。源模型以米计算的阈值与 UE API 返回坐标的单位需要实测转换，不能只凭字段名认定毫米。

## 取弹、插入与脱离

1. 将离开的旧弹匣与返回的新弹匣分为视觉阶段。复用同一网格时仅在镜头外重置轨迹；不能在可见区域瞬移或缩放藏匣。
2. 左手先离开枪体，到镜头外取新弹匣，再从有空间的一侧接近。提前给掌心、拇指根和弹匣口留余量。
3. 握持区间保持 G，先对准、沿弹匣井推进，再压实。不要用手指捏着顶部带动整匣。
4. 插好后先松握并沿弹匣外侧退开，再转腕回护木或转入空仓拍击。直接把两个手腕目标插值相连可能穿过弹匣。
5. 验证源、密集烘焙和 UE 压缩后的中间帧。整数帧姿态正确，链与弹匣分别插值仍会滑移；当前 M4 用 480 Hz 烘焙和 960 Hz 读回检查，不要求所有新动画都如此密集。

## 速度与力度

加快击打优先压缩最后挥手段，保留准备、接触时刻和回收。当前 M4 将旧 125–130 帧映射到 126.667–130 帧：83.33 ms → 55.56 ms，即速度 1.5 倍；接触仍为 130/60 秒。不要把整个换弹动画乘 1.5 后放任音效错位。

力度来自短快接近、接触时制动、枪身短暂受力和恢复。当前在已有主受力动作上叠加约 2.193 mm / 0.634° 的衰减振动，0.17 s 后归零；枪与仍握住它的手共同运动，避免接触漂移。参数见 `M4SlapImpact20260910/author_slap.py`，不要与运行时 recoil/kick 重复叠加。

若改接触时点，机械行程和声音事件一起更新。区分“本地动作加速”“全 clip 播放率”“业务动作时长”；使用一张映射表记录源帧到运行时秒。
