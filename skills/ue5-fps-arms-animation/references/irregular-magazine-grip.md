# 异形／宽长弹匣：先选自然抓握区域

2026-09-23，用户确认 SVD `SourceAssets/SVDThumbUp20260923` 的换弹左手“成功了”，要求后续异形弹匣或类似情况参考此标准。认可的是最终前半段抓握和拇指自然向上延展，不是此前多轮全手拟合。

## 默认处理次序

- 宽、长、弯曲或带突出边的弹匣不要求手掌跨越整个轮廓。先选手能够自然包住的局部区域；SVD 最终抓握前半段，四指包住前缘，拇指无需碰到后缘。
- 拇指自然向上延展，后两节保留轻微弯曲；不要为了满足后缘接触点而撑开虎口，也不要为缩小跨度将拇指收进掌心。按本枪坐标、装填路径及实际骨架调整，不能把“上”固定成任意骨架的同一 Euler 轴。
- 用户认可掌心、四指或腕臂后冻结这些部分。反馈只针对拇指，就仅修改拇指关节旋转曲线；不要重新运行整手搜索、改四指、移动手掌或重算整臂来追求接触误差最小。
- 保留骨长、指骨局部位移、缩放、rest 与蒙皮。表面距离较小、优化器成功、资产保存均不能代替自然手型与用户认可；不要用这些数值否定用户看到的虎口拉伸或关节扭曲。
- 取匣时渐进进入手型，持匣、插入和压实保持同一抓握关系；装好后的松手也使用修正后的拇指，再平滑回到既有握枪手型。覆盖原厂及已接入握把的普通／空仓动作。

## 拇指单独返修：量可见方向与虎口，根部不动（AKM / A762 2026-09-25，用户已认可）

AKM 与 A762 换弹抓握弹匣的手先后报出三个问题，最终一次通过的顺序是**扭正 → 伸直 → 抬开食指**，每一步只改拇指三条旋转轨道，其余曲线全部复制。可复用的判据与改法：

1. **先量"绕自身轴的扭转"**：拟合整手手型时容易把拇指根部的轴向滚转当成自由量（本例 `thumb_01_l` 扭了 67°，拇指压成平贴的板，指腹离壳 12–15 mm；已认可的 SVD 只有 −12°）。指尖最近距离、壳面残差、优化器收敛都暴露不了"位置对了但翻了"。
2. **再量"可见拇指"而不是骨轴**：`SK_M4_Infima` 的 `thumb_01/02/03_l` 沿链条每根上移约 50 mm，而每根骨自身 +Y 指向手背下方——可见指节方向（蒙皮 `thumb_01_l`→`thumb_03_l` 顶点组质心之差，rest 63.5 mm）与骨轴相差约 **70°**。按骨轴瞄准弹匣轴，可见拇指反而偏 59°；把"绕骨 +Y 的扭转"归零也不等于拇指没翻。**这套骨架上骨弦与骨轴扭转都不能当判据**。
3. **伸直靠远端两节，根部一个角度都不动**：沿用已认可姿态的根部四元数，只把后两节屈曲收到轻屈（SVD 用 4°/3°）。可见拇指回到 rest 的 99.6 %/100.2 %。为对准弹匣长轴去掰根部（曾摆 74°/79°）会把虎口拉坏。
4. **虎口单独量**：`thumb_01_l` 与 `index_01_l` 蒙皮质心间距作虎口宽度；`thumb_01_l` 权重顶点相对出货姿态的最大位移作"虎口被拖动量"。大角度根部摆动的读数是 **+33 %** 与 **62–65 mm**，根部不动后只有 **2.9/3.2 mm**。
5. **拇指与食指的穿插只能量面片相交**：两侧各建 `BVHTree`，求 `overlap()` 的对数与 `find_nearest` 的最近距离（本例伸直后 AKM 104 对 / A762 202 对相交）。修法是叠**一次小摆动**，轴取"手部前向轴（`hand_l`→`middle_01_l`）垂直于可见拇指方向的分量"——只摆动、不改已认可的滚转；角度取**最小能完全消除相交**的一档（AKM 8°、A762 16°）。**保持段必须逐帧核**（拇指局部姿态是常量但手在转），并在**手背方向**渲染判读"上方/下方"，只量位置差容易搞反。
6. **组合结果**（AKM / A762）：可见拇指 63.0 / 62.9 mm，与弹匣长轴 87.2° / 82.7°（SVD 认可是 89°–91°，近垂直），抬升 +18.9 / +24.0 mm，虎口相对出货 −0.12 / −0.14 mm，拇指/食指相交 0 对、最近 3.75 / 5.14 mm。
7. **最小弧校正的公式纪律**：`B_q = M₀⁻¹ D M₀ q₁` 里的 `M₀` 必须是**基座为单位旋转**时的根部 pose 矩阵（用当前 pose 矩阵只会生效一半）；任何迭代瞄准都必须在**施加最终旋转之后**再量一次，否则候选表与落盘姿态不一致。

**弯路（不要重复）**：用大角度根部摆动把可见拇指硬贴到弹匣长轴上（撑开虎口）；用"骨弦"或"绕骨 +Y 扭转"做判据；把弹匣代理的位置当成绝对真值（部分制作场景里的弹匣代理并不在出货弹匣的位置，有符号壳面间隙会读出拇指根部"陷入 30 mm"这类物理上不可能的值——此时用"指尖到弹匣骨轴的距离"这类不依赖壳体的判据）。

**验收**：非拇指骨骼逐骨 ≤0.0000°、窗口外轨道与源 clip 一致、可见拇指长度/夹角/虎口宽度/相交对数/最近距离全部逐条达标并记录在 `verify4_*.json`。

**读当前实际加载再动手**：本例的抓握资产有早期与 V4 两套（`RifleMagazineGrip20260922/` 根目录与 `IndexClearanceV4/`），运行来源是后者；以该轮 `sources.json` 的 asset→blend 映射为准。
