# 异形／宽长弹匣：先选自然抓握区域

2026-09-23，用户确认 SVD `SourceAssets/SVDThumbUp20260923` 的换弹左手“成功了”，要求后续异形弹匣或类似情况参考此标准。认可的是最终前半段抓握和拇指自然向上延展，不是此前多轮全手拟合。

## 默认处理次序

- 宽、长、弯曲或带突出边的弹匣不要求手掌跨越整个轮廓。先选手能够自然包住的局部区域；SVD 最终抓握前半段，四指包住前缘，拇指无需碰到后缘。
- 拇指自然向上延展，后两节保留轻微弯曲；不要为了满足后缘接触点而撑开虎口，也不要为缩小跨度将拇指收进掌心。按本枪坐标、装填路径及实际骨架调整，不能把“上”固定成任意骨架的同一 Euler 轴。
- 用户认可掌心、四指或腕臂后冻结这些部分。反馈只针对拇指，就仅修改拇指关节旋转曲线；不要重新运行整手搜索、改四指、移动手掌或重算整臂来追求接触误差最小。
- 保留骨长、指骨局部位移、缩放、rest 与蒙皮。表面距离较小、优化器成功、资产保存均不能代替自然手型与用户认可；不要用这些数值否定用户看到的虎口拉伸或关节扭曲。
- 取匣时渐进进入手型，持匣、插入和压实保持同一抓握关系；装好后的松手也使用修正后的拇指，再平滑回到既有握枪手型。覆盖原厂及已接入握把的普通／空仓动作。

## 先量"绕自身轴的扭转"，再看指尖距离（AKM / A762 2026-09-25）

用户反馈 AKM 与 A762 换弹抓握弹匣的手"有扭曲"。按 SVD 的次序排查，结论仍是拇指根部：拟合成组手型时把**根部的轴向滚转**也当成自由量，`thumb_01_l` 绕自身长轴扭了 **67°**，拇指被压成平贴在前面的板；指腹离壳面 12–15 mm。已认可的 SVD 同一量测只有 −12°，M4 为 +44°。

- **判据**：对每根手骨算 pose 相对 rest 的局部旋转，再按骨骼自身 +Y（长度轴）做 swing/twist 分解。指尖到壳面的最近距离、壳面残差、优化器收敛都不能暴露"位置对了但翻了"；只有扭转分量能。
- **改法**：根部限定为纯 swing —— 先按掌面语义轴做两自由度摆动，再把绕拇指轴的扭转分量投影掉；后两节只保留轻屈。参数按"指腹贴壳不穿透"有界搜索，每把枪一组。掌面、四指、腕、前臂、弹匣轨道、另一只手、枪根与机械/音效时钟全部不动，进出窗口沿用原动作（本例 20→44 闭指、保持到 237、237→250 回到 clip 自身轨道）。
- **验收**：非拇指骨骼在修复前后逐骨差异 ≤0.0000°、三节拇指扭转归零、指腹间隙由 12–15 mm 收到 4–10 mm。
- **读当前实际加载再动手**：本例的抓握资产有早期与 V4 两套（`RifleMagazineGrip20260922/` 根目录与 `IndexClearanceV4/`），运行来源是后者；按目录里最早看到的 `selected_grasp.json` 量会量到一套已被替换的动作。以该轮 `sources.json` 的 asset→blend 映射为准。

跨枪搬运整条抓握关系（而不是只修拇指）时另见 [弹匣抓握跨枪配准](magazine-grip-registration.md)。

## 拇指要"向上自由延展"：量可见方向，不要量骨轴（AKM / A762 2026-09-25 第二轮）

扭转归零之后用户反馈拇指"向内收缩进虎口"，要求精调成向上自由延伸。同一批 clip 的续修，结论与做法：

- **这套手模的拇指骨轴不可当方向用**：`SK_M4_Infima` 的 `thumb_01/02/03_l` 三个骨头沿链条**依次上移约 50 mm**，而每根骨自身的 +Y 却指向手背下方；可见指节方向（蒙皮质心链）与骨轴相差约 **70°**。于是「骨 head→tail 弦」和「绕骨 +Y 的扭转」两个量测在这里都会给出与画面相反的读数：按骨轴瞄准弹匣轴，可见拇指反而偏 59°；把骨轴扭转归零，也不等于拇指没有翻。
- **改量可见方向**：用蒙皮网格上 `thumb_01_l` 与 `thumb_03_l` 顶点组质心之差作拇指方向与长度（rest 为 63.5 mm），指腹间隙仍取顶点到弹匣壳的有符号最近距离。
- **改法（在已认可的 pose 上做最小弧摆动）**：以第一轮认可根部为基准，取 `D = 可见方向₁.rotation_difference(目标)`，再 `B_q = M₀⁻¹ D M₀ q₁`（`M₀` 是**基座为单位旋转**时的根部 pose 矩阵，不是当前 pose 矩阵；用错会让校正只生效一半）。这样只把拇指**摆**上去、不额外加滚转；后两节保持 4°/3° 近伸直。
- **目标不要正好压在弹匣轴上**：根部位置离弹匣侧面有偏移，正对轴会把指腹埋进壳里 12–16 mm。把目标在"弹匣轴—掌心"平面内偏 22° 扫描，取指腹贴壳 1–6 mm 不穿透的那一档，两把枪都落在 −22°。
- **验收**：可见拇指长 65.2 / 65.0 mm（rest 的 102.7 % / 102.2 %，第一轮只有 55.5 / 53.2 mm = 87 % / 84 %，即"缩进虎口"），与弹匣轴夹角 15.7° / 15.1°，抬升 +56.2 / +56.8 mm（第一轮为 −15.7 / −21.6 mm），三十条 clip 全部零穿透，非拇指骨骼逐骨 ≤0.0000°。
- **求解器纪律**：任何迭代瞄准都必须在**施加最终旋转之后**再量一次；本轮曾出现"存下的四元数比报告的量测多迭代一次"，导致候选表与落盘姿态不一致，整轮结论作废。

## 拇指伸直靠远端两节，不要靠根部摆动（AKM / A762 2026-09-25 第三轮）

第二轮把拇指"摆"到弹匣长轴上（根部相对已认可姿态再摆 74°/79°），用户反馈**虎口被错误拉伸**。这条与 SVD 的经验一致，且可以量化：

- **虎口要单独量**：取 `thumb_01_l` 与 `index_01_l` 蒙皮质心间距作虎口宽度，取 `thumb_01_l` 权重顶点相对"当前出货姿态"的最大位移作虎口被拖动量。第二轮这两个数是 **+33 %/+29 %** 与 **62/65 mm**；根部不动时只有 **2.9/3.2 mm**（纯粹是远端关节局部影响）。只看指尖位置、壳面间隙或"拇指长度"都发现不了虎口被拉开。
- **改法**：根部沿用**已认可姿态的四元数，一个角度都不动**，只把后两节屈曲收到轻屈（SVD 用 4°/3°）。拇指伸直完全由远端两节提供；本骨架拇指骨轴与可见指节差约 70°，所以"根部摆多少"与"拇指看多直"本来就是两件事。
- **不要为了对准弹匣长轴而掰根部**：认可过的 SVD 拇指相对弹匣长轴是 89°–91°（近垂直），本轮自然伸直后落在 95°–99°，与 SVD 同级；第二轮硬贴到 15° 才需要大角度摆动根部，正是撑开虎口的来源。SVD 文里"不要为了满足后缘接触点而撑开虎口"说的就是这个。
- **验收**：根部与出货四元数差异 0.0000°、可见拇指回到 rest 的 99.6 %/100.2 %、逐条虎口宽度与 rest 之差 ≤1.5 mm、非拇指骨骼 ≤0.0000°。
- **教训的通用形式**：手掌上任何"为了满足接触点"而加的自由度，都会在虎口/掌心这类薄皮区域留下可见拉伸；先量那块皮，再决定要不要动根部。

## 拇指与食指的穿插：用面片相交量，用小幅摆动修（AKM / A762 2026-09-25 第四轮）

第三轮把拇指伸直后出现"拇指与食指交错穿模"。这类缺陷**指尖距离、壳面间隙、长度都看不出来**，必须量面片相交：

- **量法**：把拇指（`thumb_01/02/03_l`）与食指（`index_01/02/03_l`）各自的面片各建一棵 `mathutils.bvhtree.BVHTree`，调 `overlap()` 取相交面对数，再用 `find_nearest` 取两表面最近距离。第三轮姿态 AKM 104 对 / A762 202 对为相交；修好后为 0 对、最近 3.75 / 5.14 mm。
- **修法**：在已认可姿态上叠**一次小摆动**，轴取"手部前向轴（`hand_l`→`middle_01_l`）垂直于可见拇指方向的分量"——这样只摆动、不改变已认可的滚转（不要用扭转去躲，那是第二轮被否的方向）。角度取**最小能完全消除相交**的一档（AKM 4° 仍剩 54 对、8° 归零；A762 12° 剩 39 对、16° 归零），宁可刚好清开也不要大角度。
- **必须在保持段逐帧核**：窗口内拇指局部姿态是常量，但手在转，相交可能只出现在某几帧；本轮在 68 / 148 / 220 三帧各查一次。
- **判读方向靠渲染**：把食指单独着色，从**手背方向**（`-normal`）看才能分清"拇指在食指上方"还是下方；只量位置差容易把两侧搞反。
- **验收**：30 条 clip 相交对数全 0、最近距离 ≥1 mm、可见拇指长度基本不变（63.0/62.9 mm）、虎口宽度相对出货仍在 ±2.5 mm 内。
