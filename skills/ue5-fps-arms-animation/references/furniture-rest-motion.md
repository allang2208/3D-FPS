# 坐卧动作、支撑与左右侧复用

用于坐椅、扶沙发、上床和倒放下床的完整身体动作。运行交互见 [家具坐卧](../../ue5-world-interaction/references/furniture-rest.md)。

## 源动作与自然接触

- 选源先检查完整时间轴。商品动作名称不能证明包含“站立→坐床沿→移腿→躺下”；本案 Meshy 下载的多动作 GLB 需要逐 take 确认，上床采用完整源过程。会员商用授权与公开原始素材再分发是两项权限，公开仓库只提交获准配方和必要运行配置。
- 手臂不要一直悬在大腿上方。进入从自然下垂开始，随后掌根接触扶手／床面，肩、肘、腕依次承重；挪动时保留一侧支撑，身体转移后再换手。不能只平移骨盆再把双手钉死在目标点。
- 用实际蒙皮几何和家具尺寸确定坐深、支撑高度、扶手内外间隙。脚可以自然悬空，不靠伸长小腿强压到地面；胸腰不能靠过度后仰补偿错误的骨盆位置。保持骨段长度、肘膝铰链及连续的 IK 弯曲侧。
- 双侧扶手的办公／会客椅，退出时手先解除支撑并沿扶手外形收回，再下垂；简单反向 IK 易跨过肘平面造成扭臂。倒放可提供起点，但仍须保持支撑释放和终点姿态连续。
- 上床的移腿、转髋、落肩要有先后。压缩总时长使用单调的分段源时钟，把时间留给坐稳和腿部越过床沿，缩短静止准备与收尾；不要全段等速缩短后破坏承重点。FPSGAME 本案入床 3.3 秒另加 0.6 秒对齐，下床按入床反向采样为 3.4 秒；这些是配置时长，不是新一轮视觉认可。

## 原生骨架与镜像

- 男女身体分别从已保存的原生动作重采样，保留各自修正与 retarget reference pose；已重定向姿态不能再重复套一次重定向。相机采样读取同一身体与同一已保存动画。
- 双人床左右复用应在原生参考骨架上镜像完整 pose，再与行走层混合。本案使用 `FAnimationRuntime::MirrorPose`、左右骨映射和参考组件空间旋转；不要把角色网格缩放设成负数，也不要只交换手脚而漏掉骨盆及脊柱。
- 动作镜像同时映射入口偏移、入口 yaw、退出位置和原生眼位横向分量。身体、服装 follower、第一人称眼位和其他玩家所见使用同一复制状态。
- 手部和腿部修订的证据分开：作者关键帧、已保存原生压缩帧、最终服装蒙皮、实际游戏交互各证明不同范围。仅在用户要求预览或检查时执行对应阶段。

## 保留制作依赖

本案 `BedNaturalV8`、`BedSupportedV9`、`BedHandDriveV10` 的旧发布结果已被新床动作替代，但作者函数、标定数据仍被 Meshy／床族适配链引用。旧文件名不是退役依据；仅移走无当前调用的旧保存／发布入口，保留被新版读取的输入。最新路线及素材恢复链见 `Docs/Publication/FurnitureRest20261025/README.md`，不要按历史日志重放旧发布器覆盖正式动作。
