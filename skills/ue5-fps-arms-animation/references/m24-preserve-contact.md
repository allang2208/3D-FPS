# M24：保留接触的局部腕臂修订

用于已认可枪械/手部位置下，肩根入镜、前臂拉伸、拉栓换握或独立握把替换。遵守当前授权，不自动运行动画渲染或验收。

- 区分已保存动画、握持 Profile、运行时整枪 framing、镜头加法和衣袖/手套外观。修错层会让另一个动作重新出现问题。M24 长枪不能直接套用 M4 action anchor 的整体平移；不要把根部入镜归因于手指，再把整枪推远补救。
- 固定已认可掌心接触与腕部世界变换，保持原生上/小臂长度和 scale，局部求解肩肘。肩部修订应维持锁骨—肱骨关系，用近端旋转和必要的锁骨平移退出镜头；不要拉长骨段、挤缩手腕或折叠上臂。数值只对当前骨架/镜头标定有效。
- 待机、瞄准、冲刺入/循环/出以及双手松开的动作有不同持握区间。持续扶枪段保持相同修正，松手段在实际起止窗口回退，避免只改循环导致边界跳变。分别覆盖原厂和独立握把、5/10 发弹匣 Profile。
- 拇指收拢按掌骨对掌与关节连续弧线处理，手指局部旋转保持人体屈伸；不能把整只手压进枪体以制造“捏住”。握把改成完整独立几何后，重新匹配掌心、虎口、扳机食指与回握层，不能继续复用原厂一体托腕部的抓握坐标。
- 复用开火拉栓微动到装备/空仓换弹：按实际枪栓轨迹确定时间对应，只施加枪根相对 idle 的刚体增量，同时携带双侧锁骨链和对应 IK 根。保留局部肘、腕、twist、手指与机械轨道，勿重复烘焙补偿。
- 姿态解算后保留四元数同半球连续性。必要的用户授权检查包含压缩后与帧间采样，不能仅挑几帧认定没有扭曲。身体根部漏空和衣袖/手套映射是独立交付项，裸手姿态正确不代表穿戴外观同步完成。

案例入口：`SourceAssets/M24SprintShoulder20261031`、`M24ArmRoot20261031`、`M24BoltMotionReuse20261031`、`M24RightGripFit20261031`。这些目录引用的旧姿态输入仍保留；当前资产恢复关系以工程发布说明为准。此页沉淀方法，不宣称所有历史动作已获视觉认可。

## 改造握姿的快速近战（2026-11-04）

- 原厂一体托颈部的持棍包握不能直接留给独立后握把／骨架枪托。旧 `author_grasp.py` 只按距 idle 握点的距离，在起手和回握时套握把修正，中段仍抓旧托颈；改造后的近战必须按当前实际接触重做主体。
- 本版独立握把全程以各自当前 idle 的枪根相对掌腕与五指为接触约束，整枪路径和双侧肩肘一起适配，不能固定错误枪路后只拉手臂。原生骨长与 scale 保持，辅助骨承接所属骨段，前臂 twist_01／02 按当前 V9 的 100%／50% 分配轴向转掌。
- 拟合握稳、击中、回弹控制点时保持同一旋转分支。击中和回弹独立求最小代价可能得到相反的枪身滚转；本版短回弹沿用接触姿态，再衔接恢复。四元数同半球和前臂 roll 解包均需连续。
- 原厂一体枪托继续原持棍换握，起止接回当前 idle。独立默认、平衡、幻影、防滑握把分别制作，并覆盖 5／10 发 Profile。只合并 `quick_melee`，不能拿旧作者整份 Profile 覆盖刚保存的换弹。

## 装备抬枪时肩根露出

从实际 V9 手模的肩部开口边缘取样，带上当前握姿差量、修形、骨架最上层的缩放及腰射相机，逐帧定位入镜区间。M24 原厂握姿出现在抬枪第 7–12 帧。以已有肘位约束锁骨与上臂摆动，再在前臂补偿，保留掌腕、手指相对枪械的接触。普通弹匣、扩容弹匣和独立握把分别使用自己的姿态。

普通抬枪与“抬枪后补栓”分别引用基础序列。短抬枪从当前家族 idle 建立握姿，保持共同的抬枪根轨；完整动作保留后段机械接触。写回每个配置时按基础资产身份只合并目标动作。工程制作源为 `SourceAssets/M24EquipConditional20261104/`。
