# 双手上挑的握姿与回位

用于参考视频驱动的第一人称上挑，尤其是左臂翻转、手腕扭曲和恢复段脱柄。上挑当前源是 `SourceAssets/SwordUppercut20261003/GripRecoveryV15`；运行资产保留 `A_Sword_UppercutV1_*` 名称，但内容已经是 V15，不能由路径版本号推断实际姿态。

- 先用护手、柄尾、剑尖和左右手顺序解释参考。“反手挥剑”可以仍由虎口侧出刃，不能直接等同于小指侧出刃的倒握。该参考右手靠护手，左手拇指/食指朝右手；用户最终要求沿用待机左手正握。
- 蓄势把整副武器和手臂移到右下镜头外，再快速向前上挑。通过武器与双手整体路径控制屏幕位置，不能只拉剑尖或单独扭腕来补幅度。
- 两手握点在柄的局部空间约束，肩、肘提供支撑。换握与回位沿柄轴圆周连续移动；肘极点与前臂扭转保持连续，不能让左右手各自线性插值而中途离柄。
- 恢复段同样保持武器与握点的关系，最后回到原待机。仅起点、终点相同不足以说明中途无脱离。动作与镜头用共同阶段时钟，但镜头表现不参与伤害瞄准。
- 普通柄与长握柄各有作者输出；已制作的长柄动作不要再叠一次握距差量。继续使用当前认可的 V7 手臂及其原生骨架，不为修一只手换整副骨架。

V15 作者入口 `author_uppercut_v15.py` 依赖同目录 `arm_support.py`、`author_common.py`、`inputs.json`、`SourceV14/*/editable_keys.json` 及共享 `RuneSword_BareArmsV7.blend`。`SourceV14` 是仍有效的冻结输入，不能因版本旧而归档。其他旧候选及旧包恢复位置查发布归档清单；安装脚本中允许的历史作者路径是元数据归属判断，不表示每个旧目录都必须留在活动目录。

关节/握点的历史离线读回与用户认可范围、后续游戏体验分开记录。导入保存属于制作；读回、截图与渲染默认不附带执行。位移与伤害时序另外读 `ue5-skill-magic-workflow/references/melee-lunge-contact.md`。
