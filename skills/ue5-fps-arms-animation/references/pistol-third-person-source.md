# 手枪第三人称：源动作、镜像与装填接触

用于左右单持、双持的肩肘扭曲、支撑手错位和装填穿身。先确定当前源、原生骨架与运行消费路径；不要继续叠加已被用户否定的手工手腕/肘点修正。

## 源姿态与镜像

- 已有合适完整动作时先重定向源动作，再做枪型接触适配。FPSGAME 当前双枪使用 Twinblast 完整持枪链，单持使用 ThirdPersonShooter-AnimationSets 重定向动作；许可与原始输入保留在案例目录。
- 左主手复用右主手时，在原生绑定坐标中镜像完整局部链，包括蒙皮使用的 twist/corrective 骨。上身镜像不抢占下身步态和根运动；不能只翻手腕、交换腕点或用负缩放掩盖整臂朝向错误。
- 完整双持源已经拥有肩、肘、腕和扭转骨时，不在后续层重新猜肘面、重置辅助骨或覆盖腕旋转。每只枪的开火、装填和机械时钟独立，消耗品接管的手臂优先。
- 第一人称可提供手指抓握、掌向和枪体接触关系；不要把相机空间腕点直接作为第三人称目标。按原生骨长、肩轴和身体空间求双手共同可达位置。

## 握点与装填

- 枪、操作掌和弹匣共享同一接触关系，接近阶段提前腾出空间；避免弹匣一出现才瞬移枪或手。保持释放、生成、插入和闭合的源时钟。
- 长枪体/前握把需要枪型独立的肩侧、肘侧和躯干避让；不要把 RSH 的约束全局套到普通手枪，造成插匣腕折。
- 撤离长前握把时，记录起手额外前伸量，在胸部坐标中逐渐释放。每帧追着已移动握点重新混合会压缩源行程并在末端追赶。
- 肘部平滑保存实际显示方向及肩腕轴，并随移动胸部搬运；相对于每帧源肘面的旧标量角度不能直接沿用，否则开火、移动或撤手时可能突然跨过身体中线。
- 独立抛弃弹匣/弹壳与插入道具使用明确的生命周期。可见道具出现不等于库存已经装入；左轮普通逐发、装填器和只闭合不能混用。
- 共享动作配置按具体角色键发布。退役候选不覆盖当前入口，保留最终六段换弹源与必要作者输入；构建、资产落盘、几何检查和用户视觉认可分别记录。
