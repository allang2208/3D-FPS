# 45° 握把与跨枪抓握迁移

历史案例日期：2026-09-11。作者入口为 `D:/FPS3D/FPSGAME/SourceAssets/CantedGripMigration20260911/README.md`；先核对当前运行引用，不因本页存在就覆盖后续用户微调。

- 跨枪迁移缓存握把空间中的手掌关系与手指局部旋转，再用目标枪原有肩位和骨长求解手臂；不能复制整个 M4 动作覆盖 AKM 机械轨道、装弹时刻和弹鼓分支。
- 45° 是配件安装倾角，不能简单把垂直握拳整体转 45°。同时检查掌侧、手背、腕肘、枪身和弹匣空间，参照原动作的肘部弯曲平面及上臂方向。
- 手指并拢与退握时分离是不同阶段；在实际手套表面验证退握和回握，保留原动画取弹、装入和枪机接触段。目标枪安装座参与碰撞采样，源枪无碰撞不意味着换枪后也安全。
- 同一骨架不保证两个 AnimPose 求值结果在相同空间。先把 Blender 源骨位与 UE 运行时 COMPRESSED 比较；本案例 RAW 关闭额外 `should_retarget`，COMPRESSED 开启运行时 retarget。直接将两者都设为 true 会对 AKM 共振握把产生错误的大偏差，不应先提高压缩精度或改手型。
- M4/AKM 切枪后检查组件生命周期，特别是新加入的握把要进入销毁/置空和重新初始化流程；握把 ID 一样也不能复用另一把枪的安装网格。
- 数值迁移按配件选项 ID 比较 `stats` 和 `effects`，保留目标枪基础数值与弹药合同。独立验证枪匠预览、撤销、应用、存档、切枪、四种换弹及移除。
