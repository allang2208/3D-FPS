# 弹鼓参考方向、抓握与双持启动

用于按照片调整弹鼓方向/细节、迁移步枪托鼓手型，或双持进入游戏混入单持待机。当前 G18 是制作案例，已保存和构建，尚未逐枪或换弹视觉验收。

## 参考图与握持

把供弹颈插接坐标与鼓体朝向分开。G18案例用户要求俯视顺时针90度：只将鼓体在枪体坐标绕Z转-90度，保留原供弹颈插接段和弹匣骨挂点，重新制作过渡座；不整体旋转配件导致接口离位。照片未见的背面标记为设计推断。当前方向不能作为其他枪的固定轴规范。

凸筋、端盖和侧壳采用连续曲面、倒角根部与贴壳零件，避免独立圆柱/条片交叠产生拼接。虎头配重侧形案例同理：共享实际轮廓边界，带切向的曲面连接；PBR沿同一边界投射并在线性空间混色。眼部红石、眼圈和眼睑共用原图瞳孔定位，不能把装饰点当成第二对眼睛。

G18左手托鼓参考AKM PalmGripV3的掌面语义，按G18原生V7骨架重新配准，不直接复制欧拉角。保留骨长、右手和枪体/弹匣轨道。取鼓前张手、逐指闭合，插入后先松指再退手，空仓及时交回套筒操作。普通/空仓共享Profile分别匹配原始序列；只改FBX而不重新导出Profile不会更新运行姿态。

换弹+50%由游戏统一时钟实现；作者动画保持源时长，不再额外拉长一次。源接触、补弹事件、机械轨道和声音随同一倍率。G18双持沿原单手换弹，不因单持托鼓修订而覆盖。

## 双持出生时混入单持

先看生命周期与实例所有权。Possess可早于BeginPlay；若提前恢复双持后，BeginPlay又无条件创建单持基础视模，主手AnimInstance会被替换，副手仍在。双持装备ID没变，缓存会继续更新已失效旧实例，表现为“单持托握+另一支枪”。

当前修复顺序：未BeginPlay先保存/延后档案；基础视模初始化完成后，应用影子档案或挂载本地档案；后续possession/replication沿原入口。无需添加每帧强制重载或G18特例。源码影响范围包括所有共用IsDualPistol的手枪及混合组合，范围判断不等于逐枪测试。
