# 手枪与副手书：ADS、回握和联机边界

FPSGAME 本机工程：`D:/FPS3D/FPSGAME`。处理手枪＋书横臂姿势、双持第三人称手部所有权、副手换弹收回，或相同回归时读取；普通单枪修改不自动改这些姿势。

## 已选姿态与作者源

- 当前未瞄准保持原左手持书与实时步态；仅 ADS 使用横臂支撑、书本朝下和 V5 拇指修订。此前“伸得太远、双臂重叠”的姿势及朝前书本不是恢复基线。
- 入口是 `SpellbookPistolSupport.cpp`、`SpellbookPistolSupportTuning.h`、`SpellbookPistolArmSolver.h`、`SpellbookPistolThumbPose.h`。保留原生骨长、手指与枪械握点，肩肘分向解算；前臂扭转按现有辅助骨分配，不再单独掰腕掩盖整臂问题。
- `SourceAssets/PistolBookPoseV4_20261020` 的作者源与 Blend 仍是 `PistolBookThumbV5_20261020` 的输入，不能因版本旧就移走。V5 只改左拇指三节旋转；作者预览的腰射旧图不能代替当前原待机状态。
- 本地相机坐标只用于拥有者的第一人称层。第三人称书臂使用身体上的完整原生链与相对手势，不复制相机绝对腕点；浮空书与腕部必须共享相对坐标。

## 收书、换弹与直接拿回书

- 非手枪副手按装备实例判定，不只检查“是否是书”。现有合同：收起 0.55 秒 → 原换弹 → 额外返回 0.40 秒；双持手枪不收这项代价。
- 玩法阶段和展示阶段分开。装填/必要拉栓完成后可提前开始左手退出，玩法截止时间保持原合同，不能为了剪掉回握尾段而提前恢复射击。
- 返回前 35% 由空手退出原换弹姿势，后段才接回副手。不能先回握手枪再瞬间隐藏拿书，也不能在 native reload 结束时重启已经开始的返回。
- 双持时左右手独立拥有动作通道；两手进食同时让出两臂，单手饮用保留另一只枪的独立姿势。消耗品/撞门等动作层是最后的姿态写入者，配对持书层不能覆盖它们。

## 联机与交付

- 服务器换弹等待要使用同一副手代价，并从对应 Pawn 的影子档案读取装备，不能拿主机档案判断客机副手。当前通过 `GetReloadSeconds` 补齐最低等待；这不是全枪械服务器换弹状态机的重写。
- 动作与装备可乱序。`HasMatchingMotionRig` 同时检查实际 `ItemInstance`、schema、骨数和部件数；仅检查 `GunInstance` 会漏掉书与工具。弓虽然挂左手，仍按主手实例匹配。
- 保留递增序号、可靠阶段边沿、表现租期和有界外推。旧装备/旧序号不能回拨当前回握；断流后不能永久停留在藏书状态。
- JSON 动态引用的动画要有对应 Cook 规则。本次战锤有效组合为 V7/V8/V16/V17/V18；39 个入口对应 21 个包，不能把目录里所有候选都当当前版本打包。
- 2026-10-21 本地 Game/Editor 构建、25 项权威表现隔离用例已完成；不等于双进程 UDP、延迟丢包、重连、Cook 后运行或视觉验收。后续修改不自动沿用这些结果。
- 共享宿主的局部 Git 提交/补丁和完整本地集成分别报告；配置键、文件存在不证明所有消费者代码已发布。归档、来源与发布范围查 `Docs/Publication/AnimationHandoff20261021/README.md`。
