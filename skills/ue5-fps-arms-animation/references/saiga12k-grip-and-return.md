# S12K 左手：检视、空仓回握与握把移位

适用：手穿护木、回握拇指扭曲、调整配件后手位不跟随。遵守用户的后台制作及不主动测试规则；只在明确要求时执行采样检查、运行或截图。

## 修正层次

- 先核对实际选中的六个私有配置 `base / drum / angled / vertical / canted / prism`。标准匣与弹鼓、普通与空仓换弹是不同分支，不能只修待机或标准 `reload_empty`。
- 不对整条动画强加同一平移。握住护木时掌心跟随握把；取弹、插匣、操作枪机时保留各自接触。检视先保持手对握把的关系，再绕开枪体安排肩肘，不能只把手腕推出壳体。
- 复用原生骨架与经过校准的整臂铰链求解。保留骨长、骨段缩放、手掌朝向和已有手指局部旋转，避免单独折腕/旋拇指把问题转移到前臂或指根。
- 空仓回握分为离开枪机、展开手掌、靠近握把、拇指越过边缘、收拢包握。拇指闭合晚于靠近阶段；使用分段非线性节奏，保留已认可机械接触与动作总时钟。

## 当前作者链与实例边界

- InspectClearance 的 `Inputs/runtime-source.json`、Inspect 的 `pose_math.py` 和 `author_profiles.py` 中 `sparse_track` 仍供后续作者读取，不因旧配置被替换而删除。
- ReloadReturn 是 `vertical / canted / prism` 的空仓末段增量；普通/弹鼓两个 empty 分支都覆盖。
- Resonance 是共振 `angled` 的最新制作源：实际握把下移约 2.15 cm 后，以 120 Hz 源采样生成稀疏局部姿态差量，14 个条目中调整 13 个，已松手的 sprint loop 保持原轨迹。
- 该次按手离原握点的枪体局部距离淡出偏移，保留弹匣/枪机接触；距离阈值来自本枪，不可盲目复制。当前输出 `SourceAssets/Saiga12KResonance20261019/Profiles/DA_angled.json` 覆盖同名私有运行配置。
- 配件改位要一起交付网格、动作配置和安装脚本；仅修改作者 JSON 不算 UE 保存完成。第三人称使用同一握点/配置，另需保证复制的配件顺序与动作 schema 一致。

第三人称“手消失”也可能是整枪与双手被错误瞄准方向带到躯干后方；先区分渲染隐藏与姿态方向，见 [表现同步](../../ue5-save-load-replication/references/saiga12k-presentation.md)。网格/包保存、离线接触检查和用户实际画面反馈分别记录。
