# M249 侧插换弹：接触、节奏与整枪随动

适用：手部动作已确认，只需修插匣时腕肘异常、取弹停顿或枪身僵硬。当前本机来源为 `SourceAssets/M249Orpind20261107/`；公开恢复说明见 `Docs/Publication/M24920261109/README.md`。这是游戏视模制作经验。

## 保留什么、在哪一层改

- 30/45 发共享插口和手部接触源；容量、时长及可见性走各自配置，不能因共用源动作而丢掉扩容弹匣的时间差。
- 只调节奏时修改 `M249ReloadTiming` 的运行秒→源秒映射。取旧匣、画外取新匣、对接、推进、压实分别设速度；隐藏窗和音效、摄像机、弹药提交均取同一源时钟。不能在运行时和源动画两处重复缩放。
- 插匣时掌心已对准而肘部贴镜头，应在肩—腕可达圆上调整肘弯面，并联动上臂辅助骨及 V9 前臂 full/half twist 分站。补偿腕部局部变换以保持手指与弹匣的组件空间接触；不要单独扭腕或把整只手拉远。
- 当前侧插时长为 30 发普通/空仓 3.8/5.0 秒、45 发 4.3/5.5 秒，随后仍受合法换弹属性调节。这是 Tempo27 的项目选择，不是其他武器的标准时长。更早 README 中的时长已经过时。

## 枪身静止的定位与修正

先测量实际处理区间的 `WPN_root`，不能用整条动作的最大角度证明枪身有受力反馈。M249 曾在进场时转约 5°，但拔匣至对接的大部分时间保持静止；镜头抖动不会让静止的枪与手自动产生重量感。

Feedback31 在枪与两臂共同祖先 `root` 上增加受力/回弹差量，保留所有非 root 轨道。以枪身后握把附近为转轴，对枪、双臂及机械部件施加同一个刚体变换，手相对枪和弹匣的接触关系不变。区分宽缓的承重随动与已有 RC1 接触冲量；镜头仍只有一个输出拥有者，不再叠加 CameraShake。

从组件空间转换到 root 局部空间时使用真实父矩阵，包含导入尺度。本骨架存在 100 倍尺度；原生 `poses.f32` 的位置/四元数流不携带尺度，直接当单位尺度回写会造成严重位移错误。不要把 `WPN_root` 当作双臂的共同祖先，先查真实骨骼层级。

本例附加幅度约 2.14°、转轴平移 0.73 cm；普通源秒 3.50、空仓 4.70 后差量归零，先于现有手臂待机交接。幅度和归零点只用于理解本例，其他枪按其接触、重心和动作尾段确定。

## 保存与检查边界

- 从当前资产新采集 profile 和 SHA，不拿历史 `current.pkl` 当最新现场。仅替换目标动作行的目标轨道，保留其他动作、retained 引用及已修好的指腕轨道；原资产备份另存。
- 用户要求检查时，覆盖普通/空仓、30/45 和全部握姿的完整流程，包含初始交接、画外取匣、拉栓和结束后待机；仅采插入关键帧不足以判断整段合格。
- 同时看实际图像、当前蒙皮表面及连续姿态。枪相对手的数值不变只能证明没有新增相对滑移，不能证明原有网格零穿透；10 cm 内顶点计数也只是接近相机的线索，不是穿模结论。
- Review32 完成 20 组离线引擎流程，未发现 Feedback31 新增的可见扭曲/滑移/交接跳变；这不等于实际关卡、音频或联机验收，且不自动授权下次运行测试。

## 弹箱开盖、捏链与回握

保留认可的源手模、绑定、权重、骨长及局部平移和缩放，姿势只写关节局部旋转。开盖先定掌根接触和肘部路线，把旋转分给肩、肘和前臂；逐段检查腕背轮廓及前臂是否横穿镜头。弹箱分支覆盖无前握把和各改造握把，普通与空仓换弹分别处理。

右手从托箱过渡到捏链时，先从机匣侧面绕开，再穿过夹持、提链、铺链各接触点，铺好后自然松手。检查时配对玩家视角和腕部外侧近景，连看离握、接近及回握，并看远端身体是否回到持枪。Wrist38 保存右手避让，Wrist39 在其上修订开盖左臂。
