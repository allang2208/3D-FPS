# 双手长柄：绕柄检视、换手镜像与出击节奏

战锤 2026-10-15～16 案例。用户反馈：L 检视设计方向认可；行走检视按反馈调整三轮（甩腕过冲减半、转速再加倍、只留风声）；第二段换手与 V7 节奏用户回复“成功了”；V6 被否定（出手过慢、打击力不足、像线性播放）。以上是用户反馈，不等于系统性实机验收。默认仍只做后台制作，用户要求时才诊断或渲染。

## 绕柄检视

- 先用锤体网格实测柄中线（本例为 `WPN_root` 局部 +Z，偏差 <1 mm，柄半径约 1.5 cm），绕中线上的点旋转武器；不绕网格原点、镜头或手腕。
- 握持时双掌保持待机的掌-柄局部矩阵；松握时掌心只绕同一中线、按原生半径环绕，让圆柄在掌中滚动，不穿模。首末帧等于待机。
- 拨弄阶段用“握紧整体来回拧 + 逐指抬放”表达手上动作；甩转靠右手出手、锤只减速不反向、整圈后双手合拢接住。
- 行走自动检视只播转锤半段，节奏照双手剑（装备后 2–3.5 s、之后 5–8 s，仅地面行走时倒计时）。动作、冲刺、跳、滑、闪、翻越、施法一律打断；打断时掌沿柄圆周 0.14 s 交接，不穿过柄。
- 甩腕跟随过冲 24° 被评“别扭”，12° 可接受（右腕相对待机 ≤ 约 30°）。加速转锤时保持同样过冲。检视音效：用户只保留挥动风声，钢铁碰撞层被否定。

## 换手：镜像已认可的一击

- 右手在上的斜劈应从右肩蓄力。左→右的第二击若仍右手在上，会让右臂越过头顶、肘部挡在视线前，前臂外翻。做法是把已认可的第一击左右镜像为左手在上。
- 镜像公式：`P'(b)=M·P(b̄)·(rest(b̄)⁻¹·M·rest(b))`，其中 M 为 x 反射、b̄ 为对侧骨；武器取 `W'=M·W·S`，S 为武器局部 Y 反射，保持柄轴与锤头轴。镜像前确认臂链静止姿态左右对称（<1 mm）。
- 只在两种握法握着同一把锤的时刻换手：起手竖直经过身体正中（矢状面）时从右上换到左上，随势前指时再换回右上。顺序是：上手滑到下手上方 → 下手松开、外抬约 8.5 cm 绕过 → 在上方握住 → 原上手滑到下端。握持手用绕柄角、沿柄位置、半径的柱面插值。
- 求解时，参考姿态按每只手各自的换握进度，在两套认可姿势之间做父空间混合。空中那只手的肘部引导只随手腕平移；如果连手腕转动一起刚性带动，掌向大转时会翻肘。空中保持手臂自然的腕线，接近柄时再转入握姿。锁骨的局部平移是动画量而不是骨长，混合时不能归一化。
- 招式首末仍回到共同待机（右手在上），第三段和其他动作无需改代码。

## 出击节奏（V6 被否 → V7）

- 用运动弧长（锤头 + 双手 + 双肘位移）重排已认可姿势的时钟，能去掉源动作里的死停而不改关节；接触帧、总长与玩法计时保持不变。
- V6 把下劈拉成 0.22–0.30 s 的匀加速，锤头峰值 24–29 m/s，被否：慢、没力、像线性播放。
- V7（用户认可）每一击分四拍：
  1. 蓄力：起手即动，逐渐减速到顶。
  2. 蓄满一拍：0.06–0.15 s 极慢后沉，不是死停；手指略松，镜头收紧。
  3. 爆发下劈：0.11–0.14 s，速度按 2.8–3.5 次幂集中到最后几帧（作者时锤头峰值约 53–58 m/s）。锤头滞后双手 ≤8°，接触瞬间甩直。
  4. 命中：硬停加震颤、回弹，沉重回位。挥空：带着接触角速度续行 30–40° 后刹住。
- 三段要有性格差异：标准／最快最利落（带换手）／憋得最久、最沉。
- 挥空续行要让手臂绕肩继续带锤。肘部引导应随手腕整体刚性转动；只平移时手腕会多折约 25°。
