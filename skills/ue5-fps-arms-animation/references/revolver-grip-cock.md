# 左轮握持、单动拨锤与烘焙

适用于沿用原生手枪骨架而更换枪体、加入拨锤动作，或开火后视模离开画面的排查。机构部分读 [左轮机构绑定](../../ue5-weapon-workflow/references/revolver-mechanical-binding.md)，其他动作共享按 [作者姿态差量](weapon-animation-sharing.md)。RSH-12 最新握持／拨锤修订尚未完成，以下是已定位的方法和制作边界。

## 静态源与动作烘焙

静态网格作者文件可能以 `REST` 保存。后续动画作者加载它后必须切回 `POSE` 再求值、写帧和导出；写入关键帧并不保证 FBX 导出使用动作矩阵。开火时整枪／手臂消失应先定位动画源姿态和导入求值，不直接用更大的 bounds 或视模位置掩盖绑定姿态切换。

## 接触使用完整蒙皮

依据实际手掌、掌指关节与指腹表面建立接触。顶点混合在多个骨之间时，单骨最大权重可能低于 0.5；用该阈值过滤会漏掉掌部，从而得到假的零穿透。以主导骨划分区域时保留该区域全部混合权重，再使用完整 LBS、当前肩肘两骨解算及真实枪体表面求值。

拟合基准同时使用原始模型绑定与原始未修订 profile，输出绝对修正。基于上一轮已改姿态拟合却在运行时再把修正叠回原 profile，会重复施加位移／旋转。源几何与 runtime 差量必须使用同一个基准；旧离线截图不代表下一次重制的姿态。

保留原生骨段平移、长度和缩放；联动整手、腕、肩肘与手指旋转。拇指指骨目标到达击锤，不代表指腹不穿握柄；指骨中心误差、实际表面间隙、穿透和视觉观感分别记录。扣扳机也应按真实指腹／护圈关系选目标，不能把某一段指骨中心当作所有枪型的接触点。

## 握持、过渡与 ADS

先完成稳定握持，再制作换握、压锤和回握。若 idle 与 ADS 使用不同的独立握姿，插值可能使指头穿过握柄；制作中可保持手相对枪体的共同握点，让肩肘随整枪改变。沿接触路径移动目标并以原生骨长解算，比仅混合“已接触”关节旋转更能保持中间段约束；最终过渡仍需完成作者源后才能报告效果。

开火后坐、退出 ADS、拇指接近、拨锤、回握和按持键意图回瞄使用同一源时间。动作播放倍率改变时，输入锁定、机械 cue、姿态与相机 FOV 一起变速，避免 FOV 已退出而手仍保持瞄准姿态。保留玩家瞄准键意图，不以暂时退出 ADS 覆盖输入。动画结束再交接到当前握持姿态，记录 runtime 额外交叉混合对接触的影响；是否使用完整动作权重取决于具体片段的起止合同。
