# 撞门护拳：原生绑定与跨骨架交接

适用于第一人称左手护拳动作，以及从持械实时姿态进入公共手臂动作的交接。先确认实际显示的手臂 leader、资产路径与姿态层；武器分类或“无托”标签不能决定骨架转换方式。衣袖、手套 follower 跟随修正后的 leader。

## 区分持握姿态与骨轴差异

- 骨名、父级相同还不够。比较父空间骨轴、关节偏移、scale、component rest 与实际采样姿态，分别识别原厂持握偏置和整个骨架的坐标基底旋转。
- `Q目标 = Q作者动作 × Q作者参考⁻¹ × Q目标参考` 保留目标参考持握偏置，不保证肩、肘、腕落在作者指定的相机位置。ASH-12 原生绑定属于这一情况；不能用增加腕部补偿修复整臂方向错误。
- 当关节轴和骨段偏移兼容、参考旋转只是不同持握姿态时，护拳阶段复用完整作者链旋转，再由目标原生父子偏移做 FK。保留目标 scale、骨长、绑定和权重。不同轴或不同长度需要另行适配，不能把直接复制推广为通用重定向。
- 同时处理锁骨、上臂、前臂、手腕、twist/helpers、掌骨和五指。只转手掌或漏掉前臂辅助骨会使腕部变细。握拳复用现有完整手型；轻摆从锁骨根整体移动，不分别掰腕或缩放骨骼。

## 跨组件进入与恢复

- 采样姿态乘源组件变换后，已经包含源骨架根基底与武器 pivot。转换到相机或目标组件空间后，若源、目标父空间关节轴兼容，不再追加 component rest 旋转补偿。
- 弓的根基底整体相差约 90°，但左臂父空间关节轴一致。重复 rest 补偿会改变原生骨段 FK 方向；入场和实时恢复必须采用同一空间规则。
- 作者护拳负责左臂，武器骨及 `bow_grip` 子树保留原职责。弓通过公共展示权重整体下移和恢复；输入被占用时，原弓姿态仍持续采样，避免恢复到冻结帧或重新装备。
- 恢复目标是当前持械／空手实时姿态。局部平移与四元数按同一阶段时钟混合，然后一次 FK；不要用旧示例末帧取代实时目标。
