# 第一人称锻造：锤子、钳子与淬火

用于 FPSGAME 固定工位双手工具操作；继续遵守当前认可 V7 裸手基准。作者入口 `Tools/Forging/author_forge.py`、`forge_arm_pose.py`、`forge_stroke.py`、`author_quench_motion.py`，运行入口 `Building/ForgeInteraction.*`、`ForgeArmsMeshComponent.*`、`ForgeQuenchPresentation.cpp`。

- 先确定锤柄与钳柄的真实握持坐标、柄径和接触面，再迁移已认可的握姿。工具与手共用这个关系；只移动工具或只转腕骨都会破坏接触。
- 腕部到肩部的链条一起处理。判断“肘扭曲”时区分弯曲平面跳变、前臂滚转、局部／组件空间混用，以及视模开口进入相机；不要把所有问题归为手指抓握。
- 躯干外侧肘支撑、自然屈伸与前臂滚转应随抬锤／落锤／回锤连续变化。保留腕部握点，避免仅旋转下臂让手腕补偿；相机转换到水桶后仍在当前相机关系下保持接触与双臂可见范围。
- 落锤速度改动同时更新锤面接触时刻、命中锁定、音效与火星触发，并同步可编辑动作源。热区在出锤时锁定，接触时计分，下一个目标等待回锤与间隔，避免动画还未恢复就要求玩家再次操作。
- 淬火时持续维持左手钳握及剑胚关系，镜头转向桶口不应把两手直接插值成新静止姿势。视觉蒸汽由实际入水接触触发。
- 动作采样、Manny 供体、原生绑定 JSON 和 V7 派生网格含现有授权素材数据；发布脚本与方法不等于获准公开这些采样或二进制。旧装配源若仍被当前脚本读取，必须保留，不能按版本号归为废案。

此案例在本机完成制作与常规构建，后续腕肘观感由用户在游戏确认；本页不把编译成功等同于人体工学或视觉验收。
