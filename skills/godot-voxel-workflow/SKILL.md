# 可建造体素标准

在实际 Godot 仓库读取 AGENTS.md、WORKFLOW.md。需要建筑面板或整片空间时配合 godot-building-workflow；UI 遵守仓库冷钢规则。案例参数和代码定位见 [当前实现](references/current-voxel.md)，先确认文件存在，不能把文档发布当作运行功能已发布。

## 先锁定数据合同

- 当前网格为0.5米立方体；坐标换算、格心、碰撞体、预览和存档必须一致。不要仅缩小显示网格。
- 同尺寸、同物理行为的新材质默认一个通用块ID，地面/墙体/顶棚是用途。只有真实几何或行为差异才拆类型。
- 旧wood/stone用途ID仍存在；用户讨论合并不等于已完成迁移。合并时保留旧ID读取及木墙纹向，不静默重置建筑。
- 材质加入运行注册、选择面板、实际缩略图、命中表面和存档恢复路径；不能只造材质工厂。

## 几何与移动

- 对外露边做圆滑，拼接面保持完整。相邻格、斜邻格及沿边连续段都会影响边界；仅看两个面是否空缺会产生T形接缝。
- 使用邻接签名缓存网格，增删方块要使受影响邻居更新。检查面朝向、法线、共享面边界点和立方体外包围盒。
- 显示圆角与碰撞分离，当前碰撞仍是0.5米BoxShape3D，避免圆角碰撞导致卡脚或贴墙滑移。
- 当前目标为正常行走可上0.5米台阶，1米立面阻挡自动上阶；跳跃仍按玩家已有能力处理。上阶需全胶囊上抬/前进/落地扫掠，低顶与落点同时有效。
- 身体先解决碰撞，相机单独做世界空间位移补偿和临界阻尼回正。不要平滑身体穿进台阶；连续台阶、下阶、跳跃、低顶和传送分别验证。

## 材质与细节

- 先查看当前场景和同类材质。相同石材风格优先复用现有着色器；改共享着色器时保留原默认值，新增效果由新材质显式启用。
- 木材用清晰顺纹、细孔和小木节表现厚重，避免放大斑点、强凹凸和随机脏污造成泥土感。墙体纹向与铺地纹向是材质方向，不必绑定建筑用途ID。
- 石材区分哑光细粒与大理石抛光纹脉；同时调整底色、纹理物理尺度、粗糙度和细微凹凸，不靠纯白或金属度制造光泽。
- 使用三向投影或体积纹理覆盖圆角。分块变化应稳定依赖坐标，避免每次加载重新随机；同一块的纹脉应跨面连续。
- AI贴图保留源图、提示词和实际尺寸；不得把放大后的尺寸说成原生生成分辨率。底色推导的凹凸是近似，不能宣称完整实测PBR。外部素材保留来源和许可。
- 缩略图从当前网格和材质实际渲染，等比显示；单材质更新只生成该目标，防止其他资产反复重写。

## 验证与交付

按改动选择几何边界、相邻更新、0.5/1米通行、材质预览、放置/拆除/承重、旧新类型存档测试。涉及面板检查分类、预览与确认、枪械输入阻断、Esc和鼠标捕获；输入使用有图形窗口，headless只证明非交互逻辑。

隔离INVENTORY_SAVE_PATH；新增资源先导入，再运行无头启动和相关测试。实际记录窗口尺寸、日夜照明与相机位置，保留最终实际渲染，分别报告自动检查和主观观感。清理与推送执行WORKFLOW第8节；不清空共享缓存或提交其他会话内容。
