# 动态地表材质与附近优先加载

用于 UE DynamicMesh 地面模糊、近景凹凸丢失、材质等待不结束，以及出生区域加载范围过大的排查和修改。以本机引擎源码为 API 依据；必要制作和构建照常，运行检查仅按用户授权范围进行。

## 先分开四种就绪状态

- 材质资产加载成功：确认运行网格实际绑定的 MID 及父材质，不能仅凭 Content 中有新版资产判断已应用。
- 着色器可渲染：确认当前平台资源、已请求的编译任务、可渲染 shader map，保留编译错误报告。
- 高清纹理驻留：记录实际绑定材质的纹理、resident mip、目标 mip、初始化及流送状态。全局流送队列为零不等于地面已达到需要的分辨率。
- 附近地形可行走：网格、异步碰撞和局部植被分别就绪，不能用单一固定等待时间代替。

主世界里未显示的地表贴图、首次异步加载返回的小尺寸和编辑器预览不能当作旷野实机 mip 证据。编译通过、资产已保存、实机清晰度及帧率改善分别报告。

## UE 5.8 按需着色器的等待陷阱

`FMaterial::IsGameThreadShaderMapComplete()` 检查完整变体集合；在按需编译模式下，未用到的变体不一定入队。不要把它当作运行时进入关卡的必要条件，否则会出现没有待编译任务但永远不放行的状态，也不要为放行而强制提交所有变体。

附近网格在加载遮罩下正常渲染，让引擎请求当前 pass。项目采用 `GetMaterialResource()` 获取实际地表资源，在编辑器侧通过 `IsCompilationFinished()` 等待已请求任务，并要求 shader map 存在且 `IsValidForRendering()`。进入前仍保留渲染同步和数帧稳定期；这些 API 状态不替代用户要求的视觉验收。

若无待处理任务却持续没有可渲染材质，记录资源/map 状态并显示可取消的失败；不要无限等待，也不要超时后无条件放行灰色/模糊地面。FPSGAME 该空闲失败期限为 30 秒，不是全部着色器编译的总时限。

查本机引擎 `MaterialShared.cpp` 的 `SetGameThreadShaderMap`、`TryGetShaders`、`IsCompilationFinished` 与 `MaterialShared.h` 的 `IsValidForRendering`。`UMaterialInstance::GetMaterialResource()` 会回退到父材质，不能未经读取实现就断言 MID 必然没有材质资源。

## 世界坐标采样与纹理驻留

DynamicMesh + Custom 世界坐标 UV 未必有可靠的烘焙纹理密度。`UPrimitiveComponent::GetStreamingRenderAssetInfo()` 的通用估算不足以代表每层实际 2–8 m 的平铺尺度，纹理系统可能认为低清 mip 已满足需求。

小型、固定的共享地表贴图集合可从实际 MID 的 `GetUsedTextures()` 收集，用短期限 `SetForceMipLevelsToBeResident()` 持续续期，并等待资源初始化和需要的可用 mip；尊重平台、画质、非可选载荷和 cinematic mip 限制。退出后让请求自然过期，不随意改共享贴图的永久 `NeverStream` 或整个项目纹理池。纹理集合/尺寸增长时重新评估显存成本，不把这种做法扩大成全场景锁定高清纹理。

地表纹理请求尽早与附近内容准备交叠；普通环境贴图的有限等待不能绕过关键地表条件。共享贴图的加载量和世界地块数量是两回事，不能把贴图驻留等待解释为整张世界渲染。

## 进入条件与后台流送分开

明确区分可进入的附近范围与正常游玩的视野范围。FPSGAME 当前使用 64 m 网格、初始 3×3 地块和随后与角色周围 96 m 相交的地块；范围按格子边界取整，不是精确圆形截断。

- 请求、距离判断和碰撞就绪使用同一角色中心；不要一处用相机偏移、一处用角色位置，导致等待区域外永远不会请求的地块。
- 只统计附近必须存在的地块，缺失格也算未完成；不能仅查队列为空。
- 远处任务不能通过 `!AllJobs.IsEmpty()` 拖住进入；进入后按原预算恢复远景流送。
- PCG 可保留正常生成半径，入口只等待 `min(该层半径,附近范围)`。保留前沿碰撞守卫及稳定的种子、采集身份和存档。
- 保留异步计算、每帧有限网格/碰撞提交；不要用同步 flush 或一次性生成全世界来掩盖等待问题。

低精度全景背景、全局资源编译和 PSO 预热仍是独立阶段。缩小地形等待范围不等于消除了这些成本；没有同场景实测，不承诺总加载秒数或 FPS。

## 近景凹凸与采样经验

- POM 高度步进与最终颜色/法线必须共享各层真实投影尺度、偏移和高度混合规则。只在最后命中区间细分，设置步数上限与距离/视角渐隐；POM 不改变轮廓或碰撞。
- 不同覆盖层的法线按完整 XYZ 权重混合，零权重必须无影响；额外细节再用 RNM 叠加，不能让零权重层继续乘法线 Z。
- 在真正纹理读取前分支才可能省采样；已采样结果再 lerp 不会省去读贴图。显式梯度在分支和循环外从未位移 UV 计算，压缩法线按 UE 规则解码，使用对应共享 sampler。
- 随机平铺保持颜色、法线、粗糙度使用相同变换和权重；若旋转 UV，也要旋转切线法线。本案仅干壳层随机平移，避免把多样本开销扩展到每次 POM 读取。
