# 枪械接入、装配与运行合同

## 模型与材质

- 保留用户选定枪型与当前手臂外观。当前 M4 运行网格是 `/Game/Weapons/M4HK416Replica/SK_M4_FoldingSights_HK416`；不要因旧文档写着 Cubic 手模或早期 M4InfimaV3 就恢复它们。先读取 `FPSGAMECharacter.cpp` 的真实加载路径。
- 源骨架、rest、逆绑定、单位、轴与材质槽一起审查。跨引擎转换按基底/四元数处理；Blender 源长度与 UE 厘米单位之间只转换一次。不要复制不匹配 rest 的局部旋转。
- 先处理几何连接、反向面、权重和材质槽，再调材质。金属、聚合物、皮肤、手套、衣料、光学镜片分别校准；保留有用的原生法线和受控粗糙度。游戏、枪匠预览和图标使用一致来源，检查迟生成配件的最终材质。
- 新衣服/手套需要合适网格、UV、权重与关节弯曲空间；材质不能生成衣服厚度或修正坏蒙皮。外观升级仍检查袖口、手腕、肘和所有接触姿态。Godot 的聚合物 shader 或历史统一染色数值不作为 UE 默认材质参数。

## 配件与 ADS

- 折叠机械瞄具由当前改造状态直接决定：装光学瞄具时保持折叠，卸下后立即恢复。切枪和重建组件时立即应用已有状态，不从展开姿态插值播放折叠动画。前后瞄具分别使用真实铰链与转轴，向远离光学底座的方向折叠。
- 枪身、弹匣和拉机柄保留独立分件及各自局部坐标；源模型已经拆分时不得合并为一个刚性蒙皮区。弹匣最终姿态以入枪接口决定，手掌在接触段跟随弹匣；拉栓以该枪实际机械侧别和行程重新适配。

- 复用一套通用配件几何，各武器负责安装骨骼、局部变换与眼距。逐件验证接口贴合、原件替换、装卸恢复、动画跟随和实例保存；不得出现悬空、重复件或非设计性穿插。
- 用户现有瞄具偏好为顶部导轨中段，先用侧视/斜视确认安装空间，再校准 ADS；不能直接沿用其他枪的前移距离。
- 枪口、抛壳口、准星、照门、光学中心分别测量。将标记从实际测量帧变回对应骨骼的 rest/local 空间；世界坐标不直接当挂点坐标。
- 验证最终渲染相机、瞄线及真实射击射线。区分整体后坐力与机械活动点；不逐帧追逐枪机/套筒驱动双手反向补偿。腰射摆位不能不加区分地叠入 ADS。
- 用真实 FOV、近平面、光照及不同宽高比检查枪托抢镜、断臂和镜片可见性；中心截图仅证明该帧。迁移 Godot 的 FOV/轴时按实际源参数换算，历史 AKM 偏移不是 M4 标准。

## 数据、枪匠与存档

- 沿现有 `FPSGAMECharacter`、`FPSGunplayAnimInstance`、`UGunsmithSystem` 和项目库存子系统接入；读取当前实现，不为换枪复制整套角色逻辑。
- 核对 `Content/ColdSteelData/gunsmith.json` 里的真实武器定义与配件 ID。旧报告曾发现 `weapons: []`，这是历史故障线索，不是当前状态结论。
- 枪匠要覆盖草稿、预览、应用、实例保存、重开读回和换回原件。UI 条目、候选模型或单独弹鼓测试不能代替完整改造功能。
- 保留弹匣容量、剩余弹、备用弹、拥有权、快捷切枪和 UI 数据同步。非空仓甩掉旧弹匣是当前动作风格，不隐含要求修改剩余弹药回收规则。
- 正常换弹、空仓自动换弹、按住扳机、重复按 R、切枪、ADS、冲刺、滑铲及滑铲跳按现有输入合同检查。动作繁忙期不重复启动声音、不重复补弹、不凭空补满。
- 按实际项目的隔离 profile 参数运行审计；不要在 UE 中照搬 Godot 的 `INVENTORY_SAVE_PATH`。本 M4 验收通过 `-ColdSteelProfile=<unique>` 隔离测试。

## 输出范围

按变更选择检查：模型/许可、骨架/压缩、装配/ADS、动作/音效、输入/弹药、库存/改造/保存。动画小改不自动要求重新制作整个枪匠；涉及某分支就验证该分支。报告仍存在的可见缺陷和未覆盖范围，不把数值通过包装为完美视觉。

## 近距离枪体与机械瞄具表面修整

- 先区分轮廓分段、硬边/平滑法线、法线贴图与粗糙度问题。4K 贴图和 Raw/Source 文件名不等于存在另一份高模；依据实际源包判断，不能把低清预览造成的损失当作源模型缺陷。
- 修整蒙皮枪时保留骨架 rest、权重、活动件身份、UV 和材质槽名称。机械瞄具的孔径、准星尖端与视线中心独立于倒角；不靠整体细分缩小瞄孔或改变挂点来掩盖粗糙。
- 对真实硬边使用小半径、限制重叠的倒角，再处理加权/分裂法线；避免将整枪所有面一律平滑。FBX 明确保留平滑组和自定义法线；含多边形面时可由 UE 计算 MikkTSpace 切线，不强行导出不完整切线。
- 保留源色彩和金属遮罩，将瞄具材质与枪体分开；粗糙度与法线强度按近距离用途调整。不要用降法线强度替代几何轮廓修复。
- 本机 QBZ 案例：`SourceAssets/QBZ19120260912/SurfacePolish`，瞄具 0.15 mm、枪体 0.25 mm 四段倒角、38 度硬边。仅作为可编辑起点；已导入，未做实机或渲染验收，不作为通用参数或视觉通过证据。
