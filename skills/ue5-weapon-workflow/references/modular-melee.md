# 近战武器拆分与可替换改造件

用于把已接入的整把近战武器拆成可复用模块，以及新增护手、握把、配重锤和表面符文。寒晶·双手剑在 2026-09-19 获用户确认“成功，符合预期”；这是用户实机反馈，不能写成助手本轮重新测试。

遵守宿主默认不主动测试的规则。读取接口与动作资料、制作、导出、导入及必要构建属于正常开发；新截图、游戏测试和验收按用户授权执行。

## 1. 先区分改造栏目与实体模块

| 改造栏目 | 几何/表现职责 |
|---|---|
| 剑身Ⅰ | 独立剑刃模型；可仅修改数值并继续使用原装外形 |
| 剑身Ⅱ | 附着剑刃表面的符文材质/覆盖层，不额外切一块剑刃 |
| 护手 | 中央安装座和两翼作为同一替换模块 |
| 握把 | 独立握柄，保留两端安装截面及手部接触约束 |
| 配重锤 | 独立柄尾部件，安装点跟随所选握把的柄尾 |

栏目数不等于网格数。没有独立模型的数值选项回退到本槽 `factory`；保留原改造 ID、物品实例与存档。不要为每种组合重复导出整剑、整套手臂或所有动画。

## 2. 读取并冻结接口

先读取当前实际加载的整剑、已接受修订件、手臂骨架、驱动骨、局部轴、单位与动画握点。把源几何转换到统一武器空间，再确定每个切口归属。

- 切口取各变体共同保留的原装区域，避开需要独立造型的外侧轮廓。护手中央座与两翼不要被拆到不同模块后互相覆盖。
- 保存安装原点、实际边界顶点环、法线、UV、顶点色及材质槽。连接面决定安装关系，整体包围盒只用于取景等展示用途。
- 剑刃根/尖攻击采样点、可见剑尖、符文投射范围分别保存。外观拆分不顺带改攻击距离。
- 记录骨骼缩放抵消变换，不能在作者顶点、导出单位和运行挂点上重复乘一次缩放或位移。

寒晶案例参数（不是新武器通用常量）：作者单位米，剑尖 +Z、宽 X、厚 Y；护手与握把切口 z=-0.050，握把与配重锤切口 z=-0.227；刃座 V 边界 z=-0.008+1.1×abs(x)。握把/配重锤顶点分别相对各自安装原点归零，UE 目录再给 -5/-22.7 cm 位移。骨架驱动根含约 100 倍缩放，因此挂载变换含约 0.01 抵消量。

## 3. 无缝拆分与新部件制作

1. 在原三角形上切割并插值位置、面角 UV、顶点色和表面法线；只封新切口，保留未改区域的着色。
2. 新件复制同槽原装安装端，在端面以外制作造型。曲面接头按真实截面做连续过渡，同时延续轮廓斜率与法线；不依赖塞一圈遮挡网格修补错位。
3. 保留源面角属性后焊接需要连接的同位置顶点。减面前处理 glTF 在 UV 接缝处分裂的顶点，避免减面把安装环切碎。
4. 新面展开有效 UV；原装端继续使用原 UV。使用双 UV/顶点色混合时保留两套坐标及混合通道，过渡面不能把原剑蓝色区域拉成金属接头。
5. Blender 先设置 `polygon.use_smooth`，再调用 `normals_split_custom_set`；倒序会丢失需要保留的自定义法线。
6. 形状明确、握持约束强的握把可按用户选定路线使用 Blender 精确重建；AI/5080 负责外形探索时，生成分辨率与纹理导出的 voxel grid 必须匹配。材质和接口仍在本地完成。

生成参考是造型来源；真正连接尺寸来自宿主。高分辨率不是小型配件的默认前置条件。完整处理方法另见 [模块连接面与局部重建](../../asset-model-workflow/references/modular-part-interfaces.md)。

## 4. 材质与符文归属

- 同一把剑的金属安装端复用其当前表面，保留皮革、水晶和符文的独立槽。蓝色水晶不能仅改金属底色：球体应分到独立半透明槽，金属度设为 0，支架仍用金属材质。
- 符文只附着独立剑刃，安装/卸下与 `blade_2` 选项同步。不得用覆盖整套骨骼网格的坐标范围污染手臂与护手。
- 需要夜间清晰的符文：柔和银白或冰蓝底色、非零亮度下限、轻微周期变化；本例使用局部 `EyeAdaptationInverse` 补偿和遮罩扩采样光晕。自发光可见不等于照亮周围环境，泛光还取决于后期设置。
- 反馈“发黑”时区分实际运行材质、遮罩/透明度、投射坐标、曝光与材质连接；不能仅凭代码中有 Emissive 或强度数值认定渲染已正确。
- 已被组件引用的材质优先改参数和已有节点，保留升级前源；避免删除整个表达式表后在活动实例中重建。

## 5. 共用装配入口

目录保存槽位 ID → 模型路径、安装位置、可选子部件偏移/动画目录。运行时组装函数同时服务持剑、检视、改造台草稿/应用/取消、物品预览与世界掉落。

- 手臂作为保留原骨架的动画载体，独立剑根挂到原驱动骨，其他模块挂到剑根。
- 更换一槽只替换该模块；卸装恢复 `factory`。选择键包含所有会影响可见结果的改造 ID/模型路径及符文。
- 预览包围盒取已装模块的合并范围；柄尾砸击读取实际装配后的柄端范围。
- 读写存档继续使用 `gunsmith_parts`。追加目录时先重读当前文件，只合并本次槽位条目，防止覆盖并行接入。
- 新增件只导入新增资产并追加选项；完整基础模块重建脚本可能重置目录，重跑前保存并重新合并后续改造项。

寒晶入口：`ModularSwordVisual`、`RuneSwordComponent`、`Content/ColdSteelData/frost-sword-modules.json` 和 `melee-gunsmith.json`。界面图标用实际新模型制作，并优先使用武器专属命名，避免覆盖另一把剑的共用图标。

## 6. 握把长度和动画一起适配

普通改造保留原握持外轮廓和两端位置。加长款保持上端接口，把新增长度加到中/下段，移动下端原装安装环，并通过握把目录的 `pommel_offset_cm` 同步下移所有可选配重锤。

新的双手间距通过独立动作家族适配：保留原武器轨迹、右手、手指、帧数和时长，仅在左手实际握柄阶段调整完整手臂链。扶剑格挡、检视松手与装备入场使用原接触状态退出适配。详见 [改造握把的手部适配](../../ue5-fps-arms-animation/references/modular-melee-grips.md)。

刷新条件必须包含动画家族。仅比较物品实例和手臂网格会漏掉“同一把剑从普通握把换成长柄”的动作更新。音效路径继续取基础武器目录，不跟随仅包含动画的改造目录。

寒晶当前参数：原装/吸震/速握为 17.7 cm；长柄为 20.5 cm，柄尾下移 2.8 cm，左手实际握持阶段向后适配最多 1.8 cm。这些数值由本剑尺寸决定，换武器重新读取。

## 7. 成品、依赖和发布

保留完整可编辑源、选中的生成母版、PBR、接口记录、作者/导入脚本和运行目录。用户接受后记录接受范围；本次寒晶的部件拆分、配重锤修订、符文荧光及三款握把已获用户确认。

旧整剑、原始生成 GLB、修订前参考或旧全剑 Blend 可能仍是当前脚本输入，不能按日期/文件夹名直接当废案。确认退役的独立候选与自动备份移至 `trash`，保存清单、SHA-256、原因和替代入口。

公开 Git 发布代码、脚本、文字参数和恢复说明；Manny/Meshy 等未核准再分发的模型、贴图、导出动画及密集源姿态数据保留本机。运行目录依赖本地二进制，不能把源码发布称为完整素材包。

本机作者案例：`SourceAssets/FrostSwordModules20260915`、`FrostSwordPommelsRepair20260915`、`FrostSwordRuneGlow20260919`、`FrostSwordGrips20260919`；工程入口为 `MELEE-WEAPON-WORKFLOW.md`。

## 8. 同类武器共用配重：保留设计并集

用户要求两把剑已有改造全部共用时，合并不同造型和属性的并集；不能用其中一套三款覆盖另一套三款。2026-09-20 案例为六款改造加各剑原装，共七个选择，已由用户确认达标。

- 共享目录承担唯一 ID、数值、主体模型和源安装接口；宿主 `pommel_profile.interfaces` 承担位置、旋转、比例、连接件及材质主题。新增剑只增加适配，不复制选项或按剑分叉伤害计算。
- 两组历史选项可能重名／同 ID。保留当前已发布 ID 的含义，为恢复的不同设计分配独立 ID。历史存档没有版本标记时，不能猜测相同字符串曾指哪个模型并批量改写存档。
- 接口按源安装端分类，不按每个选项复制主体。双向共用可能需要不同连接件；本例 0.9 比例和 6 mm 连接件是测量结果，不是通用常量。真实端面、UV、顶点色、法线和独立水晶／符文槽一起保留。
- 同模型换宿主材质或恢复原装时清空旧覆盖材质，移除失效连接件；长握把的尾端偏移同时作用于配重与连接件。外观缓存键包含完整装配与材质描述，不能只看模型路径和选项 ID。
- 共享装配入口覆盖手持、草稿／取消／应用、物品预览和掉落，属性详情使用同一计算入口。正常剑类连击只循环三段；配重的快速近战效果走独立技能，不重新插回第四段。
- 退役三款安装器与回滚备份前，先把最终安装器需要的原属性提取为维护中的小型输入。保留早期目录里仍在用的正向接口、材质与主体制作源；仅阶段名称过时不能判废案。六款最终入口见本机案例 `SourceAssets/SixSharedSwordPommels20260920`。

修改目录并落盘不会刷新已加载的目录缓存；普通编译成功也不能代表旧实例已加载新版本。按用户授权完成重载／必要重启，区分构建记录、用户认可与助手测试；默认不追加游戏验收。
