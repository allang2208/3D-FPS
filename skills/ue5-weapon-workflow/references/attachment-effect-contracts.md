# 改造效果的结算范围与制作回写

用于修复“目录写了效果但攻击漏用”、通用攻速、全攻击击退/伤害、触发型护手和法杖吊坠。以下是 FPSGAME 2026-10-04 的已实现合同；构建完成，尚未游戏或联机验收。具体配置仍以当前源码和目录为准。

## 从目录到实际攻击

追踪目录键 → 解析 → FMeleeModifiers 汇总 → 出手快照 → 权威命中 → 面板和制作脚本。字段已解析不代表已汇总；凝碧星核曾在 Calculate 丢失快速近战魔法易伤。状态应在确认有效命中的共同入口施加一次，移除本地动画旁路，保留剑刃与快速近战各自的适用条件。

先区分基础攻击与完整伤害。damage_mult 只表达既有基础攻击口径；all_attack_damage_mult 在 WeaponDamagePanel 构成属性、附加物理/魔法后统一缩放，QuickCombatStats 的独立公式也要消费。不要在归一后的伤害面板与最终命中重复乘倍率。当前山岳为完整近战伤害×1.1、全部击退×1.5、削韧×1.5；不因此扩大为法术增伤。

all_attack_knockback_mult 要覆盖技能自行增加的距离：普通/重击/上挑、快速近战、旋风、冲刺斩的基础和额外项。原值为零仍为零；它不修改击飞高度、倒地时长或控制准入。当前硬化配重×1.1，山岳同时装备后×1.65。

普通、快速近战、独立上挑、旋风与冲刺斩使用 ColdSteelMelee::Evaluate 的共同 AttackRate。源姿态、接触窗和事件沿同一时钟映射；不要在特殊动作内重置为 1 或只读取凤舞/狂暴。重击蓄力与技能冷却是独立属性。旋风/上挑体力也要乘装备与临时近战减耗，不能只在普通攻击入口消费。

## 普攻替换动作与护手触发

游龙升龙仍是普通第三段：保留第三段伤害/削韧、队列和普通体力，不调用独立上挑的技能公式、300 基础削韧、训练或冷却。准备段按源时间和播放时间双向映射缩短50%，不能直接跳过准备姿态。先结算削韧，再判断能否击飞，遵守 [韧性与控制](../../ue5-monster-workflow/references/toughness-bars-and-control.md)。

UTangDaoGuardComponent 在装备变化时缓存配置，不增加 Tick；世界时钟记录持续和冷却，权威端处理触发、增伤、回血，挥击序号去重多目标。龙护手减伤在已有减伤后再乘0.75；凤舞由闪避无敌期间实际躲过攻击触发，空闪不触发。龙威增伤/额外削韧和凤舞回血仅针对刀刃直接命中，不自动扩展至快速近战、剑气、持续伤害。切换清除增益但保留冷却。

## 脚架、采集与吊坠

原厂已安装的脚架成本进入 base.ads_percent，卸下选项以负值抵消；可选脚架只在选项上加0.1。沿用已有 ADS 加法口径，避免原厂成本重复计算或拆下仍惩罚。

采集“减少一次命中”旧键实际转为伤害倍率时，说明应写实际采集伤害增益，不承诺不同生命值资源固定少一击。ProductionTreeHealth 的共同换算供实战和浮窗读取。

法杖吊坠写入各法术快照，由权威有效伤害入口消费；火、冰、电的其他法术及次生伤害须逐类辨认适用范围。冰墙无伤害寒冷光环不触发额外命中吊坠。额外寒冷保留各来源减速贡献；额外灼伤与法术固有层分别施加。雷铃额外时长独立保存，结算 max(当前眩晕剩余, 本次固有眩晕)+延长量；过载只加吊坠延长，不偷带直接闪电固有眩晕。移除表现层重复施加。新增 USTRUCT 快照字段后使用常规构建，不把旧内存布局和热补丁混用。

修改目录必须同步对应 SourceAssets 制作/注册入口，防止重建恢复旧数值。法杖施法速度+25%对应耗时÷1.25，即减少20%；暴击率的百分点与相对百分比明确区分。
