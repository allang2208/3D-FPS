# 配件表面、接口与霰弹枪组合

用于旧配件表面修复、逐枪安装适配，以及 SUPER90 枪口与加长弹仓组合。以下是 2026-10-14～16 的制作经验；历史检查或用户认可不自动授权再次启动 UE、渲染或联机测试。

## 凹凸不一定来自模型

- 已认可原低模看起来平整时，先追踪当前运行网格、实际 section → 材质槽、UV 采样通道、切线通道、结构法线及干湿 MID。M16 均衡握把曾因主体/接颈/原厂接口的材质分区错位而采样整枪图集；不能按槽数组顺序猜分区。
- 法线烘焙与目标低模、UV 和切线基底成套保存。换用别枪主体但沿用损坏的共享法线，或平滑低模后继续使用原烘焙，都可能保留坑洼。M16 最终成功路径是恢复原低模及其匹配烘焙，不是换硬表面模型后继续加平滑。
- 只有用户要求诊断图时，使用同网格、相机和灯光，比较常量材质、当前结构法线、原始匹配法线。明显菱形若已存在于法线 PNG，应修复贴图来源；不能通过降低曝光或反复重算法线掩盖。
- 不按资源名判断占位图内容。A762 曾将 Engine 的 DefaultNormal 当成中性法线，实际采样了墙面纹理，在 ADS 下形成明显粗糙起伏；改用确认过的中性法线，保留有效的独立微法线及原材质参数。
- 角点 UV/法线按原装配变换和对应三角面传递；裁切面可在对应原三角面内插值。接口、涂层 UV 和原厂保留面单独保护。导入用正确 UV 构建切线、全精度 UV/高精度切线；法线关闭 sRGB，绿色通道仅转换一次。
- 常量材质下仍有碎面时，再处理几何。幻影握把旧减面体有大量断开纹理壳，最终从认可高模焊接后重新减面、传递角点法线；不能把所有此类问题都归因于法线贴图。非均匀变换下法线使用逆转置。

当前恢复链：伸缩后托的 M16 版在 `SourceAssets/M16StockMaterialDiagnosis20261015`，其他枪在 `TelescopicAllGunsRepair20261015`；幻影握把为 `PhantomGripSurface20261015` → `PhantomGripJunction20261015`。保留 R1 的原始 Inputs、M16 donor 的接口源以及 Phantom 的 canonical/high-normal 输入；它们虽在旧目录，仍是当前恢复依赖。

## 接口与瞄具

- 从当前宿主、骨骼绑定和运行组件变换还原真实安装面。握把接颈保留上端原厂接触面与下方握持主体，仅重建过渡；避免用叠层套领掩盖缝隙，同时保护扳机避让和镂空桥顶。
- M16 固定提把使用贴合槽面的转接座、下方锁紧件并保留机瞄通道。ASH 已有上导轨，只处理实际不贴合的镜座，不照搬提把座。厂商资料仅用于游戏外观参考，作者坐标不作为实物制造尺寸。
- 移动镜身时，镜片、分划、SightRear/AimCenter 等瞄准插座用同一刚体变换。公共镜体需要私有底座时，确认运行路径确实切到该枪私有版本；不能只制作新网格而仍加载通用裸镜座。六款瞄具的具体源见 `M16OpticSeat20261015` 和 `ASH12OpticSeat20261015`。

## SUPER90 组合制作

- 加长弹仓只提取原厂端帽、保留其 UV/角点法线/材质，并在原枪上用 `S90_FactoryTubeCap_` 分区隐藏/恢复；不要重导整枪破坏骨架、蒙皮或动画。第三人称快照也携带原厂分区可见性。
- 枪口槽与弹仓槽保持独立 ID/属性。组合有空间冲突时，为同一枪口制作兼容外壳并按弹仓配方选择；拆卸后恢复原外观。外壳切换不新增倍率或第二份改造。
- 当前鸭舌采用 `Super90DuckbillClosedSides20261016`；V2 基础几何和逐级 LOD 是其输入，必须保留。新侧壁有实体厚度、独立 UV 和作者法线，前方横向开口保留。运行资产仍为 `DuckbillV2_20261016`，不要按目录日期改回旧模型。
- 图标使用认可金属框母版和当前实际模型参考，依照 `attachment-icons.md` 生成；拒绝过的程序框不能再作为正式图标重建入口。
- 当前游戏合同：收束器弹丸散布 ×0.65；鸟笼后坐力/腰射散布 ×0.85 并减少火光；加长弹仓 7→10、ADS 耗时 ×1.10；鸭舌多弹丸水平扇形、腰射散布 ×0.75，独头弹仍单发。倍率相对基础值，不能把 ×0.75 误写为最终散布值。消音器数值以当前目录为准，不从早期“其他属性不变”的制作记录恢复旧数值。

## 配方与 UI 状态

- 视觉可读取 Draft，实际散布和鸭舌状态读取 Installed，并在档案应用时缓存；服务器不依赖视觉组件加载成功来决定玩法。
- 首次进入改造面板选第一条可用类别；退出时按角色档案与武器实例 ID 记住浏览类别。恢复前检查类别仍可用，只记导航，不把未应用草稿写成已安装配件，也不复制导航状态给其他玩家。
- 容量变化、预测扣弹和权威退弹见 [霰弹枪权威与表现](shotgun-authority-and-presentation.md)。完成构建、保存和源码复核，分别报告；用户停止 UE 测试后立即停止自有测试进程，剩余运行验收交用户。
