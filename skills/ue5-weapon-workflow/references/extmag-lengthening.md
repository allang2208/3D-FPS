# 加长件（扩容弹匣类）改造与重建规则

来源：`ext_mag` 扩容弹匣连续五轮返工的收口经验（2026-09-18）。适用于任何"在原厂件基础上加长/改造"的配件（弹匣、枪管、枪托、导气管）。配套口径见 [attachment-standard.md](attachment-standard.md)（落位与接口）与 [weapon-finish.md](weapon-finish.md)（材质来源）。

## 1. 几何来源必须是该枪自己的源

- **不要**从别的枪的工作场景里取"同名部件"：本项目 M4 弹匣一度取自 `AKM_RearGripSections_Editable.blend` 里的 M4 段，坐标属于那个场景，实机就是"弹匣错位"。同一工作场景里各枪部件虽同名同结构，坐标系并不等于该枪运行时网格系。
- 正解：在**该枪自己的步枪源 FBX** 里按"该部件所属材质槽"取面。本项目用例：M4 → `SourceAssets/M4HK416Replica20260910/SK_M4_FoldingSights_HK416.fbx` 的 `Magazine Light.001`；QBZ-191 → `SourceAssets/PhantomRearGripIntegration20260913/QBZ191/SK_QBZ191_Manny.fbx` 的弹匣槽；AKM → `PhantomRearGripIntegration20260913/AKM/SK_AKM_MannyNative.fbx` 的 `AKM_FactoryMagazine_Preview` / `M_AKM_Soviet_Magazine`。
- 原位延长后**落位由原厂件本身保证**，不要再做 RANSAC 拟合、也不要按井口测量重建坐标系——拟合是把"另一把枪的件"塞进本枪时才需要的补救手段。

## 2. 延长方式：沿自身轴线切一刀，按弧步生成延长管（首选）

- **不要"切一段带体、复制到下方再焊接"**（2026-09-18 第五～七轮）：切面按包围盒轴取时，对倾斜/弧形弹匣是**斜切**，切出来的根本不是截面；即便按弹匣自身切线切，两段切环仍差 1.8–2.5 mm RMS（锥度 + 法线估计误差），**不存在能把副本严丝合缝放到接缝上的刚性变换**。只平移 → 下半段横向错位（弯件还歪着）；把副本硬"钉"到接缝 → 表面揉皱。用户实机看到的就是"弹匣建模错误、有错误截断"。
- **定稿做法**（本项目 `SourceAssets/ExtMagUniversal20260917/Scripts/build_extmag_arc_tube.py`）：① 用切片质心的二次拟合取弹匣**自身中线**，得到切点与切线；② 在距底板 ~3 cm 处切一刀；③ 取该切面的**外环**——先筛"环心贴近轴线"的环，再取其中周长最大者（否则会挑到擦过凸筋的长环，本项目曾挑到半径大 40% 的环）；④ 把该环沿自身弧度按 N 段刚性推进（每段绕环心旋转 Δθ/N + 沿法线下移 h/N）生成延长管，**第一环直接复用切面顶点**：接缝由构造保证闭合；⑤ 底部件随**同一个**弧步整体下移，其顶环正好落在管末环上（同一组顶点、同一变换，焊接即可合并）。
- 回执要写判据：切面法线与包围盒轴夹角、切环顶点数、6 cm 内的弧弯角、`seam_gap_mm`（应为 0）、开放边与非流形边。本项目 M4：4.14 × 8.42 × 23.49 cm / 法线 3.55° / 弧弯 5.27° / 环 76 / seam 0.000 mm；QBZ-191：4.55 × 13.42 × 24.42 cm / 13.74° / 5.91° / 环 313 / seam 0.000 mm。
- **弧管段的取舍**：延长段是干净管体、**没有原厂肋纹**（原厂肋在切面处停止、在底部件上继续）。要让肋纹连续，就沿弧重采样肋剖面，**不要**为了肋纹回到"复制带 + 硬钉"。
- **拉伸带（smoothstep 渐入）是最后的退路**：几何不断开，但带内表面被拉开（肋距/刻字变形），且带若落在换弹抓握区，实机读感是"手不像在抓弹匣"。本项目 AKM 仍是这一版，属待统一项。
- 曾经的错误做法，别再重复：① 沿一个固定方向整体平移（底板离开曲线，底部读成"尖角"）；② **手工**复制一段本体再焊接（接缝留下开放边/台阶）；③ 把两个独立切环做刚性配准后硬钉（残差 1–2.5 mm，必然揉皱）。

## 3. 渐变带必须避开换弹抓握区

- 延长段**不能压在换弹抓握区**：带内表面要么被拉开（拉伸带），要么是复制来的重复肋纹（复制带），两者都不等于"手指握在完整原厂件上"的手感。本项目换弹动画左手在**距喉部 10–15 cm** 处合拢，早期按"距喉部 11 cm 以下延长"正好压住握点，实机表现是"左手没精准抓握弹匣"。
- 规则：延长带放到**靠近底板一侧**（本项目距底 ~2 cm 起），上段（喉部与抓握区）保持原厂几何；改完用手部抓握区与延长带的距离自检一次，带高再取整数个肋距。

## 4. 材质按"UV 岛有没有变"分两条路

- **原厂件本体原位延长（UV0 未改，本项目的 M4/AKM/QBZ 扩容弹匣都属这一类）→ 直接绑宿主同类槽材质**。该枪弹匣槽正在用的材质（`SkeletalMeshTools.get_material`）就是唯一真源；原厂刻字、磨损与金属分区自动同源，实机/编辑器里与原厂弹匣是同一套表面语言。本项目 M4 用 `M4InfimaV3/Magazine_Light_001`（第五轮由自烘焙的 `M_M4_ext_mag` 改绑，压掉最后一个口径不一致）、AKM 用 `M_AKM_Soviet_PBR`、QBZ 用 `M_QBZ191_Unified_M_QBZ191_Wear_Magazine_polymer`，都对得上自家弹匣。**复制带延长同样保持 UV0 不变**，所以这条对它一样成立，不需要另做涂层。
- **重建件（UV 岛与原厂件不再对应）→ 才用自包含/投影材质**；下面这条只适用于这一类。

- 克隆原材质会把它的图集贴图（BaseColor/ORM/Normal，按 UV0 采样）一起带过来。重建件的 UV0 与原厂件在枪身图集里的岛不再对应，结果是一片错位方块——用户原话"完全是马赛克"。
- 重建件用**自包含材质**：只采样"烘焙/投影到该件自己的 UV"的图（本项目 QBZ 走"机匣涂层 + 接触磨损烘到该件 atlas"，M4 走"物理投影 UV + 复用已验收的逐枪涂层材质"）。
- 绑定后自检：材质的纹理采样要么落在"该件自己的 atlas"，要么走物理投影 UV；不允许出现"按 UV0 采样枪身图集"的残留样本。
- **不要把机匣涂层烘到"原厂件延长"的配件上**（2026-09-18 第四次收口）：本项目 QBZ 一度用机匣涂层烘到弹匣自己的 atlas，编辑器直连同光照对比下，弹匣表面出现机匣细节（刻字/面板线）摊成的黑斑，与旁边干净的原厂弹匣一眼判为两种表面；改绑原厂弹匣槽材质后立刻一致。判定方法见第 5 节第 4 条。

## 5. 验证手段（按可用性排序）

1. **编辑器直连**（首选，见 `Docs/ue-mcp-20260918.md`）：在运行中的编辑器里摆件、设相机、截图，并直接读资产的实际尺寸与材质绑定。
2. 夹具捕获：`FPSGAME.exe -DrumGripAudit -MagazineAudit=ext_mag -AuditWeapon=<id>`（需要 `Content/ShaderCodeLibrary` 存在，否则启动即报 `Failed to initialize ShaderCodeLibrary`）。
3. Blender 同机位对照渲染：原厂件与加长件同相机出图，用于判弧度、底板、渐变带位置（本项目 `Reference/akm_*_mag_*.png`、`m4_ext_mag_*.png`）。
4. **"原厂件 vs 加长件"同光照对照**（材料是否统一的判定手法，2026-09-18 第四次收口）：延长件与原厂件都写在**该枪网格坐标系**里，所以在编辑器里把两个 StaticMeshActor 都以原点恒等变换摆出来，就是运行时"资产写在枪体坐标系 + `seat_t⁻¹`"的等价装配（无需 socket/座位换算）。加一盏临时 SpotLight（`Intensity≈2500`、半径 400、锥角 55/30，`CastShadows=false`）——黄昏关卡不加灯只能拍到剪影，判不了表面。先拍"枪 + 扩容件"，再删掉扩容件拍同一机位，两张同尺度对比：表面语言一致才算过。本项目证据 `Saved/ExtMagEditor/{m4,akm,qbz}_{lit,factory_lit}_side_right.png` 与 `*_cmp_*.png`。

5. **Blender 同机位对照是重建那一轮的即时证据**（2026-09-18 第五轮）：每轮重建都出"原厂件 vs 加长件"同机位图（本项目 `Reference/dupb_M4_pair.png`、`dupb_M4_band.png`、`dupb_QBZ_pair.png`、`dupb_QBZ_band.png`，重点看带体内肋距与接缝）。**编辑器/夹具截图按轮次失效**：换过网格之后，上一轮的截图不再代表当前资产，引用时要写明是哪一轮（本项目 `Saved/ExtMagEditor/*` 是第四轮的图，第五轮换网格后已过期），不能当当前资产的证据。

## 6. 退役与留档

- 废案（旧 FBX 变体、旧烘焙图、被否决的脚本）按 [publication.md](publication.md) 移入 `SourceAssets/<task>/trash/<task>-<date>/`：记录原路径、目标路径、字节数、SHA-256、原因与替代物，移动后读回散列比对。本项目第五轮的清单见 `trash/extmag-superseded-20260918/MOVED_final.json`（48 项 / 254.9 MB，散列全一致）。
- 保留"能重建当前结果"的输入：该枪原厂件 FBX、延长脚本、UV 工序脚本、安装回执；只退役被取代的中间产物。
