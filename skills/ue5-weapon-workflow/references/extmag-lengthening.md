# 原厂弹匣延长：曲线、纹路与贴图一起延续

2026-09-19 用户指出多轮结果仍不合格。本页替代此前相互矛盾的“复制优先”和“弧管定稿”。历史脚本用于定位问题，不是用户已接受的母版。

## 来源与不变区域

- 从该枪自己的运行源提取弹匣及材质槽，不从其他枪的工作场景取同名部件。M4 使用 M4HK416Replica20260910 的源，AKM/QBZ 使用各自 PhantomRearGripIntegration20260913 的源。
- 保留插接段、卡笋、原点、骨骼座位和换弹抓握区。不要按整体包围盒居中，也不要移动手来掩盖弹匣本体失真。
- 延长位置取决于原件结构与抓握区；距底 2/3 cm 只是旧案例参数。

## 几何制作的选择依据

延长对象是带有曲率、截面变化和表面结构的壳体。

1. 用主体前后轮廓和局部切线建立曲线坐标，排除喉部、底板外翻与凸筋影响。近似圆弧的原件可共同拟合前后边的圆心、分别拟合半径；其他形状采用分段曲线。世界轴切片在靠近斜底板时会截到端面，不能把这些点纳入轮廓拟合。
2. 识别完整纹路单元：M4 格状结构、QBZ 分区凹槽、AKM 纵向冲压筋分别处理。周期按曲线弧长计，不直接沿用世界 Z 间距或人工横肋参数。
3. 延长段从原件真实表面取得。可在曲线坐标内复用完整单元或重采样剖面；同时处理截面差异与相位。不要将不等形切环刚性拼接或把误差压在一圈顶点上。需要形状修正时分布到整个单元，并保留局部凹凸。
4. 底板沿同一曲线移动，不参加纹路重复。接缝同时考虑位置、切线、截面和图案；共享边不等于形状自然。
5. 纵筋顺曲线延续；横向纹路保留完整周期与节距；刻字、窗口、特殊端部不能作为一般重复单元。

## UV 与材质

- 同枪弹匣槽材质只是来源正确，不能证明新增区域已经延展。
- 未改区域保留原 UV 与角点法线。复制真实表面时保留逐面 UV，切面由原三角形内插；不要用最近三角面无限外推，或随机加 UV 小条带来掩盖退化。
- 新区保留物理纹理尺度、法线方向和粗糙度分区。跨 UV 岛的表面需要分面/分缝；不得把两岛之间的图集内容铺在新面上。
- 原 UV 无法复用时，制作独立 UV 并从原件烘焙颜色、法线与粗糙度。需要与枪身统一时按 weapon-finish.md 处理相应涂层，不套整张机匣图集，不覆盖弹匣的结构法线、纹路与非金属身份。
- 几何周期与磨损/刻字不是一回事，非周期特征应保留在原位置或单独做过渡。

## 已知失败与适用边界

- 固定方向平移底板：弯曲轮廓出现尖角。
- 直接复制带体并刚性焊接：有锥度时切环不全等；硬钉会揉皱。失败的是忽略曲线和截面差异的处理，不是禁止一切原件表面复用。
- smoothstep 拉伸主体：肋距、刻字和磨损被拉长，抓握区失真。
- 按角度混排多个切环：跨接不相邻的边。应沿真实拓扑处理内外壳与装饰。
- 2026-09-18 弧管缺少原厂肋纹，撤销“定稿”称呼。历史 seam_gap=0 不代表完整网格合格。
- ExtMagRebuild20260919 的整体曲线拟合、通用横肋、最近面 UV 外推已被用户否决；不作为默认母版。

## 换弹与局部补面的后续教训（2026-09-19）

- FPSGAME 的 bUsingM4Infima 还用于 QBZ/手枪的共用动作时钟，不能据此选择 M4 专用换弹。扩容动作按实际枪型分支，保留目标枪自己的普通/空仓、拉栓尾段和握把变体；共享 Skeleton 也不代表握点与部件轨迹通用。
- 整手平移接近弹匣不等于包握。M4 本轮改用已认可的 AKM 包握作为姿态来源，再适配 M4 截面与握持高度；可达范围需要锁骨联动，不伸长前臂。此实现仍需用户实机反馈，不写成已接受标准。
- 用户后来明确 AKM 所指缺口在弹匣口。此前 seal_akm.py 只补下段开放边，不能据此称用户问题已修好。功能开口仍需要口缘厚度、内壁和托弹板；空腔开口不等于可以留下单面薄壳。先区分漏选零件、破面和原始源缺少内部结构，再局部补齐，不以双面材质或平盖遮住口部。本轮入口 SourceAssets/MagazineMouthFinish20260919/author_mouth.py 保留原外壳并补口缘、内壁和下沉托弹板；尚未实机验收。
- 普通与扩容弹匣若保留同一插接段和抓握截面，可复用同枪包握接触；不要把普通弹匣遗漏在修复之外。M4 本轮普通/空仓的标准弹匣改走 ExtMagContact 动作，弹鼓仍独立，QBZ/AKM 不套 M4 动作。
- 材质必须落到实际资源槽。2026-09-19 三枪扩容件原来均为 WorldGridMaterial，原因是 UE Python 结构数组修改未写回；具体绑定方式见 weapon-finish.md。

## 延长段截断反馈（2026-09-19 后续修订）

- 连续纵向筋条不能用带收尾斜坡的截面周期重复；AKM 本轮改从筋条中段截面连续扫掠，原收尾与底板移到末端。横向周期纹路仍按完整单元处理，不把两类结构混为一谈。

## 原厂格纹重建与当前入口（2026-09-19）

- M4 最终入口为 `SourceAssets/M4GridUnified20260919/author_surface.py`，接 `finish.py`。用户看最终预览后确认成功；这仅表示该预览获认可，不扩展为实机换弹、天气或所有枪型通过。AKM 当前为 ExtMagContinuity；QBZ 为 ExtMagRemodel；ASH 为 ASH12ExtendedMagazine → ASH12MagFinish。
- 先区分纹路造型差异与法线问题。统一重算法线不能修复不同风格的下半壳，还会破坏原件平面/倒角的加权着色。保留未改区域角点法线，新采样面使用其实际表面法线；最终法线确定后再生成接缝切线空间转换。
- 从原厂外表面采样真实筋宽、槽深、圆角及节距。薄壳投射须限定同侧外表面和局部距离，避免穿透命中内壁/对侧，不无限外推最近三角形。内外轮廓按完整连通环和包围尺寸识别，不能使用受顶点密度偏置的平均半径逐点混排。
- 保留插接/抓握区与独立底板。M4 的 12.5 mm 周期、62.5 mm 延长是该模型参数，不作为其他枪型默认值。旧复制带体、法线实验不再是制作入口。
- 较旧目录仍可能存有当前作者脚本需要的 Factory 对象、UV 参数、材质和换弹资源；整理时按依赖保留，不能把所有旧日期目录当废案删除。发布及恢复边界见 `Docs/Weapons/extended-magazines-publication-20260919.md`。
