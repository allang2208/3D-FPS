# 单手斧模块、材质与符文

用于复用弯刀动作族的新单手斧、替换斧刃和斧面符文。物品身份、动作家族、模块目录分别保存；共享选项复用 ID、数值和图标，外形使用目标武器自己的安装端。当前战斧制作源在工程 `SourceAssets/OneHandAxe20261101/`，本轮记录见 `Docs/Publication/Hatchet20261104/README.md`；历史制作或检查不授权自动重跑。

## 几何与法线

- 整体挤压原厂斧头会放大原网格起伏，产生扭曲高光。替换斧刃按参考轮廓重建斧面、连续厚度与渐薄磨刃，保留真实握柄接口；斧颈、肩部和主体共用连接边环，避免叠放几块实体冒充平滑衔接。
- 对顶点做变换前先保存原角点法线，再按正确法线矩阵处理一次。Blender 在变点后可能已更新法线，重复旋转会反转大批角点；不能靠曝光或粗糙度补救。跨模型转移法线需重建目标 TBN，UE 的 OpenGL 绿通道转换只做一次。
- 归档旧版前追踪作者依赖。战斧 R5 仍从 `RebuildV2/author.py` 读取轮廓函数，R4 的 `FactoryFinish20261104/Before/author.py` 仍提供接环函数，镂空握柄依赖 V1 Blend/纹理与 `HollowV2/Before/agile_grip.json`。这些是活动输入，不能按目录名 Before 或旧版本号清掉。

## 图标与符文

- 整武器的装备栏／背包图走实际 UE 装配、原 PBR、透明画布管线；宽斧头需要保留作者 2×3 画布与留白。PNG 留白正确仍可能被画刷的 alpha 紧裁切放大，应核对目录图和异步动态图两条加载路径。
- 改造栏只显示对应部件，复用已批准的金属框母版。先用实际部件产生正交输入，再按 imagegen 工作流编辑母版并保存原始输出；不以自行渲染的近似边框替代标准图标。
- 斧面符文从真实主体两侧拟合，避开磨刃、颈部、孔洞和外轮廓。采用等厘米／像素投射，保持纹样比例并分别处理朝外方向，再烘焙到各网格自己的 UV0；不能按整件 UV 包围盒拉满。轮廓、UV 改动后重做对应遮罩。
- 原装斧头、握柄、柄尾若共用材质槽名，斧头应使用几何不变且槽名独立的承载网格。UE Python 从 `static_materials` 取得的是结构体值：修改槽后要写回 `slots[index]`，再赋回网格并保存；只改临时变量不会保存新槽名。按运行时实际查找的 MaterialSlotName 绑定，不强写只读 ImportedMaterialSlotName。
- 远端挂坠根据仅含 Definition 的临时物品查目录，不能只依赖实例 Data 内的目录字段。新增斧头需补全 Definition 到模块目录的解析，使观察者与物品展示也创建共用动态挂坠组件。材质卸装恢复与几何／动态组件身份分别处理。

联机蓄力计时与权威扣费见 [装备符文与攻击回执](../../ue5-save-load-replication/references/equipment-runes-and-attack-receipts.md)。
