# 副手魔法书：属性、专注与恢复入口

适用于 FPSGAME 法杖＋副手书。动作制作另读[手臂衔接](../../ue5-fps-arms-animation/references/spellbook-transitions.md)。本例数值是用户选择，不作为其他副手的默认平衡参数。

## 属性与 UI 同源

只聚合当前武器组、未被双手武器锁定的副手；生产工具模式不计入。单件魔攻用 `ItemMagicAttack`，角色总值用 `EquipmentMagicAttack`；提示卡不能把整套装备总值标在单件法杖或书上。基础、属性和强化系数在 `items.json` 定义，本例均为学徒杖的 40%，取整后可能略有偏差。强化支持、上限、比较预览、旧实例定义迁移与只读公式缓存都要接入，保留实例强化等级。

浮窗总览放直接的单件魔攻；详情放基础／强化公式及专注机制。施法倍率与消耗读取同一 `focusEffects`。电系派生先读未加专注的闪电数据，在最终消耗结算后只应用一次倍率；修改施法快照不追溯改变已支付法术。

## 联机状态与扣魔

第一人称动画组件在服务器没有可用网格。专注权威状态用独立开始时间、装备实例和恢复截止时间，专用服务器继续轻量推进。开书、关闭与取消 RPC 和施法共用 PlayerState 的可靠通道；回执同时核对 Pawn 和专注轮次，旧回复不能取消新动作。

只在伤害实际接纳后打断，先退出专注再广播资源改变。客户端只播放反应；服务器扣魔。即时回执、镜像和在途档案上传通过单调累计扣除记录合并差额，避免重复扣除和旧上传恢复魔法值。旧存档字段默认零；累计值随档案持久化，瞬时专注不持久化。

本例影子档案原先的写盘阻止标志也阻止施法事务，必须区分“权威内存提交”和“磁盘保存”：前者保留规范化、校验、Generation 与通知，后者仍归 PlayerState 管理，不能为影子施法解除本地损坏存档的写保护。

## 制作依赖与归档

当前作者链为 `Focus/IntegratedV30` → V24 → V23／V9 与 V7 手模；待机 V3 仍依赖 V2 握点。旧版本号不等于废案。16 面书页在 `PagesV1`，方向修正只旋转每个 atlas 单元内 UV；`OrientationV2/Before/Spellbook_16Pages.blend` 是保证重复执行不二次旋转的活动输入，不能随 Before 备份批量归档。

运行页资产、完整 Blend、作者参数、原始许可输入与实际导入回执都需在本机保留。公开原创代码、作者脚本、小型参数与来源；UE 包、完整采样、第三方手模和原素材不随源码发布。恢复和本轮检查边界见项目 `Docs/Publication/Spellbook20261012/README.md`。
