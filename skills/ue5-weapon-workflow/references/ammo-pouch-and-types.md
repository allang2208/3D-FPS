# 数字弹药袋与切换弹种

用于 FPSGAME 的弹药目录、发放、换弹与弹种战斗效果。当前实现入口为 `UI/ColdSteelAmmoRuntime.cpp`、`FPSGAMECharacterAmmo.cpp`、`Weapons/PistolDualWield*`；UI 细节见 [动态弹种轮盘](../../ue5-ui-umg-slate/references/ammo-radial-and-pouch.md)。

## 数据与数量归属

- `ammo_types.json` 的稳定 `id` 是档案键，`group` 匹配 `gunsmith.json` 的 `base.ammo_item_id`。口径显示名不决定兼容性。
- 同口径分档时最低档沿用该组原有 ID：旧 `ammo_762` 已命名为 LP，旧 `ammo_556` 已命名为 M193，旧 `ammo_58` 已命名为 DBP87，旧 `ammo_45acp` 已命名为 FMJ，旧 `ammo_357` 已命名为 SP，只改显示名、等级与图片；中间档和高档才用新 ID（`ammo_762_ps`、`ammo_556_m855a1`、`ammo_556_m995`、`ammo_58_dbp10`、`ammo_58_dbp191`、`ammo_45acp_p`、`ammo_45acp_ap`、`ammo_357_jhp`、`ammo_357_ap`）。旧备弹、枪内装填和既有奖励条目都挂在旧 ID 上，不要靠改名重建 ID 后重新发放数量。新增档位的中文/型号命名按口径选真实型号串（7.62 用 LP/PS/AP、5.56 用 M193/M855A1/M995、5.8 用 DBP87/DBP10/DBP191），命名只影响显示，不影响兼容组。
- 新增档位只进 `ammo_types.json`，**不往 `items.json` 加物品条目**（7.62、5.56、.45／.357 三批都如此）：弹药不占背包格，物品条目只服务最低档那个旧物品定义（改名与 `ue_icon`）。轮盘／弹药袋的图标只读弹种目录的 `icon`（`UColdSteelStatusModel::AmmoIcon`），不读物品条目。
- 角色 `AmmoPouch` 保存各类型备弹，武器实例保存 `LoadedAmmoType`、`Magazine`。弹药不生成背包格子或世界模型；不要为新增类型再加物品堆叠。
- 旧包内、私人仓库及已保存地面弹药一次迁入袋；枪内数量保留。武器旧 `Reserve` 字段带默认占位值，不能累加入袋。新奖励、仓库发放、消费、范围拾取和改装缩容都走同一数字入口。
- 迁移、删除旧记录/快捷栏绑定、迁移版本与袋余额使用现有档案事务共同提交。与其他奖励一起发放时在同一个 Profile 副本调用 `AddAmmoToState`，不要先单独保存弹药再保存物品。
- `VirtualMagazineAmmo` 区分训练场虚拟弹；射击先减少虚拟部分，切弹和缩容只退真实弹。新特殊弹默认不允许无限备弹，目录显式开启才继承开发开关。

## 切换事务与动作

只有一种开放兼容类型时按 R 直接换弹；多种时短按普通换弹、长按打开轮盘、松 R 请求切换。`order` 和 ID 决定稳定顺序，零数量仍留位置。选择只记录待换类型，不提前改当前弹种或扣弹。

切换播放该武器/弹匣现有空仓动作，在动作完成时一次退旧实弹、扣目标余额并更新装填类型；取消不结算，目标不足按剩余数量装填。左轮切种也不能让中途逐发事件提前结算。双持保存每只手自己的待换类型，但共用角色袋并逐事务提交；不以共享主手状态替代副手数量。换枪、菜单及动作取消必须清掉待选/待换状态。

## 伤害与比例穿透

先查现有战斗公式，避免另建一套防御算法。FPSGAME 已有 `CoreCombatFormula::Defense`；弹种 `physical_armor_penetration` 与武器已有物理穿透相加后限制到 0–1，有效护甲为 `floor(护甲 × (1 − 穿透比例))`，后续沿用原腐蚀、减伤和取整顺序。

- 仅在发射时调用 `ColdSteelSkills::Snapshot(..., true)` 保存弹种效果；飞行弹沿用发射快照，之后换枪/切弹不能改变在途弹。
- 单枪射线、弹道、近距离枪口阻挡及双持均需接通。默认 Snapshot 不带弹种穿透，防止枪托/握把近战继承。
- `damage_multiplier` 在射击伤害计算处应用一次，命中端不重复乘。比例穿透不等于同百分比最终增伤，也不代表魔法穿透或穿墙。
- 当前 7.62x39mm LP/PS/AP、5.56x45mm M193/M855A1/M995、5.8x42mm DBP87/DBP10/DBP191、.45 ACP FMJ/+P/AP 与 .357 MAG SP/JHP/AP 都是 1.00/1.00/1.05 伤害倍率、0/10/20% 物理护甲忽略。这套阶梯按口径单独设定：只有用户明确指定的口径才套用，其余口径（12.7 mm、9 mm、7.62x54R）保持单一普通弹，不要顺手复制。
- **多档弹种是轮盘弹出的前提**。`ReloadInputPressed()` 里两只手都只有一种兼容类型时直接普通换弹、不建轮盘（弹匣满时表现为"长按 R 没反应"）。给某个口径加档时先确认它对应的武器确实会走轮盘路径；双持手枪要至少一只手有多档，另一只手只有一档时那只手的盘显示单个不可提交扇区。
