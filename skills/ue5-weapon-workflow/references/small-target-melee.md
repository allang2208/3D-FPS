# 低小目标的近战范围补充

适用于近战容易越过低矮敌人的情况。当前本机实现为 `Weapons/MeleeSmallTargetQuery` 与小皮肤手；参数记录在 `Docs/Weapons/small-hand-melee-range-20260927.md`。这是一版已构建、尚未试玩的实现，数值不是跨武器通用标准。

- 先区分移动碰撞、枪弹碰撞和近战受击查询。目标为了不挡玩家而忽略 Pawn 追踪通道时，不能依靠同通道 Sweep 发现它；可用 Pawn 对象类型查询读取原胶囊，不必放大移动体积或枪弹命中体。
- 保留武器真实轨迹、当前稳定瞄准参考系和有效接触时钟；缺少低位覆盖时加短距离地面扇区。不要只增大眼位球扫半径，也不要因为范围补充而引入目标锁定、自动转向或动作追踪。
- 明确适用敌人、水平距离、总夹角、高差和朝上瞄准条件。本例只对活着的小手启用：120 cm / 60°，突刺 30°，底部高差最多 45 cm；瞄准向上约 20° 以上停用。不同体型与武器须重新定值。
- 单目标攻击保留首个有效实际接触；未命中时才从补充范围返回一个候选。普通挥砍可覆盖多个目标，真实轨迹与补充查询共用每刀去重集合和伤害/削韧/反馈入口，不另写一套伤害结算。
- 同时检查眼位到落点、目标高度到落点的遮挡，防止视线越过矮墙而在低处隔墙命中。显式限制高差，避免楼上打到楼下。范围结果只描述当前命中，不保存为后续追踪目标。
- 普通剑每个有效攻击帧最多一次局部 overlap，不按每条刃段或动画子步重复查询；快速近战只在接触时刻一次。先过滤已命中、死亡、距离和夹角，再做有界的详细遮挡。本例每次最多 16 个候选、各两条射线，无全场 Actor 扫描或额外怪物 Tick。
- 资产保存、基础模块构建、游戏手感和密集场景性能分别记录。默认不自动运行测试；发布时还须区分完整本机代码与尚依赖其他任务未发布接口的源码。
