# SVD 涂层与安装接口：制作经验

## 借鉴另一把枪的表面处理

2026-09-23 的 SVD 升级参考 A762 的机匣涂层。读实际生效的实例参数与材质图，再复制到本枪私有材质；不要直接修改参考枪或共用母材质。

- 过高的统一粗糙度会抹平零件层次。SVD 上一版金属下限约 0.56；参考 A762 的 0.34 缎面后，按本枪枪机、机匣、弹匣及紧固件分区调整。数值仅为该案例，不作所有武器的默认值。
- 替换已有涂层节点，避免在旧哑光输出上再叠一层。复制材质实例时保留继承后实际生效的纹理、标量、向量及静态开关；干湿版本同步修改，并更新运行时湿润映射。
- 细纹采用不含零件边界的可平铺涂层纹理，按物理尺度采样。独立投影只改变涂层颜色／粗糙度，保留 UV0 结构法线、AO、标记和金属／聚合物／光学区域。
- 材质用途由真实使用者决定：纯静态配件不继承无关的骨骼／布料用途；新螺钉同时用于骨骼枪体时，其私有母材质需要骨骼用途。成功步骤写回执，续跑仅补未完成步骤；保存返回失败不能称为已落盘。

## 精修衔接件时冻结已认可的接触关系

- 用户只要求提升衔接细节时，保留握把本体、安装原点、骨架与手型。先读取真实接触面和间隙，再制作连续鞍座、局部夹持边、倒角、支撑肋与紧固件；不能靠移动整件配件填缝。
- 通用瞄具支架的导轨顶面、原点和瞄准定位保持不变。新面有独立有效 UV 和法线，不从主体图集采样无关结构；未改动面的 UV／角点法线保留。
- 原厂镜体的附加几何需保留原厂显隐身份。本例新增螺钉槽含 `ScopeMount`，因此更换通用瞄具时随原厂 PSO 隐藏；不能随意改成通用槽名而留下悬空螺钉。
- 重新导入按材质槽身份恢复当前绑定，同时保留插槽和骨架参考姿势。UE Python 的 `StaticMesh.sockets` 数组在本例不可直接读取，使用临时 `StaticMeshComponent.get_all_socket_names()` 枚举，再以 `find_socket` 读取变换；无须为此生成 Actor 或启动游戏。

## 看似镂空，先区分几何与透明材质

SVD／PSO 旧接缝问题来自环形金属面被归入透明镜片槽：恢复这些环面的不透明镜体材质，保留真正玻璃面；无需给镜筒 一概封口，也不应改动已经正确的 UV、蒙皮和几何。弹匣口部、镜内腔和安装孔都可能是有意结构，不能仅凭一处透景就填满。

本机案例：`SourceAssets/SVDRefinedFinish20260923`、`SourceAssets/PSOSeamRepair20260923`。材质与接口已后台导入保存，尚无用户视觉验收；不得与用户已经认可的 [异形弹匣抓握](../../ue5-fps-arms-animation/references/irregular-magazine-grip.md) 混为同一验收结论。源码与资产恢复范围见仓库 `Docs/Weapons/svd-publication-20260923.md`。
