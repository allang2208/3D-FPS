# 配件详情：能力增减卡片＋特效说明

用户于 2026-10-08 指定，后续所有武器配件共用本结构；常规握把的能力卡片为参考。

1. 名称、安装状态及简短外观描述。
2. **能力增减卡片**：仅放持握／装备后的常驻数值。显示指标、当前组合实值和相对本槽原厂的差值；由现有 Calculate / Evaluate 推导，收益绿色、代价红色，降低耗时／消耗等按收益处理。暴击率卡片统一显示“改造暴击率（+25%）”，右侧实值／差值也使用 %；底层仍按百分点相加，不改变战斗公式。
3. **特效说明**：放触发条件、释放方式、条件性加成、持续／冷却、刷新／叠加和解除规则。按机制需要用少量短段，段落标题与正文分开；特效栏标题、分段标题及正文统一使用 ColdSteelUI::Success 绿色。已有能力卡片不能隐藏此栏；没有特效则不造空栏。
4. 基本配件说明和原有整武器数值总览；基本说明只写外观／材质／风格，不重复上述规则。

不要将高、中、低血量三档同时列作常驻收益，也不要用绿色文字代替本可推导的常驻数值卡。特效说明不重复已经展示的常驻属性。

目录选项的 `special_effects` 为字符串数组；可用 `标题｜正文` 显示分段标题。枪械、近战、弓、法杖和工具均通过 `FGunsmithOption::ReadSpecialEffects` 读取，共享 `M4GunsmithSelectedDetails.cpp` 的展示区。`effects` 继续服务旧列表／物品提示，不应作为新特效唯一来源。已有原生条件效果也汇入同一区块。

制作时同步正式目录与作者／重导入口；数值与条件仍以运行时和 stats 为准。条件段可读取数值生成，若目录保存文案则随来源一同更新。不要按武器 ID 或“是否有卡片”新增显示特例。

镇魔示例：暴击率卡片＋暴击触发／随身法阵说明。金刚示例：物理、魔法防御常驻卡片＋生命分段／吸血／切武器清除说明。蟠螭展岳示例：格挡消耗卡片＋格挡蓄势和上挑释放／伤害与削韧（含法阵牵引）说明。
