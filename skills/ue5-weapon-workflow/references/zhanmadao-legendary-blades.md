# 斩马刀改造：配方、动作与剑气

处理长刀换刃、武技替换或刀身剑气时读取。以下是 2026-10-19 的斩马刀实现约束，不是其他武器的默认参数；不自动授权游戏检查。

## 数值只有一条来源

- 模型总长与玩法判定距离分开：斩马刀刚体长约 160.1314 cm，与镇岳对齐；基础攻击距离 225 cm。不能靠放大人物手臂或通用碰撞去匹配长刀。
- 基础攻击间隔同时影响新目录物品和已有实例。已有物品只迁移 `attack_seconds`，保留改造、强化和其他实例数据。
- 新效果贯通目录、解析、聚合、统一求值、权威快照和面板。`whirlwind_damage_add` 是旋风倍率的加数：先给技能倍率加 0.5，再乘物理攻击与武技伤害；不要把它解释成最终伤害乘 1.5。
- 配方作者入口与已安装目录一起改。当前逐风由 `ZhufengBladeV1/catalog_extension.py` 管理，赤霄玩法由 `ChixiaoLegendaryV1/catalog_extension.py` 管理；只改 live JSON 会被模型重导入覆盖。

当前专属规则：背嵬 `blade_2` 武技伤害 ×1.5、武技判定范围 ×1.25；赤霄 `blade_1` 攻速 ×1.15、物攻 ×1.1；逐风 `blade_1` 范围 ×1.2、物攻 ×1.1、旋风倍率 +0.5。均为传说专属。改造说明将外观、被动属性卡、动作机制／代价分开，避免同一加成重复描述。

## 替换攻击不能丢失原合同

- 赤霄双斩使用独立的一秒武技时钟；两段都按完整重击伤害，各自重置命中集合。出手一次扣普通重击出手体力的两倍，蓄力每秒消耗不翻倍；预检、快捷栏置灰和实际扣费共用 `HeavyReleaseStamina`。
- 逐风替换已满足准备条件的冲刺攻击，保留冲刺速度。推进从起手持续到旋转结束，碰撞阻挡即停；共享大旋风等级、消耗和冷却，未学大旋风时取一级数值，仍需学会冲刺攻击。普通主动大旋风也获得倍率加数与青色剑气。
- 恒速推进期间禁用该变体的命中停顿，否则视觉旋转、位移和伤害时钟会分叉。上半身旋转／下半身步态见手臂技能的 `third-person-sword-contact.md`。
- 破锋燕翎和腾云游龙的第三段为群体攻击。复核实际矩形／扫掠调用、提前返回、循环退出、小目标补判和服务端遮挡；仅修改说明或 `bAreaDamage` 不能把单目标逻辑改成 AOE。跨查询仍按每次收尾每目标一次去重。主动上挑与原厂突刺的规则分别维护。

## 剑气跟随实际刀身

复用 `UBeiweiSwordTrailComponent` 的世界空间刀身轨迹和有限寿命样本，而不是围绕角色生成独立圆环。当前预算 48 个样本、0.24 秒；金／红／青共用网格生成，材质分别绑定，异步加载完成后重新应用当前配色。

- 配色优先级：逐风旋风青色 → 赤霄重击红色 → 背嵬其余武技金色。
- 模块根网格也必须带 `SwordSlot=blade_1`。仅给附属部件打标签会漏掉原生刀身。
- 无符文的赤霄／逐风仍捕获刀刃两端，并加入远端装备缓存键；不能以“没有 RuneDefinition”为由丢弃端点或跳过重建。
- 释放状态进入身体复制字段与权威同武器转发；本地第一人称、第三人称和观察者各用实际可见武器端点。换武器、结束和卸载时清空旧轨迹。

符文贴刃需检查承载网格材质槽、局部表面坐标和各刀身独立排布。不要通过全局旋转贴图修一把弯刀；原厂、通用刀刃、燕翎、游龙、赤霄与逐风的走向分别拟合。图标沿现有方形灰钢底板、四角铆钉与内框母版制作；模型展示图不能直接充当改造图标。
