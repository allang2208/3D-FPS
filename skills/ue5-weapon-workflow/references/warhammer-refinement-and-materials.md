# 战锤改造的实体细节、魔力球与效果合同

适用于符文战锤换头、专属配重和双手锤中央锤座。案例参数属于对应配方；普通制作不自动启动检查、渲染或游戏。

## 图案和实体表面

- 换锤头仍须转移原装刻纹。将原装几何与原 UV 遮罩烘焙到新实体的 UV；通用锤头可另加符文 UV，传说锤头可写入自身图集。别把原装刻纹与可更换的 rune 槽混成一层。
- 迅捷／破坏魔力符文沿其他战锤 rune 槽的柄部位置显示，并保留自身形状与颜色。改造图标使用实际运行的 AttachmentIcons PNG、标准灰阶金属框；保存 Texture2D 不等于更新了工作台 PNG。
- 纸片感先区分缺厚度、离开承载表面、片条相交和法线细节。镇魂钟钟室、拱框及符文必须有侧面和厚度；法线用于刻纹与微表面，不能代替轮廓。
- 顶部饰线“已有端帽”不等于闭合或落座。鸣雷 V2 的问题是独立线段悬空，应做共享首尾顶点的闭环，并按顶盖真实斜面放铆钉。V3 闪电主干与分支先作二维实体并集，再生成凹槽、倒角金属镶嵌和细发光芯线，避免同深度片条重叠。
- 局部改模保留主体 UV、面角法线、材质索引和安装端面；新增包边／面板使用独立图集。鸣雷 V3 仍依赖 V1 主体贴图、V2 闭环包边及其材质，不能把这些旧版输入当废案。
- PBR 明确 BaseColor 的 sRGB、ORM 的 AO/Roughness/Metallic 通道及切线法线方向。案例 OpenGL 法线在 UE 使用 TC_NORMALMAP、线性采样并翻转绿色通道，避免重复翻转。

## 魔力球白色棋盘格与轮廓

- 资产保存和 C++ 构建都不能证明目标 GPU 材质可编译。紫球 V2 曾在像素阶段使用仅适合顶点阶段的 PreSkinnedPosition，导致默认棋盘格。体积采样改用 `LocalPosition / Component / Exclude Material Shader Offsets`；顶点位移使用其独立坐标路径。
- 制作含 Custom HLSL 的材质时，后台导入使用目标 D3D12/SM6，完成实际材质编译再记录保存结果。NullRHI、导入退出码或“包存在”不能替代这一生产步骤；它也不代表画面验收。
- 球内云、亮核、实体光丝和光点保持局部坐标，WPO 转世界空间，随整件运动。需要球体可见时给球壳增加有色透明肩部、窄 Fresnel 亮边和镜面反射，保留清楚的中央视野。紫／蓝配重不随锤头 EnergyTint 改色。
- UI 品质可能来自独立 `GunsmithModificationTier.h`，目录 `tier: special` 与该分类都要接入。

## 不同触发器的去重单位

- 紫球：苏醒触发时读取配重并冻结本次时长，当前配方 20+10 秒。复制到期时刻和本次初始时长，HUD 分母使用同一值。
- 星潮之核：苏醒期间每次实际有效伤害接触增加 0.5 秒，无上限。放在一次攻击蓄能去重之前，才能覆盖群攻的不同目标和旋风的后续有效接触；不能让 RPC 重放重复执行伤害。延时只刷新命中脉冲，不重复播放苏醒入场。
- 破势古印座：快速近战成功结算后才对存活目标施加 8 秒状态，本次施印伤害不追溯增益。物理承伤 +15%、韧性承伤 +25% 为目标状态；配件自身的耗体 +10%、攻速 -5%、韧伤 +5%、物伤 +5% 为装备倍率，分开结算。重复命中刷新，不叠加。
- 头顶金印与命中印使用同一实体图案、同一个复制到期时刻；目标高度取胶囊／主体，排除标记自身，避免边界反馈使印记越飞越高。死亡、净化、到期和销毁一起清理；专用服务器不创建图形组件。
- 叠片缓冲座当前定位是重击准备／出手耗体：蓄力 +20%、重击出手耗体 -25%、攻速 -5%、韧伤 -10%。鸣雷疾驱座为蓄力 +35%、攻速 +20%、耗体 +30%。保持普通攻速、重击蓄力和武技时钟分别消费对应字段。

## 空间扰动与闪电

- 扰动按实际锤头采样覆盖普通三击、重击、冲刺、上挑、旋风、快速近战及镇魂钟两段，不能只挂鼠标主攻击。走路、蓄力、格挡和检视不新发射。
- 当前扰动与剑／弯刀一致，仅本地持有者可见；四个组件池，每段最多 96 站点，收尾 0.25 秒。此范围不代表远端观察者已拥有扰动。
- 镇魂钟常驻黄色闪电独立于苏醒和破坏符文染色。鸣雷座常驻电弧与组合命中金色电弧分开；有效伤害由服务端确认后触发表现多播，不额外结算伤害／状态。复用有界组件池与低频形态更新，变换每帧跟随。
