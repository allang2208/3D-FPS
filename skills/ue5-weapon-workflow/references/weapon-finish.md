# 枪械主体与改造件材质统一

用户于 2026-09-13 指定：每把枪的改造件都要针对该枪的主体材质做统一。这是新枪接入、新配件制作和跨枪复用的默认制作要求；不额外启用未授权的检查、渲染或玩法测试。

## 以当前枪身为基准

- 读取实际运行枪身网格及材质覆盖，确定机匣涂层的 BaseColor、Roughness、Metallic、Normal 和细纹尺度。记录材质/贴图来源及参考区域；目录名相同或材质名含 Metal 不代表已统一。
- 同一配件在 M4、AKM、QBZ191 上可以复用几何，但金属外壳按各自枪身选用专用材质或网格变体。不能把 M4 的材料直接传给 AKM，也不能把所有枪统一染成一种灰黑色。
- 统一覆盖握把金属框架、枪口外壳、弹匣/弹鼓金属壳、瞄具外壳、夹具、底座、螺钉、枪托金属连接件和 LPVO 活动倍率环。按实际材质槽与区域分类，避免只处理安装座。
- 聚合物、橡胶、木材、镜片、分划、发光部分、白色刻字和有意保留的钛色饰件保持各自材质身份；镜筒内壁、枪口内腔保留消光。统一的是相应金属的涂层语言，不将整件配件强制金属化。

## 制作与接入

- 原配件已经正确使用该枪的材质及适配 UV 时保留；有差异才制作专用变体，不能为材料名一致而破坏现有正常效果。
- 禁止把整张枪身 UV 图集直接套给无关模型。优先从机匣选择不含木纹、铭文及零件边界的金属区域制作可平铺贴图，或复用枪身程序化涂层并按配件自己的 UV 烘焙。
- 同时匹配底色、粗糙度、金属反射和磨损尺度，仅调 tint 不算完整统一。沿用结构法线和 AO；新增涂层不要抹平滚花、沟槽、防滑区或刻字。原 metallic 遮罩只有在确认其语义后才能作为区域遮罩。
- 新投射使用独立 UV 通道，记录通道号及物理尺度，保留 UV0、几何、分离法线、安装原点、单位和蒙皮。导入时禁止自动光照 UV 覆盖材质 UV；依赖角点色的遮罩必须随网格正确导入。
- 复制目标枪型材质，保留实例实际生效的纹理、标量、向量和静态开关覆盖；不修改跨枪共享母材质。保持原材质槽及顺序，供隐藏原厂部件、换弹分件和展示系统继续使用。
- 读取实际材质图的转换语义。若现用枪身仍经 FBX Phong 转换，记录 Shininess、sRGB 和 Specular 的真实连接；不要将纹理文件名当作线性 PBR 通道直接接入，或在配件任务中顺带改变枪身母材质。
- 源网格被打开的编辑器占用时，优先保存枪型专用网格变体，保留原短名、槽名与顺序，并同时修改装配引用和打包目录；不为了覆盖源资产终止用户编辑器。活动倍率环也按同样规则处理。
- 修改必须落到当前角色、枪匠展览、未装备实例预览、图标和掉落使用的装配入口。动态附件和倍率环的重建也使用该枪型材料；拆卸恢复原厂材质。
- 在目标资产元数据或配套清单中记录枪型、参考枪身材质、金属区域、保留区域、UV/尺度及当前绑定路径。保留可编辑源、导入入口和修改前备份；不以副本已生成代替完成运行资源绑定。

## 用户要求检查或预览时

按授权范围逐枪逐槽核对材料实际绑定和 PBR 通道，检查瞄具内壁、刻字及非金属区域。需要视觉对比时，在相同光照、曝光和距离下并排查看枪身、握把、枪口、弹匣；不要用更强高光掩盖色差。材料读取、导入读回、实际渲染和玩法回归分别记录，未运行的项目交由用户测试。
