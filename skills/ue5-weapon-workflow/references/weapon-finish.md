## 制作与接入

- 原配件已经正确使用该枪的材质及适配 UV 时保留；有差异才制作专用变体，不能为材料名一致而破坏现有正常效果。
- **原厂同类槽是材质来源，不是统一完成的证明**（2026-09-19 修订）：原件延长且 UV 对应时，可沿用该枪原厂弹匣槽；还需区分实际绑定、贴图采样与表面风格。只有原槽本身已经匹配该枪、原 UV 与材质通道确实对应时，才有依据直接沿用。若仍有色调、粗糙度、金属度或尺度差异，再按本页做枪型专用变体；不能仅凭同名或同路径宣称材质统一。
- **先处理绑定错误，再考虑重做涂层**：2026-09-19 用户反馈三枪扩容弹匣泛白、材质不统一，读取实际资源发现三者均为 `WorldGridMaterial`。旧脚本记录的是计划使用的宿主材质，不是资源实际槽值。UE Python 的结构数组元素按副本处理：`slot = slots[i]` → 修改 `slot.material_interface` → `slots[i] = slot` → `mesh.set_editor_property('static_materials', slots)` → 保存。或使用对应网格的 `set_material` API。只写 `slots[i].material_interface = material` 会丢失修改。导入回执记录实际绑定值，不用目标变量伪装读回；这属于制作/接入结果记录，不自动开启游戏测试。
- **绑定原槽与烘焙机匣图集不同**：整张机匣 BaseColor/ORM 通过盒式投影铺到小弹匣上，会带入零件边界、花斑和错误尺度。原厂同类件 UV 能复用时优先保留；需要新涂层时只使用合适的金属区域或程序化涂层，保留弹匣自身结构法线与非金属身份。此前 `ExtMagUniversal20260917` 的“定稿”描述撤销，不能把旧导入回执当成视觉通过。

- **导入时不要合并材质槽**：把原厂多槽并成一个通用槽会丢掉原厂材质分区，也不符合本页"保持原材质槽及顺序"的要求。配件沿用其可编辑源的槽位命名，由上述绑定步骤逐槽接到宿主材质。
- 禁止把整张枪身 UV 图集直接套给无关模型。优先从机匣选择不含木纹、铭文及零件边界的金属区域制作可平铺贴图，或复用枪身程序化涂层并按配件自己的 UV 烘焙。
- 同时匹配底色、粗糙度、金属反射和磨损尺度，仅调 tint 不算完整统一。沿用结构法线和 AO；新增涂层不要抹平滚花、沟槽、防滑区或刻字。原 metallic 遮罩只有在确认其语义后才能作为区域遮罩。
- 新投射使用独立 UV 通道，记录通道号及物理尺度，保留 UV0、几何、分离法线、安装原点、单位和蒙皮。导入时禁止自动光照 UV 覆盖材质 UV；依赖角点色的遮罩必须随网格正确导入。
- 复制目标枪型材质，保留实例实际生效的纹理、标量、向量和静态开关覆盖；不修改跨枪共享母材质。保持原材质槽及顺序，供隐藏原厂部件、换弹分件和展示系统继续使用。
- 读取实际材质图的转换语义。若现用枪身仍经 FBX Phong 转换，记录 Shininess、sRGB 和 Specular 的真实连接；不要将纹理文件名当作线性 PBR 通道直接接入，或在配件任务中顺带改变枪身母材质。
- 源网格被打开的编辑器占用时，优先保存枪型专用网格变体，保留原短名、槽名与顺序，并同时修改装配引用和打包目录；不为了覆盖源资产终止用户编辑器。活动倍率环也按同样规则处理。
- 修改必须落到当前角色、枪匠展览、未装备实例预览、图标和掉落使用的装配入口。动态附件和倍率环的重建也使用该枪型材料；拆卸恢复原厂材质。
- 在目标资产元数据或配套清单中记录枪型、参考枪身材质、金属区域、保留区域、UV/尺度及当前绑定路径。保留可编辑源、导入入口和修改前备份；不以副本已生成代替完成运行资源绑定。

## 715 缎面金属制作案例（2026-09-14）

- 作者入口 `SourceAssets/DanWesson715MetalFinish20260914`，说明 `Docs/Weapons/dan-wesson715-metal-finish-20260914.md`。715 采用不锈钢分件反射，不照搬 QBZ191 的深色涂层或 M1911 的发蓝钢底色。
