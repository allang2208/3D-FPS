# 生成枪械的近景精修：A762 与 201 经验

用于生成枪体已经选中、但近景出现机瞄堵孔、换弹露空、导轨下漏面或接口断裂时。保留选中母版及动作骨架，按缺陷局部重建。A762 的生成/接入记录在工程 `SourceAssets/A762Meshy20260920`，数值坐标只适用于该枪。

## 几何缺陷先于材质

- 从 ADS、检视和换弹实际可见区域定位缺面。弹匣抽出后会露出上口、唇边和内侧；不能只封侧面轮廓，或靠双面材质伪装封闭。枪管/导气管连接与枪托双杆接头都要有连续厚度和完整过渡。
- “ADS 两侧粗糙”可能同时包含烂拓扑、破碎面、平滑错误及旧图集拉伸。重建面用自己的 UV、倒角与合适硬边；不要继续把旧损坏区域的烘焙法线灌入新表面。
- 机瞄固定底座与可翻折头部分开；导出枪体时剔除旧头部，避免新件翻倒后旧几何仍堵视线。围绕实际铰链、局部轴设置前后折叠方向，不能把同一正负90°应用到不同坐标系。A762 前准星向后、后照门向前折叠。
- 瞄具依真实导轨冠面与鞍座接触面安装，光心与眼距分别适配；不因导轨清楚就直接复制其他枪的整套坐标。倍率环与光学材质也属于配件接入范围。

## 分区和统一涂层

- 新零件材质槽继续保留 FactoryStock、Flash_Hider、Magazine 等运行分区身份；重新导入采用当前 FBX 分区并显式绑定，避免沿用旧槽编号导致隐藏错误。
- 涂层统一使用本枪当前主体颜色/金属度/粗糙度基准，在原配件材质的金属分支中替换。原始区域遮罩、刻字保护、镜筒内壁及镜片分支各自保留。转换后的金属度不是可靠的原始区域遮罩，不要在已有涂层图外再套一层全局涂色。
- 微纹采用独立 UV/物理平铺，保留结构法线和光学通道；材质副本不改共享枪型母版。重导入脚本保存最终材质覆盖表，避免下一次模型导入恢复旧外壳。
- 图标同时有基础 PNG、数据引用和运行动态图路径。隐藏手臂的模糊字符串 `hand` 会误伤 `handguard`，应按真实身份排除护木；掉落展示共用过滤时同步修正。

## 保留制作链

Refinement02 的几何函数仍供 Refinement04/Accessories05 使用，初始 Integration 仍提供动作；日期早不能判为废案。归档只移动已取代的备份/输出，并留下原路径、散列和替代物。Meshy 原始候选、用户参考、最终 Blend/FBX、实际动作源及依赖贴图继续保留本机，公开发布只包含许可允许的源码和制作说明。

## 201：生成薄壳的加厚失控与版本归属

- 对生成网格的尖角、凹角做 Solidify，等厚角度补偿可能把少数内壁顶点推出数米。201 Detail35 的外皮正常，失控的是 `use_even_offset=True` 生成的内壁；增加面数、双面材质或调粗糙度都不能修复。保留加厚前外皮，从单位法线的有限偏移重建内壁，按局部厚度限制尖角补偿；不要把已飞出的顶点硬压到包围盒边界。
- 用户要求排查时，在部件绑定骨骼的局部空间比较外皮与内壁边界、最长边和离群点，再核对实际保存网格。一个尖刺不应触发全枪平滑、拓扑重造或材质重烘焙；保护 UV、机械转轴及其它骨骼权重。
- **原 201 模型已列为废案**，不包括后来 `MeshyRetry28 → Refine29 → Install30 → Surface32 → Repair36` 的新模型。运行包仍叫 `Cover10/SK_LMG201_Cover10`，不能由目录日期判定其版本。原始金属弹箱失败不等于后来 ClothFeed33 布料弹箱也退役；具体边界见工程 `Docs/Rejected/lmg201-original-model-20260929.md`。
- 当前 Repair36 仍读取 Detail35 加厚前的作者代码、Work 与贴图，材质实例也继承其母材质；失败的 D35 盖体输出可归档，所用输入不能整目录删除。Skin07 原生动作、PKMFK19 配件姿态来源与 Video26 原生骨架只是保留的制作依赖，不能据此恢复被否定的枪壳或旧弹箱动作。
- Repair36 的后台保存及定向几何检查不是用户视觉认可。废案记录保存失败原因、替代入口和本机散列清单，不把最后一次脚本结果写成已验收母版。
- **开盖要共同处理两侧可见表面**：201 的旧拆分把切割封板留在机匣上；只重建盖内构件会与这块封板交叉。先明确盖壳、机匣上沿、侧壁、托面和活动内构件的归属，再局部替换；不能保留通用大封板后不断叠内饰。
- 宽度要依据同一坐标系中多个接缝截面和实际边界环，区别外壳、翻边、内部滚轮；整体包围盒不能证明盖壳过宽，也不能作为统一缩放系数。相邻件独立重映射后，旧切割边相同不代表现在仍然贴合。
- 局部形变保留面角 UV 与自定义法线对应；新增表面独立赋 UV、法线和材质。不要在全枪重算法线后继续宣称旧结构法线的切线基准未变。
- **FitFinish37 的机匣/盖体几何已被用户否决（2026-09-29）**：存在横向尖刺、平板化错误外形和开盖镂空。局部边界样本不能用于对全部上肩点无界外推；盖壳投影重合不代表接缝闭合。ReferenceRepair38 从前版源外壁恢复机匣，以参考图可见轮廓重做盖壳，已后台保存；未获 1:1 或实机认可。记录见 `Docs/Weapons/lmg201-reference-repair-20260929.md`。
- 开盖内部按参考图分别对应轮廓、左右、台阶、压扣、翻边及可见支撑面；不能把大平板加几根滚轮写成参考图还原。不可见结构保留未知。旧顶盖封板和内部碎片须一起处理，不能沿不规则扇形三角网把内部顶点直接拉低，形成新的褶皱或穿出外壁。
- 请求检查时核对实际保存导出的网格及骨骼归属；源网格闭合、材质编译、后台保存和视觉合格是不同结论。共享材质槽可能同时包含机匣和前端底座，局部替换须联合空间/部件归属，不按同名材质整槽删除。


## 失败案例：PKM 全系列已退役（2026-09-22）

本节仅指早期 Meshy `PKM20260921`，不包括后续用户提供的 `PKMLowpoly20260922`。用户否定了早期分支从初次接入到 VideoAdaptation10 的建模和动作，整轮已归档到本机 `trash/pkm-rejected-20260922`。Integration、Refinement02、Rebuild03、SourcePreserve04、SightGrip05、Recovery07、GripFinish08、SeamContact09、VideoAdaptation10 都不是成功母版。工程记录见 `Docs/Weapons/pkm-retirement-20260922.md`；不要因“源表面保留”“导入成功”或版本号更大而自动恢复其中任何版。

- **不能据此判定 Meshy 上限或 UE 导入器有错。** 本次同时改过拆分、补面、法线、材质、握点与动作，没有形成能单独归因的对照。A762 已被接受只说明那一条处理链适配成功，不证明相同切割与动作方法适用于开盖、弹链供弹的 PKM。
- 生成网格的连通岛不是机械零件标签；上盖可能与机匣粘连，完整弹箱也可能被空间范围切坏。拆分须依据参考接缝与原表面归属，保留原三角面、UV 和角点法线的对应。用包围盒/坐标阈值批量切分、布尔后猜原面归属，容易得到碎片、薄片和运动时露空；接缝算法本身也不等于结果已正确。
- 开盖模型不能只加一块凹底或把外皮向内偏移：可见的盖内面、边缘厚度、机匣侧壁和托盘各有形状与材质接口。仅按视频实际可见层次做局部适配，遮挡部分记录为未知，不把低清游戏视频当成完整内部几何或尺寸依据。原有细节保持，不用追加方块/圆柱掩盖拆坏的轮廓。
- 材质统一要保留本枪外壳图集、材质分区和非金属身份；新面单独展开并选择对应钢材实例。提高金属度、叠微法线噪声或整体调暗粗糙度，不能修复破面、错误硬边或错误切线。旧烘焙法线也不能直接套到新拓扑。用户要求材质优化时，不因此扩大为整枪重建。
- 原表面保持、文件散列、导入回执各证明不同事情，都不证明外观或动作合格。用户未授权测试时，交付注明未测试；不要追加自测，也不要把最后一次脚本修正写成成功经验。持续失败时缩小到当前反馈对应的几何/着色/姿态层，并保留可辨认的源与候选差异。

## 201 HardSurface39：小件归属与局部硬表面（2026-09-29）

- 用户红圈中两端残片实际来自独立 `SM_LMG201_BipodBase`。先核对运行装配及静态组件归属，仅重导骨骼枪体会漏修。新底座仍沿用原腿部转轴，不能只缩短旧网格后悬在管下。
- 局部平面拟合固定拆分边、安装端与握持纹区域；不要跨入肋纹斜面。小三角面位移后法线旋转可能不稳定，不能直接用它旋转原角点法线；保留未拟合区域，在确认的面区有限混合法线及旧结构法线图。颜色、刻字、粗糙度与湿润通道各自保留。
- 作者 FBX 闭合而 UE 保存导出有裂边时，比较实际丢失的三角面。H39 的细小有效倒角面被静态导入/构建 `remove_degenerates` 删除；仅该私有部件关闭此项后，保存导出开放边由 72 恢复到 0，且无近零面积面。不要据此对全项目关闭退化面处理。
- 离线查看 UE 静态 FBX 时，将 `UCX_` / `UBX_` 等碰撞对象排除出外观渲染。旧碰撞壳随导出携带，不表示运行画面仍在显示旧外壳。
- 本例按用户明确要求做定向检查，未运行游戏；保存、闭合与灰模结果不构成用户 1:1 或整枪认可。当前入口 `SourceAssets/LMG20120260927/HardSurface39`，记录 `Docs/Weapons/lmg201-hard-surface-20260929.md`。

## 201 Assembly40：参考姿态与实际安装姿态（2026-09-29）

- 手模原生骨架的 bind pose 不等于游戏 idle。201 原厂弹匣在两者之间沿枪身相差约 61.39 mm、竖直相差约 25.51 mm；扳机也有相对偏移。接合制作先读取原 idle/相关动作的局部变换，在该姿态下确定接触，再逆变换到绑定空间。不能只按导出静态灰模移动整只弹匣，破坏已制抓握。
- 导轨冠面高度、枪体接触面、照门固定座与独立折叠头是四个接口。只重做轨齿的规则轮廓不能消除底面悬空。按现有顶面采样制作有限底面，保持冠面与挂点；头部的非瞄准镂空应与底座一起处理。
- 枪体上的生成形状与原生活动控制件可能重名但不共用骨骼。201 截图后部右侧粗糙外形属于 Receiver 主根；局部替换保留该归属，不顺带把它接到另一个位置的原拉栓动作。外观修复与动作接触修复分开记录。
- 固定机匣的侧壁、端回边、托面和活动盖内饰分别归属。可见开口需要有内侧表面及背景遮挡；壳体“每个部件封闭”不能证明装配后不会穿透看见天空。
- A40 已保存到原运行资产，并按本轮授权读取保存导出的局部 idle 灰模；未运行游戏，不能当作动作或 1:1 认可。入口 `SourceAssets/LMG20120260927/Assembly40`，记录 `Docs/Weapons/lmg201-assembly-20260929.md`。

## 201 SightFinish41：瞄准缺口必须对应实际 ADS 标记（2026-09-29）

- A40 的后照门缺口底沿比 `A_LMG201_aim` 的前后瞄准标记高约 1.48 mm，实机挡住准星。斜视灰模、部件闭合和转轴不变不能证明瞄准可用；修改缺口前读取实际 Aim 第 0 帧的 `WPN_RearSight` / `WPN_FrontSight` 根骨相对位置，再处理中央可见开口。
- 后照门下桥和中央瞄准通道用途不同。补非瞄准漏空时不能把实心挡片一直填到瞄准线上。保留折叠转轴与底座，按既有视线给准星投影留出观察区域；不要先用抬枪或改 ADS 动画掩盖几何遮挡。
- 扳机护圈要对照机匣腹板和侧缘分别取样。A40 的护圈顶面为 -3 mm，机匣底面为约 +2.6～4.6 mm，轮廓相邻仍存在间隙。连接肩伸入已有壳体，活动扳机通过真实开口连到原骨骼轴附近；保留原动作和槽名。
- S41 按用户要求读取实际保存 FBX，原 ADS 中心射线从被挡变为无遮挡，前后连接肩与机匣存在重合。只证明指定几何接口；未运行游戏或制作材质验收渲染，不能记为整枪、动作或视觉验收通过。入口 `SourceAssets/LMG20120260927/SightFinish41`，说明 `Docs/Weapons/lmg201-sight-finish-20260929.md`。

## A762 扳机区与可替换握把的归属（2026-10-01）

固定护圈、后支撑及机匣握把座不能放在 `FactoryRearGrip` 材质槽，否则改装时会和原握把一起隐藏。握把接颈按本件轮廓连续成壳；安装面贴合后仍要区分扳机空间、前缘鼓包和下部握持轮廓，局部让位不等于整件平移。R09 保留上端/后缘，以局部形变收前下部，并用形变雅可比逆转置运输原角点法线。
