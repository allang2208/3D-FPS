# 生成枪械的近景精修：A762 经验

用于生成枪体已经选中、但近景出现机瞄堵孔、换弹露空、导轨下漏面或接口断裂时。保留选中母版及动作骨架，按缺陷局部重建。A762 的生成/接入记录在工程 `SourceAssets/A762Meshy20260920`，数值坐标只适用于该枪。

## 几何缺陷先于材质

- 从 ADS、检视和换弹实际可见区域定位缺面。弹匣抽出后会露出上口、唇边和内侧；不能只封侧面轮廓，或靠双面材质伪装封闭。枪管/导气管连接与枪托双杆接头都要有连续厚度和完整过渡。
- “ADS 两侧粗糙”可能同时包含烂拓扑、破碎面、平滑错误及旧图集拉伸。重建面用自己的 UV、倒角与合适硬边；不要继续把旧损坏区域的烘焙法线灌入新表面。
- 机瞄固定底座与可翻折头部分开；导出枪体时剔除旧头部，避免新件翻倒后旧几何仍堵视线。围绕实际铰链、局部轴设置前后折叠方向，不能把同一正负90°应用到不同坐标系。A762 前准星向后、后照门向前折叠。
- 瞄具依真实导轨冠面与鞍座接触面安装，光心与眼距分别适配；不因导轨清楚就直接复制其他枪的整套坐标。倍率环与光学材质也属于配件接入范围。

## 分区和统一涂层

- 新零件材质槽继续保留 FactoryStock、Flash_Hider、Magazine 等运行分区身份；重新导入采用当前 FBX 分区并显式绑定，避免沿用旧槽编号导致隐藏错误。
- 涂层统一使用本枪当前主体颜色/金属度/粗糙度基准，在原配件材质的金属分支中替换。原始区域遮罩、刻字保护、镜筒内壁及镜片分支各自保留。转换后的金属度不是可靠的原始区域遮罩，不要在已有涂层图外再套一层全局涂色。
- 微纹采用独立 UV/物理平铺，保留结构法线和光学通道；材质副本不改共享枪型母版。重导入脚本保存最终材质覆盖表，避免下一次模型导入恢复旧外壳。
- 图标同时有基础 PNG、数据引用和运行动态图路径。隐藏手臂的模糊字符串 `hand` 会误伤 `handguard`，应按真实身份排除护木；掉落展示共用过滤时同步修正。

## 保留制作链

Refinement02 的几何函数仍供 Refinement04/Accessories05 使用，初始 Integration 仍提供动作；日期早不能判为废案。归档只移动已取代的备份/输出，并留下原路径、散列和替代物。Meshy 原始候选、用户参考、最终 Blend/FBX、实际动作源及依赖贴图继续保留本机，公开发布只包含许可允许的源码和制作说明。

## 失败案例：PKM 全系列已退役（2026-09-22）

用户否定了 PKM 从初次接入到 VideoAdaptation10 的建模和动作，整轮已归档到本机 `trash/pkm-rejected-20260922`。Integration、Refinement02、Rebuild03、SourcePreserve04、SightGrip05、Recovery07、GripFinish08、SeamContact09、VideoAdaptation10 都不是成功母版。工程记录见 `Docs/Weapons/pkm-retirement-20260922.md`；不要因“源表面保留”“导入成功”或版本号更大而自动恢复其中任何版。

- **不能据此判定 Meshy 上限或 UE 导入器有错。** 本次同时改过拆分、补面、法线、材质、握点与动作，没有形成能单独归因的对照。A762 已被接受只说明那一条处理链适配成功，不证明相同切割与动作方法适用于开盖、弹链供弹的 PKM。
- 生成网格的连通岛不是机械零件标签；上盖可能与机匣粘连，完整弹箱也可能被空间范围切坏。拆分须依据参考接缝与原表面归属，保留原三角面、UV 和角点法线的对应。用包围盒/坐标阈值批量切分、布尔后猜原面归属，容易得到碎片、薄片和运动时露空；接缝算法本身也不等于结果已正确。
- 开盖模型不能只加一块凹底或把外皮向内偏移：可见的盖内面、边缘厚度、机匣侧壁和托盘各有形状与材质接口。仅按视频实际可见层次做局部适配，遮挡部分记录为未知，不把低清游戏视频当成完整内部几何或尺寸依据。原有细节保持，不用追加方块/圆柱掩盖拆坏的轮廓。
- 材质统一要保留本枪外壳图集、材质分区和非金属身份；新面单独展开并选择对应钢材实例。提高金属度、叠微法线噪声或整体调暗粗糙度，不能修复破面、错误硬边或错误切线。旧烘焙法线也不能直接套到新拓扑。用户要求材质优化时，不因此扩大为整枪重建。
- 原表面保持、文件散列、导入回执各证明不同事情，都不证明外观或动作合格。用户未授权测试时，交付注明未测试；不要追加自测，也不要把最后一次脚本修正写成成功经验。持续失败时缩小到当前反馈对应的几何/着色/姿态层，并保留可辨认的源与候选差异。
