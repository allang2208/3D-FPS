# 跨枪型瞄具、安装座与金属材质

用于把现有瞄具或枪口复用到另一把枪。先核对当前加载的网格、材质槽、局部轴和实例配置；“已在枪匠列表出现”不代表持枪、库存和掉落模型完成接入。

## 安装基准与结构

- 分别测量枪根、机匣安装面、瞄具底脚、视线点和枪口。已烘焙到枪根空间的附件与原始共享附件可能使用不同前向轴；校准应按资产约定区分，不能只按枪型选择轴。
- 单位换算只做一次。AKM 当前案例枪根使用米、共享静态瞄具使用厘米，相对缩放 0.01；这是该骨架的约定，不是所有 UE 枪械的默认值。
- 保留瞄具合理的物理大小，为不同底脚制作专用支架。支架应有明确的机匣接触、夹紧结构、斜肩和倒角；薄导轨、适度镂空优于同厚方块叠加。固定镜体位置的底座优化完成后仍复核 ADS。
- 用真实模型确认左右侧。局部 X 正负不等于机械意义上的左/右；避开保险杆、拉机柄、抛壳口及手部扫掠。源模型侧视和游戏第一人称都要看。
- 枪口特效/弹道出口取膛轴与配件端面，不取不对称网格包围盒中心。验收长度来自源模型尺寸和安装深度，不能照搬另一把枪的任意上限。

## 枪型专用材质

- “统一金属”覆盖镜体、夹具、螺钉、底座和活动倍率环。先逐槽审计，不能只改安装座；同时保留镜片、分划、橡胶、标识及光学通道的消光处理。
- 用户只要求目标枪型变化时，使用独立材质/网格变体或目标组件覆盖，保留共享源资产。倍率环也要跟随目标枪型材质和销毁/重建生命周期。
- 不把枪身图集直接套到另一模型的 UV。可保留 UV0 与原法线，在新 UV 通道按物理尺度投射已验证的枪钢纹理；若原材质有可靠金属遮罩，可用于混合金属区域。先确认遮罩语义，不能默认所有 metallic 值都代表裸金属。
- 内壁单独检查：外壳枪钢合适，不代表镜筒内壁也适合。高反光内壁会破坏可用视野；必要时以独立材质槽或区域遮罩保留原消光层。
- Blender 计算方向遮罩时，变换后的法线先归一化；非单位对象缩放会破坏按法线分量判断的阈值。导入角点色时显式确认颜色导入选项；UV1 被材质使用时不要让自动光照 UV 覆盖它。
- Unreal 材质脚本检查连线返回值。无名输入用实际引脚名/默认输入，不能假定 Clamp 引脚叫 `Input`。NullRHI 导入 PASS 不证明 SM6 着色器可用；实际运行日志出现 `Failed to compile Material` 或默认材质回退时，视觉验收不通过。

## 验收与证据

检查四个层面：源几何/UV 保留、导入读回、真实材质渲染、游戏行为。涵盖枪匠草稿/应用/取消、实例保存重载、未装备实例、图标/掉落、切枪与拆卸、ADS/射击、相关换弹及 LPVO 活动环。

继承另一把枪的测试时，调整测试夹具的武器 ID、弹药、原点和等待时间，保留产品的装备/换弹锁。不要为了让测试通过而缩短游戏动作、改补弹时序或放宽开火次数。源尺寸的精确断言优于增大泛用容差。

资产覆盖导入与持有该资产的游戏验证进程顺序执行，避免文件占用；只结束自己启动的验证进程。新原生模块编译后用新进程验证，已有编辑器需要重启。历史 PASS 与当前发布快照的验证分别记录。

本机案例（2026-09-11）：`SourceAssets/AKMOptics20260911` 为复用接入与轴线校准，`AKMBridgeRefine20260911` 为底座结构，`AKMOpticSteel20260911` 为专用材质、UV 与内壁遮罩。分别保留历史验收 502、233、274 项，不把这些计数或尺寸写成新枪通用标准。二进制依赖见仓库 `Docs/AssetSetup.md`。
