# 左轮改造、装填事务与资源交接

用于复用成熟左轮动作但更换枪体、容量和配件接口。机械轴与膛孔读 [机构绑定](revolver-mechanical-binding.md)，握姿和腕臂读 [共用动作与短枪支撑](../../ue5-fps-arms-animation/references/revolver-shared-grip.md)。以下方法来自 RSH 双动五发接入；具体厘米数和时长不跨枪复用。

## 容量与换弹事务

- 将五发容量贯穿库存、弹巢骨、逐发入座和快速装填器；主手、副手、法杖副手都需使用同一枪型判定。动画分支接入新枪后，退壳事务若仍只接受供体 ID，会中断动作并被空仓自动换弹重复触发。
- 开仓、退壳、入弹和闭合使用同一个源时钟。换弹倍率作用于播放时钟，不能分别缩放关键点后又二次缩放。
- 弹壳脱离时先求精确释放帧的骨骼世界变换，再提交库存退壳并隐藏原蒙皮几何；由有界 FX 池承接静态弹壳的初速度、重力与碰撞。不能以最近一帧渲染姿态代替释放姿态。
- 厘米导出的静态网格接入含 100 倍根缩放的原生骨架时只补偿一次。区分保留的实弹、丢弃的空壳、快速装填全退和切弹种在插入时提交；视觉遮罩不能提前消费或返还库存。
- 收手轨迹与开仓同步渐降，整枪和握持手共同移动，再连续交给低位装填段。保留单持已认可动作，不为双持修订覆盖共享供体。

## 配件身份与作用范围

- 新枪的旧全息外形改成专属方形瞄具时，用本枪局部 ID 迁移和图标别名，保留其他枪的通用 ID、属性及成像。倍率进入真正成像入口；名称变化不能代替倍率接入。
- 握把本体与防滑纹分槽：换本体隐藏原厂分区，同时按新表面重制覆盖层的边界、螺钉孔与厚度。三种纹理可以复用，旧覆盖网格不能未经适配直接套新握把。
- 拔出速度加成按 `rate = 1 + bonus`，+100% 为时长减半；动作、音效 cue、淡入淡出共用倍率。双持每只手先读自己的配件数值，再开始装备动作，避免沿用上次武器的倍率。
- 同一接口的消音器与制退器按 ID 选择独立模型、真实出口 socket、预加载和音效分支。共用安装变换不代表都属于消音器。

## 材质与交付

复用通用配件时保留 UV0、法线、光学遮罩和物理尺寸，私人安装座跟随本枪表面。静态件材料不要残留骨骼用途；干湿映射合入本枪表，不改共享供体。修改 UE 材质槽结构体后将条目写回列表，再把列表设回网格并保存。
