# SVCH 换模、配件与实际接口

用于共享 SVD 动作、更换枪体后准星/弹匣/枪机/配件不贴合的工作。手臂细节转手臂技能的 [SVCH 握点与帧间修订](../../ue5-fps-arms-animation/references/svch-grip-subframes.md)。

## 共享骨架不等于共享物理标记

- SVCH 复用 SVD 源动作和时钟，但枪口、准星、up 轴、弹匣接口和枪托接触点来自新枪体保存后的 UE 几何。不要直接读供体 `WPN_FrontSight` 或 `WPN_SOCKET_Muzzle` 来代替新模型的物理点。
- 坐标标定以保存后的 UE component bind 为准，包含 FBX Y 反射和原生 100 倍缩放。直接反解 Blender rest 曾让准星位置偏移 28.75 cm。明确使用 root 单位还是无缩放厘米，不能叠加或漏掉 100 倍。
- ADS 射线使用眼位到实际前准星，枪口收敛使用实际出口；腰射、光学镜、遮挡和远端出口分别追踪。只修模型摆放不等于弹道已修。
- 新模型自身已包含机械准星时，按明确的型号/组件合同决定是否生成旧 M4 独立瞄具。名称包含 `FoldingSights` 不能作为安装 M4 瞄具的条件；已生成的重复组件也要在切换时清除。

## 换弹、左手拉栓和弹匣

保留认可的普通/空仓时序与 V9。新 SVCH 拉柄在左侧，空仓换弹后由左手抓柄，右手保持后握把。普通/扩容弹匣分别对齐真实接口，并同时校准手掌接触与插入轨迹，不能只平移一个运行时插槽。

标准弹匣也可以是替代组件；空配件 ID 不代表这个组件应隐藏。第三人称静态装备快照需要记录已经被替代的原弹匣、原弹头和收起的机械瞄具，否则首个动作包到达前或过期回退时会重现旧部件。

## 通用瞄具与特殊消音器

- 原包瞄具名为 KV Inhibitor 部件，不能由外形或整枪标题确定现实型号。采用中性游戏名，并将 1/2/4× 作为游戏配置；保留稳定配件 ID，切换倍率时同步 HUD、相机、镜内显示与退壳遮蔽。
- 狭窄/短导轨按真实接触做独立承接座，保留原镜主体尺寸和各宿主父骨/桥的生命周期。
- 大口径狙击消音器只在 SVD/SVCH 开放；基础 sniper 分类和 +1.0 暴击加成属于武器，0.75 子弹速度、0.60 后坐力、1.30 稳定性属于配件。
- 无声击杀复用弓的 `MonsterDamageAlert::FScopedSilentShot`：射击时按已装配实例冻结标志，服务器从权威影子重建；近战不继承此标志。伤害后存活才释放群体警报，击杀丢弃延迟警报，不清除既有警觉。
- FBX 导入比例错误可能让 31.7 cm 的模型实际只有约 0.3 cm，而 socket 仍是 31.7 cm。修复应核对保存资产的边界、出口和导入单位；重导入可能沿用旧比例。本例改为显式厘米顶点导出，保留外观和数值。

## 完成度与发布

目录选项、数值计算和世界模型是不同交付项。当前五种通用枪托仍缺 SVCH 专用接口，不能因原厂枪托已完成抵肩/近战标定就称为全改造完成。

模型原包、贴图、动画及密集蒙皮数据留本机，按许可决定是否可发布。可公开原创配方、运行代码和恢复说明。历史阶段的旧几何/源动作可能仍是当前适配输入，归档前追踪实际脚本依赖。
