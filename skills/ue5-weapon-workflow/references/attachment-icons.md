# 改造配件图标标准

用户于 2026-09-14 确认五款枪托图标达到预期，并要求将同一规则用于其他改造配件。这里的“贴图图标”是改造面板的二维图像；不表示旋转或重做模型的 PBR UV。

**用户于 2026-09-27 明确：改造栏图标统一使用无彩色灰阶配色。** 此规则覆盖分类入口、原装件、可选件和拆除状态，优先于本文早期「还原实际基色」要求。仅约束改造栏二维图；物品栏图标、三维装配预览和实战模型仍遵循各自材质规则，不随本条去色。

## 新版金属方框（用户确定，2026-09-30）

- 改造栏正式图标统一为厚实倒角金属方框、四角铆钉、银色内圆环、凹陷深灰底板与中央单个部件；适用于枪械、弓、法杖、近战及采集工具的分类、原厂、选项和拆除项。取代下文历史案例的无框透明成图规则。
- 本机认可母版为 `SourceAssets/FirearmFramedIcons20260930/muzzle_brake_framed_v2.png`。新图使用该母版约束边框，以当前实际部件图约束轮廓、纹理和方向，不能仅给旧白模套一条细线，也不能凭名称虚构部件。生成图片使用 imagegen，一项一图；相同形态可共用，不能因名称相似合并不同形态。
- 最终 PNG 保留极窄透明外缘，框内为不透明深色底；孔洞透出底板。独立部件素材仍可采用透明背景。保持中性灰阶、立体层次和材质分区，主体完整收进内环，不重叠边框、不拉伸、不添加文字或水印。
- 原厂件是可用实体：原厂脚架等必须显示实物，不加红色禁止标识。只有无配件或拆除项使用中性银色减号；分类入口使用代表部件。选中、安装、不可用状态由卡片或独立 UI 标记表达，不烘焙到图片。
- 检查覆盖范围时以运行目录合并后的分类、原厂、专属选项、公共选项为清单，同时处理强化等不在 Slots() 内的入口。区分图标引用数与独立母图数；不能只枚举已有 PNG 就宣称全覆盖。全面检查只在用户要求时执行。
- 接入须追踪实际优先路径：枪械 FramedFirearms、弓 FramedBows 与根目录旧路径可能同时存在；同一键应更新实际读取处，跨武器缓存键保留武器身份。已经画好完整边框的 PNG 不再叠加旧细线框或额外内缩；使用等比缩放，沿用现有缓存，不新增逐帧加载。
- 生成母图、部署映射与导入回执分别保存。仅写好导入脚本不算资产完成；后台实际导入并保存 Texture2D，使用 UI 纹理组、Editor Icon 压缩、sRGB 和 Never Stream。没有加载代码变化时不需要原生构建；构建失败须分别报告图片落盘、资产保存、代码未生效。
- 已替换旧图按清单归档到 trash，保留最终母图、可重建输入、映射和导入回执；本机完整资源与 Git 源码发布边界按 publication.md 执行。不得将仍在被作者脚本引用的旧素材仅凭日期判为废案。

## 统一灰白色与信息表达（用户确定，2026-09-27）

- 灰白色是所有武器改造栏的默认制作规范，覆盖枪械、弓、近战和采集工具；后续新增或重做直接沿用，不再逐件询问是否保留原色。
- 分类、原装、改造、拆除图标使用同一套中性灰阶。符文、自发光、宝石、晶体和透明材质的色相也统一去除，避免基色已经去色却仍留下蓝光、绿光或彩色反射。
- 保留真实部件轮廓、纹理、粗糙度、金属度、法线和透明孔洞。深灰表达凹槽与阴影，银灰／灰白表达主体与高光；维持材质区别和小尺寸可辨性，避免无细节的纯白填充。
- 部件差异由形状、结构、名称与属性表达。选中、已装备、不可用等状态由 UI 边框、标记或透明度表达，不将状态色烘焙进部件 PNG；元素、品质等语义由独立文字或标记表达。
- 图标去色仅作用于独立作者场景，不修改物品栏彩图、三维装配预览或实战材质。以当前实际材质恢复后的结果作为输入，禁止重新绑定过期纹理。
- Blender 可复用 [灰阶材质助手](../scripts/apply_modification_icon_grayscale.py)：对作者场景的部件调用 `apply_grayscale(objects)`，复制材质后转换有效基色、发光与着色色槽，保留其他表面参数；Blender 5.1 调用 `neutral_output(scene)`，让输出保持中性并保留透明通道。基色参考映射为 `0.16 + 0.45 × clamp(Y, 0, 1)^0.25`，与当前弓图标保持一致；灯光按对象尺度处理，不能用抹平法线或涂白来追求同色。

## 来源与单件表达

- 从当前实际加载的模型及对应可编辑源渲染，保留已认可的轮廓、孔洞、材质分区和标识。先由运行引用定位当前版本，不能按目录日期或 `Final` 名字挑选旧模型。
- 已有实装模型时，不使用概念图、生成器想象图或外观不同的素材图作为最终配件图标。需要新模型时仍先走通用模型管线；图标在该模型确定后制作。
- 一张图只展示一个配件实例；安装座、夹环等属于该配件的必要组合结构可以保留，不额外摆第二个示例、对照件或散件。
- **机械瞄具只显示一个完整机瞄，默认使用该枪的照门组件；不能同时摆放前准星和后照门。** 图标的简化不改变游戏中的前后瞄具及折叠逻辑。
- 折叠机瞄可能把活动头、固定底座分别放在静态件与枪体中；取完整照门时按当前模型的面／连通组件补齐固定底座，不能只截取活动头。排除源场景内隐藏的旧版本、手臂和参考组件。
- 顶点或连通组件编号只适用于记录的那一份模型；重新拆分弹匣、材质区或导出后必须重新建立取件映射，不能沿用早期模型的索引。
- 不同枪型的原厂件或不同造型不能误用同一张图。采用武器专属图标覆盖共享图；同造型配件可保留明确登记的代表性共享图，如本次已认可的枪托系列。
- 只有数值变化、没有独立外观模型的选项，复用实际部件图，差异由名称和属性说明表达，并在来源记录中注明“数值改造”。不能为区分图标虚构已经实装的新造型。
- “无配件／移除”没有实体模型，使用统一中性移除符号，避免画一个看似已安装的配件；装填模式可使用实际单发弹药或一个完整速装器组件表达。

## 朝向、取景与材质

- 以枪械安装姿态确定前后：枪械前方在画面左侧，后方在右侧，上方保持朝上；采用相机水平的正交侧视。枪托为安装端左、托底右；枪口件为出弹端左；光学件为朝目标一侧在左。
- 水平的是枪械基准轴及相机。握把、弹匣等保留实际安装时的竖向轮廓；45° 握把保留自身倾斜，不为横排把所有配件躺倒。不得仅根据最长包围盒轴猜测机械方向。
- 用三维旋转确定观察侧，不能用二维镜像把铭文、调节旋钮、左右结构一起翻反。对没有可辨前后的轴对称件，在清单中记录其机械轴及选定观察面。
- 分别记录模型的真实安装坐标。瞄具骨骼的局部 Z 轴可能不是枪械上方；手枪、步枪以及独立导出的配件不能共用未经确认的轴转换。优先沿用该资产作者脚本中已确定的枪口轴和上向。
- 独立部件素材使用 1024 × 1024 RGBA 透明 PNG，保留孔洞，去除地面、文字、水印、手臂及无关枪体；正式改造栏成图按上文新版金属方框合成，主体完整放入内环。
- 使用一致的中性棚拍照明和银灰／深灰明暗体系，去除木色、绿绳、棕革等色相，不逐件任意染色。去色在独立图标渲染场景中进行；保留实际 UV、纹理起伏、法线、粗糙度、材质分区及透明孔洞，不能只换成无细节白模，也不能把非金属改成金属。
- 先依照当前 UE 材质绑定及有效参数恢复纹理连接，再将有效 BaseColor 转为灰阶并统一亮度范围；不复活已失效的旧图案。中间 FBX 丢失贴图时回到源贴图与导入脚本，不能将丢图造成的纯白作为统一配色。着色转换和图标专用覆盖写入作者记录，不能回写运行材质。
- 圆环瞄具若纯侧视会丢失圆孔与竖杠，可以保持相机水平、上向不变，在三维中小幅转向能辨识结构的一侧；记录角度，保持单件及完整安装座，禁止二维镜像。本轮弓瞄具使用侧面向后转 35° 的正交视角。
- 弓弦等细线件保留当前真实锚点与中心线。真实直径缩到 48／64 像素后不可辨时，可在图标作者场景加最小屏幕线宽，记录真实尺寸和图标线宽；不要修改运行网格或拉弦参数，也不要虚构线圈、安装件。本轮弓弦为 64 像素下 1.2／1.0 像素的显示线宽。
- 已接受的枪托参考配置：正交相机、AgX、48 samples、透明背景。灯光能量、曝光和尺寸归一化随对象物理尺度处理，不把枪托尺寸或轴转换直接套到另一类别。

## 用户要求全面图标审计时

1. 按运行代码合并武器专属选项和 `common_options`，枚举所有当前可见槽位/选项；不能只枚举已有 PNG，遗漏缺图或公共选项。
2. 核对每个选项实际解析的图标路径、缓存键、缺图回退、跨武器错用、重复文件及当前源模型身份。分类图标和“无配件”状态符号与实体配件图分别记录。
3. 实际查看所有现有图标：统一无彩色灰阶、方向、水平相机、单件数量、轮廓对应、金属框及框外透明边、裁切、留白、小尺寸可辨性和表面表现。检查有色像素、尺寸、哈希或 alpha 统计只能辅助审计，不能代替查看模型和图像；同时查看 48／64 像素实际展示尺寸。
4. 对不符规则和缺失的图标，用确认过的模型重做；已认可且符合规则的图标保留。按整张最终图及小尺寸缩略图复核本轮改动，记录结果和仍存在的限制。
5. 报告审计覆盖的武器、选项、图标数，列出保留、替换、补齐和未实装独立模型的情况。未使用的旧图只登记，不擅自清理其他资产。

全面审计与额外预览仅在用户要求时执行；本标准不改变默认由用户进行游戏测试的规则。
