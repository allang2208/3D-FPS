# 武器状态刷新与输入归属

适用于 FPSGAME 的单持枪械、双持手枪与档案事务。2026-09-15 按用户要求实施；构建不等同实机测试。

- `SaveNow` 从当前控制器捕获状态，只执行持久化与档案/UI 发布；不能把保存视为重新装备武器。装备、属性、补弹等业务事务通过 `CommitState`，写入成功后应用角色。保留现有 A/B 存档与失败不提交语义，保存周期不是本任务可以顺带改的东西：2026-09-21 起定时写盘由 `fps.Save.AutosaveSeconds`（默认 300 秒、仅在有待写盘增量时写）驱动，进度型事务走 `StageTraining` 并入该周期，玩家主动事务、升级与退出仍立即写盘——细则见 `Docs/UI/autosave-policy-20260921.md`，不要在武器刷新路径里另开一套写盘时机。
- 角色按主手实例、武器定义、可用状态及双持组合识别真正换装。先释放旧输入、停止旧控制器，再加载视模并应用数据；双持退出不能递归调用角色的档案应用入口。
- 单持 `bFireHeld` 只由角色输入流程维护；双持左右手各有 `Held` / `Pending`。公共移动逻辑使用 `IsWeaponFireHeld()` 查询当前控制器，不能让未启用的组件清空另一个控制器的输入。保持手枪一次按压一发；切换单双持输入映射时要求重新按键。
- 同一武器/双持组合的属性刷新不重置射击截止时间、动作时间、换弹播放率、已结算入膛次数或已播放音效。新属性从原始基础值重新计算，作用于后续动作，不能乘回上一轮结果。
- 配件通过 `ApplyWeaponAttachmentPresentation` 按槽位差异更新。枪匠预览和撤销使用相同入口；关闭后应用已安装组合。重建视模或真正换装时失效缓存。普通数据刷新不递归显隐所有子组件，避免重新显示已隐藏配件。
- 双持弹药按两只手的物品实例写回；角色主手弹量只是显示缓存，不能随后覆盖双持主手的数据。发射先扣弹并同步，再进入可能同步发放击杀/修炼奖励的命中回调。

工程计划与实现说明：`Docs/Weapons/weapon-state-refresh-upgrade-20260915.md`。按用户规则默认不运行测试，交付明确区分代码完成、必要构建和用户实机反馈。

混合副手与视模异步刷新见 [长杖接入](staff-modular-production.md)：区分双手枪和存在副手枪，装备状态的入口必须与实际推进该时钟的控制器一致；可视配方缓存不能因普通物品数据变化反复重载。

## 检视取消归属（2026-10-02）

当前用户要求常规身体移动与枪械检视并行，只有取得武器／手部控制的动作打断。取消放在实际动作入口，不在 `InputKey` 中对所有按键或原始鼠标事件统一取消，也不放在逐帧 Axis 回调。

| 指令 | 当前 FPSGAME 行为 |
| --- | --- |
| 镜头、走跑、跳蹲、滑铲、疾避；快捷栏疾避；Z 附近批量拾取 | 保留检视 |
| 开火、瞄准、换弹／弹种轮盘、快速近战、特殊武器功能、实际换装 | 退出检视，让原动作入口取得控制 |
| 非空技能／物品快捷槽、E 成功分派目标交互、占手菜单／建筑抽屉 | 退出检视；菜单沿用 `SuspendWeaponForMenu()` |
| 再次检视 | 先清理旧检视，再从零播放 |
| 翻越／攀爬 | 检视允许探测；路径和动画真正接受后才取消，失败尝试保留 |

不要仅按物理键建立例外表：同一键可能分派移动技能、施法或界面操作。Release、Repeat、无绑定键、空快捷槽及无目标且无技能绑定的 E 不额外取消。`IsWeaponBusy(true)` 只放宽检视参与翻越探测，其他忙状态仍受原门控约束；空中抓边也在成功开始后清理。

**手枪自行提前结束的实战原因**：UE PlayerInput 会先调用动作绑定，再调用 Axis 绑定。同帧旧移动值或鼠标平滑尾值因此可能在 `InspectPressed()` 刚开始后将它取消。先前的原始事件拦截曾解决此顺序问题，但会打断普通移动，已被当前动作分类替代；不要恢复 Axis 或全键取消来修时长。

`InterruptWeaponInspection()` 仅清理共享 `Inspecting`：停止机械音与后续 cue，清除作者动画、动作权重、时钟及构图偏移，恢复当前待机／瞄准。不走正常 `FinishWeaponAction()`，否则会把下一次开火推到旧检视终点。保留真实射击冷却；重复检视同时重置状态起点、采样起点，SingleNode 与动画图路径都从零开始。

范围只含已有枪械检视；没有 clip 的枪不凭此新增动画，双持检视仍按此前用户选择禁用。实现和历史构建见 `Docs/Weapons/firearm-inspect-interruption-20261002.md`。正式 Game／Editor 已编入与游戏实测是不同交付状态，本轮未运行游戏测试。
