# 长杖模块化制作与接入

长杖系列使用独立 `staffs.json`、`staff-gunsmith.json` 与 `Weapons/Staff`，不借用剑的连击／格挡或枪械弹药状态。第一人称、改造台、背包动态图、掉落物及角色持械应读取同一六槽装配配方；清理旧子组件后再切换武器族，不能只替换根网格。

- “Meshy 生成”与“Blender 重建”要分开说明来源。学徒长杖当前保留 Meshy 设计／源模型，木杆在 Blender 按三视图重建自然凹凸，顶部绳结和水晶分别制作修整；不能把最终重建网格全部称作未经加工的 Meshy 输出。
- 替换模型前保留握持区、六槽接口和施法尖端合同。学徒长杖案例的总长 160 cm、握点 `(0,0,32)`、握持区 `z=22..42`、晶头接口 `z=62` 与默认尖端 `z=80` 是该武器的参数，不是所有长杖的统一尺寸。
- 漏空分开排查生成体开放边、切割端盖、退化三角形、UV 通道和法线。UV 岛缝上直接切片再传最近三角面 UV，会同时留下开口和拉伸木纹；需要连续闭合表面和对应的轴向 UV。不同可替换部件保持独立封闭实体，不跨装配接触面焊死。
- 世界水晶“有厚度”与 UI “写入覆盖率”是两个问题。Thin Translucent 双源混合可能不改反向覆盖率 alpha，造成世界可见而预览完全消失；在预览副本使用写入覆盖率的专用材质，保留世界材质。实时与目录图共用材质替换入口、异步资源清单和装配逻辑。
- 武器回退图按 `Icons/<definition>.png` 查找，不能只修改 JSON 的另一张 `ue_icon`。导出器须读取长杖独立目录，并保持旧存档文件名别名；横竖缩放见 [运行时图标](../../ue5-ui-umg-slate/references/runtime-icon-pipeline.md)。

当前作者链：`BranchCrystalV18` Meshy 输入、`SolidRepairV19` 表面／PBR 输入、`BarkRebuildV21` 几何、`QuartzAimV22` 世界水晶、`WorkbenchPreviewV23` UI 水晶、`EquipmentIntegrationV24` 手部装备／图标接入、`IconOrientationV26` 横竖布局。旧版本目录可能仍提供当前输入，只归档确认已退役的备份及无运行引用的输出。
