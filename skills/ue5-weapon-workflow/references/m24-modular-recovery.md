# M24 模块化、枪托与恢复链

用于长枪的独立枪托/后握把、原厂分区恢复、倍率切换与局部表面修订。遵守当前用户授权；本页不自动触发游戏、渲染或联机测试。

## 装配关系先于偏移

- 枪托安装面、机匣尾座和握把安装面分别标定。独立后握把必须是完整握把几何，不能裁一截原厂一体枪托腕部充当新握把。保持枪管、扳机、枪栓路径和已认可手部接触，再修连接座；不要移动机械骨去迎合错误配件。
- 共用骨架后托保留母体尺寸与形状，各枪制作接口。以安装轴和肩部基准对齐，不能只按整枪包围盒居中、统一缩放或一律套相同旋转。狭窄连接面从实际切边生成过渡；涂层 UV 和物理平铺尺度连续，金属、橡胶、聚合物保留身份。
- 原厂隐藏应使用可恢复的材质 section，并保留源拓扑身份。先确认替换网格加载成功，再隐藏原厂；拆下/切枪时清掉已禁用组件，避免隐藏旧组件继续进入第三人称部件清单。
- 依赖关系同时约束 UI 选择、Normalize、旧存档和实际装配。M24 案例：`body=m24_advanced_action` 才解锁后握把改造和一个 `tactical` 战术挂件槽；退回原厂枪机需同时撤下这两类依赖改造。骨架后托仍需完整的默认独立握把，不能把“改造未解锁”理解为不显示握把。
- 原厂枪托与托腮板合并为同一选项后，保留既有稳定 ID 并归一旧空值；不要再留一个功能重复的“拆托腮板”条目。原厂/先进枪机、原厂/骨架后托、普通/扩容弹匣的分支必须引用正确握持层。

## 光学与动作接口

- 镜内捕获与周围主场景分开投影：保留实体枪和镜体，镜面显示放大图像。灵敏度按实际用于瞄准的视场与输入语义处理，不能只按显示倍率字符串乘除。切 1× 上置瞄具与主体 6× 时，镜内权重、视线安装点和红点显隐使用同一过渡；滚轮到端点仍消费事件，避免同时切枪。
- 普通换弹、空仓换弹、装备拉栓保留独立机械阶段。复用认可的开火拉栓微动时，只复制机械时间窗内的枪根相对运动，并同刚体携带双臂根链；不要重复叠加旧整枪靠近身体的位移，也不要改动手指/腕肘局部接触。
- 脚架展开、手部接触和声音共用源时钟；架枪增益等待真实支撑成立。退出、换弹和正在拉栓的延迟收架要有明确交接，不能只缩短动画却保留旧判定时间。

## 材质与法线修订

- 明显条带/三角折痕先对照同一网格的法线与切线，再调粗糙度。用减弱纹理掩盖损坏法线，会留下塑料感和不稳定高光。
- 在保留几何/UV 的修订中，按三角角点、面朝向和距离匹配 donor 法线；硬边不能按共享顶点位置平均。新增切口/尾座局部重建，未改表面继承认可的法线。
- 写回 source mesh 后同时处理切线和 binormal sign。GeometryScript 的 normal overlay 成功不等于 tangent basis 有效；本例曾出现零切线，最终使用有效 render basis 回写并冻结各 LOD 的显式基底。更新应包含在可重放的 install 路径里。
- render/source 回写可重排索引。需要比较时，比较带绕序的三角位置与材质 ID，不能仅按顶点编号判定几何改变；“UV 通道数相同”不能宣称 UV 坐标逐项一致。
- 湿润支持沿当前运行调用链确认。本例运行时按 `WeaponWetness` 标量接入；一个未被调用的旧母材质白名单不能作为湿润失效的证据。

## 先进枪机的单战术挂件接口（2026-11-04）

- `inherit_common_options=false` 的 M24 只选择性合并通用 `tactical` 选项，不因此开启其他未适配槽；保持 `SupportsSecondary(ue_m24)=false`。普通镭射、手电和赐福镭射共用既有数值、光束、照明与遮挡逻辑。
- 专用源 `SourceAssets/M24Tactical20261104/`；正式资产 `/Game/Weapons/M24/Tactical20261104/SM_{laser,flashlight,blessed_laser}`。安装座按先进枪机右前导轨的实体截面制作，通过 `M24Attachments::Mount` 进入原生枪根空间，禁止套用其他枪的偏移或镜像负缩放。
- `Emitter` / `AimGuide` 保持实际枪管前向；旋转源设备后，其材质中的位置分区也须变换回 donor 坐标再计算，避免外壳遮罩覆盖镜片或发光孔。外壳和安装座采用当前 M24 表面，光学、聚合物和金色饰件保持独立身份。
- 枪身改造变化必须刷新战术装配；实际先进底盘网格就绪后才能启用挂件。卸下时清空静态网格，避免残留进入世界/第三人称部件清单。M24 预加载分支应加入专用挂件路径，复用既有世界表现与存档归一链，不追加独立逐帧系统。


## 原厂握颈接缝与栓动配件时钟

原厂后托和先进枪机同装时，检查实际可见的两侧材质及各自 UV 对应的颜色和 ORM。M24 的过渡颈原来整段取机匣金属，保留的原厂握颈接近非金属。使用当前导入的 glTF 图集按真实切边采样，局部匹配底色、粗糙度、金属度和湿润响应，再沿连接颈过渡回机匣表面。完整配方见工程 `SourceAssets/M24FactoryStockSeam20261105/`。

“拉栓速度”需要逐个核对射后循环、装备补栓、空仓换弹。取已安装配件的目录倍率，动作开始时冻结。只缩短相应机械段，用同一源时间驱动姿态、声音、抽壳、闭锁及总时长。M24 骨架托的 1.20 倍速度不应同时加快取匣或抬枪。
