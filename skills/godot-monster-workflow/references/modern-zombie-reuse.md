# 现成人形资产复用与 Low Poly 修形

用于已有模型/动作的替换、同骨架怪物变体和材质升级。当前案例为 2026-09-06 的现代普通僵尸、工装矿工、狂奔僵尸；参数不是其他怪物的默认值。

## 先保留动作，再处理风格

- 现成模型自带合适的攻击/步态时，先实际查看原片段，记录许可、作者、原片段名和时间合同。保留原片段，另建游戏动作别名；补充动作单独记录来源和重定向处理。不能因下载页面公开就推定可商用或可再分发。
- 本例采用 Denys Almaral 的 ZombieMale_A 与十段原动作（CC BY 4.0），补充 Quaternius Universal Animation Library 的 Death01、Hit_Chest（CC0）。署名及修改说明随运行资产保存在 `assets/models/modern_zombie/LICENSE.md`。
- 同一骨架可复用衣着、体型和移动方式，但相同骨数/骨名不证明兼容。核对 rest pose、轴向、逆绑定矩阵和单位。本例模型根缩放 0.01、骨局部坐标为厘米；头部命中偏移不能直接当米使用。
- 只改网格/材质时比较导出前后的动画 sampler：时间、插值方式、目标骨与变换值，随后重新导入检查变形与接地。此例三个 V02 GLB 各保留 16 段动画、1530 条通道，采样最大差异为 0；这不能替代运行表现检查。

## Low Poly 的细节取舍

- 本项目用户选择保留原脸神态、只求神似；试加独立眼球和牙齿已被否定。此类风格修形优先轮廓、关节承重、衣领袖口和色块，不继续叠加写实五官。其他角色仍按其自己的风格合同判断。
- 加面应解决可见轮廓或弯曲折痕；不是单纯把三角面变多。合并可恢复四边面、适度细分后，检查脸部缩形与鞋底离地，必要时局部投回原表面。没有重做手指骨链时，不把手部表面优化称为完整五指改造。
- 衣领、领带、袖口等附件必须随身体蒙皮。用极限姿态检查边界权重与穿插；领带增加贴身中间顶点行比简单浮在胸前更可靠。贴身伤口优先表面材质，避免独立椭球像粘上去的部件。
- 单角色不透明 PBR 材质可保持风格与绘制成本可控。闪红等运行时改材质需要实例独立，检查攻击一只时其他怪物不会一起变色。

## 当前游戏合同与验证入口

| 项目 | 当前值 |
| --- | --- |
| 正式模型 | `modern_zombie_v02.glb`、`miner_zombie_v02.glb`、`runner_zombie_v02.glb` |
| 三角面 / 骨骼 | 8572 / 31、11532 / 31、8428 / 31 |
| 攻击 | 左右两段轮换，时长 47/30 秒，有效区间 [0.60, 0.77) 秒 |
| 死亡 | 2.4 秒，之后保尸 1 秒 |
| 移动原片段时长 | 普通 2 秒、矿工 85/30 秒、狂奔 58/30 秒 |
| 对应原地动作参考速度 | 1.021683、0.197768、2.357897 米/秒 |

游戏采用速度与动作参考速度是两个量：分别保留配置，通过实际水平位移驱动播放。不要把上述时间套回旧二维僵尸合同。

复用控制器时检查实例化后 `set_script()` 的入口。本地副本适配器继承现代僵尸默认配置，否则替换模型后可能恢复旧攻击/死亡时间。工装矿工是新变体，不能自动替代副本原有 `minerZombie` 身份和奖励配置。

验证入口：`tests/test_ordinary_zombie.gd`、`test_zombie_motion.gd`、`test_humanoid_variants.gd`、`test_modern_zombie_integration.gd`。检查命中窗口、控制打断、死亡一次回调、实例材质、头部命中、主场景真实位移与落地。默认渲染器查看关键姿态；单次截图和自动检查不证明大群同屏性能。

## 制作文件整理

最终源文件、GLB、动画参考检查表、GIF、许可及构建输入保留。数字命名的逐帧截图和 `.blend1` 自动备份可在确认最终预览完整后删除；再次打包 GIF 前先重新渲染。制作目录使用 `.gdignore` 避免被游戏导入为运行资源。

重建主入口为 `tools/ai-gen/humanoid-detail-v02-20260906/build_detail.py`，V01 的合并原动画 glTF 和 UAL GLB 是输入及对照证据，不因当前运行版本为 V02 就删除。构建脚本的临时工程应可独立生成配置，不依赖已经清理的临时目录。

## 同期四足材质复用

黑狼和僵尸犬均基于现役 Quaternius 狼。处理硬法线分裂顶点时先验证重合顶点权重一致，再焊接和平滑；GLB 因 UV 接缝重新分裂顶点属正常现象。短毛可用不透明颜色/粗糙度/法线烘焙表现；坏死伤口使用原网格浅凹及表面材质，避免悬浮伤口卡片。黑狼身份和体型保持，僵尸犬单独版本；两者仍是独立候选，制作完成不自动改变游戏刷怪入口。详见两个 `tools/ai-gen/*-v01-20260906/source-contract.md` 或 README。
