# 材质变体与风格统一

用于不改几何、骨架和动画的换皮，以及多个来源怪物之间的材质协调。

- 先固定用户当前认可的参照，并在同一相机、光照和曝光下并排比较。统一可以是增强低饱和资产，也可以是压低高饱和资产，不能默认一律去色。2026-09-07 本例用户否决将毒液、胖子灰化，改为普通、矿工、奔跑向其原色靠拢；增强候选尚未等同于正式换肤批准。
- 用颜色和粗糙度区分皮肤、布料、伤口及湿润口腔。全局降饱和会抹掉身份；按红色阈值提取伤口容易把棕色污渍误选成斑块。先实际查看贴图与模型，检查分区遮罩，再批量烘焙。色彩统一无法修复轮廓或几何细节密度差异。
- 对严格材质变更，优先保留原 GLB 的 nodes、meshes、skins、animations、accessors 和二进制数据，只追加贴图及更新材质引用。核对二进制前缀和描述一致，再导入渲染。不要为改贴图重新采样所有动作。GLB 粗糙度读取 G 通道，金属度读取 B；灰度粗糙度图配 metallicFactor=0 才不会误把皮肤当金属。
- Blender 节点查找用 type==BSDF_PRINCIPLED，避免界面语言影响默认名称。材质节点在绑定姿态下烘焙后，动画显示应使用烘焙贴图；保留节点供编辑，不让基于世界坐标的衣物遮罩随动作滑动。色彩图 sRGB，粗糙度/法线为数据贴图。
- 随机换皮在实例出生时只选一次；按实际模型源路径选池。材质先实例独立，再让受击闪红逻辑缓存它；原皮也要隔离。验证固定选项、随机覆盖、重复 setup 不重抽、攻击一只不会带动其他实例变色，以及副本 set_script() 后仍继承换皮入口。
- 候选发布保留贴图、许可、可编辑来源/重建脚本和最终同灯光预览。已有同一几何时可从原模型重建多个材质 GLB，避免重复提交整套几何；清理旧试验前解除新脚本对旧目录模板的依赖。

本例源码：scripts/zombie_skin_variants.gd、tests/test_zombie_skin_variants.gd；候选：tools/ai-gen/zombie-color-rich-v01-20260907。HSV 1.65/1.08 是该候选饱和度和明度参数，不作为所有怪物默认值。
