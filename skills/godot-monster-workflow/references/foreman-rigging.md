# 人形持鞭怪物：局部模型、蒙皮与导出检查

工头 V05–V08 的经验适用于已有身份模型上的肩臂和柔性武器修复；参数不能作为其他怪物的默认值。当前结果为局部改善，仍待用户视觉反馈。

## 先区分问题来源

- 肩膀与手臂共享连续网格是正常结构；三角面多也不能单独证明绑骨失败。对同一个模型做静止、单肩抬臂、单肘弯曲与实际攻击姿态，分别检查轮廓、腋下连接、骨轴、逆绑定矩阵和权重分布，再决定修模型还是蒙皮。
- 补环线不会自动消除僵硬。局部细分应保留 UV 和接缝，修形后再调整对应权重。工头使用截面切线与局部腋下修形，不能将其称为全四边形重拓扑。
- 自动重拓扑的“保留边界”选项不是验收结果。检查边界数量、连通性、投影距离与接缝对应；最近点不保证一一对应，不能强行把多个输出顶点吸到同一原边界点。
- 辅助骨、扩大权重平滑或布尔切口均需同姿态对比。若产生前臂压扁、袖口拉丝或裂缝，撤掉该尝试，避免为继续推进而扩大到整只怪物重建。无可靠证据时不宣称找到唯一根因。

## 蒙皮与握持

- 沿真实网格邻接平滑，避免空间距离近的薄层/肢体串权重。肩部修改可以固定前臂、手掌和手指影响，仅调整躯干—上臂过渡；新增顶点需单独核对插值、影响数及归一化。
- 握柄锚点按实际掌心定位，不能把腕骨端点当掌心。检查握柄、指腹、拇指及前臂方向在蓄力、接触、收势时是否一致；群组手指控制不等于逐指骨架。
- 改拓扑后比较拉伸指标时，优先验证原顶点映射，再用同一批原始连边比较；新增边单独报告。避免用不同数量/长度分布的边直接宣称改进百分比。

## 柔性鞭链与攻击意图

- 父子骨链同时旋转和非均匀缩放可能形成 TRS 导出无法保留的剪切。工头采用挂在手下的同级截面骨、单位缩放和各截面刚性蒙皮；此方法适合该管状武器，并非所有尾巴/绳索的通用替代。
- 验证实际 GLB 的关键帧之间插值，检查蒙皮顶点到握持锚点的距离、骨骼缩放和变形是否有限；只检查关键截图可能漏掉炸面。
- “向下抽”应从腕部与鞭子轨迹确认，不能仅靠抬高前摇姿态。保持既定接触时刻，用抬起—向下加速—惯性收势表达意图。
- 延长武器后，视觉长度、起攻距离、命中距离分别确认；回归边界内命中、边界外躲避、侧移、墙体遮挡和前摇无伤害。增大长度不自动授权增大宽度或伤害。

## 预览与收尾

- 读取实际渲染尺寸后裁切，避免沿用上一台机器的固定像素框；检查完整 GIF 的总时长、关键接触姿态和所有攻击帧。检查灯须在记录中标明。
- 保留最终可编辑源、必要上游输入、来源合同、构建脚本、最终 GIF 与验证 JSON；清理可再生成的帧目录和编辑器备份前，先查输入引用。清理操作记录具体路径和回收量，不把旧文件名或 preview 后缀当作废案判据。

工头当前证据：`tools/ai-gen/foreman-retopo-v08-20260906/README.md`。同源连边的肩部 90° 测试中，P99 为 2.375→2.250，超过三倍拉伸的边为 31→20；仍有残余拉伸，不能写成彻底修复。

## 工头 V11：区分贴图、蒙皮与动作连接

- 抬臂露出块状明暗时，同时查看袖子原始 albedo、平滑/自定义法线和相同姿态的网格。V11 的一部分块状外观直接来自旧袖子贴图，细分或重刷权重不能修掉；仅为左袖重映射到完整布料区域，保留手掌 UV，并单独调整材质，避免连带改变右臂。
- 前臂/手掌权重沿各自骨轴投影，再沿真实网格邻接平滑；不要把世界高度分带当作通用肘腕定位。袖口桥接需要共享边界驱动，新增细分不应破坏这一约束。SIMPLE 细分增加变形采样但不等于重建手指拓扑。
- IK 过渡若分别插值骨头位置与旋转，可能使父骨尾和子骨头分离。导出重导入后量测连接误差，保持肩—肘—腕链一致，再看抬臂、行走及死亡。不要仅以手部目标位置正确判断整条链正确。
- 绳鞭松手使用地面摩擦、重力和长度约束时，瞬间位置投影可能被下一步速度估算放大成弹飞；使用柔和避让，检查约束注入速度、最终落点及实际蒙皮穿地。节点分离/侧向避让是近似碰撞，不等于完整网格碰撞。固定烘焙死亡从盘鞭姿态开始，不保证任意攻击中断时自然过渡。

## 接入与批量生成

- 激励要覆盖实际场景中的敌方对象，不能只遍历工头父节点的直接子节点；排除非敌方、死亡及状态免疫对象。确认 Buff 写入的参数层级与倍率读取一致（此例为 opts.meta），测试自定义倍率、重复刷新不叠乘和到期恢复。
- 分帧创建测试角色时，AI 可能在队友入场前就释放一次性号召。角色入树后暂停物理处理，全部入场后一起恢复，再验证每个队友是否真正获得 Buff。
- 替换动画后同步实际步态参考速度、导入采样率、动作名和时长；业务命中时钟不因视觉混合延后。废弃试玩场应连同旧传送门引用及测试入口一起更新，历史脚本标明失效。

V11 证据：`tools/ai-gen/foreman-v11/` 的最终源文件、预览和验证数据，以及 `docs/foreman-zombie-integration.md`。未新增逐指骨架；归档中的修复参数不是其他人形怪物的默认值。
