# 可替换部件的原装安装端与连续过渡

适用武器护手、握把、配重锤等尺寸受宿主约束的模块。2026-09-19 寒晶剑拆分/握把案例获用户接受；游戏槽位与存档规则转武器技能。

- 先确定统一坐标、单位、轴向、模块 pivot 与实际连接面。保存边界顶点环及面角 UV、法线、顶点色；包围盒不能替代安装面。
- 从已接受宿主复制安装端，在端面以外重建。切割面跨三角形时插值所有面角属性；只封新切口。新模块顶点相对安装点归零，组装偏移只施加一次。
- 连接两种截面时用连续过渡网格，匹配两端位置与轮廓斜率；不将整体移动、缩放或装饰套圈当作接缝修复。新面要有有效 UV 与一致法线。
- glTF 因 UV 接缝拆开的同位置点，需保留面角属性再焊接需要连通的几何，随后减面；先大幅减面可能把安装口变成碎片。
- 采用原装 UV0 与金属 donor UV1 混合时保留顶点色通道。只在接头内侧渐变到统一金属纹理区域，避免把源剑身的蓝色块拉成整个连接颈。
- 保留端面形状与握持区；长件只延伸中段，末端原装截面平移到新安装位置，不能缩放出一套不兼容的接口。
- 有明确手部接触约束、形状规则的握把可选择 Blender 精确建模；参考图决定设计语言，宿主原始截面决定装配尺寸。保持已选制作路线，不强制重新跑生成器。
- 使用 5080 时把几何档位、结构网格、纹理导出网格、母版/游戏面数和贴图分辨率分别记录。寒晶配重修订中，512 几何配 1024 纹理导出网格造成错配；修订采用匹配网格，保留原 seed/视图。
- 水晶、金属支架、皮革及银色嵌条用明确材质分区。蓝色半透明水晶的金属度应为 0；分区错误不会因替换颜色或提高贴图分辨率自动修好。
- Blender 新网格先设平滑，再设自定义法线；FBX 导入保留作者法线，切线按最终 UV 生成。发现着色问题按用户授权定位，不把导入成功当作视觉验收。

## 替换后露出的宿主切口

配件自身没有开放边，不等于装配后没有通孔。隐藏原厂件时，还要考虑宿主留下的切口、转接圈内孔与新支杆之间是否存在可见通道；薄壁圆环是闭合网格，也可能完全没有封住机匣。

以宿主真实切口顶点环制作闭合端板和过渡肩，接头端面与新支杆有明确封口关系。只处理本次拆分暴露的区域，保留枪口、排气孔、导轨间隙等功能开口。多个枪托共用错误转接件时，逐个适配该宿主的所有在用变体；原厂件恢复也应保持原接口。

局部重建按面角保留 UV0、附加 UV、材质索引和自定义法线；BMesh 遍历顺序中的 loop.index 未必已更新，不直接用它索引原法线数组。新增补面单独生成有效 UV/法线，再按原材质槽名称恢复 UE 绑定。

2026-09-20 M16 四种枪托的旧空心转接圈未覆盖原厂 106 边机匣切口；按该轮廓重做闭合端板、过渡肩和后端面后获用户确认。另有三个不足 0.31 mm 的局部微裂缝，只处理对应簇，未全局粗焊接。106 点和毫米值是该模型参数，不是其他枪托标准。源码与恢复说明见宿主 `Docs/Weapons/m16-publication-20260920.md`。

交付可编辑源、导出件、PBR、实际模型 UI 图标、安装契约与导入脚本。UI 图标属于制作资产；不因此追加游戏验收渲染。保留在用母版和重建依赖，按 [近战模块标准](../../ue5-weapon-workflow/references/modular-melee.md) 接入。
