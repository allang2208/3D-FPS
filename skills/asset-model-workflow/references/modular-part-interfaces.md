# 可替换部件的原装安装端与连续过渡

适用武器护手、握把、配重锤等尺寸受宿主约束的模块。2026-09-19 寒晶剑拆分/握把案例获用户接受；游戏槽位与存档规则转武器技能。

- 先确定统一坐标、单位、轴向、模块 pivot 与实际连接面。保存边界顶点环及面角 UV、法线、顶点色；包围盒不能替代安装面。
- 从已接受宿主复制安装端，在端面以外重建。切割面跨三角形时插值所有面角属性；只封新切口。新模块顶点相对安装点归零，组装偏移只施加一次。
- 连接两种截面时用连续过渡网格，匹配两端位置与轮廓斜率；不将整体移动、缩放或装饰套圈当作接缝修复。新面要有有效 UV 与一致法线。
- glTF 因 UV 接缝拆开的同位置点，需保留面角属性再焊接需要连通的几何，随后减面；先大幅减面可能把安装口变成碎片。
- 采用原装 UV0 与金属 donor UV1 混合时保留顶点色通道。只在接头内侧渐变到统一金属纹理区域，避免把源剑身的蓝色块拉成整个连接颈。
- 保留端面形状与握持区；长件只延伸中段，末端原装截面平移到新安装位置，不能缩放出一套不兼容的接口。
- 有明确手部接触约束、形状规则的握把可选择 Blender 精确建模；参考图决定设计语言，宿主原始截面决定装配尺寸。保持已选制作路线，不强制重新跑生成器。
- 使用 5080 时把几何档位、结构网格、纹理导出网格、母版/游戏面数和贴图分辨率分别记录。寒晶配重修订中，512 几何配 1024 纹理导出网格造成错配；修订采用匹配网格，保留原 seed/视图。
- 水晶、金属支架、皮革及银色嵌条用明确材质分区。蓝色半透明水晶的金属度应为 0；分区错误不会因替换颜色或提高贴图分辨率自动修好。
- Blender 新网格先设平滑，再设自定义法线；FBX 导入保留作者法线，切线按最终 UV 生成。发现着色问题按用户授权定位，不把导入成功当作视觉验收。

## 相邻活动件与独立形变后的接缝

- 盖壳与机匣等相邻件使用同一局部坐标和一份接缝截面定义，同时区分外边、内壁、厚度与可见间隙；保留枢轴、骨骼和手部接触区域。
- 原始切割边相同，只能说明拆分时共边。分件经历不同高度映射、缩放或独立平滑后，应以最终安装端作为制作约束，不能继续直接拼接。
- 开口同时包含宿主的上沿、侧壁和可见托面。拆分封板不是机构内部，须与活动件内侧共同处理；新过渡应连接实际边界环，不增加遮盖套件掩盖穿插。
- **201 FitFinish37 为用户否决的接口案例**：共享截面公式仍因边界样本外推产生尖刺，盖壳存在未闭合边且外形不符参考。不要恢复其机匣/盖体；保留仍被引用的涂层与其它部件。后续 ReferenceRepair38 记录见 `Docs/Weapons/lmg201-reference-repair-20260929.md`，后台保存不等于用户认可。
- 修正以相邻件真实边界和参考轮廓为约束；有限壁厚、端壁与翻边应连接成实际表面，不能靠重叠投影或双面材质补漏。局部线性宽度映射只适用于已确认的有效域，不把同高度全部顶点当成同一截面。

## 替换后露出的宿主切口

配件自身没有开放边，不等于装配后没有通孔。隐藏原厂件时，还要考虑宿主留下的切口、转接圈内孔与新支杆之间是否存在可见通道；薄壁圆环是闭合网格，也可能完全没有封住机匣。

以宿主真实切口顶点环制作闭合端板和过渡肩，接头端面与新支杆有明确封口关系。只处理本次拆分暴露的区域，保留枪口、排气孔、导轨间隙等功能开口。多个枪托共用错误转接件时，逐个适配该宿主的所有在用变体；原厂件恢复也应保持原接口。

局部重建按面角保留 UV0、附加 UV、材质索引和自定义法线；BMesh 遍历顺序中的 loop.index 未必已更新，不直接用它索引原法线数组。新增补面单独生成有效 UV/法线，再按原材质槽名称恢复 UE 绑定。

2026-09-20 M16 四种枪托的旧空心转接圈未覆盖原厂 106 边机匣切口；按该轮廓重做闭合端板、过渡肩和后端面后获用户确认。另有三个不足 0.31 mm 的局部微裂缝，只处理对应簇，未全局粗焊接。106 点和毫米值是该模型参数，不是其他枪托标准。源码与恢复说明见宿主 `Docs/Weapons/m16-publication-20260920.md`。

交付可编辑源、导出件、PBR、实际模型 UI 图标、安装契约与导入脚本。UI 图标属于制作资产；不因此追加游戏验收渲染。保留在用母版和重建依赖，按 [近战模块标准](../../ue5-weapon-workflow/references/modular-melee.md) 接入。

## 跨枪套用供弹塔：用线性过渡，不要 smoothstep 仿射（A762 大弹鼓 2026-09-25）

A762 大弹鼓是拿 AKM 大弹鼓套壳的：供体塔身是外枪的，接 A762 弹匣井时把塔身上段（z 45→75 mm）做了仿射重映射，并用 smoothstep 渐变。结果是**渐变带出现折角**，同时把 67 mm 深的塔身压到 58 mm，而 A762 弹匣本身是 72 mm 深——既折角又塞不满井口。用户看到的"衔接处扭曲"就是它。

- **判据**：把供体、当前件、目标枪自己的弹匣都换算到同一个弹匣骨骼坐标系，逐高度切片比中心与宽深。折角来自"渐变的形状"：`t` 用 smoothstep 时中心线是 S 形；**同一组首末值改成随 z 线性**，塔身就是一根直的斜棱柱，配合面位置不变但没有折角。
- **目标截面用目标枪自己的弹匣外包络**（它本来就通过弹匣井），不要手拍缩放系数。本案把塔身撑到"弹匣包络 +1.5 mm"。
- **前后方向要留一个不劣于现状的钳制**：塔身前表面不得比当前出货件更靠前（当前件已验证不穿机匣），重建只向后延伸填满井口。这样既修形状又不引入新的穿透。
- **先分辨"穿透"是不是问题**：机匣网格通常没有真正挖出弹匣井，弹匣本身就穿在机匣实体内（本案原厂弹匣深 14.3 mm）。把供体与已验收件、原厂弹匣三者一起量，才知道多少是隐藏的正常交叠。
- 可选的更干净解是**整体后移鼓体**让塔身竖直，但那会同时改变换弹动画里手握鼓的位置，要先确认再做。
- 案例入口 `SourceAssets/A762DrumNeck20260925/`（诊断、重建、验证与渲染），记录见 `Docs/Weapons/a762-drum-neck-20260925.md`。

## 原件恢复与接颈保留（201 R58，2026-10-01）

- 用户否决多轮变形后的握把时，从原始纹理母版恢复握持区。先保留 UV 接缝的面角属性，再焊接需要连通的同位置点；不要继续对破碎中间件减面，也不要用全件体素重建修局部接头。
- 在同一枪根坐标中，以源握持区和现用宿主安装端求刚体定位。重做上端切口到真实安装轮廓的连续连接颈，保留下半部尺寸、UV 与作者法线。接触位置改变时单独处理手部适配，不靠整体拉宽掩盖误差。
- 截面含贴近的小岛时，度数为二的边图假设可能失败；提取实际平面边界环并分别处理，不能把所有同高度顶点串成一圈。新面独立 UV，维持旧材质槽、遮罩通道、pivot 与单位契约。
- 只局部处理零面积面、零法线与塌缩 UV；导入后的近零切线提示要单列，不用全局重算法线改变原件。高密度母版恢复不代表游戏面数或性能已合格。

案例：`SourceAssets/LMG20120260927/RearGripRestore58/`。三款正式网格已保存，仍有切线/副法线提示，用户尚未实机验收；不把这一结果沉淀为已经成功的视觉标准。
