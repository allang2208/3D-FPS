# 螳螂 M27：双镰、隐身与追击衔接

当前设计名为 **螳螂 M27**，稳定 ID `MantisM27`，F6 使用 `/Game/Monsters/MantisM27/BP_MantisM27`。本节是该角色案例，不替换其他怪物的数值或导航标准。

## 当前制作链

保留 Meshy 原始模型与三视图、ProductionV1 → BindingV2、ClawV3、PounceV5 → PounceV6：后续作者仍读取这些旧版。当前为 RunV4、ClawV16、PounceV11、CloakV1、CombatV15 和 AudioV1。ClawV14 是用户认可普攻的恢复基线；ClawV16 横劈强化及 AudioV1 已保存、仍待用户体验，不能扩大为用户已认可。

详细恢复顺序、废案归档与公开边界见工程 `Docs/Monsters/MantisM27Publication20261007.md`。模型、密集权重/动作样本和 UE 包留本机；Epic Paragon Khaimera / Mutant3 派生动作不是 CC0。按依赖保留源，不凭版本号清理。

## 镰刀方向与发力

- 仅让肩到刀尖朝向目标，不能决定刀刃翻转角。应从实际刚性刃面拟合平面，再用根、尖、曲线鼓出侧建立带符号的双轴坐标，区分刃口与刀背。
- 从肩部调整整条臂链，保留局部肘腕、骨长和权重。左右刀使用真实外廓约束，横过身前时可让主刀在前、副刀在后，不能只把尖端分开却让刀体重叠。
- 横劈有蓄势、快速切入、制动和回震，腰肩带动而非整段等速。ClawV16 保留 V14 的 0.65 s 总时长和 0.25–0.30 s 接触窗口，新增横向切削平面与连续前后分区；具体参数留在作者脚本。
- 大角度方向混合先将四元数置于同一半球，避免轴角/正负表示在 180° 边界产生假旋转。PounceV9/V10 是已否定的飞扑方案，不继续叠加修正。

## 隐身与移动目标

- 首次接敌与受击半血各一次隐身，回血达到阈值后锁定“准备攻击”状态，避免稍后掉血又退回无限绕圈。攻击破影时先确定双倍倍率，再改变隐身状态，表现和伤害读同一个事件。
- 起手、停步及命中范围从同一基础距离与倍率计算，包含目标胶囊；近战起手要覆盖飞扑下限，避免两者之间留下决策空档。
- 移动目标使用实时目标脚底位置。Pursue→Attack 交接由真正成功的攻击负责停步；一次过期的 CanAttack 事实或失败起手不能把追击反复刹停。
- 冷却期间继续接近移动目标，停距深入起手圈；保留导航投影、遮挡、楼层、控制和返回分支，不以扩大无视遮挡伤害来掩盖接敌问题。
- 致残/流血从已接受伤害入口处理；服务端每次命中只抽一次流血，客户端镜像结果，持续伤害不能再次触发自身。

声音制作使用 [怪物技能音效](monster-audio.md)。历史方向读回、必要构建与用户游戏体验是不同证据；没有重新测试时不复用旧数字声称当前通过。
