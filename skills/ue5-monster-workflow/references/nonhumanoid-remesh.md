# 非人形减面：保留结构、动作与尸体绑定

适用于已有认可结构和动画、用户返回 Meshy 减面模型后的接回工作。M08/M09/M10 的 AnatomyRepairV5 与 M14 的 TeethRemeshV4 是 2026-10-07 已保存案例，仍待用户游戏体验；不是视觉或性能通过模板。

## 输入与制作顺序

- 先分清减面输入来自 Meshy 原始模型还是当前加工母版。原始模型减面不会包含后来制作的连续腕肩、开口、内壁、独立牙齿和支撑蒙皮；以当前母版为结构及骨架依据，用户低模作为可复用主体。
- 用户要求 Blender 先行时，离线完成几何、各级 LOD、UV、权重、修形及导出，再占用 UE 短批次导入。不要在共享 UE 中运行长时间减面；后台 commandlet 同样占用接入窗口。
- 保留生产骨架、参考姿态和动作引用，转移低模权重与已有修形。重导网格不等于重新制作动画；不要顺带覆盖已调好的蓝图速度、攻击、声音或 AI。

## 小结构不能按全身比例减面

- 牙齿要包含内外表面、牙根、牙龈和内口，不能只按朝向提取尖端面。替换完整缺损口部时去掉旧重叠表面，并保留各 LOD 相同的连接边界。
- UV 拆分会产生位置相同而拓扑分离的顶点。减面前可焊接几何，保留逐角 UV；独立简化接缝两边会造成远级裂口。材质边界与开放口缝需固定。
- 膜片、眼冠、钩指、爪与牙分别分预算，保护极值和连接点。源模型存在真实缺口时，参考认可表面恢复位置及 UV，再做远级；提高全身目标面数不能自动修复缺齿。
- 不同来源表面使用对应的 UV/PBR。新主体使用减面包配套纹理，恢复部位使用原材质；保留 FBX 重导后的材质槽别名以及蓝图覆盖的适配。
- LOD3 可能因封边、材质交界或薄结构保留较高面数。记录实际三角数和原因，不为目标数字损伤结构，也不把输入“十万级”写成最终准确面数。

## 活体与软体尸体是两套绑定

活体导入后导出精确 UE 坐标表面，再离线投射到当前认可软体代理，重建尸体骨架、网格、DataAsset 和动态法线材质，接回正式死亡引用。保留代理节点/四面体不表示旧表面嵌入仍有效。

活体骨架的 LOD 不能直接用于软体尸体。案例尸体只保留已重绑的 LOD0；若以后添加尸体远级，应从完成软体绑定的表面制作，保持完整软体骨架，并使用共享低频 LOD 刷新。不能把共享代码支持多 LOD 描述成当前尸体已有多 LOD。

## 重建与归档边界

工程工具链为 `Tools/MonsterAI/read_blender_geometry_sources.py` → `author_meshy_remesh_v3.py` → 局部 V4/V5 作者 → `Invoke-MeshyRemeshV3.ps1` 分批导入 → `embed_meshy_remesh_v3.py` → 尸体保存绑定。V4/V5 仍导入 V3 helper、读取 V3 Blend/材质元数据；V3 不是可以整包删除的废案。具体恢复顺序和本机输入见工程 `Docs/Monsters/m-series-publication-20261008.md`。

保存回执说明制作与落盘；用户要求的几何排查、游戏测试和性能测量分别记录。默认不追加测试或渲染。
