# 成品怪物的待机呼吸增量

适用于给已有怪物加弱呼吸和微动，保留原有 Idle、攻击、受控和死亡动作。当前实例见 `Docs/Monsters/idle-breathing-20261002.md`，覆盖六个基类及其派生的 13 个成品刷怪条目，明确跳过盲祷者。

## 接入与状态

- 现有动画求值后，在 `USkeletalMeshComponent::FinalizeBoneTransform()` 添加增量；用默认骨骼组件派生类型接入，不另加 Tick、计时器或 AI 时钟。
- 只有物种自己的严格 Idle 枚举、近零实际速度且落地时淡入；死亡、受控、击倒、物理模拟、隐藏、暂停动画或关闭 Actor Tick 时关闭。不能仅用“没有移动”认定待机。
- 以当前未加呼吸的局部动画姿态重建组件空间基线，不能反复修改上一帧显示结果造成累积。骨名与后代索引按网格缓存，换网格后重新映射。
- 选胸背、掌面或体节，弱尺度扩张与旋转错相；保留 root、骨盆、支撑脚、胶囊和道具手臂。对子骨是否继承增量显式选择，避免胸腔呼吸拖动持物手。
- 每个实例使用稳定种子、相位及少量周期差；主呼吸加弱次谐波、连续 Perlin 噪声。不要逐帧随机抽值，也不要统一振幅套用人形、犬类和软体。
- 本例入场／退出时间常数为 0.35／0.12 秒，采用指数插值；各物种周期与幅度是本次制作起点，不是已获视觉认可的标准。

## 来源与交付

GitHub 方法参考及许可链接保存在专项文档：AiGameKit Animator3D 和 Dust3D 为 MIT；GPL 的 Procedural Multi-Rig 仅作方法参考，未复制代码。该组件为工程独立实现。

源码与默认组件接入、正式 DLL 构建、游戏观感分别交付。本例不创建动画资产；已有后台构建完成，未启动游戏或做视觉测试。后续枪击反馈是独立功能，发布呼吸时不能顺带提交它或未发布的联机重构。
