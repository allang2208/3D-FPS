# 人形击飞、起身与受限布娃娃

FPSGAME 接入记录：`Docs/Monsters/humanoid-knockdown-20260926.md`。2026-09-26 制作版本，尚未经过用户视觉/玩法/性能测试，不是已认可动作模板。

- 使用 `ANurseZombie` 共用 `UHumanoidKnockdownComponent`；`UMonsterCombatComponent::ReceiveKnockdown` 为击飞入口。目标是护士、胖子、突变体 3、重建巫婆。非人形和旧巫婆骨架不强套动作。
- 落地物理姿态用快照保留；骨盆朝向区分仰躺与俯卧，起身前重新定位胶囊并转换快照根到新坐标；起身仍属于受控状态。死亡可以从击飞/倒地/起身直接接续，不能重播站姿死亡。
- 已有 Mesh2Motion CC0 `Hit_Knockback` / `LayToIdle` 是本次源动作。前者有循环回首帧，动画倒地仅用前半段；后者是仰躺起身。`ProneToIdle` 为本轮制作的接地翻身前缀加仰躺起身，如实区别于独立俯卧动捕。
- 来源、许可证、FBX、Blender 和导入收据在 `SourceAssets/HumanoidKnockdown20260926`；12 个适配片段在 `/Game/Monsters/HumanoidKnockdown`。胖子/突变体按原绑定重建骨长，不能直接交付会缩骨的原生重定向结果。
- 物理质量包括资产中的膝肘/躯干范围、质量分配、阻尼、相邻体碰撞和死亡姿态交接；只提高 solver 次数或使用强姿态驱动不能代替关节制作。运行时不得用逆缩放参考骨架重写人体关节 `SetRefFrame`，该接口不会重走实例化缩放；辅助根使用当前刚体厘米坐标重新连接。普通死亡使用一致下落速度，关闭关节瞬移投影。修正记录 `Docs/Monsters/humanoid-ragdoll-handoff-fix-20260926.md`，仍待用户测试。
- 世界级预算同时限制活跃角色和刚体总数，尸体另设准入额度；预算不足用动画倒地回退，已稳定尸体定姿释放物理和布料计算。当前初值 8 只 / 128 刚体 / 4 个新尸体准入，不是硬件吞吐保证，空中活体死亡可暂时超出尸体准入数。
- 普通枪击、持续伤害和轻击不因接入共用组件而自动增加击飞；接入具体攻击时显式确定触发条件、强度、体型系数和免疫标签。快照与动作只负责表现，伤害和控制仍使用原权威时钟。
