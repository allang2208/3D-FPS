# M-25 涡电匣：低矮宽体、并行攻击与游戏 LOD

用于继续 M25，或处理低矮宽体怪物的咬击漏伤、高面蒙皮网格优化和独立施法通道。

## 高模与游戏网格

- 本例早期将 6,524,740 面制作高模直接作为游戏网格，遗漏游戏预算和 LOD。认可造型并不等于完成游戏资产；继续制作时明确最近视距、屏幕占比、同屏数量和各级预算，再按授权执行减面。不要把本例预算推广成所有怪物的硬上限。
- 最终四级为 349,998 / 119,998 / 39,996 / 9,984 个三角形，各一个材质区段、148 骨 UE 骨架；光追最低 LOD1。保持现有 UV/PBR、动画骨名、嘴部弱点、物理资产和蓝图引用。减面重算顶点权重，每点最多四骨，本轮未新烘焙法线；不能声称逐顶点不变或从面数降幅推算 FPS。
- UE 5.8 Python 只写 `lod_settings` 指针不足以把参数应用到 LODInfo；本例采用 `mesh.call_method('SetLODSettings', (settings,))`。新建 LODInfo 后会继承前级配置，需要再次应用完整分级参数后重建。
- 从减面副本导出 FBX、再导入独立游戏网格，使游戏网格导入源不携带百万面高模。骨骼 FBX 导出器内部依赖 RHI；本机使用 `-AllowCommandletRendering -RenderOffscreen` 并关闭材质烘焙，`-nullrhi` 曾在 MeshObject 处断言。离屏生产不等于执行视觉验收。

## 攻击与运动合同

- 近战与魔法各自维护权威时钟、状态、冷却和单次伤害，不用一项全局 Busy 锁互相阻断。共享 BT 负责选择；近战范围内优先起手，正在蓄力的魔法继续。受控／死亡同时取消两通道，不能在伤害回调打断后继续执行。
- 撕咬原片段 1.4 秒，2 倍播放后为 0.7 秒，原接触窗 0.60–0.76 秒对应实时时间 0.30–0.38 秒。速度、接触窗与混合时间共同缩放；保留跨越接触窗的帧，不另加第二套伤害计时。
- 宽嘴扫掠球会进入地面。本例嘴部离地约 50 cm、接触半径 80 cm；把 WorldStatic 和玩家一起取最早接触会被地面抢占。玩家根碰撞体候选与遮挡分开：Pawn 球形扫掠找玩家，身体到嘴和嘴到玩家胶囊轴分别用 Visibility 线段阻挡墙体／道具。初始重叠的 ImpactPoint 不作为可靠遮挡终点；仍保留前方角度、范围和一咬一次结算。
- 雷枪从背部上方蓄积，最后 0.25 秒锁定窗按玩家速度计算提前量，位移封顶并处理墙体；普通闪电 CD 3 秒、雷枪 20 秒，基础魔攻 60，倍率 1 / 2.5。此项目沿用瞬发电束，不把锁定提前量当作实体弹丸飞行解算。
- 移速 55 cm/s、转向 75 度/s；动画源速度仍是 16 cm/s，按实速相除使蠕动周期跟随移动。提高移速时不要同时提高这个分母，否则会抵消动画加速。

## 奖励、特效与恢复

- 客机的击杀在服务器结算；`IsLocalController()` 会漏掉远端玩家。M25 保留玩家控制器归属门槛，通过 `ColdSteelSkills::AwardKillByOwner` 选择服务端影子档案／本地档案，并沿用公共去重；不要直接给 GameInstance 单例档案加奖励。
- 背部电流按九个电极跟随，复用固定数量组件，画面外／远距离降频，补光不投影。魔法视觉 actor 不再次结算伤害；专用服务器发布雷枪参数即可，不应依赖视觉材质加载来决定发射。
- 旧版本不是自动废案：`RigV01` 被 `BiteV01` 读取，`BiteV01` 被受击／死亡作者读取，BackElectricV01 建立 V02 要更新的系统；这些阶段留在重建链。旧快照、未提交 TRELLIS 草案和过时状态已进入 `trash/m25-retired-20261005`，正式重建不读取 trash。
