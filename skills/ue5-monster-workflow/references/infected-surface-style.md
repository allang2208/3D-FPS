# 怪物感染材质：统一规则与保留角色差异

适用：已有骨架、动作及玩法的怪物换皮、伤口精修、同场景美术风格协调。2026-09-19 用户允许继续并接受本轮收尾；制作、导入和保存已完成，未追加画面、动作或游戏测试。

## 先定位差异来源

- 已有 BaseColor / Normal / Roughness 不代表风格一致。大面积饱和色、均匀亮度、全身同样湿亮、夸大的高频凹凸，都会让已有 PBR 仍像塑料或卡通雕塑。
- 统一皮肤、湿组织、脓液、干痂、布料的视觉含义；保留虫皮、毛皮、人形皮肤各自的色彩和结构。不要把同一伤口贴图、噪声尺度或绿色直接套满所有角色。
- 材质先解决颜色、细节尺度、反差和干湿区域；只有轮廓、关节体块或表面结构本身需要改变时才修形。已有认可骨架不因换皮重新绑骨。局部同拓扑修形也需保留 UV 和权重；2 mm / 6 mm 是本例手脑与毒蛆的限定值，不是通用尺寸标准。
- 素材库的有机皮肤可提供浅层 Height / Roughness / AO，但厚重结节、大红块不宜直接铺满整只怪物。法线的坐标空间和绿通道约定需沿用源连接，不能把不同投射方向的切线法线直接混色。

## 烘焙与共享参数

以源模型静止姿态生成分区，烘焙到该模型自身 UV；运行时随蒙皮运动。需要图案固定在皮肤上时，不使用会滑动的世界坐标投射。

本工程共用 `/Game/Monsters/Shared/InfectedSurfaceV1/M_InfectedSurface_V1`，各角色用独立材质实例和贴图：

| 数据 | 约定 |
|---|---|
| BaseColor | sRGB；保留各角色语义分区 |
| Normal | DirectX；Normalmap 压缩，已烘焙负 Y 时不再翻绿通道 |
| ORM | 线性；R AO、G Roughness、B Metallic；有机表面 Metallic 为 0 |
| TissueMasks | 线性；R 皮肤、G 湿组织、B 干痂 |

`SkinTint` / `ClothTint`、`NormalStrength`、`WoundWetness`、干皮与痂的粗糙度偏置、干湿 Specular 提供实例级调整。怪物差异主要在贴图与分区，不能仅靠全局调色。本例 Default Lit 不透明表面不包含真实皮肤透射；虫皮薄膜感来自颜色、细纹和局部粗糙度。

UE 5.8 启用 Substrate 时，母材质需连接 `MaterialExpressionSubstrateShadingModels` 与 `MP_FRONT_MATERIAL`，只连接旧 BaseColor / Normal 等输出不能替代前表面连接。复用已接受母材质时创建新 MI，不为另一只怪物重置共享母材质。

## 僵尸犬：毛皮、伤口与随机分布

当前 V5.1 的细节见 [狼换皮案例](wolf-reskin.md)。可复用的关键点：

- 创面、裸皮、干痂、血污和毛发移除使用独立遮罩。血污可以延伸到残毛，但残毛不应整层混成肉色。外围碎毛和内部清毛分开控制。
- 外层毛片与身体有距离，定位图应记录其下方身体最近表面点。两层用同一伤口坐标，避免伤口与脱毛区域错位。定位图记录静止姿态坐标，非镜像 UV 防止左右伤口复制。
- 表面坐标图不能像普通颜色贴图那样跨 UV 岛生成平均坐标；本例半浮点、无 mip、常驻。伤口细高度使用 EXR，遮罩保留细边缘，不把所有语义都压进一张颜色图。
- 以三角形真实面积加权选面，再用平方根重心坐标均匀采样；有限尝试、部位容量及间距限制保持生成成本有界。固定种子在同一算法版本内复现，不承诺跨算法版本位置一致。
- 每只犬独立 MID，布局只在种子、数量或表面数据变化时重算，无需 Tick 重抽。`SaveGame` 字段不等于已经实现世界持久化或多人同步。
- 要让伤口更明显，优先调整数量、图案长短轴及类型占比；不要同步放大微小高度，把细节重新变成粗硬凹坑。V5.1 的 6～8 是目标数量，受间距和尝试上限影响可少于该值；扩图后也不承诺图案绝无重叠。

## 接入与保留边界

- 只改材质时沿用现有网格；修形时导入独立网格、指定既有 Skeleton、关闭动画导入和参考姿态更新，再引用原 Physics Asset。蓝图只切换外观所需字段，不重写状态机、攻击窗口或 AI。
- 修改材质槽时读原 `SkeletalMaterial` 结构并只改 `material_interface`，保留 slot/imported slot 名及其他字段。UE Python 的编辑器字段如 `imported_material_slot_name` 用 `get_editor_property` 访问。
- 已打开编辑器中的资产通过当前会话修改并保存；不要用离线命令覆盖其已加载版本。确认编辑器关闭时可用 commandlet 保存。PIE 中部分 EditorAssetSubsystem 调用会失败，不能据此认定资产在磁盘缺失。
- `authoring_manifest`、`ue_import`、`activation` 分别记录制作、导入与保存；不把这些标记写成画面或游戏测试通过。遵守用户默认不主动测试的规则。
- 归档以当前引用和重建依赖为依据。僵尸犬无毛 V2 已否决，可归档；V1/V3/V4 仍提供 V5 的网格、细皮肤、分层贴图和表面数据，不能按旧版本号一并移走。旧材质作为明确恢复点时也仍有用途。
