# 韧性条、基础削韧与控制门槛

用于 FPSGAME 的怪物韧性数值、破韧恢复、击飞/击倒/击退和显式眩晕。当前实现与数值为2026-10-04用户确定，已构建，未游戏验收；这不是其他游戏的通用平衡规则。

## 数据和阶段

Content/ColdSteelData/monster-toughness.json 按真实物种与实例品阶配置，正值限定200/400/600/800/1000，普通与杂鱼默认0。不能因为某物种有精英列便赋给普通实例。未列高阶物种用精英200、领主600、Boss1000；已有明确配置按物种覆盖。JSON按 GameInstance 缓存，权威生成时读取，不在命中或Tick解析。

MonsterToughnessBar.cpp 的阶段为 Guarded → Broken → Recovering → Guarded。精英/领主/Boss破韧窗口3/4/5秒，后续线性回满4/6/8秒。破韧命中可短硬直，但不续窗口；回韧期仍扣血、不重复削韧、不打断回满。未破韧脱离有效削韧3秒后每秒恢复上限10%。归巢重置当前条与阶段。

用 FMonsterToughnessState 一次复制累计值、上限、阶段、结束时刻和破韧次数；客户端按服务器时钟显示回满，不能从没有复制的本地字段画条。显式眩晕单独复制到期时刻，普通受击事件不能把历史最长时长重新加到当前时间。

## 削韧与位移

MeleeToughnessTuning.h 定义重击400、旋风200、独立上挑300基础削韧；这已经是韧性单位，不再乘生命伤害、暴击、生命防御或攻击形式基础系数。仍乘对应韧性抗性与配件/动作削韧增益。虎啸6秒内三抗为0，再乘1.25。普通攻击、快速近战和次生剑气保留各自算法；游龙升龙仍是普通第三段。

统一权威命中按动作语义选基础值，再调 ApplyHitWithToughnessScale；不要上传客户端任意基础削韧数值。旋风沿既有目标去重，每次施放每个目标只算一次。

CanReceiveLaunchOrKnockdown 仅允许上限0或正处于Broken；Recovering即使显示接近0也不允许。命中先削韧，再判断击飞，因此打破条的这一击可击飞。人形、手怪底层Launch也必须使用同一门槛。普通击退不受韧性门槛限制，保留碰撞、明确免疫标签和原位移条件。

显式眩晕/冻结、物理倒地与破韧使用独立期限。击倒不清掉已有显式眩晕；已倒地人形收到眩晕也须登记时钟。零重力悬吊怪被击飞时，限时清除冲量并恢复原移动模式，避免无限漂移。
