# Behavior Tree 怪物 AI 约定

用户于 2026-09-11 选定 Behavior Tree 统一怪物决策。正式实现和重建命令见工程 `Docs/MonsterAIWorkflow.md`。

## 从行为设计到接入

1. 先读当前控制器、Blackboard、执行组件、角色攻击时钟和源动画。写出行为表：模式名称、进入条件、目标/位置来源、优先级、退出条件、能否打断、冷却与失败处理。把期望看到的表现写成测试场景。
2. 区分感知输入与动作模式：视觉/听觉/受伤改变已知事实；追击、调查、攻击等由树选择。不能把“听见枪声”直接写成绕过控制和死亡判断的 MoveTo。
3. 为新模式选择最小扩展位置：新事实进入 Blackboard；组合规则放树分支/Decorator；短期动作放 Task；伤害、控制和技能时序留在执行组件/角色。只有重复出现的差异才抽公共接口，不预建所有怪物体系。
4. 定义中断合同：死亡最高优先，受控中止移动及可打断攻击；技能结束、任务 Abort、目标失效均释放自己拥有的移动/动画/输入控制。不可打断攻击也必须允许死亡终止。恢复时重新评估事实，不固定退回 Idle。
5. 配置导航体型和目标接受距离，先用独立障碍场景验证有效路径、实际位移和阻挡；再放入村庄检查坡地、狭窄通道和返回位置。路径不可达时按本模式选择等待、重新规划或放弃目标，并验证不会持续顶墙。
6. 在现有怪物上完成一个完整循环，再接入第二种怪物检验复用。数值保留来源和单位；每次只改相关蓝图/实例/动画引用，保存回读后启动新游戏进程。
7. 验收覆盖正常循环与抢占：看到/听到目标、最后位置调查、目标消失、路径失败、前摇被击中、连续控制、恢复攻击、死亡取消伤害。对已实现范围记录通过/失败和实拍；尚未实现的巡逻、搜索或飞行分支列为后续工作。

行为表示例（设计模板，不代表所有分支已实现）：

| 模式 | 进入条件 | 退出与抢占 | 验收重点 |
|---|---|---|---|
| 追击/调查 | 有目标或最后已知位置 | 进入攻击范围、记忆过期、受控、死亡 | 绕障、到达后重新决策 |
| 攻击 | 距离/遮挡/冷却满足 | 技能完成、允许的打断、死亡 | 接触帧、去重、取消后不补伤害 |
| 受控 | 硬直或眩晕触发 | 到期或死亡 | 不播放 Idle、连续命中不缩短控制 |

**枪械默认不硬直（2026-09-17 用户规则）**：枪械伤害走 `ColdSteelSkills::ApplyHit` → `UColdSteelStatusModel::ApplySkillWeaponHit`，只有目录条目写 `"hit_stagger": true` 时才用默认倍率；否则以 `UMonsterCombatComponent::ApplyHitWithReactionScale(0.f, …)` 关闭闸门，`ReceiveHit` 只记住攻击者后直接返回——不累加韧性、不眩晕、不切 Stagger、不停止移动、不重播受击片段。近战与技能（各自伤害类型）仍按原倍率造成硬直与击退；新增"能打断怪物的枪"必须显式在目录开这个开关，不能靠改回受击端默认值实现。

**状态跳伤同样不硬直**：流血与灼烧走 `UCombatStatusFormula::Apply`、中毒走 `UColdSteelPoisonComponent::Pulse`，两处都在结算外包 `ApplyHitWithReactionScale(0.f, …)`；伤害类型保持原样（毒/流血 `UCombatDirectDamage`、灼烧 `UFireballDamage`），避免改变 `IsMagic` 判定带来的减伤差异。新增任何持续伤害来源都要走同一条闸门，否则会出现"每秒打断怪物一次"。
| 返回 | 超过活动范围或丢失目标 | 抵达出生点或死亡 | 可达路径、恢复规则、重新感知 |

## 已验证的实现经验

- 行为树独占待机、追击、调查、返回和攻击选择。角色的攻击/受击枚举只记录执行阶段，不再从 Tick 自行追击或重置 Idle；不并行运行另一套 StateTree 决策。
- 共用 MonsterAIController、MonsterBTNodes、MonsterCombatComponent；当前组件通过明确的护士/手脑适配访问执行接口。新怪物扩展适配或抽取接口，不能宣称任意骨架自动通用。
- 控制与死亡优先于攻击和移动。受击取消尚未生效的伤害窗口，停止路径跟随，播放专用受击片段。结束后交回行为树重新判断，弱命中不得缩短未到期的眩晕。
- 攻击保持一个权威时钟和命中去重。动画不能成为第二个伤害定时源。保留已接受的接触时刻、嚎叫跳数和死亡布娃娃合同。
- AI Perception 处理视听；伤害入口同步记忆攻击者。只缓存事件会在目标清空后漏掉持续可见玩家，应从当前视觉感知缓存重新获取。
- 使用 NavMesh 路径跟随，按怪物体型配置 Supported Agents。生成 NavMeshBoundsVolume 时必须建立真实 UModel/Polys/BrushComponent；Build 返回 true 但 Brush 空时范围仍为零。读回非零范围，再验证路径及实际绕墙位移。
- 蓝图默认控制器正确不代表关卡实例正确：保存后分别读取 CDO、放置实例和运行中控制器、Behavior Tree 引用。
- 受击骨骼轴不能假设 local X 就是后仰轴；先查看参考姿态，将模型空间的目标旋转轴转换到每根骨骼空间，再验证导入片段和游戏画面。
- 使用隔离角色档案和怪物夹具。近战预期扣血遵循当前防御规则，复活校验当前 MaxHealth；不要以过期固定值误判 AI，也不要直接移除失败断言。
- 新怪物至少验证真实枪击、控制期限、恢复追击、有效绕墙路径、攻击去重/躲避/打断、死亡和回收。记录实际运行报告日期；历史通过不替代本次回归。

本次基础树未涵盖巡逻、多点搜索、掩体/EQS、飞行或联机验收；后续行为应在同一决策入口下扩展。

## 攻击距离与死亡交接（2026-09-15）

- 用户试用后要求将前轮放大的攻击距离收敛为原始基数的 1.5 倍，并让手脑（用户称首脑）保持原范围。`MonsterCombatTuning::AttackDistance` 对护士、胖子、毒蛆的现有怪物/蓝图/实例距离基数乘 1.5，不在 BeginPlay 重写属性；起手、停步、近战命中和毒蛆弹体行程同步应用。手脑的砸地触发、中心前移、伤害半径、嚎叫半径及对应预警全部恢复原始值，退出这一倍率调整。
- 有死亡片段的胖子、手脑和毒蛆统一在片段时长的 60% 交接布娃娃；采样交接时刻并刷新骨骼后开启物理，不再跳到死亡末帧或等待落地。无死亡片段时沿用原有直接物理或延迟回退。
- 本轮代码与数值说明见工程 `Docs/monster-range-ragdoll-20260915.md`。未进行游戏测试或画面验收，由用户测试。

## 弹反即时打断（2026-09-14）

- 弹反在伤害回调内完成攻击取消、硬直姿态采样和首次带碰撞击退，不能只登记参数等待下一次组件 Tick 或行为树服务。后续位移只消费剩余距离，控制时钟保留完整时长。
- 受击反应的前 0.1 秒为起势；弹反直接采样该后仰姿态，零增量刷新骨骼，并在后续表现采样中保持偏移。普通受击保留起势。
- 胖子使用专用 `A_FatZombie_Stagger`（0.9 秒），在 BeginPlay 预加载。用户随后要求改善直接切入的僵硬感：从弹反触发节点倒放当前攻击 0.3 秒，再用 0.08 秒过渡接入硬直；倒放与混合由同一受控时钟推进，击退仍立即发生，原 1 秒控制包含倒放。去除胖子倒放阶段的共用 0.1 秒表现偏移，避免一开始跳帧；死亡与后续状态清除待接片段。该修订仍待用户实测，不作为已通过案例。
- 弹反只会在怪物攻击命中入口触发，因此还需对齐可见挥击与伤害时刻。胖子正式动作的右手在约 0.65～0.7 秒挥过，原 1.00～1.18 秒窗口已落到随挥阶段；本轮改为 0.65～0.78 秒，不全局套用到其他怪物。
- 弹反方向在中断前记录；不能复用最近一次伤害方向，因为弹反不一定经过怪物 TakeDamage。伤害回调可能同步改变攻击者状态，返回后必须退出已被中断的攻击分支，避免继续命中或重新显示预警。
- 本轮修改说明见工程 `Docs/monster-parry-response-20260914.md`；未进行游戏测试或画面验收，由用户测试。

## 自动跨阶与可见模型（2026-09-12）

- 基础怪物使用 `UMonsterCharacterMovementComponent`，沿用玩家的原生扫掠跨阶；`MaxStepHeight` 与 Supported Agents 的 AgentStepHeight 同步为 40 cm。不同宽度的胶囊必须分别验证，不能用护士的通过结果代替手脑或毒蛆。
- 只将成功跨阶/贴地的离散高度修正补偿到现有 Mesh，以 cm/s 线性收敛；不替换攻击时钟，不额外推进角色。死亡禁用移动后冻结补偿，分离或物理模拟的 Mesh 不再修改；传送清除补偿。
- 宽胶囊的圆角可能把高台边缘当成地面。采用原生平底接地与踏面高度判定时，射线回退的支持高度用胶囊底部减 `LineDist`，因为 UE `SetFromLineTrace` 保留了原扫掠的 `ImpactPoint`。避免引用正在被 `FindFloor` 改写的候选作为自身高度基准。
- 用正式模型验证上下楼梯、连续与密集矮障碍、临界高度、停止、斜坡、空中落地和死亡；同时检查真实 NavMesh 路径和 Mesh 世界位置曲线。整体平滑不等于逐脚/手掌贴地 IK。重建、运行与本轮结果见工程 `Docs/monster-stair-movement-20260912.md`。
