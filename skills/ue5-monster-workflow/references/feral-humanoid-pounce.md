# 狂奔人形、张开爪型与真实落地飞扑

适用：用成熟持械动作制作无武器的人形猎手，修正手指/手臂、接地与过渡，以及追击、飞扑预判和落地反馈。来源是 2026-09-23 的突变体-3 修订；用户确认表面优化“成功了”，对距离和提前量反馈“基本成功”。这不等于完整 AI、地形、性能或多人验收。遵循 SKILL 入口的后台执行与用户测试规则。

## 从完整身体动作做局部适配

- 先确认本机素材确实包含所需片段。Fab 入库、manifest、预览图不能替代实际动画；Khaimera 的原生 IK 重定向产物与 Meshy 模型分别保留来源。免费 Paragon 不是 CC0；原包、采样姿势、派生 FBX/Blend/uasset 不随源码公开。
- 原手掌有权重不代表指节可动。先读父链和实际手指权重；新增指骨只影响选中的手指区域，保留掌部过渡、原骨绑定和身体权重。张开爪型是指根外展、指间留缝、中末节内钩、拇指保留开口，不能直接沿用握柄或握拳姿势。
- 独立强制肘方向和手腕朝向，可能破坏肩肘腕的协调；缺少 twist 辅助骨时更明显。优先恢复干净源动作，在同一源时刻重排整个身体姿势，再做有限局部修正，避免只提前手臂而保留另一时刻的躯干。
- 身体已认可、只要求爪尖下挥时，限定腕与新增指骨的旋转轨。保留其他骨的旋转和全部位移/缩放；按实际绑定局部轴转换朝向，限制腕角，用连续权重从飞行延续到落地后回收。不要重新导入全模型来替换两段手部动画。
- 用户明确要求掌心向下时，用腕部与指根建立实际掌面法线，转换到腕骨局部空间；末节指骨方向只表示爪尖，不能代替掌面朝向。保留原肩肘配合，掌面定向与小幅压腕下抓分别编排；需要起跳即朝下时，给蓄力末段添加双腕旋转过渡，避免腾空首帧突然翻掌。2026-10-02 突变体局部修订记录在工程 `Docs/Monsters/Mutant3PouncePalmDown20261002.md`，实际观感仍待用户测试，尚未作为认可模板。
- 用户已判定上述首版不合格：只准备掌面方向、把卷指和压腕延后到腾空 0.32 秒，不能满足起跳就调整手型。V2 同时在蓄力 0.08–0.38 秒准备双腕与 30 根指骨，起跳首帧保持完整下抓，腾空 0.00–0.18 秒压腕下挥；只写手部旋转。记录为 `Docs/Monsters/Mutant3PounceTakeoffHandsV2_20261002.md`，三段保存后，用户再次通过截图否定其手掌方向。编辑器 PIE 会阻止保存，应在更改前判定播放状态；必要时结束已有 PIE 后保存本任务资产，保留编辑器，不启动新游戏。
- 用户明确纠正为“方向完全相反，调转，手掌向前挥舞”时，不能继续增加向下压腕。本例 V3 保留 V2 的指型和身体动作，仅绕掌面横向局部轴反转双手 180°，同时反转掌面法线及腕到指根的方向；绕手的纵向轴只会拧掌，不能反转指向。蓄力 0.08–0.38 秒完成转向、腾空保持、落地 0.16–0.64 秒释放。只写左右 Hand 两条旋转轨，三段正式动画已保存，记录 `Docs/Monsters/Mutant3PounceForwardFlipV3_20261002.md`。后续用户确认起跳和空中方向正确，但否定落地手腕；认可仅覆盖前两段，不能复用 V3 的落地解法，也不把 180°参数泛化为其他怪物的标准。
- 起跳／空中已认可而落地扭腕时，保留已认可的正式包，仅处理落地腕轨。不要让持续的掌面世界定向、180°翻掌与各自退场权重同时驱动落地手腕。本例 V4 从第 0 帧恢复干净源中与同帧前臂配合的局部手腕旋转，由既有 0.14 秒上身姿态快照过渡接入；只写落地左右 Hand 两条旋转轨，保留指型和接地／伤害时钟。记录 `Docs/Monsters/Mutant3PounceLandingWristV4_20261002.md`，状态以保存回执为准；本轮未测试、尚未获用户认可。
- 用户继续指出蓄力环绕胸前、臂腕扭曲时，方向的局部认可不代表蓄力姿势已认可。本例 V5 仅重排蓄力六条左右 Arm／ForeArm／Hand 旋转轨：双手在自身肩线外侧向前准备、肘部向外下方、随后前上方抬手；两节臂链统一解算，并随上臂运送原肘弯曲平面，避免前臂代偿扭转。早期腕姿中性，0.20–0.54 秒沿单条最短四元数路径准备起跳腕姿；末帧保留原起跳臂链。肩锁骨、躯干、下蹲、脚部、指型、位移／缩放及空中、落地正式包不写入。记录 `Docs/Monsters/Mutant3PounceOpenWindupV5_20261002.md`，正式蓄力包已保存，未测试、未获用户认可；解算仅离线烘焙，不增加运行时 IK。
- UE 5.8 的 `AnimationSequencerDataModel.GetBoneAnimationTracks` 旧接口返回空数组，不代表实际骨轨缺失。Python 安装按 `GetBoneTrackNames` 获取实际名称，按 FName 的大小写不敏感语义匹配；在准确源帧读取 RAW 局部姿势并关闭重定向/根运动提取。比较采样率时读取分子、分母数值，不能依赖 Python 结构体包装对象比较。写轨前复制为独立数据，保留正式资产原位移与缩放；只保存目标动画，不保存临时 FBX 输入或替换骨架。

## 真实移动和动画衔接

- CharacterMovement 和胶囊拥有世界飞行、扫掠与重力；原地动画去掉重复垂直位移。真实 `Landed` 触发落地，不能按动画时间将角色悬停或传送到预设终点。
- 落地混合可能把蜷腿姿势重新带入支撑。让根、骨盆、腿直接取落地动作，上身按明确脊柱分支混合；不是对所有模型硬编码 Spine02。
- 跑步片段周期数可能不同。用左右脚支撑位置及摆动方向建立步伐映射，不能只按整段归一化时间匹配。稳定的离场循环继续推进；已打断的混合从可见姿势快照接续。同一循环不重启混合。
- 追击状态是意图，实际速度才决定跑步播放。用滞回进入正常待机，避免堵路时将奔跑放到 5% 形成慢动作。攻击、受控和普通动画各自沿既有权威时钟推进过渡，不增加伤害计时源。

## 寻路与追踪的退出条件

- 同时核对物理胶囊、NavAgent 和已有导航规格；停止半径、导航投影偏差与实际攻击距离需要一致。胶囊高度坐标不能直接当脚底导航坐标。
- 路径状态 Moving 不证明角色在移动。目标位置相同但实际速度长期很小时，应在有间隔的重试中重新规划；备选攻击位置要满足完整路径、实际视线、高度和胶囊首步通行。
- 区分初次感知距离、持续追踪距离、证据记忆和出生点活动范围。始终看到玩家却按出生点距离返回，会产生“回家再追”的循环。按怪物设计局部调整，不全局取消其他怪物的返回规则。

## 有上限的飞扑提前量

- 以目标水平速度乘实际飞行时间预测，起跳时重新采样；此时不要再次累计已经过去的蓄力时间。配置预测强度与距离上限，不在空中无限追踪。
- 对预测路径扫掠目标胶囊，避免把落点放到玩家面前的墙后。依次尝试完整、减半及零提前量，每个候选重新约束距离、可走地面、高差和整段抛物线胶囊碰撞；全部失败交回追击。
- 落点前方扇形命中需纳入目标胶囊半径与扇形边界距离、高度、视线和每次攻击去重。只在真实落地判定一次；造成正伤害且玩家存活后施加既有眩晕与相机反馈。
- 伤害回调可能同步弹反并取消攻击；回调后再次判断攻击状态，不能继续命中或覆盖弹反姿态。控制到期、死亡和销毁释放自己持有的输入锁。
- 本例最大选择距离 1125 cm（原 750 cm × 1.5）、飞行 0.65 s、提前量最多 450 cm；落地扇形 120°/250 cm、伤害倍率 3、眩晕 2 s。这些是本例配置，不是通用默认值。

## 表面粗糙与加载排查的层次

- 先区分源几何轮廓、蒙皮、法线/切线、材质连接和纹理 mip。材质槽存在不代表实际 RenderSection 引用正确；单槽网格仍可能引用不存在的槽 1。修复需同时处理 MeshDescription 导入槽名、LOD section/material map 与派生数据重建。
- Substrate 项目要有有效 Front Material 输出；旧 BaseColor/Normal 引脚有贴图不证明表面输出已接通。重新导网格时保留当前材质实例，不能回写旧基础材质而丢失细节层。
- 改造手指后可局部混合平滑法线，保留原身体的烘焙法线基础；导入保留作者法线并重建相配切线。不能整身重新平滑后仍假设原法线贴图基础没变。恢复正确 UV 密度元数据，避免影响流送判断。
- 若需近景 mip 保留，只缓存指定材质实例的序列化纹理参数，定时给附近角色短期 residency。避免依赖 shader-ready 的 GetUsedTextures、逐帧同步加载、全场扫描或全局关闭流送；共享纹理请求让其自行过期，单个角色销毁不取消其他角色的请求。
- 本机 UE 5.8 的 MaterialEditingLibrary 某些材质实例参数 setter 会赋值却仍返回 false。不要仅据该 bool 报导入失败；按具体版本读实现，读取赋值后的参数/保存结果。不能泛化为忽略所有 API 错误。
- 本例用户认可的是组合修订效果，不能据此认定“mip 缺失”是唯一根因，也没有新的性能测量结论。

## 落地表现与恢复

- 落地波和尘土由真实地面点/法线触发，命中音复用已许可音源的独立副本。视觉落地与伤害命中相互独立；闪避后仍可看到落地效果。
- 复用现有有限容量的世界特效池，预分配材质与音频声道；容量不足只丢视觉，不丢伤害。加入新粒子组时检查原有循环的用途，防止血雾逻辑顺带遍历地波组。
- 恢复顺序和当前入口见工程 `Docs/Monsters/Mutant3FeralPublication20260923.md`。干净重定向、接地源、张开爪源、完整身体重排、手部旋转补丁、表面修订分层保留。退役的独立 IK 候选和旧快照进入 trash；正式重建不依赖 trash。
