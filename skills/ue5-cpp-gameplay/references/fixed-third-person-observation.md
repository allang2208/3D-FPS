# F6 固定第三人称观察

适用：在既有开发面板增加固定镜头，以观察输入后的动作。F6 保持开发面板快捷键；入口为 F6 → 基本调参 → 第三人称固定视角。

- 通过已有 DevelopmentTuningSubsystem 的权限、状态通知和 DisableAll 扩展会话选项，不另绑 F6，不写玩家存档。
- 开启固定视角同时启用第三人称。首次经过现有碰撞扫掠后捕获最终渲染位置、朝向和 FOV；只锁定 FMinimalViewInfo，玩家眼部、ControlRotation 和输入继续运行，交互距离和攻击射线继续从玩家计算。
- 关闭固定项恢复第三人称跟随；切回第一人称或关闭全部选项释放捕获。再次开启捕获当前位置。已有死亡镜头优先级应保持，不把观察镜头插到它之前。
- 身体／装备可见性沿既有第三人称路径，只在状态变化时写 setter。固定镜头不增加每帧资产加载、额外动画执行器或独立命中时钟。

本轮 Editor 构建记录为 build-20261010-205541.log。构建不是镜头行为验收；默认交由用户运行测试，不自动启动 UE 或游戏。
