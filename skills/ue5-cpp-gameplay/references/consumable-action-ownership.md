# 进食、饮水与战斗动作的交接

用于 FPSGAME 已有手部动画的消耗品。适用入口包括背包、快捷栏和本地监听主机。优先检查 TryBegin、FirePressed 与实际武器组件的扳机、连击缓冲和快捷技能入口。

- 入口按实际装备检查两只手已有的射击、待发、装填或近战收招。物品只用一只手时，两只手的攻击仍须等待。动作从放低装备一直占用到回握完成。保持站立、移动、浏览状态或背包时，可以推进已经开始的动作和接触时钟。
- 食物、矿泉水和汽水的游戏内主开火键用于取消。该次按下和对应松开都由进食组件消费；长按或快捷键重复事件不能在恢复后补开一枪。HP/MP 药水吸收攻击输入并继续饮用。物品资格与手部姿态分别判断。
- 取消时从当前降低幅度接回正常回握。跳过的时间段不能触发吞咽、库存接触或抛瓶事件。以接触是否已经提交区分取消结果。保留主动换武器/工具、成功翻越、攀爬、闪避和滑铲的中断，以及死亡等强制中断。
- 面板打开时清除持续扳机输入，让当前动作与装备继续求值。新输入沿用 BlocksOngoingActions，正在执行的动作使用 BlocksActionContinuation。暂停和已进入的工作台小游戏使用其专门的接管入口。
- 打铁、装配、炼药和木工使用工作台近景表现。世界身体留在交互位置空手待机，退出还原显示和输入。用具体视图标识持有待机状态，防止旧视图的 EndPlay 清除新视图。锻造入口验证距离、可达性和占用；全身动画资产、握点和指定落脚通道已经退役。
