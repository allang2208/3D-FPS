# FPSGAME 建筑面板统一标准

适用于建筑抽屉的新增分类、构件卡片、模型缩略图、字体和详情浮窗。当前宿主为 `D:/FPS3D/FPSGAME`。总视觉规则以 `Docs/UI/ui-cold-steel-design-system.md` 第 15 节和 `ColdSteelUIStyle` 为准；本文件补充实现约束。不要把旧 Godot 字体或早期 116×150／12px 卡片示例当作当前标准。

## 分类与数据来源

- 单一目录：`DA_VoxelBuildPalette`。材质使用稳定 `Id`，玩家名称使用 `DisplayName`；禁止用物理密度、网格文件名或名称关键字猜分类。
- 一级保持「材质／其他」。材质下的「其他构造」依次列公共体素形状、`Prefab.Material` 指向该材质的构件；「其他」只列无归属构件。无效材质引用在 UI 落入「其他」，并在目录审计中报告，不能使构件消失。
- `Prefab.Material` 是栏目归属，`Surface` 是实际表面，二者不可混为一谈。青铜火把归属大理石建筑系列是既有决定，不能按颜色或金属材质自动改类。
- 保持目录顺序。形状调用 `SelectShape(材质 ID, ShapeMode)`，构件调用 `SelectComponent(构件自身 ID)`。展开按钮与选择按钮是兄弟控件，展开不能同时选择。
- 尺寸、数量、物理值和放置方式从当前定义／求值函数读取。显示占格范围时注明它不是模型精确外轮廓。构件支撑说明与实际 `PrefabSupportAt/IsPrefabSupported` 一致，不复制“构件不提供支撑”等过期结论。
- 玩家详情不显示资产路径、内部 ID、调色板维护教程。技术来源和异常写进审计记录。

## 布局、主题与字体

- 使用当前右抽屉合同：贴右缘、视口宽 48%（通常 720–1040px，受视口约束）、上下 12px、4/s 进度、40% 背景压暗和 HUD 让位；收回动画完成或销毁后解除让位。
- 固定标题只放标题。选择、操作状态、吸附和结构风险在独立可换行摘要区；分类页签和简短页脚固定，卡片区滚动。不要把多行摘要塞入 36px 标题栏。
- 配色、玻璃、按钮和圆角全部来自 `ColdSteelUIStyle`。建筑详情用中性灰 `Tooltip/Border` 和标准按钮；不引用旧蓝灰 `TooltipGlass` 或红色装饰关闭按钮。装备的冷白鉴定卡是另外的业务样式。
- 标题20px、分区16px、正文／构件名称14px、辅助说明／键号12px；Regular400／Medium500。文字用 Noto Sans SC，数值／单位／键号用 JetBrains Mono，数值字体保留中文 fallback。中文状态、分类和描述使用文字字体，即使其中含数字。
- 详情行明确声明数值角色（`NumericRows`），不能把所有右侧值统一换成数字字体。
- `ColdSteelUI::TextFont/NumberFont` 接收 Slate points，像素换算为 `px*0.75/PixelScale`；兼容入口 `GunsmithUI` 接收 `px/PixelScale`，内部只转换一次。
- 网格卡宽116px、最小高170px，104×104px图片、8px间距、14px名称。名称区铺满102px内宽，以显式 `WrapTextAt` 横向排满后换行；不要把 AutoWrap 文字放在只按期望尺寸居中的窄槽中。保留44px最小名称高度，超长名称让卡片自然增高，不挤压图片、不裁剪下方文字、不缩字号。括号里的操作／尺寸附注及完整名称保留在详情。
- 各材质共用的滚动区固定预留6px滚动条，去掉默认滚动条外边距；轨道画刷的期望宽度也同步DPI，不能只设置滑块厚度。网格创建及视口变化时显式设置 `WrapSize`：抽屉宽减两侧1px边框、18/12px滚动区边距、6px滚动条与14px子级缩进。展开下方分类不能改变上方分类的可用宽度，也不能让重建网格先按默认500 Slate单位换行。1040px抽屉的子网格可用988px，8张116px卡加7个8px间隔共984px；窄视口按实际宽度自然换行，不缩图片或字体。
- 图片有明确的256²源尺寸，通过 `ScaleBox(ScaleToFit)` 完整等比例适配104²区域并居中；不能用拉伸或 ScaleToFill。文本独立于图片的缩放容器，卡片按钮内容不另加未计入的默认内边距。
- 材质行使用独立的36px内容高度、28px图标。DPI变化同步处理字体、固定栏、边距、按钮和卡片尺寸，不把材质行套成网格卡；重建时移除已脱离根控件树的标签引用。
- `1–9` 按当前显示列表顺序映射，并标注对应键号；展开／分类变化时一起更新。卡片内容比较涵盖行内容、备注、字体角色和全部预览参数。

## 真实模型预览与预算

- 静态构件取实际 `Mesh/Surface`，只按放置路径覆盖对应材质槽。体素形状用实际材质方块按 `格×20+10cm` 装配；禁止拿通用石块掩盖缺失模型。
- 逻辑构件取 `ActorClass` 的完整可见静态组件。门、窗及双开门使用实际几何对齐函数与 `Configure` 材质策略，必须同时包含框和扇；喷泉保留自带水体网格与专用材质槽。
- 组装只发生在不播放的 `FPreviewScene`，不调用 BeginPlay、不 Tick 世界、不驱动门窗交互、声音或粒子。动态 FX 不作为静态图标完整性要求。只有未生成可见组件时才使用目录代表网格；新增仅在 BeginPlay 装配的类型，应提供纯外观装配入口。
- 组件池复用前清空 `OverrideMaterials`、网格和可见性。多材质模型每槽复制，避免上一件物体的水材质或石材串到下一件。
- 共用 `T_StudioEnvironment` 与 `M_WeaponPreviewResolved`；256²、固定 `FRotator(-18,-35,0)` 正交视角，颜色与逆 alpha 覆盖两次捕获。逐组件投影局部包围盒8个角点，再合并相机空间边界；投影中心对齐画面中心，长边占画面84%，单格仍按用户指定减半。不能只按世界最长边取景，也不要先合并世界轴向包围盒导致不对称装配偏心或留白过多。取景配方变化更新缓存版本（当前 fit2）。
- 缓存键包含稳定 ID 与 Mesh、Surface、ActorClass、Cells、Pivot 的内容签名。编辑器原路径重导入后应在新运行实例刷新；不宣称键能识别同路径文件内容的任意原地修改。
- 请求去重，每帧最多一对捕获。局部纹理驻留1秒，预热至少50ms、未就绪最多等350ms，禁止每帧全局 streaming flush。UE5.8 使用有效的新 `GetUsedTextures` 重载；旧五参数重载已为空实现。
- 缓存软上限32；当前列表的显示键受保护，可暂时超过上限，取消保护后按 LRU 回收。关闭／销毁取消未完成任务、释放保护键和场景网格；已缓存图片供重开复用。没有作业时不捕获。
- 加载中显示中性文字占位，连续3次失败后显示「暂无预览」并停止重试。失败计数只统计失败；缓存被回收后仍允许重建。

## 浮窗与交付范围

- 详情标题和24px关闭按钮固定，正文独立滚动；浮窗最多430×520px并受当前视口约束。名称／行值允许换行。
- 使用 Slate 绝对鼠标位置，再通过目标几何 `AbsoluteToLocal` 换算；不要混用 DPI位置和桌面绝对位置。跟随0.7秒后固定，窗口尺寸变化仍限位，保留进入浮窗点击／滚动的路径。
- 默认仅制作和必要构建，由用户测试。用户明确要求审计时，按授权范围核对当前调色板、分类覆盖、实际模型来源、字体、缓存和布局；不连带跑承重、战斗或存档回归。
- 报告分别说明资源读取、代码审计、构建和实机 UI 的完成状态。没有实际打开和渲染时，不写“预览与多分辨率验收通过”。
