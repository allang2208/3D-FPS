# FPSGAME 栏目入口与武器资源栏

用于主游戏状态／背包／技能入口、快捷键动效和右下角武器资源栏。正式尺寸、颜色和周期以工程 `Docs/UI/ui-cold-steel-design-system.md` 第 11、13 节及 `ColdSteelUIStyle` 为准；这里维护实现方法。

## 双持与近战显示

- 右下角名称、弹匣及备弹属于 `ColdSteelAmmoReadout`，与改造台右侧配件详情是不同控件。
- 主手与副手通过同一个 `BuildWeaponSection` 构建；字体、行距、分隔线、列宽及换行在同一布局循环更新。不要将副手实现为主手栏末尾的缩小附注。
- `PresentDual` 按两手实例分别读取名称、口径、当前弹量、容量、备弹及换弹状态。同口径可能读取同一个备弹池，展示不应再分摊或相加。低弹、空仓与换弹颜色按每只手自己的状态计算。
- 退出双持时折叠整个副手区及组间分隔，不仅清空文字。HUD 统一管理内容自适应高度与快捷栏、体力条、侧边入口的避让。
- 近战共用同一资源栏，但数据来自状态模型 `MeleeStaminaReadout`：当前体力可普攻次数向下取整；回满时间包含剩余恢复延迟及实际恢复倍率。估算与体力 Tick 共用活动判断，不在 UI 复制一套恢复逻辑。零消耗、恢复暂停、零恢复率和满体力使用既定显示语义，切回枪械恢复标签及字体；无限备弹不覆盖近战时间。

## 无底图标与交互

- `ColdSteelPanelNavigation.cpp` 只加载 `Navigation/*_subject.png`。生成图中的棋盘格可能是 RGB 像素；“看似透明”不能当作真实 alpha。此次用户明确指定本地抠图，恢复入口为 `Tools/UI/export_navigation_subjects.py`，输入 RGB、全尺寸抠图和最终运行 PNG 分开保留。
- 悬停只缩放主体，键位、点击区域和页面选择标记固定。进入、退出和途中反向共用当前动画进度；名称淡入与主体缩放使用同一时间轴。
- 导航快捷键复用 `ColdSteelQuickSlotFX::KeyOpacity`；中央快捷栏保持图标、键位、冷却黑遮罩和完成闪光的独立绘制层，不将数字或效果烘焙进图标。
- 抽屉预留必须包含悬停外伸；矮窗按顶部 HUD 与武器栏的剩余空间先收紧间距。独立物品弹层也要转发入口点击和快捷键，仅处理 HUD 内的外部点击保护并不足够。
- 关闭沿用控制器的输入消费与焦点恢复，避免鼠标点击穿透为攻击。图标缓存就绪仅替换图片，不重建正在交互的入口或清空滚动位置。

## 归档和源码发布

旧运行图停用后可与对应导入副本归档；用于生成、抠图、恢复的原始输入仍是有效源，不因首次输出没有 alpha 而当作废案。归档路径、字节数、SHA-256、替代物见工程 `Docs/UI/ui-panel-archive-20260915.json`。

面板可能依赖尚未提交的双持、体力、强化与技能代码。发布前依据实际 include、声明、实现和配置列出必要依赖，不只提交面板文件，也不把整个脏目录加入提交。用户已明确授权的依赖可一并发布；范围不清且涉及其他系统时先明确边界。保留他人已有暂存，二进制、字体、模型和 trash 按仓库资源规则处理。

2026-09-15 案例的必要构建已完成，未进行实机测试。后续修改仍遵守用户默认不主动测试的规则；历史构建不能作为新的提交或视觉效果已通过的证明。
