# Slate GPU 自定义顶点丝带与冷钢地图路线渲染

本页沉淀自 `SupplyRouteVFX-R60`（`SColdSteelWorldMap.cpp`「冷钢鎏金丝流」方案 A），适用于世界地图补给线、商队路径、远征航线等高品质矢量特效。

## 1. 为什么放弃多层 `MakeLines` 堆叠

- `FSlateDrawElement::MakeLines` 在粗线拐角易产生毛刺、硬边锯齿和廉价「油漆贴纸」感；叠双轨边框、高频刻度、空心线框菱形与常驻同心圆脉冲会造成视觉噪点过高且不匹配冷钢 UI 质感。

## 2. `FRouteSilkCanvas`（`MakeCustomVerts`）标准架构

1. **等弧长平滑重采样（`SampleUniformRibbon`）**：先按屏幕像素弧长将路线均匀重采样（上限 `<= 240` 点），再以中心差分求切线与防折角法线，消除急弯锯齿。
2. **7 站对称高斯羽化丝带**：每个横截面采用 `Offsets = [-1.0, -0.56, -0.24, 0.0, +0.24, +0.56, +1.0]`，外缘 Alpha 恒为 `0`，通过单次 `FSlateDrawElement::MakeCustomVerts` 批量输出（`1–2` 次 `Flush` 替代数十次线元提交）：
   - **底影层**：暖暗压地影（`#090705`），确保亮色泥地/砂石底图上仍有清晰对比度；
   - **大气光晕层**：柔和暖金光晕（`#CFA456`）；
   - **鎏金主丝带**：暗铜（`#756447`）→ 冷钢主金（`#D4B678`）→ 香槟丝光（`#F2E0A8`）+ 2 道长羽尾液态金扫光（`#FFF8E2`），端头自然渐细；
   - **静态微锚标与柔焦光斑**：少量固定实心微箭标（仅在扫光经过时顺带点亮）+ 3–5 颗真实径向羽化圆光斑（禁止空心线框菱形）+ 实心暗铜鎏金端点徽章。
3. **动态状态语义分流**：
   - **载具在途**：将实车世界坐标投影到路线弧长 `WagonU`，车后已行段沉降为暗铜，车前剩余段保留鎏金丝流与引导扫光 + 实心鎏金车轮徽章；
   - **受阻告警**：全线降饱和为停运铁灰（`#3C4249`），**仅在封锁节点（如村庄东门）局部呈现羽化暗红渐晕与单枚实心红盾 `!` 徽章**，克制且一眼聚焦堵点。
4. **零后台开销**：仅在地图控件打开绘制时运行，地图关闭期间 `0 ms` 开销；绘制前一次性 `Reserve` 顶点/索引缓冲区。
