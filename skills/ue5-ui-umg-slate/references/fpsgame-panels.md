# FPSGAME 面板与栏目

用于这个项目新增／升级面板、页签、栏目、卡片或弹窗，包括改造、强化、附魔、装备背包、仓库与状态 UI。

## 先读取当前规则

工程根为 `D:/FPS3D/FPSGAME`。在当前工程读取 `AGENTS.md`、`UI-WORKFLOW.md`、`Docs/UI/ui-cold-steel-design-system.md`，使用 `Docs/UI/panel-column-plan-template.md` 形成必要规划。个人技能与仓库镜像共用本参考，因此这里的路径均相对于工程根，不相对于个人技能目录。

新面板／栏目必须先明确结构、布局和数据合同，再制作。用户已授权接入时规划后继续执行，不额外设置审批门槛；用户仅要候选、确认后再接入时停在对应阶段。默认不运行检查、测试或截图；用户明确要求的项目检查／预览／测试才执行，必要开发、构建与接入照常进行。

## 最小规划内容

- 说明面板目的、入口、交付阶段和复用的现有面板。
- 列出“面板→页签→栏目→卡片／行”及各自可见条件。
- 给出宽屏／紧凑／窄窗／矮窗布局、滚动归属和固定操作区；按实际内容区重排。
- 标注共享主题、字体角色、字号、图标来源；避免另建一套近似主题。
- 每个显示值列真实模型、单位、范围、排序和更新事件；每个动作列业务入口、扣除、事务与保存路径。
- 明确无数据、未选择、不兼容、资源不足、数据改变、图标异步完成及关闭状态。
- 列文件修改范围、资源来源与已确认退役项。容量／占格／存档改变需要单独迁移规划。

## 视觉落地

先找相邻面板的当前实现。工作台从 `M4GunsmithLayout.cpp`／`M4GunsmithOverview.cpp`／`ColdSteelEnhancementLayout.cpp` 复用结构；背包仓库从 `ColdSteelHUDWidget`／`ColdSteelInventoryWidget`／`ColdSteelInventoryPresentation.cpp` 复用。

主题只使用 `ColdSteelUIStyle` 的当前公共入口，`GunsmithUIStyle` 为像素字体兼容入口。中性黑灰、银白强调、低透明度玻璃；改变背景 Tint 不降低整个控件 RenderOpacity。保留原枪械库背景和工作台右侧完整详细汇总。子卡片共享模糊，分区用明度、细边和留白建立层级。

中文／普通 UI 为 Noto Sans SC，数字为 JetBrains Mono，工程内加载。字号档位、DPI 换算、玻璃参数和断点只查正式规则，避免在本参考复制数值后漂移。不要把 px 直接当 Slate 点数，也不要重复做 0.75 换算。

标题、页签、页脚和主要操作固定可达；内容独立滚动。平级按钮均分、同高同间隔，下拉标题整体居中并补偿箭头。长文本换行或提供全文入口；属性名与数值分列。仓库在左、背包装备在右，等大并保留开合动画。

## 数据规则不能随样式漂移

附魔卷轴：只使用背包中的正数量堆叠。同类汇总；未持有和仓库独有卷轴不生成卡片。持有但不兼容禁用；无卷轴显示空状态。列表、默认选择、报价、数量和 Apply 扣除同源；移出背包／用尽时取消失效选择。魔法粉尘、金币、强化石仍遵循原背包＋仓库来源。

仓库“存入同类”：操作开始时取得仓库已有 Definition 集合，排除武器和全部装备；沿用合堆、空间容量和一次保存事务。不要把换按钮文字当作完成业务替换。

空间背包：物品绘制、命中和拖放必须共用几何。拖动期间用源实例快照判定失效，最终提案提交继续核对 Generation；普通自动保存不应使未变化物品的拖动失效。详情见同目录 `fpsgame-inventory-input.md`。

数值对比：展示真实聚合结果，缺失值为“—”。收益／代价按指标方向判断，耗时与后坐降低为收益；不只看正负号。空装备槽、未持有卷轴、缺材料功能各自采用业务需要的显示／隐藏／禁用规则。

## 生命周期、图标与输入

- 显示由 OnChanged 等现有事件驱动；Construct 注册，Destruct 解绑。Tick 只处理必要几何和已有实时捕获。
- 模型负责 Quote／Proposal／Apply／Save；控件不能自己重复扣除材料或保存。
- 自绘 Slate 数据／画刷更新后使 Paint 缓存失效。动态图标始终保留目录图回退，成功后再替换成真实组合图。
- 图标完成只 SetImage 或更新画刷，不重建正被点击的按钮；保留选择、焦点和滚动位置。
- 复用图标子系统的失败退出和通知：一个任务的材质错误／超时不能阻塞整个队列；失败回退不能被描述为配件外观完全正确。
- 打开／关闭走现有控制器入口，保留输入模式、视角锁定、焦点恢复、拖动取消与菜单关闭顺序；关闭事件不能穿透为攻击。新 Tooltip／菜单按实际视口限位。

## 顶部 HUD、折叠与世界时钟

参考 `ColdSteelTopVitals.cpp`、`ColdSteelEventTimeline.cpp` 和 `ColdSteelWorldClock.h/.cpp`：同组顶部控件的外框、DPI重排和下方事件栏起点由HUD统一计算，避免各自读取上一帧几何导致重叠。数值和标签分列，窄窗重排，不缩小整张画布。

旧game-dev太阳相位和UE日内时间的零点不同；移植表盘前分别读取原项目相位定义、数字时间格式和UE实际天空时间。时钟与预报共用权威时间源，只读显示；Slate自绘刻度／指针不依赖符号字体，UWidget释放时同步释放Slate引用。此次完成必要构建，未运行游戏或测试。

2026-09-13 用户反馈表盘发白、指针不清晰：自绘 `FSlateDrawElement::MakeBox` 必须显式传入最终填充颜色，不能只设置画刷的Tint；可使用白色画刷配合 `Color * WidgetTint`，或按SBorder的方式合并Brush Tint。当前时钟已修正填色，并用不透明昼夜弧线和带暗色轮廓的亮指针建立对比；构建与用户实际视觉体验分别交付。

折叠时同时控制正文、外框、模糊、分隔线和命中区域的生命周期；隐藏正文不会隐藏兄弟层的白色轮廓。展开／收起使用同一个可反向的动画进度，裁剪范围随高度变化，结束后折叠不再占位的内容。参考 `ColdSteelEventTimeline.cpp`，保留原项目的缓动与标记移动节奏。

## 技能成长与升级提示

参考 `Skills/ColdSteelSkillRules.cpp`、`ColdSteelSkillModel.cpp`、`ColdSteelProgressNotification.cpp`。把技能配置、存档进度、收益计算、命中归属与页面分开。常驻属性加成从等级派生，不重复写入基础属性；武器倍率与角色攻击分别计算，防止刷新模型时叠乘。

飞行子弹在发射时保存技能归属与倍率，换枪不改变已发射子弹。击杀与要害经验并入同一次角色存档事务；通知在提交成功后排队，旧存档补入技能不产生虚假的升级提示。暂停同步冻结提示和声音，页面关闭不撤销已提交成长。

## 资源、归档与交付

图标保持银灰拉丝面、石墨凹槽、细倒角、左上柔光；不烘焙名称、数量或状态。生成图是候选；真实游戏预览必须来自 UE 实际渲染，而且仅在用户要求时制作。工具不能选择模型时不声称使用 image2.5。RGB 经材质去黑不能称作 RGBA 原图。

有效背景、已接入分类图标、来源／许可和恢复工具保留；`Candidates` 只是路径名，不是废弃依据。确认退役且属于任务范围的文件按 `WORKFLOW.md` 归档到 `trash/<task>/`，记录原／目标路径、大小、SHA-256、原因、替代物并更新链接；不清空 trash 或删除历史证据。

发布按根目录 WORKFLOW 的仓库规则，仅提交授权范围，保留他人暂存和未提交内容。维护本技能和工程镜像一致。交付分别说明规划、制作、接入、必要构建、用户请求的预览／测试；未测试交由用户测试，不引用旧案例数字声称本轮通过。
