# 名册卡片与并排装备详情

商店和个人名册可复用同一张卡片，用永久 ID 区分浏览、购买和管理。加号打开详情，交易由详情中的明确操作提交。列表复用共享图集，条目只携带绘图和显示所需字段。对相同名册的等级刷新保留滚动位置，重名短编号放在能够独立显示的次要信息行。

详情与真实背包并排时，沿用已有装备格的空槽、穿戴图、品质色、拖放反馈与只读状态。标题和操作条固定，中间内容滚动。窄宽度下允许生命与体力分行；文字和数值分别沿用项目字体。为主图限定高度，避免图片原始尺寸撑开标题区。

收到界面检查请求时，离屏夹具先初始化真实 UMG 控件，补上实际宿主的 DPI 变换。用同名对象、满格或空格、宽窄两档覆盖截字和滚动边缘。区别控件检查、完整 HUD 点击和真实联网交易。

## 卡片高亮、详情抽屉动效与变行附属空间背包（R49 / R53）

- **选中与进详情解耦**：点击名册/商店卡片只切高亮，点击明确「详情与马具」按钮才驱动右侧详情抽屉滑出/收回（`4.0/s` `EaseSmooth`）；点击详情区背景与「返回名册」仅关闭抽屉本身，不得冒泡关掉整个外层界面。
- **复用玩家空间背包承载变行附属容器**：通过 `Place=4` + 命名空间容器键（如 `mount.<HorseId>`）与可配行数 `ColdSteelWarehouse::PageRows(InCapacity)`（支持 `0/2/4/6/8` 排 × 18 列）直接复用拖拽、旋转、堆叠、交换回填、拆分、整理与双击快捷穿戴；会话开启时缓存 `CachedMountBagCapacity`，保证 `NativeTick`/`NativePaint` 期间 `OpenStorageCapacity()` 为 O(1) 整数读取。
- **词条展示与浮点格式化**：乘算后的浮点属性显示前先做确定性舍入（如 `RoundToFloat(V*10)/10`），避免出现 `9.900001`；词条与装备 PNG 图标用 `TMap` 纹理+笔刷常驻缓存，切卡零重复磁盘导入。
