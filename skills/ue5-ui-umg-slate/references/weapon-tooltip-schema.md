# 武器浮窗固定格式与字段命名（2026-09-27）

用户要求弓参考枪械统一浮窗，不再把相同属性写成“自卫伤害”“满拉武器伤害”等不同字段。适用于枪械、弓、近战武器及可装备生产工具；长杖普通攻击沿用同一伤害格式，法术参数独立显示。

## 固定结构

沿用现有冷白鉴定卡：物品标题与元信息 → 核心属性及数值条件 → 改造与附魔 → 详细参数 → 物品说明。详细参数先复用核心摘要，再显示物品信息、战斗参数及类型专属机制；同标签同值只显示一次。无对应机制不造字段，例如弓没有弹匣、空仓换弹。

- 枪械六项：武器总伤害、攻击间隔（连发武器用组内射击间隔）、弹匣容量、有效射程、普通换弹、空仓换弹。
- 弓六项：武器总伤害、拉弓耗时、搭箭耗时、最大飞行距离、体力消耗、开镜耗时。
- 近战五项：武器总伤害、攻击间隔、体力消耗、最大攻击距离、格挡伤害减免。
- 工具四项：武器总伤害、攻击间隔、体力消耗、最大攻击距离。采集参数单列；不冒充战斗属性。

## 唯一字段表

代码名称统一取 `Source/FPSGAME/UI/ColdSteelWeaponText.h`；浮窗摘要、详情、改造总览、改造件明细和强化预览使用相同常量。不要在渲染层临时替换名称，也不要按武器类别重新造一份同义名称。

| 固定名称 | 数值含义／单位 |
|---|---|
| 武器总伤害 | 当前条件下基础物理、附加物理、附加魔法之和 |
| 基础物理伤害 | 经过现有角色、强化、改造等计算的基础物理分项，不等于目录原始值 |
| 附加物理伤害／附加魔法伤害 | 来自共用伤害评估；有对应分项才显示 |
| 基础伤害 | 改造倍率作用的基础分项；不能把它写成总伤害增加同样百分比 |
| 攻击间隔／开镜耗时 | ms，整数；“挥砍间隔”“进入 ADS 耗时”不另作名字 |
| 体力消耗 | 当前动作条件下的消耗；“满拉”“含重击”移到数值条件 |
| 弹速 | m/s；枪弹和箭矢使用同一名称 |
| 弹匣容量 | 发；不用“弹容量”与其混写 |
| 弹药／弹种效果 | 枪弹与箭种共同使用 |
| 弹药修正后伤害 | 武器总伤害 × 当前弹种伤害倍率，仍未计目标防御与暴击 |
| 普通换弹／空仓换弹／拉弓耗时／搭箭耗时 | s，最多两位小数 |
| 腰射散布半角／腰射散布倍率 | 分别为 °／×，不能仅为统一名称把它们合并为同一指标 |

所有数值保留现有运行评估来源，不调整武器平衡。伤害详情由同一 `DamageRows` 按“总伤害 → 基础物理 → 附加物理 → 附加魔法”生成；公式说明行用“伤害组成”，不再次占用总伤害字段。名称、单位、公式和计算范围必须一致。

## 条件与比较

- 公共属性名不夹带武器专属前缀。弓写“武器总伤害”，数值条件明确“满弓单箭，已计蓄力倍率”；枪械按单次射击、近战和工具按普通单次攻击。
- 弓蓄力阈值与倍率从 `ColdSteelBow::MinimumFireDrawFraction / DrawDamageMultiplier` 生成详细说明，不能把满弓数值误说成未蓄力基准。
- 明确哪些因素未计入：弹种、暴击／要害、目标防御、距离衰减按实际机制说明，不能杜撰伤害加成。
- 有效射程（全伤害范围）与最大飞行距离（箭矢飞行上限）含义不同，保留各自名称及比较键；拉弓耗时不冒充攻击间隔，连发组内间隔也不直接与单次攻击间隔相比。
- 伐木伤害对树木生命值结算，保持在采集参数。矿镐按有效命中次数采集；不要为表面统一而合并这两条业务。
- 改造汇总按所属类型读取 Gun／Bow／Melee／Tool 的真实评估，弓不能落入枪械分支。
