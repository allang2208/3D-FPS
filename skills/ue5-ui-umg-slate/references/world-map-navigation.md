# 实景底图、地图输入与标记表现

适用于 FPSGAME 的 M 键地图、正交底图、地图标记和 HUD 避让。修改前读取当前工程冷钢 UI 规则；下列经验不授权启动编辑器、截图或运行测试。

## 坐标只维护一份

底图采集与玩家点、标记、轮廓共用注册数据：中心、正交宽度、尺寸、朝向与世界原点。FPSGAME 的 +X 为北、+Y 为东；屏幕纵轴向下，正反变换成对实现。禁止凭截图估算比例或单独给玩家点补偏移。世界原点重定位后，本地显示坐标重新换算，网络数据保存绝对坐标。

主神空间使用真实场景正交烘焙与已保存贴图；只保存烘焙脚本不算底图交付。丘陵俯视底图必须包含实际材质，等高线高度来自地形实际三角形插值；水域遮罩与地形共用投影。灰色底图先核对材质加载、采集对象和贴图读取链路。

## 地图打开时仍可移动

会话数据独立于 Slate 视图，地图关闭仍按本地控制器更新探索和标记。地图不暂停游戏；保留移动轴、跳跃、冲刺和滑行动作，以及已按住按键的 release。地图按钮不夺键盘焦点，文字输入期间才临时锁移动并使用 UIOnly；退出编辑只释放自己取得的锁。

打开时收起 Buff 和任务追踪及其浮窗；关闭时读取当前效果和当前任务再显示，不能恢复开图前的过期快照。传送遮罩接管输入前先关闭地图；地图销毁不得覆盖传送的焦点和光标归属。保持 Alt 光标模式的进出状态。

## 冷钢标记与光柱

地图、360°方向提示和世界光柱读取同一标记视图，颜色保持一致。文字横排、标签优先保留距离和楼层；窄屏缩短名称、让行或滚动，避免汉字竖排。队友标记显示来源与只读语义，不能占用本人的编辑/删除入口。

OnlyOwnerSee 根据观察视角的 actor ownership 判断可见性。将本地非复制光柱的 Owner 绑定到实际 GetViewTarget()，不能仅设置 PlayerController；重生或换观察目标时更新。区分 actor/材质存在与真正画面可见，无渲染检查不能证明光柱亮起。

个人迷雾、共享和实例边界见 [标记共享与个人探索](../../ue5-save-load-replication/references/map-markers-and-personal-fog.md)。实现入口：ColdSteelWorldMapData、ColdSteelHubMapRegistration、ColdSteelHillsMap、SColdSteelWorldMap、ColdSteelMapMarkers 与 FPSGAMEGameMenu。
