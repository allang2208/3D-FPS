# 成品参数与准备提示

- 成品预览和物品浮窗共用 BuildColdSteelItemTooltip 的 Summary/ValueScope，保留同一字段、单位和角色计算口径。未制作时读取配方物品；完成后读取 ForgeJob.Item 的真实 _forgeQuality，不在UI复制品质伤害公式。
- 参数刷新沿模型 OnChanged/配方选择的脏标志执行；不要在每50ms的计时刷新里重建浮窗或控件。左右均分使用相同 Fill 权重和对称间隔，详情可独立滚动，图片按比例适配。
- 配方下拉栏复用冷钢按钮及列表行样式，文字中心补偿右侧箭头占位。程序同步选择使用 Direct 回调保护；正在制作和成品未处理时，在控件禁用和选择处理两处沿用业务限制。
- 体力条上方准备提示复用现有提示行，直接读取架枪/冲刺/蓄力的真实归一化进度，不再启动计时器。当前设计为红、黄、蓝、绿四节点线性渐变，完成为绿色，字体16px；位置和尺寸只做一次DPI换算。
- 出征概念横幅用等比UV裁切保留圆角，标题独立叠放。不能将概念图称作关卡实拍。
- 构建成功只代表代码/二进制，未运行游戏时明确由用户测试。
