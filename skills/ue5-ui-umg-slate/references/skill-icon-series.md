# 冷钢技能图标系列

制作前实际打开当前 skills.json 引用的已选PNG，读取尺寸与色彩模式，并以图像作为生成参考；不能只凭“冷钢”“银框”文字猜风格。

FPSGAME 当前非元素技能基准：1254×1254 RGB PNG，顶部尖角的拉丝银色六边框、石墨凹面、中性黑灰底、左上柔光、居中金属浮雕，无烘焙文字。保持框的比例、边距与光照，只替换中央技能符号。不要生成方框、整幅战斗场景、碎石环境或大量火花。元素技能只按已选规则把身份色集中到主体。

重击使用步枪精通、暴击的现用图作参考，将中央主体换成宽刃剑冲击金属砧块。以小槽位辨识为目的，轮廓清楚，少量浮雕冲击线，主体完整留在框内。

正式PNG放项目Content，作者选定源保留SourceAssets，恢复脚本指向选定源；技能列表、详情、拖影、快捷栏和升级通知共用定义路径。替换同名图时注意已加载纹理缓存，告知用户重新进入游戏。废案进trash并记录大小/散列/替代路径，生成工具默认目录不能作为正式依赖。生成结果展示不等于游戏UI验收。
