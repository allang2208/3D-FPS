# 冷钢生存状态栏

FPSGAME 当前左下栏采用用户选择的 A：等级及生命／魔法在上，饥饿／水分／SAN 三列在下。复用正式冷钢字体、玻璃和金色圆角线；三种颜色只用于指标轨道，面板保持中性色。

- 等级框固定 64×56px，左对齐、垂直居中；生命／魔法使用右侧余宽。将这两块放在独立核心 Grid 中，再与整宽生存行合并。
- `USizeBox::WidthOverride` 只影响期望大小。跨列的宽内容参与同一 Grid 测量、且等级槽为 Fill 时，会把等级框拉大；不能仅继续减小 WidthOverride，应隔离列测量并明确对齐方式。
- 不增加新的数值来源或高频刷新器；HUD 读真实生存组件，状态变更才更新文本／颜色，进度条复用 `SetSemanticValue` 的 Paint 失效。
- 饥饿／脱水提示优先显示损血规则，SAN 归零显示消耗翻倍／六维减半。左上“精神崩溃”持续状态保留完整说明，直到 SAN 恢复。清泉赐福用既有状态卡的空层数区域显示 `mm:ss`。
- 离线方案图与游戏截图分开。用户选择后的旧 A/B 候选可按授权归档，正式作者脚本保留；没有重新渲染的旧图不能写成当前布局的运行证明。

实现与历史设计入口：`ColdSteelTopVitals`、`ColdSteelResourceMeter`、`ColdSteelUIStyle`，以及 `Docs/UI/survival-hud-plan-20261003.md`。
