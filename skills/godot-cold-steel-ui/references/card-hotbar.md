# 卡片词条与快捷栏校准

- 原网页外观必须读取基础CSS、主题覆盖及创建DOM的JS。尺寸要同时核对box-sizing、边框和padding；原快捷栏48px是border-box总尺寸。
- Godot PanelContainer的padding设置在StyleBox内容边距，不能用不存在的margin主题常量。外框宽度取容器实际最小尺寸，避免多算分隔线或隐藏槽造成偏心。
- 本项目快捷栏：右下按键、顶部居中数量、40px居中物品图；保留当前Q/E/X与1–4业务绑定。不能因源项目存在C键而新增游戏功能。
- 圆角卡片色条需要同步内缩和圆角；稀有度、强化、改造、附魔共用几何规则，图片与角标避让可见词条。加工状态读取原标记与实际配件/附魔前后缀数据。
- 同帧重建控件时先从父节点移除旧子节点再queue_free，防止按名字取得仍待释放的旧词条。清空物品时重置可选控件引用。
- 实际引擎检查小窗口下词条边界；三字加工标签高度不足时省略“已”，不要缩放字体。截图fixture先确认物品ID仍存在，不能用空字典渲染结果验收图片。
- 验证入口：tests/test_badge_fit.gd、tests/test_hotbar_glass.gd。同时隔离INVENTORY_SAVE_PATH和GAME_SETTINGS_PATH，并提前建立保存目录。最终截图保留，淘汰预览只移动本任务明确归属的文件。
