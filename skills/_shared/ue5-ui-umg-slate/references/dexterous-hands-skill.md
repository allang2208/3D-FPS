## 技能图标选择与巧手换弹修炼

新增技能前同时读取当前 `skills.json`、SourceAssets 来源及用户选择记录。2026-09-13 已选的银灰六边形 M4 图一度仍在 Candidates 而运行时加载旧图；当前正式路径为 `Skills/rifle_mastery_cold_steel.png`。巧手 `dexterous_hands.png`、闪避 `dodge_cold_steel.png` 沿用这套拉丝银色／石墨凹面风格，不再参考旧金蓝徽章。列表、详情、升级通知共用配置图标路径；新图恢复入口 `Tools/UI/prepare_cold_steel_skill_icons.py`。不要把候选文件夹等同于用户未选定。 原因：重建需要真实的上游输入及先后顺序，仅保留最终输出无法恢复可编辑制作链。

巧手常驻敏捷从等级派生，保持基础属性存档不变；换弹速度以 `1 + 等级 × 0.01` 为倍率，角色每次从枪械／配件基础耗时重新计算，禁止在已缩短的时长上再次除倍率。换弹开始固定动作时长，保留既有源时间映射，使普通／空仓／弹鼓／手枪的姿态和机械事件同步。实际补弹成功后才在同一弹药存档事务加入经验，取消、无弹、满匣不奖励；测试地图无限备用弹分支同样走该事务。旧存档版本 3 补巧手进度，不重置既有技能或产生迁移升级提示。 原因：姿态、机械事件与命中必须引用同一进度，分别累计会在变速和停帧时错位。

界面继续复用明确可用宽度、短标签不换行、修炼方式独立卡片；属性详情显示基础敏捷与巧手加成，枪械实值显示技能后的耗时。实现完成后只做必要构建，未请求时不自动测试。 原因：制作授权不包含额外运行或验收，交付应保留未测试的实际状态。
