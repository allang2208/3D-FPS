# 名册卡片与并排装备详情

商店和个人名册可复用同一张卡片，用永久 ID 区分浏览、购买和管理。加号打开详情，交易由详情中的明确操作提交。列表复用共享图集，条目只携带绘图和显示所需字段。对相同名册的等级刷新保留滚动位置，重名短编号放在能够独立显示的次要信息行。

详情与真实背包并排时，沿用已有装备格的空槽、穿戴图、品质色、拖放反馈与只读状态。标题和操作条固定，中间内容滚动。窄宽度下允许生命与体力分行；文字和数值分别沿用项目字体。为主图限定高度，避免图片原始尺寸撑开标题区。

收到界面检查请求时，离屏夹具先初始化真实 UMG 控件，补上实际宿主的 DPI 变换。用同名对象、满格或空格、宽窄两档覆盖截字和滚动边缘。区别控件检查、完整 HUD 点击和真实联网交易。
