# 伙伴名册与装备归属

装备从角色背包移到坐骑或伙伴时，用永久角色与伙伴 ID 查找服务端拥有的物品实例。按正式物品定义确定槽位。换装在同一份状态副本中完成，连同原物的放回位置一起提交；容量不足时整笔放弃。移出背包的实例同时清除旧快捷栏绑定。

若名册活动状态和背包事务经不同网络通道送达，名册序号只决定出战、等级等名册字段。已穿戴的实例跟随对应库存版本合并，普通召回或选择消息无须反复发送整套装备。整档镜像和即时回执分别到达时，保持背包和已穿戴栏来自同一次物品状态，避免物品在旧镜像中回到两个地方。

用户要求联机验收时，用同一物品 ID 贯穿错槽、穿戴、替换、卸下、重连；分别检查服务器、拥有者和背包。共享经验按角色实际获得值结算，在场伙伴与离场伙伴分别取样。记录主机类型、客户端数量和网络条件。
