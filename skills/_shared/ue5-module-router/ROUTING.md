# UE5 模块映射参考

本资料由 ue5-auto-assistant 按需读取，不再作为独立技能触发。

- 用户给出模块名且需要定位时，在 [模块映射表](references/ue5-module-routing-table-final.csv) 中按模块名匹配，再参考 Build.cs 路径与别名。原因：相近模块名称可能属于不同层级，路径可补充实际职责信息。
- 选择对应领域技能；跨领域只补充必要的次要技能。无匹配时根据实际任务选择，不要求用户提供模块名。原因：领域路由服务实际任务，不应让用户承担内部模块分类。
- 用户要求更新映射时，使用 `../ue5-architecture/scripts/generate_module_index_v2.py`；保留当前目录位置供生成脚本写入 references。原因：生成器与输出位置已有配套关系，移动目录或默认重扫会扩大本次资料维护范围。
- 映射只提供入口；实际 API 和工具参数以当前代码、引擎及可用 schema 为准。原因：静态映射不会随本机版本和工具状态自动更新。
