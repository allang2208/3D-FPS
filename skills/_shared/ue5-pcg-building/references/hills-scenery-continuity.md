# 丘陵地形与群落的连续性

适用于 FPSGAME 运行时高度场、河湖与树簇地编。丘陵不是 Landscape；PCG 消费确定性的高度与摆放规则，换成图节点不会自动增加美术层次。

- 保留世界身份时，分开选址旧基线与最终地形塑形。进村路取消独立路堤后，旧坡度仍作为 `GradeForSiteSurvey` 的选址输入，否则相同种子也可能换村庄位置。道路走向与保护掩码保留。
- 河湖交汇处分别连续计算河床、湖岸，再平滑合并；按“最近水体”硬切高度会制造阶差。地形岸坡过渡距离与植被裸岸排除距离分开，避免整圈宽阔无草带。
- 树簇采用跨地块连续、种子确定的群落权重，保持候选格及采集 ID。林床材质、草的疏密、枯枝碎石与树干/岩石伴生点共享适宜性；保留道路、水岸、暂停区域的排除边界。丘陵黄草与雨林绿草从各自调色板取值。
- 落地支撑使用扣除正负 bounds extension 的实体包围盒；风动/剔除的渲染扩展不是物体脚底。中心与脚印角点从同一实际高度场取样。
- 开放扫描岩壁补背面时，保留原扫描 UV/法线，新侧面单独分配连续 UV 与材质槽。把扫描 UV 拉到封口会形成条带。封闭、碰撞正确不等于外观认可。
- 固定地面变换不移动时，根与地面块用静态移动性，地形编辑替换网格，地标子组件与根的移动性兼容。角色纠正原因见 [生成地面联机](../../ue5-save-load-replication/references/hills-generated-ground-network.md)。

仅在用户要求截图时，等完整资产批次、附近地形碰撞、PCG 单元和实例计数稳定，再留渲染预热帧。同机位保留就绪计数，不用提前拍摄的缺树远景否定树簇规则。暂停布局后的技术证据不能写成美术验收。 原因：源码、磁盘资产、二进制和运行效果属于不同交付阶段，需要各自的完成依据。
