# PCG 建筑图的可复用结构

- 地块或样条先按实际坡度、区域、排除标签和占用合同筛选，再生成底座变换。原因：合法输入位置需要同时满足尺寸与可建条件。
- 楼层展开沿用层高、枢轴、朝向与区域样式；门窗、侧面、拐角和顶层装饰按各自语义选件。原因：仅重复摆放同一模块不能表达完整建筑的边界和连接关系。
- 随机选择使用明确种子、稳定点顺序和本次生成固定的样式键。原因：输入顺序改变仍会使相同 seed 产生不同布局。
- 高频静态部件使用现有实例化路径，交互和独立状态部件保留 Actor 身份。原因：显示合并不能抹掉玩法对象的独立行为。
- 图的节点和属性只保留本次需要的环节，不强制最少节点数或统一的输入到输出模板。原因：现有图可能已经提供某一阶段，重复节点只增加维护成本。
- 运行时边界、调度和刷新 API 以当前项目为准，不保证旧模板在所有 UE 小版本可运行。原因：插件版本及项目配置决定实际执行路径。
- 删除固定 4 ms、50 Actor、2000 实例、10000 点和连续五次超标的全项目规则；只在用户要求测量时使用其指定预算。原因：未经具体场景和硬件确定的数字不能成为现有内容的修改门槛。
