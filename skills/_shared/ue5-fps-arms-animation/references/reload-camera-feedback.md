# 换弹镜头反馈 RC1

当前实现与逐枪覆盖表：[换弹镜头标准](../../../../Docs/Weapons/reload-camera-standard-20261013.md)。2026-10-13 根据用户要求统一枪械换弹屏幕反馈，实机幅度仍待用户体验。

- 机械接触使用 `Weapons/WeaponReloadCamera.h` 公共表，手枪/步枪/重型档为 0.8/1.0/1.1；RSH-12 为 1.0。换弹 `ReloadStrength` 独立于旧装备动作倍率。
- 镜头从 `AFPSGAMECharacter::BuildReloadCameraTracks` 取得各手源时间与语义接触，由 `UWeaponActionCameraComponent::Apply` 合成一次；不要给每把枪再叠一层 CameraShake。 原因：姿态、机械事件与命中必须引用同一进度，分别累计会在变速和停帧时错位。
- 保留动作、握持、音效和弹药提交时序。覆盖普通/空仓、弹鼓/弹箱、逐发/装填器、双持/副手及中断后闭锁。 原因：动作需要持续接触实际武器或道具，只有骨骼位置接近并不能保证真实表面贴合。
- 左轮录音预卷不是镜头接触时间；Super90 逐发跳过源循环后的闭锁必须转换到连续进弹时间，装填器整次推送只做对接/压实反馈。
- 双持同拍反馈统一限量，换弹总输出使用连续幅度上限；结束与打断都回零，不带入下一次动作。作者背景运动属于跟随，机械冲量使用公共表。
- 源码排查和后台构建不代替逐枪实机验收；遵守用户默认不测试、不主动启动编辑器的规则。 原因：后台产物能够直接保存，启动交互进程会引入额外占用和未保存状态。
