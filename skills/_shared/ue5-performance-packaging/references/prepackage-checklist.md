# 用户指定的打包准备参考

- 只有用户要求打包准备或对应检查时才使用本清单；普通开发不触发扫描或运行包。原因：打包就绪与功能制作是不同交付范围。
- 读取目标地图、GameMode、平台、RHI、插件和 cook 配置，只处理本次发行需要的依赖。原因：发布包需要包含实际入口，而不是项目中所有历史资产。
- 必要构建沿用目标配置和增量流程，不要求固定 Clean Development 或额外 Shipping 构建。原因：配置由交付目标决定，强制清理会增加与本次任务无关的成本。
- 读取该次构建/cook 的真实返回状态与首个失败依赖；不能以删掉需要的 cook 项来掩盖失败。原因：没有错误日志并不表示产物包含所需内容。
- 重定向、素材授权和大资源影响只在本次范围内处理，不把“修复全部重定向”作为默认步骤。原因：这些资产可能仍被其他入口或制作链使用。
- 启动发布包、检查玩法/存档/UI 仅在用户明确要求运行验收时执行。原因：成功生成发行文件不能自动授权启动应用，也不能证明运行体验。
