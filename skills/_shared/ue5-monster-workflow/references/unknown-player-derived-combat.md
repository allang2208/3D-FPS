# 未知：玩家装备驱动的人形敌人

适用于增加类玩家敌人或排查未知的武器、动画和战术，不用于改写玩家装备数值。

## 装备与伤害来源

- 服务器创建怪物自己的装备模型，按武器分配等级属性，再复制性别、等级、套装、武器和动作；客户端不能重新随机或读取本机玩家档案生成怪物面板。 原因：怪物属性属于服务器确定的世界状态，客户端本地档案和随机数不能重建同一权威面板。
- F6 按近战、枪械、魔法、弓四类和 10/20/30 级登记。近战锁子甲，魔法法袍＋法杖／魔法书，枪械使用其余获准套装，弓手保有弓和双弯刀两份装备快照。
- 换武器后重新缓存面板不能回满当前生命／体力。已经发射的箭保留发射时的物理／魔法比例和穿透快照，切回双刀不能改变飞行箭的伤害。 原因：换装不等于恢复资源，已发射投射物也应保留发射时的伤害身份。
- 怪物伤害倍率、单发／整轮／持续每秒上限集中在 `MonsterDamageBalance`。审计真实武器和全部法术，区分散弹总量、爆发、持续跳伤及附加状态；不修改玩家目录或共享技能基础值来削弱敌人。
- 枪械无限备弹仍走真实弹匣和换弹。法师无限魔法仍遵守准备、释放、冷却和取消；不要把无限资源等同于绕过动作合同。 原因：机械部件与手部动作需要对应实际武器状态，移植表现时不能替换原有机械事件顺序。

## 战术和动作合同

- 持枪、弓、法师各自按射界、武器／技能射程、当前接近速度和动作可移动阶段决定侧移／后退攻击。丢失视线后追查记忆位置，不持续追踪遮挡后目标的实时坐标。
- 弓切双刀与切回弓使用不同距离阈值，配合安全持续时间和撤退冷却；法术取消要清掉待接触／引导状态并允许随后重新选择，不能保留忙碌锁。 原因：冷却的起算时刻和倍率属于施放合同，界面与执行路径不能各自扣减一次。
- 障碍和同伴阻塞分别处理，保存近期失败路线、有限绕行、让路期限；不因每次目标更新都清空路线记忆而反复撞墙。战斗朝向与导航平移分开，侧退不能靠转身背对目标实现。
- 伤害接触、动作、握持使用同一武器家族的时钟和实际握点。移动近战检查下身步态是否继续采样、腰部混合是否重复旋转；玩家与未知复用相同的时序／脊柱混合帮助函数。
- 自建原生 AnimInstance 节点没有蓝图生成的 NodeData 时，不要调用依赖该数据的访问器；使用支持 standalone 的节点实例和正确初始化。`SetPosition`、资源已加载或构建成功都不证明实际姿态已更新。

## 同步与后续检查

复用玩家技能还需要核对目标类型、死亡适配、奖励归属和远端时钟，见 [类玩家怪物的伤害与生命周期](../../ue5-save-load-replication/references/unknown-combat-lifecycle.md)。 原因：玩家与敌人的目标、死亡和奖励归属不同，直接复用技能实现仍需沿用敌人的生命周期和权威边界。

当前入口为 `Monsters/UnknownHumanoid*`、`UnknownSpellCombat`、`MonsterSpellAim`、共享 `Characters/FPSBodyGunAim*` 与 `FPSBodyMeleeTiming`。源码存在战术分支不等于实战 AI 已验收；NullRHI 联机只能确认状态／结算，头发、手部、腰部、脚步和枪口画面仍需单独授权的视觉检查。
