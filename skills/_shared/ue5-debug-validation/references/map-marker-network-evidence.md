# 地图联机证据与归档

仅在用户明确要求联机/运行检查时执行。整理、推送或技能沉淀不是重跑测试的授权。

轻量地图夹具应隔离档案和输出，并在整个主客机批次持有既有运行互斥；复制主模块及所需原生插件 DLL，记录哈希和启动 PID。无关技能资源预热若耗尽内存，可用仅开发环境的显式夹具开关跳过，不能全局关闭正式游戏预热。支持时使用 -Multiprocess，避免测试宿主触发无关 SDK 校验/构建锁。已有 UE/PIE 与其他任务进程不能当作可清理的测试进程。

同一用例分开记录：正常 UDP、弱网 UDP（读回实际 NetDriver 延迟/丢包值）、模拟生命周期、Slate 输入以及渲染。退出码与最终完成回执同时保留；中断批次保留中断原因，不能用部分通过项代替完成回执。 原因：批处理的启动结果不等于内部构建结果，交付必须依据实际结束状态。

2026-11-15 地图共享记录：正常与弱网各 21 项，弱网读回为 60ms / 2%；独立模拟地牢生命周期 64 项。前两组使用真实 listen host/client UDP，后者没有 socket。NullRHI 仅覆盖标记数据与光柱 actor/材质状态，未证明鼠标、光柱画面、真实多人整段地牢或公网/专服。此处是历史案例，不代表以后版本已经验证。

归档时保留可复用脚本、精简结果、退出码、测试版本及源/资产哈希。临时宿主、DDC、复制 DLL、截图和失败候选移至本任务 trash；目录链接只移动链接本身，不遍历或删除目标。按原路径、目标路径、字节数与 SHA256 记录清单，旧文档链接指向保留回执或明确归档位置。
