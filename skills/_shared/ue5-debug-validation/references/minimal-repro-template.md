# 最小复现记录模板

仅在用户明确要求复现或运行诊断时执行步骤；已有证据可直接填入并标注日期。原因：模板记录信息，不是自动启动场景的授权。

| 字段 | 填写内容 | 原因 |
| --- | --- | --- |
| 环境 | 实际引擎版本、地图、相关资产/类、网络模式 | 这些条件决定能否重现同一执行路径。 |
| 触发步骤 | 按实际顺序记录最少必要操作 | 缺少顺序会混淆初始化与正式操作阶段。 |
| 预期 | 用户要求或既有合同中的结果 | 没有预期便无法区分缺陷与原有设计。 |
| 实际 | 真正发生的结果及首次异常时刻 | 不用推测填补未观察到的步骤。 |
| 证据 | 已有日志、用户要求的画面或状态记录 | 不同证据覆盖不同层，不强制每次同时生成截图和转储。 |
