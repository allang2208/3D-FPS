# 场景迁移与用户指定的出生点排障

- 修改范围先定位实际地图、子关卡和 LevelInstance；需要隔离修改时分别保留对应作者输入。原因：复制持久地图不一定复制其共享子关卡，局部制作可能仍写到原场景。
- 迁移地图使用现有 Unreal 资产重命名入口，保存本次相关地图、外部对象和配置，按实际消费者更新路径。原因：文件系统移动无法维护全部包引用和编辑器路径。
- 背景制作与必要保存照常完成；独立读回、场景运行、截图与回归只在用户明确要求时执行。原因：制作回执不自动授权另一轮世界检查。
- 用户要求出生或悬空排障时，读取实际 Pawn、移动模式、重力、胶囊、支撑对象和简单/复杂碰撞。原因：角色可能站在不可见的碰撞体上，零垂直速度不能单独证明重力关闭。
- `NO PLAYERSTART with positive rating` 先按实际遮挡与流送条件定位，不直接解释为没有 PlayerStart。原因：出生评分同时受可用状态与碰撞影响。
- 只修复已定位的支撑或碰撞组件，保留表面高度、材质和其他通道响应，不补巨型地板遮盖错误。原因：额外地面会改变其他交互和落地查询，不能恢复目标表面的真实合同。
- 流送就绪依赖实际必要资源与碰撞，不把一次诊断中的固定延迟推广为生产规则。原因：不同机器和场景的加载耗时并不相同。
- 用户要求运行验收时按指定范围观察起跳、下落、落地、移动与真实支撑；区分退出码、失败标记和画面证据。原因：进程正常退出或无渲染通过不能证明完整游玩路径正确。
- 物理查询需要合适的 World 上下文；优先适用的后台方式，只有具体必要操作无法后台完成时才按项目规则使用编辑器。原因：空查询可能源于未初始化的世界，不能据此认定场景缺少碰撞。
- 共享构建和编辑器占用由现有互斥等待；不联系其他对话，不终止其进程。原因：当前任务不能处置其他任务的未保存状态或构建工作。
- 仅在用户授权清理或发布时处理本次拥有的废案、精确源码与恢复资料，保留合法素材和实际作者依赖。原因：源代码发布不等于含第三方资产的地图已经获得再分发许可。
