# 性能退化归因与内存警告

- 用户反馈“以前正常，更新后变慢”，先确定回归边界；当前最大资源或最慢渲染项不自动等于新增回归根因。
- 同地图、视角、分辨率、画质、存档、天气和 PIE/独立运行状态比较；默认出生点离屏测试不能替代用户卡顿现场。CPU/GPU 时间有重叠，线程等待不得相加或误报为 CPU 计算耗时。
- 纹理流送池超预算不等于整张显卡显存耗尽。光追几何常驻内存超过预算一定百分比的警告，应区分常驻占比阈值和总预算超额。
- 区分 RHI 分配/保留、驻留显存、驱动总占用与进程系统内存；资源类别有交叉，不直接求和。memreport 的资源统计不能完整解释编辑器工作集；完整报告可能触发 GC，记录采样前后状态。
- 优先找新增加载、重复组件、阴影/光追实例、流送抖动与反复场景切换；单项对照后才能确认根因。不先隐藏警告、扩大池预算或降画质掩盖问题。
- 仅在用户授权诊断时采样；暂停后写待办及证据路径，不继续运行探针。缺少硬件错误不等于全面排除硬件故障。
