# 下方云海：失败边界与持久配置

主神空间本轮云海被用户认为粗糙、缺少烟雾层次，最终要求隐藏。当前保留源与资产用于恢复，但不能把这些参数写成已认可的云海标准。天空云图仍保留，下方海面继续使用现有喷泉波谱的无交互版本。

## 避免重复踩坑

- 云材质既需要正确的 Volume 域/混合，也需要保存 `used_with_volumetric_cloud`。普通材质编译没有错误，不证明云用途的 shader permutation 完整。缺用途标记与光追几何预算警告分别排查，不靠关闭全局光追或 Lumen 修云。
- 体积云使用逐采样点世界坐标 `WPT_DEFAULT`。不包含材质偏移的坐标可能让这一通路退化为平面采样；物体原点也是常量，不能替代密度场位置。
- 查清昼夜蓝图/构造脚本的设置来源。只写云组件，后续刷新仍可能恢复旧高度、追踪距离或可见性；持久配置与组件状态需要同时修改。
- 太阳根组件会旋转，代表海平面/行星基准的 SkyAtmosphere 不能随它绕转。根据实际层级设置绝对位置/旋转，不能通过移动整个天气 Actor 猜修。
- 线性密度纹理和颜色贴图区分 sRGB、mip、采样器。云内高度剖面保持连续，别先钳成整片 1 后再重映射，使三维噪声在主体内失效。带符号量平方用乘法，避免负底数 `pow` 产生无效值。
- 远处降低细节频率与采样成本，但保留宏观三维云形；突然关闭主体噪声会露出平板。增加采样倍率有实际成本，不能称为免费优化。
- 天气图的百分位阈值只是分布目标，不是透视画面覆盖率。没有测量时，不声称已经覆盖精确 80%。
- 橙红既可能来自真实夕阳，也可能是密度、坐标或散射错误。先分因，不反复加入固定白色发光或补色去抵消整个昼夜光照。本轮固定补色分支已退役，最终云形仍未获认可。

## 隐藏与恢复

用户要求隐藏时，保留共享天空、海洋、天气和引用资产。天气可能持续调用 `SetVisibility(true)`，因此隐藏要写回蓝图开关并设置 `hidden_in_game`，完整重建脚本也必须保留隐藏状态。隐藏并不等于可以把仍被实例/关卡引用的资产移出 Content。

当前入口为 `SourceAssets/GodSpaceLayout20260927/Integration/configure_cloud_sea.py`、`hide_cloud_sea.py`；历史黑屏原因与修复证据见 `Docs/GodSpace/cloud-cumulus-implementation-20260928.md`，当前交付边界见 `Docs/GodSpace/publication-20260928.md`。默认不启动编辑器或重新验收，只有用户明确要求再继续云海制作。
