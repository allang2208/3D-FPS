# 枪械与改造标准工作流

腰射准星、玩家/子弹阴影及模型加载警告排查，参见[反馈与运行报错复查](references/runtime-feedback-debugging.md)。

先读 [枪械主流程](references/weapon-workflow.md)。涉及配件时再读 [改造与 ADS 校准](references/gunsmith-ads.md)，不能跳过其中的骨骼、镜片、原件替换和存档检查。

## 执行顺序

1. 确认实际项目、用户授权、文件归属、当前差异；读取仓库 `WORKFLOW.md` 的整理与推送规则。
2. 先看现有枪械/动作/材质与真实 UI 入口，区分独立部件、合并蒙皮网格、表面包覆件。
3. 先优化建模、轮廓与连接，再复用现有贴图和材质；不靠改光源掩盖法线或材质问题。
4. 通用配件只保留一套几何源；武器适配器负责骨骼、安装变换与眼距。视觉活动点与稳定 ADS 校准点分别求解。
5. UI 使用草稿→预览→应用→实例保存；多型号保存稳定 ID，保留旧布尔值兼容。遵循仓库冷钢 UI 技能与当前字体规则。
6. 按改动运行对应测试：材料/UV、ADS/镜片、动作挂点、枪口、弹药、实例保存、实际渲染。所有运行检查使用独立 `INVENTORY_SAVE_PATH`。
7. 清理只处理本次确认无引用的废案；保留可编辑源、许可、生成器与必要的失败对照。精确暂存、审查差异、普通推送、回读远端 SHA。

## 发布与复用边界

本技能可独立阅读。案例中的 `scripts/`、`tools/`、`tests/` 路径来自 2026-09-06 本地枪械工作区；此技能发布不代表这些运行时文件已全部进入远端。复用前先在当前检出确认文件存在，不存在则按文中合同实现，不能凭空声称已运行测试。

只改本文或引用文档时进行链接、内容、Git 差异检查，不把运行测试当作文档正确性的证明。提交可执行代码/资产时执行主流程及仓库要求的运行检查，并报告已有故障。


## 改造页面与说明格式

新增或修改枪械改造UI时，先读[改造面板最终合同](references/gunsmith-ui.md)。统一SimHei、标题/名称加粗、正文常规；详情仅保留状态、效果摘要与一段主要说明，删除重复参数对比与补充解释尾段。

## 改造件无间隙装配（2026-09-06）

用户要求改造件组装不得有间隙。新增或修改配件时必读[无间隙装配与战术挂件案例](references/attachment-fit.md)：逐枪测量实际表面，检查枪身、底座及组件内部连接；拒绝悬空、重复模型和非设计性穿插。游戏与预览使用同一表面材质处理，保留橡胶和光学部件区别，数值采样结合多角度渲染验收。

## 装备、机械音、开火模式与镭射分态

调整首次装备、动作音效、单发/三连发、腰射与 ADS 镭射、射程或枪管数值时，阅读[对应分卷](references/actions-audio-fire-modes.md)。其中记录源动作取段、独立音效许可、逐发反馈、当前 ADS 跟准心规则及独立发布边界。

## 前握把动作与材质正式接入

调整侧斜握把、装备回握或材质候选正式接入，阅读[专项复查](references/foregrip-material-integration.md)。

## 分区聚合物与小砖点缀（2026-09-07）

新枪与新改造件默认执行[聚合物设计语言与材质标准](references/polymer-style.md)。保留连续枪体，以稀疏精细小砖点缀，采用干净分区聚合物；逐枪校准，逐件装配与动作、镜片、游戏/预览一致性验收。
