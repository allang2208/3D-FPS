# 枪械反馈与运行报错复查

## 腰射散布与准星

准星边界与弹道随机采样必须调用同一半径函数。只更新枪械内部 bloom 不足以改变固定 HUD 半径。持续开火累积、停火延迟、恢复速度都应来自现有武器数据；不要另外给 UI 加一条不匹配弹道的动画。

2026-09-06 本地实现：基础半径乘以 `1 + clamp(bloom / max_bloom, 0, 1)`，达到最大累积时为两倍半径；保留分辨率缩放、枪管倍率、ADS 无随机锥和激光零散布规则。验证五枪连射、上限、停火恢复以及投影采样点不超过准星边界。此公式是本项目本次调参，不是所有枪械项目的固定标准。

## 禁止玩家及子弹投影

设置 `GeometryInstance3D.cast_shadow = SHADOW_CASTING_SETTING_OFF`；不要关闭场景光源的阴影。子弹在创建可视网格时设置，池化复用沿用该实例。玩家先递归处理已有子节点，再在 node_added 信号中按玩家祖先关系过滤新 GeometryInstance3D，以覆盖换枪和改造配件。检查既有模型、动态子树和场景无关网格的设置。

## 截图警告与模型导入失败

场景加载达到资源完成不代表可进入游戏。覆盖层应脱离待销毁场景，在新场景的显式 readiness（含延迟 HUD/玩家初始化）及渲染完成后才到 100%。等待期间保留覆盖层并暂停游戏，结束时恢复原暂停状态；检查连续两次切场景，避免重复实例或旧场景释放打断等待。

- 区分黄色分析警告与红色加载/运行错误。沿最早资源错误往下追，贴图加载失败可连锁导致 PackedScene 加载失败和空碰撞体调用；空值处理不能代替资源修复。
- UID 失效但路径加载成功时，先确认源贴图和 .import 存在。需要刷新模型缓存时用 EditorFileSystem.reimport_files 指定单个模型；仅修改源文件时间可能因为内容未变而跳过重新导入。不要全库清空 .godot，尤其是并行会话共享缓存时。
- 混合 String/bool 的配置使用明确分支返回；保留已有存档类型，不把字符串配件 ID 转成 bool。
- 整数除法先确认用途：索引/分组显式向下取整；时间和比例需保留小数。仅改变量名时不要改字典键、节点属性或信号合同。
- 编译成功不代表所有编辑器警告消失。记录已定位条目、运行检查和仍缺行号的警告，不宣称全库清零。
