# 枪械改造面板：文字、字体与布局合同

2026-09-06 用户最终确认。新增枪械、配件及修改改造面板时先读本文；此文取代早期整段加粗、参数对比区与补充解释段落方案。

## 详情区固定顺序

1. 配件名称：SimHei，加粗。
2. 状态：已安装 / 待应用等，常规字重。
3. 分隔线与“改造说明”分区标题。
4. 效果摘要：只显示真实生效的效果；有利绿色、不利红色，无数值增减的模式/功能用中性色。在白色装备浮窗中，中性效果为纯黑、无描边；深色改造页保持可读的正文浅色，不能机械套黑色。
5. 一段主要介绍：描述配件做什么，不附第二段保留姿态、原件外观、实现原理、未改变哪些参数等解释。

删除详情标题与“改造说明”之间的“已安装 / 预览”参数对比区，包括90% → 90%、容量/倍率/开火间隔等同类行。说明区已有的效果摘要保留，不因移除重复对比而删除实际效果。

前握把示例：
- 防滑前握把
- 已安装
- 改造说明
- 降低10%连射散布增量
- 增加前护木防滑包覆，减少连续射击时新增的扩散。

不再附“保留原握持姿态，不缩小基础散布。”其他瞄具、枪口、弹匣、后握把、枪托（含型号变体）、扳机同步遵守；原厂项目也不追加“选择另一项可预览”等尾段。预览/应用/取消提示放固定操作区，真实保存行为不变。

## 字体与颜色

- 全部UI文字使用装备栏同款SimHei；不恢复YaHei/Consolas分工。
- 标题、分区、物品/武器/配件名称使用embolden 0.9；正文、说明、状态和数字使用embolden 0。
- 标题20px，分区16px，正文14px，辅助12px；保留已明确的HUD例外。图标字体独立保留。
- 使用Style公共入口；本地实现为make_font、make_heading_font、make_item_name_font、make_mono_font及apply_text_role。make_mono_font为兼容接口名，不代表继续使用Consolas。
- 正负号不等于收益方向：降低攻击间隔/装填时间属于有利效果；布尔模式、红点瞄准镜等中性效果不要按true当正数染绿。以实际参数语义判断。

## 浮窗布局

主卡至少460px、改造卡600px、附魔卡300px；按内容自然拓宽，文字不自动折行、不缩字、不压窄说明列。视口不足时允许横向滚动，默认先完整展示主卡；长内容纵向滚动、关闭按钮固定可达。原描述中的必要段落分隔与自动折行不同，改造详情仅保留主要介绍段落。

枪械改造页保持名称与状态独立控件，避免整段按钮一起加粗。修改浮窗规则不自动改动模型预览、配件挂点、战斗参数、库存与存档逻辑。

## 全屏改造页布局

- 顶部武器身份与武器切换卡放在同一紧凑横行；不要重复占用两层标题和说明高度。武器切换卡只承担武器名与装备来源，当前状态通过边框和短状态行表达。
- 中央装配预览按完整装配后 AABB 取景，枪口、枪托、后握把等伸出件必须参与缩放。默认保留约 26% 横向与 46% 纵向余量，避免后续新增长枪口或握把时重新改版；不能只按裸枪取景。
- 八个改造部位使用稳定的水平部位坞。每格保留“部位名称 + 当前或预览中的真实部件名”两行；不支持的部位继续占位、禁用并明确显示不适用，不能靠隐藏导致位置跳动。
- 右侧检查器的扫描顺序固定为候选配件、当前详情、改造说明、整枪最终数值。候选与详情连续排列；弹性留白放在详情之后，使最终数值合集稳定沉到检查器下部。
- 最终数值展示应用后的整枪结果或相对原厂的净变化，并延续收益语义配色。待应用数量紧邻撤销预览与应用改造按钮，三者视为同一操作组。
- 宽度至少 1200 时使用中央预览加右侧检查器；低于 1200 时检查器移到部位坞下方并允许纵向滚动。高度低于 800 时压缩预览与部位格，高度低于 650 时进一步压缩图标，但两行部件信息、部位坞和固定操作区始终可达。
- 视觉回归至少覆盖 1680×944、1280×720、960×540 的同状态截图。重点检查真实部件名是否裁切、右侧候选与详情之间是否出现无意义空洞、底部操作区是否遮挡部位坞。

## 验证与交付

逐枪逐部位检查原厂、预览、已应用、撤销、切枪和空态；核对控件实际字体/字号/字重，不只检查字号白名单。截图检查1920/1280/960、无压缩、边界与滚动可达性。确认中性效果无增益颜色，增减效果按收益方向保留；说明前无重复对比区，正文后无被删除的解释段落。

当前本地验证入口：tests/test_ui_typography.gd、tests/test_gunsmith_panel.gd、tests/test_neutral_craft_color.gd、tests/render_equipment_format.gd。调用前确认当前检出存在这些脚本；不存在时先实现对应检查，不声称已经验证。
