# 装备、机械音、开火模式与镭射分态合同

来自 2026-09-06 M16 和四步枪工作区。区分本地完整实现与公开仓库可用模块；模块发布不等于模型及主场景接入完成。

## 先看源动作与机械部件

- 先实际查看源动作时间轴，再采样弹匣、枪机、拉机柄相对机匣位置，记录动作长短、接触顺序和手部职责。源没有 draw 时，从已就位的换弹后半段提取操作，不把拆装弹匣过程混进装备动作。
- M16 例：源空仓动作从 1.4 秒裁起，补 0.22 秒进入、0.16 秒退出，首次准备约 1.3133 秒；普通切回为 0.62 秒抬枪。保留原手部和机械同步，不凭“武器名”假造保险手指动画。
- 动作可编辑源是原模型加生成器。记录何时算“首次完成”，中断不记完成；不能以播放装备声改变弹药。按当前实现，同型号在一次 Gun 会话共享首次标记，非每物品实例存档。
- 拆分蒙皮网格后必须保留顶点组名称与绑定：M16 曾因新网格遗失 m16a2_base 组而失去正确蒙皮。用全动作、原件隐藏/恢复和网格数量检查，避免残留、重复或静态贴件。

## 音效来源与逐事件同步

- 免费不等于允许发布；模型、手模、动画和音频分别核对许可。组合资产的 CC BY 不能覆盖 Unity 样包手模。公开源码仓库还要确认可编辑源资产的再分发条件，不能只确认游戏使用权。
- 原始音和裁切脚本要保留，写明拿到的是原文件还是公开 HQ 试听版；无账号时不假称拿到了原始 WAV。
- 本例采用 wadaltmon / Freesound 263513 的 CC0 AR15 Various Sounds，作者记录为 Blue Snowball + Audacity 实录。它是 M16 的同平台声音参考，不是 M16A2 专机实录。
- 拆成拔弹匣、插入、压实、拉柄、释放和枪机释放六段；逐事件按动画秒数触发。换弹速度修正移动事件时点，短声保留自然音高和完整起音，不随机变调整段声。首次、快速装备、普通/空仓换弹分别配置；禁止专用声叠加借用声或合成提示。
- 使用同一姿态 delta 和动作速度推进音频时钟；中断清理待播事件及尾音。很久以前已过期的事件不在卡顿后集中补播。AudioStreamPlayer 走 SFX 总线。
- 验证 30/60/144 FPS、加速/减速、重复输入、中断、切枪和弹药；导出实际 Movie Maker 音画并检查瞬态/峰值。无声 GIF、资源存在、事件计数都不能冒充主观试听。

## 单发、自动与三连发

- 用每武器可用模式数组，保留旧 automatic_fire 的兼容默认；物理 KEY_QUOTELEFT（Esc 下方 / 1 左侧）切换，仅捕获游戏输入时生效，忽略键盘 echo。繁忙期/正在按扳机不切模式。
- 现有配置：AKM/HK416/QBZ191 全自动与单发；M16 单发与三连发；P9 单发。HUD 显示当前模式，浮窗显示可用模式；字体、颜色复用冷钢 caption，不另增主题。
- 明确三连发的游戏交互：本例点按完成三发，长按不重复开下一组；菜单、冲刺、建造占用、收枪和换弹取消待发。不要宣称模拟现实机械棘轮余数。
- 三枪必须分别走同一 _shoot 链：弹药、弹丸、枪声、火光、抛壳、机械动画、后坐与抖动。禁止只把伤害乘三或一次叠三份位移。
- 保留射速修正和冷却跨帧余量；本例 100ms，扳机改造后 85ms，最低 50ms。余弹 1/2、松开再按、持续按住、切枪返回均验证。
- M16 三发 pattern (0.009,0)/(0.012,-0.002)/(0.014,0.0023)；保留多轴后推弹簧且组内不重置，高频震颤乘 0.82、附加上翻乘 0.75。参数是游戏调校案例，不是现实枪械数据。

## 镭射：腰射保留模型轴，ADS 追踪准心

- 用户当前要求覆盖旧“所有状态固定轴”规则：腰射/跑动/换弹保持发射器局部 -Z；ADS 从发射器位置指向当前可见准心的场景交点。不要改动腰射来实现 ADS。
- 使用 Gun.aim_screen_position 与当前相机求场景目标，兼容机瞄、红点、后坐和 ADS 过渡；不要另用一个固定屏幕点，导致可见红点与镭射不一致。
- 起点按同帧骨骼姿态求解，晚于 Gun 的姿态更新。先用相机射线求目标，再检查发射器到目标的近处遮挡；不得为了准心重合而穿墙。无命中只画有限长束线，不画悬空光点。
- 四枪 × 两类瞄具 × 2/10/40m × 30/60/144 FPS，检查起点、投影误差、进入/退出、近障碍、无命中。分别验证腰射轴保持和 ADS 对准，不沿用已失效的 ADS 固定轴断言。

## 射程、枪管与多轴后坐

- 有效射程 R 内满伤害，R 到 2R 线性降到 10%，之后保留 10% 下限。按弹丸实际路径累计而非直线位移；复用弹丸时重置衰减配置。整数伤害向上约束底值，部位倍率单独处理。
- 本地案例：AKM40/HK41645/QBZ19150/M1655/P920米。短枪管 ADS -200ms、腰射扩散×0.5、后坐×1.15、射程×0.8；长枪管 +200ms、×1.5、×0.85、×1.25。HUD 扩散与实际采样使用同源值。
- 数值枪管沿用旧 foregrip 存档键，兼容布尔稳定型；short/long 不添加几何。不能让“启用字符串”退化成旧布尔或只改面板不改 Gun。
- .tres 的脚本属性必须放在 script = ExtResource(...) 后面，否则自定义值可能被静默忽略。必须读取加载后的实际 Resource 验证，不只看文本。
- 腰射不要把垂直 kick、flip、jitter 和绕枪口平移重复叠加。保留后推/水平/上抬，分别用包络限制，枪模后坐与弹道/镜头后坐区分；不重设手腕骨骼掩盖问题。

## 发布与清理

- 共享脏工作区先 fetch，检查目标分支和 origin..HEAD 每一项，使用仓库允许的独立发布 worktree；不整批带上其他任务提交。
- 可独立验证的模块、CC0音效、编辑器和技能可先发布；完整接入依赖未发布资产时保持远端入口不变，列出待接入清单，不伪造缺模型的运行验收。
- 清理仅限明确归属且可重建的失败/临时输出。保留原始下载、源工程、许可、生成器、最终预览和本地恢复依据。保留每批准确文件清单、测试状态、普通 push 与远端 SHA 回读。

## 弹鼓同步与试听选择复查（2026-09-08）

- 弹鼓非线性动作不能只把事件秒数乘总时长比例：先用动画同一 output_time 映射接触点，再用最终动作时长换算播放时钟。拔匣、插入、压实、枪机分别触发，自然收势允许安静。
- 用户听感选择优先于“同名枪械实录”标签；记录普通开火与消音器两条独立选择。恢复旧声时同步修正唯一音源测试、生成器和当前说明，历史预览标注录制版本，避免生成器再次写回废案。
- 分开记载实枪、气动玩具枪机械拟音、试听 MP3 与原 WAV。游戏使用许可不自动包含 GitHub 原始或裁切音频再分发权；公开构建缺少受限素材时使用已授权备用声，并明确完整接入状态。
- Movie Maker 音轨可用源短声相关匹配核对接触事件，记录帧率和误差；此数值证据不代替主观试听。等待 frame_post_draw 的测试必须实际渲染，headless 挂起不是通过。
