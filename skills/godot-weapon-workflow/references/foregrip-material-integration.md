# 前握把动作与材质正式接入复查

## 材质做过，但游戏仍像白模

先区分独立候选渲染与正式加载。沿武器场景、视模材质处理、改造换网格、预览烘焙、拆卸恢复逐段读取实际 material/shader 路径；候选截图或文件存在不代表已经接入。HK416 曾正式停留在 v2，v03 只在独立渲染替换；M16/191 已复用 v03 风格也不能证明 HK416 同步了。

材质接入要同时覆盖机匣、去弹匣枪体、扩容弹匣及配件匹配。共享 clean profile 显式传递底色、粗糙度、金属度和高光，避免材质改版后仍使用旧补偿分支。蒙版、UV、蒙皮与原件替换保持不变；重复匹配不得累积改变颜色。金属与聚合物分开，保护镜片、发光面、橡胶及专用贴图。

以用户选择的平整深灰涂层为目标时，底色颗粒与粗糙度噪声须同步收敛。不要只降低 albedo variation，留下固定强度 roughness variation。使用相同灯光/机位的正式模型对比，再看改造面板和第一人称；不要改光照掩盖漏接。截图只能证明对应视角，不能宣称复制了参考图全部几何细节。

## 装备后直接回握

先实际查看现有装备/拉栓动作，读取时长、速度、循环和接触时刻，记录拉栓结束到原厂支撑姿态的过程。不要给所有枪统一套“结束前 0.22 秒回握”。按每种骨架的收手时刻配置开始和完全握稳两个时间点，结束后保持配件目标，防止先回托护木再切握把。

本地已验证示例，单位为原动画秒：AK-105/AKM 1.02–1.38，HK416/191 0.39–0.55，M16 0.78–1.04。它们绑定当前源片段，换片段后必须重新采样，不能跨项目照搬。播放速度同时作用于回握时间；无拉栓的快速装备保持配件握姿。动作启动当帧重施覆盖，避免恢复原骨骼后出现一帧默认姿态。

左手 IK 放在源动画之后，每帧先恢复上一帧覆盖再求源动画。校准必须从固定 rest 数据重算，不能重复 setup 后累积腕部旋转或位置；外层视模缩放不应改变校准。相同配件选择直接返回时不能先清掉现有握姿。

侧斜握把按持枪者视角确定左右方向；使用独立接触坐标系与手指接触表，不把前后倾斜误作向左侧倾。手指分批闭合，拇指与小指单独落点，换弹离握和回握须避开实际配件。指骨中心线与三角面检查只能验证路径，不能代替蒙皮体积与多视角渲染。
