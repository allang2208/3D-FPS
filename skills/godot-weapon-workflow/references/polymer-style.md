# 枪械与改造件：分区聚合物标准

2026-09-07 用户确定的现行设计语言。以后取得新枪模型或新增改造件，默认按本文处理；适用于游戏资产，不涉及现实武器制造。主流程、配件装配和动画合同仍须同时执行。

## 1. 造型与材质目标

- 保留连续、自然的原枪轮廓和机械结构。小砖只在局部作为细小凸起、连接细节或识别点缀，不能以大方格、公式化凹槽边框或整枪体素化取代机匣与弹匣。
- 采用干净的聚合物表面；不加入做旧、污渍、划痕或碳纤维编织。源模型中的木纹、碳纹、磨损贴图不能直接带入最终表面。
- 用分区建立层次：灰蓝上部、石墨色机匣、更深的握把与弹匣、克制的浅色托腮区域、少量橙色识别带。按实际结构分区，不能整枪统一乘色，也不能靠改变场景曝光掩盖问题。
- 点缀不得遮挡抛壳口、导轨、准星、镜片、活动连接或手指接触区域。倒角与细纹在第一人称近景可辨，远景不能形成闪烁噪声。

## 2. 可复用参数与逐枪校准

当前四步枪实现的起始值如下，属于调参起点，并非所有源模型的硬编码常量：

| 区域 | 着色器颜色参数 RGB | 粗糙度起点 |
| --- | --- | --- |
| 机匣基底 | 0.19 / 0.23 / 0.26 | 0.44 |
| 深色家具与弹匣 | 0.11 / 0.14 / 0.17 | 0.58 |
| 按钮、拉柄等细节 | 0.32 / 0.37 / 0.40 | 0.34 |

聚合物金属度为 0；当前高光 0.36、清漆 0.04、清漆粗糙度 0.55。区域粗糙度约 0.32–0.58，以同一游戏光照下的实际效果校准。细颗粒只弱调颜色与粗糙度，随像素导数衰减；不得形成明显蜂窝、编织或粗砂。保留有意义的源模压法线时降低强度，排除木纹、碳纹和磨损法线。

镜片透明、准星发光、反射片、软橡胶、弹药黄铜保持功能区别。材质分类先核实材质槽与用途；名字只作辅助，不能因为属于枪械就全部覆盖成聚合物。

## 3. 新枪或新改造件执行顺序

1. **登记源资产**：记录作者、来源、模型/贴图/动画/手模各自许可、可编辑源、单位、坐标轴、骨架、活动部件与材质槽。免费不等于可再分发；混合导出 GLB 不能沿用其中一部分的 CC0 标签。
2. **建立基线**：实际查看原模型和已有动作，保留原厂与改造状态的两侧全枪图、近景、ADS 和关键动作。列出该枪实际支持的槽位/变体，不把数值选项误记为几何改造件。
3. **处理轮廓**：优先修法线、倒角和连接；材质迭代不改变顶点位置、索引、UV、蒙皮或动画。若确需改几何，单独保留源文件并重验动画，不用整枪加密面数替代针对性修正。
4. **建立分区**：以该枪实测的 rest/bind 空间、前向和上向定位颜色区。不要直接复制 AKM 的坐标、骨名、缩放或色带偏移。已有顶点色有其他用途时保留其通道；占用新通道必须记录合同。烘焙与运行时着色只执行一次。
5. **应用统一表面**：同时覆盖 `material_override` 与逐 surface override 路径，保留受保护功能材质。材质处理须幂等，反复装卸不累积染色或分配；网格分区缓存绑定实际 Mesh 资源，换件后重新分类。
6. **逐件装配**：对该枪所有有效瞄具、枪口、枪托、后握把、弹匣、战术件、下挂等分别装卸与恢复。按用户并行修改边界处理前握把。检查原件隐藏、替换件唯一、夹座和内部连接无可见间隙，不能仅凭 AABB 重叠通过。
7. **动作与视线**：检验装备、持枪、ADS、开火、换弹时的骨骼跟随、蒙皮、手部接触及镜片透明。双标记对轴之外，还需从实际相机验证透镜后的画面；不得用材质修正破坏原动作时序。
8. **同步入口**：游戏和枪匠预览调用同一视模及配件应用链；同时更新装备图标与改造图标。用实际游戏 FOV、环境和材质渲染，不以概念图或无头加载代替视觉验收。
9. **交付与整理**：保存最终可编辑源、生成器、许可、当前效果图、逐件检查结果和失败记录。确认无活跃引用后将废案及配套 `.uid`/`.import` 移到 `trash`，添加 `.gdignore` 与原路径清单；归档大体积源文件不默认推送。按 `WORKFLOW.md` 精确暂存、隔离混合历史、普通推送和远端 SHA 回读。

## 4. 验收记录模板

记录：武器 ID / 源与许可 / 保留骨架与动作 / 材质槽分类 / 分区坐标及通道 / 改造槽位与所有有效变体 / 原件恢复 / 安装接触与动作 / ADS 轴与镜片 / 两侧近远景路径 / 图标 / 专项结果 / 未通过和未验证项 / 发布范围。

运行检查使用独立 `INVENTORY_SAVE_PATH`。至少实际渲染一次目标渲染器；无头加载不证明着色器视觉正确。不得把单枪专项通过写成整个装备、背包、存档链通过。

## 5. 当前实现与发布边界

- `scripts/rifle_polymer_finish.gd` 与 `assets/materials/rifle_layered_polymer.gdshader`：AK-105、HK416、QBZ-191、M16A2 的现有适配案例。骨名、网格前缀、顶点色编码和色带位置是案例数据，新枪需要适配，不能只加武器 ID。
- `assets/materials/akm_clean_polymer.gdshader`：经典 AKM 的模型空间分区案例；调用方须按活动骨骼维护空间变换，不能把坐标帧当通用值。
- 本地整枪检查记录见 `docs/rifle-layered-polymer-review.md`；发布支持模块的独立验证与范围见 `docs/weapon-polymer-publication-20260907.md`。当前检出缺少案例文件时，以本文合同实施，不声称已自动接入。
- 已淘汰方向：大方格铺面、重复凹槽边框、整体实体体素替换、碳纤维、无分区的素色聚合物。历史文件仅作对照，不能作为新模型默认标准。
