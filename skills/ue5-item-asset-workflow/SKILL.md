# 共用规则入口

共用流程读取仓库发布快照：[ue5-item-asset-workflow](../_shared/ue5-item-asset-workflow/SKILL.md)，不要叠加旧镜像流程。 为什么：共用流程只维护一个来源，避免工程镜像与个人版本给出相互冲突的步骤。

工程专属规则以当前 AGENTS.md、WORKFLOW.md 和本次用户要求为准。维护源不可用或需要查找未合入的工程经验时，读取[整理前工程资料](LOCAL-HISTORY.md)及原 references；其中历史测试与协调条款不构成执行授权。 为什么：当前用户授权决定操作范围，历史测试与协调记录不能自动成为新任务授权。

本入口随仓库提供共用规则快照；日常修订仍回到个人维护源，发布时更新快照。 为什么：相对链接支持换机阅读，单一维护源避免两套规则分叉。

制作文件、检修材料、服务器硬件或调整收集物图标时，读取本项目镜像 [搜索收集物资产](references/search-collectible-assets.md)。个人维护源保留同名参考。 为什么：「搜索收集物资产」已有专属约束与实现入口，集中查阅可避免复制另一套不一致的处理方法。
