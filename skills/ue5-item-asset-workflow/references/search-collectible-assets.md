# 搜索收集物：写实模型、图标与旧实例

用于文件、检修材料、服务器硬件等非装备收集物。物品目录为 `Content/ColdSteelData/items.json`；设计清单和最新图标规则分别见 `Docs/Gameplay/search-item-catalog-v2-20261012.json` 与 `Docs/Art/collection-icon-layout-r2-20261013.md`。容器投放与联机转世界交互的 [搜索容器合同](../../ue5-world-interaction/references/facility-search-containers.md)。

## 物品身份与制作

- 实用性与稀有度分开设计：水/食物解决生存需求，文件/硬件有回收价值，检修材料对应制作用途；不要为填满白绿档位创建没有拿取理由的物品。
- “制作台配方已设计”“物品模型已接入”“配方已实际扣料”是三种状态，逐件记录，不用模型落盘代替用途接入。
- 精密硬件采用可编辑的规则几何，保留板厚、接口开口、金手指、固定件和散热结构。显卡扇叶需有曲率和厚度，背板、供电口、散热管和显示接口分层制作。
- 参考图用于形态与材质；当前硬件采用原创 CS/COLD STEEL 标识，包含风扇轴心、标签、芯片丝印、板边小字和背面。不要只换主Logo，其他文字仍留原品牌。替换标识不等于已做商标检索或取得第三方素材公开许可。
- 当前网卡、阵列卡和处理器采用白/银/黑表面，保留镀金触点。阻焊层是非金属；金属接口和散热件单独控制粗糙度/金属度，不把白色PCB整体变成金属。
- BaseColor使用sRGB，ORM/Normal为线性；ORM为R遮蔽、G粗糙度、B金属度。OpenGL法线导入UE需匹配Y方向。薄片及倒角的UV不能退化成线；导入切线警告须明确记录，启用重建切线不等于游戏视觉验收。

## 图标与占格

- 当前收集物规则已替代“一律左上45°”：单行条状物水平居中，单列条状物垂直居中；1×1里仍明显细长的U盘、内存也水平；2×2、3×2等宽幅物品沿用原立体展示视角。武器、可穿戴装备不随这批规则改变。
- 共用 `Tools/AssetPipeline/collection_icon_orientation.py`。依据物体在相机中的投影主轴调整朝向，旋转后重新计算完整边界；正交相机、等比适配、透明背景，留边且不裁断突出接口。
- 图标从当前活动模型产生，批量任务同时核对目录、模型清单和设计表，不能因旧模型清单仍存在就重新渲染被替换版本。
- 占格是玩法字段，图标画幅只负责展示。显卡当前2×1、旋转后1×2；修改目录同时维护 `MigrateAuthoredGridFootprints`，保留旧实例ID、数量、旋转及可保留的格位。
- 旧物品保存了 Data/模型/图标快照。只改目录不会自动更新旧物品；沿用已有加载迁移，或在明确兼容需要时更新旧资源路径。资源缓存必须在新进程读取后才反映替换。

## 保留与退役

- 当前为混合恢复链：文件4件、检修5件、机房8件；机房中的显卡/内存/SSD用原创标识版，网卡/阵列卡/CPU用中性色版，硬盘/计算模块仍使用最初机房批次。旧批次不能整目录当废案搬走。
- `ServerOriginalMarks` 当前GPU使用CSR3C UE网格，但几何来源仍是CSR3B导出；不要因版本号更旧而移走输入。
- 旧网卡/阵列卡/CPU模型路径仍承担旧存档兼容，不能只看新目录引用就删其网格与材质。`previous_models.json`、原始参考及制作脚本是否仍作为输入，逐项查调用。
- 确认被替换的图标、导出、Before/PreviousIcons快照和撤回脚本可移入项目 `trash`，记录原路径、大小、SHA-256及当前替代物。当前母版、参考来源、恢复依赖与历史构建证据保留。
- 公开仓库默认发布原创制作配方、目录与说明；参考图片、模型/PBR、UE包、暂存导入宿主、日志和构建产物留本机。技能沉淀保留方法与有效边界，不复制一次性回执当成通用规则。

## 工具、电气收集物与调配材料（2026-10-15）

- 本批新增调配材料最低为稀有，沿用既有食物/药水不受材料档位下限影响。材料模型与掉落接入不代表药水调配系统已实现；后者仍待独立开发。
- 规则结构用可编辑几何表达：瓶壁与瓶底连续闭合，玻璃/液体分件；晶体保留切面法线，标签按实际表面比例排版。工具保留接口、孔槽、应力缓解段与碰撞体；精细外观不自动赋予持用或维修玩法。
- 1×2 指库存占格，不要求所有源模型都沿同一世界轴。万用表按自身长轴竖置；稳定剂托盘的长轴为局部 X，渲染时按投影轴竖直居中。更改占格还需读取 [跨存档迁移](../../ue5-save-load-replication/references/inventory-footprint-migrations.md)。
- 精修图标先输出候选目录，模型/材质实际保存后再发布到稳定图标路径并合并生产清单。不要把尚未安装的图标直接覆盖生产文件，也不要只覆盖清单中的一部分而丢失其余物品。
- 当前六材料为混合恢复链：三件保留根目录 V3 制作源，稳定剂/活性催化晶/蓝髓菌结晶采用 VisualRefineV4；UE 网格仍在 V3/Meshes，后三件引用 V4 材质。旧编号不等于废案，按生产清单和真实依赖判断。
- 后台 -run=pythonscript 导入不得调用依赖交互编辑器的 PIE 查询；命令行与 GUI 的保护分支分开。导入脚本已写好、包已保存、构建成功和游戏内验收分别记录。
