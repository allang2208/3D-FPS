# 厚衣物与原生身体的背带配对

新增上衣或身体后，按当前背包 × 上衣 × 身体建立配对清单。`world_mesh` 裸身回退可以让物品显示，但不能代表新夹克已经贴合。普通/靴型裤腰导致上衣表面不同，也应读实际外层路线。常规容量与联机合同继续见 [背包工作流](backpack-equipment.md)。

## 形体与动态一起制作

- 读取当前保存的原生身体、上衣外层及包体/肩带源，记录路径和散列。过滤内衬、隐藏皮肤和代理面，保留胸袋、门襟、肩部补强等可见体积。用实际表面构造局部包络，不把包围盒当贴合面。
- 分开处理固定肩胸段、自由带段、缝接端和刚性包体。包体作刚性变换；缝接端与其共享该变换；固定带段沿衣物变形场移动。保留 UV、原生蒙皮、动态遮罩与材料，按原策略生成 LOD。
- **逐顶点投影到衣服表面会把带子内外两面压到同一层。** 平滑法线不能恢复厚度。本案例改为角度/高度驱动、与半径无关的平滑变形场，让内外表面一起移动；斜挎带的肩部转弯区与缝接端需要单独控制过渡。
- 制作阶段发生法线警告时，对照源三角面面积及新几何，区分源自带的小面和此次新增塌陷；不要靠关闭剔除或隐藏警告交付。无新增退化面是几何制作证据，仍不等于动作穿模已验收。
- `world_mesh_by_shirt`、`rigid_pack.location_by_shirt`、`hanging_pack_by_shirt` 来自同一配方。单肩包同步中心、探针、支撑点骨骼局部坐标、带长和躯干凸代理。换骨架从该身体解析骨索引/绑定帧，不能套 Jason 的身高或另一包的角度。
- 发布前比较当前包体、裸身网格、静态旋转/位置及挂点配方与制作源；发现并行修订就重新适配。只发布对应上衣字段，扩大必要运动边界时合并当前值，保留其他衣物配对。

## 本例与恢复

2026-10-24 为六款背包各制作 Jason/Kaitlin 工装夹克配对，共十二套 `WorkJacketR2`。第一版逐点投影未发布并退役，当前脚本为 `Tools/KaitlinPlayer/author_jacket_packs.py`、`complete_pack_assets.py`、`publish_completion.py`。源码、保存资产和配置回执分别记录；原模型、密集输入与 UE 包留本机。

无界面 Python 读取批次若在退出阶段异常，不把已有 JSON 当作整个进程成功。保留失败记录和已保存散列，续接缺项；缩短反射数组/UObject 代理的生存期，避免跨引擎清理阶段持有借用视图。这是本例采用的处置，不把退出异常都归因于同一个未经证实的引擎缺陷。

本例完成后台保存和配置接入，未进行实际跑动/坐卧画面或主客机验收。整理/更新此参考不自动恢复测试授权。
