# 实心原木与树木断面

用于修复地面短原木的空心树皮、碎片外壳、缺失封面或断面贴图。倒树事务、切口支点和 Nanite 树冠适配读取 `ue5-world-interaction` 的 `references/tree-harvest-cut-and-fall.md`。本文件不触发额外测试或渲染。

## 先定位缺陷层

- 区分地面可拾取原木、固定树桩和倾倒树干；三者可使用不同网格与材质。不要根据“空心”描述同时重做整套树木。
- 有侧面树皮不代表有实体端面。检查对象本身的封面几何、法线和材质槽，再判断是缺面还是着色问题。双面材质不能补出不存在的木材截面。
- 生成模型可能在 UV 岛边界重复顶点；直接减面会把原本相邻的面变成碎片。区分仅顶点分裂与焊接后仍存在的真实裂缝，保留原母版再处理。

## 连续表面与 PBR

- 普通实心短原木可以沿母版外轮廓重建连续的环形侧面，再为两端建真实封面。此方法适用于近似圆柱物体，不用于盲目封闭机械孔洞或天然空心树。
- 保留母版不规则轮廓、粗细和树皮身份，把 BaseColor、Roughness、Normal 重新烘焙到新的连续 UV。不要用平滑或细分掩盖断裂拓扑。
- 沿目标切平面只填充该平面的边界，明确两端朝外方向；复杂轮廓先三角化，避免导出工具重新解释大多边形。
- 新增断面采用独立平面投影 UV；对继承多 UV 层的树，确认材质实际读取的通道有有效封面坐标。本案例给封面各继承通道写入相同投影，保留侧面原有数据。
- 导入时明确 UV0 和材质槽名称，按需要关闭自动 lightmap UV 生成。不能仅凭 Blender 活动 UV 层看起来正确，就假定 UE 使用同一通道。
- 树皮与年轮分材质；地面原木、固定树桩可用不透明断面，上半段切面需要与倒树主体同步消隐。不同用途的透明模式和 skeletal/static usage 分开设置。
- 本案例法线烘焙为 OpenGL 格式，UE 导入翻转绿色通道；这是来源相关设置，不对所有贴图重复翻转。

## 接入与授权范围

- 原木形状更改后沿用物品 ID、数量、拾取距离、落地位置/旋转及存档；以真实模型尺寸配置简单碰撞，不让可见粗原木仍使用细枝的尺寸。
- 用户明确要求检查模型时，可比较原始/焊接后的边界、连通性、端面面积和朝向，并按授权查看实际 UE 导出几何。Blender 对 UE 导出网格的渲染是模型检查，不能称作 PIE 截图或游戏性能验收。
- FPSGAME 2026-09-13 的短原木修复执行过用户授权的定向几何检查与 Blender 渲染；随后树桩/切口倾倒只完成制作和构建。不要把前一次检查结果借给后一次改动。

## 来源与废案整理

- 原始生成 GLB、纹理母版、参考图、生成参数和当前可编辑源属于制作依据；输出有缺陷不表示应把母版一并判废。
- 当前脚本读取的旧命名材质、纹理或 Blend 仍是有效依赖。先沿制作链与 UE 引用查明用途，再把已替代的低模、旧树桩、单独封口圆片等移入 `trash/<task>`，记录原路径、目标、大小和 SHA-256。
- 归档后更新当前入口，防止基础导入脚本重新创建淘汰网格。历史诊断工具需要旧样本时，应明确读取归档位置，不恢复到正式 Content。
- 项目生成的年轮参考与已有树木衍生资产分开记录来源；本机拥有使用许可不等于允许公开原树、纹理或衍生二进制。发布制作脚本和记录时保留本地恢复边界。
