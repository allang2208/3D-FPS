# 补水与食物消耗品

接入此类物品时同时处理目录、旧实例迁移、手持模型、世界拾取、背包图标、动画接触结算与资源档案。物品名称或 Fab 页面不能代替真实本机网格定位；原模型、PBR、可编辑源和导入回执保留本机，公开发布制作配方与恢复说明。

- 模型用厘米统一尺寸，保留原 UV、比例与材质身份；按实际手持接触位置配置动作。背包占格与模型尺寸分开：当前普通面包／汽水 1×1，矿泉水 1×2，法棍 1×3。
- 图标来自同一正式网格和 PBR，透明背景、项目标准正交构图；出图与网格导出解耦。半瓶／满瓶图标使用同一镜头，缓存键包含实际图标路径，快捷栏同时刷新剩余次数和图标。
- `useEffect` 的补水允许负数，SAN 可恢复；在成功接触事务中一并结算效果、扣水成本、次数和库存删除。全部正向资源已满时拒绝使用，不先扣代价或数量。动画开始、取消与接触结算保持原有原子提交语义。
- 可重复使用的水瓶保存 `remainingUses` 到实例数据；喝一次更新半瓶状态，最后一次再删除。手持水面随喝水进度降低，满／半瓶世界拾取使用对应模型。液体材质压低液面，不将整团水横向缩小。
- 背包和装备夹层的消耗品沿用同一右键、双击、Enter 与快捷栏路径。拖放预览和提交必须接受同样的 Place 范围；仅改预览不能修复夹层绑定。
- 关闭背包前复制传入的实例 ID。HUD 关闭会清空 `Selected`；引用此字符串的参数失效会导致动画开始但接触找不到物品。
- 附魔卷轴归 `enhancement` 大类，保留卷轴子类和附魔载荷，通过强化台使用。旧实例仅同步必要分类字段，不覆盖数量、位置或个体附魔信息。
- 旧消耗品同步目录的 `useEffect`、`stats`、`useDuration`，保留实例 ID、放置、数量及剩余次数。作者脚本与运行 JSON 共用最终动作时钟，避免重新配置后恢复旧数值／时长。
- 水／汽水／药水和喷泉补水复用随机吞咽音池；持续饮水每次重新抽取，间隔包含所选片段长度，避免重叠。食物播放一次完整吞咽音，可自然延续到收手；取消、下次使用及销毁停止旧播放。

当前生产配方位于 `SourceAssets/{MineralWater,Baguette,Bread,ConsumableAudio,SodaCan}20261003`；当前数值与本机内容恢复顺序见 `Docs/UI/survival-consumables-publication-20261003.md`。只写导入脚本不等于已保存资产；构建结果与用户游戏测试分别报告。
