# 怪物延迟命中与器官生命池

用于移动怪物远端弱点丢失、模型已命中但权威拒绝、器官伤害串入身体。遵守当前测试授权，不因维护本参考自动运行联机。

- 分别确认客户端查询、上报正规化、实际 NetSerialize、RPC 包装入口、权威验证、生命池结算和反馈。直接调用 TakeDamage 或 RPC `_Implementation` 的通过结果不能证明前面的路径成立。
- 先用客户端接触时的模型判定普通组织/要害并编码，再量化传输，最后推进服务器姿态。先移动服务器再调用“客户端正规化”会让夹具自己把合法头部或触手改成另一类。
- 世界空间接触点属于过去姿态。沉匣眼部、焚骸裂口、合阙悬心及缚群攻击触手使用有界权威姿态历史；按既有收据时间窗口解析，不能拿延迟点直接测试当前骨骼。
- FPSGAME 该实现最多 32 帧、30 Hz，在最终骨骼完成事件采样，只记录实际需要的骨骼/凸包。沿用 0.9 秒回执窗和 0/−0.05/−0.1 秒的既有平滑偏移，不新设无限迟到宽容。EndPlay 注销回调并释放缓存。
- 合阙按历史射线的首个凸包决定遮挡，不能仅因报了心脏骨就穿过肢体判要害。器官点经历史校验后映射回当前部位供既有公式使用。
- 缚群根部/折叠组织为身体，活动攻击触手有独立生命池。延迟触手接触先校验过去位置，再要求当前仍有效；器官已失效的回执直接拒绝，绝不能回退为身体伤害。
- Health 和其可变 MaxHealth 都要复制；阶级/成长导致服务器最大生命与客户端默认值不同时，仅复制当前生命会让血条比例错误。声明 CPF_Net 与 lifetime 注册缺一不可。

人形真实头部与附属组织的作者规则见 [按模型校准命中体积](../../ue5-monster-workflow/references/model-hit-volumes.md)。2026-10-18 的 34 类、68 次枪/近战及 566 个移动弱点样本来自隔离权威夹具；未建立两个 socket 客户端，不能称为真实延迟/丢包/晚加入通过。夹具边界见 [隔离权威夹具](../../ue5-debug-validation/references/authority-hit-fixture.md)。
