# 消耗品结算回执

开始、接触、取消沿用拥有者的 PlayerState 可靠通道。临时动作标识不进入存档。主机用当前 Pawn、物品实例、定义和动作标识匹配一次使用；根据作者接触时刻、双手放低时间和权威动作速度确定最早结算点。延迟导致请求挤在一起时，等待主机时钟到点，再复核当前角色、库存版本、物品和动作。每次受理后作废该标识。

区分客机已发出接触请求、主机已接受、拥有者已应用库存回执。接触前取消撤销动作；接触已提交后收手不撤销在途结算。回执仅影响原 Pawn 的同一活动动作；拒绝时收起预测姿态。只在拥有者确实应用成功后确认其库存基线。动作传输与写盘使用各自的记录。

需要复查时分别看客机剩余数量、主机的客人影子档案与存档、宿主自己的库存、观察端动作退出。覆盖无开始记录、接触前取消、服务端拒绝、接触后延迟回执、同一瓶水两次使用、重放旧标识以及药水资源恢复。断线重连的姿态恢复、服务端已写盘、恰在事务中途断线后三方重新收敛，是三种不同的证据。
