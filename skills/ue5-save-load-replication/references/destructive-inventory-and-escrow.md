# 永久销毁、弹药暂存与回执恢复

用于 FPSGAME 焚化炉及同类不可逆库存提交。源码入口为 `UI/ColdSteelIncineratorStorage.*`、`ColdSteelProfileRuntime.cpp`、`ColdSteelNetworkInventory.cpp` 和 `Multiplayer/ColdSteelInventoryRequests.cpp`。这里只记录实施约束；检查、运行测试与编辑器启动遵守当前用户授权。

- 先区分个人暂存和世界共享容器。个人焚化暂存继续随档案上传，键由双方一致的世界标识和炉体实例 ID 组成；不能用各自玩家的本地档案名替代。关闭面板不等于销毁暂存，离线或已拆除炉体的旧容器需要保留取回入口。
- 弹药袋数量与普通盒装物品是不同契约。专用暂存标记必须在普通物品目录过滤、堆叠截断之前处理，按弹药目录、袋内上限和容器占格规范化；普通物品目录可能根本没有该弹种。保留数量，拒绝把虚拟弹药转换为可取回弹药，显示 JSON 在两端用同一构造逻辑生成。
- 确认摘要针对规范化副本计算。输入按实例 ID 排序，嵌套 JSON 对象按字段名稳定排序；不能直接比较上传校验前后的原始 JSON 字符串。保留实例、数量、容器和实际内容，只排除明确无关的瞬态字段。UE 5.8 的 `FJsonObject::Values` 键可能是共享字符串，使用 `FJsonObject::FStringType` 与 `MakeStringView`，不要固定假定为 `FString`。
- 服务端核对绑定角色、存活、炉体归属、当前实例、距离和遮挡，再复算清单与产出。专用请求要放在 `Action >= Harvest` 等宽泛分派之前，避免被错误吞掉。单机和联机都复用已存在的事务保存入口；写盘结果不确定时保留冻结，不能继续用旧内存覆盖存档。
- 数量差量只应用一次；删除实例的绑定清理不能仅放在“版本改变”分支。完整档案可能先于等版本回执到达，断线也可能完全漏掉回执。较新完整档案恢复时，按本地曾有、权威已无的确切实例 ID 清理快捷栏和生产工具引用，保留其他绑定。
- 销毁持久化成功后才发布表现时段。复制服务器结束时刻供晚加入读取剩余时间；该时刻不写入存档，重载不重新销毁或重播。效果登记、烟雾预算与声音预算的收尾见流体技能的炉体表现参考。
