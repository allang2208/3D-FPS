# 武器附着火焰与脚下火环

案例：灼锋焰甲 2026-10-16/17。用户最终要求仅武器和脚下火环，取消第三人称身体上部火焰。

- 从已认可火球火焰提取主体、热核、烟和余烬层；原版供体保持不变。不要把连续火焰拆成均匀细碎点，也不要靠一个泛光片承担所有体积。
- 足环须从第三人称斜视仍可见。V5 用连续环壁和高度层次，脚下坐标/地面间隔与 Bounds 一起设置。附着从胸口改到脚下后，热成像代理的偏移和范围必须同步，否则代理会埋入地下。
- 按实际装备组件采样：剑刃端点、锤头独立模块、弓臂与箭、法杖端部、空手拳面、枪管/枪口及双持各自来源；不要给所有武器套单条直线。工具的刃端点需跟装备描述复制给第三人称。
- 位置和长度单位统一为 cm，先换到对应组件空间再送 Niagara；同帧采样姿态，换武器/瞬移重置历史，避免横跨世界的拖尾。第一人称与 F6/远端显示资格分别判断，隐藏或收起的装备不能继续冒火。
- 复制游戏状态和施法身份，视觉客户端本地建立；Dedicated Server 不加载表现资源。资源晚到、预测/回执/OnRep 先后顺序不能让有效状态永久无特效。

## 2026-11-10：原版暖焰、实际表面与逐帧跟随

本节覆盖前文 V6/V7/V9/V10 的活动武器火焰说明。用户否定新增随机火团外观后选择恢复魔晶长剑原四层结构；只改暖色，原蓝火供体保持独立。当前通用／剑／箭供体为 AllWeaponsV12，锤使用 HammerSurfaceV13 路径内的 V16 内容，不能用目录名判断实际版本。

- 保留供体的分层、图集、透明度与出生随机节奏；先处理颜色和真实表面适配。细剑按截面宽度、锤按实际外表面定位，避免套供体宽度或穿过实体。枪焰围绕手部，弓焰放在实际箭矢；隐藏／无箭时清理，火焰元素箭与焰甲箭火互斥。
- 根部直接挂到真实武器部件／手骨／箭杆，端点、方向、速度全在同一个局部系。根部不做位置追赶；速度平滑仅驱动火舌弯曲。当前帧数据、末帧组和第一人称有界独立 tick 共同保证顺序，不是增加一个低频位置计时器。
- 年龄零一次性 burst 的持久层，换表面后必须先写新参数再 `ReinitializeSystem()`；仅 `ResetSystem()`／软激活可能保留旧出生年龄，造成核心层不再生成。普通每帧更新不反复重建；改变来源或表面时才处理断点。
- CPU VectorVM 的负数随机哈希曾使样本失效。本例统一为 `frac(abs(...))`，检查实际表达式和运行样本，不能只看材质颜色。低发光与透明度、图集遮罩分开处理，不能一律叠加强光。
- 星髓充能曾因挂点从 `SwordEdge` 改为 `BladeSurface` 而被错误筛掉。匹配实际剑类、网格身份和充能武器实例，不把显示分区名称当作装备身份。
