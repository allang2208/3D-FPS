# 透明贴片与可见性问题

用于避免制作回退，或用户明确要求排查“方块、黑片、不明显、重复轮廓、穿墙”等问题。按症状读取目标源与实际引用；只有用户要求相应检查／测试时才运行图像分析、GPU 回读、截图或游戏复现，不因读取本参考就自动执行。

## 水花矩形：这次真正修复的是什么

2026-09-24 用户先报告水花周围半透明方片。第一次只处理零覆盖率法线、高光和 Front Layer Translucency，保存成功后仍出现方片。后续定位到 **FLIP 零顶点缓存帧被 Blender 用模拟域方盒回退渲染**，导致图集空帧内部 Alpha=1；边角两像素透明不能证明整帧透明。

自然水花共 4 套 ×32 帧，其中 43 帧已无液体网格。修复对每帧 `.bobj.gz` 读取顶点数：零顶点生成全透明 tile，85 个非空帧沿用已有输出，未重算模拟。用户随后明确反馈方块修复成功并要求扩展到全部水体。

必须随生成器保留的四层处理：

1. **源帧有效性。** 缓存空网格不能渲染模拟域；缺失缓存和合法零顶点不同，前者不能静默导出空白。
2. **图集与有效帧清单。** 当前 `SplashValidFrames=(22,20,22,21)` 来自这次四套烘焙；重制后根据新清单生成，不能照抄数字。末个有效帧向透明淡出，之后停止绘制，不误采下一序列。
3. **采样与流送。** 本图集曾在粗驻留 mip 下将邻帧混入空帧。当前只对 `T_RiverSplashPacked` 设置 `NeverStream=True`，保留 mip，BC7 完整 mip 理论约 2.67 MiB；这不是整卡显存实测，也不是所有纹理都常驻的理由。
4. **材质空白像素。** 极低覆盖归精确零并丢弃；透明处法线回中性，高光按覆盖衰减；仅 `M_RiverCrown` 关闭 `Allow Front Layer Translucency`。不以全局关闭 Lumen／RT 修局部材质。

正式入口：`Tools/Fluids/bake_river_splash_natural.py` 与 `author_river_splash_natural.py`。详见工程 `Docs/Fluids/river-splash-natural-performance-20260924.md` 后两节。后续改水面波纹、尾迹、浅水强度时，通常无需重制这个已认可图集和水冠材质。

## 按证据缩小问题

| 现象 | 优先读取的链条 | 常见局部处理 |
| --- | --- | --- |
| 完整方片，尤其动画后段 | 原始帧覆盖→图集有效帧→GPU 纹理设置→材质空白路径 | 修空帧、末帧钳制、tile 边界；别只调总体透明度 |
| 地面矩形或墙上整块投影 | Decal 遮罩、投影轴、接收法线、实际危险边界 | 裁掉投影体边界，地面与墙面按各自轴向处理 |
| 水花几乎不可见 | 实际对象引用→触发→Renderer／绑定→尺寸与密度→淡出与上抛 | 修错误引用／绑定或乘法衰减，再调可读范围 |
| 每次相同轮廓或跳变 | 池激活种子、系统 Determinism、变体选择、帧龄 | 激活更新装饰种子，按完整变体播放，不随机跳帧 |
| 方格串色、跳到别的动画 | 已变换的 SubUV、图集排列、采样边界、mip | 恢复格内 UV 后采另一图集，各图集使用自身排列 |
| 火焰变黑、发白或整层不出现 | 温度／密度通道、预乘、曝光补偿、模板生命周期 | 保持唯一曝光补偿，读对数据通道和发射器生命周期 |
| 转枪时整团烟跟着镜头 | 发射器 LocalSpace、挂接、位置更新 | 出生跟随枪口，离开后的粒子用世界空间 |
| 雾穿墙／墙边跳动 | 平面空间、刷新距离与额度、更新栈顺序 | 修空间和顺序，按预算缓和消散；记录近似边界 |

运行对象引用使用实际要求的完整对象路径，例如 `/Game/Fluids/RiverPilot20260923/NS_RiverBulletSplash.NS_RiverBulletSplash`；不能把只有包路径的字符串当成所有加载 API 都接受的对象路径。

水花曾同时受到粒子 Alpha、材质密度、孔洞遮罩和过早淡出相乘，主体被多层削薄；向下的入射 Flow 又抵消上抛。调可见度要沿完整表达式处理。旧“3 水冠＋14 滴”已被“1 水冠＋变体图集”方案替换，不将早期可见性文档的数量重新写回当前资产。

## 针对性修复的范围

先改产生问题的一层，沿相同源文件更新作者脚本和指定资产；不因一次方片问题重做所有水体或重烘焙所有流体。可用 `--repack-existing` 等既有分支时保留正常帧。

读取源 PNG、保存参数、工具编译结果、GPU 样本和用户截图是不同证据。源 Alpha=0 不能单独证明流送后的采样为零，资产保存不能证明方片消失；用户要求的排查结果要说明已定位到哪一层，修复后的观感仍按用户实际反馈记录。
