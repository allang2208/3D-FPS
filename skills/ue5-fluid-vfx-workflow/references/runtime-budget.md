# 运行接入与预算

适用于新增触发、风、碰撞、池、调度或性能约束。以下数值是 2026-09-24 源码基线，后续以实际文件为准；它们是容量和工作量约束，不是已测得的 GPU／CPU 帧时间或通用最佳值。

## 共用入口

- `Source/FPSGAME/WorldGeneration/RiverPilotFXSubsystem.{h,cpp}`：`FindWaterCrossing`、`SampleWater`、`TryBulletCrossing`、`TryFireCrossing`、`CharacterWater`、`UpdateWake`、`BodyWater`、静态水面注册／移除。类名保留 Pilot 兼容引用，但已覆盖全河道、喷泉和积水。
- 毒液复用 `Monsters/PoisonMaggotVenomFX.*`，血液复用 `Weapons/FPSImpactFXSubsystem.*`，枪口复用 `Weapons/FPSWeaponFXComponent.*`。不要为每个法术／水体各复制一个无限池。

## 实现规则

- 每层写明触发频率、峰值并发、最长寿命、组件／实例池上限、纹理尺寸与采样次数。池满时有明确复用／丢弃策略，不能临时无限追加组件。
- 从 BeginPlay／EndPlay、关卡到达和 Actor 生成事件登记；沿现有 Tick 或共享定频调度处理。避免每个水花、雾团或物体各起 Actor Tick，避免每帧遍历全世界。
- 角色瞬移、重生和池复用重置历史位置／时间，避免形成横跨地图的水迹。一个水面记录换槽时清掉旧 MID 的同槽数据，喷泉多层按实际高度分离。
- 热路径不新增同步 `LoadObject`、磁盘读取、GPU 回读、全量流送等待或材质编译。资源用现有异步预加载；结束时取消句柄、移除注册并释放本任务组件／MID。
- 每弹随机用装饰随机流或种子，不能消耗伤害、散布、暴击使用的随机序列。重用 Niagara 池也要更新变化，不只按命中坐标哈希。
- 局部烟系统的风与平面先转换到该系统空间；世界空间粒子直接使用世界风。组件缩放、局部上方向与法线单位统一，不把速度额外乘外观尺寸。
- 调质优先保留主体／危险提示，远处减少细滴、薄雾、额外余烟，寿命与透明覆盖也可缩减。投射物、危险液膜与伤害判定不随装饰额度消失。
- 保留当前硬件光追、Lumen、昼夜光照与纹理池策略；不为局部方块或透明开销全局关闭光照、折射、流送或扩大无限纹理池。局部渲染开关按具体材质问题处理。

## 接触近似与危险边界

烟雾使用 `User.SmokePlane0..4` 的局部平面，粒子依次修正穿入位置并按挤压衰减；接触模块应在自定义位置／颜色更新之后，避免下游模块覆盖。池复用先清五个平面，无命中用零平面。它是近景近似，不保证复杂凹角、细薄墙及高速移动障碍绝不穿透。

巫婆毒池使用 16 方向径向边界；每约 0.10–0.12 秒更新两个方向，压力大时延后。材质和 CPU 伤害使用同一边界插值，并保留每次伤害的实时遮挡；零边界不产生隐形中心伤害。初次落地建立完整轮廓，与后续动态更新分开计成本，不能只报告后续限流忽略首帧工作量。

径向采样不是任意形状液体求解，不能表达所有孔洞与不连通区域；不以加密装饰雾掩盖几何边界错误。需要更准确的障碍绕流或积液时，再按实际需求设计表示方式，而不是直接提高通用粒子数。

## 用户明确要求性能测量时

才运行采样：固定地图／种子、机位、分辨率、画质、前台状态和运行模式，比较相同开火／施法密度下的 Game、Draw、GPU 帧时与慢帧分布。父子 scope 不重复相加，记录透明覆盖、活跃组件／粒子、纹理驻留与碰撞查询。未采样只报告实现预算，不承诺“无性能影响”或 FPS 提升百分比。
