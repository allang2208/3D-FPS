# 大旋风：近战范围技能与动作占用

适用于带旋转镜头、武器横扫、命中停帧的近战主动技能。项目案例为 `Docs/Skills/whirlwind-migration-20260920.md`，公开恢复与归档边界见 `Docs/Skills/whirlwind-publication-20260920.md`。

## 数据与修炼

- `whirlwind` 保留旧 gamedev 内部 ID，显示名为大旋风。只接受库存认定的近战兵器；生产工具和枪械不因外观近似而获得权限。
- 数据、等级效果、常驻属性、旧存档迁移、冷却保存、快捷栏绑定/状态、详情页、开发技能目录及图标恢复一起接入。大旋风进度迁移是版本12；后续技能可以继续递增版本，不回退现有工作区的迁移版本。
- 等级 K 为1–20：伤害倍率 `1.5+0.1K`，常驻力量 `+K`，冷却 `10-0.2K` 秒，体力 `20+K`。半径 `(120+5K+80)*1.5` 厘米，再乘当前近战范围系数；击退375厘米，眩晕2.5秒。最终伤害基于当前近战武器统一求值结果，不再单独重算一套武器伤害。
- 每个合格目标一次技能只命中一次，两圈共用去重集合。经验为 `命中人数*1 + (命中人数>=2 ? 3 : 0) + 击杀人数*15`；空挥不加经验，排除尸体、召唤物和禁修炼对象。每级需求100K，最高20级。
- 先确认装备、动作、动画和资源，再一次性提交体力/冷却。取消不退已提交成本，已经发生的命中仍结算；正常结束与取消走同一清理入口。

## 动作与控制

- 当前合同为0.5秒蓄势、0.8秒反向720度两圈、0.52秒收势。镜头和横扫使用同一有符号旋转参数；动画仅制作横持与双臂动作，避免再烘焙一套重复转身。
- 命中停帧45ms、整次预算135ms。判定可按120Hz子步推进，但每个渲染帧只提交最终镜头下的一次骨骼姿态。动作时钟暂停时，镜头角度与判定同停；完整停帧清除前景残留运动矢量。
- 技能期间排他占用剑动作，待机、走路、普通攻击、蓄力、格挡不能另起姿态覆盖。角色本体移动限制与动画占用分别实现，按具体技能设计选择。
- 大旋风按用户要求从蓄势至收势全程禁止移动、跳跃、闪避和滑铲；读取技能活动状态作为锁定依据，退出即解除。起手清掉待处理移动、水平惯性、跳跃缓存/持续跳跃、攀爬请求和短按冲刺计时。移动组件拒绝跳跃并返回零最大移动速度；空中原垂直速度和重力继续生效。
- 不用控制器 `SetIgnoreMoveInput` 充当这一技能的移动锁：本项目动作资格把真实菜单输入锁视为取消条件，混用会自我取消。也不要保存/恢复整份控制器锁计数或旧移动速度覆盖期间其他状态。
- ALT 显示鼠标与真实菜单分开。`AFPSGAMEPlayerController::BlocksOngoingActions` 允许仅光标交互，真实菜单/忽略输入仍阻断动作；ALT 不强制把键盘焦点移到HUD，避免合成释放事件导致动作或武器被取消。近战、生产工具、双持与体力活动判断共用这一口径。
