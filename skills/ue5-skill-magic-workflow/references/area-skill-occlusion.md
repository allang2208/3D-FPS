# 范围与连锁技能的镂空遮挡

2026-10-13 用户要求：AOE／群攻不能因为楼梯栏杆或带孔障碍而整体失效。工程实现及交付状态见 `Docs/Skills/area-skill-open-barriers-20261013.md`。

- 共用 `MagicOcclusion`：复杂碰撞识别真实孔洞，目标身体内多点采样处理中心被横杆遮住的情况。仍保留技能自身范围、阵营、去重和服务端权威结算。
- 已有独立栏杆复用 `Traversal.GuardrailDrop`；新镂空组件可显式标记 `Magic.Permeable`。只跳过命中的组件并继续追踪后方阻挡，不忽略整栋建筑，不将“薄物体”或“所有动态物体”视为可穿透。
- 范围传播与实体碰撞分开调用：物理投射物飞行、冰墙放置及普通近战保留原规则。大旋风只通过 `bAreaDamage` 明确启用群体规则。
- 暴风雪随后升级为独立立体伤害与最多三层视觉采样；完整墙／楼板仍阻挡，室内传播起点不得抬穿楼板。范围环境探测可跳过明确标记的镂空组件，合法落点仍使用原物理地表；详见 `blizzard-migration.md` 和 `Docs/Skills/blizzard-volume-20261013.md`。
- 单纯修改首目标选取不完整；连锁、过载、客户端选点、释放复查和服务端结算须保持同一口径。
- 不默认启动游戏、测试或截图。构建成功与用户实机体验分别记录。
