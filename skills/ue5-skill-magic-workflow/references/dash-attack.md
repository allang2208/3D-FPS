# 冲刺攻击：条件、判定与群怪开销

当前技能从原 game-dev 基础下劈迁移；它是连续有效奔跑就绪后左键触发的被动，不占主动快捷栏。数据、等级、修炼、存档迁移、详情与准备提示需一起接入。当前制作记录见 `Docs/Skills/dash-attack-migration-20260920.md`；动画转 [近战战术冲刺](../../ue5-fps-arms-animation/references/tactical-sprint-melee.md)。

- 先在退出奔跑前读取就绪状态。已就绪但体力不足时不降格为普通攻击；技能成本替代本次普通挥击成本，只扣一次。占用与取消复用近战动作路径，直接击杀同样计命中与修炼。
- 前摇以最新用户要求为准。当前从源时间0.97秒播放，0.25秒后进入1.22–1.40秒接触窗；前方总夹角60°，没有额外前冲或回弹，收势到2.60秒。资产、音效、特效和判定共同使用该时间映射，不另挂墙钟延迟。
- 群怪出手卡顿先把准备计算、出招属性快照、范围查询、遮挡、伤害提交分开定位。当前源码消除了每帧准备条完整属性求值；完整技能／武器数据仅在发动时取一次。
- 可穿敌人的扇区攻击，先做一次粗筛和 Pawn 去重，构造可复用的忽略列表；每目标遮挡查询仍保留墙体，避免从第一只怪开始逐只重试导致近似 N² 射线。尸体、已命中和不可伤目标先排除；体积边缘与高度也参与扇区筛选。
- 这些是源码开销与合同修订，不能据此宣称群怪帧耗已实测降低。当前没有追加游戏性能测试；按用户明确授权再采样同场景数据。
