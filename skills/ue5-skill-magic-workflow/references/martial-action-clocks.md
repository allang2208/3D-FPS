# 连段武技与跃击的动作、权威时钟

用于多次接触的近战武技、固定节奏跳跃与大落差下落组合。本文来自 FPSGAME 连斩／跃击的制作及 2026-11-10 专项检查；不授权新的测试、截图或编辑器启动。

## 连段与镜头

- 连斩执行器不一定设置普通攻击的 `bAttacking`。第三人称采样必须有明确的技能分支，按接触标记划分四段，发布段编号、接触比例、释放比例和进度速率；只复制普通攻击状态会让旁观者看到待机。
- 加速第一下时共享源时间与播放时间映射，并提供逆映射和导数。伤害窗口、音效、手部、镜头及身体表现使用同一时钟；不要只加快相机或独立移动命中点。
- 命中停帧的进度速率为零。停／恢复作为可靠状态边沿发送，连续进度仍走已有快照；不能再用相邻帧差分覆盖执行器速率，否则远端会穿过停帧。
- 本例伤害使用前方普通挥砍范围，每段独立去重，不改成剑尖扫掠。该选择来自用户对连斩的明确要求，不推广为所有武技的默认判定。
- 起手前由服务器扣一次体力、开启 CD；取消和正常完成的修炼结算共用一次性标记。消耗回执、技能轮次和武器实例均需匹配。

## 跃击混合轨迹

- 蓄力固定 0.5 s；普通地形按 0.75 s 求解初速度。向下落差超过本例 1.2 m 时延长物理下落，用实际落地时间求水平速度，保持阈值两侧连续。
- 长下落降低水平速度后可能无法越过出发平台边缘。深落差平滑恢复起跳弧高；高目标或弱重力保留最低越顶余量。轨迹必须继续使用实际重力、终端速度和胶囊碰撞，不在到时后传送到目标。
- 0.75 s 是标准轨迹与动画节奏，不是空中结算定时器。大落差保持举锤，实际落地事件触发范围伤害、冲击波、镜头震动及免控解除；遇障转为下落时也按真实触地收尾。
- 长按预览复用现有 AOE 圈；位置每帧跟随，完整路径限频，松手与服务器重新校验所见目标。锁视角围绕提交方向，在实际落地解除。
- 空中免控和减速分开：眩晕、恐惧、束缚、冻结、石化、抓取、强制位移等入口逐条处理；减速与伤害保留。不要只挡移动输入而漏掉怪物专用控制入口。

## 数值与说明

本例连斩 L1–20 为每段伤害／削韧 40%→120%、CD 25→15 s、体力 40→60；跃击为伤害／削韧 160%→320%、CD 30→20 s、体力 45→65、半径 2.5→4 m、水平跳距 9→15 m。当前级、下一级与实战复用同一计算入口，避免伤害已乘倍率又对削韧重复乘算。

面板简写武器限制、段数／范围、伤害、体力与 CD；技能数据和硬编码详情同时更新。训练的释放、击杀、同次多杀分别记录，整次多杀奖励限一次。以上数值是具体技能设计，不是新技能的通用平衡模板。

恢复入口：工程 `Docs/Publication/SkillActions20261110/`；源码包括 `ChainSlashMotion.h`、`LeapStrikeMotion.h`、对应武器执行器与身体同步。原生物理检查和真实 UDP 覆盖分开记录，未覆盖的跃击双端位移、重连、画面／听感不能借用其他技能的通过记录。

## 双手锤跃击的落地交接

高低差跃击的预览和位移使用同一重力及终端速度，飞行阶段结束时把实际速度交给下落。落点击中可站立表面后才授权威落地攻击。碰墙、平台移走和取消按当前胶囊位置收尾；卡住且无法接地时走取消路径。相机释放贴墙避让时，从当帧视点交回普通相机，交接同一帧只应用一次偏移。
