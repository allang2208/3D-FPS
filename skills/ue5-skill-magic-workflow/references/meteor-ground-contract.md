# 地面魔法的预览、范围与锁点

适用于陨星及类似先锁地面、后释放的技能。火场和爆燃制作见 [地面火场与撞击层次](../../ue5-fluid-vfx-workflow/references/meteor-ground-impact.md)。

## 一个施法快照、一个地面坐标系

- 将伤害圈、持续圈、施法距离和实际表现参数分开命名。预览、释放、复制和效果读取同一份施法快照；半径扩大三倍与面积扩大三倍含义不同。
- 斜坡距离用 `delta - normal * dot(delta, normal)`，材质和 CPU 使用相同落点与归一化法线。目标筛选与距离衰减都使用同一脚下接触点，不混用脚下与身体中心。
- 有体积目标按身体与圆圈相交判定；中心略在圈外可能合法。层间高度带不能取代墙体/楼板暴露检查，友方身体跳过也不能使实体掩体失效。
- 预览跟随相机每帧更新位置与法线；复用 decal/MID，半径不变时不重提常量或包围盒。不要把高频拖动放进 100 ms 状态计时器。

## 两阶段锁点

- 起手由服务器校验真实地面、距离和可见性，再保存落点、法线与数值快照。释放阶段使用已保存目标，不能允许客户端重新选点。
- 如果设计允许锁定后躲入掩体，释放时只复核仍在范围内且地面有效，不重新要求视线；本地与远端必须采用同一规则。
- 网络量化容差按坐标精度给出，不用百分比放宽射程。取消/拒绝退款记录真实扣费量，CastId、Pawn 与旧回执过滤沿用 [持续魔法联机状态](persistent-magic-network.md)。

## 准备与结算

- 资产清单集中管理：预加载 V3 却让就绪回调等待旧 V2，会永远停在“素材准备中”。更换版本时同时更新运行路径、准备清单、回调绑定、作者和 Cook；包加载不等于 GPU 首次可见性准备完成。
- 持续伤害按服务器年龄和固定时间间隔推进；落下时间不计入火场寿命，表现资源晚到不能重置伤害时钟。
- 陨星现在在正常结束、施法者死亡和直接清理时，都结算此前已确认命中的修炼。结算先标记完成、移走奖励与模型引用，再调用权威档案；EndPlay 兜底也不能重奖。其他技能的死亡规则不自动跟随。
