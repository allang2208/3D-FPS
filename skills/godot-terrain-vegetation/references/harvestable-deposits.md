# 可采集树木与矿脉

用于斧头/矿镐、地表矿脉和可编辑旷野；先读当前运行实现，不把独立网格矿石称为逐格体素矿带。

- 工具动作在接触帧重新射线检查工具、距离和目标，切换工具取消未接触动作。当前 basic_toolkit 为 0.68 秒动作、0.24 秒接触、3.2 米范围；修改动作先查看现有持握和接触渲染。
- 树桩口径来自实际树干截面，断口两侧必须共用切割平面和轮廓。保留树皮外缘，木质截面仅覆盖真实截面；不要砍完突然添加宽大圆形贴片。木段收集先确认背包可接收，再移除。
- 矿石轮廓变化应包含峰谷、楔形或斜立等几何差异。随机选择稳定依赖位置，不消耗原地形 RNG 序列。视觉、凸包和底部采样必须使用同一变体及变换。
- 变形可能产生高处朝下凹面：直接使用旧岩石全部 underside 点会把矿脉压入地下。当前变体只取底部 12% 实际点拟合；该比例是此资产案例，换资产重新看贴地、悬空与露出高度。自动检查之外必须查看正式地形截图。
- MultiMesh 的批次键、实例索引、初始变换和采集移除标记要一起保存/恢复；刷新植被不能把采集隐藏的实例复活。
- 模型变体或贴地位置变更不得改变旧矿点身份。当前 harvest_identity 沿用旧源路径及旧贴地位置，新模型路径单独用于资源选择。
- 离线切割并烘焙碎片网格和凸包点，提前加载；现场不要扫描全部三角形再构建碰撞。碎片保留源 UV/材质；三向投影使用原局部坐标，碎片局部居中后通过 projection_offset 补回中心，避免纹理跳变。
- 金属反射仅作用于矿带遮罩，围岩保持粗糙；金银分别保留暖金、冷银色。使用各投影的遮罩再混合，不从混合后的颜色重复识别矿带。
- 采集奖励成功后再记录移除，背包满保留目标。测试错误工具、三击、单次奖励、邻居不受影响、存档恢复及植被刷新；测试使用隔离背包与地形存档。
