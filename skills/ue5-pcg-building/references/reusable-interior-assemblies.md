# 可复用室内组合件

用于工作台、维修墙、货架等包含许多小件的场景资产。用户要求默认不测试；本文不触发 PIE、渲染、截图或额外验收。案例数值只描述地牢工作间，不能直接作为其他资产的标准。

## 以组合件维护，而不是在关卡里逐个挪小物件

- 一个作者配置维护局部坐标、尺寸、支撑面、锚点、可用区、操作净空、种子与使用状态；关卡只放组合件根实例。重建保留实例变换，不用全场景重生成修一根电线。
- 按修改与功能边界拆子组件：桌架、桌面、工具板、灯、供电线、工具组、容器组。静态装饰可按材质和更新频率合并；交互件保留独立组件，不按每颗螺钉创建 Actor。
- 使用中／闲置／废弃可通过同一套网格的摆放、缺件、灯光和材质参数表达。组合件变体只是布景资产；注册到地牢生成器、随机选择、碰撞、玩法与存档属于后续独立接入。
- 接缝对齐依据实际接触面。例如 L 形桌统一台面高度、厚度与两段相交边，先改支撑范围，再让桌上物件随锚点更新。全模型包围盒会把把手和突出件误当连接面。

## 自然摆放要保留支撑关系

- 每类容器定义可用区域、底面和内壁，物品按尺寸、类别、数量上限和留白分组摆放。固定 seed，使重建不会不断漂移。
- 在容器内随机化平移、朝向和有限倾角；避免所有物件等间距同朝向。允许簇状聚集、局部叠放和空位，不把“自然”理解为全场均匀噪声。
- 需要真实接触的螺母、短管、保险丝可在 Blender 中短程刚体落定，烘焙最终矩阵，移除导出物的模拟依赖。静态货架不需要运行时逐件物理或 Tick。
- 线缆采用一条连续中心线，连续改变圈径、椭圆率、层高和出口方向，避免相同圆环垂直复制。按实际半径设置弯曲与离面间隙；灯线两端绑定插座和灯体入口，桌面路由从支撑面派生。地牢案例的电源线 5 mm、储备粗线 11 mm 均不是通用尺寸。

## 近景几何和表面分别解决

- 孔洞、夹口、把手厚度、壳体折边、灯罩曲面等影响轮廓与高光，做真实几何和合理圆角。木纹、拉丝、擦伤、油污、积尘主要交给 UV、法线和粗糙度；提高面数不等于提高写实度。
- 印刷标签贴合承载面。瓶身标签按圆柱曲率包覆；箱子贴纸和胶带优先在同一表面材质分区或贴图中表达，避免几乎共面的叠层和边缘薄片产生深度闪烁。需要厚度时给真实厚度和分离距离。
- 小文字、薄片、细线和近景孔洞按具体资产选择常规 Static Mesh/Nanite；本案例关闭少量货架小件的 Nanite，不推出全场景关闭的规则。
- 来源提供新旧磨损贴图时明确映射，保留 BaseColor、Normal、Roughness、Metallic 的通道与色彩空间。不要仅扩大贴图尺寸或增加全局噪点掩盖材质问题。

## 制作链与 UE 接入

- 可编辑源、配置和导出清单是真源；旧版目录若仍提供源对象、材质父级或整场景装配输入，就是依赖，不能按日期整体丢进 trash。
- 内容变更检测覆盖顶点、索引、UV、法线、颜色及材质槽，仅计算位置散列会漏掉表面更新。记录组件到 UE 资产、材质槽和实例的映射，按变更重建。
- 编辑器写入统一走项目 `Tools/AssetPipeline/mcp_call_codex.ps1` 的批次互斥，完整结果保存到本批独有文件。Python host 可能是 `-game` 进程；操作前确认实际项目、编辑器子系统、目标地图与 PIE 状态，不根据首个节点猜宿主。
- Blueprint 编译／网格重导入可能使本组合件的 OFPA 外部 Actor 包变脏。变更前记录 dirty 集合与归属，保存时只纳入本批实际造成的包；不能固化某次外部 Actor ID 或用通用绕过开关吞掉别人的未保存修改。
- 默认不运行应用验收；必要导入与保存结果和游戏效果分别陈述。用户另行要求截图时交付真实引擎或模型画面，概念图不作为完成证据。

## 本机案例与恢复边界

地牢工作间真源位于项目 `SourceAssets/DungeonWorkbenchKit20260921`，核心配置 `Config/workbench.json`、对象来源 `Config/sources.json`、周边 `Config/surroundings.json`；`Config/surrounding-sources.json` 记录货架覆盖源。货架独立作者链在 `SourceAssets/DungeonWorkshopRackPolish20260922`，布局在 `Config/layout.json`。

制作经验可复用；旧导入回执、源 FBX、Blender 文件、贴图和已安装 UE 包仍是本机恢复输入。公开 Git 仅含脚本、作者配置、说明及经整理的来源记录，不能声称克隆即可恢复完整场景。清理时保留引用链；已否决候选还要从生成任务配置中移除，避免重建复活。

## 顶棚、灯具与管线标高（2026-09-22）

- 房间高度明确表示顶棚底面；顶棚厚度向上增长，不能复用向下铺设的地板偏移。灯罩、吊杆、线槽使用同一个底面标高，面光源在实际扩散板下方留毫米级间隔。
- 柱梁与附属管线冲突时优先保留承重网格，按最大法兰/抱箍外径规划管线净距；同时考虑梁下距离、线槽外缘和悬垂电缆，固定件连接到实际承载面。
- 精密管件、抱箍、灯具使用规则建模；掉漆、氧化和积灰跟随接缝、接触位置、朝向分布，避免全表面等量锈斑。
- 房间升级后淘汰的灯具需要同时从合集网格、光源和恢复配置移除。整场景可编辑源与最终安装顺序同步，避免旧装配恢复废弃版本。
- 仅用户明确要求对应检查时，读取实际 SourceModel LOD0 做几何判定；Nanite 的 FBX 回退网格可能简化并改变边界，不适合代替精确源几何判断小净距。几何检查、实际渲染效果和用户验收分别陈述。

本机案例：`SourceAssets/DungeonServices20260922`，实施说明 `Docs/Gameplay/dungeon-services-20260922.md`；不作为后续自动运行检查的授权。

## 保留空间整体的生成扩展（2026-09-22 返工）

用户明确要求保留原样板的整体空间与氛围。已认可样板扩大化时，把一整段主路、侧开间、视线遮挡、建筑构件和灯光构图作为作者单元；原比例、局部变换、灯光单位/光强/范围、材质与局部磨损默认锁定。先以完整段落的刚体变换和明确接口组合，不用默认方房、统一大灯或掩体盒子替换，再把少量样板道具放回去。

“美术资产以后继续加”不表示可以删去已认可的空间设计。房间数与战斗角色属于玩法层，不能迫使维修开间变成通用竞技场，或把侧向遗迹发现改成终点矩形大厅。适配顺序是既有空间提供锚点，再绑定玩法。

需要连通时仅制作明确边界变体，继承实际地板标高、门框净宽、墙厚与顶棚。保留母版资产，入口/出口与短连接件另外命名。样板内的组合件、隐藏旧件、贴花、灯与材质覆盖随完整段落一并保留；不要重新猜其默认值。

返工案例：`SourceAssets/DungeonAuthoredExpansion20260922`；此前 `DungeonGenerationV1` 的 14 方房生成已被用户退回，不能作为已认可扩展模板。两个相同母版拼接仍只是空间候选，不代表完整多样化或探索战斗已完成；后续补齐不同用途段落再开放选择。默认不触发测试或渲染。

### 差异房间先完成建筑背景（2026-09-22 用户进一步明确）

用户要求下一步新增不同用途的房间，先完成墙、地、顶、柱梁、开口、管道和破墙，细部美术资产可以后补。保留原样板的比例、材质和氛围，应转化为新房间共同遵守的建筑语义；原样板作为母版保留，扩展内容以不同轮廓、顶棚节奏、绕行和侧向发现提供实际空间变化。

先用房间局部坐标配置外轮廓、地板分区、顶棚底面、门洞区间和结构／服务位置，从外轮廓生成墙体，内部地板拼区不额外砌墙。复杂组合墙上的开口优先直接按区间和断面建模；连接件必须同时扣除结构墙、墙裙和收边。管线以梁底和最大抱箍外径规划净空，低顶侧室单独定义高度过渡。

UE Python 的 Rotator 使用明确字段名，避免把 C++ 参数顺序带入 Python。修改已存在 Actor 的变换先调用 modify，并单独保存归属本地图的外部 Actor 包；仅关卡保存不能代表所有对象修改落盘。保存回执只记录制作／接入事实，用户未要求时不追加运行检查。

本机形状库：`SourceAssets/DungeonRoomShells20260922`，配置为 `Config/rooms.json`。首批管线分配间、排水检修室、破损支护室替换重复的 B 段。它们是三种固定作者配方与确定路线，运行时随机生成、导航、敌人和结算仍属后续接入。

### 认可的剥落表面必须随扩展继承（2026-09-22）

用户认可差异房间布局后，要求新房间直接同步通道已优化的剥落设计。优先复用最终作者表面与材质链，连同 UV、陶瓷厚度、釉面唇、粘结层、起伏砂浆和高度材质一起传递；禁止用随机删整砖或新造三角片替代。按墙段刚体放置与裁洞，不拉伸既有贴图和破损尺度。

当前适配入口是 `DungeonRoomShells20260922/Scripts/corridor_surfaces.py`，依赖最终 `DungeonTileFracture20260922/Authored/DungeonTileFracture_Source.blend`；改母版后重建房间即可同步。母版和原贴图是活跃依赖，不能作为旧文件归档删除。当前是复用最终烘焙墙段的作者生成方式，不宣称运行时重新计算完整剥落算法。

结构细化保持功能关系：格栅具有边框和承托；管道具备内壁、完整接头与按局部顶棚定位的吊架；破墙有沿厚度变化的截面、嵌入式骨料、变长弯曲钢筋，碎石不能全部是旋转盒子。几何承担剪影与真实厚度，已有矿物／金属材质承担微表面。

只升级细节时重导入既有网格，不重跑重建房间、灯光和锚点的整场安装器。接入回执按本轮修订维护，历史保存项不能跳过新制作文件。此经验不触发自动测试，最终效果交由用户判断。
