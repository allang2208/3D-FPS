# 附属建筑贴合共享预制件（工坊并入塔楼案例）

**第一条（FPSGAME）　文件位置与引用路径。** 从[制作目录与功能索引](../../../Docs/Production/README.md)和[存储规则第 4.1 节](../../../WORKFLOW.md#41-存储分配与文件操作边界)查找功能入口，再确定制作源、正式资产与输出位置；交付时在同一功能条目登记位置、发布回执和 `Before/` 恢复版本。

适用：固定建筑（工坊、仓库、马厩）与玩家可建造的共享预制件（`SM_HighWatchtower`、门楼）相邻，需要视为一个整体，去掉穿模并做自然过渡。参考：[author_workshop.py](../../../SourceAssets/HillsVillageHighWall20261120/GarrisonWorkshop/author_workshop.py)。

## 原则

1. **共享预制件不改。** 塔楼同时被所有玩家建造实例使用，只裁切和补强附属建筑这一侧的网格、碰撞、家具和运行时道具。
2. **先把预制件换算到附属建筑的局部坐标。** 由两者的 `Pose`（位置、Yaw、地面 Z 偏移）推出映射，例如 `xw = -623 - xt, yw = 60.26 - yt, zw = zt - 15`；在内存中生成预制件网格，按材质分组导出主墙面、角石（`±4 cm` 外凸）、散水护坡（`+14 cm` 线性收至 `+1 cm`）、门洞拱石的精确边界。为什么：凭肉眼对齐会漏掉角石和护坡外凸，只留 `1–4 cm` 的穿插也会闪烁。

## 过渡细节清单

- 地基和地板改成 L 形，避开预制件墙体；墙脚加铺石收边和倒角踢脚线（与墙面留 `0.2–1 cm`，避免共面）。
- 原侧墙在预制件跨度内整段删除（包括窗）；伸出预制件两端的残段用斜面楔石嫁接散水护坡，抹灰停在墙面外 `0.26 cm`。
- 室内露出预制件石墙：贴墙壁柱加石柱墩、锻铁锚箍、缩短的系梁和斜撑、贯通的墙顶托木和屋面托木。
- 屋面在预制件墙面处截断，留下伸出两端的翼部；接缝加阶梯式泛水和侧向斜泛水，下面衬托木。预制件里不再使用的门洞，用贴合拱形的木板门封住（缩进到拱石内侧，不接触外凸的拱石）。
- 家具、交互 Socket、NPC 站位、灯具、`BuildingDaylight` 房间边界、地面贴花和建造占地探测框，全部迁入未遮挡的空间并同步收缩。

## 验证与评审

- 离线 3D 审计：附属建筑全部顶点和碰撞盒，相对预制件主墙、角石、护坡、拱石，穿透为 0、共面（`< 0.05 cm`）为 0；运行时道具按半径检查。
- Blender Cycles 多机位评审：外景两侧、屋面与门洞、室内主墙、转角凹室、预制件内部各一张，检查漏光、缝隙和闪烁。评审图属于一次性产物，结论写入功能条目，图片按清理规则归档。
- 发布同时包含外壳和家具网格（不要只发布门头），Socket 坐标随导入脚本一起更新。
