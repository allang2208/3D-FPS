# 铜矿脉

旷野散石候选 i%11==5 且宽度至少 .65 米的实例使用铜矿材质，保持原摆放随机序列、碰撞与视距。与已有 i%11==0 铁矿选择分开，材质批次隔离。

矿镐三次接触采集，原矿脉碎成 8 块，获得普通材料 `copper_ore`（铜矿）×1，堆叠上限999。背包满时保留目标；不额外奖励石块或铁矿。使用原有采集移除存档，读档和地形刷新不复活。

COPPER_PREVIEW=1 运行 tests/render_scenic_rock.gd --fixed-fps 24，生成144帧实际模型动画；COPPER_HARVEST_TEST=1 运行 tests/test_scenic_rock_harvest.gd，检查正式旷野铜矿采集、奖励、邻近实例和存档。资产目录 README 记录颜色依据、贴图生成来源与渲染方法。未新增冶炼或建筑配方。
