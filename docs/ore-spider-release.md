# 矿石蜘蛛正式发布与复现

正式入口 `scenes/enemies/ore_spider.tscn` 使用获批 V07 模型及跟掌投掷。保留 `_preview` 文件名以避免资源重复；它现在是正式资产。主场景新增一只矿石蜘蛛，其他现有敌人和 UI 沿用远端基线。

## 内容

- 105 骨骼、12 条支撑足链、独立投掷臂；腿根权重闭合与交错支撑步态。
- 获批 5080 TRELLIS.2 生成贴图，非金属矿石/肉质材料；未虚构额外法线贴图。
- Idle 3 s、Walk 1.4 s、Throw 1.5 s、Slam 2 s、Death 1.2 s；投掷释放 1.125 s。死亡包含原设计临终下砸、崩解和保尸。
- 等级 6 精英，HP 650、基础攻击 45、防御 46、移速 2.1 m/s；投石物理伤害 56、范围 1.4 m、飞行 1 s；下砸内圈 90、外圈 45，按原合同结算一次。
- 棱角矿石弹体、抛起碎石、贴地尘浪与上升烟团；特效不额外伤害，约 1.1 s 清理。

通用经验见 `skills/godot-monster-workflow/SKILL.md` 对应章节；具体量测与踩坑见其 `references/ore-spider-case.md`。

最终源：`tools/ai-gen/ore-spider-impact-v07-20260906/ore-spider-impact.blend`。Blender 5.1 执行同目录 `export_final.py` 可直接导出正式 GLB；Godot 对该资产使用 90 FPS 导入。若要重做本轮甩臂，`build_impact.py` 所需 V06 输入模型一并保留。更早阶段的完整本地源链未删除，不将全部候选和重复渲染帧塞入本次发布。

投掷及烟尘预览为 V07 `throw.gif`，步态、下砸、死亡沿用同骨架前一版已认可动作，预览在 V06 目录。`tests/render_ore_spider_impact.gd`、`tests/render_ore_spider_release.gd` 可重新渲染；逐帧目录属于可再生成输出。
