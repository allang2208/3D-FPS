# 四把步枪聚合物统一与改造件复查 — 2026-09-07

按用户授权，把 AKM 的分区聚合物风格应用到其余四把步枪：AK-105（fps_akm）、HK416、QBZ-191、M16A2。P9 不在这四把步枪范围内。已进入正式视模与改造预览路径，8 张背包/改造图标同步更新。

## 当前设计与接入

灰蓝上部、石墨机匣、深色握持面/弹匣、少量橙色识别带；零金属度，按区域区分细磨砂与光滑操作面。保留各枪型原有轮廓、导轨、镂空与刻线，不增加覆盖整枪的体素或大方格。只复制网格颜色通道编码设计坐标，顶点位置、法线、UV、索引、骨骼权重和动作不变。原始源文件和许可证不变；本轮没有重新建模或新增动画。

共享材质：`assets/materials/rifle_layered_polymer.gdshader`；表面处理与分区：`scripts/rifle_polymer_finish.gd`；正式入口：`scripts/infima_viewmodel.gd` 的初始化与配件应用。使用现有源法线的低强度细节，不读取做旧颜色贴图；后握把独立碳纤维/木纹法线不带入聚合物表面。光学镜片、红点、发射器、反射面和软橡胶保留功能区别。

## 本轮发现并修正

1. AK-105/HK416 预览过去直接加载 GLB 并走独立材质链，会覆盖新材质。改为和游戏加载同一视模场景；移除这四把枪的末尾旧材质覆盖。
2. 只有 material_override 的配件被覆盖，使用 surface_override 的扩容弹匣等仍保留旧材质。现在两条表面路径都处理，扩容弹匣不再错误沿用枪身坐标分区。
3. HK416 更换配件会替换合并网格，导致新颜色坐标丢失。改为按实际网格资源标记分区，替换时补齐、恢复时复用，不反复复制已处理网格。
4. M16 的真实资源名是 m16_modular_v2，已显式映射，避免漏掉该枪。
5. Handguard/Handstop 不能被手部排除条件误判，已细化过滤。

本次外观与接触检查未发现需要改动共用配件几何的新增缺口；没有把材质修复宣称为几何重建。前握把共用几何、挂点和手部姿态保留并行任务的现状。
