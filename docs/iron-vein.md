# 铁矿脉采集

旷野原有散石序列中，每第 11 个候选且宽度至少 .65 米的石块使用铁矿脉材质；沿用原摆放坐标、尺寸、随机数序列、贴地碰撞和视距，不修改大型岩壁或普通石材材质。矿脉和普通石块使用不同绘制批次。

F7 工具模式 → 7 矿镐 → 三次有效接触。末次原模型碎裂为 8 块，背包获得普通材料 `iron_ore`（铁矿）×1，堆叠上限999。不会发普通石块，也不增加原型石材余额；背包满则保留矿脉，整理后可继续。未增加冶炼配方或铁制建筑消耗。

复用 `quarried_rocks` 存档和实例移除，读档/地形刷新不复活；旧存档中已采集的对应石块仍保持移除。新增材质只作用于铁矿批次；碎片使用同源矿脉材质并补偿切分中心，避免碎裂时纹理重新定位。

`IRON_HARVEST_TEST=1` 运行 `tests/test_scenic_rock_harvest.gd`，验证真实矿脉、工具限制、三击、铁矿入包、去重、存档和相邻实例保留。`IRON_PREVIEW=1` 运行 `tests/render_scenic_rock.gd --fixed-fps 24` 输出独立实际模型预览；正式旷野截图为 tools/basic-tools/iron-vein-in-world.png。材质来源、生成提示和实际尺寸见资产目录 README。
