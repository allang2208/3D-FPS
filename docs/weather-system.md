# 天气系统

接入公共 `WorldEnvironment` 的室外场景，沿用24分钟一天的游戏时钟。自动天气由 `scripts/weather_schedule.gd` 根据存档中的 `weatherSeed` 和游戏日生成随机天气过程；新存档各自抽种子，旧存档使用稳定兼容种子。读档和换场景恢复同一时刻的天气，不会重新抽签。

## 动态天气规则

- 晴天阶段随机70–120秒，阴天30–50秒；相邻晴天会连续保持，实际晴天可更长。
- 每个完整天气过程在阴天后有90%概率降雨，否则直接回到晴天。
- 小雨先持续85–115秒，其中80%继续发展为中雨55–85秒；中雨中有28%进一步形成暴雨30–55秒。
- 暴雨先退为中雨25–40秒，再退为小雨25–35秒，最后阴天30–50秒后放晴。单次连续降雨最多330秒，过渡消退另需约15–25秒。
- 每天尾部留出至少90秒晴天，容纳不下的整轮天气不启动，避免午夜切断暴雨。不是每天必下雨，也不是每场雨必有雷暴。
- 仅在阶段到期、时间回退或存档种子变化时重新计算；无逐帧随机抽签。暂停不推进时钟。手动天气仍由F6控制。
- 默认长期降雨目标约40%。固定种子72124模拟1000个游戏日：晴天41.41%、阴天17.86%、小雨25.91%、中雨13.05%、暴雨1.77%，合计降雨40.74%；最长连续雨约321秒。这是天气阶段时间占比，过渡尾雨另计，不是每一天的硬性配比。


## 使用

- **F6**：切换到下一档手动天气，顺序晴天/阴天/小雨/中雨/暴风雨。
- **Shift+F6**：恢复自动天气。
- 过渡使用5秒时间常数，约15秒达到目标的95%。手动选择跨场景保留，退出游戏后回到自动模式。
- 脚本入口：`WorldEnvironment.weather.set_weather("storm")`；第二个参数 `true` 为预览/测试立即切换。`resume_automatic()` 恢复自动。

## 效果与预算

- 128×128可重复噪声云图，启动生成并缓存。单层空间云球叠在日月/星空前方，不使用体积云光线步进。CPU按同一UV和双线性采样计算云遮日/月比例，减弱直接光；严重遮挡时关闭对应方向阴影。
- 雨只在相机附近24×24米范围发射，GPU模拟30 Hz，上限1200粒子。小雨18%（约216）、中雨50%（约600）、暴风雨100%，对应不同风偏和音量。软边雨滴，不增加投影阴影或逐滴物理碰撞。
- 每0.25秒一次上方碰撞射线检测近身遮蔽：屋顶下隐藏近身雨滴、降低雨声。它不是整片屋顶形状的粒子碰撞模拟，室内向外观雨仍有进一步细化空间。
- 暴风雨每12–25秒一次闪电：远处折线电光、短促双脉冲云光和无阴影方向闪光。雷声按300–900米距离/343计算，延迟约0.87–2.62秒，使用三条合成雷声并轻微改变音调。
- 雨声/雷声接入现有SFX总线；雨声连续循环，清除天气和退出场景时停止。暂停同时暂停天气推进与延迟雷声计时。
- 天空/雾/日月光照共用10 Hz刷新，闪光只更新空间材质和额外无阴影灯；不会因为闪光要求天空辐照每帧重算。

## 验证与资源

- `test_weather.gd`：自动段落、云光一致、三档雨量预算、声音播放、雷声延迟、暂停、晴天清理和实体屋顶遮蔽通过。
- 原 `test_day_night.gd` 和主场景180帧无头冒烟通过。
- `render_weather.gd`：D3D12 / Forward+、1280×720实际查看晴天/阴天/三档雨和闪电；`--motion` 配合引擎 `--fixed-fps 60` 输出480帧、8秒动态预览。GIF不带声音，游戏中雷声正常独立播放。
- `--benchmark` 记录强制绘制+读回样本。不同天气会改变阴影开销，样本也受着色器预热及共享机器负载影响，不能将其中位数直接宣称游戏FPS或稳定提速。
- 预览：`docs/preview/weather-runtime/`；单图和动态帧由渲染脚本生成。
- 当前音效由 `tools/generate_soft_rain.py` 和 `tools/generate_wilderness_thunder.py` 生成；第一版单声道音频已淘汰清理。来源说明见 `assets/sfx/weather/SOURCE.md`，没有第三方录音或付费生成依赖。

范围：天气表现，不包含闪电伤害、积水地形、装备湿度或其他玩法数值。

## 2026-09-06 闪电与雨声更新

- 闪电为28段不规则主通道、5条渐细分叉，单个网格和局部柔光材质；无投影阴影、无全屏Bloom。25毫秒生长、随机90–170毫秒复闪，整体720毫秒衰减余光；云光与场景闪光单独短促衰减。
- 雨声换成两条24秒原创合成立体声循环：柔和底声与细碎雨点，随雨量分别按平方根/1.35次方混合，增益以0.7秒时间常数平滑，停雨后淡出。雨滴视觉保持此前参数。
- 修正循环终点：以时长×采样率计算采样帧数，不能用压缩数据字节数/2。新版资产明确使用不压缩PCM，循环终点529200。
- 本次实际场景预览用60 Hz引擎帧输出，避免旧12 fps GIF导致闪电时序失真；属于引擎离线定步长捕获，不是实时性能测量。

### 荒野炸雷

雷声已换为三条11秒原创合成立体声：短促多重裂响、叠加低频滚雷，以及逐渐模糊的远处回响。回响在资产内预混，不新增实时混响总线或卷积开销；仍用单个3D播放器，空间声像强度0.4，基础音量-6 dB。每次轻微变调0.96–1.03倍，距离延迟仍约0.87–2.62秒。自动闪电间隔到期后，还会等待上一条雷声播完，避免不同距离造成的延迟变化截断尾音。合成回响用于开阔感，并非真实荒野声学采样。
