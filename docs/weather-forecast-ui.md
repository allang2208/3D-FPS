# 当前区域天气事件

保留原项目事件进度条的收起/展开、时间轴、图标、类型筛选和详情交互；撤回顺序卡片布局。

- 当前区域最多一个天气事件：正在下雨时显示本场降雨，否则预告最近的一场降雨。
- 晴天、阴天属于常态天气，不单独加入事件栏；不会把未来五天的每段天气全部列入。
- 连续的小雨、中雨、暴雨合为同一场降雨，同场事件ID不随雨势变化。雨停后移除，再预告下一场。
- 图标沿用原项目PNG；进行中的图标匹配当前雨势。未来一场包含雷暴时提前提示。
- 点击事件查看开始、结束、持续时间，以及依次发生的雨势阶段；阶段不会形成多个同时显示的事件。
- 非天气事件保留原provider及聚合规则。沿用冷钢UI、SimHei字体、左Alt鼠标开关。
- 天气实际调度、40%降雨比例、24分钟一天和音效保持现有配置。

验证脚本：`tests/test_event_timeline.gd` 检查跨日唯一降雨事件、实际雨势一致性、同场ID稳定、晴天不入栏与交互布局。`tests/render_event_timeline.gd` 输出1920/1280/960实际渲染至 `docs/preview/weather-event-bar/`。

开发入口：[天气标准工作流](weather-development-workflow.md) 与 [天气SKILL](../skills/godot-weather-workflow/SKILL.md)。
