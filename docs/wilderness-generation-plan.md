# 10 倍旷野程序化生成与性能分层

## 当前落地

- 现有 1024m × 1024m Terrain3D 保持为近景可交互区，继续负责地表碰撞、可采集树木、矿脉、河流和挖掘存档。
- 新增 10240m × 10240m 远场环带。远场由四块低面数网格和一张 512px 宏观贴图组成，不创建物理体、采集物、AI 或逐棵树节点。
- 世界规则使用 `seed + 世界坐标` 查询高度、河道、湿度、温度和生态区。生成结果不依赖区块加载顺序，可复现，也适合后续后台线程生成。
- 远场内边缘读取现有 Terrain3D 高度并在 180m 内混合，避免近远地形裂缝；远场关闭投影，且只在 360m 外显示。
- 新游戏世界种子独立保存，删除轮回档案时同步删除；再次进入旷野或读档不会换种子。
- 规则注册表自动发现 `assets/data/wilderness/rules/*.tres`，当前含两类树木与铁、铜、银、金矿脉。
- 后台队列以玩家区块为中心按距离排序，最多两个低优先级 WorkerThreadPool 任务；区块生成和原子缓存都在线程完成，缓存数据不进入场景树或显存。
- 区块缓存包含高度、地表、宏观颜色、树木/矿脉候选、稳定 feature_id 和水系验证结果。

## 完整流式方案

| 距离玩家 | 表现 | 碰撞/玩法 | 更新策略 |
|---|---|---|---|
| 0–450m | Terrain3D + 原模型/近档 LOD + GPU 草 | 树干、矿脉、河岸、AI 全开 | 3×3 活跃区块 |
| 450–1500m | 地形低档 + 树林 impostor/MultiMesh | 不生成实体和碰撞 | 玩家跨 256m 区块边界时更新 |
| 1500–5120m | 本次落地的低面数网格 + 宏观贴图 | 无实体、无碰撞、无脚本处理 | 进入旷野时生成一次 |

当前后台队列会按距离逐步生成并缓存玩家周围 9×9 区块。`chunk_presenter.gd` 只在玩家接近时由主线程每帧最多提交一个区块的地表、水面、MultiMesh 和地形碰撞；离开活动环后立即卸载。中心 1 km 保留经验证的手工出生山谷，越过边界后进入公式地形；450m 外不生成采集/AI 实体，1500m 外只保留远场贴图。

## 生成公式

1. 高度：大陆低频噪声 + 丘陵中频噪声 + 小尺度起伏 - 河谷侵蚀 - 世界边缘衰减。
2. 河流：以世界 X 为参数的多频正弦主河道，河宽随低频函数变化；地形、颜色和生态区共用同一个河距函数。
3. 生态区：湿度、温度、高度和河距组合为河流、森林、草甸、旱地、高山区。
4. 树木：在近景区块内按生态密度做确定性蓝噪声/泊松盘采样，树种由生态区决定；中景只提交 MultiMesh impostor。
5. 矿石：用独立低频矿脉噪声形成带状富集区，再用坐标哈希决定矿种和变体；只在实体半径内创建可采集节点。

## 性能合同

- 60 FPS 目标帧预算 16.6ms；区块提交不得造成单帧超过预算。
- 桌面端建议常态 draw calls ≤ 2000；远场固定为 4 个网格节点和 1 份共享材质。
- 动态阴影限制在 60m 左右；中远景 LOD/impostor 禁止投影。
- 远场永远不挂 `StaticBody3D`、`CollisionShape3D`、AI 或 `_process`；生成完成后零持续 CPU 更新。
- 保存 `world_seed`、玩家修改过的区块坐标及稀疏 edits，不保存整张高度图。读档必须复用原 seed，避免已采集矿脉或树木换位。
