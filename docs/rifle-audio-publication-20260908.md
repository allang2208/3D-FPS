# 换弹音效模块发布（2026-09-08）

本次公开提交提供可独立复用的换弹音效调度器与弹鼓动画时间映射。四枪音频事件复用 M16 调度器，普通与空仓分别配置；音频使用姿态同一 delta，弹鼓事件采用动画同一非线性映射，短声保持自然音高，中断停止事件和尾音。

## 发布内容与接入边界

- `scripts/m16_action_audio.gd`：原三参数 begin 调用兼容，增加可选 drum 参数和 start_cues 接口。
- `scripts/rifle_reload_audio.gd`：AK105、AKM、HK416、QBZ191 的接触时点；未发布的专用声音会明确回退到已有 CC0 M16 机械音。
- `scripts/large_drum_reload.gd`：动画关键帧与事件共用时间映射，不依赖模型文件。
- AKM 与 QBZ191 六段 CC0 机械音、两份原始公开下载及加工脚本。公开版运行 `python tools/prepare_rifle_audio.py --weapons akm_classic qbz191`，需 numpy、scipy、soundfile；不含本地 HK416/AK105 派生音，默认全量命令缺源时会明确退出。

远端缺少本地五枪视模及其资产，故本提交不更换远端 Gun、WeaponData 或主场景。完整接入仍在本地工作区：建立对应音频节点，play_action 时 begin，advance_pose 时 advance，收枪时 stop；Gun 有事件播放器时禁止同时播放旧整段换弹录音。完整集成测试依赖本地模型，没有复制成无法运行的公开测试。

用户最终选择：AKM 普通开火恢复与 AK105 共用 `akm_burst.mp3`。另选 AKM 实录裁切作本地消音器声音。后者来自 Sonniss GDC 2016 / Pole Position Production，允许游戏使用但不可作为独立音效公开再分发，因此此次 GitHub 提交不含该 WAV。原录音未标记使用消音器，该用途是游戏听感选择。
