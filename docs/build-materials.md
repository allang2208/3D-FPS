# 建造材料接入

- 木材 `wood` 与石块 `stone`：普通（common），材料分类，单格最多 999。图标复用现有木、石体素的实际模型缩略图。
- 木地板、木墙面、木天花板每块消耗木材 1；石地板、石墙面、石天花板、大理石块每块消耗石块 1。配方集中在 `scripts/building/build_costs.gd`，面板与放置逻辑共同读取。
- 只使用随身背包。选择预览不收费；有效放置扣除，材料不足、占用、缺支撑均拒绝。保存失败回退当前放置和背包扣除；旧建筑恢复不补扣。沿用现有拆除规则，不增加材料返还。
- 木段 E 收集、旷野现有独立石块三击采集时发放物品。背包满则保留目标供稍后采集。旧工具统计与地形实验编辑器材料余额保留，不自动兑换为物品。
- `tests/test_build_materials.gd` 验证定义、实时面板、木石与大理石扣除、失败不扣、背包满及库存保存；1280×720 实际面板截图在 `docs/sky-base/build-materials-1280.png`。树木及旷野石块按原有专项测试回归。
