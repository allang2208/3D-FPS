# 冷钢玻璃 UI 标准

2026-09-07 用户确认：冷钢配色 + 玻璃材质 + 加粗宋体。沿用 apple-glass 文件名以兼容已有引用；这是项目设计规则，不是苹果官方规格。

## 状态与优先级

本文件及 `ui/apple-glass-tokens.json` 是现行视觉真源。用户后续明确要求优先；原项目快照仅作为业务、信息布局和历史来源。旧蓝紫主色、SimHei、微软雅黑主字体和人工增加字距方案均不再作为新页面验收标准。

冷钢玻璃已推广到公共Style、项目默认字体、背包四页、NPC功能面板、主菜单/设置/加载、建筑及地牢共用UI。正文和标题统一宋体0.5，数字Consolas。实际覆盖、截图和未通过的旧测试见 [全局审计](global-ui-audit-2026-09-07.md)，不将公共接入等同所有游戏流程验收。

## 颜色与材质

| 角色 | 色值 |
|---|---|
| 画布 / 更深背景 | #080B0E / #050709 |
| 玻璃染色 / 内容承托 | #171D23 / #10151A |
| 主文字 / 次文字 / 辅助文字 | #DCE2E6 / #B5C0C8 / #9AA4AD |
| 普通强调 / 焦点 | #94ABB6 / #B8D6DF |
| 细边原色 | #DCEAF0，按层级降低透明度 |
| 有利 / 提醒 / 不利 | #68D5AD / #F0BE71 / #FF8193 |

材质层次：低频暗背景 → 染色模糊外壳 → 安静内容托底 → 清晰文字和物品。外壳表现圆润厚度、细亮边与软阴影，格子和每条数值不各自叠厚玻璃。运行材质基准：blur_lod 3.5、折射1.5px、染色0.72、输出alpha0.96；这些是着色器参数，不是CSS blur半径或直接透光率。文字与枪械模型不参与折射。

外壳圆角24，内容卡16，控件12；背包外框18、格内物品2是明确例外。平直网格放在有内边距的圆角容器内，边角裁切一致，不将每个格子改成圆形按钮。亮暗背景均检查文字可读性；玻璃失效时用同色不透明托底。

## 字体与排版

- 中文、普通界面文字：SimSun，`simsun.ttc` face 0；`FontVariation.variation_embolden=0.5`；额外字距0。这是用户认可的引擎预览值，不宣称等同CSS700。不要恢复+1/+2px字距或改回黑体。
- 纯数字、计时、容量：保留Consolas及既有原生粗体，中文回退宋体；图标/emoji专用字体保留。
- 灰度抗锯齿、Light hinting、四分之一像素定位、MSDF关闭，以已确认预览为基准。逐个检查实际命中的字体、face、字号、缩放和局部覆盖；不靠节点缩放或描边模拟粗体。
- 新标准角色：展示32、页面24、分区20、正文16、次级14、辅助12px。普通页面最多四档，禁止全部文本同一大字号。
- 已确认背包例外：背包标题20、装备空槽标签16、格内物品名12、竖向加工标识10px；保持当前字号，只统一字体粗细。枪械改造使用24/20/16/14四档。960宽窗口的格内数量允许10px并限制在本格，物品名仍12px。
- 标题行高约1.25、正文约1.5，仅作为排版目标，不把倍数直接填入Godot像素行间距。默认靠容器间距建立层次；不在文本中插空格排版。
- 名称、状态、效果和数字分控件。名称允许受控省略并提供完整查看；主要介绍正常换行。已有装备浮窗不自动折行的用户合同仍保留，不泛化到全屏改造说明。
- 所有页面消费Style公共角色；不要在单页新建另一套字体资源。资源接入和发行授权确认在实际迁移阶段处理，当前预览来自本机字体。

## 布局和游戏合同

基础间距4/8/12/16/24/32；外壳内边距24，组间距24，行间12，卡间8，主要按钮40–44px高。受保护的既有背包尺寸优先。

- 背包：右侧45%宽、上下全高；装备区15槽3×5不变。占用装备卡仅展示中央图、左侧稀有度与强化、右侧改造与附魔标识；不加名称/介绍。空槽仅部位文字，无淡图案。
- 空间背包：横向18列，初始4行72格，按行优先填充；单格边长为可用内宽/18。外边距12、内边距14。溢出纵向滚动；不以无限新增行偷偷扩大逻辑容量，扩容须有真实容量来源。
- 长枪横5×纵2，药水1×1。底板上的低对比占格线位于物品图下；拖动合法区域按真实占地显示。
- 放置严格按抓取偏移后的候选锚点；交换验证双方完整占地，重叠/越界/多目标冲突整体拒绝；堆叠剩余保留。不得为外观变化修改实例ID、弹药、加工属性或存档。
- 枪械改造保持全屏专用布局，候选、效果、最终数值、撤销与应用均保留；具体翻新见专项计划。
- 仓库、强化、附魔、交易、任务等逐页迁移。主HUD时钟/进度栏保留已认可的空间关系，更新材质和文字时单独回归，不能套背包布局。

## 状态、动效与验证

默认/悬停/选中/按下/禁用/键盘焦点成套设计；选中与待应用同时有文字标识，不只靠颜色。收益按实际参数语义判断，降低后坐/耗时是收益，不按正负号机械染色。

悬停140ms、按下90ms、选中180ms、面板260ms、落位220ms为目标值；不弹跳、不拉伸文字，不持续流光。减少动态效果时保留静态状态和透明度变化。

实施验收：真实GPU截图1920×1080、1280×720、960×540；同状态同尺寸比较字体、边界、滚动与模型完整性。读出实际控件字体/face/字号/字重/字距，不能用AI图片验收文字。正常文字对比度目标4.5:1，大字与关键非文字3:1；玻璃背景必须现场测量，规则值不代表已经达标。键盘操作、焦点、取消和关闭返回单独验证。

文档、原型、正式运行迁移和发布分别记录，不相互替代。历史视觉文本已归档到 `docs/history/ui-before-cold-glass-20260907/`，仅用于追溯。

### 装备卡侧边词条（2026-09-07）

稀有度、强化、改造、附魔共用 `ReferenceStyle.badge_surface`，4px圆角，上下内缩4px。装备卡侧边内缩6px、条宽14px、相邻间隔4px；紧凑物品卡侧边内缩4px，稀有度宽12px、加工条宽10px。中间图片、名称、数量与价格须避开可见色条。强化采用加工Token的金色底与深色字；改造、附魔沿用对应语义色。高度不够容纳三字时只省略“已”，保持字号和状态含义。刷新物品后不得残留上一件的加工标记。

本次验证：`tests/test_badge_fit.gd` 覆盖六档稀有度、三类加工的八种组合、同帧换物与紧凑边界；真实引擎输出1920/1280/960宽样张。装备效果文字634项回归通过。

### 快捷栏（2026-09-07）

按用户要求参考原 game-dev 的 `game-style.css:60–74、611–618`、`ui/panel-theme-backpack.css:1513–1570` 以及 `src/ui/panels/hud-panels-misc.js` 快捷栏结构。技能Q/E/X与物品1–4保持现有绑定，槽位48×48、7px圆角、1px细边、间距8px；两组前各有分隔线。冷钢玻璃外框圆角10px、内边距9px，底部留白12px。按键统一右下角，数量顶部居中、正常绿色/耗尽红色，物品图标40×40居中，冷却数值居中；字体继续使用当前公共字体。保留当前技能无图标及不持续闪烁规则，不恢复原项目C键业务。容器实际最小尺寸决定整体宽度，自动居中。验证：`tests/test_hotbar_glass.gd`，三种宽度及绑定交换通过。
