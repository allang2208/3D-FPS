# 现代僵尸发布记录 · 2026-09-06

目标为 `https://github.com/allang2208/3D-FPS.git` 的 `main`。从远端基线 `b0d7276` 建立隔离发布副本；原开发工作区的 `master` 有 25 个未发布提交及大量并行修改，本次未整批推送。

## 本次内容

- 普通现代僵尸、工装矿工、狂奔僵尸采用 Low Poly V02：8572 / 11532 / 8428 三角面，各 31 骨。不新增眼球和牙齿，保留原脸神态。
- 保留 Denys 原动作与 UAL 补充动作，16 段动画的采样与 V01 一致。新增可配置攻击/死亡时间与左右攻击轮换，主场景增加两个变体。
- 同步必要的物理 shape owner 映射修正，避免头部节点顺序变化后，身体/头部倍率对应错误。没有夹带本地弹丸对象池、武器或 UI 的其他改动。
- 黑狼黑毛、僵尸犬仍为独立候选；工头 V09 已停止采用，源和最终对照保留作历史。其余工头模型仍使用远端已发布的 V08。
- 整理本任务六个制作目录和两个运行资产目录：删除 7,435 个数字逐帧截图、Blender 自动备份及无引用的 V01 运行副本，释放 658.40 MiB。保留编辑源、许可、重建输入、V01 动画对照 GLB 和最终 GIF/检查表。
- 经验写入怪物技能的 `references/modern-zombie-reuse.md`，入口与旧案例注明当前版本。本机已同步该分卷。
