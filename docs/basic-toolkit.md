# 基础采集工具套件 · 2026-09-06

正式入口：旷野按 6/7 直接进入伐木斧/矿镐采集状态，5 为空手，F7 返回原武器。新体素工具存档提供各一把工具，默认空手；工具所有权仍由工具存档管理，采集产物进入 RPG 背包。左键按住使用，右键和 1–4 保持现有地形填充/选材行为。

## 当前效果

- 伐木斧：仅砍带 `landscape_asset` 和 `impact_surface=wood` 标记的旷野树木。第三次命中断裂倾倒，留下树桩与 4 段木材，按 E 逐段收集；完整说明见 `docs/tree-felling.md`。
- 矿镐：泥土、岩石和矿石共用挖掘许可，沿用现有密度场、网格/碰撞重建；泥土、石块和矿物分别进入正式背包，满包时目标保持不变。
- 空手、错误工具、未拥有工具、工具模式关闭均不能采集。有效距离 3.2 米；全动作 0.68 秒，0.24 秒重新射线检查目标并结算，切换工具或返回武器取消未命中动作。
- 独立体素实验场同样需要装备矿镐。树木采集针对正式旷野现有树干碰撞，不把石块、树桩或草误判为树。木材改为落地后手动收集，不在斧击时直接发放。
- 原地形存档路径后附 `.tools-v1.json` 保存工具所有权、木材及已砍树稳定位置/资源标识，临时文件写完再替换。刷新植被不能复活已砍树。旧地形档无需迁移；损坏工具档保留并报告保存失败。
- Ctrl+Z 仍仅撤销地形编辑，不撤销砍树。木段、旷野石块及平滑地形采集发放正式背包物品 `wood` / `stone` / `soil` / 对应矿物（普通，999 堆叠）；背包满时保留采集目标。平滑地形修改和背包奖励采用一次事务保存，任一侧失败同时回滚。建筑工坊从背包扣除材料，木质体素木材 ×1，石质体素（含大理石）石块 ×1；旧原型填充储备不再因正式旷野挖掘而增长。

## 资产与风格

来源：Kenney Survival Kit 2.0，作者 Kenney，CC0，免费修改及商用。

- 作者页面：https://kenney.nl/assets/survival-kit
- 作者公开发布：https://opengameart.org/content/survival-kit
- 原包：https://opengameart.org/sites/default/files/kenney_survival-kit.zip
- 原始文件：`tool-axe.glb` / `tool-pickaxe.glb`；许可证随运行资产保存。
- 统一处理：木柄低对比纵向木纹，冷灰锻钢和亮色刃口分材质，1.5 mm 边缘倒角；斧长 0.72 m，镐长 0.86 m，握点距柄底 22%。保留同包低模轮廓。
- 可编辑源：`tools/basic-tools/basic_tools.blend`；可复现脚本 `tools/basic-tools/prepare.py`；GLB 位于 `assets/models/basic_tools/`。
- 本源包仅静态模型，无原始工具动作视频/动画轨道。本次新增工具动作，不属于既有 2D 动作迁移；起势、接触、收势由 `scripts/tools/basic_toolkit.gd` 定义，GLB 不包含角色手臂骨骼动画。
