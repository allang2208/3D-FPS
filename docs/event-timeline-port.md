# 时间进度栏与天气预报迁移合同

> 保留原事件进度条格式。天气仅接入当前区域正在发生或最近即将发生的一场降雨，连续雨势合为一个事件，晴天与阴天不单独入栏。当前规则见 `weather-forecast-ui.md`。

## 功能对应

| 原功能 | Godot行为 |
|---|---|
| 紧凑360px、展开560px、顶部居中 | 默认紧凑，160ms展开/收起；窄屏与现有时钟重叠时向下避让 |
| 红黄蓝绿满幅时间轴、4%现在游标 | 保留方向、渐变、双层标记、呼吸提示；事件向现在靠近 |
| 全部/类型筛选、计数、类型消失回退 | 动态类型列表，移除最后一个该类事件后回到全部 |
| 密集事件簇 | 8%区间内超过2个事件合并，原始事件无丢失；点开可滚动查看 |
| 天气详情 | 位面/区域、强度、开始、结束、持续、提示、当前/预测状态 |
| PNG图标与fallback | 原文件直接复制，不重画；晴天/阴天为符号，符合原组件符号回退机制 |
| 悬停、键盘聚焦、关闭、Esc、重复点击 | 按原行为接线；收起同时关闭详情，Esc消费后不穿透至游戏 |
| 入侵状态、危险边框、支援按钮 | `set_invasion_model(data,action)`或场景provider提供真实状态与动作；没有数据则显示暂无入侵情报 |
| 事件provider聚合 | `model.register_provider(id, callable)` / `unregister_provider(id)`；场景可提供 `get_timeline_events(frame)` |

## 预报数据与适配边界

- 天气事件直接读取 `weather_schedule.gd` 的同一seed/游戏日计划，每个预报区间都对照真实排期测试。
- 连续晴天跨阶段/日期合并展示，减少重复图标。读档、时间倒退、换场景刷新数据；退出场景关闭原详情。
- 手动F6天气只显示当前手动天气，结束时间未知；Shift+F6恢复真实五日预报。没有Weather环境的场景不给出虚假天气。
- 源项目的预测塔/科技解锁、跨位面入侵战斗系统不是该UI组件。3D当前没有这些同名业务，本次按用户请求直接开放当前区域预报，保留真实事件接入接口；没有伪造塔等级、入侵倒计时或支援传送。
- 原CSS字体由当前Godot公共SimHei规则替代：标题加粗，正文/数字常规。原时间轴9/10/11/12px紧凑字号为有来源的HUD例外，集中在样式适配器；CSS模糊阴影与Godot渲染不逐像素相同。
- 详情在快捷栏之上；小窗口长列表可滚动，关闭按钮固定。位置移动不重建正在看的列表，不复位滚动。
- 模型每0.25秒刷新，天气日计划缓存；没有重复生成实际天气、粒子或声源。预报不会改变40%的长期降雨调度参数。
