# 冷钢 UI 与背包迁移（2026-09-05）

目标项目：`E:/3d/3-dfps`。原始参考：`E:/无尽轮回/长期备份/2026-7-13-1/game-dev`，未修改参考项目。

## 已接入

- 当前主题 `cold_steel`：炭黑背景、冷灰渐变卡片、银白强调、微软雅黑字体、原版指针；背包右侧 45% 宽抽屉、250ms 开关、720p/1080p 布局、冷钢按钮/滚动条/操作弹窗。NPC 面板保留现有居中工作区并适配窗口。
- 原 equipment.json 全量 194 项定义和 189 个引用图像；保留现有 Godot 的少量补充定义。迁移脚本及来源清单位于 tools/migrate_inventory_assets.py、assets/data/inventory-migration.json。
- 默认十格背包；实例身份、分堆、上限堆叠、同类合并、异类交换、整理、右键使用/装备/拆分/查看/丢弃。Shift+点击拆分。1–4 快捷栏通过实例绑定，整理后仍可使用；药品恢复生命/魔法及百分比恢复。
- 十五个装备位，主副手限制、双手武器挤出规则、满包时整笔装备操作失败且不改变物品；装备拖回指定背包格支持合法交换。
- 百格五页仓库：指定格交换/合并、批量存取、整理；与背包间保留强化、改造、附魔和其他实例字段。
- 现有商店、强化、改造、附魔、祭品合成、出征面板共用实例流转。购买容量检查/失败退款，出售按数量结算；加工槽和出征栏满包归还失败时保留物品，卷轴逐张消耗，前后缀效果共同保留。
- 本地版本化存档包含背包、装备、快捷栏、仓库、金币、面板暂存物品、地面丢弃物及当前角色属性/技能分配。库存变更合并自动保存，保存按钮可手动保存；临时文件写完后替换正式文件。仓库/金币由 HUD 跨场景持有，取消场景重复赠送测试物资。
- 丢弃确认后生成脚边可见物，靠近按 F 拾取；背包满时拾取失败保留地面物。

## 使用

B/Tab 打开装备背包，K 技能，Caps 角色状态，Esc 关闭。右键物品打开操作菜单；拖拽物品移动，拖入快捷栏绑定。保存位置为 Godot `user://inventory-cold-steel-v1.save`，不会读取或覆盖浏览器 IndexedDB 存档。

## 验证

- `tests/test_inventory_migration.gd`：36 项断言通过。覆盖容量、数量守恒、唯一实例、堆叠/拆分/整理、跨仓库交换、双手装备失败原子性、强化属性保留、存档覆盖和还原、八个 NPC 面板打开、满包加工槽与出征物品归还。
- Godot 4.7.1 主场景无头运行 120 帧无脚本错误。
- `tests/render_inventory_migration.gd` 在 OpenGL 兼容渲染器输出并检查 1920×1080、1280×720 UI 预览。预览使用独立 UI 场景，不是实战画面；未把鼠标完整手动游玩作为已验收结果。
- 测试使用 `INVENTORY_SAVE_PATH` 隔离正式存档。

## 与原游戏完整移植的边界

本次交付是现有 Godot 内的冷钢主题和背包操作闭环。原游戏的世界/邮件 IndexedDB 存档转换、完整任务奖励链、伙伴系统、金币物品化与仓库能量经济，以及每件武器对应的 3D 模型和全部战斗特殊效果，仍属于后续系统迁移。现有 Godot 数值金币接口及 NPC 合成/附魔规则继续使用其已有配置；不能把图标和装备元数据迁入等同于这些外围系统已全部重写。
