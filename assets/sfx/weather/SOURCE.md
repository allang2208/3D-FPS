# Weather audio provenance

The first mono rain/thunder experiment was superseded and its unused WAV/import
files removed during the 2026-09-06 cleanup. The historical generator remains
in tools/generate_weather_audio.py for provenance, not for runtime rebuilding.

## Soft rain revision (2026-09-06)

`rain_soft_v2.wav` and `rain_patter_v2.wav`: original 24-second stereo,
22050 Hz / 16-bit PCM, generated by `tools/generate_soft_rain.py` (NumPy).
Periodic spectral filtering and circular patter envelopes make the boundary
continuous without a silent fade or overlap-volume dip. Gentle 1.4 kHz and
2.8 kHz spectral rolloffs reduce hiss. No third-party recordings.
Imported as uncompressed PCM with forward looping; runtime endpoint is
529200 sample frames, independent of stereo byte count. The old rain was removed after reference checks. Base gain <=0.52, patter <=0.38;
0.7-second gain smoothing, reduced mix under shelter, both use SFX bus.

## Wilderness thunder revision (2026-09-06)

`thunder_wilderness_1.wav` through `thunder_wilderness_3.wav`: original
11-second stereo, 22050 Hz, 16-bit source PCM, synthesized with NumPy by
`tools/generate_wilderness_thunder.py`. No external samples or recordings.
Irregular micro-cracks precede overlapping low-frequency rolling bursts.
Softened reflection clusters at approximately 0.43/0.88/1.47/2.25/3.25 seconds
spread differently across both channels, followed by a smooth tail. This is
an artistic open-land sound, not a measured wilderness impulse response.
Peak <=0.88 full scale; runtime -6 dB plus 3D distance attenuation. No loop.
Old thunder assets were removed after reference checks.
