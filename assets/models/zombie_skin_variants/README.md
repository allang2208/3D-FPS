# Zombie randomized cosmetic variants
Each modern/ordinary, miner workwear, and runner zombie chooses its own original/new albedo with equal probability during modern_zombie._ready. DungeonZombie inherits the same entry point.
Only color textures are added: original mesh, animation, normal/roughness textures, stats and rewards remain unchanged. Materials are copied per instance before the enemy caches its damage-flash material.
appearance_choice=-1 is random; 0/1 pins a choice for previews or authored scenes. chosen_appearance records the selected appearance.
