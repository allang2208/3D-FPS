无尽轮回 · UI 调色面板

1. 点击「加载 palette.json」选择 E:\3d\3-dfps\ui\palette.json　 2. 拖动色块/输入 hex 调色　 3. 导出文件覆盖原 ui\palette.json　 4. 重开游戏生效（Godot 启动时自动读取）
「风格配置」对应 ui\style-config.json：圆角、间距、字号、动效、主题开关。 编辑后点「校验并导出」，覆盖原文件，重开游戏生效。
主题：dark_gold = 旧 2D 暗金板；gold_white_gray = 金白深灰定稿板（推荐）。
色值格式：#RRGGBB 或 #RRGGBBAA（AA 为透明度）。
THEME_* = 金白深灰定稿板（DESIGN.md）；COLOR_* = 旧 2D 暗金板（当前生效）；RARITY_* = 稀有度色。 修改色值后如涉及 DESIGN.md 关键 Token，记得同步更新 DESIGN.md，否则 test_ui_tokens 会提示不一致。
