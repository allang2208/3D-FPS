# 胖子僵尸向后倒地死亡 V02

用户已要求改做向后倒地。本目录为独立候选，不修改主项目刷怪、死亡逻辑、毒伤或尸体时间。

## V02 腿部落地修正
上一版躯干接地校正抬高了整副骨架，导致脚部悬空。本版保留躯干倒地轨迹，在躯干校正之后单独解算腿链。
左腿从 .88 秒、右腿从 .94 秒开始放下，分别于 1.36 / 1.42 秒完成。双腿微微外展，膝盖伸展但不锁死；脚跟按实际蒙皮最低点贴近地面。
重新导入 GLB 检查：左右脚部最低点均约 .008 个源模型单位；整段 127 个采样帧未检测到穿地。实际 Godot 正侧面预览已重新渲染。

## 参考与动作设计
制作前完整查看了工头原项目死亡动作参考（death-reference.jpg），并读取 reference-contract.md：14 帧、1.4 秒，非循环，屈膝后坐、背部落地、腿部伸展；其业务为停尸 1 秒再淡出 .3 秒。这里只借鉴动作顺序，不迁移工头业务。
胖子原项目只有 21 帧/1.5 秒融化，缺少向后倒地参考。当前为用户授权的新设计，保留胖子死亡表现 1.5 秒时长，不宣称精确还原原图。

0–.18 秒失衡；.18–.57 秒屈膝、重心后移；.57–.94 秒加速后倒；约 .94 秒背部落地；.94–1.22 秒轻微回弹、头手迟滞；1.22–1.5 秒收势。
左右肢体错峰约 .06 秒，腿部先支撑再抬起伸展。头部在落地附近有延迟。骨盆位移与地面校正烘焙在骨架动画中，接入时不能再额外整体翻倒或重复根位移。
死亡单次播放停末帧。GIF 重复仅供查看，末帧另停 .9 秒。
