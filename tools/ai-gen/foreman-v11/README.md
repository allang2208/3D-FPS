# 左侧空手修整 V11

基于 V10，保留右臂、鞭子网格及骨架静止位置。

检查证据：左臂 5132 顶点、6866 个平面着色面；原始左前臂/手掌配合重建袖子，权重按世界高度分带，上袖全部跟随上臂。右臂 5463 顶点，因此差异不能简单归咎于面数。Howl 原实现分别插值骨段位置与方向，过渡中可能产生连接偏差。

修改：仅松弛重建袖子内部顶点，固定开放边界；左臂使用平滑法线和一层 SIMPLE 细分以增加变形采样，保留手指原始轮廓和 UV；左袖单独重映射到原贴图细节完整的区域，避开原贴图中的块状低细节部分，并降低法线贴图强度。按肘腕骨轴重建三骨权重并沿实际网格邻接平滑，袖口连接仍共用上臂驱动，避免开缝。本轮不是重做独立手指拓扑，也没有新增手指骨骼。

Walk、Death、Howl 只改左侧上臂/前臂/手的动画通道，修正骨段连接；行走加入小幅腕部滞后，死亡加入有限的放松回落，呼喊调整腕姿。其他动画通道逐项比较保持原样，但共享左臂网格/权重也会影响其他动作外观。

参考原工头 Walk 15 帧/1.5 秒、Death 14 帧/1.4 秒、Howl 24 帧/3 秒动作表。保持既有步态、后倒顺序、左手号召右手持鞭身份。GIF 重复仅用于预览。

模型候选未替换正式游戏资产。渲染和 validation.json 来自导出 GLB 重新导入，检查三个动作的有限数、骨段连接、地面、缩放和首尾。检查不代表完整游戏运行验收。
